# 數位簽章

數位簽章是一種加密證明，可證明特定人士簽署了文件，且文件自簽署後未被修改。不同於手繪簽名（只是一張圖片），數位簽章使用 X.509 憑證與 PKCS#7 標準，提供可驗證的真實性與完整性。

BentoPDF 完全在您的瀏覽器中套用數位簽章。您的私密金鑰絕不會離開您的裝置。

## 運作方式

1. 上傳 PDF 檔案。
2. 上傳您的憑證檔案（.pfx、.p12 或 .pem）。
3. 輸入憑證密碼以解鎖。工具會顯示憑證的主體、簽發者與有效期間。
4. 可選擇設定簽章中繼資料（原因、地點、聯絡資訊）。
5. 可選擇啟用 **可見簽章**，並自訂位置、大小、圖片與文字。
6. 點擊 **簽署 PDF**。

## 支援的憑證格式

| 格式        | 副檔名     | 說明                                                                     |
| ----------- | ---------- | ------------------------------------------------------------------------ |
| **PKCS#12** | .pfx, .p12 | 業界標準的封裝，包含私密金鑰與憑證鏈。最常見的格式。                     |
| **PEM**     | .pem       | 文字格式。必須在同一個檔案中同時包含憑證與私密金鑰。支援加密的私密金鑰。 |

## 可見簽章選項

啟用後，PDF 頁面上會繪製可見的簽章區塊：

- **位置**：以點為單位的 X/Y 座標與寬度/高度
- **頁面**：第一頁、最後一頁、所有頁面或指定頁碼
- **圖片**：上傳 PNG、JPG 或 WebP 圖片（您的手寫簽名、公司印鑑等）
- **文字**：自訂文字，可設定顏色與字型大小。如果未提供圖片或文字，工具會依憑證的一般名稱與目前日期自動產生文字。

## 簽章中繼資料

- **原因**：簽署文件的原因（例如「已核准」、「已審閱」）
- **地點**：簽署的地點（例如「New York, NY」）
- **聯絡資訊**：聯絡簽署者的方式（例如電子郵件地址）

## 網際網路連線說明

簽署可能需要網際網路連線。簽署程式庫會從憑證的授權資訊存取 (AIA) 擴充中內嵌的 URL 取得憑證鏈。如果無法連線到這些伺服器，需要驗證憑證鏈的憑證將無法完成簽署。

## 使用情境

- 以具法律效力的數位簽章簽署合約、提案與協議
- 在需要 PKI 驗證的工作流程中認證正式文件
- 為符合法規要求簽署 PDF 發票（許多歐盟國家要求電子發票須經數位簽署）
- 為工程圖或品質文件加上組織核准

## 提示

- 自簽憑證可用於測試，但在 Adobe Reader 中會顯示警告。正式文件請使用受信任憑證授權單位核發的憑證。
- 可見簽章純屬視覺效果。無論是否啟用可見區塊，加密簽章都會被嵌入。
- 使用驗證簽章工具檢查已簽署的 PDF，確認簽章完好無損。

# PDF 歪斜修正

掃描文件很少完全端正。即使是輕微的傾斜，也會降低 OCR 的準確度，並讓列印結果顯得凌亂。此工具使用 OpenCV 的影像處理演算法偵測每一頁的歪斜角度，並將其旋轉回水平。

## 運作方式

1. 上傳一個或多個掃描的 PDF。
2. 設定 **歪斜門檻值**：偵測到的歪斜低於此值的頁面將維持不變。
3. 選擇 **處理品質 (DPI)**：較高的 DPI 可提升偵測準確度，但需要較長時間。
4. 點擊 **修正 PDF 歪斜**。
5. 處理完成後，結果面板會顯示每一頁偵測到的角度，以及是否已修正。

## 選項

| 設定           | 數值                  | 預設值 |
| -------------- | --------------------- | ------ |
| **歪斜門檻值** | 0.1、0.5、1.0、2.0 度 | 0.5    |
| **處理 DPI**   | 100、150、200、300    | 150    |

## 歪斜偵測的運作方式

工具會以所選的 DPI 將每一頁轉為圖片，接著使用 OpenCV 偵測內容中主要線條的角度。如果偵測到的歪斜超過門檻值，頁面會以相反角度旋轉以拉直。低於門檻值的頁面則原樣保留。

## 使用情境

- 整理批次掃描的合約或法律文件
- 為 OCR 處理準備掃描的收據或發票
- 拉直平台式掃描器因紙張擺放不一致而歪斜的頁面
- 提升數位化檔案資料的視覺品質

## 提示

- 如果 OCR 需要像素級精準對齊，請將門檻值降至 0.1 度。
- 對大多數文件而言，150 DPI 既快速又準確。文字非常小或細節豐富的頁面請使用 300 DPI。
- 歪斜修正最適合具有清楚水平文字行的文件。對於大部分是圖片或含有斜向設計元素的頁面，效果可能較差。

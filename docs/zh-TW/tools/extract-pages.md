# 擷取頁面

從 PDF 中取出一組頁面並另存為新檔案。使用範圍語法精確指定您要的頁面，工具會建立只包含這些頁面的乾淨 PDF。

## 運作方式

1. 上傳 PDF 檔案。工具會顯示檔名、大小與總頁數。
2. 使用範圍語法輸入要擷取的頁面（例如 `1-5`、`3, 7, 10-12`）。
3. 可選擇將每個範圍分別下載為獨立的 PDF，並打包成 ZIP 封存檔。
4. 點擊處理按鈕。擷取的頁面會下載為新的 PDF（或 ZIP）。

## 功能

- 彈性的頁面範圍語法：單頁、範圍或以逗號分隔的組合
- 上傳後顯示總頁數，方便參考
- 可選擇輸出為單一合併 PDF，或以 ZIP 打包的個別檔案
- 保留原始頁面內容與格式

## 使用情境

- 從冗長報告中取出執行摘要（前幾頁）
- 從教科書 PDF 中擷取單一章節
- 將表單套件中的特定頁面另存為獨立文件
- 從大型檔案中選取部分頁面建立樣本文件

## 提示

- 頁碼從 1 開始。第一頁請使用 `1`，而非 `0`。
- 若要移除頁面而非擷取，請使用 [刪除頁面](./delete-pages)，這是相反的操作。
- 如果您需要以縮圖視覺化選取頁面，請使用 [分割 PDF](./split-pdf) 的視覺選取模式。

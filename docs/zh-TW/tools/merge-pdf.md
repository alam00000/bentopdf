# 合併 PDF

將多個 PDF 檔案合併為單一文件。您可以依特定順序合併整個檔案，或切換到頁面模式，精細控制每個已上傳 PDF 中的個別頁面。

## 運作方式

1. 點擊放置區或將檔案拖曳進來，上傳兩個以上的 PDF 檔案。
2. 使用頂端的切換開關，在 **檔案模式** 與 **頁面模式** 之間選擇。
3. 在檔案模式中，拖曳檔案以重新排序，並可為每個檔案指定頁面範圍（例如 `1-3, 5`）。範圍留空則包含所有頁面。
4. 在頁面模式中，拖放個別頁面縮圖，建立您想要的確切頁面順序。
5. 點擊 **合併 PDF** 將所有內容合併為一個檔案。合併後的 PDF 會自動下載。

## 功能

- 兩種合併模式：檔案模式可快速合併整個檔案，頁面模式可逐頁控制
- 兩種模式皆支援拖放重新排序，並有流暢動畫
- 頁面範圍語法（例如 `1-3, 5, 8-10`）讓您不必切換到頁面模式也能挑選特定頁面
- 延遲載入的頁面縮圖，即使處理大型文件也能保持介面流暢
- 檔案數量與總頁數沒有限制
- 保留原始 PDF 品質，不重新編碼

## 選項

| 選項         | 說明                                                             |
| ------------ | ---------------------------------------------------------------- |
| **檔案模式** | 依自訂順序合併整個檔案，並可為每個檔案設定頁面範圍篩選           |
| **頁面模式** | 以視覺化格狀顯示所有檔案的所有頁面，拖曳縮圖建立您想要的確切順序 |
| **頁面輸入** | 每個檔案的文字欄位，可輸入如 `1-3, 5` 的範圍，只包含特定頁面     |

## 使用情境

- 將各章節的 PDF 合併為一本書或一份報告
- 將求職信與履歷合併為一份申請文件
- 從多份來源文件中擷取特定頁面，整合成一個檔案
- 將掃描的收據或發票彙整為一個封存 PDF
- 從多份簡報中挑選投影片製作講義

## 小技巧

- 當您需要交錯不同檔案的頁面，而非將檔案逐一接在後面時，請使用頁面模式。
- 初次上傳後，您可以使用 **新增更多檔案** 按鈕加入更多檔案，而不會遺失目前的排列。
- 頁面範圍從 1 開始計算，因此 `1` 代表該檔案的第一頁。

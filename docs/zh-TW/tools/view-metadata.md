# 檢視中繼資料

檢查 PDF 檔案中內嵌的隱藏屬性。此工具會以易讀的格式顯示文件資訊（標題、作者、日期）、XMP 中繼資料、頁面尺寸及其他結構資料。

## 運作方式

1. 上傳 PDF 檔案。
2. 工具會立即解析檔案，並將所有可用的中繼資料分區顯示。
3. 檢閱文件資訊字典、XMP 中繼資料樹與結構屬性。
4. 不需要任何處理步驟，檔案載入後就會顯示中繼資料。

## 功能

- 顯示標準文件資訊欄位：標題、作者、主旨、關鍵字、建立者、製作程式
- 以易讀格式顯示建立與修改日期
- 解析並呈現完整的 XMP 中繼資料樹，包含巢狀命名空間
- 將 PDF 日期格式（`D:20240101120000Z`）轉換為易讀的日期
- 以可摺疊的區塊整理，方便瀏覽

## 中繼資料區塊

| 區塊             | 內容                                                             |
| ---------------- | ---------------------------------------------------------------- |
| **文件資訊**     | 標題、作者、主旨、關鍵字、建立者、製作程式、建立日期、修改日期   |
| **XMP 中繼資料** | 完整的 XML 中繼資料樹，包含 Dublin Core、XAP、PDF 與自訂命名空間 |
| **文件屬性**     | 頁數、PDF 版本、檔案大小、加密狀態                               |

## 使用情境

- 查看 PDF 的作者以及最後修改時間
- 在發布文件前確認中繼資料已正確設定
- 檢查內嵌了哪些個人資訊，以稽核 PDF 的隱私
- 調查建立或修改 PDF 所使用的軟體（透過「製作程式」欄位）
- 檢閱 XMP 中繼資料是否符合數位資產管理規範

## 提示

- 以 `D:` 開頭的 PDF 日期字串會自動轉換為您當地時區的格式。
- 如果中繼資料欄位是空的，表示 PDF 建立者並未設定它們。並非所有 PDF 都包含豐富的中繼資料。
- 檢視後若要修改中繼資料，請使用[編輯中繼資料](./edit-metadata)。若要完全清除，請使用移除中繼資料。

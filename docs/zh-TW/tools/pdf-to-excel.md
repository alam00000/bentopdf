# PDF 轉 Excel

從 PDF 擷取表格，並儲存為 Excel（`.xlsx`）試算表。每個偵測到的表格都會放在獨立的工作表中，並標示表格編號與來源頁面。表格偵測由 PyMuPDF 提供，Excel 產生則使用 SheetJS 函式庫。

## 運作方式

1. 點選拖放區或將檔案拖曳到其中，上傳 PDF。
2. 點選**轉換**開始擷取表格。
3. 工具會掃描每一頁的表格，然後建立 Excel 活頁簿。
4. 下載 `.xlsx` 檔案，每個表格一張工作表。

## 選項

此工具沒有可設定的選項。所有偵測到的表格都會自動擷取。

## 輸出格式

- 單一 `filename.xlsx` 檔案。
- **一個表格**：單一工作表，名稱為「Table」。
- **多個表格**：工作表名稱為「Table 1 (Page 3)」、「Table 2 (Page 5)」等。工作表名稱會截斷為 31 個字元（Excel 的上限）。

## 使用情境

- 將 PDF 財務報告轉換為可編輯的試算表，以便進一步分析。
- 從供應商 PDF 擷取庫存或訂單表格。
- 將 PDF 表單或型錄中的結構化資料匯入 Excel 以便排序與篩選。
- 以非技術同事也能使用的格式封存 PDF 表格資料。

## 小技巧

- 如果工具回報「找不到表格」，表示該 PDF 很可能使用自由排列的文字版面，而非結構化表格。請改用 [PDF 轉文字](./pdf-to-text) 取得原始內容。
- 若要更簡單的平面格式，請使用 [PDF 轉 CSV](./pdf-to-csv)。若要以多種格式逐一下載表格，請使用 [擷取 PDF 表格](./extract-tables)。
- 查看工作表名稱即可得知每個表格來自哪一頁。

# 複製與組織

使用視覺化的拖放介面重新排列、複製及移除 PDF 頁面。每一頁都會以縮圖顯示，您可以在將結果儲存為新檔案前移動、複製或刪除它們。

## 運作方式

1. 上傳單一 PDF 檔案。
2. 工具會產生顯示每一頁的縮圖網格。
3. 拖曳縮圖來重新排序頁面，點選綠色的複製按鈕複製頁面，或點選紅色的刪除按鈕移除頁面。
4. 您也可以在文字欄位中輸入自訂頁面順序（例如 `3, 1, 2, 4`），再點選**套用**一次重新排列所有頁面。
5. 點選處理按鈕，產生並下載重新整理後的 PDF。

## 功能

- 拖放重新排序頁面，並附有動畫轉場
- 每頁皆有複製與刪除按鈕
- 自訂頁面順序輸入，精確重新排列
- 每次變更後自動更新的頁碼標籤
- 防止刪除最後剩下的一頁

## 使用情境

- 將報告中放錯位置的頁面移到正確位置
- 複製表單頁面，讓一個檔案中有多份空白副本
- 在發送文件前移除草稿或預留頁面
- 為列印準備而反轉或調整頁面順序
- 不需重新合併個別檔案即可建立自訂頁面順序

## 小技巧

- 自訂頁面順序欄位需要以逗號分隔的原始頁碼。每一頁都必須剛好出現一次，不可遺漏或重複。
- 複製頁面後，兩份副本都參照同一個原始頁面索引。重新排序任一份副本都互不影響。
- 若需要跨多個檔案的大量操作或更進階的工作流程，請考慮改用 [PDF 多功能工具](./pdf-multi-tool)。

# SVG 轉 PDF

將 SVG（Scalable Vector Graphics）檔案轉換為 PDF。此工具會透過瀏覽器的轉譯引擎將每個 SVG 光柵化，再以原生解析度嵌入結果。適合將向量圖示、圖表與插圖轉換為可攜式文件。

## 支援格式

| 格式 | 副檔名 |
| :--- | :----- |
| SVG  | `.svg` |

## 運作方式

1. 點擊上傳區域，或拖放一個或多個 SVG 檔案。
2. 檢查並管理檔案清單。
3. 選擇 **PDF 品質** 等級。
4. 點擊 **轉換為 PDF**。結果會下載為 `from_svgs.pdf`。

每個 SVG 都會以文字讀取，依其固有寬度與高度轉譯到畫布上（若未指定尺寸則預設為 800x600），並匯出為 PNG。接著使用 pdf-lib 將該 PNG 嵌入 PDF。透明區域會以白色背景填滿。

## 選項

**PDF 品質** 控制光柵化後的壓縮程度：

- **高品質**：最接近原始轉譯效果。
- **中等品質**（預設）：良好的平衡。
- **低品質**：檔案最小，會損失部分細節。

## 使用情境

- 將 SVG 格式的建築或工程圖表轉換為可供印刷的 PDF
- 將圖示集打包成設計系統的參考 PDF
- 將資料視覺化圖表（D3.js、圖表函式庫匯出）轉為可用於報告的 PDF
- 製作 SVG 資訊圖表的可列印版本

## 提示

- 沒有明確 `width` 與 `height` 屬性的 SVG 檔案會以 800x600 像素轉譯。為獲得最佳結果，請在轉換前於 SVG 原始碼中設定尺寸。
- 含有外部字型參照或連結圖片的複雜 SVG 可能無法完美轉譯。請將所有資源內嵌到 SVG 中，以取得可靠的輸出。
- 由於 SVG 會被光柵化，PDF 中包含的是點陣圖而非向量路徑。若需要真正的向量 PDF 輸出，則需要專用的向量工具。

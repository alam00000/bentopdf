# 建立 PDF 表單

從零開始設計專業的可填寫 PDF 表單，或在現有 PDF 中加入欄位。視覺化編輯器可讓您將表單元素（文字欄位、核取方塊、下拉選單、選項按鈕、簽名欄位等）直接拖放到頁面預覽上。設定欄位屬性、建立條件式顯示規則，並匯出完整互動式的 PDF 表單。

## 運作方式

1. 上傳現有的 PDF，**或** 點擊 **建立空白 PDF** 從零開始。
2. 如果建立空白 PDF，請選擇頁面尺寸（Letter、A4、A5、Legal、Tabloid、A3 或自訂尺寸）。
3. 表單編輯器會開啟，包含欄位類型工具列與頁面預覽區域。
4. 從工具列選擇欄位類型，然後點擊頁面放置欄位。
5. 拖曳欄位以調整位置。使用調整大小控點調整尺寸。
6. 點擊欄位開啟屬性面板，您可以在其中設定欄位名稱、預設值、字型大小、對齊方式等。
7. 使用頁面控制項在頁面之間切換。
8. 點擊 **儲存** 下載完成的可填寫 PDF。

## 功能

- 拖放式欄位放置，附有視覺化的調整大小控點
- 欄位類型：文字輸入、多行文字、核取方塊、下拉選單、選項按鈕、簽名、日期、數字與條碼
- 屬性面板可設定每個欄位的名稱、標籤、預設值、字型大小、顏色、對齊方式與驗證
- 欄位動作與條件式顯示規則（依其他欄位的值顯示或隱藏欄位）
- 多頁表單的頁面導覽
- 擷取現有欄位：自動偵測並匯入已上傳 PDF 中的表單欄位
- 可使用上傳的 PDF 或空白頁面作為表單畫布
- 多種頁面尺寸預設值以及自訂尺寸
- 由 bwip-js 提供的條碼產生功能
- 選項按鈕群組管理

## 選項

**頁面尺寸預設值（適用於空白 PDF）：**

- Letter (8.5" x 11")
- A4 (210mm x 297mm)
- A5 (148mm x 210mm)
- Legal (8.5" x 14")
- Tabloid (11" x 17")
- A3 (297mm x 420mm)
- 自訂（指定寬度與高度）

**欄位屬性（依欄位類型而異）：**

- 名稱、標籤與預留位置文字
- 預設值
- 字型、大小與顏色
- 文字對齊（靠左、置中、靠右）
- 必填欄位切換
- 唯讀切換
- 文字欄位的最大長度
- 下拉選單與選項按鈕的選項清單
- 條件式顯示動作

## 使用情境

- 建立新進員工到職表單，用文字欄位填寫個人資料，用核取方塊確認政策
- 建立客戶資料問卷，以下拉選單選擇服務項目
- 設計含計算欄位與條碼識別碼的訂購單
- 建立以選項按鈕標示合格／不合格的檢查清單
- 建立會依回答顯示後續問題的條件式問卷

## 小技巧

- 如果您上傳現有的 PDF，工具會嘗試擷取其中已有的表單欄位，讓您編輯或新增欄位。
- 使用選項按鈕群組功能建立互斥選項。同一選項群組中的欄位共用一個群組名稱。
- 下載表單並在 [PDF 表單填寫器](./form-filler) 中開啟，以測試欄位行為。

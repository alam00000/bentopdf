# 調整顏色

完整的 PDF 色彩調整工具組。可調整八個獨立參數：亮度、對比、飽和度、色相偏移、色溫、色調、Gamma 與復古棕褐色，並在移動每個滑桿時即時更新預覽。

## 運作方式

1. 上傳您的 PDF 檔案。
2. 編輯器會開啟，顯示第一頁的預覽與色彩設定面板。
3. 移動滑桿以調整各項色彩參數。預覽會即時更新。
4. 點選**重設**將所有滑桿還原到預設位置。
5. 點選**套用**以處理所有頁面並下載調整後的 PDF。

## 選項

- **亮度**：讓整頁變亮或變暗（-100 到 +100）。
- **對比**：增加或減少明暗區域之間的差異（-100 到 +100）。
- **飽和度**：提高或降低色彩強度（-100 到 +100）。設為 -100 會產生灰階效果。
- **色相偏移**：旋轉色輪，統一偏移所有顏色。
- **色溫**：讓顏色偏暖（黃色/橘色）或偏冷（藍色）。
- **色調**：加上綠色或洋紅色調。
- **伽瑪值**：使用 Gamma 曲線調整中間調亮度。低於 1.0 的值會讓中間調變暗；高於 1.0 的值會讓其變亮。
- **復古棕褐色**：套用經典的棕褐色調效果。數值越高，棕色調越強。

## 功能

- 八個可獨立調整的色彩參數
- 即時預覽，立即反映滑桿變化
- 重設按鈕可快速回到預設值
- 處理文件中的所有頁面
- 適用於任何 PDF 內容（文字、圖片、圖形）

## 使用情境

- 調亮較暗的掃描檔，或修正過度曝光的頁面
- 在列印前降低彩色文件的飽和度以減少墨水用量
- 套用棕褐色調，為證書或獎狀營造復古風格
- 修正 PDF 中內嵌照片的色溫
- 提高褪色或低品質掃描文件的對比

## 小技巧

- 若要快速轉為灰階，請將飽和度滑桿拉到 -100。
- Gamma 滑桿特別適合改善中間調過暗或過亮的掃描文件的可讀性。
- 與其他圖片效果工具一樣，此工具會將每頁點陣化。輸出將以圖片為基礎，因此文字無法選取。

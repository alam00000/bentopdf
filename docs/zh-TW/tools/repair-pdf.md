# 修復 PDF

當 PDF 無法開啟、顯示亂碼內容或在檢視器中觸發錯誤時，此工具會嘗試重建其內部結構。它使用 QPDF 的修復引擎，可從許多類型的毀損中救回資料，例如損壞的交互參照表、截斷的串流、無效的物件參照等。

## 運作方式

1. 上傳一個或多個損壞的 PDF 檔案。
2. 點擊 **修復 PDF**。
3. 單一修復檔案會直接下載。多個檔案則產生 ZIP 壓縮檔。

此工具會以 `--decrypt` 旗標將每個檔案交給 QPDF 處理，強制 QPDF 讀取並重寫整個 PDF 結構，並在過程中修正可復原的問題。

## 功能特色

- 一次批次修復多個 PDF
- 自動偵測可復原與無法復原的檔案
- 處理多個檔案時，逐一回報每個檔案的成功或失敗
- 使用 QPDF（WebAssembly），一套久經考驗的 PDF 轉換函式庫

## 可修復的問題

- 損壞或遺失的交互參照表
- 下載不完整造成的檔案結尾截斷
- 無效的物件編號與串流長度
- 有錯誤的 PDF 產生器造成的輕微結構不一致
- 解密失敗留下的加密殘留

## 無法修復的問題

- 嚴重截斷、大部分內容資料已遺失的檔案
- 以您沒有的密碼加密的 PDF
- 實際上不是 PDF 的檔案（副檔名錯誤）
- PDF 內的圖片毀損（結構會被修正，但不會重新產生像素資料）

## 使用情境

- 救回電子郵件下載失敗的 PDF
- 開啟由舊版或非標準 PDF 產生器製作的檔案
- 修正在某個檢視器中正常、在另一個檢視器中卻無法使用的 PDF
- 為長期保存準備損壞的封存文件

## 提示

- 如果修復失敗，請先嘗試在瀏覽器中開啟檔案。瀏覽器有自己的復原邏輯，可能可以轉譯出足夠的內容讓您重新儲存。
- 對於修復失敗的加密 PDF，請先使用解密 PDF，再修復解密後的輸出。

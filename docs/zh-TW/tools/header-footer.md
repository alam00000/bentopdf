# 頁首與頁尾

在 PDF 頁面的六個位置加入文字：頁首左側、頁首中央、頁首右側、頁尾左側、頁尾中央與頁尾右側。此工具支援頁碼與總頁數的動態變數，因此您可以建立像「第 3 頁，共 10 頁」這樣會依每頁自動更新的範本。

## 運作方式

1. 上傳您的 PDF 檔案。
2. 選項面板會出現，顯示格式控制項與六個文字輸入欄位。
3. 在任一頁首／頁尾位置輸入您想要的文字。
4. 使用 `{page}` 與 `{total}` 預留位置進行動態頁碼編排。
5. 調整字型大小、字型顏色，並可選擇限制於特定頁面範圍。
6. 點擊 **新增頁首與頁尾** 進行處理並下載。

## 選項

- **頁面範圍**：可選擇限制哪些頁面加上頁首與頁尾。留空則套用至所有頁面。格式：「1-3, 5」（以逗號分隔的範圍）。
- **字型大小**：介於 6 到 24 點之間。預設為 10。
- **字型顏色**：使用顏色選擇器挑選任何顏色。
- **頁首左側／中央／右側**：每頁頂端的文字欄位。
- **頁尾左側／中央／右側**：每頁底部的文字欄位。

## 功能

- 每頁六個獨立的文字位置
- 動態 `{page}` 變數，插入目前頁碼
- 動態 `{total}` 變數，插入總頁數
- 頁面範圍篩選，可指定特定頁面
- 可自訂字型大小與顏色
- 使用 Helvetica 字型，輸出簡潔專業

## 使用情境

- 在報告的頁尾中央加入「第 {page} 頁，共 {total} 頁」
- 在頁首左側放置公司名稱，並在頁首右側放置文件日期
- 在法律文件的頁尾加入機密聲明
- 在特定頁面範圍標上文件修訂版本號

## 小技巧

- 在同一欄位中結合 `{page}` 與 `{total}`，即可做出「第 {page} 頁，共 {total} 頁」或「{page}/{total}」等格式。
- 大部分欄位都可以留空，只填寫您需要的位置。空白欄位會直接略過。
- 若需要含圖片或標誌的複雜頁首，可考慮使用 [新增浮水印](./add-watermark) 工具，並將其放在頁面頂端。

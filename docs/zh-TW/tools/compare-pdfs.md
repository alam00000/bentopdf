# 比較 PDF

上傳兩份 PDF，精確查看兩者之間的變更。此工具會智慧配對頁面，偵測文字、圖片、註解、頁首與格式的差異，並以並排或疊加檢視呈現。

## 運作方式

1. 上傳兩個 PDF 檔案：原始版本（左側）與修訂版本（右側）。
2. 工具使用內容特徵在兩份文件之間配對頁面。
3. 選擇檢視模式：**並排** 或 **疊加**。
4. 使用分頁控制項在頁面配對之間切換。
5. 差異會被醒目標示並分類。使用篩選面板專注於特定的變更類型。
6. 可選擇將比較結果匯出為 PDF 報告。

## 功能

- 依內容相似度自動配對頁面
- 並排與疊加比較檢視
- 變更分類：文字、圖片、頁首/頁尾、註解、格式、背景
- 依類別切換篩選，顯示或隱藏特定變更類型
- 文字變更搜尋，支援查詢篩選
- 支援 OCR，可比較掃描文件
- 縮放控制，便於詳細檢查
- 並排模式下兩個面板同步捲動
- 將比較結果匯出為 PDF

## 選項

| 選項         | 說明                                                  |
| ------------ | ----------------------------------------------------- |
| **檢視模式** | 並排或疊加                                            |
| **OCR**      | 啟用/停用 OCR，以比較掃描文件                         |
| **OCR 語言** | 用於 OCR 文字擷取的語言                               |
| **類別篩選** | 切換文字、圖片、頁首/頁尾、註解、格式與背景變更的顯示 |
| **變更範圍** | 在疊加模式中，篩選所有變更或僅內容變更                |
| **縮放**     | 調整放大倍率以便詳細檢查                              |

## 使用情境

- 審閱合約修訂，找出版本之間的確切變更
- 比較設計模型，確認 PDF 匯出結果符合預期
- 在每項編輯都必須追蹤的受監管產業中稽核文件變更
- 確認 PDF 轉換流程準確保留了原始內容
- 對照原文檢查翻譯文件的版面變更

## 提示

- 疊加檢視會將兩份文件重疊在一起，讓空間上的差異（位移的元素、調整過大小的圖片）一目了然。
- 比較沒有文字層的掃描文件時，請啟用 OCR。比較引擎會從頁面圖片中擷取文字。
- 使用類別篩選專注於重要內容。例如，只在意文字內容差異時，可隱藏格式變更。

# 編輯附件

檢查並管理 PDF 中的檔案附件。此工具會列出每個內嵌檔案的名稱與附件層級，讓您標記個別附件以移除，或一次移除全部。

## 運作方式

1. 上傳 PDF 檔案。
2. 工具會自動掃描附件並以清單顯示。
3. 每個附件都會顯示檔名，以及它是文件層級還是頁面層級的附件。
4. 點擊附件旁的垃圾桶圖示將其標記為移除（再點一次可取消標記）。
5. 使用 **移除所有附件** 按鈕一次選取全部，或使用 **取消全選** 清除選取。
6. 點擊處理按鈕，儲存已移除所選附件的新 PDF。

## 功能

- 列出所有文件層級與頁面層級的附件
- 個別或批次移除附件
- 在確認變更前可切換選取狀態
- 標記為移除的項目會顯示刪除線並降低不透明度
- 下載已移除所選附件的修改後 PDF

## 使用情境

- 在重新發布前，移除文件中內嵌的過時或錯誤檔案
- 分享前從 PDF 移除敏感附件（財務資料、個人資訊）
- 移除不再需要的大型內嵌檔案，以縮小 PDF 檔案大小
- 稽核內嵌內容，並在封存前清理文件

## 提示

- 標記為移除的附件會以刪除線顯示。如果改變主意，可在處理前切換回來。
- 如果找不到附件，工具會清楚顯示「找不到附件」訊息，表示該 PDF 本來就沒有內嵌檔案。

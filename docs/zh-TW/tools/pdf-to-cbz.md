# PDF 轉 CBZ

將 PDF 轉換為 CBZ（Comic Book ZIP）檔案，這是數位漫畫的標準格式。每個 PDF 頁面都會成為封存檔中的一張圖片。工具會以三種格式產生中繼資料以達到最大相容性：ComicInfo.xml、metadata.opf 與 ComicBookInfo JSON。

## 運作方式

1. 點選拖放區或將檔案拖曳到其中，上傳 PDF。
2. 選擇圖片格式、品質、縮放比例，以及選用的中繼資料。
3. 點選**轉換**產生 CBZ 檔案。
4. `.cbz` 檔案會自動下載。

## 選項

| 選項         | 值              | 預設值 | 說明                                                           |
| ------------ | --------------- | ------ | -------------------------------------------------------------- |
| 圖片格式     | JPEG, PNG, WebP | JPEG   | JPEG 適合彩色漫畫，PNG 適合無損的黑白漫畫，WebP 壓縮效果最佳。 |
| 品質         | 50–100%         | 85%    | 控制 JPEG/WebP 壓縮。選擇 PNG 時隱藏（一律無損）。             |
| 縮放比例     | 1.0x–4.0x       | 2.0x   | 比例越高，圖片越清晰，適合高解析度螢幕。                       |
| 灰階         | 開/關           | 關     | 將頁面轉為灰階。可縮小黑白內容的檔案大小。                     |
| 漫畫模式     | 開/關           | 關     | 在中繼資料中設定由右至左的閱讀方向。                           |
| 包含中繼資料 | 開/關           | 開     | 內嵌 ComicInfo.xml、metadata.opf 與 ComicBookInfo JSON。       |

## 中繼資料欄位

啟用中繼資料時，您可以填寫：

- **標題**：自動從 PDF 檔名偵測。
- **系列**：系列名稱（例如「火影忍者」）。
- **集數（#）**：該系列中的期數。
- **卷數（Vol.）**：卷號。
- **作者**：作者或創作者名稱。
- **出版社**：出版公司。
- **標籤 / 類型**：以逗號分隔的標籤（例如「動作, 冒險」）。
- **出版年份**：出版年份（1900–2100）。
- **評分**：0 到 5 的社群評分。

## 中繼資料相容性

工具會以三種格式寫入中繼資料，讓每種閱讀器都能讀取：

| 格式               | 位置         | 支援的閱讀器                                |
| ------------------ | ------------ | ------------------------------------------- |
| ComicInfo.xml      | ZIP 內的檔案 | Komga, Kavita, CDisplayEx, Mylar, ComicRack |
| metadata.opf       | ZIP 內的檔案 | Calibre                                     |
| ComicBookInfo JSON | ZIP 註解欄位 | Calibre（備援）                             |

## 輸出格式

- `filename.cbz`：包含編號頁面圖片與中繼資料檔案的 ZIP 封存檔。

頁面圖片以補零的數字命名（`01.jpg`、`02.jpg` 等），讓閱讀器以正確順序顯示。

## 使用情境

- 轉換漫畫 PDF 以便在漫畫閱讀器中使用。
- 在 Komga、Kavita 或 Calibre 中建立數位漫畫庫。
- 將掃描的漫畫書轉換為方便閱讀器使用的格式。
- 以保留閱讀方向與中繼資料的格式分享漫畫。

## 小技巧

- 彩色漫畫請使用 **JPEG**，黑白漫畫請使用 **PNG**，PNG 壓縮黑白內容的效率非常高。
- 為黑白漫畫啟用**灰階**，可大幅縮小檔案大小。
- 填寫**系列**與**集數**欄位，讓書庫管理程式（Komga、Calibre）能自動整理您的收藏。
- **WebP** 的壓縮效果最好，但較舊的漫畫閱讀器可能不支援。

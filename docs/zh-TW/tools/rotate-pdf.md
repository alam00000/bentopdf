# 旋轉 PDF

將 PDF 中的頁面順時針或逆時針旋轉 90 度。此工具會顯示每一頁的縮圖預覽，讓您個別旋轉頁面，或對整份文件套用批次旋轉。

## 運作方式

1. 上傳 PDF 檔案。每一頁的縮圖會以網格方式呈現。
2. 使用每個頁面縮圖下方的左／右旋轉按鈕旋轉該頁。
3. 使用頂端的批次旋轉控制項一次旋轉所有頁面。
4. 縮圖預覽會即時更新以顯示旋轉結果。
5. 點擊處理按鈕儲存旋轉後的 PDF。

## 功能特色

- 每頁以 90 度為單位旋轉（向左或向右）
- 同時批次旋轉所有頁面
- 縮圖即時預覽，並有旋轉動畫效果
- 延遲載入縮圖，讓大型文件也能流暢操作
- 保留原始頁面內容與品質

## 使用情境

- 修正側向或上下顛倒的掃描頁面
- 將橫向頁面旋轉為直向（或反之）
- 修正部分頁面以錯誤角度掃描、方向混雜的文件
- 為特定的顯示方向準備文件

## 提示

- 旋轉會累加。點擊順時針按鈕兩次會套用 180 度旋轉。
- 若需要非 90 度的旋轉（例如以 45 度修正略微傾斜的掃描），請改用 [自訂角度旋轉](./rotate-custom)。
- 批次旋轉控制項會影響所有頁面，而不只是選取的頁面。此工具沒有選取機制，如需選取功能，請使用 [PDF 多功能工具](./pdf-multi-tool)。

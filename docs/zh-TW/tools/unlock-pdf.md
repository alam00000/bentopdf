# 解除鎖定 PDF

如果您知道加密 PDF 的密碼，此工具會完全移除加密，產生一份任何人都能直接開啟、無需憑證的解鎖副本。當多個 PDF 使用相同密碼時，也支援批次解密。

## 運作方式

1. 上傳一個或多個加密的 PDF 檔案。
2. 輸入用來保護檔案的**密碼**。
3. 點選**解密 PDF**。
4. 單一檔案會直接下載。多個檔案會產生包含所有已解鎖 PDF 的 ZIP 壓縮檔。

## 功能

- 單一檔案與批次解密
- 同時支援使用者密碼與擁有者密碼
- 產生完全未加密、沒有殘留限制的輸出
- 針對錯誤密碼或損毀檔案提供清楚的錯誤訊息
- 批次模式下逐一追蹤每個檔案的成功或失敗狀態

## 與移除限制的差異

**解密 PDF** 需要密碼，並會移除所有加密。**移除限制**針對的是使用限制（列印、複製、編輯），若只設定了擁有者密碼，可能不需要密碼。當 PDF 沒有密碼就完全無法開啟時，請使用解密。

## 使用情境

- 在不再需要密碼時，永久解鎖您先前加密的 PDF
- 移除一批封存文件的加密，方便長期存取
- 為不支援加密檔案的文件管理系統準備受密碼保護的 PDF
- 在與其他文件合併前解鎖 PDF（許多合併工具無法處理加密的輸入檔）

## 提示

- 密碼欄位會套用到所有上傳的檔案。如果您的 PDF 使用不同密碼，請分批處理。
- 如果出現「密碼錯誤」，請檢查是否有多餘的尾端空格或是否開啟了大寫鎖定。
- 解密後的輸出完全沒有安全保護。如需設定新密碼，請使用加密 PDF 重新加密。

# Bates 編號

Bates 編號會在 PDF 的每一頁蓋上連續的識別碼。這是法律程序、稽核與合規流程中標示文件的標準方法。此工具支援多個檔案與可自訂的範本，並可產生個別編號的 PDF 或單一 ZIP 壓縮檔。

## 運作方式

1. 上傳一個或多個 PDF 檔案。您可以一次拖曳多個檔案。
2. 選擇樣式預設值或建立自訂範本。
3. 設定位置、字型、大小、顏色與起始號碼。
4. 點選**套用 Bates 編號**以進行處理。
5. 單一檔案會直接下載。多個檔案會以 ZIP 壓縮檔下載。

## 選項

- **樣式預設值**：從內建格式中選擇：
  - 證物 + 案件 + Bates + 頁碼（例如「Exhibit 1 Case XYZ 000001 Page 1」）
  - 證物 + 案件 + Bates（無頁碼）
  - 案件 + Bates
  - 僅 Bates 編號（例如「000001」）
  - 自訂（撰寫您自己的範本）
- **自訂樣式**：使用預留位置的範本字串：`[BATES]`、`[PAGE]`、`[FILE]`、`[FILENAME]`。
- **Bates 補零位數**：補零 Bates 編號的位數（3 到 6）。僅在自訂模式中顯示。
- **位置**：頁首或頁尾，靠左、置中或靠右。
- **Bates 起始號碼**：第一個 Bates 編號。預設為 1。編號會跨檔案延續。
- **檔案計數起始號碼**：`[FILE]` 預留位置的起始號碼。
- **字型**：Helvetica、Times New Roman 或 Courier。
- **字型大小**：蓋印文字的大小。
- **顏色**：Bates 編號文字的顏色選擇器。

## 功能

- 即時預覽 Bates 編號在所有上傳檔案中的呈現方式
- 支援多個檔案，跨文件連續編號
- 拖放重新排列檔案以控制編號順序
- 六種位置選項（頁首/頁尾，靠左/置中/靠右）
- 依不同頁面尺寸自動計算邊界
- 多檔案批次以 ZIP 輸出
- 範本預留位置提供最大彈性

## 使用情境

- 為訴訟的證據開示文件蓋上連續的證物編號
- 為橫跨數十個檔案的稽核證據包編號
- 為合規文件加上法規參考編號
- 以案件專屬識別碼標示專利申請證物

## 小技巧

- 處理前可在檔案清單中拖曳檔案以重新排序。Bates 編號順序會依照此順序。
- 使用 `[FILENAME]` 預留位置在蓋印中加入原始檔名，有助於將頁面追溯回來源文件。
- 預覽框會在您變更設定時即時更新，讓您在處理前確認格式。

# 反轉顏色

將 PDF 中的每種顏色翻轉為其反色。白色背景變成黑色，黑色文字變成白色，其他所有顏色則轉為互補色。這是為任何 PDF 建立「深色模式」版本最快的方法。

## 運作方式

1. 上傳您的 PDF 檔案。
2. 點擊 **反轉顏色** 進行處理。
3. 反轉後的 PDF 會自動下載。

沒有其他設定。此工具會將每頁轉譯為圖片、反轉所有像素顏色，再將結果重新組合成新的 PDF。

## 功能

- 一鍵反轉所有頁面的顏色
- 處理文件中的每一頁
- 保留原始頁面尺寸與版面
- 適用於任何 PDF，不論內容類型（文字、圖片、混合）

## 使用情境

- 為教科書或手冊建立深色模式版本，夜間閱讀更舒適
- 為無障礙用途準備高對比版本的文件
- 反轉曝光不正確的掃描文件
- 為大量圖片的 PDF 產生負片版本以進行視覺分析

## 小技巧

- 由於此工具會將頁面光柵化以套用效果，輸出結果是以圖片為基礎的。文字將無法再選取或搜尋。如果反轉後需要可搜尋的文字，請將輸出結果交給 OCR 工具處理。
- 若需要更細緻的顏色調整（亮度、對比、飽和度），請改用 [調整顏色](./adjust-colors) 工具。
- 頁數多的大型 PDF 可能需要較長處理時間，因為每一頁都會個別轉譯與反轉。

# PUB 轉 PDF

將 Microsoft Publisher 檔案轉換為 PDF。Publisher 是部分 Microsoft Office 版本隨附的桌面排版工具，但大多數人並未安裝。此工具讓任何人都能直接在瀏覽器中將 PUB 檔案轉換為 PDF，不需要任何 Microsoft 軟體。

## 支援格式

| 格式                | 副檔名 | 備註         |
| :------------------ | :----- | :----------- |
| Microsoft Publisher | `.pub` | 桌面排版文件 |

## 運作方式

1. 點擊上傳區域，或將 PUB 檔案拖放到該處。可一次上傳多個檔案。
2. 檢查檔案清單。使用垃圾桶圖示移除不需要的檔案，或點擊 **新增更多檔案** 加入更多檔案。
3. 點擊 **轉換為 PDF**。以 LibreOffice 為基礎的引擎會在瀏覽器中載入並轉換每個 PUB 檔案，保留版面配置、圖片與文字方塊。
4. 單一檔案會直接下載為 PDF。多個檔案會以名為 `pub-to-pdf.zip` 的 ZIP 壓縮檔提供。

## 選項

不需要其他設定。轉換器會自動處理 PUB 版面配置。

## 使用情境

- 不必購買 Microsoft Publisher，也能開啟客戶提供的 PUB 傳單或電子報
- 轉換以 Publisher 製作的教會週報、活動節目單或學校通訊
- 以通用格式封存 Publisher 製作的行銷素材
- 在未安裝 Publisher 的系統上列印 PUB 檔案

## 提示

- 含有重疊文字方塊與精確定位的複雜 Publisher 版面，在轉換時可能會略有偏移。若精確位置很重要，請檢查輸出結果。
- LibreOffice 引擎在每個工作階段只會初始化一次。第一次轉換需要較長時間，之後就會比較快。
- 為了讓 Publisher 檔案的轉換最忠實，請確保原始檔案中使用的自訂字型為標準系統字型。

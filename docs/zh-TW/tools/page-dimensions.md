# 頁面尺寸

一款診斷工具，會讀取 PDF 中的每一頁，並回報其確切尺寸、方向、標準尺寸名稱、長寬比、面積與旋轉角度。適合在列印前找出尺寸不一的頁面，或記錄收到的 PDF 屬性。

## 運作方式

1. 上傳 PDF 檔案。分析會自動開始，不需按任何按鈕。
2. 摘要面板會顯示總頁數、不同頁面尺寸的數量，以及文件是否有混合尺寸。
3. 瀏覽包含每頁詳細資訊的完整結果表格。
4. 在點、英吋、公釐或像素之間切換顯示單位。
5. 點選**匯出為 CSV** 儲存資料。

## 回報欄位

| 欄位     | 說明                                  |
| -------- | ------------------------------------- |
| 頁碼     | 依序的頁碼                            |
| 尺寸     | 以所選單位表示的寬 x 高               |
| 標準尺寸 | 對應的名稱（A4、Letter 等）或「自訂」 |
| 方向     | 直向或橫向                            |
| 長寬比   | 以小數表示的寬高比                    |
| 面積     | 以所選單位平方表示的頁面面積          |
| 旋轉     | 以度數表示的頁面旋轉                  |

## 功能

- 自動偵測標準紙張尺寸（A3、A4、A5、Letter、Legal、Tabloid 等）
- 混合尺寸文件警告，並列出出現了哪些尺寸以及各尺寸的頁數
- 在點、英吋、公釐與像素（以 96 PPI 計）之間轉換單位
- 匯出 CSV，可用於試算表或文件系統

## 使用情境

- 將文件送交印刷廠前，確認所有頁面都是 A4
- 診斷合併後的 PDF 為何在某些頁面列印出非預期的邊界
- 為中繼資料紀錄記錄大型 PDF 封存檔的頁面版面
- 找出需要修正的旋轉頁面

## 小技巧

- 如果摘要顯示「混合尺寸」，請在列印前使用統一頁面尺寸工具將頁面標準化。
- 旋轉欄位可協助找出顯示正常但旋轉屬性不為零的頁面，這在某些工作流程中可能造成問題。

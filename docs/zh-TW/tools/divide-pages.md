# 分割頁面

將個別 PDF 頁面水平或垂直切成兩半。當單一頁面包含應分開成不同頁面的內容時，這非常實用，例如將雙欄版面掃描成一個寬頁面的情況。

## 運作方式

1. 上傳 PDF 檔案。
2. 選擇分割方向：**垂直**（左右兩半）或 **水平**（上下兩半）。
3. 可選擇指定頁面範圍，限制要分割的頁面。留空則分割所有頁面。
4. 點擊處理按鈕，產生分割後的 PDF。

## 功能

- 垂直分割：將每一頁分成左右兩半
- 水平分割：將每一頁分成上下兩半
- 頁面範圍篩選，可選擇性分割特定頁面
- 未指定的頁面維持不變
- 保留內容品質，無需重新繪製

## 使用情境

- 分開雙頁掃描的頁面（例如一張紙上同時有左右兩頁的書籍掃描）
- 將內容並排的橫式 PDF 分割成個別的直式頁面
- 將長型資訊圖表或海報分成上下兩個部分
- 準備寬幅文件以便使用標準紙張列印

## 提示

- 即使頁面內容分布不均，分割仍會在正中央進行。若需要不對稱分割，請改用 [裁切 PDF](./crop-pdf)。
- 如果頁面在分割前後需要旋轉，可搭配 [旋轉 PDF](./rotate-pdf) 使用。

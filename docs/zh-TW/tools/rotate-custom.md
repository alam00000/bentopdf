# 自訂角度旋轉

以任意角度旋轉 PDF 頁面，不限於 90 度的倍數。每一頁都有自己的角度輸入欄位，也可以使用批次控制項一次將同一角度套用到所有頁面。

## 運作方式

1. 上傳 PDF 檔案。每一頁都會轉譯出縮圖。
2. 每一頁都有一個數字輸入欄位，顯示目前的旋轉角度。
3. 輸入任意角度值（正數或負數）來旋轉特定頁面，或使用每頁的左／右按鈕快速調整 90 度。
4. 使用頂端的 **批次角度** 輸入欄位，為所有頁面設定一致的旋轉。
5. 點擊處理按鈕產生旋轉後的 PDF。

## 功能特色

- 每頁可自由輸入角度（任意整數值）
- 批次角度控制項，為每一頁設定相同旋轉
- 縮圖即時預覽旋轉效果
- 每頁的快速旋轉按鈕，以 90 度為單位
- 延遲載入縮圖，提升大型文件的效能

## 使用情境

- 將略微傾斜的掃描修正幾度
- 旋轉頁面以符合非標準的方向需求
- 對混合內容文件中的個別頁面套用精確旋轉
- 在初步批次旋轉後微調頁面角度

## 提示

- 正值為順時針旋轉，負值為逆時針旋轉。
- 套用批次角度時會覆寫所有逐頁角度。如有需要，請在批次操作後再進行個別調整。
- 若只需標準的 90／180／270 度旋轉並想要更簡單的介面，請使用 [旋轉 PDF](./rotate-pdf)。

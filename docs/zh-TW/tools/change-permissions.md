# 變更權限

精細調整收件者能對您的 PDF 執行的操作。不同於僅以密碼鎖住檔案的基本加密，此工具可讓您選擇性允許或禁止列印、複製、編輯、註解、填寫表單、文件組合與頁面擷取，全部透過 256 位元 AES 加密強制執行。

## 運作方式

1. 上傳 PDF 檔案。
2. 如果 PDF 已加密，請輸入 **目前密碼**。
3. 設定 **新使用者密碼**（開啟時需要）和/或 **新擁有者密碼**（控制權限）。
4. 使用核取方塊逐一開啟或關閉權限。
5. 點擊 **變更權限**。
6. 下載更新後的 PDF。

如果兩個新密碼欄位都留空，工具會完全解密 PDF，移除所有加密與限制。

## 權限控制

| 權限             | 控制內容                         |
| ---------------- | -------------------------------- |
| **允許列印**     | 文件是否可以列印                 |
| **允許複製**     | 文字與圖片是否可以選取和複製     |
| **允許修改**     | 文件內容是否可以編輯             |
| **允許註解**     | 是否可以新增註解、醒目提示與印章 |
| **允許填寫表單** | 互動式表單欄位是否可以填寫       |
| **允許文件組合** | 頁面是否可以插入、刪除或旋轉     |
| **允許頁面擷取** | 個別頁面是否可以擷取             |

所有權限都需要擁有者密碼才能強制執行。沒有擁有者密碼時，大多數 PDF 閱讀器會忽略權限旗標。

## PDF 權限的運作方式

PDF 權限是加密規格的一部分。它們以位元旗標的形式儲存在加密字典中，並由相容的 PDF 閱讀器強制執行。關鍵差異如下：

- **使用者密碼**：開啟檔案時必須輸入。
- **擁有者密碼**：變更權限或移除限制時必須輸入。沒有它時，權限旗標會控制使用者可執行的操作。

如果只設定擁有者密碼（不設使用者密碼），任何人都能開啟檔案，但只能執行允許的操作。如果兩者都設定，開啟檔案需要密碼，驗證後仍受到限制。

## 使用情境

- 發布可以檢視和列印、但不能編輯或複製的報告
- 分享收件者可以填寫、但不能修改的合約範本
- 發布禁止複製圖片的 PDF 型錄
- 允許在審閱草稿上加註解，同時防止結構變更

## 提示

- 為了確保有效，請務必設定擁有者密碼。沒有擁有者密碼的權限無法強制執行。
- 部分第三方 PDF 工具會忽略權限旗標。如需更強的保護，可考慮將 PDF 光柵化或使用 DRM。
- 使用此工具可將舊的 RC4 加密 PDF 升級為 AES-256。

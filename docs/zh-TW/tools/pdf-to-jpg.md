# PDF 轉 JPG

將 PDF 的每一頁轉換為 JPG 圖片。單頁文件會下載為獨立的 `.jpg` 檔案。多頁 PDF 會產生 ZIP 壓縮檔，每頁各一張 JPG。

## 運作方式

1. 點選拖放區或將檔案拖曳到其中，上傳 PDF。工具會顯示檔名、檔案大小與頁數。
2. 調整**品質**滑桿以控制 JPG 壓縮。
3. 點選**轉換**開始處理。
4. 結果會自動下載：單頁 PDF 為一張 JPG，多頁文件則為 ZIP 檔案。

## 選項

- **品質**：0% 到 100% 的滑桿（預設 90%）。數值越高，圖片越清晰，檔案也越大。數值越低，壓縮越強。

頁面在內部以 2 倍比例算繪，因此輸出解析度是 PDF 頁面尺寸的兩倍。標準 Letter 尺寸的頁面約會產生 1,224 x 1,584 像素的圖片。

## 輸出格式

- **單頁**：`filename.jpg`
- **多頁**：`filename_jpgs.zip`，內含 `page_1.jpg`、`page_2.jpg` 等

## 使用情境

- 為文件管理系統產生預覽縮圖。
- 在不支援 PDF 的聊天或電子郵件中分享報告中的某一頁。
- 從 PDF 圖表或插圖建立圖片素材。
- 將掃描文件封存為個別圖片。

## 小技巧

- 若要無損輸出，請改用 [PDF 轉 PNG](./pdf-to-png)。
- 80-90% 的品質設定能在檔案大小與畫質之間取得良好平衡。
- 如果每頁需要特定格式，可以考慮 [PDF 工作流程建構器](./pdf-workflow)，其中提供 PDF 轉圖片輸出節點。

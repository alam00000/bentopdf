# PDF 表單填寫器

開啟含有表單欄位的 PDF，並直接在內嵌檢視器中填寫。此工具同時支援標準 AcroForm 欄位與舊版 XFA (XML Forms Architecture) 表單。填寫完成後，只要點一下就能下載填好的版本。

## 運作方式

1. 上傳含有表單欄位的 PDF。
2. 文件會在整合的 PDF 檢視器中開啟，表單欄位會呈現為互動式輸入框。
3. 點擊文字欄位、核取方塊、下拉選單與選項按鈕進行填寫。
4. 點擊 **儲存並下載填寫的表單** 取得完成的 PDF。

## 功能

- 內嵌 PDF.js 檢視器，支援完整的表單欄位互動
- 支援標準 AcroForm 欄位（文字輸入框、核取方塊、下拉選單、選項按鈕）
- 支援舊版以 XML 為基礎的 XFA 表單
- 依頁面尺寸自動調整檢視器大小
- 顯示檔案名稱與大小資訊

## 選項

沒有其他設定選項。上傳表單、填寫，然後下載即可。

## 使用情境

- 填寫稅務表單、保險申請書或政府文件
- 填寫以 PDF 附件形式收到的求職申請表
- 填寫供應商到職表單或供應商問卷
- 以核取方塊欄位簽核合規檢查清單
- 在看診前填寫醫療初診表

## 小技巧

- XFA 表單是舊版格式，只有部分 PDF 檢視器支援。如果您在 Chrome 或大多數其他工具中開啟 XFA PDF 時看到空白頁面，代表這些檢視器不支援 XFA。BentoPDF 的表單填寫器與 Firefox 都能正確處理 XFA。
- 對於沒有表單欄位的 PDF，請先使用 [建立 PDF 表單](./form-creator) 工具新增欄位，再到這裡填寫。
- 檢視器會自動調整大小以符合 PDF 的頁面尺寸。

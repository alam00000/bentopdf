# PDF 文字辨識 (OCR)

將掃描文件轉為可搜尋、可複製的 PDF。此工具使用 Tesseract OCR 辨識圖片中的文字，並在原始頁面上疊加一層隱形文字層，在保留視覺外觀的同時讓內容完全可搜尋。

## 運作方式

1. 上傳掃描的 PDF 或以圖片為基礎的 PDF 檔案。
2. 從可搜尋的語言清單中，選擇文件中出現的一種或多種語言。
3. 可選擇調整進階設定（解析度、二值化、白名單）。
4. 點擊 **開始 OCR**，並在即時進度列中查看進度。
5. 完成後，檢查擷取的文字，然後下載可搜尋的 PDF 或純 `.txt` 檔案。

## 功能

- 多語言 OCR，附可搜尋的語言選擇器
- 隱形文字層保留原始文件外觀
- 處理期間提供即時進度列與記錄輸出
- 可將結果下載為可搜尋的 PDF 或純文字檔
- 直接將擷取的文字複製到剪貼簿
- 三種解析度等級，可在速度與準確度之間取得平衡

## 選項

| 設定               | 值                                                       | 預設 | 用途                                             |
| ------------------ | -------------------------------------------------------- | ---- | ------------------------------------------------ |
| **解析度**         | 標準 (192 DPI)、高 (288 DPI)、極高 (384 DPI)             | 高   | 較高解析度可提升小字的辨識準確度，但需要更長時間 |
| **圖片二值化**     | 開啟／關閉                                               | 關閉 | 轉換為黑白以增強對比，適用於乾淨的掃描檔         |
| **字元白名單預設** | 無、英數字、數字與貨幣、僅字母、僅數字、發票、表單、自訂 | 無   | 限制可辨識的字元，以提升特定文件類型的準確度     |
| **字元白名單**     | 自由輸入文字                                             | 空白 | 預設設為自訂時，手動指定的字元集                 |

## 使用情境

- 讓掃描的合約與發票可搜尋，以便使用 Ctrl+F 查找
- 從拍攝的文件或舊紙本紀錄中擷取文字
- 使用發票預設處理收據，準確擷取金額與日期
- 從純圖片掃描檔建立無障礙 PDF，以符合法規要求
- 批次擷取掃描書籍或手冊中的文字內容

## 小技巧

- 如果文件包含多種語言的內容（例如英文標題搭配日文內文），請選擇多種語言。
- 對於文字褪色或對比度低的文件，請使用二值化選項，它能大幅提升辨識準確度。
- 發票與表單白名單預設會忽略無關的字元形狀，大幅減少結構化文件中的誤判。

# 字型轉外框

將字型轉為外框，會把每個文字字元從字型字符轉換為向量路徑。PDF 不再依賴任何已安裝的字型，在每台裝置、每種作業系統與每台印表機上都能呈現完全相同的效果。這是印前作業流程中的標準步驟。

## 運作方式

1. 上傳一個或多個 PDF 檔案。
2. 點擊 **轉換為外框**。
3. Ghostscript 會將所有文字轉換為向量路徑。
4. 下載結果。多個檔案會產生 ZIP 壓縮檔。

無需任何設定。此工具使用 Ghostscript (WebAssembly) 在一次處理中將所有字型參照轉換為外框路徑。

## 會改變的地方

- 文字字元變成向量曲線（貝茲路徑）
- 不再需要嵌入字型，PDF 在字符層級即可自給自足
- 檔案大小可能會增加，因為向量路徑通常比字型參照更大
- 外觀完全保留

## 會失去的功能

- 選取文字與複製貼上
- 文字搜尋（Ctrl+F 將無法使用）
- 編輯文字內容的能力
- 螢幕閱讀器無障礙功能

## 使用情境

- 將 PDF 送交要求字型轉外框的印刷廠
- 與沒有安裝自訂或授權字型的人分享使用這些字型的文件
- 避免在其他系統上因字型替換而改變文件外觀
- 為需要向量輸入的雷射雕刻或 CNC 切割流程準備 PDF
- 確保大量使用標誌的 PDF 在所有平台上都能正確顯示

## 小技巧

- 請保留原始 PDF。轉外框無法還原，您無法將路徑轉回可編輯的文字。
- 如果您需要文字保持可搜尋，可考慮改用光柵化 PDF 工具，之後再進行 OCR。
- 轉外框的 PDF 通常較大。如果在意檔案大小，之後可執行壓縮 PDF。

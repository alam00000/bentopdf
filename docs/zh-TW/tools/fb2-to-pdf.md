# FB2 轉 PDF

將 FictionBook 2 (FB2) 檔案轉換為 PDF 文件。FB2 是一種以 XML 為基礎的電子書格式，在俄羅斯與東歐相當普及。雖然在某些平台上支援良好，但在其他平台上幾乎無人知曉，轉換成 PDF 可讓您的書在任何地方都能閱讀。

## 支援格式

| 格式          | 副檔名 | 說明                      |
| :------------ | :----- | :------------------------ |
| FictionBook 2 | `.fb2` | 以 XML 為基礎的電子書格式 |

## 運作方式

1. 點擊上傳區域，或將 FB2 檔案拖放進來。可一次選取多個檔案。
2. 檢查檔案清單。使用垃圾桶圖示移除個別項目，或點擊 **新增更多檔案** 加入更多檔案。
3. 點擊 **轉換為 PDF**。PyMuPDF 引擎會解析 FB2 的 XML 結構，並將其轉譯為分頁的 PDF 內容。
4. 單一檔案會直接下載為 PDF。多個轉換結果會打包成 `fb2-converted.zip`。

## 選項

無需任何設定。轉換器會自動處理 FB2 的 XML 結構，並保留章節分隔、格式與所有內嵌圖片。

## 使用情境

- 在僅支援 PDF 的裝置或 App 上閱讀 FB2 電子書
- 列印以 FB2 格式發行的俄文文學作品
- 將 FB2 書庫封存為通用支援的格式
- 與閱讀器不支援 FictionBook 的人分享書籍

## 小技巧

- FB2 檔案是純 XML，因此通常檔案很小，即使在瀏覽器中也能快速轉換。
- 如果您的 FB2 檔案壓縮為 `.fb2.zip`，請先解壓縮再上傳。

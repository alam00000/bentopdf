# 電子郵件轉 PDF

將儲存的電子郵件檔案轉換為乾淨、可列印的 PDF。此工具會解析 EML 與 MSG 檔案，擷取完整郵件內容（標頭、內文與附件中繼資料），並將所有內容轉換為結構化的 PDF。適用於法律證據開示、記錄保存，或只是列印一封重要郵件。

## 支援格式

| 格式 | 副檔名 | 說明                                               |
| :--- | :----- | :------------------------------------------------- |
| EML  | `.eml` | 標準 MIME 電子郵件格式（大多數郵件用戶端皆可匯出） |
| MSG  | `.msg` | Microsoft Outlook 專有格式                         |

## 運作方式

1. 點擊上傳區域，或拖放您的 EML 或 MSG 檔案。同一批次中可混合兩種格式。
2. 檢查檔案清單。使用垃圾桶圖示移除不需要的項目，或點擊 **新增更多檔案** 加入更多郵件。
3. 設定轉換選項（見下方）。
4. 點擊 **轉換為 PDF**。工具會解析每封郵件、將內容轉為帶樣式的 HTML，再透過 PyMuPDF 引擎轉換為 PDF。
5. 單一郵件會直接下載為 PDF。多封郵件會封裝成 `emails-converted.zip`。

## 選項

| 選項                   | 預設值 | 說明                                                          |
| :--------------------- | :----- | :------------------------------------------------------------ |
| **頁面大小**           | A4     | 可選擇 A4、Letter 或 Legal 頁面尺寸。                         |
| **包含副本與密件副本** | 開啟   | 啟用後，副本與密件副本收件者清單會出現在 PDF 的郵件標頭區段。 |
| **包含附件清單**       | 開啟   | 啟用後，PDF 中會顯示郵件的檔案附件清單（含檔名與大小）。      |

## 使用情境

- 將重要的商業往來信件封存為 PDF，以符合法規或供稽核使用
- 為法律程序或證據開示要求列印郵件往來串
- 為透過電子郵件收到的訂單確認、收據或合約建立永久記錄
- 將 Outlook MSG 檔案備份為不需 Outlook 即可閱讀的格式
- 從匯出的 EML 檔案記錄客戶支援往來內容

## 提示

- 同時支援 EML（Thunderbird、Apple Mail 及大多數郵件用戶端使用）與 Outlook MSG 檔案。從郵件用戶端匯出郵件後，直接拖放到工具中即可。
- HTML 格式的郵件在 PDF 中會保留其樣式。純文字郵件則以乾淨易讀的格式呈現。
- 附件清單會顯示檔名與大小，但不會將實際的附件檔案嵌入 PDF。

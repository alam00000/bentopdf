# PDF 轉 WebP

將 PDF 的每一頁轉換為 WebP 圖片。在相同的感知品質下，WebP 檔案通常比 JPG 小 25-35%，是網頁使用的絕佳選擇。

## 運作方式

1. 點選拖放區或將檔案拖曳到其中，上傳 PDF。
2. 調整**品質**滑桿。
3. 點選**轉換**處理檔案。
4. 單一 `.webp` 檔案或 ZIP 壓縮檔會自動下載。

## 選項

- **品質**：0% 到 100% 的滑桿（預設 85%）。控制有損壓縮程度。數值越高，保留的細節越多。

頁面在內部以 2 倍比例算繪，產生的圖片約為 PDF 原始尺寸的兩倍。

## 輸出格式

- **單頁**：`filename.webp`
- **多頁**：`filename_webps.zip`，內含 `page_1.webp`、`page_2.webp` 等

## 使用情境

- 為重視頻寬的網站準備頁面預覽。
- 為社群媒體產生傳單或型錄的輕量圖片版本。
- 將多頁文件批次轉換為針對網頁最佳化的圖片集。

## 小技巧

- 所有現代瀏覽器都支援 WebP。若需相容舊系統，請改用 [PDF 轉 JPG](./pdf-to-jpg)。
- 80-85% 的品質在螢幕上通常與原圖難以分辨，同時能維持較小的檔案。

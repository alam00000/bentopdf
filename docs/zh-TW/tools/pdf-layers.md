# PDF 圖層（OCG）

管理 PDF 中的選用內容群組（OCG），也就是一般所稱的「圖層」。您可以切換圖層的可見性、新增圖層（包含巢狀子圖層）、刪除圖層，並儲存修改後的 PDF。

## 運作方式

1. 上傳 PDF 檔案。
2. 點選處理按鈕，以 PyMuPDF 引擎載入文件。
3. 工具會顯示所有現有圖層，以及其可見狀態、鎖定狀態與巢狀階層。
4. 切換核取方塊來顯示或隱藏圖層。已鎖定的圖層無法切換。
5. 輸入名稱並點選新增按鈕即可新增最上層圖層，也可以在現有的父圖層下新增子圖層。
6. 刪除不再需要的圖層。
7. 點選**儲存**，下載套用圖層變更後的 PDF。

## 功能

- 以適當縮排顯示巢狀圖層的階層
- 開啟或關閉圖層可見性
- 鎖定圖層標示可防止意外變更
- 以自訂名稱新增最上層或子圖層
- 刪除個別圖層
- 將所有變更儲存為新的 PDF 檔案

## 使用情境

- 切換建築或工程圖面中標記圖層的可見性
- 在多圖層設計文件中加入新的註解圖層
- 在發送範本前移除過時的圖層
- 檢查從第三方收到的複雜 PDF 中有哪些圖層

## 小技巧

- 如果 PDF 沒有圖層，工具會顯示空白狀態並提示您新增圖層。並非所有 PDF 都使用 OCG 圖層，它們最常見於 CAD 匯出檔與設計檔案。
- 子圖層會在父圖層下方縮排顯示。圖層可以巢狀到任意深度。
- 已鎖定的圖層會顯示鎖頭圖示，且其核取方塊會停用。這些鎖定是由 PDF 建立者設定的。

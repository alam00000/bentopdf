# EPUB 轉 PDF

不必離開瀏覽器即可將 EPUB 電子書轉換為 PDF 檔案。EPUB 是數位書籍的開放標準，但有時您需要固定版面的 PDF 以便列印、加上註解，或分享給沒有電子書閱讀器的人。

## 支援格式

| 格式 | 副檔名  | 說明                  |
| :--- | :------ | :-------------------- |
| EPUB | `.epub` | EPUB 2 與 EPUB 3 檔案 |

## 運作方式

1. 點擊上傳區域，或拖放您的 EPUB 檔案。支援多選。
2. 檢查已上傳的檔案。使用垃圾桶圖示移除不需要的項目，或點擊 **新增更多檔案** 擴充批次。
3. 點擊 **轉換為 PDF**。PyMuPDF 引擎會將 EPUB 內容（文字、圖片與格式）轉換為分頁的 PDF 輸出。
4. 單一 EPUB 會直接下載為 PDF。多個檔案會封裝成名為 `epub-converted.zip` 的 ZIP 封存檔。

## 選項

轉換採用合理的預設值，無需任何設定。文字會依標準頁面尺寸重新排列，內嵌的字型與圖片也會保留到 PDF 中。

## 使用情境

- 列印無 DRM 的電子書，以便離開螢幕閱讀
- 將 EPUB 稿件以固定版面的 PDF 提交審閱
- 以所有作業系統都能原生開啟的格式封存數位書籍
- 與沒有 EPUB 閱讀器的同事分享某個章節
- 將以 EPUB 發布的技術文件轉換為可加註解的 PDF

## 提示

- 內嵌音訊與影片等 EPUB 3 功能不會保留到 PDF 中，但所有文字、圖片與表格都能順利轉換。
- 對於樣式複雜的 EPUB，請檢查輸出的前幾頁，確認版面是否忠實呈現。

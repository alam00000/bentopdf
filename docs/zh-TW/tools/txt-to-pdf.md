# 文字轉 PDF

將純文字轉換為格式化的 PDF。您可以上傳 `.txt` 檔案，或直接在內建的文字編輯器中輸入。此工具支援多種字型、自訂文字顏色，以及廣泛的頁面尺寸，從 A0 到 A10，還有 US Letter、Legal 與 Tabloid。

## 支援格式

| 輸入         | 副檔名               |
| :----------- | :------------------- |
| 純文字檔案   | `.txt`               |
| 直接輸入文字 | 在編輯器中輸入或貼上 |

## 運作方式

1. 使用頂端的切換開關選擇輸入模式：**上傳檔案** 或 **輸入文字**。
2. 如果要上傳，請拖放或點擊以選擇一個或多個 `.txt` 檔案。如果要輸入，請直接在文字區域中輸入文字。
3. 設定格式選項：字型系列、字型大小、文字顏色與頁面尺寸。
4. 點擊 **建立 PDF**。輸出會下載為 `text_to_pdf.pdf`。

上傳多個檔案時，其內容會串接在一起，中間以空白行分隔。

## 選項

| 選項         | 值                                                                   | 預設            |
| :----------- | :------------------------------------------------------------------- | :-------------- |
| **字型系列** | Helvetica（無襯線）、Tiro（襯線）、Courier（等寬）、Times（襯線）    | Helvetica       |
| **字型大小** | 6 到 72 pt                                                           | 12              |
| **文字顏色** | 透過顏色選擇器選擇任何顏色                                           | 黑色（#000000） |
| **頁面尺寸** | ISO A0–A10、B0–B10、C0–C10、US Letter、Legal、Tabloid、Ledger、11x17 | A4              |

系統會自動偵測 RTL 語言（阿拉伯文、希伯來文、波斯文、烏爾都文）。偵測到 RTL 文字時，文字方向與對齊方式會隨之切換。

## 使用情境

- 將程式碼片段或記錄檔轉換為使用 Courier 字型的可列印 PDF
- 從當場輸入的會議筆記快速建立 PDF
- 以特定字型與頁面尺寸排版純文字稿件以便投稿
- 製作 README 或變更記錄的 PDF 版本，供離線發送

## 提示

- 想快速轉換剪貼簿內容而不必先存成檔案時，請使用 **輸入文字** 模式。
- Courier（等寬）是程式碼、記錄檔或任何需要欄位對齊之內容的最佳字型選擇。
- 頁面邊界在所有方向都固定為 72 點（1 英吋）。

# PDF 工作流程建構器

工作流程建構器可讓您將多個 PDF 操作串接成單一自動化管線。不必一次執行一個工具，只要以視覺化方式連接節點圖（輸入、處理、輸出），一鍵即可執行全部操作。您的檔案絕不會離開瀏覽器。

## 運作方式

介面分為三個面板：左側的**節點工具箱**、中央的**畫布**，以及選取節點時出現在右側的**設定面板**。

1. **新增節點**：在左側邊欄點選節點，或直接拖曳到畫布上。使用工具箱頂端的搜尋列依名稱篩選。
2. **連接節點**：從輸出插槽（節點底部）拖曳到另一個節點的輸入插槽（頂部）。連線方向為由上而下。
3. **設定選項**：點選節點即可在右側開啟其設定面板。每種節點類型都有各自的選項（頁面範圍、品質滑桿、密碼等）。
4. **執行工作流程**：點選工具列中的**執行**按鈕。引擎會依拓撲順序依序處理每個節點。底部的狀態列會追蹤進度。
5. **下載結果**：終端的下載節點會儲存最終的 PDF（若產生多個檔案則為 ZIP）。

## 節點類別

節點分為六個類別，在畫布上各以不同顏色標示：

- **輸入**（藍色）：PDF 輸入、圖片輸入、Word/Excel/PowerPoint 轉 PDF，以及 15 種以上將檔案送入管線的其他格式轉換器。
- **編輯與註解**（靛藍色）：裁切、灰階、反轉顏色、浮水印、頁碼、頁首與頁尾、掃描效果、調整顏色、背景顏色、移除空白頁面、移除註解。
- **組織與管理**（紫色）：合併、分割、擷取頁面、旋轉、刪除頁面、反轉、新增空白頁面、分割頁面、N-Up、統一頁面尺寸、合併為單一頁面、小手冊、海報化、編輯中繼資料、目錄、OCR。
- **最佳化與修復**（琥珀色）：壓縮、光柵化、線性化、歪斜修正、PDF 轉 PDF/A、字型轉外框、修復。
- **保護 PDF**（玫瑰色）：加密、解密、清理、平面化、數位簽章、塗銷。
- **輸出**（藍綠色）：下載（自動判斷單一 PDF 或 ZIP）、PDF 轉圖片、PDF 轉文字、PDF 轉 DOCX、PDF 轉 XLSX、PDF 轉 CSV、PDF 轉 SVG、PDF 轉 Markdown、擷取圖片。

## 儲存與載入工作流程

工具列提供四種保存選項：

- **儲存**：將目前的工作流程以具名範本儲存在瀏覽器的本機儲存空間中。可儲存多個範本。
- **載入**：開啟列出所有已儲存範本的視窗。點選載入以還原範本，或刪除不再需要的範本。
- **匯出**：將工作流程下載為 `.json` 檔案，方便分享或備份。
- **匯入**：從磁碟載入 `.json` 工作流程檔案，還原所有節點、位置與連線。

範本會保存在本機儲存空間中，跨工作階段保留。匯出的 JSON 檔案可在不同瀏覽器與電腦之間攜帶使用。

## 執行模型

引擎會根據您的連線建立相依關係圖，並依拓撲順序執行節點。任何節點失敗時，執行會停止，失敗的節點會標示為紅色。請留意以下幾項規則：

- 每個工作流程至少需要一個**輸入**節點與一個**輸出**節點。
- 引擎會偵測循環相依，並以錯誤阻止執行。
- **加密**節點必須是輸出節點之前的最後一個處理步驟。放在更前面會觸發驗證警告，因為下游節點無法處理加密資料。
- 受密碼保護的 PDF 會在執行期間提示輸入密碼。
- 支援多個 PDF 輸入：合併節點可將它們合併，批次處理節點則會逐一處理每個 PDF。

## 插槽類型

連線使用具類型的插槽，以防止無效的連接：

- **PDF**（靛藍色）：單一 PDF 文件。
- **MultiPDF**（琥珀色）：打包在一起的多個 PDF 文件。
- **Image**（綠色）：圖片 blob。

## 選項

每個節點都有各自的設定，可透過右側設定面板存取。常見的設定包括：

- 分割、擷取頁面、刪除頁面節點上的**頁面範圍**
- 圖片轉換輸出節點上的**品質滑桿**
- 加密與解密節點上的**密碼欄位**
- 浮水印、頁首與頁尾、編輯中繼資料的**文字輸入**
- 旋轉節點上的**旋轉角度**
- 壓縮節點上的**壓縮等級**
- OCR 節點上的 **OCR 語言選擇**

## 使用情境

- **發票處理管線**：PDF 輸入 -> OCR -> 擷取表格 -> 下載為 CSV。
- **報告標準化**：Word 轉 PDF -> 統一頁面尺寸 -> 加入頁碼 -> 浮水印 -> 壓縮 -> 下載。
- **封存準備**：PDF 輸入 -> 修復 -> 平面化 -> 清理 -> PDF 轉 PDF/A -> 下載。
- **批次擷取圖片**：PDF 輸入（多個檔案）-> 擷取圖片 -> 下載 ZIP。
- **可供列印的小手冊**：PDF 輸入 -> 小手冊 -> 裁切 -> 壓縮 -> 下載。
- **安全發送**：PDF 輸入 -> 塗銷 -> 移除註解 -> 加密 -> 下載。

## 小技巧

- 使用 **Delete** 或 **Backspace** 從畫布移除所選節點。
- 點選節點狀態列上的 **X** 按鈕可直接刪除節點。
- 在空白處點選並拖曳即可平移畫布。平移時游標會變成抓取圖示。
- 在行動裝置上，使用工具列中的 **+** 按鈕切換節點工具箱。
- 如果工作流程產生多個輸出檔案，下載節點會自動將它們打包成 ZIP。
- 從簡單開始：先建立並測試兩個節點的管線，再逐步增加複雜度。

# 移除中繼資料

每個 PDF 都帶有中繼資料，可能透露是誰建立的、使用了什麼軟體、最後修改時間等資訊。此工具會將其全部移除，包括資訊字典、XMP 中繼資料串流、文件 ID 與應用程式專屬資料，留下一份不帶任何來源痕跡的乾淨文件。

## 運作方式

1. 上傳 PDF 檔案。
2. 點擊 **移除中繼資料**。
3. 下載清理後的檔案。

沒有需要設定的選項。此工具的設計就是徹底清除：它會清除所有內容。

## 移除的項目

- **資訊字典欄位**：標題、作者、主旨、關鍵字、建立者、製作程式、建立日期、修改日期
- **XMP 中繼資料串流**：儲存在文件目錄中、以 XML 為基礎的中繼資料區塊
- **文件 ID**：PDF trailer 中的唯一識別碼，可用來在不同系統間追蹤文件
- **PieceInfo**：由 Illustrator 或 InDesign 等程式加入的應用程式專屬中繼資料

## 保留的項目

- 所有可見的頁面內容（文字、圖片、圖形）
- 表單欄位與註解
- 書籤與連結
- 文件結構本身

## 使用情境

- 匿名發布文件前移除您的姓名與所屬機構
- 移除會透露文件準備時間的建立時間戳記
- 清除可辨識您 PDF 軟體組合的製作程式字串
- 為要求不含中繼資料之 PDF 的法規送件準備文件
- 對外分享文件前移除編輯紀錄痕跡

## 提示

- 移除前，請先使用檢視中繼資料工具，確認 PDF 中究竟包含哪些中繼資料。
- 如果需要移除中繼資料 _以及_ JavaScript、註解與內嵌檔案，請使用清理 PDF 進行更徹底的清理。
- 移除中繼資料是永久性的。如果之後可能需要這些資料，請保留原始檔案。

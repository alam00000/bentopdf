# PDF 轉 PNG

將 PDF 的每一頁轉換為 PNG 圖片。PNG 使用無損壓縮，因此輸出會保留原始頁面的每個細節。單頁 PDF 會下載為 `.png` 檔案，多頁 PDF 則產生 ZIP。

## 運作方式

1. 點選拖放區或將檔案拖曳到其中，上傳 PDF。
2. 設定**縮放比例**滑桿以控制輸出解析度。
3. 點選**轉換**開始處理。
4. 單一 PNG 或 ZIP 壓縮檔會自動下載。

## 選項

- **縮放比例**：範圍為 1.0x 到 3.0x（預設 2.0x）。在 2.0x 時，標準 Letter 尺寸的頁面約會算繪為 1,224 x 1,584 像素。縮放比例越高，圖片越大越清晰，但檔案大小與處理時間也會增加。

## 輸出格式

- **單頁**：`filename.png`
- **多頁**：`filename_pngs.zip`，內含 `page_1.png`、`page_2.png` 等

## 使用情境

- 為簡報擷取高擬真度的 PDF 頁面截圖。
- 擷取需要銳利邊緣且無壓縮瑕疵的圖表。
- 從 PDF 設計稿準備網頁設計素材。
- 為 OCR 前處理建立無損的頁面圖片。

## 小技巧

- PNG 檔案比 JPG 大得多。如果檔案大小比完美畫質更重要，請使用 [PDF 轉 JPG](./pdf-to-jpg) 或 [PDF 轉 WebP](./pdf-to-webp)。
- 縮放比例為 1.0x 時，輸出與 PDF 的原生解析度相同。若要列印品質的匯出，請提高到 3.0x。

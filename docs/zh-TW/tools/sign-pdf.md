# 簽署 PDF

在任何 PDF 文件上加上您的簽名。此工具內嵌完整的 PDF 檢視器與內建簽名工具，您可以徒手繪製簽名、以簽名字型輸入姓名，或上傳簽名圖片。在任何頁面上放置簽名並調整大小，然後儲存已簽署的文件。

## 運作方式

1. 上傳您的 PDF 檔案。
2. 文件會在附有註解工具的整合式 PDF 檢視器中開啟。
3. 使用檢視器的簽名工具，透過繪製、輸入或上傳圖片來建立簽名。
4. 在要放置簽名的頁面上點擊，並調整其大小與位置。
5. 可選擇勾選 **平面化 PDF**，將簽名永久嵌入文件。
6. 點擊 **儲存並下載已簽署的 PDF** 取得簽署後的檔案。

## 選項

- **平面化 PDF**：勾選後，簽名會永久嵌入頁面內容，避免他人移動或刪除簽名。未勾選時，簽名會保留為註解，可在相容的檢視器中編輯。

## 功能特色

- 三種建立簽名的方式：徒手繪製、輸入文字或上傳圖片
- 整合式 PDF 檢視器，精準放置
- 在任何頁面上拖曳以定位並調整簽名大小
- 可選擇平面化以永久嵌入簽名
- 支援在同一份文件上放置多個簽名

## 使用情境

- 簽署合約、協議或核准表單後再寄回
- 在稅務文件、保險理賠或政府表單上加上簽名
- 在多頁協議的各頁上簽上姓名縮寫
- 簽署以 PDF 附件寄來的保密協議或人資文件

## 提示

- 如果您要將簽署後的 PDF 寄給不應能移除或移動您簽名的人，請啟用平面化。
- 若需要具備憑證驗證、具法律效力的數位簽章，BentoPDF 另外提供獨立的數位簽章工具。
- 上傳背景透明的 PNG 簽名圖片，效果最乾淨。

# 工具參考

BentoPDF 提供 **130 多種工具** 來處理 PDF。所有工具都完全在您的瀏覽器中執行，您的檔案絕不會離開您的裝置。

---

## 編輯與註解

使用完整的編輯工具組，修改、標註並強化您的 PDF 文件。

<div class="tool-grid">

- [**PDF 編輯器**](./edit-pdf)：註解、螢光標記、塗黑、評論、加入形狀與圖片、搜尋及檢視 PDF。
- [**編輯書籤**](./bookmark)：新增、編輯、匯入、刪除及擷取 PDF 書籤。
- [**目錄**](./table-of-contents)：從 PDF 書籤產生目錄頁。
- [**頁碼**](./page-numbers)：在文件中插入頁碼。
- [**新增頁面標籤**](./add-page-labels)：套用含羅馬數字、前綴與自訂起始值的 PDF 頁面標籤。
- [**Bates 編號**](./bates-numbering)：為一個或多個 PDF 檔案加上連續的 Bates 編號。
- [**新增浮水印**](./add-watermark)：在 PDF 頁面上蓋上文字或圖片。
- [**頁首與頁尾**](./header-footer)：在頁面頂端與底部加入文字。
- [**反轉顏色**](./invert-colors)：建立 PDF 的深色模式版本。
- [**掃描效果**](./scanner-effect)：讓 PDF 看起來像掃描文件。
- [**調整顏色**](./adjust-colors)：微調亮度、對比、飽和度等。
- [**背景顏色**](./background-color)：變更 PDF 的背景顏色。
- [**更改文字顏色**](./text-color)：變更 PDF 中文字的顏色。
- [**簽署 PDF**](./sign-pdf)：手繪、輸入或上傳您的簽名。
- [**新增印章**](./add-stamps)：使用註解工具列在 PDF 中加入圖片印章。
- [**移除註解**](./remove-annotations)：移除評論、螢光標記與連結。
- [**裁切 PDF**](./crop-pdf)：修剪 PDF 每一頁的邊界。
- [**PDF 表單填寫器**](./form-filler)：直接在瀏覽器中填寫表單。也支援 XFA 表單。
- [**建立 PDF 表單**](./form-creator)：以拖放文字欄位的方式建立可填寫的 PDF 表單。
- [**移除空白頁面**](./remove-blank-pages)：自動偵測並刪除空白頁面。

</div>

# ODP 轉 PDF

將 OpenDocument Presentation 檔案轉換為 PDF。ODP 是 LibreOffice Impress 的原生格式，也是 Google 簡報的標準匯出格式之一。將簡報轉為 PDF 後，任何人都不需要簡報軟體就能檢視，投影片也能清晰列印。

## 支援格式

| 格式                      | 副檔名 | 說明                                    |
| :------------------------ | :----- | :-------------------------------------- |
| OpenDocument Presentation | `.odp` | LibreOffice Impress / Google 簡報匯出檔 |

## 運作方式

1. 點擊上傳區域，或將 ODP 檔案拖放進來。可一次選取多份簡報。
2. 檢查檔案清單。使用垃圾桶圖示移除項目，或使用 **新增更多檔案** 加入其他簡報。
3. 點擊 **轉換為 PDF**。以 LibreOffice 為基礎的引擎會處理每份簡報，產生每張投影片各為一頁的 PDF。
4. 單一檔案會下載為 PDF。多個檔案會以名為 `odp-to-pdf.zip` 的 ZIP 壓縮檔提供。

## 選項

無需任何設定。每張投影片都會以原始尺寸轉譯，保留文字、圖片、形狀與投影片背景。

## 使用情境

- 將簡報以 PDF 講義的形式發給觀眾
- 與偏好 PDF 而非 ODP 的人分享 Google 簡報匯出檔
- 以唯讀格式封存研討會演講與課程
- 為實體工作坊列印投影片

## 小技巧

- 投影片轉場與動畫屬於純視覺功能，不會帶入 PDF，但所有靜態內容都能正確呈現。
- PDF 輸出不包含演講者備忘稿。如果您需要備忘稿，請從簡報軟體另外匯出。
- 與其他以 LibreOffice 為基礎的工具一樣，引擎會在第一次使用時載入，並在工作階段中保持快取。

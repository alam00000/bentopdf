# 新增印章

使用內嵌檢視器及其印章註解工具列，在 PDF 頁面上放置圖片印章。印章可以包含您的名稱以標示來源，適合用於核准流程、審閱程序與文件標記。

## 運作方式

1. 在**印章使用者名稱**欄位中輸入您的名稱。此名稱會出現在您建立的印章上。
2. 點選或將 PDF 檔案拖曳到拖放區以上傳。
3. 印章編輯器會開啟，並在檢視器中載入您的文件。
4. 使用工具列的圖片印章工具，在任何頁面上選擇並放置印章。
5. 視需要調整印章的位置與大小。
6. 點選**儲存蓋章後的 PDF** 以下載結果。

## 功能

- 整合 PDF 檢視器與印章專用的註解工具列
- 在建立的印章上標示使用者名稱
- 可在任何頁面放置圖片印章
- 拖放定位與調整大小
- 依頁面長寬比自動調整檢視器大小
- 顯示檔案名稱與大小資訊

## 使用情境

- 在審閱流程中為文件加上「APPROVED」或「REVIEWED」圖片印章
- 在正式文件上放置公司印鑑或公證印章圖片
- 以包含審閱者名稱的「RECEIVED」印章標記頁面
- 為檢驗報告加上品質管制印章

## 小技巧

- 請在上傳 PDF 前設定印章使用者名稱。使用者名稱會嵌入印章的中繼資料中。
- 檢視器會依 PDF 第一頁的長寬比調整高度，以獲得最佳檢視效果。
- 若要使用文字浮水印而非圖片印章，請使用[新增浮水印](./add-watermark)工具。

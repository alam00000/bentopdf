# 合併為單一頁面

將 PDF 的每一頁合併成單一長頁面。頁面可垂直拼接（像捲軸）或水平拼接（並排），在輸出中產生一個連續頁面。

## 運作方式

1. 上傳 PDF 檔案。
2. 選擇版面方向：**垂直**（由上而下堆疊頁面）或 **水平**（並排放置頁面）。
3. 以點為單位設定頁面間距。
4. 選擇頁面間空隙的背景顏色。
5. 可選擇啟用分隔線（頁面之間的細線），並設定其粗細與顏色。
6. 點擊處理按鈕。輸出結果為單頁 PDF。

## 功能

- 垂直或水平拼接頁面
- 可設定頁面間距
- 空隙區域的背景顏色選擇器
- 可選的分隔線，粗細與顏色皆可調整
- 以完整解析度將每個原始頁面繪製到合併後的畫布上

## 選項

| 選項           | 說明                       |
| -------------- | -------------------------- |
| **方向**       | 垂直（堆疊）或水平（並排） |
| **頁面間距**   | 頁面之間的空隙，以點為單位 |
| **背景顏色**   | 頁面之間區域的顏色         |
| **新增分隔線** | 切換頁面之間的細線         |
| **分隔線粗細** | 線條粗細，以點為單位       |
| **分隔線顏色** | 分隔線的顏色               |

## 使用情境

- 將多頁線框圖或設計模型製作成單一長圖
- 產生可連續捲動的文件檢視，以嵌入網頁
- 將多頁漫畫或分鏡腳本拼接成一條長條
- 製作連續頁面的全景檢視以供審閱

## 提示

- 垂直方向最適合直式頁面的文件。橫式內容則較適合水平方向。
- 頁數很多的大型文件會產生非常高或非常寬的輸出。部分 PDF 檢視器可能難以處理極大的單一頁面。
- 使用對比色的分隔線，可輕鬆看出原始頁面的結束與下一頁的開始。

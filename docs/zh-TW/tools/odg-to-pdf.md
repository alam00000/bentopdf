# ODG 轉 PDF

將 OpenDocument Graphics 檔案轉換為 PDF。ODG 是 LibreOffice Draw 的原生格式，用於圖表、流程圖與向量插圖。轉換為 PDF 後，這些繪圖就能輕鬆分享、列印及嵌入其他文件。

## 支援格式

| 格式                  | 副檔名 | 說明                                    |
| :-------------------- | :----- | :-------------------------------------- |
| OpenDocument Graphics | `.odg` | LibreOffice Draw / OpenOffice Draw 檔案 |

## 運作方式

1. 點擊上傳區域，或將 ODG 檔案拖放進來。可一次加入多個檔案。
2. 檢查檔案清單。使用垃圾桶圖示移除個別項目，或點擊 **新增更多檔案** 加入更多繪圖。
3. 點擊 **轉換為 PDF**。以 LibreOffice 為基礎的引擎會在瀏覽器中載入，並轉換每個 ODG 檔案，保留向量圖形、形狀與文字。
4. 單一檔案會直接下載為 PDF。多個檔案會產生名為 `odg-to-pdf.zip` 的 ZIP 壓縮檔。

## 選項

無需其他設定。轉換會保留 ODG 原始檔中的頁面尺寸、形狀、連接線與文字方塊。

## 使用情境

- 與沒有安裝 LibreOffice 的客戶分享 LibreOffice Draw 圖表
- 列印在 Draw 中建立的流程圖與網路圖
- 將 ODG 插圖以內嵌 PDF 的形式放入報告或簡報
- 以數十年後仍可讀取的格式封存技術圖面

## 小技巧

- 向量元素在 PDF 輸出中仍維持向量，因此結果可清晰縮放至任何列印尺寸。
- LibreOffice 引擎第一次使用時需要稍候初始化。之後在同一工作階段中的轉換會更快。

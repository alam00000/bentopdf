# VSD 轉 PDF

無需安裝 Visio，即可將 Microsoft Visio 圖表轉換為 PDF。VSD 與 VSDX 檔案包含流程圖、組織圖、網路圖與平面圖，大多數人都無法開啟。此工具會將它們轉換為可在任何裝置上檢視的清晰 PDF。

## 支援的格式

| 格式         | 副檔名  | 備註                                     |
| :----------- | :------ | :--------------------------------------- |
| Visio 二進位 | `.vsd`  | 舊版 Visio 格式（Visio 2003 及更早版本） |
| Visio XML    | `.vsdx` | 新版 Visio 格式（Visio 2013 以上）       |

## 運作方式

1. 點選上傳區域，或拖放您的 VSD 或 VSDX 檔案。兩種格式可混合在同一批次中。
2. 檢閱檔案清單。使用垃圾桶圖示移除不需要的項目，或使用**新增更多檔案**加入更多圖表。
3. 點選**轉換為 PDF**。以 LibreOffice 為基礎的引擎會在瀏覽器中載入，並將每個圖表轉換為 PDF，保留圖形、連接線、標籤與頁面版面配置。
4. 單一圖表會直接下載為 PDF。多個檔案會產生名為 `vsd-to-pdf.zip` 的 ZIP 壓縮檔。

## 選項

不需要任何設定。轉換器會沿用 Visio 文件原本的頁面大小與方向。

## 使用情境

- 在沒有 Visio 授權的情況下檢閱同事的 Visio 圖表
- 將網路或架構圖以 PDF 形式納入專案文件
- 列印組織圖或流程圖作為會議講義
- 以適合長期保存的格式封存舊版 Visio 的 VSD 檔案

## 提示

- 多頁的 Visio 文件會產生多頁 PDF，每個 Visio 頁面對應一個 PDF 頁面。
- VSDX 檔案（新版 XML 格式）的轉換精確度通常高於舊版 VSD 二進位檔案。
- LibreOffice 引擎在每個工作階段只會載入一次。第一次轉換需稍候片刻，之後的檔案會更快完成。

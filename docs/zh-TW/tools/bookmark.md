# 編輯書籤

書籤編輯器讓您完整掌控 PDF 的導覽書籤（也稱為大綱）。您可以新增書籤、編輯現有書籤、重新整理階層，並以 CSV 和 JSON 格式匯入或匯出書籤資料。

## 運作方式

1. 點擊或將檔案拖曳到放置區以上傳 PDF。
2. 可選擇勾選 **自動擷取現有書籤**，載入文件目前的書籤樹。
3. 編輯器以分割畫面開啟：左側為 PDF 檢視器，右側為書籤面板。
4. 輸入書籤標題並點擊 **新增至頁面**，即可建立指向目前頁面的新書籤。
5. 使用工具列按鈕重新排列、設定樣式或刪除書籤。
6. 點擊 **儲存含書籤的 PDF** 下載更新後的檔案。

## 功能

- 視覺化 PDF 檢視器，具備頁面導覽、縮放控制與跳至頁面輸入框
- 一鍵將書籤新增至任何頁面
- 直接點擊 PDF 以設定精確的書籤目的地（選取模式）
- 巢狀書籤階層，支援拖放重新排序
- 批次操作：選取多個書籤，一次變更顏色、樣式或刪除
- 書籤搜尋，可在大型書籤樹中快速找到項目
- 所有變更皆支援復原與重做
- 從 CSV（標題、頁碼、層級）或 JSON 檔案匯入書籤
- 將書籤匯出為 CSV 或 JSON，以便在外部編輯
- 書籤樣式：顏色（紅、藍、綠、黃、紫）與字型樣式（粗體、斜體、粗斜體）
- 快速導覽：使用 Page Up/Page Down 鍵捲動頁面

## 選項

- **自動擷取現有書籤**：勾選後，工具會在載入時讀取並顯示 PDF 目前的書籤。
- **批次模式**：切換後可選取多個書籤，並批次套用顏色、樣式或刪除操作。
- **全部展開/收合**：快速顯示或隱藏巢狀的子書籤。

## 使用情境

- 為缺少書籤的教科書或手冊加入目錄
- 在 OCR 處理後重新整理掃描文件的書籤
- 將書籤匯出為 CSV，在試算表中編輯後再重新匯入
- 清理頁面參照錯誤的自動產生書籤
- 加入彩色書籤，標示法律文書中的重要段落

## 提示

- 使用 CSV 匯入可大量建立書籤。格式很簡單：`title,page,level`，其中層級 1 為最上層。
- 選取模式可讓您點擊 PDF 頁面上的精確位置來設定書籤目的地，比只指定頁碼更精確。
- 進行重大變更前請先匯出書籤，以便留有備份。

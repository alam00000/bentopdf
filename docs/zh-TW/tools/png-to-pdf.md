# PNG 轉 PDF

將 PNG 圖片轉換為 PDF，同時保留完整解析度。每張 PNG 都會成為獨立的一頁，尺寸與原始圖片相符。透明度會自動處理。

## 支援格式

| 格式 | 副檔名 |
| :--- | :----- |
| PNG  | `.png` |

## 運作方式

1. 點選上傳區域，或拖放 PNG 檔案。可一次選取多個檔案。
2. 管理檔案清單：移除不需要的檔案或新增更多檔案。
3. 從下拉選單選擇 **PDF 品質**等級。
4. 點選**轉換為 PDF**。輸出會下載為 `from_jpgs.pdf`。

工具使用 pdf-lib 直接嵌入每張圖片。如果某張 PNG 無法原生嵌入（例如色彩設定檔特殊），會改透過 canvas 重新算繪為 JPEG。

## 選項

**PDF 品質**控制嵌入前套用的壓縮：

- **高品質**：壓縮最少，檔案最大。
- **中等品質**（預設）：在大小與清晰度之間取得良好平衡。
- **低品質**：壓縮最多，輸出最小。

## 使用情境

- 將螢幕截圖轉換為多頁 PDF，用於錯誤回報或文件
- 將 UI 設計匯出檔打包成單一檔案以供審閱
- 將圖表匯出檔（draw.io、Excalidraw）轉換為可分享的 PDF
- 將一組圖表圖片彙整成報告

## 小技巧

- 含有透明度的 PNG 檔案在 PDF 中會使用白色背景。如果需要其他背景，請事先編輯圖片。
- 對於邊緣銳利且含文字的螢幕截圖與圖表，高品質可避免 JPEG 壓縮瑕疵。中等或低品質可能會在內部轉換為 JPEG。

# 雙面掃描整理

雙面掃描整理專為 ADF 掃描流程設計，適用於一個 PDF 包含兩個頁面區塊的情況：

- 先是所有正面
- 接著是所有背面

此工具會將兩個區塊交錯排列成自然的閱讀順序：正面1、背面1、正面2、背面2，依此類推，無需手動分割再重組。

## 運作方式

1. 上傳一個由雙面堆疊掃描產生的 PDF。
2. 設定正面區塊結束的分割點。
3. 選擇背面區塊的處理方式：
   - **反轉背面區塊**（掃描背面前翻轉紙疊時常見）
   - **保持背面區塊原樣**
4. 點擊 **整理 PDF** 下載重新排序後的結果。

## 選項

- **自動偵測分割點（一半）**：將分割點設為 `ceil(totalPages / 2)`。
- **奇數頁警告**：總頁數為奇數時發出警告（通常代表掃描不一致）。
- **區塊不等確認**：正面/背面區塊大小不同時要求確認。
- **分組匯出**：依原始文件的頁數，將整理後的輸出分割成多個 PDF，並以 ZIP 下載。

## 輸出行為

- **預設**：一個輸出 PDF（輸入一個 PDF，輸出一個 PDF）。
- **分組模式**：輸出依您設定的每份文件頁數分塊；若產生多個區塊，會以一個 ZIP 下載，否則下載單一 PDF。

如果區塊大小不等，會先整理成對的頁面，剩下未配對的頁面則附加在最後。

## 常見使用情境

- 分兩次掃描一疊雙面表單後恢復正確順序。
- 重建辦公室掃描器先輸出所有正面再輸出所有背面的正反面文件組。
- 在分割成個別文件前，對封存掃描檔進行後製處理。

## 提示

- 大多數雙面批次的總頁數應為偶數。
- 如果背面的輸出看起來順序顛倒，請在 **反轉背面區塊** 與 **保持背面區塊原樣** 之間切換。
- 對於 2 頁的原稿（正面+背面），請使用分組匯出並設定每份文件 `2` 頁。

# 海報化 PDF

將 PDF 的每一頁劃分為由較小子頁面組成的網格。這個工具可讓您將單一頁面分散列印在多張紙上，再拼接成大型海報或橫幅。

## 運作方式

1. 上傳 PDF 檔案。
2. 設定 **列數** 與 **欄數** 來定義網格（例如 2 列 x 2 欄會將每頁分割成 4 個子頁面）。
3. 可選擇指定頁面範圍，限制要海報化的頁面。
4. 預覽畫布會在目前頁面上顯示網格疊加層，讓您直觀看到切割位置。
5. 在頁面之間切換，檢查不同頁面上的疊加層。
6. 點擊處理按鈕。每個網格儲存格都會成為輸出 PDF 中的獨立頁面。

## 功能特色

- 可設定列數與欄數，靈活調整網格大小
- 即時預覽並顯示網格疊加層，清楚呈現頁面的分割位置
- 頁面範圍篩選，只海報化特定頁面
- 預覽中可逐頁瀏覽
- 快取頁面快照，讓預覽切換更快速
- 紅色虛線網格清楚標示切割邊界

## 選項

| 選項         | 說明                              |
| ------------ | --------------------------------- |
| **列數**     | 水平分割數量（預設：1）           |
| **欄數**     | 垂直分割數量（預設：1）           |
| **頁面範圍** | 要海報化的頁面（留空 = 所有頁面） |

## 使用情境

- 將海報尺寸的 PDF 列印在標準 A4 或 Letter 紙張上，再貼到牆上拼接
- 從單頁 PDF 設計製作大型橫幅
- 將超大尺寸的技術圖面分割成可列印的圖塊
- 在沒有大幅面印表機的情況下製作大尺寸印刷品

## 提示

- 2x2 網格會將一頁變成 4 頁，3x3 網格則變成 9 頁。請依照最終拼接成品的大小規劃網格。
- 預覽疊加層可協助您確認重要內容不會落在切割線上。必要時請調整列數或欄數。
- 若要進行相反的操作（將多頁放到一張紙上），請使用 [多頁併一頁 (N-Up)](./n-up-pdf)。

# 編輯中繼資料

編輯 PDF 檔案中內嵌的中繼資料。此工具會以文件現有的中繼資料預先填入表單，讓您修改任何欄位，並將變更儲存為新的 PDF。

## 運作方式

1. 上傳 PDF 檔案。工具會讀取目前的中繼資料並填入表單。
2. 編輯任何標準欄位：標題、作者、主旨、關鍵字、建立者、產生者。
3. 使用日期時間選擇器調整建立日期與修改日期。
4. 點擊新增按鈕並輸入鍵值組，即可新增自訂中繼資料欄位。
5. 點擊處理按鈕儲存修改後的 PDF。

## 功能

- 從上傳的 PDF 預先填入所有現有中繼資料
- 標準欄位：標題、作者、主旨、關鍵字、建立者、產生者
- 建立日期與修改日期的日期時間選擇器
- 自訂鍵值中繼資料欄位，可設定任意屬性
- 將變更直接儲存至 PDF 的文件資訊字典

## 可編輯欄位

| 欄位         | 說明                             |
| ------------ | -------------------------------- |
| **標題**     | PDF 閱讀器中顯示的文件標題       |
| **作者**     | 建立文件的個人或組織             |
| **主旨**     | 文件主題的簡短說明               |
| **關鍵字**   | 以逗號分隔的詞彙，用於搜尋與分類 |
| **建立者**   | 最初建立內容的應用程式           |
| **產生者**   | 產生 PDF 的應用程式              |
| **建立日期** | 文件最初建立的時間               |
| **修改日期** | 文件最後修改的時間               |
| **自訂欄位** | 您定義的任何其他鍵值組           |

## 使用情境

- 在發布文件前設定適當的標題與作者
- 加入關鍵字，提升在文件管理系統中的可搜尋性
- 更新修改日期以反映目前的修訂版本
- 加入部門、專案 ID 或機密等級等自訂中繼資料欄位
- 清理原始編寫軟體留下的中繼資料

## 提示

- 自訂欄位會直接寫入 PDF 的資訊字典。部分 PDF 閱讀器可能不會顯示自訂欄位，但它們會保留在檔案中。
- 將欄位留空即可從中繼資料中清除它。處理按鈕會儲存表單中的所有內容。
- 若只想檢視而不編輯中繼資料，請使用 [檢視中繼資料](./view-metadata)。若要完全移除所有中繼資料，請使用移除中繼資料。

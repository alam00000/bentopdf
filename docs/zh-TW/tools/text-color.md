# 更改文字顏色

替換整份 PDF 中的文字顏色。此工具會辨識每頁的文字區域，並將其重新上色為您選擇的顏色，同時保留文件版面配置與非文字內容。

## 運作方式

1. 上傳您的 PDF 檔案。
2. 使用顏色選擇器挑選新的文字顏色。預設為藍色（#0000FF）。
3. 點擊 **更改文字顏色** 進行處理。
4. 重新上色的 PDF 會自動下載。進度指示器會顯示正在處理的頁面。

## 選項

- **新文字顏色**：用於選擇文件中所有文字替換顏色的顏色選擇器。

## 功能特色

- 為文件中的每一頁文字重新上色
- 逐頁處理並顯示進度
- 顏色選擇器完整支援十六進位色碼
- 保留頁面版面配置與非文字元素

## 使用情境

- 將黑色文字改為深藍色，讓文件外觀更柔和、更現代
- 發送文件前重新為文字上色，以符合品牌規範
- 將文字轉換為特定顏色以符合無障礙要求
- 讓文字在新套用的背景顏色上清楚可見

## 提示

- 此工具會以 2 倍比例轉譯頁面以確保品質，再重建 PDF。輸出內容以圖片為基礎，因此文字將無法再被選取或搜尋。
- 若文件需要保留可選取的文字，建議改用 [PDF 編輯器](./edit-pdf) 直接編輯 PDF。
- 由於每一頁都會個別轉譯，處理時間會隨頁數增加。

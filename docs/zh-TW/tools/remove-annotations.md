# 移除註解

移除 PDF 中所有的註解，讓文件保持乾淨，包括留言、螢光標示、便利貼、文字標記、連結、印章，以及文件中內嵌的其他註解物件。底層的頁面內容（文字、圖片、圖形）完全不受影響。

## 運作方式

1. 上傳您的 PDF 檔案。
2. 工具會偵測文件的頁數並顯示檔案資訊。
3. 點擊 **移除註解** 進行處理。
4. 清理後的 PDF 會自動下載，所有註解皆已移除。

## 功能特色

- 移除所有註解類型：留言、螢光標示、底線、刪除線、便利貼、印章、連結與表單標記
- 處理文件中的每一頁
- 保留所有非註解內容（文字、圖片、向量圖形、表單欄位）
- 處理前顯示頁數與檔案大小

## 使用情境

- 在多位審閱者加上留言的審閱流程結束後，於最終發布前清理文件
- 從共享的讀書指南中移除螢光標示與便利貼
- 封存前移除文件中的連結註解
- 為協商期間加上大量註解的法律文件準備「乾淨」版本
- 送印前移除稿件中的審閱者留言

## 提示

- 此工具在 PDF 結構層級移除註解，因此結果會保留可選取的文字與原始品質，不涉及光柵化。
- 如果只想移除特定註解而非全部，請使用 [PDF 編輯器](./edit-pdf) 選擇性地刪除個別註解。
- 平面化 PDF 中的註解（已合併到頁面內容中）無法移除，因為它們已不再是獨立的物件。

# ODS 轉 PDF

將 OpenDocument 試算表檔案轉換為 PDF。ODS 是 LibreOffice Calc 的原生格式，也是 Google 試算表常見的匯出格式。此工具會將試算表的資料、格式與圖表轉成分頁的 PDF，方便列印或分享。

## 支援格式

| 格式                | 副檔名 | 說明                                 |
| :------------------ | :----- | :----------------------------------- |
| OpenDocument 試算表 | `.ods` | LibreOffice Calc / Google 試算表匯出 |

## 運作方式

1. 點選上傳區域，或將 ODS 檔案拖放到其中。支援多個檔案。
2. 檢查檔案清單。使用垃圾桶圖示移除檔案，或點選**新增更多檔案**擴充批次。
3. 點選**轉換為 PDF**。以 LibreOffice 為基礎的引擎會在瀏覽器中載入，並將每份試算表轉成 PDF 頁面。
4. 單一試算表會下載為 PDF。多個檔案會打包成 `ods-to-pdf.zip`。

## 選項

無需任何設定。轉換器會將試算表既有的列印版面、儲存格格式與欄寬套用到 PDF 輸出。

## 使用情境

- 將 LibreOffice Calc 預算表或報告分享給只接受 PDF 的人
- 列印以 ODS 格式下載的 Google 試算表匯出檔
- 以不可編輯的格式封存財務紀錄
- 將以 ODS 為基礎的表單或工時表以固定版面文件提交

## 小技巧

- 如果試算表有多個工作表，所有工作表都會包含在 PDF 輸出中。
- 非常寬的試算表可能會橫向跨越多個 PDF 頁面。若版面很重要，建議在轉換前先調整原始檔的欄寬。
- LibreOffice 引擎會在第一次使用時初始化。同一工作階段中後續的轉換會更快。

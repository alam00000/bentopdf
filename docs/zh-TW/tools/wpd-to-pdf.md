# WPD 轉 PDF

將 Corel WordPerfect 文件轉換為 PDF 檔案。WPD 曾是法律事務所與政府機關最主要的文書處理格式。如果您有新式軟體無法開啟的舊 WordPerfect 檔案，此工具能讓它們以標準 PDF 重獲新生。

## 支援的格式

| 格式        | 副檔名 | 備註                        |
| :---------- | :----- | :-------------------------- |
| WordPerfect | `.wpd` | 所有主要的 WordPerfect 版本 |

## 運作方式

1. 點選上傳區域，或拖放您的 WPD 檔案。可一次選取多個檔案。
2. 檢閱檔案清單。使用垃圾桶圖示移除不需要的檔案，或使用**新增更多檔案**加入更多文件。
3. 點選**轉換為 PDF**。此工具會在您的瀏覽器中載入以 LibreOffice 為基礎的轉換引擎，解析 WPD 格式並輸出 PDF。
4. 單一檔案會直接下載為 PDF。批次轉換會產生名為 `wpd-to-pdf.zip` 的 ZIP 壓縮檔。

## 選項

不需要任何設定。LibreOffice 引擎會自動處理 WPD 的格式、字型與版面配置。

## 使用情境

- 開啟數十年前以 WordPerfect 撰寫的法律文件
- 將封存的 WPD 政府文件轉換為新式格式
- 將舊有的 WordPerfect 文件庫遷移為 PDF 以便長期保存
- 與未安裝 Corel WordPerfect 的收件者分享 WPD 檔案

## 提示

- LibreOffice 引擎會在第一次使用時載入，需要一點時間。同一工作階段中之後的轉換會更快。
- 複雜的 WPD 巨集與顯示代碼不會保留，但視覺版面、文字內容與基本格式都會轉入 PDF。

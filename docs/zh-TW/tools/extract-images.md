# 擷取圖片

從一個或多個 PDF 檔案中取出所有內嵌圖片。擷取的圖片會顯示在預覽格狀檢視中，您可以個別下載，或以 ZIP 一次取得全部。由 PyMuPDF 驅動。

## 運作方式

1. 點擊放置區或將檔案拖曳到其上，上傳一個或多個 PDF。可視需要新增更多檔案或移除個別檔案。
2. 點擊 **擷取** 開始處理。
3. 工具會掃描每個上傳 PDF 的每一頁，找出並擷取內嵌圖片。
4. 擷取的圖片會以縮圖格狀顯示。每張圖片都有下載按鈕。
5. 點擊 **全部下載** 將所有圖片儲存為 ZIP 封存檔。

## 選項

此工具沒有可設定的選項。所有內嵌圖片都會以其原生格式擷取（通常是 PNG、JPEG，或圖片嵌入 PDF 時所使用的任何格式）。

## 輸出格式

- 圖片會在預覽格狀檢視中顯示，名稱為 `image_1.png`、`image_2.jpg` 等。
- **全部下載** 會產生包含所有圖片的 `extracted-images.zip`。
- 可從格狀檢視中逐一下載個別圖片。

## 使用情境

- 從 PDF 中還原照片或圖形，以便在其他專案中重複使用。
- 從型錄 PDF 中擷取產品圖片，用於電子商務商品頁面。
- 從技術文件中取出圖表，用於簡報。
- 在分享文件前，稽核其中內嵌了哪些圖片。

## 提示

- 此工具會依圖片在 PDF 中的儲存方式原樣擷取，不會將頁面重新繪製成圖片。若要如此，請使用 [PDF 轉 PNG](./pdf-to-png) 或 [PDF 轉 JPG](./pdf-to-jpg)。
- 如果工具回報「找不到圖片」，該 PDF 可能使用向量圖形而非內嵌點陣圖片，或者它是整頁為一張大圖的掃描文件。
- 批次處理可跨多個 PDF 進行。所有檔案的圖片會合併到同一個格狀檢視與 ZIP 中。

# 分割 PDF

使用六種分割模式之一，將 PDF 拆分成較小的文件。從簡單的頁面範圍到依書籤分割，此工具能應付各種分割文件的情境。

## 運作方式

1. 上傳單一 PDF 檔案。
2. 從下拉選單中選擇分割模式。
3. 設定該模式專屬的選項（頁面範圍、選取項目等）。
4. 點擊處理按鈕。
5. 依模式與設定而定，結果會下載為單一 PDF 或 ZIP 壓縮檔。

## 分割模式

| 模式           | 說明                                                                                           |
| -------------- | ---------------------------------------------------------------------------------------------- |
| **範圍**       | 輸入頁面範圍，例如 `1-3, 5, 8-10`。多個範圍會在 ZIP 中產生個別的 PDF，單一範圍則產生一個 PDF。 |
| **視覺化選取** | 瀏覽頁面縮圖並點擊選取想要的頁面。選取的頁面會被擷取成新的 PDF。                               |
| **偶數／奇數** | 只擷取偶數頁或奇數頁。                                                                         |
| **所有頁面**   | 將每一頁分割成獨立的 PDF 檔案，並以 ZIP 下載。                                                 |
| **書籤**       | 在書籤邊界處分割。選擇書籤層級以控制分割位置。                                                 |
| **每 N 頁**    | 分割成每份 N 頁的區塊（例如每 5 頁）。最後一個區塊的頁數可能較少。                             |

## 功能特色

- 六種不同的分割模式，幾乎涵蓋所有使用情境
- 視覺化頁面選取器，縮圖延遲載入
- 可辨識書籤的分割功能，並可依層級篩選
- 範圍與視覺化模式提供 ZIP 輸出選項
- 支援混合語法的頁面範圍（`1-3, 5, 8-10`）
- 每 N 頁分割產生不均等區塊時會顯示警告

## 使用情境

- 從大型文件中擷取特定章節或段落
- 為雙面列印流程分開奇數頁與偶數頁
- 在書籤邊界將書籍 PDF 拆分成各章節檔案
- 從合約中單獨取出特定頁面（例如簽名頁）
- 將彙整的報告拆分成各段落檔案以便發送

## 提示

- 以逗號分隔的多個頁面範圍（例如 `1-5, 10-15, 20-25`）會產生個別的 PDF，每個範圍一個，並打包成 ZIP。
- 書籤分割模式需要 PDF 實際包含書籤。如果找不到任何書籤，您會收到錯誤訊息。
- 範圍與視覺化模式中的「以 ZIP 下載」核取方塊，可讓您取得每頁各自的 PDF，而不是合併的檔案。

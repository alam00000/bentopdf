# 刪除頁面

從 PDF 文件中移除不需要的頁面。輸入頁碼或範圍指定要刪除的頁面，或直接點擊頁面縮圖將其標記為移除。

## 運作方式

1. 上傳 PDF 檔案。工具會產生每一頁的縮圖預覽。
2. 在文字欄位中使用範圍語法（例如 `2, 5-8`）輸入要刪除的頁面，或點擊縮圖切換選取。
3. 已標記的頁面會以醒目方式顯示，方便您確認選取內容。
4. 點擊處理按鈕。系統會建立已移除所選頁面的新 PDF。

## 功能

- 以文字選取頁面，支援範圍語法（`2, 5-8, 12`）
- 視覺化縮圖格狀檢視，點擊即可選取要刪除的頁面
- 即時預覽並醒目標示已標記刪除的頁面
- 依實際頁數驗證輸入
- 所有未刪除的頁面皆保持原始順序

## 使用情境

- 移除掃描文件中的空白頁或填充頁
- 在分享文件前移除封面頁或附錄
- 清理不小心留在最終版 PDF 中的草稿頁
- 在發布前移除含有敏感資訊的頁面

## 提示

- 刪除頁面不會影響其餘頁面的內容或格式。輸出結果是原始文件扣除已移除頁面後的忠實副本。
- 如果您想只保留特定頁面而非移除特定頁面，[擷取頁面](./extract-pages) 會更合適。
- 縮圖檢視採延遲載入，因此大型文件仍能保持流暢。

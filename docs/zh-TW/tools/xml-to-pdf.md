# XML 轉 PDF

將 XML 資料檔轉換為易讀、結構化的 PDF 文件。原始 XML 功能強大，但對人來說難以閱讀。此工具會解析 XML 樹、找出重複的資料結構，並在橫向 A4 PDF 中將其呈現為格式化的表格與區段。

## 支援的格式

| 格式 | 副檔名 | 備註                    |
| :--- | :----- | :---------------------- |
| XML  | `.xml` | 任何格式正確的 XML 文件 |

## 運作方式

1. 點選上傳區域，或拖放您的 XML 檔案。可在單一批次中處理多個檔案。
2. 檢閱檔案清單。使用垃圾桶圖示移除不需要的檔案，或點選**新增更多檔案**加入更多檔案。
3. 點選**轉換為 PDF**。此工具會使用瀏覽器內建的 DOMParser 解析 XML 結構、分析資料階層，並使用 jsPDF 搭配自動表格格式將其轉換為 PDF。
4. 單一檔案會下載為 PDF。多個轉換結果會打包成 `xml-to-pdf.zip`。

## 選項

不需要手動設定。轉換器會自動偵測 XML 結構並選擇合適的表格版面。輸出使用橫向 A4 方向，以容納較寬的資料集。

## 使用情境

- 將資料庫或 API 匯出的 XML 資料轉換為可列印的報表
- 從 XML 設定檔建立易讀的摘要
- 將 XML 格式的發票或交易紀錄轉換為 PDF 以便存檔
- 讓 XML 網站地圖或 RSS 摘要以文件形式易於閱讀

## 提示

- XML 必須格式正確。如果剖析器遇到語法錯誤，轉換會失敗，並顯示指出問題所在的錯誤訊息。
- 深層巢狀的 XML 結構會被扁平化為表格。為獲得最佳結果，資料應具有重複的同層元素，且其子元素一致。
- 轉換期間會顯示進度更新，呈現每個階段：讀取、解析、分析與轉譯。

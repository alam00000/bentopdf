# PDF 小手冊

將 PDF 的頁面重新排列為小手冊拼版順序。雙面列印並對摺後，頁面就會依正確的閱讀順序排列。這是騎馬釘小手冊與小誌所使用的版面。

## 運作方式

1. 上傳 PDF 檔案。
2. 設定小手冊選項：輸出頁面大小與方向。
3. 點選**產生預覽**，查看頁面在每張紙上的排列方式。
4. 檢查預覽，其中會顯示每張實體紙張正反面所分配的頁面。
5. 點選**下載**，儲存已完成小手冊拼版的 PDF。

## 功能

- 自動為騎馬釘裝訂重新排序頁面
- 可設定輸出頁面大小
- 下載前可預覽小手冊版面
- 頁數為奇數時，會在需要處插入空白頁
- 縮放來源頁面以符合小手冊紙張大小

## 使用情境

- 從一般 PDF 製作可列印的小手冊或小誌
- 準備會議議程或活動指南以便自行列印
- 製作摺疊賀卡或小型型錄
- 製作手工裝訂的小冊子或詩集

## 小技巧

- 來源 PDF 的頁數最好是 4 的倍數，小手冊才會整齊。若不是，系統會自動加入空白頁補滿最後一張紙。
- 使用印表機的「短邊翻頁」設定雙面列印輸出結果，然後將所有紙張疊在一起對摺，並在書脊處裝訂。
- 若只是要將多頁放在同一張紙上而不需小手冊排序，請改用 [多頁併一頁 (N-Up)](./n-up-pdf)。

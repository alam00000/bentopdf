# 交錯混合頁面

將多個 PDF 檔案的頁面交錯排列，讓頁面在各文件之間輪替。當一般合併只會將檔案首尾相接，而您需要的是檔案 A 的第 1 頁、檔案 B 的第 1 頁、檔案 A 的第 2 頁依此類推時，就該使用這個工具。

## 運作方式

1. 使用拖放區上傳至少兩個 PDF 檔案。
2. 工具會顯示每個檔案的頁數與檔案大小。
3. 拖曳握把以調整交錯順序中哪個檔案的頁面優先。
4. 點選**混合頁面**以產生交錯輸出。
5. 結果會下載為 `alternated-mixed.pdf`。

## 功能

- 可交錯任意數量的 PDF（至少兩個）
- 拖放重新排列檔案以控制交錯優先順序
- 保留來源文件的書籤
- 顯示每個上傳檔案的頁數與檔案大小
- 透過專用的 Web Worker 處理，讓介面保持流暢

## 使用情境

- 重組奇數頁與偶數頁分開掃描的雙面掃描檔
- 將題目卷與解答合併，讓每題後面緊接著答案
- 逐頁合併雙語文件（例如一頁英文，下一頁譯文）
- 交錯單面掃描器掃描的正面與背面

## 小技巧

- 如果來源 PDF 的頁數不同，較短文件的頁面會先用完，較長文件的剩餘頁面會出現在最後。
- 檔案順序很重要：清單中的第一個檔案提供輸出的第一頁。如有需要請拖曳重新排列。

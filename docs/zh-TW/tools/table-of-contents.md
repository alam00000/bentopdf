# 目錄

此工具會讀取 PDF 中的書籤（大綱），並產生格式化的目錄頁面，插入到文件最前面。如果您的 PDF 已有書籤但缺少可見的目錄頁，此工具會自動建立一頁。

## 運作方式

1. 上傳含有書籤的 PDF。
2. 自訂目錄標題、字型大小與字型系列。
3. 可選擇勾選 **為目錄頁新增書籤**，將目錄本身加入書籤樹中。
4. 點擊 **產生目錄** 處理檔案。
5. 更新後的 PDF 會自動下載，目錄頁已插入在開頭。

## 選項

- **目錄標題**：顯示在產生頁面頂端的標題。預設為「目錄」。
- **字型大小**：可選擇 10pt 到 72pt。預設為 12pt。
- **字型系列**：可選擇 Times Roman、Helvetica 或 Courier 的各種樣式（標準、粗體、斜體、粗斜體）。預設為 Helvetica。
- **為目錄頁新增書籤**：勾選後，會在 PDF 的大綱樹中加入指向目錄頁本身的書籤項目。

## 功能特色

- 讀取 PDF 中完整的書籤階層
- 產生格式整齊、附有頁碼參照的目錄頁
- 支援以縮排呈現的巢狀書籤層級
- 可選擇 12 種內建 PDF 字型
- 可選擇為目錄頁加入指向自身的書籤

## 使用情境

- 為只有數位書籤的電子書或報告加上可列印的目錄
- 合併多個 PDF 後，為合併的文件建立目錄
- 為冗長的技術手冊產生參考頁面
- 為需要可見目錄的印刷文件做準備

## 提示

- 如果您的 PDF 沒有書籤，請先使用 [編輯書籤](./bookmark) 工具建立書籤，再回到這裡產生目錄。
- 對於大型文件，較大的字型大小（例如 14pt 或 16pt）可提升可讀性。

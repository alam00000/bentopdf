# CSV 轉 PDF

將 CSV 檔案轉換為乾淨、格式化的 PDF 文件。每個 CSV 都會被解析並在輸出 PDF 中呈現為表格。當您需要列印或分享表格資料，而收件者不一定有試算表軟體時，這非常實用。

## 支援格式

| 格式 | 副檔名 |
| :--- | :----- |
| CSV  | `.csv` |

## 運作方式

1. 點擊上傳區域，或拖放一個或多個 CSV 檔案。
2. 檢查檔案清單。新增更多檔案或移除不需要的檔案。
3. 點擊 **轉換為 PDF**。進度指示器會顯示轉換狀態。
4. 單一檔案會直接下載為 PDF。多個檔案會封裝成 `csv-converted.zip`。

## 選項

此工具沒有額外設定。CSV 會自動解析並格式化為表格。

## 輸出

| 輸入數量     | 輸出                                                  |
| :----------- | :---------------------------------------------------- |
| 1 個檔案     | 單一 PDF 下載（例如 `data.pdf`）                      |
| 2 個以上檔案 | ZIP 封存檔（`csv-converted.zip`），每個檔案各一個 PDF |

## 使用情境

- 將匯出的資料庫報表轉換為可列印的 PDF 表格
- 與沒有 Excel 的人分享財務資料或庫存清單
- 為合規文件建立 CSV 記錄檔的 PDF 版本
- 列印地址清單、成績表或任何以 CSV 儲存的表格資料

## 提示

- 為獲得最佳結果，請確保 CSV 使用標準逗號分隔符號。此工具遵循常見的 CSV 解析慣例。
- 如果 CSV 欄位很多，表格可能會被壓縮以符合頁面寬度。可考慮將寬資料集拆分成多個檔案。
- 對於 Excel 檔案（`.xls`、`.xlsx`），請使用 [Excel 轉 PDF](./excel-to-pdf) 工具，它會保留試算表格式與多個工作表。

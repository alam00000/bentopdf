# 光柵化 PDF

光柵化會將 PDF 的每一頁轉換為圖片，再將這些圖片重新組合成 PDF。結果看起來與原始檔案完全相同，但沒有可選取的文字、互動元素或可編輯的圖層。實際上就像一份高品質的影印本。

## 運作方式

1. 上傳一個或多個 PDF 檔案。
2. 設定光柵化輸出的 **DPI**（解析度）。
3. 選擇 **圖片格式**：PNG 為無損品質，JPEG 則檔案較小。
4. 可選擇勾選 **轉換為灰階**。
5. 點擊 **光柵化 PDF**。多個檔案會以 ZIP 下載。

## 選項

| 設定         | 值                        | 預設 |
| ------------ | ------------------------- | ---- |
| **DPI**      | 72, 150, 200, 300, 600    | 150  |
| **圖片格式** | PNG（無損）、JPEG（較小） | PNG  |
| **灰階**     | 開啟／關閉                | 關閉 |

## DPI 建議

- **72**：僅供螢幕檢視，檔案最小
- **150**：一般用途的良好平衡
- **200**：文字更清晰，檔案大小適中
- **300**：印刷品質輸出
- **600**：高品質封存或專業印刷

## 使用情境

- 分享機密文件前防止文字被擷取
- 將文字轉換為像素，消除字型相依問題
- 為含有複雜圖層或透明度、在不同檢視器中呈現不一致的 PDF 建立「平面」版本
- 為只接受圖片輸入的系統準備 PDF
- 將 PDF 轉為純圖片，移除隱藏內容（例如追蹤修訂或表單資料）

## 提示

- PNG 搭配 150 DPI 是可靠的預設值。只有在需要印刷輸出或放大檢視細節時才調高。
- JPEG 產生的檔案明顯較小，但會在銳利的文字邊緣產生壓縮瑕疵。
- 光柵化無法復原。如果之後可能需要可編輯的文字，請保留原始 PDF。

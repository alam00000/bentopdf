# 反轉頁面

反轉 PDF 的頁面順序，讓最後一頁變成第一頁、倒數第二頁變成第二頁，依此類推。支援一次批次處理多個檔案。

## 運作方式

1. 上傳一個或多個 PDF 檔案。
2. 點擊處理按鈕。
3. 每個檔案都會各自反轉。如果您上傳了多個檔案，輸出會是包含所有反轉後 PDF 的 ZIP 壓縮檔。
4. 單一檔案會直接下載為反轉後的 PDF。

## 功能特色

- 批次處理：一次反轉多個 PDF
- 單一 PDF 輸出單一檔案，多個則輸出 ZIP
- 處理前可逐一移除檔案
- 保留所有頁面內容與格式

## 使用情境

- 修正以相反順序掃描的文件
- 準備從後往前閱讀的簡報 PDF
- 為以相反順序進紙的特定列印流程反轉頁面順序
- 修正頁面不小心以相反順序組合的文件

## 提示

- 批次中的每個檔案都會各自反轉，檔案之間的相對順序不會改變。
- 若需要更細緻的頁面重新排序（而不只是整體反轉），請使用 [複製與組織](./organize-pdf)。

# PDF 編輯器

BentoPDF 的 PDF 編輯器可讓您為 PDF 加上註解、醒目提示、塗黑、評論、新增形狀與圖片，並搜尋內容。它直接在您的瀏覽器中載入功能完整的編輯器，無需上傳到伺服器。

## 運作方式

1. 點擊放置區或將檔案拖曳到其上，上傳您的 PDF。
2. 內嵌的 PDF 編輯器會自動開啟並載入您的文件。
3. 使用工具列加上註解、醒目提示、塗黑、新增文字、繪製形狀或插入圖片。
4. 點擊 **下載編輯後的 PDF** 儲存變更。

## 功能

- 完整的註解工具列，提供醒目提示、底線、刪除線與手繪
- 插入文字與加上評論
- 塗黑工具：套用塗黑後會永久移除標記的內容。如果您點擊 **下載編輯後的 PDF** 時仍有標記尚未套用，編輯器會提議先套用它們。
- 形狀工具：矩形、圓形、線條與箭頭
- 在 PDF 頁面上插入圖片
- 內建全文件文字搜尋
- 以分頁支援多份文件（最多可同時開啟 10 份文件）
- 拖放載入檔案

## 使用情境

- 審閱合約，以醒目提示與評論標示變更
- 分享前塗黑身分證號碼或財務資料等機密資訊
- 為建築平面圖或工程圖加上註解
- 在文件頁面上插入公司標誌或印章
- 在冗長的法律文件中搜尋特定詞彙

## 提示

- 您可以同時開啟多個 PDF，並使用編輯器頂端的分頁列在它們之間切換。
- 編輯器會保留原始 PDF 結構，因此字型、版面與表單欄位都會保持完整。
- 標記文字或區域以進行塗黑時，在套用塗黑之前不會移除任何內容。當您塗黑選取的文字時，該文字在檔案屬性、書籤、評論與附件中的副本也會從下載檔案中移除，除非檔案已加密。
- 若要大量加上浮水印或頁碼，請改用專用工具，以便更精細地控制格式。

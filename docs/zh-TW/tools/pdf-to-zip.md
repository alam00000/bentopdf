# PDF 轉 ZIP

將多個 PDF 檔案打包成單一 ZIP 壓縮檔。這是一個單純的打包工具，不會轉換、壓縮或修改 PDF 本身。

## 運作方式

1. 使用拖放區上傳多個 PDF 檔案。
2. 檢查檔案清單。移除任何不想包含的檔案。
3. 點選處理按鈕。
4. 包含所有已上傳 PDF 的 ZIP 壓縮檔會立即下載。

## 功能

- 接受任意數量的 PDF 檔案
- 建立壓縮檔前可逐一移除檔案
- 在 ZIP 中保留原始檔名
- 不修改 PDF 內容，檔案原樣打包
- 顯示每個已上傳 PDF 的檔名與大小

## 使用情境

- 將一組發票或收據打包成電子郵件附件
- 打包專案交付成果（多份 PDF 報告）以便交接
- 為一系列表單或範本建立單一下載檔
- 將一批文件封存成一個壓縮檔

## 小技巧

- ZIP 檔案使用原始的 PDF 檔名。如果有同名檔案，請在上傳前重新命名以避免衝突。
- 此工具不會壓縮 PDF 本身。若要縮小檔案大小，請先用壓縮 PDF 處理，再以此工具打包。

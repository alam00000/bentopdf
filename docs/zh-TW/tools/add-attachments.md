# 新增附件

將一個或多個檔案直接嵌入 PDF 文件中。附件可以加在文件層級（在任何 PDF 閱讀器的附件面板中都看得到），也可以綁定到特定頁面。

## 運作方式

1. 上傳您要附加檔案的 PDF。
2. 使用附件拖放區選擇要嵌入的檔案（任何檔案類型皆可）。
3. 選擇附件層級：**文件**（預設）或**頁面**。
4. 如果選擇頁面層級，請輸入頁面範圍（例如 `1-3` 或 `5`）。
5. 點選處理按鈕。修改後的 PDF 會連同嵌入的檔案一起下載。

## 功能

- 可附加任何檔案類型：圖片、試算表、壓縮檔、執行檔，什麼都行
- 可放在文件層級或頁面層級
- 一次操作即可附加多個檔案
- 顯示所有已選附件的檔名與大小
- 輸出保留原始 PDF 內容，並加入嵌入的檔案

## 選項

| 選項         | 說明                                       |
| ------------ | ------------------------------------------ |
| **文件層級** | 將檔案附加到整份 PDF，可從附件面板存取     |
| **頁面層級** | 將檔案附加到特定頁面，透過頁面範圍輸入指定 |

## 使用情境

- 將原始資料（Excel 檔案、CSV）與 PDF 報告打包在一起
- 將原始圖片檔附加到攝影作品集 PDF
- 在合約或提案中嵌入佐證文件
- 在訓練手冊的特定頁面加入補充資料

## 小技巧

- 文件層級附件在各種 PDF 閱讀器中支援度最高。頁面層級附件不一定能在所有檢視器中看到。
- 附件沒有檔案大小限制，但非常大的嵌入檔案會使 PDF 大小等比例增加。

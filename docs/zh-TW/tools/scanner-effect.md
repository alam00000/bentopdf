# 掃描效果

將乾淨的數位 PDF 轉換成看起來像是從平台式掃描器掃出來的文件。此工具會套用可設定的雜訊、輕微旋轉、模糊、亮度變化與選用的泛黃效果，模擬實體掃描的瑕疵。

## 運作方式

1. 上傳您的 PDF 檔案。
2. 編輯器會開啟，顯示第一頁的即時預覽與設定面板。
3. 使用滑桿與切換開關調整掃描效果參數。
4. 變更設定時，預覽會即時更新。
5. 點擊 **套用** 處理所有頁面並下載結果。

## 選項

- **色彩空間（灰階切換）**：將輸出轉為灰階，呈現經典的黑白掃描外觀。
- **邊框**：在頁面邊緣加上細微的深色邊框，模擬掃描器的邊框痕跡。
- **旋轉**：套用輕微旋轉（-5 到 +5 度），模擬進紙歪斜。
- **旋轉變異**：為旋轉角度加入隨機變化，讓每一頁的傾斜程度略有不同。
- **亮度**：調高或調低整體亮度。
- **對比**：調整對比，模擬碳粉品質的差異。
- **模糊**：套用高斯模糊柔化文字邊緣，就像低品質的掃描。
- **雜訊**：加入隨機像素雜訊，模擬掃描器感測器的顆粒感。數值越高，顆粒越明顯。
- **泛黃**：加入溫暖的黃色色調，模擬老舊或再生紙。
- **解析度**：設定輸出 DPI。數值越低，越有像素感、越像掃描。
- **重設**：將所有設定恢復為預設值。

## 功能特色

- 調整每個參數時都會即時更新預覽
- 每頁隨機旋轉變異，呈現逼真的變化
- 十個可獨立調整的參數
- 灰階模式，呈現道地的黑白掃描輸出
- 解析度控制，從低 DPI 的傳真品質到高 DPI 的封存品質

## 使用情境

- 讓數位建立的文件看起來像是經過掃描與列印
- 模擬實體文件老化，用於重現歷史文件
- 以劣化的掃描品質測試 OCR 軟體
- 製作與現有掃描封存資料視覺風格一致的文件

## 提示

- 先從細微的數值開始。雜訊等級 10-20、0.5 度的輕微旋轉，加上最小的模糊，就能產生逼真的掃描外觀。
- 結合灰階模式與輕微泛黃，可營造「影印本的影印本」效果。
- 較低的解析度設定（100-150 DPI）最能呈現逼真的傳真機外觀。

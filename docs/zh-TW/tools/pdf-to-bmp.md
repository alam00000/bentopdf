# PDF 轉 BMP

將 PDF 的每一頁轉換為 BMP（點陣圖）圖片。BMP 是未壓縮格式，因此輸出像素完美、沒有任何品質損失，但檔案會很大。

## 運作方式

1. 點選拖放區或將檔案拖曳到其中，上傳 PDF。
2. 點選**轉換**處理檔案。
3. 單一 `.bmp` 檔案或 ZIP 壓縮檔會自動下載。

## 選項

此工具沒有可設定的選項。頁面以固定的 2 倍比例算繪，產生的圖片約為 PDF 原始頁面尺寸的兩倍。

## 輸出格式

- **單頁**：`filename.bmp`
- **多頁**：`filename_bmps.zip`，內含 `page_1.bmp`、`page_2.bmp` 等

## 使用情境

- 將 PDF 頁面輸入只接受 BMP 的舊系統或硬體。
- 為特定列印工作流程準備未壓縮的圖片。
- 將點陣圖輸出用於需要原始像素資料的影像處理工具。

## 小技巧

- BMP 檔案會儲存未經壓縮的原始像素資料，因此非常大。大多數用途下，[PDF 轉 PNG](./pdf-to-png) 可提供無損品質，檔案也小得多。
- 如果目標系統接受 PNG 或 TIFF，請優先使用這些格式以節省磁碟空間。

# 背景顏色

在 PDF 所有現有內容的後方設定純色背景。此工具會在每頁建立一個彩色矩形，並將原始內容疊在上方，因此文字、圖片與圖形在新背景上都能完整顯示。

## 運作方式

1. 上傳您的 PDF 檔案。
2. 使用顏色選擇器挑選背景顏色。預設為淺黃色（#FFFFCC）。
3. 點選**變更背景顏色**以進行處理。
4. 更新後的 PDF 會自動下載。

## 選項

- **背景顏色**：用於選擇任何純色的標準顏色選擇器。預設為淺黃色。

## 功能

- 為每一頁套用統一的背景顏色
- 在彩色圖層上方保留所有原始內容（文字、圖片、向量圖形）
- 維持原始頁面尺寸
- 適用於任何頁數的文件

## 使用情境

- 加上淺奶油色或象牙色背景，讓文件呈現更柔和、類似紙張的外觀
- 為不同類別套用不同背景顏色，以顏色區分文件組
- 為不同對象建立視覺上可區分的同一文件版本
- 加上淺色背景，提升在螢幕上投影文件時的可讀性

## 小技巧

- 淺色、柔和的顏色效果最好。非常深的背景會讓文字難以閱讀，除非文字本身已是淺色。
- 如果想同時變更背景與文字顏色，請先套用背景顏色，再對結果使用[更改文字顏色](./text-color)。
- 此工具在 PDF 結構層級運作（而非點陣化），因此輸出中的文字仍可選取與搜尋。

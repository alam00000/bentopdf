# 多頁併一頁 (N-Up)

以格狀排列方式將多個頁面放在單一頁面上。每張紙可容納 2、4、6、8、9 或 16 頁，藉此減少列印的頁數。此工具會處理縮放、定位，並可選擇設定頁面尺寸。

## 運作方式

1. 上傳一個 PDF 檔案。
2. 選擇每張紙的頁數（「N」值）：2、4、6、8、9 或 16。
3. 選擇輸出頁面尺寸（預設為 A4）與方向。
4. 可選擇設定間距、邊框顏色與背景顏色。
5. 點擊處理按鈕。工具會縮放每一頁，並將它們拼排到新的頁面上。

## 功能

- 格狀版面：2-up、4-up、6-up、8-up、9-up 與 16-up
- 可設定輸出頁面尺寸與方向
- 可選擇拼排頁面之間的間距
- 背景與邊框顏色設定
- 縮放以符合版面時保留原始頁面的長寬比

## 選項

| 選項         | 說明                                              |
| ------------ | ------------------------------------------------- |
| **每張頁數** | 每個輸出頁面要容納的原始頁數（2、4、6、8、9、16） |
| **頁面尺寸** | 輸出頁面的尺寸（A4、Letter、Legal 等）            |
| **方向**     | 輸出頁面為直向或橫向                              |
| **間距**     | 拼排頁面之間的間隔（單位為點）                    |
| **背景顏色** | 輸出頁面背景的填滿顏色                            |
| **邊框顏色** | 每個拼排頁面周圍的邊框顏色                        |

## 使用情境

- 列印每頁 4 張投影片的講義以節省紙張
- 製作將多個參考頁面放在同一張紙上的學習單
- 製作精簡的文件封存以便歸檔
- 為長篇文件產生縮圖總覽頁

## 小技巧

- 2-up 版面通常較適合橫向，而 4-up 以上通常以直向最佳。
- 增加間距有助於閱讀，但會減少每個拼排頁面的可用面積。

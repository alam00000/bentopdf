# 移除限制

PDF 可以帶有兩種密碼：使用者密碼（開啟檔案時需要）與擁有者密碼（控制您能對檔案執行的操作）。此工具會移除這兩種密碼，以及所有相關限制，包括列印、編輯、複製與註解鎖定。

## 運作方式

1. 上傳 PDF 檔案。
2. 如果 PDF 設有擁有者密碼，請在 **擁有者密碼** 欄位中輸入。如果 PDF 只有使用限制而沒有密碼，請留空。
3. 點擊 **移除限制**。
4. 下載不受限制的 PDF。

此工具使用 QPDF 的 `--decrypt` 與 `--remove-restrictions` 旗標，產生乾淨且不受限制的副本。

## 移除的項目

- 密碼保護（使用者密碼與擁有者密碼）
- 列印限制
- 編輯限制
- 文字與圖片複製限制
- 註解與留言限制
- PDF 中編碼的所有其他安全限制

## 使用情境

- 解鎖您擁有、但多年前設定密碼的 PDF
- 移除您有合法存取權之文件的列印限制
- 在參考資料上啟用複製貼上，方便做筆記
- 為無法處理受限文件的無障礙工具準備 PDF

## 提示

- 如果設有擁有者密碼，您必須知道該密碼。此工具不會破解或暴力破解密碼。
- 如果需要保持檔案加密但變更特定權限，請改用變更權限工具。
- 輸出檔案完全沒有加密，任何收到檔案的人都可以自由開啟。

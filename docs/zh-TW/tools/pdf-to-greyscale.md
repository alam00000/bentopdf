# PDF 轉灰階

將彩色 PDF 轉換為灰階版本。每一頁都會先算繪、去除飽和度，再以 JPEG 圖片重新嵌入新的 PDF。輸出會保留原始頁面尺寸。

## 運作方式

1. 點選拖放區或將檔案拖曳到其中，上傳 PDF。
2. 點選**轉換**處理檔案。
3. 下載新的 `greyscale.pdf`，所有頁面皆已轉為黑白。

在背後，每一頁以 2 倍比例算繪，像素資料經過灰階濾鏡處理，再以 90% 品質重新編碼為 JPEG，放入全新的 PDF 文件中。

## 選項

此工具沒有可設定的選項。灰階轉換使用標準亮度公式，JPEG 品質固定為 90%。

## 輸出格式

- 單一 `greyscale.pdf` 檔案，所有頁面皆為灰階 JPEG 圖片。

## 使用情境

- 準備黑白列印文件，節省彩色墨水成本。
- 符合法律或政府文件要求灰階的提交規定。
- 縮小色彩豐富的 PDF 檔案大小（灰階 JPEG 圖片比彩色小）。
- 讓彩色與黑白頁面混雜的文件呈現一致的視覺風格。

## 小技巧

- 由於每一頁都會點陣化並以 JPEG 重新嵌入，輸出是以圖片為基礎。原始 PDF 中的文字將無法再選取或搜尋。若之後需要可搜尋的文字，請將輸出交給 OCR 工具處理。
- 若要更精細地調整色彩（亮度、對比、飽和度），請參考調整顏色工具，或 [PDF 工作流程建構器](./pdf-workflow) 中的灰階節點。

# 移除空白頁面

掃描 PDF 中空白或近乎空白的頁面並自動移除。此工具會轉譯每一頁並分析其像素內容來判斷是否為空白，接著讓您在處理前確認要移除哪些頁面。

## 運作方式

1. 上傳您的 PDF 檔案。
2. 調整 **敏感度** 滑桿，控制「空白」的判定嚴格程度。
3. 點擊 **偵測空白頁面** 掃描文件。
4. 工具會顯示偵測到的空白頁面縮圖，供您檢查。
5. 確認選取項目，並下載已移除空白頁面的 PDF。

## 選項

- **敏感度**：從 0% 到 100% 的滑桿（預設 80%）。數值越高越嚴格，只會標記完全或幾乎全白的頁面。數值越低越寬鬆，也會抓出只有極少內容的頁面，例如單一圓點或淡淡的浮水印。

## 功能特色

- 逐頁進行像素層級分析以偵測空白內容
- 可調整敏感度滑桿以微調偵測
- 偵測到的空白頁面會顯示縮圖預覽，方便手動確認
- 所有非空白頁面完整保留原樣
- 可處理任何大小或頁數的文件
- 掃描期間顯示進度

## 使用情境

- 清理掃描文件中，掃描器擷取到的單面原稿空白背面
- 移除大量掃描文件批次中的分隔頁
- 移除文件管理系統插入的空白頁面
- 清理文書處理軟體匯出時有時會在結尾附加空白頁的 PDF
- 移除不必要的空白頁面以縮小檔案大小

## 提示

- 先從預設的 80% 敏感度開始，再依情況調整。如果工具漏掉了您認為是空白的頁面，請降低敏感度。如果工具標記了含有您想保留之淡色內容的頁面，請調高敏感度。
- 此工具會轉譯每一頁來分析內容，因此處理時間會隨頁數增加。處理非常大型的文件時，請稍候片刻。
- 確認移除前，請先在縮圖預覽中檢查偵測到的空白頁面。依敏感度設定而定，含有淡色頁首、頁尾或浮水印的頁面也可能被標記。

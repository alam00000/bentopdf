# PDF 轉 PDF/A

PDF/A 是經 ISO 標準化的 PDF 子集，專為長期數位保存而設計。此工具使用直接在瀏覽器中執行的 Ghostscript，將標準 PDF 轉換為符合 PDF/A 的文件。

## 運作方式

1. 上傳一個或多個 PDF 檔案。
2. 從下拉選單選擇 **PDF/A 版本**。
3. 對於一般轉換失敗的複雜檔案，可選擇啟用**預先平面化 PDF**。
4. 點選**轉換為 PDF/A**。多個檔案會產生 ZIP 壓縮檔。

## PDF/A 版本

| 版本         | 限制                         | 最適合                         |
| ------------ | ---------------------------- | ------------------------------ |
| **PDF/A-1b** | 最嚴格。不允許透明度與圖層。 | 與較舊的封存系統達到最大相容性 |
| **PDF/A-2b** | 允許透明度與 JPEG2000。      | 一般用途封存（建議）           |
| **PDF/A-3b** | 允許內嵌任何格式的附件。     | 封存附帶原始資料檔的文件       |

預設選擇 PDF/A-2b，適用於絕大多數封存需求。

## 預先平面化選項

有些 PDF 包含會妨礙順利轉換為 PDF/A 的特性，例如特殊的字型編碼、複雜的透明度堆疊或損壞的內部結構。啟用**預先平面化**會在轉換前以 300 DPI 將 PDF 點陣化，雖能確保符合規範，但文字將無法選取。請在標準轉換產生錯誤時作為備援使用。

預先平面化需要 PyMuPDF WASM 引擎。

## 使用情境

- 符合政府或法律的封存要求（許多司法管轄區規定法院文件須使用 PDF/A）
- 將文件提交至機構典藏庫或數位圖書館
- 保存商業紀錄，以防原始軟體十年後已不復存在
- 為要求附帶 XML 附件之 PDF/A-3b 的電子發票標準準備發票

## 小技巧

- 請先嘗試不使用預先平面化進行轉換。只有在發生錯誤時才啟用。
- PDF/A 會內嵌所有字型，因此輸出檔案通常比原始檔案大。
- 如果您的工作流程要求嚴格符合規範，請使用專用的 PDF/A 驗證工具驗證輸出。

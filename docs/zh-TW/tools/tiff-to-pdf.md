# TIFF 轉 PDF

將 TIFF 檔案轉換為 PDF，包括多頁 TIFF。TIFF 檔案中的每一頁（或「IFD」）都會成為輸出 PDF 中的獨立頁面。這對於常以多頁 TIFF 儲存的掃描文件、傳真與醫學影像特別實用。

## 支援格式

| 格式 | 副檔名          |
| :--- | :-------------- |
| TIFF | `.tiff`, `.tif` |

## 運作方式

1. 點擊上傳區域，或將 TIFF 檔案拖放到該處。
2. 檢查檔案清單並視需要管理。
3. 點擊 **轉換為 PDF**。結果會下載為 `from_tiff.pdf`。

此工具使用 JavaScript TIFF 解碼器解碼每個 TIFF 檔案，擷取每一頁的原始 RGBA 像素資料。每一頁都會轉譯到畫布上、匯出為 PNG，再嵌入 PDF。頁面尺寸與原始 TIFF 頁面一致。

## 選項

此工具不提供其他品質設定。圖片會以原生解析度嵌入。

## 使用情境

- 將多頁傳真文件（TIFF-F）轉換為更具可攜性的 PDF 格式
- 將以 TIFF 儲存的掃描文件封存轉為可搜尋的 PDF（之後再搭配 OCR 工具）
- 處理使用 TIFF 的醫學影像檔案（病理切片、放射影像匯出）
- 將 GIS 或衛星影像 TIFF 檔案轉換為可分享的文件

## 提示

- 完整支援多頁 TIFF。10 頁的 TIFF 會產生 10 頁的 PDF，不需要先分割 TIFF。
- 非常大的 TIFF 檔案（數百 MB）可能需要較長的處理時間，因為整個檔案都必須在瀏覽器記憶體中解碼。
- 如果需要對產生的 PDF 進行 OCR，請在轉換後使用 [PDF 文字辨識 (OCR)](./ocr-pdf) 工具處理。

# 圖片轉 PDF

萬用的圖片轉 PDF 轉換器。上傳幾乎任何格式的圖片，並將它們合併為單一 PDF 文件。每張圖片各佔一頁，頁面大小與原始尺寸相符。

## 支援格式

| 格式            | 副檔名                                 |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

這是 BentoPDF 所有圖片轉換器中支援格式最廣的一個。如果您只需要特定格式，請改用對應的專用工具。

## 運作方式

1. 點擊上傳區域，或將圖片檔案拖放進來。可一次選取多個檔案。
2. 檢查檔案清單。使用垃圾桶圖示移除不需要的檔案，或點擊 **新增更多檔案** 加入其他圖片。
3. 從下拉選單選擇 **PDF 品質** 等級。
4. 點擊 **轉換為 PDF**。工具會透過 PyMuPDF 引擎處理圖片，並將結果下載為 `images_to_pdf.pdf`。

## 選項

**PDF 品質** 控制圖片嵌入 PDF 時套用的壓縮程度：

- **高品質**：壓縮最少，檔案較大。最適合列印或封存。
- **中等品質**（預設）：壓縮程度平衡。適合大多數用途。
- **低品質**：強力壓縮，檔案最小。適合電子郵件或快速分享。

HEIC 與 WebP 檔案會在嵌入前自動轉換為 PNG。這會在背後自動完成，不需要任何額外步驟。

## 使用情境

- 將用手機相機掃描的收據或文件合併為一個 PDF
- 以不同格式的圖片製作作品集或型錄
- 無需安裝桌面軟體，就能將 iPhone 照片 (HEIC) 轉為可分享的 PDF
- 將 PSD 匯出檔與螢幕截圖組合成交付給客戶的設計樣稿
- 將一整個資料夾的舊式圖片格式（PNM、JXR、JP2）封存為單一 PDF

## 小技巧

- PDF 中的圖片順序與檔案清單中的順序相同。請依您想要的順序上傳。
- 若要盡可能縮小檔案，請選擇低品質。對於以文字為主的掃描檔，視覺差異通常微乎其微。
- 如果您只有一種圖片格式，專用轉換器（JPG 轉 PDF、PNG 轉 PDF 等）能以更簡單的介面提供相同結果。

# WebP 轉 PDF

將 Google 的 WebP 圖片格式轉換為 PDF。當您從網路下載的圖片是 WebP 格式，而需要更普遍通用的格式來列印或分享時，這個工具特別實用。

## 支援的格式

| 格式 | 副檔名  |
| :--- | :------ |
| WebP | `.webp` |

## 運作方式

1. 點選上傳區域，或拖放您的 WebP 檔案。
2. 檢閱檔案清單，並移除不需要的檔案。
3. 選擇 **PDF 品質**等級。
4. 點選**轉換為 PDF**。輸出檔會下載為 `from_webps.pdf`。

在內部，每張 WebP 圖片會先透過瀏覽器的 canvas API 解碼，再使用 pdf-lib 嵌入 PDF。因此只要瀏覽器支援 WebP 解碼（所有現代瀏覽器都支援），轉換就能運作。

## 選項

**PDF 品質**控制嵌入圖片時的壓縮程度：

- **高品質**：保留最多細節。
- **中等品質**（預設）：輸出較為平衡。
- **低品質**：檔案最小。

## 使用情境

- 將從網路下載並儲存為 WebP 的圖片轉換為可列印的 PDF
- 將 Chrome 或 Edge 的 WebP 螢幕截圖整理進文件中
- 以預設輸出 WebP 的設計工具所匯出的圖片建立 PDF 作品集
- 以更普遍可讀的格式封存 WebP 圖片

## 提示

- WebP 在嵌入 PDF 前會先在內部解碼為 PNG，因此無損 WebP 圖片在高品質設定下能保有原本的品質。
- 如果您同時有 WebP 和其他圖片格式，請改用[圖片轉 PDF](./image-to-pdf) 工具，它可以一次接受所有格式。

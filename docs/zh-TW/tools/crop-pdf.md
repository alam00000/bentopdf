# 裁切 PDF

使用視覺化裁切介面修剪 PDF 頁面的邊界。直接在每個頁面上繪製裁切矩形、預覽結果並套用裁切。您可以為不同頁面設定不同的裁切區域，也可以對整份文件套用相同的裁切。

## 運作方式

1. 上傳您的 PDF 檔案。
2. 裁切編輯器開啟，顯示第一頁及可拖曳的裁切覆蓋層。
3. 拖曳邊緣或角落來調整裁切矩形。
4. 使用頁面導覽按鈕在頁面間切換，並為每一頁設定裁切區域。
5. 點擊 **裁切** 套用裁切並下載結果。

## 功能

- 由 Cropper.js 驅動的視覺化裁切編輯器，提供控點以精確調整
- 逐頁導覽，可設定個別裁切區域
- 儲存每頁的裁切設定，讓您為不同頁面定義不同的裁切
- 即時預覽所選的裁切區域
- 支援任何頁面尺寸或方向的 PDF

## 使用情境

- 移除掃描文件的寬邊界，聚焦於內容區域
- 修剪印前 PDF 中的印表機裁切標記或對位標記
- 裁切講義投影片，移除簡報者備註區域
- 在分享文件摘錄前，移除每一頁的頁首或頁尾
- 調整頁面大小以符合特定顯示或列印版面

## 提示

- 裁切覆蓋層可自由調整大小與位置。拖曳角落可等比例調整，拖曳邊緣可單軸調整。
- 若文件的每一頁都需要相同的裁切，請在第一頁設定即可，工具會在您切換頁面時記住裁切區域。
- 如果您需要統一頁面尺寸而非視覺裁切，統一頁面尺寸工具可能更適合。

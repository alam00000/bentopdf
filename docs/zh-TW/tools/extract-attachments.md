# 擷取附件

從一個或多個 PDF 檔案中取出所有內嵌附件。所有擷取的檔案都會打包成單一 ZIP 封存檔供下載。

## 運作方式

1. 上傳一個或多個含有內嵌附件的 PDF 檔案。
2. 點擊 **擷取附件**。
3. 工具會掃描每個 PDF 中的文件層級與頁面層級附件。
4. 找到的所有檔案會封裝成 ZIP 封存檔並自動下載。
5. 狀態訊息會確認找到的附件數量及其總大小。

## 功能

- 一次從多個 PDF 批次擷取
- 同時擷取文件層級與頁面層級的附件
- 輸出包含所有擷取檔案的單一 ZIP 檔
- 顯示附件總數與合計檔案大小
- 找不到附件時會顯示清楚的狀態訊息

## 使用情境

- 還原報告 PDF 中內嵌的資料檔案
- 從作品集或規格文件中取出圖片素材
- 從訓練或合規 PDF 中擷取補充資料
- 稽核一批 PDF 中內嵌了哪些檔案

## 提示

- 如果工具回報沒有附件，該 PDF 可能含有的是內嵌圖片或表單資料，這些並不是檔案附件。內嵌圖片請使用 [擷取圖片](./extract-images)。
- 處理多個 PDF 時，所有檔案的附件都會放進同一個 ZIP。檔名會沿用原始內嵌時的名稱。

# WPS 轉 PDF

將 Microsoft Works 文書處理檔案轉換為 PDF。Microsoft Works 在 1990 年代末到 2000 年代隨消費型電腦一起提供，至今仍有許多 WPS 檔案存放在舊硬碟與電子郵件封存中。此工具可在瀏覽器中開啟它們並產生清晰的 PDF。

## 支援的格式

| 格式            | 副檔名 | 備註                           |
| :-------------- | :----- | :----------------------------- |
| Microsoft Works | `.wps` | Microsoft Works 的文書處理檔案 |

## 運作方式

1. 點選上傳區域，或拖放您的 WPS 檔案。可接受多個檔案。
2. 檢閱檔案清單。使用垃圾桶圖示移除個別檔案，或點選**新增更多檔案**擴充批次。
3. 點選**轉換為 PDF**。以 LibreOffice 為基礎的引擎會在瀏覽器中載入，並將每份 WPS 文件轉換為 PDF。
4. 單一檔案會直接下載為 PDF。多個檔案會打包成名為 `wps-to-pdf.zip` 的 ZIP 壓縮檔。

## 選項

不需要其他設定。轉換器會處理 WPS 檔案中的文字、基本格式與內嵌圖片。

## 使用情境

- 救回以 Microsoft Works 格式儲存的舊學校或工作文件
- 在未安裝 Microsoft Works 的情況下開啟 WPS 電子郵件附件
- 轉換整批 WPS 檔案，以遷移至新式文件系統
- 列印目前文書處理軟體無法開啟的舊文件

## 提示

- 請勿將 Microsoft Works 的 `.wps` 檔案與 WPS Office 檔案混淆。此工具專門處理較舊的 Microsoft Works 格式。
- LibreOffice 引擎在第一次使用時需要一點時間載入。載入後，同一工作階段中的其他轉換會更快。

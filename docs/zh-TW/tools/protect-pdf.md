# 保護 PDF

用密碼鎖住您的 PDF，只有經授權的人才能開啟。BentoPDF 使用 256 位元 AES 加密（與銀行及政府機關採用的標準相同），並透過 QPDF 完全在您的瀏覽器中套用。

## 運作方式

1. 上傳 PDF 檔案。
2. 輸入 **使用者密碼**（必填）。這是其他人開啟檔案時需要的密碼。
3. 可選擇輸入 **擁有者密碼**。設定後，PDF 會加上使用限制，禁止列印、編輯、複製與註解。
4. 點擊 **加密 PDF**。
5. 下載加密後的檔案。

## 密碼類型

### 使用者密碼（必填）

使用者密碼是收件人開啟 PDF 時要輸入的密碼。沒有它，就完全無法存取文件。每個加密的 PDF 都必須設定。

### 擁有者密碼（選填）

擁有者密碼控制授權使用者在開啟檔案後可以執行哪些操作。當您設定不同的擁有者密碼時，BentoPDF 會自動套用最嚴格的限制組合：

- 禁止修改
- 禁止擷取／複製
- 禁止列印
- 禁止註解
- 禁止填寫表單
- 禁止組合文件

若擁有者密碼留空，PDF 仍會加密（開啟時仍需使用者密碼），但開啟後沒有任何使用限制。

## 加密詳細資訊

- **演算法**：AES-256（256 位元進階加密標準）
- **金鑰長度**：256 位元
- **標準**：PDF 2.0 加密（QPDF 實作）

以目前的技術，AES-256 在運算上無法被暴力破解。加密 PDF 的安全性完全取決於您的密碼強度。

## 使用情境

- 以電子郵件寄送機密財務報告前先加以保護
- 保護與對造律師共享的法律文件
- 為醫療紀錄或個人識別資訊加上密碼
- 以存取控制發布付費內容（電子書、報告）
- 遵循要求靜態資料加密的資料保護政策

## 提示

- 請使用強度高且獨一無二的密碼。理想的是 12 個字元以上、混合大小寫、數字與符號的密碼片語。
- 請透過其他管道（電話、簡訊）分享密碼，絕對不要與 PDF 放在同一封電子郵件中。
- 如果只需要限制操作（禁止列印、禁止複製），而不需要密碼才能開啟，請改用變更權限工具。

# 新增浮水印

使用視覺化編輯器為 PDF 頁面加上文字或圖片浮水印。您可以直接在預覽上拖曳浮水印來定位、用角落控點調整大小，並設定不透明度、旋轉、字型與顏色。每一頁可以有各自的浮水印位置，也可以一次將相同的浮水印套用到所有頁面。

## 運作方式

1. 上傳您的 PDF 檔案。
2. 編輯器會開啟，顯示第一頁的即時預覽與可拖曳的浮水印圖層。
3. 使用切換按鈕選擇**文字**或**圖片**浮水印模式。
4. 在側邊欄面板中設定浮水印選項。
5. 在預覽上拖曳浮水印，將其放在您想要的確切位置。使用角落控點調整大小。
6. 切換頁面以設定個別頁面的浮水印，或保持勾選**套用到所有頁面**。
7. 點選**新增浮水印**以處理並下載。

## 選項

**文字浮水印設定：**

- **文字**：浮水印文字（例如「機密」、「草稿」）。
- **字型大小**：從 10 到 200 點。預設為 72。
- **顏色**：透過顏色選擇器選擇任何顏色。
- **不透明度**：控制從完全透明到完全不透明的透明度。
- **旋轉**：將浮水印文字旋轉 -180 到 180 度。

**圖片浮水印設定：**

- **上傳圖片**：上傳 PNG、JPG 或其他圖片檔作為浮水印。
- **不透明度**：控制圖片的透明度。
- **縮放**：調整圖片浮水印的大小。

**版面配置設定：**

- **單一**：每頁一個浮水印，可拖曳或使用位置預設值定位。
- **平鋪**：以依循旋轉角度的斜向網格在整頁重複浮水印，讓標記從邊緣到邊緣覆蓋整份文件。
- **水平間距**：沿文字方向的平鋪間距，以浮水印寬度的百分比表示（僅限平鋪模式）。
- **垂直間距**：平鋪列之間的間距，以浮水印高度的百分比表示（僅限平鋪模式）。

**一般設定：**

- **套用到所有頁面**：勾選時，相同的浮水印會套用到每一頁。取消勾選可為每頁設定個別浮水印。
- **頁面範圍**：指定要加上浮水印的頁面（例如「1-3, 5, 7-9」或「all」）。

## 功能

- 在即時 PDF 預覽上以視覺化拖放定位
- 可用角落控點調整浮水印大小
- 文字與圖片浮水印模式
- 單一或整頁平鋪（重複）版面配置，間距可調整
- 可套用到個別頁面或全部頁面
- 在預覽中逐頁切換
- 不透明度與旋轉控制
- 頁面範圍篩選

## 使用情境

- 在草稿文件傳閱審閱前標上「草稿」
- 為敏感的財務報告加上「機密」浮水印
- 以公司標誌圖片浮水印為文件加上品牌
- 在提供給潛在客戶的產品文件上標示「SAMPLE」
- 為發佈的 PDF 資料加上版權聲明

## 小技巧

- 若要在頁面上加上斜向浮水印，請將旋轉設為約 45 度並加大字型大小。
- 平鋪模式讓文件在裁切後更難被再利用，因為移除一個標記後仍會留下數十個。平鋪時請降低不透明度，讓底下的文字保持可讀。
- 透明背景的圖片浮水印（PNG 格式）能更自然地與文件內容融合。
- 如果不同頁面需要不同的浮水印文字，請取消勾選「套用到所有頁面」並逐頁設定。

# Markdown 轉 PDF

功能完整的 Markdown 編輯器，具備即時預覽與一鍵匯出 PDF。您可以從頭開始撰寫、上傳現有的 `.md` 檔案，或從剪貼簿貼上內容。編輯器會即時轉譯您的 Markdown，並使用瀏覽器內建的列印引擎匯出有樣式的 PDF。

## 支援格式

| 輸入       | 說明                 |
| :--------- | :------------------- |
| `.md` 檔案 | 透過上傳按鈕上傳     |
| 直接輸入   | 在編輯器中輸入或貼上 |

## 運作方式

1. 開啟 Markdown 轉 PDF 工具。編輯器會以分割檢視載入：左側為 Markdown 原始碼，右側為轉譯後的預覽。
2. 撰寫 Markdown、貼上內容，或點擊 **上傳** 載入 `.md` 檔案。
3. 使用工具列中的主題滑桿切換淺色與深色主題。
4. 點擊 **匯出 PDF**（或按下 `Ctrl/Cmd + S`），透過瀏覽器的列印對話框產生 PDF。

## 功能

編輯器支援的 Markdown 功能遠不只基本語法：

- **標準 Markdown**：標題、粗體、斜體、連結、圖片、清單、引用區塊、水平線
- **程式碼區塊**，支援 15 種以上語言的語法醒目提示（JavaScript、TypeScript、Python、Go、Rust、SQL、Java、C#、C++、YAML、Bash 等）
- **Mermaid 圖表**：流程圖、循序圖、ER 圖及其他 Mermaid 圖表類型可直接在預覽中呈現
- **表格**，使用標準 Markdown 表格語法
- **任務清單**，附核取方塊
- **註腳**、**下標**、**上標**
- **定義清單**、**縮寫**
- **表情符號** 支援（`:smile:` 會呈現為表情符號）
- **醒目標示**（`==marked text==`）與 **插入文字**（`++inserted text++`）
- **自動連結網址**：純網址會轉換為可點擊的連結
- **目錄** 產生
- 標題上的 **錨點連結**

## 使用情境

- 撰寫專案文件，並匯出精美的 PDF 給利害關係人
- 建立含程式碼範例與 Mermaid 架構圖的技術報告
- 將 GitHub README 轉換為 PDF，供離線使用或列印
- 草擬含任務清單與表格的提案或規格書
- 從以 Markdown 撰寫的課堂筆記產生有樣式的講義

## 小技巧

- PDF 輸出使用瀏覽器的「列印成 PDF」功能。在 Chrome 中，您可以在儲存前於列印對話框自訂邊界與縮放比例。
- Mermaid 圖表會在預覽中呈現，但第一次使用時可能需要稍候初始化。
- 使用 `Ctrl/Cmd + S` 鍵盤快速鍵即可匯出，不必點擊按鈕。

# CBZ 轉 PDF

將漫畫封存檔轉換為 PDF。CBZ 和 CBR 是數位漫畫的標準格式，其實就是裝滿圖片的 ZIP 或 RAR 封存檔。此工具會擷取每一頁、保留閱讀順序，並產生乾淨的 PDF，每張圖片都成為一個完整尺寸的頁面。

## 支援格式

| 格式 | 副檔名 | 說明                                                 |
| :--- | :----- | :--------------------------------------------------- |
| CBZ  | `.cbz` | 以 ZIP 為基礎的漫畫封存檔（使用 pdf-lib 在本機處理） |
| CBR  | `.cbr` | 以 RAR 為基礎的漫畫封存檔（透過 PyMuPDF 引擎處理）   |

CBZ 轉換器可辨識封存檔中的 JPEG、PNG、GIF、BMP、WebP、AVIF、TIFF、HEIC 和 JXL 圖片。非標準格式會在嵌入前自動轉換為 PNG。

## 運作方式

1. 點擊上傳區域，或拖放您的 CBZ 或 CBR 檔案。同一批次中可混合兩種格式。
2. 檢查列出的檔案。移除不需要的檔案，或點擊 **新增更多檔案** 加入更多。
3. 點擊 **轉換為 PDF**。對於 CBZ 檔案，工具會解壓縮封存檔、依自然順序按名稱排序圖片檔、偵測每張圖片的實際格式，並使用 pdf-lib 將其嵌入 PDF。CBR 檔案則改由 PyMuPDF 引擎處理。
4. 單一檔案會下載為 PDF。多個檔案會產生名為 `comic-converted.zip` 的 ZIP 封存檔。

## 選項

無需任何設定。每張圖片都會成為與其原始尺寸相符的頁面，因此跨頁仍保持寬幅，單頁仍保持窄幅。

## 使用情境

- 在支援 PDF 但不支援 CBZ/CBR 的平板或手機應用程式上閱讀漫畫
- 列印數位漫畫中的特定頁面
- 將漫畫收藏封存為任何檔案檢視器都能開啟的格式
- 與沒有專用漫畫閱讀器的人分享漫畫

## 提示

- 封存檔中的圖片使用自然排序（因此 `page2.jpg` 會排在 `page10.jpg` 之前）。請以一致的編號命名檔案，以確保頁面順序正確。
- 轉換器依據二進位特徵（而非副檔名）偵測圖片格式。不小心命名為 `.jpg` 的 PNG 仍能正確嵌入。
- CBZ 檔案完全在瀏覽器中處理，不需載入 PyMuPDF 引擎，因此轉換速度比 CBR 檔案快。

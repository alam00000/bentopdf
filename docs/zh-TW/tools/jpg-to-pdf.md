# JPG 轉 PDF

將 JPG 圖片轉為整潔的 PDF。上傳單一檔案，或一次批次處理多張 JPG，每張圖片都會成為輸出文件中的一個完整頁面。

## 支援格式

| 格式      | 副檔名          |
| :-------- | :-------------- |
| JPEG      | `.jpg`, `.jpeg` |
| JPEG 2000 | `.jp2`, `.jpx`  |

## 運作方式

1. 點擊上傳區域，或將 JPG 檔案拖放進來。支援多選。
2. 檢查已上傳的檔案。使用垃圾桶圖示移除個別檔案，或點擊 **新增更多檔案** 加入清單。
3. 選擇 **PDF 品質** 等級。
4. 點擊 **轉換為 PDF**。工具會依您的品質設定壓縮圖片，透過 PyMuPDF 引擎轉換，並下載 `from_jpgs.pdf`。

## 選項

**PDF 品質** 調整每張圖片嵌入 PDF 前套用的壓縮程度：

- **高品質**：保留最多細節。適用於攝影或列印。
- **中等品質**（預設）：在清晰度與檔案大小之間取得良好平衡。
- **低品質**：強力壓縮，輸出檔案最小。

## 使用情境

- 將存成 JPG 的掃描文件轉換為單一提交用 PDF
- 將產品照片打包成給客戶的型錄
- 將 JPEG 2000 醫療或衛星影像轉為便於攜帶的 PDF
- 以相機匯出的照片製作可列印的相簿

## 小技巧

- 完整支援 JPEG 2000 檔案（`.jp2`、`.jpx`），不只是標準 JPEG。這對醫療影像與地理空間資料很有用。
- 如果您的 JPG 來自手機相機，中等品質產生的檔案通常比高品質小 40-60%，在螢幕上看不出差異。

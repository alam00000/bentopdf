# 清理 PDF

PDF 所包含的內容遠比您在螢幕上看到的多。隱藏的中繼資料、內嵌的 JavaScript、檔案附件、表單資料與圖層資訊，都可能洩漏敏感資料或帶來安全風險。清理會將這些全部移除，留下一份可以安心公開分享的乾淨文件。

## 運作方式

1. 上傳 PDF 檔案。
2. 從檢查清單中選擇要移除的元素。
3. 點擊 **清理 PDF**。
4. 下載清理後的檔案。

## 清理選項

所有選項預設皆為啟用。取消勾選您想保留的項目。

| 選項                | 移除的內容                                    |
| ------------------- | --------------------------------------------- |
| **平面化表單**      | 將互動式表單欄位轉換為靜態內容                |
| **移除中繼資料**    | 移除作者、標題、建立日期、軟體資訊與 XMP 資料 |
| **移除註解**        | 刪除留言、螢光標示、便利貼與標記              |
| **移除 JavaScript** | 清除開啟時可能執行的內嵌指令碼                |
| **移除內嵌檔案**    | 移除 PDF 中內嵌的檔案附件                     |
| **移除圖層（OCG）** | 將選擇性內容群組平面化為單一圖層              |
| **移除連結**        | 移除超連結與 URL 參照                         |
| **移除結構樹**      | 移除用於無障礙標記的文件結構                  |
| **移除 MarkInfo**   | 移除標記內容資訊                              |
| **移除字型**        | 移除內嵌字型資料（請謹慎使用）                |

## 使用情境

- 移除內部中繼資料（作者姓名、軟體版本、編輯紀錄），為公開發布準備 PDF
- 開啟來自不受信任來源的 PDF 前，先移除其中的 JavaScript
- 將 PDF 寄給不應看到內嵌留言或表單欄位名稱的客戶前先加以清理
- 分享最終版本前移除建築圖面中的隱藏圖層
- 遵循隱私法規中的資料最小化要求

## 提示

- 除非確定 PDF 仍能正確轉譯，否則請勿勾選「移除字型」。移除字型可能會使文字在部分檢視器中無法顯示。
- 如果只需要移除中繼資料，專用的移除中繼資料工具更快速也更專注。
- 清理無法復原。請保留原始檔案。

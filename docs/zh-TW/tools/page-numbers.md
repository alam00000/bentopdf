# 頁碼

為 PDF 的每一頁加上可見的頁碼。您選擇位置、格式、字型大小與顏色，其餘交給工具處理。

## 運作方式

1. 上傳 PDF 檔案。
2. 在出現的選項面板中設定頁碼。
3. 點選**加入頁碼**進行處理。
4. 加上頁碼的 PDF 會自動下載。

## 選項

- **位置**：選擇頁碼出現的位置：下方置中、左下、右下、上方置中、左上或右上。
- **格式**：選擇簡單編號（1、2、3...）或「第 X 頁，共 Y 頁」格式（1 / 5、2 / 5...）。
- **字型大小**：設定頁碼文字的大小。預設為 12。
- **顏色**：使用顏色選擇器為頁碼文字挑選任意顏色。

## 功能

- 六種位置選項，涵蓋所有角落與置中位置
- 兩種編號格式：簡單連續編號或「第 X 頁，共 Y 頁」
- 字型大小可自訂，範圍 6 到 72 點
- 完整的文字顏色選擇器
- 自動處理邊界，無論頁面大小都讓頁碼保持在安全區域內

## 使用情境

- 準備需要可見頁碼參照的列印文件
- 為由多個來源檔案合併而成的 PDF 加上頁碼
- 在發送前為簡報講義編號
- 為法律文件或合約加上連續編號

## 小技巧

- 「第 X 頁，共 Y 頁」格式適合讀者需要知道總長度的文件，例如提案或報告。
- 如果不同章節需要不同的編號樣式（例如前置內容使用羅馬數字），請改用 [新增頁面標籤](./add-page-labels) 工具。

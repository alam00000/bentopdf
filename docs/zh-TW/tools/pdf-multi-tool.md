# PDF 多功能工具

一個整合所有頁面層級 PDF 操作的工作區。上傳一個或多個 PDF，即可在單一視覺化網格中處理所有頁面。旋轉、重新排序、複製、刪除、插入新的 PDF、新增空白頁面並分割結果，全都不必離開此工具。

## 運作方式

1. 點選**上傳 PDF**，或將檔案拖曳到上傳區域。支援多個檔案。
2. 所有上傳檔案的每一頁都會以縮圖顯示在可捲動的網格中。
3. 使用工具列或每頁的操作按鈕來處理頁面。
4. 使用每張卡片上的核取方塊選取頁面，再套用批次操作。
5. 使用剪刀圖示標記分割點，將輸出分成多個檔案。
6. 點選**匯出 PDF** 下載最終結果。如果有分割標記，輸出會是包含多個 PDF 的 ZIP。

## 功能

- **合併**：上傳多個 PDF，會自動合併到同一個工作區
- **重新排序**：拖放頁面卡片來重新排列順序
- **旋轉**：以 90 度為單位（向左或向右）旋轉單頁或批次旋轉
- **複製**：一鍵複製任何頁面
- **刪除**：移除個別頁面或批次刪除所選頁面
- **插入 PDF**：在任一特定頁面之後加入新的 PDF
- **新增空白頁面**：在最後附加一張空白 A4 頁面
- **分割**：在頁面之間放置分割標記，然後匯出為包含多個 PDF 的 ZIP
- **全選 / 取消全選**：快速選取以進行批次操作
- **復原 / 重做**：每項操作都有完整的復原/重做歷程
- **下載所選頁面**：僅將所選頁面匯出為獨立的 PDF
- 載入前自動修復損毀的 PDF

## 使用情境

- 從多個來源 PDF 的頁面組合出自訂文件
- 整理掃描文件：刪除空白頁、旋轉橫向掃描的頁面並重新排序章節
- 使用視覺化分割標記，依章節分割大型 PDF
- 不需完整 PDF 編輯器即可快速進行頁面層級編輯

## 小技巧

- 復原/重做系統會追蹤每項操作。放心使用，您不會意外毀掉自己的成果。
- 分割標記會以藍色虛線顯示在頁面之間。在您想分割文件的位置放置標記，然後匯出即可取得 ZIP。
- 若只是單純的合併或分割，專用的 [合併 PDF](./merge-pdf) 或 [分割 PDF](./split-pdf) 工具可能更快。多功能工具的強項在於需要在同一工作階段中進行多種操作時。

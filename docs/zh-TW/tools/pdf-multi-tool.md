# PDF 多功能工具

一個整合所有頁面層級 PDF 操作的工作區。上傳一個或多個 PDF，即可在單一視覺化網格中處理所有頁面。旋轉、重新排序、複製及刪除頁面，插入 PDF、圖片與空白頁面，重新編號、調整大小並分割結果，全都不必離開此工具。

## 運作方式

1. 點選**選取檔案**，或將檔案拖曳到上傳區域。支援多個檔案，並會依上傳順序合併。
2. 所有頁面都會以縮圖顯示在可捲動的網格中。
3. 點選頁面即可選取。按住 Shift 點選可選取連續範圍，按住 Cmd/Ctrl 點選可加入或移除個別頁面。
4. 使用頁面管理工具的工具列，或在頁面上按右鍵，來執行頁面操作。
5. 點選**匯出 PDF** 下載最終結果。

## 功能

- **合併**：上傳多個 PDF 和圖片，會自動合併成一份文件
- **重新排序**：拖放頁面來重新排列順序，或反轉整份文件
- **旋轉**：以 90 度為單位向左或向右旋轉所選頁面
- **複製**：複製所選頁面，並將副本放在原頁面之後
- **刪除**：移除所選頁面
- **插入**：加入其他 PDF 或圖片的頁面、空白頁面、剪貼簿中的頁面，或將第二份 PDF 的頁面與目前頁面交錯排列
- **取代**：以另一份 PDF 的第一頁取代某一頁
- **剪下、複製與貼上**：在文件內移動或複製頁面
- **擷取**：將所選頁面下載為 PDF 或圖片
- **頁碼**：為一段頁面設定頁面標籤，例如 i、ii、iii 或 A-1、A-2
- **頁面大小**：將頁面調整為標準紙張尺寸或自訂尺寸
- **分割**：依頁面範圍、奇數頁與偶數頁、每一頁、書籤、每 N 頁或檔案大小分割文件
- **復原 / 重做**：每項頁面操作都可以復原與重做
- 載入前自動修復損毀的 PDF

## 鍵盤快速鍵

| 操作             | 快速鍵                        |
| ---------------- | ----------------------------- |
| 向右 / 向左旋轉  | R / Shift+R                   |
| 全選             | Cmd/Ctrl+A                    |
| 剪下、複製、貼上 | Cmd/Ctrl+X, C, V              |
| 複製頁面         | Cmd/Ctrl+D                    |
| 刪除             | Delete 或 Backspace           |
| 復原 / 重做      | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| 移動選取範圍     | 方向鍵、Home、End             |

## 使用情境

- 從多個來源 PDF 的頁面組合出自訂文件
- 整理掃描文件：刪除空白頁、旋轉橫向掃描的頁面並重新排序章節
- 利用書籤，依章節分割大型 PDF
- 不需完整 PDF 編輯器即可快速進行頁面層級編輯

## 小技巧

- 復原/重做歷程會追蹤每項頁面操作。放心使用，您不會意外毀掉自己的成果。
- 隨時可以使用 **Insert > From File**，或將更多 PDF 或圖片拖放到頁面網格中，把它們加入文件。
- 若只是單純的合併或分割，專用的 [合併 PDF](./merge-pdf) 或 [分割 PDF](./split-pdf) 工具可能更快。多功能工具的強項在於需要在同一工作階段中進行多種操作時。

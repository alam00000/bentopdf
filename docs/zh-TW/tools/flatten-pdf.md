# 平面化 PDF

平面化會將互動元素（表單欄位、下拉選單、核取方塊、註解、螢光標記、便利貼）直接合併到頁面內容中。外觀維持不變，但所有內容都無法再編輯或擷取。這就像是把填好的表單列印出來再掃描回去，只是品質完全不會降低。

## 運作方式

1. 上傳一個或多個 PDF 檔案。
2. 點擊 **平面化 PDF**。
3. 單一檔案會直接下載。多個檔案則會產生 ZIP 壓縮檔。

此工具使用 pdf-lib 平面化表單欄位（透過 `form.flatten()`），並使用專用的註解平面化程式將註解燒錄到頁面串流中。兩項作業會在一次處理中完成。

## 會被平面化的內容

- **表單欄位**：文字輸入框、核取方塊、選項按鈕、下拉選單、簽名欄位
- **註解**：評論、螢光標記、刪除線、底線、便利貼、印章、手寫註解
- **互動元素**：按鈕、動作觸發器

## 維持不變的內容

- 文字內容（仍可選取與搜尋）
- 圖片與圖形
- 頁面版面與尺寸
- 書籤與目錄
- 超連結（以註解為基礎的除外）

## 使用情境

- 鎖定已完成的表單，讓收件者無法更改已提交的答案
- 準備封存用的 PDF，不需要互動元素
- 修正因註解在不同檢視器中呈現方式不同而造成的顯示問題
- 確保已簽署的文件在簽名後無法被修改
- 移除表單欄位定義與註解物件以縮小檔案大小

## 小技巧

- 請在所有編輯完成後再平面化。PDF 一旦平面化就無法還原。
- 如果您需要平面化並同時移除中繼資料、JavaScript 與附件，請改用清理 PDF 工具，它將平面化列為選項之一。
- 有些 PDF 會顯示「找不到表單」，如果文件只有註解而沒有表單欄位，這是正常現象。

# 新增空白頁面

在 PDF 中您指定的位置插入空白頁面。您可以控制空白頁面插入的位置與數量。

## 運作方式

1. 上傳 PDF 檔案。工具會顯示頁數。
2. 輸入要插入空白頁面的**位置**。使用 `0` 插入到最前面，或使用總頁數附加到最後。
3. 輸入要新增的空白頁面**數量**（預設為 1）。
4. 點選處理按鈕。插入空白頁面後的 PDF 會自動下載。

## 功能

- 可插入任何位置：文件開頭、中間或結尾
- 一次操作即可新增多頁空白頁面
- 位置提示會依上傳 PDF 的頁數動態更新
- 標準 A4 尺寸的空白頁面

## 使用情境

- 在彙編文件的各章節之間加入空白分隔頁
- 插入空白頁面以對齊雙面列印
- 在列印的學習指南中加入手寫筆記的空間
- 補足頁數以符合最低頁數要求

## 小技巧

- 位置 `0` 會插入到第一頁之前。位置等於總頁數時會附加到最後一頁之後。
- 如果需要在特定位置插入內容（而不只是空白頁），請使用 [PDF 多功能工具](./pdf-multi-tool)在指定頁面後插入另一份 PDF。

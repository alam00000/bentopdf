# 統一頁面尺寸

由多個來源組合而成的 PDF 經常出現頁面尺寸不一致的情況：有些是 Letter，有些是 A4，有些則完全不是標準尺寸。此工具會將每一頁強制調整為單一目標尺寸，並視需要縮放內容以符合或填滿頁面。

## 運作方式

1. 上傳一個 PDF 檔案。
2. 從下拉選單選擇 **目標頁面尺寸**（A4、Letter、Legal、A3、A5、Tabloid 或自訂）。
3. 選擇 **方向**：「自動」會保留每頁原本的方向，您也可以強制設為直向或橫向。
4. 選擇 **內容縮放** 模式：符合（保留所有內容，可能會加上邊界）或填滿（填滿頁面，可能會裁切邊緣）。
5. 可選擇為新增的邊界設定 **背景顏色**。
6. 點擊 **統一頁面尺寸**。

## 選項

- **標準尺寸**：A4、Letter、Legal、A3、A5、Tabloid
- **自訂尺寸**：以英吋或公釐輸入寬度與高度
- **方向**：自動、直向、橫向
- **縮放模式**：符合或填滿（裁切）
- **背景顏色**：邊界填充可使用任何顏色

## 使用情境

- 統一合併後的 PDF，其中頁面來自不同的掃描器
- 將 US Letter 文件轉換為 A4 以供國際發布
- 準備需要一致裁切尺寸的印刷用 PDF
- 修正略微偏離標準的頁面（例如 8.49 x 11.02 英吋而非 8.5 x 11）

## 小技巧

- 使用符合模式可確保不遺失任何內容。填滿模式看起來較整齊，但可能會裁掉邊緣。
- 使用頁面尺寸工具檢查輸出結果，確認每一頁都符合目標尺寸。
- 預設背景顏色為白色；如果您的文件邊界是深色，請改用深色。

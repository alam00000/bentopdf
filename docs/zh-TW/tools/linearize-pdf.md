# 線性化 PDF

線性化會重新組織 PDF 的結構，讓第一頁在整個檔案下載完成前就能顯示。Adobe 稱之為「快速網頁檢視」(Fast Web View)。如果您在網站上提供 PDF，或透過文件入口網站提供，線性化能讓它們開啟的速度明顯變快。

## 運作方式

1. 上傳一個或多個 PDF 檔案。
2. 點擊 **線性化 PDF**。
3. 下載包含所有線性化檔案的 ZIP 壓縮檔。

無需任何設定。此工具使用 QPDF 的 `--linearize` 旗標，重新排列 PDF 的內部結構，而不改變其視覺內容。

## 線性化的作用

- 重新排序 PDF 物件，讓第一頁的資料出現在檔案開頭
- 加入線性化字典與提示表，讓檢視器知道每一頁的位置
- 支援位元組範圍請求：瀏覽器只需擷取第一頁，而不必下載整個檔案
- 整理交叉參照表，以便有效率地隨機存取

## 功能

- 一次操作即可批次處理多個 PDF
- 輸出保留所有內容、字型、圖片與互動元素
- 使用 QPDF (WebAssembly) 進行可靠且符合標準的線性化
- 結果會打包成 ZIP，方便下載

## 使用情境

- 在網站上提供 PDF 報告，讓使用者能立即看到頁面
- 在具有瀏覽器內檢視器的網頁應用程式中嵌入 PDF
- 發布透過緩慢行動網路存取的 PDF 型錄或手冊
- 為支援位元組範圍傳輸的內容傳遞網路 (CDN) 準備文件

## 小技巧

- 請在所有其他編輯完成後再進行線性化。之後的任何修改（合併、新增頁面）都會破壞線性化。
- 搭配壓縮 PDF 使用，可得到最小、載入最快的 PDF。
- 線性化會讓檔案大小略微增加（通常不到 1%）。

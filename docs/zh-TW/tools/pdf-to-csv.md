# PDF 轉 CSV

從 PDF 擷取表格並匯出為 CSV 檔案。工具會使用 PyMuPDF 的表格偵測引擎掃描每一頁的表格資料，然後將找到的所有列寫入單一以逗號分隔的輸出檔。

## 運作方式

1. 點選拖放區或將檔案拖曳到其中，上傳 PDF。
2. 點選**轉換**開始擷取表格。
3. 工具會掃描每一頁並自動辨識表格。
4. 下載包含所有擷取表格資料的 `.csv` 檔案。

輸出中，不同頁面的表格以空白列分隔。含有逗號、引號或換行的儲存格會依照 RFC 4180 正確跳脫。

## 選項

此工具沒有可設定的選項。文件中找到的所有表格都會被擷取並合併為單一 CSV。

## 輸出格式

- 單一 `filename.csv` 檔案，包含所有偵測到的表格。

## 使用情境

- 將 PDF 銀行對帳單或發票中的財務資料匯入試算表。
- 從廠商報價中擷取價目表以便比較。
- 將 PDF 論文中的表格研究資料轉換為適合分析工具使用的格式。
- 將舊有 PDF 報告中的資料移轉到資料庫。

## 小技巧

- 如果找不到表格，工具會顯示「找不到表格」訊息。這通常表示 PDF 使用的是看起來像表格、但並未結構化為實際表格的文字版面。
- 若要更精細地控制個別表格，請使用 [擷取 PDF 表格](./extract-tables)，可選擇 CSV、JSON 與 Markdown 輸出格式。
- 如果需要 Excel 格式，且每個表格各自一張工作表，請使用 [PDF 轉 Excel](./pdf-to-excel)。

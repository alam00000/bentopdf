# MOBI 轉 PDF

將 Amazon Kindle MOBI 電子書轉換為 PDF 文件。MOBI 檔案綁定 Kindle 裝置與 App，在其他地方很難閱讀。轉換成 PDF 後，您就有一個可攜式版本，能在任何裝置上開啟或列印。

## 支援格式

| 格式 | 副檔名  | 說明                           |
| :--- | :------ | :----------------------------- |
| MOBI | `.mobi` | Kindle 電子書格式 (Mobipocket) |

## 運作方式

1. 點擊上傳區域，或拖放一個或多個 MOBI 檔案。
2. 檢查檔案清單。使用垃圾桶圖示移除不需要的檔案，或使用 **新增更多檔案** 加入其他電子書。
3. 點擊 **轉換為 PDF**。PyMuPDF 引擎會解析 MOBI 結構，並將每一頁轉譯為 PDF 內容。
4. 單一檔案會下載為 PDF。轉換多個檔案時，您會得到名為 `mobi-converted.zip` 的 ZIP 壓縮檔。

## 選項

無需其他設定。轉換會保留原始 MOBI 檔案中的文字內容、格式與內嵌圖片。

## 使用情境

- 在僅支援 PDF 的非 Kindle 電子閱讀器上閱讀 Kindle 購買的內容
- 列印電子書的章節，供離線研讀或註記
- 以通用格式封存您的個人電子書庫
- 與沒有安裝 Kindle App 的人分享摘錄內容

## 小技巧

- 受 DRM 保護的 MOBI 檔案無法轉換。此工具僅適用於無 DRM 的 MOBI 檔案。
- 含有大量內嵌圖片的大型電子書可能需要多花幾秒處理，因為所有作業都在瀏覽器中進行。

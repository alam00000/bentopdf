# 壓縮 PDF

縮小 PDF 檔案而不破壞內容。壓縮 PDF 由 BentoPDF 自家的壓縮引擎 [Hyper Compress](https://www.bentopdf.com/hyper-compress) 驅動。它會重新壓縮圖片、對字型進行子集化與合併，並移除內嵌縮圖和私有應用程式資料等多餘內容。PDF 仍保有完整功能：文字依然可選取，連結與表單欄位也能正常運作。

Hyper Compress 編譯為 WebAssembly 並隨 BentoPDF 一起提供，因此壓縮可離線運作，也能在實體隔離的部署環境中使用，無需額外設定。

## 運作方式

1. 點擊放置區或拖曳檔案，上傳一個或多個 PDF。
2. 選擇 **壓縮等級**：低、中、高或無損。
3. 可選擇輸入 **目標檔案大小**，或展開 **自訂設定** 進行細部控制，包括 **轉換為灰階**。
4. 點擊 **壓縮 PDF**。多個檔案會以單一 ZIP 下載。

## 特殊文件

- **數位簽署的 PDF** 會原封不動地傳回，因為任何變更都會使簽章失效。在自訂設定中開啟 **覆寫內容保護**，即可移除簽章並進行壓縮；頁面上的可見簽名會保留，但檔案將不再具有簽章。
- **PDF/A 檔案** 壓縮後會移除其 PDF/A 標記，避免檔案宣稱符合已不再符合的標準。在自訂設定中開啟 **保留 PDF/A**，即可讓檔案維持合規。
- **受密碼保護的 PDF** 會在檔案卡片上顯示密碼欄位。在此輸入密碼，Hyper Compress 即會自行開啟檔案，無需另外解鎖。有兩個以上的加密檔案時，一個共用欄位即可解鎖所有使用相同密碼的檔案。壓縮後的副本不含密碼；請使用 [保護 PDF](./protect-pdf) 重新加上密碼。
- **沒有文字層的掃描檔** 可在自訂設定中使用 **光柵化頁面** 進一步縮小，此功能會將每個頁面替換為一張最佳化圖片。任何含有可選取文字的文件（包括經過 OCR 的掃描檔）都會略過此步驟，除非開啟 **覆寫內容保護**。開啟後，文字頁面也會變成圖片，文字將無法選取，連結也會失效。

## 壓縮等級

| 等級     | 圖片品質 | 最大解析度 | 最適合                 |
| -------- | -------- | ---------- | ---------------------- |
| **低**   | 80       | 200 DPI    | 保留視覺品質           |
| **中**   | 50       | 150 DPI    | 日常文件               |
| **高**   | 20       | 72 DPI     | 電子郵件附件、網頁上傳 |
| **無損** | 圖片不變 | 不變       | 封存副本               |

「高」等級還會取消嵌入 14 種標準 PDF 字型，以及在安全時取消嵌入 Arial 等相似字型。

## 目標檔案大小

輸入以 KB 或 MB 為單位的大小，Hyper Compress 會從您選擇的等級開始，搜尋仍能符合大小的最佳圖片品質。如果文件無法縮到那麼小，您會得到它能產生的最小版本，並看到相關訊息。[將 PDF 壓縮至 1MB](https://www.bentopdf.com/compress-pdf-to-1mb) 等專用頁面開啟時已預先填入目標大小。

## 自訂設定

展開自訂設定面板即可直接調整 Hyper Compress。選擇壓縮等級會將這些設定重設為該等級的值，而編輯任何一項設定都會將等級切換為自訂。

- **覆寫內容保護**：預設情況下，Hyper Compress 不會變更已簽署的 PDF，也不會光柵化含有文字的頁面。開啟此選項會略過這兩項限制。變更等級時此選項會保持開啟。

- **圖片**：圖片品質、最大解析度、強制重新取樣、色彩縮減、裁除不可見的圖片區域、移除替代圖片、簡化色彩描述檔、JPEG 2000 與無損模式
- **字型**：子集化、合併重複字型，以及取消嵌入標準字型及其相似字型
- **內容**：平面化註解、表單欄位或連結
- **清理**：移除縮圖、應用程式資料、文章串、網頁擷取資訊、結構樹或輸出意圖
- **光柵化**：以圖片取代頁面，適用於純圖片掃描檔；文件含有可選取文字時會略過
- **輸出**：保留 PDF/A，以及供支援的 PDF 2.0 閱讀器使用的 Brotli 壓縮

## 使用情境

- 將 50 MB 的報告縮小到電子郵件附件限制以內
- 利用目標檔案大小，讓掃描檔符合入口網站嚴格的上傳限制
- 最佳化行銷 PDF，加快網站下載速度
- 封存大量文件，節省儲存成本
- 透過通訊應用程式分享 PDF 時減少行動數據用量

## 提示

- 從「中」開始。如果結果仍然太大，請設定目標檔案大小或改用「高」。
- 對於沒有文字層的掃描檔，請在自訂設定中開啟光柵化頁面。
- 自訂設定中的轉換為灰階，可縮小色彩豐富文件的檔案大小。

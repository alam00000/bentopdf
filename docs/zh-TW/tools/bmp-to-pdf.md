# BMP 轉 PDF

將 Windows 點陣圖（BMP）檔案轉換為 PDF。BMP 是一種未壓縮的圖片格式，至今仍常見於舊系統、醫學影像與工業掃描器。此工具無需安裝任何軟體即可將其轉換為 PDF。

## 支援格式

| 格式 | 副檔名 |
| :--- | :----- |
| BMP  | `.bmp` |

## 運作方式

1. 點選上傳區域，或拖放您的 BMP 檔案。
2. 檢查檔案清單。可新增更多檔案或移除不需要的檔案。
3. 點選**轉換為 PDF**。輸出會下載為 `from_bmps.pdf`。

每個 BMP 會先繪製到畫布上、匯出為 PNG，再使用 pdf-lib 嵌入 PDF。頁面尺寸與原始圖片尺寸相同。

## 選項

此工具沒有額外的品質設定。圖片會以原始解析度、無損 PNG 的形式嵌入 PDF。

## 使用情境

- 將以 BMP 儲存的舊掃描文件轉換為可封存的 PDF
- 將舊版 Windows 應用程式的 BMP 截圖轉為可分享的文件
- 處理預設輸出 BMP 的醫學或工業掃描器檔案
- 將舊圖片檔案庫遷移到更通用的格式

## 小技巧

- BMP 檔案未經壓縮，因此通常很大。由於圖片在內部會重新編碼為 PNG，產生的 PDF 會明顯較小。
- 如果 BMP 檔案與其他圖片格式混在一起，請使用[圖片轉 PDF](./image-to-pdf) 工具一次批次轉換所有檔案。

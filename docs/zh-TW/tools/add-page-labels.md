# 新增頁面標籤

頁面標籤控制頁碼在 PDF 檢視器中的顯示方式（工具列中顯示的號碼，而非印在頁面上的號碼）。此工具可讓您為不同頁面範圍指定不同的標籤方案：前言使用羅馬數字、正文使用十進位數字、附錄使用字母等等。

## 運作方式

1. 上傳您的 PDF 檔案。
2. 選項面板會出現，預設有一條標籤規則。
3. 為每條規則設定頁面範圍、樣式、選用的前綴與起始值。
4. 點選**新增規則**，為不同章節建立更多規則。
5. 點選**新增頁面標籤**以套用所有規則並下載結果。

## 選項

每條標籤規則有以下設定：

- **頁面範圍**：規則套用的頁面。留空表示所有頁面。支援 `1-4`、`7`、`odd` 或 `1-9,30-40` 等範圍。
- **標籤樣式**：十進位阿拉伯數字、小寫羅馬數字（i、ii、iii）、大寫羅馬數字（I、II、III）、小寫字母（a、b、c）、大寫字母（A、B、C），或無標籤（僅前綴）。
- **標籤前綴**：加在每個標籤前方的選用文字，例如「A-」可產生 A-1、A-2、A-3 這樣的標籤。
- **起始值**：開始計數的號碼。預設為 1。設為 0 則從零開始編號。
- **在不連續範圍間延續編號**：當規則針對不連續頁面（例如 `1-9,30-40` 或 `odd`）且您希望編號依序延續時，請啟用此選項。
- **移除現有頁面標籤**：預設勾選。在套用新規則前清除先前的所有標籤。

## 功能

- 每份文件可設定多條標籤規則，以實現複雜的編號方案
- 六種標籤樣式，涵蓋所有標準編號系統
- 支援自訂前綴，方便依章節標示
- 支援不連續範圍與連續編號
- 可選擇保留或移除現有標籤

## 使用情境

- 為書籍的序言設定羅馬數字標籤（i、ii、iii），正文則使用十進位標籤
- 以字母前綴標示附錄頁面，例如「A-1」、「A-2」、「B-1」、「B-2」
- 修正掃描文件中實體頁碼與 PDF 頁面順序不符的頁面標籤
- 為技術文件加上從零開始的編號

## 小技巧

- 頁面標籤是 PDF 檢視器在導覽工具列中顯示的中繼資料，不會印在實際頁面上。若需要可見的號碼，請使用[頁碼](./page-numbers)。
- 此工具需要在 WASM 設定中設定 CoherentPDF（CPDF）。如果尚未設定，系統會提示您進行設定。

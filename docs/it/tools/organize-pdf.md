# Duplica e Organizza

Riorganizza, duplica e rimuovi le pagine di un PDF con un'interfaccia visiva a trascinamento. Ogni pagina appare come una miniatura che puoi spostare, clonare o eliminare prima di salvare il risultato come nuovo file.

## Come funziona

1. Carica un singolo file PDF.
2. Lo strumento mostra una griglia di miniature con tutte le pagine.
3. Trascina le miniature per riordinare le pagine, clicca sul pulsante verde di duplicazione per clonare una pagina o sul pulsante rosso di eliminazione per rimuoverla.
4. In alternativa, inserisci un ordine di pagine personalizzato nel campo di testo (ad es. `3, 1, 2, 4`) e clicca su **Applica** per riorganizzare tutte le pagine in una volta.
5. Clicca sul pulsante di elaborazione per creare e scaricare il PDF riorganizzato.

## Funzionalità

- Riordino delle pagine con trascinamento e transizioni animate
- Pulsanti di duplicazione ed eliminazione per ogni pagina
- Ordine di pagine personalizzato per una disposizione precisa
- Etichette con il numero di pagina che si aggiornano automaticamente dopo ogni modifica
- Impedisce di eliminare l'ultima pagina rimasta

## Casi d'uso

- Spostare nella posizione corretta una pagina fuori posto in un report
- Duplicare la pagina di un modulo per avere più copie vuote in un unico file
- Rimuovere pagine di bozza o segnaposto prima di distribuire un documento
- Invertire o rimescolare l'ordine delle pagine per preparare la stampa
- Creare una sequenza di pagine personalizzata senza dover unire di nuovo file separati

## Suggerimenti

- Il campo dell'ordine personalizzato richiede i numeri delle pagine originali separati da virgole. Deve includere ogni pagina esattamente una volta: nessuna omissione e nessun duplicato.
- Dopo aver duplicato una pagina, entrambe le copie fanno riferimento allo stesso indice di pagina originale. Puoi riordinare ciascuna copia in modo indipendente.
- Per operazioni in blocco su più file o flussi di lavoro più avanzati, valuta lo [Strumento PDF multifunzione](./pdf-multi-tool).

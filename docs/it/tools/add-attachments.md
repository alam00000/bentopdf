# Aggiungi allegati

Incorpora uno o più file direttamente all'interno di un documento PDF. Gli allegati possono essere aggiunti a livello di documento (visibili nel pannello degli allegati di qualsiasi lettore PDF) oppure associati a pagine specifiche.

## Come funziona

1. Carica il PDF a cui vuoi allegare i file.
2. Usa l'area di rilascio degli allegati per selezionare i file da incorporare (di qualsiasi tipo).
3. Scegli il livello dell'allegato: **Documento** (predefinito) o **Pagina**.
4. Se scegli il livello Pagina, inserisci un intervallo di pagine (ad es. `1-3` o `5`).
5. Fai clic sul pulsante di elaborazione. Il PDF modificato viene scaricato con i tuoi file incorporati.

## Funzionalità

- Allega qualsiasi tipo di file: immagini, fogli di calcolo, archivi, eseguibili, qualunque cosa
- Posizionamento dell'allegato a livello di documento o di pagina
- È possibile allegare più file in una sola operazione
- Mostra nomi e dimensioni di tutti gli allegati selezionati
- L'output conserva il contenuto originale del PDF con l'aggiunta dei file incorporati

## Opzioni

| Opzione               | Descrizione                                                                   |
| --------------------- | ----------------------------------------------------------------------------- |
| **Livello documento** | Allega i file al PDF nel suo insieme, accessibili dal pannello degli allegati |
| **Livello pagina**    | Allega i file a pagine specifiche, indicate tramite un intervallo di pagine   |

## Casi d'uso

- Unire i dati di origine (file Excel, CSV) a un report in PDF
- Allegare i file immagine originali al PDF del portfolio di un fotografo
- Incorporare documenti di supporto in un contratto o in una proposta
- Aggiungere materiali integrativi a pagine specifiche di un manuale di formazione

## Suggerimenti

- Gli allegati a livello di documento sono i più supportati dai lettori PDF. Gli allegati a livello di pagina potrebbero non essere visibili in tutti i visualizzatori.
- Non c'è un limite alla dimensione degli allegati, ma file incorporati molto grandi aumenteranno proporzionalmente le dimensioni del PDF.

# VSD in PDF

Converti i diagrammi Microsoft Visio in PDF senza installare Visio. I file VSD e VSDX contengono diagrammi di flusso, organigrammi, diagrammi di rete e planimetrie che la maggior parte delle persone non riesce ad aprire. Questo strumento li trasforma in PDF puliti, visualizzabili su qualsiasi dispositivo.

## Formati supportati

| Formato       | Estensione | Note                                           |
| :------------ | :--------- | :--------------------------------------------- |
| Visio binario | `.vsd`     | Formato Visio legacy (Visio 2003 e precedenti) |
| Visio XML     | `.vsdx`    | Formato Visio moderno (Visio 2013+)            |

## Come funziona

1. Fai clic sull'area di caricamento o trascina i tuoi file VSD o VSDX. Puoi mescolare i due formati nello stesso batch.
2. Controlla l'elenco dei file. Rimuovi le voci indesiderate con l'icona del cestino, oppure usa **Aggiungi altri file** per aggiungere altri diagrammi.
3. Fai clic su **Converti in PDF**. Il motore basato su LibreOffice si carica nel browser e trasforma ogni diagramma in un PDF, mantenendo forme, connettori, etichette e layout di pagina.
4. Un singolo diagramma viene scaricato direttamente come PDF. Più file producono un archivio ZIP chiamato `vsd-to-pdf.zip`.

## Opzioni

Non è richiesta alcuna configurazione. Il convertitore rispetta le dimensioni e l'orientamento di pagina originali del documento Visio.

## Casi d'uso

- Consultare i diagrammi Visio di un collega quando non hai una licenza Visio
- Includere diagrammi di rete o di architettura nella documentazione di progetto come PDF
- Stampare organigrammi o flussi di processo come dispense per le riunioni
- Archiviare vecchi file VSD delle versioni precedenti di Visio in un formato destinato a durare

## Suggerimenti

- I documenti Visio con più pagine producono PDF con più pagine, con ogni pagina Visio associata a una pagina PDF.
- I file VSDX (il formato moderno basato su XML) in genere vengono convertiti con maggiore fedeltà rispetto ai vecchi file binari VSD.
- Il motore LibreOffice viene caricato una sola volta per sessione. Aspettati una breve attesa alla prima conversione, con risultati più rapidi sui file successivi.

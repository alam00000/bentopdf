# ODP in PDF

Converti i file OpenDocument Presentation in PDF. ODP è il formato nativo di LibreOffice Impress ed è un'esportazione standard di Google Slides. Trasformare le presentazioni in PDF permette a chiunque di visualizzarle senza software di presentazione, e le diapositive si stampano in modo pulito.

## Formati supportati

| Formato                   | Estensione | Note                                                |
| :------------------------ | :--------- | :-------------------------------------------------- |
| OpenDocument Presentation | `.odp`     | LibreOffice Impress / esportazione di Google Slides |

## Come funziona

1. Clicca sull'area di caricamento o trascina i tuoi file ODP. Puoi selezionare più presentazioni contemporaneamente.
2. Controlla l'elenco dei file. Rimuovi le voci con l'icona del cestino, oppure usa **Aggiungi altri file** per includere altre presentazioni.
3. Clicca su **Converti in PDF**. Il motore basato su LibreOffice elabora ogni presentazione e produce un PDF in cui ogni diapositiva diventa una pagina.
4. Un singolo file viene scaricato come PDF. Più file vengono consegnati in un archivio ZIP chiamato `odp-to-pdf.zip`.

## Opzioni

Nessuna impostazione da configurare. Ogni diapositiva viene resa alle sue dimensioni originali, preservando testo, immagini, forme e sfondi.

## Casi d'uso

- Distribuire una presentazione al pubblico come dispensa in PDF
- Condividere le esportazioni di Google Slides con chi preferisce il PDF all'ODP
- Archiviare interventi a conferenze e lezioni in un formato di sola lettura
- Stampare presentazioni per workshop in presenza

## Suggerimenti

- Le transizioni e le animazioni delle diapositive sono funzioni solo visive che non passano nel PDF, ma tutto il contenuto statico viene reso correttamente.
- Le note del relatore non sono incluse nel PDF. Se ti servono le note, esportale separatamente dal tuo software di presentazione.
- Come gli altri strumenti basati su LibreOffice, il motore si carica al primo utilizzo e resta in cache per la sessione.

# WPD in PDF

Converti i documenti Corel WordPerfect in file PDF. WPD è stato per anni il formato di elaborazione testi dominante negli studi legali e negli enti pubblici. Se hai vecchi file WordPerfect che i software moderni non riescono ad aprire, questo strumento li riporta in vita come PDF standard.

## Formati supportati

| Formato     | Estensione | Note                                        |
| :---------- | :--------- | :------------------------------------------ |
| WordPerfect | `.wpd`     | Tutte le principali versioni di WordPerfect |

## Come funziona

1. Fai clic sull'area di caricamento o trascina i tuoi file WPD. Puoi selezionare più file contemporaneamente.
2. Controlla l'elenco dei file. Rimuovi i file indesiderati con l'icona del cestino, oppure usa **Aggiungi altri file** per aggiungere altri documenti.
3. Fai clic su **Converti in PDF**. Lo strumento carica nel browser un motore di conversione basato su LibreOffice, che analizza il formato WPD e produce il PDF.
4. Un singolo file viene scaricato direttamente come PDF. Le conversioni in batch producono un archivio ZIP chiamato `wpd-to-pdf.zip`.

## Opzioni

Non è richiesta alcuna configurazione. Il motore LibreOffice gestisce automaticamente formattazione, font e layout WPD.

## Casi d'uso

- Aprire documenti legali vecchi di decenni scritti in WordPerfect
- Convertire pratiche governative archiviate da WPD a un formato moderno
- Migrare una vecchia libreria di documenti WordPerfect in PDF per l'archiviazione a lungo termine
- Condividere file WPD con destinatari che non hanno Corel WordPerfect installato

## Suggerimenti

- Il motore LibreOffice si carica al primo utilizzo, e ci vuole un momento. Le conversioni successive nella stessa sessione sono più rapide.
- Le macro WPD complesse e i codici rivelati non vengono mantenuti, ma layout visivo, contenuto testuale e formattazione di base passano nel PDF.

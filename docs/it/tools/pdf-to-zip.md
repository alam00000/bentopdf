# PDF in ZIP

Raccogli più file PDF in un unico archivio ZIP. È un semplice strumento di impacchettamento: nessuna conversione, compressione o modifica dei PDF stessi.

## Come funziona

1. Carica più file PDF usando l'area di rilascio.
2. Controlla l'elenco dei file. Rimuovi quelli che non vuoi includere.
3. Clicca sul pulsante di elaborazione.
4. Un archivio ZIP contenente tutti i PDF caricati viene scaricato subito.

## Funzionalità

- Accetta qualsiasi numero di file PDF
- Rimozione dei singoli file prima di creare l'archivio
- Mantiene i nomi originali dei file all'interno dello ZIP
- Nessuna modifica al contenuto dei PDF: i file vengono impacchettati così come sono
- Mostra nome e dimensione di ogni PDF caricato

## Casi d'uso

- Raccogliere un insieme di fatture o ricevute da allegare a un'email
- Impacchettare i deliverable di un progetto (più report PDF) per la consegna
- Creare un unico download per una raccolta di moduli o modelli
- Archiviare un gruppo di documenti in un unico file compresso

## Suggerimenti

- Il file ZIP usa i nomi originali dei PDF. Se hai file con lo stesso nome, rinominali prima del caricamento per evitare conflitti.
- Questo strumento non comprime i PDF stessi. Per ridurre le dimensioni dei file, passali prima da Comprimi PDF, poi impacchettali con questo strumento.

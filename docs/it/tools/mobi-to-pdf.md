# MOBI in PDF

Converti gli ebook MOBI di Amazon Kindle in documenti PDF. I file MOBI sono legati ai dispositivi e alle app Kindle, quindi è difficile leggerli altrove. Convertirli in PDF ti dà una versione portabile che puoi aprire su qualsiasi dispositivo o stampare.

## Formati supportati

| Formato | Estensione | Note                              |
| :------ | :--------- | :-------------------------------- |
| MOBI    | `.mobi`    | Formato ebook Kindle (Mobipocket) |

## Come funziona

1. Clicca sull'area di caricamento o trascina uno o più file MOBI.
2. Controlla l'elenco dei file. Rimuovi quelli che non ti servono con l'icona del cestino, oppure usa **Aggiungi altri file** per includere altri ebook.
3. Clicca su **Converti in PDF**. Il motore PyMuPDF analizza la struttura del MOBI e rende ogni pagina come contenuto PDF.
4. Un singolo file viene scaricato come PDF. Se converti più file, ottieni un archivio ZIP chiamato `mobi-converted.zip`.

## Opzioni

Non servono impostazioni aggiuntive. La conversione conserva il contenuto testuale, la formattazione e le immagini incorporate del file MOBI originale.

## Casi d'uso

- Leggere contenuti acquistati su Kindle su un e-reader non Kindle che supporta solo il PDF
- Stampare capitoli di un ebook per lo studio o le annotazioni offline
- Archiviare la tua libreria personale di ebook in un formato universale
- Condividere estratti con chi non ha l'app Kindle installata

## Suggerimenti

- I file MOBI protetti da DRM non possono essere convertiti. Lo strumento funziona solo con file MOBI senza DRM.
- Gli ebook grandi con molte immagini incorporate possono richiedere qualche secondo in più, perché tutto avviene nel browser.

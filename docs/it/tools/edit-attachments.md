# Modifica allegati

Ispeziona e gestisci i file allegati all'interno di un PDF. Lo strumento elenca ogni file incorporato con il suo nome e il livello di allegato, poi ti permette di contrassegnare singoli allegati per la rimozione o di eliminarli tutti in una volta.

## Come funziona

1. Carica un file PDF.
2. Lo strumento cerca automaticamente gli allegati e li mostra in un elenco.
3. Ogni allegato mostra il nome del file e se è un allegato a livello di documento o di pagina.
4. Fai clic sull'icona del cestino accanto a un allegato per contrassegnarlo per la rimozione (fai di nuovo clic per annullare).
5. Usa il pulsante **Rimuovi tutti gli allegati** per selezionare tutto in una volta, oppure **Deseleziona tutto** per azzerare le selezioni.
6. Fai clic sul pulsante di elaborazione per salvare un nuovo PDF senza gli allegati selezionati.

## Funzionalità

- Elenca tutti gli allegati a livello di documento e di pagina
- Rimozione singola o in blocco degli allegati
- Selezione attivabile e disattivabile prima di confermare le modifiche
- Testo barrato e opacità ridotta sugli elementi contrassegnati per la rimozione
- Scarica il PDF modificato senza gli allegati selezionati

## Casi d'uso

- Rimuovere file obsoleti o errati incorporati in un documento prima di ridistribuirlo
- Eliminare allegati sensibili (dati finanziari, informazioni personali) da un PDF prima di condividerlo
- Ridurre le dimensioni del PDF rimuovendo grandi file incorporati non più necessari
- Verificare i contenuti incorporati e ripulire un documento prima di archiviarlo

## Suggerimenti

- Gli allegati contrassegnati per la rimozione vengono mostrati barrati. Puoi riattivarli prima dell'elaborazione se cambi idea.
- Se non vengono trovati allegati, lo strumento mostra un chiaro messaggio "Nessun allegato trovato": il PDF semplicemente non contiene file incorporati.

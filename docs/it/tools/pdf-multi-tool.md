# Strumento PDF multifunzione

Uno spazio di lavoro unificato per ogni operazione sulle pagine di un PDF. Carica uno o più PDF e lavora con tutte le loro pagine in un'unica griglia visiva. Ruota, riordina, duplica, elimina, inserisci nuovi PDF, aggiungi pagine vuote e dividi il risultato, il tutto senza uscire dallo strumento.

## Come funziona

1. Clicca su **Carica PDF** o trascina i file sull'area di caricamento. Sono supportati più file.
2. Tutte le pagine di ogni file caricato compaiono in una griglia scorrevole con le miniature.
3. Usa la barra degli strumenti o i pulsanti di azione di ogni pagina per modificare le pagine.
4. Seleziona le pagine con la casella di controllo su ogni scheda, poi applica le operazioni in blocco.
5. Segna i punti di divisione con l'icona delle forbici per suddividere l'output in file separati.
6. Clicca su **Esporta PDF** per scaricare il risultato finale. Se sono presenti segni di divisione, l'output è uno ZIP con più PDF.

## Funzionalità

- **Unisci**: carica più PDF e vengono combinati automaticamente in un unico spazio di lavoro
- **Riordina**: trascina le schede delle pagine per cambiare la sequenza
- **Ruota**: rotazione per pagina o in blocco a passi di 90 gradi (a sinistra o a destra)
- **Duplica**: clona qualsiasi pagina con un clic
- **Elimina**: rimuovi singole pagine o elimina in blocco quelle selezionate
- **Inserisci PDF**: aggiungi un nuovo PDF dopo una pagina specifica
- **Aggiungi pagina vuota**: aggiungi in fondo una pagina A4 vuota
- **Dividi**: posiziona segni di divisione tra le pagine, poi esporta come ZIP di PDF separati
- **Seleziona tutto / Deseleziona tutto**: selezione rapida per le operazioni in blocco
- **Annulla / Ripeti**: cronologia completa di annullamento e ripristino per ogni operazione
- **Scarica selezionate**: esporta solo le pagine selezionate come PDF autonomo
- Ripara automaticamente i PDF danneggiati prima del caricamento

## Casi d'uso

- Creare un documento personalizzato con pagine prese da più PDF di origine
- Ripulire un documento scansionato eliminando le pagine vuote, ruotando le scansioni di lato e riordinando le sezioni
- Dividere un PDF di grandi dimensioni ai confini dei capitoli con segni di divisione visivi
- Modificare rapidamente le pagine senza bisogno di un editor PDF completo

## Suggerimenti

- Il sistema di annullamento e ripristino tiene traccia di ogni operazione. Usalo liberamente: non puoi distruggere il tuo lavoro per sbaglio.
- I segni di divisione appaiono come linee blu tratteggiate tra le pagine. Posizionali visivamente dove vuoi dividere il documento, poi esporta per ottenere uno ZIP.
- Per semplici operazioni di unione o divisione, gli strumenti dedicati [Unisci PDF](./merge-pdf) o [Dividi PDF](./split-pdf) possono essere più rapidi. Lo strumento multifunzione dà il meglio quando servono più operazioni in una sola sessione.

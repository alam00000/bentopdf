# Strumento PDF multifunzione

Uno spazio di lavoro unificato per ogni operazione sulle pagine di un PDF. Carica uno o più PDF e lavora con tutte le loro pagine in un'unica griglia visiva. Ruota, riordina, duplica, elimina, inserisci PDF, immagini e pagine vuote, rinumera, ridimensiona e dividi il risultato, il tutto senza uscire dallo strumento.

## Come funziona

1. Clicca su **Seleziona file** o trascina i file sull'area di caricamento. Sono supportati più file, che vengono uniti nell'ordine di caricamento.
2. Tutte le pagine compaiono in una griglia scorrevole con le miniature.
3. Clicca su una pagina per selezionarla. Usa Shift+clic per selezionare un intervallo e Cmd/Ctrl+clic per aggiungere o togliere singole pagine.
4. Usa la barra degli strumenti dell'organizzatore o fai clic destro su una pagina per le azioni sulle pagine.
5. Clicca su **Esporta PDF** per scaricare il risultato finale.

## Funzionalità

- **Unisci**: carica più PDF e immagini e vengono combinati automaticamente in un unico documento
- **Riordina**: trascina le pagine per cambiarne la sequenza, oppure inverti l'intero documento
- **Ruota**: ruota le pagine selezionate a sinistra o a destra a passi di 90 gradi
- **Duplica**: copia le pagine selezionate e posiziona le copie subito dopo
- **Elimina**: rimuovi le pagine selezionate
- **Inserisci**: aggiungi pagine da un altro PDF o da un'immagine, una pagina vuota, pagine dagli appunti, oppure alterna le pagine di un secondo PDF con quelle attuali
- **Sostituisci**: sostituisci una pagina con la prima pagina di un altro PDF
- **Taglia, copia e incolla**: sposta o copia le pagine all'interno del documento
- **Estrai**: scarica le pagine selezionate come PDF o come immagini
- **Numeri di pagina**: imposta etichette di pagina come i, ii, iii o A-1, A-2 per un intervallo di pagine
- **Dimensione pagina**: adatta le pagine a un formato carta standard o a una dimensione personalizzata
- **Dividi**: dividi il documento per intervalli di pagine, pagine dispari e pari, pagina per pagina, segnalibri, ogni N pagine o dimensione del file
- **Annulla / Ripeti**: ogni operazione sulle pagine può essere annullata e ripetuta
- Ripara automaticamente i PDF danneggiati prima del caricamento

## Scorciatoie da tastiera

| Azione                      | Scorciatoia                   |
| --------------------------- | ----------------------------- |
| Ruota a destra / a sinistra | R / Shift+R                   |
| Seleziona tutto             | Cmd/Ctrl+A                    |
| Taglia, copia, incolla      | Cmd/Ctrl+X, C, V              |
| Duplica                     | Cmd/Ctrl+D                    |
| Elimina                     | Canc o Backspace              |
| Annulla / Ripeti            | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| Sposta la selezione         | Tasti freccia, Home, End      |

## Casi d'uso

- Creare un documento personalizzato con pagine prese da più PDF di origine
- Ripulire un documento scansionato eliminando le pagine vuote, ruotando le scansioni di lato e riordinando le sezioni
- Dividere un PDF di grandi dimensioni ai confini dei capitoli usando i suoi segnalibri
- Modificare rapidamente le pagine senza bisogno di un editor PDF completo

## Suggerimenti

- La cronologia di annullamento e ripristino tiene traccia di ogni operazione sulle pagine. Usala liberamente: non puoi distruggere il tuo lavoro per sbaglio.
- Usa **Insert > From File** o trascina altri PDF o immagini sulla griglia delle pagine in qualsiasi momento per aggiungerli al documento.
- Per semplici operazioni di unione o divisione, gli strumenti dedicati [Unisci PDF](./merge-pdf) o [Dividi PDF](./split-pdf) possono essere più rapidi. Lo strumento multifunzione dà il meglio quando servono più operazioni in una sola sessione.

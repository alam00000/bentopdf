# EPUB in PDF

Converti gli ebook EPUB in file PDF senza uscire dal browser. EPUB è lo standard aperto per i libri digitali, ma a volte serve un PDF a layout fisso per stampare, annotare o condividere con chi non ha un lettore di ebook.

## Formati supportati

| Formato | Estensione | Note                  |
| :------ | :--------- | :-------------------- |
| EPUB    | `.epub`    | File EPUB 2 ed EPUB 3 |

## Come funziona

1. Fai clic sull'area di caricamento o trascina i tuoi file EPUB. È supportata la selezione multipla.
2. Controlla i file caricati. Rimuovi le voci indesiderate con l'icona del cestino, oppure fai clic su **Aggiungi altri file** per ampliare il lotto.
3. Fai clic su **Converti in PDF**. Il motore PyMuPDF rende il contenuto dell'EPUB (testo, immagini e formattazione) in un PDF impaginato.
4. Un singolo EPUB viene scaricato direttamente come PDF. Più file vengono raccolti in un archivio ZIP chiamato `epub-converted.zip`.

## Opzioni

La conversione usa impostazioni predefinite sensate e non richiede alcuna configurazione. Il testo si adatta alle dimensioni di pagina standard, mentre font e immagini incorporati vengono mantenuti nel PDF.

## Casi d'uso

- Stampare un ebook privo di DRM per leggerlo lontano dagli schermi
- Inviare un manoscritto EPUB come PDF a layout fisso per la revisione
- Archiviare libri digitali in un formato che ogni sistema operativo può aprire in modo nativo
- Condividere un capitolo con un collega che non ha un lettore EPUB
- Convertire la documentazione tecnica distribuita in EPUB in PDF annotabili

## Suggerimenti

- Le funzionalità di EPUB 3 come audio e video incorporati non vengono trasferite nel PDF, ma tutto il testo, le immagini e le tabelle si convertono correttamente.
- Per ottenere i migliori risultati con EPUB molto stilizzati, controlla le prime pagine dell'output per verificare la fedeltà del layout.

# Ruota PDF

Ruota le pagine di un PDF di 90 gradi in senso orario o antiorario. Lo strumento mostra le anteprime di ogni pagina e ti permette di ruotarle singolarmente oppure di applicare una rotazione in blocco a tutto il documento.

## Come funziona

1. Carica un file PDF. Le miniature di tutte le pagine vengono mostrate in una griglia.
2. Usa i pulsanti di rotazione sinistra/destra sotto la miniatura di ogni pagina per ruotare quella pagina.
3. Usa i controlli di rotazione in blocco in alto per ruotare tutte le pagine insieme.
4. L'anteprima delle miniature si aggiorna in tempo reale per mostrare la rotazione.
5. Fai clic sul pulsante di elaborazione per salvare il PDF ruotato.

## Funzionalità

- Rotazione per ogni pagina a passi di 90 gradi (a sinistra o a destra)
- Rotazione in blocco di tutte le pagine contemporaneamente
- Anteprima delle miniature in tempo reale con transizioni di rotazione animate
- Miniature caricate in modo differito per prestazioni fluide sui documenti grandi
- Conserva il contenuto e la qualità originali delle pagine

## Casi d'uso

- Correggere pagine scansionate di lato o capovolte
- Ruotare le pagine orizzontali in verticale (o viceversa)
- Correggere un documento con orientamenti misti in cui alcune pagine sono state scansionate con l'angolo sbagliato
- Preparare un documento per uno specifico orientamento di visualizzazione

## Suggerimenti

- Le rotazioni sono cumulative. Fare clic due volte sul pulsante orario applica una rotazione di 180 gradi.
- Per rotazioni diverse da 90 gradi (ad es. 45 gradi per correggere una scansione leggermente inclinata), usa invece [Ruota di Gradi Personalizzati](./rotate-custom).
- I controlli di rotazione in blocco agiscono su tutte le pagine, non solo su quelle selezionate. In questo strumento non esiste la selezione: per quella, usa lo [Strumento PDF multifunzione](./pdf-multi-tool).

# Combina in una pagina

Unisci ogni pagina di un PDF in un'unica pagina lunga. Le pagine vengono affiancate in verticale (come un rotolo) o in orizzontale (una accanto all'altra), producendo una sola pagina continua in uscita.

## Come funziona

1. Carica un file PDF.
2. Seleziona la direzione del layout: **Verticale** (pagine impilate dall'alto in basso) oppure **Orizzontale** (pagine affiancate).
3. Imposta la spaziatura tra le pagine in punti.
4. Scegli un colore di sfondo per gli spazi tra le pagine.
5. Facoltativamente, attiva i separatori (linee sottili tra le pagine) e configurane spessore e colore.
6. Fai clic sul pulsante di elaborazione. Il risultato è un PDF di una sola pagina.

## Funzionalità

- Unione delle pagine in verticale o in orizzontale
- Spaziatura configurabile tra le pagine
- Selettore del colore di sfondo per le aree di spazio
- Linee di separazione facoltative con spessore e colore regolabili
- Rende ogni pagina originale a piena risoluzione sul canvas combinato

## Opzioni

| Opzione                           | Descrizione                                     |
| --------------------------------- | ----------------------------------------------- |
| **Direzione del layout**          | Verticale (impilate) o orizzontale (affiancate) |
| **Spaziatura**                    | Spazio tra le pagine in punti                   |
| **Colore di sfondo**              | Colore dell'area tra le pagine                  |
| **Aggiungi linee di separazione** | Attiva le linee sottili tra le pagine           |
| **Spessore del separatore**       | Spessore della linea in punti                   |
| **Colore del separatore**         | Colore delle linee di separazione               |

## Casi d'uso

- Creare un'unica immagine lunga da un wireframe o un mockup di design su più pagine
- Generare una vista continua e scorrevole di un documento da incorporare nel web
- Unire un fumetto o uno storyboard di più pagine in un'unica striscia
- Produrre una vista panoramica di pagine in sequenza per la revisione

## Suggerimenti

- L'orientamento verticale funziona meglio per i documenti con pagine verticali. Quello orizzontale è migliore per i contenuti in formato orizzontale.
- I documenti grandi con molte pagine producono un risultato molto alto o molto largo. Alcuni visualizzatori PDF potrebbero avere difficoltà con pagine singole estremamente grandi.
- Aggiungere separatori di un colore a contrasto rende facile capire dove finisce una pagina originale e inizia la successiva.

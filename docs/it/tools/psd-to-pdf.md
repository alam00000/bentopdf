# PSD in PDF

Converti i file Adobe Photoshop PSD in documenti PDF. PSD è il formato nativo di Photoshop e aprirlo di solito richiede costosi software Adobe. Questo strumento elabora l'immagine composita appiattita del tuo file PSD come pagina PDF a piena risoluzione.

## Formati supportati

| Formato         | Estensione | Note                                    |
| :-------------- | :--------- | :-------------------------------------- |
| Adobe Photoshop | `.psd`     | Elabora l'immagine composita appiattita |

## Come funziona

1. Fai clic sull'area di caricamento o trascina i tuoi file PSD. Sono supportati più file.
2. Controlla l'elenco dei file. Rimuovi quelli che non vuoi con l'icona del cestino oppure usa **Aggiungi altri file** per includerne altri.
3. Fai clic su **Converti in PDF**. Il motore PyMuPDF legge il file PSD e incorpora l'immagine composita in una pagina PDF alla risoluzione originale.
4. Un singolo PSD produce un PDF. Se carichi più file PSD, vengono uniti in un unico PDF multipagina chiamato `psd_to_pdf.pdf`, in cui ogni PSD diventa una pagina.

## Opzioni

Non servono impostazioni. Il convertitore usa i dati immagine appiattiti del file PSD.

## Casi d'uso

- Visualizzare in anteprima i progetti Photoshop senza aprire Photoshop
- Inviare bozze di design a clienti che non hanno Adobe Creative Suite
- Stampare illustrazioni ad alta risoluzione da file PSD
- Creare un portfolio PDF da più file di design PSD: ognuno diventa una pagina di un unico documento

## Suggerimenti

- La conversione elabora la vista composita (appiattita) del PSD. I singoli livelli, i livelli di regolazione e gli effetti di livello non vengono conservati come elementi separati nel PDF.
- Più file PSD vengono uniti in un unico PDF multipagina anziché in PDF separati. È utile per creare portfolio o lookbook.
- I file PSD ad altissima risoluzione (file di stampa a 300+ DPI) producono PDF di grandi dimensioni. Lo strumento mantiene la risoluzione completa.

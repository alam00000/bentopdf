# Aggiungi pagina vuota

Inserisci pagine vuote in un PDF nella posizione che indichi. Decidi tu dove vanno le pagine vuote e quante aggiungerne.

## Come funziona

1. Carica un file PDF. Lo strumento mostra il numero di pagine.
2. Inserisci la **posizione** in cui inserire le pagine vuote. Usa `0` per inserirle all'inizio, oppure il numero totale di pagine per aggiungerle alla fine.
3. Inserisci il **numero** di pagine vuote da aggiungere (il valore predefinito è 1).
4. Fai clic sul pulsante di elaborazione. Il PDF modificato viene scaricato con le pagine vuote inserite.

## Funzionalità

- Inserimento in qualsiasi posizione: all'inizio, nel mezzo o alla fine del documento
- Aggiunta di più pagine vuote in una sola operazione
- Il suggerimento sulla posizione si aggiorna dinamicamente in base al numero di pagine del PDF caricato
- Pagine vuote in formato A4 standard

## Casi d'uso

- Aggiungere una pagina vuota di separazione tra le sezioni di un documento composito
- Inserire pagine vuote per allineare la stampa fronte/retro
- Lasciare spazio per appunti scritti a mano in una guida allo studio stampata
- Riempire un documento per raggiungere un numero minimo di pagine

## Suggerimenti

- La posizione `0` inserisce prima della prima pagina. Una posizione pari al numero totale di pagine aggiunge dopo l'ultima pagina.
- Se devi inserire contenuto (non solo pagine vuote) in una posizione specifica, usa [Strumento PDF multifunzione](./pdf-multi-tool) per inserire un altro PDF dopo una determinata pagina.

# PUB in PDF

Converti i file Microsoft Publisher in PDF. Publisher è uno strumento di desktop publishing incluso in alcune edizioni di Microsoft Office, ma la maggior parte delle persone non lo ha installato. Questo strumento permette a chiunque di convertire i file PUB in PDF direttamente nel browser, senza software Microsoft.

## Formati supportati

| Formato             | Estensione | Note                            |
| :------------------ | :--------- | :------------------------------ |
| Microsoft Publisher | `.pub`     | Documenti di desktop publishing |

## Come funziona

1. Fai clic sull'area di caricamento o trascina i tuoi file PUB. Puoi caricare più file contemporaneamente.
2. Controlla l'elenco dei file. Rimuovi quelli che non vuoi con l'icona del cestino oppure fai clic su **Aggiungi altri file** per aggiungerne altri.
3. Fai clic su **Converti in PDF**. Un motore basato su LibreOffice si carica nel browser e converte ogni file PUB, mantenendo layout, immagini e caselle di testo.
4. Un singolo file viene scaricato direttamente come PDF. Più file vengono consegnati in un archivio ZIP chiamato `pub-to-pdf.zip`.

## Opzioni

Non serve alcuna configurazione aggiuntiva. Il convertitore gestisce automaticamente il layout PUB.

## Casi d'uso

- Aprire un volantino o una newsletter PUB ricevuti da un cliente senza acquistare Microsoft Publisher
- Convertire bollettini parrocchiali, programmi di eventi o newsletter scolastiche creati con Publisher
- Archiviare materiali di marketing creati in Publisher in un formato accessibile a tutti
- Stampare file PUB su un sistema che non ha Publisher installato

## Suggerimenti

- I layout complessi di Publisher, con caselle di testo sovrapposte e posizionamento preciso, possono spostarsi leggermente durante la conversione. Controlla l'output se la posizione esatta è importante.
- Il motore LibreOffice si avvia una sola volta per sessione. La prima conversione richiede più tempo, le successive sono più veloci.
- Per una conversione il più fedele possibile dei file Publisher, assicurati che gli eventuali font personalizzati usati nell'originale siano font di sistema standard.

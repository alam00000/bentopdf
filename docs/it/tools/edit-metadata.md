# Modifica metadati

Modifica i metadati incorporati in un file PDF. Lo strumento precompila un modulo con i metadati esistenti del documento, ti permette di modificare qualsiasi campo e salva le modifiche in un nuovo PDF.

## Come funziona

1. Carica un file PDF. Lo strumento legge i metadati attuali e compila il modulo.
2. Modifica uno qualsiasi dei campi standard: Titolo, Autore, Oggetto, Parole chiave, Creatore, Produttore.
3. Regola Data di creazione e Data di modifica con i selettori di data e ora.
4. Aggiungi campi di metadati personalizzati facendo clic sul pulsante di aggiunta e inserendo una coppia chiave-valore.
5. Fai clic sul pulsante di elaborazione per salvare il PDF modificato.

## Funzionalità

- Precompila tutti i metadati esistenti del PDF caricato
- Campi standard: Titolo, Autore, Oggetto, Parole chiave, Creatore, Produttore
- Selettori di data e ora per Data di creazione e Data di modifica
- Campi di metadati personalizzati chiave-valore per proprietà arbitrarie
- Salva le modifiche direttamente nel dizionario delle informazioni del documento PDF

## Campi modificabili

| Campo                    | Descrizione                                                      |
| ------------------------ | ---------------------------------------------------------------- |
| **Titolo**               | Il titolo del documento mostrato nei lettori PDF                 |
| **Autore**               | La persona o l'organizzazione che ha creato il documento         |
| **Oggetto**              | Una breve descrizione dell'argomento del documento               |
| **Parole chiave**        | Termini separati da virgole per la ricerca e la categorizzazione |
| **Creatore**             | L'applicazione che ha creato originariamente il contenuto        |
| **Produttore**           | L'applicazione che ha generato il PDF                            |
| **Data di creazione**    | Quando il documento è stato creato originariamente               |
| **Data di modifica**     | Quando il documento è stato modificato l'ultima volta            |
| **Campi personalizzati** | Qualsiasi coppia chiave-valore aggiuntiva che definisci          |

## Casi d'uso

- Impostare un titolo e un autore corretti prima di pubblicare un documento
- Aggiungere parole chiave per migliorare la reperibilità nei sistemi di gestione documentale
- Aggiornare la data di modifica per riflettere la revisione corrente
- Aggiungere campi di metadati personalizzati come Reparto, ID progetto o Classificazione
- Ripulire i metadati lasciati dal software di creazione originale

## Suggerimenti

- I campi personalizzati vengono scritti direttamente nel dizionario delle informazioni del PDF. Alcuni lettori PDF potrebbero non mostrarli, ma vengono conservati nel file.
- Lascia un campo vuoto per cancellarlo dai metadati. Il pulsante di elaborazione salva ciò che si trova nel modulo.
- Per visualizzare i metadati senza modificarli, usa [Visualizza Metadati](./view-metadata). Per rimuovere del tutto i metadati, usa Rimuovi Metadati.

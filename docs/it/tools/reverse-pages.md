# Inverti pagine

Inverti l'ordine delle pagine di un PDF in modo che l'ultima pagina diventi la prima, la penultima diventi la seconda e così via. Supporta l'elaborazione in batch di più file contemporaneamente.

## Come funziona

1. Carica uno o più file PDF.
2. Fai clic sul pulsante di elaborazione.
3. Ogni file viene invertito in modo indipendente. Se hai caricato più file, l'output è un archivio ZIP con tutti i PDF invertiti.
4. Un singolo file viene scaricato direttamente come PDF invertito.

## Funzionalità

- Elaborazione in batch: inverti più PDF in una sola operazione
- Output di un singolo file per un PDF, ZIP per più file
- Pulsanti per rimuovere i singoli file prima dell'elaborazione
- Conserva tutto il contenuto e la formattazione delle pagine

## Casi d'uso

- Correggere un documento scansionato in ordine inverso
- Preparare un PDF di presentazione da leggere dall'ultima alla prima pagina
- Invertire l'ordine delle pagine per flussi di stampa che alimentano le pagine al contrario
- Correggere un documento le cui pagine sono state assemblate per errore al contrario

## Suggerimenti

- Ogni file di un batch viene invertito in modo indipendente: i file stessi non vengono riordinati tra loro.
- Per un riordino delle pagine più preciso (non solo un'inversione completa), usa [Duplica e Organizza](./organize-pdf).

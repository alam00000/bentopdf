# Estrai pagine

Estrai un insieme di pagine da un PDF e salvale come nuovo file. Indica esattamente quali pagine vuoi usando la sintassi degli intervalli e lo strumento crea un PDF pulito contenente solo quelle pagine.

## Come funziona

1. Carica un file PDF. Lo strumento mostra il nome del file, la dimensione e il numero totale di pagine.
2. Inserisci le pagine da estrarre usando la sintassi degli intervalli (ad es. `1-5`, `3, 7, 10-12`).
3. Facoltativamente, scegli di scaricare ogni intervallo come PDF separato in un archivio ZIP.
4. Fai clic sul pulsante di elaborazione. Le pagine estratte vengono scaricate come nuovo PDF (o ZIP).

## Funzionalità

- Sintassi flessibile degli intervalli: pagine singole, intervalli o combinazioni separate da virgole
- Mostra il numero totale di pagine dopo il caricamento per un facile riferimento
- Opzione per ottenere un unico PDF combinato o file separati in un ZIP
- Preserva il contenuto e la formattazione originali delle pagine

## Casi d'uso

- Estrarre il riepilogo esecutivo (le prime pagine) da un report lungo
- Estrarre un singolo capitolo da un PDF di un libro di testo
- Salvare pagine specifiche di un pacchetto di moduli come documenti autonomi
- Creare un documento di esempio da pagine selezionate di un file più grande

## Suggerimenti

- I numeri di pagina partono da 1. Usa `1` per la prima pagina, non `0`.
- Per rimuovere pagine anziché estrarle, usa [Elimina Pagine](./delete-pages): è l'operazione inversa.
- Se ti serve la selezione visuale delle pagine con le miniature, usa [Dividi PDF](./split-pdf) nella modalità Visual Select.

# Unisci PDF

Combina più file PDF in un unico documento. Puoi unire file interi in un ordine specifico, oppure passare alla Modalità Pagina per avere un controllo preciso sulle singole pagine di ogni PDF caricato.

## Come funziona

1. Carica due o più file PDF cliccando sull'area di rilascio o trascinandoli.
2. Scegli tra **Modalità File** e **Modalità Pagina** con l'interruttore in alto.
3. In Modalità File, trascina i file per riordinarli e, se vuoi, specifica gli intervalli di pagine (ad es. `1-3, 5`) per ciascun file. Lascia l'intervallo vuoto per includere tutte le pagine.
4. In Modalità Pagina, trascina le miniature delle singole pagine per costruire l'esatta sequenza di pagine.
5. Clicca su **Unisci PDF** per combinare tutto in un unico file. Il PDF unito viene scaricato automaticamente.

## Funzionalità

- Due modalità di unione: Modalità File per combinare rapidamente file interi, Modalità Pagina per il controllo pagina per pagina
- Riordinamento con trascinamento in entrambe le modalità, con animazioni fluide
- La sintassi degli intervalli di pagine (ad es. `1-3, 5, 8-10`) permette di scegliere le pagine senza passare alla Modalità Pagina
- Le miniature delle pagine vengono caricate al bisogno, così l'interfaccia resta reattiva anche con documenti grandi
- Nessun limite al numero di file o al totale delle pagine
- Conserva la qualità originale del PDF senza ricodifica

## Opzioni

| Opzione             | Descrizione                                                                                               |
| ------------------- | --------------------------------------------------------------------------------------------------------- |
| **Modalità File**   | Unisci file interi in un ordine personalizzato, con filtri facoltativi per intervallo di pagine per file  |
| **Modalità Pagina** | Griglia visiva di tutte le pagine di tutti i file: trascina le miniature per costruire la sequenza esatta |
| **Campo Pagine**    | Campo di testo per file che accetta intervalli come `1-3, 5` per includere solo pagine specifiche         |

## Casi d'uso

- Combinare PDF di capitoli separati in un unico libro o relazione
- Unire una lettera di presentazione e un curriculum in un unico documento di candidatura
- Estrarre pagine specifiche da più documenti di origine in un file consolidato
- Raccogliere ricevute o fatture scansionate in un unico PDF d'archivio
- Creare una dispensa di presentazione con diapositive provenienti da più presentazioni

## Suggerimenti

- Usa la Modalità Pagina quando devi alternare pagine di file diversi invece di accodare un file dopo l'altro.
- Puoi aggiungere altri file dopo il caricamento iniziale con il pulsante **Aggiungi altri file** senza perdere la disposizione attuale.
- Gli intervalli di pagine partono da 1, quindi `1` indica la prima pagina di quel file.

# Immagini in PDF

Il convertitore universale da immagini a PDF. Carica immagini in praticamente qualsiasi formato e uniscile in un unico documento PDF. Ogni immagine ottiene una pagina propria, delle stesse dimensioni dell'originale.

## Formati supportati

| Formato         | Estensioni                             |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

È il supporto di formati più ampio tra tutti i convertitori di immagini di BentoPDF. Se ti serve un solo formato, usa invece uno degli strumenti dedicati.

## Come funziona

1. Clicca sull'area di caricamento o trascina i tuoi file immagine. Puoi selezionare più file contemporaneamente.
2. Controlla l'elenco dei file. Rimuovi quelli che non ti servono con l'icona del cestino, oppure clicca su **Aggiungi altri file** per includere altre immagini.
3. Scegli un livello di **Qualità PDF** dal menu a tendina.
4. Clicca su **Converti in PDF**. Lo strumento elabora le immagini con il motore PyMuPDF e scarica il risultato come `images_to_pdf.pdf`.

## Opzioni

**Qualità PDF** controlla la compressione applicata alle immagini quando vengono incorporate nel PDF:

- **Alta qualità**: compressione minima, file più grande. Ideale per la stampa o l'archiviazione.
- **Qualità media** (predefinita): compressione bilanciata. Va bene per la maggior parte degli usi.
- **Bassa qualità**: compressione aggressiva, file più piccolo. Adatta a email o condivisioni rapide.

I file HEIC e WebP vengono convertiti automaticamente in PNG prima dell'incorporamento. Questo avviene in modo trasparente e non richiede passaggi extra.

## Casi d'uso

- Unire in un unico PDF ricevute o documenti scansionati con la fotocamera del telefono
- Creare un portfolio fotografico o un lookbook da immagini in formati misti
- Convertire le foto dell'iPhone (HEIC) in un PDF condivisibile senza installare software desktop
- Assemblare mockup di design da esportazioni PSD e screenshot in un documento da consegnare al cliente
- Archiviare una cartella di formati di immagine datati (PNM, JXR, JP2) come un unico PDF

## Suggerimenti

- L'ordine delle immagini nel PDF corrisponde all'ordine in cui compaiono nell'elenco dei file. Caricale nella sequenza che desideri.
- Per ottenere il file più piccolo possibile, scegli Bassa qualità. La differenza visiva è spesso trascurabile per scansioni ricche di testo.
- Se hai un solo formato di immagine, i convertitori dedicati (JPG in PDF, PNG in PDF, ecc.) offrono lo stesso risultato con un'interfaccia più semplice.

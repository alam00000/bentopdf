# Estrai allegati

Estrai ogni allegato incorporato da uno o più file PDF. Tutti i file estratti vengono raccolti in un unico archivio ZIP da scaricare.

## Come funziona

1. Carica uno o più file PDF che contengono allegati incorporati.
2. Fai clic su **Estrai allegati**.
3. Lo strumento analizza ogni PDF alla ricerca di allegati a livello di documento e di pagina.
4. Tutti i file trovati vengono inseriti in un archivio ZIP e scaricati automaticamente.
5. Un messaggio di stato conferma quanti allegati sono stati trovati e la loro dimensione totale.

## Funzionalità

- Estrazione in blocco da più PDF contemporaneamente
- Estrae sia gli allegati a livello di documento sia quelli a livello di pagina
- Produce un unico file ZIP con tutti i file estratti
- Mostra il numero totale di allegati e la dimensione complessiva dei file
- Messaggi di stato chiari se non viene trovato alcun allegato

## Casi d'uso

- Recuperare file di dati incorporati in un PDF di report
- Estrarre risorse di immagini da un portfolio o da un documento di specifiche
- Estrarre materiali supplementari da PDF di formazione o conformità
- Verificare quali file sono incorporati in un lotto di PDF

## Suggerimenti

- Se lo strumento segnala che non ci sono allegati, il PDF potrebbe contenere immagini incorporate o dati di moduli, che non sono allegati di file. Usa [Estrai Immagini](./extract-images) per le immagini incorporate.
- Quando elabori più PDF, tutti gli allegati di ogni file finiscono in un unico ZIP. I nomi dei file originali vengono mantenuti.

# Confronta PDF

Carica due PDF e scopri esattamente cosa è cambiato tra l'uno e l'altro. Lo strumento abbina le pagine in modo intelligente, rileva le differenze in testo, immagini, annotazioni, intestazioni e formattazione e le presenta in una vista affiancata o sovrapposta.

## Come funziona

1. Carica due file PDF: l'originale (a sinistra) e la versione rivista (a destra).
2. Lo strumento abbina le pagine tra i documenti usando le firme del contenuto.
3. Seleziona una modalità di visualizzazione: **Fianco a fianco** oppure **Sovrapposizione**.
4. Spostati tra le coppie di pagine con i controlli di paginazione.
5. Le differenze vengono evidenziate e classificate. Usa il pannello dei filtri per concentrarti su tipi di modifica specifici.
6. Facoltativamente, esporta il confronto come report PDF.

## Funzionalità

- Abbinamento automatico delle pagine in base alla somiglianza del contenuto
- Viste di confronto affiancata e sovrapposta
- Classificazione delle modifiche: testo, immagine, intestazione/piè di pagina, annotazione, formattazione, sfondo
- Filtri per categoria per mostrare o nascondere tipi di modifica specifici
- Ricerca nelle modifiche di testo con filtro per query
- Supporto OCR per confrontare documenti scansionati
- Controlli dello zoom per un'ispezione dettagliata
- Scorrimento sincronizzato tra i pannelli nella vista affiancata
- Esporta i risultati del confronto come PDF

## Opzioni

| Opzione                         | Descrizione                                                                                                                         |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **Modalità di visualizzazione** | Fianco a fianco o Sovrapposizione                                                                                                   |
| **OCR**                         | Attiva/disattiva l'OCR per il confronto di documenti scansionati                                                                    |
| **Lingua OCR**                  | Lingua per l'estrazione del testo con OCR                                                                                           |
| **Filtri per categoria**        | Attiva o disattiva la visibilità delle modifiche a testo, immagini, intestazioni/piè di pagina, annotazioni, formattazione e sfondo |
| **Ambito delle modifiche**      | Nella modalità sovrapposizione, filtra tra tutte le modifiche o solo il contenuto                                                   |
| **Zoom**                        | Regola il livello di ingrandimento per un'ispezione dettagliata                                                                     |

## Casi d'uso

- Rivedere le revisioni di un contratto per trovare esattamente cosa è cambiato tra le versioni
- Confrontare mockup di design per verificare che le esportazioni PDF corrispondano alle aspettative
- Verificare le modifiche ai documenti nei settori regolamentati, dove ogni modifica deve essere tracciata
- Controllare che un processo di conversione PDF abbia preservato fedelmente il contenuto originale
- Confrontare i documenti tradotti con l'originale per individuare cambiamenti di layout

## Suggerimenti

- La vista sovrapposta impila i due documenti uno sull'altro, rendendo subito visibili le differenze spaziali (elementi spostati, immagini ridimensionate).
- Attiva l'OCR quando confronti documenti scansionati privi di livello di testo. Il motore di confronto estrarrà il testo dalle immagini delle pagine.
- Usa i filtri per categoria per concentrarti su ciò che conta. Ad esempio, nascondi le modifiche di formattazione quando ti interessano solo le differenze di testo.

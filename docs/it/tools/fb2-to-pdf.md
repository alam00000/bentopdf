# FB2 in PDF

Converti i file FictionBook 2 (FB2) in documenti PDF. FB2 è un formato di ebook basato su XML, popolare in Russia e nell'Europa orientale. Mentre su alcune piattaforme è ben supportato, su altre è praticamente sconosciuto: convertirlo in PDF rende i tuoi libri leggibili ovunque.

## Formati supportati

| Formato       | Estensione | Note                        |
| :------------ | :--------- | :-------------------------- |
| FictionBook 2 | `.fb2`     | Formato ebook basato su XML |

## Come funziona

1. Clicca sull'area di caricamento o trascina i tuoi file FB2. La selezione multipla è supportata.
2. Controlla l'elenco dei file. Usa l'icona del cestino per rimuovere singole voci, oppure **Aggiungi altri file** per includerne altri.
3. Clicca su **Converti in PDF**. Il motore PyMuPDF analizza la struttura XML dell'FB2 e la rende come contenuto PDF paginato.
4. Un singolo file viene scaricato direttamente come PDF. Più conversioni vengono raggruppate in `fb2-converted.zip`.

## Opzioni

Non serve alcuna configurazione. Il convertitore gestisce automaticamente la struttura XML dell'FB2, conservando interruzioni di capitolo, formattazione e immagini incorporate.

## Casi d'uso

- Leggere ebook FB2 su dispositivi o app che supportano solo il PDF
- Stampare letteratura in lingua russa distribuita in formato FB2
- Archiviare una libreria FB2 in un formato supportato universalmente
- Condividere un libro con chi ha un lettore che non supporta FictionBook

## Suggerimenti

- I file FB2 sono semplice XML, quindi tendono a essere piccoli e a convertirsi in fretta anche nel browser.
- Se i tuoi file FB2 sono compressi come `.fb2.zip`, estraili prima di caricarli.

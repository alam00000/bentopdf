# ODG in PDF

Converti i file OpenDocument Graphics in PDF. ODG è il formato nativo di LibreOffice Draw ed è usato per diagrammi, diagrammi di flusso e illustrazioni vettoriali. Convertire in PDF rende questi disegni facili da condividere, stampare e incorporare in altri documenti.

## Formati supportati

| Formato               | Estensione | Note                                       |
| :-------------------- | :--------- | :----------------------------------------- |
| OpenDocument Graphics | `.odg`     | File di LibreOffice Draw / OpenOffice Draw |

## Come funziona

1. Clicca sull'area di caricamento o trascina i tuoi file ODG. Puoi aggiungere più file contemporaneamente.
2. Controlla l'elenco dei file. Rimuovi singole voci con l'icona del cestino, oppure clicca su **Aggiungi altri file** per aggiungere altri disegni.
3. Clicca su **Converti in PDF**. Un motore basato su LibreOffice si carica nel browser e converte ogni file ODG, preservando grafica vettoriale, forme e testo.
4. Un singolo file viene scaricato direttamente come PDF. Più file producono un archivio ZIP chiamato `odg-to-pdf.zip`.

## Opzioni

Non sono richieste impostazioni aggiuntive. La conversione preserva le dimensioni originali della pagina, le forme, i connettori e le caselle di testo del sorgente ODG.

## Casi d'uso

- Condividere diagrammi di LibreOffice Draw con clienti che non hanno LibreOffice installato
- Stampare diagrammi di flusso e diagrammi di rete creati in Draw
- Includere illustrazioni ODG in una relazione o presentazione come PDF incorporati
- Archiviare disegni tecnici in un formato che resterà leggibile per decenni

## Suggerimenti

- Gli elementi vettoriali restano vettoriali nel PDF risultante, quindi il risultato si scala in modo pulito a qualsiasi dimensione di stampa.
- Il motore LibreOffice richiede un momento per inizializzarsi al primo utilizzo. Le conversioni successive nella stessa sessione sono più rapide.

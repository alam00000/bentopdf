# Elimina pagine

Rimuovi le pagine indesiderate da un documento PDF. Indica le pagine da eliminare digitando numeri di pagina o intervalli, oppure fai clic direttamente sulle miniature per contrassegnarle per la rimozione.

## Come funziona

1. Carica un file PDF. Lo strumento genera le anteprime in miniatura di ogni pagina.
2. Inserisci nel campo di testo le pagine da eliminare usando la sintassi degli intervalli (ad es. `2, 5-8`), oppure fai clic sulle miniature per selezionarle o deselezionarle.
3. Le pagine contrassegnate vengono evidenziate visivamente, così puoi confermare la selezione.
4. Fai clic sul pulsante di elaborazione. Viene creato un nuovo PDF senza le pagine selezionate.

## Funzionalità

- Selezione delle pagine tramite testo con sintassi degli intervalli (`2, 5-8, 12`)
- Griglia di miniature per eliminare con un clic
- Evidenziazione in tempo reale delle pagine contrassegnate per l'eliminazione
- Validazione dell'input rispetto al numero effettivo di pagine
- Mantiene tutte le pagine non eliminate nel loro ordine originale

## Casi d'uso

- Rimuovere pagine vuote o di riempimento da un documento scansionato
- Eliminare copertine o appendici prima di condividere un documento
- Ripulire pagine di bozza rimaste per errore in un PDF finale
- Rimuovere le pagine con informazioni sensibili prima della distribuzione

## Suggerimenti

- Eliminare le pagine non influisce sul contenuto o sulla formattazione di quelle rimanenti. Il risultato è una copia fedele dell'originale meno le pagine rimosse.
- Se vuoi conservare solo determinate pagine anziché rimuoverne alcune, [Estrai Pagine](./extract-pages) è la scelta migliore.
- La vista a miniature si carica in modo progressivo, quindi i documenti grandi restano reattivi.

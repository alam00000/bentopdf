# WPS in PDF

Converti i file di elaborazione testi di Microsoft Works in PDF. Microsoft Works era incluso nei PC di largo consumo tra la fine degli anni '90 e gli anni 2000, e molti file WPS si trovano ancora su vecchi dischi rigidi e archivi di posta. Questo strumento li apre nel browser e produce PDF puliti.

## Formati supportati

| Formato         | Estensione | Note                                          |
| :-------------- | :--------- | :-------------------------------------------- |
| Microsoft Works | `.wps`     | File di elaborazione testi di Microsoft Works |

## Come funziona

1. Fai clic sull'area di caricamento o trascina i tuoi file WPS. Sono accettati più file.
2. Controlla l'elenco dei file. Usa l'icona del cestino per rimuovere singoli file, oppure fai clic su **Aggiungi altri file** per ampliare il batch.
3. Fai clic su **Converti in PDF**. Un motore basato su LibreOffice si carica nel browser e converte ogni documento WPS in PDF.
4. Un file viene scaricato direttamente come PDF. Più file vengono raccolti in un archivio ZIP chiamato `wps-to-pdf.zip`.

## Opzioni

Non servono impostazioni aggiuntive. Il convertitore gestisce testo, formattazione di base e immagini incorporate del file WPS.

## Casi d'uso

- Recuperare vecchi documenti di scuola o lavoro salvati in formato Microsoft Works
- Aprire allegati WPS ricevuti via email quando non hai Microsoft Works installato
- Convertire un archivio di file WPS per migrarlo a un moderno sistema documentale
- Stampare documenti legacy che gli attuali programmi di elaborazione testi non riescono ad aprire

## Suggerimenti

- Non confondere i file `.wps` di Microsoft Works con i file di WPS Office. Questo strumento è pensato specificamente per il vecchio formato Microsoft Works.
- Il motore LibreOffice impiega un momento a caricarsi al primo utilizzo. Una volta caricato, le conversioni successive nella stessa sessione sono più rapide.

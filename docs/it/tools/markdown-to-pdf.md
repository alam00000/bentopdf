# Markdown in PDF

Un editor Markdown completo con anteprima dal vivo ed esportazione in PDF con un clic. Scrivi da zero, carica un file `.md` esistente o incolla il contenuto dagli appunti. L'editor rende il tuo Markdown in tempo reale ed esporta un PDF con stile usando il motore di stampa integrato nel browser.

## Formati supportati

| Input         | Descrizione                     |
| :------------ | :------------------------------ |
| File `.md`    | Caricali con il pulsante Carica |
| Input diretto | Scrivi o incolla nell'editor    |

## Come funziona

1. Apri lo strumento Markdown in PDF. L'editor si carica con una vista divisa: sorgente Markdown a sinistra, anteprima renderizzata a destra.
2. Scrivi il tuo Markdown, incollalo oppure clicca su **Carica** per caricare un file `.md`.
3. Passa dal tema chiaro a quello scuro con il cursore del tema nella barra degli strumenti.
4. Clicca su **Esporta PDF** (oppure premi `Ctrl/Cmd + S`) per generare un PDF tramite la finestra di stampa del browser.

## Funzionalità

L'editor supporta un ampio insieme di funzionalità Markdown oltre alle basi:

- **Markdown standard**: titoli, grassetto, corsivo, link, immagini, elenchi, citazioni, linee orizzontali
- **Blocchi di codice** con evidenziazione della sintassi per più di 15 linguaggi (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash e altri)
- **Diagrammi Mermaid**: diagrammi di flusso, diagrammi di sequenza, diagrammi ER e altri tipi di grafici Mermaid vengono resi direttamente nell'anteprima
- **Tabelle** con la sintassi standard delle tabelle Markdown
- **Elenchi di attività** con caselle di controllo
- **Note a piè di pagina**, **pedici**, **apici**
- **Elenchi di definizioni**, **abbreviazioni**
- Supporto per le **emoji** (`:smile:` viene reso come emoji)
- **Evidenziazioni** (`==marked text==`) e **inserimenti** (`++inserted text++`)
- **URL con link automatico**: gli URL semplici vengono convertiti in link cliccabili
- Generazione dell'**indice**
- **Link di ancoraggio** sui titoli

## Casi d'uso

- Scrivere la documentazione di un progetto ed esportare un PDF curato per gli stakeholder
- Creare report tecnici con esempi di codice e diagrammi di architettura Mermaid
- Convertire un README di GitHub in PDF per l'uso offline o la stampa
- Redigere una proposta o una specifica con elenchi di attività e tabelle
- Generare una dispensa con stile a partire da appunti di lezione scritti in Markdown

## Suggerimenti

- L'output PDF usa la funzione di stampa in PDF del browser. In Chrome puoi personalizzare margini e scala nella finestra di stampa prima di salvare.
- I diagrammi Mermaid vengono resi nell'anteprima, ma al primo utilizzo possono richiedere un momento per inizializzarsi.
- Usa `Ctrl/Cmd + S` come scorciatoia da tastiera per esportare senza cercare il pulsante.

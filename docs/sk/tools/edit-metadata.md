# Upraviť metadáta

Upravte metadáta vložené v súbore PDF. Nástroj vopred vyplní formulár existujúcimi metadátami dokumentu, umožní vám zmeniť ľubovoľné pole a zmeny uloží do nového PDF.

## Ako to funguje

1. Nahrajte súbor PDF. Nástroj prečíta jeho aktuálne metadáta a vyplní formulár.
2. Upravte ktorékoľvek zo štandardných polí: Názov, Autor, Predmet, Kľúčové slová, Tvorca, Producent.
3. Upravte Dátum vytvorenia a Dátum úpravy pomocou výberu dátumu a času.
4. Pridajte vlastné polia metadát kliknutím na tlačidlo pridania a zadaním dvojice kľúč-hodnota.
5. Kliknutím na tlačidlo spracovania uložíte upravené PDF.

## Funkcie

- Vopred vyplní všetky existujúce metadáta z nahraného PDF
- Štandardné polia: Názov, Autor, Predmet, Kľúčové slová, Tvorca, Producent
- Výber dátumu a času pre Dátum vytvorenia a Dátum úpravy
- Vlastné polia metadát kľúč-hodnota pre ľubovoľné vlastnosti
- Ukladá zmeny priamo do informačného slovníka dokumentu PDF

## Upraviteľné polia

| Pole                 | Popis                                               |
| -------------------- | --------------------------------------------------- |
| **Názov**            | Názov dokumentu zobrazený v čítačkách PDF           |
| **Autor**            | Osoba alebo organizácia, ktorá dokument vytvorila   |
| **Predmet**          | Krátky popis témy dokumentu                         |
| **Kľúčové slová**    | Výrazy oddelené čiarkou na vyhľadávanie a triedenie |
| **Tvorca**           | Aplikácia, ktorá pôvodne vytvorila obsah            |
| **Producent**        | Aplikácia, ktorá vygenerovala PDF                   |
| **Dátum vytvorenia** | Kedy bol dokument pôvodne vytvorený                 |
| **Dátum úpravy**     | Kedy bol dokument naposledy upravený                |
| **Vlastné polia**    | Akékoľvek ďalšie dvojice kľúč-hodnota, ktoré zadáte |

## Prípady použitia

- Nastavenie správneho názvu a autora pred zverejnením dokumentu
- Pridanie kľúčových slov na lepšiu vyhľadateľnosť v systémoch na správu dokumentov
- Aktualizácia dátumu úpravy podľa aktuálnej revízie
- Pridanie vlastných polí metadát, napríklad Oddelenie, ID projektu alebo Klasifikácia
- Vyčistenie metadát, ktoré zanechal pôvodný autorský softvér

## Tipy

- Vlastné polia sa zapisujú priamo do informačného slovníka PDF. Niektoré čítačky PDF ich nemusia zobrazovať, no v súbore zostanú zachované.
- Ak pole necháte prázdne, z metadát sa vymaže. Tlačidlo spracovania uloží všetko, čo je vo formulári.
- Na zobrazenie metadát bez úprav použite [Zobraziť metadáta](./view-metadata). Na úplné odstránenie všetkých metadát použite Odstrániť metadáta.

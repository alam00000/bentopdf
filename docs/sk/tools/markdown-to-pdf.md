# Markdown do PDF

Plnohodnotný editor Markdownu so živým náhľadom a exportom do PDF jedným kliknutím. Píšte od nuly, nahrajte existujúci súbor `.md` alebo vložte obsah zo schránky. Editor vykresľuje Markdown v reálnom čase a exportuje naštýlované PDF pomocou vstavaného tlačového enginu prehliadača.

## Podporované formáty

| Vstup        | Popis                             |
| :----------- | :-------------------------------- |
| Súbory `.md` | Nahranie tlačidlom Nahrať         |
| Priamy vstup | Písanie alebo vloženie do editora |

## Ako to funguje

1. Otvorte nástroj Markdown do PDF. Editor sa načíta v rozdelenom zobrazení: zdrojový Markdown vľavo, vykreslený náhľad vpravo.
2. Napíšte Markdown, vložte ho alebo kliknite na **Nahrať** a načítajte súbor `.md`.
3. Medzi svetlou a tmavou témou prepínate posuvníkom témy na paneli nástrojov.
4. Kliknite na **Exportovať PDF** (alebo stlačte `Ctrl/Cmd + S`) a vytvorte PDF cez dialóg tlače prehliadača.

## Funkcie

Editor podporuje rozsiahlu sadu funkcií Markdownu nad rámec základov:

- **Štandardný Markdown**: nadpisy, tučné písmo, kurzíva, odkazy, obrázky, zoznamy, citácie, vodorovné čiary
- **Bloky kódu** so zvýrazňovaním syntaxe pre viac ako 15 jazykov (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash a ďalšie)
- **Diagramy Mermaid**: vývojové diagramy, sekvenčné diagramy, ER diagramy a ďalšie typy grafov Mermaid sa vykreslia priamo v náhľade
- **Tabuľky** so štandardnou syntaxou tabuliek Markdown
- **Zoznamy úloh** so zaškrtávacími políčkami
- **Poznámky pod čiarou**, **dolný index**, **horný index**
- **Definičné zoznamy**, **skratky**
- Podpora **emoji** (`:smile:` sa vykreslí ako emoji)
- **Zvýraznenia** (`==marked text==`) a **vloženia** (`++inserted text++`)
- **Automatické odkazy**: obyčajné URL sa prevedú na klikateľné odkazy
- Generovanie **obsahu**
- **Kotviace odkazy** pri nadpisoch

## Príklady použitia

- Písanie projektovej dokumentácie a export upraveného PDF pre zainteresované strany
- Tvorba technických správ s ukážkami kódu a architektonickými diagramami Mermaid
- Prevod README z GitHubu do PDF na použitie offline alebo tlač
- Príprava návrhu alebo špecifikácie so zoznamami úloh a tabuľkami
- Vytvorenie naštýlovaných podkladov z poznámok z prednášok napísaných v Markdowne

## Tipy

- Výstup PDF využíva funkciu tlače do PDF v prehliadači. V Chrome môžete pred uložením upraviť okraje a mierku v dialógu tlače.
- Diagramy Mermaid sa vykreslia v náhľade, ale pri prvom použití môže inicializácia chvíľu trvať.
- Klávesovou skratkou `Ctrl/Cmd + S` exportujete bez hľadania tlačidla.

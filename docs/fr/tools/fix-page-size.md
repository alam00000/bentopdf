# Uniformiser la taille des pages

Les PDF assemblés à partir de plusieurs sources se retrouvent souvent avec des tailles de page différentes : certaines en Letter, d'autres en A4, d'autres totalement non standard. Cet outil impose une taille cible unique à chaque page, en ajustant ou en remplissant le contenu selon le besoin.

## Fonctionnement

1. Envoyez un fichier PDF.
2. Sélectionnez une **Taille de page cible** dans la liste déroulante (A4, Letter, Legal, A3, A5, Tabloid ou Personnalisée).
3. Choisissez une **Orientation** : Auto conserve l'orientation d'origine de chaque page, ou vous pouvez forcer Portrait ou Paysage.
4. Choisissez un mode de **Mise à l'échelle du contenu** : Ajuster (conserve tout le contenu, peut ajouter des marges) ou Remplir (remplit la page, peut rogner les bords).
5. Si besoin, définissez une **Couleur de fond** pour les marges ajoutées.
6. Cliquez sur **Uniformiser la taille des pages**.

## Options

- **Tailles standard** : A4, Letter, Legal, A3, A5, Tabloid
- **Dimensions personnalisées** : saisissez la largeur et la hauteur en pouces ou en millimètres
- **Orientation** : Auto, Portrait, Paysage
- **Mode de mise à l'échelle** : Ajuster ou Remplir (rogner)
- **Couleur de fond** : n'importe quelle couleur pour le remplissage des marges

## Cas d'usage

- Normaliser un PDF fusionné dont les pages proviennent de scanners différents
- Convertir un document US Letter en A4 pour une diffusion internationale
- Préparer des PDF prêts à imprimer qui exigent un format de coupe constant
- Corriger des pages légèrement hors norme (par ex. 8,49 x 11,02 pouces au lieu de 8,5 x 11)

## Astuces

- Utilisez le mode Ajuster pour garantir qu'aucun contenu n'est perdu. Le mode Remplir est plus propre visuellement mais peut couper les bords.
- Vérifiez le résultat avec l'outil Dimensions des pages pour confirmer que chaque page correspond à la cible.
- Le blanc est la couleur de fond par défaut ; choisissez une couleur sombre si votre document a des marges sombres.

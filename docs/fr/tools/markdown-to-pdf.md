# Markdown vers PDF

Un éditeur Markdown complet avec aperçu en direct et export PDF en un clic. Écrivez de zéro, envoyez un fichier `.md` existant ou collez du contenu depuis le presse-papiers. L'éditeur affiche votre Markdown en temps réel et exporte un PDF mis en forme grâce au moteur d'impression intégré du navigateur.

## Formats pris en charge

| Entrée         | Description                    |
| :------------- | :----------------------------- |
| Fichiers `.md` | Envoyés avec le bouton Envoyer |
| Saisie directe | Tapez ou collez dans l'éditeur |

## Fonctionnement

1. Ouvrez l'outil Markdown vers PDF. L'éditeur se charge en vue partagée : source Markdown à gauche, aperçu rendu à droite.
2. Écrivez votre Markdown, collez-le ou cliquez sur **Envoyer** pour charger un fichier `.md`.
3. Basculez entre les thèmes clair et sombre avec le curseur de thème de la barre d'outils.
4. Cliquez sur **Exporter en PDF** (ou appuyez sur `Ctrl/Cmd + S`) pour générer un PDF via la boîte de dialogue d'impression du navigateur.

## Fonctionnalités

L'éditeur prend en charge un large éventail de fonctionnalités Markdown au-delà des bases :

- **Markdown standard** : titres, gras, italique, liens, images, listes, citations, filets horizontaux
- **Blocs de code** avec coloration syntaxique pour plus de 15 langages (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash, et plus)
- **Diagrammes Mermaid** : organigrammes, diagrammes de séquence, diagrammes ER et autres types de graphiques Mermaid s'affichent directement dans l'aperçu
- **Tableaux** avec la syntaxe de tableau Markdown standard
- **Listes de tâches** avec cases à cocher
- **Notes de bas de page**, **indices**, **exposants**
- **Listes de définitions**, **abréviations**
- Prise en charge des **emoji** (`:smile:` s'affiche comme l'emoji)
- **Surlignages** (`==marked text==`) et **insertions** (`++inserted text++`)
- **URL liées automatiquement** : les URL brutes sont converties en liens cliquables
- Génération de **table des matières**
- **Liens d'ancrage** sur les titres

## Cas d'usage

- Rédiger de la documentation de projet et exporter un PDF soigné pour les parties prenantes
- Créer des rapports techniques avec des exemples de code et des diagrammes d'architecture Mermaid
- Convertir un README GitHub en PDF pour une lecture hors ligne ou l'impression
- Rédiger une proposition ou une spécification avec des listes de tâches et des tableaux
- Générer un support mis en forme à partir de notes de cours écrites en Markdown

## Astuces

- Le PDF produit utilise la fonction d'impression en PDF du navigateur. Dans Chrome, vous pouvez personnaliser les marges et l'échelle dans la boîte de dialogue d'impression avant d'enregistrer.
- Les diagrammes Mermaid s'affichent dans l'aperçu mais peuvent nécessiter un instant d'initialisation à la première utilisation.
- Utilisez le raccourci `Ctrl/Cmd + S` pour exporter sans chercher le bouton.

# Rotation par angle personnalisé

Faites pivoter les pages d'un PDF selon un angle quelconque, pas seulement par incréments de 90 degrés. Chaque page dispose de son propre champ d'angle, et vous pouvez appliquer un même angle à toutes les pages à la fois grâce à la commande par lots.

## Fonctionnement

1. Importez un fichier PDF. Les miniatures de chaque page s'affichent.
2. Chaque page a un champ numérique indiquant son angle de rotation actuel.
3. Saisissez une valeur en degrés (positive ou négative) pour faire pivoter une page précise, ou utilisez les boutons gauche/droite de chaque page pour des ajustements rapides de 90 degrés.
4. Utilisez le champ d'**angle global** en haut pour définir une rotation uniforme pour toutes les pages.
5. Cliquez sur le bouton de traitement pour générer le PDF pivoté.

## Fonctionnalités

- Saisie libre des degrés par page (toute valeur entière)
- Commande d'angle global pour appliquer la même rotation à chaque page
- Aperçu de la rotation en temps réel dans les miniatures
- Boutons de rotation rapide par page par incréments de 90 degrés
- Miniatures chargées à la demande pour de bonnes performances sur les gros documents

## Cas d'usage

- Corriger de quelques degrés des numérisations légèrement inclinées
- Faire pivoter des pages pour respecter une exigence d'orientation non standard
- Appliquer des rotations précises à des pages individuelles dans un document au contenu mixte
- Affiner les angles des pages après une première rotation globale

## Conseils

- Les valeurs positives font pivoter dans le sens horaire, les valeurs négatives dans le sens antihoraire.
- Le champ d'angle global écrase tous les angles par page lorsqu'il est appliqué. Définissez les ajustements individuels après l'opération globale si nécessaire.
- Pour des rotations standard de 90/180/270 degrés avec une interface plus simple, utilisez [Faire pivoter un PDF](./rotate-pdf).

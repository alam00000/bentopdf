# Gérer les pièces jointes

Inspectez et gérez les fichiers joints d'un PDF. L'outil liste chaque fichier intégré avec son nom et son niveau de rattachement, puis vous permet de marquer des pièces jointes individuelles pour les supprimer ou de toutes les retirer d'un coup.

## Fonctionnement

1. Importez un fichier PDF.
2. L'outil recherche automatiquement les pièces jointes et les affiche dans une liste.
3. Chaque pièce jointe affiche son nom de fichier et indique s'il s'agit d'une pièce jointe au niveau du document ou de la page.
4. Cliquez sur l'icône de corbeille à côté d'une pièce jointe pour la marquer en vue de sa suppression (cliquez à nouveau pour annuler).
5. Utilisez le bouton **Supprimer toutes les pièces jointes** pour tout sélectionner d'un coup, ou **Tout désélectionner** pour effacer votre sélection.
6. Cliquez sur le bouton de traitement pour enregistrer un nouveau PDF sans les pièces jointes sélectionnées.

## Fonctionnalités

- Liste toutes les pièces jointes au niveau du document et de la page
- Suppression individuelle ou groupée des pièces jointes
- Sélection activable et désactivable avant de valider les modifications
- Texte barré et opacité réduite pour les éléments marqués en vue de leur suppression
- Télécharge le PDF modifié sans les pièces jointes sélectionnées

## Cas d'usage

- Supprimer des fichiers obsolètes ou incorrects intégrés dans un document avant sa redistribution
- Retirer des pièces jointes sensibles (données financières, informations personnelles) d'un PDF avant de le partager
- Réduire la taille d'un PDF en supprimant de gros fichiers intégrés devenus inutiles
- Auditer le contenu intégré et nettoyer un document avant de l'archiver

## Conseils

- Les pièces jointes marquées en vue de leur suppression sont affichées barrées. Vous pouvez annuler le marquage avant le traitement si vous changez d'avis.
- Si aucune pièce jointe n'est trouvée, l'outil affiche un message clair « Aucune pièce jointe trouvée » : le PDF ne contient simplement pas de fichiers intégrés.

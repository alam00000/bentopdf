# PDF vers ZIP

Regroupez plusieurs fichiers PDF dans une seule archive ZIP. C'est un simple outil d'archivage : aucune conversion, compression ni modification des PDF eux-mêmes.

## Fonctionnement

1. Envoyez plusieurs fichiers PDF avec la zone de dépôt.
2. Vérifiez la liste des fichiers. Retirez ceux que vous ne souhaitez pas inclure.
3. Cliquez sur le bouton de traitement.
4. Une archive ZIP contenant tous les PDF envoyés est téléchargée immédiatement.

## Fonctionnalités

- Accepte un nombre quelconque de fichiers PDF
- Retrait de fichiers un par un avant la création de l'archive
- Conserve les noms de fichiers d'origine dans le ZIP
- Aucune modification du contenu des PDF : les fichiers sont archivés tels quels
- Affiche le nom et la taille de chaque PDF envoyé

## Cas d'usage

- Regrouper un ensemble de factures ou de reçus pour une pièce jointe d'e-mail
- Archiver les livrables d'un projet (plusieurs rapports PDF) pour une passation
- Créer un téléchargement unique pour une collection de formulaires ou de modèles
- Archiver un lot de documents dans un seul fichier compressé

## Astuces

- Le fichier ZIP utilise les noms de fichiers PDF d'origine. Si certains fichiers portent le même nom, renommez-les avant l'envoi pour éviter les conflits.
- Cet outil ne compresse pas les PDF eux-mêmes. Pour réduire leur taille, passez-les d'abord dans Compresser un PDF, puis regroupez-les avec cet outil.

# Table des matières

Cet outil lit les signets (plan) de votre PDF et génère une page de table des matières mise en forme, ajoutée au début du document. Si votre PDF contient déjà des signets mais pas de page de table des matières visible, cet outil en crée une automatiquement.

## Fonctionnement

1. Importez un PDF qui contient des signets.
2. Personnalisez le titre, la taille de police et la famille de police de la table des matières.
3. Cochez éventuellement **Ajouter un signet pour la page de table des matières** pour inclure la table des matières elle-même dans l'arborescence des signets.
4. Cliquez sur **Générer la table des matières** pour traiter le fichier.
5. Le PDF mis à jour est téléchargé automatiquement, avec la page de table des matières insérée au début.

## Options

- **Titre de la table des matières** : le titre affiché en haut de la page générée. Par défaut « Table des matières ».
- **Taille de police** : de 10 pt à 72 pt. La valeur par défaut est 12 pt.
- **Famille de police** : choisissez parmi les variantes Times Roman, Helvetica ou Courier (normal, gras, italique, gras italique). Helvetica par défaut.
- **Ajouter un signet pour la page de table des matières** : lorsque cette option est cochée, une entrée de signet pour la page de table des matières elle-même est ajoutée au plan du PDF.

## Fonctionnalités

- Lit toute la hiérarchie des signets du PDF
- Génère une page de table des matières proprement mise en forme avec les numéros de page
- Prend en charge les niveaux de signets imbriqués avec indentation
- Choix parmi 12 polices PDF intégrées
- Signet autoréférencé facultatif pour la page de table des matières

## Cas d'usage

- Ajouter une table des matières imprimable à des e-books ou des rapports qui n'ont que des signets numériques
- Créer une table des matières pour un document fusionné après l'assemblage de plusieurs PDF
- Générer une page de référence pour de longs manuels techniques
- Préparer des documents pour l'impression lorsqu'une table des matières visible est attendue

## Conseils

- Si votre PDF n'a pas de signets, utilisez d'abord l'outil [Modifier les signets](./bookmark) pour en créer, puis revenez ici pour générer la table des matières.
- Pour les gros documents, une taille de police plus grande, comme 14 pt ou 16 pt, améliore la lisibilité.

# Modifier les métadonnées

Modifiez les métadonnées intégrées à un fichier PDF. L'outil pré-remplit un formulaire avec les métadonnées existantes du document, vous laisse modifier n'importe quel champ et enregistre les changements dans un nouveau PDF.

## Fonctionnement

1. Importez un fichier PDF. L'outil lit ses métadonnées actuelles et remplit le formulaire.
2. Modifiez n'importe quel champ standard : Titre, Auteur, Sujet, Mots-clés, Créateur, Producteur.
3. Ajustez la date de création et la date de modification avec les sélecteurs de date et d'heure.
4. Ajoutez des champs de métadonnées personnalisés en cliquant sur le bouton d'ajout et en saisissant une paire clé-valeur.
5. Cliquez sur le bouton de traitement pour enregistrer le PDF modifié.

## Fonctionnalités

- Pré-remplit toutes les métadonnées existantes du PDF importé
- Champs standard : Titre, Auteur, Sujet, Mots-clés, Créateur, Producteur
- Sélecteurs de date et d'heure pour la date de création et la date de modification
- Champs de métadonnées personnalisés clé-valeur pour des propriétés arbitraires
- Enregistre les changements directement dans le dictionnaire d'informations du document PDF

## Champs modifiables

| Champ                    | Description                                                        |
| ------------------------ | ------------------------------------------------------------------ |
| **Titre**                | Le titre du document affiché dans les lecteurs PDF                 |
| **Auteur**               | La personne ou l'organisation qui a créé le document               |
| **Sujet**                | Une brève description du thème du document                         |
| **Mots-clés**            | Termes séparés par des virgules pour la recherche et le classement |
| **Créateur**             | L'application qui a créé le contenu à l'origine                    |
| **Producteur**           | L'application qui a généré le PDF                                  |
| **Date de création**     | Quand le document a été créé à l'origine                           |
| **Date de modification** | Quand le document a été modifié pour la dernière fois              |
| **Champs personnalisés** | Toutes les paires clé-valeur supplémentaires que vous définissez   |

## Cas d'usage

- Définir un titre et un auteur appropriés avant de publier un document
- Ajouter des mots-clés pour améliorer la recherche dans les systèmes de gestion documentaire
- Mettre à jour la date de modification pour refléter la révision en cours
- Ajouter des champs de métadonnées personnalisés comme Service, ID de projet ou Classification
- Nettoyer les métadonnées laissées par le logiciel de création d'origine

## Conseils

- Les champs personnalisés sont écrits directement dans le dictionnaire d'informations du PDF. Certains lecteurs PDF peuvent ne pas les afficher, mais ils sont conservés dans le fichier.
- Laissez un champ vide pour l'effacer des métadonnées. Le bouton de traitement enregistre tout ce qui se trouve dans le formulaire.
- Pour consulter les métadonnées sans les modifier, utilisez [Afficher les métadonnées](./view-metadata). Pour supprimer entièrement toutes les métadonnées, utilisez Supprimer les métadonnées.

# Faire pivoter un PDF

Faites pivoter les pages d'un PDF de 90 degrés dans le sens horaire ou antihoraire. L'outil affiche un aperçu en miniature de chaque page, ce qui permet de les faire pivoter individuellement ou d'appliquer une rotation globale à tout le document.

## Fonctionnement

1. Importez un fichier PDF. Les miniatures de chaque page s'affichent en grille.
2. Utilisez les boutons de rotation gauche/droite sous chaque miniature pour faire pivoter cette page précise.
3. Utilisez les commandes de rotation globale en haut pour faire pivoter toutes les pages à la fois.
4. L'aperçu en miniature se met à jour en temps réel pour montrer la rotation.
5. Cliquez sur le bouton de traitement pour enregistrer le PDF pivoté.

## Fonctionnalités

- Rotation par page par incréments de 90 degrés (gauche ou droite)
- Rotation globale de toutes les pages simultanément
- Aperçu en miniature en temps réel avec transitions de rotation animées
- Miniatures chargées à la demande pour de bonnes performances sur les gros documents
- Préserve le contenu et la qualité d'origine des pages

## Cas d'usage

- Corriger des pages numérisées de travers ou à l'envers
- Faire passer des pages du mode paysage au mode portrait (ou l'inverse)
- Corriger un document d'orientation mixte dont certaines pages ont été numérisées sous le mauvais angle
- Préparer un document pour une orientation d'affichage précise

## Conseils

- Les rotations sont cumulatives. Cliquer deux fois sur le bouton horaire applique une rotation de 180 degrés.
- Pour des rotations qui ne sont pas des multiples de 90 degrés (par ex. 45 degrés pour corriger une numérisation légèrement inclinée), utilisez plutôt [Rotation par angle personnalisé](./rotate-custom).
- Les commandes de rotation globale affectent toutes les pages, pas seulement celles qui sont sélectionnées. Cet outil n'a pas de mécanisme de sélection : pour cela, utilisez l'[Outil PDF tout-en-un](./pdf-multi-tool).

# Changer la couleur du texte

Remplacez la couleur du texte dans tout votre PDF. L'outil repère les zones de texte de chaque page et les recolore avec la couleur choisie, en préservant la mise en page du document et le contenu non textuel.

## Fonctionnement

1. Importez votre fichier PDF.
2. Choisissez une nouvelle couleur de texte avec le sélecteur de couleur. La valeur par défaut est le bleu (#0000FF).
3. Cliquez sur **Changer la couleur du texte** pour lancer le traitement.
4. Le PDF recoloré est téléchargé automatiquement. Un indicateur de progression montre quelle page est en cours de traitement.

## Options

- **Nouvelle couleur du texte** : un sélecteur de couleur pour choisir la couleur de remplacement de tout le texte du document.

## Fonctionnalités

- Recolore le texte de chaque page du document
- Traitement page par page avec indication de progression
- Sélecteur de couleur avec prise en charge complète des couleurs hexadécimales
- Préserve la mise en page et les éléments non textuels

## Cas d'usage

- Passer du texte noir au bleu foncé pour un aspect de document plus doux et plus moderne
- Recolorer le texte pour respecter une charte graphique avant de diffuser des documents
- Convertir le texte en une couleur précise pour se conformer à des exigences d'accessibilité
- Rendre le texte visible sur une couleur de fond nouvellement appliquée

## Conseils

- Cet outil restitue les pages à l'échelle 2x pour la qualité, puis reconstruit le PDF. Le résultat est composé d'images : le texte ne sera donc plus sélectionnable ni consultable par recherche.
- Pour les documents dont vous devez conserver le texte sélectionnable, envisagez plutôt de modifier directement le PDF avec l'[Éditeur PDF](./edit-pdf).
- Le temps de traitement augmente avec le nombre de pages, car chaque page est restituée individuellement.

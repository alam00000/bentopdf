# Comparer des PDF

Importez deux PDF et voyez exactement ce qui a changé entre eux. L'outil associe intelligemment les pages, détecte les différences de texte, d'images, d'annotations, d'en-têtes et de mise en forme, puis les présente en vue côte à côte ou en superposition.

## Fonctionnement

1. Importez deux fichiers PDF : l'original (à gauche) et la version révisée (à droite).
2. L'outil associe les pages des deux documents à l'aide de signatures de contenu.
3. Choisissez un mode d'affichage : **Côte à côte** ou **Superposition**.
4. Naviguez entre les paires de pages avec les commandes de pagination.
5. Les différences sont surlignées et classées. Utilisez le panneau de filtres pour vous concentrer sur certains types de modifications.
6. Exportez éventuellement la comparaison sous forme de rapport PDF.

## Fonctionnalités

- Association automatique des pages selon la similarité du contenu
- Vues de comparaison côte à côte et en superposition
- Classement des modifications : texte, image, en-tête/pied de page, annotation, mise en forme, arrière-plan
- Filtres par catégorie pour afficher ou masquer certains types de modifications
- Recherche dans les modifications de texte avec filtrage par requête
- Prise en charge de l'OCR pour comparer des documents numérisés
- Commandes de zoom pour une inspection détaillée
- Défilement synchronisé entre les panneaux en mode côte à côte
- Export des résultats de la comparaison en PDF

## Options

| Option                       | Description                                                                                                                                |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Mode d'affichage**         | Côte à côte ou superposition                                                                                                               |
| **OCR**                      | Active/désactive l'OCR pour la comparaison de documents numérisés                                                                          |
| **Langue de l'OCR**          | Langue utilisée pour l'extraction du texte par OCR                                                                                         |
| **Filtres par catégorie**    | Active ou masque l'affichage des modifications de texte, d'image, d'en-tête/pied de page, d'annotation, de mise en forme et d'arrière-plan |
| **Portée des modifications** | En mode superposition, filtre entre toutes les modifications ou le contenu uniquement                                                      |
| **Zoom**                     | Ajuste le niveau d'agrandissement pour une inspection détaillée                                                                            |

## Cas d'usage

- Relire les révisions d'un contrat pour trouver exactement ce qui a changé entre deux versions
- Comparer des maquettes de design pour vérifier que les exports PDF correspondent aux attentes
- Auditer les modifications de documents dans des secteurs réglementés où chaque changement doit être tracé
- Vérifier qu'un processus de conversion PDF a fidèlement préservé le contenu d'origine
- Comparer des documents traduits à la source pour repérer les changements de mise en page

## Conseils

- La vue en superposition empile les deux documents l'un sur l'autre, ce qui rend immédiatement visibles les différences spatiales (éléments déplacés, images redimensionnées).
- Activez l'OCR pour comparer des documents numérisés sans couche de texte. Le moteur de comparaison extraira le texte des images de page.
- Utilisez les filtres par catégorie pour vous concentrer sur l'essentiel. Par exemple, masquez les changements de mise en forme si seules les différences de contenu textuel vous intéressent.

# Fusionner des PDF

Combinez plusieurs fichiers PDF en un seul document. Vous pouvez fusionner des fichiers entiers dans un ordre précis, ou passer en Mode Pages pour contrôler finement chaque page de tous les PDF envoyés.

## Fonctionnement

1. Envoyez au moins deux fichiers PDF en cliquant sur la zone de dépôt ou en les y glissant.
2. Choisissez entre le **Mode Fichiers** et le **Mode Pages** avec le commutateur en haut.
3. En Mode Fichiers, faites glisser les fichiers pour les réordonner et, si besoin, indiquez des plages de pages (par ex. `1-3, 5`) pour chaque fichier. Laissez la plage vide pour inclure toutes les pages.
4. En Mode Pages, glissez-déposez les miniatures de pages pour construire précisément votre séquence.
5. Cliquez sur **Fusionner les PDF** pour tout combiner en un seul fichier. Le PDF fusionné se télécharge automatiquement.

## Fonctionnalités

- Deux modes de fusion : le Mode Fichiers pour combiner rapidement des fichiers entiers, le Mode Pages pour un contrôle page par page
- Réorganisation par glisser-déposer dans les deux modes, avec des animations fluides
- La syntaxe de plages de pages (par ex. `1-3, 5, 8-10`) permet de choisir des pages sans passer en Mode Pages
- Les miniatures de pages chargées à la demande gardent l'interface réactive, même avec de gros documents
- Aucune limite sur le nombre de fichiers ou de pages au total
- Conserve la qualité d'origine du PDF, sans réencodage

## Options

| Option            | Description                                                                                                             |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Mode Fichiers** | Fusionne des fichiers entiers dans un ordre personnalisé, avec des filtres de plages de pages optionnels par fichier    |
| **Mode Pages**    | Grille visuelle de toutes les pages de tous les fichiers : faites glisser les miniatures pour construire votre séquence |
| **Champ Pages**   | Champ de texte par fichier acceptant des plages comme `1-3, 5` pour n'inclure que certaines pages                       |

## Cas d'usage

- Combiner des PDF de chapitres séparés en un seul livre ou rapport
- Fusionner une lettre de motivation et un CV en un seul dossier de candidature
- Extraire des pages précises de plusieurs documents sources dans un fichier consolidé
- Assembler des reçus ou factures numérisés en un seul PDF d'archive
- Créer un support de présentation à partir de diapositives de plusieurs présentations

## Astuces

- Utilisez le Mode Pages lorsque vous devez intercaler des pages de fichiers différents plutôt que d'ajouter un fichier après l'autre.
- Vous pouvez ajouter d'autres fichiers après l'envoi initial avec le bouton **Ajouter d'autres fichiers**, sans perdre votre organisation actuelle.
- Les plages de pages commencent à 1 : `1` désigne donc la première page du fichier.

# Numéros de page

Ajoutez des numéros de page visibles sur chaque page de votre PDF. Vous choisissez la position, le format, la taille de police et la couleur, l'outil s'occupe du reste.

## Fonctionnement

1. Envoyez votre fichier PDF.
2. Configurez les réglages de numérotation dans le panneau d'options qui apparaît.
3. Cliquez sur **Ajouter les numéros de page** pour lancer le traitement.
4. Le PDF numéroté est téléchargé automatiquement.

## Options

- **Position** : choisissez l'emplacement des numéros : Bas centre, Bas gauche, Bas droite, Haut centre, Haut gauche ou Haut droite.
- **Format** : choisissez entre une numérotation simple (1, 2, 3...) ou le format « page X sur Y » (1 / 5, 2 / 5...).
- **Taille de police** : définissez la taille du texte des numéros de page. 12 par défaut.
- **Couleur** : choisissez la couleur du texte des numéros de page avec le sélecteur de couleur.

## Fonctionnalités

- Six positions couvrant tous les coins et les centres
- Deux formats de numérotation : séquentielle simple ou « page X sur Y »
- Taille de police personnalisable de 6 à 72 points
- Sélecteur de couleur complet pour le texte
- Gestion automatique des marges qui garde les numéros dans les zones sûres quelle que soit la taille de la page

## Cas d'usage

- Préparer des documents à imprimer qui nécessitent des repères de page visibles
- Ajouter des numéros de page à un PDF fusionné créé à partir de plusieurs fichiers sources
- Numéroter des supports de présentation avant leur distribution
- Ajouter une numérotation séquentielle à des documents juridiques ou des contrats

## Astuces

- Le format « page X sur Y » est utile pour les documents où les lecteurs doivent connaître la longueur totale, comme les propositions commerciales ou les rapports.
- Si vous avez besoin de styles de numérotation différents selon les sections (par exemple des chiffres romains pour les pages liminaires), utilisez plutôt l'outil [Ajouter des étiquettes de page](./add-page-labels).

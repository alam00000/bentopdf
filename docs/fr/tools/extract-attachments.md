# Extraire les pièces jointes

Récupérez chaque pièce jointe intégrée d'un ou plusieurs fichiers PDF. Tous les fichiers extraits sont regroupés dans une seule archive ZIP à télécharger.

## Fonctionnement

1. Importez un ou plusieurs fichiers PDF contenant des pièces jointes intégrées.
2. Cliquez sur **Extraire les pièces jointes**.
3. L'outil analyse chaque PDF à la recherche de pièces jointes au niveau du document et de la page.
4. Tous les fichiers trouvés sont regroupés dans une archive ZIP et téléchargés automatiquement.
5. Un message d'état confirme le nombre de pièces jointes trouvées et leur taille totale.

## Fonctionnalités

- Extraction par lots depuis plusieurs PDF à la fois
- Extrait les pièces jointes au niveau du document comme de la page
- Produit un seul fichier ZIP contenant tous les fichiers extraits
- Affiche le nombre total de pièces jointes et la taille cumulée des fichiers
- Messages d'état clairs si aucune pièce jointe n'est trouvée

## Cas d'usage

- Récupérer des fichiers de données intégrés dans un PDF de rapport
- Extraire des ressources d'images d'un portfolio ou d'un document de spécifications
- Extraire des documents complémentaires de PDF de formation ou de conformité
- Auditer les fichiers intégrés dans un lot de PDF

## Conseils

- Si l'outil ne signale aucune pièce jointe, le PDF peut contenir des images intégrées ou des données de formulaire à la place : ce ne sont pas des fichiers joints. Utilisez [Extraire les images](./extract-images) pour les images intégrées.
- Lors du traitement de plusieurs PDF, toutes les pièces jointes de chaque fichier se retrouvent dans un seul ZIP. Les noms de fichiers d'origine sont conservés.

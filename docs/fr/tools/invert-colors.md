# Inverser les couleurs

Remplacez chaque couleur de votre PDF par son inverse. Les fonds blancs deviennent noirs, le texte noir devient blanc, et toutes les autres couleurs passent à leur valeur complémentaire. C'est le moyen le plus rapide de créer une version « mode sombre » de n'importe quel PDF.

## Fonctionnement

1. Envoyez votre fichier PDF.
2. Cliquez sur **Inverser les couleurs** pour lancer le traitement.
3. Le PDF inversé se télécharge automatiquement.

Il n'y a aucun réglage supplémentaire. L'outil rend chaque page sous forme d'image, inverse la couleur de tous les pixels et réassemble le résultat dans un nouveau PDF.

## Fonctionnalités

- Inversion des couleurs en un clic pour toutes les pages
- Traitement de chaque page du document
- Conservation des dimensions et de la mise en page d'origine
- Fonctionne avec n'importe quel PDF, quel que soit le type de contenu (texte, images, mixte)

## Cas d'usage

- Créer des versions en mode sombre de manuels ou de livres de cours pour lire confortablement la nuit
- Préparer des versions à fort contraste de documents pour l'accessibilité
- Inverser des documents numérisés avec une mauvaise exposition
- Générer des versions négatives de PDF riches en images pour une analyse visuelle

## Astuces

- L'outil rastérise les pages pour appliquer l'effet : le résultat est donc basé sur des images. Le texte ne sera plus sélectionnable ni consultable. Si vous voulez du texte consultable après l'inversion, passez le résultat dans un outil d'OCR.
- Pour des réglages de couleur plus fins (luminosité, contraste, saturation), utilisez plutôt l'outil [Ajuster les couleurs](./adjust-colors).
- Les PDF volumineux comptant beaucoup de pages peuvent prendre plus de temps, car chaque page est rendue et inversée individuellement.

# Ajouter des pièces jointes

Intégrez un ou plusieurs fichiers directement dans un document PDF. Les pièces jointes peuvent être ajoutées au niveau du document (visibles dans le panneau des pièces jointes de n'importe quel lecteur PDF) ou liées à des pages précises.

## Fonctionnement

1. Importez le PDF auquel vous souhaitez joindre des fichiers.
2. Utilisez la zone de dépôt des pièces jointes pour sélectionner les fichiers à intégrer (tout type de fichier).
3. Choisissez le niveau de la pièce jointe : **Document** (par défaut) ou **Page**.
4. Si vous choisissez le niveau Page, saisissez une plage de pages (par exemple `1-3` ou `5`).
5. Cliquez sur le bouton de traitement. Le PDF modifié est téléchargé avec vos fichiers intégrés.

## Fonctionnalités

- Joignez n'importe quel type de fichier : images, feuilles de calcul, archives, exécutables, tout est possible
- Placement des pièces jointes au niveau du document ou de la page
- Possibilité de joindre plusieurs fichiers en une seule opération
- Affichage du nom et de la taille de toutes les pièces jointes sélectionnées
- Le PDF de sortie conserve le contenu d'origine, avec les fichiers intégrés en plus

## Options

| Option              | Description                                                                                   |
| ------------------- | --------------------------------------------------------------------------------------------- |
| **Niveau document** | Joint les fichiers au PDF dans son ensemble, accessibles depuis le panneau des pièces jointes |
| **Niveau page**     | Joint les fichiers à des pages précises, indiquées par une plage de pages                     |

## Cas d'usage

- Regrouper des données sources (fichiers Excel, CSV) avec un rapport PDF
- Joindre les images originales à un portfolio photo au format PDF
- Intégrer des documents justificatifs dans un contrat ou une proposition
- Ajouter des documents complémentaires à des pages précises d'un manuel de formation

## Astuces

- Les pièces jointes au niveau du document sont les mieux prises en charge par les lecteurs PDF. Celles au niveau de la page peuvent ne pas être visibles dans tous les lecteurs.
- Il n'y a pas de limite de taille pour les pièces jointes, mais les fichiers intégrés très volumineux augmentent la taille du PDF d'autant.

# ODG vers PDF

Convertissez des fichiers OpenDocument Graphics en PDF. L'ODG est le format natif de LibreOffice Draw, utilisé pour les diagrammes, les organigrammes et les illustrations vectorielles. La conversion en PDF facilite le partage, l'impression et l'intégration de ces dessins dans d'autres documents.

## Formats pris en charge

| Format                | Extension | Remarques                                   |
| :-------------------- | :-------- | :------------------------------------------ |
| OpenDocument Graphics | `.odg`    | Fichiers LibreOffice Draw / OpenOffice Draw |

## Fonctionnement

1. Cliquez sur la zone d'envoi ou glissez-déposez vos fichiers ODG. Vous pouvez ajouter plusieurs fichiers à la fois.
2. Vérifiez la liste des fichiers. Retirez un fichier avec l'icône de corbeille, ou cliquez sur **Ajouter d'autres fichiers** pour ajouter d'autres dessins.
3. Cliquez sur **Convertir en PDF**. Un moteur basé sur LibreOffice se charge dans le navigateur et convertit chaque fichier ODG en conservant les graphiques vectoriels, les formes et le texte.
4. Un seul fichier est téléchargé directement en PDF. Plusieurs fichiers produisent une archive ZIP nommée `odg-to-pdf.zip`.

## Options

Aucun réglage supplémentaire n'est nécessaire. La conversion conserve les dimensions de page, les formes, les connecteurs et les zones de texte d'origine du fichier ODG.

## Cas d'usage

- Partager des diagrammes LibreOffice Draw avec des clients qui n'ont pas LibreOffice installé
- Imprimer des organigrammes et des schémas réseau créés dans Draw
- Inclure des illustrations ODG dans un rapport ou une présentation sous forme de PDF intégrés
- Archiver des dessins techniques dans un format qui restera lisible pendant des décennies

## Astuces

- Les éléments vectoriels restent vectoriels dans le PDF produit, le résultat s'adapte donc proprement à toute taille d'impression.
- Le moteur LibreOffice met un moment à s'initialiser à la première utilisation. Les conversions suivantes dans la même session sont plus rapides.

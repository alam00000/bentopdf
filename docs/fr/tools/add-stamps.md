# Ajouter des tampons

Placez des tampons image sur vos pages PDF à l'aide d'un lecteur intégré doté d'une barre d'outils d'annotation de tampons. Les tampons peuvent inclure votre nom pour l'attribution, ce qui est utile pour les circuits d'approbation, les processus de relecture et le marquage de documents.

## Fonctionnement

1. Saisissez votre nom dans le champ **Nom d'utilisateur du tampon**. Ce nom apparaîtra sur les tampons que vous créez.
2. Importez votre fichier PDF en cliquant ou en le glissant dans la zone de dépôt.
3. L'éditeur de tampons s'ouvre avec votre document chargé dans un lecteur.
4. Utilisez l'outil de tampon image de la barre d'outils pour sélectionner et placer des tampons sur n'importe quelle page.
5. Positionnez et redimensionnez les tampons selon vos besoins.
6. Cliquez sur **Enregistrer le PDF tamponné** pour télécharger le résultat.

## Fonctionnalités

- Lecteur PDF intégré avec une barre d'outils d'annotation dédiée aux tampons
- Attribution par nom d'utilisateur sur les tampons créés
- Placement de tampons image sur n'importe quelle page
- Positionnement et redimensionnement par glisser-déposer
- Dimensionnement automatique du lecteur selon le format de la page
- Affichage du fichier avec son nom et sa taille

## Cas d'usage

- Ajouter des tampons image « APPROUVÉ » ou « RELU » aux documents d'un circuit de relecture
- Placer le sceau d'une entreprise ou le cachet d'un notaire sur des documents officiels
- Marquer des pages avec des tampons « REÇU » incluant le nom du relecteur
- Ajouter des tampons de contrôle qualité à des rapports d'inspection

## Astuces

- Définissez le nom d'utilisateur du tampon avant d'importer le PDF. Le nom d'utilisateur est intégré aux métadonnées du tampon.
- Le lecteur ajuste sa hauteur selon le format de la première page du PDF pour un affichage optimal.
- Pour des filigranes textuels plutôt que des tampons image, utilisez l'outil [Ajouter un filigrane](./add-watermark).

# Lägg till bilagor

Bädda in en eller flera filer direkt i ett PDF-dokument. Bilagor kan läggas till på dokumentnivå (synliga i bilagepanelen i alla PDF-läsare) eller kopplas till specifika sidor.

## Så fungerar det

1. Ladda upp PDF-filen som du vill bifoga filer till.
2. Använd bilageytan för att välja de filer du vill bädda in (valfri filtyp).
3. Välj bilagenivå: **Dokument** (standard) eller **Sida**.
4. Om du väljer sidnivå anger du ett sidintervall (t.ex. `1-3` eller `5`).
5. Klicka på bearbetningsknappen. Den ändrade PDF-filen laddas ner med dina filer inbäddade.

## Funktioner

- Bifoga valfri filtyp: bilder, kalkylblad, arkiv, körbara filer, vad som helst
- Placering av bilagor på dokumentnivå eller sidnivå
- Flera filer kan bifogas i en och samma åtgärd
- Visar filnamn och storlek för alla valda bilagor
- Resultatet behåller det ursprungliga PDF-innehållet med de inbäddade filerna tillagda

## Alternativ

| Alternativ       | Beskrivning                                                           |
| ---------------- | --------------------------------------------------------------------- |
| **Dokumentnivå** | Bifogar filer till PDF-filen som helhet, åtkomliga från bilagepanelen |
| **Sidnivå**      | Bifogar filer till specifika sidor, angivna med ett sidintervall      |

## Användningsområden

- Samla underlagsdata (Excel-filer, CSV) tillsammans med en PDF-rapport
- Bifoga originalbilder till en PDF med ett fotoportfolio
- Bädda in stödjande dokument i ett avtal eller ett förslag
- Lägga till kompletterande material på specifika sidor i en utbildningsmanual

## Tips

- Bilagor på dokumentnivå stöds bredast i PDF-läsare. Bilagor på sidnivå kanske inte syns i alla läsare.
- Det finns ingen storleksgräns för bilagor, men mycket stora inbäddade filer ökar PDF-filens storlek i motsvarande grad.

# WPD till PDF

Konvertera Corel WordPerfect-dokument till PDF-filer. WPD var en gång det dominerande ordbehandlingsformatet på advokatbyråer och myndigheter. Om du har gamla WordPerfect-filer som modern programvara vägrar öppna väcker det här verktyget dem till liv igen som vanliga PDF:er.

## Format som stöds

| Format      | Filändelse | Anmärkningar                      |
| :---------- | :--------- | :-------------------------------- |
| WordPerfect | `.wpd`     | Alla större WordPerfect-versioner |

## Så fungerar det

1. Klicka på uppladdningsytan eller dra och släpp dina WPD-filer. Flera filer kan väljas samtidigt.
2. Gå igenom fillistan. Ta bort oönskade filer med papperskorgsikonen, eller använd **Lägg till fler filer** för att lägga till fler dokument.
3. Klicka på **Konvertera till PDF**. Verktyget läser in en LibreOffice-baserad konverteringsmotor i webbläsaren, som tolkar WPD-formatet och skapar PDF.
4. En enskild fil laddas ner direkt som PDF. Batchkonverteringar ger ett ZIP-arkiv med namnet `wpd-to-pdf.zip`.

## Alternativ

Ingen konfiguration krävs. LibreOffice-motorn hanterar WPD-formatering, typsnitt och layout automatiskt.

## Användningsområden

- Öppna årtionden gamla juridiska dokument skrivna i WordPerfect
- Konvertera arkiverade myndighetshandlingar från WPD till ett modernt format
- Migrera ett äldre WordPerfect-dokumentbibliotek till PDF för långtidslagring
- Dela WPD-filer med mottagare som inte har Corel WordPerfect installerat

## Tips

- LibreOffice-motorn läses in vid första användningen, vilket tar en stund. Följande konverteringar under samma session går snabbare.
- Komplexa WPD-makron och reveal codes bevaras inte, men den visuella layouten, textinnehållet och grundläggande formatering följer med till PDF.

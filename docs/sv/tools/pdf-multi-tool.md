# PDF-multiverktyg

En enhetlig arbetsyta för alla åtgärder på sidnivå i PDF. Ladda upp en eller flera PDF-filer och arbeta med alla deras sidor i ett enda visuellt rutnät. Rotera, ordna om, duplicera och ta bort sidor, infoga PDF-filer, bilder och tomma sidor, numrera om, ändra storlek och dela resultatet, allt utan att lämna verktyget.

## Så fungerar det

1. Klicka på **Välj filer** eller dra filer till uppladdningsytan. Flera filer stöds och de sammanfogas i den ordning de laddas upp.
2. Alla sidor visas i ett rullningsbart rutnät med miniatyrer.
3. Klicka på en sida för att markera den. Shift-klicka för att markera ett intervall och Cmd/Ctrl-klicka för att lägga till eller ta bort enskilda sidor ur markeringen.
4. Använd verktygsfältet eller högerklicka på en sida för sidåtgärder.
5. Klicka på **Exportera PDF** för att ladda ner slutresultatet.

## Funktioner

- **Sammanfoga**: Ladda upp flera PDF-filer och bilder så kombineras de automatiskt till ett dokument
- **Ordna om**: Dra och släpp sidor för att ändra ordningen, eller vänd ordningen på hela dokumentet
- **Rotera**: Rotera markerade sidor åt vänster eller höger i steg om 90 grader
- **Duplicera**: Kopiera markerade sidor och placera kopiorna direkt efter dem
- **Ta bort**: Ta bort de markerade sidorna
- **Infoga**: Lägg till sidor från en annan PDF eller bild, en tom sida eller sidor från urklipp, eller varva sidorna i en andra PDF med de nuvarande
- **Ersätt**: Byt ut en sida mot första sidan i en annan PDF
- **Klipp ut, kopiera och klistra in**: Flytta eller kopiera sidor inom dokumentet
- **Extrahera**: Ladda ner de markerade sidorna som PDF eller som bilder
- **Sidnummer**: Ange sidetiketter som i, ii, iii eller A-1, A-2 för ett sidintervall
- **Sidstorlek**: Anpassa sidor till en standardpappersstorlek eller en egen storlek
- **Dela**: Dela upp dokumentet efter sidintervall, udda och jämna sidor, varje sida, bokmärken, var N:e sida eller filstorlek
- **Ångra / Gör om**: Varje sidåtgärd kan ångras och göras om
- Reparerar skadade PDF-filer automatiskt innan de läses in

## Kortkommandon

| Åtgärd                        | Kortkommando                  |
| ----------------------------- | ----------------------------- |
| Rotera höger / vänster        | R / Shift+R                   |
| Markera alla                  | Cmd/Ctrl+A                    |
| Klipp ut, kopiera, klistra in | Cmd/Ctrl+X, C, V              |
| Duplicera                     | Cmd/Ctrl+D                    |
| Ta bort                       | Delete eller Backspace        |
| Ångra / Gör om                | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| Flytta markeringen            | Piltangenter, Home, End       |

## Användningsområden

- Bygga ett eget dokument av sidor från flera käll-PDF:er
- Städa upp ett skannat dokument genom att ta bort tomma sidor, rotera sidvända skanningar och ordna om avsnitt
- Dela en stor PDF vid kapitelgränser med hjälp av dess bokmärken
- Snabb redigering på sidnivå utan att behöva en fullständig PDF-redigerare

## Tips

- Ångra- och gör om-historiken spårar varje sidåtgärd. Använd den fritt, du kan inte råka förstöra ditt arbete.
- Använd **Insert > From File** eller släpp fler PDF-filer eller bilder på sidrutnätet när som helst för att lägga till dem i dokumentet.
- För enkla uppgifter som sammanfogning eller delning kan de särskilda verktygen [Sammanfoga PDF](./merge-pdf) eller [Dela PDF](./split-pdf) gå snabbare. Multiverktyget är bäst när du behöver flera åtgärder i en session.

# Ta bort sidor

Ta bort oönskade sidor från ett PDF-dokument. Ange vilka sidor som ska tas bort genom att skriva sidnummer eller intervall, eller klicka direkt på sidminiatyrer för att markera dem för borttagning.

## Så fungerar det

1. Ladda upp en PDF-fil. Verktyget återger miniatyrförhandsvisningar av varje sida.
2. Ange sidorna som ska tas bort i textfältet med intervallsyntax (t.ex. `2, 5-8`), eller klicka på miniatyrer för att växla dem.
3. Markerade sidor framhävs visuellt så att du kan bekräfta ditt val.
4. Klicka på bearbetningsknappen. En ny PDF skapas utan de valda sidorna.

## Funktioner

- Textbaserat sidval med intervallsyntax (`2, 5-8, 12`)
- Visuellt miniatyrrutnät för borttagning genom klick
- Förhandsgranskning i realtid som framhäver sidor markerade för borttagning
- Indatavalidering mot det faktiska sidantalet
- Behåller alla sidor som inte tas bort i ursprunglig ordning

## Användningsfall

- Ta bort tomma sidor eller utfyllnadssidor från ett skannat dokument
- Ta bort omslagssidor eller bilagor innan ett dokument delas
- Rensa bort utkastsidor som av misstag lämnats kvar i en slutlig PDF
- Ta bort sidor med känslig information före distribution

## Tips

- Att ta bort sidor påverkar inte innehållet eller formateringen på de återstående sidorna. Utdata är en trogen kopia av originalet utan de borttagna sidorna.
- Om du vill behålla bara vissa sidor i stället för att ta bort vissa passar [Extrahera sidor](./extract-pages) bättre.
- Miniatyrvyn läses in stegvis, så stora dokument förblir responsiva.

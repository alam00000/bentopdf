# Ändra textfärg

Byt färg på text i hela din PDF. Verktyget identifierar textområden på varje sida och färgar om dem till din valda färg, med bevarad dokumentlayout och innehåll som inte är text.

## Så fungerar det

1. Ladda upp din PDF-fil.
2. Välj en ny textfärg med färgväljaren. Standard är blå (#0000FF).
3. Klicka på **Ändra textfärg** för att bearbeta.
4. Den omfärgade PDF-filen laddas ned automatiskt. En förloppsindikator visar vilken sida som bearbetas.

## Alternativ

- **Ny textfärg**: En färgväljare för att välja ersättningsfärgen för all text i dokumentet.

## Funktioner

- Färgar om text på varje sida i dokumentet
- Bearbetning per sida med förloppsvisning
- Färgväljare med fullt stöd för hexfärger
- Bevarar sidlayout och element som inte är text

## Användningsområden

- Ändra svart text till mörkblå för ett mjukare, modernare dokumentutseende
- Färga om text för att matcha varumärkesriktlinjer innan dokument distribueras
- Konvertera text till en specifik färg för att uppfylla tillgänglighetskrav
- Göra text synlig mot en nyligen tillämpad bakgrundsfärg

## Tips

- Verktyget renderar sidor i 2x skala för kvalitet och bygger sedan om PDF-filen. Utdatan är bildbaserad, så texten går inte längre att markera eller söka i.
- För dokument där du behöver behålla markerbar text, överväg att redigera PDF-filen direkt med [PDF-redigeraren](./edit-pdf) i stället.
- Bearbetningstiden ökar med sidantalet eftersom varje sida renderas individuellt.

# VSD till PDF

Konvertera Microsoft Visio-diagram till PDF utan att installera Visio. VSD- och VSDX-filer innehåller flödesscheman, organisationsscheman, nätverksdiagram och planritningar som de flesta inte kan öppna. Det här verktyget renderar dem som rena PDF:er som går att visa på vilken enhet som helst.

## Format som stöds

| Format       | Filändelse | Anmärkningar                                 |
| :----------- | :--------- | :------------------------------------------- |
| Visio Binary | `.vsd`     | Äldre Visio-format (Visio 2003 och tidigare) |
| Visio XML    | `.vsdx`    | Modernt Visio-format (Visio 2013+)           |

## Så fungerar det

1. Klicka på uppladdningsytan eller dra och släpp dina VSD- eller VSDX-filer. Båda formaten kan blandas i samma batch.
2. Gå igenom fillistan. Ta bort oönskade poster med papperskorgsikonen, eller använd **Lägg till fler filer** för att lägga till fler diagram.
3. Klicka på **Konvertera till PDF**. LibreOffice-baserade motorn läses in i webbläsaren och renderar varje diagram till en PDF, med bevarade former, kopplingar, etiketter och sidlayout.
4. Ett enskilt diagram laddas ner direkt som PDF. Flera filer ger ett ZIP-arkiv med namnet `vsd-to-pdf.zip`.

## Alternativ

Ingen konfiguration krävs. Konverteraren respekterar den ursprungliga sidstorleken och orienteringen i Visio-dokumentet.

## Användningsområden

- Granska Visio-diagram från en kollega när du saknar Visio-licens
- Ta med nätverks- eller arkitekturdiagram som PDF:er i projektdokumentation
- Skriva ut organisationsscheman eller processflöden som utdelningsmaterial till möten
- Arkivera äldre VSD-filer från äldre Visio-versioner i ett framtidssäkert format

## Tips

- Visio-dokument med flera sidor ger PDF:er med flera sidor, där varje Visio-sida motsvarar en PDF-sida.
- VSDX-filer (det moderna XML-baserade formatet) konverteras oftast med högre kvalitet än äldre binära VSD-filer.
- LibreOffice-motorn läses in en gång per session. Räkna med en kort väntan vid första konverteringen, med snabbare resultat för följande filer.

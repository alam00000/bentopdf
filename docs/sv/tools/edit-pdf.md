# PDF-redigerare

BentoPDF:s PDF-redigerare låter dig kommentera, markera, maskera, kommentera i text, lägga till former och bilder och söka i dina PDF-filer. Den läser in en fullfjädrad redigerare direkt i webbläsaren utan serveruppladdningar.

## Så fungerar det

1. Ladda upp din PDF genom att klicka på släppytan eller dra en fil dit.
2. Den inbäddade PDF-redigeraren öppnas automatiskt med ditt dokument inläst.
3. Använd verktygsfältet för att kommentera, markera, maskera, lägga till text, rita former eller infoga bilder.
4. Klicka på **Ladda ner redigerad PDF** för att spara dina ändringar.

## Funktioner

- Fullständigt kommentarsverktygsfält med markering, understrykning, genomstrykning och frihandsritning
- Textinfogning och kommentarer
- Maskeringsverktyg som permanent tar bort markerat innehåll när du tillämpar maskeringen. Om några markeringar inte har tillämpats när du klickar på **Ladda ner redigerad PDF** erbjuder redigeraren att tillämpa dem först.
- Formverktyg för rektanglar, cirklar, linjer och pilar
- Bildinfogning på PDF-sidor
- Inbyggd textsökning i hela dokumentet
- Stöd för flera dokument med flikar (upp till 10 dokument öppna samtidigt)
- Filinläsning med dra och släpp

## Användningsfall

- Granska avtal och markera ändringar med markeringar och kommentarer
- Maskera konfidentiell information som personnummer eller finansiella data innan delning
- Lägga till kommentarer på arkitektritningar eller tekniska ritningar
- Infoga företagslogotyper eller stämplar på dokumentsidor
- Söka efter vissa termer i långa juridiska dokument

## Tips

- Du kan öppna flera PDF-filer samtidigt och växla mellan dem med flikfältet högst upp i redigeraren.
- Redigeraren bevarar den ursprungliga PDF-strukturen, så typsnitt, layouter och formulärfält förblir intakta.
- Att markera text eller ett område för maskering tar inte bort något förrän maskeringen tillämpas. När du maskerar markerad text tas även kopior av den i filens egenskaper, bokmärken, kommentarer och bilagor bort från nedladdningen, om inte filen är krypterad.
- För massvis med vattenstämplar eller sidnumrering, använd de särskilda verktygen i stället för mer kontroll över formateringen.

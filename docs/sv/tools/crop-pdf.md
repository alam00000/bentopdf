# Beskär PDF

Trimma marginalerna på dina PDF-sidor med ett visuellt beskärningsgränssnitt. Rita en beskärningsrektangel direkt på varje sida, förhandsgranska resultatet och tillämpa beskärningen. Du kan ange olika beskärningsområden för olika sidor eller tillämpa samma beskärning på hela dokumentet.

## Så fungerar det

1. Ladda upp din PDF-fil.
2. Beskärningsredigeraren öppnas och visar den första sidan med ett dragbart beskärningsöverlägg.
3. Justera beskärningsrektangeln genom att dra i dess kanter eller hörn.
4. Använd sidnavigeringsknapparna för att flytta mellan sidor och ange beskärningsområden för var och en.
5. Klicka på **Beskär** för att tillämpa beskärningen och ladda ner resultatet.

## Funktioner

- Visuell beskärningsredigerare baserad på Cropper.js med handtag för exakt justering
- Navigering sida för sida för att ange enskilda beskärningsområden
- Sparar beskärningsinställningar per sida så att du kan ange olika beskärningar för olika sidor
- Liveförhandsgranskning av det valda beskärningsområdet
- Stöder PDF-filer med valfri sidstorlek eller orientering

## Användningsfall

- Ta bort breda marginaler från skannade dokument för att fokusera på innehållsytan
- Trimma bort skrivarens beskärningsmärken eller passmärken från PDF-filer för tryckförberedelse
- Beskära föreläsningsbilder för att ta bort området för talaranteckningar
- Ta bort sidhuvuden eller sidfötter från varje sida innan ett dokumentutdrag delas
- Ändra storlek på sidor för att passa en viss skärm eller utskriftslayout

## Tips

- Beskärningsöverlägget kan ändras i storlek och flyttas fritt. Dra i hörnen för proportionell storleksändring eller i kanterna för justering längs en axel.
- För dokument där varje sida behöver samma beskärning, ange den på första sidan. Verktyget kommer ihåg ditt beskärningsområde medan du navigerar mellan sidor.
- Om du behöver standardisera sidstorlekar i stället för att beskära visuellt kan verktyget Fixa sidstorlek passa bättre.

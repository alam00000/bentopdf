# ODG till PDF

Konvertera OpenDocument Graphics-filer till PDF. ODG är det inbyggda formatet för LibreOffice Draw och används för diagram, flödesscheman och vektorillustrationer. Genom att konvertera till PDF blir dessa ritningar enkla att dela, skriva ut och bädda in i andra dokument.

## Format som stöds

| Format                | Filändelse | Anmärkningar                             |
| :-------------------- | :--------- | :--------------------------------------- |
| OpenDocument Graphics | `.odg`     | LibreOffice Draw / OpenOffice Draw-filer |

## Så fungerar det

1. Klicka på uppladdningsytan eller dra och släpp dina ODG-filer. Flera filer kan läggas till på en gång.
2. Granska fillistan. Ta bort enskilda poster med papperskorgsikonen, eller klicka på **Lägg till fler filer** för att lägga till fler ritningar.
3. Klicka på **Konvertera till PDF**. En LibreOffice-baserad motor laddas i webbläsaren och konverterar varje ODG-fil och bevarar vektorgrafik, former och text.
4. En fil laddas ned direkt som PDF. Flera filer ger ett ZIP-arkiv med namnet `odg-to-pdf.zip`.

## Alternativ

Inga ytterligare inställningar krävs. Konverteringen bevarar de ursprungliga sidmåtten, formerna, kopplingarna och textrutorna från ODG-källan.

## Användningsområden

- Dela LibreOffice Draw-diagram med kunder som inte har LibreOffice installerat
- Skriva ut flödesscheman och nätverksdiagram skapade i Draw
- Ta med ODG-illustrationer i en rapport eller presentation som inbäddade PDF-filer
- Arkivera tekniska ritningar i ett format som förblir läsbart i årtionden

## Tips

- Vektorelement förblir vektorer i PDF-resultatet, så att det skalar rent till vilken utskriftsstorlek som helst.
- LibreOffice-motorn behöver en stund för att initieras vid första användningen. Konverteringar i samma session därefter går snabbare.

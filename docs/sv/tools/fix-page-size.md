# Fixa sidstorlek

PDF-filer som sätts ihop från flera källor får ofta sidor med olika storlek: vissa Letter, vissa A4, vissa helt ostandardiserade. Det här verktyget tvingar alla sidor till en enda målstorlek och skalar innehållet så att det passar eller fyller sidan.

## Så fungerar det

1. Ladda upp en PDF-fil.
2. Välj en **Målsidstorlek** i listan (A4, Letter, Legal, A3, A5, Tabloid eller Anpassad).
3. Välj **Orientering**: Auto behåller varje sidas ursprungliga orientering, eller så kan du tvinga Stående eller Liggande.
4. Välj ett **Innehållsskalningsläge**: Anpassa (bevarar allt innehåll, kan lägga till marginaler) eller Fyll (fyller sidan, kan beskära kanter).
5. Ställ eventuellt in en **Bakgrundsfärg** för tillagda marginaler.
6. Klicka på **Fixa sidstorlek**.

## Alternativ

- **Standardstorlekar**: A4, Letter, Legal, A3, A5, Tabloid
- **Egna mått**: Ange bredd och höjd i tum eller millimeter
- **Orientering**: Auto, Stående, Liggande
- **Skalningsläge**: Anpassa eller Fyll (beskär)
- **Bakgrundsfärg**: Valfri färg för marginalutfyllnad

## Användningsområden

- Normalisera en sammanfogad PDF där sidorna kommer från olika skannrar
- Konvertera ett US Letter-dokument till A4 för internationell distribution
- Förbereda tryckklara PDF-filer som kräver en enhetlig beskärningsstorlek
- Rätta till sidor som avviker något från standard (t.ex. 8,49 x 11,02 tum i stället för 8,5 x 11)

## Tips

- Använd läget Anpassa för att garantera att inget innehåll går förlorat. Läget Fyll ser renare ut men kan klippa kanter.
- Kontrollera resultatet med verktyget Sidmått för att bekräfta att varje sida matchar målet.
- Vit är standardbakgrundsfärg. Byt till en mörk färg om ditt dokument har mörka marginaler.

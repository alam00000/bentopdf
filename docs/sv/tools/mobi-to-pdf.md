# MOBI till PDF

Konvertera Amazon Kindle MOBI-e-böcker till PDF-dokument. MOBI-filer är knutna till Kindle-enheter och appar, vilket gör dem svåra att läsa på andra ställen. Genom att konvertera till PDF får du en portabel version som du kan öppna på vilken enhet som helst eller skriva ut.

## Format som stöds

| Format | Filändelse | Anmärkningar                     |
| :----- | :--------- | :------------------------------- |
| MOBI   | `.mobi`    | Kindle-e-boksformat (Mobipocket) |

## Så fungerar det

1. Klicka på uppladdningsytan eller dra och släpp en eller flera MOBI-filer.
2. Granska fillistan. Ta bort oönskade filer med papperskorgsikonen, eller använd **Lägg till fler filer** för att lägga till fler e-böcker.
3. Klicka på **Konvertera till PDF**. PyMuPDF-motorn tolkar MOBI-strukturen och renderar varje sida som PDF-innehåll.
4. En enskild fil laddas ned som PDF. När flera filer konverteras får du ett ZIP-arkiv med namnet `mobi-converted.zip`.

## Alternativ

Inga ytterligare inställningar behövs. Konverteringen bevarar textinnehåll, formatering och inbäddade bilder från den ursprungliga MOBI-filen.

## Användningsområden

- Läsa innehåll köpt via Kindle på en e-läsare som inte är en Kindle och bara stöder PDF
- Skriva ut kapitel ur en e-bok för offlinestudier eller anteckningar
- Arkivera ditt personliga e-boksbibliotek i ett universellt format
- Dela utdrag med någon som inte har Kindle-appen installerad

## Tips

- DRM-skyddade MOBI-filer kan inte konverteras. Verktyget fungerar bara med DRM-fria MOBI-filer.
- Stora e-böcker med många inbäddade bilder kan ta några sekunder längre att bearbeta eftersom allt sker i webbläsaren.

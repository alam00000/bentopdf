# Sammanfoga PDF

Kombinera flera PDF-filer till ett enda dokument. Du kan sammanfoga hela filer i en viss ordning, eller växla till Sidläge för detaljerad kontroll över enskilda sidor från varje uppladdad PDF.

## Så fungerar det

1. Ladda upp två eller flera PDF-filer genom att klicka på släppytan eller dra in dem.
2. Välj mellan **Filläge** och **Sidläge** med reglaget överst.
3. I Filläge drar du filerna för att ordna om dem och kan ange sidintervall (t.ex. `1-3, 5`) för varje fil. Lämna intervallet tomt för att ta med alla sidor.
4. I Sidläge drar och släpper du enskilda sidminiatyrer för att bygga din exakta sidföljd.
5. Klicka på **Sammanfoga PDF-filer** för att kombinera allt till en fil. Den sammanfogade PDF-filen laddas ned automatiskt.

## Funktioner

- Två sammanfogningslägen: Filläge för snabb sammanfogning av hela filer, Sidläge för kontroll per sida
- Omordning med dra och släpp i båda lägena med mjuka animationer
- Syntax för sidintervall (t.ex. `1-3, 5, 8-10`) låter dig välja sidor utan att byta till Sidläge
- Latladdade sidminiatyrer håller gränssnittet responsivt även med stora dokument
- Ingen gräns för antal filer eller totalt sidantal
- Bevarar den ursprungliga PDF-kvaliteten utan omkodning

## Alternativ

| Alternativ  | Beskrivning                                                                                     |
| ----------- | ----------------------------------------------------------------------------------------------- |
| **Filläge** | Sammanfoga hela filer i valfri ordning, med valfria sidintervallfilter per fil                  |
| **Sidläge** | Visuellt rutnät med alla sidor från alla filer: dra miniatyrer för att bygga din exakta sekvens |
| **Sidfält** | Textfält per fil som accepterar intervall som `1-3, 5` för att bara ta med specifika sidor      |

## Användningsområden

- Kombinera separata kapitel-PDF:er till en enda bok eller rapport
- Sammanfoga ett personligt brev och ett CV till ett ansökningsdokument
- Hämta specifika sidor från flera källdokument till en samlad fil
- Samla skannade kvitton eller fakturor i en arkiv-PDF
- Skapa ett utdelningsmaterial från bilder i flera presentationer

## Tips

- Använd Sidläge när du behöver varva sidor från olika filer i stället för att lägga en fil efter en annan.
- Du kan lägga till fler filer efter den första uppladdningen med knappen **Lägg till fler filer** utan att förlora din nuvarande ordning.
- Sidintervall är 1-indexerade, så `1` avser den första sidan i den filen.

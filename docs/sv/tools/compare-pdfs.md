# Jämför PDF:er

Ladda upp två PDF-filer och se exakt vad som har ändrats mellan dem. Verktyget parar ihop sidor på ett smart sätt, identifierar skillnader i text, bilder, kommentarer, sidhuvuden och formatering och visar dem i en vy sida vid sida eller i överlagring.

## Så fungerar det

1. Ladda upp två PDF-filer: originalet (till vänster) och den reviderade versionen (till höger).
2. Verktyget parar ihop sidor mellan dokumenten med hjälp av innehållssignaturer.
3. Välj visningsläge: **Sida vid sida** eller **Överlagring**.
4. Navigera mellan sidpar med sidnumreringskontrollerna.
5. Skillnader markeras och kategoriseras. Använd filterpanelen för att fokusera på vissa typer av ändringar.
6. Exportera eventuellt jämförelsen som en PDF-rapport.

## Funktioner

- Automatisk sidparning baserad på innehållslikhet
- Jämförelsevyer sida vid sida och i överlagring
- Ändringskategorisering: text, bild, sidhuvud/sidfot, kommentar, formatering, bakgrund
- Filterreglage per kategori för att visa eller dölja vissa typer av ändringar
- Sökning bland textändringar med frågefilter
- OCR-stöd för jämförelse av skannade dokument
- Zoomkontroller för detaljgranskning
- Synkroniserad rullning mellan panelerna i läget sida vid sida
- Exportera jämförelseresultat som en PDF

## Alternativ

| Alternativ         | Beskrivning                                                                                        |
| ------------------ | -------------------------------------------------------------------------------------------------- |
| **Visningsläge**   | Sida vid sida eller överlagring                                                                    |
| **OCR**            | Aktivera/inaktivera OCR för jämförelse av skannade dokument                                        |
| **OCR-språk**      | Språk för OCR-textextrahering                                                                      |
| **Kategorifilter** | Växla synligheten för ändringar i text, bild, sidhuvud/sidfot, kommentar, formatering och bakgrund |
| **Ändringsomfång** | I överlagringsläge: filtrera mellan alla ändringar eller endast innehåll                           |
| **Zoom**           | Justera förstoringsnivån för detaljgranskning                                                      |

## Användningsfall

- Granska avtalsrevisioner för att se exakt vad som ändrats mellan versioner
- Jämföra designmockups för att kontrollera att PDF-exporter motsvarar förväntningarna
- Granska dokumentändringar i reglerade branscher där varje ändring måste spåras
- Kontrollera att en PDF-konvertering har bevarat originalinnehållet korrekt
- Kontrollera översättningsdokument mot källan för layoutändringar

## Tips

- Överlagringsvyn lägger båda dokumenten ovanpå varandra, så rumsliga skillnader (förflyttade element, storleksändrade bilder) syns direkt.
- Aktivera OCR när du jämför skannade dokument som saknar textlager. Jämförelsemotorn extraherar då text från sidbilderna.
- Använd kategorifilter för att fokusera på det som är viktigt. Dölj till exempel formateringsändringar när du bara bryr dig om skillnader i textinnehåll.

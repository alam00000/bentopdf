# Redigera metadata

Redigera metadatan som är inbäddad i en PDF-fil. Verktyget fyller i ett formulär med dokumentets befintliga metadata, låter dig ändra vilket fält som helst och sparar ändringarna i en ny PDF.

## Så fungerar det

1. Ladda upp en PDF-fil. Verktyget läser dess nuvarande metadata och fyller i formuläret.
2. Redigera något av standardfälten: Titel, Författare, Ämne, Nyckelord, Skapare, Producent.
3. Justera Skapandedatum och Ändringsdatum med datum- och tidväljarna.
4. Lägg till anpassade metadatafält genom att klicka på lägg till-knappen och ange ett nyckel-värde-par.
5. Klicka på bearbetningsknappen för att spara den ändrade PDF-filen.

## Funktioner

- Fyller i all befintlig metadata från den uppladdade PDF-filen
- Standardfält: Titel, Författare, Ämne, Nyckelord, Skapare, Producent
- Datum- och tidväljare för Skapandedatum och Ändringsdatum
- Anpassade nyckel-värde-metadatafält för valfria egenskaper
- Sparar ändringar direkt i PDF-filens dokumentinformationsordlista

## Redigerbara fält

| Fält               | Beskrivning                                           |
| ------------------ | ----------------------------------------------------- |
| **Titel**          | Dokumenttiteln som visas i PDF-läsare                 |
| **Författare**     | Personen eller organisationen som skapade dokumentet  |
| **Ämne**           | En kort beskrivning av dokumentets ämne               |
| **Nyckelord**      | Kommaseparerade termer för sökning och kategorisering |
| **Skapare**        | Programmet som ursprungligen skapade innehållet       |
| **Producent**      | Programmet som genererade PDF-filen                   |
| **Skapandedatum**  | När dokumentet ursprungligen skapades                 |
| **Ändringsdatum**  | När dokumentet senast ändrades                        |
| **Anpassade fält** | Alla ytterligare nyckel-värde-par som du definierar   |

## Användningsfall

- Ange en korrekt titel och författare innan ett dokument publiceras
- Lägga till nyckelord för att förbättra sökbarheten i dokumenthanteringssystem
- Uppdatera ändringsdatumet så att det speglar den aktuella revisionen
- Lägga till anpassade metadatafält som Avdelning, Projekt-ID eller Klassificering
- Rensa upp metadata som lämnats kvar av det ursprungliga skrivprogrammet

## Tips

- Anpassade fält skrivs direkt i PDF-filens informationsordlista. Vissa PDF-läsare visar kanske inte anpassade fält, men de bevaras i filen.
- Lämna ett fält tomt för att rensa det från metadatan. Bearbetningsknappen sparar det som finns i formuläret.
- För att visa metadata utan att redigera, använd [Visa metadata](./view-metadata). För att ta bort all metadata helt, använd Ta bort metadata.

# N-Up PDF

Placera flera sidor på ett enda ark i ett rutnät. Det minskar antalet utskrivna sidor genom att rymma 2, 4, 6, 8, 9 eller 16 sidor per ark. Verktyget hanterar skalning, placering och valfri konfiguration av sidstorlek.

## Så fungerar det

1. Ladda upp en PDF-fil.
2. Välj antal sidor per ark ("N"-värdet): 2, 4, 6, 8, 9 eller 16.
3. Välj utdatasidans storlek (standard är A4) och orientering.
4. Konfigurera eventuellt avstånd, ramfärg och bakgrundsfärg.
5. Klicka på bearbetningsknappen. Verktyget skalar varje sida och lägger ut dem som plattor på nya ark.

## Funktioner

- Rutnätslayouter: 2-up, 4-up, 6-up, 8-up, 9-up och 16-up
- Konfigurerbar storlek och orientering på utdatasidan
- Valfritt avstånd mellan sidorna
- Inställningar för bakgrunds- och ramfärg
- Bevarar de ursprungliga sidornas proportioner vid skalning

## Alternativ

| Alternativ        | Beskrivning                                                               |
| ----------------- | ------------------------------------------------------------------------- |
| **Sidor per ark** | Antal ursprungliga sidor som ryms på varje utdatasida (2, 4, 6, 8, 9, 16) |
| **Sidstorlek**    | Storlek på utdataarket (A4, Letter, Legal osv.)                           |
| **Orientering**   | Stående eller Liggande för utdataarket                                    |
| **Avstånd**       | Mellanrum i punkter mellan sidorna                                        |
| **Bakgrundsfärg** | Fyllnadsfärg för utdatarkets bakgrund                                     |
| **Ramfärg**       | Färg på ramarna runt varje sida                                           |

## Användningsområden

- Skriva ut utdelningsmaterial med 4 bilder per sida för att spara papper
- Skapa studieblad med flera referenssidor på ett ark
- Producera kompakta dokumentarkiv för arkivering
- Generera översiktsark med miniatyrer av ett långt dokument

## Tips

- Liggande orientering fungerar ofta bättre för 2-up-layouter, medan stående oftast är bäst för 4-up och uppåt.
- Större avstånd förbättrar läsbarheten men minskar ytan för varje sida.
- För den omvända åtgärden (dela en sida i flera), se [Postera PDF](./posterize-pdf).

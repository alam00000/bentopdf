# Bilder till PDF

Den universella konverteraren från bild till PDF. Ladda upp bilder i praktiskt taget vilket format som helst och kombinera dem till ett enda PDF-dokument. Varje bild får en egen sida, anpassad efter originalmåtten.

## Format som stöds

| Format          | Filändelser                            |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

Det här är det bredaste formatstödet av alla bildkonverterare i BentoPDF. Om du bara behöver ett specifikt format kan du använda ett av de dedikerade verktygen i stället.

## Så fungerar det

1. Klicka på uppladdningsytan eller dra och släpp dina bildfiler. Du kan välja flera filer på en gång.
2. Granska fillistan. Ta bort oönskade filer med papperskorgsikonen, eller klicka på **Lägg till fler filer** för att lägga till fler bilder.
3. Välj en **PDF-kvalitet** i listan.
4. Klicka på **Konvertera till PDF**. Verktyget bearbetar bilderna med PyMuPDF-motorn och laddar ned resultatet som `images_to_pdf.pdf`.

## Alternativ

**PDF-kvalitet** styr den bildkomprimering som används när bilderna bäddas in i PDF-filen:

- **Hög kvalitet**: minimal komprimering, större filstorlek. Bäst för tryck eller arkivering.
- **Medelhög kvalitet** (standard): balanserad komprimering. Passar de flesta ändamål.
- **Låg kvalitet**: kraftig komprimering, minsta filstorlek. Lämplig för e-post eller snabb delning.

HEIC- och WebP-filer konverteras automatiskt till PNG innan de bäddas in. Det sker transparent och kräver inga extra steg.

## Användningsområden

- Kombinera skannade kvitton eller dokument från en mobilkamera till en PDF
- Skapa en fotoportfölj eller lookbook av bilder i blandade format
- Konvertera iPhone-foton (HEIC) till en delbar PDF utan att installera skrivbordsprogramvara
- Sätta ihop designskisser från PSD-exporter och skärmbilder till en kundleverans
- Arkivera en mapp med äldre bildformat (PNM, JXR, JP2) som en enda PDF

## Tips

- Bildernas ordning i PDF-filen följer ordningen i fillistan. Ladda upp dem i den ordning du vill ha.
- Välj Låg kvalitet för minsta möjliga filstorlek. Den visuella skillnaden är ofta försumbar för textrika skanningar.
- Om du bara har ett bildformat ger de dedikerade konverterarna (JPG till PDF, PNG till PDF osv.) samma resultat med ett enklare gränssnitt.

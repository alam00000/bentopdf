# Invertera färger

Vänd varje färg i din PDF till sin invers. Vita bakgrunder blir svarta, svart text blir vit och alla andra färger skiftar till sina komplementfärger. Det är det snabbaste sättet att skapa en version i "mörkt läge" av vilken PDF som helst.

## Så fungerar det

1. Ladda upp din PDF-fil.
2. Klicka på **Invertera färger** för att bearbeta.
3. Den inverterade PDF-filen laddas ned automatiskt.

Det finns inga ytterligare inställningar. Verktyget renderar varje sida som en bild, inverterar alla pixelfärger och sätter ihop resultatet till en ny PDF.

## Funktioner

- Färginvertering med ett klick för alla sidor
- Bearbetar varje sida i dokumentet
- Behåller ursprungliga sidmått och layout
- Fungerar med vilken PDF som helst oavsett innehållstyp (text, bilder, blandat)

## Användningsområden

- Skapa versioner i mörkt läge av läroböcker eller manualer för bekväm kvällsläsning
- Förbereda högkontrastversioner av dokument i tillgänglighetssyfte
- Invertera skannade dokument som fångats med felaktig exponering
- Generera negativa versioner av bildtunga PDF-filer för visuell analys

## Tips

- Eftersom verktyget rasteriserar sidorna för att åstadkomma effekten blir resultatet bildbaserat. Texten går då inte längre att markera eller söka i. Om du behöver sökbar text efter inverteringen kan du köra resultatet genom ett OCR-verktyg.
- För mer detaljerade färgjusteringar (ljusstyrka, kontrast, mättnad), använd verktyget [Justera färger](./adjust-colors) i stället.
- Stora PDF-filer med många sidor kan ta längre tid att bearbeta eftersom varje sida renderas och inverteras för sig.

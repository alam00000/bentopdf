# Skapa PDF-formulär

Designa professionella ifyllbara PDF-formulär från grunden eller genom att lägga till fält i en befintlig PDF. Den visuella redigeraren låter dig dra och släppa formulärelement (textfält, kryssrutor, listrutor, alternativknappar, signaturfält med mera) direkt på sidförhandsvisningar. Konfigurera fältegenskaper, ställ in regler för villkorlig synlighet och exportera ett fullt interaktivt PDF-formulär.

## Så fungerar det

1. Ladda upp en befintlig PDF **eller** klicka på **Skapa tom PDF** för att börja från början.
2. Om du skapar en tom PDF väljer du en sidstorlek (Letter, A4, A5, Legal, Tabloid, A3 eller egna mått).
3. Formulärredigeraren öppnas med ett verktygsfält med fälttyper och ett sidförhandsvisningsområde.
4. Välj en fälttyp i verktygsfältet och klicka sedan på sidan för att placera den.
5. Dra fält för att flytta dem. Använd storlekshandtagen för att justera måtten.
6. Klicka på ett fält för att öppna egenskapspanelen där du kan ange fältnamn, standardvärde, teckenstorlek, justering med mera.
7. Navigera mellan sidor med sidkontrollerna.
8. Klicka på **Spara** för att ladda ned den färdiga ifyllbara PDF-filen.

## Funktioner

- Placering av fält med dra och släpp och visuella handtag för storleksändring
- Fälttyper: textfält, flerradig text, kryssruta, listruta, alternativknapp, signatur, datum, nummer och streckkod
- Egenskapspanel för att konfigurera varje fälts namn, etikett, standardvärde, teckenstorlek, färg, justering och validering
- Fältåtgärder och regler för villkorlig synlighet (visa/dölj fält baserat på andra fälts värden)
- Sidnavigering för flersidiga formulär
- Extrahering av befintliga fält: identifierar och importerar automatiskt formulärfält från uppladdade PDF-filer
- Stöd för både uppladdade PDF-filer och tomma sidor som formulärunderlag
- Flera förinställda sidstorlekar samt egna mått
- Streckkodsgenerering med bwip-js
- Hantering av grupper av alternativknappar

## Alternativ

**Förinställda sidstorlekar (för tomma PDF-filer):**

- Letter (8,5" x 11")
- A4 (210 mm x 297 mm)
- A5 (148 mm x 210 mm)
- Legal (8,5" x 14")
- Tabloid (11" x 17")
- A3 (297 mm x 420 mm)
- Anpassad (ange bredd och höjd)

**Fältegenskaper (varierar efter fälttyp):**

- Namn, etikett och platshållartext
- Standardvärde
- Teckensnittsfamilj, storlek och färg
- Textjustering (vänster, center, höger)
- Reglage för obligatoriskt fält
- Reglage för skrivskydd
- Maxlängd för textfält
- Alternativlista för listrutor och alternativknappar
- Åtgärder för villkorlig synlighet

## Användningsområden

- Bygga introduktionsformulär för nyanställda med textfält för personuppgifter och kryssrutor för bekräftelse av policyer
- Skapa kundfrågeformulär med listrutor för val av tjänst
- Designa beställningsformulär med beräknade fält och streckkodsidentifierare
- Bygga inspektionschecklistor med alternativknappar för godkänt/underkänt
- Skapa enkätformulär med villkorliga följdfrågor som visas utifrån svar

## Tips

- Om du laddar upp en befintlig PDF försöker verktyget extrahera de formulärfält som redan finns, så att du kan redigera eller lägga till i dem.
- Använd funktionen för grupper av alternativknappar för att skapa ömsesidigt uteslutande val. Fält i samma grupp delar gruppnamn.
- Testa ditt formulär genom att ladda ned det och öppna det i [Formulärifyllare](./form-filler) för att verifiera fältens beteende.

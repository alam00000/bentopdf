# Rotera med valfri vinkel

Rotera PDF-sidor i valfri vinkel, inte bara i steg om 90 grader. Varje sida får ett eget vinkelfält, och du kan tillämpa en enda vinkel på alla sidor samtidigt med batchkontrollen.

## Så fungerar det

1. Ladda upp en PDF-fil. Miniatyrer renderas för varje sida.
2. Varje sida har ett numeriskt inmatningsfält som visar dess aktuella rotationsvinkel.
3. Skriv in valfritt gradvärde (positivt eller negativt) för att rotera en specifik sida, eller använd knapparna vänster/höger per sida för snabba justeringar om 90 grader.
4. Använd fältet för **batchvinkel** högst upp för att ange en enhetlig rotation för alla sidor.
5. Klicka på bearbetningsknappen för att skapa den roterade PDF-filen.

## Funktioner

- Fri gradinmatning per sida (valfritt heltal)
- Batchvinkelkontroll för att ange samma rotation på varje sida
- Förhandsvisning av rotationen i realtid i miniatyrerna
- Snabbrotationsknappar per sida för steg om 90 grader
- Miniatyrer som laddas vid behov för bra prestanda i stora dokument

## Användningsområden

- Rätta till något sneda skanningar med några få grader
- Rotera sidor för att uppfylla ett krav på ovanlig orientering
- Tillämpa exakta rotationer på enskilda sidor i ett dokument med blandat innehåll
- Finjustera sidvinklar efter en första massrotation

## Tips

- Positiva värden roterar medurs, negativa värden roterar moturs.
- Batchvinkelfältet skriver över alla vinklar per sida när det tillämpas. Gör individuella justeringar efter batchoperationen vid behov.
- För vanliga rotationer på 90/180/270 grader med ett enklare gränssnitt, använd [Rotera PDF](./rotate-pdf).

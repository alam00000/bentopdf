# WPS till PDF

Konvertera ordbehandlingsfiler från Microsoft Works till PDF. Microsoft Works följde med konsument-PC under hela slutet av 1990-talet och 2000-talet, och gott om WPS-filer finns kvar på gamla hårddiskar och i e-postarkiv. Det här verktyget öppnar dem i webbläsaren och skapar rena PDF:er.

## Format som stöds

| Format          | Filändelse | Anmärkningar                             |
| :-------------- | :--------- | :--------------------------------------- |
| Microsoft Works | `.wps`     | Ordbehandlingsfiler från Microsoft Works |

## Så fungerar det

1. Klicka på uppladdningsytan eller dra och släpp dina WPS-filer. Flera filer accepteras.
2. Gå igenom fillistan. Använd papperskorgsikonen för att ta bort enskilda filer, eller klicka på **Lägg till fler filer** för att utöka din batch.
3. Klicka på **Konvertera till PDF**. En LibreOffice-baserad motor läses in i webbläsaren och konverterar varje WPS-dokument till PDF.
4. En fil laddas ner direkt som PDF. Flera filer paketeras i ett ZIP-arkiv med namnet `wps-to-pdf.zip`.

## Alternativ

Inga ytterligare inställningar behövs. Konverteraren hanterar text, grundläggande formatering och inbäddade bilder från WPS-filen.

## Användningsområden

- Återskapa gamla skol- eller arbetsdokument som sparats i Microsoft Works-format
- Öppna WPS-bilagor i e-post när du inte har Microsoft Works installerat
- Konvertera ett arkiv med WPS-filer för migrering till ett modernt dokumentsystem
- Skriva ut äldre dokument som dagens ordbehandlare inte kan öppna

## Tips

- Blanda inte ihop Microsoft Works `.wps`-filer med WPS Office-filer. Det här verktyget är specifikt för det äldre Microsoft Works-formatet.
- LibreOffice-motorn tar en stund att läsa in vid första användningen. När den väl är inläst går ytterligare konverteringar under samma session snabbare.

# ODS till PDF

Konvertera OpenDocument Spreadsheet-filer till PDF. ODS är det inbyggda formatet i LibreOffice Calc och en vanlig exportmetod från Google Sheets. Verktyget renderar kalkylbladets data, formatering och diagram till en sidindelad PDF som du kan skriva ut eller dela.

## Format som stöds

| Format                   | Filändelse | Anmärkningar                            |
| :----------------------- | :--------- | :-------------------------------------- |
| OpenDocument Spreadsheet | `.ods`     | LibreOffice Calc / Google Sheets-export |

## Så fungerar det

1. Klicka på uppladdningsytan eller dra och släpp dina ODS-filer. Flera filer stöds.
2. Granska fillistan. Använd papperskorgsikonen för att ta bort filer, eller klicka på **Lägg till fler filer** för att utöka gruppen.
3. Klicka på **Konvertera till PDF**. LibreOffice-motorn laddas i webbläsaren och renderar varje kalkylblad till PDF-sidor.
4. Ett enskilt kalkylblad laddas ner som en PDF. Flera filer paketeras i `ods-to-pdf.zip`.

## Alternativ

Ingen konfiguration krävs. Konverteraren använder kalkylbladets befintliga utskriftslayout, cellformatering och kolumnbredder i PDF-utdata.

## Användningsområden

- Dela en budget eller rapport från LibreOffice Calc med någon som bara tar emot PDF-filer
- Skriva ut en Google Sheets-export som laddats ner som ODS
- Arkivera ekonomiska underlag i ett format som inte kan redigeras
- Skicka in ODS-baserade formulär eller tidrapporter som dokument med fast layout

## Tips

- Om ditt kalkylblad har flera blad ingår alla blad i PDF-utdata.
- Mycket breda kalkylblad kan sträcka sig över flera PDF-sidor på bredden. Justera kolumnbredderna i källfilen innan konverteringen om layouten är viktig.
- LibreOffice-motorn initieras vid första användningen. Följande konverteringar i samma session går snabbare.

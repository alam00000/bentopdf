# Postera PDF

Dela varje sida i en PDF i ett rutnät av mindre delsidor. Det här verktyget används för att skriva ut en enda sida över flera pappersark, som du sedan sätter ihop till en stor affisch eller banderoll.

## Så fungerar det

1. Ladda upp en PDF-fil.
2. Ange antal **rader** och **kolumner** för rutnätet (t.ex. 2 rader x 2 kolumner delar varje sida i 4 delsidor).
3. Ange vid behov ett sidintervall för att begränsa vilka sidor som posteras.
4. Förhandsvisningen visar ett rutnät över den aktuella sidan så att du kan se var den delas.
5. Bläddra mellan sidor för att kontrollera rutnätet på olika sidor.
6. Klicka på bearbetningsknappen. Varje rutcell blir en egen sida i den färdiga PDF-filen.

## Funktioner

- Valfritt antal rader och kolumner för flexibla rutnätsstorlekar
- Liveförhandsvisning med rutnät som visar exakt var sidorna delas
- Sidintervallfilter för att postera enbart vissa sidor
- Sida-för-sida-navigering i förhandsvisningen
- Cachade sidbilder för snabb navigering i förhandsvisningen
- Streckade röda rutnätslinjer markerar tydligt skärgränserna

## Alternativ

| Alternativ       | Beskrivning                                      |
| ---------------- | ------------------------------------------------ |
| **Rader**        | Antal horisontella delningar (standard: 1)       |
| **Kolumner**     | Antal vertikala delningar (standard: 1)          |
| **Sidintervall** | Vilka sidor som ska posteras (tomt = alla sidor) |

## Användningsområden

- Skriva ut en PDF i affischstorlek över vanliga A4- eller Letter-ark för att sätta ihop på en vägg
- Skapa stora banderoller från en ensidig PDF-design
- Dela överdimensionerade tekniska ritningar i utskrivbara delar
- Göra storformatsutskrifter utan tillgång till en storformatsskrivare

## Tips

- Ett 2x2-rutnät gör en sida till 4 sidor. Ett 3x3-rutnät gör en sida till 9. Planera rutnätet efter hur stor den färdiga sammansättningen ska bli.
- Förhandsvisningens rutnät hjälper dig att se till att viktigt innehåll inte hamnar på en skärlinje. Justera rader/kolumner vid behov.
- För den omvända operationen (flera sidor på ett ark), använd [N-Up PDF](./n-up-pdf).

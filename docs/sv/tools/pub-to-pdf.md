# PUB till PDF

Konvertera Microsoft Publisher-filer till PDF. Publisher är ett desktop publishing-program som ingår i vissa utgåvor av Microsoft Office, men de flesta har det inte installerat. Med det här verktyget kan vem som helst konvertera PUB-filer till PDF direkt i webbläsaren, utan Microsoft-programvara.

## Format som stöds

| Format              | Filändelse | Anmärkningar                |
| :------------------ | :--------- | :-------------------------- |
| Microsoft Publisher | `.pub`     | Desktop publishing-dokument |

## Så fungerar det

1. Klicka på uppladdningsytan eller dra och släpp dina PUB-filer. Flera filer kan laddas upp samtidigt.
2. Granska fillistan. Ta bort oönskade filer med papperskorgsikonen, eller klicka på **Lägg till fler filer** för att lägga till fler.
3. Klicka på **Konvertera till PDF**. En LibreOffice-baserad motor laddas i webbläsaren och konverterar varje PUB-fil med bevarad layout, bilder och textrutor.
4. En fil laddas ned direkt som PDF. Flera filer levereras i ett ZIP-arkiv med namnet `pub-to-pdf.zip`.

## Alternativ

Ingen ytterligare konfiguration behövs. Konverteraren hanterar PUB-layoutmotorn automatiskt.

## Användningsområden

- Öppna en PUB-flygblad eller ett nyhetsbrev från en kund utan att köpa Microsoft Publisher
- Konvertera programblad, evenemangsprogram eller skolbrev skapade i Publisher
- Arkivera marknadsföringsmaterial från Publisher i ett universellt tillgängligt format
- Skriva ut PUB-filer på ett system som inte har Publisher installerat

## Tips

- Komplexa Publisher-layouter med överlappande textrutor och exakt placering kan förskjutas något vid konverteringen. Granska resultatet om exakt placering är avgörande.
- LibreOffice-motorn initieras en gång per session. Den första konverteringen tar längre tid, de följande går snabbare.
- För den mest trogna konverteringen av Publisher-filer, se till att eventuella egna typsnitt i originalet är vanliga systemtypsnitt.

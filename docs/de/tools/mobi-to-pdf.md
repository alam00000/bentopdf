# MOBI zu PDF

Wandeln Sie MOBI-E-Books von Amazon Kindle in PDF-Dokumente um. MOBI-Dateien sind an Kindle-Geräte und -Apps gebunden und lassen sich anderswo schwer lesen. Mit der Umwandlung in PDF erhalten Sie eine portable Version, die Sie auf jedem Gerät öffnen oder drucken kÃ¶nnen.

## Unterstützte Formate

| Format | Erweiterung | Hinweise                          |
| :----- | :---------- | :-------------------------------- |
| MOBI   | `.mobi`     | Kindle-E-Book-Format (Mobipocket) |

## So funktioniert es

1. Klicken Sie auf den Upload-Bereich oder ziehen Sie eine oder mehrere MOBI-Dateien per Drag & Drop hinein.
2. Prüfen Sie die Dateiliste. Entfernen Sie unerwünschte Dateien mit dem Papierkorb-Symbol oder nutzen Sie **Weitere Dateien hinzufügen**, um zusätzliche E-Books aufzunehmen.
3. Klicken Sie auf **In PDF umwandeln**. Die PyMuPDF-Engine liest die MOBI-Struktur ein und gibt jede Seite als PDF-Inhalt aus.
4. Eine einzelne Datei wird als PDF heruntergeladen. Bei mehreren Dateien erhalten Sie ein ZIP-Archiv namens `mobi-converted.zip`.

## Optionen

Es sind keine zusätzlichen Einstellungen nötig. Die Umwandlung erhält Textinhalt, Formatierung und eingebettete Bilder der ursprünglichen MOBI-Datei.

## Anwendungsfälle

- Bei Kindle gekaufte Inhalte auf einem Nicht-Kindle-E-Reader lesen, der nur PDF unterstützt
- Kapitel eines E-Books für das Lernen oder Annotieren offline ausdrucken
- Die persönliche E-Book-Bibliothek in einem universellen Format archivieren
- Auszüge mit jemandem teilen, der die Kindle-App nicht installiert hat

## Tipps

- MOBI-Dateien mit DRM-Schutz können nicht umgewandelt werden. Das Werkzeug funktioniert nur mit DRM-freien MOBI-Dateien.
- Große E-Books mit vielen eingebetteten Bildern brauchen etwas länger, da alles im Browser abläuft.

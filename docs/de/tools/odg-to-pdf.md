# ODG zu PDF

Wandeln Sie OpenDocument-Graphics-Dateien in PDF um. ODG ist das native Format von LibreOffice Draw und wird für Diagramme, Flussdiagramme und Vektorillustrationen verwendet. Als PDF lassen sich diese Zeichnungen leicht teilen, drucken und in andere Dokumente einbetten.

## Unterstützte Formate

| Format                | Erweiterung | Hinweise                                    |
| :-------------------- | :---------- | :------------------------------------------ |
| OpenDocument Graphics | `.odg`      | LibreOffice-Draw- / OpenOffice-Draw-Dateien |

## So funktioniert es

1. Klicken Sie auf den Upload-Bereich oder ziehen Sie Ihre ODG-Dateien per Drag & Drop hinein. Mehrere Dateien können auf einmal hinzugefügt werden.
2. Prüfen Sie die Dateiliste. Entfernen Sie einzelne Einträge mit dem Papierkorb-Symbol oder klicken Sie auf **Weitere Dateien hinzufügen**, um weitere Zeichnungen aufzunehmen.
3. Klicken Sie auf **In PDF umwandeln**. Eine LibreOffice-basierte Engine wird im Browser geladen und wandelt jede ODG-Datei um, wobei Vektorgrafiken, Formen und Text erhalten bleiben.
4. Eine einzelne Datei wird direkt als PDF heruntergeladen. Mehrere Dateien ergeben ein ZIP-Archiv namens `odg-to-pdf.zip`.

## Optionen

Es sind keine zusätzlichen Einstellungen erforderlich. Die Umwandlung erhält Seitenmaße, Formen, Verbinder und Textfelder der ODG-Quelle.

## Anwendungsfälle

- LibreOffice-Draw-Diagramme mit Kunden teilen, die LibreOffice nicht installiert haben
- In Draw erstellte Flussdiagramme und Netzwerkdiagramme drucken
- ODG-Illustrationen als eingebettete PDFs in einen Bericht oder eine Präsentation aufnehmen
- Technische Zeichnungen in einem Format archivieren, das jahrzehntelang lesbar bleibt

## Tipps

- Vektorelemente bleiben in der PDF-Ausgabe Vektoren, das Ergebnis lässt sich daher für jede Druckgröße sauber skalieren.
- Die LibreOffice-Engine braucht bei der ersten Nutzung einen Moment zur Initialisierung. Danach sind Umwandlungen in derselben Sitzung schneller.

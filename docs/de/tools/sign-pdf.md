# PDF unterschreiben

Fügen Sie Ihre Unterschrift zu einem beliebigen PDF-Dokument hinzu. Das Werkzeug bettet einen vollständigen PDF-Viewer mit integrierten Signaturwerkzeugen ein, mit denen Sie eine Unterschrift freihändig zeichnen, Ihren Namen in einer Schreibschrift tippen oder ein Unterschriftsbild hochladen können. Platzieren Sie und skalieren Sie Unterschriften auf jeder Seite und speichern Sie dann das unterschriebene Dokument.

## So funktioniert es

1. Laden Sie Ihre PDF-Datei hoch.
2. Das Dokument öffnet sich in einem integrierten PDF-Viewer mit Annotationswerkzeugen.
3. Erstellen Sie mit dem Signaturwerkzeug des Viewers Ihre Unterschrift durch Zeichnen, Tippen oder Hochladen eines Bildes.
4. Klicken Sie auf die Stelle der Seite, an der die Unterschrift stehen soll, und passen Sie Größe und Position an.
5. Aktivieren Sie optional **PDF reduzieren**, um die Unterschrift dauerhaft in das Dokument einzubetten.
6. Klicken Sie auf **Speichern & unterschriebene PDF herunterladen**, um Ihre unterschriebene Datei zu erhalten.

## Optionen

- **PDF reduzieren**: Wenn aktiviert, wird die Unterschrift dauerhaft in den Seiteninhalt eingebettet. So kann sie von anderen nicht verschoben oder gelöscht werden. Wenn deaktiviert, bleibt die Unterschrift eine Annotation, die in kompatiblen Viewern bearbeitet werden kann.

## Funktionen

- Drei Methoden zur Unterschriftserstellung: freihändiges Zeichnen, getippter Text oder hochgeladenes Bild
- Integrierter PDF-Viewer für genaues Platzieren
- Unterschriften auf jeder Seite per Ziehen positionieren und skalieren
- Optionales Reduzieren, um Unterschriften dauerhaft einzubetten
- Unterstützung mehrerer Unterschriften im selben Dokument

## Anwendungsfälle

- Verträge, Vereinbarungen oder Genehmigungsformulare unterschreiben, bevor Sie sie zurücksenden
- Ihre Unterschrift unter Steuerunterlagen, Versicherungsansprüche oder Behördenformulare setzen
- Paraphen auf einzelne Seiten einer mehrseitigen Vereinbarung setzen
- NDAs oder Personaldokumente unterschreiben, die als PDF-Anhang eintreffen

## Tipps

- Aktivieren Sie das Reduzieren, wenn Sie die unterschriebene PDF an jemanden senden, der Ihre Unterschrift nicht entfernen oder verschieben können soll.
- Für rechtsverbindliche digitale Signaturen mit zertifikatsbasierter Überprüfung bietet BentoPDF außerdem ein separates Werkzeug für digitale Signaturen.
- Laden Sie ein PNG-Unterschriftsbild mit transparentem Hintergrund hoch, um das sauberste Ergebnis zu erhalten.

# PDF-Formular erstellen

Gestalten Sie professionelle ausfüllbare PDF-Formulare von Grund auf oder fügen Sie Felder zu einer bestehenden PDF hinzu. Im visuellen Editor ziehen Sie Formularelemente wie Textfelder, Kontrollkästchen, Dropdowns, Optionsfelder und Signaturfelder direkt auf die Seitenvorschau. Konfigurieren Sie Feldeigenschaften, richten Sie Regeln für bedingte Sichtbarkeit ein und exportieren Sie ein vollständig interaktives PDF-Formular.

## So funktioniert es

1. Laden Sie eine bestehende PDF hoch **oder** klicken Sie auf **Leere PDF erstellen**, um von vorn zu beginnen.
2. Wenn Sie eine leere PDF erstellen, wählen Sie eine Seitengröße (Letter, A4, A5, Legal, Tabloid, A3 oder eigene Maße).
3. Der Formulareditor öffnet sich mit einer Symbolleiste für Feldtypen und einer Seitenvorschau.
4. Wählen Sie in der Symbolleiste einen Feldtyp aus und klicken Sie dann auf die Seite, um es zu platzieren.
5. Ziehen Sie Felder, um sie zu verschieben. Mit den Anfasserpunkten passen Sie die Größe an.
6. Klicken Sie auf ein Feld, um das Eigenschaftenfenster zu öffnen. Dort legen Sie Feldname, Standardwert, Schriftgröße, Ausrichtung und mehr fest.
7. Wechseln Sie mit den Seitensteuerungen zwischen den Seiten.
8. Klicken Sie auf **Speichern**, um die fertige ausfüllbare PDF herunterzuladen.

## Funktionen

- Felder per Drag & Drop platzieren, mit sichtbaren Anfassern zur Größenänderung
- Feldtypen: Texteingabe, mehrzeiliger Text, Kontrollkästchen, Dropdown, Optionsfeld, Signatur, Datum, Zahl und Barcode
- Eigenschaftenfenster zum Konfigurieren von Name, Beschriftung, Standardwert, Schriftgröße, Farbe, Ausrichtung und Validierung jedes Felds
- Feldaktionen und Regeln für bedingte Sichtbarkeit (Felder abhängig von anderen Feldwerten ein- oder ausblenden)
- Seitennavigation für mehrseitige Formulare
- Extraktion vorhandener Felder: Formularfelder aus hochgeladenen PDFs werden automatisch erkannt und importiert
- Unterstützung sowohl für hochgeladene PDFs als auch für leere Seiten als Formularfläche
- Mehrere Seitengrößen-Voreinstellungen sowie eigene Maße
- Barcode-Erzeugung mit bwip-js
- Verwaltung von Optionsfeldgruppen

## Optionen

**Seitengrößen-Voreinstellungen (für leere PDFs):**

- Letter (8,5" x 11")
- A4 (210mm x 297mm)
- A5 (148mm x 210mm)
- Legal (8,5" x 14")
- Tabloid (11" x 17")
- A3 (297mm x 420mm)
- Benutzerdefiniert (Breite und Höhe angeben)

**Feldeigenschaften (abhängig vom Feldtyp):**

- Name, Beschriftung und Platzhaltertext
- Standardwert
- Schriftart, Schriftgröße und Farbe
- Textausrichtung (links, zentriert, rechts)
- Schalter für Pflichtfeld
- Schalter für Schreibschutz
- Maximale Länge für Textfelder
- Optionsliste für Dropdowns und Optionsfelder
- Aktionen für bedingte Sichtbarkeit

## Anwendungsfälle

- Onboarding-Formulare für Mitarbeitende mit Textfeldern für persönliche Angaben und Kontrollkästchen für die Bestätigung von Richtlinien
- Fragebögen zur Kundenaufnahme mit Dropdowns zur Leistungsauswahl
- Bestellformulare mit berechneten Feldern und Barcode-Kennungen
- Prüfchecklisten mit Optionsfeldern für Bestanden/Nicht bestanden
- Umfrageformulare mit bedingten Folgefragen, die abhängig von den Antworten erscheinen

## Tipps

- Wenn Sie eine bestehende PDF hochladen, versucht das Werkzeug, vorhandene Formularfelder zu extrahieren, sodass Sie sie bearbeiten oder ergänzen können.
- Nutzen Sie die Optionsfeldgruppen, um sich gegenseitig ausschließende Auswahlen zu erstellen. Felder in derselben Gruppe teilen sich einen Gruppennamen.
- Testen Sie Ihr Formular, indem Sie es herunterladen und im [PDF-Formular ausfüllen](./form-filler) öffnen, um das Feldverhalten zu prüfen.

# WPS zu PDF

Konvertieren Sie Textverarbeitungsdateien von Microsoft Works in PDF. Microsoft Works wurde in den späten 1990er und 2000er Jahren mit Verbraucher-PCs ausgeliefert, und viele WPS-Dateien liegen noch auf alten Festplatten und in E-Mail-Archiven. Dieses Tool öffnet sie im Browser und erzeugt saubere PDFs.

## Unterstützte Formate

| Format          | Erweiterung | Hinweise                                     |
| :-------------- | :---------- | :------------------------------------------- |
| Microsoft Works | `.wps`      | Textverarbeitungsdateien von Microsoft Works |

## So funktioniert es

1. Klicken Sie auf den Upload-Bereich oder ziehen Sie Ihre WPS-Dateien per Drag-and-drop hinein. Mehrere Dateien werden akzeptiert.
2. Prüfen Sie die Dateiliste. Entfernen Sie einzelne Dateien mit dem Papierkorb-Symbol oder klicken Sie auf **Weitere Dateien hinzufügen**, um Ihren Stapel zu erweitern.
3. Klicken Sie auf **In PDF konvertieren**. Eine LibreOffice-basierte Engine wird im Browser geladen und konvertiert jedes WPS-Dokument in PDF.
4. Eine einzelne Datei wird direkt als PDF heruntergeladen. Mehrere Dateien werden in einem ZIP-Archiv mit dem Namen `wps-to-pdf.zip` gebündelt.

## Optionen

Es sind keine zusätzlichen Einstellungen nötig. Der Konverter verarbeitet Text, grundlegende Formatierung und eingebettete Bilder aus der WPS-Datei.

## Anwendungsfälle

- Alte Schul- oder Arbeitsdokumente retten, die im Microsoft-Works-Format gespeichert wurden
- WPS-E-Mail-Anhänge öffnen, wenn Microsoft Works nicht installiert ist
- Ein Archiv von WPS-Dateien für die Migration in ein modernes Dokumentensystem konvertieren
- Alte Dokumente drucken, die aktuelle Textverarbeitungen nicht öffnen können

## Tipps

- Verwechseln Sie WPS-Dateien von Microsoft Works (`.wps`) nicht mit Dateien von WPS Office. Dieses Tool ist speziell für das ältere Microsoft-Works-Format gedacht.
- Die LibreOffice-Engine braucht bei der ersten Verwendung einen Moment zum Laden. Ist sie geladen, laufen weitere Konvertierungen in derselben Sitzung schneller.

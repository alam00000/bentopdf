# Hintergrundfarbe

Legen Sie hinter allen vorhandenen Inhalten Ihres PDFs eine einfarbige Hintergrundfarbe fest. Das Werkzeug erstellt auf jeder Seite ein farbiges Rechteck und legt den ursprünglichen Inhalt darüber, sodass Text, Bilder und Grafiken vor dem neuen Hintergrund vollständig sichtbar bleiben.

## So funktioniert es

1. Laden Sie Ihre PDF-Datei hoch.
2. Wählen Sie mit der Farbauswahl eine Hintergrundfarbe. Standard ist ein helles Gelb (#FFFFCC).
3. Klicken Sie auf **Hintergrundfarbe ändern**, um zu verarbeiten.
4. Das aktualisierte PDF wird automatisch heruntergeladen.

## Optionen

- **Hintergrundfarbe** -- Eine Standard-Farbauswahl für jede beliebige einfarbige Farbe. Standard ist helles Gelb.

## Funktionen

- Wendet eine einheitliche Hintergrundfarbe auf jede Seite an
- Behält alle ursprünglichen Inhalte (Text, Bilder, Vektorgrafiken) über der Farbschicht bei
- Behält die ursprünglichen Seitenabmessungen bei
- Funktioniert mit Dokumenten beliebiger Seitenzahl

## Anwendungsfälle

- Einen hellen Creme- oder Elfenbeinhintergrund hinzufügen, damit Dokumente weicher und papierähnlicher wirken
- Dokumentensätze farblich kennzeichnen, indem verschiedenen Kategorien unterschiedliche Hintergrundfarben zugewiesen werden
- Optisch unterscheidbare Versionen desselben Dokuments für verschiedene Zielgruppen erstellen
- Eine helle Hintergrundtönung hinzufügen, um die Lesbarkeit bei der Projektion von Dokumenten auf einen Bildschirm zu verbessern

## Tipps

- Helle, gedeckte Farben funktionieren am besten. Ein sehr dunkler Hintergrund kann Text schwer lesbar machen, sofern der Text nicht bereits hell ist.
- Wenn Sie sowohl Hintergrund- als auch Textfarbe ändern möchten, wenden Sie zuerst die Hintergrundfarbe an und nutzen Sie dann [Textfarbe ändern](./text-color) auf das Ergebnis.
- Dieses Werkzeug arbeitet auf der strukturellen PDF-Ebene (ohne Rasterung), daher bleibt der Text in der Ausgabe auswählbar und durchsuchbar.

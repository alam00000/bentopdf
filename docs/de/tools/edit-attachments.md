# Anhänge bearbeiten

Prüfen und verwalten Sie die Dateianhänge in einer PDF. Das Werkzeug listet jede eingebettete Datei mit Namen und Anhangsebene auf und lässt Sie einzelne Anhänge zum Entfernen markieren oder alle auf einmal entfernen.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch.
2. Das Werkzeug sucht automatisch nach Anhängen und zeigt sie in einer Liste an.
3. Jeder Anhang zeigt seinen Dateinamen und ob es ein Anhang auf Dokument- oder Seitenebene ist.
4. Klicken Sie auf das Papierkorb-Symbol neben einem Anhang, um ihn zum Entfernen zu markieren (erneut klicken hebt die Markierung auf).
5. Mit der Schaltfläche **Alle Anhänge entfernen** wählen Sie alles auf einmal aus, mit **Auswahl aufheben** löschen Sie Ihre Auswahl.
6. Klicken Sie auf die Verarbeitungsschaltfläche, um eine neue PDF ohne die ausgewählten Anhänge zu speichern.

## Funktionen

- Listet alle Anhänge auf Dokument- und Seitenebene auf
- Einzelnes oder gesammeltes Entfernen von Anhängen
- Auswahl vor dem Übernehmen der Änderungen ein- und ausschalten
- Visuelle Durchstreichung und geringere Deckkraft bei zum Entfernen markierten Einträgen
- Lädt die geänderte PDF ohne die ausgewählten Anhänge herunter

## Anwendungsfälle

- Veraltete oder falsche eingebettete Dateien aus einem Dokument entfernen, bevor es weitergegeben wird
- Sensible Anhänge (Finanzdaten, persönliche Angaben) aus einer PDF entfernen, bevor Sie sie teilen
- Die PDF-Dateigröße verringern, indem nicht mehr benötigte große eingebettete Dateien entfernt werden
- Eingebettete Inhalte prüfen und ein Dokument vor der Archivierung bereinigen

## Tipps

- Zum Entfernen markierte Anhänge werden durchgestrichen dargestellt. Sie können die Markierung vor der Verarbeitung wieder aufheben, wenn Sie es sich anders überlegen.
- Wenn keine Anhänge gefunden werden, zeigt das Werkzeug eine klare Meldung "Keine Anhänge gefunden". Die PDF enthält dann einfach keine eingebetteten Dateien.

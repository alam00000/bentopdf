# PSD zu PDF

Wandeln Sie Adobe-Photoshop-PSD-Dateien in PDF-Dokumente um. PSD ist das native Photoshop-Format, und zum Öffnen braucht man normalerweise teure Adobe-Software. Dieses Werkzeug rendert das reduzierte Gesamtbild Ihrer PSD-Datei als PDF-Seite in voller Auflösung.

## Unterstützte Formate

| Format          | Endung | Hinweise                                   |
| :-------------- | :----- | :----------------------------------------- |
| Adobe Photoshop | `.psd` | Rendert das auf eine Ebene reduzierte Bild |

## So funktioniert es

1. Klicken Sie auf den Upload-Bereich oder ziehen Sie Ihre PSD-Dateien per Drag & Drop hinein. Mehrere Dateien werden unterstützt.
2. Prüfen Sie die Dateiliste. Entfernen Sie unerwünschte Dateien mit dem Papierkorb-Symbol oder fügen Sie über **Weitere Dateien hinzufügen** mehr hinzu.
3. Klicken Sie auf **In PDF umwandeln**. Die PyMuPDF-Engine liest die PSD-Datei und bettet das Gesamtbild in der Originalauflösung in eine PDF-Seite ein.
4. Eine einzelne PSD ergibt eine PDF. Wenn Sie mehrere PSD-Dateien hochladen, werden sie zu einer mehrseitigen PDF namens `psd_to_pdf.pdf` kombiniert, wobei jede PSD eine Seite wird.

## Optionen

Es sind keine Einstellungen nötig. Der Konverter verwendet die reduzierten Bilddaten der PSD-Datei.

## Anwendungsfälle

- Photoshop-Entwürfe ansehen, ohne Photoshop zu öffnen
- Design-Korrekturabzüge an Kunden senden, die keine Adobe Creative Suite haben
- Hochauflösende Grafiken aus PSD-Dateien drucken
- Aus mehreren PSD-Designdateien ein PDF-Portfolio erstellen, wobei jede Datei eine Seite in einem einzigen Dokument wird

## Tipps

- Die Umwandlung rendert die Gesamtansicht (auf eine Ebene reduziert) der PSD. Einzelne Ebenen, Einstellungsebenen und Ebeneneffekte bleiben in der PDF nicht als eigene Elemente erhalten.
- Mehrere PSD-Dateien werden zu einer mehrseitigen PDF zusammengeführt statt zu einzelnen PDFs. Das ist praktisch für Portfolios oder Lookbooks.
- PSD-Dateien mit sehr hoher Auflösung (Druckdateien mit 300+ DPI) ergeben große PDFs. Das Werkzeug behält die volle Auflösung bei.

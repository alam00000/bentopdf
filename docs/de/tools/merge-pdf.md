# PDF zusammenführen

Kombinieren Sie mehrere PDF-Dateien zu einem einzigen Dokument. Sie können ganze Dateien in einer bestimmten Reihenfolge zusammenführen oder in den Seitenmodus wechseln, um einzelne Seiten aus allen hochgeladenen PDFs gezielt zu steuern.

## So funktioniert es

1. Laden Sie zwei oder mehr PDF-Dateien hoch, indem Sie auf die Ablagezone klicken oder sie hineinziehen.
2. Wählen Sie mit dem Umschalter oben zwischen **Dateimodus** und **Seitenmodus**.
3. Im Dateimodus ordnen Sie die Dateien per Drag & Drop neu an und geben optional pro Datei Seitenbereiche an (z. B. `1-3, 5`). Lassen Sie den Bereich leer, um alle Seiten einzubeziehen.
4. Im Seitenmodus ziehen Sie einzelne Seitenminiaturen per Drag & Drop, um Ihre genaue Seitenfolge aufzubauen.
5. Klicken Sie auf **PDFs zusammenführen**, um alles zu einer Datei zu kombinieren. Die zusammengeführte PDF wird automatisch heruntergeladen.

## Funktionen

- Zwei Zusammenführungsmodi: Dateimodus zum schnellen Kombinieren ganzer Dateien, Seitenmodus für Kontrolle pro Seite
- Neuanordnung per Drag & Drop in beiden Modi mit flüssigen Animationen
- Mit der Seitenbereichssyntax (z. B. `1-3, 5, 8-10`) wählen Sie Seiten gezielt aus, ohne in den Seitenmodus zu wechseln
- Per Lazy Loading geladene Seitenminiaturen halten die Oberfläche auch bei großen Dokumenten reaktionsfähig
- Keine Begrenzung für Anzahl der Dateien oder Gesamtseitenzahl
- Erhält die ursprüngliche PDF-Qualität ohne erneute Kodierung

## Optionen

| Option             | Beschreibung                                                                                             |
| ------------------ | -------------------------------------------------------------------------------------------------------- |
| **Dateimodus**     | Ganze Dateien in beliebiger Reihenfolge zusammenführen, mit optionalen Seitenbereichsfiltern pro Datei   |
| **Seitenmodus**    | Visuelles Raster aller Seiten aus allen Dateien: Miniaturen ziehen, um die genaue Reihenfolge aufzubauen |
| **Seiten-Eingabe** | Textfeld pro Datei, das Bereiche wie `1-3, 5` akzeptiert, um nur bestimmte Seiten aufzunehmen            |

## Anwendungsfälle

- Einzelne Kapitel-PDFs zu einem Buch oder Bericht kombinieren
- Anschreiben und Lebenslauf zu einem Bewerbungsdokument zusammenführen
- Bestimmte Seiten aus mehreren Quelldokumenten in einer gemeinsamen Datei bündeln
- Gescannte Belege oder Rechnungen zu einer Archiv-PDF zusammenstellen
- Aus Folien mehrerer Präsentationen ein Handout erstellen

## Tipps

- Nutzen Sie den Seitenmodus, wenn Sie Seiten aus verschiedenen Dateien abwechselnd einfügen wollen, statt eine Datei an die andere anzuhängen.
- Sie können nach dem ersten Upload mit der Schaltfläche **Weitere Dateien hinzufügen** weitere Dateien ergänzen, ohne Ihre aktuelle Anordnung zu verlieren.
- Seitenbereiche beginnen bei 1, `1` bezeichnet also die erste Seite der jeweiligen Datei.

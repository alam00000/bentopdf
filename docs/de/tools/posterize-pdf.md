# PDF posterisieren

Teilen Sie jede Seite einer PDF in ein Raster kleinerer Teilseiten auf. Mit diesem Werkzeug drucken Sie eine einzelne Seite auf mehrere Blätter Papier, die Sie anschließend zu einem großen Poster oder Banner zusammensetzen.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch.
2. Legen Sie die Anzahl der **Zeilen** und **Spalten** für das Raster fest (z. B. teilen 2 Zeilen x 2 Spalten jede Seite in 4 Teilseiten).
3. Geben Sie optional einen Seitenbereich an, um einzuschränken, welche Seiten posterisiert werden.
4. Die Vorschau zeigt ein Raster über der aktuellen Seite, damit Sie die Schnitte sehen können.
5. Wechseln Sie zwischen den Seiten, um das Raster auf anderen Seiten zu prüfen.
6. Klicken Sie auf die Schaltfläche zum Verarbeiten. Jede Rasterzelle wird in der Ausgabe-PDF zu einer eigenen Seite.

## Funktionen

- Einstellbare Zeilen- und Spaltenanzahl für flexible Rastergrößen
- Live-Vorschau mit Rasterüberlagerung, die genau zeigt, wo die Seiten geteilt werden
- Seitenbereichsfilter, um nur bestimmte Seiten zu posterisieren
- Seitenweise Navigation in der Vorschau
- Zwischengespeicherte Seitenvorschauen für schnelles Blättern
- Gestrichelte rote Rasterlinien markieren die Schnittkanten deutlich

## Optionen

| Option            | Beschreibung                                           |
| ----------------- | ------------------------------------------------------ |
| **Zeilen**        | Anzahl der horizontalen Teilungen (Standard: 1)        |
| **Spalten**       | Anzahl der vertikalen Teilungen (Standard: 1)          |
| **Seitenbereich** | Welche Seiten posterisiert werden (leer = alle Seiten) |

## Anwendungsfälle

- Eine Poster-PDF auf normalen A4- oder Letter-Blättern drucken und an der Wand zusammensetzen
- Große Banner aus dem Design einer einzelnen PDF-Seite erstellen
- Übergroße technische Zeichnungen in druckbare Kacheln aufteilen
- Großformatige Ausdrucke ohne Großformatdrucker anfertigen

## Tipps

- Ein 2x2-Raster macht aus einer Seite 4 Seiten. Ein 3x3-Raster macht aus einer Seite 9. Planen Sie das Raster danach, wie groß das zusammengesetzte Ergebnis werden soll.
- Die Vorschau hilft sich zu prüfen, dass wichtige Inhalte nicht auf einer Schnittlinie liegen. Passen Sie bei Bedarf Zeilen und Spalten an.
- Für die umgekehrte Operation (mehrere Seiten auf einem Blatt) nutzen Sie [N-Up PDF](./n-up-pdf).

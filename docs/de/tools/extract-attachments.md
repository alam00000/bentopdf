# Anhänge extrahieren

Holen Sie jeden eingebetteten Anhang aus einer oder mehreren PDF-Dateien heraus. Alle extrahierten Dateien werden zum Download in einem einzigen ZIP-Archiv gebündelt.

## So funktioniert es

1. Laden Sie eine oder mehrere PDF-Dateien hoch, die eingebettete Anhänge enthalten.
2. Klicken Sie auf **Anhänge extrahieren**.
3. Das Werkzeug durchsucht jede PDF nach Anhängen auf Dokument- und Seitenebene.
4. Alle gefundenen Dateien werden in einem ZIP-Archiv verpackt und automatisch heruntergeladen.
5. Eine Statusmeldung bestätigt, wie viele Anhänge gefunden wurden und wie groß sie insgesamt sind.

## Funktionen

- Stapelextraktion aus mehreren PDFs gleichzeitig
- Extrahiert Anhänge auf Dokument- und auf Seitenebene
- Gibt eine einzelne ZIP-Datei mit allen extrahierten Dateien aus
- Zeigt die Gesamtzahl der Anhänge und die kombinierte Dateigröße an
- Klare Statusmeldungen, wenn keine Anhänge gefunden werden

## Anwendungsfälle

- In einer Bericht-PDF eingebettete Datendateien wiederherstellen
- Bilddateien aus einem Portfolio oder einer Spezifikation herausholen
- Ergänzende Materialien aus Schulungs- oder Compliance-PDFs extrahieren
- Prüfen, welche Dateien in einem Stapel von PDFs eingebettet sind

## Tipps

- Meldet das Werkzeug keine Anhänge, enthält die PDF möglicherweise stattdessen eingebettete Bilder oder Formulardaten, die keine Dateianhänge sind. Für eingebettete Bilder nutzen Sie [Bilder extrahieren](./extract-images).
- Bei der Verarbeitung mehrerer PDFs landen alle Anhänge aller Dateien in einem ZIP. Die Dateinamen bleiben wie bei der ursprünglichen Einbettung erhalten.

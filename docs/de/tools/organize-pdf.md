# Duplizieren & Organisieren

Ordnen Sie Seiten eines PDFs neu an, duplizieren Sie oder entfernen Sie sie mit einer visuellen Drag-and-drop-Oberfläche. Jede Seite erscheint als Vorschaubild, das Sie verschieben, klonen oder löschen können, bevor Sie das Ergebnis als neue Datei speichern.

## So funktioniert es

1. Laden Sie eine einzelne PDF-Datei hoch.
2. Das Werkzeug zeigt ein Raster mit Vorschaubildern aller Seiten.
3. Ziehen Sie Vorschaubilder, um Seiten neu anzuordnen, klicken Sie auf die grüne Duplizieren-Schaltfläche, um eine Seite zu klonen, oder auf die rote Löschen-Schaltfläche, um sie zu entfernen.
4. Alternativ geben Sie im Textfeld eine eigene Seitenreihenfolge ein (z. B. `3, 1, 2, 4`) und klicken Sie auf **Anwenden**, um alle Seiten auf einmal neu anzuordnen.
5. Klicken Sie auf die Schaltfläche zum Verarbeiten, um das neu organisierte PDF zu erstellen und herunterzuladen.

## Funktionen

- Neuanordnung der Seiten per Drag-and-drop mit animierten Übergängen
- Duplizieren- und Löschen-Schaltflächen pro Seite
- Eingabe einer eigenen Seitenreihenfolge für präzises Umordnen
- Seitenzahlen, die sich nach jeder Änderung automatisch aktualisieren
- Verhindert das Löschen der letzten verbleibenden Seite

## Anwendungsfälle

- Eine falsch eingeordnete Seite in einem Bericht an die richtige Stelle verschieben
- Eine Formularseite duplizieren, um mehrere leere Kopien in einer Datei zu haben
- Entwurfs- oder Platzhalterseiten entfernen, bevor ein Dokument verteilt wird
- Die Seitenreihenfolge für die Druckvorbereitung umkehren oder mischen
- Eine eigene Seitenfolge erstellen, ohne einzelne Dateien erneut zusammenzuführen

## Tipps

- Das Feld für die eigene Seitenreihenfolge erwartet durch Kommas getrennte ursprüngliche Seitenzahlen. Jede Seite muss genau einmal vorkommen, ohne Auslassungen oder Duplikate.
- Nach dem Duplizieren einer Seite verweisen beide Kopien auf denselben ursprünglichen Seitenindex. Beide Kopien lassen sich unabhängig voneinander verschieben.
- Für Massenoperationen über mehrere Dateien oder komplexere Abläufe nehmen Sie besser das [PDF-Multitool](./pdf-multi-tool).

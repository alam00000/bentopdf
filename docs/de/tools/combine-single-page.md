# Zu einer Seite kombinieren

Fügen Sie jede Seite einer PDF zu einer einzigen langen Seite zusammen. Die Seiten werden vertikal (wie eine Schriftrolle) oder horizontal (nebeneinander) aneinandergereiht, sodass die Ausgabe aus einer durchgehenden Seite besteht.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch.
2. Wählen Sie die Ausrichtung: **Vertikal** (Seiten von oben nach unten gestapelt) oder **Horizontal** (Seiten nebeneinander).
3. Legen Sie den Abstand zwischen den Seiten in Punkt fest.
4. Wählen Sie eine Hintergrundfarbe für die Lücken zwischen den Seiten.
5. Aktivieren Sie optional Trennlinien (dünne Linien zwischen den Seiten) und stellen Sie Stärke und Farbe ein.
6. Klicken Sie auf die Verarbeitungsschaltfläche. Die Ausgabe ist eine einseitige PDF.

## Funktionen

- Vertikales oder horizontales Aneinanderreihen der Seiten
- Einstellbarer Abstand zwischen den Seiten
- Farbauswahl für den Hintergrund der Zwischenräume
- Optionale Trennlinien mit einstellbarer Stärke und Farbe
- Rendert jede Originalseite in voller Auflösung auf die kombinierte Fläche

## Optionen

| Option                    | Beschreibung                                           |
| ------------------------- | ------------------------------------------------------ |
| **Ausrichtung**           | Vertikal (gestapelt) oder Horizontal (nebeneinander)   |
| **Seitenabstand**         | Lücke zwischen den Seiten in Punkt                     |
| **Hintergrundfarbe**      | Farbe des Bereichs zwischen den Seiten                 |
| **Trennlinie hinzufügen** | Dünne Linien zwischen den Seiten ein- oder ausschalten |
| **Trennlinienstärke**     | Linienstärke in Punkt                                  |
| **Trennlinienfarbe**      | Farbe der Trennlinien                                  |

## Anwendungsfälle

- Aus einem mehrseitigen Wireframe oder Design-Mockup ein einzelnes langes Bild erstellen
- Eine durchgehend scrollbare Ansicht eines Dokuments zum Einbetten im Web erzeugen
- Einen mehrseitigen Comic oder ein Storyboard zu einem Streifen zusammenfügen
- Eine Panoramaansicht aufeinanderfolgender Seiten zur Durchsicht erstellen

## Tipps

- Die vertikale Ausrichtung eignet sich am besten für Dokumente mit Hochformatseiten. Horizontal passt besser zu Querformat-Inhalten.
- Große Dokumente mit vielen Seiten ergeben eine sehr hohe oder breite Ausgabe. Einige PDF-Viewer haben mit extrem großen Einzelseiten Probleme.
- Trennlinien in einer Kontrastfarbe zeigen leicht, wo eine Originalseite endet und die nächste beginnt.

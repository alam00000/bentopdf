# PUB zu PDF

Wandeln Sie Microsoft-Publisher-Dateien in PDF um. Publisher ist ein Desktop-Publishing-Programm, das in manchen Microsoft-Office-Editionen enthalten ist, aber die meisten Leute haben es nicht installiert. Mit diesem Werkzeug kann jeder PUB-Dateien direkt im Browser in PDF umwandeln, ganz ohne Microsoft-Software.

## Unterstützte Formate

| Format              | Endung | Hinweise                     |
| :------------------ | :----- | :--------------------------- |
| Microsoft Publisher | `.pub` | Desktop-Publishing-Dokumente |

## So funktioniert es

1. Klicken Sie auf den Upload-Bereich oder ziehen Sie Ihre PUB-Dateien per Drag & Drop hinein. Mehrere Dateien können gleichzeitig hochgeladen werden.
2. Prüfen Sie die Dateiliste. Entfernen Sie unerwünschte Dateien mit dem Papierkorb-Symbol oder klicken Sie auf **Weitere Dateien hinzufügen**.
3. Klicken Sie auf **In PDF umwandeln**. Eine LibreOffice-basierte Engine wird im Browser geladen und wandelt jede PUB-Datei um, wobei Layout, Bilder und Textfelder erhalten bleiben.
4. Eine einzelne Datei wird direkt als PDF heruntergeladen. Mehrere Dateien werden in einem ZIP-Archiv namens `pub-to-pdf.zip` geliefert.

## Optionen

Es ist keine zusätzliche Konfiguration nötig. Der Konverter übernimmt die PUB-Layout-Engine automatisch.

## Anwendungsfälle

- Einen PUB-Flyer oder Newsletter von einem Kunden öffnen, ohne Microsoft Publisher zu kaufen
- Gemeindebriefe, Veranstaltungsprogramme oder Schulnewsletter umwandeln, die in Publisher erstellt wurden
- Marketingmaterial aus Publisher in einem universell zugänglichen Format archivieren
- PUB-Dateien auf einem System drucken, auf dem Publisher nicht installiert ist

## Tipps

- Komplexe Publisher-Layouts mit überlagerten Textfeldern und exakter Positionierung können sich bei der Umwandlung leicht verschieben. Prüfen Sie die Ausgabe, wenn es auf genaue Positionen ankommt.
- Die LibreOffice-Engine wird einmal pro Sitzung initialisiert. Die erste Umwandlung dauert länger, weitere gehen schneller.
- Für die originalgetreueste Umwandlung von Publisher-Dateien sollten die im Original verwendeten Schriftarten Standard-Systemschriften sein.

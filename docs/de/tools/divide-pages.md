# Seiten teilen

Schneiden Sie einzelne PDF-Seiten in Hälften, indem Sie sie horizontal oder vertikal teilen. Das ist nützlich, wenn eine Seite Inhalte enthält, die auf getrennte Seiten gehören, zum Beispiel ein zweispaltiges Layout, das als eine breite Seite gescannt wurde.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch.
2. Wählen Sie die Teilungsrichtung: **Vertikal** (linke/rechte Hälfte) oder **Horizontal** (obere/untere Hälfte).
3. Geben Sie optional einen Seitenbereich an, um einzugrenzen, welche Seiten geteilt werden. Lassen Sie das Feld leer, um alle Seiten zu teilen.
4. Klicken Sie auf die Verarbeitungsschaltfläche, um die geteilte PDF zu erzeugen.

## Funktionen

- Vertikale Teilung: teilt jede Seite in eine linke und eine rechte Hälfte
- Horizontale Teilung: teilt jede Seite in eine obere und eine untere Hälfte
- Seitenbereichsfilter, um gezielt bestimmte Seiten zu teilen
- Nicht ausgewählte Seiten bleiben unverändert
- Erhält die Inhaltsqualität ohne erneutes Rendern

## Anwendungsfälle

- Zweiseitig gescannte Seiten trennen (z. B. ein Buchscan mit linker und rechter Seite auf einem Blatt)
- Eine Querformat-PDF mit nebeneinanderliegenden Inhalten in einzelne Hochformatseiten teilen
- Hohe Infografiken oder Poster in einen oberen und einen unteren Abschnitt teilen
- Breitformatige Dokumente für den Druck auf Standardpapier vorbereiten

## Tipps

- Wenn der Inhalt Ihrer Seiten ungleich verteilt ist, erfolgt die Teilung trotzdem genau in der Mitte. Für asymmetrische Teilungen nutzen Sie stattdessen [PDF zuschneiden](./crop-pdf).
- Kombinieren Sie dieses Werkzeug mit [PDF drehen](./rotate-pdf), falls Ihre Seiten vor oder nach dem Teilen gedreht werden müssen.

# Bilder zu PDF

Der universelle Bild-zu-PDF-Konverter. Laden Sie Bilder in praktisch jedem Format hoch und kombinieren Sie sie zu einem einzigen PDF-Dokument. Jedes Bild erhält eine eigene Seite in der Größe des Originals.

## Unterstützte Formate

| Format          | Erweiterungen                          |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

Das ist die breiteste Formatunterstützung aller Bildkonverter in BentoPDF. Wenn Sie nur ein bestimmtes Format brauchen, nutzen Sie stattdessen eines der spezialisierten Werkzeuge.

## So funktioniert es

1. Klicken Sie auf den Upload-Bereich oder ziehen Sie Ihre Bilddateien per Drag & Drop hinein. Sie können mehrere Dateien auf einmal auswählen.
2. Prüfen Sie die Dateiliste. Entfernen Sie unerwünschte Dateien mit dem Papierkorb-Symbol oder klicken Sie auf **Weitere Dateien hinzufügen**, um zusätzliche Bilder aufzunehmen.
3. Wählen Sie im Dropdown eine **PDF-Qualität**.
4. Klicken Sie auf **In PDF umwandeln**. Das Werkzeug verarbeitet die Bilder mit der PyMuPDF-Engine und lädt das Ergebnis als `images_to_pdf.pdf` herunter.

## Optionen

Die **PDF-Qualität** steuert die Bildkomprimierung beim Einbetten der Bilder in die PDF:

- **Hohe Qualität**: minimale Komprimierung, größere Datei. Am besten für Druck oder Archivierung.
- **Mittlere Qualität** (Standard): ausgewogene Komprimierung. Für die meisten Zwecke gut geeignet.
- **Niedrige Qualität**: starke Komprimierung, kleinste Datei. Geeignet für E-Mail oder schnelles Teilen.

HEIC- und WebP-Dateien werden vor dem Einbetten automatisch in PNG umgewandelt. Das geschieht unbemerkt und erfordert keine zusätzlichen Schritte.

## Anwendungsfälle

- Gescannte Belege oder Dokumente aus der Handykamera in einer PDF zusammenfassen
- Aus Bildern in gemischten Formaten ein Foto-Portfolio oder Lookbook erstellen
- iPhone-Fotos (HEIC) in eine teilbare PDF umwandeln, ohne Desktop-Software zu installieren
- Design-Mockups aus PSD-Exporten und Screenshots zu einer Kundenlieferung zusammenstellen
- Einen Ordner mit älteren Bildformaten (PNM, JXR, JP2) als eine einzige PDF archivieren

## Tipps

- Die Reihenfolge der Bilder in der PDF entspricht der Reihenfolge in der Dateiliste. Laden Sie sie in der gewünschten Reihenfolge hoch.
- Für die kleinstmögliche Dateigröße wähle Niedrige Qualität. Bei textlastigen Scans ist der optische Unterschied oft vernachlässigbar.
- Wenn Sie nur ein Bildformat haben, liefern die spezialisierten Konverter (JPG zu PDF, PNG zu PDF usw.) dasselbe Ergebnis mit einer einfacheren Oberfläche.

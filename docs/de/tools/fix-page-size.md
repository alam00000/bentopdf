# Seitengröße reparieren

PDFs, die aus mehreren Quellen zusammengestellt wurden, haben oft unterschiedliche Seitengrößen: manche Letter, manche A4, manche völlig untypisch. Dieses Werkzeug zwingt jede Seite auf eine einzige Zielgröße und skaliert den Inhalt je nach Bedarf, damit er passt oder die Seite füllt.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch.
2. Wählen Sie im Dropdown eine **Zielseitengröße** (A4, Letter, Legal, A3, A5, Tabloid oder Benutzerdefiniert).
3. Wählen Sie eine **Ausrichtung**: Automatisch behält die ursprüngliche Ausrichtung jeder Seite bei, alternativ erzwingen Sie Hochformat oder Querformat.
4. Wählen Sie einen **Inhaltsskalierungs**-Modus: Einpassen (erhält den gesamten Inhalt, kann Ränder hinzufügen) oder Füllen (füllt die Seite, kann Ränder abschneiden).
5. Legen Sie optional eine **Hintergrundfarbe** für hinzugefügte Ränder fest.
6. Klicken Sie auf **Seitengröße reparieren**.

## Optionen

- **Standardgrößen**: A4, Letter, Legal, A3, A5, Tabloid
- **Benutzerdefinierte Maße**: Breite und Höhe in Zoll oder Millimetern eingeben
- **Ausrichtung**: Automatisch, Hochformat, Querformat
- **Skalierungsmodus**: Einpassen oder Füllen (Zuschneiden)
- **Hintergrundfarbe**: Beliebige Farbe für die Randauffüllung

## Anwendungsfälle

- Eine zusammengeführte PDF vereinheitlichen, deren Seiten von verschiedenen Scannern stammen
- Ein US-Letter-Dokument für den internationalen Versand in A4 umwandeln
- Druckfertige PDFs mit einheitlichem Endformat vorbereiten
- Seiten korrigieren, die leicht vom Standard abweichen (z. B. 8,49 x 11,02 Zoll statt 8,5 x 11)

## Tipps

- Nutzen Sie den Modus Einpassen, damit garantiert kein Inhalt verloren geht. Der Modus Füllen sieht sauberer aus, kann aber Ränder abschneiden.
- Prüfen Sie das Ergebnis mit dem Werkzeug Seitenmaße, um sicherzugehen, dass jede Seite zur Zielgröße passt.
- Standardmäßig ist die Hintergrundfarbe Weiß. Wechseln Sie zu einer dunklen Farbe, wenn Ihr Dokument dunkle Ränder hat.

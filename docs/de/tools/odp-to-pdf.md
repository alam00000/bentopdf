# ODP zu PDF

Wandeln Sie OpenDocument-Presentation-Dateien in PDF um. ODP ist das native Format von LibreOffice Impress und ein Standardexport aus Google Slides. Als PDF kann jeder Präsentationen ohne Präsentationssoftware ansehen, und die Folien lassen sich sauber drucken.

## Unterstützte Formate

| Format                    | Erweiterung | Hinweise                                   |
| :------------------------ | :---------- | :----------------------------------------- |
| OpenDocument Presentation | `.odp`      | LibreOffice Impress / Google-Slides-Export |

## So funktioniert es

1. Klicken Sie auf den Upload-Bereich oder ziehen Sie Ihre ODP-Dateien per Drag & Drop hinein. Sie können mehrere Präsentationen auf einmal auswählen.
2. Prüfen Sie die Dateiliste. Entfernen Sie Einträge mit dem Papierkorb-Symbol oder nutzen Sie **Weitere Dateien hinzufügen**, um weitere Präsentationen aufzunehmen.
3. Klicken Sie auf **In PDF umwandeln**. Die LibreOffice-basierte Engine verarbeitet jede Präsentation und erzeugt eine PDF, in der jede Folie zu einer Seite wird.
4. Eine einzelne Datei wird als PDF heruntergeladen. Mehrere Dateien werden in einem ZIP-Archiv namens `odp-to-pdf.zip` geliefert.

## Optionen

Es gibt nichts zu konfigurieren. Jede Folie wird in ihren ursprünglichen Maßen gerendert, mit Text, Bildern, Formen und Folienhintergründen.

## Anwendungsfälle

- Eine Präsentation als Handout-PDF an das Publikum verteilen
- Google-Slides-Exporte mit Personen teilen, die PDF gegenüber ODP bevorzugen
- Konferenzvorträge und Vorlesungen in einem schreibgeschützten Format archivieren
- Foliensätze für Präsenz-Workshops drucken

## Tipps

- Folienübergänge und Animationen sind rein visuelle Funktionen, die nicht in die PDF übernommen werden, aber alle statischen Inhalte werden korrekt dargestellt.
- Sprechernotizen sind nicht in der PDF-Ausgabe enthalten. Wenn Sie Notizen brauchen, exportieren Sie sie separat aus Ihrer Präsentationssoftware.
- Wie die anderen LibreOffice-basierten Werkzeuge wird die Engine bei der ersten Nutzung geladen und für die Sitzung zwischengespeichert.

# Seitenzahlen

Fügen Sie jeder Seite Ihres PDFs sichtbare Seitenzahlen hinzu. Sie wählen Position, Format, Schriftgröße und Farbe, den Rest erledigt das Werkzeug.

## So funktioniert es

1. Laden Sie Ihre PDF-Datei hoch.
2. Stellen Sie im erscheinenden Optionsbereich die Seitenzahlen ein.
3. Klicken Sie zum Verarbeiten auf **Seitenzahlen hinzufügen**.
4. Das nummerierte PDF wird automatisch heruntergeladen.

## Optionen

- **Position**: Wähle, wo die Seitenzahlen erscheinen: Unten mittig, Unten links, Unten rechts, Oben mittig, Oben links oder Oben rechts.
- **Format**: Wählen Sie zwischen einfacher Nummerierung (1, 2, 3...) oder dem Format "Seite X von Y" (1 / 5, 2 / 5...).
- **Schriftgröße**: Legen Sie die Größe des Seitenzahltexts fest. Standard ist 12.
- **Farbe**: Wählen Sie mit dem Farbwähler eine beliebige Farbe für den Seitenzahltext.

## Funktionen

- Sechs Positionen, die alle Ecken und die mittleren Positionen abdecken
- Zwei Nummerierungsformate: einfach fortlaufend oder "Seite X von Y"
- Anpassbare Schriftgröße von 6 bis 72 Punkt
- Vollständiger Farbwähler für die Textfarbe
- Automatische Randbehandlung, die Zahlen unabhängig von der Seitengröße in sicheren Bereichen hält

## Anwendungsfälle

- Dokumente für den Druck vorbereiten, die sichtbare Seitenverweise brauchen
- Seitenzahlen zu einem aus mehreren Quelldateien zusammengeführten PDF hinzufügen
- Handouts von Präsentationen vor der Verteilung nummerieren
- Rechtsdokumente oder Verträge fortlaufend nummerieren

## Tipps

- Das Format "Seite X von Y" ist hilfreich bei Dokumenten, bei denen Leser die Gesamtlänge kennen sollen, etwa Angebote oder Berichte.
- Wenn Sie für verschiedene Abschnitte unterschiedliche Nummerierungsstile brauchen (etwa römische Ziffern für den Vorspann), nutzen Sie stattdessen das Werkzeug [Seitenbeschriftungen hinzufügen](./add-page-labels).

# Seiten löschen

Entfernen Sie unerwünschte Seiten aus einem PDF-Dokument. Geben Sie die zu löschenden Seiten als Seitenzahlen oder Bereiche ein oder klicken Sie direkt auf Seitenvorschaubilder, um sie zum Entfernen zu markieren.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch. Das Werkzeug erstellt Vorschaubilder jeder Seite.
2. Geben Sie die zu löschenden Seiten im Textfeld mit Bereichssyntax ein (z. B. `2, 5-8`) oder klicken Sie auf Vorschaubilder, um sie umzuschalten.
3. Markierte Seiten werden visuell hervorgehoben, damit Sie Ihre Auswahl prüfen können.
4. Klicken Sie auf die Verarbeitungsschaltfläche. Es wird eine neue PDF ohne die ausgewählten Seiten erstellt.

## Funktionen

- Textbasierte Seitenauswahl mit Bereichssyntax (`2, 5-8, 12`)
- Visuelles Vorschaubildraster zum Löschen per Klick
- Echtzeit-Hervorhebung der zum Löschen markierten Seiten
- Eingabeprüfung anhand der tatsächlichen Seitenzahl
- Behält alle nicht gelöschten Seiten in ihrer ursprünglichen Reihenfolge

## Anwendungsfälle

- Leere oder Füllseiten aus einem gescannten Dokument entfernen
- Deckblätter oder Anhänge entfernen, bevor Sie ein Dokument teilen
- Entwurfsseiten bereinigen, die versehentlich in einer endgültigen PDF geblieben sind
- Seiten mit sensiblen Informationen vor der Weitergabe entfernen

## Tipps

- Das Löschen von Seiten wirkt sich nicht auf Inhalt oder Formatierung der übrigen Seiten aus. Die Ausgabe ist eine getreue Kopie des Originals abzüglich der entfernten Seiten.
- Wenn Sie nur bestimmte Seiten behalten statt bestimmte entfernen wollen, ist [Seiten extrahieren](./extract-pages) besser geeignet.
- Die Vorschauansicht lädt träge nach, sodass große Dokumente reaktionsschnell bleiben.

# PDF zuschneiden

Beschneiden Sie die Ränder Ihrer PDF-Seiten mit einer visuellen Zuschneideoberfläche. Zeichnen Sie direkt auf jeder Seite ein Zuschneiderechteck, sehen Sie sich das Ergebnis in der Vorschau an und wenden Sie den Zuschnitt an. Sie können für verschiedene Seiten unterschiedliche Zuschneidebereiche festlegen oder denselben Zuschnitt auf das ganze Dokument anwenden.

## So funktioniert es

1. Laden Sie Ihre PDF-Datei hoch.
2. Der Zuschneide-Editor öffnet sich und zeigt die erste Seite mit einer verschiebbaren Zuschneideüberlagerung.
3. Passen Sie das Zuschneiderechteck an, indem Sie an Kanten oder Ecken ziehen.
4. Wechslen Sie mit den Seitennavigationsschaltflächen zwischen den Seiten und legen Sie für jede einen Zuschneidebereich fest.
5. Klicken Sie auf **Zuschneiden**, um den Zuschnitt anzuwenden und das Ergebnis herunterzuladen.

## Funktionen

- Visueller Zuschneide-Editor auf Basis von Cropper.js mit Anfassern für präzise Anpassung
- Seitenweise Navigation, um individuelle Zuschneidebereiche festzulegen
- Speichert Zuschnitteinstellungen pro Seite, sodass Sie für verschiedene Seiten unterschiedliche Zuschnitte definieren können
- Live-Vorschau des gewählten Zuschneidebereichs
- Unterstützt PDFs mit beliebiger Seitengröße oder Ausrichtung

## Anwendungsfälle

- Breite Ränder gescannter Dokumente entfernen, um sich auf den Inhaltsbereich zu konzentrieren
- Druckermarken oder Passermarken aus Druckvorstufen-PDFs entfernen
- Vorlesungsfolien zuschneiden, um den Bereich mit den Referentennotizen zu entfernen
- Kopf- oder Fußzeilen von jeder Seite entfernen, bevor Sie einen Dokumentauszug teilen
- Seiten an ein bestimmtes Anzeige- oder Drucklayout anpassen

## Tipps

- Die Zuschneideüberlagerung lässt sich frei in der Größe ändern und verschieben. Ziehen Sie an den Ecken für proportionale Größenänderung oder an den Kanten für Anpassung in einer Achse.
- Wenn jede Seite denselben Zuschnitt braucht, legen Sie ihn auf der ersten Seite fest. Das Werkzeug merkt sich Ihren Zuschneidebereich beim Wechseln der Seiten.
- Wenn Sie Seitengrößen vereinheitlichen statt visuell zuschneiden wollen, passt das Werkzeug Seitengröße korrigieren möglicherweise besser.

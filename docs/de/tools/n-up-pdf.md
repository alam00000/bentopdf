# N-Up PDF

Platzieren Sie mehrere Seiten in einer Rasteranordnung auf einem Blatt. Das verringert die Zahl der gedruckten Seiten, indem 2, 4, 6, 8, 9 oder 16 Seiten auf ein Blatt passen. Das Werkzeug übernimmt Skalierung, Positionierung und optional die Konfiguration der Seitengröße.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch.
2. Wählen Sie die Anzahl der Seiten pro Blatt (den Wert "N"): 2, 4, 6, 8, 9 oder 16.
3. Wählen Sie die Ausgabeseitengröße (Standard ist A4) und die Ausrichtung.
4. Konfigurieren Sie optional Abstand, Rahmenfarbe und Hintergrundfarbe.
5. Klicken Sie auf die Schaltfläche zum Verarbeiten. Das Werkzeug skaliert jede Seite und ordnet sie auf neuen Blättern an.

## Funktionen

- Rasterlayouts: 2-up, 4-up, 6-up, 8-up, 9-up und 16-up
- Konfigurierbare Ausgabeseitengröße und Ausrichtung
- Optionaler Abstand zwischen den angeordneten Seiten
- Einstellungen für Hintergrund- und Rahmenfarbe
- Behält das Seitenverhältnis der Originalseiten beim Einpassen bei

## Optionen

| Option               | Beschreibung                                                   |
| -------------------- | -------------------------------------------------------------- |
| **Seiten pro Blatt** | Anzahl der Originalseiten pro Ausgabeseite (2, 4, 6, 8, 9, 16) |
| **Seitengröße**      | Größe des Ausgabeblatts (A4, Letter, Legal usw.)               |
| **Ausrichtung**      | Hochformat oder Querformat für das Ausgabeblatt                |
| **Abstand**          | Lücke in Punkt zwischen den angeordneten Seiten                |
| **Hintergrundfarbe** | Füllfarbe für den Hintergrund des Ausgabeblatts                |
| **Rahmenfarbe**      | Farbe für die Rahmen um jede angeordnete Seite                 |

## Anwendungsfälle

- Handouts mit 4 Folien pro Seite drucken, um Papier zu sparen
- Lernzettel mit mehreren Referenzseiten auf einem Blatt erstellen
- Kompakte Dokumentarchive zum Ablegen erzeugen
- Miniatur-Übersichtsblätter eines langen Dokuments erstellen

## Tipps

- Das Querformat funktioniert bei 2-up-Layouts oft besser, während Hochformat meist für 4-up und mehr am besten ist.
- Ein größerer Abstand verbessert die Lesbarkeit, verkleinert aber die verfügbare Fläche für jede angeordnete Seite.
- Für die umgekehrte Operation (eine Seite in mehrere aufteilen) siehe [PDF posterisieren](./posterize-pdf).

# WPD zu PDF

Konvertieren Sie Corel-WordPerfect-Dokumente in PDF-Dateien. WPD war einst das dominierende Textverarbeitungsformat in Anwaltskanzleien und Behörden. Wenn Sie alte WordPerfect-Dateien haben, die moderne Software nicht mehr öffnen will, erweckt dieses Tool sie als Standard-PDFs wieder zum Leben.

## Unterstützte Formate

| Format      | Erweiterung | Hinweise                             |
| :---------- | :---------- | :----------------------------------- |
| WordPerfect | `.wpd`      | Alle wichtigen WordPerfect-Versionen |

## So funktioniert es

1. Klicken Sie auf den Upload-Bereich oder ziehen Sie Ihre WPD-Dateien per Drag-and-drop hinein. Es können mehrere Dateien gleichzeitig ausgewählt werden.
2. Prüfen Sie die Dateiliste. Entfernen Sie unerwünschte Dateien mit dem Papierkorb-Symbol oder fügen Sie über **Weitere Dateien hinzufügen** weitere Dokumente hinzu.
3. Klicken Sie auf **In PDF konvertieren**. Das Tool lädt in Ihrem Browser eine LibreOffice-basierte Konvertierungs-Engine, die das WPD-Format einliest und PDF ausgibt.
4. Eine einzelne Datei wird direkt als PDF heruntergeladen. Stapelkonvertierungen ergeben ein ZIP-Archiv mit dem Namen `wpd-to-pdf.zip`.

## Optionen

Es ist keine Konfiguration erforderlich. Die LibreOffice-Engine übernimmt WPD-Formatierung, Schriften und Layout automatisch.

## Anwendungsfälle

- Jahrzehntealte Rechtsdokumente öffnen, die in WordPerfect geschrieben wurden
- Archivierte behördliche Unterlagen von WPD in ein modernes Format umwandeln
- Eine alte WordPerfect-Dokumentenbibliothek für die Langzeitspeicherung in PDF überführen
- WPD-Dateien an Empfänger weitergeben, die Corel WordPerfect nicht installiert haben

## Tipps

- Die LibreOffice-Engine wird bei der ersten Verwendung geladen, was einen Moment dauert. Weitere Konvertierungen in derselben Sitzung sind schneller.
- Komplexe WPD-Makros und Reveal Codes bleiben nicht erhalten, aber das visuelle Layout, der Textinhalt und die grundlegende Formatierung werden in die PDF übernommen.

# Leere Seite hinzufügen

Fügen Sie leere Seiten an einer von Ihnen festgelegten Position in ein PDF ein. Sie bestimmen, wo die leeren Seiten eingefügt werden und wie viele es sein sollen.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch. Das Werkzeug zeigt die Seitenzahl an.
2. Geben Sie die **Position** ein, an der leere Seiten eingefügt werden sollen. Verwenden Sie `0` für den Anfang oder die Gesamtseitenzahl, um am Ende anzufügen.
3. Geben Sie die **Anzahl** der hinzuzufügenden leeren Seiten ein (Standard ist 1).
4. Klicken Sie auf die Verarbeiten-Schaltfläche. Das geänderte PDF wird mit den eingefügten leeren Seiten heruntergeladen.

## Funktionen

- An beliebiger Position einfügen: am Anfang, in der Mitte oder am Ende des Dokuments
- Mehrere leere Seiten in einem Vorgang hinzufügen
- Der Positionshinweis passt sich dynamisch an die Seitenzahl des hochgeladenen PDFs an
- Leere Seiten im Standardformat A4

## Anwendungsfälle

- Eine leere Trennseite zwischen Abschnitten eines zusammengestellten Dokuments einfügen
- Leere Seiten für die korrekte Ausrichtung beim doppelseitigen Druck einfügen
- Platz für handschriftliche Notizen in einem gedruckten Lernleitfaden schaffen
- Ein Dokument auffüllen, um eine Mindestseitenzahl zu erreichen

## Tipps

- Position `0` fügt vor der ersten Seite ein. Eine Position gleich der Gesamtseitenzahl fügt nach der letzten Seite an.
- Wenn Sie Inhalte (nicht nur leere Seiten) an einer bestimmten Position einfügen möchten, nutzen Sie das [PDF-Multitool](./pdf-multi-tool), um ein weiteres PDF nach einer bestimmten Seite einzufügen.

# Textfarbe ändern

Ersetze die Farbe des Textes in Ihrer gesamten PDF. Das Werkzeug erkennt Textbereiche auf jeder Seite und färbt sie in Ihre gewählte Farbe um, während Layout und Inhalte, die kein Text sind, erhalten bleiben.

## So funktioniert es

1. Laden Sie Ihre PDF-Datei hoch.
2. Wählen Sie mit der Farbauswahl eine neue Textfarbe. Standard ist Blau (#0000FF).
3. Klicken Sie auf **Textfarbe ändern**, um die Verarbeitung zu starten.
4. Die umgefärbte PDF wird automatisch heruntergeladen. Eine Fortschrittsanzeige zeigt, welche Seite gerade verarbeitet wird.

## Optionen

- **Neue Textfarbe**: Eine Farbauswahl für die Ersatzfarbe des gesamten Textes im Dokument.

## Funktionen

- Färbt den Text auf jeder Seite des Dokuments um
- Verarbeitung seitenweise mit Fortschrittsanzeige
- Farbauswahl mit voller Unterstützung von Hex-Farbwerten
- Erhält Seitenlayout und Elemente, die kein Text sind

## Anwendungsfälle

- Schwarzen Text in dunkles Blau ändern, für ein weicheres, moderneres Dokumentbild
- Text vor der Verteilung von Dokumenten an Markenrichtlinien anpassen
- Text für die Barrierefreiheit in eine bestimmte Farbe umwandeln
- Text vor einer neu angewendeten Hintergrundfarbe sichtbar machen

## Tipps

- Dieses Werkzeug rendert Seiten für die Qualität in doppelter Größe und baut die PDF dann neu auf. Die Ausgabe ist bildbasiert, der Text ist danach nicht mehr auswählbar oder durchsuchbar.
- Wenn Sie auswählbaren Text behalten müssen, bearbeiten Sie die PDF stattdessen direkt mit dem [PDF-Editor](./edit-pdf).
- Die Verarbeitungszeit steigt mit der Seitenzahl, da jede Seite einzeln gerendert wird.

# PDFs zu ZIP

Bündeln Sie mehrere PDF-Dateien in einem einzigen ZIP-Archiv. Dies ist ein einfaches Verpackungswerkzeug: Die PDFs selbst werden weder umgewandelt noch komprimiert oder verändert.

## So funktioniert es

1. Laden Sie mehrere PDF-Dateien über die Ablagefläche hoch.
2. Prüfen Sie die Dateiliste. Entfernen Sie alle Dateien, die nicht enthalten sein sollen.
3. Klicken Sie auf die Schaltfläche zum Verarbeiten.
4. Ein ZIP-Archiv mit allen hochgeladenen PDFs wird sofort heruntergeladen.

## Funktionen

- Akzeptiert beliebig viele PDF-Dateien
- Einzelne Dateien lassen sich vor dem Erstellen des Archivs entfernen
- Behält die ursprünglichen Dateinamen im ZIP bei
- Keine Änderung am PDF-Inhalt, die Dateien werden unverändert gepackt
- Zeigt Dateiname und Größe jedes hochgeladenen PDFs an

## Anwendungsfälle

- Eine Reihe von Rechnungen oder Belegen für den E-Mail-Anhang bündeln
- Projektergebnisse (mehrere PDF-Berichte) für die Übergabe verpacken
- Einen einzigen Download für eine Sammlung von Formularen oder Vorlagen erstellen
- Einen Stapel Dokumente in einer komprimierten Datei archivieren

## Tipps

- Die ZIP-Datei verwendet die ursprünglichen PDF-Dateinamen. Wenn Sie Dateien mit gleichem Namen haben, benennen Sie sie vor dem Hochladen um, um Konflikte zu vermeiden.
- Dieses Werkzeug komprimiert die PDFs selbst nicht. Um die Dateigröße zu verringern, schicken Sie sie zuerst durch PDF komprimieren und verpacken Sie sie dann mit diesem Werkzeug.

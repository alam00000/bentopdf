# Seiten extrahieren

Holen Sie eine Reihe von Seiten aus einer PDF und speichern Sie sie als neue Datei. Geben Sie mit der Bereichssyntax genau an, welche Seiten Sie möchten, und das Werkzeug erstellt eine saubere PDF, die nur diese Seiten enthält.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch. Das Werkzeug zeigt Dateinamen, Größe und Gesamtseitenzahl an.
2. Geben Sie die zu extrahierenden Seiten mit der Bereichssyntax ein (z. B. `1-5`, `3, 7, 10-12`).
3. Wählen Sie optional, jeden Bereich als separate PDF in einem ZIP-Archiv herunterzuladen.
4. Klicken Sie auf die Verarbeitungsschaltfläche. Die extrahierten Seiten werden als neue PDF (oder ZIP) heruntergeladen.

## Funktionen

- Flexible Seitenbereichssyntax: einzelne Seiten, Bereiche oder durch Kommas getrennte Kombinationen
- Zeigt nach dem Hochladen die Gesamtseitenzahl zur einfachen Orientierung an
- Option zur Ausgabe als eine kombinierte PDF oder als einzelne Dateien in einem ZIP
- Erhält den ursprünglichen Seiteninhalt und die Formatierung

## Anwendungsfälle

- Die Zusammenfassung (die ersten Seiten) aus einem langen Bericht herausziehen
- Ein einzelnes Kapitel aus einer Lehrbuch-PDF extrahieren
- Bestimmte Seiten aus einem Formularpaket als eigenständige Dokumente speichern
- Aus ausgewählten Seiten einer größeren Datei ein Beispieldokument erstellen

## Tipps

- Seitenzahlen beginnen bei 1. Verwenden Sie `1` für die erste Seite, nicht `0`.
- Zum Entfernen statt Extrahieren von Seiten nutzen Sie [Seiten löschen](./delete-pages), die Umkehroperation.
- Wenn Sie eine visuelle Seitenauswahl mit Vorschaubildern brauchen, nutzen Sie [PDF teilen](./split-pdf) im Modus Visuelle Auswahl.

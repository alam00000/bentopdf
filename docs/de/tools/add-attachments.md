# Anhänge hinzufügen

Betten Sie eine oder mehrere Dateien direkt in ein PDF-Dokument ein. Anhänge können auf Dokumentebene hinzugefügt werden (sichtbar im Anhangbereich jedes PDF-Readers) oder an bestimmte Seiten gebunden werden.

## So funktioniert es

1. Laden Sie das PDF hoch, an das Sie Dateien anhängen möchten.
2. Wählen Sie über die Ablagefläche für Anhänge die Dateien aus, die Sie einbetten möchten (beliebiger Dateityp).
3. Wählen Sie die Anhangsebene: **Dokument** (Standard) oder **Seite**.
4. Wenn Sie die Seitenebene wählen, geben Sie einen Seitenbereich ein (z. B. `1-3` oder `5`).
5. Klicken Sie auf die Verarbeiten-Schaltfläche. Das geänderte PDF wird mit den eingebetteten Dateien heruntergeladen.

## Funktionen

- Beliebige Dateitypen anhängen: Bilder, Tabellen, Archive, ausführbare Dateien, alles
- Anhänge auf Dokument- oder Seitenebene platzieren
- Mehrere Dateien in einem Vorgang anhängen
- Zeigt Dateinamen und Größen aller ausgewählten Anhänge an
- Die Ausgabe behält den ursprünglichen PDF-Inhalt bei und ergänzt die eingebetteten Dateien

## Optionen

| Option            | Beschreibung                                                                           |
| ----------------- | -------------------------------------------------------------------------------------- |
| **Dokumentebene** | Hängt Dateien an das gesamte PDF an, abrufbar über den Anhangbereich                   |
| **Seitenebene**   | Hängt Dateien an bestimmte Seiten an, festgelegt über die Eingabe eines Seitenbereichs |

## Anwendungsfälle

- Quelldaten (Excel-Dateien, CSVs) mit einem PDF-Bericht bündeln
- Originalbilddateien an ein Fotografie-Portfolio im PDF-Format anhängen
- Begleitdokumente in einen Vertrag oder ein Angebot einbetten
- Ergänzendes Material an bestimmte Seiten eines Schulungshandbuchs anhängen

## Tipps

- Anhänge auf Dokumentebene werden von PDF-Readern am besten unterstützt. Anhänge auf Seitenebene sind möglicherweise nicht in allen Viewern sichtbar.
- Es gibt keine Größenbeschränkung für Anhänge, aber sehr große eingebettete Dateien lassen das PDF entsprechend wachsen.

# PDF-Formular ausfüllen

Öffnen Sie eine PDF mit Formularfeldern und füllen Sie sie direkt in einem integrierten Viewer aus. Das Werkzeug unterstützt sowohl Standard-AcroForm-Felder als auch ältere XFA-Formulare (XML Forms Architecture). Wenn Sie das Formular ausgefüllt haben, laden Sie die ausgefüllte Version mit einem Klick herunter.

## So funktioniert es

1. Laden Sie eine PDF mit Formularfeldern hoch.
2. Das Dokument öffnet sich in einem integrierten PDF-Viewer, der Formularfelder als interaktive Eingaben darstellt.
3. Klicken Sie auf Textfelder, Kontrollkästchen, Dropdowns und Optionsfelder, um sie auszufüllen.
4. Klicken Sie auf **Speichern & ausgefülltes Formular herunterladen**, um die fertige PDF zu erhalten.

## Funktionen

- Integrierter PDF.js-Viewer mit vollständiger Interaktion mit Formularfeldern
- Unterstützung für Standard-AcroForm-Felder (Texteingaben, Kontrollkästchen, Dropdowns, Optionsfelder)
- XFA-Unterstützung für ältere XML-basierte Formulare
- Automatische Viewer-Größe anhand der Seitenmaße
- Dateianzeige mit Name und Größe

## Optionen

Es gibt keine zusätzlichen Konfigurationsoptionen. Laden Sie das Formular hoch, füllen Sie es aus und laden Sie es herunter.

## Anwendungsfälle

- Steuerformulare, Versicherungsanträge oder Behördenunterlagen ausfüllen
- Bewerbungsformulare ausfüllen, die als PDF-Anhang eingehen
- Onboarding-Formulare für Lieferanten oder Lieferantenfragebögen ausfüllen
- Compliance-Checklisten mit Kontrollkästchen abzeichnen
- Anamnesebögen vor einem Termin ausfüllen

## Tipps

- XFA-Formulare sind ein älteres Format, das nur von manchen PDF-Viewern unterstützt wird. Wenn Sie eine XFA-PDF in Chrome oder den meisten anderen Programmen öffnen und leere Seiten sehen, fehlt diesen Viewern die XFA-Unterstützung. Das Ausfüllen von Formularen in BentoPDF und Firefox verarbeiten XFA korrekt.
- Für PDFs ohne vorhandene Formularfelder nutzen Sie zuerst das Werkzeug [PDF-Formular erstellen](./form-creator), um Felder hinzuzufügen, und füllen sie dann hier aus.
- Der Viewer passt seine Größe automatisch an die Seitenmaße der PDF an.

# PDF-Broschüre

Ordnen Sie die Seiten eines PDFs in der Reihenfolge einer Broschüren-Ausschießung an. Beidseitig gedruckt und in der Mitte gefalzt, ergeben die Seiten die richtige Lesereihenfolge. Dies ist das Layout für rückengeheftete Broschüren und Zines.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch.
2. Stellen Sie die Broschüreneinstellungen ein: Ausgabeseitengröße und Ausrichtung.
3. Klicken Sie auf **Vorschau erstellen**, um zu sehen, wie die Seiten auf jedem Bogen angeordnet werden.
4. Prüfen Sie die Vorschau, die jeden physischen Bogen mit der Zuordnung von Vorder- und Rückseite zeigt.
5. Klicken Sie auf **Herunterladen**, um das ausgeschossene Broschüren-PDF zu speichern.

## Funktionen

- Automatische Seitenumordnung für die Rückenstichheftung
- Einstellbare Ausgabeseitengröße
- Visuelle Vorschau des Broschürenlayouts vor dem Herunterladen
- Verarbeitet ungerade Seitenzahlen, indem bei Bedarf Leerseiten eingefügt werden
- Skaliert die Quellseiten passend zur Bogengröße der Broschüre

## Anwendungsfälle

- Druckbare Broschüren oder Zines aus einem normalen PDF erstellen
- Konferenzprogramme oder Veranstaltungsführer für den Druck im eigenen Haus vorbereiten
- Gefalzte Grußkarten oder kleine Kataloge herstellen
- Heftchen oder Gedichtsammlungen zum Binden von Hand erstellen

## Tipps

- Die Seitenzahl Ihres Quell-PDFs sollte für eine saubere Broschüre idealerweise ein Vielfaches von 4 sein. Ist sie es nicht, werden automatisch Leerseiten ergänzt, um den letzten Bogen aufzufüllen.
- Drucken Sie die Ausgabe beidseitig mit der Druckereinstellung "Wenden an der kurzen Kante", falzen Sie dann alle Bögen zusammen und heften Sie sie am Rücken.
- Um nur mehrere Seiten auf einem Bogen ohne Broschürenreihenfolge zu platzieren, nutzen Sie stattdessen [N-Up PDF](./n-up-pdf).

# PDFs vergleichen

Laden Sie zwei PDFs hoch und sehen Sie genau, was sich zwischen ihnen geändert hat. Das Werkzeug ordnet Seiten intelligent einander zu, erkennt Unterschiede bei Text, Bildern, Anmerkungen, Kopfzeilen und Formatierung und zeigt sie in einer Nebeneinander- oder Überlagerungsansicht an.

## So funktioniert es

1. Laden Sie zwei PDF-Dateien hoch: das Original (links) und die überarbeitete Version (rechts).
2. Das Werkzeug ordnet die Seiten beider Dokumente anhand von Inhaltssignaturen einander zu.
3. Wählen Sie einen Ansichtsmodus: **Nebeneinander** oder **Überlagerung**.
4. Wechslen Sie mit den Seitensteuerungen zwischen den Seitenpaaren.
5. Unterschiede werden hervorgehoben und kategorisiert. Nutzen Sie das Filterfeld, um sich auf bestimmte Änderungsarten zu konzentrieren.
6. Exportieren Sie den Vergleich optional als PDF-Bericht.

## Funktionen

- Automatische Seitenzuordnung anhand der Inhaltsähnlichkeit
- Vergleichsansichten nebeneinander und als Überlagerung
- Kategorisierung der Änderungen: Text, Bild, Kopf-/Fußzeile, Anmerkung, Formatierung, Hintergrund
- Filterschalter pro Kategorie, um bestimmte Änderungsarten ein- oder auszublenden
- Suche in Textänderungen mit Abfragefilter
- OCR-Unterstützung zum Vergleichen gescannter Dokumente
- Zoomsteuerung für die genaue Prüfung
- Synchronisiertes Scrollen zwischen den Bereichen in der Nebeneinander-Ansicht
- Vergleichsergebnisse als PDF exportieren

## Optionen

| Option              | Beschreibung                                                                                                      |
| ------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **Ansichtsmodus**   | Nebeneinander oder Überlagerung                                                                                   |
| **OCR**             | OCR für den Vergleich gescannter Dokumente ein- oder ausschalten                                                  |
| **OCR-Sprache**     | Sprache für die OCR-Textextraktion                                                                                |
| **Kategoriefilter** | Sichtbarkeit von Text-, Bild-, Kopf-/Fußzeilen-, Anmerkungs-, Formatierungs- und Hintergrundänderungen umschalten |
| **Änderungsumfang** | Im Überlagerungsmodus zwischen allen Änderungen oder nur Inhalt filtern                                           |
| **Zoom**            | Vergrößerungsstufe für die genaue Prüfung anpassen                                                                |

## Anwendungsfälle

- Vertragsüberarbeitungen prüfen, um genau zu sehen, was sich zwischen Versionen geändert hat
- Design-Mockups vergleichen, um zu prüfen, dass PDF-Exporte den Erwartungen entsprechen
- Dokumentänderungen in regulierten Branchen prüfen, in denen jede Bearbeitung nachvollziehbar sein muss
- Überprüfen, dass ein PDF-Konvertierungsprozess den Originalinhalt korrekt erhalten hat
- Übersetzte Dokumente auf Layoutänderungen gegenüber dem Original prüfen

## Tipps

- Die Überlagerungsansicht legt beide Dokumente übereinander, sodass räumliche Unterschiede (verschobene Elemente, skalierte Bilder) sofort sichtbar werden.
- Aktivieren Sie OCR, wenn Sie gescannte Dokumente ohne Textebene vergleichen. Die Vergleichs-Engine extrahiert dann den Text aus den Seitenbildern.
- Nutzen Sie die Kategoriefilter, um sich auf das Wesentliche zu konzentrieren. Blenden Sie zum Beispiel Formatierungsänderungen aus, wenn sich nur Unterschiede im Textinhalt interessieren.

# Stempel hinzufügen

Platzieren Sie Bildstempel auf Ihren PDF-Seiten mit einem eingebetteten Viewer samt Symbolleiste für Stempel-Annotationen. Stempel können Ihren Namen zur Zuordnung enthalten, das ist nützlich für Freigabe-Workflows, Prüfprozesse und die Kennzeichnung von Dokumenten.

## So funktioniert es

1. Geben Sie Ihren Namen in das Feld **Stempel-Benutzername** ein. Dieser Name erscheint auf den Stempeln, die Sie erstellen.
2. Laden Sie Ihre PDF-Datei hoch, indem Sie auf die Ablagefläche klicken oder die Datei dorthin ziehen.
3. Der Stempel-Editor öffnet sich mit Ihrem Dokument im Viewer.
4. Wählen Sie mit dem Bildstempel-Werkzeug der Symbolleiste Stempel aus und platzieren Sie sie auf einer beliebigen Seite.
5. Positionieren Sie die Stempel und änderen Sie ihre Größe nach Bedarf.
6. Klicken Sie auf **Gestempeltes PDF speichern**, um das Ergebnis herunterzuladen.

## Funktionen

- Integrierter PDF-Viewer mit spezieller Annotations-Symbolleiste für Stempel
- Zuordnung über den Benutzernamen auf erstellten Stempeln
- Bildstempel auf jeder Seite platzieren
- Positionieren und Skalieren per Drag-and-drop
- Automatische Viewer-Größe basierend auf dem Seitenverhältnis
- Dateianzeige mit Name und Größe

## Anwendungsfälle

- "GENEHMIGT"- oder "GEPRÜFT"-Bildstempel in einem Prüf-Workflow auf Dokumente setzen
- Firmensiegel oder Notarstempel als Bild auf offizielle Dokumente setzen
- Seiten mit "ERHALTEN"-Stempeln samt Namen der prüfenden Person markieren
- Qualitätskontrollstempel zu Prüfberichten hinzufügen

## Tipps

- Legen Sie Ihren Stempel-Benutzernamen fest, bevor Sie das PDF hochladen. Der Benutzername wird in den Stempel-Metadaten gespeichert.
- Der Viewer passt seine Höhe an das Seitenverhältnis der ersten PDF-Seite an, für eine optimale Darstellung.
- Für textbasierte Wasserzeichen statt Bildstempeln nutzen Sie das Werkzeug [Wasserzeichen hinzufügen](./add-watermark).

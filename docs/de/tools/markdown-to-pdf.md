# Markdown zu PDF

Ein voll ausgestatteter Markdown-Editor mit Live-Vorschau und PDF-Export per Klick. Schreiben Sie von Grund auf, laden Sie eine vorhandene `.md`-Datei hoch oder fügen Sie Inhalte aus der Zwischenablage ein. Der Editor rendert Ihr Markdown in Echtzeit und exportiert mit der integrierten Druck-Engine des Browsers eine gestaltete PDF.

## Unterstützte Formate

| Eingabe       | Beschreibung                              |
| :------------ | :---------------------------------------- |
| `.md`-Dateien | Hochladen über die Schaltfläche Hochladen |
| Direkteingabe | In den Editor tippen oder einfügen        |

## So funktioniert es

1. Öffnen Sie das Werkzeug Markdown zu PDF. Der Editor lädt mit geteilter Ansicht: Markdown-Quelltext links, gerenderte Vorschau rechts.
2. Schreiben Sie Ihr Markdown, fügen Sie es ein oder klicken Sie auf **Hochladen**, um eine `.md`-Datei zu laden.
3. Wechseln Sie mit dem Design-Schieberegler in der Symbolleiste zwischen hellem und dunklem Design.
4. Klicken Sie auf **PDF exportieren** (oder drücke `Ctrl/Cmd + S`), um über den Druckdialog des Browsers eine PDF zu erzeugen.

## Funktionen

Der Editor unterstützt über die Grundlagen hinaus viele Markdown-Funktionen:

- **Standard-Markdown**: Überschriften, fett, kursiv, Links, Bilder, Listen, Blockzitate, horizontale Linien
- **Codeblöcke** mit Syntaxhervorhebung für mehr als 15 Sprachen (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash und mehr)
- **Mermaid-Diagramme**: Flussdiagramme, Sequenzdiagramme, ER-Diagramme und andere Mermaid-Diagrammtypen werden direkt in der Vorschau gerendert
- **Tabellen** mit der Standard-Markdown-Tabellensyntax
- **Aufgabenlisten** mit Kontrollkästchen
- **Fußnoten**, **tiefgestellter Text**, **hochgestellter Text**
- **Definitionslisten**, **Abkürzungen**
- **Emoji**-Unterstützung (`:smile:` wird als Emoji dargestellt)
- **Hervorhebungen** (`==marked text==`) und **Einfügungen** (`++inserted text++`)
- **Automatische Verlinkung von URLs**: einfache URLs werden in anklickbare Links umgewandelt
- Erzeugung eines **Inhaltsverzeichnisses**
- **Anker-Links** bei Überschriften

## Anwendungsfälle

- Projektdokumentation schreiben und eine ansprechende PDF für Stakeholder exportieren
- Technische Berichte mit Codebeispielen und Mermaid-Architekturdiagrammen erstellen
- Eine GitHub-README für die Offline-Nutzung oder zum Drucken in eine PDF umwandeln
- Ein Angebot oder eine Spezifikation mit Aufgabenlisten und Tabellen entwerfen
- Aus Vorlesungsnotizen in Markdown ein gestaltetes Handout erzeugen

## Tipps

- Die PDF-Ausgabe nutzt die Funktion "Als PDF drucken" des Browsers. In Chrome können Sie Ränder und Skalierung im Druckdialog vor dem Speichern anpassen.
- Mermaid-Diagramme werden in der Vorschau gerendert, brauchen bei der ersten Nutzung aber eventuell einen Moment zur Initialisierung.
- Nutzen Sie `Ctrl/Cmd + S` als Tastenkürzel zum Exportieren, ohne zur Schaltfläche greifen zu müssen.

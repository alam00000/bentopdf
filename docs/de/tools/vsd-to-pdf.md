# VSD zu PDF

Konvertieren Sie Microsoft-Visio-Diagramme in PDF, ohne Visio zu installieren. VSD- und VSDX-Dateien enthalten Flussdiagramme, Organigramme, Netzwerkdiagramme und Grundrisse, die die meisten Menschen nicht öffnen können. Dieses Tool wandelt sie in saubere PDFs um, die sich auf jedem Gerät ansehen lassen.

## Unterstützte Formate

| Format       | Erweiterung | Hinweise                                   |
| :----------- | :---------- | :----------------------------------------- |
| Visio Binary | `.vsd`      | Altes Visio-Format (Visio 2003 und früher) |
| Visio XML    | `.vsdx`     | Modernes Visio-Format (Visio 2013+)        |

## So funktioniert es

1. Klicken Sie auf den Upload-Bereich oder ziehen Sie Ihre VSD- oder VSDX-Dateien per Drag-and-drop hinein. Beide Formate können in einem Stapel gemischt werden.
2. Prüfen Sie die Dateiliste. Entfernen Sie unerwünschte Einträge mit dem Papierkorb-Symbol oder fügen Sie über **Weitere Dateien hinzufügen** weitere Diagramme hinzu.
3. Klicken Sie auf **In PDF konvertieren**. Die LibreOffice-basierte Engine wird im Browser geladen und wandelt jedes Diagramm in eine PDF um, wobei Formen, Verbinder, Beschriftungen und Seitenlayout erhalten bleiben.
4. Ein einzelnes Diagramm wird direkt als PDF heruntergeladen. Bei mehreren Dateien entsteht ein ZIP-Archiv mit dem Namen `vsd-to-pdf.zip`.

## Optionen

Es ist keine Konfiguration erforderlich. Der Konverter übernimmt Seitengröße und Ausrichtung aus dem Visio-Dokument.

## Anwendungsfälle

- Visio-Diagramme von Kollegen ansehen, wenn Sie keine Visio-Lizenz haben
- Netzwerk- oder Architekturdiagramme als PDF in die Projektdokumentation aufnehmen
- Organigramme oder Prozessabläufe als Handout für Besprechungen drucken
- Alte VSD-Dateien aus früheren Visio-Versionen in einem zukunftssicheren Format archivieren

## Tipps

- Mehrseitige Visio-Dokumente ergeben mehrseitige PDFs, wobei jede Visio-Seite einer PDF-Seite entspricht.
- VSDX-Dateien (das moderne XML-basierte Format) werden im Allgemeinen originalgetreuer konvertiert als ältere binäre VSD-Dateien.
- Die LibreOffice-Engine wird einmal pro Sitzung geladen. Rechnen Sie bei der ersten Konvertierung mit einer kurzen Wartezeit, bei weiteren Dateien geht es schneller.

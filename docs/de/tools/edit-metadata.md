# Metadaten bearbeiten

Bearbeiten Sie die in einer PDF-Datei eingebetteten Metadaten. Das Werkzeug füllt ein Formular mit den vorhandenen Metadaten des Dokuments, lässt Sie jedes Feld ändern und speichert die Änderungen in einer neuen PDF.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch. Das Werkzeug liest ihre aktuellen Metadaten und füllt das Formular.
2. Bearbeiten Sie eines der Standardfelder: Titel, Autor, Betreff, Schlüsselwörter, Ersteller, Producer.
3. Passen Sie Erstellungsdatum und Änderungsdatum mit den Datums- und Zeitauswahlen an.
4. Fügen Sie benutzerdefinierte Metadatenfelder hinzu, indem Sie auf die Hinzufügen-Schaltfläche klicken und ein Schlüssel-Wert-Paar eingeben.
5. Klicken Sie auf die Verarbeitungsschaltfläche, um die geänderte PDF zu speichern.

## Funktionen

- Füllt alle vorhandenen Metadaten der hochgeladenen PDF vorab aus
- Standardfelder: Titel, Autor, Betreff, Schlüsselwörter, Ersteller, Producer
- Datums- und Zeitauswahlen für Erstellungs- und Änderungsdatum
- Benutzerdefinierte Schlüssel-Wert-Metadatenfelder für beliebige Eigenschaften
- Speichert Änderungen direkt im Dokumentinformationswörterbuch der PDF

## Bearbeitbare Felder

| Feld                          | Beschreibung                                                   |
| ----------------------------- | -------------------------------------------------------------- |
| **Titel**                     | Der in PDF-Readern angezeigte Dokumenttitel                    |
| **Autor**                     | Die Person oder Organisation, die das Dokument erstellt hat    |
| **Betreff**                   | Eine kurze Beschreibung des Dokumentthemas                     |
| **Schlüsselwörter**           | Durch Kommas getrennte Begriffe für Suche und Kategorisierung  |
| **Ersteller**                 | Die Anwendung, die den Inhalt ursprünglich erstellt hat        |
| **Produzent**                 | Die Anwendung, die die PDF erzeugt hat                         |
| **Erstellungsdatum**          | Wann das Dokument ursprünglich erstellt wurde                  |
| **Änderungsdatum**            | Wann das Dokument zuletzt geändert wurde                       |
| **Benutzerdefinierte Felder** | Beliebige zusätzliche Schlüssel-Wert-Paare, die Sie definieren |

## Anwendungsfälle

- Einen passenden Titel und Autor festlegen, bevor ein Dokument veröffentlicht wird
- Schlüsselwörter hinzufügen, um die Auffindbarkeit in Dokumentenmanagementsystemen zu verbessern
- Das Änderungsdatum aktualisieren, damit es der aktuellen Überarbeitung entspricht
- Benutzerdefinierte Metadatenfelder wie Abteilung, Projekt-ID oder Klassifizierung hinzufügen
- Metadaten bereinigen, die von der ursprünglichen Autorensoftware hinterlassen wurden

## Tipps

- Benutzerdefinierte Felder werden direkt in das Info-Wörterbuch der PDF geschrieben. Manche PDF-Reader zeigen benutzerdefinierte Felder nicht an, sie bleiben aber in der Datei erhalten.
- Lassen Sie ein Feld leer, um es aus den Metadaten zu löschen. Die Verarbeitungsschaltfläche speichert, was im Formular steht.
- Um Metadaten nur anzusehen, nutzen Sie [Metadaten anzeigen](./view-metadata). Um alle Metadaten vollständig zu entfernen, nutzen Sie Metadaten entfernen.

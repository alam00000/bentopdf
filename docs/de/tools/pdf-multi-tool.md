# PDF-Multitool

Ein einheitlicher Arbeitsbereich für jede Operation auf Seitenebene. Laden Sie ein oder mehrere PDFs hoch und bearbeiten Sie alle Seiten in einem einzigen visuellen Raster. Drehe, ordnen Sie um, dupliziere, lösche, fügen Sie neue PDFs ein, ergänzen Sie Leerseiten und teilen Sie das Ergebnis, alles ohne das Werkzeug zu verlassen.

## So funktioniert es

1. Klicken Sie auf **PDFs hochladen** oder ziehen Sie Dateien auf den Upload-Bereich. Mehrere Dateien werden unterstützt.
2. Alle Seiten aller hochgeladenen Dateien erscheinen mit Vorschaubildern in einem scrollbaren Raster.
3. Bearbeiten Sie Seiten über die Werkzeugleiste oder die Aktionsschaltflächen pro Seite.
4. Wählen Sie Seiten über das Kontrollkästchen auf jeder Karte aus und wende dann Massenoperationen an.
5. Markieren Sie Trennpunkte mit dem Scheren-Symbol, um die Ausgabe in separate Dateien zu teilen.
6. Klicken Sie auf **PDF exportieren**, um das Endergebnis herunterzuladen. Sind Trennmarkierungen vorhanden, ist die Ausgabe ein ZIP mit mehreren PDFs.

## Funktionen

- **Zusammenführen**: Laden Sie mehrere PDFs hoch, sie werden automatisch in einem Arbeitsbereich vereint
- **Neu anordnen**: Ziehen Sie Seitenkarten per Drag-and-drop, um die Reihenfolge zu ändern
- **Drehen**: Drehung pro Seite oder gesammelt in 90-Grad-Schritten (links oder rechts)
- **Duplizieren**: Klonen Sie jede Seite mit einem Klick
- **Löschen**: Entfernen Sie einzelne Seiten oder löschen Sie ausgewählte gesammelt
- **PDF einfügen**: Fügen Sie nach einer bestimmten Seite ein neues PDF hinzu
- **Leere Seite hinzufügen**: Hängen Sie am Ende eine leere A4-Seite an
- **Teilen**: Setzen Sie Trennmarkierungen zwischen Seiten und exportieren Sie dann ein ZIP mit separaten PDFs
- **Alle auswählen / Auswahl aufheben**: Schnelle Auswahl für Massenoperationen
- **Rückgängig / Wiederholen**: Vollständiger Verlauf für jede Operation
- **Auswahl herunterladen**: Exportieren Sie nur die ausgewählten Seiten als eigenständiges PDF
- Repariert beschädigte PDFs automatisch vor dem Laden

## Anwendungsfälle

- Ein eigenes Dokument aus Seiten mehrerer Quell-PDFs zusammenstellen
- Ein gescanntes Dokument bereinigen, indem Sie leere Seiten löschen, seitlich gescannte Seiten drehen und Abschnitte neu ordnen
- Ein großes PDF an Kapitelgrenzen mit visuellen Trennmarkierungen teilen
- Schnelle Bearbeitung auf Seitenebene ohne vollständigen PDF-Editor

## Tipps

- Das Rückgängig/Wiederholen-System erfasst jede Operation. Nutzen Sie es ruhig, Sie können Ihre Arbeit nicht versehentlich zerstören.
- Trennmarkierungen erscheinen als gestrichelte blaue Linien zwischen Seiten. Setzen Sie sie visuell dort, wo das Dokument geteilt werden soll, und exportieren Sie dann ein ZIP.
- Für einfaches Zusammenführen oder Teilen sind die eigenen Werkzeuge [PDF zusammenführen](./merge-pdf) oder [PDF teilen](./split-pdf) möglicherweise schneller. Das Multi-Werkzeug zeigt seine Stärke, wenn Sie in einer Sitzung mehrere Operationen brauchen.

# PDF-Multitool

Ein einheitlicher Arbeitsbereich für jede PDF-Operation auf Seitenebene. Laden Sie ein oder mehrere PDFs hoch und bearbeiten Sie alle Seiten in einem einzigen visuellen Raster. Drehen Sie Seiten, ordnen Sie sie neu an, duplizieren oder löschen Sie sie, fügen Sie PDFs, Bilder und leere Seiten ein, vergeben Sie neue Seitennummern, ändern Sie die Seitengröße und teilen Sie das Ergebnis, alles ohne das Werkzeug zu verlassen.

## So funktioniert es

1. Klicken Sie auf **Dateien auswählen** oder ziehen Sie Dateien auf den Upload-Bereich. Mehrere Dateien werden unterstützt und in der Reihenfolge des Hochladens zusammengeführt.
2. Alle Seiten erscheinen mit Vorschaubildern in einem scrollbaren Raster.
3. Klicken Sie auf eine Seite, um sie auszuwählen. Mit Shift-Klick wählen Sie einen Bereich aus, mit Cmd/Ctrl-Klick fügen Sie einzelne Seiten zur Auswahl hinzu oder entfernen sie daraus.
4. Nutzen Sie die Werkzeugleiste des Organizers oder klicken Sie mit der rechten Maustaste auf eine Seite, um die Seitenaktionen aufzurufen.
5. Klicken Sie auf **PDF exportieren**, um das Endergebnis herunterzuladen.

## Funktionen

- **Zusammenführen**: Laden Sie mehrere PDFs und Bilder hoch, sie werden automatisch zu einem Dokument vereint
- **Neu anordnen**: Ordnen Sie Seiten per Drag-and-drop neu an oder kehren Sie die Reihenfolge des gesamten Dokuments um
- **Drehen**: Drehen Sie ausgewählte Seiten in 90-Grad-Schritten nach links oder rechts
- **Duplizieren**: Kopieren Sie ausgewählte Seiten und fügen Sie die Kopien direkt dahinter ein
- **Löschen**: Entfernen Sie die ausgewählten Seiten
- **Einfügen**: Fügen Sie Seiten aus einem anderen PDF oder Bild, eine leere Seite oder Seiten aus der Zwischenablage ein, oder mischen Sie die Seiten eines zweiten PDFs abwechselnd mit den vorhandenen
- **Ersetzen**: Tauschen Sie eine Seite gegen die erste Seite eines anderen PDFs aus
- **Ausschneiden, Kopieren und Einfügen**: Verschieben oder kopieren Sie Seiten innerhalb des Dokuments
- **Extrahieren**: Laden Sie die ausgewählten Seiten als PDF oder als Bilder herunter
- **Seitenzahlen**: Legen Sie für einen Seitenbereich Seitenbeschriftungen wie i, ii, iii oder A-1, A-2 fest
- **Seitengröße**: Passen Sie Seiten an ein Standardpapierformat oder eine benutzerdefinierte Größe an
- **Teilen**: Teilen Sie das Dokument nach Seitenbereichen, ungeraden und geraden Seiten, jeder einzelnen Seite, Lesezeichen, jeweils N Seiten oder Dateigröße
- **Rückgängig / Wiederholen**: Jede Seitenoperation lässt sich rückgängig machen und wiederholen
- Repariert beschädigte PDFs automatisch vor dem Laden

## Tastenkürzel

| Aktion                           | Tastenkürzel                  |
| -------------------------------- | ----------------------------- |
| Nach rechts / links drehen       | R / Shift+R                   |
| Alles auswählen                  | Cmd/Ctrl+A                    |
| Ausschneiden, Kopieren, Einfügen | Cmd/Ctrl+X, C, V              |
| Duplizieren                      | Cmd/Ctrl+D                    |
| Löschen                          | Entf oder Rücktaste           |
| Rückgängig / Wiederholen         | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| Auswahl verschieben              | Pfeiltasten, Home, End        |

## Anwendungsfälle

- Ein eigenes Dokument aus Seiten mehrerer Quell-PDFs zusammenstellen
- Ein gescanntes Dokument bereinigen, indem Sie leere Seiten löschen, seitlich gescannte Seiten drehen und Abschnitte neu ordnen
- Ein großes PDF anhand seiner Lesezeichen an Kapitelgrenzen teilen
- Schnelle Bearbeitung auf Seitenebene ohne vollständigen PDF-Editor

## Tipps

- Der Verlauf für Rückgängig/Wiederholen erfasst jede Seitenoperation. Nutzen Sie ihn ruhig, Sie können Ihre Arbeit nicht versehentlich zerstören.
- Mit **Insert > From File** können Sie jederzeit weitere PDFs oder Bilder zum Dokument hinzufügen, oder Sie ziehen sie einfach auf das Seitenraster.
- Für einfaches Zusammenführen oder Teilen sind die eigenen Werkzeuge [PDF zusammenführen](./merge-pdf) oder [PDF teilen](./split-pdf) möglicherweise schneller. Das Multitool zeigt seine Stärke, wenn Sie in einer Sitzung mehrere Operationen brauchen.

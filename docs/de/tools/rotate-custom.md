# Um benutzerdefinierte Grad drehen

Drehen Sie PDF-Seiten um einen beliebigen Winkel, nicht nur in 90-Grad-Schritten. Jede Seite hat ein eigenes Winkelfeld, und mit der Stapelsteuerung können Sie einen einzelnen Winkel auf alle Seiten gleichzeitig anwenden.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch. Für jede Seite werden Vorschaubilder erzeugt.
2. Jede Seite hat ein numerisches Eingabefeld mit ihrem aktuellen Drehwinkel.
3. Geben Sie einen beliebigen Gradwert (positiv oder negativ) ein, um eine bestimmte Seite zu drehen, oder nutzen Sie die Links-/Rechts-Schaltflächen pro Seite für schnelle 90-Grad-Anpassungen.
4. Nutzen Sie das Feld **Stapelwinkel** oben, um eine einheitliche Drehung für alle Seiten festzulegen.
5. Klicken Sie auf die Schaltfläche zum Verarbeiten, um die gedrehte PDF zu erzeugen.

## Funktionen

- Freie Gradeingabe pro Seite (beliebiger ganzzahliger Wert)
- Stapelwinkel, um dieselbe Drehung auf jede Seite anzuwenden
- Echtzeit-Vorschau der Drehung in den Vorschaubildern
- Schnelldreh-Schaltflächen pro Seite für 90-Grad-Schritte
- Vorschaubilder werden bei Bedarf geladen, für gute Leistung bei großen Dokumenten

## Anwendungsfälle

- Leicht schiefe Scans um wenige Grad korrigieren
- Seiten drehen, um eine nicht standardmäßige Ausrichtung zu erfüllen
- Einzelne Seiten in einem Dokument mit gemischten Inhalten präzise drehen
- Seitenwinkel nach einer ersten Stapeldrehung feinjustieren

## Tipps

- Positive Werte drehen im Uhrzeigersinn, negative gegen den Uhrzeigersinn.
- Das Feld Stapelwinkel überschreibt beim Anwenden alle Winkel der einzelnen Seiten. Nimm einzelne Anpassungen bei Bedarf nach dem Stapelvorgang vor.
- Für Standarddrehungen um 90/180/270 Grad mit einfacherer Oberfläche nutze [PDF drehen](./rotate-pdf).

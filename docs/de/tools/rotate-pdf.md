# PDF drehen

Drehen Sie Seiten einer PDF um 90 Grad im oder gegen den Uhrzeigersinn. Das Werkzeug zeigt Vorschaubilder jeder Seite, sodass Sie sie einzeln drehen oder eine Stapeldrehung auf das gesamte Dokument anwenden können.

## So funktioniert es

1. Laden Sie eine PDF-Datei hoch. Die Vorschaubilder aller Seiten werden in einem Raster dargestellt.
2. Nutzen Sie die Dreh-Schaltflächen links/rechts unter jedem Vorschaubild, um genau diese Seite zu drehen.
3. Nutzen Sie die Stapeldrehung oben, um alle Seiten auf einmal zu drehen.
4. Die Vorschaubilder werden in Echtzeit aktualisiert und zeigen die Drehung.
5. Klicken Sie auf die Schaltfläche zum Verarbeiten, um die gedrehte PDF zu speichern.

## Funktionen

- Drehung pro Seite in 90-Grad-Schritten (links oder rechts)
- Stapeldrehung für alle Seiten gleichzeitig
- Echtzeit-Vorschau mit animierten Drehübergängen
- Vorschaubilder werden bei Bedarf geladen, für flüssige Leistung bei großen Dokumenten
- Erhält Seiteninhalt und Qualität des Originals

## Anwendungsfälle

- Seitlich oder auf dem Kopf gescannte Seiten korrigieren
- Querformatseiten ins Hochformat drehen (oder umgekehrt)
- Ein Dokument mit gemischter Ausrichtung korrigieren, in dem manche Seiten im falschen Winkel gescannt wurden
- Ein Dokument für eine bestimmte Anzeigeausrichtung vorbereiten

## Tipps

- Drehungen summieren sich. Zweimal auf die Schaltfläche im Uhrzeigersinn zu klicken ergibt eine Drehung um 180 Grad.
- Für Drehungen, die keine Vielfachen von 90 Grad sind (z. B. 45 Grad, um einen leicht schiefen Scan zu korrigieren), nutzen Sie stattdessen [Um benutzerdefinierte Grad drehen](./rotate-custom).
- Die Stapeldrehung betrifft alle Seiten, nicht nur ausgewählte. In diesem Werkzeug gibt es keine Auswahl. Dafür nutze das [PDF-Multitool](./pdf-multi-tool).

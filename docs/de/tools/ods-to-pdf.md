# ODS zu PDF

Wandeln Sie OpenDocument-Tabellen in PDF um. ODS ist das native Format von LibreOffice Calc und ein häufiger Export aus Google Sheets. Dieses Werkzeug rendert Ihre Tabellendaten, Formatierungen und Diagramme in ein seitenweise aufgeteiltes PDF, das Sie drucken oder teilen können.

## Unterstützte Formate

| Format                   | Endung | Hinweise                                    |
| :----------------------- | :----- | :------------------------------------------ |
| OpenDocument Spreadsheet | `.ods` | Export aus LibreOffice Calc / Google Sheets |

## So funktioniert es

1. Klicken Sie auf den Upload-Bereich oder ziehen Sie Ihre ODS-Dateien per Drag-and-drop hinein. Mehrere Dateien werden unterstützt.
2. Prüfen Sie die Dateiliste. Mit dem Papierkorb-Symbol entfernen Sie Dateien, mit **Weitere Dateien hinzufügen** erweitern Sie den Stapel.
3. Klicken Sie auf **In PDF umwandeln**. Die auf LibreOffice basierende Engine wird im Browser geladen und rendert jede Tabelle in PDF-Seiten.
4. Eine einzelne Tabelle wird als PDF heruntergeladen. Mehrere Dateien werden in `ods-to-pdf.zip` gepackt.

## Optionen

Es ist keine Konfiguration nötig. Der Konverter übernimmt das vorhandene Drucklayout, die Zellformatierung und die Spaltenbreiten der Tabelle in die PDF-Ausgabe.

## Anwendungsfälle

- Ein Budget oder einen Bericht aus LibreOffice Calc mit jemandem teilen, der nur PDFs akzeptiert
- Einen als ODS heruntergeladenen Google-Sheets-Export drucken
- Finanzunterlagen in einem nicht bearbeitbaren Format archivieren
- ODS-basierte Formulare oder Stundenzettel als Dokumente mit festem Layout einreichen

## Tipps

- Wenn Ihre Tabelle mehrere Blätter hat, werden alle Blätter in die PDF-Ausgabe übernommen.
- Sehr breite Tabellen können horizontal über mehrere PDF-Seiten laufen. Passen Sie die Spaltenbreiten in der Quelldatei vor der Umwandlung an, wenn das Layout wichtig ist.
- Die LibreOffice-Engine wird bei der ersten Nutzung initialisiert. Weitere Umwandlungen in derselben Sitzung sind schneller.

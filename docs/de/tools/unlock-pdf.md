# PDF entsperren

Wenn Sie das Passwort einer verschlüsselten PDF kennen, entfernt dieses Tool die Verschlüsselung vollständig und erzeugt eine entsperrte Kopie, die jeder ohne Zugangsdaten öffnen kann. Es unterstützt die Stapelentschlüsselung, wenn mehrere PDFs dasselbe Passwort haben.

## So funktioniert es

1. Laden Sie eine oder mehrere verschlüsselte PDF-Dateien hoch.
2. Geben Sie das **Passwort** ein, mit dem die Dateien geschützt wurden.
3. Klicken Sie auf **PDF entschlüsseln**.
4. Eine einzelne Datei wird direkt heruntergeladen. Bei mehreren Dateien entsteht ein ZIP-Archiv mit allen entsperrten PDFs.

## Funktionen

- Entschlüsselung einzelner Dateien und im Stapel
- Unterstützt Benutzer- und Besitzerpasswörter
- Erzeugt eine vollständig unverschlüsselte Ausgabe ohne verbleibende Einschränkungen
- Klare Fehlermeldungen bei falschen Passwörtern oder beschädigten Dateien
- Erfolg und Fehler werden im Stapelmodus pro Datei erfasst

## Unterschied zu „Beschränkungen entfernen“

**PDF entschlüsseln** erfordert das Passwort und entfernt die gesamte Verschlüsselung. **Beschränkungen entfernen** zielt auf Nutzungsbeschränkungen (Drucken, Kopieren, Bearbeiten) ab und benötigt möglicherweise kein Passwort, wenn nur ein Besitzerpasswort gesetzt wurde. Verwenden Sie „Entschlüsseln“, wenn sich die PDF ohne Passwort gar nicht öffnen lässt.

## Anwendungsfälle

- Von Ihnen früher verschlüsselte PDFs dauerhaft entsperren, wenn das Passwort nicht mehr gebraucht wird
- Die Verschlüsselung eines Stapels archivierter Dokumente entfernen, um den Langzeitzugriff zu erleichtern
- Passwortgeschützte PDFs für ein Dokumentenmanagementsystem vorbereiten, das keine verschlüsselten Dateien unterstützt
- PDFs entsperren, bevor Sie sie mit anderen Dokumenten zusammenfügen (viele Tools zum Zusammenfügen können verschlüsselte Eingaben nicht verarbeiten)

## Tipps

- Das Passwortfeld gilt für alle hochgeladenen Dateien. Wenn Ihre PDFs unterschiedliche Passwörter haben, verarbeiten Sie sie in getrennten Stapeln.
- Wenn die Fehlermeldung „Falsches Passwort“ erscheint, prüfen Sie auf Leerzeichen am Ende oder eine aktivierte Feststelltaste.
- Nach der Entschlüsselung hat die Ausgabe keinerlei Schutz. Verschlüsseln Sie sie mit „PDF verschlüsseln“ erneut, wenn Sie ein neues Passwort vergeben möchten.

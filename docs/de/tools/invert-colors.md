# Farben invertieren

Kehren Sie jede Farbe Ihrer PDF ins Gegenteil um. Weiße Hintergründe werden schwarz, schwarzer Text wird weiß und alle anderen Farben wechseln zu ihren Komplementärwerten. So erstellen Sie am schnellsten eine "Dark-Mode"-Version jeder PDF.

## So funktioniert es

1. Laden Sie Ihre PDF-Datei hoch.
2. Klicken Sie zum Verarbeiten auf **Farben invertieren**.
3. Die invertierte PDF wird automatisch heruntergeladen.

Es gibt keine weiteren Einstellungen. Das Werkzeug rendert jede Seite als Bild, invertiert alle Pixelfarben und setzt das Ergebnis zu einer neuen PDF zusammen.

## Funktionen

- Farbinvertierung per Klick für alle Seiten
- Verarbeitet jede Seite des Dokuments
- Behält Seitenmaße und Layout des Originals bei
- Funktioniert mit jeder PDF, unabhängig vom Inhalt (Text, Bilder, gemischt)

## Anwendungsfälle

- Dark-Mode-Versionen von Lehrbüchern oder Handbüchern für angenehmes Lesen bei Nacht erstellen
- Kontrastreiche Versionen von Dokumenten für die Barrierefreiheit vorbereiten
- Gescannte Dokumente invertieren, die mit falscher Belichtung erfasst wurden
- Negativversionen bildlastiger PDFs für die visuelle Analyse erzeugen

## Tipps

- Da das Werkzeug die Seiten rastert, um den Effekt anzuwenden, ist die Ausgabe bildbasiert. Text ist danach nicht mehr auswählbar oder durchsuchbar. Wenn Sie nach dem Invertieren durchsuchbaren Text brauchen, schicken Sie das Ergebnis durch ein OCR-Werkzeug.
- Für feinere Farbanpassungen (Helligkeit, Kontrast, Sättigung) nutzen Sie stattdessen das Werkzeug [Farben anpassen](./adjust-colors).
- Große PDFs mit vielen Seiten können länger dauern, da jede Seite einzeln gerendert und invertiert wird.

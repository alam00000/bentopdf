# Seiten umkehren

Kehren Sie die Seitenreihenfolge einer PDF um, sodass die letzte Seite zur ersten wird, die vorletzte zur zweiten und so weiter. Unterstützt die Stapelverarbeitung mehrerer Dateien gleichzeitig.

## So funktioniert es

1. Laden Sie eine oder mehrere PDF-Dateien hoch.
2. Klicken Sie auf die Schaltfläche zum Verarbeiten.
3. Jede Datei wird unabhängig umgekehrt. Wenn Sie mehrere Dateien hochgeladen haben, ist die Ausgabe ein ZIP-Archiv mit allen umgekehrten PDFs.
4. Eine einzelne Datei wird direkt als umgekehrte PDF heruntergeladen.

## Funktionen

- Stapelverarbeitung: mehrere PDFs in einem Vorgang umkehren
- Einzeldatei-Ausgabe bei einer PDF, ZIP-Ausgabe bei mehreren
- Schaltflächen zum Entfernen einzelner Dateien vor der Verarbeitung
- Erhält alle Seiteninhalte und die Formatierung

## Anwendungsfälle

- Ein Dokument korrigieren, das in umgekehrter Reihenfolge gescannt wurde
- Eine Präsentations-PDF so vorbereiten, dass sie von hinten nach vorn gelesen wird
- Die Seitenreihenfolge für bestimmte Druckabläufe umkehren, die Seiten rückwärts einziehen
- Ein Dokument korrigieren, dessen Seiten versehentlich verkehrt herum zusammengestellt wurden

## Tipps

- Jede Datei in einem Stapel wird unabhängig umgekehrt. Die Dateien selbst werden untereinander nicht neu angeordnet.
- Für eine feinere Neuordnung der Seiten (nicht nur eine vollständige Umkehrung) nutze [Duplizieren & Organisieren](./organize-pdf).

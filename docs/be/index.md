## OCR па-за сеткай

Калі вы размяшчаеце BentoPDF у ізаляваным або аўтаномным асяроддзі, для OCR патрэбны не толькі воркер Tesseract і файлы traineddata. Для PDF з магчымасцю пошуку таксама трэба раздаваць шрыфты тэкставага слоя OCR унутры сеткі.
Глядзіце [Уласнае размяшчэнне](/be/self-hosting/), каб даведацца пра поўную наладку, уключаючы `VITE_OCR_FONT_BASE_URL`, убудаваны каталог `ocr-fonts/` і абноўлены працэс для ізаляваных сетак.

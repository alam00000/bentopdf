# SVG у PDF

Пераўтварайце файлы Scalable Vector Graphics (SVG) у PDF. Інструмент растарызуе кожны SVG рухавіком адмалёўкі браўзера, а потым убудоўвае вынік у родным разрозненні. Зручна, каб ператварыць вектарныя значкі, дыяграмы і ілюстрацыі ў партатыўныя дакументы.

## Падтрымліваемыя фарматы

| Фармат | Пашырэнні |
| :----- | :-------- |
| SVG    | `.svg`    |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце адзін або некалькі файлаў SVG.
2. Праверце спіс файлаў і кіруйце ім.
3. Выберыце ўзровень **Якасць PDF**.
4. Націсніце **Канвертаваць у PDF**. Вынік спампоўваецца як `from_svgs.pdf`.

Кожны SVG чытаецца як тэкст, адмалёўваецца на палатне ў яго ўласнай шырыні і вышыні (800x600 па змаўчанні, калі памеры не зададзены) і экспартуецца ў PNG. Затым гэты PNG убудоўваецца ў PDF з дапамогай pdf-lib. Празрыстыя вобласці запаўняюцца белым фонам.

## Параметры

**Якасць PDF** кіруе сцісканнем пасля растарызацыі:

- **Высокая якасць**: найбліжэй да арыгінальнай адмалёўкі.
- **Сярэдняя якасць** (па змаўчанні): добры баланс.
- **Нізкая якасць**: найменшы файл, частковая страта дэталяў.

## Сцэнарыі выкарыстання

- Пераўтварэнне архітэктурных або інжынерных дыяграм з SVG у PDF, гатовы да друку
- Упакоўка набораў значкоў у даведачны PDF для дызайн-сістэмы
- Ператварэнне візуалізацый даных (D3.js, экспарт бібліятэк дыяграм) у PDF для справаздач
- Стварэнне версій інфаграфікі на аснове SVG для друку

## Парады

- Файлы SVG без яўных атрыбутаў `width` і `height` адмалёўваюцца ў памеры 800x600 пікселяў. Для найлепшага выніку задайце памеры ў зыходным SVG перад пераўтварэннем.
- Складаныя SVG са спасылкамі на знешнія шрыфты або звязаныя відарысы могуць адмалёўвацца не ідэальна. Убудуйце ўсе рэсурсы ў SVG для надзейнага выніку.
- Паколькі SVG растарызуецца, PDF будзе змяшчаць растравы відарыс, а не вектарныя контуры. Для сапраўднага вектарнага PDF патрэбны спецыяльны вектарны інструмент.

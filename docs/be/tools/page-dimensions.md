# Памеры старонкі

Дыягнастычны інструмент, які чытае кожную старонку PDF і паказвае яе дакладныя памеры, арыентацыю, назву стандартнага фармату, суадносіны бакоў, плошчу і паварот. Карысны, каб заўважыць старонкі розных памераў перад друкам або задакументаваць уласцівасці атрыманага PDF.

## Як гэта працуе

1. Загрузіце файл PDF. Аналіз пачынаецца аўтаматычна, націскаць кнопку не трэба.
2. Панэль зводкі паказвае колькасць старонак, колькасць унікальных памераў і ці ёсць у дакуменце змешаныя памеры.
3. Праглядзіце поўную табліцу вынікаў з падрабязнасцямі па кожнай старонцы.
4. Пераключайце адзінкі паміж пунктамі, цалямі, міліметрамі і пікселямі.
5. Націсніце **Экспарт у CSV**, каб захаваць даныя.

## Палі справаздачы

| Слупок            | Апісанне                                          |
| ----------------- | ------------------------------------------------- |
| Старонка №        | Паслядоўны нумар старонкі                         |
| Памеры            | Шырыня x Вышыня ў выбраных адзінках               |
| Стандартны фармат | Знойдзеная назва (A4, Letter і г.д.) або «Уласны» |
| Арыентацыя        | Кніжная або альбомная                             |
| Суадносіны бакоў  | Адносіны шырыні да вышыні ў выглядзе дробу        |
| Плошча            | Плошча старонкі ў квадратных выбраных адзінках    |
| Паварот           | Паварот старонкі ў градусах                       |

## Магчымасці

- Аўтаматычнае вызначэнне стандартных фарматаў паперы (A3, A4, A5, Letter, Legal, Tabloid і іншыя)
- Папярэджанне пра змешаныя памеры з разбіўкай, якія памеры ёсць і колькі старонак кожнага
- Пераўтварэнне адзінак паміж пунктамі, цалямі, міліметрамі і пікселямі (пры 96 PPI)
- Экспарт у CSV для электронных табліц або сістэм дакументацыі

## Сцэнарыі выкарыстання

- Праверка, што ўсе старонкі A4, перад адпраўкай дакумента ў друкарню
- Высвятленне, чаму аб'яднаны PDF друкуецца з нечаканымі палямі на некаторых старонках
- Дакументаванне макета старонак вялікага архіва PDF для запісаў метаданых
- Пошук павернутых старонак, якія трэба выправіць

## Парады

- Калі зводка паказвае «Змешаныя памеры», выкарыстайце інструмент «Уніфікаваць памер старонак» перад друкам.
- Поле павароту дапамагае знайсці старонкі, якія адлюстроўваюцца правільна, але маюць ненулявы атрыбут павароту, што можа выклікаць праблемы ў некаторых працэсах.

# PDF у WebP

Пераўтварае кожную старонку PDF у відарыс WebP. Пры той жа ўспрымаемай якасці WebP звычайна дае файлы на 25-35% меншыя за JPG, таму гэта добры выбар для вэба.

## Як гэта працуе

1. Загрузіце PDF, націснуўшы на вобласць загрузкі або перацягнуўшы туды файл.
2. Наладзьце паўзунок **Якасць**.
3. Націсніце **Пераўтварыць**, каб апрацаваць файл.
4. Адзін файл `.webp` або архіў ZIP спампуецца аўтаматычна.

## Налады

- **Якасць**: паўзунок ад 0% да 100% (па змаўчанні 85%). Кіруе ўзроўнем сціскання са стратамі. Большыя значэнні захоўваюць больш дэталяў.

Унутры старонкі рэндэрацца з маштабам 2x, таму відарысы прыкладна ўдвая большыя за ўласныя памеры PDF.

## Фармат выніку

- **Адна старонка**: `filename.webp`
- **Некалькі старонак**: `filename_webps.zip` з `page_1.webp`, `page_2.webp` і г.д.

## Сцэнарыі выкарыстання

- Падрыхтоўка праглядаў старонак для сайтаў, дзе важны трафік.
- Стварэнне лёгкіх версій улётак або брашур для сацыяльных сетак.
- Пакетнае пераўтварэнне шматстаронкавых дакументаў у набор відарысаў, аптымізаваных для вэба.

## Парады

- WebP падтрымліваецца ва ўсіх сучасных браўзерах. Для сумяшчальнасці са старымі сістэмамі выкарыстайце [PDF у JPG](./pdf-to-jpg).
- Якасць 80-85% на экране звычайна не адрозніць ад арыгінала, а памер файлаў застаецца малым.

# Зрабіць лінейны PDF

Лінеарызацыя перабудоўвае PDF так, каб першую старонку можна было паказаць да таго, як спампуецца ўвесь файл. Adobe называе гэта «Fast Web View». Калі вы размяшчаеце PDF на сайце або раздаяце іх праз партал дакументаў, лінеарызацыя робіць іх адкрыццё значна хутчэйшым.

## Як гэта працуе

1. Запампуйце адзін або некалькі файлаў PDF.
2. Націсніце **Лінеарызаваць PDF**.
3. Спампуйце вынікі ў архіве ZIP з усімі лінеарызаванымі файламі.

Наладжваць нічога не трэба. Інструмент выкарыстоўвае сцяг `--linearize` QPDF, які перабудоўвае ўнутраную структуру PDF, не змяняючы яго выгляду.

## Што робіць лінеарызацыя

- Пераўпарадкоўвае аб'екты PDF так, каб даныя першай старонкі былі ў пачатку файла
- Дадае слоўнік лінеарызацыі і табліцы падказак, каб праглядальнікі ведалі, дзе знаходзіцца кожная старонка
- Дазваляе запыты дыяпазонаў байтаў: браўзер можа атрымаць толькі першую старонку без спампоўвання ўсяго файла
- Упарадкоўвае табліцу перакрыжаваных спасылак для эфектыўнага адвольнага доступу

## Магчымасці

- Пакетная апрацоўка некалькіх PDF за адну аперацыю
- Вынік захоўвае ўсё змесціва, шрыфты, відарысы і інтэрактыўныя элементы
- Выкарыстоўвае QPDF (WebAssembly) для надзейнай лінеарызацыі ў адпаведнасці са стандартамі
- Вынікі пакуюцца ў ZIP для зручнага спампоўвання

## Сцэнарыі выкарыстання

- Размяшчэнне справаздач PDF на сайце, дзе карыстальнікі чакаюць імгненнага паказу старонак
- Убудоўванне PDF у вэб-праграмы з праглядальнікамі ў браўзеры
- Публікацыя каталогаў або інструкцый PDF, якія адкрываюць праз павольнае мабільнае злучэнне
- Падрыхтоўка дакументаў для сетак дастаўкі кантэнту (CDN) з падтрымкай дыяпазонаў байтаў

## Парады

- Лінеарызуйце пасля ўсіх іншых правак. Любая наступная змена (аб'яднанне, даданне старонак) парушыць лінеарызацыю.
- Спалучайце з інструментам «Сціснуць PDF», каб атрымаць найменшыя і найхутчэйшыя PDF.
- Лінеарызацыя крыху павялічвае памер файла (звычайна менш за 1%).

# Пераўтварыць у постэр

Дзяліце кожную старонку PDF на сетку меншых падстаронак. Гэты інструмент дазваляе надрукаваць адну старонку на некалькіх аркушах паперы, якія потым складаюцца разам у вялікі постэр або банер.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Задайце колькасць **радкоў** і **слупкоў** сеткі (напрыклад, 2 радкі x 2 слупкі дзеляць кожную старонку на 4 падстаронкі).
3. Пры жаданні ўкажыце дыяпазон старонак, каб абмежаваць, якія старонкі будуць апрацаваны.
4. Палатно папярэдняга прагляду паказвае сетку на бягучай старонцы, каб вы бачылі лініі разрэзу.
5. Пераключайцеся паміж старонкамі, каб праверыць сетку на розных старонках.
6. Націсніце кнопку апрацоўкі. Кожная ячэйка сеткі становіцца асобнай старонкай у выніковым PDF.

## Магчымасці

- Наладжвальная колькасць радкоў і слупкоў для гнуткага памеру сеткі
- Жывы папярэдні прагляд з сеткай, якая дакладна паказвае, дзе будуць падзелены старонкі
- Фільтр дыяпазону старонак, каб апрацаваць толькі пэўныя старонкі
- Пастаронкавая навігацыя ў папярэднім праглядзе
- Кэшаваныя здымкі старонак для хуткай навігацыі
- Чырвоныя пункцірныя лініі сеткі выразна адзначаюць межы разрэзу

## Параметры

| Параметр              | Апісанне                                             |
| --------------------- | ---------------------------------------------------- |
| **Радкі**             | Колькасць гарызантальных дзяленняў (па змаўчанні: 1) |
| **Слупкі**            | Колькасць вертыкальных дзяленняў (па змаўчанні: 1)   |
| **Дыяпазон старонак** | Якія старонкі апрацаваць (пуста = усе старонкі)      |

## Сцэнарыі выкарыстання

- Друк PDF памеру постэра на стандартных аркушах A4 або Letter для зборкі на сцяне
- Стварэнне вялікіх банераў з аднастаронкавага дызайну PDF
- Падзел вялікіх тэхнічных чарцяжоў на фрагменты для друку
- Друк вялікага фармату без шырокафарматнага прынтара

## Парады

- Сетка 2x2 ператварае адну старонку ў 4. Сетка 3x3 ператварае адну старонку ў 9. Плануйце сетку ў залежнасці ад жаданага памеру сабранага выніку.
- Сетка ў папярэднім праглядзе дапамагае пераканацца, што важны змест не трапляе на лінію разрэзу. Пры неабходнасці змяніце радкі або слупкі.
- Для адваротнай аперацыі (размяшчэнне некалькіх старонак на адным аркушы) выкарыстоўвайце [N-Up PDF](./n-up-pdf).

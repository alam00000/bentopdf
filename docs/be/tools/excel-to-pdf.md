# Excel у PDF

Пераўтварайце файлы электронных табліц у PDF. Інструмент апрацоўвае сучасныя файлы Excel, стары фармат XLS, электронныя табліцы OpenDocument і нават CSV, і ўсё гэта праз рухавік LibreOffice у браўзеры, які захоўвае фарматаванне ячэек, формулы (як вылічаныя значэнні), дыяграмы і макеты з некалькімі аркушамі.

## Падтрымліваемыя фарматы

| Фармат                           | Пашырэнні |
| :------------------------------- | :-------- |
| Excel (сучасны)                  | `.xlsx`   |
| Excel (стары)                    | `.xls`    |
| Электронная табліца OpenDocument | `.ods`    |
| CSV                              | `.csv`    |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце файлы электронных табліц.
2. Праверце спіс файлаў. Дадайце яшчэ файлы або выдаліце непатрэбныя.
3. Націсніце **Пераўтварыць у PDF**. Рухавік LibreOffice ініцыялізуецца пры першым выкарыстанні, а потым апрацоўвае кожны файл.
4. Адзін файл спампоўваецца непасрэдна як PDF. Некалькі файлаў перадаюцца як `excel-converted.zip`.

## Параметры

У гэтага інструмента няма дадатковых налад. Рухавік LibreOffice вызначае макет старонкі, маштаб і вобласць друку паводле ўбудаваных налад электроннай табліцы.

## Вынік

| Колькасць файлаў | Вынік                                                                  |
| :--------------- | :--------------------------------------------------------------------- |
| 1 файл           | Спампоўванне аднаго PDF (арыгінальная назва файла з пашырэннем `.pdf`) |
| 2+ файлы         | Архіў ZIP (`excel-converted.zip`) з адным PDF на кожны файл            |

## Сцэнарыі выкарыстання

- Пераўтварэнне фінансавых справаздач або бюджэтаў з Excel у PDF для распаўсюджвання
- Стварэнне гатовых да друку PDF з табліц запасаў або каталогаў прадукцыі
- Абмен вынікамі аналізу даных з зацікаўленымі асобамі, у якіх не ўсталяваны Excel
- Архіваванне квартальных справаздач у фармаце, які нельга рэдагаваць
- Пераўтварэнне файлаў ODS з LibreOffice Calc у PDF

## Парады

- Дыяграмы, убудаваныя ў электронную табліцу, выводзяцца ў PDF. Перад пераўтварэннем пераканайцеся, што яны правільна выглядаюць у зыходным файле.
- Калі ў электроннай табліцы некалькі аркушаў, усе яны ўключаюцца ў PDF.
- Для простых даных CSV без фарматавання інструмент [CSV у PDF](./csv-to-pdf) дае больш лёгкае пераўтварэнне. Выкарыстоўвайце Excel у PDF, калі трэба захаваць фарматаванне, дыяграмы або некалькі аркушаў.

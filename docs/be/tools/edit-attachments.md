# Рэдагаваць далучэнні

Праглядайце і кіруйце далучанымі файламі ўнутры PDF. Інструмент паказвае кожны ўбудаваны файл з назвай і ўзроўнем далучэння, а потым дазваляе пазначыць асобныя далучэнні для выдалення або выдаліць іх усе адразу.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Інструмент аўтаматычна шукае далучэнні і паказвае іх спісам.
3. Для кожнага далучэння паказваецца назва файла і тое, ці далучана яно да дакумента або да старонкі.
4. Націсніце значок кошыка побач з далучэннем, каб пазначыць яго для выдалення (націсніце яшчэ раз, каб зняць пазнаку).
5. Карыстайцеся кнопкай **Выдаліць усе далучэнні**, каб выбраць усё адразу, або **Зняць выбар з усіх**, каб ачысціць выбар.
6. Націсніце кнопку апрацоўкі, каб захаваць новы PDF без выбраных далучэнняў.

## Магчымасці

- Спіс усіх далучэнняў на ўзроўні дакумента і старонак
- Выдаленне далучэнняў па адным або ўсіх разам
- Уключэнне і выключэнне выбару перад захаваннем змен
- Пазначаныя для выдалення элементы закрэсліваюцца і становяцца паўпразрыстымі
- Спампоўванне змененага PDF без выбраных далучэнняў

## Сцэнарыі выкарыстання

- Выдаленне састарэлых або памылковых файлаў, убудаваных у дакумент, перад паўторным распаўсюджваннем
- Выдаленне канфідэнцыйных далучэнняў (фінансавыя даныя, асабістая інфармацыя) з PDF перад абменам
- Памяншэнне памеру PDF за кошт выдалення вялікіх убудаваных файлаў, якія больш не патрэбныя
- Аўдыт убудаванага змесціва і ачыстка дакумента перад архіваваннем

## Парады

- Пазначаныя для выдалення далучэнні паказваюцца закрэсленымі. Калі перадумаеце, можна вярнуць іх перад апрацоўкай.
- Калі далучэнні не знойдзены, інструмент паказвае паведамленне «Далучэнні не знойдзены»: PDF проста не ўтрымлівае ўбудаваных файлаў.

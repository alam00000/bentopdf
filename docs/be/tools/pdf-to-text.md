# PDF у тэкст

Вымае ўвесь тэкст з файлаў PDF і захоўвае яго як простыя файлы `.txt`. Падтрымліваецца пакетная апрацоўка: загрузіце некалькі PDF і атрымайце тэкст кожнага за адну аперацыю. Працуе на PyMuPDF.

## Як гэта працуе

1. Загрузіце адзін ці некалькі PDF, націснуўшы на вобласць загрузкі або перацягнуўшы туды файлы. Кіруйце спісам файлаў кнопкамі «Дадаць яшчэ» і «Ачысціць».
2. Націсніце **Выняць**, каб пачаць апрацоўку.
3. Адзін файл спампоўваецца як `filename.txt`. Некалькі файлаў даюць архіў `pdf-to-text.zip`.

## Налады

У гэтага інструмента няма налад. Увесь тэкст вымаецца з кожнай старонкі ў парадку чытання.

## Фармат выніку

- **Адзін файл**: `filename.txt`
- **Некалькі файлаў**: `pdf-to-text.zip` з адным `.txt` на кожны ўваходны PDF.

## Сцэнарыі выкарыстання

- Выманне асноўнага тэксту са справаздач PDF для паўнатэкставай індэксацыі.
- Пераўтварэнне электронных кніг або артыкулаў PDF у просты тэкст для чытання на прыладах з e-ink.
- Выманне тэксту з дагавораў або юрыдычных дакументаў для аналізу ключавых слоў.
- Выдаленне фарматавання з PDF, каб атрымаць чысты тэкст для скрыптоў апрацоўкі даных.
- Падрыхтоўка тэкставага корпуса з архіваў PDF для апрацоўкі натуральнай мовы.

## Парады

- Сканаваныя PDF (толькі відарысы) дадуць пустыя тэкставыя файлы, бо ў іх няма тэкставага пласта. Спачатку апрацуйце сканы з дапамогай OCR.
- Вынік захоўвае парадак чытання так, як яго вызначае PyMuPDF: звычайна злева направа і зверху ўніз. Макеты з некалькімі слупкамі могуць даць перамешаны тэкст.
- Для структураванага выніку з загалоўкамі і фарматаваннем паспрабуйце [PDF у Markdown](./pdf-to-markdown). Для структураванага JSON, гатовага для ШI, выкарыстайце [Падрыхтаваць PDF для ШI](./prepare-pdf-for-ai).

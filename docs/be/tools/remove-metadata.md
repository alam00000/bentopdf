# Выдаліць метаданыя

Кожны PDF змяшчае метаданыя, якія могуць паказаць, хто яго стварыў, якая праграма выкарыстоўвалася, калі ён апошні раз змяняўся, і іншае. Гэты інструмент выдаляе ўсё гэта: слоўнік Info, патокі метаданых XMP, ідэнтыфікатары дакумента і спецыфічныя для праграм даныя, пакідаючы чысты дакумент без слядоў паходжання.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Націсніце **Выдаліць метаданыя**.
3. Спампуйце ачышчаны файл.

Налад няма. Інструмент наўмысна грунтоўны: ён ачышчае ўсё.

## Што выдаляецца

- **Палі слоўніка Info**: загаловак, аўтар, тэма, ключавыя словы, стваральнік, вытворца, дата стварэння, дата змянення
- **Паток метаданых XMP**: блок метаданых на аснове XML, які захоўваецца ў каталогу дакумента
- **Ідэнтыфікатары дакумента**: унікальныя ідэнтыфікатары ў трэйлеры PDF, якія можна выкарыстоўваць для адсочвання дакумента паміж сістэмамі
- **PieceInfo**: спецыфічныя метаданыя, дададзеныя праграмамі накшталт Illustrator або InDesign

## Што застаецца

- Увесь бачны змест старонак (тэкст, відарысы, графіка)
- Палі формаў і анатацыі
- Закладкі і спасылкі
- Сама структура дакумента

## Сцэнарыі выкарыстання

- Выдаленне вашага імя і арганізацыі з дакумента перад ананімнай публікацыяй
- Выдаленне часовых метак стварэння, якія паказваюць, калі дакумент быў падрыхтаваны
- Ачыстка радкоў вытворцы, якія ідэнтыфікуюць ваша праграмнае забеспячэнне для PDF
- Падрыхтоўка дакументаў для рэгулятарных падач, якія патрабуюць PDF без метаданых
- Выдаленне слядоў гісторыі рэдагавання перад перадачай дакумента вонкі

## Парады

- Спачатку выкарыстайце інструмент "Праглядзець метаданыя", каб убачыць, якія менавіта метаданыя ёсць у PDF, перад іх выдаленнем.
- Калі трэба выдаліць метаданыя _і_ JavaScript, анатацыі і ўбудаваныя файлы, выкарыстоўвайце "Ачысціць PDF" для больш грунтоўнай ачысткі.
- Выдаленне метаданых незваротнае. Захавайце арыгінал, калі гэтыя даныя могуць спатрэбіцца пазней.

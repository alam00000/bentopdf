# Павярнуць на зададзены вугал

Паварочвайце старонкі PDF на любы адвольны вугал, а не толькі з крокам 90 градусаў. Кожная старонка мае ўласнае поле вугла, а з дапамогай пакетнага кіравання можна адразу ўжыць адзін вугал да ўсіх старонак.

## Як гэта працуе

1. Загрузіце файл PDF. Для кожнай старонкі адмалёўваюцца мініяцюры.
2. Кожная старонка мае лікавае поле з яе бягучым вуглом павароту.
3. Увядзіце любое значэнне ў градусах (дадатнае або адмоўнае), каб павярнуць пэўную старонку, або выкарыстоўвайце кнопкі ўлева/ўправа для хуткага павароту на 90 градусаў.
4. Выкарыстоўвайце поле **пакетнага вугла** уверсе, каб задаць аднолькавы паварот для ўсіх старонак.
5. Націсніце кнопку апрацоўкі, каб стварыць павернуты PDF.

## Магчымасці

- Адвольнае значэнне градусаў для кожнай старонкі (любы цэлы лік)
- Пакетнае кіраванне вуглом для аднолькавага павароту ўсіх старонак
- Папярэдні прагляд павароту ў мініяцюрах у рэальным часе
- Кнопкі хуткага павароту на 90 градусаў для кожнай старонкі
- Адкладзеная загрузка мініяцюр для хуткасці на вялікіх дакументах

## Сцэнарыі выкарыстання

- Выпраўленне крыху нахіленых сканаў на некалькі градусаў
- Паварот старонак пад нестандартную арыентацыю
- Дакладны паварот асобных старонак у дакуменце са змешаным зместам
- Тонкая налада вуглоў старонак пасля першаснага масавага павароту

## Парады

- Дадатныя значэнні паварочваюць па гадзінніку, адмоўныя супраць гадзінніка.
- Пакетнае поле вугла перазапісвае ўсе вуглы асобных старонак пры ўжыванні. Пры неабходнасці задавайце асобныя налады пасля пакетнай аперацыі.
- Для стандартных паваротаў на 90/180/270 градусаў з прасцейшым інтэрфейсам выкарыстоўвайце [Павярнуць PDF](./rotate-pdf).

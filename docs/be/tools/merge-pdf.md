# Аб'яднаць PDF

Аб'ядноўвайце некалькі файлаў PDF у адзін дакумент. Можна аб'яднаць цэлыя файлы ў пэўным парадку або пераключыцца ў рэжым старонак для дэталёвага кіравання асобнымі старонкамі з кожнага запампаванага PDF.

## Як гэта працуе

1. Запампуйце два або больш файлаў PDF, націснуўшы на вобласць запампоўвання або перацягнуўшы іх.
2. Выберыце **Рэжым файлаў** або **Рэжым старонак** пераключальнікам уверсе.
3. У рэжыме файлаў перацягвайце файлы, каб змяніць іх парадак, і пры жаданні ўказвайце дыяпазоны старонак (напрыклад, `1-3, 5`) для кожнага файла. Пакіньце дыяпазон пустым, каб уключыць усе старонкі.
4. У рэжыме старонак перацягвайце мініяцюры асобных старонак, каб скласці патрэбную паслядоўнасць.
5. Націсніце **Аб'яднаць PDF**, каб злучыць усё ў адзін файл. Аб'яднаны PDF спампуецца аўтаматычна.

## Магчымасці

- Два рэжымы аб'яднання: рэжым файлаў для хуткага аб'яднання цэлых файлаў, рэжым старонак для кіравання кожнай старонкай
- Пераўпарадкаванне перацягваннем у абодвух рэжымах з плаўнымі анімацыямі
- Сінтаксіс дыяпазонаў старонак (напрыклад, `1-3, 5, 8-10`) дазваляе выбіраць старонкі без пераходу ў рэжым старонак
- Адкладзеная загрузка мініяцюр старонак захоўвае спагадлівасць інтэрфейсу нават з вялікімі дакументамі
- Без абмежаванняў на колькасць файлаў або агульную колькасць старонак
- Захоўвае арыгінальную якасць PDF без перакадавання

## Параметры

| Параметр           | Апісанне                                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
| **Рэжым файлаў**   | Аб'яднанне цэлых файлаў у ўласным парадку з неабавязковымі фільтрамі дыяпазону старонак для кожнага файла |
| **Рэжым старонак** | Візуальная сетка ўсіх старонак з усіх файлаў: перацягвайце мініяцюры, каб скласці патрэбную паслядоўнасць |
| **Поле старонак**  | Тэкставае поле для кожнага файла з дыяпазонамі накшталт `1-3, 5`, каб уключыць толькі пэўныя старонкі     |

## Сцэнарыі выкарыстання

- Аб'яднанне асобных PDF з раздзеламі ў адну кнігу або справаздачу
- Аб'яднанне суправаджальнага ліста і рэзюмэ ў адзін дакумент заяўкі
- Выбар пэўных старонак з некалькіх дакументаў у зводны файл
- Збор сканаваных чэкаў або рахункаў у адзін архіўны PDF
- Стварэнне раздатковага матэрыялу са слайдаў некалькіх прэзентацый

## Парады

- Выкарыстоўвайце рэжым старонак, калі трэба чаргаваць старонкі з розных файлаў, а не проста дадаваць адзін файл за адным.
- Пасля першага запампоўвання можна дадаць яшчэ файлы кнопкай **Дадаць яшчэ файлы**, не губляючы бягучага парадку.
- Нумарацыя старонак у дыяпазонах пачынаецца з 1, таму `1` азначае першую старонку файла.

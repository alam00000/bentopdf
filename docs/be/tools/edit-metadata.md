# Рэдагаваць метаданыя

Рэдагуйце метаданыя, убудаваныя ў файл PDF. Інструмент загадзя запаўняе форму існуючымі метаданымі дакумента, дазваляе змяніць любое поле і захоўвае змены ў новы PDF.

## Як гэта працуе

1. Загрузіце файл PDF. Інструмент чытае яго бягучыя метаданыя і запаўняе форму.
2. Рэдагуйце любыя стандартныя палі: Назва, Аўтар, Тэма, Ключавыя словы, Стваральнік, Вытворца.
3. Наладзьце Дату стварэння і Дату змянення з дапамогай выбару даты і часу.
4. Дадавайце ўласныя палі метаданых: націсніце кнопку дадавання і ўвядзіце пару ключ-значэнне.
5. Націсніце кнопку апрацоўкі, каб захаваць зменены PDF.

## Магчымасці

- Загадзя запаўняе ўсе існуючыя метаданыя з загружанага PDF
- Стандартныя палі: Назва, Аўтар, Тэма, Ключавыя словы, Стваральнік, Вытворца
- Выбар даты і часу для Даты стварэння і Даты змянення
- Уласныя палі метаданых ключ-значэнне для любых уласцівасцей
- Захоўвае змены непасрэдна ў інфармацыйны слоўнік дакумента PDF

## Палі для рэдагавання

| Поле               | Апісанне                                                  |
| ------------------ | --------------------------------------------------------- |
| **Назва**          | Назва дакумента, якая паказваецца ў праграмах чытання PDF |
| **Аўтар**          | Чалавек або арганізацыя, якія стварылі дакумент           |
| **Тэма**           | Кароткае апісанне тэмы дакумента                          |
| **Ключавыя словы** | Тэрміны праз коску для пошуку і катэгарызацыі             |
| **Стваральнік**    | Праграма, у якой першапачаткова створана змесціва         |
| **Вытворца**       | Праграма, якая стварыла PDF                               |
| **Дата стварэння** | Калі дакумент быў першапачаткова створаны                 |
| **Дата змянення**  | Калі дакумент быў апошні раз зменены                      |
| **Уласныя палі**   | Любыя дадатковыя пары ключ-значэнне, якія вы задасце      |

## Сцэнарыі выкарыстання

- Заданне правільнай назвы і аўтара перад публікацыяй дакумента
- Дадаванне ключавых слоў для лепшага пошуку ў сістэмах кіравання дакументамі
- Абнаўленне даты змянення ў адпаведнасці з бягучай рэдакцыяй
- Дадаванне ўласных палёў метаданых, такіх як Аддзел, ID праекта або Класіфікацыя
- Ачыстка метаданых, пакінутых зыходнай праграмай стварэння

## Парады

- Уласныя палі запісваюцца непасрэдна ў інфармацыйны слоўнік PDF. Некаторыя праграмы чытання PDF могуць іх не паказваць, але ў файле яны захоўваюцца.
- Пакіньце поле пустым, каб выдаліць яго з метаданых. Кнопка апрацоўкі захоўвае тое, што ёсць у форме.
- Каб праглядзець метаданыя без рэдагавання, скарыстайцеся [Праглядзець метаданыя](./view-metadata). Каб цалкам выдаліць усе метаданыя, скарыстайцеся «Выдаліць метаданыя».

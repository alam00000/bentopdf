# JPG у PDF

Ператварайце відарысы JPG у акуратны PDF. Запампуйце адзін файл або некалькі JPG адразу: кожны відарыс становіцца поўнапамернай старонкай выніковага дакумента.

## Падтрымліваемыя фарматы

| Фармат    | Пашырэнні       |
| :-------- | :-------------- |
| JPEG      | `.jpg`, `.jpeg` |
| JPEG 2000 | `.jp2`, `.jpx`  |

## Як гэта працуе

1. Націсніце на вобласць запампоўвання або перацягніце файлы JPG. Падтрымліваецца выбар некалькіх файлаў.
2. Праверце запампаваныя файлы. Выкарыстоўвайце значок сметніцы, каб выдаліць асобныя файлы, або націсніце **Дадаць яшчэ файлы**, каб дапоўніць спіс.
3. Выберыце ўзровень **Якасці PDF**.
4. Націсніце **Пераўтварыць у PDF**. Інструмент сціскае відарысы згодна з наладай якасці, пераўтварае іх рухавіком PyMuPDF і спампоўвае `from_jpgs.pdf`.

## Параметры

**Якасць PDF** вызначае сціск кожнага відарыса перад убудоўваннем у PDF:

- **Высокая якасць**: захоўвае максімум дэталяў. Для фатаграфій або друку.
- **Сярэдняя якасць** (па змаўчанні): добры баланс паміж выразнасцю і памерам файла.
- **Нізкая якасць**: моцны сціск для найменшага выніку.

## Сцэнарыі выкарыстання

- Пераўтварэнне сканаваных дакументаў, захаваных як JPG, у адзін PDF для падачы
- Збор фота тавараў у каталог для кліентаў
- Пераўтварэнне медыцынскіх або спадарожнікавых відарысаў JPEG 2000 у партатыўны PDF
- Стварэнне фотаальбома для друку з экспартаў камеры

## Парады

- Файлы JPEG 2000 (`.jp2`, `.jpx`) цалкам падтрымліваюцца, а не толькі стандартны JPEG. Гэта карысна для медыцынскіх відарысаў і геапрасторавых даных.
- Калі вашы JPG зроблены камерай тэлефона, сярэдняя якасць звычайна дае файл на 40-60% меншы, чым высокая, без бачнай розніцы на экране.

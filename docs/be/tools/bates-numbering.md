# Нумарацыя Бейтса

Нумарацыя Бейтса праштампоўвае паслядоўныя ідэнтыфікатары на кожнай старонцы PDF. Гэта стандартны спосаб пазначэння дакументаў у судовых працэсах, аўдытах і працэсах адпаведнасці патрабаванням. Інструмент падтрымлівае некалькі файлаў і наладжвальныя шаблоны і стварае асобна пранумараваныя PDF або адзін ZIP-архіў.

## Як гэта працуе

1. Загрузіце адзін або некалькі PDF-файлаў. Можна перацягнуць некалькі файлаў адразу.
2. Выберыце гатовы стыль або стварыце ўласны шаблон.
3. Наладзьце размяшчэнне, шрыфт, памер, колер і пачатковыя нумары.
4. Націсніце **Прымяніць нумары Бейтса**, каб апрацаваць.
5. Адзін файл спампуецца непасрэдна. Некалькі файлаў спампуюцца як ZIP-архіў.

## Параметры

- **Гатовы стыль**: выберыце адзін з убудаваных фарматаў:
  - Доказ + Справа + Бейтс + Старонка (напрыклад, "Exhibit 1 Case XYZ 000001 Page 1")
  - Доказ + Справа + Бейтс (без нумара старонкі)
  - Справа + Бейтс
  - Толькі нумар Бейтса (напрыклад, "000001")
  - Уласны (напішыце свой шаблон)
- **Наладзіць стыль**: радок шаблону з запаўняльнікамі: `[BATES]`, `[PAGE]`, `[FILE]`, `[FILENAME]`.
- **Дапаўненне Бейтса**: колькасць лічбаў (ад 3 да 6) для нумароў Бейтса з вядучымі нулямі. Бачна толькі ва ўласным рэжыме.
- **Размяшчэнне**: верхні або ніжні калантытул, злева, па цэнтры або справа.
- **Бейтс пачынаецца з**: першы нумар Бейтса. Па змаўчанні 1. Нумарацыя працягваецца паміж файламі.
- **Лічыльнік файлаў пачынаецца з**: пачатковы нумар для запаўняльніка `[FILE]`.
- **Шрыфт**: Helvetica, Times New Roman або Courier.
- **Памер шрыфту**: памер праштампаванага тэксту.
- **Колер**: палітра для колеру тэксту нумара Бейтса.

## Магчымасці

- Жывы прагляд таго, як нумары Бейтса будуць выглядаць ва ўсіх загружаных файлах
- Падтрымка некалькіх файлаў з бесперапыннай нумарацыяй паміж дакументамі
- Змена парадку файлаў перацягваннем для кіравання паслядоўнасцю нумарацыі
- Шэсць варыянтаў размяшчэння (верхні/ніжні калантытул, злева/па цэнтры/справа)
- Адаптыўны разлік палёў з улікам розных памераў старонак
- Вынік у ZIP для пакетаў з некалькіх файлаў
- Запаўняльнікі шаблону для максімальнай гнуткасці

## Сцэнарыі выкарыстання

- Штампаванне дакументаў для судовага разбору паслядоўнымі нумарамі доказаў
- Нумарацыя пакетаў аўдытарскіх доказаў з дзясяткаў файлаў
- Нанясенне рэгулятарных даведачных нумароў на дакументацыю адпаведнасці
- Пазначэнне дадаткаў да патэнтавых заявак ідэнтыфікатарамі справы

## Парады

- Перацягвайце файлы ў спісе, каб змяніць іх парадак перад апрацоўкай. Паслядоўнасць нумарацыі Бейтса ідзе ў гэтым парадку.
- Выкарыстайце запаўняльнік `[FILENAME]`, каб уключыць у штамп зыходную назву файла: гэта дапамагае адсочваць старонкі да зыходных дакументаў.
- Акно прагляду абнаўляецца ў рэальным часе пры змене налад, таму фармат можна праверыць перад апрацоўкай.

# PDF у Markdown

Пераўтварае файлы PDF у фармат Markdown (`.md`), захоўваючы загалоўкі, абзацы, спісы і базавае фарматаванне. Пры жаданні вымае і ўключае ўбудаваныя відарысы. Падтрымліваецца адзіночнае і пакетнае пераўтварэнне. Працуе на PyMuPDF.

## Як гэта працуе

1. Загрузіце адзін ці некалькі PDF, націснуўшы на вобласць загрузкі або перацягнуўшы туды файлы.
2. Пры жаданні ўключыце **Уключаць відарысы**, каб убудаваць вынятыя відарысы ў Markdown.
3. Націсніце **Пераўтварыць**, каб пачаць апрацоўку.
4. Адзін файл спампоўваецца як `filename.md`. Некалькі файлаў даюць `markdown-files.zip`.

## Налады

- **Уключаць відарысы**: калі адзначана, убудаваныя відарысы з PDF вымаюцца і на іх ёсць спасылкі ў Markdown. Калі не адзначана, пераўтвараецца толькі тэкст.

## Фармат выніку

- **Адзін файл**: `filename.md`
- **Некалькі файлаў**: `markdown-files.zip` з адным `.md` на кожны ўваходны PDF.

## Сцэнарыі выкарыстання

- Пераўтварэнне дакументацыі PDF у Markdown для генератара статычных сайтаў, такога як VitePress, Hugo або Jekyll.
- Ператварэнне навуковых артыкулаў PDF у рэдагаваны Markdown для праграм нататак, такіх як Obsidian.
- Перанос старых баз ведаў PDF у тэкставы фармат, зручны для Git.
- Выманне структураванага змесціва з электронных кніг PDF для пераафармлення.

## Парады

- Опцыя «Уключаць відарысы» карысная, калі PDF змяшчае схемы або ілюстрацыі, важныя для зместу. Для тэкставых дакументаў адключыце яе, каб вынік быў чыстым.
- Складаныя макеты з бакавымі панэлямі, зноскамі або некалькімі слупкамі могуць даць недасканалы Markdown. Праверце і пры неабходнасці выпраўце вынік.
- Для сырога тэксту без фарматавання выкарыстайце [PDF у тэкст](./pdf-to-text).

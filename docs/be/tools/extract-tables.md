# Выняць табліцы з PDF

Знаходзіць усе табліцы ў PDF і дазваляе экспартаваць іх у выбраным фармаце: CSV, JSON або Markdown. Кожная табліца вымаецца асобна з метаданымі пра старонку і пазіцыю. Працуе на рухавіку выяўлення табліц PyMuPDF.

## Як гэта працуе

1. Загрузіце PDF: націсніце на вобласць загрузкі або перацягніце на яе файл.
2. Выберыце патрэбны **фармат экспарту**: CSV, JSON або Markdown.
3. Націсніце **Выняць**, каб пачаць апрацоўку.
4. Калі знойдзена адна табліца, яна спампоўваецца як адзін файл. Некалькі табліц даюць архіў ZIP з адным файлам на кожную табліцу.

## Параметры

- **Фармат экспарту**: выбар паміж:
  - **CSV**: значэнні праз коску з правільным выкарыстаннем двукоссяў для палёў, што ўтрымліваюць коскі, двукоссі або пераносы радкоў. Падыходзіць для электронных табліц і баз даных.
  - **JSON**: структура «масіў масіваў», адфарматаваная з водступам у 2 прабелы. Падыходзіць для праграмнай апрацоўкі.
  - **Markdown**: фармат табліц з раздзяляльнікамі `|`, які стварае PyMuPDF. Падыходзіць для дакументацыі і файлаў README.

## Фармат выніку

- **Адна табліца**: `filename_table.csv` (або `.json` / `.md`)
- **Некалькі табліц**: `filename_tables.zip` з файламі `table_1_page3.csv`, `table_2_page5.csv` і г. д.

## Сцэнарыі выкарыстання

- Выманне пэўных табліц з аб'ёмных справаздач PDF без вымання даных усяго дакумента.
- Атрыманне табліц у фармаце Markdown, каб устаўляць іх непасрэдна ў issues на GitHub, вікі або дакументацыю.
- Выманне структураваных даных JSON з табліц PDF для інтэграцый праз API або скрыптоў.
- Параўнанне табліц у розных версіях PDF: экспартуйце абедзве ў CSV і параўнайце.

## Парады

- Гэты інструмент дае кантроль над кожнай табліцай. Калі трэба проста выгрузіць усе табліцы ў адзін CSV, карыстайцеся [PDF у CSV](./pdf-to-csv). Для поўнай кнігі Excel карыстайцеся [PDF у Excel](./pdf-to-excel).
- Табліцы, што займаюць некалькі старонак, могуць распазнавацца як асобныя табліцы на кожнай старонцы. Можа спатрэбіцца аб'яднаць іх уручную.
- Калі табліцы не знойдзены, PDF можа быць сканаваным відарысам. Спачатку прапусціце яго праз OCR, каб дадаць тэкставы пласт.

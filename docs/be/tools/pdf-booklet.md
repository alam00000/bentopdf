# Буклет PDF

Пераўпарадкоўвае старонкі PDF у парадак спуска палос для буклета. Пасля двухбаковага друку і згінання напалову старонкі будуць ісці ў правільнай паслядоўнасці. Такі макет выкарыстоўваецца для буклетаў і зінаў, сшытых скобай.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Наладзьце буклет: памер і арыентацыю выходных старонак.
3. Націсніце **Стварыць папярэдні прагляд**, каб убачыць, як старонкі размесцяцца на кожным аркушы.
4. Праглядзіце папярэдні прагляд: ён паказвае кожны фізічны аркуш са старонкамі на ліцавым і адваротным баку.
5. Націсніце **Спампаваць**, каб захаваць PDF у парадку буклета.

## Магчымасці

- Аўтаматычнае пераўпарадкаванне старонак для шыцця скобай
- Налада памеру выходных старонак
- Візуальны папярэдні прагляд макета буклета перад спампоўваннем
- Пры няцотнай колькасці старонак пры неабходнасці дадаюцца пустыя
- Зыходныя старонкі маштабуюцца пад памер аркуша буклета

## Сцэнарыі выкарыстання

- Стварэнне буклетаў або зінаў для друку са звычайнага PDF
- Падрыхтоўка праграм канферэнцый або даведнікаў мерапрыемстваў для друку ўласнымі сіламі
- Выраб складаных паштовак або невялікіх каталогаў
- Стварэнне невялікіх кніжак або паэтычных зборнікаў для ручнога пераплёту

## Парады

- Для акуратнага буклета колькасць старонак зыходнага PDF лепш мець кратнай 4. Калі гэта не так, пустыя старонкі дадаюцца аўтаматычна, каб запоўніць апошні аркуш.
- Надрукуйце вынік з двух бакоў з наладай прынтара «пераварот па кароткім краі», затым складзіце ўсе аркушы разам і сшыйце па згібе.
- Каб проста размясціць некалькі старонак на адным аркушы без парадку буклета, выкарыстайце [N-Up PDF](./n-up-pdf).

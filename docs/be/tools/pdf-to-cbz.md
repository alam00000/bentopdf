# PDF у CBZ

Пераўтварае PDF у файл CBZ (Comic Book ZIP), стандартны фармат для лічбавых коміксаў і мангі. Кожная старонка PDF становіцца відарысам у архіве. Інструмент стварае метаданыя ў трох фарматах для максімальнай сумяшчальнасці: ComicInfo.xml, metadata.opf і ComicBookInfo JSON.

## Як гэта працуе

1. Загрузіце PDF, націснуўшы на вобласць загрузкі або перацягнуўшы туды файл.
2. Выберыце фармат відарысаў, якасць, маштаб і, пры жаданні, метаданыя.
3. Націсніце **Пераўтварыць**, каб стварыць файл CBZ.
4. Файл `.cbz` спампуецца аўтаматычна.

## Налады

| Налада             | Значэнні        | Па змаўчанні | Апісанне                                                                                         |
| ------------------ | --------------- | ------------ | ------------------------------------------------------------------------------------------------ |
| Фармат відарысаў   | JPEG, PNG, WebP | JPEG         | JPEG для каляровых коміксаў, PNG для чорна-белай мангі без страт, WebP для найлепшага сціскання. |
| Якасць             | 50–100%         | 85%          | Кіруе сцісканнем JPEG/WebP. Схавана для PNG (заўсёды без страт).                                 |
| Маштаб             | 1.0x–4.0x       | 2.0x         | Большы маштаб дае больш выразныя відарысы для экранаў з высокім разрозненнем.                    |
| Градацыі шэрага    | Укл./Выкл.      | Выкл.        | Пераўтварае старонкі ў градацыі шэрага. Памяншае памер для чорна-белага змесціва.                |
| Рэжым мангі        | Укл./Выкл.      | Выкл.        | Задае ў метаданых кірунак чытання справа налева.                                                 |
| Уключыць метаданыя | Укл./Выкл.      | Укл.         | Убудоўвае ComicInfo.xml, metadata.opf і ComicBookInfo JSON.                                      |

## Палі метаданых

Калі метаданыя ўключаныя, можна запоўніць:

- **Назва**: вызначаецца аўтаматычна з імя файла PDF.
- **Серыя**: назва серыі (напрыклад, «Naruto»).
- **Нумар (#)**: нумар выпуску ў серыі.
- **Том (Vol.)**: нумар тома.
- **Аўтар(ы)**: імя сцэнарыста або стваральніка.
- **Выдавец**: выдавецкая кампанія.
- **Тэгі / Жанр**: тэгі праз коску (напрыклад, «Баявік, Прыгоды»).
- **Год выдання**: год публікацыі (1900–2100).
- **Рэйтынг**: рэйтынг супольнасці ад 0 да 5.

## Сумяшчальнасць метаданых

Інструмент запісвае метаданыя ў трох фарматах, каб іх знайшла кожная праграма:

| Фармат             | Размяшчэнне         | Падтрымліваецца                             |
| ------------------ | ------------------- | ------------------------------------------- |
| ComicInfo.xml      | Файл у ZIP          | Komga, Kavita, CDisplayEx, Mylar, ComicRack |
| metadata.opf       | Файл у ZIP          | Calibre                                     |
| ComicBookInfo JSON | Поле каментарыя ZIP | Calibre (рэзервова)                         |

## Фармат выніку

- `filename.cbz`: архіў ZIP з пранумараванымі відарысамі старонак і файламі метаданых.

Відарысы старонак названыя нумарамі з вядучымі нулямі (`01.jpg`, `02.jpg` і г.д.), каб праграмы паказвалі іх у правільным парадку.

## Сцэнарыі выкарыстання

- Пераўтварэнне PDF з мангай або коміксамі для праграм чытання коміксаў.
- Стварэнне бібліятэкі лічбавых коміксаў у Komga, Kavita або Calibre.
- Пераўтварэнне сканаваных коміксаў у зручны для чытання фармат.
- Абмен коміксамі ў фармаце, які захоўвае кірунак чытання і метаданыя.

## Парады

- Выкарыстоўвайце **JPEG** для каляровых коміксаў і **PNG** для чорна-белай мангі: PNG вельмі эфектыўна сціскае чорна-белае змесціва.
- Уключыце **Градацыі шэрага** для мангі, каб значна паменшыць памер файла.
- Запоўніце палі **Серыя** і **Нумар**, каб менеджары бібліятэк (Komga, Calibre) упарадкавалі калекцыю аўтаматычна.
- **WebP** дае найлепшае сцісканне, але старыя праграмы чытання коміксаў могуць яго не падтрымліваць.

# BMP у PDF

Пераўтварайце файлы Windows Bitmap (BMP) у PDF. BMP: гэта нясціснуты фармат выяў, які дагэтуль сустракаецца ў састарэлых сістэмах, медыцынскай візуалізацыі і прамысловых сканерах. Інструмент пераўтварае іх у PDF без усталявання чаго-небудзь.

## Падтрымліваемыя фарматы

| Фармат | Пашырэнні |
| :----- | :-------- |
| BMP    | `.bmp`    |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце туды файлы BMP.
2. Праверце спіс файлаў. Дадайце яшчэ файлы або выдаліце непатрэбныя.
3. Націсніце **Пераўтварыць у PDF**. Вынік спампуецца як `from_bmps.pdf`.

Кожны BMP малюецца на canvas, экспартуецца як PNG і затым убудоўваецца ў PDF з дапамогай pdf-lib. Памер старонкі адпавядае памерам зыходнай выявы.

## Параметры

Інструмент не мае дадатковых налад якасці. Выявы ўбудоўваюцца ў PDF у зыходным раздзяленні як PNG без страт.

## Сцэнарыі выкарыстання

- Пераўтварэнне састарэлых сканаваных дакументаў у BMP у архіўныя PDF
- Ператварэнне скрыншотаў BMP са старых праграм Windows у дакументы для абмену
- Апрацоўка выніку медыцынскіх або прамысловых сканераў, якія па змаўчанні захоўваюць BMP
- Перанос старых архіваў выяў у больш партатыўны фармат

## Парады

- Файлы BMP не сціснутыя, таму звычайна вялікія. Выніковы PDF будзе значна меншым, бо выявы ўнутры перакадуюцца ў PNG.
- Калі ў вас ёсць BMP разам з выявамі іншых фарматаў, выкарыстайце інструмент [Выявы ў PDF](./image-to-pdf), каб пераўтварыць усё адным пакетам.

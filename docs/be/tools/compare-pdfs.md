# Параўнаць PDF

Загрузіце два PDF і дакладна ўбачце, што змянілася паміж імі. Інструмент разумна супастаўляе старонкі, выяўляе адрозненні ў тэксце, відарысах, анатацыях, калантытулах і фарматаванні і паказвае іх побач або ў рэжыме накладання.

## Як гэта працуе

1. Загрузіце два файлы PDF: арыгінал (злева) і перагледжаную версію (справа).
2. Інструмент супастаўляе старонкі дакументаў па сігнатурах змесціва.
3. Выберыце рэжым прагляду: **Побач** або **Накладанне**.
4. Пераходзьце паміж парамі старонак з дапамогай элементаў пагінацыі.
5. Адрозненні вылучаюцца і класіфікуюцца. Карыстайцеся панэллю фільтраў, каб засяродзіцца на пэўных тыпах змен.
6. Пры жаданні экспартуйце параўнанне як справаздачу PDF.

## Магчымасці

- Аўтаматычнае супастаўленне старонак па падабенстве змесціва
- Рэжымы параўнання побач і накладаннем
- Класіфікацыя змен: тэкст, відарыс, калантытул, анатацыя, фарматаванне, фон
- Пераключальнікі фільтраў па катэгорыях, каб паказваць або хаваць пэўныя тыпы змен
- Пошук тэкставых змен з фільтрацыяй па запыце
- Падтрымка OCR для параўнання сканаваных дакументаў
- Маштабаванне для дэталёвага агляду
- Сінхранізаваная пракрутка панэляў у рэжыме побач
- Экспарт вынікаў параўнання ў PDF

## Параметры

| Параметр              | Апісанне                                                                  |
| --------------------- | ------------------------------------------------------------------------- |
| **Рэжым прагляду**    | Побач або Накладанне                                                      |
| **OCR**               | Уключыць/выключыць OCR для параўнання сканаваных дакументаў               |
| **Мова OCR**          | Мова для вымання тэксту з дапамогай OCR                                   |
| **Фільтры катэгорый** | Паказ змен тэксту, відарысаў, калантытулаў, анатацый, фарматавання і фону |
| **Аб'ём змен**        | У рэжыме накладання выбар паміж усімі зменамі і толькі зменамі змесціва   |
| **Маштаб**            | Налада павелічэння для дэталёвага агляду                                  |

## Сцэнарыі выкарыстання

- Праверка рэдакцый дагавора, каб дакладна знайсці змены паміж версіямі
- Параўнанне дызайн-макетаў, каб пераканацца, што экспарт у PDF адпавядае чаканням
- Аўдыт змен дакументаў у рэгуляваных галінах, дзе трэба адсочваць кожную праўку
- Праверка, што пераўтварэнне ў PDF дакладна захавала арыгінальнае змесціва
- Параўнанне перакладзеных дакументаў з арыгіналам на прадмет змен макета

## Парады

- Рэжым накладання размяшчае абодва дакументы адзін на адным, таму прасторавыя адрозненні (зрушаныя элементы, змененыя відарысы) адразу бачныя.
- Уключайце OCR пры параўнанні сканаваных дакументаў без тэкставага пласта. Рухавік параўнання выме тэкст з відарысаў старонак.
- Карыстайцеся фільтрамі катэгорый, каб засяродзіцца на галоўным. Напрыклад, схавайце змены фарматавання, калі вас цікавяць толькі адрозненні ў тэксце.

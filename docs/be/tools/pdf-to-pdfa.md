# PDF у PDF/A

PDF/A з'яўляецца стандартызаваным ISO падмноствам PDF для доўгатэрміновага лічбавага захоўвання. Гэты інструмент пераўтварае звычайныя PDF у дакументы, сумяшчальныя з PDF/A, з дапамогай Ghostscript, які працуе непасрэдна ў браўзеры.

## Як гэта працуе

1. Загрузіце адзін ці некалькі файлаў PDF.
2. Выберыце **Версію PDF/A** у выпадальным спісе.
3. Пры жаданні ўключыце **Папярэдне звесці PDF** для складаных файлаў, якія не пераўтвараюцца звычайным спосабам.
4. Націсніце **Пераўтварыць у PDF/A**. Для некалькіх файлаў ствараецца архіў ZIP.

## Версіі PDF/A

| Версія       | Абмежаванні                                   | Лепш для                                                   |
| ------------ | --------------------------------------------- | ---------------------------------------------------------- |
| **PDF/A-1b** | Найстражэйшая. Без празрыстасці і пластоў.    | Максімальнай сумяшчальнасці са старымі архіўнымі сістэмамі |
| **PDF/A-2b** | Дазваляе празрыстасць і JPEG2000.             | Агульнага архівавання (рэкамендуецца)                      |
| **PDF/A-3b** | Дазваляе ўбудаваныя далучэнні любога фармату. | Архівавання дакументаў з зыходнымі файламі даных           |

PDF/A-2b выбрана па змаўчанні і падыходзіць для пераважнай большасці задач архівавання.

## Опцыя папярэдняга звядзення

Некаторыя PDF маюць асаблівасці, якія перашкаджаюць чыстаму пераўтварэнню ў PDF/A: незвычайныя кадзіроўкі шрыфтоў, складаныя стэкі празрыстасці або пашкоджаную ўнутраную структуру. Опцыя **Папярэдне звесці** растарызуе PDF з 300 DPI перад пераўтварэннем, што гарантуе адпаведнасць, але тэкст больш нельга вылучыць. Выкарыстоўвайце яе як запасны варыянт, калі звычайнае пераўтварэнне дае памылкі.

Для папярэдняга звядзення патрэбны рухавік PyMuPDF WASM.

## Сцэнарыі выкарыстання

- Выкананне дзяржаўных або юрыдычных патрабаванняў да архівавання (многія юрысдыкцыі патрабуюць PDF/A для судовых дакументаў)
- Падача дакументаў у інстытуцыйныя рэпазіторыі або лічбавыя бібліятэкі
- Захаванне дзелавых запісаў, калі арыгінальнай праграмы праз дзесяць гадоў можа ўжо не быць
- Падрыхтоўка рахункаў для стандартаў электронных рахункаў, якія патрабуюць PDF/A-3b з далучэннямі XML

## Парады

- Спачатку паспрабуйце пераўтварэнне без папярэдняга звядзення. Уключайце яго, толькі калі атрымаеце памылку.
- PDF/A убудоўвае ўсе шрыфты, таму выходныя файлы часта большыя за арыгіналы.
- Калі для вашага працэсу патрэбная строгая адпаведнасць, праверце вынік у спецыяльным валідатары PDF/A.

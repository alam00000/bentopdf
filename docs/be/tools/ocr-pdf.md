# OCR PDF

Ператварайце сканаваныя дакументы ў PDF з пошукам і капіраваннем. Інструмент выкарыстоўвае Tesseract OCR для распазнавання тэксту на відарысах і накладае нябачны тэкставы пласт на арыгінальныя старонкі, захоўваючы іх выгляд і робячы змесціва цалкам даступным для пошуку.

## Як гэта працуе

1. Запампуйце сканаваны PDF або PDF на аснове відарысаў.
2. Выберыце адну або некалькі моў дакумента ў спісе моў з пошукам.
3. Пры жаданні змяніце пашыраныя налады (разрозненне, бінарызацыя, белы спіс).
4. Націсніце **Пачаць OCR** і сачыце за ходам па індыкатары ў рэальным часе.
5. Пасля завяршэння праглядзіце атрыманы тэкст і спампуйце PDF з пошукам або звычайны файл `.txt`.

## Магчымасці

- OCR на некалькіх мовах з пошукам у выбары моў
- Нябачны тэкставы пласт захоўвае арыгінальны выгляд дакумента
- Індыкатар ходу і журнал у рэальным часе падчас апрацоўкі
- Спампоўванне вынікаў як PDF з пошукам або звычайнага тэкставага файла
- Капіраванне вынятага тэксту непасрэдна ў буфер абмену
- Тры ўзроўні разрознення для балансу паміж хуткасцю і дакладнасцю

## Параметры

| Налада                           | Значэнні                                                                                  | Па змаўчанні | Прызначэнне                                                                            |
| -------------------------------- | ----------------------------------------------------------------------------------------- | ------------ | -------------------------------------------------------------------------------------- |
| **Разрозненне**                  | Стандартнае (192 DPI), Высокае (288 DPI), Ультра (384 DPI)                                | Высокае      | Больш высокае разрозненне павышае дакладнасць на дробным тэксце, але займае больш часу |
| **Бінарызаваць відарыс**         | Укл. / Выкл.                                                                              | Выкл.        | Павышае кантраст чыстых сканаў, пераўтвараючы іх у чорна-белыя                         |
| **Шаблон белага спіса сімвалаў** | Няма, Літары і лічбы, Лічбы + валюта, Толькі літары, Толькі лічбы, Рахунак, Формы, Уласны | Няма         | Абмяжоўвае распазнаваныя сімвалы для павышэння дакладнасці на пэўных тыпах дакументаў  |
| **Белы спіс сімвалаў**           | Адвольны тэкст                                                                            | Пуста        | Ручны набор сімвалаў, калі выбраны шаблон «Уласны»                                     |

## Сцэнарыі выкарыстання

- Пошук па сканаваных дагаворах і рахунках з дапамогай Ctrl+F
- Выманне тэксту з сфатаграфаваных дакументаў або старых папяровых запісаў
- Апрацоўка чэкаў з шаблонам «Рахунак» для дакладнага распазнавання сум у доларах і дат
- Стварэнне даступных PDF са сканаў, якія складаюцца толькі з відарысаў, для выканання патрабаванняў
- Пакетнае выманне тэксту са сканаваных кніг або інструкцый

## Парады

- Выберыце некалькі моў, калі дакумент змяшчае тэкст на розных мовах (напрыклад, англійскія загалоўкі і асноўны тэкст на японскай).
- Выкарыстоўвайце бінарызацыю для дакументаў з выцвілым або малакантрасным тэкстам: яна можа значна павысіць дакладнасць распазнавання.
- Шаблоны белага спіса «Рахунак» і «Формы» значна памяншаюць колькасць ілжывых спрацоўванняў на структураваных дакументах, ігнаруючы непатрэбныя формы сімвалаў.

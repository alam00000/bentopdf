# Колер фону

Задайце суцэльны колер фону пад усім існуючым змесцівам PDF. Інструмент стварае каляровы прамавугольнік на кожнай старонцы і накладае зверху зыходнае змесціва, таму тэкст, выявы і графіка застаюцца цалкам бачнымі на новым фоне.

## Як гэта працуе

1. Загрузіце PDF-файл.
2. Выберыце колер фону ў палітры. Па змаўчанні светла-жоўты (#FFFFCC).
3. Націсніце **Змяніць колер фону**, каб апрацаваць.
4. Абноўлены PDF спампуецца аўтаматычна.

## Параметры

- **Колер фону**: стандартная палітра для выбару любога суцэльнага колеру. Па змаўчанні светла-жоўты.

## Магчымасці

- Аднолькавы колер фону на кожнай старонцы
- Захаванне ўсяго зыходнага змесціва (тэкст, выявы, вектарная графіка) над каляровым слоем
- Захаванне зыходных памераў старонак
- Працуе з дакументамі любой колькасці старонак

## Сцэнарыі выкарыстання

- Светла-крэмавы або слановай косці фон, каб надаць дакументам мякчэйшы выгляд, падобны да паперы
- Каляровае кадзіраванне камплектаў дакументаў рознымі фонамі для розных катэгорый
- Стварэнне візуальна адрозных версій аднаго дакумента для розных аўдыторый
- Лёгкі адценне фону для лепшай чытэльнасці пры праекцыі дакументаў на экран

## Парады

- Лепш за ўсё падыходзяць светлыя, прыглушаныя колеры. Вельмі цёмны фон можа зрабіць тэкст цяжкім для чытання, калі тэкст не светлы.
- Калі трэба змяніць і фон, і колер тэксту, спачатку прымяніце колер фону, а потым выкарыстайце [Змяніць колер тэксту](./text-color) для выніку.
- Інструмент працуе на ўзроўні структуры PDF (без растравання), таму тэкст у выніку застаецца даступным для вылучэння і пошуку.

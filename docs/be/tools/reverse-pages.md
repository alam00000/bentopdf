# Адваротны парадак старонак

Перавярніце парадак старонак PDF, каб апошняя старонка стала першай, перадапошняя другой і гэтак далей. Падтрымліваецца пакетная апрацоўка некалькіх файлаў адразу.

## Як гэта працуе

1. Загрузіце адзін або некалькі файлаў PDF.
2. Націсніце кнопку апрацоўкі.
3. Кожны файл апрацоўваецца асобна. Калі вы загрузілі некалькі файлаў, вынікам будзе архіў ZIP з усімі перавернутымі PDF.
4. Адзін файл спампоўваецца адразу як перавернуты PDF.

## Магчымасці

- Пакетная апрацоўка: змяненне парадку ў некалькіх PDF за адну аперацыю
- Адзін файл на выхадзе для аднаго PDF, ZIP для некалькіх
- Кнопкі выдалення кожнага файла перад апрацоўкай
- Захоўвае ўвесь змест і фарматаванне старонак

## Сцэнарыі выкарыстання

- Выпраўленне дакумента, які быў адсканаваны ў адваротным парадку
- Падрыхтоўка PDF прэзентацыі для чытання з канца ў пачатак
- Змяненне парадку старонак для пэўных працэсаў друку, якія падаюць старонкі ў адваротным парадку
- Выпраўленне дакумента, старонкі якога выпадкова сабралі задам наперад

## Парады

- Кожны файл у пакеце перагортваецца асобна: самі файлы не мяняюць парадак адзін адносна аднаго.
- Для больш дэталёвага змянення парадку старонак (не толькі поўнага перагортвання) выкарыстоўвайце [Дубляваць і арганізаваць](./organize-pdf).

# PDF у SVG

Пераўтварае кожную старонку PDF у файл SVG (Scalable Vector Graphics). У адрозненне ад растравых фарматаў, SVG захоўвае вектарныя контуры, тэкст і фігуры, таму вынік маштабуецца да любога памеру без пікселізацыі. Працуе на PyMuPDF.

## Як гэта працуе

1. Загрузіце адзін ці некалькі PDF, націснуўшы на вобласць загрузкі або перацягнуўшы туды файлы. Можна дадаць некалькі файлаў і кіраваць імі асобна.
2. Націсніце **Пераўтварыць**, каб апрацаваць усе загружаныя файлы.
3. Адзін файл з адной старонкай спампоўваецца як асобны `.svg`. Усё астатняе спампоўваецца як архіў ZIP.

## Налады

У гэтага інструмента няма налад. Кожная старонка пераўтвараецца ў SVG уласным вектарным экспартам PyMuPDF.

## Фармат выніку

- **Адзін файл, адна старонка**: `filename.svg`
- **Адзін файл, некалькі старонак**: `filename_svg.zip` з `page_1.svg`, `page_2.svg` і г.д.
- **Некалькі файлаў**: `pdf_to_svg.zip` з файламі, упарадкаванымі па назвах зыходных дакументаў.

## Сцэнарыі выкарыстання

- Выманне вектарных схем, графікаў або ілюстрацый са справаздач PDF для вэб-старонак.
- Рэдагаванне змесціва старонак PDF у вектарным рэдактары, такім як Inkscape або Illustrator.
- Убудаванне маштабуемых праглядаў старонак у адаптыўныя вэб-праграмы.
- Выманне лагатыпаў або графікі з брашур PDF з захаваннем выразных краёў.

## Парады

- SVG лепш за ўсё працуе з PDF з вектарным змесцівам. Сканаваныя дакументы або PDF з мноствам відарысаў дадуць вялікія файлы SVG з убудаванымі растравымі данымі.
- Для растравага выніку з PDF з мноствам відарысаў выкарыстайце [PDF у PNG](./pdf-to-png) або [PDF у JPG](./pdf-to-jpg).
- Інструмент падтрымлівае пакетнае пераўтварэнне: загрузіце некалькі PDF адразу, каб пераўтварыць іх за адзін запуск.

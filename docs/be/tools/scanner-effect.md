# Эфект сканера

Ператварыце чысты лічбавы PDF у дакумент, які выглядае так, быццам выйшаў з планшэтнага сканера. Інструмент ужывае наладжвальны шум, лёгкі паварот, размыццё, змяненне яркасці і неабавязковае пажаўценне, каб імітаваць недахопы фізічнага сканавання.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Рэдактар адкрываецца з жывым папярэднім праглядам першай старонкі побач з панэллю налад.
3. Наладзьце параметры эфекту сканавання паўзункамі і пераключальнікамі.
4. Папярэдні прагляд абнаўляецца ў рэальным часе пры змене налад.
5. Націсніце **Ужыць эфект сканера**, каб апрацаваць усе старонкі і спампаваць вынік.

## Параметры

- **Colorspace (пераключальнік Grayscale)**: пераўтварыць вынік у адценні шэрага для класічнага чорна-белага выгляду скана.
- **Рамка**: дадаць лёгкую цёмную рамку па краях старонкі, каб імітаваць артэфакты краёў сканера.
- **Паварот**: ужыць лёгкі паварот (ад -5 да +5 градусаў), каб імітаваць крыва пададзеную паперу.
- **Варыяцыя павароту**: дадаць выпадковае адхіленне вугла павароту, каб кожная старонка нахілялася крыху па-рознаму.
- **Яркасць**: павысіць або панізіць агульную яркасць.
- **Кантраст**: наладзіць кантраснасць, каб імітаваць ваганні якасці тонера.
- **Размытасць**: ужыць размыццё па Гаусе, каб змякчыць краі тэксту як у скане нізкай якасці.
- **Шум**: дадаць выпадковы шум пікселяў, каб імітаваць зярністасць сенсара сканера. Больш высокія значэнні даюць больш зярністы вынік.
- **Жаўтаватасць**: дадаць цёплы жоўты адценак, каб імітаваць старую або перапрацаваную паперу.
- **Раздзяляльнасць**: задаць DPI выніку. Ніжэйшыя значэнні ствараюць больш піксельны выгляд, падобны да скана.
- **Скінуць**: вярнуць усе налады да стандартных значэнняў.

## Магчымасці

- Папярэдні прагляд у рэальным часе, які абнаўляецца пры змене кожнага параметра
- Выпадковае адхіленне павароту для кожнай старонкі для рэалістычнай варыятыўнасці
- Дзесяць параметраў, якія наладжваюцца незалежна
- Рэжым адценняў шэрага для сапраўднага чорна-белага скана
- Кіраванне разрозненнем ад нізкага DPI, як у факса, да высокага DPI архіўнай якасці

## Сцэнарыі выкарыстання

- Каб лічбава створаныя дакументы выглядалі адсканаванымі і надрукаванымі
- Імітацыя старэння фізічных дакументаў для ўзнаўлення гістарычных дакументаў
- Тэставанне праграм OCR на сканах дрэннай якасці
- Стварэнне дакументаў, якія адпавядаюць візуальнаму стылю існых сканаваных архіваў

## Парады

- Пачынайце з невялікіх значэнняў. Шум 10-20, лёгкі паварот на 0,5 градуса і мінімальнае размыццё ўжо даюць пераканаўчы выгляд скана.
- Спалучайце рэжым адценняў шэрага з лёгкім пажаўценнем для эфекту "ксеракопіі з ксеракопіі".
- Нізкае разрозненне (100-150 DPI) стварае найбольш рэалістычны выгляд факса.

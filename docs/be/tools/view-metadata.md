# Праглядзець метаданыя

Вывучайце схаваныя ўласцівасці, убудаваныя ў PDF-файл. Інструмент паказвае звесткі пра дакумент (назва, аўтар, даты), метаданыя XMP, памеры старонак і іншыя структурныя даныя ў зручным для чытання выглядзе.

## Як гэта працуе

1. Загрузіце PDF-файл.
2. Інструмент адразу разбірае файл і паказвае ўсе даступныя метаданыя ў выглядзе ўпарадкаваных раздзелаў.
3. Праглядзіце слоўнік звестак пра дакумент, дрэва метаданых XMP і структурныя ўласцівасці.
4. Асобны крок апрацоўкі не патрэбны: метаданыя паказваюцца адразу пасля загрузкі файла.

## Магчымасці

- Паказвае стандартныя палі звестак пра дакумент: загаловак, аўтар, тэма, ключавыя словы, стваральнік, вытворца
- Паказвае даты стварэння і змянення ў зручным для чытання фармаце
- Разбірае і адлюстроўвае поўнае дрэва метаданых XMP з укладзенымі прасторамі імёнаў
- Пераўтварае фармат даты PDF (`D:20240101120000Z`) у зразумелыя даты
- Раздзелы можна згортваць для зручнай навігацыі

## Раздзелы метаданых

| Раздзел                   | Змест                                                                                     |
| ------------------------- | ----------------------------------------------------------------------------------------- |
| **Звесткі пра дакумент**  | Назва, аўтар, тэма, ключавыя словы, стваральнік, вытворца, дата стварэння, дата змянення  |
| **Метаданыя XMP**         | Поўнае дрэва метаданых на аснове XML з прасторамі імёнаў Dublin Core, XAP, PDF і ўласнымі |
| **Уласцівасці дакумента** | Колькасць старонак, версія PDF, памер файла, стан шыфравання                              |

## Сцэнарыі выкарыстання

- Праверка, хто аўтар PDF і калі ён быў зменены апошні раз
- Праверка, што метаданыя правільна зададзены перад публікацыяй дакумента
- Аўдыт PDF на прыватнасць: праверка, якія асабістыя звесткі ўбудаваны
- Вызначэнне праграмы, з дапамогай якой PDF быў створаны або зменены (праз поле Producer)
- Прагляд метаданых XMP для адпаведнасці патрабаванням кіравання лічбавымі актывамі

## Парады

- Радкі дат PDF, якія пачынаюцца з `D:`, аўтаматычна пераўтвараюцца ў фармат вашага мясцовага часавага пояса.
- Калі палі метаданых пустыя, стваральнік PDF проста іх не запоўніў. Не ўсе PDF маюць багатыя метаданыя.
- Каб змяніць метаданыя пасля прагляду, выкарыстоўвайце [Рэдагаваць метаданыя](./edit-metadata). Каб цалкам іх выдаліць, выкарыстоўвайце «Выдаліць метаданыя».

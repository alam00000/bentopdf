# Чаргаваць і змяшаць старонкі

Перамяжоўвайце старонкі з некалькіх PDF-файлаў так, каб яны чаргаваліся паміж дакументамі. Гэты інструмент патрэбен, калі звычайнае аб'яднанне проста дадало б файлы адзін за адным, а вам трэба старонка 1 файла A, потым старонка 1 файла B, потым старонка 2 файла A і гэтак далей.

## Як гэта працуе

1. Загрузіце як мінімум два PDF-файлы праз вобласць загрузкі.
2. Інструмент пакажа кожны файл з колькасцю старонак і памерам.
3. Перацягвайце за маркеры, каб змяніць, старонкі якога файла ідуць першымі ў паслядоўнасці.
4. Націсніце **Змяшаць старонкі**, каб атрымаць вынік.
5. Вынік спампуецца як `alternated-mixed.pdf`.

## Магчымасці

- Чаргаванне старонак любой колькасці PDF (мінімум два)
- Змена парадку файлаў перацягваннем для кіравання прыярытэтам чаргавання
- Захаванне закладак з зыходных дакументаў
- Паказ колькасці старонак і памеру кожнага загружанага файла
- Апрацоўка ў асобным web worker для спагаднага інтэрфейсу

## Сцэнарыі выкарыстання

- Зборка двухбаковых сканаў, дзе няцотныя і цотныя старонкі сканаваліся асобна
- Спалучэнне аркушаў з пытаннямі і адказаў, каб пасля кожнага пытання ішоў адказ
- Пастаронкавае аб'яднанне двухмоўных дакументаў (напрыклад, англійская на адной старонцы, пераклад на наступнай)
- Чаргаванне сканаў пярэдняга і адваротнага бакоў з аднабаковага сканера

## Парады

- Калі ў зыходных PDF розная колькасць старонак, старонкі карацейшага дакумента скончацца раней, а астатнія старонкі даўжэйшага з'явяцца ў канцы.
- Парадак файлаў важны: першы файл у спісе дае першую старонку выніку. Пры неабходнасці перацягніце, каб змяніць парадак.

# TIFF у PDF

Пераўтварайце файлы TIFF у PDF, у тым ліку шматстаронкавыя TIFF. Кожная старонка (або "IFD") у файле TIFF становіцца асобнай старонкай выніковага PDF. Гэта асабліва зручна для сканаваных дакументаў, факсаў і медыцынскіх відарысаў, якія часта захоўваюцца як шматстаронкавыя TIFF.

## Падтрымліваемыя фарматы

| Фармат | Пашырэнні       |
| :----- | :-------------- |
| TIFF   | `.tiff`, `.tif` |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце файлы TIFF.
2. Праверце спіс файлаў і кіруйце ім пры неабходнасці.
3. Націсніце **Канвертаваць у PDF**. Вынік спампоўваецца як `from_tiff.pdf`.

Інструмент дэкадуе кожны файл TIFF з дапамогай дэкодэра TIFF на JavaScript і выцягвае сырыя даныя пікселяў RGBA кожнай старонкі. Кожная старонка адмалёўваецца на палатне, экспартуецца ў PNG і ўбудоўваецца ў PDF. Памеры старонак адпавядаюць зыходным старонкам TIFF.

## Параметры

Гэты інструмент не мае дадатковых налад якасці. Відарысы ўбудоўваюцца ў родным разрозненні.

## Сцэнарыі выкарыстання

- Пераўтварэнне шматстаронкавых факсаў (TIFF-F) у больш партатыўны фармат PDF
- Ператварэнне архіваў сканаваных дакументаў у TIFF у PDF з пошукам (пасля выкарыстайце інструмент OCR)
- Апрацоўка медыцынскіх відарысаў (гісталагічныя прэпараты, экспарт з радыялогіі) у фармаце TIFF
- Пераўтварэнне файлаў TIFF з ГІС або спадарожнікавымі здымкамі ў дакументы, якімі зручна дзяліцца

## Парады

- Шматстаронкавыя TIFF падтрымліваюцца цалкам. 10-старонкавы TIFF дасць 10-старонкавы PDF. Падзяляць TIFF загадзя не трэба.
- Вельмі вялікія файлы TIFF (сотні мегабайт) могуць апрацоўвацца даўжэй, бо ўвесь файл трэба дэкадаваць у памяці браўзера.
- Калі для выніковага PDF патрэбны OCR, пасля пераўтварэння апрацуйце яго інструментам [OCR PDF](./ocr-pdf).

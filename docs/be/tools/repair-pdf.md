# Аднавіць PDF

Калі PDF не адкрываецца, паказвае скажоны змест або выклікае памылкі ў праграме прагляду, гэты інструмент спрабуе перабудаваць яго ўнутраную структуру. Ён выкарыстоўвае рухавік аднаўлення QPDF, які можа аднавіць даныя пры многіх відах пашкоджанняў: зламаных табліцах перакрыжаваных спасылак, абрэзаных патоках, няслушных спасылках на аб'екты і іншых.

## Як гэта працуе

1. Загрузіце адзін або некалькі пашкоджаных файлаў PDF.
2. Націсніце **Аднавіць PDF**.
3. Адзін адноўлены файл спампоўваецца адразу. Некалькі файлаў ствараюць архіў ZIP.

Інструмент прапускае кожны файл праз QPDF са сцягам `--decrypt`, які прымушае QPDF прачытаць і перазапісаць усю структуру PDF, па ходзе выпраўляючы праблемы, якія можна выправіць.

## Магчымасці

- Пакетнае аднаўленне некалькіх PDF за адну аперацыю
- Аўтаматычнае вызначэнне файлаў, якія можна і нельга аднавіць
- Справаздача пра поспех або памылку для кожнага файла пры апрацоўцы некалькіх файлаў
- Выкарыстоўвае QPDF (WebAssembly), правераную часам бібліятэку пераўтварэння PDF

## Што можна выправіць

- Зламаныя або адсутныя табліцы перакрыжаваных спасылак
- Абрэзаныя канцы файлаў пасля незавершаных спамповак
- Няслушную нумарацыю аб'ектаў і даўжыні патокаў
- Дробныя структурныя неадпаведнасці ад памылковых генератараў PDF
- Артэфакты шыфравання пасля няўдалых спроб расшыфроўкі

## Што выправіць нельга

- Моцна абрэзаныя файлы, у якіх адсутнічае большая частка даных
- PDF, зашыфраваныя паролем, якога ў вас няма
- Файлы, якія насамрэч не з'яўляюцца PDF (няправільнае пашырэнне)
- Пашкоджанне відарысаў унутры PDF (структура выпраўляецца, але даныя пікселяў не ствараюцца нанова)

## Сцэнарыі выкарыстання

- Аднаўленне PDF пасля няўдалай спампоўкі з электроннай пошты
- Адкрыццё файлаў, створаных старымі або нестандартнымі генератарамі PDF
- Выпраўленне PDF, якія працуюць у адной праграме прагляду, але не ў іншай
- Падрыхтоўка пашкоджаных архіўных дакументаў да доўгатэрміновага захоўвання

## Парады

- Калі аднавіць не атрымалася, паспрабуйце спачатку адкрыць файл у браўзеры: у браўзераў ёсць уласная логіка аднаўлення, і яны могуць адмаляваць дастаткова зместу для паўторнага захавання.
- Для зашыфраваных PDF, якія не ўдаецца аднавіць, спачатку выкарыстайце "Расшыфраваць PDF", а потым аднавіце расшыфраваны вынік.

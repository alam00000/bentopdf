# Markdown у PDF

Поўнафункцыйны рэдактар Markdown з жывым перадпраглядам і экспартам у PDF адным націскам. Пішыце з нуля, запампуйце існуючы файл `.md` або ўстаўце змесціва з буфера абмену. Рэдактар паказвае ваш Markdown у рэальным часе і экспартуе стыльны PDF праз убудаваны механізм друку браўзера.

## Падтрымліваемыя фарматы

| Уваход          | Апісанне                            |
| :-------------- | :---------------------------------- |
| Файлы `.md`     | Запампоўванне кнопкай «Запампаваць» |
| Непасрэдны ўвод | Увядзіце або ўстаўце ў рэдактар     |

## Як гэта працуе

1. Адкрыйце інструмент «Markdown у PDF». Рэдактар загружаецца ў падзеленым выглядзе: зыходны Markdown злева, перадпрагляд справа.
2. Пішыце Markdown, устаўце яго або націсніце **Запампаваць**, каб загрузіць файл `.md`.
3. Пераключайцеся паміж светлай і цёмнай тэмамі паўзунком тэмы на панэлі інструментаў.
4. Націсніце **Экспартаваць PDF** (або `Ctrl/Cmd + S`), каб стварыць PDF праз дыялог друку браўзера.

## Магчымасці

Рэдактар падтрымлівае шырокі набор магчымасцей Markdown, акрамя базавых:

- **Стандартны Markdown**: загалоўкі, тлусты шрыфт, курсіў, спасылкі, відарысы, спісы, цытаты, гарызантальныя лініі
- **Блокі кода** з падсветкай сінтаксісу для больш чым 15 моў (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash і іншыя)
- **Дыяграмы Mermaid**: блок-схемы, дыяграмы паслядоўнасці, ER-дыяграмы і іншыя тыпы дыяграм Mermaid паказваюцца непасрэдна ў перадпраглядзе
- **Табліцы** са стандартным сінтаксісам табліц Markdown
- **Спісы задач** са сцяжкамі
- **Зноскі**, **ніжні індэкс**, **верхні індэкс**
- **Спісы азначэнняў**, **абрэвіятуры**
- Падтрымка **эмодзі** (`:smile:` паказваецца як эмодзі)
- **Вылучэнні** (`==marked text==`) і **ўстаўкі** (`++inserted text++`)
- **Аўтаспасылкі**: звычайныя URL ператвараюцца ў спасылкі
- Генерацыя **зместу**
- **Якары** на загалоўках

## Сцэнарыі выкарыстання

- Напісанне праектнай дакументацыі і экспарт акуратнага PDF для зацікаўленых бакоў
- Стварэнне тэхнічных справаздач з прыкладамі кода і архітэктурнымі дыяграмамі Mermaid
- Пераўтварэнне README з GitHub у PDF для афлайн-выкарыстання або друку
- Падрыхтоўка прапановы або спецыфікацыі са спісамі задач і табліцамі
- Стварэнне стыльнага раздатковага матэрыялу з канспектаў лекцый, напісаных у Markdown

## Парады

- Вынік PDF выкарыстоўвае функцыю друку ў PDF браўзера. У Chrome можна наладзіць палі і маштаб у дыялогу друку перад захаваннем.
- Дыяграмы Mermaid паказваюцца ў перадпраглядзе, але пры першым выкарыстанні ім можа спатрэбіцца крыху часу на ініцыялізацыю.
- Выкарыстоўвайце спалучэнне `Ctrl/Cmd + S`, каб экспартаваць без націскання кнопкі.

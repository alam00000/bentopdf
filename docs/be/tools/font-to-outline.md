# Шрыфт у контуры

Пераўтварэнне шрыфтоў у контуры ператварае кожны сімвал тэксту з гліфа шрыфту ў вектарны контур. PDF больш не залежыць ад усталяваных шрыфтоў: ён выглядае аднолькава на любой прыладзе, аперацыйнай сістэме і прынтары. Гэта стандартны этап дадрукарскай падрыхтоўкі.

## Як гэта працуе

1. Запампуйце адзін або некалькі файлаў PDF.
2. Націсніце **Пераўтварыць у контуры**.
3. Ghostscript пераўтварае ўвесь тэкст у вектарныя контуры.
4. Спампуйце вынік. Некалькі файлаў ствараюць архіў ZIP.

Наладжваць нічога не трэба. Інструмент выкарыстоўвае Ghostscript (WebAssembly), каб пераўтварыць усе спасылкі на шрыфты ў контуры за адзін праход.

## Што змяняецца

- Сімвалы тэксту становяцца вектарнымі крывымі (крывыя Безье)
- Убудоўванне шрыфтоў больш не патрэбнае: PDF самадастатковы на ўзроўні гліфаў
- Памер файла можа павялічыцца, бо вектарныя контуры звычайна займаюць больш, чым спасылкі на шрыфты
- Выгляд захоўваецца дакладна

## Што вы губляеце

- Вылучэнне і капіраванне тэксту
- Пошук па тэксце (Ctrl+F перастае працаваць)
- Магчымасць рэдагаваць тэкст
- Даступнасць для чытачоў экрана

## Сцэнарыі выкарыстання

- Адпраўка PDF у друкарню, якая патрабуе шрыфтоў у контурах
- Абмен дакументамі з уласнымі або ліцэнзаванымі шрыфтамі з людзьмі, у якіх гэтых шрыфтоў няма
- Прадухіленне замены шрыфтоў, якая змяняе выгляд дакумента ў іншых сістэмах
- Падрыхтоўка PDF для лазернай гравіроўкі або ЧПУ-рэзкі, дзе патрэбны вектарныя дадзеныя
- Карэктнае адлюстраванне PDF з вялікай колькасцю лагатыпаў на ўсіх платформах

## Парады

- Захоўвайце арыгінальны PDF. Пераўтварэнне ў контуры незваротнае: контуры нельга вярнуць у рэдагаваны тэкст.
- Калі тэкст павінен заставацца даступным для пошуку, разгледзьце інструмент «Растарызаваць PDF» з наступным OCR.
- PDF з контурамі звычайна большыя. Пасля пераўтварэння запусціце «Сціснуць PDF», калі важны памер файла.

# Змест

Гэты інструмент чытае закладкі (структуру) вашага PDF і стварае адфарматаваную старонку зместу, якая дадаецца ў пачатак дакумента. Калі ў PDF ужо ёсць закладкі, але няма бачнай старонкі зместу, гэты інструмент створыць яе аўтаматычна.

## Як гэта працуе

1. Загрузіце PDF, які змяшчае закладкі.
2. Наладзьце загаловак зместу, памер шрыфту і гарнітуру.
3. Пры жаданні адзначце **Дадаць закладку для старонкі зместу**, каб уключыць саму старонку зместу ў дрэва закладак.
4. Націсніце **Стварыць змест**, каб апрацаваць файл.
5. Абноўлены PDF са старонкай зместу ў пачатку спампоўваецца аўтаматычна.

## Параметры

- **Загаловак зместу**: загаловак уверсе створанай старонкі. Па змаўчанні "Змест".
- **Памер шрыфта**: ад 10pt да 72pt. Па змаўчанні 12pt.
- **Сямейства шрыфтоў**: выбар з варыянтаў Times Roman, Helvetica або Courier (звычайны, тлусты, курсіў, тлусты курсіў). Па змаўчанні Helvetica.
- **Дадаць закладку для старонкі зместу**: калі адзначана, у дрэва структуры PDF дадаецца закладка на саму старонку зместу.

## Магчымасці

- Чытае ўсю іерархію закладак з PDF
- Стварае акуратна адфарматаваную старонку зместу з нумарамі старонак
- Падтрымлівае ўкладзеныя ўзроўні закладак з водступамі
- Выбар з 12 убудаваных шрыфтоў PDF
- Неабавязковая закладка на саму старонку зместу

## Сцэнарыі выкарыстання

- Даданне зместу для друку ў электронныя кнігі або справаздачы, якія маюць толькі лічбавыя закладкі
- Стварэнне зместу для аб'яднанага дакумента пасля злучэння некалькіх PDF
- Стварэнне даведачнай старонкі для доўгіх тэхнічных дапаможнікаў
- Падрыхтоўка дакументаў да друку, дзе чакаецца бачны змест

## Парады

- Калі ў PDF няма закладак, спачатку стварыце іх у інструменце [Рэдагаваць закладкі](./bookmark), а потым вярніцеся сюды, каб стварыць змест.
- Для вялікіх дакументаў больш буйны шрыфт, напрыклад 14pt або 16pt, палепшыць чытэльнасць.

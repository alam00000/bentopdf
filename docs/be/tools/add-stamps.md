# Дадаць штампы

Размяшчайце штампы-выявы на старонках PDF ва ўбудаваным праглядальніку з панэллю анатацый для штампаў. Штампы могуць змяшчаць ваша імя, што карысна для працэсаў зацвярджэння, рэцэнзавання і пазначэння дакументаў.

## Як гэта працуе

1. Увядзіце сваё імя ў поле **Імя карыстальніка для штампа**. Гэта імя будзе на створаных вамі штампах.
2. Загрузіце PDF-файл, націснуўшы на вобласць загрузкі або перацягнуўшы яго туды.
3. Адкрыецца рэдактар штампаў з вашым дакументам у праглядальніку.
4. Выкарыстайце інструмент штампа-выявы на панэлі, каб выбраць і размясціць штампы на любой старонцы.
5. Пры неабходнасці змяніце размяшчэнне і памер штампаў.
6. Націсніце **Захаваць PDF са штампамі**, каб спампаваць вынік.

## Магчымасці

- Убудаваны праглядальнік PDF з панэллю анатацый для штампаў
- Подпіс імя карыстальніка на створаных штампах
- Размяшчэнне штампаў-выяў на любой старонцы
- Размяшчэнне і змена памеру перацягваннем
- Аўтаматычны памер праглядальніка паводле прапорцый старонкі
- Паказ файла з назвай і памерам

## Сцэнарыі выкарыстання

- Даданне штампаў "APPROVED" або "REVIEWED" да дакументаў у працэсе рэцэнзавання
- Размяшчэнне выяў пячаткі кампаніі або натарыуса на афіцыйных дакументах
- Пазначэнне старонак штампам "RECEIVED" з імем рэцэнзента
- Даданне штампаў кантролю якасці да справаздач аб праверцы

## Парады

- Задайце імя карыстальніка для штампа перад загрузкай PDF. Імя ўбудоўваецца ў метаданыя штампа.
- Праглядальнік падладжвае сваю вышыню пад прапорцыі першай старонкі PDF для зручнага прагляду.
- Для тэкставых вадзяных знакаў замест штампаў-выяў выкарыстайце інструмент [Дадаць вадзяны знак](./add-watermark).

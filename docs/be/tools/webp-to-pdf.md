# WebP у PDF

Пераўтварайце выявы ў фармаце Google WebP у PDF. Гэта асабліва карысна, калі вы спампавалі з сеціва выявы ў фармаце WebP і вам патрэбны больш універсальны фармат для друку або абмену.

## Падтрымліваемыя фарматы

| Фармат | Пашырэнні |
| :----- | :-------- |
| WebP   | `.webp`   |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце файлы WebP.
2. Праглядзіце спіс файлаў і выдаліце непатрэбныя.
3. Выберыце ўзровень **Якасць PDF**.
4. Націсніце **Пераўтварыць у PDF**. Вынік спампуецца як `from_webps.pdf`.

Унутры кожная выява WebP дэкадуецца праз canvas API браўзера, а затым убудоўваецца ў PDF з дапамогай pdf-lib. Гэта значыць, што пераўтварэнне працуе ў любым браўзеры, які падтрымлівае дэкадаванне WebP (так робяць усе сучасныя браўзеры).

## Параметры

**Якасць PDF** кіруе сцісканнем пры ўбудаванні выяў:

- **Высокая якасць**: захоўвае найбольш дэталей.
- **Сярэдняя якасць** (па змаўчанні): збалансаваны вынік.
- **Нізкая якасць**: найменшы памер файла.

## Сцэнарыі выкарыстання

- Пераўтварэнне спампаваных з сеціва выяў WebP у PDF для друку
- Афармленне здымкаў экрана WebP з Chrome або Edge у дакументацыю
- Стварэнне PDF-партфоліо з выяў, экспартаваных з дызайнерскіх праграм, якія па змаўчанні захоўваюць у WebP
- Архіваванне выяў WebP у больш універсальным фармаце

## Парады

- Унутры WebP дэкадуецца ў PNG перад убудаваннем у PDF, таму выявы WebP без страт захоўваюць якасць пры наладзе «Высокая».
- Калі ў вас сумесь WebP і іншых фарматаў выяў, выкарыстоўвайце інструмент [Відарысы ў PDF](./image-to-pdf): ён прымае ўсё адразу.

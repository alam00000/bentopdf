# Выдаліць абмежаванні

PDF можа мець два тыпы пароляў: пароль карыстальніка (патрэбны для адкрыцця файла) і пароль уладальніка (вызначае, што можна рабіць з файлам). Гэты інструмент выдаляе абодва разам з усімі звязанымі абмежаваннямі: блакіроўкамі друку, рэдагавання, капіравання і анатавання.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Калі PDF мае пароль уладальніка, увядзіце яго ў поле **Пароль уладальніка**. Пакіньце поле пустым, калі PDF мае толькі абмежаванні выкарыстання без пароля.
3. Націсніце **Выдаліць абмежаванні**.
4. Спампуйце PDF без абмежаванняў.

Інструмент выкарыстоўвае сцягі QPDF `--decrypt` і `--remove-restrictions`, каб стварыць чыстую копію без абмежаванняў.

## Што выдаляецца

- Абарона паролем (і пароль карыстальніка, і пароль уладальніка)
- Абмежаванні друку
- Абмежаванні рэдагавання
- Абмежаванні капіравання тэксту і відарысаў
- Абмежаванні анатавання і каментавання
- Усе іншыя абмежаванні бяспекі, закадаваныя ў PDF

## Сцэнарыі выкарыстання

- Разблакіроўка вашага ўласнага PDF, пароль якога вы задалі шмат гадоў таму
- Выдаленне абмежаванняў друку з дакумента, да якога ў вас ёсць законны доступ
- Уключэнне капіравання і ўстаўкі ў даведачных матэрыялах для нататак
- Падрыхтоўка PDF для інструментаў даступнасці, якія не працуюць з абмежаванымі дакументамі

## Парады

- Калі пароль уладальніка зададзены, вы павінны яго ведаць. Гэты інструмент не ўзломвае і не падбірае паролі.
- Калі трэба пакінуць файл зашыфраваным, але змяніць пэўныя дазволы, выкарыстоўвайце інструмент "Змяніць дазволы".
- Выніковы файл зусім не зашыфраваны: любы, хто яго атрымае, зможа свабодна яго адкрыць.

## Звязаныя інструменты

- [Зашыфраваць PDF](./protect-pdf): зноў зашыфраваць з новымі наладамі

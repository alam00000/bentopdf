# PDF у CSV

Вымае табліцы з PDF і экспартуе іх у файл CSV. Інструмент шукае таблічныя даныя на кожнай старонцы з дапамогай рухавіка выяўлення табліц PyMuPDF, а потым запісвае ўсе знойдзеныя радкі ў адзін файл са значэннямі праз коску.

## Як гэта працуе

1. Загрузіце PDF, націснуўшы на вобласць загрузкі або перацягнуўшы туды файл.
2. Націсніце **Пераўтварыць**, каб пачаць выманне табліц.
3. Інструмент праглядае кожную старонку і аўтаматычна знаходзіць табліцы.
4. Спампоўваецца файл `.csv` з усімі вынятымі данымі табліц.

Табліцы з розных старонак у выніку раздзеленыя пустымі радкамі. Ячэйкі з коскамі, двукоссямі або пераносамі радкоў экранаваныя паводле RFC 4180.

## Налады

У гэтага інструмента няма налад. Усе знойдзеныя ў дакуменце табліцы вымаюцца і аб'ядноўваюцца ў адзін CSV.

## Фармат выніку

- Адзін файл `filename.csv` з усімі знойдзенымі табліцамі.

## Сцэнарыі выкарыстання

- Перанос фінансавых даных з PDF-выпісак банка або рахункаў у электронную табліцу.
- Выманне табліц цэн з камерцыйных прапаноў пастаўшчыкоў для параўнання.
- Пераўтварэнне таблічных даных даследаванняў з PDF у фармат для інструментаў аналізу.
- Перанос даных са старых справаздач PDF у базы даных.

## Парады

- Калі табліцы не знойдзеныя, інструмент паказвае паведамленне «Табліцы не знойдзены». Звычайна гэта значыць, што PDF выкарыстоўвае тэкставы макет, які выглядае як табліца, але не з'яўляецца сапраўднай табліцай.
- Для большага кантролю над асобнымі табліцамі выкарыстайце [Выняць табліцы з PDF](./extract-tables): там можна выбраць фармат CSV, JSON або Markdown.
- Калі даныя патрэбныя ў фармаце Excel з асобным аркушам на кожную табліцу, выкарыстайце [PDF у Excel](./pdf-to-excel).

# PDF у JPG

Пераўтварае кожную старонку PDF у відарыс JPG. Аднастаронкавыя дакументы спампоўваюцца як асобны файл `.jpg`. Шматстаронкавыя PDF даюць архіў ZIP з адным JPG на кожную старонку.

## Як гэта працуе

1. Загрузіце PDF, націснуўшы на вобласць загрузкі або перацягнуўшы туды файл. Інструмент паказвае імя файла, памер і колькасць старонак.
2. Наладзьце паўзунок **Якасць**, каб кіраваць сцісканнем JPG.
3. Націсніце **Пераўтварыць**, каб пачаць апрацоўку.
4. Вынік спампуецца аўтаматычна: адзін JPG для аднастаронкавых PDF або файл ZIP для шматстаронкавых дакументаў.

## Налады

- **Якасць**: паўзунок ад 0% да 100% (па змаўчанні 90%). Большыя значэнні даюць больш выразныя відарысы большага памеру. Меншыя значэнні сціскаюць мацней.

Унутры старонкі рэндэрацца з маштабам 2x, таму разрозненне выніку ўдвая большае за памеры старонкі PDF. Стандартная старонка фармату Letter дае відарыс прыкладна 1 224 x 1 584 пікселі.

## Фармат выніку

- **Адна старонка**: `filename.jpg`
- **Некалькі старонак**: `filename_jpgs.zip` з `page_1.jpg`, `page_2.jpg` і г.д.

## Сцэнарыі выкарыстання

- Стварэнне мініяцюр для сістэмы кіравання дакументамі.
- Абмен старонкай справаздачы ў чаце або лісце, дзе PDF не падтрымліваецца.
- Стварэнне відарысаў з дыяграм або ілюстрацый PDF.
- Архіваванне сканаваных дакументаў як асобных відарысаў.

## Парады

- Для выніку без страт выкарыстайце [PDF у PNG](./pdf-to-png).
- Якасць 80-90% дае добры баланс паміж памерам файла і візуальнай дакладнасцю.
- Калі для кожнай старонкі патрэбны пэўны фармат, паглядзіце [Канструктар рабочага працэсу PDF](./pdf-workflow) з вузлом вываду PDF у відарысы.

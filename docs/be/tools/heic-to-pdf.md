# HEIC у PDF

Пераўтварайце відарысы HEIC/HEIF у PDF. HEIC з'яўляецца стандартным фарматам фота на iPhone і iPad пачынаючы з iOS 11. Гэты інструмент дазваляе ператварыць такія фота ў PDF без усталявання праграм на камп'ютар і без запампоўвання файлаў на сервер.

## Падтрымліваемыя фарматы

| Фармат | Пашырэнні |
| :----- | :-------- |
| HEIC   | `.heic`   |
| HEIF   | `.heif`   |

## Як гэта працуе

1. Націсніце на вобласць запампоўвання або перацягніце файлы HEIC/HEIF.
2. Праверце спіс файлаў і выдаліце непатрэбныя.
3. Націсніце **Пераўтварыць у PDF**. Вынік спампоўваецца як `from_heic.pdf`.

Кожны файл HEIC дэкадуецца бібліятэкай heic2any, якая пераўтварае яго ў PNG з якасцю 92%. Потым PNG убудоўваецца ў PDF з дапамогай pdf-lib, кожны відарыс на асобнай старонцы ў поўным разрозненні.

## Параметры

Дадатковых налад няма. Відарысы HEIC пераўтвараюцца ў PNG з высокай якасцю (0.92) перад убудоўваннем.

## Сцэнарыі выкарыстання

- Стварэнне PDF з фота з iPhone для далучэння да страхавой заявы або справаздачы
- Пераўтварэнне фота HEIC для аб'явы аб нерухомасці ў адзін дакумент для друку
- Ператварэнне здымкаў экрана iPad (фармат HEIF) у PDF для абмену
- Пакетнае пераўтварэнне фота з адпачынку для дзённіка падарожжаў

## Парады

- Дэкадаванне HEIC цалкам адбываецца ў браўзеры з дапамогай WebAssembly. Першае пераўтварэнне можа заняць крыху часу, пакуль загружаецца дэкодар.
- Калі трэба спалучыць HEIC з іншымі фарматамі відарысаў (JPG, PNG і г.д.), выкарыстоўвайце інструмент [Відарысы ў PDF](./image-to-pdf), які апрацоўвае HEIC разам з усімі іншымі фарматамі.
- Файлы HEIC з iPhone часта змяшчаюць даныя EXIF, у тым ліку каардынаты GPS. Выніковы PDF гэтыя метаданыя не захоўвае.

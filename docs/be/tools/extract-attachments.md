# Выняць далучэнні

Вымайце кожнае ўбудаванае далучэнне з аднаго або некалькіх файлаў PDF. Усе вынятыя файлы збіраюцца ў адзін архіў ZIP для спампоўвання.

## Як гэта працуе

1. Загрузіце адзін або некалькі файлаў PDF з убудаванымі далучэннямі.
2. Націсніце **Выняць далучэнні**.
3. Інструмент шукае ў кожным PDF далучэнні на ўзроўні дакумента і старонак.
4. Усе знойдзеныя файлы пакуюцца ў архіў ZIP і спампоўваюцца аўтаматычна.
5. Паведамленне пра стан паказвае, колькі далучэнняў знойдзена і іх агульны памер.

## Магчымасці

- Пакетнае выманне з некалькіх PDF адначасова
- Выманне далучэнняў як на ўзроўні дакумента, так і на ўзроўні старонак
- Вынік у выглядзе аднаго файла ZIP з усімі вынятымі файламі
- Паказ агульнай колькасці далучэнняў і іх сумарнага памеру
- Зразумелыя паведамленні, калі далучэнні не знойдзены

## Сцэнарыі выкарыстання

- Аднаўленне файлаў даных, убудаваных у PDF справаздачы
- Выманне відарысаў з партфоліо або дакумента са спецыфікацыяй
- Выманне дадатковых матэрыялаў з навучальных PDF або PDF па адпаведнасці
- Аўдыт таго, якія файлы ўбудаваны ў набор PDF

## Парады

- Калі інструмент не знаходзіць далучэнняў, PDF можа ўтрымліваць убудаваныя відарысы або даныя форм, якія не з'яўляюцца далучанымі файламі. Для ўбудаваных відарысаў карыстайцеся [Выняць відарысы](./extract-images).
- Пры апрацоўцы некалькіх PDF усе далучэнні з кожнага файла трапляюць у адзін ZIP. Назвы файлаў захоўваюцца з арыгінальных далучэнняў.

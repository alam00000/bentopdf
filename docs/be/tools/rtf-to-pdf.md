# RTF у PDF

Пераўтварайце дакументы Rich Text Format у PDF. RTF з'яўляецца кросплатформенным фарматам дакументаў, які падтрымліваюць практычна ўсе тэкставыя рэдактары. Гэты інструмент выкарыстоўвае рухавік LibreOffice у браўзеры, каб адмаляваць файлы RTF з захаваннем фарматавання: тлусты шрыфт, курсіў, табліцы і ўбудаваныя відарысы пераносяцца ў PDF.

## Падтрымліваемыя фарматы

| Фармат | Пашырэнні | Тыпы MIME                     |
| :----- | :-------- | :---------------------------- |
| RTF    | `.rtf`    | `text/rtf`, `application/rtf` |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце адзін або некалькі файлаў RTF.
2. Праверце спіс файлаў. Дадайце або выдаліце файлы пры неабходнасці.
3. Націсніце **Канвертаваць у PDF**. Рухавік LibreOffice ініцыялізуецца пры першым выкарыстанні, а потым апрацоўвае кожны файл.
4. Адзін файл спампоўваецца адразу як PDF. Некалькі файлаў перадаюцца як `rtf-converted.zip`.

## Параметры

У гэтага інструмента няма дадатковых налад. Пераўтварэнне захоўвае зыходнае фарматаванне RTF.

## Вынік

| Колькасць файлаў | Вынік                                                     |
| :--------------- | :-------------------------------------------------------- |
| 1 файл           | Спампоўка аднаго PDF (напрыклад, `letter.pdf`)            |
| 2+ файлы         | Архіў ZIP (`rtf-converted.zip`) з адным PDF на кожны файл |

## Сцэнарыі выкарыстання

- Пераўтварэнне старых дакументаў RTF са старых тэкставых рэдактараў у сучасныя PDF
- Ператварэнне шаблонаў электронных лістоў RTF у папярэдні прагляд PDF
- Апрацоўка вынікаў RTF з юрыдычных або медыцынскіх праграмных сістэм
- Пакетнае пераўтварэнне файлаў RTF з сістэмы кіравання дакументамі ў PDF для архіва

## Парады

- Рухавік LibreOffice загружаецца адзін раз і кэшуецца. Першае пераўтварэнне ў сесіі займае некалькі лішніх секунд, наступныя хутчэйшыя.
- Файлы RTF з убудаванымі аб'ектамі OLE могуць адмалёўвацца не ідэальна. Просты тэкст, відарысы і стандартнае фарматаванне пераўтвараюцца надзейна.
- Калі файлы RTF створаны ў Microsoft Word, іх таксама можна пераўтварыць праз інструмент [Word у PDF](./word-to-pdf), які прымае RTF разам з DOC і DOCX.

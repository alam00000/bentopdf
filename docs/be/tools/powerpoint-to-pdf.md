# PowerPoint у PDF

Пераўтварайце файлы прэзентацый у PDF. Кожны слайд становіцца старонкай выніковага дакумента, а тэкст, відарысы, фігуры і пераходы адмалёўваюцца рухавіком LibreOffice, які працуе ў браўзеры. Падтрымліваюцца сучасныя і старыя фарматы PowerPoint, а таксама фармат OpenDocument Presentation.

## Падтрымліваемыя фарматы

| Фармат                    | Пашырэнні |
| :------------------------ | :-------- |
| PowerPoint (сучасны)      | `.pptx`   |
| PowerPoint (стары)        | `.ppt`    |
| OpenDocument Presentation | `.odp`    |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце файлы прэзентацый.
2. Праверце спіс файлаў. Дадайце або выдаліце файлы пры неабходнасці.
3. Націсніце **Канвертаваць у PDF**. Рухавік LibreOffice загружаецца пры першым выкарыстанні, а потым пераўтварае кожны файл.
4. Адзін файл спампоўваецца адразу як PDF. Некалькі файлаў пакуюцца ў `powerpoint-converted.zip`.

## Параметры

У гэтага інструмента няма дадатковых налад. Слайды адмалёўваюцца ў іх родных памерах.

## Вынік

| Колькасць файлаў | Вынік                                                            |
| :--------------- | :--------------------------------------------------------------- |
| 1 файл           | Спампоўка аднаго PDF (зыходная назва файла з пашырэннем `.pdf`)  |
| 2+ файлы         | Архіў ZIP (`powerpoint-converted.zip`) з адным PDF на кожны файл |

## Сцэнарыі выкарыстання

- Пераўтварэнне прэзентацыі ў PDF перад тым, як падзяліцца ёю з аўдыторыяй, у якой можа не быць PowerPoint
- Стварэнне версіі слайдаў для друку на канферэнцыю або семінар
- Архіваванне прэзентацый у фармаце, які аднолькава адлюстроўваецца на любой прыладзе
- Пакетнае пераўтварэнне бібліятэкі прэзентацый ODP з LibreOffice Impress у PDF
- Стварэнне PDF-версіі пітч-дэка для ўкладанняў у электронныя лісты

## Парады

- Анімацыі і пераходы слайдаў не перадаюцца ў PDF. Кожны слайд захоўваецца як статычная старонка.
- Убудаваныя відэа не з'явяцца ў выніку. Пры неабходнасці замяніце іх скрыншотам або відарысам-запаўняльнікам.
- Нататкі дакладчыка не ўключаюцца ў стандартны экспарт PDF. Калі вам патрэбны нататкі, спачатку экспартуйце з рэжыму "Друк нататак" у самім PowerPoint.
- Рухавік LibreOffice кэшуецца пасля першай загрузкі, таму пераўтварэнне наступнай прэзентацыі ў той жа сесіі адбываецца значна хутчэй.

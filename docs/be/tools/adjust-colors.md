# Наладзіць колеры

Поўны набор інструментаў каляровай карэкцыі для PDF. Наладжвайце восем незалежных параметраў (яркасць, кантраст, насычанасць, зрух адцення, тэмпературу, тон, гаму і сэпію) з жывым праглядам, які абнаўляецца пры руху кожнага паўзунка.

## Як гэта працуе

1. Загрузіце PDF-файл.
2. Адкрыецца рэдактар з праглядам першай старонкі і панэллю налад колеру.
3. Рухайце паўзункі, каб наладзіць кожны параметр. Прагляд абнаўляецца ў рэальным часе.
4. Націсніце **Скінуць**, каб вярнуць усе паўзункі ў пачатковае становішча.
5. Націсніце **Прымяніць**, каб апрацаваць усе старонкі і спампаваць зменены PDF.

## Параметры

- **Яркасць**: асвятліць або зацямніць усю старонку (ад -100 да +100).
- **Кантраст**: павялічыць або паменшыць розніцу паміж светлымі і цёмнымі ўчасткамі (ад -100 да +100).
- **Насычанасць**: узмацніць або аслабіць інтэнсіўнасць колераў (ад -100 да +100). Значэнне -100 дае адценні шэрага.
- **Зрух адцення**: паварочвае каляровае кола, раўнамерна зрушваючы ўсе колеры.
- **Тэмпература**: робіць колеры цяплейшымі (жоўты/аранжавы) або халаднейшымі (сіні).
- **Тон**: дадае зялёны або пурпурны адцянак.
- **Гама**: наладжвае яркасць сярэдніх тонаў з дапамогай крывой гамы. Значэнні ніжэй за 1.0 зацямняюць сярэднія тоны, вышэй за 1.0 асвятляюць іх.
- **Сэпія**: прымяняе класічны эфект сэпіі. Большыя значэнні даюць мацнейшы карычневы адцянак.

## Магчымасці

- Восем незалежна наладжвальных параметраў колеру
- Жывы прагляд, які адразу рэагуе на змены паўзункоў
- Кнопка скіду для хуткага вяртання да значэнняў па змаўчанні
- Апрацоўка ўсіх старонак дакумента
- Працуе з любым змесцівам PDF (тэкст, выявы, графіка)

## Сцэнарыі выкарыстання

- Асвятленне цёмнага скана або выпраўленне перасветленых старонак
- Зніжэнне насычанасці каляровага дакумента, каб зэканоміць чарніла пры друку
- Эфект сэпіі для старадаўняга выгляду сертыфікатаў або ўзнагарод
- Выпраўленне каляровай тэмпературы фотаздымкаў, убудаваных у PDF
- Павышэнне кантрасту выцвілых або няякасных сканаваных дакументаў

## Парады

- Для хуткага пераўтварэння ў адценні шэрага перацягніце паўзунок насычанасці да -100.
- Паўзунок гамы асабліва карысны для паляпшэння чытэльнасці сканаваных дакументаў, дзе сярэднія тоны занадта цёмныя або светлыя.
- Як і іншыя інструменты эфектаў выяў, гэты растравае кожную старонку. Вынік будзе складацца з выяў, таму тэкст нельга будзе вылучыць.

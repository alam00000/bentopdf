# Нумары старонак

Дадавайце бачныя нумары на кожную старонку PDF. Вы выбіраеце месца, фармат, памер шрыфту і колер, а астатняе зробіць інструмент.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Наладзьце нумары старонак на панэлі налад, якая з'явіцца.
3. Націсніце **Дадаць нумары старонак**, каб апрацаваць файл.
4. PDF з нумарамі спампуецца аўтаматычна.

## Налады

- **Размяшчэнне**: выберыце, дзе будуць нумары: унізе па цэнтры, унізе злева, унізе справа, уверсе па цэнтры, уверсе злева або ўверсе справа.
- **Фармат**: простая нумарацыя (1, 2, 3...) або фармат «старонка X з Y» (1 / 5, 2 / 5...).
- **Памер шрыфту**: памер тэксту нумара. Па змаўчанні 12.
- **Колер**: любы колер тэксту нумара праз палітру колераў.

## Магчымасці

- Шэсць варыянтаў размяшчэння: усе куты і цэнтр
- Два фарматы нумарацыі: простая паслядоўная або «старонка X з Y»
- Памер шрыфту ад 6 да 72 пунктаў
- Поўная палітра для колеру тэксту
- Аўтаматычныя водступы ўтрымліваюць нумары ў бяспечнай зоне пры любым памеры старонкі

## Сцэнарыі выкарыстання

- Падрыхтоўка да друку дакументаў, якім патрэбныя бачныя нумары старонак
- Нумарацыя аб'яднанага PDF, сабранага з некалькіх файлаў
- Нумарацыя раздатковых матэрыялаў прэзентацыі перад распаўсюджваннем
- Паслядоўная нумарацыя юрыдычных дакументаў або дагавораў

## Парады

- Фармат «старонка X з Y» карысны для дакументаў, дзе чытачу трэба ведаць агульны аб'ём, напрыклад прапаноў або справаздач.
- Калі патрэбныя розныя стылі нумарацыі для розных раздзелаў (напрыклад, рымскія лічбы для ўступнай часткі), выкарыстайце інструмент [Дадаць пазнакі старонак](./add-page-labels).

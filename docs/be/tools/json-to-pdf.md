# JSON у PDF

Аднаўляйце дакументы PDF з файлаў JSON, раней створаных інструментам BentoPDF **PDF у JSON**. Гэта інструмент зваротнага пераўтварэння: ён бярэ структураванае JSON-прадстаўленне PDF і аднаўляе арыгінальны дакумент.

::: warning
Гэты інструмент прымае толькі файлы JSON, створаныя канвертарам BentoPDF «PDF у JSON». Звычайныя файлы JSON з API, баз даных або іншых інструментаў не падтрымліваюцца.
:::

## Падтрымліваемыя фарматы

| Уваход  | Апісанне                                                     |
| :------ | :----------------------------------------------------------- |
| `.json` | Файлы JSON, экспартаваныя інструментам BentoPDF «PDF у JSON» |

## Як гэта працуе

1. Націсніце на вобласць запампоўвання або перацягніце адзін або некалькі файлаў JSON.
2. Спіс файлаў паказвае кожны выбраны файл з яго памерам.
3. Націсніце **Пераўтварыць у PDF**. Інструмент апрацоўвае ўсе файлы з дапамогай Web Worker і рухавіка CPDF.
4. Вынік спампоўваецца як `jsons-to-pdf.zip`, які змяшчае па адным PDF на кожны ўваходны файл JSON.

Пераўтварэнне выконваецца ў фонавым Web Worker, таму інтэрфейс застаецца спагадлівым нават з вялікімі файламі.

## Параметры

Наладжвальных параметраў няма. Структура JSON цалкам вызначае выніковы PDF.

## Вынік

Пры пераўтварэнні некалькіх файлаў JSON вынікі перадаюцца ў архіве ZIP. Кожны PDF называецца паводле зыходнага файла JSON (напрыклад, `report.json` становіцца `report.pdf`).

## Сцэнарыі выкарыстання

- Аднаўленне PDF з рэзервовай копіі або архіва на аснове JSON
- Пераўтварэнне PDF у JSON для праверкі і назад у PDF
- Аднаўленне дакументаў пасля праграмных змен у структуры JSON
- Праверка таго, што экспарт PDF у JSON захапіў усё змесціва, праз зваротнае пераўтварэнне

## Парады

- Калі трэба пераўтварыць адвольныя даныя JSON (напрыклад, адказы API або файлы канфігурацыі) у адфарматаваны PDF, лепш падыдзе інструмент [Тэкст у PDF](./txt-to-pdf). Устаўце JSON як тэкст, і ён будзе выведзены з належным фарматаваннем.
- Для працы гэтага інструмента павінен быць даступны рухавік CPDF на WebAssembly. Для ўласных разгортванняў трэба наладзіць файлы CPDF WASM.

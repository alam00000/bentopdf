# Інвертаваць колеры

Ператварыце кожны колер у PDF у адваротны. Белы фон становіцца чорным, чорны тэкст становіцца белым, а ўсе іншыя колеры змяняюцца на дадатковыя. Гэта самы хуткі спосаб стварыць «цёмную» версію любога PDF.

## Як гэта працуе

1. Запампуйце файл PDF.
2. Націсніце **Інвертаваць колеры**, каб апрацаваць файл.
3. Інвертаваны PDF спампуецца аўтаматычна.

Дадатковых налад няма. Інструмент выводзіць кожную старонку як відарыс, інвертуе колеры ўсіх пікселяў і збірае вынік у новы PDF.

## Магчымасці

- Інверсія колераў усіх старонак адным націскам
- Апрацоўка кожнай старонкі дакумента
- Захаванне арыгінальных памераў і макета старонак
- Працуе з любым PDF незалежна ад тыпу змесціва (тэкст, відарысы, змешанае)

## Сцэнарыі выкарыстання

- Стварэнне цёмных версій падручнікаў або інструкцый для зручнага чытання ўначы
- Падрыхтоўка высокакантрасных версій дакументаў для даступнасці
- Інверсія сканаваных дакументаў, знятых з няправільнай экспазіцыяй
- Стварэнне негатываў PDF з вялікай колькасцю відарысаў для візуальнага аналізу

## Парады

- Паколькі інструмент растарызуе старонкі, вынік складаецца з відарысаў. Тэкст больш нельга будзе вылучыць або знайсці. Калі пасля інверсіі патрэбны тэкст з пошукам, апрацуйце вынік інструментам OCR.
- Для больш тонкай налады колераў (яркасць, кантраст, насычанасць) выкарыстоўвайце інструмент [Наладзіць колеры](./adjust-colors).
- Вялікія PDF з мноствам старонак могуць апрацоўвацца даўжэй, бо кожная старонка выводзіцца і інвертуецца асобна.

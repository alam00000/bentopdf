# Тэкст у PDF

Пераўтварайце просты тэкст у адфарматаваны PDF. Можна загрузіць файлы `.txt` або ўвесці тэкст непасрэдна ва ўбудаваны тэкставы рэдактар. Інструмент падтрымлівае некалькі шрыфтоў, уласныя колеры тэксту і шырокі выбар памераў старонак: ад A0 да A10, а таксама US Letter, Legal і Tabloid.

## Падтрымліваемыя фарматы

| Увод                    | Пашырэнні                       |
| :---------------------- | :------------------------------ |
| Простыя тэкставыя файлы | `.txt`                          |
| Непасрэдны ўвод тэксту  | Увядзіце або ўстаўце ў рэдактар |

## Як гэта працуе

1. Выберыце рэжым уводу пераключальнікам уверсе: **Запампаваць файлы** або **Увесці тэкст**.
2. Пры загрузцы перацягніце або націсніце, каб выбраць адзін або некалькі файлаў `.txt`. Пры ўводзе ўпішыце тэкст непасрэдна ў тэкставае поле.
3. Наладзьце параметры фарматавання: гарнітуру, памер шрыфту, колер тэксту і памер старонкі.
4. Націсніце **Стварыць PDF**. Вынік спампоўваецца як `text_to_pdf.pdf`.

Пры загрузцы некалькіх файлаў іх змест аб'ядноўваецца з пустымі радкамі паміж імі.

## Параметры

| Параметр              | Значэнні                                                                                | Па змаўчанні    |
| :-------------------- | :-------------------------------------------------------------------------------------- | :-------------- |
| **Сямейства шрыфтоў** | Helvetica (без засечак), Tiro (з засечкамі), Courier (монашырынны), Times (з засечкамі) | Helvetica       |
| **Памер шрыфта**      | 6-72 pt                                                                                 | 12              |
| **Колер тэксту**      | Любы колер праз выбар колеру                                                            | Чорны (#000000) |
| **Памер старонкі**    | ISO A0-A10, B0-B10, C0-C10, US Letter, Legal, Tabloid, Ledger, 11x17                    | A4              |

Мовы з напрамкам справа налева (арабская, іўрыт, фарсі, урду) вызначаюцца аўтаматычна. Калі знойдзены такі тэкст, напрамак і выраўноўванне тэксту пераключаюцца адпаведна.

## Сцэнарыі выкарыстання

- Пераўтварэнне фрагментаў кода або файлаў журналаў у PDF для друку са шрыфтам Courier
- Хуткае стварэнне PDF з нататак сустрэчы, набраных на месцы
- Фарматаванне простага тэкставага рукапісу з пэўным шрыфтам і памерам старонкі для падачы
- Стварэнне PDF-версіі README або changelog для распаўсюджвання па-за сеткай

## Парады

- Выкарыстоўвайце рэжым **Увесці тэкст**, калі трэба хутка пераўтварыць змест буфера абмену, не захоўваючы яго спачатку ў файл.
- Courier (монашырынны) з'яўляецца найлепшым выбарам для кода, журналаў або любога зместу, дзе важнае выраўноўванне па слупках.
- Палі старонкі фіксаваныя: 72 пункты (1 цаля) з усіх бакоў.

# Дадаць пустую старонку

Устаўляйце пустыя старонкі ў PDF у вызначанае вамі месца. Вы самі выбіраеце, куды іх уставіць і колькі дадаць.

## Як гэта працуе

1. Загрузіце PDF-файл. Інструмент пакажа колькасць старонак.
2. Увядзіце **пазіцыю**, куды трэба ўставіць пустыя старонкі. Выкарыстайце `0`, каб уставіць у самы пачатак, або агульную колькасць старонак, каб дадаць у канец.
3. Увядзіце **колькасць** пустых старонак (па змаўчанні 1).
4. Націсніце кнопку апрацоўкі. Зменены PDF з устаўленымі пустымі старонкамі спампуецца.

## Магчымасці

- Устаўка ў любое месца: пачатак, сярэдзіну або канец дакумента
- Даданне некалькіх пустых старонак за адну аперацыю
- Падказка пазіцыі абнаўляецца паводле колькасці старонак загружанага PDF
- Стандартныя пустыя старонкі памеру A4

## Сцэнарыі выкарыстання

- Даданне пустой старонкі-раздзяляльніка паміж раздзеламі сабранага дакумента
- Устаўка пустых старонак для выраўноўвання пры двухбаковым друку
- Даданне месца для рукапісных нататак у раздрукаваным вучэбным дапаможніку
- Дапаўненне дакумента да мінімальнай патрабаванай колькасці старонак

## Парады

- Пазіцыя `0` устаўляе перад першай старонкай. Пазіцыя, роўная агульнай колькасці старонак, дадае пасля апошняй.
- Калі трэба ўставіць змест (а не толькі пустыя старонкі) у пэўнае месца, выкарыстайце [Шматфункцыянальны інструмент PDF](./pdf-multi-tool), каб уставіць іншы PDF пасля зададзенай старонкі.

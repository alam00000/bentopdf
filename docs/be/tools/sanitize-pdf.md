# Ачысціць PDF

PDF можа змяшчаць значна больш, чым вы бачыце на экране. Схаваныя метаданыя, убудаваны JavaScript, далучаныя файлы, даныя формаў і звесткі пра пласты могуць выдаць адчувальныя даныя або стварыць рызыку бяспекі. Ачыстка выдаляе ўсё гэта і пакідае чысты дакумент, які бяспечна публікаваць.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Выберыце ў спісе элементы, якія трэба выдаліць.
3. Націсніце **Ачысціць PDF**.
4. Спампуйце ачышчаны файл.

## Параметры ачысткі

Усе параметры ўключаны па змаўчанні. Зніміце адзнаку з тых, што хочаце захаваць.

| Параметр                       | Што выдаляе                                                              |
| ------------------------------ | ------------------------------------------------------------------------ |
| **Сплошчыць формы**            | Пераўтварае інтэрактыўныя палі формаў у статычны змест                   |
| **Выдаліць метаданыя**         | Выдаляе аўтара, назву, дату стварэння, звесткі пра праграму і даныя XMP  |
| **Выдаліць анатацыі**          | Выдаляе каментарыі, вылучэнні, нататкі-налепкі і разметку                |
| **Выдаліць JavaScript**        | Выдаляе ўбудаваныя скрыпты, якія могуць выконвацца пры адкрыцці          |
| **Выдаліць убудаваныя файлы**  | Выдаляе файлы, далучаныя ўнутры PDF                                      |
| **Выдаліць слаі (OCG)**        | Зводзіць групы неабавязковага зместу ў адзін пласт                       |
| **Выдаліць спасылкі**          | Выдаляе гіперспасылкі і спасылкі на URL                                  |
| **Выдаліць дрэва структуры**   | Выдаляе структуру дакумента, якая выкарыстоўваецца для тэгаў даступнасці |
| **Выдаліць MarkInfo**          | Выдаляе звесткі пра пазначаны змест                                      |
| **Выдаліць убудаваныя шрыфты** | Выдаляе ўбудаваныя даныя шрыфтоў (выкарыстоўвайце асцярожна)             |

## Сцэнарыі выкарыстання

- Падрыхтоўка PDF да публікацыі з выдаленнем унутраных метаданых (імёнаў аўтараў, версій праграм, гісторыі рэдагавання)
- Выдаленне JavaScript з PDF, атрыманага з ненадзейнай крыніцы, перад адкрыццём
- Ачыстка PDF перад адпраўкай кліенту, які не павінен бачыць убудаваныя каментарыі або назвы палёў формаў
- Выдаленне схаваных пластоў з архітэктурнага чарцяжа перад перадачай канчатковай версіі
- Выкананне патрабаванняў мінімізацыі даных паводле правілаў прыватнасці

## Парады

- Не адзначайце "Выдаліць убудаваныя шрыфты", калі не ўпэўнены, што PDF усё роўна будзе адлюстроўвацца правільна. Выдаленне шрыфтоў можа зрабіць тэкст нябачным у некаторых праграмах прагляду.
- Калі трэба выдаліць толькі метаданыя, асобны інструмент "Выдаліць метаданыя" хутчэйшы і больш мэтанакіраваны.
- Ачыстка незваротная. Захавайце арыгінальны файл.

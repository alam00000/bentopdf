# Выняць відарысы

Вымае кожны ўбудаваны відарыс з аднаго або некалькіх файлаў PDF. Вынятыя відарысы паказваюцца ў сетцы папярэдняга прагляду, дзе іх можна спампаваць па адным або ўсе адразу архівам ZIP. Працуе на PyMuPDF.

## Як гэта працуе

1. Загрузіце адзін або некалькі PDF: націсніце на вобласць загрузкі або перацягніце на яе файлы. Пры патрэбе дадайце яшчэ файлы або выдаліце асобныя.
2. Націсніце **Выняць**, каб пачаць апрацоўку.
3. Інструмент праглядае кожную старонку кожнага загружанага PDF, знаходзіць і вымае ўбудаваныя відарысы.
4. Вынятыя відарысы з'яўляюцца ў сетцы з мініяцюрамі. Кожны відарыс мае кнопку спампоўвання.
5. Націсніце **Спампаваць усё**, каб захаваць усё як архіў ZIP.

## Параметры

У гэтага інструмента няма наладжвальных параметраў. Усе ўбудаваныя відарысы вымаюцца ў іх родным фармаце (звычайна PNG, JPEG або той фармат, у якім відарыс быў убудаваны ў PDF).

## Фармат выніку

- Відарысы паказваюцца ў сетцы з назвамі `image_1.png`, `image_2.jpg` і г. д.
- **Спампаваць усё** стварае `extracted-images.zip` з усімі відарысамі.
- Асобныя відарысы можна спампоўваць па адным з сеткі.

## Сцэнарыі выкарыстання

- Аднаўленне фатаграфій або графікі з PDF для выкарыстання ў іншым праекце.
- Выманне відарысаў тавараў з каталога PDF для інтэрнэт-крамы.
- Выманне дыяграм з тэхнічнай дакументацыі для прэзентацый.
- Аўдыт таго, якія відарысы ўбудаваны ў дакумент, перад абменам ім.

## Парады

- Інструмент вымае відарысы дакладна так, як яны захоўваюцца ў PDF. Ён не рэндэрыць старонкі ў відарысы: для гэтага карыстайцеся [PDF у PNG](./pdf-to-png) або [PDF у JPG](./pdf-to-jpg).
- Калі інструмент паведамляе «Відарысы не знойдзены», PDF можа выкарыстоўваць вектарную графіку замест убудаваных растравых відарысаў або быць сканаваным дакументам, дзе ўся старонка з'яўляецца адным вялікім відарысам.
- Пакетная апрацоўка працуе для некалькіх PDF. Усе відарысы з усіх файлаў аб'ядноўваюцца ў адну сетку і адзін ZIP.

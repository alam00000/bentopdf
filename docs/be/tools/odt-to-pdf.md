# ODT у PDF

Пераўтварайце файлы OpenDocument Text у PDF. ODT з'яўляецца ўласным фарматам LibreOffice Writer, Apache OpenOffice і іншых тэкставых рэдактараў з адкрытым кодам. Гэты інструмент выкарыстоўвае рухавік LibreOffice у браўзеры для дакладнага пераўтварэння з захаваннем фарматавання, табліц, відарысаў і стыляў.

## Падтрымліваемыя фарматы

| Фармат            | Пашырэнні |
| :---------------- | :-------- |
| OpenDocument Text | `.odt`    |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце адзін ці некалькі файлаў ODT.
2. Праверце спіс файлаў. Дадайце яшчэ файлы або выдаліце непатрэбныя.
3. Націсніце **Пераўтварыць у PDF**. Рухавік LibreOffice ініцыялізуецца (індыкатар паказвае ход загрузкі), затым кожны файл пераўтвараецца.
4. Адзін файл спампоўваецца непасрэдна як PDF. Некалькі файлаў пакуюцца ў `odt-converted.zip`.

## Налады

У гэтага інструмента няма дадатковых налад. Пераўтварэнне як мага дакладней захоўвае фарматаванне арыгінальнага дакумента.

## Вынік

| Колькасць файлаў | Вынік                                                     |
| :--------------- | :-------------------------------------------------------- |
| 1 файл           | Адзін PDF (напрыклад, `document.pdf`)                     |
| 2+ файлы         | Архіў ZIP (`odt-converted.zip`) з адным PDF на кожны файл |

## Сцэнарыі выкарыстання

- Пераўтварэнне дакументаў LibreOffice Writer у PDF для карыстальнікаў Microsoft Office
- Стварэнне гатовых да друку PDF з навуковых работ у фармаце OpenDocument
- Пакетнае пераўтварэнне папкі шаблонаў ODT у PDF для распаўсюджвання
- Стварэнне PDF з файлаў ODT, згенераваных аўтаматычнымі сістэмамі

## Парады

- Рухавік LibreOffice загружаецца пры першым выкарыстанні і кэшуецца для наступных пераўтварэнняў. Першая загрузка займае некалькі секунд, пасля гэтага пераўтварэнні хуткія.
- Складаныя дакументы з убудаванымі аб'ектамі OLE або незвычайнымі шрыфтамі могуць выглядаць крыху інакш, чым у настольным LibreOffice. Праверце на ўзоры перад пакетным пераўтварэннем.
- Для дакументаў Word (`.doc`, `.docx`) выкарыстоўвайце інструмент [Word у PDF](./word-to-pdf): ён таксама працуе на рухавіку LibreOffice, але прымае фарматы Microsoft напрамую.

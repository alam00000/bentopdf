# Дадаць далучэнні

Убудоўвайце адзін або некалькі файлаў непасрэдна ў PDF-дакумент. Далучэнні можна дадаць на ўзроўні дакумента (бачныя на панэлі далучэнняў любой праграмы для чытання PDF) або прывязаць да пэўных старонак.

## Як гэта працуе

1. Загрузіце PDF, да якога хочаце далучыць файлы.
2. Выкарыстайце вобласць далучэнняў, каб выбраць файлы для ўбудавання (любога тыпу).
3. Выберыце ўзровень далучэння: **Дакумент** (па змаўчанні) або **Старонка**.
4. Калі вы выбралі ўзровень старонкі, увядзіце дыяпазон старонак (напрыклад, `1-3` або `5`).
5. Націсніце кнопку апрацоўкі. Зменены PDF з убудаванымі файламі спампуецца.

## Магчымасці

- Далучайце файлы любога тыпу: выявы, табліцы, архівы, выканальныя файлы, што заўгодна
- Размяшчэнне далучэнняў на ўзроўні дакумента або старонкі
- Некалькі файлаў можна далучыць за адну аперацыю
- Паказваюцца назвы і памеры ўсіх выбраных далучэнняў
- Вынік захоўвае зыходны змест PDF з дададзенымі ўбудаванымі файламі

## Параметры

| Параметр               | Апісанне                                                              |
| ---------------------- | --------------------------------------------------------------------- |
| **Узровень дакумента** | Далучае файлы да ўсяго PDF, даступныя з панэлі далучэнняў             |
| **Узровень старонкі**  | Далучае файлы да пэўных старонак, зададзеных полем дыяпазону старонак |

## Сцэнарыі выкарыстання

- Аб'яднанне зыходных даных (файлы Excel, CSV) са справаздачай у PDF
- Далучэнне арыгінальных файлаў выяў да PDF-партфоліо фатографа
- Убудаванне дапаможных дакументаў у дагавор або прапанову
- Даданне дадатковых матэрыялаў да пэўных старонак навучальнага дапаможніка

## Парады

- Далучэнні на ўзроўні дакумента найлепш падтрымліваюцца праграмамі для чытання PDF. Далучэнні на ўзроўні старонкі могуць быць бачныя не ва ўсіх праграмах.
- Абмежавання памеру файлаў для далучэнняў няма, але вельмі вялікія ўбудаваныя файлы прапарцыйна павялічаць памер PDF.

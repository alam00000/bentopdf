# PNG у PDF

Пераўтварайце відарысы PNG у PDF з захаваннем поўнага разрознення. Кожны PNG становіцца асобнай старонкай памерам з арыгінальны відарыс. Празрыстасць апрацоўваецца аўтаматычна.

## Падтрымліваемыя фарматы

| Фармат | Пашырэнні |
| :----- | :-------- |
| PNG    | `.png`    |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце файлы PNG. Можна выбраць некалькі адразу.
2. Кіруйце спісам файлаў: выдаляйце непатрэбныя або дадавайце новыя.
3. Выберыце ўзровень **Якасць PDF** у выпадальным спісе.
4. Націсніце **Пераўтварыць у PDF**. Вынік спампоўваецца як `from_jpgs.pdf`.

Інструмент выкарыстоўвае pdf-lib, каб убудаваць кожны відарыс напрамую. Калі PNG нельга ўбудаваць напрамую (напрыклад, з-за незвычайнага колеравага профілю), ён перарысоўваецца праз canvas у JPEG.

## Налады

**Якасць PDF** кіруе сцісканнем перад убудаваннем:

- **Высокая якасць**: мінімальнае сцісканне, найбольшы памер файла.
- **Сярэдняя якасць** (па змаўчанні): добры баланс памеру і выразнасці.
- **Нізкая якасць**: максімальнае сцісканне, найменшы вынік.

## Сцэнарыі выкарыстання

- Пераўтварэнне здымкаў экрана ў шматстаронкавы PDF для справаздач пра памылкі або дакументацыі
- Упакоўка экспарту дызайну інтэрфейсу ў адзін файл для прагляду
- Ператварэнне экспартаваных схем (draw.io, Excalidraw) у PDF для абмену
- Збор набору відарысаў графікаў у справаздачу

## Парады

- Файлы PNG з празрыстасцю атрымліваюць у PDF белы фон. Калі патрэбны іншы фон, адрэдагуйце відарысы загадзя.
- Для здымкаў экрана і схем з выразнымі краямі і тэкстам высокая якасць дазваляе пазбегнуць артэфактаў сціскання JPEG. Сярэдняя або нізкая могуць унутры пераўтвараць у JPEG.

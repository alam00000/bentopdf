# Растарызаваць PDF

Растарызацыя пераўтварае кожную старонку PDF у відарыс і збірае гэтыя відарысы назад у PDF. Вынік выглядае гэтак жа, як арыгінал, але не мае вылучальнага тэксту, інтэрактыўных элементаў і рэдагавальных пластоў. Па сутнасці, гэта якасная ксеракопія.

## Як гэта працуе

1. Загрузіце адзін або некалькі файлаў PDF.
2. Задайце **DPI** (разрозненне) выніку.
3. Выберыце **Фармат выявы**: PNG для якасці без страт або JPEG для меншых файлаў.
4. Пры жаданні адзначце **Пераўтварыць у адценні шэрага**.
5. Націсніце **Растарызаваць PDF**. Некалькі файлаў спампоўваюцца як ZIP.

## Параметры

| Налада                            | Значэнні                      | Па змаўчанні |
| --------------------------------- | ----------------------------- | ------------ |
| **DPI**                           | 72, 150, 200, 300, 600        | 150          |
| **Фармат выявы**                  | PNG (без страт), JPEG (меншы) | PNG          |
| **Пераўтварыць у адценні шэрага** | Укл./Выкл.                    | Выкл.        |

## Рэкамендацыі па DPI

- **72**: толькі для прагляду на экране, найменшы памер файла
- **150**: добры баланс для звычайнага выкарыстання
- **200**: больш выразны тэкст, умераны памер файла
- **300**: якасць для друку
- **600**: высокая якасць для архівавання або прафесійнага друку

## Сцэнарыі выкарыстання

- Прадухіленне выцягвання тэксту з канфідэнцыйных дакументаў перад перадачай
- Пазбаўленне ад праблем з шрыфтамі праз пераўтварэнне тэксту ў пікселі
- Стварэнне "плоскай" версіі PDF са складанымі пластамі або празрыстасцю, якія па-рознаму адлюстроўваюцца ў розных праграмах
- Падрыхтоўка PDF для сістэмы, якая прымае толькі відарысы
- Выдаленне схаванага зместу (напрыклад, адсочаных змен або даных формаў) шляхам ператварэння PDF у чыстыя відарысы

## Парады

- 150 DPI у PNG з'яўляецца надзейным значэннем па змаўчанні. Павялічвайце толькі для друку або калі трэба набліжаць дробныя дэталі.
- JPEG дае прыкметна меншыя файлы, але дадае артэфакты сціскання на рэзкіх краях тэксту.
- Растарызацыя незваротная: захоўвайце арыгінальны PDF, калі пазней можа спатрэбіцца рэдагавальны тэкст.

# Змяніць дазволы

Дакладна вызначайце, што атрымальнікі могуць рабіць з вашым PDF. У адрозненне ад простага шыфравання, якое толькі закрывае файл паролем, гэты інструмент дазваляе выбарачна дазваляць або забараняць друк, капіраванне, рэдагаванне, анатаванне, запаўненне форм, зборку дакумента і выманне старонак, і ўсё гэта забяспечваецца 256-бітным шыфраваннем AES.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Калі PDF ужо зашыфраваны, увядзіце **Бягучы пароль**.
3. Задайце **Новы пароль карыстальніка** (патрэбны для адкрыцця) і/або **Новы пароль уладальніка** (кіруе дазволамі).
4. Уключайце або выключайце асобныя дазволы сцяжкамі.
5. Націсніце **Змяніць дазволы**.
6. Спампуйце абноўлены PDF.

Калі пакінуць абодва палі новых пароляў пустымі, інструмент цалкам расшыфроўвае PDF і выдаляе ўсё шыфраванне і абмежаванні.

## Кіраванне дазволамі

| Дазвол                         | Што кантралюе                                         |
| ------------------------------ | ----------------------------------------------------- |
| **Дазволіць друк**             | Ці можна раздрукаваць дакумент                        |
| **Дазволіць капіраванне**      | Ці можна вылучаць і капіраваць тэкст і відарысы       |
| **Дазволіць змяненне**         | Ці можна рэдагаваць змесціва дакумента                |
| **Дазволіць анатаванне**       | Ці можна дадаваць каментарыі, вылучэнні і штампы      |
| **Дазволіць запаўненне форм**  | Ці можна запаўняць інтэрактыўныя палі формы           |
| **Дазволіць зборку дакумента** | Ці можна ўстаўляць, выдаляць або паварочваць старонкі |
| **Дазволіць выманне старонак** | Ці можна вымаць асобныя старонкі                      |

Каб дазволы дзейнічалі, патрэбны пароль уладальніка. Без яго большасць праграм для чытання PDF ігнаруе сцяжкі дазволаў.

## Як працуюць дазволы ў PDF

Дазволы PDF з'яўляюцца часткай спецыфікацыі шыфравання. Яны захоўваюцца як бітавыя сцяжкі ў слоўніку шыфравання, і іх выконваюць сумяшчальныя праграмы для чытання PDF. Галоўнае адрозненне:

- **Пароль карыстальніка**: патрэбны, каб наогул адкрыць файл.
- **Пароль уладальніка**: патрэбны, каб змяніць дазволы або зняць абмежаванні. Без яго сцяжкі дазволаў вызначаюць, якія аперацыі можа выконваць карыстальнік.

Калі задаць толькі пароль уладальніка (без пароля карыстальніка), любы можа адкрыць файл, але будзе абмежаваны дазволенымі аперацыямі. Калі задаць абодва, файл патрабуе пароль для адкрыцця і застаецца абмежаваным пасля аўтэнтыфікацыі.

## Сцэнарыі выкарыстання

- Распаўсюджванне справаздачы, якую можна праглядаць і друкаваць, але нельга рэдагаваць або капіраваць
- Абмен шаблонам дагавора, які атрымальнікі могуць запоўніць, але не змяніць
- Публікацыя каталога PDF з забаронай капіравання відарысаў
- Дазвол анатавання ў чарнавіку для рэцэнзавання з забаронай структурных змен

## Парады

- Каб дазволы дзейнічалі, заўсёды задавайце пароль уладальніка. Без яго дазволы немагчыма забяспечыць.
- Некаторыя іншыя інструменты PDF ігнаруюць сцяжкі дазволаў. Для мацнейшай абароны разгледзьце растарызацыю PDF або DRM.
- Карыстайцеся гэтым інструментам, каб абнавіць старыя PDF з шыфраваннем RC4 да AES-256.

# Павярнуць PDF

Паварочвайце старонкі PDF на 90 градусаў па гадзінніку або супраць гадзінніка. Інструмент паказвае мініяцюры ўсіх старонак, дазваляючы паварочваць іх асобна або ўжыць масавы паварот да ўсяго дакумента.

## Як гэта працуе

1. Загрузіце файл PDF. Мініяцюры ўсіх старонак адмалёўваюцца ў сетцы.
2. Выкарыстоўвайце кнопкі павароту ўлева/ўправа пад кожнай мініяцюрай, каб павярнуць пэўную старонку.
3. Выкарыстоўвайце элементы масавага павароту ўверсе, каб павярнуць усе старонкі адразу.
4. Мініяцюры абнаўляюцца ў рэальным часе, паказваючы паварот.
5. Націсніце кнопку апрацоўкі, каб захаваць павернуты PDF.

## Магчымасці

- Паварот кожнай старонкі з крокам 90 градусаў (улева або ўправа)
- Масавы паварот усіх старонак адначасова
- Папярэдні прагляд мініяцюр у рэальным часе з анімацыяй павароту
- Адкладзеная загрузка мініяцюр для плаўнай працы з вялікімі дакументамі
- Захоўвае зыходны змест і якасць старонак

## Сцэнарыі выкарыстання

- Выпраўленне сканаваных старонак, якія ляжаць бокам або дагары нагамі
- Паварот альбомных старонак у кніжную арыентацыю (або наадварот)
- Выпраўленне дакумента са змешанай арыентацыяй, дзе частка старонак адсканавана пад няправільным вуглом
- Падрыхтоўка дакумента для пэўнай арыентацыі адлюстравання

## Парады

- Павароты сумуюцца. Двайны націск кнопкі па гадзінніку дае паварот на 180 градусаў.
- Для паваротаў, не кратных 90 градусам (напрыклад, 45 градусаў, каб выправіць крыху нахілены скан), выкарыстоўвайце [Павярнуць на зададзены вугал](./rotate-custom).
- Элементы масавага павароту ўплываюць на ўсе старонкі, а не толькі на выбраныя. У гэтым інструменце няма выбару старонак: для гэтага выкарыстоўвайце [Мультыінструмент PDF](./pdf-multi-tool).

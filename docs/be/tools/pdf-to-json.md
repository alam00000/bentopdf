# PDF у JSON

Пераўтварае адзін або некалькі файлаў PDF у фармат JSON. Інструмент выкарыстоўвае CPDF (Coherent PDF), каб сэрыялізаваць унутраную структуру кожнага PDF у машыначытэльнае прадстаўленне JSON. Вынік заўсёды выдаецца як архіў ZIP.

## Як гэта працуе

1. Выберыце адзін або некалькі файлаў PDF праз акно выбару файлаў.
2. Націсніце **Пераўтварыць**, каб пачаць апрацоўку. Пераўтварэнне выконваецца ў фонавым web worker.
3. Спампоўваецца архіў ZIP з адным файлам JSON на кожны ўваходны PDF.

Радок стану паказвае ход пераўтварэння і стварэння ZIP.

## Налады

У гэтага інструмента няма налад. Кожны PDF пераўтвараецца ў поўнае прадстаўленне JSON.

## Фармат выніку

- Файл `pdfs-to-json.zip` з `filename.json` для кожнага ўваходнага PDF.

Вынік JSON адлюстроўвае ўнутраную структуру аб'ектаў PDF, у тым ліку дрэвы старонак, спасылкі на шрыфты, метаданыя і патокі змесціва.

## Сцэнарыі выкарыстання

- Праверка ўнутранай структуры PDF для адладкі або валідацыі.
- Праграмнае выманне структураваных метаданых і ўласцівасцей старонак.
- Перадача даных структуры PDF ва ўласныя канвееры апрацоўкі.
- Аўдыт дакументаў PDF на адпаведнасць праз аналіз дрэў аб'ектаў.

## Парады

- Гэты інструмент выдае сырую структуру аб'ектаў PDF, а не вынятае тэкставае змесціва. Калі патрэбны тэкст старонак у JSON, выкарыстайце [Падрыхтаваць PDF для ШI](./prepare-pdf-for-ai).
- Для простага вымання тэксту [PDF у тэкст](./pdf-to-text) зручнейшы.
- Вялікія PDF са складанай структурай даюць вельмі вялікія файлы JSON.

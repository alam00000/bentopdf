# PUB у PDF

Пераўтварайце файлы Microsoft Publisher у PDF. Publisher з'яўляецца праграмай для настольнай вёрсткі, якая ўваходзіць у некаторыя выданні Microsoft Office, але ў большасці людзей яна не ўсталявана. Гэты інструмент дазваляе любому пераўтварыць файлы PUB у PDF проста ў браўзеры, без праграм Microsoft.

## Падтрымліваемыя фарматы

| Фармат              | Пашырэнне | Заўвагі                      |
| :------------------ | :-------- | :--------------------------- |
| Microsoft Publisher | `.pub`    | Дакументы настольнай вёрсткі |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце файлы PUB. Можна загрузіць некалькі файлаў адразу.
2. Праверце спіс файлаў. Выдаліце непатрэбныя файлы значком сметніцы або націсніце **Дадаць больш файлаў**, каб дадаць іншыя.
3. Націсніце **Канвертаваць у PDF**. Рухавік на аснове LibreOffice загружаецца ў браўзеры і пераўтварае кожны файл PUB, захоўваючы макет, відарысы і тэкставыя блокі.
4. Адзін файл спампоўваецца адразу як PDF. Некалькі файлаў перадаюцца ў архіве ZIP з назвай `pub-to-pdf.zip`.

## Параметры

Дадатковая налада не патрэбна. Канвертар аўтаматычна апрацоўвае макет PUB.

## Сцэнарыі выкарыстання

- Адкрыццё флаера або бюлетэня PUB ад кліента без набыцця Microsoft Publisher
- Пераўтварэнне царкоўных бюлетэняў, праграм мерапрыемстваў або школьных газет, створаных у Publisher
- Архіваванне маркетынгавых матэрыялаў з Publisher у агульнадаступным фармаце
- Друк файлаў PUB на сістэме без усталяванага Publisher

## Парады

- Складаныя макеты Publisher з накладзенымі тэкставымі блокамі і дакладным пазіцыянаваннем могуць крыху зрушыцца пры пераўтварэнні. Праверце вынік, калі дакладнае размяшчэнне важнае.
- Рухавік LibreOffice ініцыялізуецца адзін раз за сесію. Першае пераўтварэнне займае больш часу, наступныя хутчэйшыя.
- Для найбольш дакладнага пераўтварэння файлаў Publisher пераканайцеся, што ўсе шрыфты ў арыгінале з'яўляюцца стандартнымі сістэмнымі шрыфтамі.

# PDF у BMP

Пераўтварае кожную старонку PDF у відарыс BMP (Bitmap). BMP з'яўляецца несціснутым фарматам, таму вынік дакладны да пікселя без страты якасці, але файлы вялікія.

## Як гэта працуе

1. Загрузіце PDF, націснуўшы на вобласць загрузкі або перацягнуўшы туды файл.
2. Націсніце **Пераўтварыць**, каб апрацаваць файл.
3. Адзін файл `.bmp` або архіў ZIP спампуецца аўтаматычна.

## Налады

У гэтага інструмента няма налад. Старонкі рэндэрацца з фіксаваным маштабам 2x, таму відарысы прыкладна ўдвая большыя за ўласныя памеры старонак PDF.

## Фармат выніку

- **Адна старонка**: `filename.bmp`
- **Некалькі старонак**: `filename_bmps.zip` з `page_1.bmp`, `page_2.bmp` і г.д.

## Сцэнарыі выкарыстання

- Перадача старонак PDF у састарэлыя сістэмы або абсталяванне, якія прымаюць толькі BMP.
- Падрыхтоўка несціснутых відарысаў для пэўных працэсаў друку.
- Выкарыстанне растравага выніку як уваходу для інструментаў апрацоўкі відарысаў, якім патрэбныя сырыя піксельныя даныя.

## Парады

- Файлы BMP вельмі вялікія, бо захоўваюць сырыя піксельныя даныя без сціскання. У большасці выпадкаў [PDF у PNG](./pdf-to-png) дае якасць без страт пры значна меншых файлах.
- Калі мэтавая сістэма прымае PNG або TIFF, выбірайце гэтыя фарматы, каб зэканоміць месца на дыску.

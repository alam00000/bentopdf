# Падпісаць PDF

Дадайце свой подпіс у любы дакумент PDF. Інструмент убудоўвае поўную праграму прагляду PDF з інструментамі подпісу, дзе можна намаляваць подпіс ад рукі, увесці імя рукапісным шрыфтам або загрузіць відарыс подпісу. Размяшчайце і змяняйце памер подпісаў на любой старонцы, а потым захавайце падпісаны дакумент.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Дакумент адкрываецца ва ўбудаванай праграме прагляду PDF з інструментамі анатавання.
3. Выкарыстоўвайце інструмент подпісу, каб стварыць подпіс: намаляваць, увесці або загрузіць відарыс.
4. Націсніце на месца на старонцы, дзе трэба размясціць подпіс, і наладзьце яго памер і пазіцыю.
5. Пры жаданні адзначце **Сплошчыць PDF**, каб назаўсёды ўбудаваць подпіс у дакумент.
6. Націсніце **Захаваць і спампаваць падпісаны PDF**, каб атрымаць падпісаны файл.

## Параметры

- **Сплошчыць PDF**: калі адзначана, подпіс назаўсёды ўбудоўваецца ў змест старонкі. Гэта не дае іншым перамясціць або выдаліць подпіс. Калі не адзначана, подпіс застаецца анатацыяй, якую можна рэдагаваць у сумяшчальных праграмах прагляду.

## Магчымасці

- Тры спосабы стварэння подпісу: малюнак ад рукі, уведзены тэкст або загружаны відарыс
- Убудаваная праграма прагляду PDF для дакладнага размяшчэння
- Перацягванне для размяшчэння і змянення памеру подпісаў на любой старонцы
- Неабавязковае зводжанне для пастаяннага ўбудавання подпісаў
- Падтрымка некалькіх подпісаў у адным дакуменце

## Сцэнарыі выкарыстання

- Падпісанне кантрактаў, пагадненняў або формаў зацвярджэння перад адпраўкай назад
- Даданне подпісу да падатковых дакументаў, страхавых заяў або дзяржаўных формаў
- Размяшчэнне ініцыялаў на асобных старонках шматстаронкавага пагаднення
- Падпісанне NDA або кадравых дакументаў, якія прыходзяць як далучэнні PDF

## Парады

- Уключыце зводжанне, калі адпраўляеце падпісаны PDF таму, хто не павінен мець магчымасці выдаліць або перамясціць ваш подпіс.
- Для юрыдычна значных лічбавых подпісаў з праверкай на аснове сертыфікатаў BentoPDF таксама прапануе асобны інструмент "Лічбавы подпіс PDF".
- Для найлепшага выніку загружайце відарыс подпісу PNG з празрыстым фонам.

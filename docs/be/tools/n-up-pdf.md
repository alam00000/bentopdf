# N-Up PDF

Размяшчайце некалькі старонак на адным аркушы ў выглядзе сеткі. Гэта памяншае колькасць друкаваных старонак, змяшчаючы 2, 4, 6, 8, 9 або 16 старонак на аркуш. Інструмент сам маштабуе і размяшчае старонкі і дазваляе наладзіць памер старонкі.

## Як гэта працуе

1. Запампуйце файл PDF.
2. Выберыце колькасць старонак на аркуш (значэнне «N»): 2, 4, 6, 8, 9 або 16.
3. Выберыце памер выніковай старонкі (па змаўчанні A4) і арыентацыю.
4. Пры жаданні наладзьце адступы, колер рамкі і колер фону.
5. Націсніце кнопку апрацоўкі. Інструмент маштабуе кожную старонку і размяшчае іх на новых аркушах.

## Магчымасці

- Макеты сеткі: 2-up, 4-up, 6-up, 8-up, 9-up і 16-up
- Наладжвальны памер і арыентацыя выніковай старонкі
- Неабавязковыя адступы паміж старонкамі
- Налады колеру фону і рамкі
- Захоўвае прапорцыі арыгінальных старонак пры маштабаванні

## Параметры

| Параметр              | Апісанне                                                                         |
| --------------------- | -------------------------------------------------------------------------------- |
| **Старонак на аркуш** | Колькасць арыгінальных старонак на кожнай выніковай старонцы (2, 4, 6, 8, 9, 16) |
| **Памер старонкі**    | Памер выніковага аркуша (A4, Letter, Legal і г.д.)                               |
| **Арыентацыя**        | Кніжная або альбомная для выніковага аркуша                                      |
| **Адступ**            | Прамежак у пунктах паміж старонкамі                                              |
| **Колер фону**        | Колер запаўнення фону выніковага аркуша                                          |
| **Колер рамкі**       | Колер рамак вакол кожнай старонкі                                                |

## Сцэнарыі выкарыстання

- Друк раздатковых матэрыялаў з 4 слайдамі на старонку для эканоміі паперы
- Стварэнне шпаргалак з некалькімі даведачнымі старонкамі на адным аркушы
- Стварэнне кампактных архіваў дакументаў для захоўвання
- Стварэнне аглядных аркушаў з мініяцюрамі доўгага дакумента

## Парады

- Альбомная арыентацыя часта лепш падыходзіць для макетаў 2-up, а кніжная звычайна найлепшая для 4-up і больш.
- Павелічэнне адступу паляпшае чытэльнасць, але памяншае даступную плошчу для кожнай старонкі.
- Для адваротнай аперацыі (падзел адной старонкі на некалькі) гл. [Пераўтварыць у постэр](./posterize-pdf).

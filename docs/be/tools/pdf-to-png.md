# PDF у PNG

Пераўтварае кожную старонку PDF у відарыс PNG. PNG выкарыстоўвае сцісканне без страт, таму вынік захоўвае кожную дэталь арыгінальнай старонкі. Аднастаронкавыя PDF спампоўваюцца як файл `.png`, шматстаронкавыя даюць ZIP.

## Як гэта працуе

1. Загрузіце PDF, націснуўшы на вобласць загрузкі або перацягнуўшы туды файл.
2. Наладзьце паўзунок **Маштаб**, каб кіраваць разрозненнем выніку.
3. Націсніце **Пераўтварыць**, каб пачаць апрацоўку.
4. Адзін PNG або архіў ZIP спампуецца аўтаматычна.

## Налады

- **Маштаб**: ад 1.0x да 3.0x (па змаўчанні 2.0x). Пры 2.0x стандартная старонка Letter рэндэрыцца прыкладна ў 1 224 x 1 584 пікселі. Большы маштаб дае большыя і больш выразныя відарысы за кошт памеру файла і часу апрацоўкі.

## Фармат выніку

- **Адна старонка**: `filename.png`
- **Некалькі старонак**: `filename_pngs.zip` з `page_1.png`, `page_2.png` і г.д.

## Сцэнарыі выкарыстання

- Дакладныя здымкі старонак PDF для прэзентацый.
- Выманне графікаў або схем, якім патрэбныя выразныя краі без артэфактаў сціскання.
- Падрыхтоўка рэсурсаў для вэб-дызайну з макетаў PDF.
- Стварэнне відарысаў старонак без страт для папярэдняй апрацоўкі перад OCR.

## Парады

- Файлы PNG значна большыя за JPG. Калі памер файла важнейшы за ідэальную якасць, выкарыстайце [PDF у JPG](./pdf-to-jpg) або [PDF у WebP](./pdf-to-webp).
- Пры маштабе 1.0x вынік адпавядае ўласнаму разрозненню PDF. Павялічце да 3.0x для экспарту ў друкарскай якасці.

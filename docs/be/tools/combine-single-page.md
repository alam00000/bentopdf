# Аб'яднаць у адну старонку

Аб'ядноўвайце ўсе старонкі PDF у адну доўгую старонку. Старонкі злучаюцца вертыкальна (як скрутак) або гарызантальна (побач), і ў выніку атрымліваецца адна бесперапынная старонка.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Выберыце напрамак размяшчэння: **Вертыкальна** (старонкі адна пад адной) або **Гарызантальна** (старонкі побач).
3. Задайце адлегласць паміж старонкамі ў пунктах.
4. Выберыце колер фону для прамежкаў паміж старонкамі.
5. Пры жаданні ўключыце раздзяляльнікі (тонкія лініі паміж старонкамі) і наладзьце іх таўшчыню і колер.
6. Націсніце кнопку апрацоўкі. У выніку атрымаецца PDF з адной старонкай.

## Магчымасці

- Вертыкальнае або гарызантальнае злучэнне старонак
- Настройваемая адлегласць паміж старонкамі
- Выбар колеру фону для прамежкаў
- Неабавязковыя лініі-раздзяляльнікі з наладжвальнай таўшчынёй і колерам
- Кожная арыгінальная старонка рэндэрыцца ў поўным разрозненні на агульным палатне

## Параметры

| Параметр                        | Апісанне                                               |
| ------------------------------- | ------------------------------------------------------ |
| **Арыентацыя**                  | Вертыкальна (адна пад адной) або Гарызантальна (побач) |
| **Адлегласць паміж старонкамі** | Прамежак паміж старонкамі ў пунктах                    |
| **Колер фону**                  | Колер вобласці паміж старонкамі                        |
| **Дадаць раздзяляльнік**        | Уключае тонкія лініі паміж старонкамі                  |
| **Таўшчыня раздзяляльніка**     | Таўшчыня лініі ў пунктах                               |
| **Колер раздзяляльніка**        | Колер ліній-раздзяляльнікаў                            |

## Сцэнарыі выкарыстання

- Стварэнне аднаго доўгага відарыса з шматстаронкавага макета або дызайн-макета
- Стварэнне бесперапыннага выгляду дакумента для ўбудавання на вэб-старонку
- Злучэнне шматстаронкавага комікса або раскадроўкі ў адну стужку
- Стварэнне панарамнага выгляду паслядоўных старонак для прагляду

## Парады

- Вертыкальная арыентацыя лепш падыходзіць для дакументаў з кніжнымі старонкамі. Гарызантальная лепш для альбомнага змесціва.
- Вялікія дакументы з мноствам старонак дадуць вельмі высокі або шырокі вынік. Некаторыя праглядальнікі PDF могуць не спраўляцца з надзвычай вялікімі старонкамі.
- Раздзяляльнікі кантрастнага колеру дапамагаюць убачыць, дзе заканчваецца адна арыгінальная старонка і пачынаецца наступная.

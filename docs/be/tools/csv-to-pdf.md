# CSV у PDF

Ператварайце файлы CSV у акуратныя адфарматаваныя дакументы PDF. Кожны CSV разбіраецца і выводзіцца ў PDF як табліца. Гэта зручна, калі трэба раздрукаваць або перадаць таблічныя даныя, не патрабуючы ад атрымальніка праграмы для электронных табліц.

## Падтрымліваемыя фарматы

| Фармат | Пашырэнні |
| :----- | :-------- |
| CSV    | `.csv`    |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце адзін ці некалькі файлаў CSV.
2. Праверце спіс файлаў. Дадайце яшчэ файлы або выдаліце непатрэбныя.
3. Націсніце **Пераўтварыць у PDF**. Індыкатар паказвае ход пераўтварэння.
4. Адзін файл спампоўваецца непасрэдна як PDF. Некалькі файлаў пакуюцца ў `csv-converted.zip`.

## Параметры

У гэтага інструмента няма дадатковых налад. CSV аўтаматычна разбіраецца і фармуецца як табліца.

## Вынік

| Колькасць файлаў | Вынік                                                     |
| :--------------- | :-------------------------------------------------------- |
| 1 файл           | Спампоўванне аднаго PDF (напрыклад, `data.pdf`)           |
| 2+ файлы         | Архіў ZIP (`csv-converted.zip`) з адным PDF на кожны файл |

## Сцэнарыі выкарыстання

- Пераўтварэнне экспартаваных справаздач з баз даных у табліцы PDF для друку
- Перадача фінансавых даных або спісаў запасаў людзям, у якіх няма Excel
- Стварэнне PDF-версій файлаў журналаў CSV для дакументацыі па адпаведнасці
- Друк спісаў адрасоў, ведамасцей ацэнак або любых таблічных даных у CSV

## Парады

- Для лепшага выніку пераканайцеся, што ў CSV выкарыстоўваюцца стандартныя раздзяляльнікі-коскі. Інструмент прытрымліваецца агульнапрынятых правілаў разбору CSV.
- Калі ў CSV шмат слупкоў, табліца можа быць сціснута да шырыні старонкі. Падумайце пра падзел шырокіх набораў даных на некалькі файлаў.
- Для файлаў Excel (`.xls`, `.xlsx`) карыстайцеся інструментам [Excel у PDF](./excel-to-pdf), які захоўвае фарматаванне і некалькі аркушаў.

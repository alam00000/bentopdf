# PDF у TIFF

Пераўтварае кожную старонку PDF у відарыс TIFF. TIFF з'яўляецца стандартным фарматам для друкарскай вытворчасці, факсавых сістэм і архівавання дакументаў. Інструмент выкарыстоўвае сцісканне PackBits для кадавання TIFF і пераходзіць на PNG, калі старонку не ўдаецца закадаваць.

## Як гэта працуе

1. Загрузіце PDF, націснуўшы на вобласць загрузкі або перацягнуўшы туды файл.
2. Націсніце **Пераўтварыць**, каб апрацаваць файл.
3. Адзін файл TIFF або архіў ZIP спампуецца аўтаматычна.

## Налады

У гэтага інструмента няма налад. Старонкі рэндэрацца з фіксаваным маштабам 2x.

## Фармат выніку

- **Адна старонка**: `filename.tiff`
- **Некалькі старонак**: `filename_tiffs.zip` з `page_1.tiff`, `page_2.tiff` і г.д.

Калі кадаванне TIFF для пэўнай старонкі не ўдаецца (з-за праблем са сцісканнем), гэтая старонка захоўваецца як файл `.png`. У такім выпадку ZIP будзе змяшчаць і TIFF, і PNG.

## Сцэнарыі выкарыстання

- Падача дакументаў у дзяржаўныя ўстановы або судовыя сістэмы, якія патрабуюць фармат TIFF.
- Падрыхтоўка старонак для перадачы праз лічбавыя факсавыя сэрвісы.
- Архіваванне сканаваных дакументаў у шырока падтрымліваемым фармаце без страт.
- Перадача старонак у карпаратыўныя сістэмы кіравання дакументамі.

## Парады

- Файлы TIFF вялікія. Калі патрэбна якасць без страт толькі для вэба або экрана, лепш выбраць [PDF у PNG](./pdf-to-png).
- Праверце змесціва ZIP, калі для некаторых старонак спатрэбіўся PNG: магчыма, іх варта пераўтварыць асобна.

# Выняць старонкі

Вымайце набор старонак з PDF і захоўвайце іх як новы файл. Дакладна ўкажыце патрэбныя старонкі з дапамогай дыяпазонаў, і інструмент створыць акуратны PDF толькі з гэтымі старонкамі.

## Як гэта працуе

1. Загрузіце файл PDF. Інструмент паказвае назву файла, памер і агульную колькасць старонак.
2. Увядзіце старонкі, якія трэба выняць, з дапамогай дыяпазонаў (напрыклад, `1-5`, `3, 7, 10-12`).
3. Пры жаданні выберыце спампоўванне кожнага дыяпазону як асобнага PDF у архіве ZIP.
4. Націсніце кнопку апрацоўкі. Вынятыя старонкі спампуюцца як новы PDF (або ZIP).

## Магчымасці

- Гнуткі сінтаксіс дыяпазонаў: асобныя старонкі, дыяпазоны або спалучэнні праз коску
- Паказ агульнай колькасці старонак пасля загрузкі для зручнасці
- Вынік у выглядзе аднаго агульнага PDF або асобных файлаў у ZIP
- Захоўваюцца арыгінальнае змесціва і фарматаванне старонак

## Сцэнарыі выкарыстання

- Выманне кароткага выкладу (першых некалькіх старонак) з аб'ёмнай справаздачы
- Выманне аднаго раздзела з падручніка ў PDF
- Захаванне пэўных старонак з пакета бланкаў як асобных дакументаў
- Стварэнне ўзору дакумента з выбраных старонак большага файла

## Парады

- Нумарацыя старонак пачынаецца з 1. Выкарыстоўвайце `1` для першай старонкі, а не `0`.
- Каб выдаліць старонкі, а не выняць іх, карыстайцеся [Выдаліць старонкі](./delete-pages): гэта адваротная аперацыя.
- Калі патрэбны візуальны выбар старонак з мініяцюрамі, карыстайцеся [Падзяліць PDF](./split-pdf) у рэжыме візуальнага выбару.

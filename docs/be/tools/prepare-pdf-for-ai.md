# Падрыхтаваць PDF для ШI

Выцягвае змест з файлаў PDF і структуруе яго ў JSON, аптымізаваны для апрацоўкі вялікімі моўнымі мадэлямі (LLM) і ШI-фрэймворкамі, такімі як LlamaIndex. Змест кожнай старонкі выцягваецца і арганізуецца ў структураваны фармат, гатовы для RAG-канвеераў, чат-ботаў або сістэм семантычнага пошуку.

## Як гэта працуе

1. Загрузіце адзін або некалькі PDF, націснуўшы на вобласць загрузкі або перацягнуўшы файлы на яе.
2. Націсніце **Выняць для ШІ**, каб пачаць апрацоўку.
3. Адзін файл спампоўваецца як `filename_llm.json`. Некалькі файлаў ствараюць архіў `pdf-for-ai.zip`.

Інструмент выкарыстоўвае інтэграцыю PyMuPDF з LlamaIndex, каб выцягваць змест на ўзроўні старонак разам з метаданымі, і стварае вынік, які можна адразу загрузіць у ШI-фрэймворкі.

## Параметры

У гэтага інструмента няма наладжвальных параметраў. Усе старонкі выцягваюцца з поўным тэкстам і метаданымі.

## Фармат выніку

- **Адзін файл**: `filename_llm.json`
- **Некалькі файлаў**: `pdf-for-ai.zip` з адным `_llm.json` на кожны ўваходны PDF.

Вынік у JSON адпавядае схеме дакумента LlamaIndex з тэкставым зместам і палямі метаданых для кожнай старонкі.

## Сцэнарыі выкарыстання

- Падрыхтоўка дакументаў PDF для канвеераў генерацыі з дапамогай пошуку (RAG).
- Стварэнне базы ведаў з архіваў PDF для ШI-чат-бота.
- Перадача справаздач PDF у працоўныя працэсы аналізу на аснове LLM.
- Папярэдняя апрацоўка навуковых артыкулаў для семантычнага пошуку і сістэм адказаў на пытанні.
- Стварэнне структураваных навучальных даных з калекцый дакументаў PDF.

## Парады

# Разблакаваць PDF

Калі ў вас ёсць пароль ад зашыфраванага PDF, гэты інструмент цалкам выдаляе шыфраванне і стварае разблакаваную копію, якую любы можа адкрыць без уліковых даных. Падтрымліваецца пакетная расшыфроўка, калі некалькі PDF маюць аднолькавы пароль.

## Як гэта працуе

1. Загрузіце адзін або некалькі зашыфраваных PDF-файлаў.
2. Увядзіце **пароль**, якім абаронены файлы.
3. Націсніце **Расшыфраваць PDF**.
4. Адзін файл спампоўваецца адразу. Некалькі файлаў ствараюць ZIP-архіў з усімі разблакаванымі PDF.

## Магчымасці

- Расшыфроўка аднаго файла і пакетная расшыфроўка
- Апрацоўка як пароляў карыстальніка, так і пароляў уладальніка
- Цалкам незашыфраваны вынік без рэшткавых абмежаванняў
- Зразумелыя паведамленні пра памылкі пры няправільным паролі або пашкоджаных файлах
- Адсочванне поспеху або памылкі для кожнага файла ў пакетным рэжыме

## Чым адрозніваецца ад «Выдаліць абмежаванні»

**Расшыфраваць PDF** патрабуе пароль і выдаляе ўсё шыфраванне. **Выдаліць абмежаванні** працуе з абмежаваннямі выкарыстання (друк, капіраванне, рэдагаванне) і можа не патрабаваць пароля, калі быў зададзены толькі пароль уладальніка. Выкарыстоўвайце расшыфроўку, калі PDF наогул не адкрываецца без пароля.

## Сцэнарыі выкарыстання

- Канчатковая разблакоўка PDF, якія вы раней зашыфравалі, калі пароль больш не патрэбны
- Выдаленне шыфравання з пакета архіўных дакументаў для зручнага доўгатэрміновага доступу
- Падрыхтоўка абароненых паролем PDF для сістэмы кіравання дакументамі, якая не падтрымлівае зашыфраваныя файлы
- Разблакоўка PDF перад іх аб'яднаннем з іншымі дакументамі (многія інструменты аб'яднання не могуць апрацоўваць зашыфраваныя файлы)

## Парады

- Поле пароля прымяняецца да ўсіх загружаных файлаў. Калі ў вашых PDF розныя паролі, апрацоўвайце іх асобнымі пакетамі.
- Калі вы атрымалі памылку «Няправільны пароль», праверце, ці няма прабелаў у канцы і ці не ўключаны Caps Lock.
- Пасля расшыфроўкі вынік не мае ніякай абароны. Зашыфруйце яго зноў праз «Зашыфраваць PDF», калі трэба задаць новы пароль.

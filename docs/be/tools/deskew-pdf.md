# Выпрастаць PDF

Сканаваныя дакументы рэдка бываюць ідэальна роўнымі. Нават невялікі нахіл зніжае дакладнасць OCR і робіць друк неакуратным. Гэты інструмент выкарыстоўвае алгарытмы апрацоўкі відарысаў OpenCV, каб вызначыць кут нахілу кожнай старонкі і павярнуць яе назад да роўнага становішча.

## Як гэта працуе

1. Загрузіце адзін або некалькі сканаваных PDF.
2. Задайце **Парог нахілу**: старонкі з нахілам меншым за гэта значэнне застаюцца без змен.
3. Выберыце **Якасць апрацоўкі (DPI)**: больш высокі DPI павышае дакладнасць выяўлення, але апрацоўка займае больш часу.
4. Націсніце **Выпрастаць PDF**.
5. Пасля апрацоўкі панэль вынікаў паказвае выяўлены кут кожнай старонкі і ці была яна выпраўлена.

## Параметры

| Налада            | Значэнні                   | Па змаўчанні |
| ----------------- | -------------------------- | ------------ |
| **Парог нахілу**  | 0.1, 0.5, 1.0, 2.0 градуса | 0.5          |
| **DPI апрацоўкі** | 100, 150, 200, 300         | 150          |

## Як працуе выяўленне нахілу

Інструмент рэндэрыць кожную старонку ў відарыс з выбраным DPI, а потым з дапамогай OpenCV вызначае дамінуючыя вуглы ліній у змесціве. Калі выяўлены нахіл перавышае парог, старонка паварочваецца на адваротны кут, каб выраўнаваць яе. Старонкі ніжэй за парог застаюцца без змен.

## Сцэнарыі выкарыстання

- Ачыстка пакетна адсканаваных дагавораў або юрыдычных дакументаў
- Падрыхтоўка адсканаваных чэкаў або рахункаў да OCR
- Выраўноўванне старонак з планшэтнага сканера пры няроўна пакладзенай паперы
- Паляпшэнне візуальнай якасці алічбаваных архіўных матэрыялаў

## Парады

- Паменшыце парог да 0.1 градуса, калі для OCR патрэбна ідэальнае выраўноўванне.
- 150 DPI хутка і дакладна для большасці дакументаў. Для вельмі дробнага тэксту або старонак з дробнымі дэталямі выкарыстоўвайце 300 DPI.
- Выпрастанне лепш за ўсё працуе з дакументамі з выразнымі гарызантальнымі радкамі тэксту. Яно можа не спраўляцца са старонкамі, дзе пераважаюць відарысы або дыяганальныя элементы дызайну.

# CBZ у PDF

Ператварайце архівы коміксаў у PDF. CBZ і CBR з'яўляюцца стандартнымі фарматамі лічбавых коміксаў: гэта проста архівы ZIP або RAR з відарысамі. Інструмент вымае кожную старонку, захоўвае парадак чытання і стварае акуратны PDF, дзе кожны відарыс становіцца поўнапамернай старонкай.

## Падтрымліваемыя фарматы

| Фармат | Пашырэнне | Заўвагі                                                         |
| :----- | :-------- | :-------------------------------------------------------------- |
| CBZ    | `.cbz`    | Архіў коміксаў на аснове ZIP (апрацоўваецца лакальна з pdf-lib) |
| CBR    | `.cbr`    | Архіў коміксаў на аснове RAR (апрацоўваецца рухавіком PyMuPDF)  |

Канвертар CBZ распазнае ўнутры архіва відарысы JPEG, PNG, GIF, BMP, WebP, AVIF, TIFF, HEIC і JXL. Нестандартныя фарматы перад устаўкай аўтаматычна пераўтвараюцца ў PNG.

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце файлы CBZ ці CBR. Можна змешваць абодва фарматы ў адным пакеце.
2. Праверце спіс файлаў. Выдаліце непатрэбныя або націсніце **Дадаць файлы**, каб дадаць яшчэ.
3. Націсніце **Пераўтварыць у PDF**. Для файлаў CBZ інструмент распакоўвае архіў, сартуе відарысы па назве ў натуральным парадку, вызначае сапраўдны фармат кожнага відарыса і ўстаўляе іх у PDF з дапамогай pdf-lib. Файлы CBR замест гэтага апрацоўваюцца рухавіком PyMuPDF.
4. Адзін файл спампоўваецца як PDF. Некалькі файлаў даюць архіў ZIP з назвай `comic-converted.zip`.

## Параметры

Налады не патрэбныя. Кожны відарыс становіцца старонкай памерам з арыгінал, таму развароты застаюцца шырокімі, а асобныя старонкі вузкімі.

## Сцэнарыі выкарыстання

- Чытанне коміксаў на планшэце або ў праграме на тэлефоне, якая падтрымлівае PDF, але не CBZ/CBR
- Друк асобных старонак лічбавага комікса
- Архіваванне калекцыі коміксаў у фармаце, які адкрые любы праглядальнік
- Абмен коміксам з тым, у каго няма спецыяльнай праграмы для чытання коміксаў

## Парады

- Відарысы ў архіве сартуюцца ў натуральным парадку (таму `page2.jpg` ідзе перад `page10.jpg`). Называйце файлы з паслядоўнай нумарацыяй, каб старонкі ішлі правільна.
- Канвертар вызначае фармат відарысаў па іх двайковых сігнатурах, а не па пашырэннях. PNG, выпадкова названы `.jpg`, усё роўна ўставіцца правільна.
- Файлы CBZ цалкам апрацоўваюцца ў браўзеры без загрузкі рухавіка PyMuPDF, таму яны пераўтвараюцца хутчэй за файлы CBR.

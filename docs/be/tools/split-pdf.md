# Падзяліць PDF

Разбівайце PDF на меншыя дакументы з дапамогай аднаго з шасці рэжымаў падзелу. Ад простых дыяпазонаў старонак да падзелу па закладках, гэты інструмент спраўляецца з любым сцэнарыем падзелу дакумента.

## Як гэта працуе

1. Загрузіце адзін файл PDF.
2. Выберыце рэжым падзелу ў выпадальным спісе.
3. Наладзьце параметры рэжыму (дыяпазоны старонак, выбар і г.д.).
4. Націсніце кнопку апрацоўкі.
5. Вынік спампоўваецца як адзін PDF або архіў ZIP у залежнасці ад рэжыму і налад.

## Рэжымы падзелу

| Рэжым                                       | Апісанне                                                                                                                                  |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Здабыванне па дыяпазоне старонак**        | Увядзіце дыяпазоны старонак, напрыклад `1-3, 5, 8-10`. Некалькі дыяпазонаў ствараюць асобныя PDF у ZIP. Адзін дыяпазон стварае адзін PDF. |
| **Выбар старонак візуальна**                | Праглядайце мініяцюры старонак і націскайце, каб выбраць патрэбныя старонкі. Выбраныя старонкі выцягваюцца ў новы PDF.                    |
| **Падзел па цотных і няцотных старонках**   | Выцягнуць толькі цотныя або няцотныя старонкі.                                                                                            |
| **Падзяліць усе старонкі на асобныя файлы** | Падзяліць кожную старонку ў асобны файл PDF, які спампоўваецца як ZIP.                                                                    |
| **Падзел па закладках**                     | Дзяліць па межах закладак. Выберыце ўзровень закладак, каб вызначыць месцы падзелу.                                                       |
| **Падзел кожныя N старонак**                | Дзяліць на часткі па N старонак (напрыклад, кожныя 5 старонак). Апошняя частка можа мець менш старонак.                                   |

## Магчымасці

- Шэсць розных рэжымаў падзелу, якія ахопліваюць практычна любы сцэнарый
- Візуальны выбар старонак з адкладзенай загрузкай мініяцюр
- Падзел з улікам закладак з фільтрацыяй па ўзроўні
- Варыянт выніку ў ZIP для рэжымаў дыяпазону і візуальнага выбару
- Апрацоўка дыяпазонаў старонак са змешаным сінтаксісам (`1-3, 5, 8-10`)
- Папярэджанне, калі падзел па N старонак дае нераўнамерныя часткі

## Сцэнарыі выкарыстання

- Выцягванне пэўнага раздзела або часткі з вялікага дакумента
- Падзел цотных і няцотных старонак для двухбаковага друку
- Разбіўка кнігі PDF на асобныя файлы раздзелаў па межах закладак
- Вылучэнне пэўных старонак (напрыклад, старонкі подпісу) з кантракта
- Падзел зводнай справаздачы на файлы па раздзелах для распаўсюджвання

## Парады

- Некалькі дыяпазонаў старонак праз коску (напрыклад, `1-5, 10-15, 20-25`) ствараюць асобныя PDF, па адным на дыяпазон, сабраныя ў ZIP.
- Рэжым падзелу па закладках патрабуе, каб PDF сапраўды змяшчаў закладкі. Калі іх няма, вы ўбачыце паведамленне пра памылку.
- Сцяжок "Спампаваць як ZIP" у рэжымах выбару дыяпазону і візуальнага выбару дазваляе атрымаць асобныя PDF для кожнай старонкі замест аднаго аб'яднанага файла.

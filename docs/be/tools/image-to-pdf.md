# Відарысы ў PDF

Універсальны канвертар відарысаў у PDF. Запампоўвайце відарысы практычна ў любым фармаце і аб'ядноўвайце іх у адзін дакумент PDF. Кожны відарыс атрымлівае асобную старонку, памер якой адпавядае арыгінальным памерам.

## Падтрымліваемыя фарматы

| Фармат          | Пашырэнні                              |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

Гэта найшырэйшая падтрымка фарматаў сярод усіх канвертараў відарысаў BentoPDF. Калі вам патрэбны толькі пэўны фармат, выкарыстоўвайце адзін са спецыялізаваных інструментаў.

## Як гэта працуе

1. Націсніце на вобласць запампоўвання або перацягніце файлы відарысаў. Можна выбраць некалькі файлаў адразу.
2. Праверце спіс файлаў. Выдаліце непатрэбныя файлы значком сметніцы або націсніце **Дадаць яшчэ файлы**, каб дадаць іншыя відарысы.
3. Выберыце ўзровень **Якасці PDF** у спісе.
4. Націсніце **Пераўтварыць у PDF**. Інструмент апрацоўвае відарысы рухавіком PyMuPDF і спампоўвае вынік як `images_to_pdf.pdf`.

## Параметры

**Якасць PDF** вызначае сціск відарысаў пры ўбудоўванні ў PDF:

- **Высокая якасць**: мінімальны сціск, большы памер файла. Найлепш для друку або архівавання.
- **Сярэдняя якасць** (па змаўчанні): збалансаваны сціск. Падыходзіць для большасці задач.
- **Нізкая якасць**: моцны сціск, найменшы памер файла. Падыходзіць для электроннай пошты або хуткага абмену.

Файлы HEIC і WebP аўтаматычна пераўтвараюцца ў PNG перад убудоўваннем. Гэта адбываецца незаўважна і не патрабуе дадатковых крокаў.

## Сцэнарыі выкарыстання

- Аб'яднанне сканаваных чэкаў або дакументаў з камеры тэлефона ў адзін PDF
- Стварэнне фотапартфоліо або лукбука з відарысаў розных фарматаў
- Пераўтварэнне фота з iPhone (HEIC) у PDF для абмену без усталявання праграм
- Зборка макетаў дызайну з экспартаў PSD і здымкаў экрана ў матэрыял для кліента
- Архіваванне папкі з відарысамі ў старых фарматах (PNM, JXR, JP2) у адзін PDF

## Парады

- Парадак відарысаў у PDF адпавядае іх парадку ў спісе файлаў. Запампоўвайце іх у патрэбнай паслядоўнасці.
- Для найменшага памеру файла выберыце нізкую якасць. Для сканаў з вялікай колькасцю тэксту візуальная розніца часта нязначная.
- Калі ў вас толькі адзін фармат відарысаў, спецыялізаваныя канвертары (JPG у PDF, PNG у PDF і г.д.) даюць той жа вынік з больш простым інтэрфейсам.

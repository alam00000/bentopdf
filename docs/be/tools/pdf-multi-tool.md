# Мультыінструмент PDF

Адзінае працоўнае асяроддзе для ўсіх аперацый са старонкамі PDF. Загрузіце адзін ці некалькі PDF і працуйце з усімі старонкамі ў адной візуальнай сетцы. Паварочвайце, пераўпарадкоўвайце, дублюйце, выдаляйце, устаўляйце новыя PDF, дадавайце пустыя старонкі і дзяліце вынік, не пакідаючы інструмента.

## Як гэта працуе

1. Націсніце **Загрузіць PDF** або перацягніце файлы ў вобласць загрузкі. Падтрымліваецца некалькі файлаў.
2. Усе старонкі з кожнага загружанага файла з'яўляюцца ў сетцы мініяцюр з пракруткай.
3. Выкарыстоўвайце панэль інструментаў або кнопкі на кожнай старонцы для працы са старонкамі.
4. Вылучайце старонкі сцяжком на кожнай картцы, затым ужывайце масавыя аперацыі.
5. Адзначайце пункты падзелу значком нажніц, каб падзяліць вынік на асобныя файлы.
6. Націсніце **Экспартаваць PDF**, каб спампаваць канчатковы вынік. Калі ёсць маркеры падзелу, вынікам будзе ZIP з некалькімі PDF.

## Магчымасці

- **Аб'яднанне**: загрузіце некалькі PDF, і яны аўтаматычна аб'яднаюцца ў адно працоўнае асяроддзе
- **Змяненне парадку**: перацягвайце карткі старонак, каб змяніць паслядоўнасць
- **Паварот**: паварот асобных або некалькіх старонак з крокам 90 градусаў (улева або ўправа)
- **Дубляванне**: капіяванне любой старонкі адным націскам
- **Выдаленне**: выдаленне асобных старонак або ўсіх вылучаных
- **Уставіць PDF**: дадаванне новага PDF пасля любой старонкі
- **Дадаць пустую старонку**: дадаванне пустой старонкі A4 у канец
- **Падзел**: размясціце маркеры падзелу паміж старонкамі і экспартуйце ZIP з асобнымі PDF
- **Вылучыць усё / Зняць вылучэнне**: хуткае вылучэнне для масавых аперацый
- **Адрабіць / Паўтарыць**: поўная гісторыя адмены і паўтору для кожнай аперацыі
- **Спампаваць вылучанае**: экспарт толькі вылучаных старонак як асобнага PDF
- Аўтаматычнае аднаўленне пашкоджаных PDF перад загрузкай

## Сцэнарыі выкарыстання

- Стварэнне ўласнага дакумента са старонак некалькіх зыходных PDF
- Ачыстка сканаванага дакумента: выдаленне пустых старонак, паварот бакавых сканаў і змяненне парадку раздзелаў
- Падзел вялікага PDF па межах раздзелаў з дапамогай візуальных маркераў
- Хуткае рэдагаванне старонак без поўнага рэдактара PDF

## Парады

- Сістэма адмены і паўтору адсочвае кожную аперацыю. Карыстайцеся ёй смела: выпадкова знішчыць сваю працу не атрымаецца.
- Маркеры падзелу паказваюцца як сінія пункцірныя лініі паміж старонкамі. Размясціце іх там, дзе трэба падзяліць дакумент, і экспартуйце ZIP.
- Для простага аб'яднання або падзелу спецыяльныя інструменты [Аб'яднаць PDF](./merge-pdf) і [Падзяліць PDF](./split-pdf) могуць быць хутчэйшыя. Мультыінструмент найлепшы, калі ў адной сесіі патрэбныя некалькі аперацый.

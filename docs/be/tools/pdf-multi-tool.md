# Мультыінструмент PDF

Адзінае працоўнае асяроддзе для ўсіх аперацый са старонкамі PDF. Загрузіце адзін ці некалькі PDF і працуйце з усімі старонкамі ў адной візуальнай сетцы. Паварочвайце, пераўпарадкоўвайце, дублюйце і выдаляйце старонкі, устаўляйце PDF, выявы і пустыя старонкі, змяняйце нумарацыю і памер старонак і дзяліце вынік, не пакідаючы інструмента.

## Як гэта працуе

1. Націсніце **Выбраць файлы** або перацягніце файлы ў вобласць загрузкі. Падтрымліваецца некалькі файлаў, яны аб'ядноўваюцца ў парадку загрузкі.
2. Усе старонкі з'яўляюцца ў сетцы мініяцюр з пракруткай.
3. Націсніце на старонку, каб вылучыць яе. Каб вылучыць дыяпазон, націскайце з Shift, а каб дадаць або прыбраць асобныя старонкі, націскайце з Cmd/Ctrl.
4. Выкарыстоўвайце панэль інструментаў арганайзера або націсніце на старонку правай кнопкай мышы, каб адкрыць дзеянні са старонкай.
5. Націсніце **Экспартаваць PDF**, каб спампаваць канчатковы вынік.

## Магчымасці

- **Аб'яднанне**: загрузіце некалькі PDF і выяў, і яны аўтаматычна аб'яднаюцца ў адзін дакумент
- **Змяненне парадку**: перацягвайце старонкі, каб змяніць паслядоўнасць, або перавярніце парадак усяго дакумента
- **Паварот**: паварочвайце вылучаныя старонкі ўлева або ўправа з крокам 90 градусаў
- **Дубляванне**: капіруйце вылучаныя старонкі і змяшчайце копіі адразу пасля іх
- **Выдаленне**: выдаляйце вылучаныя старонкі
- **Устаўка**: дадавайце старонкі з іншага PDF або выявы, пустую старонку, старонкі з буфера абмену або чаргуйце старонкі другога PDF з бягучымі
- **Замена**: замяняйце старонку першай старонкай іншага PDF
- **Выразаць, капіраваць і ўставіць**: перамяшчайце або капіруйце старонкі ўнутры дакумента
- **Выманне**: спампоўвайце вылучаныя старонкі як PDF або як выявы
- **Нумары старонак**: задавайце для дыяпазону старонак меткі, напрыклад i, ii, iii або A-1, A-2
- **Памер старонкі**: падганяйце старонкі пад стандартны фармат паперы або адвольны памер
- **Падзел**: дзяліце дакумент па дыяпазонах старонак, на няцотныя і цотныя старонкі, па кожнай старонцы, па закладках, кожныя N старонак або па памеры файла
- **Адрабіць / Паўтарыць**: кожную аперацыю са старонкамі можна адмяніць і паўтарыць
- Аўтаматычнае аднаўленне пашкоджаных PDF перад загрузкай

## Спалучэнні клавіш

| Дзеянне                        | Спалучэнне клавіш               |
| ------------------------------ | ------------------------------- |
| Павярнуць управа / улева       | R / Shift+R                     |
| Вылучыць усё                   | Cmd/Ctrl+A                      |
| Выразаць, капіраваць, уставіць | Cmd/Ctrl+X, C, V                |
| Дубляваць                      | Cmd/Ctrl+D                      |
| Выдаліць                       | Delete або Backspace            |
| Адрабіць / Паўтарыць           | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z   |
| Перамясціць вылучэнне          | Клавішы са стрэлкамі, Home, End |

## Сцэнарыі выкарыстання

- Стварэнне ўласнага дакумента са старонак некалькіх зыходных PDF
- Ачыстка сканаванага дакумента: выдаленне пустых старонак, паварот бакавых сканаў і змяненне парадку раздзелаў
- Падзел вялікага PDF па межах раздзелаў з дапамогай яго закладак
- Хуткае рэдагаванне старонак без поўнага рэдактара PDF

## Парады

- Гісторыя адмены і паўтору адсочвае кожную аперацыю са старонкамі. Карыстайцеся ёй смела: выпадкова знішчыць сваю працу не атрымаецца.
- Каб дадаць у дакумент новыя PDF або выявы, у любы момант выкарыстоўвайце **Insert > From File** або перацягніце іх на сетку старонак.
- Для простага аб'яднання або падзелу спецыяльныя інструменты [Аб'яднаць PDF](./merge-pdf) і [Падзяліць PDF](./split-pdf) могуць быць хутчэйшыя. Мультыінструмент найлепшы, калі ў адной сесіі патрэбныя некалькі аперацый.

# Выдаліць старонкі

Выдаляйце непатрэбныя старонкі з дакумента PDF. Укажыце старонкі для выдалення, увёўшы нумары або дыяпазоны, або націскайце на мініяцюры старонак, каб пазначыць іх.

## Як гэта працуе

1. Загрузіце файл PDF. Інструмент паказвае мініяцюры ўсіх старонак.
2. Увядзіце старонкі для выдалення ў тэкставае поле з дыяпазонамі (напрыклад, `2, 5-8`) або націскайце на мініяцюры, каб пазначыць іх.
3. Пазначаныя старонкі вылучаюцца, каб вы маглі праверыць выбар.
4. Націсніце кнопку апрацоўкі. Будзе створаны новы PDF без выбраных старонак.

## Магчымасці

- Тэкставы выбар старонак з дыяпазонамі (`2, 5-8, 12`)
- Сетка мініяцюр для выбару старонак націскам
- Вылучэнне пазначаных для выдалення старонак у рэальным часе
- Праверка ўводу адносна сапраўднай колькасці старонак
- Усе невыдаленыя старонкі захоўваюць зыходны парадак

## Сцэнарыі выкарыстання

- Выдаленне пустых або лішніх старонак са сканаванага дакумента
- Выдаленне вокладак або дадаткаў перад абменам дакументам
- Ачыстка чарнавых старонак, якія выпадкова засталіся ў выніковым PDF
- Выдаленне старонак з канфідэнцыйнай інфармацыяй перад распаўсюджваннем

## Парады

- Выдаленне старонак не ўплывае на змесціва і фарматаванне астатніх. Вынік з'яўляецца дакладнай копіяй арыгінала без выдаленых старонак.
- Калі трэба пакінуць толькі пэўныя старонкі, а не выдаліць пэўныя, лепш падыдзе [Выняць старонкі](./extract-pages).
- Мініяцюры загружаюцца па меры патрэбы, таму вялікія дакументы застаюцца хуткімі.

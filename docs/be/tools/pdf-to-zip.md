# PDF у ZIP

Аб'ядноўвайце некалькі файлаў PDF у адзін архіў ZIP. Гэта просты інструмент упакоўкі: самі PDF не пераўтвараюцца, не сціскаюцца і не змяняюцца.

## Як гэта працуе

1. Загрузіце некалькі файлаў PDF праз вобласць загрузкі.
2. Праверце спіс файлаў. Выдаліце тыя, якія не трэба ўключаць.
3. Націсніце кнопку апрацоўкі.
4. Архіў ZIP з усімі загружанымі PDF адразу спампуецца.

## Магчымасці

- Прымае любую колькасць файлаў PDF
- Выдаленне асобных файлаў перад стварэннем архіва
- Захоўвае арыгінальныя імёны файлаў у ZIP
- Змесціва PDF не змяняецца: файлы пакуюцца як ёсць
- Паказвае імя і памер кожнага загружанага PDF

## Сцэнарыі выкарыстання

- Аб'яднанне набору рахункаў або чэкаў для ўкладання ў ліст
- Упакоўка вынікаў праекта (некалькіх справаздач PDF) для перадачы
- Стварэнне адной спампоўкі для калекцыі форм або шаблонаў
- Архіваванне пакета дакументаў у адзін сціснуты файл

## Парады

- ZIP выкарыстоўвае арыгінальныя імёны файлаў PDF. Калі ёсць файлы з аднолькавымі імёнамі, перайменуйце іх перад загрузкай, каб пазбегнуць канфліктаў.
- Інструмент не сціскае самі PDF. Каб паменшыць памер, спачатку апрацуйце іх інструментам «Сціснуць PDF», а потым запакуйце тут.

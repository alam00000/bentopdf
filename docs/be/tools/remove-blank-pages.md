# Выдаліць пустыя старонкі

Праскануйце PDF на наяўнасць пустых або амаль пустых старонак і аўтаматычна выдаліце іх. Інструмент адмалёўвае кожную старонку і аналізуе яе пікселі, каб вызначыць, ці пустая яна, а потым дазваляе пацвердзіць, якія старонкі выдаліць, перад апрацоўкай.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Наладзьце паўзунок **Адчувальнасць**, каб вызначыць, наколькі строга вызначаецца "пустая" старонка.
3. Націсніце **Знайсці пустыя старонкі**, каб праскануваць дакумент.
4. Інструмент паказвае мініяцюры знойдзеных пустых старонак для праверкі.
5. Пацвердзіце выбар і спампуйце ачышчаны PDF без пустых старонак.

## Параметры

- **Адчувальнасць**: паўзунок ад 0% да 100% (па змаўчанні 80%). Больш высокія значэнні строжэйшыя і адзначаюць толькі цалкам або амаль белыя старонкі. Ніжэйшыя значэнні мякчэйшыя і ловяць старонкі з мінімальным зместам, напрыклад з адной кропкай або бледным вадзяным знакам.

## Магчымасці

- Аналіз кожнай старонкі на ўзроўні пікселяў для выяўлення пустога зместу
- Наладжвальны паўзунок адчувальнасці для дакладнай налады выяўлення
- Мініяцюры знойдзеных пустых старонак для ручной праверкі
- Захоўвае ўсе непустыя старонкі без змен
- Апрацоўвае дакументы любога памеру і з любой колькасцю старонак
- Паказ прагрэсу падчас сканавання

## Сцэнарыі выкарыстання

- Ачыстка сканаваных дакументаў, дзе сканер захапіў пустыя адваротныя бакі аднабаковых арыгіналаў
- Выдаленне раздзяляльных старонак з пакетаў масава сканаваных дакументаў
- Выдаленне пустых старонак, устаўленых сістэмамі кіравання дакументамі
- Ачыстка PDF, экспартаваных з тэкставых рэдактараў, якія часам дадаюць пустыя старонкі ў канцы
- Памяншэнне памеру файла за кошт выдалення непатрэбных пустых старонак

## Парады

- Пачніце са стандартнай адчувальнасці 80% і падладжвайце ад яе. Калі інструмент прапускае старонкі, якія вам здаюцца пустымі, панізьце адчувальнасць. Калі ён адзначае старонкі са слабым зместам, які вы хочаце захаваць, павысьце яе.
- Інструмент адмалёўвае кожную старонку для аналізу, таму час апрацоўкі расце з колькасцю старонак. Для вельмі вялікіх дакументаў давядзецца крыху пачакаць.
- Праглядзіце знойдзеныя пустыя старонкі ў мініяцюрах перад пацвярджэннем выдалення. Старонкі з бледнымі калантытуламі або вадзянымі знакамі могуць быць адзначаны ў залежнасці ад адчувальнасці.

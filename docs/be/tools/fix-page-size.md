# Уніфікаваць памер старонак

PDF, сабраныя з розных крыніц, часта маюць старонкі рознага памеру: адны Letter, іншыя A4, а некаторыя зусім нестандартныя. Гэты інструмент прыводзіць кожную старонку да аднаго мэтавага памеру, маштабуючы змесціва так, каб яно ўмяшчалася або запаўняла старонку.

## Як гэта працуе

1. Запампуйце файл PDF.
2. Выберыце **Мэтавы памер старонкі** у спісе (A4, Letter, Legal, A3, A5, Tabloid або ўласны).
3. Выберыце **Арыентацыю**: «Аўта» захоўвае арыгінальную арыентацыю кожнай старонкі, або можна прымусова задаць кніжную ці альбомную.
4. Выберыце рэжым **Маштабавання змесціва**: «Умясціць» (захоўвае ўсё змесціва, можа дадаць палі) або «Запоўніць» (запаўняе старонку, можа абрэзаць краі).
5. Пры жаданні задайце **Колер фону** для дададзеных палёў.
6. Націсніце **Уніфікаваць памер старонак**.

## Параметры

- **Стандартныя памеры**: A4, Letter, Legal, A3, A5, Tabloid
- **Уласныя памеры**: увядзіце шырыню і вышыню ў цалях або міліметрах
- **Арыентацыя**: аўта, кніжная, альбомная
- **Рэжым маштабавання**: «Умясціць» або «Запоўніць» (абрэзка)
- **Колер фону**: любы колер для запаўнення палёў

## Сцэнарыі выкарыстання

- Нармалізацыя аб'яднанага PDF, старонкі якога атрыманы з розных сканераў
- Пераўтварэнне дакумента US Letter у A4 для міжнароднага распаўсюджвання
- Падрыхтоўка PDF да друку, дзе патрэбны аднолькавы фармат
- Выпраўленне старонак, якія крыху адхіляюцца ад стандарту (напрыклад, 8.49 x 11.02 цаля замест 8.5 x 11)

## Парады

- Выкарыстоўвайце рэжым «Умясціць», каб гарантавана не страціць змесціва. Рэжым «Запоўніць» выглядае акуратней, але можа абрэзаць краі.
- Праверце вынік інструментам «Памеры старонкі», каб пераканацца, што кожная старонка адпавядае мэтаваму памеру.
- Колер фону па змаўчанні белы; выберыце цёмны колер, калі ў дакумента цёмныя палі.

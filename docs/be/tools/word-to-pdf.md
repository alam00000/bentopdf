# Word у PDF

Пераўтварайце дакументы Microsoft Word і сумяшчальныя фарматы ў PDF. Інструмент выкарыстоўвае рухавік LibreOffice у браўзеры, які апрацоўвае файлы DOC, DOCX, ODT і RTF і захоўвае ў выніку фарматаванне, табліцы, выявы, верхнія і ніжнія калантытулы і стылі.

## Падтрымліваемыя фарматы

| Фармат            | Пашырэнні |
| :---------------- | :-------- |
| Word (сучасны)    | `.docx`   |
| Word (стары)      | `.doc`    |
| OpenDocument Text | `.odt`    |
| Rich Text Format  | `.rtf`    |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце дакументы Word. Можна выбраць некалькі файлаў адразу.
2. Праглядзіце спіс файлаў і кіруйце ім.
3. Націсніце **Пераўтварыць у PDF**. Рухавік LibreOffice загружаецца пры першым выкарыстанні (індыкатар прагрэсу паказвае стан ініцыялізацыі), пасля чаго пераўтвараецца кожны файл.
4. Адзін файл спампоўваецца адразу як PDF. Некалькі файлаў пакуюцца ў `word-converted.zip`.

## Параметры

У гэтага інструмента няма дадатковых налад. Рухавік LibreOffice стварае вынік з дапамогай свайго стандартнага профілю экспарту ў PDF.

## Вынік

| Колькасць файлаў | Вынік                                                      |
| :--------------- | :--------------------------------------------------------- |
| 1 файл           | Адзін PDF (арыгінальная назва файла з пашырэннем `.pdf`)   |
| 2+ файлы         | ZIP-архіў (`word-converted.zip`) з адным PDF на кожны файл |

## Сцэнарыі выкарыстання

- Пераўтварэнне рэзюмэ або суправаджальнага ліста з DOCX у PDF перад адпраўкай на вакансію
- Пакетнае пераўтварэнне дагавораў або прапаноў у PDF для перадачы кліенту
- Ператварэнне старых файлаў `.doc` у сучасныя PDF для доўгатэрміновага архіва
- Пераўтварэнне сумесных дакументаў з Google Docs (экспартаваных як DOCX) у PDF
- Стварэнне гатовых да друку PDF з шаблонаў Word, якія выкарыстоўваюцца для аўтаматычнага стварэння дакументаў

## Парады

- Рухавік LibreOffice спампоўваецца адзін раз за сеанс і кэшуецца. Пры першым пераўтварэнні загрузка зойме некалькі секунд, наступныя пераўтварэнні значна хутчэйшыя.
- Складанае фарматаванне (макрасы, элементы ActiveX, складаны SmartArt) можа пераўтварыцца не ідэальна. Стандартныя элементы дакумента (тэкст, табліцы, выявы, калантытулы, зноскі) пераўтвараюцца надзейна.
- Паколькі інструмент таксама прымае ODT і RTF, яго можна выкарыстоўваць як універсальны пераўтваральнік для ўсіх тэкставых фарматаў.

# Змяніць колер тэксту

Замяніце колер тэксту ва ўсім PDF. Інструмент знаходзіць вобласці тэксту на кожнай старонцы і перафарбоўвае іх у выбраны колер, захоўваючы макет дакумента і нетэкставы змест.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Выберыце новы колер тэксту праз выбар колеру. Па змаўчанні сіні (#0000FF).
3. Націсніце **Змяніць колер тэксту**, каб пачаць апрацоўку.
4. Перафарбаваны PDF спампоўваецца аўтаматычна. Індыкатар прагрэсу паказвае, якая старонка апрацоўваецца.

## Параметры

- **Новы колер тэксту**: выбар колеру, які заменіць колер усяго тэксту ў дакуменце.

## Магчымасці

- Перафарбоўвае тэкст на кожнай старонцы дакумента
- Пастаронкавая апрацоўка з паказам прагрэсу
- Выбар колеру з поўнай падтрымкай hex-колераў
- Захоўвае макет старонак і нетэкставыя элементы

## Сцэнарыі выкарыстання

- Змяненне чорнага тэксту на цёмна-сіні для больш мяккага і сучаснага выгляду дакумента
- Перафарбоўванне тэксту пад патрабаванні брэнда перад распаўсюджваннем дакументаў
- Змяненне колеру тэксту на пэўны для адпаведнасці патрабаванням даступнасці
- Каб тэкст быў бачны на новым колеры фону

## Парады

- Гэты інструмент адмалёўвае старонкі ў маштабе 2x для якасці, а потым перабудоўвае PDF. Вынік складаецца з відарысаў, таму тэкст больш нельга будзе вылучыць або шукаць.
- Для дакументаў, дзе трэба захаваць вылучальны тэкст, лепш рэдагаваць PDF непасрэдна ў [Рэдактары PDF](./edit-pdf).
- Час апрацоўкі расце з колькасцю старонак, бо кожная старонка адмалёўваецца асобна.

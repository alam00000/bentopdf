# VSD у PDF

Пераўтварайце дыяграмы Microsoft Visio у PDF без усталёўкі Visio. Файлы VSD і VSDX змяшчаюць блок-схемы, арганізацыйныя дыяграмы, сеткавыя схемы і планы памяшканняў, якія большасць людзей не можа адкрыць. Гэты інструмент ператварае іх у акуратныя PDF, якія можна праглядаць на любой прыладзе.

## Падтрымліваемыя фарматы

| Фармат       | Пашырэнне | Заўвагі                                    |
| :----------- | :-------- | :----------------------------------------- |
| Visio Binary | `.vsd`    | Стары фармат Visio (Visio 2003 і ранейшыя) |
| Visio XML    | `.vsdx`   | Сучасны фармат Visio (Visio 2013+)         |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце файлы VSD ці VSDX. Абодва фарматы можна змешваць у адным пакеце.
2. Праглядзіце спіс файлаў. Выдаліце непатрэбныя з дапамогай значка сметніцы або выкарыстайце **Дадаць файлы**, каб дадаць іншыя дыяграмы.
3. Націсніце **Пераўтварыць у PDF**. Рухавік на аснове LibreOffice загружаецца ў браўзеры і ператварае кожную дыяграму ў PDF, захоўваючы фігуры, злучальнікі, подпісы і макет старонкі.
4. Адна дыяграма спампоўваецца адразу як PDF. Некалькі файлаў ствараюць ZIP-архіў з назвай `vsd-to-pdf.zip`.

## Параметры

Налады не патрэбны. Пераўтваральнік захоўвае арыгінальны памер і арыентацыю старонкі з дакумента Visio.

## Сцэнарыі выкарыстання

- Прагляд дыяграм Visio ад калегі, калі ў вас няма ліцэнзіі Visio
- Уключэнне сеткавых або архітэктурных дыяграм у праектную дакументацыю ў выглядзе PDF
- Друк арганізацыйных дыяграм або схем працэсаў для раздатковых матэрыялаў на сустрэчах
- Архіваванне старых файлаў VSD з ранейшых версій Visio ў надзейным фармаце

## Парады

- Шматстаронкавыя дакументы Visio ствараюць шматстаронкавыя PDF: кожная старонка Visio адпавядае старонцы PDF.
- Файлы VSDX (сучасны фармат на аснове XML) звычайна пераўтвараюцца дакладней, чым старыя двайковыя файлы VSD.
- Рухавік LibreOffice загружаецца адзін раз за сеанс. Пры першым пераўтварэнні давядзецца крыху пачакаць, наступныя файлы апрацоўваюцца хутчэй.

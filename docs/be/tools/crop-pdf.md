# Абрэзаць PDF

Абразайце палі старонак PDF з дапамогай візуальнага інтэрфейсу. Намалюйце прамавугольнік абрэзкі непасрэдна на кожнай старонцы, праглядзіце вынік і прымяніце абрэзку. Можна задаваць розныя вобласці для розных старонак або прымяніць адну абрэзку да ўсяго дакумента.

## Як гэта працуе

1. Загрузіце файл PDF.
2. Адкрываецца рэдактар абрэзкі з першай старонкай і рамкай абрэзкі, якую можна перацягваць.
3. Наладзьце прамавугольнік абрэзкі, перацягваючы яго краі або вуглы.
4. Карыстайцеся кнопкамі навігацыі, каб пераходзіць паміж старонкамі і задаваць вобласць абрэзкі для кожнай.
5. Націсніце **Абрэзаць**, каб прымяніць абрэзку і спампаваць вынік.

## Магчымасці

- Візуальны рэдактар абрэзкі на аснове Cropper.js з маркерамі для дакладнай налады
- Пастаронкавая навігацыя для задання асобных абласцей абрэзкі
- Налады абрэзкі захоўваюцца для кожнай старонкі, таму для розных старонак можна задаць розную абрэзку
- Жывы папярэдні прагляд выбранай вобласці
- Падтрымка PDF з любым памерам і арыентацыяй старонак

## Сцэнарыі выкарыстання

- Выдаленне шырокіх палёў са сканаваных дакументаў, каб засяродзіцца на змесціве
- Абрэзка друкарскіх метак і метак сумяшчэння з PDF для перадрукарскай падрыхтоўкі
- Абрэзка слайдаў лекцый, каб прыбраць вобласць нататак дакладчыка
- Выдаленне калантытулаў з кожнай старонкі перад абменам урыўкам дакумента
- Змяненне памеру старонак пад пэўны экран або макет друку

## Парады

- Рамку абрэзкі можна свабодна змяняць і перамяшчаць. Цягніце за вуглы для прапарцыйнай змены памеру або за краі для змены па адной восі.
- Калі для ўсіх старонак патрэбна аднолькавая абрэзка, задайце яе на першай старонцы: інструмент запамінае вобласць абрэзкі пры пераходзе паміж старонкамі.
- Калі трэба ўніфікаваць памеры старонак, а не абразаць іх візуальна, лепш падыдзе інструмент «Уніфікаваць памер старонак».

# XML у PDF

Пераўтварайце файлы даных XML у зручныя для чытання структураваныя PDF-дакументы. Сыры XML магутны, але людзям яго цяжка чытаць. Гэты інструмент разбірае дрэва XML, знаходзіць паўторныя структуры даных і афармляе іх як табліцы і раздзелы ў PDF фармату A4 з альбомнай арыентацыяй.

## Падтрымліваемыя фарматы

| Фармат | Пашырэнне | Заўвагі                               |
| :----- | :-------- | :------------------------------------ |
| XML    | `.xml`    | Любы карэктна сфармаваны XML-дакумент |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце файлы XML. Некалькі файлаў можна апрацаваць адным пакетам.
2. Праглядзіце спіс файлаў. Выдаліце непатрэбныя з дапамогай значка сметніцы або націсніце **Дадаць файлы**, каб дадаць іншыя.
3. Націсніце **Пераўтварыць у PDF**. Інструмент разбірае структуру XML з дапамогай убудаванага ў браўзер DOMParser, аналізуе іерархію даных і стварае PDF з дапамогай jsPDF з аўтаматычным фарматаваннем табліц.
4. Адзін файл спампоўваецца як PDF. Некалькі вынікаў пакуюцца ў `xml-to-pdf.zip`.

## Параметры

Ручная налада не патрэбна. Пераўтваральнік аўтаматычна вызначае структуру XML і выбірае прыдатны макет табліц. Вынік выкарыстоўвае альбомную арыентацыю A4, каб змясціць шырокія наборы даных.

## Сцэнарыі выкарыстання

- Ператварэнне экспартаў даных XML з баз даных або API у справаздачы для друку
- Стварэнне зразумелых зводак з файлаў канфігурацыі XML
- Пераўтварэнне рахункаў або журналаў транзакцый на аснове XML у PDF для ўліку
- Ператварэнне карт сайта XML або стужак RSS у зручныя для чытання дакументы

## Парады

- XML павінен быць карэктна сфармаваны. Калі аналізатар знойдзе сінтаксічныя памылкі, пераўтварэнне не атрымаецца, і з'явіцца паведамленне з апісаннем праблемы.
- Глыбока ўкладзеныя структуры XML разгортваюцца ў табліцы. Для лепшага выніку даныя павінны мець паўторныя суседнія элементы з аднолькавымі даччынымі элементамі.
- Падчас пераўтварэння паказваецца прагрэс кожнага этапу: чытанне, разбор, аналіз і адлюстраванне.

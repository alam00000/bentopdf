# Дубляваць і арганізаваць

Пераўпарадкоўвайце, дублюйце і выдаляйце старонкі PDF у візуальным інтэрфейсе з перацягваннем. Кожная старонка паказваецца як мініяцюра, якую можна перамясціць, скапіяваць або выдаліць перад захаваннем выніку ў новы файл.

## Як гэта працуе

1. Загрузіце адзін файл PDF.
2. Інструмент паказвае сетку мініяцюр усіх старонак.
3. Перацягвайце мініяцюры, каб змяніць парадак, націсніце зялёную кнопку дублявання, каб скапіяваць старонку, або чырвоную кнопку выдалення, каб яе выдаліць.
4. Або ўвядзіце ўласны парадак старонак у тэкставае поле (напрыклад, `3, 1, 2, 4`) і націсніце **Ужыць**, каб пераўпарадкаваць усе старонкі адразу.
5. Націсніце кнопку апрацоўкі, каб сабраць і спампаваць пераўпарадкаваны PDF.

## Магчымасці

- Змяненне парадку старонак перацягваннем з анімацыяй
- Кнопкі дублявання і выдалення для кожнай старонкі
- Уласны парадак старонак для дакладнага пераўпарадкавання
- Нумары старонак абнаўляюцца аўтаматычна пасля кожнай змены
- Нельга выдаліць апошнюю старонку

## Сцэнарыі выкарыстання

- Перамяшчэнне памылкова размешчанай старонкі на правільнае месца ў справаздачы
- Дубляванне старонкі формы, каб мець некалькі пустых копій у адным файле
- Выдаленне чарнавых старонак або запаўняльнікаў перад распаўсюджваннем дакумента
- Адваротны або перамешаны парадак старонак для падрыхтоўкі да друку
- Стварэнне ўласнай паслядоўнасці старонак без паўторнага аб'яднання файлаў

## Парады

- Поле ўласнага парадку чакае арыгінальныя нумары старонак праз коску. Кожная старонка павінна быць указана роўна адзін раз, без пропускаў і паўтораў.
- Пасля дублявання абедзве копіі спасылаюцца на той самы арыгінальны індэкс старонкі. Кожную копію можна перамяшчаць незалежна.
- Для масавых аперацый з некалькімі файламі або больш складаных працэсаў лепш выкарыстаць [Мультыінструмент PDF](./pdf-multi-tool).

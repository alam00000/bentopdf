# WPS у PDF

Пераўтварайце файлы тэкставага рэдактара Microsoft Works у PDF. Microsoft Works пастаўляўся з хатнімі камп'ютарамі ў канцы 1990-х і ў 2000-я гады, і шмат файлаў WPS дагэтуль захоўваецца на старых дысках і ў архівах пошты. Гэты інструмент адкрывае іх у браўзеры і стварае акуратныя PDF.

## Падтрымліваемыя фарматы

| Фармат          | Пашырэнне | Заўвагі                                      |
| :-------------- | :-------- | :------------------------------------------- |
| Microsoft Works | `.wps`    | Файлы тэкставага рэдактара з Microsoft Works |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце файлы WPS. Можна дадаць некалькі файлаў.
2. Праглядзіце спіс файлаў. Выкарыстайце значок сметніцы, каб выдаліць асобныя файлы, або націсніце **Дадаць файлы**, каб пашырыць пакет.
3. Націсніце **Пераўтварыць у PDF**. Рухавік на аснове LibreOffice загружаецца ў браўзеры і пераўтварае кожны дакумент WPS у PDF.
4. Адзін файл спампоўваецца адразу як PDF. Некалькі файлаў аб'ядноўваюцца ў ZIP-архіў з назвай `wps-to-pdf.zip`.

## Параметры

Дадатковыя налады не патрэбны. Пераўтваральнік апрацоўвае тэкст, базавае фарматаванне і ўбудаваныя выявы з файла WPS.

## Сцэнарыі выкарыстання

- Аднаўленне старых школьных або працоўных дакументаў, захаваных у фармаце Microsoft Works
- Адкрыццё далучэнняў WPS з электроннай пошты, калі Microsoft Works не ўсталяваны
- Пераўтварэнне архіва файлаў WPS для пераносу ў сучасную сістэму дакументаў
- Друк старых дакументаў, якія сучасныя тэкставыя рэдактары не могуць адкрыць

## Парады

- Не блытайце файлы `.wps` з Microsoft Works з файламі WPS Office. Гэты інструмент прызначаны менавіта для старога фармату Microsoft Works.
- Рухавік LibreOffice загружаецца пры першым выкарыстанні некаторы час. Пасля загрузкі наступныя пераўтварэнні ў тым жа сеансе выконваюцца хутчэй.

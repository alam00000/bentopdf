# Email у PDF

Пераўтварайце захаваныя лісты ў акуратныя PDF для друку. Інструмент разбірае файлы EML і MSG, вымае ўвесь ліст (загалоўкі, тэкст і метаданыя далучэнняў) і выводзіць усё ў структураваны PDF. Зручна для юрыдычнага раскрыцця даных, вядзення запісаў або проста друку важнага ліста.

## Падтрымліваемыя фарматы

| Фармат | Пашырэнне | Заўвагі                                                                   |
| :----- | :-------- | :------------------------------------------------------------------------ |
| EML    | `.eml`    | Стандартны фармат лістоў MIME (экспартуецца з большасці паштовых праграм) |
| MSG    | `.msg`    | Уласны фармат Microsoft Outlook                                           |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце файлы EML ці MSG. Можна змешваць абодва фарматы ў адным пакеце.
2. Праверце спіс файлаў. Выдаліце непатрэбныя значком кошыка або націсніце **Дадаць файлы**, каб дадаць яшчэ лісты.
3. Наладзьце параметры пераўтварэння (гл. ніжэй).
4. Націсніце **Пераўтварыць у PDF**. Інструмент разбірае кожны ліст, выводзіць змесціва як аформлены HTML і пераўтварае яго ў PDF рухавіком PyMuPDF.
5. Адзін ліст спампоўваецца непасрэдна як PDF. Некалькі лістоў пакуюцца ў `emails-converted.zip`.

## Параметры

| Параметр                     | Па змаўчанні | Апісанне                                                                                |
| :--------------------------- | :----------- | :-------------------------------------------------------------------------------------- |
| **Памер старонкі**           | A4           | Выбар паміж памерамі старонак A4, Letter або Legal.                                     |
| **Уключыць CC і BCC**        | Укл.         | Калі ўключана, спісы атрымальнікаў CC і BCC паказваюцца ў загалоўку ліста ў PDF.        |
| **Уключыць спіс далучэнняў** | Укл.         | Калі ўключана, у PDF паказваецца спіс далучаных да ліста файлаў (з назвамі і памерамі). |

## Сцэнарыі выкарыстання

- Архіваванне важнай дзелавой перапіскі ў PDF для адпаведнасці патрабаванням або аўдыту
- Друк ланцужкоў лістоў для судовых разбіральніцтваў або запытаў на раскрыццё
- Стварэнне пастаяннага запісу пацвярджэнняў заказаў, чэкаў або дагавораў, атрыманых па пошце
- Рэзервовае капіраванне файлаў Outlook MSG у фармат, для чытання якога не патрэбны Outlook
- Дакументаванне зваротаў у службу падтрымкі з экспартаваных файлаў EML

## Парады

- Падтрымліваюцца і EML (выкарыстоўваецца ў Thunderbird, Apple Mail і большасці паштовых праграм), і файлы Outlook MSG. Экспартуйце лісты з паштовай праграмы і перацягніце іх непасрэдна ў інструмент.
- Лісты ў фармаце HTML захоўваюць афармленне ў PDF. Лісты простым тэкстам выводзяцца з акуратным, лёгкім для чытання фарматаваннем.
- Спіс далучэнняў паказвае назвы і памеры файлаў, але не ўбудоўвае самі далучаныя файлы ў PDF.

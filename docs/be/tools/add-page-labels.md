# Дадаць пазнакі старонак

Пазнакі старонак вызначаюць, як нумары старонак паказваюцца ў праграмах прагляду PDF (нумар на панэлі інструментаў, а не надрукаваны на старонцы). Гэты інструмент дазваляе прызначаць розныя схемы пазначэння розным дыяпазонам старонак: рымскія лічбы для ўступнай часткі, дзесятковыя лікі для асноўнага тэксту, літарныя дадаткі і іншае.

## Як гэта працуе

1. Загрузіце PDF-файл.
2. З'явіцца панэль параметраў з адным правілам па змаўчанні.
3. Наладзьце кожнае правіла: дыяпазон старонак, стыль, неабавязковы прэфікс і пачатковае значэнне.
4. Націсніце **Дадаць правіла**, каб стварыць дадатковыя правілы для іншых раздзелаў.
5. Націсніце **Дадаць пазнакі старонак**, каб прымяніць усе правілы і спампаваць вынік.

## Параметры

Кожнае правіла мае такія налады:

- **Дыяпазон старонак**: да якіх старонак ужываецца правіла. Пакіньце пустым для ўсіх старонак. Падтрымліваюцца дыяпазоны накшталт `1-4`, `7`, `odd` або `1-9,30-40`.
- **Стыль пазнакі**: дзесятковыя арабскія, малыя рымскія (i, ii, iii), вялікія рымскія (I, II, III), малыя літары (a, b, c), вялікія літары (A, B, C) або без пазнакі (толькі прэфікс).
- **Прэфікс пазнакі**: неабавязковы тэкст перад кожнай пазнакай, напрыклад "A-", каб атрымаць пазнакі A-1, A-2, A-3.
- **Пачатковае значэнне**: лік, з якога пачынаецца адлік. Па змаўчанні 1. Устанавіце 0 для нумарацыі з нуля.
- **Працягваць нумарацыю праз несумежныя дыяпазоны**: уключыце, калі правіла ахоплівае несумежныя старонкі (напрыклад, `1-9,30-40` або `odd`) і вы хочаце, каб нумарацыя ішла паслядоўна.
- **Выдаліць існуючыя пазнакі старонак**: уключана па змаўчанні. Ачышчае папярэднія пазнакі перад прымяненнем новых правілаў.

## Магчымасці

- Некалькі правілаў на дакумент для складаных схем нумарацыі
- Шэсць стыляў пазнак, якія ахопліваюць усе стандартныя сістэмы нумарацыі
- Падтрымка ўласных прэфіксаў для пазначэння па раздзелах
- Падтрымка несумежных дыяпазонаў з паслядоўнай нумарацыяй
- Магчымасць захаваць або выдаліць існуючыя пазнакі

## Сцэнарыі выкарыстання

- Рымскія пазнакі (i, ii, iii) для прадмовы кнігі і дзесятковыя для асноўнага тэксту
- Пазначэнне старонак дадаткаў літарнымі прэфіксамі, напрыклад "A-1", "A-2", "B-1", "B-2"
- Выпраўленне пазнак у сканаваным дакуменце, дзе фізічныя нумары старонак не адпавядаюць парадку старонак PDF
- Нумарацыя з нуля для тэхнічных дакументаў

## Парады

- Пазнакі старонак з'яўляюцца метаданымі, якія праграмы прагляду PDF паказваюць на панэлі навігацыі. Яны не друкуюцца на самой старонцы. Для бачных нумароў выкарыстайце [Нумары старонак](./page-numbers).
- Для гэтага інструмента патрэбна наладзіць CoherentPDF (CPDF) у наладах WASM. Калі ён не наладжаны, вам прапануюць гэта зрабіць.

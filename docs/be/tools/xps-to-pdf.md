# XPS у PDF

Пераўтварайце дакументы Microsoft XPS і OXPS у стандартныя PDF-файлы. XPS (XML Paper Specification) быў адказам Microsoft на PDF, але яго падтрымка на розных платформах значна скарацілася. Гэты інструмент зноў робіць такія дакументы даступнымі для ўсіх.

## Падтрымліваемыя фарматы

| Фармат | Пашырэнне | Заўвагі                              |
| :----- | :-------- | :----------------------------------- |
| XPS    | `.xps`    | Арыгінальны фармат Microsoft XPS     |
| OXPS   | `.oxps`   | Open XPS, варыянт стандарту ECMA-388 |

## Як гэта працуе

1. Націсніце на вобласць загрузкі або перацягніце файлы XPS/OXPS. Можна выбраць некалькі файлаў адразу.
2. Праглядзіце спіс файлаў. Выдаліце асобныя файлы з дапамогай значка сметніцы або націсніце **Дадаць файлы**, каб дадаць іншыя дакументы.
3. Націсніце **Пераўтварыць у PDF**. Рухавік PyMuPDF апрацоўвае кожны дакумент лакальна ў вашым браўзеры.
4. Адзін файл спампоўваецца адразу як PDF. Некалькі файлаў аб'ядноўваюцца ў ZIP-архіў з назвай `xps-converted.zip`.

## Параметры

Гэты інструмент выконвае прамое пераўтварэнне фармату без дадатковых налад. Вынік захоўвае арыгінальныя памеры старонак, вектарную графіку, шрыфты і выявы з крыніцы XPS.

## Сцэнарыі выкарыстання

- Адкрыццё файлаў XPS са старых сістэм Windows, дзе па змаўчанні выкарыстоўваўся драйвер друку XPS
- Пераўтварэнне дакументаў OXPS з Windows 10/11 для абмену з карыстальнікамі macOS або Linux
- Архіваванне старых файлаў XPS у больш распаўсюджаным фармаце
- Забеспячэнне доступу знешніх атрымальнікаў да дзяржаўных або карпаратыўных дакументаў у фармаце XPS

## Парады

- Пашырэнні `.xps` і `.oxps` апрацоўваюцца аўтаматычна: іх можна змешваць у адным пакеце.
- Калі арыгінальны файл XPS быў створаны драйверам друку з высокай раздзяляльнасцю, атрыманы PDF захоўвае гэтую якасць. Перадыскрэтызацыя не выконваецца.

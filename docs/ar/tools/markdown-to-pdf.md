# Markdown إلى PDF

محرر Markdown متكامل مع معاينة مباشرة وتصدير PDF بنقرة واحدة. اكتب من الصفر، أو ارفع ملف `.md` موجودًا، أو الصق المحتوى من الحافظة. يعرض المحرر Markdown في الوقت الفعلي ويصدّر ملف PDF منسقًا باستخدام محرك الطباعة المدمج في المتصفح.

## الصيغ المدعومة

| المدخل      | الوصف                  |
| :---------- | :--------------------- |
| ملفات `.md` | ارفعها عبر زر الرفع    |
| إدخال مباشر | اكتب أو الصق في المحرر |

## طريقة العمل

1. افتح أداة Markdown إلى PDF. يُحمَّل المحرر بعرض مقسوم: مصدر Markdown على اليسار والمعاينة المعروضة على اليمين.
2. اكتب Markdown أو الصقه، أو انقر على **رفع** لتحميل ملف `.md`.
3. بدّل بين السمتين الفاتحة والداكنة بمنزلق السمة في شريط الأدوات.
4. انقر على **تصدير PDF** (أو اضغط `Ctrl/Cmd + S`) لإنشاء ملف PDF عبر مربع حوار الطباعة في المتصفح.

## الميزات

يدعم المحرر مجموعة واسعة من ميزات Markdown تتجاوز الأساسيات:

- **Markdown القياسي**: العناوين والخط الغامق والمائل والروابط والصور والقوائم والاقتباسات والخطوط الأفقية
- **كتل الأكواد** مع تمييز الصياغة لأكثر من 15 لغة (JavaScript وTypeScript وPython وGo وRust وSQL وJava وC# وC++ وYAML وBash وغيرها)
- **مخططات Mermaid**: تُعرض المخططات الانسيابية ومخططات التسلسل ومخططات ER وأنواع مخططات Mermaid الأخرى مباشرة في المعاينة
- **الجداول** بصياغة جداول Markdown القياسية
- **قوائم المهام** مع مربعات اختيار
- **الحواشي السفلية** و**النص المنخفض** و**النص المرتفع**
- **قوائم التعريفات** و**الاختصارات**
- دعم **الرموز التعبيرية** (يُعرض `:smile:` كرمز تعبيري)
- **التمييز** (`==marked text==`) و**الإدراج** (`++inserted text++`)
- **الروابط التلقائية**: تُحوَّل عناوين URL العادية إلى روابط قابلة للنقر
- إنشاء **جدول المحتويات**
- **روابط الارتساء** على العناوين

## حالات الاستخدام

- كتابة وثائق المشاريع وتصدير ملف PDF أنيق لأصحاب المصلحة
- إنشاء تقارير تقنية بنماذج أكواد ومخططات معمارية بـ Mermaid
- تحويل README من GitHub إلى PDF للاستخدام دون اتصال أو للطباعة
- صياغة مقترح أو مواصفة مع قوائم مهام وجداول
- إنشاء نشرة منسقة من ملاحظات محاضرة مكتوبة بـ Markdown

## نصائح

- يستخدم ناتج PDF وظيفة الطباعة إلى PDF في المتصفح. في Chrome، يمكنك تخصيص الهوامش والمقياس في مربع حوار الطباعة قبل الحفظ.
- تُعرض مخططات Mermaid في المعاينة لكنها قد تحتاج لحظة للتهيئة عند أول استخدام.
- استخدم `Ctrl/Cmd + S` كاختصار لوحة مفاتيح للتصدير دون الحاجة إلى الزر.

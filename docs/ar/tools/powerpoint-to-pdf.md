# PowerPoint إلى PDF

حوّل ملفات العروض التقديمية إلى PDF. تصبح كل شريحة صفحة في المستند الناتج، مع عرض النصوص والصور والأشكال والانتقالات عبر محرك LibreOffice يعمل داخل المتصفح. يدعم صيغ PowerPoint الحديثة والقديمة، إضافة إلى صيغة OpenDocument Presentation.

## الصيغ المدعومة

| الصيغة                    | الامتدادات |
| :------------------------ | :--------- |
| PowerPoint (حديثة)        | `.pptx`    |
| PowerPoint (قديمة)        | `.ppt`     |
| OpenDocument Presentation | `.odp`     |

## طريقة العمل

1. انقر على منطقة الرفع أو اسحب ملفات العرض التقديمي وأفلتها.
2. راجع قائمة الملفات. أضف المزيد أو أزل ما لا تحتاجه.
3. انقر على **تحويل إلى PDF**. يتم تحميل محرك LibreOffice عند أول استخدام، ثم يحوّل كل ملف.
4. يتم تنزيل الملف الواحد مباشرة بصيغة PDF. أما الملفات المتعددة فتُحزم في `powerpoint-converted.zip`.

## الخيارات

لا تحتوي هذه الأداة على إعدادات إضافية. تُعرض الشرائح بأبعادها الأصلية.

## الناتج

| عدد الملفات المدخلة | الناتج                                                           |
| :------------------ | :--------------------------------------------------------------- |
| ملف واحد            | تنزيل ملف PDF واحد (باسم الملف الأصلي مع الامتداد `.pdf`)        |
| ملفان أو أكثر       | أرشيف ZIP (`powerpoint-converted.zip`) يحتوي على ملف PDF لكل ملف |

## حالات الاستخدام

- تحويل عرض تقديمي إلى PDF قبل مشاركته مع جمهور قد لا يملك PowerPoint
- إنشاء نسخة مطبوعة من العرض كمذكرة لمؤتمر أو ورشة عمل
- أرشفة العروض التقديمية بصيغة تظهر بشكل متطابق على كل جهاز
- تحويل مجموعة كبيرة من عروض ODP من LibreOffice Impress إلى PDF دفعة واحدة
- إنشاء نسخة PDF من عرض تقديمي للمستثمرين لإرفاقها بالبريد الإلكتروني

## نصائح

- لا تُنقل حركات الشرائح وانتقالاتها إلى PDF. تُلتقط كل شريحة كصفحة ثابتة.
- لن تظهر مقاطع الفيديو المضمّنة في الناتج. استبدلها بلقطة شاشة أو صورة بديلة عند الحاجة.
- لا تُضمَّن ملاحظات المتحدث في تصدير PDF الافتراضي. إذا احتجت إليها، فكّر في التصدير أولًا من عرض "طباعة الملاحظات" الأصلي في PowerPoint.
- يحتفظ المتصفح بمحرك LibreOffice مخزنًا مؤقتًا بعد التحميل الأول، لذا يكون تحويل عرض ثانٍ في الجلسة نفسها أسرع بكثير.

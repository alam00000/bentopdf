# تحويل PDF إلى صور نقطية

يحوّل التحويل النقطي كل صفحة من ملف PDF إلى صورة ثم يعيد تجميع هذه الصور في ملف PDF. تبدو النتيجة مطابقة للأصل لكنها لا تحتوي على نص قابل للتحديد ولا عناصر تفاعلية ولا طبقات قابلة للتحرير. إنها عمليًا نسخة ضوئية عالية الجودة.

## طريقة العمل

1. ارفع ملف PDF واحدًا أو أكثر.
2. اضبط **الدقة (DPI)** للناتج النقطي.
3. اختر **صيغة الصورة**: PNG لجودة بلا فقدان أو JPEG لملفات أصغر.
4. يمكنك اختياريًا تحديد **التحويل إلى تدرج الرمادي**.
5. انقر على **تحويل PDF إلى صور نقطية**. تُنزَّل الملفات المتعددة في ملف ZIP.

## الخيارات

| الإعداد          | القيم                        | الافتراضي |
| ---------------- | ---------------------------- | --------- |
| **الدقة (DPI)**  | 72، 150، 200، 300، 600       | 150       |
| **صيغة الصورة**  | PNG (بلا فقدان)، JPEG (أصغر) | PNG       |
| **تدرج الرمادي** | تشغيل/إيقاف                  | إيقاف     |

## إرشادات الدقة

- **72**: للعرض على الشاشة فقط، وأصغر حجم للملف
- **150**: توازن جيد للاستخدام العام
- **200**: نص أكثر حدة وحجم ملف معتدل
- **300**: ناتج بجودة الطباعة
- **600**: أرشفة عالية الجودة أو طباعة احترافية

## حالات الاستخدام

- منع استخراج النص من المستندات السرية قبل مشاركتها
- التخلص من مشكلات الاعتماد على الخطوط بتحويل النص إلى بكسلات
- إنشاء نسخة "مسطحة" من ملف PDF ذي طبقات معقدة أو شفافية تظهر بشكل مختلف بين برامج العرض
- تجهيز ملف PDF لنظام يقبل المدخلات القائمة على الصور فقط
- إزالة المحتوى المخفي (مثل التغييرات المتتبعة أو بيانات النماذج) بتحويل PDF إلى صور خالصة

## نصائح

- دقة 150 مع PNG إعداد افتراضي جيد. لا ترفعها إلا إذا احتجت إلى ناتج للطباعة أو إلى تكبير التفاصيل الدقيقة.
- ينتج JPEG ملفات أصغر بشكل ملحوظ لكنه يضيف تشوهات الضغط على حواف النص الحادة.
- التحويل النقطي لا رجعة فيه، لذا احتفظ بملف PDF الأصلي إذا كنت قد تحتاج إلى نص قابل للتحرير لاحقًا.

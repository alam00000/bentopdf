# إضافة مرفقات

ضمّن ملفًا واحدًا أو أكثر مباشرة داخل مستند PDF. يمكن إضافة المرفقات على مستوى المستند (تظهر في لوحة المرفقات في أي قارئ PDF) أو ربطها بصفحات محددة.

## طريقة العمل

1. ارفع ملف PDF الذي تريد إرفاق الملفات به.
2. استخدم منطقة إفلات المرفقات لاختيار الملفات التي تريد تضمينها (من أي نوع).
3. اختر مستوى المرفق: **المستند** (الافتراضي) أو **الصفحة**.
4. إذا اخترت مستوى الصفحة، فأدخل نطاق الصفحات (مثل `1-3` أو `5`).
5. انقر على زر المعالجة. سيتم تنزيل ملف PDF المعدّل مع الملفات المضمّنة.

## المزايا

- إرفاق أي نوع من الملفات: صور، جداول بيانات، أرشيفات، ملفات تنفيذية، أي شيء
- وضع المرفق على مستوى المستند أو على مستوى الصفحة
- يمكن إرفاق عدة ملفات في عملية واحدة
- عرض أسماء الملفات وأحجامها لجميع المرفقات المحددة
- يحافظ الناتج على محتوى PDF الأصلي مع إضافة الملفات المضمّنة

## الخيارات

| الخيار            | الوصف                                                          |
| ----------------- | -------------------------------------------------------------- |
| **مستوى المستند** | يرفق الملفات بملف PDF ككل، ويمكن الوصول إليها من لوحة المرفقات |
| **مستوى الصفحة**  | يرفق الملفات بصفحات محددة، تُحدَّد عبر إدخال نطاق الصفحات      |

## حالات الاستخدام

- حزم بيانات المصدر (ملفات Excel وCSV) مع تقرير PDF
- إرفاق ملفات الصور الأصلية بملف PDF لمعرض أعمال تصوير
- تضمين المستندات الداعمة داخل عقد أو عرض مقترح
- إضافة مواد تكميلية إلى صفحات محددة من دليل تدريبي

## نصائح

- المرفقات على مستوى المستند هي الأكثر دعمًا في قارئات PDF. قد لا تظهر المرفقات على مستوى الصفحة في جميع العارضات.
- لا يوجد حد لحجم المرفقات، لكن الملفات المضمّنة الكبيرة جدًا ستزيد حجم PDF بما يتناسب معها.

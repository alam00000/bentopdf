# N-Up PDF

ضع عدة صفحات على ورقة واحدة بترتيب شبكي. يقلل هذا عدد الصفحات المطبوعة بوضع 2 أو 4 أو 6 أو 8 أو 9 أو 16 صفحة في الورقة الواحدة. تتولى الأداة التحجيم وتحديد المواضع وضبط حجم الصفحة اختياريًا.

## طريقة العمل

1. ارفع ملف PDF.
2. اختر عدد الصفحات في الورقة (قيمة "N"): 2 أو 4 أو 6 أو 8 أو 9 أو 16.
3. اختر حجم صفحة الناتج (الافتراضي A4) واتجاهها.
4. يمكنك اختياريًا ضبط التباعد ولون الحدود ولون الخلفية.
5. انقر على زر المعالجة. تحجّم الأداة كل صفحة وترصفها على أوراق جديدة.

## الميزات

- تخطيطات شبكية: 2 و4 و6 و8 و9 و16 صفحة في الورقة
- حجم صفحة الناتج واتجاهها قابلان للضبط
- تباعد اختياري بين الصفحات المرصوفة
- إعدادات لون الخلفية والحدود
- يحافظ على نسبة أبعاد الصفحات الأصلية أثناء التحجيم للملاءمة

## الخيارات

| الخيار                | الوصف                                                              |
| --------------------- | ------------------------------------------------------------------ |
| **الصفحات في الورقة** | عدد الصفحات الأصلية في كل صفحة ناتجة (2 أو 4 أو 6 أو 8 أو 9 أو 16) |
| **حجم الصفحة**        | حجم ورقة الناتج (A4 وLetter وLegal وغيرها)                         |
| **الاتجاه**           | عمودي أو أفقي لورقة الناتج                                         |
| **التباعد**           | الفجوة بالنقاط بين الصفحات المرصوفة                                |
| **لون الخلفية**       | لون تعبئة خلفية ورقة الناتج                                        |
| **لون الحدود**        | لون الحدود حول كل صفحة مرصوفة                                      |

## حالات الاستخدام

- طباعة نشرات بأربع شرائح في الصفحة لتوفير الورق
- إنشاء أوراق مذاكرة بعدة صفحات مرجعية في ورقة واحدة
- إنتاج أرشيفات مستندات مضغوطة للحفظ
- إنشاء أوراق نظرة عامة مصغرة لمستند طويل

## نصائح

- غالبًا ما يعمل الاتجاه الأفقي بشكل أفضل مع تخطيط 2 في الورقة، بينما يكون العمودي الأفضل عادةً لـ 4 وما فوق.
- زيادة التباعد تحسّن القراءة لكنها تقلل المساحة المتاحة لكل صفحة مرصوفة.
- للعملية العكسية (تقسيم صفحة واحدة إلى عدة صفحات)، راجع [تقسيم PDF إلى ملصقات](./posterize-pdf).

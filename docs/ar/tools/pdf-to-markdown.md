# PDF إلى Markdown

يحوّل ملفات PDF إلى صيغة Markdown (`.md`) مع الحفاظ على العناوين والفقرات والقوائم والتنسيق الأساسي. ويمكنه اختياريًا استخراج الصور المضمّنة وإدراجها. يدعم التحويل الفردي والجماعي. يعتمد على PyMuPDF.

## طريقة العمل

1. ارفع ملف PDF واحدًا أو أكثر بالنقر على منطقة الإفلات أو بسحب الملفات إليها.
2. بدّل خيار **تضمين الصور بصيغة base64** اختياريًا لتضمين الصور المستخرجة في ناتج Markdown.
3. انقر على **تحويل إلى Markdown** لبدء المعالجة.
4. يتم تنزيل الملف الواحد باسم `filename.md`. أما الملفات المتعددة فتنتج `markdown-files.zip`.

## الخيارات

- **تضمين الصور بصيغة base64**: عند تفعيله، تُستخرج الصور المضمّنة من ملف PDF ويُشار إليها في ناتج Markdown. وعند تعطيله، يُحوَّل محتوى النص فقط.

## صيغة الناتج

- **ملف واحد**: `filename.md`
- **عدة ملفات**: `markdown-files.zip` يحتوي على ملف `.md` واحد لكل ملف PDF مدخل.

## حالات الاستخدام

- تحويل وثائق PDF إلى Markdown لمولّد مواقع ثابتة مثل VitePress أو Hugo أو Jekyll.
- تحويل الأوراق البحثية بصيغة PDF إلى Markdown قابل للتعديل لتطبيقات تدوين الملاحظات مثل Obsidian.
- ترحيل قواعد المعرفة القديمة بصيغة PDF إلى صيغة نصية مناسبة لـ Git.
- استخراج المحتوى المنظم من كتب PDF الإلكترونية لإعادة تنسيقه.

## نصائح

- خيار "تضمين الصور بصيغة base64" مفيد عندما يحتوي ملف PDF على مخططات أو أشكال أساسية للمحتوى. عطّله للمستندات النصية الكثيفة للحفاظ على نظافة الناتج.
- قد تنتج التخطيطات المعقدة ذات الأشرطة الجانبية أو الحواشي السفلية أو النص متعدد الأعمدة ملف Markdown غير مثالي. راجع الناتج وعدّله حسب الحاجة.

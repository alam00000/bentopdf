# XML إلى PDF

حوّل ملفات بيانات XML إلى مستندات PDF منظمة ومقروءة. XML قوي لكنه صعب القراءة على البشر. تحلل هذه الأداة شجرة XML وتتعرف على هياكل البيانات المتكررة وتعرضها كجداول وأقسام منسقة في ملف PDF بحجم A4 أفقي.

## الصيغ المدعومة

| الصيغة | الامتداد | ملاحظات                  |
| :----- | :------- | :----------------------- |
| XML    | `.xml`   | أي مستند XML سليم البنية |

## طريقة العمل

1. انقر على منطقة الرفع أو اسحب ملفات XML وأفلتها. يمكن معالجة عدة ملفات في دفعة واحدة.
2. راجع قائمة الملفات. أزل الملفات غير المرغوبة بأيقونة سلة المهملات، أو انقر على **إضافة المزيد من الملفات** لإضافة المزيد.
3. انقر على **تحويل إلى PDF**. تحلل الأداة بنية XML باستخدام DOMParser المدمج في المتصفح، وتحلل التسلسل الهرمي للبيانات، وتعرضه في PDF باستخدام jsPDF مع تنسيق الجداول التلقائي.
4. يُنزَّل الملف الواحد كملف PDF. أما التحويلات المتعددة فتُجمَّع في `xml-to-pdf.zip`.

## الخيارات

لا حاجة إلى إعداد يدوي. يكتشف المحوّل بنية XML تلقائيًا ويختار تخطيطات الجداول المناسبة. يستخدم الناتج اتجاه A4 الأفقي لاستيعاب مجموعات البيانات العريضة.

## حالات الاستخدام

- تحويل بيانات XML المصدّرة من قواعد البيانات أو واجهات API إلى تقارير قابلة للطباعة
- إنشاء ملخصات مقروءة من ملفات إعداد XML
- تحويل الفواتير أو سجلات المعاملات المعتمدة على XML إلى PDF لحفظ السجلات
- جعل خرائط مواقع XML أو خلاصات RSS مقروءة بصيغة مستند

## نصائح

- يجب أن يكون XML سليم البنية. إذا واجه المحلل أخطاء في الصياغة، يفشل التحويل مع رسالة خطأ وصفية تشير إلى المشكلة.
- تُسطَّح بنى XML العميقة التداخل إلى جداول. وللحصول على أفضل النتائج، ينبغي أن تحتوي البيانات على عناصر شقيقة متكررة ذات عناصر فرعية متسقة.
- تظهر تحديثات التقدم أثناء التحويل وتعرض كل مرحلة: القراءة والتحليل والفحص والعرض.

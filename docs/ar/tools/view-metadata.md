# عرض البيانات الوصفية

اطّلع على الخصائص المخفية المضمّنة في ملف PDF. تعرض الأداة معلومات المستند (العنوان والمؤلف والتواريخ) وبيانات XMP الوصفية وأبعاد الصفحات وغيرها من البيانات البنيوية بصيغة مقروءة.

## طريقة العمل

1. ارفع ملف PDF.
2. تحلل الأداة الملف فورًا وتعرض كل البيانات الوصفية المتاحة في أقسام منظمة.
3. راجع قاموس معلومات المستند وشجرة بيانات XMP الوصفية والخصائص البنيوية.
4. لا حاجة إلى خطوة معالجة: تُعرض البيانات الوصفية بمجرد تحميل الملف.

## الميزات

- يعرض حقول معلومات المستند القياسية: العنوان والمؤلف والموضوع والكلمات المفتاحية والمنشئ والمنتج
- يعرض تواريخ الإنشاء والتعديل بصيغة مقروءة
- يحلل شجرة بيانات XMP الوصفية كاملة بمساحات أسماء متداخلة ويعرضها
- يحول صيغة تاريخ PDF (`D:20240101120000Z`) إلى تواريخ مقروءة
- منظم في أقسام قابلة للطي لسهولة التنقل

## أقسام البيانات الوصفية

| القسم                  | المحتويات                                                                                 |
| ---------------------- | ----------------------------------------------------------------------------------------- |
| **معلومات المستند**    | العنوان والمؤلف والموضوع والكلمات المفتاحية والمنشئ والمنتج وتاريخ الإنشاء وتاريخ التعديل |
| **بيانات XMP الوصفية** | شجرة بيانات وصفية كاملة بصيغة XML مع Dublin Core وXAP وPDF ومساحات أسماء مخصصة            |
| **خصائص المستند**      | عدد الصفحات وإصدار PDF وحجم الملف وحالة التشفير                                           |

## حالات الاستخدام

- معرفة من أنشأ ملف PDF ومتى عُدّل آخر مرة
- التحقق من ضبط البيانات الوصفية بشكل صحيح قبل نشر مستند
- تدقيق ملفات PDF من حيث الخصوصية بفحص المعلومات الشخصية المضمّنة
- معرفة البرنامج المستخدم في إنشاء ملف PDF أو تعديله (عبر حقل المنتج)
- مراجعة بيانات XMP الوصفية للامتثال في إدارة الأصول الرقمية

## نصائح

- تُحوَّل سلاسل تاريخ PDF التي تبدأ بـ `D:` تلقائيًا إلى صيغة منطقتك الزمنية المحلية.
- إذا بدت بعض الحقول فارغة، فهذا يعني أن منشئ ملف PDF لم يضبطها. لا تحتوي كل ملفات PDF على بيانات وصفية غنية.
- لتعديل البيانات الوصفية بعد فحصها، استخدم [تعديل البيانات الوصفية](./edit-metadata). ولإزالتها بالكامل، استخدم إزالة البيانات الوصفية.

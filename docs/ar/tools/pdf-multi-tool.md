# أداة PDF المتعددة

مساحة عمل موحدة لكل عمليات PDF على مستوى الصفحة. ارفع ملف PDF واحدًا أو أكثر وتعامل مع جميع صفحاتها في شبكة مرئية واحدة. دوّر الصفحات وأعد ترتيبها وكرّرها واحذفها، وأدرج ملفات PDF وصورًا وصفحات فارغة، وأعد الترقيم، وغيّر الحجم، وقسّم النتيجة، كل ذلك دون مغادرة الأداة.

## طريقة العمل

1. انقر على **اختر الملفات** أو اسحب الملفات إلى منطقة الرفع. يمكنك رفع عدة ملفات، وتُدمج بترتيب رفعها.
2. تظهر جميع الصفحات في شبكة قابلة للتمرير مع صور مصغرة.
3. انقر على صفحة لتحديدها. استخدم Shift مع النقر لتحديد نطاق، وCmd/Ctrl مع النقر لإضافة صفحات مفردة إلى التحديد أو إزالتها منه.
4. استخدم شريط أدوات المنظِّم أو انقر بزر الفأرة الأيمن على صفحة للوصول إلى إجراءات الصفحة.
5. انقر على **تصدير PDF** لتنزيل النتيجة النهائية.

## الميزات

- **دمج**: ارفع عدة ملفات PDF وصور وستُدمج في مستند واحد تلقائيًا
- **إعادة الترتيب**: اسحب الصفحات وأفلتها لإعادة ترتيب التسلسل، أو اعكس ترتيب المستند بالكامل
- **تدوير**: دوّر الصفحات المحددة يسارًا أو يمينًا بخطوات قدرها 90 درجة
- **تكرار**: انسخ الصفحات المحددة وضع النسخ بعدها مباشرة
- **حذف**: احذف الصفحات المحددة
- **إدراج**: أضف صفحات من ملف PDF آخر أو من صورة، أو صفحة فارغة، أو صفحات من الحافظة، أو ادمج صفحات ملف PDF ثانٍ بالتناوب مع الصفحات الحالية
- **استبدال**: استبدل صفحة بالصفحة الأولى من ملف PDF آخر
- **قص ونسخ ولصق**: انقل الصفحات أو انسخها داخل المستند
- **استخراج**: نزّل الصفحات المحددة كملف PDF أو كصور
- **أرقام الصفحات**: عيّن تسميات لنطاق من الصفحات مثل i وii وiii أو A-1 وA-2
- **حجم الصفحة**: اضبط الصفحات على مقاس ورق قياسي أو على مقاس مخصص
- **تقسيم**: قسّم المستند حسب نطاقات الصفحات، أو الصفحات الفردية والزوجية، أو كل صفحة، أو الإشارات المرجعية، أو كل N صفحات، أو حجم الملف
- **تراجع / إعادة**: يمكن التراجع عن كل عملية على الصفحات وإعادتها
- يصلح ملفات PDF التالفة تلقائيًا قبل التحميل

## اختصارات لوحة المفاتيح

| الإجراء               | الاختصار                      |
| --------------------- | ----------------------------- |
| تدوير لليمين / لليسار | R / Shift+R                   |
| تحديد الكل            | Cmd/Ctrl+A                    |
| قص، نسخ، لصق          | Cmd/Ctrl+X, C, V              |
| تكرار                 | Cmd/Ctrl+D                    |
| حذف                   | Delete أو Backspace           |
| تراجع / إعادة         | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| نقل التحديد           | مفاتيح الأسهم وHome وEnd      |

## حالات الاستخدام

- إنشاء مستند مخصص من صفحات عدة ملفات PDF مصدر
- تنظيف مستند ممسوح ضوئيًا بحذف الصفحات الفارغة وتدوير الصفحات الجانبية وإعادة ترتيب الأقسام
- تقسيم ملف PDF كبير عند حدود الفصول باستخدام إشاراته المرجعية
- تعديل سريع على مستوى الصفحة دون الحاجة إلى محرر PDF كامل

## نصائح

- يتتبع سجل التراجع والإعادة كل عملية على الصفحات. استخدمه بحرية، فلا يمكنك إتلاف عملك عن طريق الخطأ.
- استخدم **Insert > From File** أو أفلت مزيدًا من ملفات PDF أو الصور على شبكة الصفحات في أي وقت لإضافتها إلى المستند.
- لمهام الدمج أو التقسيم البسيطة، قد تكون أداتا [دمج PDF](./merge-pdf) و[تقسيم PDF](./split-pdf) المخصصتان أسرع. تتألق الأداة المتعددة عندما تحتاج إلى عدة عمليات في جلسة واحدة.

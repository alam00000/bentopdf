# أداة PDF المتعددة

مساحة عمل موحدة لكل عمليات PDF على مستوى الصفحة. ارفع ملف PDF واحدًا أو أكثر وتعامل مع جميع صفحاتها في شبكة مرئية واحدة. دوّر وأعد الترتيب وكرّر واحذف وأدرج ملفات PDF جديدة وأضف صفحات فارغة وقسّم النتيجة، كل ذلك دون مغادرة الأداة.

## طريقة العمل

1. انقر على **رفع ملفات PDF** أو اسحب الملفات إلى منطقة الرفع. يمكنك رفع عدة ملفات.
2. تظهر جميع صفحات كل ملف مرفوع في شبكة قابلة للتمرير مع صور مصغرة.
3. استخدم شريط الأدوات أو أزرار الإجراءات لكل صفحة للتعامل مع الصفحات.
4. حدد الصفحات باستخدام مربع الاختيار في كل بطاقة، ثم طبّق العمليات الجماعية.
5. ضع نقاط تقسيم بأيقونة المقص لتقسيم الناتج إلى ملفات منفصلة.
6. انقر على **تصدير PDF** لتنزيل النتيجة النهائية. إذا وُجدت علامات تقسيم، يكون الناتج ملف ZIP يضم عدة ملفات PDF.

## الميزات

- **دمج**: ارفع عدة ملفات PDF وستُدمج في مساحة عمل واحدة تلقائيًا
- **إعادة الترتيب**: اسحب بطاقات الصفحات وأفلتها لإعادة ترتيب التسلسل
- **تدوير**: تدوير لكل صفحة أو جماعي بمقدار 90 درجة (يسارًا أو يمينًا)
- **تكرار**: انسخ أي صفحة بنقرة واحدة
- **حذف**: احذف صفحات فردية أو احذف المحددة منها دفعة واحدة
- **إدراج PDF**: أضف ملف PDF جديدًا بعد أي صفحة محددة
- **إضافة صفحة فارغة**: أضف صفحة A4 فارغة في النهاية
- **تقسيم**: ضع علامات تقسيم بين الصفحات، ثم صدّر كملف ZIP من ملفات PDF منفصلة
- **تحديد الكل / إلغاء تحديد الكل**: تحديد سريع للعمليات الجماعية
- **تراجع / إعادة**: سجل كامل للتراجع والإعادة لكل عملية
- **تنزيل المحدد**: صدّر الصفحات المحددة فقط كملف PDF مستقل
- يصلح ملفات PDF التالفة تلقائيًا قبل التحميل

## حالات الاستخدام

- إنشاء مستند مخصص من صفحات عدة ملفات PDF مصدر
- تنظيف مستند ممسوح ضوئيًا بحذف الصفحات الفارغة وتدوير الصفحات الجانبية وإعادة ترتيب الأقسام
- تقسيم ملف PDF كبير عند حدود الفصول باستخدام علامات تقسيم مرئية
- تعديل سريع على مستوى الصفحة دون الحاجة إلى محرر PDF كامل

## نصائح

- يتتبع نظام التراجع والإعادة كل عملية. استخدمه بحرية، فلا يمكنك إتلاف عملك عن طريق الخطأ.
- تظهر علامات التقسيم كخطوط زرقاء متقطعة بين الصفحات. ضعها بصريًا حيث تريد تقسيم المستند، ثم صدّر للحصول على ملف ZIP.
- لمهام الدمج أو التقسيم البسيطة، قد تكون أداتا [دمج PDF](./merge-pdf) و[تقسيم PDF](./split-pdf) المخصصتان أسرع. تتألق الأداة المتعددة عندما تحتاج إلى عدة عمليات في جلسة واحدة.

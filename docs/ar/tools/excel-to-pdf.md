# Excel إلى PDF

حوّل ملفات جداول البيانات إلى PDF. تتعامل الأداة مع ملفات Excel الحديثة وصيغة XLS القديمة وجداول OpenDocument وحتى CSV، وكلها تُعرض عبر محرك LibreOffice داخل المتصفح الذي يحافظ على تنسيق الخلايا والصيغ (كقيم محسوبة) والمخططات وتخطيطات الأوراق المتعددة.

## الصيغ المدعومة

| الصيغة                   | الامتدادات |
| :----------------------- | :--------- |
| Excel (حديثة)            | `.xlsx`    |
| Excel (قديمة)            | `.xls`     |
| OpenDocument Spreadsheet | `.ods`     |
| CSV                      | `.csv`     |

## طريقة العمل

1. انقر منطقة الرفع أو اسحب ملفات جداول البيانات وأفلتها.
2. راجع قائمة الملفات. أضف المزيد أو أزل ما لا تريده.
3. انقر **تحويل إلى PDF**. يبدأ محرك LibreOffice عند أول استخدام، ثم يعالج كل ملف.
4. يُنزَّل الملف الواحد مباشرة بصيغة PDF. وتُسلَّم الملفات المتعددة باسم `excel-converted.zip`.

## الخيارات

لا تحتاج هذه الأداة إلى أي إعداد إضافي. يحدد محرك LibreOffice تخطيط الصفحة والتحجيم ومنطقة الطباعة بناءً على الإعدادات المضمنة في جدول البيانات.

## الناتج

| عدد المدخلات  | الناتج                                                  |
| :------------ | :------------------------------------------------------ |
| ملف واحد      | تنزيل ملف PDF واحد (اسم الملف الأصلي بامتداد `.pdf`)    |
| ملفان أو أكثر | أرشيف ZIP (`excel-converted.zip`) يحتوي ملف PDF لكل ملف |

## حالات الاستخدام

- تحويل التقارير المالية أو الميزانيات من Excel إلى PDF للتوزيع
- إنشاء ملفات PDF جاهزة للطباعة من جداول المخزون أو كتالوجات المنتجات
- مشاركة نتائج تحليل البيانات مع أصحاب المصلحة الذين لا يملكون Excel
- أرشفة التقارير ربع السنوية بصيغة غير قابلة للتعديل
- تحويل ملفات ODS من LibreOffice Calc إلى PDF

## نصائح

- تُعرض المخططات المضمنة في جدول البيانات في PDF. تأكد من أنها تبدو صحيحة في الملف المصدر قبل التحويل.
- إذا كان جدول بياناتك يحتوي أوراقًا متعددة، تُضمَّن كل الأوراق في ناتج PDF.
- لبيانات CSV البسيطة دون تنسيق، توفر أداة [CSV إلى PDF](./csv-to-pdf) تحويلًا أخف. استخدم Excel إلى PDF عندما تحتاج إلى الحفاظ على التنسيق أو المخططات أو الأوراق المتعددة.

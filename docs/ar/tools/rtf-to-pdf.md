# RTF إلى PDF

حوّل مستندات Rich Text Format إلى PDF. RTF صيغة مستندات متعددة المنصات تدعمها تقريبًا كل معالجات النصوص. تستخدم هذه الأداة محرك LibreOffice يعمل داخل المتصفح لعرض ملفات RTF مع الحفاظ على تنسيقها: الخط العريض والمائل والجداول والصور المضمّنة كلها تنتقل إلى PDF.

## الصيغ المدعومة

| الصيغة | الامتدادات | أنواع MIME                    |
| :----- | :--------- | :---------------------------- |
| RTF    | `.rtf`     | `text/rtf`, `application/rtf` |

## طريقة العمل

1. انقر على منطقة الرفع أو اسحب ملف RTF واحدًا أو أكثر وأفلته.
2. راجع قائمة الملفات. أضف المزيد أو أزل ما لا تحتاجه.
3. انقر على **تحويل إلى PDF**. يُهيَّأ محرك LibreOffice عند أول استخدام، ثم يعالج كل ملف.
4. يُنزَّل الملف الواحد مباشرة بصيغة PDF. أما الملفات المتعددة فتُسلَّم باسم `rtf-converted.zip`.

## الخيارات

لا تحتوي هذه الأداة على إعدادات إضافية. يحافظ التحويل على تنسيق RTF الأصلي.

## الناتج

| عدد الملفات المدخلة | الناتج                                                    |
| :------------------ | :-------------------------------------------------------- |
| ملف واحد            | تنزيل ملف PDF واحد (مثل `letter.pdf`)                     |
| ملفان أو أكثر       | أرشيف ZIP (`rtf-converted.zip`) يحتوي على ملف PDF لكل ملف |

## حالات الاستخدام

- تحويل مستندات RTF القديمة من معالجات النصوص الأقدم إلى ملفات PDF حديثة
- تحويل قوالب البريد الإلكتروني بصيغة RTF إلى معاينات PDF
- معالجة مخرجات RTF من الأنظمة القانونية أو الطبية
- تحويل ملفات RTF من نظام إدارة مستندات إلى PDF للأرشفة دفعة واحدة

## نصائح

- يُحمَّل محرك LibreOffice مرة واحدة ويُخزَّن مؤقتًا. يستغرق التحويل الأول في الجلسة بضع ثوانٍ إضافية، وتكون التحويلات اللاحقة أسرع.
- قد لا تُعرض كائنات OLE المضمّنة في ملفات RTF بشكل مثالي. أما النص العادي والصور والتنسيق القياسي فتُحوَّل بموثوقية.
- إذا أُنشئت ملفات RTF بواسطة Microsoft Word، فيمكنك أيضًا تحويلها مباشرة بأداة [Word إلى PDF](./word-to-pdf) التي تقبل RTF إلى جانب DOC وDOCX.

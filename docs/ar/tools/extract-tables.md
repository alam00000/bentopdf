# استخراج الجداول

يكشف كل الجداول في ملف PDF ويتيح لك تصديرها بالصيغة التي تختارها: CSV أو JSON أو Markdown. يُستخرج كل جدول على حدة مع بيانات وصفية عن الصفحة والموضع. يعمل بمحرك كشف الجداول في PyMuPDF.

## طريقة العمل

1. ارفع ملف PDF بالنقر على منطقة الإسقاط أو بسحب ملف إليها.
2. اختر **صيغة التصدير** المفضلة: CSV أو JSON أو Markdown.
3. انقر **استخراج** لبدء المعالجة.
4. إذا عُثر على جدول واحد، يُنزَّل كملف واحد. أما الجداول المتعددة فتنتج أرشيف ZIP بملف لكل جدول.

## الخيارات

- **صيغة التصدير**: اختر بين:
  - **CSV**: قيم مفصولة بفواصل مع اقتباس صحيح للحقول التي تحتوي فواصل أو علامات اقتباس أو أسطرًا جديدة. مناسبة لجداول البيانات وقواعد البيانات.
  - **JSON**: بنية مصفوفة من المصفوفات، منسّقة بمسافتين بادئتين. مناسبة للاستهلاك البرمجي.
  - **Markdown**: صيغة جدول مفصولة بخطوط عمودية يعرضها PyMuPDF. مناسبة للوثائق وملفات README.

## صيغة الناتج

- **جدول واحد**: `filename_table.csv` (أو `.json` / `.md`)
- **جداول متعددة**: `filename_tables.zip` يحتوي ملفات بأسماء مثل `table_1_page3.csv` و`table_2_page5.csv` وهكذا.

## حالات الاستخدام

- استخراج جداول محددة من تقارير PDF الطويلة دون سحب بيانات المستند كاملًا.
- الحصول على الجداول بصيغة Markdown للصقها مباشرة في مسائل GitHub أو الويكي أو الوثائق.
- سحب بيانات JSON منظمة من جداول PDF لتكاملات API أو السكربتات.
- مقارنة الجداول بين نسخ PDF مختلفة بتصدير كليهما إلى CSV ومقارنة الفروق.

## نصائح

- تمنحك هذه الأداة تحكمًا لكل جدول. إذا أردت فقط تفريغ كل الجداول في ملف CSV واحد، استخدم [PDF إلى CSV](./pdf-to-csv). ولمصنف Excel كامل، استخدم [PDF إلى Excel](./pdf-to-excel).
- قد تُكتشف الجداول الممتدة على عدة صفحات كجداول منفصلة لكل صفحة. وقد تحتاج إلى دمجها يدويًا.
- إذا لم تُكتشف أي جداول، فقد يكون PDF صورة ممسوحة ضوئيًا. مرّره على التعرف الضوئي أولًا لإضافة طبقة نصية.

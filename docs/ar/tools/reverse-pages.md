# عكس الصفحات

اعكس ترتيب صفحات ملف PDF بحيث تصبح الصفحة الأخيرة هي الأولى، والصفحة قبل الأخيرة هي الثانية، وهكذا. يدعم المعالجة الدفعية لعدة ملفات في آنٍ واحد.

## طريقة العمل

1. ارفع ملف PDF واحدًا أو أكثر.
2. انقر على زر المعالجة.
3. يُعكس كل ملف بشكل مستقل. إذا رفعت ملفات متعددة، فالناتج أرشيف ZIP يحتوي على كل ملفات PDF المعكوسة.
4. يُنزَّل الملف الواحد مباشرة بصيغة PDF معكوس.

## الميزات

- معالجة دفعية: اعكس عدة ملفات PDF في عملية واحدة
- ناتج بملف واحد لملف PDF واحد، وبصيغة ZIP للملفات المتعددة
- أزرار إزالة لكل ملف قبل المعالجة
- تحافظ على كل محتوى الصفحات وتنسيقها

## حالات الاستخدام

- إصلاح مستند مُسح ضوئيًا بترتيب معكوس
- تجهيز عرض تقديمي بصيغة PDF ليُقرأ من الخلف إلى الأمام
- عكس ترتيب الصفحات لسير عمل طباعة معين يغذّي الصفحات بترتيب معكوس
- تصحيح مستند جُمعت صفحاته بالخطأ بترتيب معكوس

## نصائح

- يُعكس كل ملف في الدفعة بشكل مستقل، ولا يُعاد ترتيب الملفات نفسها بالنسبة لبعضها.
- لإعادة ترتيب أدق للصفحات (وليس عكسًا كاملًا فقط)، استخدم [تنظيم وتكرار](./organize-pdf).

# قص PDF

قلّم هوامش صفحات PDF باستخدام واجهة قص مرئية. ارسم مستطيل القص مباشرة على كل صفحة، وعاين النتيجة ثم طبّق القص. يمكنك تعيين مناطق قص مختلفة لصفحات مختلفة أو تطبيق القص نفسه على المستند كاملًا.

## طريقة العمل

1. ارفع ملف PDF.
2. يفتح محرر القص ويعرض الصفحة الأولى مع طبقة قص قابلة للسحب.
3. اضبط مستطيل القص بسحب حوافه أو زواياه.
4. استخدم أزرار التنقل بين الصفحات للانتقال بينها وتعيين مناطق القص لكل منها.
5. انقر **قص** لتطبيق القص وتنزيل النتيجة.

## الميزات

- محرر قص مرئي مدعوم بـ Cropper.js مع مقابض للضبط الدقيق
- تنقل صفحة بصفحة لتعيين مناطق قص فردية
- يخزّن إعدادات القص لكل صفحة لتتمكن من تحديد قصات مختلفة لصفحات مختلفة
- معاينة مباشرة لمنطقة القص المحددة
- يدعم ملفات PDF بأي حجم صفحة أو اتجاه

## حالات الاستخدام

- إزالة الهوامش العريضة من المستندات الممسوحة ضوئيًا للتركيز على منطقة المحتوى
- تقليم علامات القص أو التسجيل الخاصة بالطابعة من ملفات PDF قبل الطباعة
- قص شرائح المحاضرات لإزالة منطقة ملاحظات المقدّم
- إزالة الرؤوس أو التذييلات من كل صفحة قبل مشاركة مقتطف من مستند
- تغيير حجم الصفحات لتناسب شاشة أو تخطيط طباعة محددًا

## نصائح

- يمكن تغيير حجم طبقة القص وإعادة تموضعها بحرية. اسحب الزوايا لتغيير الحجم بتناسب أو الحواف لضبط محور واحد.
- في المستندات التي تحتاج كل صفحاتها إلى القص نفسه، عيّنه على الصفحة الأولى، فالأداة تتذكر منطقة القص أثناء تنقلك بين الصفحات.
- إذا كنت تريد توحيد أحجام الصفحات بدل القص البصري، فقد تكون أداة توحيد حجم الصفحة أنسب.

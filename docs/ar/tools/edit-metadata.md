# تعديل البيانات الوصفية

عدّل البيانات الوصفية المضمنة في ملف PDF. تملأ الأداة نموذجًا مسبقًا بالبيانات الوصفية الحالية للمستند، وتتيح لك تعديل أي حقل، ثم تحفظ التغييرات في ملف PDF جديد.

## طريقة العمل

1. ارفع ملف PDF. تقرأ الأداة بياناته الوصفية الحالية وتملأ النموذج بها.
2. عدّل أي حقل قياسي: العنوان، المؤلف، الموضوع، الكلمات المفتاحية، المنشئ، المنتِج.
3. اضبط تاريخ الإنشاء وتاريخ التعديل باستخدام منتقيات التاريخ والوقت.
4. أضف حقول بيانات وصفية مخصصة بالنقر على زر الإضافة وإدخال زوج مفتاح وقيمة.
5. انقر زر المعالجة لحفظ PDF المعدّل.

## الميزات

- يملأ مسبقًا كل البيانات الوصفية الموجودة من ملف PDF المرفوع
- الحقول القياسية: العنوان، المؤلف، الموضوع، الكلمات المفتاحية، المنشئ، المنتِج
- منتقيات التاريخ والوقت لتاريخ الإنشاء وتاريخ التعديل
- حقول بيانات وصفية مخصصة بأزواج مفتاح وقيمة لخصائص اعتباطية
- يحفظ التغييرات مباشرة في قاموس معلومات المستند في PDF

## الحقول القابلة للتعديل

| الحقل                 | الوصف                                |
| --------------------- | ------------------------------------ |
| **العنوان**           | عنوان المستند المعروض في قارئات PDF  |
| **المؤلف**            | الشخص أو الجهة التي أنشأت المستند    |
| **الموضوع**           | وصف موجز لموضوع المستند              |
| **الكلمات المفتاحية** | مصطلحات مفصولة بفواصل للبحث والتصنيف |
| **المنشئ**            | التطبيق الذي أنشأ المحتوى في الأصل   |
| **المنتِج**           | التطبيق الذي ولّد ملف PDF            |
| **تاريخ الإنشاء**     | متى أُنشئ المستند أصلًا              |
| **تاريخ التعديل**     | متى عُدّل المستند آخر مرة            |
| **الحقول المخصصة**    | أي أزواج مفتاح وقيمة إضافية تحددها   |

## حالات الاستخدام

- تعيين عنوان ومؤلف مناسبين قبل نشر مستند
- إضافة كلمات مفتاحية لتحسين قابلية البحث في أنظمة إدارة المستندات
- تحديث تاريخ التعديل ليعكس المراجعة الحالية
- إضافة حقول بيانات وصفية مخصصة مثل القسم أو معرّف المشروع أو التصنيف
- تنظيف البيانات الوصفية التي تركها برنامج التأليف الأصلي

## نصائح

- تُكتب الحقول المخصصة مباشرة في قاموس معلومات PDF. قد لا تعرض بعض قارئات PDF الحقول المخصصة، لكنها تبقى محفوظة في الملف.
- اترك حقلًا فارغًا لمسحه من البيانات الوصفية. يحفظ زر المعالجة ما هو موجود في النموذج.
- لعرض البيانات الوصفية دون تعديل، استخدم [عرض البيانات الوصفية](./view-metadata). ولإزالة كل البيانات الوصفية، استخدم إزالة البيانات الوصفية.

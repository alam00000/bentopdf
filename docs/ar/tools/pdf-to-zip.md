# PDF إلى ZIP

اجمع عدة ملفات PDF في أرشيف ZIP واحد. هذه أداة تحزيم بسيطة: لا يتم تحويل ملفات PDF أو ضغطها أو تعديلها.

## طريقة العمل

1. ارفع عدة ملفات PDF باستخدام منطقة الإفلات.
2. راجع قائمة الملفات. أزل أي ملف لا تريد تضمينه.
3. انقر على زر المعالجة.
4. يتم تنزيل أرشيف ZIP يحتوي على جميع ملفات PDF المرفوعة فورًا.

## الميزات

- يقبل أي عدد من ملفات PDF
- إزالة كل ملف على حدة قبل إنشاء الأرشيف
- يحافظ على أسماء الملفات الأصلية داخل ZIP
- لا تعديل على محتوى PDF، فالملفات تُحزم كما هي
- يعرض اسم الملف وحجمه لكل ملف PDF مرفوع

## حالات الاستخدام

- جمع مجموعة من الفواتير أو الإيصالات كمرفق بريد إلكتروني
- تحزيم مخرجات المشروع (عدة تقارير PDF) للتسليم
- إنشاء تنزيل واحد لمجموعة نماذج أو قوالب
- أرشفة دفعة من المستندات في ملف مضغوط واحد

## نصائح

- يستخدم ملف ZIP أسماء ملفات PDF الأصلية. إذا كانت لديك ملفات بالاسم نفسه، فأعد تسميتها قبل الرفع لتجنب التعارضات.
- لا تضغط هذه الأداة ملفات PDF نفسها. لتقليل حجم الملفات، مرّرها عبر ضغط PDF أولًا، ثم احزمها بهذه الأداة.

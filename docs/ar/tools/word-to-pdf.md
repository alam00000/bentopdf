# Word إلى PDF

حوّل مستندات Microsoft Word والصيغ المتوافقة معها إلى PDF. تستخدم الأداة محرك LibreOffice يعمل في المتصفح ويتعامل مع ملفات DOC وDOCX وODT وRTF، مع الحفاظ على التنسيق والجداول والصور والرؤوس والتذييلات والأنماط في الناتج.

## الصيغ المدعومة

| الصيغة            | الامتدادات |
| :---------------- | :--------- |
| Word (حديثة)      | `.docx`    |
| Word (قديمة)      | `.doc`     |
| OpenDocument Text | `.odt`     |
| Rich Text Format  | `.rtf`     |

## طريقة العمل

1. انقر على منطقة الرفع أو اسحب مستندات Word وأفلتها. يمكن تحديد عدة ملفات دفعة واحدة.
2. راجع قائمة الملفات وأدرها.
3. انقر على **تحويل إلى PDF**. يُحمَّل محرك LibreOffice عند أول استخدام (يعرض مؤشر التقدم حالة التهيئة)، ثم يُحوَّل كل ملف.
4. يُنزَّل الملف الواحد مباشرة كملف PDF. أما الملفات المتعددة فتُجمَّع في `word-converted.zip`.

## الخيارات

لا تحتوي هذه الأداة على إعدادات إضافية. ينتج محرك LibreOffice الناتج باستخدام ملف تصدير PDF الافتراضي.

## الناتج

| عدد المدخلات  | الناتج                                                      |
| :------------ | :---------------------------------------------------------- |
| ملف واحد      | تنزيل ملف PDF واحد (اسم الملف الأصلي بالامتداد `.pdf`)      |
| ملفان أو أكثر | أرشيف ZIP (`word-converted.zip`) يضم ملف PDF واحدًا لكل ملف |

## حالات الاستخدام

- تحويل سيرة ذاتية أو خطاب تقديم من DOCX إلى PDF قبل إرسال طلب وظيفة
- تحويل مجموعة من العقود أو العروض دفعة واحدة إلى PDF لتسليمها لعميل
- تحويل ملفات `.doc` القديمة إلى ملفات PDF حديثة للأرشفة طويلة الأمد
- تحويل المستندات التعاونية من Google Docs (المصدّرة بصيغة DOCX) إلى PDF
- إنتاج ملفات PDF جاهزة للطباعة من قوالب Word المستخدمة في توليد المستندات آليًا

## نصائح

- يُنزَّل محرك LibreOffice مرة واحدة في كل جلسة ويُخزَّن مؤقتًا. توقع بضع ثوانٍ من التحميل عند أول تحويل، وتكون التحويلات اللاحقة أسرع بكثير.
- قد لا تُحوَّل التنسيقات المعقدة (الماكرو وعناصر ActiveX وSmartArt المتقدمة) بشكل مثالي. أما عناصر المستند القياسية (النصوص والجداول والصور والرؤوس والحواشي السفلية) فتُحوَّل بموثوقية.
- بما أن هذه الأداة تقبل ODT وRTF أيضًا، يمكنك استخدامها كمحوّل شامل لجميع صيغ معالجة النصوص.

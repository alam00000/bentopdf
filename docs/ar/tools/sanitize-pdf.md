# تنظيف PDF

يمكن أن تحمل ملفات PDF أكثر بكثير مما تراه على الشاشة. فالبيانات الوصفية المخفية وJavaScript المضمّن ومرفقات الملفات وبيانات النماذج ومعلومات الطبقات قد تسرّب بيانات حساسة أو تشكل مخاطر أمنية. يزيل التنظيف كل ذلك، ليترك لك مستندًا نظيفًا وآمنًا للمشاركة العلنية.

## طريقة العمل

1. ارفع ملف PDF.
2. حدد العناصر المراد إزالتها من قائمة الخيارات.
3. انقر على **تنظيف PDF**.
4. نزّل الملف النظيف.

## خيارات التنظيف

كل الخيارات مفعّلة افتراضيًا. ألغِ تحديد أي خيار تريد الإبقاء عليه.

| الخيار                     | ما الذي يزيله                                                     |
| -------------------------- | ----------------------------------------------------------------- |
| **تسطيح النماذج**          | يحوّل حقول النماذج التفاعلية إلى محتوى ثابت                       |
| **إزالة البيانات الوصفية** | يزيل المؤلف والعنوان وتاريخ الإنشاء ومعلومات البرنامج وبيانات XMP |
| **إزالة التعليقات**        | يحذف الملاحظات والتمييزات والملاحظات اللاصقة وعلامات التدوين      |
| **إزالة JavaScript**       | يزيل السكربتات المضمّنة التي قد تُنفَّذ عند الفتح                 |
| **إزالة الملفات المضمّنة** | يزيل مرفقات الملفات المضمّنة داخل PDF                             |
| **إزالة الطبقات (OCG)**    | يسطّح مجموعات المحتوى الاختياري في طبقة واحدة                     |
| **إزالة الروابط**          | يزيل الروابط التشعبية ومراجع URL                                  |
| **إزالة شجرة البنية**      | يزيل بنية المستند المستخدمة في وسوم إمكانية الوصول                |
| **إزالة MarkInfo**         | يزيل معلومات المحتوى الموسوم                                      |
| **إزالة الخطوط**           | يزيل بيانات الخطوط المضمّنة (استخدمه بحذر)                        |

## حالات الاستخدام

- تجهيز ملف PDF للنشر العلني بإزالة البيانات الوصفية الداخلية (أسماء المؤلفين وإصدارات البرامج وسجل التعديل)
- إزالة JavaScript من ملف PDF وارد من مصدر غير موثوق قبل فتحه
- تنظيف ملف PDF قبل إرساله إلى عميل لا ينبغي أن يرى التعليقات المضمّنة أو أسماء حقول النماذج
- إزالة الطبقات المخفية من رسم معماري قبل مشاركة النسخة النهائية
- الامتثال لمتطلبات تقليل البيانات بموجب لوائح الخصوصية

## نصائح

- اترك "إزالة الخطوط" غير محدد ما لم تكن متأكدًا من أن ملف PDF سيظهر بشكل صحيح بعد ذلك. قد تجعل إزالة الخطوط النص غير مرئي في بعض برامج العرض.
- إذا كنت تحتاج فقط إلى إزالة البيانات الوصفية، فأداة إزالة البيانات الوصفية المخصصة أسرع وأكثر تركيزًا.
- التنظيف لا رجعة فيه. احتفظ بملفك الأصلي.

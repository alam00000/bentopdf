# تحضير PDF للذكاء الاصطناعي

يستخرج محتوى ملفات PDF وينظّمه بصيغة JSON محسّنة للاستيعاب من قبل نماذج اللغة الكبيرة (LLMs) وأطر الذكاء الاصطناعي مثل LlamaIndex. يُستخرج محتوى كل صفحة ويُنظَّم في بنية جاهزة لخطوط RAG وروبوتات المحادثة وأنظمة البحث الدلالي.

## طريقة العمل

1. ارفع ملف PDF واحدًا أو أكثر بالنقر على منطقة الإفلات أو بسحب الملفات إليها.
2. انقر على **استخراج** لبدء المعالجة.
3. يتم تنزيل الملف الواحد باسم `filename_llm.json`. أما الملفات المتعددة فتنتج أرشيف `pdf-for-ai.zip`.

تستخدم الأداة تكامل LlamaIndex في PyMuPDF لاستخراج محتوى كل صفحة مع البيانات الوصفية، لينتج مخرجات يمكن تحميلها مباشرة في أطر الذكاء الاصطناعي.

## الخيارات

لا تحتوي هذه الأداة على خيارات قابلة للضبط. تُستخرج كل الصفحات بالنص الكامل والبيانات الوصفية.

## صيغة الناتج

- **ملف واحد**: `filename_llm.json`
- **ملفات متعددة**: `pdf-for-ai.zip` يحتوي على ملف `_llm.json` واحد لكل ملف PDF مدخل.

يتبع ناتج JSON مخطط مستندات LlamaIndex مع محتوى نصي وحقول بيانات وصفية لكل صفحة.

## حالات الاستخدام

- تحضير مستندات PDF لخطوط التوليد المعزز بالاسترجاع (RAG).
- بناء قاعدة معرفة قابلة للبحث من أرشيفات PDF لروبوت محادثة يعمل بالذكاء الاصطناعي.
- تغذية تقارير PDF إلى مسارات التحليل المعتمدة على نماذج اللغة الكبيرة.
- المعالجة المسبقة للأوراق البحثية لأنظمة البحث الدلالي والإجابة عن الأسئلة.
- إنشاء بيانات تدريب منظمة من مجموعات مستندات PDF.

## نصائح

- لاستخراج النص العادي دون تنسيق خاص بالذكاء الاصطناعي، استخدم [PDF إلى نص](./pdf-to-text).
- للحصول على ناتج Markdown يحافظ على العناوين والبنية، استخدم [PDF إلى Markdown](./pdf-to-markdown).
- ستنتج ملفات PDF الممسوحة ضوئيًا مخرجات فارغة أو شبه فارغة. مرّرها عبر التعرف الضوئي على الحروف أولًا لإضافة طبقة نصية قبل الاستخراج.

# تغيير الأذونات

تحكم بدقة فيما يستطيع المستلمون فعله بملف PDF الخاص بك. فعلى عكس التشفير الأساسي الذي يكتفي بقفل الملف بكلمة مرور، تتيح لك هذه الأداة السماح أو المنع انتقائيًا للطباعة والنسخ والتحرير والتعليق وتعبئة النماذج وتجميع المستند واستخراج الصفحات، وكل ذلك يُفرض عبر تشفير AES بطول 256 بت.

## طريقة العمل

1. ارفع ملف PDF.
2. إذا كان PDF مشفرًا بالفعل، أدخل **كلمة المرور الحالية**.
3. عيّن **كلمة مرور مستخدم جديدة** (مطلوبة للفتح) و/أو **كلمة مرور مالك جديدة** (تتحكم بالأذونات).
4. فعّل الأذونات أو عطّلها كلًا على حدة باستخدام مربعات الاختيار.
5. انقر **تغيير الأذونات**.
6. نزّل ملف PDF المحدّث.

إذا تركت حقلي كلمة المرور الجديدتين فارغين، تفك الأداة تشفير PDF بالكامل وتزيل كل التشفير والقيود.

## عناصر التحكم بالأذونات

| الإذن                       | ما الذي يتحكم به                          |
| --------------------------- | ----------------------------------------- |
| **السماح بالطباعة**         | هل يمكن طباعة المستند                     |
| **السماح بالنسخ**           | هل يمكن تحديد النصوص والصور ونسخها        |
| **السماح بالتعديل**         | هل يمكن تحرير محتوى المستند               |
| **السماح بالتعليق**         | هل يمكن إضافة تعليقات وتمييز وأختام       |
| **السماح بتعبئة النماذج**   | هل يمكن إكمال حقول النموذج التفاعلية      |
| **السماح بتجميع المستند**   | هل يمكن إدراج الصفحات أو حذفها أو تدويرها |
| **السماح باستخراج الصفحات** | هل يمكن استخراج صفحات فردية               |

تتطلب جميع الأذونات كلمة مرور مالك لتُفرض. وبدون كلمة مرور المالك، تتجاهل معظم قارئات PDF علامات الأذونات.

## كيف تعمل الأذونات في PDF

الأذونات في PDF جزء من مواصفة التشفير. وتُخزَّن كعلامات بتّية في قاموس التشفير وتفرضها قارئات PDF المتوافقة. الفرق الأساسي:

- **كلمة مرور المستخدم**: مطلوبة لفتح الملف أصلًا.
- **كلمة مرور المالك**: مطلوبة لتغيير الأذونات أو إزالة القيود. وبدونها، تتحكم علامات الأذونات بالعمليات التي يستطيع المستخدم تنفيذها.

إذا عيّنت كلمة مرور مالك فقط (دون كلمة مرور مستخدم)، يستطيع أي شخص فتح الملف لكنه مقيّد بالعمليات المسموحة. وإذا عيّنت الاثنتين، يتطلب الملف كلمة مرور لفتحه ويصبح مقيّدًا بعد المصادقة.

## حالات الاستخدام

- توزيع تقرير يمكن عرضه وطباعته دون تحريره أو نسخه
- مشاركة قالب عقد يستطيع المستلمون تعبئته دون تعديله
- نشر كتالوج PDF مع تعطيل نسخ الصور
- السماح بالتعليق على مسودة مراجعة مع منع التغييرات الهيكلية

## نصائح

- لتكون الأذونات فعّالة، عيّن دائمًا كلمة مرور مالك. فالأذونات بدون كلمة مرور مالك لا يمكن فرضها.
- بعض أدوات PDF الخارجية تتجاهل علامات الأذونات. لحماية أقوى، فكّر في تحويل PDF إلى صور أو استخدام إدارة الحقوق الرقمية (DRM).
- استخدم هذه الأداة لترقية ملفات PDF القديمة المشفرة بـ RC4 إلى AES-256.

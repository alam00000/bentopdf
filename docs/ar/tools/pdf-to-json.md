# PDF إلى JSON

يحوّل ملف PDF واحدًا أو أكثر إلى صيغة JSON. تستخدم الأداة CPDF (Coherent PDF) لتسلسل البنية الداخلية لكل ملف PDF إلى تمثيل JSON قابل للقراءة آليًا. يُسلَّم الناتج دائمًا كأرشيف ZIP.

## طريقة العمل

1. اختر ملف PDF واحدًا أو أكثر باستخدام منتقي الملفات.
2. انقر على **تحويل إلى JSON** لبدء المعالجة. يعمل التحويل في web worker في الخلفية.
3. يتم تنزيل أرشيف ZIP يحتوي على ملف JSON واحد لكل ملف PDF مدخل.

يعرض شريط الحالة التقدم خلال مرحلتي التحويل وإنشاء ZIP.

## الخيارات

لا تحتوي هذه الأداة على خيارات قابلة للضبط. يتم تحويل كل ملف PDF إلى تمثيل JSON الكامل له.

## صيغة الناتج

- ملف `pdfs-to-json.zip` يحتوي على `filename.json` لكل ملف PDF مدخل.

يمثّل ناتج JSON بنية كائنات PDF الداخلية، بما في ذلك أشجار الصفحات ومراجع الخطوط والبيانات الوصفية وتدفقات المحتوى.

## حالات الاستخدام

- فحص البنية الداخلية لملف PDF لأغراض تصحيح الأخطاء أو التحقق.
- استخراج البيانات الوصفية وخصائص الصفحات المنظمة برمجيًا.
- تغذية خطوط معالجة مخصصة ببيانات بنية PDF.
- تدقيق مستندات PDF للامتثال عبر تحليل أشجار كائناتها.

## نصائح

- تُخرج هذه الأداة بنية كائنات PDF الخام، وليس محتوى النص المستخرج. إذا كنت تحتاج إلى نص الصفحات بصيغة JSON، فاستخدم [تحضير PDF للذكاء الاصطناعي](./prepare-pdf-for-ai) بدلًا من ذلك.
- لاستخراج النص العادي، تكون [PDF إلى نص](./pdf-to-text) أكثر مباشرة.
- تنتج ملفات PDF الكبيرة ذات البنى المعقدة ملفات JSON كبيرة جدًا.

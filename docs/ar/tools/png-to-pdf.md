# PNG إلى PDF

حوّل صور PNG إلى PDF مع الحفاظ على دقتها الكاملة. تصبح كل صورة PNG صفحة خاصة بها بحجم يطابق أبعاد الصورة الأصلية. تتم معالجة الشفافية تلقائيًا.

## الصيغ المدعومة

| الصيغة | الامتدادات |
| :----- | :--------- |
| PNG    | `.png`     |

## طريقة العمل

1. انقر على منطقة الرفع أو اسحب ملفات PNG وأفلتها. يمكنك تحديد عدة ملفات دفعة واحدة.
2. أدر قائمة الملفات: أزل الملفات غير المرغوب فيها أو أضف المزيد.
3. اختر مستوى **جودة PDF** من القائمة المنسدلة.
4. انقر على **التحويل إلى PDF**. يتم تنزيل الناتج باسم `from_jpgs.pdf`.

تستخدم الأداة pdf-lib لتضمين كل صورة مباشرة. إذا تعذر تضمين ملف PNG بشكل أصلي (مثلًا بسبب ملف تعريف ألوان غير شائع)، فإنها تعود إلى إعادة عرضه عبر canvas كصورة JPEG.

## الخيارات

يتحكم **جودة PDF** في الضغط المطبّق قبل التضمين:

- **جودة عالية**: ضغط أدنى وأكبر حجم ملف.
- **جودة متوسطة** (الافتراضي): توازن جيد بين الحجم والوضوح.
- **جودة منخفضة**: أقصى ضغط وأصغر ناتج.

## حالات الاستخدام

- تحويل لقطات الشاشة إلى ملف PDF متعدد الصفحات لتقارير الأخطاء أو التوثيق
- تحزيم مخرجات تصميم واجهات المستخدم في ملف واحد للمراجعة
- تحويل مخرجات المخططات (draw.io وExcalidraw) إلى ملف PDF قابل للمشاركة
- تجميع مجموعة من صور المخططات البيانية في تقرير

## نصائح

- تحصل ملفات PNG ذات الشفافية على خلفية بيضاء في ملف PDF. إذا كنت تحتاج إلى خلفية مختلفة، فعدّل الصور مسبقًا.
- بالنسبة للقطات الشاشة والمخططات ذات الحواف الحادة والنصوص، تتجنب الجودة High عيوب ضغط JPEG. وقد تتحول الصور داخليًا إلى JPEG مع Medium أو Low.

# CSV إلى PDF

حوّل ملفات CSV إلى مستندات PDF نظيفة ومنسقة. يُحلَّل كل ملف CSV ويُعرض كجدول في ملف PDF الناتج. هذا مفيد عندما تريد طباعة بيانات جدولية أو مشاركتها دون أن يحتاج المستلم إلى برنامج جداول بيانات.

## الصيغ المدعومة

| الصيغة | الامتدادات |
| :----- | :--------- |
| CSV    | `.csv`     |

## طريقة العمل

1. انقر منطقة الرفع أو اسحب ملف CSV واحدًا أو أكثر وأفلته.
2. راجع قائمة الملفات. أضف المزيد أو أزل ما لا تريده.
3. انقر **تحويل إلى PDF**. يعرض مؤشر التقدم حالة التحويل.
4. يُنزَّل الملف الواحد مباشرة بصيغة PDF. وتُجمَّع الملفات المتعددة في `csv-converted.zip`.

## الخيارات

لا تحتاج هذه الأداة إلى أي إعداد إضافي. يُحلَّل ملف CSV وينسَّق كجدول تلقائيًا.

## الناتج

| عدد المدخلات  | الناتج                                                |
| :------------ | :---------------------------------------------------- |
| ملف واحد      | تنزيل ملف PDF واحد (مثل `data.pdf`)                   |
| ملفان أو أكثر | أرشيف ZIP (`csv-converted.zip`) يحتوي ملف PDF لكل ملف |

## حالات الاستخدام

- تحويل تقارير قواعد البيانات المصدّرة إلى جداول PDF قابلة للطباعة
- مشاركة البيانات المالية أو قوائم المخزون مع من لا يملكون Excel
- إنشاء نسخ PDF من ملفات سجلات CSV لتوثيق الامتثال
- طباعة قوائم العناوين أو كشوف الدرجات أو أي بيانات جدولية مخزنة بصيغة CSV

## نصائح

- للحصول على أفضل النتائج، تأكد أن ملف CSV يستخدم فواصل الفاصلة القياسية. تتبع الأداة أعراف تحليل CSV الشائعة.
- إذا كان ملف CSV يحتوي أعمدة كثيرة، فقد يُضغط الجدول ليناسب عرض الصفحة. فكّر في تقسيم مجموعات البيانات العريضة إلى عدة ملفات.
- لملفات Excel (`.xls`، `.xlsx`)، استخدم أداة [Excel إلى PDF](./excel-to-pdf) التي تحافظ على تنسيق الجداول وتعدد الأوراق.

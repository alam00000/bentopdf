# تعديل المرفقات

افحص المرفقات داخل ملف PDF وأدرها. تسرد الأداة كل ملف مضمن باسمه ومستوى إرفاقه، ثم تتيح لك تعليم مرفقات فردية للإزالة أو حذفها كلها دفعة واحدة.

## طريقة العمل

1. ارفع ملف PDF.
2. تفحص الأداة المرفقات تلقائيًا وتعرضها في قائمة.
3. يعرض كل مرفق اسم ملفه وهل هو مرفق على مستوى المستند أو على مستوى الصفحة.
4. انقر أيقونة سلة المهملات بجوار المرفق لتعليمه للإزالة (انقر مرة أخرى لإلغاء التعليم).
5. استخدم زر **إزالة كل المرفقات** لتحديد كل شيء دفعة واحدة، أو **إلغاء تحديد الكل** لمسح التحديدات.
6. انقر زر المعالجة لحفظ PDF جديد بعد إزالة المرفقات المحددة.

## الميزات

- يسرد كل المرفقات على مستوى المستند وعلى مستوى الصفحة
- إزالة المرفقات فرديًا أو دفعة واحدة
- تبديل التحديد تشغيلًا وإيقافًا قبل تثبيت التغييرات
- شطب مرئي وتغيير في الشفافية للعناصر المعلَّمة للإزالة
- ينزّل PDF المعدّل بعد حذف المرفقات المحددة

## حالات الاستخدام

- إزالة الملفات القديمة أو الخاطئة المضمنة في مستند قبل إعادة توزيعه
- حذف المرفقات الحساسة (بيانات مالية أو معلومات شخصية) من PDF قبل مشاركته
- تقليل حجم PDF بإزالة الملفات المضمنة الكبيرة التي لم تعد مطلوبة
- تدقيق المحتوى المضمن وتنظيف المستند قبل الأرشفة

## نصائح

- تظهر المرفقات المعلَّمة للإزالة مع شطب مرئي. يمكنك إعادتها قبل المعالجة إذا غيّرت رأيك.
- إذا لم تُعثر على مرفقات، تعرض الأداة رسالة واضحة "لم يتم العثور على مرفقات"، أي أن PDF لا يحتوي ببساطة على ملفات مضمنة.

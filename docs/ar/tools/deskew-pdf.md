# تصحيح انحراف PDF

نادرًا ما تكون المستندات الممسوحة ضوئيًا مستقيمة تمامًا. حتى الميل الطفيف يقلل دقة التعرف الضوئي ويجعل الطباعة تبدو غير مرتبة. تستخدم هذه الأداة خوارزميات معالجة الصور في OpenCV لكشف زاوية انحراف كل صفحة وإعادة تدويرها لتصبح مستوية.

## طريقة العمل

1. ارفع ملف PDF ممسوحًا ضوئيًا واحدًا أو أكثر.
2. اضبط **حد الانحراف**: تُترك دون تغيير الصفحات التي يقل انحرافها المكتشف عن هذه القيمة.
3. اختر **جودة المعالجة (DPI)**: الدقة الأعلى تحسّن دقة الكشف لكنها تستغرق وقتًا أطول.
4. انقر **تصحيح انحراف PDF**.
5. بعد المعالجة، تعرض لوحة النتائج زاوية كل صفحة المكتشفة وهل صُحِّحت.

## الخيارات

| الإعداد          | القيم                   | الافتراضي |
| ---------------- | ----------------------- | --------- |
| **حد الانحراف**  | 0.1، 0.5، 1.0، 2.0 درجة | 0.5       |
| **DPI المعالجة** | 100، 150، 200، 300      | 150       |

## كيف يعمل كشف الانحراف

تعرض الأداة كل صفحة كصورة بدقة DPI المحددة، ثم تستخدم OpenCV لكشف زوايا الخطوط المهيمنة في المحتوى. إذا تجاوز الانحراف المكتشف الحد، تُدوَّر الصفحة بالزاوية المعاكسة لتستقيم. وتمر الصفحات الأقل من الحد دون تغيير.

## حالات الاستخدام

- تنظيف العقود أو المستندات القانونية الممسوحة ضوئيًا دفعة واحدة
- تجهيز الإيصالات أو الفواتير الممسوحة للتعرف الضوئي
- تقويم صفحات من ماسح مسطح وُضع فيه الورق بشكل غير متسق
- تحسين الجودة البصرية للمواد الأرشيفية المرقمنة

## نصائح

- اخفض الحد إلى 0.1 درجة إذا احتجت محاذاة دقيقة للتعرف الضوئي.
- 150 DPI سريعة ودقيقة لمعظم المستندات. استخدم 300 DPI للنصوص الصغيرة جدًا أو الصفحات كثيرة التفاصيل.
- يعمل تصحيح الانحراف بأفضل شكل على المستندات ذات الأسطر الأفقية الواضحة. وقد يواجه صعوبة مع الصفحات التي تغلب عليها الصور أو عناصر التصميم المائلة.

# تنظيم ونسخ الصفحات

أعد ترتيب صفحات ملف PDF وكرّرها واحذفها عبر واجهة مرئية بالسحب والإفلات. تظهر كل صفحة كصورة مصغرة يمكنك نقلها أو نسخها أو حذفها قبل حفظ النتيجة كملف جديد.

## طريقة العمل

1. ارفع ملف PDF واحدًا.
2. تعرض الأداة شبكة من الصور المصغرة لكل صفحة.
3. اسحب الصور المصغرة لإعادة ترتيب الصفحات، أو انقر على زر النسخ الأخضر لتكرار صفحة، أو انقر على زر الحذف الأحمر لإزالتها.
4. أو أدخل ترتيبًا مخصصًا للصفحات في حقل النص (مثل `3, 1, 2, 4`) وانقر على **تطبيق الترتيب** لإعادة ترتيب جميع الصفحات دفعة واحدة.
5. انقر على زر المعالجة لإنشاء ملف PDF المعاد تنظيمه وتنزيله.

## الميزات

- إعادة ترتيب الصفحات بالسحب والإفلات مع انتقالات متحركة
- أزرار نسخ وحذف لكل صفحة
- حقل ترتيب مخصص للصفحات لإعادة ترتيب دقيقة
- تتحدث أرقام الصفحات تلقائيًا بعد كل تغيير
- يمنع حذف آخر صفحة متبقية

## حالات الاستخدام

- نقل صفحة في غير موضعها إلى المكان الصحيح في تقرير
- تكرار صفحة نموذج للحصول على عدة نسخ فارغة في ملف واحد
- إزالة الصفحات المبدئية أو النائبة قبل توزيع المستند
- عكس ترتيب الصفحات أو خلطها استعدادًا للطباعة
- إنشاء تسلسل مخصص للصفحات دون إعادة دمج ملفات منفصلة

## نصائح

- يتوقع حقل الترتيب المخصص أرقام الصفحات الأصلية مفصولة بفواصل. ويجب أن يتضمن كل صفحة مرة واحدة بالضبط، دون حذف أو تكرار.
- بعد تكرار صفحة، تشير النسختان إلى فهرس الصفحة الأصلية نفسه. ويعمل إعادة ترتيب أي من النسختين بشكل مستقل.
- للعمليات الجماعية على عدة ملفات أو لسير العمل الأكثر تقدمًا، فكّر في استخدام [أداة PDF المتعددة](./pdf-multi-tool) بدلًا من ذلك.

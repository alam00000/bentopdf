# JSON إلى PDF

أعد بناء مستندات PDF من ملفات JSON أُنشئت سابقًا بأداة **PDF إلى JSON** في BentoPDF. هذه أداة تحويل ذهابًا وإيابًا: تأخذ التمثيل المنظَّم لملف PDF بصيغة JSON وتعيد بناء المستند الأصلي.

::: warning
تقبل هذه الأداة فقط ملفات JSON التي أنتجها محوّل PDF إلى JSON في BentoPDF. ملفات JSON القياسية من واجهات API أو قواعد البيانات أو أدوات أخرى غير مدعومة.
:::

## الصيغ المدعومة

| المدخل  | الوصف                                              |
| :------ | :------------------------------------------------- |
| `.json` | ملفات JSON المصدّرة بأداة PDF إلى JSON في BentoPDF |

## طريقة العمل

1. انقر على منطقة الرفع أو اسحب ملف JSON واحدًا أو أكثر وأفلته.
2. تعرض قائمة الملفات كل ملف محدد مع حجمه.
3. انقر على **تحويل إلى PDF**. تعالج الأداة كل الملفات باستخدام Web Worker ومحرك CPDF.
4. يُنزَّل الناتج باسم `jsons-to-pdf.zip` ويحتوي على ملف PDF واحد لكل ملف JSON مُدخَل.

يعمل التحويل في Web Worker في الخلفية، لذا تبقى الواجهة سريعة الاستجابة حتى مع الملفات الكبيرة.

## الخيارات

لا تحتوي هذه الأداة على خيارات قابلة للضبط. بنية JSON تحدد ملف PDF الناتج بالكامل.

## المخرجات

عند تحويل عدة ملفات JSON، تُسلَّم النتائج كأرشيف ZIP. يُسمّى كل ملف PDF باسم ملف JSON المصدر (مثلًا يصبح `report.json` هو `report.pdf`).

## حالات الاستخدام

- استعادة ملفات PDF من نسخة احتياطية أو مسار أرشفة مبني على JSON
- تمرير ملف PDF عبر JSON للفحص ثم إعادته إلى PDF
- إعادة بناء المستندات بعد تعديلات برمجية على بنية JSON
- التحقق من أن تصدير PDF إلى JSON التقط كل محتوى المستند بتحويله عائدًا

## نصائح

- إذا كنت تحتاج إلى تحويل بيانات JSON عشوائية (مثل استجابات API أو ملفات الإعدادات) إلى PDF منسّق، فأداة [نص إلى PDF](./txt-to-pdf) أنسب. الصق JSON كنص وسيُعرض بتنسيق مناسب.
- يجب أن يكون محرك CPDF WebAssembly متاحًا لتعمل هذه الأداة. تحتاج النسخ المستضافة ذاتيًا إلى ضبط ملفات CPDF WASM.

# تقسيم PDF

قسّم ملف PDF إلى مستندات أصغر باستخدام أحد ستة أوضاع تقسيم. من نطاقات الصفحات البسيطة إلى التقسيم بحسب الإشارات المرجعية، تتعامل هذه الأداة مع كل سيناريو لتقسيم المستند.

## طريقة العمل

1. ارفع ملف PDF واحدًا.
2. اختر وضع التقسيم من القائمة المنسدلة.
3. اضبط الخيارات الخاصة بالوضع (نطاقات الصفحات والتحديدات وغيرها).
4. انقر على زر المعالجة.
5. تُنزَّل النتيجة كملف PDF واحد أو أرشيف ZIP بحسب الوضع والإعدادات.

## أوضاع التقسيم

| الوضع                 | الوصف                                                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **نطاق**              | أدخل نطاقات صفحات مثل `1-3, 5, 8-10`. النطاقات المتعددة تنتج ملفات PDF منفصلة في ZIP. النطاق الواحد ينتج ملف PDF واحدًا. |
| **تحديد مرئي**        | تصفح الصور المصغرة للصفحات وانقر لتحديد الصفحات المطلوبة. تُستخرج الصفحات المحددة في ملف PDF جديد.                       |
| **زوجي / فردي**       | استخرج الصفحات ذات الأرقام الزوجية أو الفردية فقط.                                                                       |
| **كل الصفحات**        | قسّم كل صفحة إلى ملف PDF مستقل، يُنزَّل في ZIP.                                                                          |
| **الإشارات المرجعية** | قسّم عند حدود الإشارات المرجعية. اختر مستوى الإشارة للتحكم في أماكن التقسيم.                                             |
| **كل N صفحة**         | قسّم إلى أجزاء من N صفحة لكل منها (مثلًا كل 5 صفحات). قد يحتوي الجزء الأخير على صفحات أقل.                               |

## الميزات

- ستة أوضاع تقسيم متميزة تغطي تقريبًا كل حالات الاستخدام
- محدد صفحات مرئي مع صور مصغرة تُحمَّل عند الحاجة
- تقسيم يراعي الإشارات المرجعية مع تصفية المستويات
- خيار ناتج ZIP لوضعي النطاق والتحديد المرئي
- يتعامل مع نطاقات الصفحات ذات الصيغة المختلطة (`1-3, 5, 8-10`)
- تحذير عندما ينتج تقسيم N صفحة أجزاء غير متساوية

## حالات الاستخدام

- استخراج فصل أو قسم محدد من مستند كبير
- فصل الصفحات الفردية والزوجية لسير عمل الطباعة على الوجهين
- تقسيم كتاب PDF إلى ملفات فصول فردية عند حدود الإشارات المرجعية
- عزل صفحات محددة (مثل صفحة التوقيع) من عقد
- تقسيم تقرير مجمَّع إلى ملفات لكل قسم للتوزيع

## نصائح

- النطاقات المتعددة المفصولة بفواصل (مثل `1-5, 10-15, 20-25`) تنتج ملفات PDF منفصلة، واحدًا لكل نطاق، في حزمة ZIP.
- يتطلب وضع التقسيم بالإشارات المرجعية أن يحتوي ملف PDF فعليًا على إشارات مرجعية. إذا لم توجد، فستظهر رسالة خطأ.
- يتيح مربع "تنزيل كملف ZIP" في وضعي النطاق والتحديد المرئي الحصول على ملف PDF منفصل لكل صفحة بدلًا من ملف مجمَّع.

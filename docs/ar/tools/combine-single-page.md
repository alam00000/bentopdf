# دمج في صفحة واحدة

ادمج كل صفحات PDF في صفحة واحدة طويلة. تُجمَّع الصفحات عموديًا (مثل لفافة) أو أفقيًا (جنبًا إلى جنب) لتنتج صفحة واحدة متصلة في الملف الناتج.

## طريقة العمل

1. ارفع ملف PDF.
2. اختر اتجاه التخطيط: **عمودي** (الصفحات مرصوصة من الأعلى إلى الأسفل) أو **أفقي** (الصفحات جنبًا إلى جنب).
3. حدّد المسافة بين الصفحات بالنقاط.
4. اختر لون خلفية للفراغات بين الصفحات.
5. يمكنك تفعيل الفواصل (خطوط رفيعة بين الصفحات) وضبط سماكتها ولونها.
6. انقر زر المعالجة. الناتج ملف PDF من صفحة واحدة.

## الميزات

- تجميع الصفحات عموديًا أو أفقيًا
- مسافة قابلة للضبط بين الصفحات
- منتقي لون الخلفية لمناطق الفراغ
- خطوط فاصلة اختيارية بسماكة ولون قابلين للتعديل
- يعرض كل صفحة أصلية بدقتها الكاملة على اللوحة المدمجة

## الخيارات

| الخيار                  | الوصف                                 |
| ----------------------- | ------------------------------------- |
| **الاتجاه**             | عمودي (مرصوص) أو أفقي (جنبًا إلى جنب) |
| **المسافة بين الصفحات** | الفراغ بين الصفحات بالنقاط            |
| **لون الخلفية**         | لون المنطقة بين الصفحات               |
| **إضافة فاصل**          | تفعيل خطوط رفيعة بين الصفحات          |
| **سماكة الفاصل**        | سماكة الخط بالنقاط                    |
| **لون الفاصل**          | لون الخطوط الفاصلة                    |

## حالات الاستخدام

- إنشاء صورة واحدة طويلة من هيكل أو تصميم تجريبي متعدد الصفحات
- توليد عرض متصل قابل للتمرير لمستند من أجل تضمينه في الويب
- ربط قصة مصورة أو لوحة قصصية متعددة الصفحات في شريط واحد
- إنتاج عرض بانورامي لصفحات متتابعة للمراجعة

## نصائح

- يناسب الاتجاه العمودي المستندات ذات الصفحات الطولية. أما الأفقي فأفضل للمحتوى ذي الاتجاه العرضي.
- ستنتج المستندات الكبيرة ذات الصفحات الكثيرة ملفًا طويلًا أو عريضًا جدًا. وقد تعجز بعض عارضات PDF عن التعامل مع صفحات مفردة كبيرة للغاية.
- إضافة فواصل بلون متباين تسهّل رؤية أين تنتهي صفحة أصلية وتبدأ التي تليها.

# تدوير بزاوية مخصصة

دوّر صفحات PDF بأي زاوية تريدها، وليس فقط بمضاعفات 90 درجة. لكل صفحة حقل زاوية خاص بها، ويمكنك تطبيق زاوية واحدة على كل الصفحات دفعة واحدة باستخدام عنصر التحكم الدفعي.

## طريقة العمل

1. ارفع ملف PDF. تُعرض صور مصغرة لكل صفحة.
2. لكل صفحة حقل إدخال رقمي يعرض زاوية تدويرها الحالية.
3. اكتب أي قيمة بالدرجات (موجبة أو سالبة) لتدوير صفحة محددة، أو استخدم أزرار اليسار/اليمين لكل صفحة لتعديلات سريعة بمقدار 90 درجة.
4. استخدم حقل **الزاوية الدفعية** في الأعلى لتعيين تدوير موحد لكل الصفحات.
5. انقر على زر المعالجة لإنشاء ملف PDF المدوَّر.

## الميزات

- إدخال حر للدرجات لكل صفحة (أي عدد صحيح)
- عنصر تحكم بزاوية دفعية لتعيين التدوير نفسه على كل صفحة
- معاينة فورية للتدوير في الصور المصغرة
- أزرار تدوير سريع لكل صفحة بمقدار 90 درجة
- تحميل الصور المصغرة عند الحاجة لأداء أفضل في المستندات الكبيرة

## حالات الاستخدام

- تصحيح المسوحات الضوئية المائلة قليلًا بضع درجات
- تدوير الصفحات لتطابق متطلبات اتجاه غير قياسية
- تطبيق تدويرات دقيقة على صفحات فردية في مستند متنوع المحتوى
- ضبط زوايا الصفحات بدقة بعد تدوير جماعي أولي

## نصائح

- القيم الموجبة تدور مع اتجاه عقارب الساعة، والقيم السالبة عكس اتجاه عقارب الساعة.
- يستبدل حقل الزاوية الدفعية كل زوايا الصفحات عند تطبيقه. أجرِ التعديلات الفردية بعد العملية الدفعية عند الحاجة.
- لتدويرات 90/180/270 درجة القياسية بواجهة أبسط، استخدم [تدوير PDF](./rotate-pdf).

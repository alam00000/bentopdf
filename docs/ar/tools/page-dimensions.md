# أبعاد الصفحة

أداة تشخيصية تقرأ كل صفحة في ملف PDF وتعرض أبعادها الدقيقة واتجاهها واسم حجمها القياسي ونسبة أبعادها ومساحتها ودورانها. مفيدة لاكتشاف الصفحات ذات الأحجام المختلفة قبل الطباعة أو لتوثيق خصائص ملف PDF استلمته.

## طريقة العمل

1. ارفع ملف PDF. يبدأ التحليل تلقائيًا، فلا يوجد زر للضغط عليه.
2. تعرض لوحة الملخص إجمالي الصفحات وعدد الأحجام الفريدة وما إذا كان المستند يحتوي على أحجام مختلطة.
3. تصفّح جدول النتائج الكامل مع تفاصيل كل صفحة.
4. بدّل وحدات العرض بين النقاط والبوصات والمليمترات والبكسلات.
5. انقر على **تصدير إلى CSV** لحفظ البيانات.

## الحقول المعروضة

| العمود                  | الوصف                                       |
| ----------------------- | ------------------------------------------- |
| رقم الصفحة              | رقم الصفحة التسلسلي                         |
| الأبعاد                 | العرض × الارتفاع بالوحدة المحددة            |
| الحجم القياسي           | الاسم المطابق (A4 وLetter وغيرها) أو "مخصص" |
| الاتجاه                 | عمودي أو أفقي                               |
| نسبة العرض إلى الارتفاع | نسبة العرض إلى الارتفاع كعدد عشري           |
| المساحة                 | مساحة الصفحة بمربع الوحدة المحددة           |
| Rotation                | دوران الصفحة بالدرجات                       |

## الميزات

- اكتشاف تلقائي لأحجام الورق القياسية (A3 وA4 وA5 وLetter وLegal وTabloid وغيرها)
- تحذير من المستند ذي الأحجام المختلطة مع تفصيل الأحجام الموجودة وعدد الصفحات التي تستخدم كل حجم
- تحويل الوحدات بين النقاط والبوصات والمليمترات والبكسلات (بدقة 96 PPI)
- تصدير CSV للاستخدام في جداول البيانات أو أنظمة التوثيق

## حالات الاستخدام

- التحقق من أن جميع الصفحات بحجم A4 قبل تسليم المستند إلى المطبعة
- تشخيص سبب طباعة ملف PDF مدموج بهوامش غير متوقعة في بعض الصفحات
- توثيق تخطيط صفحات أرشيف PDF كبير لسجلات البيانات الوصفية
- تحديد الصفحات المدارة التي تحتاج إلى تصحيح

## نصائح

- إذا أظهر الملخص "أحجام مختلفة"، فاستخدم أداة توحيد حجم الصفحة لتوحيد الأحجام قبل الطباعة.
- يساعد حقل الدوران على تحديد الصفحات التي تُعرض بشكل صحيح لكن لها خاصية دوران غير صفرية، وقد تسبب مشاكل في بعض سير العمل.

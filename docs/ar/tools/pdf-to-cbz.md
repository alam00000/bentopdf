# PDF إلى CBZ

يحوّل ملف PDF إلى ملف CBZ (Comic Book ZIP)، وهي الصيغة القياسية للكتب المصورة الرقمية والمانغا. تصبح كل صفحة PDF صورة داخل الأرشيف. تنشئ الأداة البيانات الوصفية بثلاث صيغ لأقصى توافق: ComicInfo.xml وmetadata.opf وComicBookInfo JSON.

## طريقة العمل

1. ارفع ملف PDF بالنقر على منطقة الإفلات أو بسحب ملف إليها.
2. اختر صيغة الصورة والجودة والمقياس والبيانات الوصفية الاختيارية.
3. انقر على **تحويل** لإنشاء ملف CBZ.
4. يتم تنزيل ملف `.cbz` تلقائيًا.

## الخيارات

| الخيار                 | القيم           | الافتراضي | الوصف                                                                                |
| ---------------------- | --------------- | --------- | ------------------------------------------------------------------------------------ |
| تنسيق الصورة           | JPEG, PNG, WebP | JPEG      | JPEG للكتب المصورة الملونة، وPNG للمانغا بالأبيض والأسود دون فقدان، وWebP لأفضل ضغط. |
| جودة الصورة            | 50–100%         | 85%       | يتحكم في ضغط JPEG/WebP. مخفي مع PNG (دائمًا دون فقدان).                              |
| المقياس                | 1.0x–4.0x       | 2.0x      | يعطي المقياس الأعلى صورًا أكثر حدة للشاشات عالية الدقة.                              |
| تدرج الرمادي           | تشغيل/إيقاف     | إيقاف     | يحوّل الصفحات إلى تدرج الرمادي. يقلل حجم الملف للمحتوى بالأبيض والأسود.              |
| وضع المانغا            | تشغيل/إيقاف     | إيقاف     | يضبط اتجاه القراءة من اليمين إلى اليسار في البيانات الوصفية.                         |
| تضمين البيانات الوصفية | تشغيل/إيقاف     | تشغيل     | يضمّن ComicInfo.xml وmetadata.opf وComicBookInfo JSON.                               |

## حقول البيانات الوصفية

عند تفعيل البيانات الوصفية، يمكنك تعبئة ما يلي:

- **العنوان**: يُكتشف تلقائيًا من اسم ملف PDF.
- **السلسلة**: اسم السلسلة (مثل "Naruto").
- **الرقم (#)**: رقم العدد داخل السلسلة.
- **المجلد**: رقم المجلد.
- **المؤلف(ون)**: اسم الكاتب أو المبدع.
- **الناشر**: شركة النشر.
- **الوسوم / النوع**: وسوم مفصولة بفواصل (مثل "Action, Adventure").
- **سنة النشر**: سنة النشر (1900–2100).
- **التقييم**: تقييم المجتمع من 0 إلى 5.

## توافق البيانات الوصفية

تكتب الأداة البيانات الوصفية بثلاث صيغ ليتمكن كل قارئ من العثور عليها:

| الصيغة             | الموقع        | مدعومة من                                   |
| ------------------ | ------------- | ------------------------------------------- |
| ComicInfo.xml      | ملف داخل ZIP  | Komga, Kavita, CDisplayEx, Mylar, ComicRack |
| metadata.opf       | ملف داخل ZIP  | Calibre                                     |
| ComicBookInfo JSON | حقل تعليق ZIP | Calibre (احتياطي)                           |

## صيغة الناتج

- `filename.cbz`: أرشيف ZIP يحتوي على صور الصفحات المرقّمة وملفات البيانات الوصفية.

تُسمى صور الصفحات بأرقام مسبوقة بأصفار (`01.jpg` و`02.jpg` وهكذا) لتعرضها القارئات بالترتيب الصحيح.

## حالات الاستخدام

- تحويل ملفات PDF للمانغا أو الكتب المصورة لاستخدامها مع قارئات الكتب المصورة.
- بناء مكتبة كتب مصورة رقمية في Komga أو Kavita أو Calibre.
- تحويل الكتب المصورة الممسوحة ضوئيًا إلى صيغة مناسبة للقارئات.
- مشاركة الكتب المصورة بصيغة تحافظ على اتجاه القراءة والبيانات الوصفية.

## نصائح

- استخدم **JPEG** للكتب المصورة الملونة و**PNG** للمانغا بالأبيض والأسود، فـ PNG يضغط المحتوى بالأبيض والأسود بكفاءة عالية.
- فعّل **تحويل إلى تدرج الرمادي** للمانغا لتقليل حجم الملف بشكل كبير.
- املأ حقلي **السلسلة** و**الرقم (#)** ليتمكن مديرو المكتبات (Komga وCalibre) من تنظيم مجموعتك تلقائيًا.
- يوفر **WebP** أفضل ضغط، لكن قارئات الكتب المصورة الأقدم قد لا تدعمه.

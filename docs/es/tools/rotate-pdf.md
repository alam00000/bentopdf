# Rotar PDF

Rota las páginas de un PDF 90 grados en sentido horario o antihorario. La herramienta muestra miniaturas de todas las páginas y te permite rotarlas individualmente o aplicar una rotación masiva a todo el documento.

## Cómo funciona

1. Sube un archivo PDF. Las miniaturas de todas las páginas se muestran en una cuadrícula.
2. Usa los botones de rotación izquierda/derecha bajo la miniatura de cada página para rotar esa página concreta.
3. Usa los controles de rotación masiva de la parte superior para rotar todas las páginas a la vez.
4. La vista previa de miniaturas se actualiza en tiempo real para mostrar la rotación.
5. Haz clic en el botón de procesar para guardar el PDF rotado.

## Características

- Rotación por página en incrementos de 90 grados (izquierda o derecha)
- Rotación masiva de todas las páginas a la vez
- Vista previa de miniaturas en tiempo real con transiciones de rotación animadas
- Miniaturas de carga diferida para un rendimiento fluido en documentos grandes
- Conserva el contenido y la calidad originales de las páginas

## Casos de uso

- Arreglar páginas escaneadas de lado o boca abajo
- Rotar páginas apaisadas a orientación vertical (o viceversa)
- Corregir un documento de orientación mixta en el que algunas páginas se escanearon con el ángulo equivocado
- Preparar un documento para una orientación de pantalla concreta

## Consejos

- Las rotaciones son acumulativas. Hacer clic dos veces en el botón de sentido horario aplica una rotación de 180 grados.
- Para rotaciones que no sean de 90 grados (por ejemplo, 45 grados para corregir un escaneo ligeramente inclinado), usa en su lugar [Rotar por grados personalizados](./rotate-custom).
- Los controles de rotación masiva afectan a todas las páginas, no solo a las seleccionadas. Esta herramienta no tiene mecanismo de selección: para eso, usa [Multiherramienta PDF](./pdf-multi-tool).

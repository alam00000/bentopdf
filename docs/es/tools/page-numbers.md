# Números de página

Agrega números de página visibles a todas las páginas de tu PDF. Tú eliges la posición, el formato, el tamaño de fuente y el color, y la herramienta se encarga del resto.

## Cómo funciona

1. Sube tu archivo PDF.
2. Configura los ajustes de numeración en el panel de opciones que aparece.
3. Haz clic en **Agregar números de página** para procesar.
4. El PDF numerado se descarga automáticamente.

## Opciones

- **Posición**: elige dónde aparecen los números de página: abajo al centro, abajo a la izquierda, abajo a la derecha, arriba al centro, arriba a la izquierda o arriba a la derecha.
- **Formato**: elige entre numeración simple (1, 2, 3...) o el formato "página X de Y" (1 / 5, 2 / 5...).
- **Tamaño de fuente**: define el tamaño del texto del número de página. Por defecto es 12.
- **Color**: elige cualquier color para el texto del número de página con el selector de color.

## Características

- Seis opciones de posición que cubren todas las esquinas y las posiciones centrales
- Dos formatos de numeración: secuencial simple o "página X de Y"
- Tamaño de fuente personalizable de 6 a 72 puntos
- Selector de color completo para el color del texto
- Manejo automático de márgenes que mantiene los números dentro de zonas seguras sin importar el tamaño de la página

## Casos de uso

- Preparar documentos para imprimir que necesitan referencias de página visibles
- Agregar números de página a un PDF fusionado creado a partir de varios archivos de origen
- Numerar los folletos de una presentación antes de distribuirlos
- Agregar numeración secuencial a documentos legales o contratos

## Consejos

- El formato "página X de Y" es útil para documentos en los que los lectores necesitan saber la extensión total, como propuestas o informes.
- Si necesitas distintos estilos de numeración para diferentes secciones (como números romanos para las páginas preliminares), usa en su lugar la herramienta [Agregar etiquetas de página](./add-page-labels).

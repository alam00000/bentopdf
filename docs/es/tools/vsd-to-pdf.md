# VSD a PDF

Convierte diagramas de Microsoft Visio en PDF sin instalar Visio. Los archivos VSD y VSDX contienen diagramas de flujo, organigramas, diagramas de red y planos que la mayoría de las personas no puede abrir. Esta herramienta los convierte en PDF limpios que se pueden ver en cualquier dispositivo.

## Formatos admitidos

| Formato       | Extensión | Notas                                               |
| :------------ | :-------- | :-------------------------------------------------- |
| Visio binario | `.vsd`    | Formato antiguo de Visio (Visio 2003 y anteriores)  |
| Visio XML     | `.vsdx`   | Formato moderno de Visio (Visio 2013 y posteriores) |

## Cómo funciona

1. Haz clic en el área de carga o arrastra y suelta tus archivos VSD o VSDX. Se pueden mezclar ambos formatos en un mismo lote.
2. Revisa la lista de archivos. Quita las entradas que no quieras con el icono de la papelera o usa **Añadir más archivos** para agregar más diagramas.
3. Haz clic en **Convertir a PDF**. El motor basado en LibreOffice se carga en el navegador y convierte cada diagrama en un PDF, conservando formas, conectores, etiquetas y la disposición de página.
4. Un solo diagrama se descarga directamente como PDF. Varios archivos generan un archivo ZIP llamado `vsd-to-pdf.zip`.

## Opciones

No se requiere ninguna configuración. El conversor respeta el tamaño y la orientación de página originales del documento de Visio.

## Casos de uso

- Revisar diagramas de Visio de un compañero cuando no tienes licencia de Visio
- Incluir diagramas de red o de arquitectura en la documentación de un proyecto como PDF
- Imprimir organigramas o flujos de procesos como material para reuniones
- Archivar archivos VSD antiguos de versiones anteriores de Visio en un formato con futuro

## Consejos

- Los documentos de Visio de varias páginas generan PDF de varias páginas, y cada página de Visio se convierte en una página del PDF.
- Los archivos VSDX (el formato moderno basado en XML) suelen convertirse con mayor fidelidad que los archivos binarios VSD más antiguos.
- El motor de LibreOffice se carga una sola vez por sesión. Espera un momento en la primera conversión; los siguientes archivos serán más rápidos.

# Editar metadatos

Edita los metadatos incrustados en un archivo PDF. La herramienta rellena un formulario con los metadatos existentes del documento, te permite modificar cualquier campo y guarda los cambios en un nuevo PDF.

## Cómo Funciona

1. Sube un archivo PDF. La herramienta lee sus metadatos actuales y rellena el formulario.
2. Edita cualquiera de los campos estándar: Título, Autor, Asunto, Palabras clave, Creador, Productor.
3. Ajusta Fecha de creación y Fecha de modificación con los selectores de fecha y hora.
4. Agrega campos de metadatos personalizados haciendo clic en el botón de agregar e ingresando un par clave-valor.
5. Haz clic en el botón de procesar para guardar el PDF modificado.

## Características

- Rellena todos los metadatos existentes del PDF subido
- Campos estándar: Título, Autor, Asunto, Palabras clave, Creador, Productor
- Selectores de fecha y hora para Fecha de creación y Fecha de modificación
- Campos de metadatos personalizados de clave-valor para propiedades arbitrarias
- Guarda los cambios directamente en el diccionario de información del documento PDF

## Campos Editables

| Campo                     | Descripción                                                   |
| ------------------------- | ------------------------------------------------------------- |
| **Título**                | El título del documento que se muestra en los lectores de PDF |
| **Autor**                 | La persona u organización que creó el documento               |
| **Asunto**                | Una breve descripción del tema del documento                  |
| **Palabras clave**        | Términos separados por comas para búsqueda y categorización   |
| **Creador**               | La aplicación que creó originalmente el contenido             |
| **Productor**             | La aplicación que generó el PDF                               |
| **Fecha de creación**     | Cuándo se creó el documento originalmente                     |
| **Fecha de modificación** | Cuándo se modificó el documento por última vez                |
| **Campos personalizados** | Cualquier par clave-valor adicional que definas               |

## Casos de Uso

- Establecer un título y un autor adecuados antes de publicar un documento
- Agregar palabras clave para mejorar la capacidad de búsqueda en sistemas de gestión documental
- Actualizar la fecha de modificación para reflejar la revisión actual
- Agregar campos de metadatos personalizados como Departamento, ID de proyecto o Clasificación
- Limpiar los metadatos dejados por el software de creación original

## Consejos

- Los campos personalizados se escriben directamente en el diccionario de información del PDF. Algunos lectores de PDF pueden no mostrar los campos personalizados, pero se conservan en el archivo.
- Deja un campo en blanco para borrarlo de los metadatos. El botón de procesar guarda lo que haya en el formulario.
- Para ver los metadatos sin editarlos, usa [Ver Metadatos](./view-metadata). Para eliminar todos los metadatos por completo, usa Eliminar Metadatos.

# Dividir páginas

Corta páginas individuales de un PDF por la mitad, de forma horizontal o vertical. Es útil cuando una sola página contiene contenido que debería separarse en páginas distintas, por ejemplo, un diseño de dos columnas escaneado como una sola página ancha.

## Cómo Funciona

1. Sube un archivo PDF.
2. Selecciona la dirección de la división: **Vertical** (mitades izquierda/derecha) u **Horizontal** (mitades superior/inferior).
3. Opcionalmente, especifica un rango de páginas para limitar cuáles se dividen. Déjalo en blanco para dividir todas las páginas.
4. Haz clic en el botón de procesar para generar el PDF dividido.

## Características

- División vertical: divide cada página en mitades izquierda y derecha
- División horizontal: divide cada página en mitades superior e inferior
- Filtro de rango de páginas para dividir solo páginas específicas
- Las páginas no seleccionadas pasan sin cambios
- Conserva la calidad del contenido sin volver a renderizar

## Casos de Uso

- Separar páginas escaneadas de dos en dos (p. ej., el escaneo de un libro con las páginas izquierda y derecha en una sola hoja)
- Dividir un PDF apaisado con contenido en paralelo en páginas verticales individuales
- Dividir infografías o pósteres altos en secciones superior e inferior separadas
- Preparar documentos de formato ancho para imprimirlos en papel estándar

## Consejos

- Si el contenido de tus páginas no está distribuido de forma uniforme, la división se hace igualmente en el punto medio exacto. Para divisiones asimétricas, considera usar [Recortar PDF](./crop-pdf).
- Combina esta herramienta con [Rotar PDF](./rotate-pdf) si tus páginas necesitan girarse antes o después de dividirlas.

# ODP a PDF

Convierte archivos OpenDocument Presentation en PDF. ODP es el formato nativo de LibreOffice Impress y una exportación estándar de Google Slides. Convertir las presentaciones a PDF permite que cualquiera las vea sin software de presentaciones, y las diapositivas se imprimen con limpieza.

## Formatos compatibles

| Formato                   | Extensión | Notas                                              |
| :------------------------ | :-------- | :------------------------------------------------- |
| OpenDocument Presentation | `.odp`    | LibreOffice Impress / exportación de Google Slides |

## Cómo funciona

1. Haz clic en el área de carga o arrastra y suelta tus archivos ODP. Puedes seleccionar varias presentaciones a la vez.
2. Revisa la lista de archivos. Quita entradas con el icono de papelera, o usa **Agregar Más Archivos** para incluir más presentaciones.
3. Haz clic en **Convertir a PDF**. El motor basado en LibreOffice procesa cada presentación y genera un PDF en el que cada diapositiva es una página.
4. Un solo archivo se descarga como PDF. Varios archivos se entregan en un archivo ZIP llamado `odp-to-pdf.zip`.

## Opciones

No hay ajustes que configurar. Cada diapositiva se renderiza con sus dimensiones originales, conservando el texto, las imágenes, las formas y los fondos.

## Casos de uso

- Distribuir una presentación al público como PDF de material de apoyo
- Compartir exportaciones de Google Slides con personas que prefieren PDF a ODP
- Archivar charlas de congresos y clases en un formato de solo lectura
- Imprimir presentaciones para talleres presenciales

## Consejos

- Las transiciones y animaciones de las diapositivas son funciones puramente visuales que no pasan al PDF, pero todo el contenido estático se renderiza correctamente.
- Las notas del orador no se incluyen en el PDF. Si necesitas las notas, expórtalas por separado desde tu software de presentaciones.
- Como las demás herramientas basadas en LibreOffice, el motor se carga la primera vez que se usa y queda en caché durante la sesión.

# Posterizar PDF

Divide cada página de un PDF en una cuadrícula de subpáginas más pequeñas. Es la herramienta para imprimir una sola página repartida en varias hojas de papel, que luego unes para crear un póster o una pancarta grande.

## Cómo funciona

1. Sube un archivo PDF.
2. Define el número de **filas** y **columnas** de la cuadrícula (por ejemplo, 2 filas x 2 columnas divide cada página en 4 subpáginas).
3. Opcionalmente, indica un rango de páginas para limitar cuáles se posterizan.
4. El lienzo de vista previa muestra una cuadrícula superpuesta sobre la página actual para que visualices los cortes.
5. Navega entre páginas para comprobar la cuadrícula en distintas páginas.
6. Haz clic en el botón de procesar. Cada celda de la cuadrícula se convierte en su propia página del PDF resultante.

## Características

- Número de filas y columnas configurable para cuadrículas flexibles
- Vista previa en vivo con la cuadrícula superpuesta que muestra exactamente dónde se dividirán las páginas
- Filtro de rango de páginas para posterizar solo páginas concretas
- Navegación página por página en la vista previa
- Instantáneas de páginas en caché para navegar rápido por la vista previa
- Las líneas rojas discontinuas de la cuadrícula marcan claramente los límites de corte

## Opciones

| Opción               | Descripción                                        |
| -------------------- | -------------------------------------------------- |
| **Filas**            | Número de divisiones horizontales (por defecto: 1) |
| **Columnas**         | Número de divisiones verticales (por defecto: 1)   |
| **Rango de páginas** | Qué páginas posterizar (vacío = todas las páginas) |

## Casos de uso

- Imprimir un PDF del tamaño de un póster en hojas A4 o Carta estándar para montarlo en una pared
- Crear pancartas grandes a partir de un diseño PDF de una sola página
- Dividir planos técnicos de gran tamaño en teselas imprimibles
- Hacer impresiones de gran formato sin acceso a una impresora de formato ancho

## Consejos

- Una cuadrícula de 2x2 convierte una página en 4 páginas. Una de 3x3 convierte una página en 9. Planifica la cuadrícula según el tamaño que quieras para el resultado montado.
- La cuadrícula de la vista previa te ayuda a comprobar que el contenido importante no caiga sobre una línea de corte. Ajusta filas/columnas si hace falta.
- Para la operación inversa (colocar varias páginas en una sola hoja), usa [N-Up PDF](./n-up-pdf).

# Efecto escáner

Transforma un PDF digital limpio en algo que parezca salido de un escáner de cama plana. La herramienta aplica ruido configurable, una ligera rotación, desenfoque, cambios de brillo y un amarilleado opcional para simular las imperfecciones de un escaneo físico.

## Cómo funciona

1. Sube tu archivo PDF.
2. El editor se abre con una vista previa en vivo de la primera página junto a un panel de ajustes.
3. Ajusta los parámetros del efecto de escaneo con los controles deslizantes y los interruptores.
4. La vista previa se actualiza en tiempo real al cambiar los ajustes.
5. Haz clic en **Aplicar** para procesar todas las páginas y descargar el resultado.

## Opciones

- **Espacio de color (interruptor de escala de grises)**: convierte el resultado a escala de grises para un aspecto clásico de escaneo en blanco y negro.
- **Borde**: añade un borde oscuro sutil alrededor de los bordes de la página para imitar los artefactos de borde del escáner.
- **Rotación**: aplica una ligera rotación (de -5 a +5 grados) para simular una alimentación desalineada del papel.
- **Variación de rotación**: añade una variación aleatoria al ángulo de rotación para que cada página se incline de forma ligeramente distinta.
- **Brillo**: sube o baja el brillo general.
- **Contraste**: ajusta el contraste para simular variaciones en la calidad del tóner.
- **Desenfoque**: aplica un desenfoque gaussiano para suavizar los bordes del texto como en un escaneo de baja calidad.
- **Ruido**: añade ruido aleatorio de píxeles para simular el grano del sensor del escáner. Los valores altos producen resultados más granulados.
- **Amarilleado**: añade un tinte amarillo cálido para simular papel envejecido o reciclado.
- **Resolución**: define los DPI del resultado. Los valores bajos crean una apariencia más pixelada, propia de un escaneo.
- **Restablecer**: devuelve todos los ajustes a sus valores por defecto.

## Características

- Vista previa en tiempo real que se actualiza al modificar cada parámetro
- Variación aleatoria de rotación por página para una variación realista
- Diez parámetros ajustables de forma independiente
- Modo de escala de grises para un resultado auténtico de escaneo en blanco y negro
- Control de resolución, desde calidad de fax de pocos DPI hasta calidad de archivo de muchos DPI

## Casos de uso

- Hacer que documentos creados digitalmente parezcan escaneados e impresos
- Simular el envejecimiento físico de documentos para recrear documentos históricos
- Probar software de OCR con escaneos de calidad degradada
- Producir documentos que coincidan con el estilo visual de archivos escaneados existentes

## Consejos

- Empieza con valores sutiles. Un nivel de ruido de 10-20, una ligera rotación de 0,5 grados y un desenfoque mínimo ya producen un aspecto de escaneo convincente.
- Combina el modo de escala de grises con un ligero amarilleado para lograr un efecto de "fotocopia de una fotocopia".
- Los ajustes de resolución más bajos (100-150 DPI) crean la apariencia más realista de máquina de fax.

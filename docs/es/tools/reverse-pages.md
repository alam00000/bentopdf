# Invertir páginas

Invierte el orden de las páginas de un PDF para que la última página pase a ser la primera, la penúltima la segunda, y así sucesivamente. Admite el procesamiento por lotes de varios archivos a la vez.

## Cómo funciona

1. Sube uno o más archivos PDF.
2. Haz clic en el botón de procesar.
3. Cada archivo se invierte de forma independiente. Si subiste varios archivos, el resultado es un archivo ZIP con todos los PDF invertidos.
4. Un solo archivo se descarga directamente como PDF invertido.

## Características

- Procesamiento por lotes: invierte varios PDF en una sola operación
- Salida de un solo archivo para un PDF, ZIP para varios
- Botones para quitar cada archivo antes de procesar
- Conserva todo el contenido y el formato de las páginas

## Casos de uso

- Arreglar un documento que se escaneó en orden inverso
- Preparar un PDF de presentación para leerlo de atrás hacia delante
- Invertir el orden de las páginas para flujos de impresión que alimentan las páginas al revés
- Corregir un documento cuyas páginas se ensamblaron por error al revés

## Consejos

- Cada archivo de un lote se invierte de forma independiente: los archivos en sí no se reordenan entre ellos.
- Para reordenar páginas con más control (no solo una inversión completa), usa [Duplicar y organizar](./organize-pdf).

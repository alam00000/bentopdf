# Extraer páginas

Saca un conjunto de páginas de un PDF y guárdalas como un archivo nuevo. Indica exactamente qué páginas quieres con la sintaxis de rangos, y la herramienta crea un PDF limpio que contiene solo esas páginas.

## Cómo Funciona

1. Sube un archivo PDF. La herramienta muestra el nombre del archivo, su tamaño y el total de páginas.
2. Ingresa las páginas que quieres extraer con la sintaxis de rangos (p. ej., `1-5`, `3, 7, 10-12`).
3. Opcionalmente, elige descargar cada rango como un PDF separado dentro de un archivo ZIP.
4. Haz clic en el botón de procesar. Las páginas extraídas se descargan como un nuevo PDF (o ZIP).

## Características

- Sintaxis flexible de rangos de páginas: páginas individuales, rangos o combinaciones separadas por comas
- Muestra el total de páginas después de la carga para consultarlo fácilmente
- Opción de generar un único PDF combinado o archivos separados en un ZIP
- Conserva el contenido y el formato originales de las páginas

## Casos de Uso

- Sacar el resumen ejecutivo (las primeras páginas) de un informe extenso
- Extraer un solo capítulo del PDF de un libro de texto
- Guardar páginas específicas de un paquete de formularios como documentos independientes
- Crear un documento de muestra con páginas seleccionadas de un archivo más grande

## Consejos

- Los números de página empiezan en 1. Usa `1` para la primera página, no `0`.
- Para quitar páginas en lugar de extraerlas, usa [Eliminar Páginas](./delete-pages), que es la operación inversa.
- Si necesitas selección visual de páginas con miniaturas, usa [Dividir PDF](./split-pdf) en el modo Visual Select.

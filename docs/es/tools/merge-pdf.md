# Fusionar PDF

Combina varios archivos PDF en un solo documento. Puedes unir archivos completos en un orden concreto, o cambiar al Modo página para controlar con precisión cada página de todos los PDF subidos.

## Cómo funciona

1. Sube dos o más archivos PDF haciendo clic en la zona de carga o arrastrándolos.
2. Elige entre **Modo archivo** y **Modo página** con el interruptor de la parte superior.
3. En Modo archivo, arrastra los archivos para reordenarlos y, si quieres, indica rangos de páginas (por ejemplo, `1-3, 5`) para cada archivo. Deja el rango en blanco para incluir todas las páginas.
4. En Modo página, arrastra y suelta las miniaturas de cada página para construir tu secuencia exacta.
5. Haz clic en **Fusionar PDF** para combinarlo todo en un solo archivo. El PDF combinado se descarga automáticamente.

## Características

- Dos modos de combinación: Modo archivo para unir archivos completos rápidamente y Modo página para controlar cada página
- Reordenación por arrastrar y soltar en ambos modos, con animaciones fluidas
- La sintaxis de rangos de páginas (por ejemplo, `1-3, 5, 8-10`) permite elegir páginas sin cambiar a Modo página
- Las miniaturas de página se cargan bajo demanda para que la interfaz siga respondiendo incluso con documentos grandes
- Sin límite en el número de archivos ni en el total de páginas
- Conserva la calidad original del PDF, sin recodificar

## Opciones

| Opción            | Descripción                                                                                                               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Modo archivo**  | Combina archivos completos en un orden personalizado, con filtros opcionales de rango de páginas por archivo              |
| **Modo página**   | Cuadrícula visual con todas las páginas de todos los archivos: arrastra las miniaturas para construir tu secuencia exacta |
| **Campo Páginas** | Campo de texto por archivo que acepta rangos como `1-3, 5` para incluir solo páginas concretas                            |

## Casos de uso

- Combinar PDF de capítulos sueltos en un único libro o informe
- Unir una carta de presentación y un currículum en un solo documento de candidatura
- Reunir páginas concretas de varios documentos de origen en un archivo consolidado
- Reunir recibos o facturas escaneados en un único PDF de archivo
- Crear un material de apoyo para una presentación a partir de diapositivas de varias presentaciones

## Consejos

- Usa Modo página cuando necesites intercalar páginas de distintos archivos en lugar de añadir un archivo detrás de otro.
- Puedes añadir más archivos después de la carga inicial con el botón **Agregar Más Archivos** sin perder tu organización actual.
- Los rangos de páginas empiezan a contar en 1, así que `1` se refiere a la primera página de ese archivo.

# Combinar en una sola página

Fusiona todas las páginas de un PDF en una única página larga. Las páginas se unen verticalmente (como un pergamino) u horizontalmente (una al lado de otra), y el resultado es una página continua.

## Cómo Funciona

1. Sube un archivo PDF.
2. Selecciona la dirección del diseño: **Vertical** (páginas apiladas de arriba abajo) u **Horizontal** (páginas colocadas una al lado de otra).
3. Define el espacio entre páginas en puntos.
4. Elige un color de fondo para los espacios entre páginas.
5. Opcionalmente, activa los separadores (líneas finas entre páginas) y configura su grosor y color.
6. Haz clic en el botón de procesar. El resultado es un PDF de una sola página.

## Características

- Unión de páginas vertical u horizontal
- Espaciado configurable entre páginas
- Selector de color de fondo para las áreas de separación
- Líneas separadoras opcionales con grosor y color ajustables
- Renderiza cada página original a resolución completa sobre el lienzo combinado

## Opciones

| Opción                        | Descripción                                            |
| ----------------------------- | ------------------------------------------------------ |
| **Dirección del diseño**      | Vertical (apiladas) u Horizontal (una al lado de otra) |
| **Espaciado**                 | Espacio entre páginas en puntos                        |
| **Color de fondo**            | Color del área entre páginas                           |
| **Añadir líneas separadoras** | Activa líneas finas entre páginas                      |
| **Grosor del separador**      | Grosor de la línea en puntos                           |
| **Color del separador**       | Color de las líneas separadoras                        |

## Casos de Uso

- Crear una sola imagen larga a partir de un wireframe o maqueta de diseño de varias páginas
- Generar una vista continua con desplazamiento de un documento para incrustarlo en la web
- Unir un cómic o storyboard de varias páginas en una sola tira
- Producir una vista panorámica de páginas secuenciales para su revisión

## Consejos

- La orientación vertical funciona mejor con documentos de páginas verticales. La horizontal es mejor para contenido apaisado.
- Los documentos grandes con muchas páginas producirán un resultado muy alto o muy ancho. Algunos visores de PDF pueden tener dificultades con páginas únicas extremadamente grandes.
- Agregar separadores con un color contrastante facilita ver dónde termina una página original y empieza la siguiente.

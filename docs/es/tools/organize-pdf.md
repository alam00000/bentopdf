# Duplicar y Organizar

Reorganiza, duplica y elimina páginas de un PDF con una interfaz visual de arrastrar y soltar. Cada página aparece como una miniatura que puedes mover, clonar o eliminar antes de guardar el resultado como un archivo nuevo.

## Cómo funciona

1. Sube un único archivo PDF.
2. La herramienta muestra una cuadrícula de miniaturas con todas las páginas.
3. Arrastra las miniaturas para reordenar las páginas, haz clic en el botón verde de duplicar para clonar una página o en el botón rojo de eliminar para quitarla.
4. También puedes escribir un orden de páginas personalizado en el campo de texto (p. ej., `3, 1, 2, 4`) y hacer clic en **Aplicar** para reorganizar todas las páginas de una vez.
5. Haz clic en el botón de procesar para crear y descargar el PDF reorganizado.

## Características

- Reordenación de páginas con arrastrar y soltar y transiciones animadas
- Botones de duplicar y eliminar en cada página
- Campo de orden de páginas personalizado para una reorganización precisa
- Etiquetas con el número de página que se actualizan automáticamente tras cada cambio
- Impide eliminar la última página restante

## Casos de uso

- Mover una página mal colocada a su posición correcta en un informe
- Duplicar una página de formulario para tener varias copias en blanco en un solo archivo
- Quitar páginas de borrador o de relleno antes de distribuir un documento
- Invertir o mezclar el orden de las páginas para preparar la impresión
- Crear una secuencia de páginas personalizada sin volver a fusionar archivos separados

## Consejos

- El campo de orden de páginas personalizado espera números de página originales separados por comas. Debe incluir cada página exactamente una vez, sin omisiones ni duplicados.
- Después de duplicar una página, ambas copias hacen referencia al mismo índice de página original. Reordenar cualquiera de las copias funciona de forma independiente.
- Para operaciones masivas con varios archivos o flujos de trabajo más avanzados, considera usar en su lugar la [Multiherramienta PDF](./pdf-multi-tool).

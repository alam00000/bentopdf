# Comparar PDFs

Sube dos PDFs y ve exactamente qué cambió entre ellos. La herramienta empareja las páginas de forma inteligente, detecta diferencias en texto, imágenes, anotaciones, encabezados y formato, y las presenta en una vista lado a lado o superpuesta.

## Cómo Funciona

1. Sube dos archivos PDF: el original (izquierda) y la versión revisada (derecha).
2. La herramienta empareja las páginas de ambos documentos usando firmas de contenido.
3. Selecciona un modo de vista: **Lado a lado** u **Superponer**.
4. Navega entre los pares de páginas con los controles de paginación.
5. Las diferencias se resaltan y se categorizan. Usa el panel de filtros para centrarte en tipos de cambio específicos.
6. Opcionalmente, exporta la comparación como informe en PDF.

## Características

- Emparejamiento automático de páginas según la similitud del contenido
- Vistas de comparación lado a lado y superpuesta
- Categorización de cambios: texto, imagen, encabezado/pie de página, anotación, formato, fondo
- Filtros por categoría para mostrar u ocultar tipos de cambio específicos
- Búsqueda de cambios de texto con filtrado por consulta
- Compatibilidad con OCR para comparar documentos escaneados
- Controles de zoom para una inspección detallada
- Desplazamiento sincronizado entre paneles en la vista lado a lado
- Exporta los resultados de la comparación como PDF

## Opciones

| Opción                     | Descripción                                                                                                  |
| -------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Modo de vista**          | Lado a lado o Superponer                                                                                     |
| **OCR**                    | Activa o desactiva el OCR para comparar documentos escaneados                                                |
| **Idioma del OCR**         | Idioma para la extracción de texto con OCR                                                                   |
| **Filtros de categoría**   | Alterna la visibilidad de los cambios de texto, imagen, encabezado/pie de página, anotación, formato y fondo |
| **Alcance de los cambios** | En el modo superposición, filtra entre todos los cambios o solo el contenido                                 |
| **Zoom**                   | Ajusta el nivel de aumento para una inspección detallada                                                     |

## Casos de Uso

- Revisar las revisiones de un contrato para encontrar exactamente qué cambió entre versiones
- Comparar maquetas de diseño para verificar que las exportaciones a PDF coincidan con lo esperado
- Auditar cambios en documentos en industrias reguladas donde cada edición debe registrarse
- Verificar que un proceso de conversión de PDF conservó con exactitud el contenido original
- Revisar documentos traducidos frente al original para detectar cambios de diseño

## Consejos

- La vista superpuesta apila ambos documentos uno sobre otro, haciendo visibles al instante las diferencias espaciales (elementos desplazados, imágenes redimensionadas).
- Activa el OCR al comparar documentos escaneados que no tienen capa de texto. El motor de comparación extraerá el texto de las imágenes de las páginas.
- Usa los filtros por categoría para centrarte en lo importante. Por ejemplo, oculta los cambios de formato cuando solo te interesan las diferencias de contenido de texto.

# Color de fondo

Establece un color de fondo sólido detrás de todo el contenido existente de tu PDF. La herramienta crea un rectángulo de color en cada página y coloca el contenido original encima, de modo que el texto, las imágenes y los gráficos siguen siendo totalmente visibles sobre el nuevo fondo.

## Cómo funciona

1. Sube tu archivo PDF.
2. Elige un color de fondo con el selector de color. El valor por defecto es un amarillo claro (#FFFFCC).
3. Haz clic en **Cambiar Color de Fondo** para procesar.
4. El PDF actualizado se descarga automáticamente.

## Opciones

- **Color de Fondo**: un selector de color estándar para elegir cualquier color sólido. Por defecto es amarillo claro.

## Características

- Aplica un color de fondo uniforme a todas las páginas
- Conserva todo el contenido original (texto, imágenes, gráficos vectoriales) sobre la capa de color
- Mantiene las dimensiones originales de la página
- Funciona con documentos de cualquier número de páginas

## Casos de uso

- Añadir un fondo crema o marfil claro para dar a los documentos un aspecto más suave, parecido al papel
- Clasificar por colores conjuntos de documentos aplicando distintos colores de fondo a distintas categorías
- Crear versiones visualmente distintas del mismo documento para diferentes públicos
- Añadir un tinte de fondo claro para mejorar la legibilidad al proyectar documentos en pantalla

## Consejos

- Los colores claros y suaves funcionan mejor. Un fondo muy oscuro puede dificultar la lectura del texto, a menos que este ya sea de color claro.
- Si quieres cambiar tanto el color de fondo como el del texto, aplica primero el color de fondo y luego usa [Cambiar Color de Texto](./text-color) sobre el resultado.
- Esta herramienta trabaja a nivel estructural del PDF (sin rasterizar), por lo que el texto sigue siendo seleccionable y se puede buscar en el resultado.

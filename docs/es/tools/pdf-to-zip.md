# PDFs a ZIP

Agrupa varios archivos PDF en un único archivo ZIP. Es una herramienta de empaquetado sencilla: no convierte, comprime ni modifica los PDF.

## Cómo funciona

1. Sube varios archivos PDF con la zona de carga.
2. Revisa la lista de archivos. Quita los que no quieras incluir.
3. Haz clic en el botón de procesar.
4. Un archivo ZIP con todos los PDF subidos se descarga de inmediato.

## Características

- Acepta cualquier cantidad de archivos PDF
- Permite quitar archivos individuales antes de crear el archivo comprimido
- Conserva los nombres de archivo originales dentro del ZIP
- No modifica el contenido de los PDF: los archivos se empaquetan tal cual
- Muestra el nombre y el tamaño de cada PDF subido

## Casos de uso

- Agrupar un conjunto de facturas o recibos para adjuntarlos a un correo
- Empaquetar entregables de un proyecto (varios informes en PDF) para su entrega
- Crear una única descarga para una colección de formularios o plantillas
- Archivar un lote de documentos en un solo archivo comprimido

## Consejos

- El archivo ZIP usa los nombres de archivo originales de los PDF. Si tienes archivos con el mismo nombre, renómbralos antes de subirlos para evitar conflictos.
- Esta herramienta no comprime los PDF en sí. Para reducir el tamaño, pásalos primero por Comprimir PDF y luego empaquétalos con esta herramienta.

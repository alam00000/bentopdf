# Markdown a PDF

Un editor de Markdown completo con vista previa en vivo y exportación a PDF con un clic. Escribe desde cero, sube un archivo `.md` existente o pega contenido del portapapeles. El editor renderiza tu Markdown en tiempo real y exporta un PDF con estilo usando el motor de impresión integrado del navegador.

## Formatos compatibles

| Entrada         | Descripción                 |
| :-------------- | :-------------------------- |
| Archivos `.md`  | Súbelos con el botón Upload |
| Entrada directa | Escribe o pega en el editor |

## Cómo funciona

1. Abre la herramienta Markdown a PDF. El editor se carga con vista dividida: el código Markdown a la izquierda y la vista previa renderizada a la derecha.
2. Escribe tu Markdown, pégalo o haz clic en **Cargar** para cargar un archivo `.md`.
3. Alterna entre los temas claro y oscuro con el control deslizante de tema de la barra de herramientas.
4. Haz clic en **Exportar PDF** (o pulsa `Ctrl/Cmd + S`) para generar un PDF mediante el cuadro de impresión del navegador.

## Características

El editor admite un amplio conjunto de funciones de Markdown más allá de lo básico:

- **Markdown estándar**: encabezados, negrita, cursiva, enlaces, imágenes, listas, citas, líneas horizontales
- **Bloques de código** con resaltado de sintaxis para más de 15 lenguajes (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash y más)
- **Diagramas Mermaid**: los diagramas de flujo, de secuencia, ER y otros tipos de gráficos Mermaid se renderizan directamente en la vista previa
- **Tablas** con la sintaxis de tablas estándar de Markdown
- **Listas de tareas** con casillas
- **Notas al pie**, **subíndices**, **superíndices**
- **Listas de definiciones**, **abreviaturas**
- Compatibilidad con **emoji** (`:smile:` se muestra como el emoji)
- **Resaltados** (`==marked text==`) e **inserciones** (`++inserted text++`)
- **URL con enlace automático**: las URL sin formato se convierten en enlaces en los que se puede hacer clic
- Generación de **tabla de contenido**
- **Enlaces ancla** en los encabezados

## Casos de uso

- Escribir documentación de proyectos y exportar un PDF cuidado para las partes interesadas
- Crear informes técnicos con ejemplos de código y diagramas de arquitectura Mermaid
- Convertir un README de GitHub en un PDF para usarlo sin conexión o imprimirlo
- Redactar una propuesta o una especificación con listas de tareas y tablas
- Generar un material de apoyo con estilo a partir de apuntes de clase escritos en Markdown

## Consejos

- El PDF resultante usa la función de imprimir a PDF del navegador. En Chrome, puedes personalizar los márgenes y la escala en el cuadro de impresión antes de guardar.
- Los diagramas Mermaid se renderizan en la vista previa, pero pueden tardar un momento en inicializarse la primera vez.
- Usa `Ctrl/Cmd + S` como atajo de teclado para exportar sin tener que buscar el botón.

# Editar adjuntos

Inspecciona y administra los archivos adjuntos dentro de un PDF. La herramienta lista cada archivo incrustado con su nombre y su nivel de adjunto, y te permite marcar adjuntos individuales para eliminarlos o quitarlos todos a la vez.

## Cómo Funciona

1. Sube un archivo PDF.
2. La herramienta busca automáticamente los adjuntos y los muestra en una lista.
3. Cada adjunto muestra su nombre de archivo y si es un adjunto a nivel de documento o de página.
4. Haz clic en el icono de la papelera junto a un adjunto para marcarlo para eliminarlo (haz clic de nuevo para desmarcarlo).
5. Usa el botón **Quitar todos los adjuntos** para seleccionar todo a la vez, o **Deseleccionar todo** para borrar tus selecciones.
6. Haz clic en el botón de procesar para guardar un nuevo PDF sin los adjuntos seleccionados.

## Características

- Lista todos los adjuntos a nivel de documento y de página
- Eliminación individual o masiva de adjuntos
- Activa y desactiva la selección antes de confirmar los cambios
- Texto tachado y cambio de opacidad en los elementos marcados para eliminar
- Descarga el PDF modificado sin los adjuntos seleccionados

## Casos de Uso

- Quitar archivos obsoletos o incorrectos incrustados en un documento antes de redistribuirlo
- Eliminar adjuntos sensibles (datos financieros, información personal) de un PDF antes de compartirlo
- Reducir el tamaño de un PDF quitando archivos incrustados grandes que ya no se necesitan
- Auditar el contenido incrustado y limpiar un documento antes de archivarlo

## Consejos

- Los adjuntos marcados para eliminar se muestran tachados. Puedes volver a activarlos antes de procesar si cambias de opinión.
- Si no se encuentran adjuntos, la herramienta muestra un mensaje claro de "No se encontraron adjuntos": el PDF simplemente no contiene archivos incrustados.

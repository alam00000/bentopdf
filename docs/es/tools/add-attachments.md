# Agregar adjuntos

Incrusta uno o varios archivos directamente dentro de un documento PDF. Los adjuntos pueden añadirse a nivel de documento (visibles en el panel de adjuntos de cualquier lector de PDF) o vincularse a páginas concretas.

## Cómo funciona

1. Sube el PDF al que quieres adjuntar archivos.
2. Usa la zona de carga de adjuntos para seleccionar los archivos que quieres incrustar (de cualquier tipo).
3. Elige el nivel del adjunto: **Documento** (predeterminado) o **Página**.
4. Si eliges el nivel de página, introduce un rango de páginas (por ejemplo, `1-3` o `5`).
5. Haz clic en el botón de procesar. El PDF modificado se descarga con tus archivos incrustados.

## Características

- Adjunta cualquier tipo de archivo: imágenes, hojas de cálculo, archivos comprimidos, ejecutables, lo que sea
- Colocación de adjuntos a nivel de documento o de página
- Se pueden adjuntar varios archivos en una sola operación
- Muestra los nombres y tamaños de todos los adjuntos seleccionados
- El resultado conserva el contenido original del PDF con los archivos incrustados añadidos

## Opciones

| Opción                 | Descripción                                                                      |
| ---------------------- | -------------------------------------------------------------------------------- |
| **Nivel de documento** | Adjunta los archivos al PDF completo, accesibles desde el panel de adjuntos      |
| **Nivel de página**    | Adjunta los archivos a páginas concretas, indicadas mediante un rango de páginas |

## Casos de uso

- Incluir datos de origen (archivos de Excel, CSV) junto con un informe en PDF
- Adjuntar los archivos de imagen originales a un PDF de portafolio fotográfico
- Incrustar documentos de respaldo dentro de un contrato o una propuesta
- Añadir material complementario a páginas específicas de un manual de formación

## Consejos

- Los adjuntos a nivel de documento son los más compatibles entre lectores de PDF. Es posible que los adjuntos a nivel de página no se vean en todos los visores.
- No hay límite de tamaño para los adjuntos, pero los archivos incrustados muy grandes aumentarán el tamaño del PDF de forma proporcional.

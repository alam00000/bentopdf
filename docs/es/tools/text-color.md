# Cambiar color de texto

Sustituye el color del texto en todo tu PDF. La herramienta identifica las regiones de texto de cada página y las vuelve a colorear con el color elegido, conservando el diseño del documento y el contenido que no es texto.

## Cómo funciona

1. Sube tu archivo PDF.
2. Elige un nuevo color de texto con el selector de color. El valor por defecto es azul (#0000FF).
3. Haz clic en **Cambiar color de texto** para procesar.
4. El PDF recoloreado se descarga automáticamente. Un indicador de progreso muestra qué página se está procesando.

## Opciones

- **Nuevo color de texto**: un selector de color para elegir el color de reemplazo de todo el texto del documento.

## Características

- Recolorea el texto de todas las páginas del documento
- Procesamiento por página con indicador de progreso
- Selector de color con compatibilidad completa con colores hexadecimales
- Conserva el diseño de página y los elementos que no son texto

## Casos de uso

- Cambiar el texto negro por azul oscuro para lograr un documento más suave y moderno
- Recolorear el texto para ajustarlo a las guías de marca antes de distribuir documentos
- Convertir el texto a un color específico para cumplir con la accesibilidad
- Hacer visible el texto sobre un color de fondo recién aplicado

## Consejos

- Esta herramienta renderiza las páginas al doble de escala para mantener la calidad y después reconstruye el PDF. El resultado se basa en imágenes, por lo que el texto ya no se podrá seleccionar ni buscar.
- Si necesitas conservar el texto seleccionable, considera editar el PDF directamente con el [Editor de PDF](./edit-pdf).
- El tiempo de procesamiento aumenta con el número de páginas, ya que cada página se renderiza por separado.

# N-Up PDF

Coloca varias páginas en una sola hoja con una disposición en cuadrícula. Así se reduce el número de páginas impresas al ajustar 2, 4, 6, 8, 9 o 16 páginas por hoja. La herramienta se encarga del escalado, el posicionamiento y la configuración opcional del tamaño de página.

## Cómo funciona

1. Sube un archivo PDF.
2. Selecciona el número de páginas por hoja (el valor "N"): 2, 4, 6, 8, 9 o 16.
3. Elige el tamaño de página de salida (A4 por defecto) y la orientación.
4. Opcionalmente, configura el espaciado, el color del borde y el color de fondo.
5. Haz clic en el botón de procesar. La herramienta escala cada página y las distribuye en hojas nuevas.

## Características

- Disposiciones en cuadrícula: 2, 4, 6, 8, 9 y 16 páginas por hoja
- Tamaño de página de salida y orientación configurables
- Espaciado opcional entre las páginas
- Ajustes de color de fondo y de borde
- Mantiene la proporción de las páginas originales al escalarlas para que quepan

## Opciones

| Opción                         | Descripción                                                                         |
| ------------------------------ | ----------------------------------------------------------------------------------- |
| **Páginas por hoja**           | Número de páginas originales que caben en cada página de salida (2, 4, 6, 8, 9, 16) |
| **Tamaño de página de salida** | Tamaño de la hoja de salida (A4, Letter, Legal, etc.)                               |
| **Orientación**                | Portrait o Landscape para la hoja de salida                                         |
| **Espaciado**                  | Separación en puntos entre las páginas                                              |
| **Color de fondo**             | Color de relleno del fondo de la hoja de salida                                     |
| **Color del borde**            | Color de los bordes alrededor de cada página                                        |

## Casos de uso

- Imprimir material de apoyo con 4 diapositivas por página para ahorrar papel
- Crear hojas de estudio con varias páginas de referencia en una sola hoja
- Producir archivos de documentos compactos para su archivo
- Generar hojas de miniaturas con una vista general de un documento largo

## Consejos

- La orientación horizontal suele funcionar mejor para las disposiciones de 2 páginas, mientras que la vertical suele ser la mejor para 4 o más.
- Aumentar el espaciado mejora la legibilidad, pero reduce el área disponible para cada página.
- Para la operación inversa (dividir una página en varias), consulta [Posterizar PDF](./posterize-pdf).

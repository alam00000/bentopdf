# Imágenes a PDF

El conversor universal de imágenes a PDF. Sube imágenes en prácticamente cualquier formato y combínalas en un único documento PDF. Cada imagen ocupa su propia página, con el tamaño de las dimensiones originales.

## Formatos compatibles

| Formato         | Extensiones                            |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

Es la compatibilidad de formatos más amplia de todos los conversores de imágenes de BentoPDF. Si solo necesitas un formato concreto, usa en su lugar una de las herramientas dedicadas.

## Cómo funciona

1. Haz clic en el área de carga o arrastra y suelta tus archivos de imagen. Puedes seleccionar varios a la vez.
2. Revisa la lista de archivos. Quita los que no quieras con el icono de papelera, o haz clic en **Agregar Más Archivos** para incluir más imágenes.
3. Elige un nivel de **Calidad del PDF** en el menú desplegable.
4. Haz clic en **Convertir a PDF**. La herramienta procesa las imágenes con el motor PyMuPDF y descarga el resultado como `images_to_pdf.pdf`.

## Opciones

**Calidad del PDF** controla la compresión que se aplica al incrustar las imágenes en el PDF:

- **Calidad alta**: compresión mínima, mayor tamaño de archivo. Ideal para impresión o archivo.
- **Calidad media** (predeterminado): compresión equilibrada. Buena para la mayoría de los usos.
- **Calidad baja**: compresión agresiva, el menor tamaño de archivo. Adecuada para correo electrónico o para compartir rápido.

Los archivos HEIC y WebP se convierten automáticamente a PNG antes de incrustarse. Esto ocurre de forma transparente y no requiere pasos adicionales.

## Casos de uso

- Combinar en un solo PDF recibos o documentos escaneados con la cámara del móvil
- Crear un portafolio de fotos o un lookbook a partir de imágenes en distintos formatos
- Convertir fotos de iPhone (HEIC) en un PDF para compartir, sin instalar software de escritorio
- Reunir maquetas de diseño a partir de exportaciones PSD y capturas de pantalla en un entregable para el cliente
- Archivar una carpeta de formatos de imagen antiguos (PNM, JXR, JP2) como un único PDF

## Consejos

- El orden de las imágenes en el PDF coincide con el orden de la lista de archivos. Súbelas en la secuencia que quieras.
- Para obtener el menor tamaño de archivo posible, elige Calidad baja. La diferencia visual suele ser insignificante en escaneos con mucho texto.
- Si solo tienes un formato de imagen, los conversores dedicados (JPG a PDF, PNG a PDF, etc.) ofrecen el mismo resultado con una interfaz más sencilla.

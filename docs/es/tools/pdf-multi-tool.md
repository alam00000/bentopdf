# Multiherramienta PDF

Un espacio de trabajo unificado para cualquier operación a nivel de página en PDF. Sube uno o más PDF y trabaja con todas sus páginas en una única cuadrícula visual. Rota, reordena, duplica, elimina, inserta PDF, imágenes y páginas en blanco, renumera, cambia el tamaño y divide el resultado, todo sin salir de la herramienta.

## Cómo funciona

1. Haz clic en **Seleccionar Archivos** o arrastra archivos al área de carga. Se admiten varios archivos, que se combinan en el orden en que se suben.
2. Todas las páginas aparecen en una cuadrícula desplazable con miniaturas.
3. Haz clic en una página para seleccionarla. Usa Shift-clic para seleccionar un rango y Cmd/Ctrl-clic para añadir o quitar páginas sueltas de la selección.
4. Usa la barra de herramientas del organizador o haz clic derecho en una página para ver las acciones de página.
5. Haz clic en **Exportar PDF** para descargar el resultado final.

## Características

- **Fusionar**: sube varios PDF e imágenes y se combinan automáticamente en un solo documento
- **Reordenar**: arrastra y suelta páginas para cambiar la secuencia o invierte el orden de todo el documento
- **Rotar**: rota las páginas seleccionadas a la izquierda o a la derecha en pasos de 90 grados
- **Duplicar**: copia las páginas seleccionadas y coloca las copias justo después de ellas
- **Eliminar**: quita las páginas seleccionadas
- **Insertar**: añade páginas de otro PDF o de una imagen, una página en blanco, páginas del portapapeles, o intercala las páginas de un segundo PDF con las actuales
- **Reemplazar**: sustituye una página por la primera página de otro PDF
- **Cortar, copiar y pegar**: mueve o copia páginas dentro del documento
- **Extraer**: descarga las páginas seleccionadas como PDF o como imágenes
- **Números de página**: define etiquetas de página como i, ii, iii o A-1, A-2 para un rango de páginas
- **Tamaño de página**: ajusta las páginas a un tamaño de papel estándar o a un tamaño personalizado
- **Dividir**: divide el documento por rangos de páginas, páginas impares y pares, cada página, marcadores, cada N páginas o tamaño de archivo
- **Deshacer / Rehacer**: todas las operaciones de página se pueden deshacer y rehacer
- Repara automáticamente los PDF dañados antes de cargarlos

## Atajos de teclado

| Acción                         | Atajo                         |
| ------------------------------ | ----------------------------- |
| Rotar a la derecha / izquierda | R / Shift+R                   |
| Seleccionar todo               | Cmd/Ctrl+A                    |
| Cortar, copiar, pegar          | Cmd/Ctrl+X, C, V              |
| Duplicar                       | Cmd/Ctrl+D                    |
| Eliminar                       | Supr o Retroceso              |
| Deshacer / Rehacer             | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| Mover la selección             | Teclas de flecha, Home, End   |

## Casos de uso

- Crear un documento personalizado con páginas de varios PDF de origen
- Limpiar un documento escaneado eliminando páginas en blanco, rotando escaneos de lado y reordenando secciones
- Dividir un PDF grande por capítulos usando sus marcadores
- Edición rápida a nivel de página sin necesidad de un editor de PDF completo

## Consejos

- El historial de deshacer y rehacer registra cada operación de página. Úsalo con libertad: no puedes perder tu trabajo por accidente.
- Usa **Insert > From File** o suelta más PDF o imágenes sobre la cuadrícula de páginas en cualquier momento para añadirlos al documento.
- Para tareas sencillas de fusión o división, las herramientas dedicadas [Fusionar PDF](./merge-pdf) o [Dividir PDF](./split-pdf) pueden ser más rápidas. La Multiherramienta destaca cuando necesitas varias operaciones en una sola sesión.

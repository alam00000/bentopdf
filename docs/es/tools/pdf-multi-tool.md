# Multiherramienta PDF

Un espacio de trabajo unificado para cualquier operación a nivel de página en PDF. Sube uno o más PDF y trabaja con todas sus páginas en una única cuadrícula visual. Rota, reordena, duplica, elimina, inserta nuevos PDF, agrega páginas en blanco y divide el resultado, todo sin salir de la herramienta.

## Cómo funciona

1. Haz clic en **Subir PDFs** o arrastra archivos al área de carga. Se admiten varios archivos.
2. Todas las páginas de cada archivo subido aparecen en una cuadrícula desplazable con miniaturas.
3. Usa la barra de herramientas o los botones de acción de cada página para manipular las páginas.
4. Selecciona páginas con la casilla de cada tarjeta y luego aplica operaciones masivas.
5. Marca puntos de división con el icono de tijeras para dividir la salida en archivos separados.
6. Haz clic en **Exportar PDF** para descargar el resultado final. Si hay marcadores de división, la salida es un ZIP con varios PDF.

## Características

- **Fusionar**: sube varios PDF y se combinan automáticamente en un solo espacio de trabajo
- **Reordenar**: arrastra y suelta las tarjetas de página para cambiar la secuencia
- **Rotar**: rotación por página o masiva en incrementos de 90 grados (izquierda o derecha)
- **Duplicar**: clona cualquier página con un clic
- **Eliminar**: quita páginas individuales o elimina en bloque las seleccionadas
- **Insertar PDF**: agrega un nuevo PDF después de cualquier página concreta
- **Agregar página en blanco**: añade una página A4 en blanco al final
- **Dividir**: coloca marcadores de división entre páginas y luego exporta un ZIP de PDF separados
- **Seleccionar todo / Deseleccionar todo**: selección rápida para operaciones masivas
- **Deshacer / Rehacer**: historial completo de deshacer y rehacer para cada operación
- **Descargar selección**: exporta solo las páginas seleccionadas como un PDF independiente
- Repara automáticamente los PDF dañados antes de cargarlos

## Casos de uso

- Crear un documento personalizado con páginas de varios PDF de origen
- Limpiar un documento escaneado eliminando páginas en blanco, rotando escaneos de lado y reordenando secciones
- Dividir un PDF grande en los límites de los capítulos con marcadores de división visuales
- Edición rápida a nivel de página sin necesidad de un editor de PDF completo

## Consejos

- El sistema de deshacer y rehacer registra cada operación. Úsalo con libertad: no puedes perder tu trabajo por accidente.
- Los marcadores de división aparecen como líneas azules discontinuas entre páginas. Colócalos visualmente donde quieras dividir el documento y luego exporta para obtener un ZIP.
- Para tareas sencillas de fusión o división, las herramientas dedicadas [Fusionar PDF](./merge-pdf) o [Dividir PDF](./split-pdf) pueden ser más rápidas. La Multiherramienta destaca cuando necesitas varias operaciones en una sola sesión.

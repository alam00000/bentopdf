# Recortar PDF

Recorta los márgenes de las páginas de tu PDF con una interfaz visual. Dibuja un rectángulo de recorte directamente sobre cada página, previsualiza el resultado y aplica el recorte. Puedes definir regiones de recorte distintas para diferentes páginas o aplicar el mismo recorte a todo el documento.

## Cómo Funciona

1. Sube tu archivo PDF.
2. Se abre el editor de recorte, que muestra la primera página con una superposición de recorte que se puede arrastrar.
3. Ajusta el rectángulo de recorte arrastrando sus bordes o esquinas.
4. Usa los botones de navegación de páginas para moverte entre ellas y definir la región de recorte de cada una.
5. Haz clic en **Recortar y descargar** para aplicar el recorte y descargar el resultado.

## Características

- Editor de recorte visual basado en Cropper.js, con controladores para un ajuste preciso
- Navegación página por página para definir regiones de recorte individuales
- Guarda los ajustes de recorte por página, para que puedas definir recortes distintos en páginas distintas
- Vista previa en vivo del área de recorte seleccionada
- Admite PDFs de cualquier tamaño u orientación de página

## Casos de Uso

- Quitar márgenes amplios de documentos escaneados para centrarse en el área de contenido
- Eliminar marcas de corte o de registro de impresora de PDFs de preimpresión
- Recortar diapositivas de clase para quitar el área de notas del presentador
- Quitar encabezados o pies de página de todas las páginas antes de compartir un extracto de un documento
- Redimensionar páginas para adaptarlas a una pantalla o un diseño de impresión específico

## Consejos

- La superposición de recorte se puede redimensionar y reposicionar libremente. Arrastra las esquinas para un cambio de tamaño proporcional o los bordes para un ajuste en un solo eje.
- Si todas las páginas necesitan el mismo recorte, defínelo en la primera página: la herramienta recuerda tu región de recorte mientras navegas por las páginas.
- Si necesitas estandarizar los tamaños de página en lugar de recortar visualmente, la herramienta Fijar Tamaño de Página puede ser más adecuada.

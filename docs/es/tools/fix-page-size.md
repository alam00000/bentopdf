# Ajustar tamaño de página

Los PDF creados a partir de varias fuentes suelen tener páginas de tamaños distintos: algunas Letter, otras A4, otras totalmente fuera de norma. Esta herramienta fuerza todas las páginas a un único tamaño, escalando el contenido para ajustarlo o llenarlo según haga falta.

## Cómo funciona

1. Sube un archivo PDF.
2. Selecciona un **Tamaño de página de destino** en el menú desplegable (A4, Letter, Legal, A3, A5, Tabloid o Custom).
3. Elige una **Orientación**: Auto mantiene la orientación original de cada página, o puedes forzar Portrait o Landscape.
4. Elige un modo de **Escalado del contenido**: Fit (conserva todo el contenido, puede añadir márgenes) o Fill (llena la página, puede recortar los bordes).
5. Opcionalmente, define un **Color de fondo** para los márgenes añadidos.
6. Haz clic en **Ajustar tamaño de página**.

## Opciones

- **Tamaños estándar**: A4, Letter, Legal, A3, A5, Tabloid
- **Dimensiones personalizadas**: introduce ancho y alto en pulgadas o milímetros
- **Orientación**: Automática, Vertical, Horizontal
- **Modo de escalado**: Fit o Fill (Crop)
- **Color de fondo**: cualquier color para el relleno de los márgenes

## Casos de uso

- Normalizar un PDF combinado cuyas páginas vienen de escáneres distintos
- Convertir un documento US Letter a A4 para distribución internacional
- Preparar PDF listos para imprimir que exigen un tamaño de corte uniforme
- Corregir páginas ligeramente fuera de estándar (por ejemplo, 8,49 x 11,02 pulgadas en lugar de 8,5 x 11)

## Consejos

- Usa el modo Fit para garantizar que no se pierda contenido. El modo Fill se ve más limpio, pero puede recortar los bordes.
- Revisa el resultado con la herramienta Dimensiones de página para confirmar que todas las páginas coinciden con el tamaño objetivo.
- El color de fondo predeterminado es el blanco; cambia a un color oscuro si tu documento tiene márgenes oscuros.

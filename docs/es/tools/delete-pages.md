# Eliminar páginas

Quita las páginas que no quieres de un documento PDF. Indica las páginas a eliminar escribiendo números de página o rangos, o haz clic directamente en las miniaturas para marcarlas.

## Cómo Funciona

1. Sube un archivo PDF. La herramienta genera vistas previas en miniatura de cada página.
2. Ingresa las páginas a eliminar en el campo de texto con la sintaxis de rangos (p. ej., `2, 5-8`), o haz clic en las miniaturas para alternarlas.
3. Las páginas marcadas se resaltan visualmente para que confirmes tu selección.
4. Haz clic en el botón de procesar. Se crea un nuevo PDF sin las páginas seleccionadas.

## Características

- Selección de páginas por texto con sintaxis de rangos (`2, 5-8, 12`)
- Cuadrícula visual de miniaturas para eliminar con un clic
- Resaltado en tiempo real de las páginas marcadas para eliminar
- Validación de la entrada según el número real de páginas
- Conserva todas las páginas no eliminadas en su orden original

## Casos de Uso

- Eliminar páginas en blanco o de relleno de un documento escaneado
- Eliminar portadas o apéndices antes de compartir un documento
- Limpiar páginas de borrador que quedaron por accidente en un PDF final
- Quitar páginas con información sensible antes de distribuir

## Consejos

- Eliminar páginas no afecta el contenido ni el formato de las páginas restantes. El resultado es una copia fiel del original sin las páginas eliminadas.
- Si quieres conservar solo ciertas páginas en lugar de quitar otras específicas, [Extraer Páginas](./extract-pages) es la mejor opción.
- La vista de miniaturas se carga de forma diferida, por lo que los documentos grandes siguen respondiendo con fluidez.

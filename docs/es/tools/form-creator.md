# Crear formulario PDF

Diseña formularios PDF rellenables profesionales desde cero o añadiendo campos a un PDF existente. El editor visual te permite arrastrar y soltar elementos de formulario (campos de texto, casillas, menús desplegables, botones de opción, campos de firma y más) directamente sobre las vistas previas de página. Configura las propiedades de los campos, define reglas de visibilidad condicional y exporta un formulario PDF totalmente interactivo.

## Cómo funciona

1. Sube un PDF existente **o** haz clic en **Crear PDF en blanco** para empezar desde cero.
2. Si creas un PDF en blanco, selecciona un tamaño de página (Letter, A4, A5, Legal, Tabloid, A3 o dimensiones personalizadas).
3. Se abre el editor de formularios con una barra de herramientas de tipos de campo y un área de vista previa de la página.
4. Selecciona un tipo de campo en la barra de herramientas y luego haz clic en la página para colocarlo.
5. Arrastra los campos para reposicionarlos. Usa los tiradores para ajustar las dimensiones.
6. Haz clic en un campo para abrir el panel de propiedades, donde puedes definir el nombre del campo, el valor predeterminado, el tamaño de fuente, la alineación y más.
7. Navega entre páginas con los controles de página.
8. Haz clic en **Descargar formulario PDF** para descargar el PDF rellenable terminado.

## Características

- Colocación de campos arrastrando y soltando, con tiradores visuales para redimensionar
- Tipos de campo: entrada de texto, texto multilínea, casilla, menú desplegable, botón de opción, firma, fecha, número y código de barras
- Panel de propiedades para configurar el nombre, la etiqueta, el valor predeterminado, el tamaño de fuente, el color, la alineación y la validación de cada campo
- Acciones de campo y reglas de visibilidad condicional (mostrar u ocultar campos según los valores de otros campos)
- Navegación por páginas para formularios de varias páginas
- Extracción de campos existentes: detecta e importa automáticamente los campos de formulario de los PDF subidos
- Compatible tanto con PDF subidos como con páginas en blanco como lienzo del formulario
- Varios tamaños de página predefinidos, además de dimensiones personalizadas
- Generación de códigos de barras con bwip-js
- Gestión de grupos de botones de opción

## Opciones

**Tamaños de página predefinidos (para PDF en blanco):**

- Letter (8.5" x 11")
- A4 (210mm x 297mm)
- A5 (148mm x 210mm)
- Legal (8.5" x 14")
- Tabloid (11" x 17")
- A3 (297mm x 420mm)
- Custom (indica ancho y alto)

**Propiedades de los campos (varían según el tipo de campo):**

- Nombre, etiqueta y texto de marcador
- Valor predeterminado
- Familia, tamaño y color de la fuente
- Alineación del texto (izquierda, centro, derecha)
- Interruptor de campo obligatorio
- Interruptor de solo lectura
- Longitud máxima de los campos de texto
- Lista de opciones para menús desplegables y botones de opción
- Acciones de visibilidad condicional

## Casos de uso

- Crear formularios de incorporación de empleados con campos de texto para datos personales y casillas para aceptar políticas
- Crear cuestionarios de admisión de clientes con menús desplegables para elegir el servicio
- Diseñar formularios de pedido con campos calculados e identificadores de código de barras
- Crear listas de inspección con botones de opción para valoraciones de aprobado o suspenso
- Crear encuestas con preguntas de seguimiento condicionales que aparecen según las respuestas

## Consejos

- Si subes un PDF existente, la herramienta intentará extraer los campos de formulario que ya contenga, para que puedas editarlos o añadir otros.
- Usa la función de grupo de botones de opción para crear selecciones mutuamente excluyentes. Los campos del mismo grupo comparten un nombre de grupo.
- Prueba tu formulario descargándolo y abriéndolo en [Form Filler](./form-filler) para verificar el comportamiento de los campos.

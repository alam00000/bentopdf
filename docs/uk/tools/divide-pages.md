# Розділити сторінки

Розрізайте окремі сторінки PDF навпіл, розділяючи їх горизонтально або вертикально. Це корисно, коли одна сторінка містить вміст, який слід розділити на окремі сторінки, наприклад, дві колонки, відскановані як одна широка сторінка.

## Як це працює

1. Завантажте файл PDF.
2. Виберіть напрямок розділення: **Вертикально** (ліва/права половини) або **Горизонтально** (верхня/нижня половини).
3. За бажання вкажіть діапазон сторінок, щоб обмежити, які сторінки розділяти. Залиште порожнім, щоб розділити всі сторінки.
4. Натисніть кнопку обробки, щоб створити розділений PDF.

## Можливості

- Вертикальне розділення: ділить кожну сторінку на ліву та праву половини
- Горизонтальне розділення: ділить кожну сторінку на верхню та нижню половини
- Фільтр діапазону сторінок для вибіркового розділення певних сторінок
- Сторінки поза вибором проходять без змін
- Зберігає якість вмісту без повторного відображення

## Сценарії використання

- Розділення сторінок, відсканованих по дві (наприклад, скан книги, де ліва та права сторінки на одному аркуші)
- Розбиття альбомного PDF з вмістом поруч на окремі книжкові сторінки
- Поділ високих інфографік чи плакатів на окремі верхню та нижню частини
- Підготовка широкоформатних документів до друку на стандартному папері

## Поради

- Якщо вміст на сторінках розподілено нерівномірно, розділення все одно відбувається рівно посередині. Для асиметричного розділення краще скористайтеся [Обрізати PDF](./crop-pdf).
- Поєднуйте цей інструмент із [Повернути PDF](./rotate-pdf), якщо сторінки потрібно повернути до або після розділення.

# Корекція кольору

Повноцінний набір для колірної корекції PDF. Налаштовуйте вісім незалежних параметрів -- яскравість, контраст, насиченість, зсув відтінку, температуру, тонування, гамму та сепію -- з попереднім переглядом наживо, що оновлюється під час руху кожного повзунка.

## Як це працює

1. Завантажте PDF-файл.
2. Відкриється редактор із попереднім переглядом першої сторінки та панеллю колірних налаштувань.
3. Рухайте повзунки, щоб змінити кожен колірний параметр. Попередній перегляд оновлюється в реальному часі.
4. Натисніть **Скинути**, щоб повернути всі повзунки до початкових положень.
5. Натисніть **Застосувати**, щоб обробити всі сторінки й завантажити відкоригований PDF.

## Параметри

- **Яскравість** -- Висвітлення або затемнення всієї сторінки (від -100 до +100).
- **Контраст** -- Збільшення або зменшення різниці між світлими й темними ділянками (від -100 до +100).
- **Насиченість** -- Посилення або зменшення інтенсивності кольорів (від -100 до +100). Значення -100 дає відтінки сірого.
- **Зсув відтінку** -- Поворот колірного кола для рівномірного зсуву всіх кольорів.
- **Температура** -- Зсув кольорів у теплий (жовтий/оранжевий) або холодний (синій) бік.
- **Тонування** -- Додавання зеленого або пурпурного відтінку.
- **Гамма** -- Регулювання яскравості півтонів за допомогою гамма-кривої. Значення нижче 1.0 затемнюють півтони, а вище 1.0 висвітлюють їх.
- **Сепія** -- Класичний ефект сепії. Вищі значення дають інтенсивніший коричневий відтінок.

## Можливості

- Вісім незалежно регульованих колірних параметрів
- Попередній перегляд наживо, що миттєво реагує на рух повзунків
- Кнопка скидання для швидкого повернення до початкових значень
- Обробка всіх сторінок документа
- Працює з будь-яким вмістом PDF (текст, зображення, графіка)

## Приклади використання

- Освітлення темного скана або виправлення переекспонованих сторінок
- Зменшення насиченості кольорового документа для економії чорнила перед друком
- Застосування тону сепії для старовинного вигляду сертифікатів або нагород
- Корекція колірної температури фотографій, вбудованих у PDF
- Підвищення контрасту блідих або низькоякісних сканованих документів

## Поради

- Для швидкого перетворення на відтінки сірого перетягніть повзунок насиченості до -100.
- Повзунок гамми особливо корисний для покращення читабельності сканованих документів, де півтони надто темні або надто світлі.
- Як і інші інструменти ефектів зображення, цей інструмент растеризує кожну сторінку. Результат буде у вигляді зображень, тому текст не можна буде виділити.

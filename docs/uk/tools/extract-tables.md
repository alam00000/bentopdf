# Витяг таблиць

Знаходить усі таблиці в PDF і дозволяє експортувати їх у вибраному форматі: CSV, JSON або Markdown. Кожна таблиця витягується окремо з метаданими сторінки та позиції. Працює на рушії виявлення таблиць PyMuPDF.

## Як це працює

1. Завантажте PDF, клацнувши зону завантаження або перетягнувши на неї файл.
2. Виберіть бажаний **формат експорту**: CSV, JSON або Markdown.
3. Натисніть **Витягнути таблиці**, щоб почати обробку.
4. Якщо знайдено одну таблицю, вона завантажується як один файл. Кілька таблиць дають ZIP-архів з одним файлом на таблицю.

## Параметри

- **Формат експорту**: виберіть один із варіантів:
  - **CSV**: значення, розділені комами, з належним екрануванням полів, що містять коми, лапки чи переноси рядків. Підходить для електронних таблиць і баз даних.
  - **JSON**: структура масиву масивів, відформатована з відступом у 2 пробіли. Підходить для програмної обробки.
  - **Markdown**: формат таблиці з роздільниками-вертикальними рисками, який формує PyMuPDF. Підходить для документації та файлів README.

## Формат результату

- **Одна таблиця**: `filename_table.csv` (або `.json` / `.md`)
- **Кілька таблиць**: `filename_tables.zip` з файлами на кшталт `table_1_page3.csv`, `table_2_page5.csv` тощо.

## Сценарії використання

- Витягування окремих таблиць із довгих PDF-звітів без вивантаження даних усього документа.
- Отримання таблиць у форматі Markdown для вставлення безпосередньо в задачі GitHub, вікі чи документацію.
- Отримання структурованих даних JSON із таблиць PDF для інтеграцій з API чи скриптів.
- Порівняння таблиць у різних версіях PDF шляхом експорту обох у CSV і перегляду відмінностей.

## Поради

- Цей інструмент дає контроль над кожною таблицею окремо. Якщо потрібно просто вивантажити всі таблиці в один CSV, скористайтеся [PDF у CSV](./pdf-to-csv). Для повної книги Excel використовуйте [PDF у Excel](./pdf-to-excel).
- Таблиці, що охоплюють кілька сторінок, можуть визначатися як окремі таблиці на кожній сторінці. Можливо, їх доведеться об’єднати вручну.
- Якщо таблиць не виявлено, PDF може бути скануванням. Спершу пропустіть його через OCR, щоб додати текстовий шар.

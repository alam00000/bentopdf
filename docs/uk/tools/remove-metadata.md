# Видалити метадані

Кожен PDF містить метадані, які можуть розкрити, хто його створив, яке програмне забезпечення використовувалося, коли його востаннє змінювали, тощо. Цей інструмент прибирає все: словник інформації, потоки метаданих XMP, ідентифікатори документа та дані, специфічні для програм. У результаті ви отримуєте чистий документ без жодних слідів походження.

## Як це працює

1. Завантажте файл PDF.
2. Натисніть **Видалити метадані**.
3. Завантажте очищений файл.

Налаштовувати нічого не потрібно. Інструмент ретельний за задумом: він очищає все.

## Що видаляється

- **Поля словника інформації**: назва, автор, тема, ключові слова, творець, виробник, дата створення, дата зміни
- **Потік метаданих XMP**: XML-блок метаданих, що зберігається в каталозі документа
- **Ідентифікатори документа**: унікальні ідентифікатори в трейлері PDF, за якими документ можна відстежувати між системами
- **PieceInfo**: метадані, специфічні для програм, додані такими програмами, як Illustrator або InDesign

## Що залишається

- Увесь видимий вміст сторінок (текст, зображення, графіка)
- Поля форм і анотації
- Закладки та посилання
- Сама структура документа

## Сценарії використання

- Видалення вашого імені й назви організації з документа перед анонімною публікацією
- Видалення часових позначок створення, що розкривають, коли документ було підготовлено
- Очищення рядків виробника, що вказують на ваш набір програм для PDF
- Підготовка документів для регуляторних подань, які вимагають PDF без метаданих
- Видалення слідів історії редагування перед передаванням документа зовні

## Поради

- Спершу скористайтеся інструментом «Перегляд метаданих», щоб побачити, які саме метадані містить ваш PDF, перш ніж їх видаляти.
- Якщо потрібно видалити метадані _та_ JavaScript, анотації й вбудовані файли, скористайтеся «Очистити PDF» для ґрунтовнішого очищення.
- Видалення метаданих незворотне. Збережіть оригінал, якщо ці дані можуть знадобитися пізніше.

## Пов’язані інструменти

- [Очистити PDF](./sanitize-pdf): видаліть метадані, а також скрипти, вкладення та інше
- [Зашифрувати PDF](./protect-pdf): захистіть очищений PDF паролем
- [Стиснення PDF](./compress-pdf): видалення метаданих може трохи зменшити розмір файлу; стисніть для більшої економії

# Видалити сторінки

Видаляйте непотрібні сторінки з документа PDF. Вказуйте сторінки для видалення, вводячи номери чи діапазони, або клацайте безпосередньо по мініатюрах сторінок, щоб позначити їх.

## Як це працює

1. Завантажте файл PDF. Інструмент відобразить мініатюри всіх сторінок.
2. Введіть сторінки для видалення в текстове поле за синтаксисом діапазонів (наприклад, `2, 5-8`) або клацайте мініатюри, щоб перемикати їх.
3. Позначені сторінки візуально підсвічуються, щоб ви могли підтвердити вибір.
4. Натисніть кнопку обробки. Буде створено новий PDF без вибраних сторінок.

## Можливості

- Текстовий вибір сторінок із синтаксисом діапазонів (`2, 5-8, 12`)
- Візуальна сітка мініатюр для видалення клацанням
- Підсвічування сторінок, позначених для видалення, у реальному часі
- Перевірка введеного щодо фактичної кількості сторінок
- Усі невидалені сторінки залишаються в початковому порядку

## Сценарії використання

- Видалення порожніх чи заповнювальних сторінок зі сканованого документа
- Прибирання обкладинок чи додатків перед поширенням документа
- Видалення чернеткових сторінок, випадково залишених у фінальному PDF
- Видалення сторінок із конфіденційною інформацією перед розповсюдженням

## Поради

- Видалення сторінок не впливає на вміст чи форматування решти сторінок. Результат є точною копією оригіналу без видалених сторінок.
- Якщо потрібно залишити лише певні сторінки, а не видаляти певні, краще підійде [Витяг сторінок](./extract-pages).
- Перегляд мініатюр завантажується поступово, тому великі документи залишаються чутливими до дій.

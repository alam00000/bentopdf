# Додати штампи

Розміщуйте зображення-штампи на сторінках PDF за допомогою вбудованого переглядача з панеллю анотацій для штампів. Штампи можуть містити ваше ім’я, що корисно для процесів погодження, рецензування та маркування документів.

## Як це працює

1. Введіть своє ім’я в поле **Ім’я користувача для штампа**. Це ім’я відображатиметься на створених вами штампах.
2. Завантажте PDF-файл, клацнувши зону завантаження або перетягнувши файл у неї.
3. Відкриється редактор штампів із завантаженим документом у переглядачі.
4. За допомогою інструмента зображення-штампа на панелі виберіть і розмістіть штампи на будь-якій сторінці.
5. За потреби змініть положення та розмір штампів.
6. Натисніть **Зберегти PDF зі штампами**, щоб завантажити результат.

## Можливості

- Інтегрований PDF-переглядач із панеллю анотацій для штампів
- Зазначення імені користувача на створених штампах
- Розміщення зображень-штампів на будь-якій сторінці
- Позиціювання та зміна розміру перетягуванням
- Автоматичний підбір розміру переглядача за співвідношенням сторін сторінки
- Відображення назви й розміру файлу

## Приклади використання

- Додавання зображень-штампів "APPROVED" або "REVIEWED" до документів у процесі рецензування
- Розміщення зображень печатки компанії або нотаріального штампа на офіційних документах
- Маркування сторінок штампами "RECEIVED" з ім’ям рецензента
- Додавання штампів контролю якості до звітів про перевірку

## Поради

- Вкажіть ім’я користувача для штампа до завантаження PDF. Ім’я вбудовується в метадані штампа.
- Переглядач підбирає висоту за співвідношенням сторін першої сторінки PDF для зручного перегляду.
- Для текстових водяних знаків замість зображень-штампів скористайтеся інструментом [Додати водяний знак](./add-watermark).

# Додати вкладення

Вбудуйте один або кілька файлів безпосередньо в PDF-документ. Вкладення можна додати на рівні документа (вони відображаються на панелі вкладень будь-якого PDF-переглядача) або прив’язати до окремих сторінок.

## Як це працює

1. Завантажте PDF, до якого потрібно додати файли.
2. У зоні для вкладень виберіть файли, які потрібно вбудувати (будь-якого типу).
3. Виберіть рівень вкладення: **Документ** (за замовчуванням) або **Сторінка**.
4. Якщо вибрано рівень сторінки, введіть діапазон сторінок (наприклад, `1-3` або `5`).
5. Натисніть кнопку обробки. Змінений PDF завантажиться з вбудованими файлами.

## Можливості

- Вкладення файлів будь-якого типу: зображення, таблиці, архіви, виконувані файли, усе що завгодно
- Розміщення вкладень на рівні документа або сторінки
- Кілька файлів можна додати за одну операцію
- Відображення назв і розмірів усіх вибраних вкладень
- Початковий вміст PDF зберігається, до нього лише додаються вбудовані файли

## Параметри

| Параметр             | Опис                                                                         |
| -------------------- | ---------------------------------------------------------------------------- |
| **Рівень документа** | Прикріплює файли до PDF загалом, доступні на панелі вкладень                 |
| **Рівень сторінки**  | Прикріплює файли до окремих сторінок, які вказуються через діапазон сторінок |

## Приклади використання

- Додавання вихідних даних (файлів Excel, CSV) до PDF-звіту
- Прикріплення оригінальних зображень до PDF-портфоліо фотографа
- Вбудовування супровідних документів у договір або комерційну пропозицію
- Додавання додаткових матеріалів до окремих сторінок навчального посібника

## Поради

- Вкладення на рівні документа підтримуються більшістю PDF-переглядачів. Вкладення на рівні сторінки можуть не відображатися в усіх переглядачах.
- Обмеження розміру вкладень немає, але дуже великі вбудовані файли пропорційно збільшують розмір PDF.

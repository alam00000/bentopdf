# WPS у PDF

Перетворюйте файли текстового редактора Microsoft Works на PDF. Microsoft Works постачався зі споживчими ПК наприкінці 1990-х і в 2000-х, і багато файлів WPS досі лежать на старих дисках та в поштових архівах. Цей інструмент відкриває їх у браузері й створює чисті PDF.

## Підтримувані формати

| Формат          | Розширення | Примітки                                   |
| :-------------- | :--------- | :----------------------------------------- |
| Microsoft Works | `.wps`     | Файли текстового редактора Microsoft Works |

## Як це працює

1. Натисніть область завантаження або перетягніть файли WPS. Можна додати кілька файлів.
2. Перегляньте список файлів. Піктограмою кошика видаліть окремі файли або натисніть **Додати ще файли**, щоб розширити пакет.
3. Натисніть **Перетворити на PDF**. Рушій на основі LibreOffice завантажується в браузері й конвертує кожен документ WPS у PDF.
4. Один файл завантажується напряму як PDF. Кілька файлів пакуються в ZIP-архів `wps-to-pdf.zip`.

## Параметри

Додаткові налаштування не потрібні. Конвертер обробляє текст, базове форматування та вбудовані зображення з файлу WPS.

## Сценарії використання

- Відновлення старих шкільних чи робочих документів, збережених у форматі Microsoft Works
- Відкриття вкладень WPS в електронних листах, коли Microsoft Works не встановлено
- Перетворення архіву файлів WPS для перенесення в сучасну систему документів
- Друк старих документів, які сучасні текстові редактори не можуть відкрити

## Поради

- Не плутайте файли Microsoft Works `.wps` із файлами WPS Office. Цей інструмент призначений саме для старішого формату Microsoft Works.
- Рушій LibreOffice завантажується під час першого використання, це потребує трохи часу. Після завантаження наступні перетворення в тому самому сеансі швидші.

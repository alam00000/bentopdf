# XML у PDF

Перетворюйте файли даних XML на читабельні структуровані PDF-документи. Сирий XML потужний, але незручний для людського читання. Цей інструмент розбирає дерево XML, виявляє повторювані структури даних і відображає їх як форматовані таблиці та розділи в альбомному PDF формату A4.

## Підтримувані формати

| Формат | Розширення | Примітки                         |
| :----- | :--------- | :------------------------------- |
| XML    | `.xml`     | Будь-який коректний XML-документ |

## Як це працює

1. Натисніть область завантаження або перетягніть файли XML. В одному пакеті можна обробити кілька файлів.
2. Перегляньте список файлів. Видаляйте зайві файли піктограмою кошика або натисніть **Додати ще файли**, щоб додати інші.
3. Натисніть **Перетворити на PDF**. Інструмент розбирає структуру XML за допомогою вбудованого в браузер DOMParser, аналізує ієрархію даних і відображає її у PDF через jsPDF з автоматичним форматуванням таблиць.
4. Один файл завантажується як PDF. Кілька перетворень пакуються в `xml-to-pdf.zip`.

## Параметри

Ручне налаштування не потрібне. Конвертер сам визначає структуру XML і добирає відповідні макети таблиць. Результат має альбомну орієнтацію A4, щоб вмістити широкі набори даних.

## Сценарії використання

- Перетворення експортів XML з баз даних чи API на звіти для друку
- Створення читабельних зведень із конфігураційних файлів XML
- Перетворення рахунків або журналів транзакцій у форматі XML на PDF для обліку
- Подання XML-карт сайту чи RSS-стрічок у читабельному вигляді документа

## Поради

- XML має бути коректним. Якщо парсер знайде синтаксичні помилки, перетворення завершиться з описовим повідомленням, що вказує на проблему.
- Глибоко вкладені структури XML розгортаються в таблиці. Найкращий результат дають дані з повторюваними сусідніми елементами однакової структури.
- Під час перетворення показуються оновлення прогресу з кожним етапом: читання, розбір, аналіз і відображення.

# RTF у PDF

Конвертуйте документи Rich Text Format у PDF. RTF є міжплатформним форматом документів, який підтримує практично кожен текстовий процесор. Цей інструмент використовує рушій LibreOffice у браузері, щоб відтворити файли RTF із збереженням форматування: напівжирний шрифт, курсив, таблиці та вбудовані зображення переносяться в PDF.

## Підтримувані формати

| Формат | Розширення | Типи MIME                     |
| :----- | :--------- | :---------------------------- |
| RTF    | `.rtf`     | `text/rtf`, `application/rtf` |

## Як це працює

1. Натисніть область завантаження або перетягніть один чи кілька файлів RTF.
2. Перегляньте список файлів. Додайте інші або видаліть зайві.
3. Натисніть **Конвертувати в PDF**. Рушій LibreOffice ініціалізується під час першого використання, потім обробляє кожен файл.
4. Один файл завантажується одразу як PDF. Кілька файлів надходять як `rtf-converted.zip`.

## Параметри

Цей інструмент не має додаткових налаштувань. Конвертація зберігає початкове форматування RTF.

## Результат

| Кількість вхідних файлів | Результат                                                 |
| :----------------------- | :-------------------------------------------------------- |
| 1 файл                   | Одне завантаження PDF (наприклад, `letter.pdf`)           |
| 2+ файли                 | Архів ZIP (`rtf-converted.zip`) з одним PDF на кожен файл |

## Сценарії використання

- Конвертація застарілих документів RTF зі старих текстових процесорів у сучасні PDF
- Перетворення шаблонів електронних листів RTF на попередній перегляд у PDF
- Обробка виводу RTF із юридичних або медичних програмних систем
- Пакетна конвертація файлів RTF із системи керування документами в PDF для архівування

## Поради

- Рушій LibreOffice завантажується один раз і кешується. Перша конвертація в сеансі триває на кілька секунд довше, наступні швидші.
- Файли RTF із вбудованими об’єктами OLE можуть відображати не всі об’єкти ідеально. Простий текст, зображення та стандартне форматування конвертуються надійно.
- Якщо ваші файли RTF створено в Microsoft Word, їх також можна конвертувати безпосередньо інструментом [Word у PDF](./word-to-pdf), який приймає RTF поряд з DOC і DOCX.

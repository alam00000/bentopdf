# Перегляд метаданих

Перегляньте приховані властивості, вбудовані у PDF-файл. Інструмент показує відомості про документ (назва, автор, дати), метадані XMP, розміри сторінок та інші структурні дані в зручному вигляді.

## Як це працює

1. Завантажте PDF-файл.
2. Інструмент одразу розбирає файл і показує всі доступні метадані за розділами.
3. Перегляньте словник відомостей про документ, дерево метаданих XMP і структурні властивості.
4. Окрема обробка не потрібна: метадані відображаються, щойно файл завантажено.

## Можливості

- Показує стандартні поля: заголовок, автор, тема, ключові слова, створювач, виробник
- Відображає дати створення та зміни в зручному для читання форматі
- Розбирає й показує повне дерево метаданих XMP із вкладеними просторами імен
- Перетворює формат дат PDF (`D:20240101120000Z`) на зрозумілі дати
- Розділи згортаються для зручної навігації

## Розділи метаданих

| Розділ                     | Вміст                                                                                  |
| -------------------------- | -------------------------------------------------------------------------------------- |
| **Відомості про документ** | Заголовок, автор, тема, ключові слова, створювач, виробник, дата створення, дата зміни |
| **Метадані XMP**           | Повне XML-дерево метаданих з просторами імен Dublin Core, XAP, PDF та власними         |
| **Властивості документа**  | Кількість сторінок, версія PDF, розмір файлу, стан шифрування                          |

## Сценарії використання

- Дізнатися, хто автор PDF і коли його востаннє змінювали
- Переконатися, що метадані задано правильно перед публікацією документа
- Перевірити PDF на приватність, подивившись, які особисті дані вбудовано
- З'ясувати, яке програмне забезпечення створило або змінило PDF (за полем Producer)
- Перевірити метадані XMP на відповідність вимогам керування цифровими активами

## Поради

- Рядки дат PDF, що починаються з `D:`, автоматично перетворюються на формат вашого часового поясу.
- Якщо поля метаданих порожні, автор PDF просто не заповнив їх. Не всі PDF містять багаті метадані.
- Щоб змінити метадані після перегляду, скористайтеся [Редагувати метадані](./edit-metadata). Щоб видалити їх повністю, використайте «Видалити метадані».

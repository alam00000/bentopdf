# Редагувати вкладення

Перевіряйте вкладені файли всередині PDF та керуйте ними. Інструмент виводить список усіх вбудованих файлів із їхніми назвами та рівнем вкладення, а потім дозволяє позначити окремі вкладення для видалення або прибрати їх усі одразу.

## Як це працює

1. Завантажте файл PDF.
2. Інструмент автоматично шукає вкладення та показує їх у списку.
3. Для кожного вкладення відображається назва файлу та те, чи воно на рівні документа, чи на рівні сторінки.
4. Клацніть піктограму кошика поруч із вкладенням, щоб позначити його для видалення (клацніть ще раз, щоб зняти позначку).
5. Кнопка **Видалити всі вкладення** позначає все одразу, а **Скасувати вибір усіх** скидає вибір.
6. Натисніть кнопку обробки, щоб зберегти новий PDF без вибраних вкладень.

## Можливості

- Список усіх вкладень на рівні документа та на рівні сторінки
- Видалення окремих вкладень або всіх одразу
- Перемикання вибору до підтвердження змін
- Візуальне закреслення та зміна прозорості для елементів, позначених для видалення
- Завантаження зміненого PDF без вибраних вкладень

## Сценарії використання

- Видалення застарілих чи помилкових файлів, вбудованих у документ, перед повторним розповсюдженням
- Прибирання конфіденційних вкладень (фінансові дані, особисті відомості) з PDF перед поширенням
- Зменшення розміру PDF шляхом видалення великих вбудованих файлів, які більше не потрібні
- Аудит вбудованого вмісту та очищення документа перед архівуванням

## Поради

- Вкладення, позначені для видалення, відображаються із закресленням. Ви можете зняти позначку до обробки, якщо передумаєте.
- Якщо вкладень не знайдено, інструмент показує чітке повідомлення "У цьому PDF вкладень не знайдено": PDF просто не містить вбудованих файлів.

# Обрізати PDF

Обрізайте поля сторінок PDF у візуальному інтерфейсі. Намалюйте прямокутник обрізання безпосередньо на кожній сторінці, перегляньте результат і застосуйте обрізання. Можна задати різні області для різних сторінок або застосувати однакове обрізання до всього документа.

## Як це працює

1. Завантажте файл PDF.
2. Відкриється редактор обрізання з першою сторінкою та накладкою, яку можна перетягувати.
3. Змінюйте прямокутник обрізання, перетягуючи його краї або кути.
4. Кнопками навігації переходьте між сторінками та задавайте області обрізання для кожної.
5. Натисніть **Обрізати й завантажити**, щоб застосувати обрізання й завантажити результат.

## Можливості

- Візуальний редактор обрізання на основі Cropper.js з маркерами для точного налаштування
- Посторінкова навігація для окремих областей обрізання
- Збереження параметрів обрізання для кожної сторінки, тож можна задати різні обрізання для різних сторінок
- Живий попередній перегляд вибраної області
- Підтримка PDF будь-якого розміру сторінки чи орієнтації

## Сценарії використання

- Видалення широких полів зі сканованих документів, щоб зосередитися на вмісті
- Прибирання друкарських міток обрізання чи реєстрації з PDF для передпресової підготовки
- Обрізання слайдів лекцій, щоб прибрати область приміток доповідача
- Видалення верхніх або нижніх колонтитулів з кожної сторінки перед поширенням уривка документа
- Зміна розміру сторінок під конкретний дисплей чи макет друку

## Поради

- Накладку обрізання можна вільно змінювати за розміром і переміщувати. Тягніть за кути для пропорційної зміни розміру або за краї для зміни по одній осі.
- Якщо до всіх сторінок потрібне однакове обрізання, задайте його на першій сторінці: інструмент запам’ятовує вашу область, поки ви переходите між сторінками.
- Якщо потрібно уніфікувати розміри сторінок, а не обрізати візуально, краще підійде інструмент «Вирівняти розмір сторінок».

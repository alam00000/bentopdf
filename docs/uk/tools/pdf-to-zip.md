# PDF у ZIP

Зберіть кілька файлів PDF в один ZIP-архів. Це простий інструмент пакування: жодної конвертації, стиснення чи зміни самих PDF.

## Як це працює

1. Завантажте кілька файлів PDF в області завантаження.
2. Перегляньте список файлів. Видаліть ті, які не потрібно включати.
3. Натисніть кнопку обробки.
4. ZIP-архів з усіма завантаженими PDF одразу завантажується.

## Можливості

- Приймає будь-яку кількість файлів PDF
- Видалення окремих файлів перед створенням архіву
- Зберігає початкові імена файлів усередині ZIP
- Без змін вмісту PDF: файли пакуються як є
- Показує ім’я та розмір кожного завантаженого PDF

## Сценарії використання

- Об’єднання набору рахунків чи квитанцій для вкладення в лист
- Пакування результатів проєкту (кількох PDF-звітів) для передавання
- Створення єдиного завантаження для колекції форм чи шаблонів
- Архівування пакета документів в один стиснений файл

## Поради

- ZIP-файл використовує початкові імена PDF. Якщо у вас є файли з однаковими іменами, перейменуйте їх перед завантаженням, щоб уникнути конфліктів.
- Цей інструмент не стискає самі PDF. Щоб зменшити розмір файлів, спершу пропустіть їх через «Стиснення PDF», а потім запакуйте цим інструментом.

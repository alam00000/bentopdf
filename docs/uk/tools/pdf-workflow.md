# Конструктор PDF-процесів

Конструктор процесів дає змогу об’єднати кілька операцій з PDF в один автоматизований конвеєр. Замість запуску інструментів по одному ви збираєте візуальний граф із вузлів (вхід, обробка, вихід) і виконуєте все одним кліком. Ваші файли ніколи не залишають браузер.

## Як це працює

Інтерфейс поділено на три панелі: **набір вузлів** ліворуч, **полотно** в центрі та **панель налаштувань** праворуч, яка з’являється після вибору вузла.

1. **Додавайте вузли**, натискаючи на них у лівій бічній панелі або перетягуючи прямо на полотно. Скористайтеся рядком пошуку вгорі набору, щоб фільтрувати за назвою.
2. **З’єднуйте вузли**, перетягуючи від вихідного гнізда (унизу вузла) до вхідного гнізда (угорі іншого вузла). З’єднання йдуть згори вниз.
3. **Налаштовуйте параметри**, натиснувши на вузол, щоб відкрити його панель налаштувань праворуч. Кожен тип вузла має власні параметри (діапазони сторінок, повзунки якості, паролі тощо).
4. **Запускайте процес**, натиснувши кнопку **Запустити** на панелі інструментів. Рушій виконує вузли в топологічному порядку, обробляючи кожен послідовно. Рядок стану внизу показує прогрес.
5. **Завантажуйте результати**: кінцевий вузол Завантажити зберігає підсумковий PDF (або ZIP, якщо створено кілька файлів).

## Категорії вузлів

Вузли організовано в шість категорій, кожна позначена власним кольором на полотні:

- **Ввід** (синій): Введення PDF, Вхідне зображення, Word/Excel/PowerPoint у PDF та понад 15 інших конвертерів форматів, що передають файли в конвеєр.
- **Редагування та анотації** (індиго): Обрізати PDF, PDF у відтінки сірого, Інвертувати кольори, Додати водяний знак, Нумерація сторінок, Колонтитули, Ефект сканера, Корекція кольору, Колір фону, Видалити порожні сторінки, Видалити анотації.
- **Організація та керування** (фіолетовий): Об’єднати PDF, Розділити PDF, Витяг сторінок, Повернути PDF, Видалити сторінки, Зворотний порядок сторінок, Додати порожню сторінку, Розділити сторінки, N-Up PDF, Вирівняти розмір сторінок, Об’єднати в одну сторінку, PDF-буклет, Постеризація PDF, Редагувати метадані, Зміст, OCR PDF.
- **Оптимізація та відновлення** (бурштиновий): Стиснення PDF, Растеризація PDF, Лінеаризація PDF, Вирівнювання PDF, PDF у PDF/A, Шрифти у контури, Відновити PDF.
- **Захист PDF** (рожево-червоний): Зашифрувати, Розшифрувати, Очистити PDF, Сплющити PDF, Цифровий підпис, Закреслити.
- **Вивід** (бірюзовий): Завантажити (автоматично визначає один PDF чи ZIP), PDF у зображення, PDF у текст, PDF у DOCX, PDF у XLSX, PDF у CSV, PDF у SVG, PDF у Markdown, Витяг зображень.

## Збереження та завантаження процесів

Панель інструментів пропонує чотири способи збереження:

- **Зберегти**: зберігає поточний процес як іменований шаблон у локальному сховищі вашого браузера. Можна зберегти кілька шаблонів.
- **Завантажити**: відкриває вікно зі списком усіх збережених шаблонів. Натисніть «Завантажити», щоб відновити шаблон, або видаліть непотрібні.
- **Експорт**: завантажує процес як файл `.json`, щоб ним можна було поділитися або створити резервну копію.
- **Імпорт**: завантажує файл процесу `.json` з диска, відновлюючи всі вузли, їхні позиції та з’єднання.

Шаблони зберігаються між сеансами в локальному сховищі. Експортовані файли JSON переносяться між браузерами та пристроями.

## Модель виконання

Рушій будує граф залежностей із ваших з’єднань і виконує вузли в топологічному порядку. Якщо будь-який вузол завершується помилкою, виконання зупиняється, а вузол із помилкою позначається червоним. Кілька правил, які варто пам’ятати:

- Кожному процесу потрібен принаймні один вузол **Ввід** і один вузол **Вивід**.
- Рушій виявляє циклічні залежності та блокує виконання з помилкою.
- Вузол **Зашифрувати** має бути останнім кроком обробки перед вихідним вузлом. Розміщення його раніше спричинить попередження валідації, бо наступні вузли не можуть працювати із зашифрованими даними.
- Для PDF із паролем під час виконання з’являється запит пароля.
- Підтримуються вхідні дані з кількох PDF: вузол Об’єднати PDF може їх об’єднати, а вузли пакетної обробки обробляють кожен PDF окремо.

## Типи гнізд

З’єднання використовують типізовані гнізда, щоб запобігти неправильним підключенням:

- **PDF** (індиго): один документ PDF.
- **MultiPDF** (бурштиновий): кілька документів PDF, зібраних разом.
- **Image** (зелений): блоб зображення.

## Параметри

Кожен вузол має власну конфігурацію, доступну через праву панель налаштувань. Типові приклади:

- **Діапазони сторінок** у вузлах Розділити PDF, Витяг сторінок, Видалити сторінки
- **Повзунки якості** у вихідних вузлах перетворення на зображення
- **Поля пароля** у вузлах Зашифрувати і Розшифрувати
- **Текстові поля** для Додати водяний знак, Колонтитули, Редагувати метадані
- **Кути повороту** у вузлі Повернути PDF
- **Рівень стиснення** у вузлі Стиснення PDF
- **Вибір мови OCR** у вузлі OCR PDF

## Сценарії використання

- **Конвеєр обробки рахунків**: Введення PDF -> OCR PDF -> Витяг таблиць з PDF -> Завантажити як CSV.
- **Стандартизація звітів**: Word у PDF -> Вирівняти розмір сторінок -> Нумерація сторінок -> Додати водяний знак -> Стиснення PDF -> Завантажити.
- **Підготовка до архівування**: Введення PDF -> Відновити PDF -> Сплющити PDF -> Очистити PDF -> PDF у PDF/A -> Завантажити.
- **Пакетний витяг зображень**: Введення PDF (кілька файлів) -> Витяг зображень -> Завантажити ZIP.
- **Буклети, готові до друку**: Введення PDF -> PDF-буклет -> Обрізати PDF -> Стиснення PDF -> Завантажити.
- **Захищене розповсюдження**: Введення PDF -> Закреслити -> Видалити анотації -> Зашифрувати -> Завантажити.

## Поради

- Використовуйте **Delete** або **Backspace**, щоб видалити вибраний вузол із полотна.
- Натисніть кнопку **X** на рядку стану вузла, щоб видалити його напряму.
- Переміщуйте полотно, натискаючи й перетягуючи на порожньому місці. Під час переміщення курсор змінюється на іконку руки.
- На мобільних пристроях використовуйте кнопку **+** на панелі інструментів, щоб перемикати набір вузлів.
- Якщо процес створює кілька вихідних файлів, вузол Завантажити автоматично пакує їх у ZIP.
- Починайте з простого: збудуйте й перевірте конвеєр із двох вузлів, перш ніж ускладнювати.

# PNG у PDF

Конвертуйте зображення PNG у PDF зі збереженням повної роздільності. Кожен PNG стає окремою сторінкою розміром, що відповідає початковому зображенню. Прозорість обробляється автоматично.

## Підтримувані формати

| Формат | Розширення |
| :----- | :--------- |
| PNG    | `.png`     |

## Як це працює

1. Натисніть на область завантаження або перетягніть файли PNG. Можна вибрати одразу кілька.
2. Керуйте списком файлів: видаляйте зайві або додавайте нові.
3. Оберіть рівень **Якості PDF** у випадному списку.
4. Натисніть **Конвертувати у PDF**. Результат завантажується як `from_jpgs.pdf`.

Інструмент використовує pdf-lib, щоб вбудовувати кожне зображення напряму. Якщо PNG неможливо вбудувати рідним способом (наприклад, через незвичний профіль кольору), він повторно відображається через canvas як JPEG.

## Параметри

**Якість PDF** керує стисненням, що застосовується перед вбудовуванням:

- **Висока якість**: мінімальне стиснення, найбільший розмір файлу.
- **Середня якість** (за замовчуванням): добрий баланс розміру та чіткості.
- **Низька якість**: максимальне стиснення, найменший результат.

## Сценарії використання

- Перетворення знімків екрана на багатосторінковий PDF для звітів про помилки чи документації
- Пакування експорту UI-дизайну в один файл для рецензування
- Перетворення експорту діаграм (draw.io, Excalidraw) на PDF для спільного доступу
- Складання набору зображень графіків у звіт

## Поради

- PNG із прозорістю отримують білий фон у PDF. Якщо потрібен інший фон, відредагуйте зображення заздалегідь.
- Для знімків екрана та діаграм із чіткими краями й текстом висока якість уникає артефактів стиснення JPEG. Середня чи низька можуть внутрішньо конвертувати у JPEG.

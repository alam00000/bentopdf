# PDF у JPG

Перетворює кожну сторінку PDF на зображення JPG. Односторінкові документи завантажуються як окремий файл `.jpg`. Багатосторінкові PDF створюють ZIP-архів з одним JPG на кожну сторінку.

## Як це працює

1. Завантажте PDF, натиснувши на область завантаження або перетягнувши файл. Інструмент покаже ім’я файлу, його розмір і кількість сторінок.
2. Налаштуйте повзунок **Якість**, щоб керувати стисненням JPG.
3. Натисніть **Конвертувати**, щоб почати обробку.
4. Результат завантажується автоматично: один JPG для односторінкового PDF або ZIP-файл для багатосторінкових документів.

## Параметри

- **Якість**: повзунок від 0% до 100% (за замовчуванням 90%). Вищі значення дають чіткіші зображення більшого розміру. Нижчі значення стискають агресивніше.

Усередині сторінки відображаються в масштабі 2x, тож роздільність результату вдвічі більша за розміри сторінки PDF. Стандартна сторінка формату Letter дає зображення приблизно 1 224 x 1 584 пікселів.

## Формат результату

- **Одна сторінка**: `filename.jpg`
- **Кілька сторінок**: `filename_jpgs.zip`, що містить `page_1.jpg`, `page_2.jpg` тощо.

## Сценарії використання

- Створення мініатюр для системи керування документами.
- Надсилання сторінки зі звіту в чаті чи листі, що не підтримує PDF.
- Створення графічних ресурсів із PDF-діаграм чи ілюстрацій.
- Архівування відсканованих документів як окремих зображень.

## Поради

- Для результату без втрат скористайтеся [PDF у PNG](./pdf-to-png).
- Якість 80-90% забезпечує добрий баланс між розміром файлу та візуальною точністю.
- Якщо для кожної сторінки потрібен певний формат, зверніть увагу на [Конструктор PDF-процесів](./pdf-workflow), де є вихідний вузол «PDF у зображення».

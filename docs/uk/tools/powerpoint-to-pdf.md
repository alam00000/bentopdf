# PowerPoint у PDF

Конвертуйте файли презентацій у PDF. Кожен слайд стає сторінкою вихідного документа, а текст, зображення, фігури та переходи відтворюються через рушій LibreOffice, що працює в браузері. Підтримуються як сучасні, так і застарілі формати PowerPoint, а також формат OpenDocument Presentation.

## Підтримувані формати

| Формат                    | Розширення |
| :------------------------ | :--------- |
| PowerPoint (сучасний)     | `.pptx`    |
| PowerPoint (застарілий)   | `.ppt`     |
| OpenDocument Presentation | `.odp`     |

## Як це працює

1. Натисніть область завантаження або перетягніть файли презентацій.
2. Перегляньте список файлів. Додайте інші або видаліть зайві.
3. Натисніть **Конвертувати в PDF**. Рушій LibreOffice завантажується під час першого використання, потім конвертує кожен файл.
4. Один файл завантажується одразу як PDF. Кілька файлів пакуються в `powerpoint-converted.zip`.

## Параметри

Цей інструмент не має додаткових налаштувань. Слайди відтворюються у своїх початкових розмірах.

## Результат

| Кількість вхідних файлів | Результат                                                          |
| :----------------------- | :----------------------------------------------------------------- |
| 1 файл                   | Одне завантаження PDF (початкова назва файлу з розширенням `.pdf`) |
| 2+ файли                 | Архів ZIP (`powerpoint-converted.zip`) з одним PDF на кожен файл   |

## Сценарії використання

- Конвертація презентації в PDF перед відправкою аудиторії, яка може не мати PowerPoint
- Створення версії слайдів для друку як роздатковий матеріал для конференції чи воркшопу
- Архівування презентацій у форматі, що однаково відображається на кожному пристрої
- Пакетна конвертація бібліотеки презентацій ODP з LibreOffice Impress у PDF
- Створення PDF-версії pitch deck для вкладення в електронний лист

## Поради

- Анімації та переходи слайдів у PDF не передаються. Кожен слайд зберігається як статична сторінка.
- Вбудовані відео у вихідному файлі не відображатимуться. За потреби замініть їх знімком екрана або зображенням-заповнювачем.
- Нотатки доповідача не входять до стандартного експорту в PDF. Якщо нотатки потрібні, спершу експортуйте з власного режиму «Друк нотаток» у PowerPoint.
- Рушій LibreOffice кешується після першого завантаження, тому конвертація другої презентації в тому ж сеансі набагато швидша.

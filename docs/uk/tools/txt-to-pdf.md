# Текст у PDF

Конвертуйте звичайний текст у відформатований PDF. Можна завантажити файли `.txt` або ввести текст прямо у вбудований текстовий редактор. Інструмент підтримує кілька шрифтів, власні кольори тексту та широкий вибір розмірів сторінок: від A0 до A10, а також US Letter, Legal і Tabloid.

## Підтримувані формати

| Вхідні дані             | Розширення                     |
| :---------------------- | :----------------------------- |
| Звичайні текстові файли | `.txt`                         |
| Пряме введення тексту   | Введіть або вставте в редактор |

## Як це працює

1. Виберіть режим введення за допомогою перемикача вгорі: **Завантажити файли** або **Ввести текст**.
2. Якщо завантажуєте, перетягніть або клацніть, щоб вибрати один чи кілька файлів `.txt`. Якщо вводите, введіть текст прямо в текстове поле.
3. Налаштуйте параметри форматування: гарнітуру шрифту, розмір шрифту, колір тексту та розмір сторінки.
4. Натисніть **Створити PDF**. Результат завантажується як `text_to_pdf.pdf`.

Під час завантаження кількох файлів їхній вміст об’єднується з порожніми рядками між ними.

## Параметри

| Параметр             | Значення                                                                                   | За замовчуванням |
| :------------------- | :----------------------------------------------------------------------------------------- | :--------------- |
| **Гарнітура шрифту** | Helvetica (без засічок), Tiro (із засічками), Courier (моноширинний), Times (із засічками) | Helvetica        |
| **Розмір шрифту**    | 6 -- 72 pt                                                                                 | 12               |
| **Колір тексту**     | Будь-який колір через вибір кольору                                                        | Чорний (#000000) |
| **Розмір сторінки**  | ISO A0--A10, B0--B10, C0--C10, US Letter, Legal, Tabloid, Ledger, 11x17                    | A4               |

Мови з письмом справа наліво (арабська, іврит, перська, урду) визначаються автоматично. Коли знайдено текст RTL, напрям тексту й вирівнювання відповідно перемикаються.

## Сценарії використання

- Конвертація фрагментів коду або файлів журналів у PDF для друку шрифтом Courier
- Швидке створення PDF із нотаток зустрічі, набраних на місці
- Форматування рукопису у вигляді звичайного тексту певним шрифтом і розміром сторінки для подання
- Створення PDF-версії README або журналу змін для офлайн-розповсюдження

## Поради

- Скористайтеся режимом **Ввести текст**, коли потрібно швидко конвертувати вміст буфера обміну, не зберігаючи його спершу у файл.
- Courier (моноширинний) є найкращим вибором шрифту для коду, журналів або будь-якого вмісту, де важливе вирівнювання стовпців.
- Поля сторінки фіксовані на 72 пунктах (1 дюйм) з усіх боків.

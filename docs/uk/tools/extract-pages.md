# Витяг сторінок

Витягуйте набір сторінок із PDF і зберігайте їх як новий файл. Вкажіть потрібні сторінки за синтаксисом діапазонів, і інструмент створить чистий PDF лише з ними.

## Як це працює

1. Завантажте файл PDF. Інструмент покаже назву файлу, розмір і загальну кількість сторінок.
2. Введіть сторінки для витягування за синтаксисом діапазонів (наприклад, `1-5`, `3, 7, 10-12`).
3. За бажання виберіть завантаження кожного діапазону як окремого PDF у ZIP-архіві.
4. Натисніть кнопку обробки. Витягнуті сторінки завантажаться як новий PDF (або ZIP).

## Можливості

- Гнучкий синтаксис діапазонів: окремі сторінки, діапазони або комбінації через кому
- Показує загальну кількість сторінок після завантаження для зручності
- Можливість отримати один об’єднаний PDF або окремі файли в ZIP
- Зберігає початковий вміст і форматування сторінок

## Сценарії використання

- Витягування короткого резюме (перших кількох сторінок) з довгого звіту
- Витягування одного розділу з PDF-підручника
- Збереження окремих сторінок із пакета форм як самостійних документів
- Створення зразка документа з вибраних сторінок більшого файлу

## Поради

- Нумерація сторінок починається з одиниці. Використовуйте `1` для першої сторінки, а не `0`.
- Щоб видалити сторінки, а не витягнути їх, скористайтеся [Видалити сторінки](./delete-pages): це обернена операція.
- Якщо потрібен візуальний вибір сторінок із мініатюрами, використовуйте [Розділити PDF](./split-pdf) у режимі «Вибрати сторінки візуально».

# PDF у CBZ

Перетворює PDF на файл CBZ (Comic Book ZIP), стандартний формат цифрових коміксів і манґи. Кожна сторінка PDF стає зображенням в архіві. Інструмент створює метадані в трьох форматах для максимальної сумісності: ComicInfo.xml, metadata.opf і ComicBookInfo JSON.

## Як це працює

1. Завантажте PDF, натиснувши на область завантаження або перетягнувши файл.
2. Оберіть формат зображень, якість, масштаб і необов’язкові метадані.
3. Натисніть **Конвертувати**, щоб створити файл CBZ.
4. Файл `.cbz` завантажується автоматично.

## Параметри

| Параметр         | Значення        | За замовчуванням | Опис                                                                                              |
| ---------------- | --------------- | ---------------- | ------------------------------------------------------------------------------------------------- |
| Формат зображень | JPEG, PNG, WebP | JPEG             | JPEG для кольорових коміксів, PNG для чорно-білої манґи без втрат, WebP для найкращого стиснення. |
| Якість           | 50–100%         | 85%              | Керує стисненням JPEG/WebP. Приховано для PNG (завжди без втрат).                                 |
| Масштаб          | 1.0x–4.0x       | 2.0x             | Вищий масштаб дає чіткіші зображення для екранів високої роздільності.                            |
| Відтінки сірого  | Увімк./Вимк.    | Вимк.            | Перетворює сторінки на відтінки сірого. Зменшує розмір файлу для чорно-білого вмісту.             |
| Режим манґи      | Увімк./Вимк.    | Вимк.            | Задає в метаданих напрямок читання справа наліво.                                                 |
| Додати метадані  | Увімк./Вимк.    | Увімк.           | Вбудовує ComicInfo.xml, metadata.opf і ComicBookInfo JSON.                                        |

## Поля метаданих

Коли метадані ввімкнено, можна заповнити:

- **Назва**: автоматично визначається з імені файлу PDF.
- **Серія**: назва серії (напр., "Naruto").
- **Номер (#)**: номер випуску в серії.
- **Том**: номер тому.
- **Автор(и)**: ім’я сценариста або творця.
- **Видавець**: видавнича компанія.
- **Теги / Жанр**: теги через кому (напр., "Action, Adventure").
- **Рік видання**: рік публікації (1900–2100).
- **Рейтинг**: оцінка спільноти від 0 до 5.

## Сумісність метаданих

Інструмент записує метадані в трьох форматах, щоб їх знайшла кожна читалка:

| Формат             | Розташування       | Підтримується в                             |
| ------------------ | ------------------ | ------------------------------------------- |
| ComicInfo.xml      | Файл усередині ZIP | Komga, Kavita, CDisplayEx, Mylar, ComicRack |
| metadata.opf       | Файл усередині ZIP | Calibre                                     |
| ComicBookInfo JSON | Поле коментаря ZIP | Calibre (запасний варіант)                  |

## Формат результату

- `filename.cbz`: ZIP-архів із пронумерованими зображеннями сторінок і файлами метаданих.

Зображення сторінок мають імена з нулями попереду (`01.jpg`, `02.jpg` тощо), щоб читалки показували їх у правильному порядку.

## Сценарії використання

- Конвертація PDF манґи чи коміксів для читалок коміксів.
- Створення цифрової бібліотеки коміксів у Komga, Kavita або Calibre.
- Перетворення відсканованих коміксів на зручний для читалок формат.
- Обмін коміксами у форматі, що зберігає напрямок читання та метадані.

## Поради

- Використовуйте **JPEG** для кольорових коміксів і **PNG** для чорно-білої манґи: PNG дуже ефективно стискає чорно-білий вміст.
- Увімкніть **Відтінки сірого** для манґи, щоб суттєво зменшити розмір файлу.
- Заповніть поля **Серія** та **Номер**, щоб менеджери бібліотек (Komga, Calibre) могли автоматично впорядкувати вашу колекцію.
- **WebP** забезпечує найкраще стиснення, але старіші читалки коміксів можуть його не підтримувати.

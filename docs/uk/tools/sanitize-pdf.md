# Очистити PDF

PDF можуть містити набагато більше, ніж ви бачите на екрані. Приховані метадані, вбудований JavaScript, вкладені файли, дані форм та інформація про шари можуть розкрити конфіденційні дані або становити загрозу безпеці. Очищення прибирає все це, залишаючи чистий документ, безпечний для публічного поширення.

## Як це працює

1. Завантажте файл PDF.
2. Виберіть у списку, які елементи видалити.
3. Натисніть **Очистити PDF**.
4. Завантажте очищений файл.

## Параметри очищення

Усі параметри ввімкнено за замовчуванням. Зніміть позначку з тих, які хочете зберегти.

| Параметр                      | Що видаляється                                                             |
| ----------------------------- | -------------------------------------------------------------------------- |
| **Сплющити форми**            | Перетворює інтерактивні поля форм на статичний вміст                       |
| **Видалити метадані**         | Прибирає автора, назву, дату створення, відомості про програму та дані XMP |
| **Видалити анотації**         | Видаляє коментарі, виділення, стікери та розмітку                          |
| **Видалити JavaScript**       | Усуває вбудовані скрипти, які можуть виконатися під час відкриття          |
| **Видалити вбудовані файли**  | Прибирає вкладені файли, вбудовані в PDF                                   |
| **Видалити шари (OCG)**       | Зводить групи необов’язкового вмісту в один шар                            |
| **Видалити посилання**        | Прибирає гіперпосилання та посилання на URL                                |
| **Видалити дерево структури** | Видаляє структуру документа, яку використовують для тегування доступності  |
| **Видалити MarkInfo**         | Прибирає інформацію про позначений вміст                                   |
| **Видалити шрифти**           | Видаляє дані вбудованих шрифтів (використовуйте обережно)                  |

## Сценарії використання

- Підготовка PDF до публічного випуску шляхом видалення внутрішніх метаданих (імена авторів, версії програм, історія редагування)
- Видалення JavaScript із PDF, отриманого з ненадійного джерела, перед його відкриттям
- Очищення PDF перед відправкою клієнту, який не повинен бачити вбудовані коментарі чи назви полів форм
- Видалення прихованих шарів з архітектурного креслення перед поширенням остаточної версії
- Дотримання вимог мінімізації даних відповідно до нормативів із конфіденційності

## Поради

- Не позначайте «Видалити вбудовані шрифти», якщо не впевнені, що PDF і далі відображатиметься правильно. Видалення шрифтів може зробити текст невидимим у деяких переглядачах.
- Якщо потрібно видалити лише метадані, спеціальний інструмент «Видалити метадані» швидший і більш цілеспрямований.
- Очищення незворотне. Збережіть оригінальний файл.

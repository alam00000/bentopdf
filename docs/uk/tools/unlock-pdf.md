# Розблокувати PDF

Якщо ви знаєте пароль до зашифрованого PDF, цей інструмент повністю прибирає шифрування й створює розблоковану копію, яку будь-хто може відкрити без пароля. Він підтримує пакетне розшифрування, коли кілька PDF мають однаковий пароль.

## Як це працює

1. Завантажте один або кілька зашифрованих PDF-файлів.
2. Введіть **пароль**, яким захищено файли.
3. Натисніть **Розшифрувати PDF**.
4. Один файл завантажується напряму. Для кількох файлів створюється ZIP-архів з усіма розблокованими PDF.

## Можливості

- Розшифрування одного файлу та пакетне розшифрування
- Працює і з паролями користувача, і з паролями власника
- Повністю нешифрований результат без залишкових обмежень
- Зрозумілі повідомлення про неправильний пароль або пошкоджені файли
- Облік успіху чи помилки для кожного файлу в пакетному режимі

## Чим відрізняється від «Видалити обмеження»

**Розшифрувати PDF** потребує пароль і прибирає все шифрування. **Видалити обмеження** працює з обмеженнями на використання (друк, копіювання, редагування) і може не потребувати пароля, якщо встановлено лише пароль власника. Використовуйте «Розшифрувати», коли PDF взагалі не відкривається без пароля.

## Сценарії використання

- Остаточне розблокування PDF, які ви шифрували раніше, коли пароль більше не потрібен
- Зняття шифрування з пакета архівних документів для зручнішого довгострокового доступу
- Підготовка захищених паролем PDF для системи керування документами, яка не підтримує зашифровані файли
- Розблокування PDF перед об'єднанням з іншими документами (багато інструментів об'єднання не обробляють зашифровані файли)

## Поради

- Поле пароля діє для всіх завантажених файлів. Якщо в ваших PDF різні паролі, обробляйте їх окремими пакетами.
- Якщо ви бачите помилку «Неправильний пароль», перевірте, чи немає зайвих пробілів у кінці та чи не ввімкнено Caps Lock.
- Після розшифрування результат не має жодного захисту. Якщо потрібен новий пароль, зашифруйте файл знову через «Зашифрувати PDF».

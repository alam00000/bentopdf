# Порівняти PDF

Завантажте два PDF і побачте, що саме змінилося між ними. Інструмент розумно зіставляє сторінки, виявляє відмінності в тексті, зображеннях, анотаціях, колонтитулах і форматуванні та показує їх у режимі поруч або накладання.

## Як це працює

1. Завантажте два файли PDF: оригінал (ліворуч) і змінену версію (праворуч).
2. Інструмент зіставляє сторінки документів за сигнатурами вмісту.
3. Виберіть режим перегляду: **Пліч-о-пліч** або **Накладання**.
4. Переходьте між парами сторінок за допомогою елементів керування пагінацією.
5. Відмінності підсвічуються та класифікуються. Скористайтеся панеллю фільтрів, щоб зосередитися на певних типах змін.
6. За бажання експортуйте порівняння як звіт у PDF.

## Можливості

- Автоматичне зіставлення сторінок за схожістю вмісту
- Режими порівняння поруч і з накладанням
- Класифікація змін: текст, зображення, колонтитули, анотації, форматування, тло
- Перемикачі фільтрів за категоріями, щоб показувати або ховати певні типи змін
- Пошук змін у тексті з фільтрацією за запитом
- Підтримка OCR для порівняння відсканованих документів
- Елементи керування масштабом для детального огляду
- Синхронна прокрутка панелей у режимі поруч
- Експорт результатів порівняння у PDF

## Параметри

| Параметр              | Опис                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------ |
| **Режим перегляду**   | Пліч-о-пліч або накладання                                                                 |
| **OCR**               | Увімкнення чи вимкнення OCR для порівняння відсканованих документів                        |
| **Мова OCR**          | Мова для розпізнавання тексту OCR                                                          |
| **Фільтри категорій** | Показ або приховування змін тексту, зображень, колонтитулів, анотацій, форматування та тла |
| **Обсяг змін**        | У режимі накладання: усі зміни або лише зміни вмісту                                       |
| **Масштаб**           | Налаштування масштабу для детального огляду                                                |

## Сценарії використання

- Перегляд редакцій договору, щоб знайти, що саме змінилося між версіями
- Порівняння макетів дизайну, щоб переконатися, що експорт у PDF відповідає очікуванням
- Аудит змін у документах у регульованих галузях, де потрібно відстежувати кожну правку
- Перевірка того, що процес конвертації в PDF точно зберіг початковий вміст
- Звірення перекладених документів з оригіналом на предмет змін у верстці

## Поради

- Режим накладання розміщує обидва документи один на одному, тож просторові відмінності (зсунуті елементи, змінені зображення) одразу помітні.
- Вмикайте OCR, коли порівнюєте скановані документи без текстового шару. Рушій порівняння витягне текст із зображень сторінок.
- Використовуйте фільтри категорій, щоб зосередитися на важливому. Наприклад, сховайте зміни форматування, якщо вас цікавлять лише відмінності в тексті.

# Змінити дозволи

Точно налаштуйте, що можуть робити отримувачі з вашим PDF. На відміну від звичайного шифрування, яке лише закриває файл паролем, цей інструмент дозволяє вибірково дозволяти або забороняти друк, копіювання, редагування, коментування, заповнення форм, складання документа та вилучення сторінок, і все це забезпечується 256-бітним шифруванням AES.

## Як це працює

1. Завантажте файл PDF.
2. Якщо PDF уже зашифровано, введіть **Поточний пароль**.
3. Задайте **Новий пароль користувача** (потрібен для відкриття) та/або **Новий пароль власника** (керує дозволами).
4. Увімкніть або вимкніть окремі дозволи за допомогою прапорців.
5. Натисніть **Змінити дозволи**.
6. Завантажте оновлений PDF.

Якщо залишити обидва поля нових паролів порожніми, інструмент повністю розшифрує PDF і зніме все шифрування та обмеження.

## Керування дозволами

| Дозвіл                             | Що він контролює                                    |
| ---------------------------------- | --------------------------------------------------- |
| **Дозволити друк**                 | Чи можна друкувати документ                         |
| **Дозволити копіювання тексту**    | Чи можна виділяти та копіювати текст і зображення   |
| **Дозволити зміни**                | Чи можна редагувати вміст документа                 |
| **Дозволити анотування**           | Чи можна додавати коментарі, виділення та штампи    |
| **Дозволити заповнення форм**      | Чи можна заповнювати інтерактивні поля форм         |
| **Дозволити складання документа**  | Чи можна вставляти, видаляти або повертати сторінки |
| **Дозволити видобування сторінок** | Чи можна вилучати окремі сторінки                   |

Для дії всіх дозволів потрібен пароль власника. Без пароля власника прапорці дозволів ігнорує більшість програм для читання PDF.

## Як працюють дозволи в PDF

Дозволи PDF є частиною специфікації шифрування. Вони зберігаються як бітові прапорці в словнику шифрування, і їх застосовують сумісні програми для читання PDF. Ключова відмінність:

- **Пароль користувача**: потрібен, щоб узагалі відкрити файл.
- **Пароль власника**: потрібен, щоб змінити дозволи або зняти обмеження. Без нього прапорці дозволів визначають, які операції може виконувати користувач.

Якщо задати лише пароль власника (без пароля користувача), файл зможе відкрити будь-хто, але лише з дозволеними операціями. Якщо задати обидва, для відкриття файлу потрібен пароль, а після автентифікації діють обмеження.

## Сценарії використання

- Розповсюдження звіту, який можна переглядати й друкувати, але не редагувати чи копіювати
- Надання шаблону договору, який отримувачі можуть заповнити, але не змінювати
- Публікація PDF-каталогу із забороненим копіюванням зображень
- Дозвіл коментувати чернетку для рецензії із забороною структурних змін

## Поради

- Щоб дозволи діяли, завжди задавайте пароль власника. Дозволи без пароля власника неможливо забезпечити.
- Деякі сторонні інструменти для PDF ігнорують прапорці дозволів. Для надійнішого захисту розгляньте растеризацію PDF або DRM.
- Скористайтеся цим інструментом, щоб оновити старі PDF із шифруванням RC4 до AES-256.

# Повернути PDF

Повертайте сторінки PDF на 90 градусів за годинниковою стрілкою або проти неї. Інструмент показує мініатюри всіх сторінок, дозволяючи повертати їх окремо або застосувати масовий поворот до всього документа.

## Як це працює

1. Завантажте файл PDF. Мініатюри всіх сторінок відображаються в сітці.
2. Скористайтеся кнопками повороту вліво/вправо під мініатюрою сторінки, щоб повернути саме цю сторінку.
3. Скористайтеся елементами масового повороту вгорі, щоб повернути всі сторінки одразу.
4. Попередній перегляд мініатюр оновлюється в реальному часі, показуючи поворот.
5. Натисніть кнопку обробки, щоб зберегти повернутий PDF.

## Можливості

- Поворот окремих сторінок з кроком 90 градусів (вліво або вправо)
- Масовий поворот усіх сторінок одночасно
- Попередній перегляд мініатюр у реальному часі з анімованими переходами повороту
- Відкладене завантаження мініатюр для плавної роботи на великих документах
- Зберігає початковий вміст сторінок і якість

## Сценарії використання

- Виправлення сканованих сторінок, що лежать на боці або догори дном
- Поворот альбомних сторінок у книжкову орієнтацію (або навпаки)
- Виправлення документа зі змішаною орієнтацією, де деякі сторінки було відскановано під неправильним кутом
- Підготовка документа для певної орієнтації відображення

## Поради

- Повороти накопичуються. Двічі натиснувши кнопку за годинниковою стрілкою, ви застосуєте поворот на 180 градусів.
- Для поворотів не на 90 градусів (наприклад, на 45 градусів, щоб виправити трохи нахилений скан) скористайтеся [Повернути на довільний кут](./rotate-custom).
- Елементи масового повороту впливають на всі сторінки, а не лише на вибрані. У цьому інструменті немає механізму вибору: для цього скористайтеся [PDF мультиінструмент](./pdf-multi-tool).

# Створити PDF-форму

Створюйте професійні PDF-форми для заповнення з нуля або додавайте поля до наявного PDF. Візуальний редактор дозволяє перетягувати елементи форми (текстові поля, прапорці, випадні списки, радіокнопки, поля підпису та інше) безпосередньо на попередній перегляд сторінок. Налаштовуйте властивості полів, задавайте правила умовної видимості та експортуйте повністю інтерактивну PDF-форму.

## Як це працює

1. Завантажте наявний PDF **або** натисніть **Створити порожній PDF**, щоб почати з нуля.
2. Якщо створюєте порожній PDF, оберіть розмір сторінки (Letter, A4, A5, Legal, Tabloid, A3 або власні розміри).
3. Відкриється редактор форм із панеллю типів полів і областю попереднього перегляду сторінки.
4. Оберіть тип поля на панелі, а потім клацніть на сторінці, щоб його розмістити.
5. Перетягуйте поля, щоб змінити їхнє положення. Маркерами зміни розміру коригуйте розміри.
6. Клацніть поле, щоб відкрити панель властивостей, де можна задати ім’я поля, значення за замовчуванням, розмір шрифту, вирівнювання та інше.
7. Переходьте між сторінками за допомогою елементів керування сторінками.
8. Натисніть **Зберегти**, щоб завантажити готовий PDF для заповнення.

## Можливості

- Розміщення полів перетягуванням із візуальними маркерами зміни розміру
- Типи полів: текстове, багаторядкове, прапорець, випадний список, радіокнопка, підпис, дата, число та штрихкод
- Панель властивостей для налаштування імені, мітки, значення за замовчуванням, розміру шрифту, кольору, вирівнювання та перевірки кожного поля
- Дії полів і правила умовної видимості (показ або приховування полів залежно від значень інших полів)
- Навігація сторінками для багатосторінкових форм
- Витягування наявних полів: автоматичне виявлення та імпорт полів форм із завантажених PDF
- Підтримка як завантажених PDF, так і порожніх сторінок як основи форми
- Кілька готових розмірів сторінки та власні розміри
- Генерація штрихкодів на основі bwip-js
- Керування групами радіокнопок

## Параметри

**Готові розміри сторінки (для порожніх PDF):**

- Letter (8.5" x 11")
- A4 (210mm x 297mm)
- A5 (148mm x 210mm)
- Legal (8.5" x 14")
- Tabloid (11" x 17")
- A3 (297mm x 420mm)
- Власний (вкажіть ширину та висоту)

**Властивості полів (залежать від типу поля):**

- Ім’я, мітка та текст-підказка
- Значення за замовчуванням
- Гарнітура, розмір і колір шрифту
- Вирівнювання тексту (ліворуч, по центру, праворуч)
- Перемикач обов’язкового поля
- Перемикач «лише для читання»
- Максимальна довжина для текстових полів
- Список варіантів для випадних списків і радіокнопок
- Дії умовної видимості

## Сценарії використання

- Створення форм для прийому нових співробітників із текстовими полями для особистих даних і прапорцями для підтвердження політик
- Створення анкет для нових клієнтів із випадними списками для вибору послуги
- Розробка бланків замовлення з обчислюваними полями та штрихкодами-ідентифікаторами
- Створення контрольних списків для інспекцій із радіокнопками для оцінок «пройдено/не пройдено»
- Створення опитувань з умовними уточнювальними запитаннями, що з’являються залежно від відповідей

## Поради

- Якщо ви завантажуєте наявний PDF, інструмент спробує витягти всі наявні поля форм, щоб ви могли редагувати їх або додавати нові.
- Використовуйте групи радіокнопок для взаємовиключних варіантів. Поля в одній групі мають спільне ім’я групи.
- Перевірте форму: завантажте її та відкрийте в інструменті [Заповнення PDF-форм](./form-filler), щоб переконатися, що поля працюють правильно.

# Видалити порожні сторінки

Проскануйте PDF на наявність порожніх або майже порожніх сторінок і видаліть їх автоматично. Інструмент відтворює кожну сторінку та аналізує її пікселі, щоб визначити, чи вона порожня, а потім дозволяє підтвердити, які сторінки видалити, перед обробкою.

## Як це працює

1. Завантажте файл PDF.
2. Налаштуйте повзунок **Чутливість**, щоб керувати суворістю визначення «порожньої» сторінки.
3. Натисніть **Знайти порожні сторінки**, щоб просканувати документ.
4. Інструмент показує мініатюри виявлених порожніх сторінок, щоб ви могли їх переглянути.
5. Підтвердьте вибір і завантажте очищений PDF без порожніх сторінок.

## Параметри

- **Чутливість**: повзунок від 0% до 100% (за замовчуванням 80%). Вищі значення суворіші й позначають лише повністю або майже білі сторінки. Нижчі значення поблажливіші й ловлять сторінки з мінімальним вмістом, як-от одна крапка чи ледь помітний водяний знак.

## Можливості

- Піксельний аналіз кожної сторінки для виявлення порожнього вмісту
- Регульований повзунок чутливості для точного налаштування виявлення
- Попередній перегляд мініатюр виявлених порожніх сторінок для ручної перевірки
- Зберігає всі непорожні сторінки без змін
- Працює з документами будь-якого розміру та кількості сторінок
- Індикація прогресу під час сканування

## Сценарії використання

- Очищення сканованих документів, де сканер захопив порожні зворотні боки односторонніх оригіналів
- Видалення роздільних сторінок з пакетів документів, відсканованих масово
- Видалення порожніх сторінок, вставлених системами керування документами
- Очищення PDF, експортованих з текстових процесорів, які іноді додають порожні сторінки в кінці
- Зменшення розміру файлу шляхом видалення непотрібних порожніх сторінок

## Поради

- Почніть зі стандартної чутливості 80% і коригуйте звідти. Якщо інструмент пропускає сторінки, які вам здаються порожніми, зменште чутливість. Якщо він позначає сторінки з легким вмістом, який ви хочете залишити, збільште її.
- Інструмент відтворює кожну сторінку для аналізу вмісту, тому час обробки залежить від кількості сторінок. Для дуже великих документів доведеться трохи зачекати.
- Перегляньте виявлені порожні сторінки в мініатюрах перед підтвердженням видалення. Сторінки зі слабкими колонтитулами чи водяними знаками можуть бути позначені залежно від налаштувань чутливості.

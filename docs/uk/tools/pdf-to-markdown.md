# PDF у Markdown

Конвертує файли PDF у формат Markdown (`.md`), зберігаючи заголовки, абзаци, списки та базове форматування. За бажанням витягує й додає вбудовані зображення. Підтримує одиночну та пакетну конвертацію. Працює на PyMuPDF.

## Як це працює

1. Завантажте один чи кілька PDF, натиснувши на область завантаження або перетягнувши файли.
2. За бажанням увімкніть **Додати зображення**, щоб вбудувати витягнуті зображення в результат Markdown.
3. Натисніть **Конвертувати**, щоб почати обробку.
4. Один файл завантажується як `filename.md`. Кілька файлів створюють `markdown-files.zip`.

## Параметри

- **Додати зображення**: якщо позначено, вбудовані в PDF зображення витягуються й додаються як посилання в результат Markdown. Якщо не позначено, конвертується лише текстовий вміст.

## Формат результату

- **Один файл**: `filename.md`
- **Кілька файлів**: `markdown-files.zip`, що містить по одному `.md` на кожен вхідний PDF.

## Сценарії використання

- Конвертація PDF-документації в Markdown для генератора статичних сайтів, як-от VitePress, Hugo чи Jekyll.
- Перетворення PDF-статей на редагований Markdown для застосунків нотаток, як-от Obsidian.
- Міграція застарілих баз знань у PDF у текстовий формат, зручний для Git.
- Витяг структурованого вмісту з PDF-книг для переформатування.

## Поради

- Параметр «Додати зображення» корисний, коли PDF містить діаграми чи рисунки, важливі для змісту. Для текстових документів вимкніть його, щоб результат був чистішим.
- Складні макети з бічними колонками, виносками чи багатоколонковим текстом можуть дати недосконалий Markdown. Перегляньте результат і за потреби відкоригуйте.
- Для сирого тексту без форматування скористайтеся [PDF у текст](./pdf-to-text).

# Розділити PDF

Розбийте PDF на менші документи в одному з шести режимів поділу. Від простих діапазонів сторінок до поділу за закладками, цей інструмент охоплює кожен сценарій розділення документа.

## Як це працює

1. Завантажте один файл PDF.
2. Виберіть режим поділу зі списку.
3. Налаштуйте параметри, специфічні для режиму (діапазони сторінок, вибір тощо).
4. Натисніть кнопку обробки.
5. Результат завантажується як один PDF або архів ZIP залежно від режиму та налаштувань.

## Режими поділу

| Режим                | Опис                                                                                                                           |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Діапазон**         | Введіть діапазони сторінок, як-от `1-3, 5, 8-10`. Кілька діапазонів дають окремі PDF в архіві ZIP. Один діапазон дає один PDF. |
| **Візуальний вибір** | Переглядайте мініатюри сторінок і клацайте, щоб вибрати потрібні сторінки. Вибрані сторінки витягуються в новий PDF.           |
| **Парні / Непарні**  | Витягніть лише сторінки з парними або непарними номерами.                                                                      |
| **Усі сторінки**     | Розділіть кожну сторінку на окремий файл PDF, що завантажується як ZIP.                                                        |
| **Закладки**         | Розділення за межами закладок. Виберіть рівень закладок, щоб керувати місцями поділу.                                          |
| **Кожні N сторінок** | Розділіть на частини по N сторінок (наприклад, кожні 5 сторінок). Остання частина може мати менше сторінок.                    |

## Можливості

- Шість окремих режимів поділу, що охоплюють практично всі сценарії
- Візуальний вибір сторінок із відкладеним завантаженням мініатюр
- Поділ за закладками з фільтрацією за рівнем
- Варіант виводу в ZIP для режимів діапазону та візуального вибору
- Обробка діапазонів сторінок зі змішаним синтаксисом (`1-3, 5, 8-10`)
- Попередження, коли поділ на N сторінок дає нерівні частини

## Сценарії використання

- Витягування певного розділу чи секції з великого документа
- Розділення непарних і парних сторінок для процесів двостороннього друку
- Розбиття PDF книги на окремі файли розділів за межами закладок
- Виокремлення певних сторінок (як-от сторінки з підписом) з контракту
- Розділення зведеного звіту на файли за розділами для розповсюдження

## Поради

- Кілька діапазонів сторінок, розділених комами (наприклад, `1-5, 10-15, 20-25`), дають окремі PDF, по одному на діапазон, упаковані в ZIP.
- Режим поділу за закладками потребує, щоб PDF справді містив закладки. Якщо їх не знайдено, ви побачите повідомлення про помилку.
- Прапорець «Завантажити як ZIP» у режимах діапазону та візуального вибору дозволяє отримати окремі PDF для кожної сторінки замість єдиного файлу.

# BMP у PDF

Перетворюйте файли Windows Bitmap (BMP) на PDF. BMP є нестисненим форматом зображень, який досі трапляється в застарілих системах, медичній візуалізації та промислових сканерах. Цей інструмент перетворює їх на PDF без жодного встановлення.

## Підтримувані формати

| Формат | Розширення |
| :----- | :--------- |
| BMP    | `.bmp`     |

## Як це працює

1. Клацніть зону завантаження або перетягніть у неї BMP-файли.
2. Перегляньте список файлів. Додайте ще файлів або видаліть зайві.
3. Натисніть **Перетворити на PDF**. Результат завантажиться як `from_bmps.pdf`.

Кожен BMP малюється на полотні (canvas), експортується як PNG і вбудовується в PDF за допомогою pdf-lib. Розмір сторінки відповідає розмірам початкового зображення.

## Параметри

Цей інструмент не має додаткових налаштувань якості. Зображення вбудовуються в початковій роздільності як PNG без втрат.

## Приклади використання

- Перетворення застарілих сканованих документів у форматі BMP на архівні PDF
- Перетворення BMP-знімків екрана зі старіших програм Windows на документи для обміну
- Обробка результатів медичних або промислових сканерів, які за замовчуванням видають BMP
- Міграція старих архівів зображень у більш портативний формат

## Поради

- Файли BMP нестиснені, тому зазвичай великі. Отриманий PDF буде значно меншим, оскільки зображення всередині перекодовуються в PNG.
- Якщо поряд із BMP у вас є зображення інших форматів, скористайтеся інструментом [Зображення у PDF](./image-to-pdf), щоб перетворити все одним пакетом.

# PDF у SVG

Перетворює кожну сторінку PDF на файл SVG (Scalable Vector Graphics). На відміну від растрових форматів, SVG зберігає векторні контури, текст і форми, тож результат масштабується до будь-якого розміру без пікселізації. Працює на PyMuPDF.

## Як це працює

1. Завантажте один чи кілька PDF, натиснувши на область завантаження або перетягнувши файли. Можна додати кілька файлів і керувати ними окремо.
2. Натисніть **Конвертувати**, щоб обробити всі завантажені файли.
3. Конвертація одного файлу з однією сторінкою завантажується як окремий `.svg`. Решта випадків завантажуються як ZIP-архів.

## Параметри

Цей інструмент не має настроюваних параметрів. Кожна сторінка конвертується в SVG за допомогою рідного векторного експорту PyMuPDF.

## Формат результату

- **Один файл, одна сторінка**: `filename.svg`
- **Один файл, кілька сторінок**: `filename_svg.zip`, що містить `page_1.svg`, `page_2.svg` тощо.
- **Кілька файлів**: `pdf_to_svg.zip` з файлами, упорядкованими за назвою вихідного документа.

## Сценарії використання

- Витяг векторних діаграм, графіків чи ілюстрацій із PDF-звітів для використання на веб-сторінках.
- Редагування вмісту сторінок PDF у векторному редакторі, як-от Inkscape чи Illustrator.
- Вбудовування масштабованих попередніх переглядів сторінок в адаптивні веб-застосунки.
- Витяг логотипів чи графіки з PDF-брошур зі збереженням чітких країв.

## Поради

- SVG найкраще працює з PDF, що містять векторний вміст. Скановані документи або PDF із великою кількістю зображень дадуть великі файли SVG із вбудованими растровими даними.
- Для растрового результату PDF із великою кількістю зображень скористайтеся [PDF у PNG](./pdf-to-png) або [PDF у JPG](./pdf-to-jpg).
- Цей інструмент підтримує пакетну конвертацію: завантажте кілька PDF одразу, щоб конвертувати їх за один запуск.

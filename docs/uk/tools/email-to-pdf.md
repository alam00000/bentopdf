# Email у PDF

Перетворюйте збережені файли електронних листів на охайні PDF для друку. Інструмент розбирає файли EML і MSG, витягує повне повідомлення (заголовки, вміст тіла та метадані вкладень) і відображає все у структурованому PDF. Корисно для юридичного розкриття доказів, ведення записів або просто для друку важливого листа.

## Підтримувані формати

| Формат | Розширення | Примітки                                                              |
| :----- | :--------- | :-------------------------------------------------------------------- |
| EML    | `.eml`     | Стандартний формат MIME (експортується з більшості поштових клієнтів) |
| MSG    | `.msg`     | Власний формат Microsoft Outlook                                      |

## Як це працює

1. Клацніть зону завантаження або перетягніть файли EML чи MSG. В одній партії можна поєднувати обидва формати.
2. Перегляньте список файлів. Видаліть непотрібні піктограмою кошика або натисніть **Додати ще файли**, щоб додати інші листи.
3. Налаштуйте параметри перетворення (див. нижче).
4. Натисніть **Конвертувати у PDF**. Інструмент розбирає кожен лист, відображає вміст як стилізований HTML і перетворює його на PDF за допомогою рушія PyMuPDF.
5. Один лист завантажується одразу як PDF. Кілька листів пакуються в `emails-converted.zip`.

## Параметри

| Параметр                                    | За замовчуванням | Опис                                                                                      |
| :------------------------------------------ | :--------------- | :---------------------------------------------------------------------------------------- |
| **Розмір сторінки**                         | A4               | Вибір розміру сторінки: A4, Letter або Legal.                                             |
| **Додати одержувачів CC і BCC у заголовок** | Увімк.           | Якщо ввімкнено, списки одержувачів CC і BCC з’являються в розділі заголовка листа в PDF.  |
| **Додати список вкладень листа**            | Увімк.           | Якщо ввімкнено, у PDF з’являється список вкладених файлів листа (з іменами та розмірами). |

## Сценарії використання

- Архівування важливого ділового листування у PDF для відповідності вимогам чи аудиту
- Друк ланцюжків листів для судових проваджень чи запитів про розкриття доказів
- Створення постійного запису підтверджень замовлень, квитанцій чи договорів, отриманих електронною поштою
- Резервне копіювання файлів Outlook MSG у форматі, для читання якого не потрібен Outlook
- Документування звернень до служби підтримки за експортованими файлами EML

## Поради

- Підтримуються і EML (використовують Thunderbird, Apple Mail і більшість поштових клієнтів), і файли Outlook MSG. Експортуйте листи зі свого поштового клієнта й перетягуйте їх прямо в інструмент.
- Листи у форматі HTML зберігають стилі в PDF. Листи з простим текстом відображаються з охайним, читабельним форматуванням.
- Список вкладень показує імена файлів і розміри, але не вбудовує самі вкладені файли в PDF.

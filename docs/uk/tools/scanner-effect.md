# Ефект сканера

Перетворіть чистий цифровий PDF на документ, що виглядає так, ніби він вийшов із планшетного сканера. Інструмент застосовує налаштовувані шум, невеликий поворот, розмиття, зміни яскравості та за бажанням пожовтіння, щоб імітувати недосконалості фізичного сканування.

## Як це працює

1. Завантажте файл PDF.
2. Відкривається редактор із попереднім переглядом першої сторінки в реальному часі поряд із панеллю налаштувань.
3. Налаштуйте параметри ефекту сканування повзунками та перемикачами.
4. Попередній перегляд оновлюється в реальному часі під час зміни налаштувань.
5. Натисніть **Застосувати**, щоб обробити всі сторінки й завантажити результат.

## Параметри

- **Колірний простір (перемикач градацій сірого)**: конвертуйте результат у градації сірого для класичного чорно-білого вигляду скану.
- **Рамка**: додайте ледь помітну темну рамку по краях сторінки, щоб імітувати артефакти країв сканера.
- **Поворот**: застосуйте невеликий поворот (від -5 до +5 градусів), щоб імітувати перекошену подачу паперу.
- **Варіація повороту**: додайте випадкову варіацію кута повороту, щоб кожна сторінка була нахилена трохи по-іншому.
- **Яскравість**: змістіть загальну яскравість вгору або вниз.
- **Контраст**: налаштуйте контраст, щоб імітувати відмінності якості тонера.
- **Розмиття**: застосуйте розмиття за Гауссом, щоб пом’якшити краї тексту, як у скані низької якості.
- **Шум**: додайте випадковий піксельний шум, щоб імітувати зернистість сенсора сканера. Вищі значення дають зернистіший результат.
- **Жовтуватість**: додайте теплий жовтий відтінок, щоб імітувати старий або перероблений папір.
- **Роздільна здатність**: задайте DPI результату. Нижчі значення створюють піксельніший вигляд, схожий на скан.
- **Скинути**: поверніть усі налаштування до значень за замовчуванням.

## Можливості

- Попередній перегляд у реальному часі, що оновлюється під час зміни кожного параметра
- Випадкова варіація повороту для кожної сторінки для реалістичної різноманітності
- Десять параметрів, що налаштовуються незалежно
- Режим градацій сірого для автентичного чорно-білого результату
- Керування роздільною здатністю від якості факсу з низьким DPI до архівної якості з високим DPI

## Сценарії використання

- Створення враження, що цифрові документи було відскановано та надруковано
- Імітація фізичного старіння документів для відтворення історичних документів
- Тестування програм OCR на погіршеній якості скану
- Створення документів, що відповідають візуальному стилю наявних сканованих архівів

## Поради

- Починайте з м’яких значень. Рівень шуму 10-20, невеликий поворот 0,5 градуса та мінімальне розмиття вже дають переконливий вигляд скану.
- Поєднайте режим градацій сірого з легким пожовтінням для ефекту «ксерокопії ксерокопії».
- Нижчі значення роздільної здатності (100-150 DPI) створюють найреалістичніший вигляд факсу.

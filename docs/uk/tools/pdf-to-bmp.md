# PDF у BMP

Перетворює кожну сторінку PDF на зображення BMP (Bitmap). BMP є нестисненим форматом, тому результат піксель у піксель без втрати якості, але файли великі.

## Як це працює

1. Завантажте PDF, натиснувши на область завантаження або перетягнувши файл.
2. Натисніть **Конвертувати** для обробки файлу.
3. Один файл `.bmp` або ZIP-архів завантажується автоматично.

## Параметри

Цей інструмент не має настроюваних параметрів. Сторінки відображаються у фіксованому масштабі 2x, тож зображення приблизно вдвічі більші за рідні розміри сторінки PDF.

## Формат результату

- **Одна сторінка**: `filename.bmp`
- **Кілька сторінок**: `filename_bmps.zip`, що містить `page_1.bmp`, `page_2.bmp` тощо.

## Сценарії використання

- Передавання сторінок PDF у застарілі системи або обладнання, що приймають лише BMP.
- Підготовка нестиснутих зображень для певних друкарських процесів.
- Використання растрового результату як вводу для інструментів обробки зображень, що потребують сирих пікселів.

## Поради

- Файли BMP дуже великі, бо зберігають сирі дані пікселів без стиснення. Для більшості завдань [PDF у PNG](./pdf-to-png) дає якість без втрат і значно менші файли.
- Якщо ваша система приймає PNG або TIFF, віддайте перевагу цим форматам, щоб заощадити місце на диску.

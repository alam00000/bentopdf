# Дублювати та впорядкувати

Змінюйте порядок, дублюйте та видаляйте сторінки PDF у наочному інтерфейсі з перетягуванням. Кожна сторінка відображається як мініатюра, яку можна перемістити, клонувати або видалити, перш ніж зберегти результат як новий файл.

## Як це працює

1. Завантажте один файл PDF.
2. Інструмент відобразить сітку мініатюр усіх сторінок.
3. Перетягуйте мініатюри, щоб змінити порядок сторінок, натисніть зелену кнопку дублювання, щоб клонувати сторінку, або червону кнопку видалення, щоб прибрати її.
4. Також можна ввести власний порядок сторінок у текстовому полі (напр., `3, 1, 2, 4`) і натиснути **Застосувати**, щоб одразу переставити всі сторінки.
5. Натисніть кнопку обробки, щоб зібрати та завантажити впорядкований PDF.

## Можливості

- Зміна порядку сторінок перетягуванням з анімованими переходами
- Кнопки дублювання та видалення для кожної сторінки
- Введення власного порядку сторінок для точного переставляння
- Номери сторінок автоматично оновлюються після кожної зміни
- Не дозволяє видалити останню сторінку

## Сценарії використання

- Переміщення сторінки, що опинилася не на своєму місці, на правильну позицію у звіті
- Дублювання сторінки форми, щоб мати кілька порожніх копій в одному файлі
- Видалення чернеткових або службових сторінок перед розповсюдженням документа
- Зворотний або довільний порядок сторінок для підготовки до друку
- Створення власної послідовності сторінок без повторного об’єднання окремих файлів

## Поради

- Поле власного порядку сторінок очікує номери вихідних сторінок через кому. Воно має містити кожну сторінку рівно один раз: без пропусків і дублікатів.
- Після дублювання сторінки обидві копії посилаються на той самий індекс вихідної сторінки. Переставляння будь-якої з копій працює незалежно.
- Для масових операцій з кількома файлами або складніших сценаріїв скористайтеся [PDF мультиінструментом](./pdf-multi-tool).

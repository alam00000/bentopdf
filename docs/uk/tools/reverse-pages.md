# Зворотний порядок сторінок

Змініть порядок сторінок PDF на зворотний: остання сторінка стає першою, передостання другою тощо. Підтримується пакетна обробка кількох файлів одночасно.

## Як це працює

1. Завантажте один або кілька файлів PDF.
2. Натисніть кнопку обробки.
3. Кожен файл обробляється окремо. Якщо ви завантажили кілька файлів, результатом буде архів ZIP з усіма перевернутими PDF.
4. Один файл завантажується одразу як PDF зі зворотним порядком сторінок.

## Можливості

- Пакетна обробка: зворотний порядок для кількох PDF в одній операції
- Окремий файл для одного PDF, архів ZIP для кількох
- Кнопки видалення окремих файлів перед обробкою
- Зберігає весь вміст сторінок і форматування

## Сценарії використання

- Виправлення документа, відсканованого у зворотному порядку
- Підготовка PDF-презентації для читання з кінця до початку
- Зворотний порядок сторінок для певних процесів друку, що подають сторінки у зворотному порядку
- Виправлення документа, у якому сторінки випадково зібрано навпаки

## Поради

- Кожен файл у пакеті обробляється окремо: самі файли не змінюють порядок відносно один одного.
- Для детальнішого перевпорядкування сторінок (а не лише повного розвороту) скористайтеся [Дублювати та впорядкувати](./organize-pdf).

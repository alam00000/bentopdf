# Редагувати метадані

Редагуйте метадані, вбудовані у файл PDF. Інструмент попередньо заповнює форму наявними метаданими документа, дозволяє змінити будь-яке поле та зберігає зміни в новий PDF.

## Як це працює

1. Завантажте файл PDF. Інструмент зчитує поточні метадані та заповнює форму.
2. Редагуйте будь-які стандартні поля: Заголовок, Автор, Тема, Ключові слова, Створювач, Виробник.
3. Налаштуйте поля «Дата створення» і «Дата зміни» за допомогою вибору дати й часу.
4. Додавайте власні поля метаданих, натискаючи кнопку додавання та вводячи пару ключ-значення.
5. Натисніть кнопку обробки, щоб зберегти змінений PDF.

## Можливості

- Попереднє заповнення всіх наявних метаданих із завантаженого PDF
- Стандартні поля: Заголовок, Автор, Тема, Ключові слова, Створювач, Виробник
- Вибір дати й часу для полів «Дата створення» і «Дата зміни»
- Власні поля метаданих «ключ-значення» для довільних властивостей
- Збереження змін безпосередньо в інформаційний словник документа PDF

## Поля, які можна редагувати

| Поле               | Опис                                                           |
| ------------------ | -------------------------------------------------------------- |
| **Заголовок**      | Назва документа, що відображається в програмах для читання PDF |
| **Автор**          | Особа чи організація, що створила документ                     |
| **Тема**           | Короткий опис теми документа                                   |
| **Ключові слова**  | Терміни через кому для пошуку та категоризації                 |
| **Створювач**      | Програма, у якій спочатку створено вміст                       |
| **Виробник**       | Програма, яка згенерувала PDF                                  |
| **Дата створення** | Коли документ було створено                                    |
| **Дата зміни**     | Коли документ востаннє змінювали                               |
| **Власні поля**    | Будь-які додаткові пари «ключ-значення», які ви задаєте        |

## Сценарії використання

- Установлення належної назви й автора перед публікацією документа
- Додавання ключових слів для кращого пошуку в системах керування документами
- Оновлення дати зміни, щоб відобразити поточну редакцію
- Додавання власних полів метаданих, як-от Department, Project ID чи Classification
- Очищення метаданих, залишених початковою програмою створення

## Поради

- Власні поля записуються безпосередньо в інформаційний словник PDF. Деякі програми для читання PDF можуть не показувати власні поля, але вони зберігаються у файлі.
- Залиште поле порожнім, щоб очистити його в метаданих. Кнопка обробки зберігає все, що є у формі.
- Щоб переглянути метадані без редагування, скористайтеся [Перегляд метаданих](./view-metadata). Щоб повністю видалити всі метадані, скористайтеся інструментом «Видалити метадані».

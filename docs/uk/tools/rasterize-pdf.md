# Растеризація PDF

Растеризація перетворює кожну сторінку PDF на зображення й збирає ці зображення назад у PDF. Результат виглядає ідентично до оригіналу, але не містить виділюваного тексту, інтерактивних елементів і редагованих шарів. Це фактично високоякісна фотокопія.

## Як це працює

1. Завантажте один або кілька файлів PDF.
2. Задайте **DPI** (роздільну здатність) растеризованого результату.
3. Виберіть **Формат зображення**: PNG для якості без втрат або JPEG для менших файлів.
4. За потреби позначте **Конвертувати в градації сірого**.
5. Натисніть **Растеризувати PDF**. Кілька файлів завантажуються як ZIP.

## Параметри

| Налаштування          | Значення                              | За замовчуванням |
| --------------------- | ------------------------------------- | ---------------- |
| **DPI**               | 72, 150, 200, 300, 600                | 150              |
| **Формат зображення** | PNG (без втрат), JPEG (менший розмір) | PNG              |
| **Градації сірого**   | Увімк./Вимк.                          | Вимк.            |

## Рекомендації щодо DPI

- **72**: лише перегляд на екрані, найменший розмір файлу
- **150**: гарний баланс для загального використання
- **200**: чіткіший текст, помірний розмір файлу
- **300**: результат друкарської якості
- **600**: висока якість для архівування або професійного друку

## Сценарії використання

- Запобігання вилученню тексту з конфіденційних документів перед передаванням
- Усунення проблем із залежністю від шрифтів шляхом перетворення тексту на пікселі
- Створення «пласкої» версії PDF зі складними шарами чи прозорістю, що по-різному відображаються в різних переглядачах
- Підготовка PDF для системи, яка приймає лише вхідні дані у вигляді зображень
- Видалення прихованого вмісту (як-от відстежуваних змін чи даних форм) шляхом зведення PDF до чистих зображень

## Поради

- 150 DPI з PNG є надійним вибором за замовчуванням. Збільшуйте, лише якщо потрібен друк або масштабування дрібних деталей.
- JPEG дає помітно менші файли, але вносить артефакти стиснення на чітких краях тексту.
- Растеризація незворотна: збережіть оригінальний PDF, якщо вам може знадобитися редагований текст.

# VSD у PDF

Перетворюйте діаграми Microsoft Visio на PDF без встановлення Visio. Файли VSD і VSDX містять блок-схеми, організаційні структури, мережеві діаграми та плани приміщень, які більшість людей не можуть відкрити. Цей інструмент створює з них чисті PDF, які можна переглянути на будь-якому пристрої.

## Підтримувані формати

| Формат       | Розширення | Примітки                                      |
| :----------- | :--------- | :-------------------------------------------- |
| Visio Binary | `.vsd`     | Застарілий формат Visio (Visio 2003 і раніше) |
| Visio XML    | `.vsdx`    | Сучасний формат Visio (Visio 2013+)           |

## Як це працює

1. Натисніть область завантаження або перетягніть файли VSD чи VSDX. В одному пакеті можна поєднувати обидва формати.
2. Перегляньте список файлів. Видаляйте зайві записи піктограмою кошика або додайте діаграми кнопкою **Додати ще файли**.
3. Натисніть **Перетворити на PDF**. Рушій на основі LibreOffice завантажується в браузері й відтворює кожну діаграму у PDF, зберігаючи фігури, з'єднувачі, підписи та макет сторінки.
4. Одна діаграма завантажується напряму як PDF. Для кількох файлів створюється ZIP-архів `vsd-to-pdf.zip`.

## Параметри

Налаштування не потрібні. Конвертер зберігає початковий розмір і орієнтацію сторінки з документа Visio.

## Сценарії використання

- Перегляд діаграм Visio від колеги, коли у вас немає ліцензії Visio
- Додавання мережевих чи архітектурних діаграм у проєктну документацію у вигляді PDF
- Друк організаційних структур або схем процесів для роздаткових матеріалів на нарадах
- Архівація старих файлів VSD із ранніх версій Visio у форматі, що прослужить довго

## Поради

- Багатосторінкові документи Visio дають багатосторінкові PDF: кожна сторінка Visio стає сторінкою PDF.
- Файли VSDX (сучасний формат на основі XML) зазвичай конвертуються точніше, ніж старі двійкові файли VSD.
- Рушій LibreOffice завантажується один раз за сеанс. Під час першого перетворення доведеться трохи зачекати, наступні файли обробляються швидше.

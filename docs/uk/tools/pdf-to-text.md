# PDF у текст

Витягує весь текстовий вміст із файлів PDF і зберігає його як прості файли `.txt`. Підтримує пакетну обробку: завантажте кілька PDF і отримайте текст кожного за одну операцію. Працює на PyMuPDF.

## Як це працює

1. Завантажте один чи кілька PDF, натиснувши на область завантаження або перетягнувши файли. Керуйте списком файлів кнопками «Додати ще» та «Очистити».
2. Натисніть **Витягти**, щоб почати обробку.
3. Один файл завантажується як `filename.txt`. Кілька файлів створюють архів `pdf-to-text.zip`.

## Параметри

Цей інструмент не має настроюваних параметрів. Увесь текст витягується з кожної сторінки в порядку читання.

## Формат результату

- **Один файл**: `filename.txt`
- **Кілька файлів**: `pdf-to-text.zip`, що містить по одному `.txt` на кожен вхідний PDF.

## Сценарії використання

- Витяг основного тексту з PDF-звітів для індексації повнотекстового пошуку.
- Конвертація PDF-книг чи статей у простий текст для читання на пристроях з е-чорнилом.
- Отримання тексту з договорів чи юридичних документів для аналізу за ключовими словами.
- Видалення форматування з PDF, щоб отримати чистий текст для скриптів обробки даних.
- Підготовка текстового корпусу з PDF-архівів для обробки природної мови.

## Поради

- Скановані PDF (лише зображення) дадуть порожні текстові файли, бо текстового шару для витягу немає. Спершу пропустіть скановані документи через OCR.
- Результат зберігає порядок читання, як його інтерпретує PyMuPDF, зазвичай зліва направо й згори вниз. Багатоколонкові макети можуть давати перемішаний текст.
- Для структурованого результату із заголовками та форматуванням спробуйте [PDF у Markdown](./pdf-to-markdown). Для структурованого JSON, готового для ШІ, скористайтеся [Підготовка PDF для ШІ](./prepare-pdf-for-ai).

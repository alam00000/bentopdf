# Колонтитули

Додавайте текст у шість позицій на сторінках PDF: верхній ліворуч, верхній по центру, верхній праворуч, нижній ліворуч, нижній по центру та нижній праворуч. Інструмент підтримує динамічні змінні для номера сторінки та загальної кількості сторінок, тож можна створювати шаблони на кшталт «Сторінка 3 з 10», які автоматично оновлюються для кожної сторінки.

## Як це працює

1. Завантажте файл PDF.
2. З’явиться панель параметрів з елементами форматування та шістьма полями введення тексту.
3. Введіть потрібний текст у будь-яку позицію колонтитулів.
4. Використовуйте заповнювачі `{page}` і `{total}` для динамічної нумерації сторінок.
5. Налаштуйте розмір і колір шрифту та за потреби обмежте діапазон сторінок.
6. Натисніть **Додати колонтитули**, щоб обробити файл і завантажити результат.

## Параметри

- **Діапазон сторінок**: за потреби обмежте сторінки, на які додаються колонтитули. Залиште порожнім, щоб застосувати до всіх сторінок. Формат: «1-3, 5» (діапазони через кому).
- **Розмір шрифту**: від 6 до 24 пунктів. За замовчуванням 10.
- **Колір шрифту**: оберіть будь-який колір за допомогою вибору кольору.
- **Верхній ліворуч / по центру / праворуч**: текстові поля для верхньої частини кожної сторінки.
- **Нижній ліворуч / по центру / праворуч**: текстові поля для нижньої частини кожної сторінки.

## Можливості

- Шість незалежних позицій тексту на кожній сторінці
- Динамічна змінна `{page}`, що вставляє поточний номер сторінки
- Динамічна змінна `{total}`, що вставляє загальну кількість сторінок
- Фільтрація за діапазоном сторінок для вибору конкретних сторінок
- Налаштовуваний розмір і колір шрифту
- Шрифт Helvetica для чистого професійного вигляду

## Сценарії використання

- Додавання «Сторінка {page} з {total}» у нижній колонтитул по центру звіту
- Розміщення назви компанії у верхньому колонтитулі ліворуч, а дати документа праворуч
- Додавання повідомлень про конфіденційність у нижній колонтитул юридичних документів
- Нанесення номерів редакцій документа на певні діапазони сторінок

## Поради

- Поєднуйте `{page}` і `{total}` в одному полі для форматів на кшталт «Сторінка {page} з {total}» або «{page}/{total}».
- Більшість полів можна залишити порожніми та заповнити лише потрібні позиції. Порожні поля просто пропускаються.
- Для складніших колонтитулів із зображеннями чи логотипами скористайтеся інструментом [Додати водяний знак](./add-watermark), розмістивши його у верхній частині сторінки.

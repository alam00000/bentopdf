# PDF у CSV

Витягує таблиці з PDF і експортує їх у файл CSV. Інструмент сканує кожну сторінку на табличні дані за допомогою механізму виявлення таблиць PyMuPDF, а потім записує всі знайдені рядки в один результат, розділений комами.

## Як це працює

1. Завантажте PDF, натиснувши на область завантаження або перетягнувши файл.
2. Натисніть **Конвертувати**, щоб почати витяг таблиць.
3. Інструмент сканує кожну сторінку та автоматично визначає таблиці.
4. Файл `.csv` завантажується з усіма витягнутими даними таблиць.

Таблиці з різних сторінок розділяються в результаті порожніми рядками. Клітинки з комами, лапками або переносами рядків коректно екрануються згідно з RFC 4180.

## Параметри

Цей інструмент не має настроюваних параметрів. Усі знайдені в документі таблиці витягуються й об’єднуються в один CSV.

## Формат результату

- Один файл `filename.csv`, що містить усі виявлені таблиці.

## Сценарії використання

- Перенесення фінансових даних із банківських виписок чи рахунків у PDF до електронної таблиці.
- Витяг цінових таблиць із комерційних пропозицій постачальників для порівняння.
- Перетворення табличних дослідницьких даних із PDF-статей на формат, придатний для інструментів аналізу.
- Міграція даних зі застарілих PDF-звітів у бази даних.

## Поради

- Якщо таблиць не знайдено, інструмент показує повідомлення "Таблиць не знайдено". Зазвичай це означає, що PDF використовує текстове розташування, схоже на таблицю, але не є справжньою таблицею.
- Для більшого контролю над окремими таблицями скористайтеся інструментом [Витяг таблиць з PDF](./extract-tables), що дає змогу обрати вивід у CSV, JSON або Markdown.
- Якщо дані потрібні у форматі Excel з окремими аркушами для кожної таблиці, скористайтеся [PDF у Excel](./pdf-to-excel).

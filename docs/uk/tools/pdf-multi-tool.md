# PDF мультиінструмент

Єдиний робочий простір для всіх операцій зі сторінками PDF. Завантажте один чи кілька PDF і працюйте з усіма їхніми сторінками в одній наочній сітці. Повертайте, переставляйте, дублюйте й видаляйте сторінки, вставляйте PDF, зображення та порожні сторінки, змінюйте нумерацію й розмір і розділяйте результат, не залишаючи інструмент.

## Як це працює

1. Натисніть **Вибрати файли** або перетягніть файли на область завантаження. Підтримується кілька файлів, і вони об’єднуються в порядку завантаження.
2. Усі сторінки з’являються в прокручуваній сітці з мініатюрами.
3. Клацніть сторінку, щоб вибрати її. Клацання з Shift вибирає діапазон, а клацання з Cmd/Ctrl додає або прибирає окремі сторінки.
4. Для дій зі сторінками скористайтеся панеллю інструментів менеджера сторінок або клацніть сторінку правою кнопкою миші.
5. Натисніть **Експортувати PDF**, щоб завантажити готовий результат.

## Можливості

- **Об’єднання**: завантажте кілька PDF і зображень, і вони автоматично об’єднаються в один документ
- **Зміна порядку**: перетягуйте сторінки, щоб змінити послідовність, або розверніть порядок усього документа
- **Поворот**: повертайте вибрані сторінки ліворуч або праворуч кроками по 90 градусів
- **Дублювання**: копіюйте вибрані сторінки й розміщуйте копії одразу після них
- **Видалення**: прибирайте вибрані сторінки
- **Вставка**: додавайте сторінки з іншого PDF чи зображення, порожню сторінку, сторінки з буфера обміну або чергуйте сторінки другого PDF із поточними
- **Заміна**: замініть сторінку першою сторінкою іншого PDF
- **Вирізання, копіювання та вставка**: переміщуйте чи копіюйте сторінки в межах документа
- **Витяг**: завантажте вибрані сторінки як PDF або як зображення
- **Нумерація сторінок**: задайте для діапазону сторінок мітки на кшталт i, ii, iii або A-1, A-2
- **Розмір сторінок**: припасуйте сторінки до стандартного формату паперу або власного розміру
- **Розділення**: розділіть документ за діапазонами сторінок, на непарні та парні сторінки, на окремі сторінки, за закладками, через кожні N сторінок або за розміром файлу
- **Скасувати / Повторити**: кожну операцію зі сторінками можна скасувати й повторити
- Автоматично відновлює пошкоджені PDF перед завантаженням

## Гарячі клавіші

| Дія                           | Клавіші                         |
| ----------------------------- | ------------------------------- |
| Повернути праворуч / ліворуч  | R / Shift+R                     |
| Вибрати все                   | Cmd/Ctrl+A                      |
| Вирізати, копіювати, вставити | Cmd/Ctrl+X, C, V                |
| Дублювати                     | Cmd/Ctrl+D                      |
| Видалити                      | Delete або Backspace            |
| Скасувати / Повторити         | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z   |
| Перемістити виділення         | Клавіші зі стрілками, Home, End |

## Сценарії використання

- Створення власного документа зі сторінок кількох вихідних PDF
- Наведення порядку в скануванні: видалення порожніх сторінок, поворот бічних сканів і зміна порядку розділів
- Розділення великого PDF по межах розділів за його закладками
- Швидке редагування сторінок без повноцінного редактора PDF

## Поради

- Історія скасування та повторення відстежує кожну операцію зі сторінками. Користуйтеся нею вільно: випадково зіпсувати роботу неможливо.
- Щоб додати до документа нові PDF або зображення, будь-коли скористайтеся **Insert > From File** або перетягніть їх на сітку сторінок.
- Для простого об’єднання чи розділення окремі інструменти [Об’єднати PDF](./merge-pdf) або [Розділити PDF](./split-pdf) можуть бути швидшими. Мультиінструмент незамінний, коли в одному сеансі потрібно кілька операцій.

# Зміст

Цей інструмент зчитує закладки (структуру) вашого PDF і створює відформатовану сторінку змісту, яка додається на початок документа. Якщо ваш PDF уже має закладки, але не має видимої сторінки змісту, цей інструмент створює її автоматично.

## Як це працює

1. Завантажте PDF, що містить закладки.
2. Налаштуйте заголовок змісту, розмір шрифту та гарнітуру.
3. За потреби позначте **Додати закладку для сторінки змісту**, щоб включити сам зміст у дерево закладок.
4. Натисніть **Створити зміст**, щоб обробити файл.
5. Оновлений PDF автоматично завантажується зі сторінкою змісту на початку.

## Параметри

- **Заголовок змісту**: заголовок, що відображається вгорі створеної сторінки. За замовчуванням «Зміст».
- **Розмір шрифту**: виберіть від 10 pt до 72 pt. За замовчуванням 12 pt.
- **Гарнітура шрифту**: виберіть варіанти Times Roman, Helvetica або Courier (звичайний, напівжирний, курсив, напівжирний курсив). За замовчуванням Helvetica.
- **Додати закладку для сторінки змісту**: якщо позначено, до дерева структури PDF додається закладка для самої сторінки змісту.

## Можливості

- Зчитує повну ієрархію закладок із PDF
- Створює чітко відформатовану сторінку змісту з посиланнями на номери сторінок
- Підтримує вкладені рівні закладок з відступами
- Вибір із 12 вбудованих шрифтів PDF
- Необов’язкова закладка на саму сторінку змісту

## Сценарії використання

- Додавання змісту для друку в електронні книги чи звіти, що мають лише цифрові закладки
- Створення змісту для об’єднаного документа після поєднання кількох PDF
- Створення довідкової сторінки для довгих технічних посібників
- Підготовка документів до друку, де очікується видимий зміст

## Поради

- Якщо у вашому PDF немає закладок, спершу скористайтеся інструментом [Редагувати закладки](./bookmark), щоб їх створити, а потім поверніться сюди, щоб створити зміст.
- Для великих документів більший розмір шрифту, наприклад 14 pt або 16 pt, покращує читабельність.

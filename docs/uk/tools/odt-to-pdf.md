# ODT у PDF

Конвертуйте файли OpenDocument Text у PDF. ODT є рідним форматом LibreOffice Writer, Apache OpenOffice та інших відкритих текстових редакторів. Цей інструмент використовує LibreOffice-рушій у браузері для точної конвертації зі збереженням форматування, таблиць, зображень і стилів.

## Підтримувані формати

| Формат            | Розширення |
| :---------------- | :--------- |
| OpenDocument Text | `.odt`     |

## Як це працює

1. Натисніть на область завантаження або перетягніть один чи кілька файлів ODT.
2. Перегляньте список файлів. Додайте ще файли або видаліть зайві.
3. Натисніть **Конвертувати у PDF**. Рушій LibreOffice ініціалізується (індикатор прогресу показує стан завантаження), після чого кожен файл конвертується.
4. Один файл завантажується одразу як PDF. Кілька файлів пакуються в `odt-converted.zip`.

## Параметри

Цей інструмент не має додаткових налаштувань. Конвертація максимально точно зберігає форматування вихідного документа.

## Результат

| Кількість файлів | Результат                                                         |
| :--------------- | :---------------------------------------------------------------- |
| 1 файл           | Завантаження одного PDF (напр., `document.pdf`)                   |
| 2 і більше       | ZIP-архів (`odt-converted.zip`), що містить по одному PDF на файл |

## Сценарії використання

- Конвертація документів LibreOffice Writer у PDF для обміну з користувачами Microsoft Office
- Створення PDF для друку з наукових робіт, написаних у форматі OpenDocument
- Пакетна конвертація теки шаблонів ODT у PDF для розсилки
- Створення PDF із файлів ODT, згенерованих системами автоматичного формування документів

## Поради

- Рушій LibreOffice завантажується під час першого використання та кешується для наступних конвертацій. Перше завантаження займає кілька секунд, далі конвертація швидка.
- Складні документи з вбудованими об’єктами OLE або нестандартними шрифтами можуть відображатися трохи інакше, ніж у настільному LibreOffice. Перед пакетною конвертацією перевірте на зразку.
- Для документів Word (`.doc`, `.docx`) скористайтеся інструментом [Word у PDF](./word-to-pdf): він також використовує рушій LibreOffice, але напряму приймає формати Microsoft.

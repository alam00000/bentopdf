# PDF у відтінки сірого

Перетворює кольоровий PDF на версію у відтінках сірого. Кожна сторінка відображається, знебарвлюється й повторно вбудовується як зображення JPEG у новий PDF. Результат зберігає початкові розміри сторінок.

## Як це працює

1. Завантажте PDF, натиснувши на область завантаження або перетягнувши файл.
2. Натисніть **Конвертувати** для обробки файлу.
3. Новий файл `greyscale.pdf` завантажується з усіма сторінками, перетвореними на чорно-білі.

Усередині кожна сторінка відображається в масштабі 2x, дані пікселів проходять через фільтр відтінків сірого, потім кодуються як JPEG із якістю 90% і розміщуються в новому документі PDF.

## Параметри

Цей інструмент не має настроюваних параметрів. Перетворення у відтінки сірого використовує стандартну формулу яскравості, а якість JPEG фіксована на рівні 90%.

## Формат результату

- Один файл `greyscale.pdf`, що містить усі сторінки як зображення JPEG у відтінках сірого.

## Сценарії використання

- Підготовка документів до чорно-білого друку для економії на кольоровому тонері.
- Виконання вимог до подання юридичних чи державних документів, що вимагають відтінків сірого.
- Зменшення розміру файлу кольорових PDF (зображення JPEG у відтінках сірого менші за кольорові).
- Створення єдиного візуального стилю для документів зі змішаними кольоровими й чорно-білими сторінками.

## Поради

- Оскільки кожна сторінка растеризується й повторно вбудовується як JPEG, результат складається із зображень. Текст початкового PDF більше не можна буде виділяти чи шукати. Якщо потім потрібен текст із пошуком, пропустіть результат через інструмент OCR.
- Для точнішого керування кольорами (яскравість, контраст, насиченість) зверніть увагу на інструмент «Корекція кольору» або вузол Greyscale у [Конструкторі PDF-процесів](./pdf-workflow).

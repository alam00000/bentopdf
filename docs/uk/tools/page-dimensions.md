# Розміри сторінок

Діагностичний інструмент, який зчитує кожну сторінку PDF і повідомляє її точні розміри, орієнтацію, назву стандартного формату, співвідношення сторін, площу та поворот. Корисний, щоб помітити сторінки різного розміру перед друком або задокументувати властивості отриманого PDF.

## Як це працює

1. Завантажте файл PDF. Аналіз починається автоматично, натискати кнопку не потрібно.
2. Панель підсумку показує загальну кількість сторінок, кількість унікальних розмірів сторінок і чи містить документ сторінки різного розміру.
3. Перегляньте повну таблицю результатів з даними по кожній сторінці.
4. Перемикайте одиниці виміру між пунктами, дюймами, міліметрами та пікселями.
5. Натисніть **Експортувати в CSV**, щоб зберегти дані.

## Поля звіту

| Стовпець              | Опис                                                    |
| --------------------- | ------------------------------------------------------- |
| Сторінка №            | Порядковий номер сторінки                               |
| Розміри               | Ширина x Висота у вибраній одиниці                      |
| Стандартний розмір    | Знайдена назва (A4, Letter тощо) або "Власний"          |
| Орієнтація            | Книжкова або альбомна                                   |
| Співвідношення сторін | Відношення ширини до висоти у вигляді десяткового числа |
| Площа                 | Площа сторінки у квадратних одиницях вибраної одиниці   |
| Поворот               | Поворот сторінки в градусах                             |

## Можливості

- Автоматичне визначення стандартних форматів паперу (A3, A4, A5, Letter, Legal, Tabloid та інші)
- Попередження про документ зі сторінками різного розміру з розподілом: які розміри є і скільки сторінок використовує кожен
- Перетворення одиниць між пунктами, дюймами, міліметрами та пікселями (при 96 PPI)
- Експорт у CSV для електронних таблиць або систем документації

## Сценарії використання

- Перевірка того, що всі сторінки мають формат A4, перед відправкою документа в друкарню
- З’ясування, чому об’єднаний PDF друкується з неочікуваними полями на окремих сторінках
- Документування макета сторінок великого архіву PDF для метаданих
- Виявлення повернутих сторінок, які потребують виправлення

## Поради

- Якщо підсумок показує "Різні розміри", скористайтеся інструментом «Вирівняти розмір сторінок», щоб уніфікувати розміри перед друком.
- Поле повороту допомагає знайти сторінки, які відображаються правильно, але мають ненульовий атрибут повороту, що може спричиняти проблеми в деяких робочих процесах.

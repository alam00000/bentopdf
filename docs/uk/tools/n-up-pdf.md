# N-Up PDF

Розміщуйте кілька сторінок на одному аркуші у вигляді сітки. Це зменшує кількість друкованих сторінок, вміщуючи по 2, 4, 6, 8, 9 або 16 сторінок на аркуш. Інструмент виконує масштабування, позиціонування та додаткове налаштування розміру сторінки.

## Як це працює

1. Завантажте файл PDF.
2. Оберіть кількість сторінок на аркуші (значення «N»): 2, 4, 6, 8, 9 або 16.
3. Оберіть розмір вихідної сторінки (за замовчуванням A4) та орієнтацію.
4. За потреби налаштуйте відступи, колір рамки та колір фону.
5. Натисніть кнопку обробки. Інструмент масштабує кожну сторінку та розміщує їх плиткою на нових аркушах.

## Можливості

- Сітки: 2-up, 4-up, 6-up, 8-up, 9-up і 16-up
- Налаштовувані розмір і орієнтація вихідної сторінки
- Необов’язкові відступи між сторінками в сітці
- Налаштування кольору фону та рамки
- Збереження пропорцій оригінальних сторінок під час масштабування

## Параметри

| Параметр               | Опис                                                                            |
| ---------------------- | ------------------------------------------------------------------------------- |
| **Сторінок на аркуші** | Кількість оригінальних сторінок на кожній вихідній сторінці (2, 4, 6, 8, 9, 16) |
| **Розмір сторінки**    | Розмір вихідного аркуша (A4, Letter, Legal тощо)                                |
| **Орієнтація**         | Книжкова або альбомна для вихідного аркуша                                      |
| **Відступи**           | Проміжок у пунктах між сторінками в сітці                                       |
| **Колір фону**         | Колір заливки фону вихідного аркуша                                             |
| **Колір рамки**        | Колір рамок навколо кожної сторінки в сітці                                     |

## Сценарії використання

- Друк роздаткових матеріалів із 4 слайдами на сторінці для економії паперу
- Створення навчальних аркушів із кількома довідковими сторінками на одному аркуші
- Створення компактних архівів документів для підшивання
- Створення оглядових аркушів із мініатюрами довгого документа

## Поради

- Альбомна орієнтація часто краще підходить для розкладки 2-up, а книжкова зазвичай найкраща для 4-up і більше.
- Збільшення відступів покращує читабельність, але зменшує площу для кожної сторінки в сітці.
- Для зворотної операції (розділення однієї сторінки на кілька) дивіться [Постеризація PDF](./posterize-pdf).

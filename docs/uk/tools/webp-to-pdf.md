# WebP у PDF

Перетворюйте формат зображень WebP від Google на PDF. Це особливо корисно, коли ви завантажили з інтернету зображення у форматі WebP і вам потрібен загальноприйнятіший формат для друку чи надсилання.

## Підтримувані формати

| Формат | Розширення |
| :----- | :--------- |
| WebP   | `.webp`    |

## Як це працює

1. Натисніть область завантаження або перетягніть файли WebP.
2. Перегляньте список файлів і видаліть ті, що не потрібні.
3. Виберіть рівень **якості PDF**.
4. Натисніть **Перетворити на PDF**. Результат завантажується як `from_webps.pdf`.

Усередині кожне зображення WebP декодується через canvas API браузера, а потім вбудовується у PDF за допомогою pdf-lib. Тому перетворення працює в будь-якому браузері з підтримкою декодування WebP (усі сучасні браузери її мають).

## Параметри

**Якість PDF** визначає стиснення під час вбудовування зображень:

- **Висока якість**: зберігає найбільше деталей.
- **Середня якість** (за замовчуванням): збалансований результат.
- **Низька якість**: найменший розмір файлу.

## Сценарії використання

- Перетворення завантажених з інтернету зображень WebP на PDF для друку
- Збирання скриншотів WebP із Chrome чи Edge у документацію
- Створення PDF-портфоліо із зображень, які експортують дизайнерські інструменти зі WebP за замовчуванням
- Архівація зображень WebP у ширше підтримуваному форматі

## Поради

- WebP перед вбудовуванням у PDF декодується в PNG, тому WebP без втрат зберігає якість на високому рівні.
- Якщо у вас суміш WebP та інших форматів зображень, скористайтеся інструментом [Зображення у PDF](./image-to-pdf): він приймає все одразу.

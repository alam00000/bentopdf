# PUB у PDF

Конвертуйте файли Microsoft Publisher у PDF. Publisher є настільною програмою для верстки, що входить до деяких редакцій Microsoft Office, але в більшості людей її не встановлено. Цей інструмент дозволяє будь-кому конвертувати файли PUB у PDF прямо в браузері, без програмного забезпечення Microsoft.

## Підтримувані формати

| Формат              | Розширення | Примітки                         |
| :------------------ | :--------- | :------------------------------- |
| Microsoft Publisher | `.pub`     | Документи для настільної верстки |

## Як це працює

1. Натисніть область завантаження або перетягніть файли PUB. Можна завантажити кілька файлів одночасно.
2. Перегляньте список файлів. Видаліть зайві файли значком кошика або натисніть **Додати ще файли**, щоб додати інші.
3. Натисніть **Конвертувати в PDF**. У браузері завантажується рушій на основі LibreOffice і конвертує кожен файл PUB зі збереженням макета, зображень і текстових полів.
4. Один файл завантажується одразу як PDF. Кілька файлів надходять в архіві ZIP з назвою `pub-to-pdf.zip`.

## Параметри

Додаткове налаштування не потрібне. Конвертер автоматично обробляє макет PUB.

## Сценарії використання

- Відкриття флаєра чи інформаційного бюлетеня PUB від клієнта без купівлі Microsoft Publisher
- Конвертація церковних оголошень, програм заходів або шкільних бюлетенів, створених у Publisher
- Архівування маркетингових матеріалів з Publisher у загальнодоступному форматі
- Друк файлів PUB у системі, де не встановлено Publisher

## Поради

- Складні макети Publisher з накладеними текстовими полями та точним позиціонуванням можуть трохи зміститися під час конвертації. Перегляньте результат, якщо точне розташування критичне.
- Рушій LibreOffice ініціалізується один раз за сеанс. Перша конвертація триває довше, наступні швидші.
- Для найточнішої конвертації файлів Publisher переконайтеся, що власні шрифти з оригіналу є стандартними системними шрифтами.

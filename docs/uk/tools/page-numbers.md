# Нумерація сторінок

Додайте видимі номери на кожну сторінку PDF. Ви обираєте позицію, формат, розмір шрифту та колір, а решту інструмент зробить сам.

## Як це працює

1. Завантажте файл PDF.
2. Налаштуйте параметри нумерації на панелі, що з’явиться.
3. Натисніть **Додати нумерацію сторінок** для обробки.
4. Пронумерований PDF завантажиться автоматично.

## Параметри

- **Позиція**: оберіть, де з’являтимуться номери: унизу по центру, унизу ліворуч, унизу праворуч, угорі по центру, угорі ліворуч або угорі праворуч.
- **Формат**: проста нумерація (1, 2, 3...) або формат "сторінка X з Y" (1 / 5, 2 / 5...).
- **Розмір шрифту**: розмір тексту номера. За замовчуванням 12.
- **Колір**: оберіть будь-який колір тексту номера за допомогою палітри.

## Можливості

- Шість варіантів розміщення, що охоплюють усі кути та центральні позиції
- Два формати нумерації: проста послідовна або "сторінка X з Y"
- Настроюваний розмір шрифту від 6 до 72 пунктів
- Повна палітра для вибору кольору тексту
- Автоматична обробка полів, що тримає номери в безпечній зоні незалежно від розміру сторінки

## Сценарії використання

- Підготовка документів до друку, де потрібні видимі посилання на сторінки
- Додавання номерів сторінок в об’єднаний PDF, створений із кількох вихідних файлів
- Нумерація роздаткових матеріалів до презентацій перед розповсюдженням
- Додавання послідовної нумерації в юридичні документи або договори

## Поради

- Формат "сторінка X з Y" корисний для документів, де читачам важливо знати загальний обсяг, наприклад комерційних пропозицій чи звітів.
- Якщо для різних розділів потрібні різні стилі нумерації (наприклад, римські цифри для вступної частини), скористайтеся інструментом [Додати нумерацію сторінок](./add-page-labels).

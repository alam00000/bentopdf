# Excel у PDF

Перетворюйте файли електронних таблиць на PDF. Інструмент працює із сучасними файлами Excel, застарілим форматом XLS, таблицями OpenDocument і навіть CSV, і все це відображається через рушій LibreOffice у браузері, який зберігає форматування клітинок, формули (як обчислені значення), діаграми та багатоаркушеві макети.

## Підтримувані формати

| Формат               | Розширення |
| :------------------- | :--------- |
| Excel (сучасний)     | `.xlsx`    |
| Excel (застарілий)   | `.xls`     |
| Таблиця OpenDocument | `.ods`     |
| CSV                  | `.csv`     |

## Як це працює

1. Клацніть зону завантаження або перетягніть файли електронних таблиць.
2. Перегляньте список файлів. Додайте ще файли або видаліть непотрібні.
3. Натисніть **Конвертувати у PDF**. Рушій LibreOffice ініціалізується під час першого використання, а потім обробляє кожен файл.
4. Один файл завантажується одразу як PDF. Кілька файлів надаються як `excel-converted.zip`.

## Параметри

Цей інструмент не має додаткових налаштувань. Рушій LibreOffice визначає макет сторінки, масштабування та область друку за вбудованими параметрами таблиці.

## Результат

| Кількість вхідних файлів | Результат                                                              |
| :----------------------- | :--------------------------------------------------------------------- |
| 1 файл                   | Один PDF для завантаження (початкова назва файлу з розширенням `.pdf`) |
| 2+ файли                 | ZIP-архів (`excel-converted.zip`) з одним PDF на кожен файл            |

## Сценарії використання

- Перетворення фінансових звітів чи бюджетів з Excel на PDF для розповсюдження
- Створення PDF, готових до друку, з таблиць інвентаря чи каталогів продукції
- Передавання результатів аналізу даних зацікавленим сторонам, які не мають Excel
- Архівування квартальних звітів у форматі без можливості редагування
- Перетворення файлів ODS з LibreOffice Calc на PDF

## Поради

- Діаграми, вбудовані в таблицю, відображаються в PDF. Переконайтеся, що вони виглядають правильно у початковому файлі, перш ніж перетворювати.
- Якщо в таблиці кілька аркушів, усі аркуші потрапляють у вихідний PDF.
- Для простих даних CSV без форматування інструмент [CSV у PDF](./csv-to-pdf) пропонує легше перетворення. Використовуйте Excel у PDF, коли потрібно зберегти форматування, діаграми чи кілька аркушів.

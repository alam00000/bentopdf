# HEIC у PDF

Конвертуйте зображення HEIC/HEIF у PDF. HEIC є стандартним форматом фото на iPhone та iPad починаючи з iOS 11. Цей інструмент дозволяє перетворити такі фото на PDF без встановлення програм і без завантаження файлів на сервер.

## Підтримувані формати

| Формат | Розширення |
| :----- | :--------- |
| HEIC   | `.heic`    |
| HEIF   | `.heif`    |

## Як це працює

1. Натисніть область завантаження або перетягніть файли HEIC/HEIF.
2. Перегляньте список файлів і видаліть непотрібні.
3. Натисніть **Конвертувати в PDF**. Результат завантажується як `from_heic.pdf`.

Кожен файл HEIC декодується бібліотекою heic2any, яка перетворює його на PNG із якістю 92%. Потім PNG вбудовується в PDF за допомогою pdf-lib: кожне зображення на окремій сторінці в повному розмірі.

## Параметри

Цей інструмент не має додаткових налаштувань. Зображення HEIC перед вбудовуванням конвертуються у PNG з високою якістю (0.92).

## Сценарії використання

- Створення PDF із фото з iPhone для додавання до страхової заяви чи звіту
- Конвертація фото HEIC для оголошення про нерухомість в один документ для друку
- Перетворення скриншотів iPad (формат HEIF) на PDF, яким легко поділитися
- Пакетна конвертація фото з відпустки для подорожнього щоденника

## Поради

- Декодування HEIC повністю відбувається у браузері за допомогою WebAssembly. Перша конвертація може тривати трохи довше, поки завантажується декодер.
- Якщо потрібно поєднати HEIC з іншими форматами зображень (JPG, PNG тощо), скористайтеся інструментом [Зображення у PDF](./image-to-pdf), який обробляє HEIC разом з усіма іншими форматами.
- Файли HEIC з iPhone часто містять дані EXIF, зокрема координати GPS. У вихідному PDF ці метадані не зберігаються.

# PDF у JSON

Конвертує один чи кілька файлів PDF у формат JSON. Інструмент використовує CPDF (Coherent PDF), щоб серіалізувати внутрішню структуру кожного PDF у машинозчитуване представлення JSON. Результат завжди надається як ZIP-архів.

## Як це працює

1. Оберіть один чи кілька файлів PDF у вікні вибору файлів.
2. Натисніть **Конвертувати**, щоб почати обробку. Конвертація виконується у фоновому веб-воркері.
3. Завантажується ZIP-архів, що містить по одному файлу JSON для кожного вхідного PDF.

Рядок стану показує перебіг етапів конвертації та створення ZIP.

## Параметри

Цей інструмент не має настроюваних параметрів. Кожен PDF конвертується в повне представлення JSON.

## Формат результату

- Файл `pdfs-to-json.zip`, що містить `filename.json` для кожного вхідного PDF.

Результат JSON відображає внутрішню структуру об’єктів PDF, зокрема дерева сторінок, посилання на шрифти, метадані та потоки вмісту.

## Сценарії використання

- Перевірка внутрішньої структури PDF для налагодження чи валідації.
- Програмне отримання структурованих метаданих і властивостей сторінок.
- Передавання даних про структуру PDF у власні конвеєри обробки.
- Аудит PDF-документів на відповідність вимогам шляхом аналізу їхніх дерев об’єктів.

## Поради

- Цей інструмент виводить сиру структуру об’єктів PDF, а не витягнутий текстовий вміст. Якщо потрібен текст сторінок у форматі JSON, скористайтеся натомість [Підготовка PDF для ШІ](./prepare-pdf-for-ai).
- Для витягу простого тексту [PDF у текст](./pdf-to-text) більш прямолінійний.
- Великі PDF зі складною структурою дають дуже великі файли JSON.

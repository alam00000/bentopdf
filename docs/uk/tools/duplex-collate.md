# Сортування двостороннього сканування

Дуплексне впорядкування призначене для робочих процесів сканування через автоподавач, коли один PDF містить два блоки сторінок:

- спочатку всі лицьові сторони
- потім усі зворотні сторони

Замість ручного розділення та повторного складання цей інструмент чергує два блоки в природному порядку читання: лицьова 1, зворотна 1, лицьова 2, зворотна 2 і так далі.

## Як це працює

1. Завантажте один PDF, створений скануванням стосу у дуплексному режимі.
2. Задайте точку розділення, де закінчується блок лицьових сторінок.
3. Виберіть обробку блоку зворотних сторінок:
   - **Обернути блок зворотів** (поширений випадок, коли стос перевертають перед скануванням зворотних сторін)
   - **Залишити блок зворотів без змін**
4. Натисніть **Зібрати PDF**, щоб завантажити результат із переупорядкованими сторінками.

## Параметри

- **Визначити розділення автоматично (половина)**: задає точку розділення як `ceil(totalPages / 2)`.
- **Попередження про непарну кількість сторінок**: попереджає, коли загальна кількість сторінок непарна (часто це невідповідність під час сканування).
- **Підтвердження нерівних блоків**: просить підтвердження, коли розміри блоків лицьових і зворотних сторінок різні.
- **Експорт групами**: розділяє результат на окремі PDF за кількістю сторінок початкового документа та завантажує їх як ZIP.

## Поведінка результату

- **За замовчуванням**: один вихідний PDF (один вхідний PDF дає один вихідний PDF).
- **Режим групування**: результат ділиться на частини за вашим значенням сторінок на документ; якщо утворюється кілька частин, їх завантажують одним ZIP, інакше завантажується один PDF.

Якщо розміри блоків різні, спочатку впорядковуються парні сторінки, а решта сторінок без пари додається в кінець.

## Типові сценарії використання

- Відновлення порядку після сканування стосу двосторонніх форм у два проходи.
- Відновлення пакетів лицьових і зворотних сторінок зі сканерів офісного типу, які виводять спочатку всі лицьові, потім усі зворотні сторони.
- Постобробка архівних сканів перед розділенням на файли для окремих документів.

## Поради

- У більшості дуплексних пакетів загальна кількість сторінок має бути парною.
- Якщо зворотні сторінки виглядають перевернутими, перемкніть між **Обернути блок зворотів** і **Залишити блок зворотів без змін**.
- Для оригіналів із 2 сторінок (лицьова та зворотна) використовуйте груповий експорт із `2` сторінками на документ.

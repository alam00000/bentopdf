# Вирівняти розмір сторінок

PDF, зібрані з різних джерел, часто мають сторінки різного розміру: одні Letter, інші A4, а деякі зовсім нестандартні. Цей інструмент примусово задає всім сторінкам один цільовий розмір, масштабуючи вміст так, щоб він вписувався або заповнював сторінку.

## Як це працює

1. Завантажте файл PDF.
2. Оберіть **Цільовий розмір сторінки** зі списку (A4, Letter, Legal, A3, A5, Tabloid або Власний).
3. Оберіть **Орієнтацію**: Авто зберігає початкову орієнтацію кожної сторінки, або можна примусово задати книжкову чи альбомну.
4. Оберіть режим **Масштабування вмісту**: Вписати (зберігає весь вміст, може додати поля) або Заповнити (заповнює сторінку, може обрізати краї).
5. За потреби задайте **Колір фону** для доданих полів.
6. Натисніть **Вирівняти розмір сторінок**.

## Параметри

- **Стандартні розміри**: A4, Letter, Legal, A3, A5, Tabloid
- **Власні розміри**: введіть ширину та висоту в дюймах або міліметрах
- **Орієнтація**: Авто, книжкова, альбомна
- **Режим масштабування**: Вписати або Заповнити (з обрізанням)
- **Колір фону**: будь-який колір для заповнення полів

## Сценарії використання

- Нормалізація об’єднаного PDF, сторінки якого походять із різних сканерів
- Перетворення документа US Letter на A4 для міжнародного розповсюдження
- Підготовка PDF до друку, що потребують однакового розміру обрізання
- Виправлення сторінок, які трохи відхиляються від стандарту (наприклад, 8,49 x 11,02 дюйма замість 8,5 x 11)

## Поради

- Використовуйте режим Вписати, щоб гарантовано не втратити вміст. Режим Заповнити виглядає охайніше, але може обрізати краї.
- Перевірте результат інструментом «Розміри сторінок», щоб переконатися, що всі сторінки відповідають цільовому розміру.
- За замовчуванням фон білий; оберіть темний колір, якщо поля вашого документа темні.

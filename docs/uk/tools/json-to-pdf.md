# JSON у PDF

Відновлюйте документи PDF із файлів JSON, раніше створених інструментом **PDF у JSON** від BentoPDF. Це інструмент зворотної конвертації: він бере структуроване JSON-представлення PDF і перебудовує початковий документ.

::: warning
Цей інструмент приймає лише файли JSON, створені конвертером PDF у JSON від BentoPDF. Звичайні файли JSON з API, баз даних чи інших інструментів не підтримуються.
:::

## Підтримувані формати

| Вхідні дані | Опис                                                          |
| :---------- | :------------------------------------------------------------ |
| `.json`     | Файли JSON, експортовані інструментом PDF у JSON від BentoPDF |

## Як це працює

1. Натисніть область завантаження або перетягніть один чи кілька файлів JSON.
2. У списку файлів відображається кожен вибраний файл із його розміром.
3. Натисніть **Конвертувати в PDF**. Інструмент обробляє всі файли за допомогою Web Worker і рушія CPDF.
4. Результат завантажується як `jsons-to-pdf.zip`, що містить по одному PDF для кожного вхідного файлу JSON.

Конвертація виконується у фоновому Web Worker, тому інтерфейс залишається чутливим навіть із великими файлами.

## Параметри

Цей інструмент не має налаштовуваних параметрів. Структура JSON повністю визначає вихідний PDF.

## Результат

Під час конвертації кількох файлів JSON результати надаються як архів ZIP. Кожен PDF має ім’я вихідного файлу JSON (наприклад, `report.json` стає `report.pdf`).

## Сценарії використання

- Відновлення PDF із резервної копії чи архівного конвеєра на основі JSON
- Подвійна конвертація PDF через JSON для перевірки, а потім назад у PDF
- Перебудова документів після програмних змін у структурі JSON
- Перевірка того, що експорт PDF у JSON зберіг увесь вміст документа, шляхом конвертації назад

## Поради

- Якщо потрібно конвертувати довільні дані JSON (наприклад, відповіді API чи файли конфігурації) у відформатований PDF, краще підійде інструмент [Текст у PDF](./txt-to-pdf). Вставте JSON як текст, і він буде відображений із належним форматуванням.
- Для роботи цього інструмента потрібен рушій CPDF WebAssembly. Для власних екземплярів потрібно налаштувати файли CPDF WASM.

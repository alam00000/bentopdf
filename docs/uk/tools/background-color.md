# Колір фону

Задайте суцільний колір фону під усім наявним вмістом PDF. Інструмент створює кольоровий прямокутник на кожній сторінці й накладає на нього початковий вміст, тож текст, зображення та графіка залишаються повністю видимими на новому фоні.

## Як це працює

1. Завантажте PDF-файл.
2. Виберіть колір фону за допомогою вибору кольору. За замовчуванням це світло-жовтий (#FFFFCC).
3. Натисніть **Змінити колір фону**, щоб обробити файл.
4. Оновлений PDF завантажиться автоматично.

## Параметри

- **Колір фону** -- Стандартний вибір кольору для будь-якого суцільного кольору. За замовчуванням світло-жовтий.

## Можливості

- Єдиний колір фону на кожній сторінці
- Збереження всього початкового вмісту (текст, зображення, векторна графіка) поверх кольорового шару
- Збереження початкових розмірів сторінок
- Працює з документами з будь-якою кількістю сторінок

## Приклади використання

- Додавання світло-кремового або слонової кістки фону для м’якшого, паперового вигляду документів
- Колірне кодування наборів документів різними кольорами фону для різних категорій
- Створення візуально відмінних версій одного документа для різної аудиторії
- Додавання світлого відтінку фону для кращої читабельності під час показу документів на екрані

## Поради

- Найкраще працюють світлі, приглушені кольори. Дуже темний фон ускладнює читання тексту, якщо сам текст не світлий.
- Щоб змінити і фон, і колір тексту, спершу застосуйте колір фону, а потім скористайтеся інструментом [Змінити колір тексту](./text-color) для результату.
- Інструмент працює на структурному рівні PDF (без растеризації), тому текст у результаті залишається виділюваним і придатним для пошуку.

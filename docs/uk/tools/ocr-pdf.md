# OCR PDF

Перетворюйте скановані документи на PDF з пошуком і копіюванням. Інструмент використовує Tesseract OCR для розпізнавання тексту на зображеннях і накладає невидимий текстовий шар поверх оригінальних сторінок, зберігаючи їхній вигляд і роблячи вміст повністю придатним для пошуку.

## Як це працює

1. Завантажте відсканований PDF або PDF із зображень.
2. Оберіть одну чи кілька мов, присутніх у документі, у списку мов із пошуком.
3. За потреби налаштуйте розширені параметри (роздільна здатність, бінаризація, білий список).
4. Натисніть **Почати OCR** і стежте за прогресом на індикаторі в реальному часі.
5. Після завершення перегляньте витягнутий текст, а потім завантажте PDF із пошуком або простий файл `.txt`.

## Можливості

- OCR кількома мовами з вибором мови за допомогою пошуку
- Невидимий текстовий шар зберігає оригінальний вигляд документа
- Індикатор прогресу та журнал у реальному часі під час обробки
- Завантаження результатів як PDF із пошуком або простого текстового файлу
- Копіювання витягнутого тексту прямо в буфер обміну
- Три рівні роздільної здатності для балансу між швидкістю та точністю

## Параметри

| Налаштування                     | Значення                                                                                  | За замовчуванням | Призначення                                                                             |
| -------------------------------- | ----------------------------------------------------------------------------------------- | ---------------- | --------------------------------------------------------------------------------------- |
| **Роздільна здатність**          | Стандартна (192 DPI), Висока (288 DPI), Ультра (384 DPI)                                  | Висока           | Вища роздільна здатність підвищує точність на дрібному тексті, але потребує більше часу |
| **Бінаризація зображення**       | Увімк. / Вимк.                                                                            | Вимк.            | Підвищує контраст чистих сканів, перетворюючи їх на чорно-білі                          |
| **Набір білого списку символів** | Немає, Буквено-цифровий, Числа + валюта, Лише літери, Лише числа, Рахунок, Форми, Власний | Немає            | Обмежує розпізнавані символи для підвищення точності для певних типів документів        |
| **Білий список символів**        | Довільний текст                                                                           | Порожньо         | Ручний набір символів, коли набір має значення «Власний»                                |

## Сценарії використання

- Перетворення сканованих контрактів і рахунків на документи з пошуком, щоб шукати в них через Ctrl+F
- Витягування тексту із сфотографованих документів чи старих паперових записів
- Обробка чеків за допомогою набору «Рахунок» для точного розпізнавання сум і дат
- Створення доступних PDF зі сканів без тексту для виконання вимог відповідності
- Пакетне витягування текстового вмісту зі сканованих книг чи посібників

## Поради

- Оберіть кілька мов, якщо документ містить текст різними мовами (наприклад, англійські заголовки та японський основний текст).
- Використовуйте бінаризацію для документів зі зблідлим або малоконтрастним текстом: вона може значно підвищити точність розпізнавання.
- Набори білого списку «Рахунок» і «Форми» різко зменшують кількість хибних спрацювань на структурованих документах, ігноруючи невідповідні форми символів.

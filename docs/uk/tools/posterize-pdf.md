# Постеризація PDF

Розділіть кожну сторінку PDF на сітку менших підсторінок. Цей інструмент потрібен, щоб надрукувати одну сторінку на кількох аркушах паперу, які потім складаються разом у великий постер або банер.

## Як це працює

1. Завантажте файл PDF.
2. Задайте кількість **рядків** і **стовпців**, щоб визначити сітку (наприклад, 2 рядки x 2 стовпці розділяють кожну сторінку на 4 підсторінки).
3. За потреби вкажіть діапазон сторінок, щоб обмежити, які сторінки буде постеризовано.
4. На полотні попереднього перегляду показано накладену сітку на поточній сторінці, щоб ви бачили лінії розрізу.
5. Перемикайтеся між сторінками, щоб перевірити сітку на різних сторінках.
6. Натисніть кнопку обробки. Кожна клітинка сітки стане окремою сторінкою у вихідному PDF.

## Можливості

- Налаштовувана кількість рядків і стовпців для гнучких розмірів сітки
- Попередній перегляд у реальному часі з накладеною сіткою, що точно показує, де сторінки будуть розділені
- Фільтр діапазону сторінок для постеризації лише певних сторінок
- Посторінкова навігація в попередньому перегляді
- Кешовані знімки сторінок для швидкої навігації в попередньому перегляді
- Червоні пунктирні лінії сітки чітко позначають межі розрізу

## Параметри

| Параметр              | Опис                                                   |
| --------------------- | ------------------------------------------------------ |
| **Рядки**             | Кількість горизонтальних поділів (за замовчуванням: 1) |
| **Стовпці**           | Кількість вертикальних поділів (за замовчуванням: 1)   |
| **Діапазон сторінок** | Які сторінки постеризувати (порожньо = усі сторінки)   |

## Сценарії використання

- Друк PDF розміром з постер на стандартних аркушах A4 або Letter для збирання на стіні
- Створення великих банерів з одностороннього PDF-макета
- Розділення завеликих технічних креслень на придатні для друку фрагменти
- Великоформатний друк без доступу до широкоформатного принтера

## Поради

- Сітка 2x2 перетворює одну сторінку на 4 сторінки. Сітка 3x3 перетворює одну сторінку на 9. Плануйте сітку залежно від того, наскільки великим має бути зібраний результат.
- Накладена сітка в попередньому перегляді допомагає переконатися, що важливий вміст не потрапляє на лінію розрізу. За потреби змініть кількість рядків і стовпців.
- Для зворотної операції (розміщення кількох сторінок на одному аркуші) скористайтеся [N-Up PDF](./n-up-pdf).

# PDF-буклет

Переставте сторінки PDF у порядок розкладки буклета. Після двостороннього друку та складання навпіл сторінки йтимуть у правильній послідовності читання. Такий макет використовують для буклетів зі зшиванням внакидку та зінів.

## Як це працює

1. Завантажте файл PDF.
2. Налаштуйте параметри буклета: розмір сторінки результату та орієнтацію.
3. Натисніть **Створити попередній перегляд**, щоб побачити, як сторінки розташуються на кожному аркуші.
4. Перегляньте попередній перегляд: він показує кожен фізичний аркуш із розподілом сторінок на лицьовому та зворотному боці.
5. Натисніть **Завантажити**, щоб зберегти PDF із розкладкою буклета.

## Можливості

- Автоматична перестановка сторінок для зшивання внакидку
- Настроюваний розмір сторінки результату
- Наочний попередній перегляд макета буклета перед завантаженням
- Непарна кількість сторінок обробляється додаванням порожніх сторінок, де потрібно
- Масштабування вихідних сторінок під розмір аркуша буклета

## Сценарії використання

- Створення буклетів або зінів для друку зі звичайного PDF
- Підготовка програм конференцій або путівників заходів для друку власними силами
- Виготовлення складених вітальних листівок або невеликих каталогів
- Випуск збірок віршів чи невеликих книжечок для ручного палітурства

## Поради

- Кількість сторінок у вихідному PDF бажано кратна 4, щоб буклет вийшов охайним. Якщо це не так, порожні сторінки додаються автоматично, щоб заповнити останній аркуш.
- Друкуйте результат двосторонньо з налаштуванням принтера "перевертати по короткому краю", потім складіть усі аркуші разом і скріпіть степлером по корінцю.
- Щоб просто розмістити кілька сторінок на одному аркуші без порядку буклета, скористайтеся [N-Up PDF](./n-up-pdf).

# CSV у PDF

Перетворюйте файли CSV на охайні відформатовані документи PDF. Кожен CSV розбирається та відображається як таблиця у вихідному PDF. Це корисно, коли потрібно надрукувати чи поділитися табличними даними, не вимагаючи від отримувача програми для електронних таблиць.

## Підтримувані формати

| Формат | Розширення |
| :----- | :--------- |
| CSV    | `.csv`     |

## Як це працює

1. Клацніть зону завантаження або перетягніть один чи кілька файлів CSV.
2. Перегляньте список файлів. Додайте ще файли або видаліть непотрібні.
3. Натисніть **Перетворити на PDF**. Індикатор прогресу показує стан перетворення.
4. Один файл завантажується напряму як PDF. Кілька файлів пакуються в `csv-converted.zip`.

## Параметри

Цей інструмент не має додаткових налаштувань. CSV автоматично розбирається та форматується як таблиця.

## Результат

| Кількість вхідних файлів | Результат                                                 |
| :----------------------- | :-------------------------------------------------------- |
| 1 файл                   | Один PDF для завантаження (наприклад, `data.pdf`)         |
| 2+ файли                 | ZIP-архів (`csv-converted.zip`) з одним PDF на кожен файл |

## Сценарії використання

- Перетворення експортованих звітів з бази даних на таблиці PDF для друку
- Передавання фінансових даних чи списків інвентаря людям без Excel
- Створення PDF-версій журналів CSV для документації відповідності вимогам
- Друк списків адрес, відомостей оцінок чи будь-яких табличних даних у форматі CSV

## Поради

- Для найкращого результату переконайтеся, що ваш CSV використовує стандартні роздільники-коми. Інструмент дотримується поширених правил розбору CSV.
- Якщо в CSV багато стовпців, таблицю може бути стиснуто до ширини сторінки. Розгляньте розділення широких наборів даних на кілька файлів.
- Для файлів Excel (`.xls`, `.xlsx`) скористайтеся інструментом [Excel у PDF](./excel-to-pdf), який зберігає форматування таблиць і кілька аркушів.

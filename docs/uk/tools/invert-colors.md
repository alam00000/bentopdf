# Інвертувати кольори

Замініть кожен колір у PDF на протилежний. Білий фон стає чорним, чорний текст білим, а всі інші кольори змінюються на додаткові. Це найшвидший спосіб створити версію будь-якого PDF для темного режиму.

## Як це працює

1. Завантажте файл PDF.
2. Натисніть **Інвертувати кольори** для обробки.
3. Інвертований PDF завантажується автоматично.

Додаткових налаштувань немає. Інструмент відтворює кожну сторінку як зображення, інвертує кольори всіх пікселів і збирає результат у новий PDF.

## Можливості

- Інверсія кольорів усіх сторінок одним кліком
- Обробка кожної сторінки документа
- Збереження початкових розмірів і макета сторінок
- Працює з будь-яким PDF незалежно від типу вмісту (текст, зображення, змішаний)

## Сценарії використання

- Створення версій підручників чи посібників для темного режиму для комфортного читання вночі
- Підготовка висококонтрастних версій документів для доступності
- Інверсія відсканованих документів, зроблених із неправильною експозицією
- Створення негативів PDF із великою кількістю зображень для візуального аналізу

## Поради

- Оскільки для ефекту інструмент растеризує сторінки, результат складається із зображень. Текст більше не можна виділяти чи шукати. Якщо після інверсії потрібен текст із пошуком, пропустіть результат через інструмент OCR.
- Для точнішого налаштування кольору (яскравість, контраст, насиченість) скористайтеся інструментом [Корекція кольору](./adjust-colors).
- Великі PDF із багатьма сторінками можуть оброблятися довше, бо кожна сторінка відтворюється та інвертується окремо.

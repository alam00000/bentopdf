# SVG у PDF

Конвертуйте файли Scalable Vector Graphics (SVG) у PDF. Інструмент растеризує кожен SVG через рушій відтворення браузера, а потім вбудовує результат у його рідній роздільній здатності. Корисно для перетворення векторних іконок, діаграм та ілюстрацій на портативні документи.

## Підтримувані формати

| Формат | Розширення |
| :----- | :--------- |
| SVG    | `.svg`     |

## Як це працює

1. Натисніть область завантаження або перетягніть один чи кілька файлів SVG.
2. Перегляньте список файлів і керуйте ним.
3. Виберіть рівень **Якості PDF**.
4. Натисніть **Конвертувати в PDF**. Результат завантажується як `from_svgs.pdf`.

Кожен SVG зчитується як текст, відтворюється на полотні у власній ширині та висоті (за замовчуванням 800x600, якщо розміри не вказано) і експортується як PNG. Потім цей PNG вбудовується в PDF за допомогою pdf-lib. Прозорі ділянки заповнюються білим тлом.

## Параметри

**Якість PDF** керує стисненням після растеризації:

- **Висока якість**: найближча до оригінального відтворення.
- **Середня якість** (за замовчуванням): гарний баланс.
- **Низька якість**: найменший файл, певна втрата деталей.

## Сценарії використання

- Конвертація архітектурних чи інженерних діаграм з SVG у PDF, готовий до друку
- Пакування наборів іконок у довідковий PDF для дизайн-системи
- Перетворення візуалізацій даних (D3.js, експорти бібліотек діаграм) на PDF, готові для звітів
- Створення версій для друку інфографіки на основі SVG

## Поради

- Файли SVG без явних атрибутів `width` і `height` відтворюються розміром 800x600 пікселів. Для найкращого результату задайте розміри у вихідному коді SVG перед конвертацією.
- Складні SVG із посиланнями на зовнішні шрифти чи пов’язані зображення можуть відтворюватися не ідеально. Вбудуйте всі ресурси в SVG для надійного результату.
- Оскільки SVG растеризується, PDF міститиме растрове зображення, а не векторні контури. Для справжнього векторного PDF потрібен спеціальний векторний інструмент.

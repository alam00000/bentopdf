# Додати нумерацію сторінок

Мітки сторінок визначають, як номери сторінок відображаються в PDF-переглядачах (номер на панелі інструментів, а не надрукований на самій сторінці). Цей інструмент дає змогу призначати різні схеми нумерації різним діапазонам сторінок: римські цифри для вступної частини, десяткові числа для основного тексту, буквені додатки тощо.

## Як це працює

1. Завантажте PDF-файл.
2. З’явиться панель параметрів з одним правилом міток за замовчуванням.
3. Налаштуйте кожне правило: діапазон сторінок, стиль, необов’язковий префікс і початкове значення.
4. Натисніть **Додати правило**, щоб створити додаткові правила для інших розділів.
5. Натисніть **Додати нумерацію сторінок**, щоб застосувати всі правила й завантажити результат.

## Параметри

Кожне правило міток має такі налаштування:

- **Діапазон сторінок** -- Сторінки, до яких застосовується правило. Залиште порожнім для всіх сторінок. Підтримуються діапазони на кшталт `1-4`, `7`, `odd` або `1-9,30-40`.
- **Стиль мітки** -- Десяткові арабські цифри, римські малі (i, ii, iii), римські великі (I, II, III), малі літери (a, b, c), великі літери (A, B, C) або без мітки (лише префікс).
- **Префікс мітки** -- Необов’язковий текст перед кожною міткою, наприклад "A-", щоб отримати мітки A-1, A-2, A-3.
- **Початкове значення** -- Число, з якого починається відлік. За замовчуванням 1. Встановіть 0 для нумерації з нуля.
- **Продовжувати нумерацію між розривними діапазонами** -- Увімкніть, якщо правило охоплює несуміжні сторінки (наприклад, `1-9,30-40` або `odd`) і нумерація має тривати послідовно.
- **Видалити наявні мітки сторінок** -- Увімкнено за замовчуванням. Очищає всі попередні мітки перед застосуванням нових правил.

## Можливості

- Кілька правил міток в одному документі для складних схем нумерації
- Шість стилів міток, що охоплюють усі стандартні системи нумерації
- Підтримка власних префіксів для нумерації за розділами
- Підтримка розривних діапазонів зі наскрізною нумерацією
- Можливість зберегти або видалити наявні мітки

## Приклади використання

- Римські цифри (i, ii, iii) для передмови книги й десяткові мітки для основного тексту
- Позначення сторінок додатків буквеними префіксами, як-от "A-1", "A-2", "B-1", "B-2"
- Виправлення міток сторінок у відсканованому документі, де фізичні номери сторінок не збігаються з порядком сторінок у PDF
- Нумерація з нуля для технічних документів

## Поради

- Мітки сторінок є метаданими, які PDF-переглядачі показують на навігаційній панелі. Вони не друкуються на самій сторінці. Для видимих номерів використовуйте [Нумерація сторінок](./page-numbers).
- Для цього інструмента потрібно налаштувати CoherentPDF (CPDF) у налаштуваннях WASM. Якщо його не налаштовано, вам буде запропоновано це зробити.

# Word у PDF

Перетворюйте документи Microsoft Word та сумісні формати на PDF. Інструмент використовує рушій LibreOffice у браузері, який обробляє файли DOC, DOCX, ODT і RTF та зберігає у результаті форматування, таблиці, зображення, колонтитули й стилі.

## Підтримувані формати

| Формат            | Розширення |
| :---------------- | :--------- |
| Word (сучасний)   | `.docx`    |
| Word (застарілий) | `.doc`     |
| OpenDocument Text | `.odt`     |
| Rich Text Format  | `.rtf`     |

## Як це працює

1. Натисніть область завантаження або перетягніть документи Word. Можна вибрати одразу кілька файлів.
2. Перегляньте список файлів і впорядкуйте його.
3. Натисніть **Перетворити на PDF**. Під час першого використання завантажується рушій LibreOffice (індикатор прогресу показує стан ініціалізації), після чого кожен файл конвертується.
4. Один файл завантажується напряму як PDF. Кілька файлів пакуються в `word-converted.zip`.

## Параметри

Додаткових налаштувань немає. Рушій LibreOffice створює результат за стандартним профілем експорту в PDF.

## Результат

| Кількість файлів | Результат                                                      |
| :--------------- | :------------------------------------------------------------- |
| 1 файл           | Один PDF (початкова назва файлу з розширенням `.pdf`)          |
| 2+ файли         | ZIP-архів (`word-converted.zip`) з одним PDF для кожного файлу |

## Сценарії використання

- Перетворення резюме чи супровідного листа з DOCX на PDF перед поданням заявки на роботу
- Пакетне перетворення набору договорів або пропозицій на PDF для передачі клієнту
- Перетворення старих файлів `.doc` на сучасні PDF для довгострокового архівування
- Перетворення спільних документів із Google Docs (експортованих як DOCX) на PDF
- Створення PDF, готових до друку, із шаблонів Word, які використовуються в автоматичному формуванні документів

## Поради

- Рушій LibreOffice завантажується один раз за сеанс і кешується. Під час першого перетворення доведеться почекати кілька секунд, наступні виконуються значно швидше.
- Складне форматування (макроси, елементи ActiveX, розширений SmartArt) може конвертуватися неідеально. Стандартні елементи документа (текст, таблиці, зображення, колонтитули, виноски) конвертуються надійно.
- Оскільки інструмент приймає також ODT і RTF, його можна використовувати як універсальний конвертер усіх текстових форматів.

# Нумерація Bates

Нумерація Bates наносить послідовні ідентифікатори на кожну сторінку ваших PDF. Це стандартний метод маркування документів у судових процесах, аудитах і робочих процесах відповідності вимогам. Інструмент підтримує кілька файлів і настроювані шаблони та видає окремо пронумеровані PDF або єдиний ZIP-архів.

## Як це працює

1. Завантажте один або кілька PDF-файлів. Можна перетягнути одразу кілька файлів.
2. Виберіть готовий стиль або створіть власний шаблон.
3. Налаштуйте позицію, шрифт, розмір, колір і початкові номери.
4. Натисніть **Застосувати номери Bates**, щоб обробити файли.
5. Один файл завантажується напряму. Кілька файлів завантажуються як ZIP-архів.

## Параметри

- **Готовий стиль** -- Виберіть один із вбудованих форматів:
  - Exhibit + Case + Bates + Page (наприклад, "Exhibit 1 Case XYZ 000001 Page 1")
  - Exhibit + Case + Bates (без номера сторінки)
  - Case + Bates
  - Bates Number Only (наприклад, "000001")
  - Власний (напишіть власний шаблон)
- **Власний стиль** -- Рядок шаблону із заповнювачами: `[BATES]`, `[PAGE]`, `[FILE]`, `[FILENAME]`.
- **Заповнення номера Bates** -- Кількість цифр (від 3 до 6) для номерів Bates із ведучими нулями. Видимий лише у власному режимі.
- **Позиція** -- Верхній або нижній колонтитул, ліворуч, по центру або праворуч.
- **Номер Bates починається з** -- Перший номер Bates. За замовчуванням 1. Нумерація продовжується між файлами.
- **Лічильник файлів починається з** -- Початковий номер для заповнювача `[FILE]`.
- **Шрифт** -- Helvetica, Times New Roman або Courier.
- **Розмір шрифту** -- Розмір нанесеного тексту.
- **Колір** -- Вибір кольору тексту номера Bates.

## Можливості

- Попередній перегляд наживо, що показує вигляд номерів Bates у всіх завантажених файлах
- Підтримка кількох файлів зі скрізною нумерацією між документами
- Зміна порядку файлів перетягуванням для керування послідовністю нумерації
- Шість варіантів позиції (верх/низ, ліворуч/по центру/праворуч)
- Адаптивний розрахунок полів з урахуванням різних розмірів сторінок
- Вивід у ZIP для пакетів із кількох файлів
- Заповнювачі в шаблонах для максимальної гнучкості

## Приклади використання

- Нанесення послідовних номерів експонатів на документи для судового розкриття доказів
- Нумерація пакетів доказів аудиту, що охоплюють десятки файлів
- Застосування регуляторних довідкових номерів до документації з відповідності вимогам
- Маркування додатків до патентних заявок ідентифікаторами конкретної справи

## Поради

- Перед обробкою перетягніть файли у списку, щоб змінити їх порядок. Послідовність нумерації Bates відповідає цьому порядку.
- Використовуйте заповнювач `[FILENAME]`, щоб додати до штампа початкову назву файлу, що допомагає простежити сторінки до вихідних документів.
- Поле попереднього перегляду оновлюється в реальному часі під час зміни налаштувань, тож ви можете перевірити формат до обробки.

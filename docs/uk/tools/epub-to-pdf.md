# EPUB у PDF

Перетворюйте електронні книги EPUB на файли PDF, не залишаючи браузер. EPUB є відкритим стандартом цифрових книг, але іноді потрібен PDF із фіксованою версткою для друку, коментування чи передавання людям без читалки.

## Підтримувані формати

| Формат | Розширення | Примітки              |
| :----- | :--------- | :-------------------- |
| EPUB   | `.epub`    | Файли EPUB 2 і EPUB 3 |

## Як це працює

1. Клацніть зону завантаження або перетягніть файли EPUB. Підтримується вибір кількох файлів.
2. Перегляньте завантажені файли. Видаліть непотрібні піктограмою кошика або натисніть **Додати ще файли**, щоб розширити партію.
3. Натисніть **Конвертувати у PDF**. Рушій PyMuPDF відображає вміст EPUB (текст, зображення та форматування) у посторінковий PDF.
4. Один EPUB завантажується одразу як PDF. Кілька файлів пакуються в ZIP-архів `epub-converted.zip`.

## Параметри

Перетворення виконується зі зручними типовими налаштуваннями й не потребує обов’язкової конфігурації. Текст перекомпоновується під стандартні розміри сторінки, а вбудовані шрифти й зображення переносяться в PDF.

## Сценарії використання

- Друк електронної книги без DRM для читання поза екранами
- Подання рукопису EPUB як PDF із фіксованою версткою для рецензування
- Архівування цифрових книг у форматі, який нативно відкриває кожна операційна система
- Передавання розділу колезі, який не має читалки EPUB
- Перетворення технічної документації, що поширюється як EPUB, на PDF, які можна коментувати

## Поради

- Функції EPUB 3, як-от вбудоване аудіо та відео, не переносяться в PDF, але весь текст, зображення й таблиці перетворюються без проблем.
- Для найкращого результату з сильно стилізованими EPUB перевірте кілька перших сторінок результату, щоб переконатися у відповідності верстки.

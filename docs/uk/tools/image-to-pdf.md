# Зображення у PDF

Універсальний конвертер зображень у PDF. Завантажуйте зображення практично в будь-якому форматі та об’єднуйте їх в один документ PDF. Кожне зображення отримує власну сторінку з розмірами оригіналу.

## Підтримувані формати

| Формат          | Розширення                             |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

Це найширша підтримка форматів серед усіх конвертерів зображень BentoPDF. Якщо вам потрібен лише один формат, скористайтеся відповідним окремим інструментом.

## Як це працює

1. Натисніть область завантаження або перетягніть файли зображень. Можна вибрати кілька файлів одночасно.
2. Перегляньте список файлів. Видаліть непотрібні файли значком кошика або натисніть **Додати ще файли**, щоб додати інші зображення.
3. Оберіть рівень **Якості PDF** у списку.
4. Натисніть **Конвертувати в PDF**. Інструмент обробляє зображення рушієм PyMuPDF і завантажує результат як `images_to_pdf.pdf`.

## Параметри

**Якість PDF** визначає стиснення зображень під час вбудовування в PDF:

- **Висока якість**: мінімальне стиснення, більший розмір файлу. Найкраще для друку чи архівування.
- **Середня якість** (за замовчуванням): збалансоване стиснення. Підходить для більшості випадків.
- **Низька якість**: сильне стиснення, найменший розмір файлу. Підходить для електронної пошти чи швидкого обміну.

Файли HEIC і WebP автоматично конвертуються у PNG перед вбудовуванням. Це відбувається непомітно й не потребує додаткових дій.

## Сценарії використання

- Об’єднання сканованих чеків чи документів, зроблених камерою телефона, в один PDF
- Створення фотопортфоліо чи лукбука зі зображень різних форматів
- Конвертація фото з iPhone (HEIC) у PDF без встановлення програм
- Збирання дизайнерських макетів з експортів PSD і скриншотів у фінальний матеріал для клієнта
- Архівування теки зі старими форматами зображень (PNM, JXR, JP2) в один PDF

## Поради

- Порядок зображень у PDF відповідає їхньому порядку в списку файлів. Завантажуйте їх у потрібній послідовності.
- Для найменшого розміру файлу оберіть низьку якість. Для сканів із великою кількістю тексту різниця зазвичай непомітна.
- Якщо у вас зображення лише одного формату, окремі конвертери (JPG у PDF, PNG у PDF тощо) дають той самий результат із простішим інтерфейсом.

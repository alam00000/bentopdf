# Підготовка PDF для AI

Витягує вміст із файлів PDF і структурує його як JSON, оптимізований для споживання великими мовними моделями (LLM) і AI-фреймворками, як-от LlamaIndex. Вміст кожної сторінки витягується й організовується у структурований формат, готовий для конвеєрів RAG, чат-ботів або систем семантичного пошуку.

## Як це працює

1. Завантажте один або кілька PDF, натиснувши зону перетягування або перетягнувши файли на неї.
2. Натисніть **Витягти**, щоб почати обробку.
3. Один файл завантажується як `filename_llm.json`. Кілька файлів дають архів `pdf-for-ai.zip`.

Інструмент використовує інтеграцію PyMuPDF з LlamaIndex, щоб витягти вміст на рівні сторінок з метаданими, отримуючи результат, який можна напряму завантажувати в AI-фреймворки.

## Параметри

Цей інструмент не має налаштовуваних параметрів. Усі сторінки витягуються з повним текстом і метаданими.

## Формат результату

- **Один файл**: `filename_llm.json`
- **Кілька файлів**: `pdf-for-ai.zip` з одним `_llm.json` на кожен вхідний PDF.

JSON-результат відповідає схемі документів LlamaIndex з текстовим вмістом кожної сторінки та полями метаданих.

## Сценарії використання

- Підготовка документів PDF для конвеєрів генерації з доповненням пошуком (RAG).
- Створення бази знань з пошуком з архівів PDF для AI-чат-бота.
- Передача звітів PDF в аналітичні процеси на основі LLM.
- Попередня обробка наукових статей для семантичного пошуку та систем «питання-відповідь».
- Створення структурованих навчальних даних із колекцій документів PDF.

## Поради

- Для вилучення простого тексту без AI-специфічного форматування скористайтеся [PDF у текст](./pdf-to-text).
- Для виводу в Markdown зі збереженням заголовків і структури скористайтеся [PDF у Markdown](./pdf-to-markdown).
- Скановані PDF дадуть порожній або мінімальний результат. Спершу пропустіть їх через OCR, щоб додати текстовий шар перед вилученням.

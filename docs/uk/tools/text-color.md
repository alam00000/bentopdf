# Змінити колір тексту

Замініть колір тексту в усьому PDF. Інструмент визначає текстові області на кожній сторінці й перефарбовує їх у вибраний колір, зберігаючи макет документа та нетекстовий вміст.

## Як це працює

1. Завантажте файл PDF.
2. Виберіть новий колір тексту за допомогою вибору кольору. За замовчуванням синій (#0000FF).
3. Натисніть **Змінити колір тексту** для обробки.
4. Перефарбований PDF завантажується автоматично. Індикатор прогресу показує, яка сторінка обробляється.

## Параметри

- **Новий колір тексту**: вибір кольору для заміни кольору всього тексту в документі.

## Можливості

- Перефарбовує текст на кожній сторінці документа
- Обробка посторінково з індикацією прогресу
- Вибір кольору з повною підтримкою hex-кольорів
- Зберігає макет сторінки та нетекстові елементи

## Сценарії використання

- Заміна чорного тексту на темно-синій для м’якшого, сучаснішого вигляду документа
- Перефарбування тексту відповідно до фірмових стандартів перед розповсюдженням документів
- Перетворення тексту на певний колір для відповідності вимогам доступності
- Забезпечення видимості тексту на щойно застосованому кольорі фону

## Поради

- Цей інструмент відтворює сторінки в масштабі 2x для якості, а потім відновлює PDF. Результат є зображенням, тому текст більше не можна буде виділити чи шукати.
- Для документів, де потрібно зберегти виділюваний текст, краще відредагуйте PDF безпосередньо за допомогою [Редактора PDF](./edit-pdf).
- Час обробки зростає зі збільшенням кількості сторінок, оскільки кожна сторінка відтворюється окремо.

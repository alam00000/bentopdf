# TIFF у PDF

Конвертуйте файли TIFF у PDF, зокрема багатосторінкові TIFF. Кожна сторінка (або «IFD») у файлі TIFF стає окремою сторінкою вихідного PDF. Це особливо корисно для сканованих документів, факсів і медичних зображень, які зазвичай зберігаються як багатосторінкові TIFF.

## Підтримувані формати

| Формат | Розширення      |
| :----- | :-------------- |
| TIFF   | `.tiff`, `.tif` |

## Як це працює

1. Натисніть область завантаження або перетягніть файли TIFF.
2. Перегляньте список файлів і керуйте ним за потреби.
3. Натисніть **Конвертувати в PDF**. Результат завантажується як `from_tiff.pdf`.

Інструмент декодує кожен файл TIFF за допомогою декодера TIFF на JavaScript, витягуючи необроблені піксельні дані RGBA кожної сторінки. Кожна сторінка відтворюється на полотні, експортується як PNG і вбудовується в PDF. Розміри сторінок відповідають оригінальним сторінкам TIFF.

## Параметри

Цей інструмент не надає додаткових налаштувань якості. Зображення вбудовуються у власній роздільній здатності.

## Сценарії використання

- Конвертація багатосторінкових факсимільних документів (TIFF-F) у зручніший для перенесення формат PDF
- Перетворення архівів сканованих документів, що зберігаються як TIFF, на PDF з пошуком (після цього поєднайте з інструментом OCR)
- Обробка файлів медичної візуалізації (патологічні препарати, експорти рентгенології), що використовують TIFF
- Конвертація файлів TIFF із ГІС або супутниковими знімками в документи для поширення

## Поради

- Багатосторінкові TIFF повністю підтримуються. 10-сторінковий TIFF дасть 10-сторінковий PDF. Спершу розділяти TIFF не потрібно.
- Дуже великі файли TIFF (сотні мегабайтів) можуть оброблятися довше, оскільки весь файл потрібно декодувати в пам’яті браузера.
- Якщо потрібен OCR отриманого PDF, пропустіть його через інструмент [OCR PDF](./ocr-pdf) після конвертації.

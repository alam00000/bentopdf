# Лінеаризація PDF

Лінеаризація перебудовує структуру PDF так, щоб першу сторінку можна було показати ще до завантаження всього файлу. Adobe називає це «Fast Web View». Якщо ви розміщуєте PDF на сайті або видаєте їх через портал документів, лінеаризація помітно пришвидшує їх відкриття.

## Як це працює

1. Завантажте один або кілька файлів PDF.
2. Натисніть **Лінеаризувати PDF**.
3. Завантажте результати як архів ZIP з усіма лінеаризованими файлами.

Налаштовувати нічого не потрібно. Інструмент використовує прапорець `--linearize` програми QPDF, який змінює внутрішню структуру PDF без зміни його візуального вмісту.

## Що робить лінеаризація

- Переупорядковує об’єкти PDF так, щоб дані першої сторінки опинилися на початку файлу
- Додає словник лінеаризації та таблиці підказок, щоб переглядачі знали, де шукати кожну сторінку
- Вмикає запити діапазонів байтів: браузер може отримати лише першу сторінку без завантаження всього файлу
- Очищає таблицю перехресних посилань для ефективного довільного доступу

## Можливості

- Пакетна обробка кількох PDF в одній операції
- Результат зберігає весь вміст, шрифти, зображення та інтерактивні елементи
- Використовує QPDF (WebAssembly) для надійної лінеаризації за стандартами
- Результати пакуються в ZIP для зручного завантаження

## Сценарії використання

- Розміщення PDF-звітів на сайті, де користувачі очікують миттєвого відображення сторінки
- Вбудовування PDF у вебзастосунки з переглядачами у браузері
- Публікація PDF-каталогів чи посібників, до яких звертаються через повільні мобільні з’єднання
- Підготовка документів для мереж доставки вмісту (CDN), що підтримують віддачу діапазонів байтів

## Поради

- Лінеаризуйте після завершення всіх інших правок. Будь-яка наступна зміна (об’єднання, додавання сторінок) порушить лінеаризацію.
- Поєднуйте зі «Стисненням PDF», щоб отримати найменші та найшвидші для завантаження PDF.
- Лінеаризація трохи збільшує розмір файлу (зазвичай менше ніж на 1%).

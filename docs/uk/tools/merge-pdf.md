# Об’єднати PDF

Об’єднуйте кілька файлів PDF в один документ. Можна зливати цілі файли у вибраному порядку або перейти в режим сторінок для докладного керування окремими сторінками з кожного завантаженого PDF.

## Як це працює

1. Завантажте два або більше файлів PDF, клацнувши область завантаження або перетягнувши їх.
2. Оберіть між **Режимом файлів** і **Режимом сторінок** за допомогою перемикача вгорі.
3. У режимі файлів перетягуйте файли, щоб змінити порядок, і за потреби вказуйте діапазони сторінок (наприклад, `1-3, 5`) для кожного файлу. Залиште діапазон порожнім, щоб додати всі сторінки.
4. У режимі сторінок перетягуйте окремі мініатюри сторінок, щоб побудувати точну послідовність сторінок.
5. Натисніть **Об’єднати PDF**, щоб зібрати все в один файл. Об’єднаний PDF завантажується автоматично.

## Можливості

- Два режими об’єднання: режим файлів для швидкого злиття цілих файлів, режим сторінок для керування кожною сторінкою
- Перевпорядкування перетягуванням в обох режимах із плавними анімаціями
- Синтаксис діапазонів сторінок (наприклад, `1-3, 5, 8-10`) дозволяє вибирати сторінки без переходу в режим сторінок
- Відкладене завантаження мініатюр сторінок зберігає чутливість інтерфейсу навіть із великими документами
- Без обмежень на кількість файлів чи загальну кількість сторінок
- Зберігає початкову якість PDF без повторного кодування

## Параметри

| Параметр           | Опис                                                                                                     |
| ------------------ | -------------------------------------------------------------------------------------------------------- |
| **Режим файлів**   | Об’єднання цілих файлів у власному порядку з необов’язковими фільтрами діапазонів для кожного файлу      |
| **Режим сторінок** | Візуальна сітка всіх сторінок з усіх файлів: перетягуйте мініатюри, щоб побудувати точну послідовність   |
| **Поле сторінок**  | Текстове поле для кожного файлу, що приймає діапазони на кшталт `1-3, 5`, щоб додати лише певні сторінки |

## Сценарії використання

- Об’єднання окремих PDF розділів в одну книгу чи звіт
- Поєднання супровідного листа та резюме в один документ для подання
- Збирання окремих сторінок із кількох джерел в один файл
- Збирання сканованих чеків чи рахунків в один архівний PDF
- Створення роздаткового матеріалу презентації зі слайдів кількох наборів

## Поради

- Використовуйте режим сторінок, коли потрібно чергувати сторінки з різних файлів, а не додавати один файл після іншого.
- Після початкового завантаження можна додати ще файли кнопкою **Додати ще файли**, не втрачаючи поточного розташування.
- Діапазони сторінок нумеруються з 1, тож `1` означає першу сторінку цього файлу.

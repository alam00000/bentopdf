# PDF у TIFF

Перетворює кожну сторінку PDF на зображення TIFF. TIFF є стандартним форматом для поліграфії, факсових систем і архівування документів. Інструмент використовує стиснення PackBits для кодування TIFF і повертається до PNG, якщо сторінку закодувати не вдалося.

## Як це працює

1. Завантажте PDF, натиснувши на область завантаження або перетягнувши файл.
2. Натисніть **Конвертувати** для обробки файлу.
3. Один файл TIFF або ZIP-архів завантажується автоматично.

## Параметри

Цей інструмент не має настроюваних параметрів. Сторінки відображаються у фіксованому масштабі 2x.

## Формат результату

- **Одна сторінка**: `filename.tiff`
- **Кілька сторінок**: `filename_tiffs.zip`, що містить `page_1.tiff`, `page_2.tiff` тощо.

Якщо кодування TIFF для певної сторінки не вдалося (через проблеми зі стисненням), ця сторінка зберігається як файл `.png`. У такому разі ZIP міститиме суміш файлів TIFF і PNG.

## Сценарії використання

- Подання документів до державних органів чи юридичних систем, що вимагають формат TIFF.
- Підготовка сторінок до передавання факсом через цифрові факсові сервіси.
- Архівування відсканованих документів у широко підтримуваному форматі без втрат.
- Передавання сторінок у корпоративні системи керування документами.

## Поради

- Файли TIFF великі. Якщо вам потрібна якість без втрат лише для вебу чи екрана, краще підійде [PDF у PNG](./pdf-to-png).
- Перевірте вміст ZIP, якщо для деяких сторінок знадобився запасний PNG: можливо, їх варто конвертувати окремо.

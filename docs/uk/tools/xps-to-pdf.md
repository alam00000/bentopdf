# XPS у PDF

Перетворюйте документи Microsoft XPS і OXPS на стандартні файли PDF. XPS (XML Paper Specification) був відповіддю Microsoft на PDF, але підтримка його на платформах поступово згасла. Цей інструмент знову робить такі документи доступними для всіх.

## Підтримувані формати

| Формат | Розширення | Примітки                                 |
| :----- | :--------- | :--------------------------------------- |
| XPS    | `.xps`     | Початковий формат Microsoft XPS          |
| OXPS   | `.oxps`    | Open XPS, варіант за стандартом ECMA-388 |

## Як це працює

1. Натисніть область завантаження або перетягніть файли XPS/OXPS. Можна вибрати одразу кілька файлів.
2. Перегляньте список файлів. Видаляйте окремі файли піктограмою кошика або натисніть **Додати ще файли**, щоб додати документи.
3. Натисніть **Перетворити на PDF**. Рушій PyMuPDF обробляє кожен документ локально у вашому браузері.
4. Один файл завантажується напряму як PDF. Кілька файлів пакуються в ZIP-архів `xps-converted.zip`.

## Параметри

Інструмент виконує пряме перетворення формату без додаткових налаштувань. Результат зберігає початкові розміри сторінок, векторну графіку, шрифти й зображення з файлу XPS.

## Сценарії використання

- Відкриття файлів XPS, отриманих зі старих систем Windows, де драйвер друку XPS був типовим
- Перетворення документів OXPS із Windows 10/11 для передачі користувачам macOS чи Linux
- Архівація старих файлів XPS у ширше підтримуваному форматі
- Надання зовнішнім отримувачам доступу до державних чи корпоративних документів у форматі XPS

## Поради

- Розширення `.xps` та `.oxps` обробляються автоматично: їх можна змішувати в одному пакеті.
- Якщо початковий файл XPS створено драйвером друку з високою роздільною здатністю, PDF збереже цю якість. Передискретизації не відбувається.

# PDF у PDF/A

PDF/A є підмножиною PDF, стандартизованою ISO, для довготривалого цифрового збереження. Цей інструмент конвертує ваші звичайні PDF у документи, що відповідають PDF/A, за допомогою Ghostscript, який працює безпосередньо у вашому браузері.

## Як це працює

1. Завантажте один чи кілька файлів PDF.
2. Оберіть **Версію PDF/A** у випадному списку.
3. За бажанням увімкніть **Попереднє сплощення PDF** для складних файлів, які не конвертуються звичайним способом.
4. Натисніть **Конвертувати у PDF/A**. Кілька файлів створюють ZIP-архів.

## Версії PDF/A

| Версія       | Обмеження                                        | Найкраще для                                            |
| ------------ | ------------------------------------------------ | ------------------------------------------------------- |
| **PDF/A-1b** | Найсуворіша. Без прозорості, без шарів.          | Максимальна сумісність зі старішими архівними системами |
| **PDF/A-2b** | Дозволяє прозорість і JPEG2000.                  | Універсальне архівування (рекомендовано)                |
| **PDF/A-3b** | Дозволяє вбудовані вкладення будь-якого формату. | Архівування документів із вихідними файлами даних       |

PDF/A-2b вибрано за замовчуванням, і він підходить для переважної більшості потреб архівування.

## Параметр попереднього сплощення

Деякі PDF містять особливості, що заважають чистій конвертації в PDF/A: незвичні кодування шрифтів, складні стеки прозорості або пошкоджені внутрішні структури. Увімкнення **Попереднього сплощення** растеризує PDF з роздільністю 300 DPI перед конвертацією, що гарантує відповідність ціною неможливості виділяти текст. Використовуйте його як запасний варіант, коли звичайна конвертація дає помилки.

Для попереднього сплощення потрібен рушій PyMuPDF WASM.

## Сценарії використання

- Виконання вимог державного чи юридичного архівування (у багатьох юрисдикціях PDF/A обов’язковий для судових документів)
- Подання документів до інституційних репозиторіїв або цифрових бібліотек
- Збереження ділових записів, для яких початкового програмного забезпечення за десять років може не існувати
- Підготовка рахунків до стандартів електронного виставлення, що вимагають PDF/A-3b із вкладеннями XML

## Поради

- Спершу спробуйте конвертацію без попереднього сплощення. Вмикайте його, лише якщо виникає помилка.
- PDF/A вбудовує всі шрифти, тож вихідні файли часто більші за оригінали.
- Якщо для вашого процесу потрібна сувора відповідність, перевірте результат у спеціальному валідаторі PDF/A.

# ODG у PDF

Конвертуйте файли OpenDocument Graphics у PDF. ODG є рідним форматом LibreOffice Draw і використовується для діаграм, блок-схем і векторних ілюстрацій. Конвертація в PDF спрощує обмін цими малюнками, їх друк і вбудовування в інші документи.

## Підтримувані формати

| Формат                | Розширення | Примітки                                 |
| :-------------------- | :--------- | :--------------------------------------- |
| OpenDocument Graphics | `.odg`     | Файли LibreOffice Draw / OpenOffice Draw |

## Як це працює

1. Натисніть область завантаження або перетягніть файли ODG. Можна додати кілька файлів одразу.
2. Перегляньте список файлів. Видаліть окремі записи значком кошика або натисніть **Додати ще файли**, щоб додати інші малюнки.
3. Натисніть **Конвертувати в PDF**. Рушій на основі LibreOffice завантажується у браузері та конвертує кожен файл ODG, зберігаючи векторну графіку, фігури й текст.
4. Один файл завантажується як PDF одразу. Кілька файлів дають архів ZIP з назвою `odg-to-pdf.zip`.

## Параметри

Додаткові налаштування не потрібні. Конвертація зберігає початкові розміри сторінки, фігури, з’єднувальні лінії та текстові поля з джерела ODG.

## Сценарії використання

- Передавання діаграм LibreOffice Draw клієнтам, у яких не встановлено LibreOffice
- Друк блок-схем і мережевих діаграм, створених у Draw
- Додавання ілюстрацій ODG у звіт чи презентацію як вбудованих PDF
- Архівування технічних креслень у форматі, який залишатиметься читабельним десятиліттями

## Поради

- Векторні елементи залишаються векторними у вихідному PDF, тому результат чітко масштабується до будь-якого розміру друку.
- Рушію LibreOffice потрібна мить для ініціалізації під час першого використання. Наступні конвертації в тому ж сеансі виконуються швидше.

# Редагувати закладки

Редактор закладок дає повний контроль над навігаційними закладками PDF (їх також називають структурою документа). Ви можете додавати нові закладки, редагувати наявні, змінювати ієрархію та імпортувати чи експортувати дані закладок у форматах CSV і JSON.

## Як це працює

1. Завантажте PDF, клацнувши по зоні або перетягнувши в неї файл.
2. За бажання позначте **Автоматично витягувати наявні закладки**, щоб підтягнути поточне дерево закладок документа.
3. Редактор відкриється в режимі розділеного вікна: переглядач PDF ліворуч, панель закладок праворуч.
4. Введіть назву закладки та натисніть **Додати до сторінки**, щоб створити закладку, яка вказує на поточну сторінку.
5. Кнопками на панелі інструментів змінюйте порядок, стиль або видаляйте закладки.
6. Натисніть **Зберегти PDF із закладками**, щоб завантажити оновлений файл.

## Можливості

- Візуальний переглядач PDF з навігацією сторінками, масштабуванням і переходом на сторінку за номером
- Додавання закладок до будь-якої сторінки одним клацанням
- Клацання безпосередньо по PDF для точного місця призначення закладки (режим вибору)
- Вкладена ієрархія закладок із перевпорядкуванням перетягуванням
- Пакетні операції: виберіть кілька закладок, щоб змінити колір, стиль або видалити їх одразу
- Пошук закладок для швидкого знаходження записів у великих деревах
- Скасування та повернення всіх змін
- Імпорт закладок із CSV (назва, сторінка, рівень) або JSON
- Експорт закладок у CSV або JSON для редагування в інших програмах
- Стилізація закладок: колір (червоний, синій, зелений, жовтий, фіолетовий) і накреслення (жирний, курсив, жирний курсив)
- Швидка навігація: гортайте сторінки клавішами Page Up/Page Down

## Параметри

- **Автоматично витягувати наявні закладки**: якщо позначено, інструмент зчитує й показує поточні закладки PDF під час завантаження.
- **Пакетний режим**: дозволяє вибрати кілька закладок і застосувати до них масову зміну кольору, стилю або видалення.
- **Розгорнути все / Згорнути все**: швидко показує або ховає вкладені закладки.

## Сценарії використання

- Додавання змісту до підручника чи посібника без закладок
- Перебудова закладок у відсканованому документі після розпізнавання тексту (OCR)
- Експорт закладок у CSV, редагування в електронній таблиці та повторний імпорт
- Виправлення автоматично створених закладок з неправильними посиланнями на сторінки
- Додавання кольорових закладок для позначення важливих розділів у юридичному документі

## Поради

- Для масового створення закладок використовуйте імпорт CSV. Формат простий: `title,page,level`, де рівень 1 означає верхній рівень.
- Режим вибору дозволяє клацнути точне місце на сторінці PDF, щоб задати призначення закладки. Це точніше, ніж указувати лише номер сторінки.
- Експортуйте закладки перед великими змінами, щоб мати резервну копію.

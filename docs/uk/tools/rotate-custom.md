# Повернути на довільний кут

Повертайте сторінки PDF на будь-який довільний кут, а не лише кратний 90 градусам. Кожна сторінка має власне поле для кута, а один кут можна застосувати до всіх сторінок одразу за допомогою пакетного керування.

## Як це працює

1. Завантажте файл PDF. Для кожної сторінки відображаються мініатюри.
2. Кожна сторінка має числове поле введення, що показує її поточний кут повороту.
3. Введіть будь-яке значення в градусах (додатне або від’ємне), щоб повернути певну сторінку, або скористайтеся кнопками вліво/вправо для кожної сторінки для швидких поворотів на 90 градусів.
4. Скористайтеся полем **пакетного кута** вгорі, щоб задати однаковий поворот для всіх сторінок.
5. Натисніть кнопку обробки, щоб створити повернутий PDF.

## Можливості

- Довільне введення градусів для кожної сторінки (будь-яке ціле значення)
- Пакетне керування кутом для задання однакового повороту на кожній сторінці
- Попередній перегляд повороту в мініатюрах у реальному часі
- Кнопки швидкого повороту для кожної сторінки з кроком 90 градусів
- Відкладене завантаження мініатюр для продуктивності на великих документах

## Сценарії використання

- Виправлення трохи нахилених сканів на кілька градусів
- Поворот сторінок відповідно до нестандартної вимоги щодо орієнтації
- Точне повертання окремих сторінок у документі зі змішаним вмістом
- Точне підлаштування кутів сторінок після початкового масового повороту

## Поради

- Додатні значення повертають за годинниковою стрілкою, від’ємні проти годинникової стрілки.
- Поле пакетного кута перезаписує всі кути окремих сторінок після застосування. За потреби задайте індивідуальні коригування після пакетної операції.
- Для стандартних поворотів на 90/180/270 градусів із простішим інтерфейсом скористайтеся [Повернути PDF](./rotate-pdf).

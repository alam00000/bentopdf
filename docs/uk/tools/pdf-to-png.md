# PDF у PNG

Перетворює кожну сторінку PDF на зображення PNG. PNG використовує стиснення без втрат, тож результат зберігає кожну деталь оригінальної сторінки. Односторінкові PDF завантажуються як файл `.png`, багатосторінкові створюють ZIP.

## Як це працює

1. Завантажте PDF, натиснувши на область завантаження або перетягнувши файл.
2. Налаштуйте повзунок **Масштаб**, щоб керувати роздільністю результату.
3. Натисніть **Конвертувати**, щоб почати обробку.
4. Один PNG або ZIP-архів завантажується автоматично.

## Параметри

- **Масштаб**: від 1.0x до 3.0x (за замовчуванням 2.0x). При 2.0x стандартна сторінка формату Letter відображається приблизно як 1 224 x 1 584 пікселів. Вищі значення масштабу дають більші й чіткіші зображення ціною розміру файлу та часу обробки.

## Формат результату

- **Одна сторінка**: `filename.png`
- **Кілька сторінок**: `filename_pngs.zip`, що містить `page_1.png`, `page_2.png` тощо.

## Сценарії використання

- Створення високоточних знімків сторінок PDF для презентацій.
- Витяг діаграм чи схем, яким потрібні чіткі краї без артефактів стиснення.
- Підготовка ресурсів для веб-дизайну з PDF-макетів.
- Створення зображень сторінок без втрат для попередньої обробки перед OCR.

## Поради

- Файли PNG значно більші за JPG. Якщо розмір файлу важливіший за ідеальну якість, скористайтеся [PDF у JPG](./pdf-to-jpg) або [PDF у WebP](./pdf-to-webp).
- При масштабі 1.0x результат відповідає рідній роздільності PDF. Підніміть до 3.0x для експорту якості друку.

# Об’єднати в одну сторінку

Зведіть усі сторінки PDF в одну довгу сторінку. Сторінки зшиваються вертикально (як сувій) або горизонтально (поруч), і на виході виходить одна суцільна сторінка.

## Як це працює

1. Завантажте файл PDF.
2. Виберіть напрямок розташування: **Вертикально** (сторінки одна під одною) або **Горизонтально** (сторінки поруч).
3. Задайте відстань між сторінками в пунктах.
4. Виберіть колір тла для проміжків між сторінками.
5. За бажання ввімкніть роздільники (тонкі лінії між сторінками) та налаштуйте їхню товщину й колір.
6. Натисніть кнопку обробки. Результатом буде PDF з однією сторінкою.

## Можливості

- Вертикальне або горизонтальне зшивання сторінок
- Налаштовувана відстань між сторінками
- Вибір кольору тла для проміжків
- Необов’язкові роздільні лінії з регульованою товщиною та кольором
- Кожна початкова сторінка відображається в повній роздільності на спільному полотні

## Параметри

| Параметр                     | Опис                                                   |
| ---------------------------- | ------------------------------------------------------ |
| **Напрямок розкладки**       | Вертикально (одна під одною) або горизонтально (поруч) |
| **Відступ**                  | Проміжок між сторінками в пунктах                      |
| **Колір фону**               | Колір області між сторінками                           |
| **Додати лінії-роздільники** | Увімкнення тонких ліній між сторінками                 |
| **Товщина роздільника**      | Товщина лінії в пунктах                                |
| **Колір роздільника**        | Колір ліній-роздільників                               |

## Сценарії використання

- Створення одного довгого зображення з багатосторінкового каркаса чи макета дизайну
- Створення суцільного вигляду документа для вбудовування на вебсторінку
- Зшивання багатосторінкового коміксу чи розкадровки в одну стрічку
- Створення панорамного вигляду послідовних сторінок для перегляду

## Поради

- Вертикальна орієнтація найкраще підходить для документів із книжковими сторінками. Горизонтальна краща для альбомного вмісту.
- Великі документи з багатьма сторінками дають дуже високий або дуже широкий результат. Деякі переглядачі PDF можуть погано працювати з надзвичайно великими окремими сторінками.
- Роздільники контрастного кольору допомагають побачити, де закінчується одна початкова сторінка й починається наступна.

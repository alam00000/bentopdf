# JPG у PDF

Перетворіть зображення JPG на охайний PDF. Завантажте один файл або кілька JPG одразу: кожне зображення стає повнорозмірною сторінкою вихідного документа.

## Підтримувані формати

| Формат    | Розширення      |
| :-------- | :-------------- |
| JPEG      | `.jpg`, `.jpeg` |
| JPEG 2000 | `.jp2`, `.jpx`  |

## Як це працює

1. Натисніть область завантаження або перетягніть файли JPG. Можна вибрати кілька файлів.
2. Перегляньте завантажені файли. Значком кошика видаляйте окремі файли або натисніть **Додати ще файли**, щоб доповнити список.
3. Оберіть рівень **Якості PDF**.
4. Натисніть **Конвертувати в PDF**. Інструмент стискає зображення відповідно до обраної якості, конвертує їх рушієм PyMuPDF і завантажує `from_jpgs.pdf`.

## Параметри

**Якість PDF** визначає стиснення кожного зображення перед вбудовуванням у PDF:

- **Висока якість**: зберігає максимум деталей. Для фотографії чи друку.
- **Середня якість** (за замовчуванням): хороший баланс між чіткістю та розміром файлу.
- **Низька якість**: сильне стиснення для найменшого результату.

## Сценарії використання

- Конвертація відсканованих документів, збережених як JPG, в один PDF для подання
- Пакування фото товарів у каталог для клієнтів
- Перетворення медичних чи супутникових зображень JPEG 2000 на переносний PDF
- Створення фотоальбому для друку з експортів камери

## Поради

- Файли JPEG 2000 (`.jp2`, `.jpx`) підтримуються повністю, а не лише стандартний JPEG. Це корисно для медичної візуалізації та геопросторових даних.
- Якщо ваші JPG зроблено камерою телефона, середня якість зазвичай дає файл на 40-60% менший, ніж висока, без помітної різниці на екрані.

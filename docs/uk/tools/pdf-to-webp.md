# PDF у WebP

Перетворює кожну сторінку PDF на зображення WebP. WebP зазвичай дає файли на 25-35% менші за JPG при тій самій сприйнятій якості, що робить його вдалим вибором для вебу.

## Як це працює

1. Завантажте PDF, натиснувши на область завантаження або перетягнувши файл.
2. Налаштуйте повзунок **Якість**.
3. Натисніть **Конвертувати** для обробки файлу.
4. Один файл `.webp` або ZIP-архів завантажується автоматично.

## Параметри

- **Якість**: повзунок від 0% до 100% (за замовчуванням 85%). Керує рівнем стиснення з втратами. Вищі значення зберігають більше деталей.

Усередині сторінки відображаються в масштабі 2x, тож зображення приблизно вдвічі більші за рідні розміри PDF.

## Формат результату

- **Одна сторінка**: `filename.webp`
- **Кілька сторінок**: `filename_webps.zip`, що містить `page_1.webp`, `page_2.webp` тощо.

## Сценарії використання

- Підготовка попередніх переглядів сторінок для сайтів, де важлива пропускна здатність.
- Створення легких зображень листівок чи брошур для соціальних мереж.
- Пакетна конвертація багатосторінкових документів в оптимізований для вебу набір зображень.

## Поради

- WebP підтримується в усіх сучасних браузерах. Для сумісності зі старішими скористайтеся запасним варіантом [PDF у JPG](./pdf-to-jpg).
- Якість 80-85% на екрані зазвичай не відрізняється від оригіналу, зберігаючи малий розмір файлів.

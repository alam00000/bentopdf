# Markdown у PDF

Повнофункціональний редактор Markdown із живим переглядом і експортом у PDF одним кліком. Пишіть з нуля, завантажуйте наявний файл `.md` або вставляйте вміст із буфера обміну. Редактор відтворює ваш Markdown у реальному часі та експортує стилізований PDF за допомогою вбудованого рушія друку браузера.

## Підтримувані формати

| Вхідні дані    | Опис                               |
| :------------- | :--------------------------------- |
| Файли `.md`    | Завантаження кнопкою «Завантажити» |
| Пряме введення | Введіть або вставте в редактор     |

## Як це працює

1. Відкрийте інструмент Markdown у PDF. Редактор завантажується з розділеним виглядом: джерело Markdown ліворуч, відтворений перегляд праворуч.
2. Напишіть Markdown, вставте його або натисніть **Завантажити**, щоб відкрити файл `.md`.
3. Перемикайте світлу й темну теми повзунком теми на панелі інструментів.
4. Натисніть **Експортувати PDF** (або `Ctrl/Cmd + S`), щоб створити PDF через діалог друку браузера.

## Можливості

Редактор підтримує широкий набір можливостей Markdown, окрім базових:

- **Стандартний Markdown**: заголовки, напівжирний, курсив, посилання, зображення, списки, цитати, горизонтальні лінії
- **Блоки коду** з підсвічуванням синтаксису для понад 15 мов (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash та інші)
- **Діаграми Mermaid**: блок-схеми, діаграми послідовностей, ER-діаграми та інші типи діаграм Mermaid відображаються прямо в перегляді
- **Таблиці** зі стандартним синтаксисом таблиць Markdown
- **Списки завдань** із прапорцями
- **Виноски**, **нижні індекси**, **верхні індекси**
- **Списки визначень**, **абревіатури**
- Підтримка **емодзі** (`:smile:` відображається як емодзі)
- **Виділення** (`==marked text==`) і **вставки** (`++inserted text++`)
- **Автоматичні посилання**: прості URL перетворюються на клікабельні посилання
- Створення **змісту**
- **Якірні посилання** на заголовках

## Сценарії використання

- Написання документації проєкту та експорт охайного PDF для зацікавлених сторін
- Створення технічних звітів із прикладами коду та архітектурними діаграмами Mermaid
- Конвертація README з GitHub у PDF для офлайн-використання чи друку
- Підготовка пропозиції чи специфікації зі списками завдань і таблицями
- Створення стилізованого роздаткового матеріалу з конспектів лекцій, написаних у Markdown

## Поради

- PDF створюється функцією друку в PDF браузера. У Chrome перед збереженням можна налаштувати поля й масштаб у діалозі друку.
- Діаграми Mermaid відображаються в перегляді, але під час першого використання їм може знадобитися мить для ініціалізації.
- Використовуйте `Ctrl/Cmd + S` як гарячу клавішу для експорту без звернення до кнопки.

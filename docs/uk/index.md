## OCR офлайн

Якщо ви самостійно розгортаєте BentoPDF в ізольованому або офлайн-середовищі, для OCR потрібні не лише Tesseract worker і файли traineddata. Для пошукового PDF також потрібно внутрішньо віддавати шрифти текстового шару OCR.
Повне налаштування, зокрема `VITE_OCR_FONT_BASE_URL`, вбудований каталог `ocr-fonts/` та оновлений процес для ізольованих середовищ, дивіться в розділі [Самостійне розгортання](/uk/self-hosting/).

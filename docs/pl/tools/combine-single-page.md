# Połącz w jedną stronę

Połącz wszystkie strony PDF w jedną, długą stronę. Strony są zszywane w pionie (jak zwój) lub w poziomie (obok siebie), dając w wyniku jedną ciągłą stronę.

## Jak to działa

1. Prześlij plik PDF.
2. Wybierz kierunek układu: **Pionowo** (strony jedna pod drugą) lub **Poziomo** (strony obok siebie).
3. Ustaw odstęp między stronami w punktach.
4. Wybierz kolor tła dla przerw między stronami.
5. Opcjonalnie włącz separatory (cienkie linie między stronami) i skonfiguruj ich grubość i kolor.
6. Kliknij przycisk przetwarzania. Wynikiem jest jednostronicowy PDF.

## Funkcje

- Zszywanie stron w pionie lub w poziomie
- Konfigurowalny odstęp między stronami
- Wybór koloru tła obszarów między stronami
- Opcjonalne linie separatorów z regulowaną grubością i kolorem
- Renderuje każdą oryginalną stronę w pełnej rozdzielczości na połączonym płótnie

## Opcje

| Opcja                      | Opis                                                |
| -------------------------- | --------------------------------------------------- |
| **Orientacja**             | Pionowo (jedna pod drugą) lub poziomo (obok siebie) |
| **Odstęp między stronami** | Przerwa między stronami w punktach                  |
| **Kolor tła**              | Kolor obszaru między stronami                       |
| **Dodaj separator**        | Włącza cienkie linie między stronami                |
| **Grubość separatora**     | Grubość linii w punktach                            |
| **Kolor separatora**       | Kolor linii separatorów                             |

## Zastosowania

- Tworzenie jednego długiego obrazu z wielostronicowego szkieletu lub makiety projektu
- Generowanie ciągłego, przewijanego widoku dokumentu do osadzenia w sieci
- Zszywanie wielostronicowego komiksu lub storyboardu w jeden pasek
- Tworzenie panoramicznego widoku kolejnych stron do recenzji

## Wskazówki

- Układ pionowy najlepiej sprawdza się w dokumentach ze stronami pionowymi. Poziomy jest lepszy dla treści w orientacji poziomej.
- Duże dokumenty z wieloma stronami dadzą bardzo wysoki lub szeroki wynik. Niektóre przeglądarki PDF mogą mieć problem z ekstremalnie dużymi pojedynczymi stronami.
- Dodanie separatorów w kontrastowym kolorze ułatwia zobaczenie, gdzie kończy się jedna oryginalna strona, a zaczyna następna.

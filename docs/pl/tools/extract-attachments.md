# Wyodrębnij załączniki

Wyciągnij każdy osadzony załącznik z jednego lub wielu plików PDF. Wszystkie wyodrębnione pliki są pakowane do jednego archiwum ZIP do pobrania.

## Jak to działa

1. Prześlij jeden lub więcej plików PDF zawierających osadzone załączniki.
2. Kliknij **Wyodrębnij załączniki**.
3. Narzędzie skanuje każdy PDF pod kątem załączników na poziomie dokumentu i strony.
4. Wszystkie znalezione pliki są pakowane do archiwum ZIP i pobierane automatycznie.
5. Komunikat o stanie potwierdza, ile załączników znaleziono i jaki jest ich łączny rozmiar.

## Funkcje

- Wyodrębnianie wsadowe z wielu plików PDF naraz
- Wyodrębnia załączniki na poziomie dokumentu i strony
- Zwraca jeden plik ZIP ze wszystkimi wyodrębnionymi plikami
- Wyświetla łączną liczbę załączników i łączny rozmiar plików
- Czytelne komunikaty, jeśli nie znaleziono załączników

## Zastosowania

- Odzyskiwanie plików danych osadzonych w raporcie PDF
- Wyciąganie zasobów graficznych z portfolio lub dokumentu specyfikacji
- Wyodrębnianie materiałów dodatkowych z plików PDF szkoleniowych lub dotyczących zgodności
- Audyt plików osadzonych w partii plików PDF

## Wskazówki

- Jeśli narzędzie zgłasza brak załączników, PDF może zawierać osadzone obrazy lub dane formularzy, które nie są załącznikami plikowymi. Dla osadzonych obrazów użyj [Wyodrębnij obrazy](./extract-images).
- Przy przetwarzaniu wielu plików PDF wszystkie załączniki ze wszystkich plików trafiają do jednego ZIP. Nazwy plików są zachowywane z oryginalnych osadzeń.

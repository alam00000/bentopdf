# Napraw rozmiar strony

PDF-y złożone z wielu źródeł często mają strony o różnych rozmiarach: jedne w formacie Letter, inne A4, a jeszcze inne zupełnie niestandardowe. To narzędzie wymusza jeden docelowy rozmiar dla każdej strony, skalując zawartość tak, aby pasowała lub wypełniała stronę.

## Jak to działa

1. Prześlij plik PDF.
2. Wybierz **Docelowy rozmiar strony** z listy rozwijanej (A4, Letter, Legal, A3, A5, Tabloid lub Niestandardowy).
3. Wybierz **Orientację**: Auto zachowuje oryginalną orientację każdej strony, ale możesz też wymusić pionową lub poziomą.
4. Wybierz tryb **Skalowania zawartości**: Dopasuj (zachowuje całą zawartość, może dodać marginesy) lub Wypełnij (wypełnia stronę, może przyciąć krawędzie).
5. Opcjonalnie ustaw **Kolor tła** dla dodanych marginesów.
6. Kliknij **Napraw rozmiar strony**.

## Opcje

- **Standardowe rozmiary**: A4, Letter, Legal, A3, A5, Tabloid
- **Własne wymiary**: Podaj szerokość i wysokość w calach lub milimetrach
- **Orientacja**: Auto, pionowa, pozioma
- **Tryb skalowania**: Dopasuj lub Wypełnij (z przycięciem)
- **Kolor tła**: Dowolny kolor wypełnienia marginesów

## Zastosowania

- Ujednolicanie połączonego PDF-a, którego strony pochodziły z różnych skanerów
- Konwersja dokumentu w formacie US Letter na A4 na potrzeby międzynarodowej dystrybucji
- Przygotowanie PDF-ów do druku, które wymagają stałego rozmiaru po przycięciu
- Naprawa stron o lekko niestandardowych wymiarach (np. 8,49 x 11,02 cala zamiast 8,5 x 11)

## Wskazówki

- Użyj trybu Dopasuj, aby mieć pewność, że żadna zawartość nie zginie. Tryb Wypełnij wygląda czyściej, ale może przyciąć krawędzie.
- Sprawdź wynik narzędziem Wymiary strony, aby upewnić się, że każda strona odpowiada rozmiarowi docelowemu.
- Domyślny kolor tła to biały. Przełącz na ciemny, jeśli dokument ma ciemne marginesy.

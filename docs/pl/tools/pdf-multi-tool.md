# Wielofunkcyjne narzędzie PDF

Jedno miejsce pracy dla każdej operacji na stronach PDF. Prześlij jeden lub więcej plików PDF i pracuj na wszystkich ich stronach w jednej wizualnej siatce. Obracaj, zmieniaj kolejność, duplikuj i usuwaj strony, wstawiaj pliki PDF, obrazy i puste strony, zmieniaj numerację i rozmiar stron oraz dziel wynik, a wszystko bez opuszczania narzędzia.

## Jak to działa

1. Kliknij **Wybierz pliki** lub przeciągnij pliki na obszar przesyłania. Obsługiwanych jest wiele plików, a łączą się one w kolejności przesłania.
2. Wszystkie strony pojawiają się w przewijanej siatce z miniaturami.
3. Kliknij stronę, aby ją zaznaczyć. Kliknij z wciśniętym Shift, aby zaznaczyć zakres, lub z wciśniętym Cmd/Ctrl, aby dodać albo usunąć z zaznaczenia pojedyncze strony.
4. Użyj paska narzędzi lub kliknij stronę prawym przyciskiem myszy, aby wybrać działania na stronach.
5. Kliknij **Eksportuj PDF**, aby pobrać końcowy wynik.

## Funkcje

- **Łączenie**: prześlij wiele plików PDF i obrazów, a automatycznie połączą się w jeden dokument
- **Zmiana kolejności**: przeciągaj i upuszczaj strony, aby zmienić ich kolejność, lub odwróć kolejność całego dokumentu
- **Obracanie**: obracaj zaznaczone strony w lewo lub w prawo co 90 stopni
- **Duplikowanie**: skopiuj zaznaczone strony i umieść kopie zaraz za nimi
- **Usuwanie**: usuń zaznaczone strony
- **Wstawianie**: dodaj strony z innego pliku PDF lub obrazu, pustą stronę albo strony ze schowka lub przeplataj strony drugiego pliku PDF z bieżącymi
- **Zastępowanie**: zamień stronę na pierwszą stronę innego pliku PDF
- **Wycinanie, kopiowanie i wklejanie**: przenoś lub kopiuj strony w obrębie dokumentu
- **Wyodrębnianie**: pobierz zaznaczone strony jako PDF lub jako obrazy
- **Numery stron**: ustaw etykiety stron, takie jak i, ii, iii lub A-1, A-2, dla zakresu stron
- **Rozmiar strony**: dopasuj strony do standardowego formatu papieru lub własnego rozmiaru
- **Podział**: podziel dokument według zakresów stron, na strony nieparzyste i parzyste, na pojedyncze strony, według zakładek, co N stron lub według rozmiaru pliku
- **Cofnij / Ponów**: każdą operację na stronach można cofnąć i ponowić
- Automatycznie naprawia uszkodzone pliki PDF przed załadowaniem

## Skróty klawiszowe

| Działanie              | Skrót                         |
| ---------------------- | ----------------------------- |
| Obróć w prawo / w lewo | R / Shift+R                   |
| Zaznacz wszystko       | Cmd/Ctrl+A                    |
| Wytnij, kopiuj, wklej  | Cmd/Ctrl+X, C, V              |
| Duplikuj               | Cmd/Ctrl+D                    |
| Usuń                   | Delete lub Backspace          |
| Cofnij / Ponów         | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| Przesuń zaznaczenie    | Klawisze strzałek, Home, End  |

## Przypadki użycia

- Budowanie własnego dokumentu ze stron z wielu źródłowych plików PDF
- Porządkowanie zeskanowanego dokumentu przez usuwanie pustych stron, obracanie skanów ułożonych bokiem i zmianę kolejności sekcji
- Dzielenie dużego PDF na granicach rozdziałów za pomocą jego zakładek
- Szybka edycja na poziomie stron bez potrzeby używania pełnego edytora PDF

## Wskazówki

- Historia cofania i ponawiania śledzi każdą operację na stronach. Korzystaj z niej swobodnie, nie możesz przypadkowo zniszczyć swojej pracy.
- Użyj **Insert > From File** lub w dowolnym momencie upuść kolejne pliki PDF albo obrazy na siatkę stron, aby dodać je do dokumentu.
- Do prostych zadań łączenia lub dzielenia dedykowane narzędzia [Połącz PDF](./merge-pdf) lub [Podziel PDF](./split-pdf) mogą być szybsze. Wielofunkcyjne narzędzie sprawdza się, gdy potrzebujesz wielu operacji w jednej sesji.

# Markdown na PDF

W pełni funkcjonalny edytor Markdown z podglądem na żywo i eksportem do PDF jednym kliknięciem. Pisz od zera, prześlij istniejący plik `.md` lub wklej treść ze schowka. Edytor renderuje Markdown w czasie rzeczywistym i eksportuje sformatowany PDF za pomocą wbudowanego silnika drukowania przeglądarki.

## Obsługiwane formaty

| Wejście                   | Opis                          |
| :------------------------ | :---------------------------- |
| Pliki `.md`               | Prześlij przyciskiem Prześlij |
| Bezpośrednie wprowadzanie | Wpisz lub wklej w edytorze    |

## Jak to działa

1. Otwórz narzędzie Markdown na PDF. Edytor ładuje się z widokiem podzielonym: źródło Markdown po lewej, wyrenderowany podgląd po prawej.
2. Napisz Markdown, wklej go lub kliknij **Prześlij**, aby wczytać plik `.md`.
3. Przełączaj motyw jasny i ciemny suwakiem motywu na pasku narzędzi.
4. Kliknij **Eksportuj PDF** (lub naciśnij `Ctrl/Cmd + S`), aby wygenerować PDF przez okno drukowania przeglądarki.

## Funkcje

Edytor obsługuje szeroki zestaw funkcji Markdown wykraczający poza podstawy:

- **Standardowy Markdown**: nagłówki, pogrubienie, kursywa, linki, obrazy, listy, cytaty, linie poziome
- **Bloki kodu** z podświetlaniem składni dla ponad 15 języków (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash i inne)
- **Diagramy Mermaid**: schematy blokowe, diagramy sekwencji, diagramy ER i inne typy wykresów Mermaid renderują się bezpośrednio w podglądzie
- **Tabele** w standardowej składni tabel Markdown
- **Listy zadań** z polami wyboru
- **Przypisy**, **indeks dolny**, **indeks górny**
- **Listy definicji**, **skróty**
- Obsługa **emoji** (`:smile:` renderuje się jako emoji)
- **Wyróżnienia** (`==marked text==`) i **wstawienia** (`++inserted text++`)
- **Automatyczne linki**: zwykłe adresy URL są zamieniane na klikalne linki
- Generowanie **spisu treści**
- **Linki kotwic** w nagłówkach

## Zastosowania

- Pisanie dokumentacji projektu i eksport dopracowanego PDF-a dla interesariuszy
- Tworzenie raportów technicznych z przykładami kodu i diagramami architektury Mermaid
- Konwersja README z GitHub do PDF na potrzeby użycia offline lub druku
- Przygotowywanie propozycji lub specyfikacji z listami zadań i tabelami
- Generowanie stylizowanych materiałów dla uczestników z notatek z wykładu napisanych w Markdown

## Wskazówki

- PDF powstaje za pomocą funkcji drukowania do PDF w przeglądarce. W Chrome możesz dostosować marginesy i skalę w oknie drukowania przed zapisem.
- Diagramy Mermaid renderują się w podglądzie, ale przy pierwszym użyciu może minąć chwila, zanim się zainicjalizują.
- Użyj skrótu `Ctrl/Cmd + S`, aby wyeksportować bez sięgania po przycisk.

# Edytuj metadane

Edytuj metadane osadzone w pliku PDF. Narzędzie wstępnie wypełnia formularz istniejącymi metadanymi dokumentu, pozwala zmienić dowolne pole i zapisuje zmiany w nowym PDF.

## Jak to działa

1. Prześlij plik PDF. Narzędzie odczytuje jego bieżące metadane i wypełnia formularz.
2. Edytuj dowolne ze standardowych pól: Tytuł, Autor, Temat, Słowa kluczowe, Twórca, Producent.
3. Dostosuj Datę utworzenia i Datę modyfikacji za pomocą selektorów daty i godziny.
4. Dodaj własne pola metadanych, klikając przycisk dodawania i wpisując parę klucz-wartość.
5. Kliknij przycisk przetwarzania, aby zapisać zmodyfikowany PDF.

## Funkcje

- Wstępnie wypełnia wszystkie istniejące metadane z przesłanego PDF
- Pola standardowe: Tytuł, Autor, Temat, Słowa kluczowe, Twórca, Producent
- Selektory daty i godziny dla Daty utworzenia i Daty modyfikacji
- Własne pola metadanych klucz-wartość dla dowolnych właściwości
- Zapisuje zmiany bezpośrednio w słowniku informacji o dokumencie PDF

## Edytowalne pola

| Pole                    | Opis                                                           |
| ----------------------- | -------------------------------------------------------------- |
| **Tytuł**               | Tytuł dokumentu wyświetlany w czytnikach PDF                   |
| **Autor**               | Osoba lub organizacja, która utworzyła dokument                |
| **Temat**               | Krótki opis tematu dokumentu                                   |
| **Słowa kluczowe**      | Terminy oddzielone przecinkami do wyszukiwania i kategoryzacji |
| **Twórca**              | Aplikacja, która pierwotnie utworzyła treść                    |
| **Producent**           | Aplikacja, która wygenerowała PDF                              |
| **Data utworzenia**     | Kiedy dokument został pierwotnie utworzony                     |
| **Data modyfikacji**    | Kiedy dokument został ostatnio zmodyfikowany                   |
| **Pola niestandardowe** | Wszelkie dodatkowe pary klucz-wartość, które zdefiniujesz      |

## Zastosowania

- Ustawienie właściwego tytułu i autora przed publikacją dokumentu
- Dodawanie słów kluczowych, aby poprawić wyszukiwalność w systemach zarządzania dokumentami
- Aktualizacja daty modyfikacji, aby odzwierciedlała bieżącą wersję
- Dodawanie własnych pól metadanych, takich jak Dział, ID projektu lub Klasyfikacja
- Czyszczenie metadanych pozostawionych przez oryginalne oprogramowanie autorskie

## Wskazówki

- Pola niestandardowe są zapisywane bezpośrednio w słowniku informacji PDF. Niektóre czytniki PDF mogą ich nie wyświetlać, ale są zachowane w pliku.
- Zostaw pole puste, aby usunąć je z metadanych. Przycisk przetwarzania zapisuje wszystko, co jest w formularzu.
- Aby wyświetlić metadane bez edycji, użyj [Wyświetl metadane](./view-metadata). Aby całkowicie usunąć wszystkie metadane, użyj Usuń metadane.

# Edytuj załączniki

Sprawdzaj załączniki wewnątrz PDF i zarządzaj nimi. Narzędzie wyświetla każdy osadzony plik wraz z nazwą i poziomem załącznika, a następnie pozwala oznaczyć pojedyncze załączniki do usunięcia lub usunąć wszystkie naraz.

## Jak to działa

1. Prześlij plik PDF.
2. Narzędzie automatycznie skanuje załączniki i wyświetla je na liście.
3. Każdy załącznik pokazuje nazwę pliku i informację, czy jest załącznikiem na poziomie dokumentu, czy strony.
4. Kliknij ikonę kosza obok załącznika, aby oznaczyć go do usunięcia (kliknij ponownie, aby cofnąć oznaczenie).
5. Użyj przycisku **Usuń wszystkie załączniki**, aby zaznaczyć wszystko naraz, lub **Odznacz wszystko**, aby wyczyścić zaznaczenia.
6. Kliknij przycisk przetwarzania, aby zapisać nowy PDF bez wybranych załączników.

## Funkcje

- Wyświetla wszystkie załączniki na poziomie dokumentu i strony
- Usuwanie pojedyncze lub zbiorcze
- Włączanie i wyłączanie zaznaczenia przed zatwierdzeniem zmian
- Wizualne przekreślenie i zmiana przezroczystości elementów oznaczonych do usunięcia
- Pobiera zmodyfikowany PDF bez wybranych załączników

## Zastosowania

- Usuwanie nieaktualnych lub błędnych plików osadzonych w dokumencie przed jego rozpowszechnieniem
- Usuwanie wrażliwych załączników (dane finansowe, dane osobowe) z PDF przed udostępnieniem
- Zmniejszanie rozmiaru PDF przez usunięcie dużych osadzonych plików, które nie są już potrzebne
- Audyt osadzonej zawartości i porządkowanie dokumentu przed archiwizacją

## Wskazówki

- Załączniki oznaczone do usunięcia są pokazywane z wizualnym przekreśleniem. Możesz je przywrócić przed przetwarzaniem, jeśli zmienisz zdanie.
- Jeśli nie znaleziono żadnych załączników, narzędzie wyświetla wyraźny komunikat "Nie znaleziono załączników": PDF po prostu nie zawiera osadzonych plików.

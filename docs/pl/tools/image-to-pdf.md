# Obrazy do PDF

Uniwersalny konwerter obrazów na PDF. Prześlij obrazy w praktycznie dowolnym formacie i połącz je w jeden dokument PDF. Każdy obraz trafia na osobną stronę, o rozmiarze odpowiadającym oryginalnym wymiarom.

## Obsługiwane formaty

| Format          | Rozszerzenia                           |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

To najszersza obsługa formatów spośród wszystkich konwerterów obrazów w BentoPDF. Jeśli potrzebujesz tylko jednego konkretnego formatu, użyj zamiast tego dedykowanego narzędzia.

## Jak to działa

1. Kliknij obszar przesyłania lub przeciągnij i upuść pliki obrazów. Możesz wybrać wiele plików naraz.
2. Sprawdź listę plików. Usuń niepotrzebne ikoną kosza lub kliknij **Dodaj więcej plików**, aby dołączyć kolejne obrazy.
3. Wybierz poziom **Jakości PDF** z listy rozwijanej.
4. Kliknij **Konwertuj na PDF**. Narzędzie przetwarza obrazy silnikiem PyMuPDF i pobiera wynik jako `images_to_pdf.pdf`.

## Opcje

**Jakość PDF** określa kompresję obrazów stosowaną podczas osadzania ich w PDF:

- **Wysoka jakość**: minimalna kompresja, większy plik. Najlepsza do druku lub archiwizacji.
- **Średnia jakość** (domyślnie): zrównoważona kompresja. Dobra do większości zastosowań.
- **Niska jakość**: agresywna kompresja, najmniejszy plik. Nadaje się do e-maila lub szybkiego udostępniania.

Pliki HEIC i WebP są przed osadzeniem automatycznie konwertowane do PNG. Dzieje się to w tle i nie wymaga żadnych dodatkowych kroków.

## Zastosowania

- Łączenie zeskanowanych paragonów lub dokumentów z aparatu telefonu w jeden PDF
- Tworzenie portfolio zdjęć lub lookbooka z obrazów w różnych formatach
- Konwersja zdjęć z iPhone'a (HEIC) na PDF do udostępnienia bez instalowania programów na komputerze
- Składanie makiet projektów z eksportów PSD i zrzutów ekranu w materiał dla klienta
- Archiwizowanie folderu starszych formatów obrazów (PNM, JXR, JP2) jako jednego PDF-a

## Wskazówki

- Kolejność obrazów w PDF odpowiada ich kolejności na liście plików. Prześlij je w żądanej sekwencji.
- Aby uzyskać jak najmniejszy plik, wybierz niską jakość. Różnica wizualna jest często pomijalna w skanach z dużą ilością tekstu.
- Jeśli masz tylko jeden format obrazów, dedykowane konwertery (JPG na PDF, PNG na PDF itd.) dają ten sam wynik w prostszym interfejsie.

# PDF na ZIP

Spakuj wiele plików PDF w jedno archiwum ZIP. To proste narzędzie do pakowania: bez konwersji, kompresji ani modyfikacji samych plików PDF.

## Jak to działa

1. Prześlij wiele plików PDF za pomocą strefy upuszczania.
2. Przejrzyj listę plików. Usuń te, których nie chcesz dołączać.
3. Kliknij przycisk przetwarzania.
4. Archiwum ZIP zawierające wszystkie przesłane pliki PDF pobiera się natychmiast.

## Funkcje

- Przyjmuje dowolną liczbę plików PDF
- Usuwanie pojedynczych plików przed utworzeniem archiwum
- Zachowuje oryginalne nazwy plików wewnątrz ZIP
- Brak modyfikacji zawartości PDF: pliki są pakowane bez zmian
- Wyświetla nazwę i rozmiar każdego przesłanego pliku PDF

## Przypadki użycia

- Pakowanie zestawu faktur lub paragonów jako załącznika e-mail
- Pakowanie rezultatów projektu (wielu raportów PDF) do przekazania
- Tworzenie jednego pliku do pobrania dla kolekcji formularzy lub szablonów
- Archiwizowanie partii dokumentów w jednym skompresowanym pliku

## Wskazówki

- Archiwum ZIP używa oryginalnych nazw plików PDF. Jeśli masz pliki o tej samej nazwie, zmień je przed przesłaniem, aby uniknąć konfliktów.
- To narzędzie nie kompresuje samych plików PDF. Aby zmniejszyć rozmiar, najpierw przepuść je przez Kompresuj PDF, a potem spakuj tym narzędziem.

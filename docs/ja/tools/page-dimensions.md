# ページ寸法

PDFのすべてのページを読み取り、正確な寸法、向き、標準サイズ名、縦横比、面積、回転を報告する診断ツールです。印刷前にサイズが混在したページを見つけたり、受け取ったPDFのプロパティを記録したりするのに便利です。

## 使い方

1. PDFファイルをアップロードします。分析は自動的に始まり、押すボタンはありません。
2. サマリーパネルに、総ページ数、異なるページサイズの数、サイズが混在しているかどうかが表示されます。
3. ページごとの詳細を含む結果テーブル全体を確認します。
4. 表示単位をポイント、インチ、ミリメートル、ピクセルから切り替えられます。
5. **CSVにエクスポート**をクリックしてデータを保存します。

## 報告される項目

| 列         | 説明                                              |
| ---------- | ------------------------------------------------- |
| ページ番号 | 連番のページ番号                                  |
| 寸法       | 選択した単位での幅 x 高さ                         |
| 標準サイズ | 一致した名前 (A4、Letterなど)、または「カスタム」 |
| 向き       | 縦または横                                        |
| 縦横比     | 幅と高さの比 (小数)                               |
| 面積       | 選択した単位の2乗でのページ面積                   |
| 回転       | ページの回転角度 (度)                             |

## 機能

- 標準の用紙サイズ (A3、A4、A5、Letter、Legal、Tabloidなど) の自動検出
- サイズ混在の警告。どのサイズが何ページで使われているかの内訳も表示
- ポイント、インチ、ミリメートル、ピクセル (96 PPI) の間の単位変換
- スプレッドシートやドキュメント管理システムで使えるCSVエクスポート

## ユースケース

- 印刷会社に文書を提出する前に、すべてのページがA4であることを確認する
- 結合したPDFで特定のページだけ余白が想定外になる原因を調べる
- 大量のPDFアーカイブのページレイアウトをメタデータ記録として文書化する
- 修正が必要な回転済みページを見つける

## ヒント

- サマリーに「サイズ混在」と表示された場合は、印刷前にページサイズを固定ツールで統一してください。
- 回転フィールドを見ると、正しく表示されていても回転属性が0以外のページを特定できます。これは一部のワークフローで問題の原因になることがあります。

# PDFからTIFF

PDFの各ページをTIFF画像に変換します。TIFFは、印刷製版、ファクスシステム、文書アーカイブの標準形式です。このツールはTIFFのエンコードにPackBits圧縮を使い、ページのエンコードに失敗した場合はPNGにフォールバックします。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、PDFをアップロードします。
2. **変換**をクリックしてファイルを処理します。
3. 1つのTIFFファイル、またはZIPアーカイブが自動的にダウンロードされます。

## オプション

このツールに設定可能なオプションはありません。ページは固定の2倍スケールでレンダリングされます。

## 出力形式

- **1ページ**: `filename.tiff`
- **複数ページ**: `filename_tiffs.zip`。`page_1.tiff`、`page_2.tiff`などを含みます。

特定のページでTIFFのエンコードに失敗した場合 (圧縮の問題による)、そのページは代わりに`.png`ファイルとして保存されます。その場合、ZIPにはTIFFとPNGのファイルが混在します。

## ユースケース

- TIFF形式を必須とする行政機関や法的システムに文書を提出する。
- デジタルファクスサービスで送信するためのページを準備する。
- スキャンした文書を、広くサポートされているロスレス形式で保管する。
- 企業の文書管理システムにページを渡す。

## ヒント

- TIFFファイルは大きくなります。Webや画面での利用でロスレスの品質だけが必要な場合は、[PDFからPNG](./pdf-to-png)のほうが適しています。
- 一部のページでPNGへのフォールバックが発生した場合は、ZIPの中身を確認してください。それらのページは別途変換し直したほうがよいかもしれません。

# ODGからPDF

OpenDocument GraphicsファイルをPDFに変換します。ODGはLibreOffice Drawのネイティブ形式で、図表、フローチャート、ベクターイラストに使われます。PDFに変換すると、これらの図を共有、印刷、ほかの文書への埋め込みがしやすくなります。

## 対応フォーマット

| フォーマット          | 拡張子 | 備考                                         |
| :-------------------- | :----- | :------------------------------------------- |
| OpenDocument Graphics | `.odg` | LibreOffice Draw / OpenOffice Drawのファイル |

## 使い方

1. アップロードエリアをクリックするか、ODGファイルをドラッグ＆ドロップします。複数のファイルを一度に追加できます。
2. ファイル一覧を確認します。ゴミ箱アイコンで個別に削除でき、**ファイルを追加**でさらに図面を追加できます。
3. **PDFに変換**をクリックします。LibreOfficeベースのエンジンがブラウザー内で読み込まれ、ベクターグラフィック、図形、テキストを保持したまま各ODGファイルを変換します。
4. ファイルが1つの場合はPDFが直接ダウンロードされます。複数の場合は、`odg-to-pdf.zip`という名前のZIPアーカイブになります。

## オプション

追加の設定は不要です。変換では、ODGソースの元のページ寸法、図形、コネクター、テキストボックスが保持されます。

## 活用例

- LibreOfficeをインストールしていない取引先と、LibreOffice Drawの図を共有する
- Drawで作成したフローチャートやネットワーク図を印刷する
- ODGのイラストを、PDFとしてレポートやプレゼンテーションに埋め込む
- 技術図面を、数十年先でも読める形式でアーカイブする

## ヒント

- ベクター要素はPDF出力でもベクターのまま保たれるため、どんな印刷サイズにもきれいに拡大縮小できます。
- LibreOfficeエンジンは初回の使用時に初期化に少し時間がかかります。その後、同じセッション内の変換はより速くなります。

# ページサイズを固定

複数の出典から組み立てたPDFでは、LetterとA4が混在したり、規格外のサイズが混ざったりして、ページサイズがそろわないことがあります。このツールはすべてのページを1つのサイズに揃え、必要に応じて内容を拡大縮小して収めたり埋めたりします。

## 使い方

1. PDFファイルをアップロードします。
2. ドロップダウンから**ターゲットページサイズ**を選びます（A4、Letter、Legal、A3、A5、Tabloid、カスタム）。
3. **向き**を選びます。自動なら各ページの元の向きを保ち、縦または横に固定することもできます。
4. **コンテンツのスケーリング**モードを選びます。フィット（内容をすべて保持、余白が付く場合あり）またはフィル（ページを埋める、端が切れる場合あり）です。
5. 必要に応じて、追加される余白の**背景色**を設定します。
6. **ページサイズを固定**をクリックします。

## オプション

- **標準サイズ**: A4、Letter、Legal、A3、A5、Tabloid
- **カスタムサイズ**: 幅と高さをインチまたはミリメートルで入力
- **向き**: 自動、縦、横
- **スケーリングモード**: フィットまたはフィル（トリミング）
- **背景色**: 余白部分に使う任意の色

## 活用例

- 別々のスキャナーで取り込んだページを結合したPDFを統一する
- USレターの文書を海外向けにA4へ変換する
- 一定の仕上がりサイズが必要な印刷用PDFを準備する
- 標準からわずかにずれたページ（例: 8.5 x 11ではなく8.49 x 11.02インチ）を修正する

## ヒント

- 内容を失いたくない場合はフィットモードを使います。フィルモードは見た目がすっきりしますが、端が切れることがあります。
- 出力は「ページ寸法」ツールで確認すると、すべてのページが目標サイズに一致しているか分かります。
- 背景色の初期値は白です。文書の余白が暗い場合は暗い色に切り替えてください。

# ページの反転

PDFのページ順を反転させ、最後のページを最初に、最後から2番目のページを2番目にというように並べ替えます。複数のファイルの一括処理に対応しています。

## 使い方

1. 1つ以上のPDFファイルをアップロードします。
2. 処理ボタンをクリックします。
3. 各ファイルは個別に反転されます。複数のファイルをアップロードした場合、出力は反転されたすべてのPDFを含むZIPアーカイブになります。
4. ファイルが1つの場合は、反転されたPDFとして直接ダウンロードされます。

## 機能

- 一括処理：複数のPDFを1回の操作で反転
- PDFが1つなら単一ファイルで出力、複数ならZIPで出力
- 処理前にファイルごとの削除ボタンで取り除ける
- すべてのページ内容と書式を保持

## 活用例

- 逆順にスキャンされてしまったドキュメントを修正する
- プレゼンテーションPDFを後ろから前へ読めるように準備する
- ページを逆順で給紙する特定の印刷ワークフロー向けに、ページ順を反転する
- 誤って逆向きに組み立てられたドキュメントを修正する

## ヒント

- バッチ内の各ファイルは個別に反転されます。ファイル同士の順序が入れ替わるわけではありません。
- 全体の反転だけでなく、より細かくページを並べ替えたい場合は、[複製と整理](./organize-pdf)を使用してください。

# PDF OCGレイヤー

PDF内のオプショナルコンテンツグループ (OCG)、一般に「レイヤー」と呼ばれるものを管理します。レイヤーの表示切り替え、新しいレイヤー (入れ子の子レイヤーを含む) の追加、レイヤーの削除を行い、変更したPDFを保存できます。

## 使い方

1. PDFファイルをアップロードします。
2. 処理ボタンをクリックして、PyMuPDFエンジンで文書を読み込みます。
3. 既存のすべてのレイヤーが、表示状態、ロック状態、入れ子の階層とともに表示されます。
4. チェックボックスでレイヤーの表示と非表示を切り替えます。ロックされたレイヤーは切り替えられません。
5. 名前を入力して追加ボタンをクリックすると新しいトップレベルのレイヤーを追加でき、既存の親レイヤーの下に子レイヤーも追加できます。
6. 不要になったレイヤーを削除します。
7. **保存**をクリックして、レイヤーの変更を反映したPDFをダウンロードします。

## 機能

- 入れ子のレイヤーを適切なインデントで階層表示
- レイヤーの表示と非表示の切り替え
- ロックされたレイヤーの表示により、誤った変更を防止
- 任意の名前でトップレベルまたは子レイヤーを追加
- 個別のレイヤーを削除
- すべての変更を新しいPDFファイルに保存

## ユースケース

- 建築や設計図面で、マークアップレイヤーの表示を切り替える
- 複数レイヤーのデザイン文書に新しい注釈レイヤーを追加する
- テンプレートを配布する前に、不要になったレイヤーを削除する
- 第三者から受け取った複雑なPDFにどのレイヤーがあるか調べる

## ヒント

- PDFにレイヤーがない場合、ツールは空の状態を表示し、レイヤーの追加を促します。すべてのPDFがOCGレイヤーを使っているわけではなく、CAD出力やデザインファイルで最もよく使われます。
- 子レイヤーは親の下にインデントして表示されます。レイヤーは任意の深さまで入れ子にできます。
- ロックされたレイヤーにはロックアイコンが表示され、チェックボックスは無効になります。このロックはPDFの作成者が設定したものです。

# ページの交互結合と混合

複数の PDF ファイルのページを交互に差し込んで、文書間でページが入れ替わるようにします。通常の結合ではファイルが単に端から端へつながるだけですが、ファイル A の 1 ページ目、ファイル B の 1 ページ目、ファイル A の 2 ページ目、というように並べたいときに使うツールです。

## 使い方

1. ドロップゾーンを使って、2 つ以上の PDF ファイルをアップロードします。
2. ツールに、各ファイルのページ数とファイルサイズが表示されます。
3. グリップハンドルをドラッグして、差し込みの順序でどのファイルのページを先に置くかを並べ替えます。
4. **ページを混合**をクリックして、交互に差し込んだ出力を作成します。
5. 結果は `alternated-mixed.pdf` としてダウンロードされます。

## 機能

- 任意の数の PDF（最低 2 つ）にわたってページを交互に差し込み
- ファイルをドラッグ＆ドロップで並べ替えて、差し込みの優先順位を制御
- 元の文書のしおりを保持
- アップロードした各ファイルのページ数とファイルサイズを表示
- 専用の Web ワーカーで処理するため、UI の応答性を維持

## ユースケース

- 奇数ページと偶数ページを別々にスキャンした両面スキャンを組み直す
- 問題用紙と解答集を組み合わせて、各問題の直後に解答が来るようにする
- 2 言語の文書をページごとに結合する（例: 片面に英語、次の面に翻訳）
- 片面スキャナーで読み取った表と裏のスキャンを交互に差し込む

## ヒント

- 元の PDF のページ数が異なる場合は、短い文書のページが先になくなり、長い文書の残りのページは末尾にまとめて配置されます。
- ファイルの順序は重要です。リストの先頭のファイルが、出力の最初のページになります。必要に応じてドラッグして並べ替えてください。

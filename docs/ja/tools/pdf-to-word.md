# PDFからWord

PDFファイルを編集可能なWord (`.docx`) 文書に変換します。このツールはPyMuPDFを使って文書の内容を再構築し、テキスト、基本的な書式、レイアウトを保持します。単一ファイルと一括変換に対応しています。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、1つ以上のPDFをアップロードします。ファイルを追加したり、リストから個別に削除したりできます。
2. **変換**をクリックして処理を開始します。
3. 1つのファイルは`filename.docx`としてダウンロードされます。複数のファイルは`converted-documents.zip`にまとめられます。

## オプション

このツールに設定可能なオプションはありません。各PDFは、PyMuPDFの組み込み変換エンジンでDOCXに変換されます。

## 出力形式

- **単一ファイル**: `filename.docx`
- **複数ファイル**: 入力したPDFごとに1つの`.docx`を含む`converted-documents.zip`。

## ユースケース

- 受け取ったPDFのテキストを、修正のために編集する。
- 保管してあるPDFレポートを、同僚がMicrosoft WordやGoogle Docsで編集できる形式に変換する。
- PDFの契約書や提案書の内容をWordに取り込み、修正履歴を付けて校正する。
- 古いPDFドキュメントを、編集可能な形式に移行する。

## ヒント

- 複数段組みのテキスト、埋め込みフォーム、多くのグラフィックを含む複雑なレイアウトは、完全には変換されないことがあります。出力を確認し、ワープロで書式を調整してください。
- スキャンされたPDF (画像のみ) は、空または最小限のDOCXファイルになります。先にOCRにかけてテキストレイヤーを追加してください。
- 一括モードは、フォルダ全体のPDFを変換するのに効率的です。まとめてアップロードしてください。

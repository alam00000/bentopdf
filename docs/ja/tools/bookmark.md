# しおりの編集

しおりエディターを使えば、PDFのナビゲーション用しおり（アウトラインとも呼ばれます）を自在に管理できます。新しいしおりの追加、既存のしおりの編集、階層の整理、CSVやJSON形式でのしおりデータのインポートとエクスポートができます。

## 使い方

1. クリックするか、ドロップゾーンにファイルをドラッグしてPDFをアップロードします。
2. 必要に応じて **既存のしおりを自動抽出** にチェックを入れると、文書にある現在のしおりツリーを読み込みます。
3. エディターが分割表示で開きます。左にPDFビューアー、右にしおりパネルが表示されます。
4. しおりのタイトルを入力し、**ページに追加** をクリックすると、現在のページを指す新しいしおりが作成されます。
5. ツールバーのボタンでしおりの並べ替え、スタイル設定、削除ができます。
6. **しおり付きでPDFを保存** をクリックして、更新したファイルをダウンロードします。

## 機能

- ページ移動、ズーム操作、ページ指定入力を備えたビジュアルPDFビューアー
- ワンクリックで任意のページにしおりを追加
- PDF上を直接クリックして、しおりの移動先を正確に指定（ピックモード）
- ドラッグ&ドロップで並べ替えできる階層構造のしおり
- 一括操作：複数のしおりを選択して、色やスタイルの変更、削除をまとめて実行
- 大きなツリーでもすばやく見つけられるしおり検索
- すべての変更に対応した元に戻す、やり直す
- CSV（タイトル、ページ、レベル）またはJSONファイルからしおりをインポート
- 外部での編集用に、しおりをCSVまたはJSONでエクスポート
- しおりのスタイル設定：色（赤、青、緑、黄、紫）とフォントスタイル（太字、斜体、太字斜体）
- クイックナビゲーション：Page Up/Page Downキーでページをスクロール

## オプション

- **既存のしおりを自動抽出**: チェックすると、読み込み時にPDFの現在のしおりを読み取って表示します。
- **一括モード**: 切り替えて複数のしおりを選択し、色、スタイル、削除をまとめて適用します。
- **すべて展開/折りたたむ**: 入れ子になった子しおりをすばやく表示または非表示にします。

## 活用例

- しおりのない教科書やマニュアルに目次を追加する
- OCR処理後のスキャン文書でしおりの構成を整える
- しおりをCSVにエクスポートし、表計算ソフトで編集してから再インポートする
- ページ参照が間違っている自動生成のしおりを修正する
- 法律文書の重要な箇所に色付きのしおりを付ける

## ヒント

- 大量のしおりを作るにはCSVインポートが便利です。形式は簡単で、`title,page,level` と書き、レベル1が最上位です。
- ピックモードでは、PDFページ上の正確な位置をクリックして移動先を指定できるため、ページ番号だけを指定するより精密です。
- 大きな変更を行う前に、バックアップとしてしおりをエクスポートしておきましょう。

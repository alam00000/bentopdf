# ODTからPDF

OpenDocument TextファイルをPDFに変換します。ODTはLibreOffice Writer、Apache OpenOffice、その他のオープンソースワープロのネイティブ形式です。このツールはブラウザ上のLibreOfficeエンジンを使い、書式、表、画像、スタイルを保持した正確な変換を行います。

## 対応フォーマット

| フォーマット      | 拡張子 |
| :---------------- | :----- |
| OpenDocument Text | `.odt` |

## 使い方

1. アップロード領域をクリックするか、1つ以上のODTファイルをドラッグ&ドロップします。
2. ファイル一覧を確認します。ファイルの追加や不要なファイルの削除ができます。
3. **PDFに変換**をクリックします。LibreOfficeエンジンが初期化され (進行状況インジケーターに読み込み状況が表示されます)、その後各ファイルが変換されます。
4. 1つのファイルはPDFとして直接ダウンロードされます。複数のファイルは`odt-converted.zip`にまとめられます。

## オプション

このツールに追加の設定はありません。変換では、元の文書の書式をできるだけ忠実に保持します。

## 出力

| 入力数        | 出力                                                                  |
| :------------ | :-------------------------------------------------------------------- |
| 1ファイル     | 単一のPDFをダウンロード (例: `document.pdf`)                          |
| 2ファイル以上 | ZIPアーカイブ (`odt-converted.zip`)。ファイルごとに1つのPDFを含みます |

## ユースケース

- LibreOffice Writerの文書をPDFに変換し、Microsoft Officeユーザーと共有する
- OpenDocument形式で書かれた学術論文から印刷用PDFを作成する
- ODTテンプレートのフォルダをまとめてPDFに変換して配布する
- 自動文書生成システムが作成したODTファイルからPDFを生成する

## ヒント

- LibreOfficeエンジンは初回使用時に読み込まれ、以降の変換のためにキャッシュされます。初回の読み込みには数秒かかりますが、その後の変換は高速です。
- 埋め込みOLEオブジェクトや特殊なフォントを含む複雑な文書は、デスクトップ版LibreOfficeとわずかに異なる表示になることがあります。一括変換の前にサンプルで試してください。
- Word文書 (`.doc`, `.docx`) には、代わりに[WordからPDF](./word-to-pdf)ツールを使ってください。同じLibreOfficeエンジンを使い、Microsoft形式を直接受け付けます。

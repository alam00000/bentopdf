# PDFの結合

複数のPDFファイルを1つの文書に結合します。ファイル全体を指定した順序で結合することも、ページモードに切り替えて、アップロードしたすべてのPDFの個々のページを細かく制御することもできます。

## 使い方

1. ドロップゾーンをクリックするか、ドラッグして、2つ以上のPDFファイルをアップロードします。
2. 上部の切り替えで、**ファイルモード**と**ページモード**のどちらかを選びます。
3. ファイルモードでは、ファイルをドラッグして並べ替え、必要に応じて各ファイルのページ範囲（例: `1-3, 5`）を指定します。範囲を空欄にすると、すべてのページが含まれます。
4. ページモードでは、個々のページのサムネイルをドラッグ＆ドロップして、思い通りのページ順を作ります。
5. **PDFを結合**をクリックすると、すべてが1つのファイルにまとめられます。結合したPDFは自動でダウンロードされます。

## 機能

- 2つの結合モード: ファイル全体をすばやく結合するファイルモードと、ページ単位で制御するページモード
- どちらのモードでも、滑らかなアニメーションでドラッグ＆ドロップによる並べ替えが可能
- ページ範囲の記法（例: `1-3, 5, 8-10`）で、ページモードに切り替えずに必要なページだけを選べる
- サムネイルを遅延読み込みするため、大きな文書でもUIが軽快に動作
- ファイル数や合計ページ数に制限なし
- 再エンコードせず、元のPDFの品質を維持

## オプション

| オプション         | 説明                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------- |
| **ファイルモード** | ファイル全体を好きな順序で結合。ファイルごとにページ範囲のフィルターも指定可能           |
| **ページモード**   | すべてのファイルのすべてのページを一覧表示。サムネイルをドラッグして思い通りの順序を作成 |
| **ページ入力**     | ファイルごとのテキスト欄。`1-3, 5`のような範囲を指定して、特定のページだけを含める       |

## 活用例

- 章ごとに分かれたPDFを、1冊の本やレポートにまとめる
- 送付状と履歴書を、1つの応募書類に結合する
- 複数の元文書から特定のページを取り出して、1つのファイルにまとめる
- スキャンしたレシートや請求書を、1つのアーカイブPDFにまとめる
- 複数のスライド資料から、プレゼンテーションの配布資料を作る

## ヒント

- ファイルを次々に追加するのではなく、異なるファイルのページを交互に挟み込みたい場合は、ページモードを使ってください。
- 最初のアップロード後でも、**ファイルを追加**ボタンでファイルを追加できます。現在の並びは失われません。
- ページ範囲は1始まりなので、`1`はそのファイルの最初のページを指します。

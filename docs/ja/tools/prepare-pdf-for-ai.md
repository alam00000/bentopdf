# AI用のPDFを準備する

PDFファイルから内容を抽出し、大規模言語モデル（LLM）やLlamaIndexなどのAIフレームワークに取り込みやすいJSONとして構造化します。各ページの内容が抽出され、RAGパイプライン、チャットボット、セマンティック検索システムにそのまま使える形式に整理されます。

## 使い方

1. ドロップゾーンをクリックするかファイルをドラッグして、1つ以上のPDFをアップロードします。
2. **抽出**をクリックして処理を開始します。
3. ファイルが1つの場合は`filename_llm.json`としてダウンロードされます。複数の場合は`pdf-for-ai.zip`アーカイブになります。

このツールはPyMuPDFのLlamaIndex連携を使用して、ページ単位の内容をメタデータ付きで抽出し、AIフレームワークに直接読み込める出力を生成します。

## オプション

このツールに設定可能なオプションはありません。すべてのページがテキスト全体とメタデータとともに抽出されます。

## 出力形式

- **1ファイル**：`filename_llm.json`
- **複数ファイル**：入力PDFごとに1つの`_llm.json`を含む`pdf-for-ai.zip`。

JSON出力はLlamaIndexのドキュメントスキーマに従い、ページごとのテキスト内容とメタデータフィールドを持ちます。

## 活用例

- 検索拡張生成（RAG）パイプライン向けにPDFドキュメントを準備する。
- AIチャットボット向けに、PDFアーカイブから検索可能なナレッジベースを構築する。
- PDFレポートをLLMベースの分析ワークフローに取り込む。
- セマンティック検索や質問応答システム向けに、研究論文を前処理する。
- PDFドキュメントのコレクションから構造化された学習データを作成する。

## ヒント

- AI向けの整形をしないプレーンテキストの抽出には、[PDFからテキスト](./pdf-to-text)を使用します。
- 見出しや構造を保ったMarkdown出力には、[PDFからMarkdown](./pdf-to-markdown)を使用します。
- スキャンされたPDFでは、出力が空になるか、ごくわずかになります。抽出の前にOCRを実行して、テキストレイヤーを追加してください。

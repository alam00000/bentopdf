# TIFFからPDF

複数ページのTIFFを含め、TIFFファイルをPDFに変換します。TIFFファイル内の各ページ（「IFD」）が、出力PDFの別々のページになります。複数ページのTIFFとして保存されることが多い、スキャン文書、FAX、医療画像に特に便利です。

## 対応フォーマット

| フォーマット | 拡張子          |
| :----------- | :-------------- |
| TIFF         | `.tiff`, `.tif` |

## 使い方

1. アップロード領域をクリックするか、TIFFファイルをドラッグアンドドロップします。
2. ファイル一覧を確認し、必要に応じて管理します。
3. **PDFに変換**をクリックします。結果は`from_tiff.pdf`としてダウンロードされます。

このツールは、JavaScriptのTIFFデコーダーで各TIFFファイルをデコードし、すべてのページの生のRGBAピクセルデータを抽出します。各ページはキャンバスに描画され、PNGとして書き出されてPDFに埋め込まれます。ページのサイズは元のTIFFのページと一致します。

## オプション

このツールには、品質に関する追加の設定はありません。画像は元の解像度で埋め込まれます。

## 活用例

- 複数ページのFAX文書（TIFF-F）を、より持ち運びやすいPDF形式に変換する
- TIFFで保存されたスキャン文書のアーカイブを、検索可能なPDFにする（その後OCRツールと組み合わせます）
- TIFFを使用する医療画像ファイル（病理スライド、放射線画像の出力）を処理する
- GISや衛星画像のTIFFファイルを、共有できるドキュメントに変換する

## ヒント

- 複数ページのTIFFに完全対応しています。10ページのTIFFからは10ページのPDFが生成されます。先にTIFFを分割する必要はありません。
- 非常に大きなTIFFファイル（数百メガバイト）は、ファイル全体をブラウザのメモリ内でデコードする必要があるため、処理に時間がかかることがあります。
- 生成されたPDFにOCRが必要な場合は、変換後に[OCR PDF](./ocr-pdf)ツールを実行してください。

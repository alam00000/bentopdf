# メタデータの表示

PDFファイルに埋め込まれた隠れたプロパティを調べます。このツールは、ドキュメント情報(タイトル、作成者、日付)、XMPメタデータ、ページサイズなどの構造データを、読みやすい形式で表示します。

## 使い方

1. PDFファイルをアップロードします。
2. ツールがすぐにファイルを解析し、利用可能なすべてのメタデータを整理されたセクションに表示します。
3. ドキュメント情報ディクショナリ、XMPメタデータツリー、構造プロパティを確認します。
4. 処理の手順は不要です。ファイルが読み込まれるとすぐにメタデータが表示されます。

## 機能

- 標準のドキュメント情報フィールドを表示: タイトル、作成者、サブジェクト、キーワード、作成アプリケーション、PDF変換
- 作成日と更新日を読みやすい形式で表示
- ネストされた名前空間を含む、XMPメタデータツリー全体を解析して表示
- PDFの日付形式(`D:20240101120000Z`)を読みやすい日付に変換
- 折りたたみ可能なセクションに整理され、移動しやすい

## メタデータのセクション

| セクション                   | 内容                                                                                      |
| ---------------------------- | ----------------------------------------------------------------------------------------- |
| **ドキュメント情報**         | タイトル、作成者、サブジェクト、キーワード、作成アプリケーション、PDF変換、作成日、更新日 |
| **XMPメタデータ**            | Dublin Core、XAP、PDF、カスタム名前空間を含む、XMLベースのメタデータツリー全体            |
| **ドキュメントのプロパティ** | ページ数、PDFバージョン、ファイルサイズ、暗号化の状態                                     |

## 活用例

- PDFの作成者と最終更新日を確認する
- 文書を公開する前に、メタデータが正しく設定されているか確認する
- 埋め込まれている個人情報を調べ、プライバシーの観点からPDFを監査する
- PDFの作成や変更に使われたソフトウェアを調べる(Producerフィールドから)
- デジタルアセット管理のコンプライアンスのためにXMPメタデータを確認する

## ヒント

- `D:`で始まるPDFの日付文字列は、自動的にお使いのローカルタイムゾーンの形式に変換されます。
- メタデータのフィールドが空の場合は、PDFの作成者が設定しなかっただけです。すべてのPDFに豊富なメタデータが含まれているわけではありません。
- 確認したメタデータを変更するには[メタデータの編集](./edit-metadata)を、完全に削除するにはメタデータの削除を使用してください。

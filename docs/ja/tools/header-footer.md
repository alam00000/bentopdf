# ヘッダーとフッター

PDFのページの6か所（ヘッダー左、ヘッダー中央、ヘッダー右、フッター左、フッター中央、フッター右）にテキストを追加します。ページ番号と総ページ数の動的変数に対応しているので、「10ページ中3ページ」のようなテンプレートを作れば、ページごとに自動で更新されます。

## 使い方

1. PDFファイルをアップロードします。
2. 書式設定のコントロールと6つのテキスト入力欄を含むオプションパネルが表示されます。
3. ヘッダー/フッターの任意の位置に、表示したいテキストを入力します。
4. 動的なページ番号には`{page}`と`{total}`のプレースホルダーを使います。
5. フォントサイズと文字色を調整し、必要に応じて特定のページ範囲に限定します。
6. **ヘッダーとフッターを追加**をクリックして処理し、ダウンロードします。

## オプション

- **ページ範囲**: ヘッダーとフッターを付けるページを限定できます（任意）。空欄にするとすべてのページに適用されます。形式は「1-3, 5」（カンマ区切りの範囲）です。
- **フォントサイズ**: 6〜24ポイント。初期値は10です。
- **文字色**: カラーセレクターで好きな色を選べます。
- **ヘッダー左 / 中央 / 右**: 各ページ上部のテキスト欄です。
- **フッター左 / 中央 / 右**: 各ページ下部のテキスト欄です。

## 機能

- 1ページにつき、独立した6つのテキスト位置
- 現在のページ番号を挿入する動的な`{page}`変数
- 総ページ数を挿入する動的な`{total}`変数
- 特定のページを対象にするページ範囲フィルター
- フォントサイズと色のカスタマイズ
- すっきりとしたプロフェッショナルな仕上がりのHelveticaフォント

## 活用例

- レポートのフッター中央に「{total} ページ中 {page} ページ」を追加する
- ヘッダー左に会社名、ヘッダー右に文書の日付を配置する
- 法律文書のフッターに機密保持の注意書きを追加する
- 特定のページ範囲に文書の改訂番号を入れる

## ヒント

- `{page}`と`{total}`を1つの欄に組み合わせて、「{total} ページ中 {page} ページ」や「{page}/{total}」のような形式にできます。
- 必要な位置だけ入力し、ほとんどの欄を空のままにできます。空の欄は単にスキップされます。
- 画像やロゴを含むより複雑なヘッダーには、ページ上部に配置した[透かしの追加](./add-watermark)ツールの利用を検討してください。

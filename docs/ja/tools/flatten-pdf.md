# PDFの平坦化

平坦化では、フォームフィールド、ドロップダウン、チェックボックス、注釈、ハイライト、付箋などのインタラクティブな要素をページの内容に直接統合します。見た目は変わりませんが、編集も抽出もできなくなります。入力済みのフォームを印刷してスキャンし直すのと同じ効果ですが、画質は完全に保たれます。

## 使い方

1. 1つ以上のPDFファイルをアップロードします。
2. **PDFを平坦化**をクリックします。
3. ファイルが1つの場合は直接ダウンロードされ、複数の場合はZIPアーカイブになります。

このツールはpdf-libでフォームフィールドを平坦化し（`form.flatten()`経由）、専用の注釈フラットナーで注釈をページストリームに焼き付けます。どちらの処理も1回のパスで行われます。

## 平坦化されるもの

- **フォームフィールド**: テキスト入力、チェックボックス、ラジオボタン、ドロップダウン、署名フィールド
- **注釈**: コメント、ハイライト、取り消し線、下線、付箋、スタンプ、インク注釈
- **インタラクティブ要素**: ボタン、アクショントリガー

## 変更されないもの

- テキストの内容（選択や検索は引き続き可能）
- 画像とグラフィック
- ページのレイアウトと寸法
- しおりと目次
- ハイパーリンク（注釈ベースのものを除く）

## 活用例

- 入力済みのフォームをロックし、受取人が提出内容を変更できないようにする
- インタラクティブ要素が不要なアーカイブ用にPDFを準備する
- ビューアーごとに注釈の表示が異なる問題を解消する
- 署名済みの文書が署名後に変更されないようにする
- フォームフィールドの定義と注釈オブジェクトを除去してファイルサイズを減らす

## ヒント

- すべての編集が終わってから平坦化してください。平坦化したPDFを元に戻す方法はありません。
- 平坦化に加えてメタデータ、JavaScript、添付ファイルも削除したい場合は、代わりに「PDFをサニタイズ」ツールを使ってください。平坦化もオプションの1つとして含まれています。
- 「フォームが見つかりません」と表示されるPDFがありますが、文書に注釈のみでフォームフィールドがない場合は正常です。

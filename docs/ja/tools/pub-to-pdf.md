# PUBからPDF

Microsoft PublisherファイルをPDFに変換します。PublisherはMicrosoft Officeの一部のエディションに含まれるデスクトップパブリッシングツールですが、インストールしている人は多くありません。このツールを使えば、Microsoftのソフトウェアなしで、ブラウザ上で直接PUBファイルをPDFに変換できます。

## 対応フォーマット

| フォーマット        | 拡張子 | 備考                           |
| :------------------ | :----- | :----------------------------- |
| Microsoft Publisher | `.pub` | デスクトップパブリッシング文書 |

## 使い方

1. アップロード領域をクリックするか、PUBファイルをドラッグアンドドロップします。複数のファイルを一度にアップロードできます。
2. ファイル一覧を確認します。不要なファイルはゴミ箱アイコンで削除するか、**ファイルを追加**をクリックしてさらに追加します。
3. **PDFに変換**をクリックします。LibreOfficeベースのエンジンがブラウザに読み込まれ、レイアウト、画像、テキストボックスを保ったまま各PUBファイルを変換します。
4. ファイルが1つの場合はPDFとして直接ダウンロードされます。複数の場合は、`pub-to-pdf.zip`という名前のZIPアーカイブで届きます。

## オプション

追加の設定は不要です。コンバーターがPUBのレイアウトエンジンを自動的に処理します。

## 活用例

- Microsoft Publisherを購入せずに、クライアントから受け取ったPUBのチラシやニュースレターを開く
- Publisherで作成した教会の会報、イベントプログラム、学校のニュースレターを変換する
- Publisherのマーケティング資料を、誰でも開ける形式で保管する
- Publisherがインストールされていないシステムで、PUBファイルを印刷する

## ヒント

- テキストボックスが重なり、位置が細かく指定された複雑なPublisherレイアウトは、変換時に少しずれることがあります。正確な位置が重要な場合は、出力を確認してください。
- LibreOfficeエンジンはセッションごとに1回初期化されます。最初の変換には時間がかかり、2回目以降は高速です。
- Publisherファイルを最も忠実に変換するには、元のファイルで使用しているカスタムフォントが標準のシステムフォントであることを確認してください。

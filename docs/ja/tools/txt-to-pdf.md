# テキストからPDF

プレーンテキストを、書式設定されたPDFに変換します。`.txt`ファイルをアップロードするか、内蔵のテキストエディターに直接入力できます。複数のフォント、テキストの色の指定、A0からA10に加えてUSレター、リーガル、タブロイドまで、幅広いページサイズに対応しています。

## 対応フォーマット

| 入力                     | 拡張子                         |
| :----------------------- | :----------------------------- |
| プレーンテキストファイル | `.txt`                         |
| テキストの直接入力       | エディターに入力または貼り付け |

## 使い方

1. 上部のトグルで入力モードを選択します。**ファイルをアップロード**または**テキストを入力**です。
2. アップロードする場合は、1つ以上の`.txt`ファイルをドラッグアンドドロップするか、クリックして選択します。入力する場合は、テキストエリアに直接テキストを入力します。
3. 書式のオプションを設定します。フォントファミリー、フォントサイズ、テキストの色、ページサイズです。
4. **PDFを作成**をクリックします。出力は`text_to_pdf.pdf`としてダウンロードされます。

複数のファイルをアップロードした場合、それらの内容は間に空行を挟んで連結されます。

## オプション

| オプション             | 値                                                                                   | デフォルト    |
| :--------------------- | :----------------------------------------------------------------------------------- | :------------ |
| **フォントファミリー** | Helvetica（サンセリフ）、Tiro（セリフ）、Courier（等幅）、Times（セリフ）            | Helvetica     |
| **フォントサイズ**     | 6 - 72 pt                                                                            | 12            |
| **テキストの色**       | カラーピッカーで任意の色                                                             | 黒（#000000） |
| **ページサイズ**       | ISO A0からA10、B0からB10、C0からC10、USレター、リーガル、タブロイド、レジャー、11x17 | A4            |

RTL言語（アラビア語、ヘブライ語、ペルシア語、ウルドゥー語）は自動的に検出されます。RTLのテキストが見つかると、テキストの方向と配置がそれに応じて切り替わります。

## 活用例

- コードスニペットやログファイルを、Courierフォントの印刷可能なPDFに変換する
- その場で入力した会議メモから、すばやくPDFを作成する
- プレーンテキストの原稿を、提出用に特定のフォントとページサイズで整形する
- READMEや変更履歴のPDF版を、オフライン配布用に作成する

## ヒント

- クリップボードの内容を、ファイルとして保存せずにすばやく変換したい場合は、**テキストを入力**モードを使用してください。
- Courier（等幅）は、コードやログ、列の揃いが重要な内容に最適なフォントです。
- ページの余白は、四辺とも72ポイント（1インチ）に固定されています。

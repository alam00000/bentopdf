# メタデータの削除

すべてのPDFには、誰が作成したか、どのソフトウェアを使ったか、最後にいつ変更されたかなどを明らかにするメタデータが含まれています。このツールは、情報辞書、XMPメタデータストリーム、ドキュメントID、アプリケーション固有のデータをすべて取り除き、作成元の痕跡がないクリーンなドキュメントにします。

## 使い方

1. PDFファイルをアップロードします。
2. **メタデータを削除**をクリックします。
3. クリーンになったファイルをダウンロードします。

設定するオプションはありません。このツールはすべてを消去する、徹底した設計になっています。

## 削除されるもの

- **情報辞書のフィールド**：タイトル、作成者、サブジェクト、キーワード、作成アプリケーション、PDF変換ソフト、作成日、更新日
- **XMPメタデータストリーム**：ドキュメントカタログに保存されているXMLベースのメタデータブロック
- **ドキュメントID**：PDFトレーラー内の一意の識別子で、システムをまたいでドキュメントを追跡するのに使われることがあります
- **PieceInfo**：IllustratorやInDesignなどのプログラムが追加するアプリケーション固有のメタデータ

## 残るもの

- 表示されるすべてのページ内容（テキスト、画像、グラフィック）
- フォームフィールドと注釈
- しおりとリンク
- ドキュメントの構造そのもの

## 活用例

- 匿名で公開する前に、ドキュメントから自分の名前と組織名を削除する
- ドキュメントがいつ準備されたかを示す作成タイムスタンプを取り除く
- 使用しているPDFソフトウェアの構成がわかるプロデューサー文字列を消去する
- メタデータのないPDFを求める規制当局への提出書類を準備する
- 外部に共有する前に、編集履歴の痕跡を削除する

## ヒント

- 取り除く前に、まずメタデータの表示ツールで、PDFにどんなメタデータが含まれているかを正確に確認してください。
- メタデータに加えて、JavaScript、注釈、埋め込みファイルも削除する必要がある場合は、より徹底的なクリーニングができるPDFをサニタイズを使用してください。
- メタデータの削除は元に戻せません。後でそのデータが必要になる可能性がある場合は、元のファイルを保管してください。

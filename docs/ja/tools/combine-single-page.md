# 単一ページに結合

PDFのすべてのページを、1枚の長いページに結合します。ページは縦（スクロールのよう）または横（並べて）につなぎ合わされ、出力は連続した1ページになります。

## 使い方

1. PDFファイルをアップロードします。
2. レイアウトの方向を選びます。**縦**（ページを上から下に積み重ねる）または **横**（ページを横に並べる）です。
3. ページ間の間隔をポイント単位で設定します。
4. ページ間の隙間の背景色を選びます。
5. 必要に応じて、区切り線（ページ間の細い線）を有効にし、太さと色を設定します。
6. 処理ボタンをクリックします。出力は1ページのPDFになります。

## 機能

- ページを縦または横につなぎ合わせ
- ページ間隔を設定可能
- 隙間部分の背景色ピッカー
- 太さと色を調整できる区切り線（任意）
- 元の各ページを、結合したキャンバスに原寸の解像度で描画

## オプション

| オプション         | 説明                             |
| ------------------ | -------------------------------- |
| **向き**           | 縦（積み重ね）または横（並べる） |
| **ページ間隔**     | ページ間の隙間（ポイント単位）   |
| **背景色**         | ページ間の領域の色               |
| **区切り線を追加** | ページ間の細い線のオン/オフ      |
| **区切り線の太さ** | 線の太さ（ポイント単位）         |
| **区切り線の色**   | 区切り線の色                     |

## 活用例

- 複数ページのワイヤーフレームやデザインモックアップから、1枚の長い画像を作る
- Webへの埋め込み用に、文書を連続してスクロールできる表示にする
- 複数ページのコミックやストーリーボードを1本の帯につなぎ合わせる
- 連続したページを、レビュー用にパノラマ表示にする

## ヒント

- 縦向きは縦長ページの文書に最適です。横向きは横長のコンテンツに向いています。
- ページ数の多い文書は、非常に縦長または横長の出力になります。極端に大きな単一ページは、一部のPDFビューアーでは扱いにくい場合があります。
- コントラストのある色の区切り線を追加すると、元のページの終わりと次のページの始まりがわかりやすくなります。

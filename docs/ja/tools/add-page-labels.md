# ページラベルの追加

ページラベルは、PDF ビューアでのページ番号の表示方法を決めるものです（ツールバーに表示される番号であり、ページ上には印刷されません）。このツールでは、ページ範囲ごとに異なるラベル方式を割り当てられます。たとえば、前付にはローマ数字、本文には算用数字、付録にはアルファベットといった設定ができます。

## 使い方

1. PDF ファイルをアップロードします。
2. オプションパネルが表示され、デフォルトで 1 つのラベルルールが用意されています。
3. 各ルールにページ範囲、スタイル、任意のプレフィックス、開始値を設定します。
4. **ルールを追加**をクリックすると、別のセクション用のルールを追加できます。
5. **ページラベルを追加**をクリックして、すべてのルールを適用し、結果をダウンロードします。

## オプション

各ラベルルールには次の設定があります。

- **ページ範囲** -- ルールを適用するページです。空欄にするとすべてのページが対象になります。`1-4`、`7`、`odd`、`1-9,30-40` などの指定に対応しています。
- **ラベルスタイル** -- 算用数字、小文字のローマ数字（i, ii, iii）、大文字のローマ数字（I, II, III）、小文字の英字（a, b, c）、大文字の英字（A, B, C）、ラベルなし（プレフィックスのみ）から選べます。
- **ラベルプレフィックス** -- 各ラベルの先頭に付ける任意のテキストです。たとえば "A-" を指定すると、A-1、A-2、A-3 のようなラベルになります。
- **開始値** -- 数え始める数字です。デフォルトは 1 です。0 から始める番号付けにしたい場合は 0 を設定します。
- **離れた範囲でも番号を継続する** -- ルールの対象が連続しないページ（`1-9,30-40` や `odd` など）で、番号を連続させたい場合に有効にします。
- **既存のページラベルを削除** -- デフォルトでオンです。新しいルールを適用する前に、以前のラベルをすべて消去します。

## 機能

- 複雑な番号付けスキームに対応する、1 つの文書内の複数のラベルルール
- あらゆる標準的な番号体系をカバーする 6 種類のラベルスタイル
- セクションごとのラベル付けに使えるカスタムプレフィックス
- 離れた範囲に対応し、番号を連続させることが可能
- 既存のラベルを残すか削除するかを選択可能

## ユースケース

- 書籍の序文にはローマ数字（i, ii, iii）、本文には算用数字のラベルを設定する
- 付録ページに "A-1"、"A-2"、"B-1"、"B-2" のようなアルファベットのプレフィックスを付ける
- 実際のページ番号と PDF のページ順が一致しないスキャン文書のページラベルを修正する
- 技術文書向けに 0 から始まる番号付けを追加する

## ヒント

- ページラベルは、PDF ビューアのナビゲーションツールバーに表示されるメタデータです。実際のページには印刷されません。目に見える番号が必要な場合は、[ページ番号](./page-numbers) を使用してください。
- このツールを使うには、WASM 設定で CoherentPDF (CPDF) を設定しておく必要があります。未設定の場合は、設定を促すメッセージが表示されます。

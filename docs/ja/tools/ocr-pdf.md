# OCR PDF

スキャンした文書を、検索やコピーができるPDFに変えます。このツールはTesseract OCRで画像内のテキストを認識し、元のページの上に不可視のテキストレイヤーを重ねます。見た目はそのままで、内容を完全に検索できるようになります。

## 使い方

1. スキャンしたPDF、または画像ベースのPDFファイルをアップロードします。
2. 検索できる言語リストから、文書に含まれる言語を1つ以上選びます。
3. 必要に応じて、詳細設定（解像度、二値化、ホワイトリスト）を調整します。
4. **OCRを開始**をクリックし、リアルタイムの進行状況バーで進み具合を確認します。
5. 完了したら、抽出されたテキストを確認し、検索可能なPDFまたはプレーンな`.txt`ファイルをダウンロードします。

## 機能

- 検索可能な言語セレクターによる、多言語OCR
- 不可視のテキストレイヤーで、元の文書の見た目を維持
- 処理中のリアルタイムな進行状況バーとログ出力
- 検索可能なPDFまたはプレーンテキストファイルとして結果をダウンロード
- 抽出したテキストをクリップボードに直接コピー
- 速度と精度のバランスを取る、3段階の解像度

## オプション

| 設定                               | 値                                                                       | 初期値 | 目的                                                                   |
| ---------------------------------- | ------------------------------------------------------------------------ | ------ | ---------------------------------------------------------------------- |
| **解像度**                         | 標準（192 DPI）、高（288 DPI）、超高（384 DPI）                          | 高     | 解像度を上げると小さな文字の精度が向上しますが、処理に時間がかかります |
| **画像を二値化**                   | オン / オフ                                                              | オフ   | 白黒に変換して、きれいなスキャンのコントラストを高めます               |
| **文字ホワイトリストのプリセット** | なし、英数字、数字と通貨、文字のみ、数字のみ、請求書、フォーム、カスタム | なし   | 認識する文字を制限して、特定の種類の文書での精度を高めます             |
| **文字ホワイトリスト**             | 自由入力                                                                 | 空     | プリセットがカスタムのときに使う、手動の文字セット                     |

## 活用例

- スキャンした契約書や請求書を検索可能にして、Ctrl+Fで探せるようにする
- 撮影した文書や古い紙の記録からテキストを抽出する
- 請求書プリセットでレシートを処理し、金額や日付を正確に取り込む
- コンプライアンス要件のために、画像のみのスキャンからアクセシブルなPDFを作る
- スキャンした書籍やマニュアルのテキストを一括で抽出する

## ヒント

- 文書に複数の言語が混在している場合（例: 英語の見出しと日本語の本文）は、複数の言語を選択してください。
- 文字がかすれていたりコントラストが低い文書には、二値化オプションを使ってください。認識精度が大きく向上することがあります。
- 請求書とフォームのホワイトリストプリセットは、無関係な文字の形を無視するため、構造化された文書での誤認識を大幅に減らします。

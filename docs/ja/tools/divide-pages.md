# ページの分割

PDFの各ページを、横または縦に分割して半分に切ります。1ページに入っている内容を別々のページに分けたいときに便利です。たとえば、2段組みのレイアウトを1枚の横長ページとしてスキャンした場合などです。

## 使い方

1. PDFファイルをアップロードします。
2. 分割の方向を選びます。**縦**（左右の半分）または **横**（上下の半分）です。
3. 必要に応じて、分割するページを限定するページ範囲を指定します。空欄にすると、すべてのページが分割されます。
4. 処理ボタンをクリックして、分割したPDFを生成します。

## 機能

- 縦の分割：各ページを左右の半分に分割
- 横の分割：各ページを上下の半分に分割
- 特定のページだけを分割するページ範囲フィルター
- 対象外のページは、そのまま通過
- 再描画せずに、内容の品質を保持

## 活用例

- 2ページ分を1枚にスキャンしたページを分ける（例: 1枚に左右のページが写った本のスキャン）
- 内容が左右に並んだ横向きのPDFを、個別の縦向きページに分割する
- 縦長のインフォグラフィックやポスターを、上下の別々のセクションに分割する
- 大判の文書を、標準サイズの用紙に印刷できるよう準備する

## ヒント

- ページ内の内容の配分が偏っていても、分割は正確に中央で行われます。左右非対称に分割したい場合は、代わりに [PDFのトリミング](./crop-pdf) を検討してください。
- 分割の前後でページの回転が必要な場合は、このツールを [PDFの回転](./rotate-pdf) と組み合わせてください。

# PDFからCSV

PDFから表を抽出し、CSVファイルとしてエクスポートします。このツールはPyMuPDFの表検出エンジンですべてのページから表形式のデータを探し、見つかったすべての行を1つのカンマ区切りの出力に書き込みます。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、PDFをアップロードします。
2. **変換**をクリックして表の抽出を開始します。
3. ツールが各ページをスキャンし、表を自動的に識別します。
4. 抽出されたすべての表データを含む`.csv`ファイルがダウンロードされます。

異なるページの表は、出力内で空白行によって区切られます。カンマ、引用符、改行を含むセルは、RFC 4180に従って適切にエスケープされます。

## オプション

このツールに設定可能なオプションはありません。文書内で見つかったすべての表が抽出され、1つのCSVにまとめられます。

## 出力形式

- 検出されたすべての表を含む、単一の`filename.csv`ファイル。

## ユースケース

- PDFの銀行明細や請求書の財務データをスプレッドシートに取り込む。
- 業者の見積書から価格表を抽出して比較する。
- PDF論文の表形式の研究データを、分析ツールに適した形式に変換する。
- 古いPDFレポートのデータをデータベースに移行する。

## ヒント

- 表が見つからない場合、ツールは「表が見つかりません」というメッセージを表示します。これは通常、PDFのテキストレイアウトが表のように見えても、実際の表として構造化されていないことを意味します。
- 個々の表をより細かく制御したい場合は、CSV、JSON、Markdownの出力形式から選べる[PDFテーブルの抽出](./extract-tables)を使ってください。
- 表ごとにシートを分けたExcel形式でデータが必要な場合は、[PDFからExcel](./pdf-to-excel)を使ってください。

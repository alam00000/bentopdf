# PDFからBMP

PDFの各ページをBMP (ビットマップ) 画像に変換します。BMPは非圧縮形式なので、出力は画質の劣化がなくピクセル単位で正確ですが、ファイルは大きくなります。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、PDFをアップロードします。
2. **変換**をクリックしてファイルを処理します。
3. 1つの`.bmp`ファイル、またはZIPアーカイブが自動的にダウンロードされます。

## オプション

このツールに設定可能なオプションはありません。ページは固定の2倍スケールでレンダリングされ、PDF本来のページ寸法のおよそ2倍の画像になります。

## 出力形式

- **1ページ**: `filename.bmp`
- **複数ページ**: `filename_bmps.zip`。`page_1.bmp`、`page_2.bmp`などを含みます。

## ユースケース

- BMP入力しか受け付けないレガシーシステムやハードウェアにPDFのページを渡す。
- 特定の印刷ワークフロー向けに非圧縮画像を準備する。
- 生のピクセルデータが必要な画像処理ツールの入力としてビットマップ出力を使う。

## ヒント

- BMPファイルは圧縮なしで生のピクセルデータを保存するため、非常に大きくなります。ほとんどの用途では、[PDFからPNG](./pdf-to-png)のほうがロスレスの画質を保ちながらファイルがはるかに小さくなります。
- 対象のシステムがPNGやTIFFに対応しているなら、ディスク容量を節約するためそれらの形式を優先してください。

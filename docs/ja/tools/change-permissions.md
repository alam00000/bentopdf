# 権限の変更

受け取った人がPDFで何をできるかを細かく調整します。ファイルをパスワードで保護するだけの基本的な暗号化とは異なり、このツールでは、印刷、コピー、編集、注釈、フォーム入力、文書の組み立て、ページの抽出を個別に許可または禁止でき、そのすべてが256ビットAES暗号化によって適用されます。

## 使い方

1. PDFファイルをアップロードします。
2. PDFがすでに暗号化されている場合は、**現在のパスワード** を入力します。
3. **新しいユーザーパスワード**（開くために必要）や **新しいオーナーパスワード**（権限を管理）を設定します。
4. チェックボックスで、個々の権限のオンとオフを切り替えます。
5. **権限の変更** をクリックします。
6. 更新されたPDFをダウンロードします。

新しいパスワード欄を両方とも空にすると、ツールはPDFを完全に復号し、すべての暗号化と制限を解除します。

## 権限の設定項目

| 権限                     | 制御する内容                                             |
| ------------------------ | -------------------------------------------------------- |
| **印刷を許可**           | 文書を印刷できるかどうか                                 |
| **コピーを許可**         | テキストや画像を選択してコピーできるかどうか             |
| **変更を許可**           | 文書の内容を編集できるかどうか                           |
| **注釈を許可**           | コメント、ハイライト、スタンプを追加できるかどうか       |
| **フォーム入力を許可**   | インタラクティブなフォームフィールドに入力できるかどうか |
| **文書の組み立てを許可** | ページの挿入、削除、回転ができるかどうか                 |
| **ページの抽出を許可**   | 個々のページを抽出できるかどうか                         |

すべての権限は、適用するためにオーナーパスワードが必要です。オーナーパスワードがないと、権限フラグはほとんどのPDFリーダーで無視されます。

## PDFにおける権限のしくみ

PDFの権限は暗号化仕様の一部です。暗号化辞書にビットフラグとして保存され、準拠したPDFリーダーによって適用されます。重要な違いは次のとおりです。

- **ユーザーパスワード**: ファイルを開くために必要です。
- **オーナーパスワード**: 権限の変更や制限の解除に必要です。これがない場合、権限フラグによってユーザーが実行できる操作が制御されます。

オーナーパスワードだけを設定した場合（ユーザーパスワードなし）、誰でもファイルを開けますが、許可された操作に制限されます。両方を設定した場合は、開くのにパスワードが必要で、認証後も制限が適用されます。

## 活用例

- 閲覧と印刷はできても、編集やコピーはできないレポートを配布する
- 受け取った人が記入はできても変更はできない契約書テンプレートを共有する
- 画像のコピーを無効にしたPDFカタログを公開する
- 構造の変更は防ぎつつ、レビュー用の下書きには注釈を許可する

## ヒント

- 効果を出すには、必ずオーナーパスワードを設定してください。オーナーパスワードのない権限は強制できません。
- 一部のサードパーティ製PDFツールは権限フラグを無視します。より強力に保護したい場合は、PDFを画像化するか、DRMの利用を検討してください。
- このツールを使うと、古いRC4暗号化のPDFをAES-256にアップグレードできます。

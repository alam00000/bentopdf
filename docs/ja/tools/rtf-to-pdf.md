# RTFからPDF

リッチテキスト形式のドキュメントをPDFに変換します。RTFは、ほぼすべてのワープロでサポートされているクロスプラットフォームのドキュメント形式です。このツールはブラウザ上のLibreOfficeエンジンを使って、書式を保ったままRTFファイルを描画します。太字、斜体、表、埋め込み画像もすべてPDFに引き継がれます。

## 対応フォーマット

| フォーマット | 拡張子 | MIMEタイプ                    |
| :----------- | :----- | :---------------------------- |
| RTF          | `.rtf` | `text/rtf`, `application/rtf` |

## 使い方

1. アップロード領域をクリックするか、1つ以上のRTFファイルをドラッグアンドドロップします。
2. ファイル一覧を確認します。必要に応じてファイルを追加または削除します。
3. **PDFに変換**をクリックします。LibreOfficeエンジンは初回使用時に初期化され、その後各ファイルが処理されます。
4. ファイルが1つの場合はPDFとして直接ダウンロードされます。複数の場合は`rtf-converted.zip`として届きます。

## オプション

このツールに追加の設定はありません。変換では元のRTFの書式が保持されます。

## 出力

| 入力数        | 出力                                                                 |
| :------------ | :------------------------------------------------------------------- |
| 1ファイル     | PDFを1つダウンロード（例：`letter.pdf`）                             |
| 2ファイル以上 | ZIPアーカイブ（`rtf-converted.zip`）に、ファイルごとに1つのPDFを格納 |

## 活用例

- 古いワープロで作成したレガシーなRTFドキュメントを、現在のPDFに変換する
- RTFのメールテンプレートをPDFのプレビューにする
- 法務や医療のソフトウェアシステムが出力するRTFを処理する
- 文書管理システムのRTFファイルを、アーカイブ用にまとめてPDFに変換する

## ヒント

- LibreOfficeエンジンは一度読み込まれてキャッシュされます。セッション内の最初の変換は数秒余分にかかり、2回目以降は高速です。
- 埋め込みOLEオブジェクトを含むRTFファイルでは、すべてのオブジェクトが完全に描画されない場合があります。プレーンテキスト、画像、標準的な書式は確実に変換されます。
- RTFファイルがMicrosoft Wordで作成された場合は、DOCやDOCXと並んでRTFも受け付ける[WordからPDF](./word-to-pdf)ツールで直接変換することもできます。

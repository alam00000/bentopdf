# ODPからPDF

OpenDocument PresentationファイルをPDFに変換します。ODPはLibreOffice Impressのネイティブ形式で、Googleスライドの標準的な書き出し形式でもあります。プレゼンテーションをPDFにすれば、誰でもプレゼンテーションソフトなしで閲覧でき、スライドもきれいに印刷できます。

## 対応フォーマット

| フォーマット              | 拡張子 | 備考                                           |
| :------------------------ | :----- | :--------------------------------------------- |
| OpenDocument Presentation | `.odp` | LibreOffice Impress / Googleスライドの書き出し |

## 使い方

1. アップロードエリアをクリックするか、ODPファイルをドラッグ＆ドロップします。複数のプレゼンテーションを一度に選択できます。
2. ファイル一覧を確認します。ゴミ箱アイコンで削除でき、**ファイルを追加**でプレゼンテーションを追加できます。
3. **PDFに変換**をクリックします。LibreOfficeベースのエンジンが各プレゼンテーションを処理し、スライドが1枚ずつ1ページになったPDFを作成します。
4. ファイルが1つの場合はPDFとしてダウンロードされます。複数ファイルの場合は、`odp-to-pdf.zip`という名前のZIPアーカイブで提供されます。

## オプション

設定する項目はありません。各スライドは元の寸法でレンダリングされ、テキスト、画像、図形、スライドの背景が保持されます。

## 活用例

- 配布資料のPDFとして、プレゼンテーションを参加者に配布する
- ODPよりPDFを好む相手に、Googleスライドの書き出しを共有する
- カンファレンスの講演や講義を、読み取り専用の形式でアーカイブする
- 対面のワークショップ用に、スライド資料を印刷する

## ヒント

- スライドの切り替え効果やアニメーションは視覚効果のみでPDFには引き継がれませんが、静的なコンテンツはすべて正しくレンダリングされます。
- スピーカーノートはPDFの出力に含まれません。ノートが必要な場合は、プレゼンテーションソフトから別途書き出してください。
- ほかのLibreOfficeベースのツールと同様に、エンジンは初回の使用時に読み込まれ、セッション中はキャッシュされたままになります。

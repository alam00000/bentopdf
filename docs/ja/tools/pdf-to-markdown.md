# PDFからマークダウン

PDFファイルをMarkdown (`.md`) 形式に変換し、見出し、段落、リスト、基本的な書式を保持します。埋め込み画像の抽出と取り込みも任意で行えます。単一ファイルと一括変換に対応しています。PyMuPDFを使用しています。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、1つ以上のPDFをアップロードします。
2. 必要に応じて**画像を含める**を切り替え、抽出した画像をMarkdown出力に埋め込みます。
3. **変換**をクリックして処理を開始します。
4. 1つのファイルは`filename.md`としてダウンロードされます。複数のファイルは`markdown-files.zip`になります。

## オプション

- **画像を含める**: チェックすると、PDFの埋め込み画像が抽出され、Markdown出力から参照されます。チェックしない場合は、テキストコンテンツのみが変換されます。

## 出力形式

- **単一ファイル**: `filename.md`
- **複数ファイル**: 入力したPDFごとに1つの`.md`を含む`markdown-files.zip`。

## ユースケース

- PDFのドキュメントを、VitePress、Hugo、Jekyllなどの静的サイトジェネレーター向けにMarkdownへ変換する。
- PDFの研究論文を、Obsidianなどのノートアプリ向けに編集可能なMarkdownにする。
- 古いPDFのナレッジベースを、Gitと相性のよいテキスト形式に移行する。
- PDFの電子書籍から構造化されたコンテンツを抽出し、再フォーマットする。

## ヒント

- 画像を含めるオプションは、PDFにコンテンツに不可欠な図や表が含まれている場合に便利です。テキスト中心の文書では、出力をすっきり保つために無効にしてください。
- サイドバー、脚注、複数段組みのテキストを含む複雑なレイアウトでは、Markdownが完全にならないことがあります。必要に応じて出力を確認し、調整してください。
- 書式のない生のテキストが必要な場合は、代わりに[PDFからテキスト](./pdf-to-text)を使ってください。

# PDFのトリミング

視覚的なトリミング画面で、PDFページの余白を切り取ります。各ページ上に直接トリミング用の長方形を描き、結果をプレビューして、トリミングを適用します。ページごとに異なるトリミング領域を設定することも、文書全体に同じトリミングを適用することもできます。

## 使い方

1. PDFファイルをアップロードします。
2. トリミングエディターが開き、ドラッグできるトリミングのオーバーレイが付いた最初のページが表示されます。
3. 辺や角をドラッグして、トリミングの長方形を調整します。
4. ページ移動ボタンでページを切り替え、それぞれのトリミング領域を設定します。
5. **トリミング** をクリックして適用し、結果をダウンロードします。

## 機能

- 精密な調整用のハンドルを備えた、Cropper.js搭載のビジュアルトリミングエディター
- ページごとに移動して、個別のトリミング領域を設定
- トリミング設定をページごとに保存するため、ページによって異なるトリミングを定義可能
- 選択したトリミング領域のライブプレビュー
- あらゆるページサイズや向きのPDFに対応

## 活用例

- スキャン文書の広い余白を取り除いて、内容の領域に集中させる
- プリプレス用PDFから、プリンターのトンボや見当マークを切り取る
- 講義スライドから、発表者ノートの領域を取り除く
- 文書の抜粋を共有する前に、すべてのページからヘッダーやフッターを取り除く
- 特定の画面や印刷レイアウトに合わせて、ページのサイズを変更する

## ヒント

- トリミングのオーバーレイは、自由にサイズ変更や移動ができます。角をドラッグすると縦横比を保ったまま、辺をドラッグすると1方向だけ調整できます。
- すべてのページに同じトリミングが必要な文書では、最初のページで設定してください。ページを移動しても、ツールがトリミング領域を記憶しています。
- 視覚的にトリミングするのではなく、ページサイズを統一したい場合は、ページサイズを固定ツールのほうが適していることがあります。

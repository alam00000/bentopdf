# PNGからPDF

PNG画像を、フル解像度を保ったままPDFに変換します。各PNGは、元の画像サイズに合わせた1ページになります。透明部分は自動的に処理されます。

## 対応フォーマット

| フォーマット | 拡張子 |
| :----------- | :----- |
| PNG          | `.png` |

## 使い方

1. アップロード領域をクリックするか、PNGファイルをドラッグ&ドロップします。複数を同時に選択できます。
2. ファイルリストを管理します。不要なファイルを削除したり、追加したりできます。
3. ドロップダウンから**PDF品質**のレベルを選びます。
4. **PDFに変換**をクリックします。出力は`from_jpgs.pdf`としてダウンロードされます。

このツールはpdf-libを使って各画像を直接埋め込みます。PNGをネイティブに埋め込めない場合 (たとえば特殊なカラープロファイルのため) は、キャンバス経由でJPEGとして再レンダリングするフォールバックが働きます。

## オプション

**PDF品質**は、埋め込み前に適用される圧縮を制御します。

- **高品質**: 圧縮を最小限にし、ファイルサイズは最大になります。
- **中品質** (デフォルト): サイズと鮮明さのバランスがよい設定です。
- **低品質**: 圧縮を最大にし、出力は最小になります。

## ユースケース

- スクリーンショットを、バグレポートやドキュメント用の複数ページPDFに変換する
- UIデザインのエクスポートを、レビュー用に1つのファイルにまとめる
- 図のエクスポート (draw.io、Excalidraw) を、共有できるPDFにする
- 一連のグラフ画像を、レポートとしてまとめる

## ヒント

- 透明部分を含むPNGは、PDFでは白い背景になります。別の背景が必要な場合は、事前に画像を編集してください。
- 輪郭やテキストがくっきりしたスクリーンショットや図では、高品質を選ぶとJPEG圧縮のノイズを避けられます。中品質や低品質では、内部的にJPEGへ変換されることがあります。

# PDFテーブルの抽出

PDF内のすべての表を検出し、CSV、JSON、Markdownのお好みの形式でエクスポートできます。各表は、ページと位置のメタデータとともに個別に抽出されます。PyMuPDFの表検出エンジンを搭載しています。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、PDFをアップロードします。
2. お好みの **エクスポート形式** を選びます。CSV、JSON、Markdownのいずれかです。
3. **抽出** をクリックして、処理を開始します。
4. 表が1つ見つかった場合は、単一のファイルとしてダウンロードされます。複数の表がある場合は、表ごとに1ファイルのZIPアーカイブになります。

## オプション

- **エクスポート形式**: 次から選べます。
  - **CSV**: カンマ、引用符、改行を含むフィールドを適切に引用符で囲んだ、カンマ区切りの値。表計算ソフトやデータベースに適しています。
  - **JSON**: 配列の配列の構造で、2スペースのインデントで整形されます。プログラムでの利用に適しています。
  - **Markdown**: PyMuPDFが描画する、パイプ区切りの表形式。ドキュメントやREADMEファイルに適しています。

## 出力形式

- **表が1つ**: `filename_table.csv`（または `.json` / `.md`）
- **複数の表**: `table_1_page3.csv`、`table_2_page5.csv` のような名前のファイルを含む `filename_tables.zip`

## 活用例

- 長いPDFレポートから、文書全体のデータを取り出さずに、特定の表だけを抽出する。
- GitHubのIssue、Wiki、ドキュメントに直接貼り付けるために、表をMarkdown形式で取得する。
- APIの連携やスクリプトのために、PDFの表から構造化されたJSONデータを取り出す。
- 異なるバージョンのPDFの表を、両方をCSVにエクスポートして差分を取って比較する。

## ヒント

- このツールでは表ごとに制御できます。すべての表を1つのCSVにまとめて出力するだけなら、[PDFからCSV](./pdf-to-csv) を使ってください。Excelのブック全体が必要な場合は、[PDFからExcel](./pdf-to-excel) を使ってください。
- 複数のページにまたがる表は、ページごとに別々の表として検出されることがあります。手動で連結する必要があるかもしれません。
- 表が検出されない場合、PDFはスキャン画像かもしれません。先にOCRを実行して、テキストレイヤーを追加してください。

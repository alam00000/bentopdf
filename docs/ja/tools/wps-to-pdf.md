# WPSからPDF

Microsoft Worksのワープロファイルを、PDFに変換します。Microsoft Worksは1990年代後半から2000年代にかけて、家庭向けPCにバンドルされており、多くのWPSファイルが今も古いハードディスクやメールのアーカイブに残っています。このツールは、それらをブラウザ上で開き、きれいなPDFを作成します。

## 対応フォーマット

| フォーマット    | 拡張子 | 備考                              |
| :-------------- | :----- | :-------------------------------- |
| Microsoft Works | `.wps` | Microsoft Worksのワープロファイル |

## 使い方

1. アップロード領域をクリックするか、WPSファイルをドラッグ&ドロップします。複数のファイルを受け付けます。
2. ファイル一覧を確認します。ゴミ箱アイコンで個別のファイルを削除するか、**さらにファイルを追加する**をクリックしてバッチを広げます。
3. **PDFに変換**をクリックします。LibreOfficeベースのエンジンがブラウザに読み込まれ、各WPS文書をPDFに変換します。
4. 1ファイルの場合は、そのままPDFとしてダウンロードされます。複数ファイルの場合は、`wps-to-pdf.zip`という名前のZIPアーカイブにまとめられます。

## オプション

追加の設定は不要です。コンバーターは、WPSファイルのテキスト、基本的な書式、埋め込み画像を処理します。

## 活用例

- Microsoft Works形式で保存された、古い学校や仕事の文書を復元する
- Microsoft Worksをインストールしていなくても、メールに添付されたWPSファイルを開く
- WPSファイルのアーカイブを、最新の文書システムへ移行するために変換する
- 現在のワープロでは開けない古い文書を印刷する

## ヒント

- Microsoft Worksの`.wps`ファイルを、WPS Officeのファイルと混同しないでください。このツールは、古いMicrosoft Works形式専用です。
- LibreOfficeエンジンは初回の使用時に読み込みに少し時間がかかります。読み込み後は、同じセッション内の追加の変換がより速く実行されます。

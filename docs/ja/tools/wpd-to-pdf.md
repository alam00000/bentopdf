# WPDからPDF

Corel WordPerfectの文書をPDFファイルに変換します。WPDは、かつて法律事務所や政府機関で主流だったワープロ形式でした。最近のソフトウェアでは開けない古いWordPerfectファイルを、標準的なPDFとしてよみがえらせることができます。

## 対応フォーマット

| フォーマット | 拡張子 | 備考                                |
| :----------- | :----- | :---------------------------------- |
| WordPerfect  | `.wpd` | WordPerfectの主要なバージョンすべて |

## 使い方

1. アップロード領域をクリックするか、WPDファイルをドラッグ&ドロップします。複数のファイルを一度に選択できます。
2. ファイル一覧を確認します。不要なファイルはゴミ箱アイコンで削除するか、**さらにファイルを追加する**で文書を追加します。
3. **PDFに変換**をクリックします。ツールがLibreOfficeベースの変換エンジンをブラウザに読み込み、WPD形式を解析してPDFを出力します。
4. 1ファイルの場合は、そのままPDFとしてダウンロードされます。一括変換の場合は、`wpd-to-pdf.zip`という名前のZIPアーカイブが作成されます。

## オプション

設定は不要です。LibreOfficeエンジンが、WPDの書式、フォント、レイアウトを自動的に処理します。

## 活用例

- WordPerfectで書かれた数十年前の法的文書を開く
- 保管されている政府の提出書類をWPDから最新の形式に変換する
- 従来のWordPerfect文書ライブラリを、長期保存用にPDFへ移行する
- Corel WordPerfectをインストールしていない相手と、WPDファイルを共有する

## ヒント

- LibreOfficeエンジンは初回の使用時に読み込まれるため、少し時間がかかります。同じセッション内の以降の変換は、より速くなります。
- 複雑なWPDのマクロやコード表示は保持されませんが、見た目のレイアウト、テキスト内容、基本的な書式はPDFに引き継がれます。

# ページの削除

PDF文書から不要なページを削除します。削除するページは、ページ番号や範囲を入力して指定するか、ページのサムネイルを直接クリックして削除対象に設定します。

## 使い方

1. PDFファイルをアップロードします。ツールがすべてのページのサムネイルプレビューを表示します。
2. テキスト欄に、範囲の構文（例: `2, 5-8`）で削除するページを入力するか、サムネイルをクリックして切り替えます。
3. 選択したページはハイライト表示されるので、選択内容を確認できます。
4. 処理ボタンをクリックします。選択したページを取り除いた新しいPDFが作成されます。

## 機能

- 範囲の構文（`2, 5-8, 12`）によるテキストでのページ選択
- クリックで選択して削除できる、ビジュアルなサムネイルグリッド
- 削除対象のページをリアルタイムでハイライトするプレビュー
- 実際のページ数に対する入力の検証
- 削除しなかったすべてのページを元の順序で保持

## 活用例

- スキャン文書から、白紙や穴埋め用のページを削除する
- 文書を共有する前に、表紙や付録を取り除く
- 最終版のPDFに誤って残った下書きのページを整理する
- 配布前に、機密情報を含むページを削除する

## ヒント

- ページを削除しても、残りのページの内容や書式には影響しません。出力は、削除したページを除いた元の文書の忠実なコピーです。
- 特定のページを削除するのではなく、特定のページだけを残したい場合は、[ページの抽出](./extract-pages) のほうが適しています。
- サムネイル表示は遅延読み込みされるため、大きな文書でも操作が軽快です。

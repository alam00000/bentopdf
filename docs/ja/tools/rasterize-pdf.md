# PDFの画像化

ラスタライズは、PDFの各ページを画像に変換し、それらの画像をPDFに組み直す処理です。見た目は元のPDFと同じですが、選択可能なテキスト、インタラクティブな要素、編集可能なレイヤーは含まれません。いわば高品質なコピーです。

## 使い方

1. 1つ以上のPDFファイルをアップロードします。
2. ラスタライズ出力の**DPI**（解像度）を設定します。
3. **画像形式**を選択します。可逆圧縮の高品質ならPNG、ファイルを小さくするならJPEGです。
4. 必要に応じて**グレースケールに変換**をオンにします。
5. **PDFをラスタライズ**をクリックします。複数のファイルはZIPでダウンロードされます。

## オプション

| 設定               | 値                                  | デフォルト |
| ------------------ | ----------------------------------- | ---------- |
| **DPI**            | 72、150、200、300、600              | 150        |
| **画像形式**       | PNG（可逆圧縮）、JPEG（より小さい） | PNG        |
| **グレースケール** | オン/オフ                           | オフ       |

## DPIの目安

- **72**：画面での閲覧のみ。ファイルサイズが最小
- **150**：一般的な用途に適したバランス
- **200**：テキストがより鮮明で、ファイルサイズは中程度
- **300**：印刷品質の出力
- **600**：高品質のアーカイブやプロ向けの印刷

## 活用例

- 機密文書を共有する前に、テキストの抽出を防ぐ
- テキストをピクセルに変換して、フォントの依存関係の問題をなくす
- ビューアーによって表示が異なる、複雑なレイヤーや透明効果を含むPDFの「フラット」版を作成する
- 画像ベースの入力しか受け付けないシステム向けにPDFを準備する
- PDFを画像だけにして、隠れたコンテンツ（変更履歴やフォームデータなど）を取り除く

## ヒント

- PNGで150 DPIは、安心できるデフォルトです。印刷出力が必要な場合や細部を拡大したい場合にのみ、それより高くしてください。
- JPEGはファイルがかなり小さくなりますが、鮮明なテキストの縁に圧縮ノイズが出ます。
- ラスタライズは元に戻せません。後で編集可能なテキストが必要になる可能性がある場合は、元のPDFを保管してください。

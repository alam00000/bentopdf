# PDFの分割

6つの分割モードのいずれかを使って、PDFを小さなドキュメントに分けます。単純なページ範囲からしおりによる分割まで、ドキュメントを分けるあらゆる場面に対応します。

## 使い方

1. PDFファイルを1つアップロードします。
2. ドロップダウンから分割モードを選択します。
3. モードごとのオプション（ページ範囲、選択など）を設定します。
4. 処理ボタンをクリックします。
5. 結果は、モードと設定に応じて、単一のPDFまたはZIPアーカイブとしてダウンロードされます。

## 分割モード

| モード             | 説明                                                                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **範囲**           | `1-3, 5, 8-10`のようにページ範囲を入力します。複数の範囲を指定すると、別々のPDFがZIPで生成されます。範囲が1つなら、PDFが1つ生成されます。 |
| **視覚的に選択**   | ページのサムネイルを見ながら、クリックして必要なページを選択します。選択したページが新しいPDFに抽出されます。                             |
| **偶数 / 奇数**    | 偶数ページまたは奇数ページだけを抽出します。                                                                                              |
| **すべてのページ** | すべてのページを個別のPDFファイルに分割し、ZIPでダウンロードします。                                                                      |
| **しおり**         | しおりの境界で分割します。しおりのレベルを選んで、分割する位置を制御します。                                                              |
| **Nページごと**    | Nページずつのまとまりに分割します（例：5ページごと）。最後のまとまりはページ数が少なくなる場合があります。                                |

## 機能

- ほぼすべての用途をカバーする6つの分割モード
- 遅延読み込みのサムネイルによる視覚的なページ選択
- レベルで絞り込めるしおり対応の分割
- 範囲モードと視覚的選択モードでのZIP出力オプション
- 混在した記法のページ範囲（`1-3, 5, 8-10`）に対応
- Nページごとの分割で、まとまりが不均等になる場合の警告

## 活用例

- 大きなドキュメントから特定の章やセクションを抽出する
- 両面印刷のワークフロー向けに、奇数ページと偶数ページを分ける
- 書籍のPDFを、しおりの境界で章ごとのファイルに分割する
- 契約書から、署名ページなどの特定のページを取り出す
- まとめられたレポートを、配布用にセクションごとのファイルに分割する

## ヒント

- カンマで区切った複数のページ範囲（例：`1-5, 10-15, 20-25`）を指定すると、範囲ごとに別々のPDFが生成され、ZIPにまとめられます。
- しおりによる分割モードには、PDFに実際にしおりが含まれている必要があります。見つからない場合はエラーメッセージが表示されます。
- 範囲モードと視覚的選択モードの「ZIPとしてダウンロード」チェックボックスを使うと、結合したファイルではなく、ページごとの個別のPDFを入手できます。

# 色の調整

PDF 向けの本格的なカラーグレーディングツールキットです。明るさ、コントラスト、彩度、色相シフト、色温度、色合い、ガンマ、セピアの 8 つのパラメータを独立して調整でき、スライダーを動かすたびにライブプレビューが更新されます。

## 使い方

1. PDF ファイルをアップロードします。
2. 最初のページのプレビューと色設定パネルが表示されたエディタが開きます。
3. スライダーを動かして、各カラーパラメータを調整します。プレビューはリアルタイムで更新されます。
4. **リセット**をクリックすると、すべてのスライダーがデフォルトの位置に戻ります。
5. **適用**をクリックすると、すべてのページを処理して、調整後の PDF をダウンロードします。

## オプション

- **明るさ** -- ページ全体を明るくまたは暗くします（-100 ～ +100）。
- **コントラスト** -- 明るい部分と暗い部分の差を大きくまたは小さくします（-100 ～ +100）。
- **彩度** -- 色の鮮やかさを上げ下げします（-100 ～ +100）。-100 にするとグレースケールになります。
- **色相シフト** -- 色相環を回転させて、すべての色を一様にずらします。
- **色温度** -- 色を暖色系（黄色やオレンジ）または寒色系（青）にずらします。
- **色合い** -- 緑またはマゼンタの色かぶりを加えます。
- **ガンマ** -- ガンマカーブを使って中間調の明るさを調整します。1.0 未満の値では中間調が暗くなり、1.0 を超える値では明るくなります。
- **セピア** -- クラシックなセピア調の効果を適用します。値が大きいほど、茶色の色味が強くなります。

## 機能

- 独立して調整できる 8 つのカラーパラメータ
- スライダーの変更に即座に反応するライブプレビュー
- すぐにデフォルトへ戻せるリセットボタン
- 文書内のすべてのページを処理
- あらゆる PDF の内容（テキスト、画像、グラフィック）に対応

## ユースケース

- 暗いスキャンを明るくしたり、露出オーバーのページを補正したりする
- カラフルな文書の彩度を下げて、印刷時のインク使用量を減らす
- セピア調を適用して、証明書や賞状にアンティークな雰囲気を出す
- PDF に埋め込まれた写真の色温度を補正する
- 色あせたスキャン文書や低品質なスキャン文書のコントラストを上げる

## ヒント

- 手早くグレースケールに変換するには、彩度のスライダーを -100 まで動かします。
- ガンマのスライダーは、中間調が暗すぎる、または明るすぎるスキャン文書の読みやすさを改善するのに特に役立ちます。
- 他の画像エフェクト系ツールと同様に、このツールは各ページをラスタライズします。出力は画像ベースになるため、テキストは選択できなくなります。

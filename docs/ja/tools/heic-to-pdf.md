# HEICからPDF

HEIC/HEIF画像をPDFに変換します。HEICはiOS 11以降のiPhoneとiPadで標準の写真フォーマットです。このツールを使えば、デスクトップソフトをインストールしたりファイルをサーバーにアップロードしたりせずに、写真をPDFにできます。

## 対応フォーマット

| フォーマット | 拡張子  |
| :----------- | :------ |
| HEIC         | `.heic` |
| HEIF         | `.heif` |

## 使い方

1. アップロードエリアをクリックするか、HEIC/HEIFファイルをドラッグ＆ドロップします。
2. ファイル一覧を確認し、不要なファイルを削除します。
3. **PDFに変換**をクリックします。結果は`from_heic.pdf`としてダウンロードされます。

各HEICファイルはheic2anyライブラリでデコードされ、品質92%のPNGに変換されます。そのPNGはpdf-libでPDFに埋め込まれ、1枚の画像が1ページに、フル解像度で配置されます。

## オプション

このツールに追加の設定はありません。HEIC画像は高品質（0.92）でPNGに変換されてから埋め込まれます。

## 活用例

- 保険請求やレポートに添付するため、iPhoneの写真からPDFを作る
- 不動産掲載用のHEIC写真を、印刷可能な1つの文書にまとめる
- iPadのスクリーンショット（HEIF形式）を共有しやすいPDFにする
- 旅行記用に、旅行の写真を一括で変換する

## ヒント

- HEICのデコードはWebAssemblyを使ってすべてブラウザー内で行われます。デコーダーの読み込み中は、最初の変換に少し時間がかかる場合があります。
- HEICを他の画像形式（JPG、PNGなど）と混ぜたい場合は、HEICを含むすべての形式を扱える[画像からPDF](./image-to-pdf)ツールを使ってください。
- iPhoneのHEICファイルには、GPS座標を含むEXIFデータが含まれていることがよくあります。PDFの出力にはこのメタデータは引き継がれません。

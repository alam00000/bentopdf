# PDFエディター

BentoPDFのPDFエディターを使うと、PDFに注釈を付け、ハイライトし、墨消しし、コメントし、図形や画像を追加し、検索できます。高機能なエディターがブラウザ上で直接読み込まれ、サーバーへのアップロードは不要です。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、PDFをアップロードします。
2. 埋め込みのPDFエディターが自動的に開き、文書が読み込まれます。
3. ツールバーを使って、注釈、ハイライト、墨消し、テキストの追加、図形の描画、画像の挿入ができます。
4. **編集したPDFをダウンロード** をクリックして、変更を保存します。

## 機能

- ハイライト、下線、取り消し線、フリーハンド描画を備えた、フル機能の注釈ツールバー
- テキストの挿入とコメント
- 墨消しを適用すると、マークした内容を完全に削除する墨消しツール。**編集したPDFをダウンロード** をクリックしたときに適用されていないマークがある場合、エディターは先にそれらを適用するか確認します。
- 長方形、円、線、矢印の図形ツール
- PDFのページへの画像の挿入
- 文書全体を対象とした、内蔵のテキスト検索
- タブによる複数文書のサポート（最大10個の文書を同時に開けます）
- ドラッグ&ドロップによるファイルの読み込み

## 活用例

- 契約書を確認し、ハイライトやコメントで変更箇所に印を付ける
- 共有の前に、社会保障番号や財務データなどの機密情報を墨消しする
- 建築図面や設計図に注釈を追加する
- 会社のロゴやスタンプを文書のページに挿入する
- 長い法的文書から、特定の用語を検索する

## ヒント

- 複数のPDFを同時に開き、エディター上部のタブバーで切り替えられます。
- エディターは元のPDFの構造を保持するため、フォント、レイアウト、フォームフィールドはそのまま維持されます。
- テキストや領域を墨消し対象にマークしただけでは、墨消しを適用するまで何も削除されません。選択したテキストを墨消しすると、ファイルのプロパティ、しおり、コメント、添付ファイルにあるそのコピーも、ダウンロードから削除されます（ファイルが暗号化されている場合を除く）。
- 一括の透かしやページ番号の追加には、書式をより細かく制御できる専用ツールを使ってください。

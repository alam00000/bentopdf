# ページ番号

PDFのすべてのページに、見えるページ番号を追加します。位置、形式、フォントサイズ、色を選ぶだけで、あとはツールが処理します。

## 使い方

1. PDFファイルをアップロードします。
2. 表示されるオプションパネルでページ番号の設定を行います。
3. **ページ番号を追加**をクリックして処理します。
4. 番号付きのPDFが自動的にダウンロードされます。

## オプション

- **位置**: ページ番号を表示する場所を選びます。下中央、左下、右下、上中央、左上、右上から選べます。
- **形式**: 単純な連番 (1, 2, 3...) か、「全Yページ中Xページ」形式 (1 / 5, 2 / 5...) を選びます。
- **フォントサイズ**: ページ番号のテキストサイズを設定します。デフォルトは12です。
- **色**: カラーピッカーでページ番号のテキストの色を自由に選べます。

## 機能

- 四隅と中央をカバーする6種類の配置オプション
- 2種類の番号形式: 単純な連番、または「全Yページ中Xページ」
- 6〜72ポイントで調整できるフォントサイズ
- テキストの色を選べるフルカラーピッカー
- ページサイズに関係なく、番号を安全な領域内に収める自動余白処理

## ユースケース

- ページ参照が必要な文書を印刷用に準備する
- 複数のファイルから作った結合PDFにページ番号を追加する
- 配布前のプレゼン資料にページ番号を振る
- 法律文書や契約書に連番を追加する

## ヒント

- 「全Yページ中Xページ」形式は、提案書やレポートなど、読み手が全体の長さを知る必要がある文書に便利です。
- 前付けにローマ数字を使うなど、セクションごとに異なる番号スタイルが必要な場合は、代わりに[ページラベルの追加](./add-page-labels)ツールを使ってください。

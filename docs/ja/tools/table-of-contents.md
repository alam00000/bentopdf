# 目次

このツールは、PDF内のしおり（アウトライン）を読み取り、書式設定された目次ページを生成してドキュメントの先頭に追加します。PDFにしおりはあるものの、目に見える目次ページがない場合に、自動的に作成します。

## 使い方

1. しおりを含むPDFをアップロードします。
2. 目次のタイトル、フォントサイズ、フォントファミリーをカスタマイズします。
3. 必要に応じて**目次ページのしおりを追加**にチェックを入れ、目次自体もしおりツリーに含めます。
4. **目次を生成**をクリックして、ファイルを処理します。
5. 先頭に目次ページが挿入されたPDFが、自動的にダウンロードされます。

## オプション

- **目次のタイトル**：生成されるページの上部に表示される見出しです。デフォルトは「目次」です。
- **フォントサイズ**：10ptから72ptまで選べます。デフォルトは12ptです。
- **フォントファミリー**：Times Roman、Helvetica、Courierのバリエーション（標準、太字、斜体、太字斜体）から選択します。デフォルトはHelveticaです。
- **目次ページのしおりを追加**：チェックを入れると、目次ページ自体のしおり項目がPDFのアウトラインツリーに追加されます。

## 機能

- PDFのしおりの階層全体を読み取り
- ページ番号の参照付きで、きれいに整形された目次ページを生成
- 入れ子になったしおりのレベルを、インデントでサポート
- 12種類の内蔵PDFフォントから選択可能
- 目次ページ自体を指すしおりを、任意で追加

## 活用例

- デジタルのしおりしかない電子書籍やレポートに、印刷可能な目次を追加する
- 複数のPDFを結合した後のドキュメントに、目次を作成する
- 長い技術マニュアルの参照ページを生成する
- 目に見える目次が求められる印刷用のドキュメントを準備する

## ヒント

- PDFにしおりがない場合は、先に[しおりの編集](./bookmark)ツールでしおりを作成してから、ここに戻って目次を生成してください。
- 大きなドキュメントでは、14ptや16ptなど大きめのフォントサイズにすると読みやすくなります。

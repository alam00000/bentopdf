# PDFの傾き補正

スキャンした文書が完全にまっすぐなことはまれです。わずかな傾きでも、OCRの精度が下がり、印刷の見た目も雑になります。このツールはOpenCVの画像処理アルゴリズムを使って各ページの傾きの角度を検出し、水平に戻すよう回転させます。

## 使い方

1. スキャンしたPDFを1つ以上アップロードします。
2. **傾きのしきい値** を設定します。検出された傾きがこの値を下回るページには、手を加えません。
3. **処理品質（DPI）** を選びます。DPIが高いほど検出精度は上がりますが、時間がかかります。
4. **PDFの傾き補正** をクリックします。
5. 処理が終わると、結果パネルに各ページの検出された角度と、補正されたかどうかが表示されます。

## オプション

| 設定               | 値                   | デフォルト |
| ------------------ | -------------------- | ---------- |
| **傾きのしきい値** | 0.1、0.5、1.0、2.0度 | 0.5        |
| **処理DPI**        | 100、150、200、300   | 150        |

## 傾き検出のしくみ

ツールは各ページを選択したDPIで画像に描画し、OpenCVを使ってコンテンツ内の主要な線の角度を検出します。検出された傾きがしきい値を超える場合、ページは逆の角度で回転されてまっすぐになります。しきい値を下回るページは、そのまま通過します。

## 活用例

- 一括スキャンした契約書や法的文書を整える
- スキャンしたレシートや請求書を、OCR処理用に準備する
- 紙の置き方が一定でないフラットベッドスキャナーのページをまっすぐにする
- デジタル化した資料の見た目の品質を向上させる

## ヒント

- OCR向けにピクセル単位の正確な位置合わせが必要な場合は、しきい値を0.1度に下げてください。
- 150 DPIは、ほとんどの文書で高速かつ正確です。非常に小さな文字や細部の多いページには、300 DPIを使ってください。
- 傾き補正は、はっきりした水平のテキスト行がある文書で最もよく機能します。ほとんどが画像のページや、斜めのデザイン要素があるページでは、うまくいかないことがあります。

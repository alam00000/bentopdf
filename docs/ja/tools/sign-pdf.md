# PDFへ署名

あらゆるPDFドキュメントに署名を追加します。このツールには、署名ツールを備えたPDFビューアーが組み込まれており、署名を手書きしたり、署名用フォントで名前を入力したり、署名画像をアップロードしたりできます。署名は任意のページに配置してサイズを変更し、署名済みのドキュメントを保存します。

## 使い方

1. PDFファイルをアップロードします。
2. ドキュメントが、注釈ツールを備えた統合PDFビューアーで開きます。
3. ビューアーの署名ツールで、手書き、入力、または画像のアップロードによって署名を作成します。
4. 署名を配置したいページをクリックし、サイズと位置を調整します。
5. 必要に応じて、**PDFをフラット化**にチェックを入れ、署名をドキュメントに完全に埋め込みます。
6. **署名済みPDFを保存してダウンロード**をクリックして、署名済みのファイルを入手します。

## オプション

- **PDFをフラット化**：チェックを入れると、署名がページの内容に完全に埋め込まれます。これにより、他の人が署名を移動したり削除したりできなくなります。チェックを外すと、署名は注釈のままで、対応するビューアーで編集できます。

## 機能

- 3つの署名作成方法：手書き、入力したテキスト、アップロードした画像
- 正確に配置できる統合PDFビューアー
- 任意のページで署名をドラッグして配置し、サイズを変更
- 署名を完全に埋め込む、任意のフラット化
- 同じドキュメントに複数の署名を追加可能

## 活用例

- 契約書、合意書、承認フォームに署名して返送する
- 税務書類、保険の請求書、行政の書類に署名を追加する
- 複数ページの合意書の各ページにイニシャルを入れる
- PDFの添付ファイルとして届いたNDAや人事書類に署名する

## ヒント

- 署名済みのPDFを、署名を削除したり位置を変更したりできないようにしたい相手に送る場合は、フラット化を有効にしてください。
- 証明書ベースの検証を伴う、法的拘束力のあるデジタル署名には、BentoPDFに別途用意されているデジタル署名ツールを使用できます。
- 最もきれいな結果を得るには、背景が透明なPNGの署名画像をアップロードしてください。

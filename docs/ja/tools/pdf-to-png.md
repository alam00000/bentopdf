# PDFからPNG

PDFの各ページをPNG画像に変換します。PNGはロスレス圧縮を使うため、出力は元のページのあらゆるディテールを保持します。1ページのPDFは`.png`ファイルとしてダウンロードされ、複数ページのPDFはZIPになります。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、PDFをアップロードします。
2. **スケール**スライダーを設定して、出力解像度を制御します。
3. **変換**をクリックして処理を開始します。
4. 1つのPNG、またはZIPアーカイブが自動的にダウンロードされます。

## オプション

- **スケール**: 1.0xから3.0x (デフォルトは2.0x)。2.0xでは、標準のレターサイズのページが約1,224 x 1,584ピクセルでレンダリングされます。スケールを上げると、より大きく鮮明な画像になりますが、ファイルサイズと処理時間が増えます。

## 出力形式

- **1ページ**: `filename.png`
- **複数ページ**: `filename_pngs.zip`。`page_1.png`、`page_2.png`などを含みます。

## ユースケース

- プレゼン用に、PDFページの高精細なスクリーンショットを取得する。
- 輪郭がくっきりして圧縮ノイズのない、グラフや図を抽出する。
- PDFのモックアップから、Webデザイン用の素材を準備する。
- OCRの前処理用に、ロスレスのページ画像を作る。

## ヒント

- PNGファイルはJPGよりかなり大きくなります。完璧な品質よりファイルサイズが重要な場合は、[PDFからJPG](./pdf-to-jpg)または[PDFからWebP](./pdf-to-webp)を使ってください。
- スケール1.0xでは、出力はPDF本来の解像度と一致します。印刷品質で書き出すには3.0xに上げてください。

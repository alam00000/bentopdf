# 色の反転

PDFのすべての色を反転色にします。白い背景は黒に、黒い文字は白に、その他の色は補色に変わります。どんなPDFでも「ダークモード」版を作る最も手軽な方法です。

## 使い方

1. PDFファイルをアップロードします。
2. **色の反転**をクリックして処理します。
3. 反転したPDFが自動でダウンロードされます。

追加の設定はありません。このツールは各ページを画像としてレンダリングし、すべてのピクセルの色を反転して、結果を新しいPDFに組み直します。

## 機能

- すべてのページの色をワンクリックで反転
- 文書内のすべてのページを処理
- 元のページ寸法とレイアウトを維持
- 内容の種類（テキスト、画像、混在）を問わずあらゆるPDFで動作

## 活用例

- 夜間でも読みやすいように、教科書やマニュアルのダークモード版を作る
- アクセシビリティのために、文書の高コントラスト版を用意する
- 露出が正しくない状態で取り込んだスキャン文書を反転する
- 画像の多いPDFのネガ版を作って、視覚的に分析する

## ヒント

- このツールは効果を適用するためにページを画像化するため、出力は画像ベースになります。テキストは選択も検索もできなくなります。反転後に検索可能なテキストが必要な場合は、出力をOCRツールにかけてください。
- 明るさ、コントラスト、彩度などをより細かく調整したい場合は、代わりに[色の調整](./adjust-colors)ツールを使ってください。
- ページ数の多い大きなPDFは、各ページを個別にレンダリングして反転するため、処理に時間がかかる場合があります。

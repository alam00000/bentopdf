# PDFからJPG

PDFの各ページをJPG画像に変換します。1ページの文書は単独の`.jpg`ファイルとしてダウンロードされます。複数ページのPDFは、1ページにつき1つのJPGを含むZIPアーカイブになります。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、PDFをアップロードします。ツールにファイル名、ファイルサイズ、ページ数が表示されます。
2. **品質**スライダーを調整して、JPGの圧縮を制御します。
3. **変換**をクリックして処理を開始します。
4. 結果は自動的にダウンロードされます。1ページのPDFなら1つのJPG、複数ページの文書ならZIPファイルです。

## オプション

- **品質**: 0%から100% (デフォルトは90%) のスライダー。値を高くすると、ファイルサイズは大きくなりますが、より鮮明な画像になります。値を低くすると、より強く圧縮されます。

ページは内部で2倍スケールでレンダリングされるため、出力解像度はPDFのページ寸法の2倍になります。標準のレターサイズのページでは、約1,224 x 1,584ピクセルの画像になります。

## 出力形式

- **1ページ**: `filename.jpg`
- **複数ページ**: `filename_jpgs.zip`。`page_1.jpg`、`page_2.jpg`などを含みます。

## ユースケース

- 文書管理システム用のプレビューサムネイルを生成する。
- PDFに対応していないチャットやメールで、レポートの1ページを共有する。
- PDFの図やイラストから画像素材を作る。
- スキャンした文書を個別の画像として保管する。

## ヒント

- ロスレスの出力が必要な場合は、代わりに[PDFからPNG](./pdf-to-png)を使ってください。
- 品質を80〜90%に設定すると、ファイルサイズと見た目の忠実度のバランスがよくなります。
- ページごとに特定の形式が必要な場合は、PDFから画像への出力ノードを持つ[PDFワークフロービルダー](./pdf-workflow)をご検討ください。

# JSONからPDF

BentoPDFの**PDFからJSON**ツールで作成したJSONファイルから、PDF文書を再構築します。これは往復変換のためのツールで、PDFの構造化されたJSON表現を受け取り、元の文書を組み立て直します。

::: warning
このツールが受け付けるのは、BentoPDFのPDFからJSONコンバーターで作成したJSONファイルのみです。APIやデータベース、他のツールが出力する一般的なJSONファイルには対応していません。
:::

## 対応フォーマット

| 入力    | 説明                                                  |
| :------ | :---------------------------------------------------- |
| `.json` | BentoPDFのPDFからJSONツールで書き出されたJSONファイル |

## 使い方

1. アップロードエリアをクリックするか、1つ以上のJSONファイルをドラッグ＆ドロップします。
2. ファイル一覧に、選択した各ファイルとそのサイズが表示されます。
3. **PDFに変換**をクリックします。ツールはWeb WorkerとCPDFエンジンですべてのファイルを処理します。
4. 出力は`jsons-to-pdf.zip`としてダウンロードされ、入力した各JSONファイルにつき1つのPDFが含まれます。

変換はバックグラウンドのWeb Workerで実行されるため、大きなファイルでもUIは応答し続けます。

## オプション

このツールに設定可能なオプションはありません。出力されるPDFは、JSONの構造によって完全に決まります。

## 出力

複数のJSONファイルを変換した場合、結果はZIPアーカイブで提供されます。各PDFは元のJSONファイルの名前が付きます（例: `report.json`は`report.pdf`になります）。

## 活用例

- JSONベースのバックアップやアーカイブのパイプラインからPDFを復元する
- PDFをJSONに変換して中身を確認し、再びPDFに戻す
- JSON構造をプログラムで変更した後に、文書を再構築する
- PDFからJSONへの書き出しがすべての文書内容を取得できているか、変換し直して確認する

## ヒント

- 任意のJSONデータ（APIのレスポンスや設定ファイルなど）を整形したPDFに変換したい場合は、[テキストからPDF](./txt-to-pdf)ツールのほうが向いています。JSONをテキストとして貼り付けると、適切な書式でレンダリングされます。
- このツールを使うには、CPDF WebAssemblyエンジンが利用可能である必要があります。セルフホスト環境では、CPDFのWASMファイルを設定してください。

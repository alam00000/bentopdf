# 空白ページの追加

指定した位置に空のページを PDF へ挿入します。空白ページを入れる場所と枚数を自由に指定できます。

## 使い方

1. PDF ファイルをアップロードします。ツールにページ数が表示されます。
2. 空白ページを挿入する**位置**を入力します。先頭に挿入するには `0`、末尾に追加するには総ページ数を指定します。
3. 追加する空白ページの**枚数**を入力します（デフォルトは 1）。
4. 処理ボタンをクリックします。空白ページが挿入された PDF がダウンロードされます。

## 機能

- 先頭、途中、末尾など、任意の位置に挿入可能
- 1 回の操作で複数の空白ページを追加可能
- アップロードした PDF のページ数に応じて、位置のヒントが動的に更新
- 標準的な A4 サイズの空白ページ

## ユースケース

- まとめた文書のセクション間に、区切り用の空白ページを追加する
- 両面印刷の位置合わせのために空白ページを挿入する
- 印刷した学習ガイドに手書きメモ用のスペースを追加する
- 最低ページ数の要件を満たすために文書のページ数を調整する

## ヒント

- 位置 `0` は最初のページの前に挿入します。総ページ数と同じ位置を指定すると、最後のページの後ろに追加されます。
- 空白ではなく内容のあるページを特定の位置に挿入したい場合は、[PDFマルチツール](./pdf-multi-tool) を使って、指定したページの後ろに別の PDF を挿入してください。

# PDFをサニタイズ

PDFには、画面に表示されるもの以外にも多くのものが含まれていることがあります。隠れたメタデータ、埋め込みのJavaScript、添付ファイル、フォームデータ、レイヤー情報は、機密データを漏らしたり、セキュリティ上のリスクになったりすることがあります。サニタイズはそれらをすべて取り除き、公開しても安全なクリーンなドキュメントにします。

## 使い方

1. PDFファイルをアップロードします。
2. チェックリストから、削除する要素を選択します。
3. **PDFをサニタイズ**をクリックします。
4. クリーンになったファイルをダウンロードします。

## サニタイズのオプション

すべてのオプションはデフォルトで有効です。残したいものはチェックを外してください。

| オプション                 | 削除されるもの                                               |
| -------------------------- | ------------------------------------------------------------ |
| **フォームをフラット化**   | インタラクティブなフォームフィールドを静的な内容に変換       |
| **メタデータを削除**       | 作成者、タイトル、作成日、ソフトウェア情報、XMPデータを削除  |
| **注釈を削除**             | コメント、ハイライト、付箋、マークアップを削除               |
| **JavaScriptを削除**       | 開いたときに実行される可能性のある埋め込みスクリプトを除去   |
| **埋め込みファイルを削除** | PDFに埋め込まれた添付ファイルを削除                          |
| **レイヤー（OCG）を削除**  | オプションコンテンツグループを1つのレイヤーにフラット化      |
| **リンクを削除**           | ハイパーリンクとURL参照を削除                                |
| **構造ツリーを削除**       | アクセシビリティのタグ付けに使われるドキュメント構造を削除   |
| **MarkInfoを削除**         | マークされたコンテンツ情報を削除                             |
| **フォントを削除**         | 埋め込まれたフォントデータを削除（注意して使用してください） |

## 活用例

- 内部のメタデータ（作成者名、ソフトウェアのバージョン、編集履歴）を取り除いて、PDFを一般公開用に準備する
- 信頼できない送信元から受け取ったPDFを開く前に、JavaScriptを削除する
- 埋め込みコメントやフォームフィールド名を見せたくないクライアントにPDFを送る前に整理する
- 建築図面から隠れたレイヤーを取り除いてから、最終版を共有する
- プライバシー規制のデータ最小化の要件に準拠する

## ヒント

- PDFが正しく表示されることが確実でない限り、「フォントを削除」のチェックは外したままにしてください。フォントを削除すると、ビューアーによってはテキストが見えなくなることがあります。
- メタデータだけを取り除きたい場合は、専用のメタデータの削除ツールのほうが速く、目的に合っています。
- サニタイズは元に戻せません。元のファイルを保管してください。

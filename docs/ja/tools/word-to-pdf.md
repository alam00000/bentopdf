# WordからPDF

Microsoft Word文書と互換形式をPDFに変換します。このツールはブラウザベースのLibreOfficeエンジンを使用し、DOC、DOCX、ODT、RTFファイルを処理して、書式、表、画像、ヘッダー、フッター、スタイルを出力に維持します。

## 対応フォーマット

| フォーマット         | 拡張子  |
| :------------------- | :------ |
| Word(現行)           | `.docx` |
| Word(旧形式)         | `.doc`  |
| OpenDocumentテキスト | `.odt`  |
| リッチテキスト形式   | `.rtf`  |

## 使い方

1. アップロード領域をクリックするか、Word文書をドラッグ&ドロップします。複数のファイルを一度に選択できます。
2. ファイル一覧を確認して整理します。
3. **PDFに変換**をクリックします。LibreOfficeエンジンは初回の使用時に読み込まれ(進行状況インジケーターに初期化の状態が表示されます)、その後、各ファイルが変換されます。
4. 1ファイルの場合は、そのままPDFとしてダウンロードされます。複数ファイルの場合は、`word-converted.zip`にまとめられます。

## オプション

このツールに追加の設定はありません。LibreOfficeエンジンが、デフォルトのPDFエクスポートプロファイルで出力を生成します。

## 出力

| 入力数        | 出力                                                                |
| :------------ | :------------------------------------------------------------------ |
| 1ファイル     | 単一のPDFをダウンロード(元のファイル名に`.pdf`拡張子)               |
| 2ファイル以上 | ZIPアーカイブ(`word-converted.zip`)に、ファイルごとに1つのPDFを格納 |

## 活用例

- 就職応募の前に、履歴書やカバーレターをDOCXからPDFに変換する
- 顧客への納品用に、契約書や提案書のセットをまとめてPDFに変換する
- 旧形式の`.doc`ファイルを、長期保管用の最新のPDFに変換する
- Google Docsで共同編集した文書(DOCXとしてエクスポート)をPDFに変換する
- 自動文書生成で使われるWordテンプレートから、印刷用のPDFを作成する

## ヒント

- LibreOfficeエンジンはセッションごとに1回ダウンロードされ、キャッシュされます。最初の変換では数秒の読み込み時間がかかりますが、以降の変換ははるかに速くなります。
- 複雑な書式(マクロ、ActiveXコントロール、高度なSmartArt)は、完全には変換されない場合があります。テキスト、表、画像、ヘッダー、脚注といった標準的な文書要素は、確実に変換されます。
- このツールはODTとRTFにも対応しているため、あらゆるワープロ形式をまとめて変換できるツールとして使えます。

# WebPからPDF

GoogleのWebP画像形式をPDFに変換します。Webからダウンロードした画像がWebP形式で、印刷や共有のためにより広く対応された形式が必要な場合に特に便利です。

## 対応フォーマット

| フォーマット | 拡張子  |
| :----------- | :------ |
| WebP         | `.webp` |

## 使い方

1. アップロード領域をクリックするか、WebPファイルをドラッグ&ドロップします。
2. ファイル一覧を確認し、不要なファイルを削除します。
3. **PDFの品質**のレベルを選択します。
4. **PDFに変換**をクリックします。出力は`from_webps.pdf`としてダウンロードされます。

内部では、各WebP画像がブラウザのcanvas APIでデコードされ、pdf-libを使ってPDFに埋め込まれます。そのため、WebPのデコードに対応しているブラウザ(最近のブラウザはすべて対応)であれば変換できます。

## オプション

**PDFの品質**は、画像を埋め込む際の圧縮を制御します。

- **高画質（ファイルサイズ大）**: 最も多くの細部を維持します。
- **中画質（バランス）**(デフォルト): バランスの取れた出力です。
- **低画質（ファイルサイズ小）**: ファイルサイズが最小になります。

## 活用例

- Webからダウンロードして保存したWebP画像を、印刷可能なPDFに変換する
- ChromeやEdgeで撮影したWebPのスクリーンショットをドキュメントにまとめる
- WebPが既定のデザインツールから書き出した画像で、PDFポートフォリオを作成する
- WebP画像を、より広く読める形式で保管する

## ヒント

- WebPはPDFに埋め込む前に内部でPNGにデコードされるため、ロスレスのWebP画像はHigh設定で品質が維持されます。
- WebPとほかの画像形式が混在している場合は、代わりに[画像からPDF](./image-to-pdf)ツールを使用してください。すべてをまとめて受け付けます。

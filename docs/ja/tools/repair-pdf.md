# PDFの修復

PDFが開かない、内容が文字化けする、ビューアーでエラーが出るといったときに、このツールが内部構造の再構築を試みます。QPDFの修復エンジンを使用しており、壊れた相互参照テーブル、途切れたストリーム、無効なオブジェクト参照など、さまざまな種類の破損からデータを復元できます。

## 使い方

1. 損傷した1つ以上のPDFファイルをアップロードします。
2. **PDFを修復**をクリックします。
3. ファイルが1つの場合は、修復されたファイルが直接ダウンロードされます。複数の場合はZIPアーカイブになります。

このツールは、各ファイルを`--decrypt`フラグ付きでQPDFに通します。これにより、QPDFはPDF構造全体を読み込んで書き直し、その過程で修復可能な問題を修正します。

## 機能

- 複数のPDFを1回の操作でまとめて修復
- 復元可能なファイルと不可能なファイルを自動判別
- 複数のファイルを処理するとき、ファイルごとに成功/失敗を報告
- 実績のあるPDF変換ライブラリであるQPDF（WebAssembly）を使用

## 修復できるもの

- 壊れた、または欠けている相互参照テーブル
- ダウンロードが中断されたことによるファイル末尾の欠落
- 無効なオブジェクト番号とストリーム長
- 不具合のあるPDFジェネレーターによる軽微な構造の不整合
- 復号化に失敗したことで生じた暗号化の残骸

## 修復できないもの

- 内容データのほとんどが失われた、大きく途切れたファイル
- 持っていないパスワードで暗号化されたPDF
- 実際にはPDFではないファイル（拡張子が間違っている）
- PDF内の画像の破損（構造は修復されますが、ピクセルデータは再生成されません）

## 活用例

- メールのダウンロードに失敗したPDFを復元する
- 古い、または標準に沿わないPDFジェネレーターで作成されたファイルを開く
- あるビューアーでは開けるが、別のビューアーでは開けないPDFを修正する
- 損傷したアーカイブ文書を長期保存用に準備する

## ヒント

- 修復に失敗した場合は、まずブラウザでファイルを開いてみてください。ブラウザには独自の復元ロジックがあり、再保存できる程度に内容を表示できることがあります。
- 修復に失敗する暗号化されたPDFは、まずPDFの復号化を試し、その後で復号化した出力を修復してください。

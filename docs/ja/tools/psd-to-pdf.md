# PSDからPDF

Adobe PhotoshopのPSDファイルをPDFドキュメントに変換します。PSDはPhotoshopのネイティブ形式で、通常は高価なAdobeソフトウェアがないと開けません。このツールは、PSDファイルの統合済みの合成画像を、フル解像度のPDFページとして描画します。

## 対応フォーマット

| フォーマット    | 拡張子 | 備考                           |
| :-------------- | :----- | :----------------------------- |
| Adobe Photoshop | `.psd` | 統合済みの合成画像を描画します |

## 使い方

1. アップロード領域をクリックするか、PSDファイルをドラッグアンドドロップします。複数のファイルに対応しています。
2. ファイル一覧を確認します。不要なファイルはゴミ箱アイコンで削除するか、**ファイルを追加**でさらに追加します。
3. **PDFに変換**をクリックします。PyMuPDFエンジンがPSDファイルを読み込み、合成画像を元の解像度でPDFのページに埋め込みます。
4. PSDが1つの場合はPDFが1つ生成されます。複数のPSDファイルをアップロードした場合は、`psd_to_pdf.pdf`という名前の1つの複数ページPDFにまとめられ、各PSDが1ページになります。

## オプション

設定は不要です。コンバーターはPSDファイルの統合済み画像データを使用します。

## 活用例

- Photoshopを開かずにデザインをプレビューする
- Adobe Creative Suiteを持っていないクライアントにデザインの校正を送る
- PSDファイルの高解像度アートワークを印刷する
- 複数のPSDデザインファイルからPDFポートフォリオを作成する（それぞれが1つのドキュメント内の1ページになります）

## ヒント

- 変換では、PSDの合成（統合済み）ビューが描画されます。個々のレイヤー、調整レイヤー、レイヤー効果は、PDFの中で別々の要素としては保持されません。
- 複数のPSDファイルは、個別のPDFではなく1つの複数ページPDFに結合されます。ポートフォリオやルックブックの作成に便利です。
- 解像度が非常に高いPSDファイル（300 DPI以上の印刷用ファイル）は、大きなPDFになります。このツールはフル解像度を保持します。

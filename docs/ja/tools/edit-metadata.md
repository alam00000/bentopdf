# メタデータの編集

PDFファイルに埋め込まれたメタデータを編集します。ツールは、文書の既存のメタデータをフォームにあらかじめ入力し、任意のフィールドを変更でき、変更を新しいPDFに保存します。

## 使い方

1. PDFファイルをアップロードします。ツールが現在のメタデータを読み取り、フォームに入力します。
2. 標準フィールド（タイトル、作成者、サブジェクト、キーワード、作成アプリケーション、PDF変換）を編集します。
3. 日時ピッカーで、作成日と更新日を調整します。
4. 追加ボタンをクリックし、キーと値のペアを入力して、カスタムメタデータフィールドを追加します。
5. 処理ボタンをクリックして、変更したPDFを保存します。

## 機能

- アップロードしたPDFの既存のメタデータをすべて自動入力
- 標準フィールド：タイトル、作成者、サブジェクト、キーワード、作成アプリケーション、PDF変換
- 作成日と更新日の日時ピッカー
- 任意のプロパティのための、キーと値によるカスタムメタデータフィールド
- 変更をPDFの文書情報辞書に直接保存

## 編集できるフィールド

| フィールド               | 説明                                       |
| ------------------------ | ------------------------------------------ |
| **タイトル**             | PDFリーダーに表示される文書のタイトル      |
| **作成者**               | 文書を作成した個人または組織               |
| **サブジェクト**         | 文書のトピックの簡単な説明                 |
| **キーワード**           | 検索や分類のための、カンマ区切りの用語     |
| **作成アプリケーション** | コンテンツを最初に作成したアプリケーション |
| **PDF変換**              | PDFを生成したアプリケーション              |
| **作成日**               | 文書が最初に作成された日時                 |
| **更新日**               | 文書が最後に変更された日時                 |
| **カスタムフィールド**   | 独自に定義する追加のキーと値のペア         |

## 活用例

- 文書を公開する前に、適切なタイトルと作成者を設定する
- 文書管理システムでの検索性を高めるために、キーワードを追加する
- 現在の改訂を反映するように、更新日を更新する
- 部署、プロジェクトID、分類などのカスタムメタデータフィールドを追加する
- 元の作成ソフトが残したメタデータを整理する

## ヒント

- カスタムフィールドは、PDFの情報辞書に直接書き込まれます。一部のPDFリーダーではカスタムフィールドが表示されないことがありますが、ファイルには保持されます。
- フィールドを空欄にすると、メタデータから消去されます。処理ボタンは、フォームに入っている内容をそのまま保存します。
- 編集せずにメタデータを表示するには、[メタデータの表示](./view-metadata) を使ってください。メタデータをすべて削除するには、メタデータの削除を使います。

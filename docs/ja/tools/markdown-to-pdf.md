# マークダウンからPDF

ライブプレビューとワンクリックのPDF書き出しを備えた、高機能なMarkdownエディターです。ゼロから書く、既存の`.md`ファイルをアップロードする、クリップボードから貼り付けるのいずれも可能です。エディターはMarkdownをリアルタイムでレンダリングし、ブラウザー内蔵の印刷エンジンでスタイル付きのPDFを書き出します。

## 対応フォーマット

| 入力          | 説明                               |
| :------------ | :--------------------------------- |
| `.md`ファイル | アップロードボタンからアップロード |
| 直接入力      | エディターに入力または貼り付け     |

## 使い方

1. マークダウンからPDFツールを開きます。エディターは分割ビューで読み込まれ、左にMarkdownのソース、右にレンダリングされたプレビューが表示されます。
2. Markdownを書くか貼り付けるか、**アップロード**をクリックして`.md`ファイルを読み込みます。
3. ツールバーのテーマスライダーで、ライトテーマとダークテーマを切り替えます。
4. **PDFを書き出し**をクリックするか`Ctrl/Cmd + S`を押すと、ブラウザーの印刷ダイアログ経由でPDFが生成されます。

## 機能

このエディターは、基本を超えた豊富なMarkdown機能に対応しています。

- **標準のMarkdown**: 見出し、太字、斜体、リンク、画像、リスト、引用、水平線
- 15以上の言語（JavaScript、TypeScript、Python、Go、Rust、SQL、Java、C#、C++、YAML、Bashなど）に対応した、シンタックスハイライト付きの**コードブロック**
- **Mermaid図**: フローチャート、シーケンス図、ER図などのMermaidチャートがプレビュー上で直接表示されます
- 標準のMarkdown記法による**表**
- チェックボックス付きの**タスクリスト**
- **脚注**、**下付き文字**、**上付き文字**
- **定義リスト**、**略語**
- **絵文字**に対応（`:smile:`が絵文字として表示されます）
- **ハイライト**（`==marked text==`）と**挿入**（`++inserted text++`）
- **URLの自動リンク化**: プレーンなURLがクリック可能なリンクに変換されます
- **目次**の生成
- 見出しへの**アンカーリンク**

## 活用例

- プロジェクトのドキュメントを書き、関係者向けに整ったPDFとして書き出す
- コードサンプルやMermaidのアーキテクチャ図を含む技術レポートを作る
- GitHubのREADMEを、オフラインでの閲覧や印刷用にPDFへ変換する
- タスクリストや表を使って、提案書や仕様書の下書きを作る
- Markdownで書いた講義ノートから、スタイル付きの配布資料を作る

## ヒント

- PDFの出力にはブラウザーの「PDFに印刷」機能を使います。Chromeでは、保存前に印刷ダイアログで余白や拡大率を調整できます。
- Mermaid図はプレビューに表示されますが、初回は初期化に少し時間がかかる場合があります。
- ボタンに手を伸ばさず書き出すには、キーボードショートカットの`Ctrl/Cmd + S`を使ってください。

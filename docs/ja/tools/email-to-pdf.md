# 電子メールからPDF

保存したメールファイルを、すっきりした印刷可能なPDFに変換します。このツールはEMLとMSGのファイルを解析し、ヘッダー、本文、添付ファイルのメタデータを含むメッセージ全体を取り出して、構造化されたPDFに描画します。法的な証拠開示、記録の保管、あるいは大事なメールを印刷したいときに役立ちます。

## 対応形式

| 形式 | 拡張子 | 備考                                                                     |
| :--- | :----- | :----------------------------------------------------------------------- |
| EML  | `.eml` | 標準的なMIME形式のメール（ほとんどのメールクライアントからエクスポート） |
| MSG  | `.msg` | Microsoft Outlookの独自形式                                              |

## 使い方

1. アップロード領域をクリックするか、EMLまたはMSGファイルをドラッグ&ドロップします。両方の形式を1回のバッチに混在させることもできます。
2. ファイル一覧を確認します。不要な項目はゴミ箱アイコンで削除するか、**ファイルを追加** をクリックして、さらにメールを追加します。
3. 変換オプションを設定します（下記参照）。
4. **PDFに変換** をクリックします。ツールは各メールを解析し、内容をスタイル付きHTMLとして描画して、PyMuPDFエンジンでPDFに変換します。
5. 1通のメールの場合は、PDFとして直接ダウンロードされます。複数のメールの場合は `emails-converted.zip` にまとめられます。

## オプション

| オプション                   | デフォルト | 説明                                                                                    |
| :--------------------------- | :--------- | :-------------------------------------------------------------------------------------- |
| **ページサイズ**             | A4         | A4、Letter、Legalのページ寸法から選択します。                                           |
| **CCとBCCを含める**          | オン       | 有効にすると、CCとBCCの宛先リストが、PDFのメールヘッダー部分に表示されます。            |
| **添付ファイル一覧を含める** | オン       | 有効にすると、メールのファイル添付の一覧（ファイル名とサイズ付き）がPDFに表示されます。 |

## 活用例

- コンプライアンスや監査のために、重要なビジネス上のやり取りをPDFとして保管する
- 法的手続きや証拠開示の要求のために、メールのスレッドを印刷する
- メールで受け取った注文確認、領収書、契約書の恒久的な記録を作成する
- Outlookがなくても読める形式で、OutlookのMSGファイルをバックアップする
- エクスポートしたEMLファイルから、カスタマーサポートのやり取りを記録する

## ヒント

- EML（Thunderbird、Apple Mail、ほとんどのメールクライアントで使われます）とOutlookのMSGファイルの両方に対応しています。メールクライアントからメールをエクスポートして、そのままツールにドロップしてください。
- HTML形式のメールは、PDFでもスタイルが保たれます。プレーンテキストのメールは、すっきりした読みやすい書式で描画されます。
- 添付ファイルの一覧にはファイル名とサイズが表示されますが、実際の添付ファイルがPDFに埋め込まれることはありません。

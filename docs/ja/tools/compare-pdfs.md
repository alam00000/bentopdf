# PDFの比較

2つのPDFをアップロードすると、その間で何が変わったのかが正確にわかります。このツールはページを賢く対応付け、テキスト、画像、注釈、ヘッダー、書式の違いを検出して、並べて表示またはオーバーレイ表示で示します。

## 使い方

1. 2つのPDFファイルをアップロードします。元のファイル（左）と改訂版（右）です。
2. ツールが、内容のシグネチャを使って文書間のページを対応付けます。
3. 表示モードを選びます。**並べて表示** または **オーバーレイ** です。
4. ページネーションのコントロールで、ページの組を移動します。
5. 違いはハイライトされ、分類されます。フィルターパネルを使って、特定の変更タイプに絞り込めます。
6. 必要に応じて、比較結果をPDFレポートとしてエクスポートします。

## 機能

- 内容の類似度に基づく自動ページ対応付け
- 並べて表示とオーバーレイの比較ビュー
- 変更の分類：テキスト、画像、ヘッダー/フッター、注釈、書式、背景
- カテゴリごとのフィルター切り替えで、特定の変更タイプを表示または非表示
- クエリで絞り込めるテキスト変更の検索
- スキャン文書を比較するためのOCR対応
- 詳細確認用のズーム操作
- 並べて表示モードでのパネル間の同期スクロール
- 比較結果をPDFとしてエクスポート

## オプション

| オプション             | 説明                                                                        |
| ---------------------- | --------------------------------------------------------------------------- |
| **表示モード**         | 並べて表示またはオーバーレイ                                                |
| **OCR**                | スキャン文書の比較用にOCRを有効/無効にする                                  |
| **OCR言語**            | OCRによるテキスト抽出の言語                                                 |
| **カテゴリフィルター** | テキスト、画像、ヘッダー/フッター、注釈、書式、背景の変更の表示を切り替える |
| **変更の範囲**         | オーバーレイモードで、すべての変更とコンテンツのみを切り替える              |
| **ズーム**             | 詳細確認のための拡大率を調整する                                            |

## 活用例

- 契約書の改訂版を確認し、版の間で何が変わったかを正確に見つける
- デザインのモックアップを比較し、PDFへのエクスポート結果が期待どおりか確認する
- すべての編集を追跡する必要がある規制対象の業界で、文書の変更を監査する
- PDFの変換処理で、元の内容が正確に保たれたかを検証する
- 翻訳文書を原文と照らし合わせ、レイアウトの変化を確認する

## ヒント

- オーバーレイ表示は、2つの文書を重ねて表示するため、位置のずれや画像のサイズ変更といった空間的な違いがすぐにわかります。
- テキストレイヤーのないスキャン文書を比較するときは、OCRを有効にしてください。比較エンジンがページ画像からテキストを抽出します。
- カテゴリフィルターで重要なものに集中しましょう。たとえば、テキスト内容の違いだけが気になるときは、書式の変更を非表示にします。

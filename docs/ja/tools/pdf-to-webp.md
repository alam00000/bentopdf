# PDFからWebP

PDFの各ページをWebP画像に変換します。WebPは、同じ体感品質でJPGより25〜35%小さいファイルになるのが一般的で、Web用途に適しています。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、PDFをアップロードします。
2. **品質**スライダーを調整します。
3. **変換**をクリックしてファイルを処理します。
4. 1つの`.webp`ファイル、またはZIPアーカイブが自動的にダウンロードされます。

## オプション

- **品質**: 0%から100% (デフォルトは85%) のスライダー。非可逆圧縮のレベルを制御します。値を高くすると、より多くのディテールが保持されます。

ページは内部で2倍スケールでレンダリングされ、PDF本来の寸法のおよそ2倍の画像になります。

## 出力形式

- **1ページ**: `filename.webp`
- **複数ページ**: `filename_webps.zip`。`page_1.webp`、`page_2.webp`などを含みます。

## ユースケース

- 帯域幅が重要なWebサイト向けに、ページのプレビューを準備する。
- ソーシャルメディア向けに、チラシやパンフレットの軽量な画像版を生成する。
- 複数ページの文書を、Web向けに最適化した画像セットに一括変換する。

## ヒント

- WebPはすべてのモダンブラウザでサポートされています。古い環境との互換性が必要な場合は、[PDFからJPG](./pdf-to-jpg)を使ってください。
- 品質80〜85%なら、画面上では通常元の画像と見分けがつかず、ファイルサイズも小さく保てます。

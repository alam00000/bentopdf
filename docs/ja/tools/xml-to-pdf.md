# XMLからPDF

XMLデータファイルを、読みやすく構造化されたPDF文書に変換します。生のXMLは強力ですが、人間には読みにくいものです。このツールはXMLツリーを解析し、繰り返されるデータ構造を見つけて、横向きのA4 PDFに整形された表とセクションとしてレンダリングします。

## 対応フォーマット

| フォーマット | 拡張子 | 備考                          |
| :----------- | :----- | :---------------------------- |
| XML          | `.xml` | 整形式のXML文書であれば何でも |

## 使い方

1. アップロード領域をクリックするか、XMLファイルをドラッグ&ドロップします。複数のファイルを1つのバッチで処理できます。
2. ファイル一覧を確認します。不要なファイルはゴミ箱アイコンで削除するか、**さらにファイルを追加する**をクリックしてファイルを追加します。
3. **PDFに変換**をクリックします。ツールはブラウザ組み込みのDOMParserでXML構造を解析し、データ階層を分析して、jsPDFのauto-table書式でPDFにレンダリングします。
4. 1ファイルの場合は、PDFとしてダウンロードされます。複数の変換結果は`xml-to-pdf.zip`にまとめられます。

## オプション

手動の設定は不要です。コンバーターはXML構造を自動的に検出し、適切な表のレイアウトを選択します。出力は、横幅の広いデータセットに対応するため、横向きのA4になります。

## 活用例

- データベースやAPIから書き出したXMLデータを、印刷可能なレポートにする
- XML設定ファイルから、読みやすい概要を作成する
- XMLベースの請求書や取引ログを、記録保管用のPDFに変換する
- XMLサイトマップやRSSフィードを、文書の形で読みやすくする

## ヒント

- XMLは整形式である必要があります。パーサーが構文エラーを検出した場合、問題箇所を示す具体的なエラーメッセージとともに変換が失敗します。
- 深くネストされたXML構造は、表に平坦化されます。最良の結果を得るには、データに、一貫した子要素を持つ繰り返しの兄弟要素が含まれているようにしてください。
- 変換中は、読み込み、解析、分析、レンダリングという各段階を示す進行状況が表示されます。

# 添付ファイルの抽出

1つ以上のPDFファイルから、埋め込まれたすべての添付ファイルを取り出します。抽出されたファイルは、ダウンロード用に1つのZIPアーカイブにまとめられます。

## 使い方

1. 埋め込まれた添付ファイルを含む、1つ以上のPDFファイルをアップロードします。
2. **添付ファイルを抽出** をクリックします。
3. ツールが、各PDFの文書レベルとページレベルの添付ファイルをスキャンします。
4. 見つかったすべてのファイルがZIPアーカイブにまとめられ、自動的にダウンロードされます。
5. ステータスメッセージで、見つかった添付ファイルの数と合計サイズを確認できます。

## 機能

- 複数のPDFからの一括抽出
- 文書レベルとページレベルの両方の添付ファイルを抽出
- 抽出したすべてのファイルを含む、1つのZIPファイルを出力
- 添付ファイルの合計数と合計ファイルサイズを表示
- 添付ファイルが見つからない場合は、わかりやすいステータスメッセージを表示

## 活用例

- レポートのPDFに埋め込まれたデータファイルを復元する
- ポートフォリオや仕様書から、画像素材を取り出す
- 研修やコンプライアンス用のPDFから、補足資料を抽出する
- 一連のPDFにどのファイルが埋め込まれているかを監査する

## ヒント

- ツールが添付ファイルなしと報告した場合、PDFには、ファイル添付ではなく、埋め込み画像やフォームデータが含まれている可能性があります。それらはファイル添付ではありません。埋め込み画像には [画像の抽出](./extract-images) を使ってください。
- 複数のPDFを処理すると、すべてのファイルの添付ファイルが1つのZIPにまとめられます。ファイル名は、元の埋め込み時のものが保持されます。

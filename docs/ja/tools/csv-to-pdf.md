# CSVからPDF

CSVファイルを、すっきりとした書式のPDF文書に変換します。各CSVは解析され、出力PDFの中で表として描画されます。受け取る人が表計算ソフトを持っていなくても、表形式のデータを印刷したり共有したりしたいときに便利です。

## 対応形式

| 形式 | 拡張子 |
| :--- | :----- |
| CSV  | `.csv` |

## 使い方

1. アップロード領域をクリックするか、1つ以上のCSVファイルをドラッグ&ドロップします。
2. ファイル一覧を確認します。ファイルを追加したり、不要なものを削除したりできます。
3. **PDFに変換** をクリックします。進行状況インジケーターが変換の状態を示します。
4. 1ファイルの場合は、PDFとして直接ダウンロードされます。複数ファイルの場合は `csv-converted.zip` にまとめられます。

## オプション

このツールに追加の設定はありません。CSVは自動的に解析され、表として整形されます。

## 出力

| 入力数        | 出力                                                                 |
| :------------ | :------------------------------------------------------------------- |
| 1ファイル     | 単一のPDFをダウンロード（例: `data.pdf`）                            |
| 2ファイル以上 | ZIPアーカイブ（`csv-converted.zip`）に、ファイルごとに1つのPDFを格納 |

## 活用例

- エクスポートしたデータベースのレポートを、印刷できるPDFの表に変換する
- Excelを持っていない人に、財務データや在庫リストを共有する
- コンプライアンス文書用に、CSVのログファイルのPDF版を作成する
- CSVで保存されている住所録、成績表、その他の表形式データを印刷する

## ヒント

- 最良の結果を得るには、CSVが標準的なカンマ区切りであることを確認してください。ツールは一般的なCSVの解析規則に従います。
- CSVの列が多い場合、表はページの幅に収まるように圧縮されることがあります。幅の広いデータセットは、複数のファイルに分割することを検討してください。
- Excelファイル（`.xls`、`.xlsx`）には、表計算の書式や複数のシートを保持する [ExcelからPDF](./excel-to-pdf) ツールを使ってください。

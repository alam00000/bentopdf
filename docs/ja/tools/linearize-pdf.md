# PDFの線形化

線形化はPDFの構造を組み替えて、ファイル全体のダウンロードが終わる前に最初のページを表示できるようにします。Adobeはこれを「Fast Web View」と呼んでいます。PDFをWebサイトで公開したり、ドキュメントポータルで提供したりしている場合、線形化すると開くときの体感速度が大きく向上します。

## 使い方

1. 1つ以上のPDFファイルをアップロードします。
2. **PDFを線形化**をクリックします。
3. すべての線形化済みファイルを含むZIPアーカイブとして、結果をダウンロードします。

設定項目はありません。このツールはQPDFの`--linearize`フラグを使い、見た目の内容を変えずにPDFの内部構造を並べ替えます。

## 線形化で行われること

- 最初のページのデータがファイルの先頭に来るよう、PDFオブジェクトを並べ替える
- ビューアーが各ページの場所を把握できるよう、線形化ディクショナリとヒントテーブルを追加する
- バイトレンジリクエストを有効にし、ブラウザーがファイル全体をダウンロードせずに最初のページだけを取得できるようにする
- ランダムアクセスを効率化するため、相互参照テーブルを整理する

## 機能

- 複数のPDFを1回の操作でバッチ処理
- 出力はすべてのコンテンツ、フォント、画像、インタラクティブ要素を保持
- 確実で標準に準拠した線形化のためにQPDF（WebAssembly）を使用
- 結果は簡単にダウンロードできるようZIPにまとめられる

## 活用例

- ユーザーが即座にページ表示されることを期待するWebサイトで、PDFレポートを公開する
- ブラウザー内ビューアーを備えたWebアプリケーションにPDFを埋め込む
- 低速なモバイル回線でアクセスされるPDFのカタログやマニュアルを公開する
- バイトレンジ配信に対応したコンテンツ配信ネットワーク（CDN）向けに文書を準備する

## ヒント

- 線形化は、ほかの編集がすべて終わってから行ってください。その後に変更（結合やページの追加など）を加えると、線形化が解除されます。
- 「PDFの圧縮」と組み合わせると、最小で最速に読み込めるPDFになります。
- 線形化によってファイルサイズがわずかに増えます（通常は1%未満）。

# EPUBからPDF

EPUBの電子書籍を、ブラウザから離れることなくPDFファイルに変換します。EPUBはデジタル書籍のオープンスタンダードですが、印刷、注釈の追加、電子書籍リーダーを持っていない人との共有のために、レイアウト固定のPDFが必要になることがあります。

## 対応形式

| 形式 | 拡張子  | 備考                     |
| :--- | :------ | :----------------------- |
| EPUB | `.epub` | EPUB 2とEPUB 3のファイル |

## 使い方

1. アップロード領域をクリックするか、EPUBファイルをドラッグ&ドロップします。複数選択に対応しています。
2. アップロードしたファイルを確認します。不要な項目はゴミ箱アイコンで削除するか、**ファイルを追加** をクリックして、バッチを広げます。
3. **PDFに変換** をクリックします。PyMuPDFエンジンが、EPUBの内容（テキスト、画像、書式）をページ分割されたPDF出力に描画します。
4. 1つのEPUBの場合は、PDFとして直接ダウンロードされます。複数ファイルの場合は、`epub-converted.zip` という名前のZIPアーカイブにまとめられます。

## オプション

変換は妥当なデフォルト設定で実行され、必須の設定はありません。テキストは標準のページ寸法に再配置され、埋め込みフォントと画像はPDFに引き継がれます。

## 活用例

- DRMフリーの電子書籍を印刷して、画面から離れて読む
- EPUBの原稿を、レビュー用にレイアウト固定のPDFとして提出する
- デジタル書籍を、どのOSでも標準で開ける形式でアーカイブする
- EPUBリーダーを持っていない同僚に、1つの章を共有する
- EPUBで配布されている技術文書を、注釈を付けられるPDFに変換する

## ヒント

- 埋め込み音声や動画といったEPUB 3の機能はPDFに引き継がれませんが、テキスト、画像、表はすべてきれいに変換されます。
- スタイルが多用されたEPUBで最良の結果を得るには、出力の最初の数ページを確認して、レイアウトが忠実か確かめてください。

# PDFからExcel

PDFから表を抽出し、Excel (`.xlsx`) スプレッドシートとして保存します。検出された各表は、表番号と元のページが付いた専用のワークシートに配置されます。表の検出にはPyMuPDF、Excelの生成にはSheetJSライブラリを使用しています。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、PDFをアップロードします。
2. **変換**をクリックして表の抽出を開始します。
3. ツールがすべてのページから表をスキャンし、Excelブックを作成します。
4. 表ごとに1シートを持つ`.xlsx`ファイルがダウンロードされます。

## オプション

このツールに設定可能なオプションはありません。検出されたすべての表が自動的に抽出されます。

## 出力形式

- 単一の`filename.xlsx`ファイル。
- **表が1つの場合**: 「Table」という名前のワークシートが1つ。
- **表が複数の場合**: 「Table 1 (Page 3)」、「Table 2 (Page 5)」などの名前のワークシート。シート名はExcelの上限である31文字に切り詰められます。

## ユースケース

- PDFの財務レポートを、さらに分析するための編集可能なスプレッドシートに変換する。
- 仕入先のPDFから在庫表や注文表を抽出する。
- PDFのフォームやカタログの構造化データをExcelに取り込み、並べ替えやフィルターを行う。
- 表形式のPDFデータを、専門外の同僚でも扱える形式で保管する。

## ヒント

- ツールが「表が見つかりません」と報告する場合、そのPDFは構造化された表ではなく、自由なテキストレイアウトを使っている可能性があります。代わりに[PDFからテキスト](./pdf-to-text)で生のコンテンツを取得してみてください。
- よりシンプルなフラット形式には[PDFからCSV](./pdf-to-csv)を使ってください。表ごとに複数の形式でダウンロードしたい場合は、[PDFテーブルの抽出](./extract-tables)を使ってください。
- シート名を確認すると、各表がどのページのものか分かります。

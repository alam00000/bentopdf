# PDFからSVG

PDFの各ページをSVG (Scalable Vector Graphics) ファイルに変換します。ラスター形式と違い、SVGはベクターパス、テキスト、図形を保持するため、出力はピクセル化せずに任意のサイズへ拡大できます。PyMuPDFを使用しています。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、1つ以上のPDFをアップロードします。複数のファイルを追加し、個別に管理できます。
2. **変換**をクリックして、アップロードしたすべてのファイルを処理します。
3. 1ファイル1ページの変換は、単独の`.svg`としてダウンロードされます。それ以外はZIPアーカイブとしてダウンロードされます。

## オプション

このツールに設定可能なオプションはありません。各ページは、PyMuPDFのネイティブなベクターエクスポートでSVGに変換されます。

## 出力形式

- **単一ファイル、単一ページ**: `filename.svg`
- **単一ファイル、複数ページ**: `filename_svg.zip`。`page_1.svg`、`page_2.svg`などを含みます。
- **複数ファイル**: 元の文書名ごとに整理されたファイルを含む`pdf_to_svg.zip`。

## ユースケース

- PDFレポートからベクターの図、グラフ、イラストを抽出し、Webページで使う。
- InkscapeやIllustratorなどのベクターエディターで、PDFページの内容を編集する。
- レスポンシブなWebアプリケーションに、拡大縮小できるページプレビューを埋め込む。
- PDFのパンフレットから、輪郭を保ったままロゴやグラフィックを抽出する。

## ヒント

- SVGは、ベクターコンテンツを含むPDFで最も効果を発揮します。スキャンした文書や画像の多いPDFは、ラスターデータが埋め込まれた大きなSVGファイルになります。
- 画像の多いPDFをラスター形式で出力するには、代わりに[PDFからPNG](./pdf-to-png)または[PDFからJPG](./pdf-to-jpg)を使ってください。
- このツールは一括変換に対応しています。複数のPDFを一度にアップロードして、1回の実行ですべて変換できます。

# N-Up PDF

複数のページを、グリッド状に1枚のシートに配置します。1枚に2、4、6、8、9、16ページを収めることで、印刷枚数を減らせます。拡大縮小、配置、必要に応じたページサイズの設定は、ツールが処理します。

## 使い方

1. PDFファイルをアップロードします。
2. 1枚あたりのページ数（「N」の値）を選びます: 2、4、6、8、9、16。
3. 出力するページサイズ（初期値はA4）と向きを選びます。
4. 必要に応じて、間隔、枠線の色、背景色を設定します。
5. 処理ボタンをクリックします。ツールが各ページを拡大縮小し、新しいシートに並べます。

## 機能

- グリッドレイアウト: 2-up、4-up、6-up、8-up、9-up、16-up
- 出力ページサイズと向きを設定可能
- 並べたページ間の間隔を任意で設定可能
- 背景色と枠線の色の設定
- 元のページの縦横比を保ったまま、収まるように拡大縮小

## オプション

| オプション              | 説明                                                   |
| ----------------------- | ------------------------------------------------------ |
| **1枚あたりのページ数** | 出力ページ1枚に収める元のページ数（2、4、6、8、9、16） |
| **ページサイズ**        | 出力シートのサイズ（A4、Letter、Legalなど）            |
| **向き**                | 出力シートの縦または横                                 |
| **間隔**                | 並べたページ間のすき間（ポイント単位）                 |
| **背景色**              | 出力シートの背景の塗りつぶし色                         |
| **枠線の色**            | 並べた各ページの周囲の枠線の色                         |

## 活用例

- 紙を節約するため、1ページにスライド4枚を載せた配布資料を印刷する
- 複数の参考ページを1枚にまとめた学習用シートを作る
- ファイリング用に、コンパクトな文書アーカイブを作る
- 長い文書のサムネイル一覧シートを作る

## ヒント

- 2-upのレイアウトには横向きが適していることが多く、4-up以上では通常は縦向きが最適です。
- 間隔を広げると読みやすくなりますが、並べた各ページに使える面積が小さくなります。
- 逆の操作（1ページを複数に分割する）については、[PDFのポスタライズ](./posterize-pdf)をご覧ください。

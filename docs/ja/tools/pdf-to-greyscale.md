# PDFのグレースケール化

カラーのPDFをグレースケール版に変換します。各ページはレンダリングされ、彩度を落とした後、JPEG画像として新しいPDFに再埋め込みされます。出力は元のページ寸法を保持します。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、PDFをアップロードします。
2. **変換**をクリックしてファイルを処理します。
3. すべてのページが白黒に変換された新しい`greyscale.pdf`がダウンロードされます。

内部的には、各ページが2倍スケールでレンダリングされ、ピクセルデータにグレースケールフィルターが適用され、品質90%のJPEGとして再エンコードされて、新しいPDF文書に配置されます。

## オプション

このツールに設定可能なオプションはありません。グレースケール変換には標準の輝度計算式を使い、JPEG品質は90%に固定されています。

## 出力形式

- すべてのページをグレースケールのJPEG画像として含む、単一の`greyscale.pdf`ファイル。

## ユースケース

- カラーインクのコストを節約するため、白黒印刷用に文書を準備する。
- グレースケールを義務付ける法的または行政の提出要件を満たす。
- カラーが多いPDFのファイルサイズを減らす (グレースケールのJPEG画像はカラーより小さくなります)。
- カラーと白黒のページが混在する文書で、見た目を統一する。

## ヒント

- 各ページがラスタライズされJPEGとして再埋め込みされるため、出力は画像ベースになります。元のPDFのテキストは選択も検索もできなくなります。後で検索可能なテキストが必要な場合は、出力をOCRツールにかけてください。
- 明るさ、コントラスト、彩度などの色調整をより細かく行いたい場合は、色の調整ツールや、[PDFワークフロービルダー](./pdf-workflow)のグレースケールノードをご覧ください。

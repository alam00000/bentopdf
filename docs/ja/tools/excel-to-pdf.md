# ExcelからPDF

表計算ファイルをPDFに変換します。このツールは、最新のExcelファイル、従来のXLS形式、OpenDocumentスプレッドシート、さらにCSVにも対応しており、そのすべてがブラウザ上のLibreOfficeエンジンで描画されるため、セルの書式、数式（計算された値として）、グラフ、複数シートのレイアウトが保たれます。

## 対応形式

| 形式                         | 拡張子  |
| :--------------------------- | :------ |
| Excel（最新）                | `.xlsx` |
| Excel（従来）                | `.xls`  |
| OpenDocumentスプレッドシート | `.ods`  |
| CSV                          | `.csv`  |

## 使い方

1. アップロード領域をクリックするか、表計算ファイルをドラッグ&ドロップします。
2. ファイル一覧を確認します。ファイルを追加したり、不要なものを削除したりできます。
3. **PDFに変換** をクリックします。LibreOfficeエンジンは初回の使用時に初期化され、その後で各ファイルを処理します。
4. 1ファイルの場合は、PDFとして直接ダウンロードされます。複数ファイルの場合は `excel-converted.zip` として提供されます。

## オプション

このツールに追加の設定はありません。ページレイアウト、拡大縮小、印刷範囲は、スプレッドシートに組み込まれた設定に基づいて、LibreOfficeエンジンが決定します。

## 出力

| 入力数        | 出力                                                                   |
| :------------ | :--------------------------------------------------------------------- |
| 1ファイル     | 単一のPDFをダウンロード（元のファイル名に `.pdf` 拡張子）              |
| 2ファイル以上 | ZIPアーカイブ（`excel-converted.zip`）に、ファイルごとに1つのPDFを格納 |

## 活用例

- 配布用に、財務レポートや予算表をExcelからPDFに変換する
- 在庫表や商品カタログのスプレッドシートから、印刷用のPDFを作成する
- Excelがインストールされていない関係者に、データ分析の結果を共有する
- 四半期レポートを、編集できない形式でアーカイブする
- LibreOffice CalcのODSファイルをPDFに変換する

## ヒント

- スプレッドシートに埋め込まれたグラフはPDFに描画されます。変換する前に、元のファイルで正しく見えることを確認してください。
- スプレッドシートに複数のシートがある場合、すべてのシートがPDFの出力に含まれます。
- 書式のない単純なCSVデータには、[CSVからPDF](./csv-to-pdf) ツールのほうが軽量な変換になります。書式、グラフ、複数シートを保持したい場合は、ExcelからPDFを使ってください。

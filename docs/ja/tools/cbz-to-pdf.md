# CBZからPDF

コミックアーカイブファイルをPDFに変換します。CBZとCBRはデジタルコミックの標準形式で、実体は画像を詰め込んだZIPまたはRARアーカイブです。このツールは各ページを取り出し、読む順番を保ったまま、すべての画像を原寸大のページにしたすっきりしたPDFを作成します。

## 対応形式

| 形式 | 拡張子 | 備考                                                   |
| :--- | :----- | :----------------------------------------------------- |
| CBZ  | `.cbz` | ZIPベースのコミックアーカイブ（pdf-libでローカル処理） |
| CBR  | `.cbr` | RARベースのコミックアーカイブ（PyMuPDFエンジンで処理） |

CBZコンバーターは、アーカイブ内のJPEG、PNG、GIF、BMP、WebP、AVIF、TIFF、HEIC、JXL画像を認識します。標準外の形式は、埋め込む前に自動でPNGに変換されます。

## 使い方

1. アップロード領域をクリックするか、CBZまたはCBRファイルをドラッグ&ドロップします。両方の形式を1回のバッチに混在させることもできます。
2. 一覧に表示されたファイルを確認します。不要なものは削除し、**ファイルを追加** をクリックしてさらに追加できます。
3. **PDFに変換** をクリックします。CBZファイルの場合、ツールはアーカイブを展開し、画像ファイルを名前の自然順で並べ、各画像の実際の形式を判定して、pdf-libでPDFに埋め込みます。CBRファイルは代わりにPyMuPDFエンジンで処理されます。
4. 1ファイルの場合はPDFとしてダウンロードされます。複数ファイルの場合は `comic-converted.zip` という名前のZIPアーカイブになります。

## オプション

設定は不要です。各画像は元のサイズに合わせたページになるため、見開きは横長のまま、単ページは縦長のままになります。

## 活用例

- PDFには対応していてもCBZ/CBRには対応していないタブレットやスマートフォンのアプリでコミックを読む
- デジタルコミックの特定のページを印刷する
- コミックのコレクションを、どのファイルビューアーでも開ける形式で保管する
- 専用のコミックリーダーを持っていない人にコミックを共有する

## ヒント

- アーカイブ内の画像は自然順で並べ替えられます（そのため `page2.jpg` は `page10.jpg` より前になります）。正しいページ順にするため、ファイル名には一貫した番号を付けてください。
- コンバーターは、ファイル拡張子ではなくバイナリシグネチャで画像形式を判定します。誤って `.jpg` と名付けられたPNGでも正しく埋め込まれます。
- CBZファイルはPyMuPDFエンジンを読み込まずにブラウザ内ですべて処理されるため、CBRファイルより高速に変換できます。

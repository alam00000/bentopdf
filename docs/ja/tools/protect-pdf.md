# PDFの保護

PDFをパスワードでロックし、許可された人だけが開けるようにします。BentoPDFは、銀行や政府機関でも使われている標準と同じ256ビットAES暗号化を、QPDFを通じてすべてブラウザ上で適用します。

## 使い方

1. PDFファイルをアップロードします。
2. **ユーザーパスワード**を入力します（必須）。ファイルを開くために必要なパスワードです。
3. 必要に応じて**所有者パスワード**を入力します。設定すると、印刷、編集、コピー、注釈の追加を禁止する利用制限がPDFに適用されます。
4. **PDFを暗号化**をクリックします。
5. 暗号化されたファイルをダウンロードします。

## パスワードの種類

### ユーザーパスワード（必須）

ユーザーパスワードは、受信者がPDFを開くときに入力するものです。これがなければ、ドキュメントにはまったくアクセスできません。暗号化されたPDFには必ず1つ設定します。

### 所有者パスワード（任意）

所有者パスワードは、許可されたユーザーがファイルを開いた後にできることを制御します。ユーザーパスワードと異なる所有者パスワードを設定すると、BentoPDFは最も厳しい制限を自動的に適用します。

- 変更を無効化
- 抽出とコピーを無効化
- 印刷を無効化
- 注釈を無効化
- フォーム入力を無効化
- ドキュメントの組み立てを無効化

所有者パスワードを空欄にした場合、PDFは暗号化されます（開くにはユーザーパスワードが必要です）が、開いた後の利用制限はありません。

## 暗号化の詳細

- **アルゴリズム**：AES-256（256ビット Advanced Encryption Standard）
- **鍵長**：256ビット
- **規格**：PDF 2.0暗号化（QPDF実装）

AES-256は、現在の技術ではブルートフォースで破ることが計算上不可能です。暗号化したPDFの安全性は、パスワードの強度にかかっています。

## 活用例

- 機密性の高い財務レポートをメールで送る前に保護する
- 相手方の弁護士と共有する法的文書を保護する
- 医療記録や個人を特定できる情報にパスワードを設定する
- 有料コンテンツ（電子書籍やレポート）をアクセス制御付きで配布する
- 保存時の暗号化を求めるデータ保護ポリシーに準拠する

## ヒント

- 強力で一意なパスワードを使用してください。大文字小文字、数字、記号を混ぜた12文字以上のパスフレーズが理想的です。
- パスワードは、PDFと同じメールではなく、電話やテキストメッセージなど別の経路で共有してください。
- 開くときのパスワードは不要で、操作（印刷不可、コピー不可など）だけを制限したい場合は、代わりに権限の変更ツールを使用してください。

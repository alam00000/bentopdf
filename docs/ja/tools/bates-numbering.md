# 通し番号付け

ベイツ番号は、PDF のすべてのページに連続した識別子を押印する方式です。法的手続き、監査、コンプライアンス業務で文書にラベルを付ける際の標準的な方法です。このツールは複数のファイル、カスタマイズ可能なテンプレートに対応し、個別に番号を付けた PDF、または 1 つの ZIP アーカイブとして出力します。

## 使い方

1. 1 つ以上の PDF ファイルをアップロードします。複数のファイルを一度にドラッグできます。
2. スタイルのプリセットを選ぶか、カスタムテンプレートを作成します。
3. 位置、フォント、サイズ、色、開始番号を設定します。
4. **ベイツ番号を適用**をクリックして処理します。
5. ファイルが 1 つの場合は直接ダウンロードされます。複数のファイルは ZIP アーカイブとしてダウンロードされます。

## オプション

- **スタイルプリセット** -- 組み込みの形式から選択します。
  - 証拠 + 事件 + ベイツ + ページ（例: "Exhibit 1 Case XYZ 000001 Page 1"）
  - 証拠 + 事件 + ベイツ（ページ番号なし）
  - 事件 + ベイツ
  - ベイツ番号のみ（例: "000001"）
  - カスタム（独自のテンプレートを作成）
- **スタイルのカスタマイズ** -- プレースホルダー `[BATES]`、`[PAGE]`、`[FILE]`、`[FILENAME]` を使ったテンプレート文字列です。
- **ベイツ番号の桁数** -- ゼロ埋めするベイツ番号の桁数（3 ～ 6）です。カスタムモードでのみ表示されます。
- **位置** -- ヘッダーまたはフッター、左、中央、右から選びます。
- **ベイツ開始番号** -- 最初のベイツ番号です。デフォルトは 1 です。番号はファイルをまたいで続きます。
- **ファイルカウンターの開始番号** -- `[FILE]` プレースホルダーの開始番号です。
- **フォント** -- Helvetica、Times New Roman、Courier から選びます。
- **フォントサイズ** -- 押印するテキストのサイズです。
- **色** -- ベイツ番号のテキストの色を選ぶカラーピッカーです。

## 機能

- アップロードしたすべてのファイルでベイツ番号がどう表示されるかを確認できるライブプレビュー
- 文書をまたいで連続した番号を付けられる複数ファイル対応
- ファイルをドラッグ＆ドロップで並べ替えて、番号付けの順序を制御
- 6 通りの位置指定（ヘッダー/フッター、左/中央/右）
- ページサイズの違いに対応する、適応型の余白計算
- 複数ファイルのバッチ向け ZIP 出力
- 高い柔軟性を実現するテンプレートプレースホルダー

## ユースケース

- 訴訟の証拠開示文書に、連続した証拠番号を押印する
- 数十のファイルにまたがる監査証拠パッケージに番号を付ける
- コンプライアンス文書に規制の参照番号を付与する
- 特許出願の添付資料に、事件固有の識別子を付ける

## ヒント

- 処理する前に、ファイルリストでファイルをドラッグして並べ替えてください。ベイツ番号の順序は、この並び順に従います。
- `[FILENAME]` プレースホルダーを使うと、元のファイル名を押印に含められるため、ページを元の文書までたどりやすくなります。
- プレビューボックスは設定を変更するとリアルタイムで更新されるので、処理する前に形式を確認できます。

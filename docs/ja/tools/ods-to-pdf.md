# ODSからPDF

OpenDocumentスプレッドシートファイルをPDFに変換します。ODSはLibreOffice Calcのネイティブ形式で、Google Sheetsからよくエクスポートされる形式でもあります。このツールは、スプレッドシートのデータ、書式、グラフをページ分割されたPDFにレンダリングし、印刷や共有に使えるようにします。

## 対応フォーマット

| フォーマット             | 拡張子 | 備考                                           |
| :----------------------- | :----- | :--------------------------------------------- |
| OpenDocument Spreadsheet | `.ods` | LibreOffice Calc / Google Sheetsのエクスポート |

## 使い方

1. アップロード領域をクリックするか、ODSファイルをドラッグ&ドロップします。複数のファイルに対応しています。
2. ファイル一覧を確認します。ごみ箱アイコンでファイルを削除するか、**ファイルを追加**をクリックしてバッチを増やせます。
3. **PDFに変換**をクリックします。LibreOfficeベースのエンジンがブラウザに読み込まれ、各スプレッドシートをPDFページにレンダリングします。
4. 1つのスプレッドシートはPDFとしてダウンロードされます。複数のファイルは`ods-to-pdf.zip`にまとめられます。

## オプション

設定は不要です。コンバーターは、スプレッドシートに設定済みの印刷レイアウト、セルの書式、列幅をそのままPDF出力に適用します。

## ユースケース

- PDFしか受け付けない相手にLibreOffice Calcの予算表やレポートを共有する
- ODSとしてダウンロードしたGoogle Sheetsのエクスポートを印刷する
- 財務記録を編集できない形式で保管する
- ODSベースのフォームやタイムシートをレイアウト固定の文書として提出する

## ヒント

- スプレッドシートに複数のシートがある場合、すべてのシートがPDF出力に含まれます。
- 非常に幅の広いスプレッドシートは、PDFの複数ページに横方向で分割されることがあります。レイアウトが重要な場合は、変換前に元ファイルで列幅を調整してください。
- LibreOfficeエンジンは初回使用時に初期化されます。同じセッション内の2回目以降の変換は高速です。

# PDFフォームの作成

入力可能なPDFフォームを、ゼロから、または既存のPDFにフィールドを追加して作成できます。ビジュアルエディターで、テキストフィールド、チェックボックス、ドロップダウン、ラジオボタン、署名フィールドなどのフォーム要素をページプレビューに直接ドラッグ＆ドロップできます。フィールドのプロパティを設定し、条件付き表示ルールを組んで、完全にインタラクティブなPDFフォームとして書き出せます。

## 使い方

1. 既存のPDFをアップロードするか、**空白のPDFを作成**をクリックしてゼロから始めます。
2. 空白のPDFを作成する場合は、ページサイズ（Letter、A4、A5、Legal、Tabloid、A3、またはカスタム寸法）を選びます。
3. フィールドの種類を並べたツールバーとページプレビューのあるフォームエディターが開きます。
4. ツールバーからフィールドの種類を選び、ページ上をクリックして配置します。
5. フィールドをドラッグして位置を変え、リサイズハンドルでサイズを調整します。
6. フィールドをクリックするとプロパティパネルが開き、フィールド名、初期値、フォントサイズ、配置などを設定できます。
7. ページ操作でページ間を移動します。
8. **保存**をクリックして、完成した入力可能なPDFをダウンロードします。

## 機能

- ドラッグ＆ドロップでのフィールド配置と、リサイズ用のビジュアルハンドル
- フィールドの種類: テキスト入力、複数行テキスト、チェックボックス、ドロップダウン、ラジオボタン、署名、日付、数値、バーコード
- 各フィールドの名前、ラベル、初期値、フォントサイズ、色、配置、検証を設定するプロパティパネル
- フィールドアクションと条件付き表示ルール（他のフィールドの値に応じてフィールドを表示/非表示）
- 複数ページのフォームに対応したページ移動
- 既存フィールドの抽出: アップロードしたPDFからフォームフィールドを自動で検出して取り込み
- アップロードしたPDFと空白ページの両方をフォームのキャンバスとして利用可能
- 複数のページサイズプリセットとカスタム寸法
- bwip-jsによるバーコード生成
- ラジオボタングループの管理

## オプション

**ページサイズのプリセット（空白のPDF用）:**

- Letter（8.5" x 11"）
- A4（210mm x 297mm）
- A5（148mm x 210mm）
- Legal（8.5" x 14"）
- Tabloid（11" x 17"）
- A3（297mm x 420mm）
- カスタム（幅と高さを指定）

**フィールドのプロパティ（フィールドの種類により異なります）:**

- 名前、ラベル、プレースホルダーテキスト
- 初期値
- フォントファミリー、サイズ、色
- テキストの配置（左、中央、右）
- 必須フィールドの切り替え
- 読み取り専用の切り替え
- テキストフィールドの最大文字数
- ドロップダウンとラジオボタンの選択肢リスト
- 条件付き表示アクション

## 活用例

- 個人情報用のテキストフィールドと、規定への同意用のチェックボックスを備えた入社手続きフォームを作る
- サービス選択用のドロップダウンを備えた顧客向けヒアリングシートを作る
- 計算フィールドとバーコード識別子を備えた注文書を設計する
- 合格/不合格を選ぶラジオボタンを使った点検チェックリストを作る
- 回答に応じて追加の質問が表示される条件付きのアンケートフォームを作る

## ヒント

- 既存のPDFをアップロードすると、すでにあるフォームフィールドの抽出を試み、編集や追加ができるようになります。
- 排他的な選択肢にはラジオボタングループ機能を使います。同じラジオグループのフィールドはグループ名を共有します。
- フォームをダウンロードして[PDFフォーム入力機能](./form-filler)で開き、フィールドの動作を確認してください。

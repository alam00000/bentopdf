# VSDからPDF

Visioをインストールせずに、Microsoft VisioのダイアグラムをPDFに変換します。VSDファイルとVSDXファイルには、フローチャート、組織図、ネットワーク図、間取り図などが含まれていますが、多くの人は開けません。このツールは、それらをどのデバイスでも見られるきれいなPDFとして出力します。

## 対応フォーマット

| フォーマット  | 拡張子  | 備考                            |
| :------------ | :------ | :------------------------------ |
| Visioバイナリ | `.vsd`  | 従来のVisio形式(Visio 2003以前) |
| Visio XML     | `.vsdx` | 現在のVisio形式(Visio 2013以降) |

## 使い方

1. アップロード領域をクリックするか、VSDまたはVSDXファイルをドラッグ&ドロップします。両方の形式を1つのバッチに混在させることができます。
2. ファイル一覧を確認します。不要な項目はゴミ箱アイコンで削除するか、**さらにファイルを追加する**でダイアグラムを追加します。
3. **PDFに変換**をクリックします。LibreOfficeベースのエンジンがブラウザに読み込まれ、図形、コネクタ、ラベル、ページレイアウトを維持したまま各ダイアグラムをPDFにレンダリングします。
4. 1つのダイアグラムはそのままPDFとしてダウンロードされます。複数ファイルの場合は、`vsd-to-pdf.zip`という名前のZIPアーカイブが作成されます。

## オプション

設定は不要です。コンバーターは、Visio文書の元のページサイズと向きを尊重します。

## 活用例

- Visioのライセンスがなくても、同僚のVisio図を確認する
- ネットワーク図やアーキテクチャ図を、プロジェクトのドキュメントにPDFとして含める
- 会議の配布資料として、組織図やプロセスフローを印刷する
- 古いバージョンのVisioで作られたVSDファイルを、将来も使える形式で保管する

## ヒント

- 複数ページのVisio文書は複数ページのPDFになり、Visioの各ページがPDFの各ページに対応します。
- VSDXファイル(現在のXMLベースの形式)は、古いVSDバイナリファイルよりも高い再現度で変換されるのが一般的です。
- LibreOfficeエンジンはセッションごとに1回読み込まれます。最初の変換では少し待ち時間がありますが、以降のファイルはより速く処理されます。

# 両面スキャンの並べ替え

両面スキャンの並べ替えは、1つのPDFに2つのページブロックが含まれるADFスキャンのワークフロー向けに作られています。

- 最初にすべての表面
- 次にすべての裏面

手作業で分割して組み直す代わりに、このツールは2つのブロックを自然な読み順に交互に並べます。表1、裏1、表2、裏2、というようにです。

## 使い方

1. 両面の束をスキャンして作成した、1つのPDFをアップロードします。
2. 表面のブロックが終わる分割位置を設定します。
3. 裏面のブロックの扱いを選びます。
   - **裏面ブロックを反転**（裏面をスキャンする前に束をひっくり返した場合に一般的）
   - **裏面ブロックをそのまま維持**
4. **PDFを並べ替え** をクリックして、並べ替えた結果をダウンロードします。

## オプション

- **分割位置を自動検出（半分）**: 分割位置を `ceil(totalPages / 2)` に設定します。
- **奇数ページの警告**: 総ページ数が奇数の場合に警告します（スキャンの不一致であることが多いです）。
- **ブロックサイズ不一致の確認**: 表面と裏面のブロックのサイズが異なる場合に、確認を求めます。
- **グループ別エクスポート**: 並べ替えた出力を、元の文書のページ数に基づいて個別のPDFに分割し、ZIPとしてダウンロードします。

## 出力の動作

- **デフォルト**: 1つの出力PDF（入力PDF1つに対して、出力PDF1つ）。
- **グループモード**: 出力は、指定した文書あたりのページ数で分割されます。複数のまとまりができた場合は1つのZIPとして、そうでない場合は単一のPDFとしてダウンロードされます。

ブロックのサイズが揃っていない場合は、対になるページが先に並べ替えられ、残った対のないページは最後に追加されます。

## よくある活用例

- 両面印刷のフォームの束を2回に分けてスキャンした後、順序を元に戻す
- すべての表面の後にすべての裏面を出力するオフィス用スキャナーから、表裏のセットを組み直す
- アーカイブ用のスキャンを、文書ごとのファイルに分割する前に後処理する

## ヒント

- ほとんどの両面バッチでは、総ページ数は偶数になるはずです。
- 裏面の向きが逆に見える場合は、**裏面ブロックを反転** と **裏面ブロックをそのまま維持** を切り替えてください。
- 2ページの原本（表と裏）には、文書あたり `2` ページでグループ別エクスポートを使用します。

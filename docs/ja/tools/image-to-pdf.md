# 画像からPDF

あらゆる画像に対応したユニバーサルな画像PDFコンバーターです。ほぼどんな形式の画像でもアップロードして、1つのPDF文書にまとめられます。各画像は元の寸法に合わせたサイズで、1枚につき1ページになります。

## 対応フォーマット

| フォーマット    | 拡張子                                 |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

BentoPDFの画像コンバーターの中で、最も幅広い形式に対応しています。特定の形式だけが必要な場合は、専用のツールを使うこともできます。

## 使い方

1. アップロードエリアをクリックするか、画像ファイルをドラッグ＆ドロップします。複数のファイルを同時に選択できます。
2. ファイル一覧を確認します。不要なファイルはゴミ箱アイコンで削除でき、**ファイルを追加**で画像を追加できます。
3. ドロップダウンから**PDFの品質**を選びます。
4. **PDFに変換**をクリックします。ツールはPyMuPDFエンジンで画像を処理し、結果を`images_to_pdf.pdf`としてダウンロードします。

## オプション

**PDFの品質**は、画像をPDFに埋め込むときの圧縮を調整します。

- **高品質**: 圧縮を最小限に抑え、ファイルサイズは大きくなります。印刷やアーカイブに最適です。
- **中品質**（初期値）: バランスの取れた圧縮です。ほとんどの用途に適しています。
- **低品質**: 強力に圧縮し、ファイルサイズを最小にします。メールや簡単な共有に向いています。

HEICとWebPファイルは、埋め込み前に自動でPNGに変換されます。これは自動的に行われ、追加の操作は不要です。

## 活用例

- スマートフォンのカメラで撮ったレシートや書類のスキャンを1つのPDFにまとめる
- 形式が混在した画像から、フォトポートフォリオやルックブックを作る
- デスクトップソフトをインストールせずに、iPhoneの写真（HEIC）を共有しやすいPDFに変換する
- PSDの書き出しとスクリーンショットから、クライアント向けのデザインモックアップ資料を作る
- 古い形式（PNM、JXR、JP2）の画像が入ったフォルダーを、1つのPDFとしてアーカイブする

## ヒント

- PDF内の画像の順序は、ファイル一覧の並び順と一致します。希望する順番でアップロードしてください。
- ファイルサイズを最小にしたい場合は低品質を選びます。文字中心のスキャンでは、見た目の差はたいてい気になりません。
- 画像形式が1種類だけなら、専用コンバーター（JPGからPDF、PNGからPDFなど）でも同じ結果が、よりシンプルな画面で得られます。

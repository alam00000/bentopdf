# BMPからPDF

Windows ビットマップ（BMP）ファイルを PDF に変換します。BMP は非圧縮の画像形式で、レガシーシステム、医用画像、産業用スキャナーなどで今も使われています。このツールなら、何もインストールせずに PDF へ変換できます。

## 対応形式

| 形式 | 拡張子 |
| :--- | :----- |
| BMP  | `.bmp` |

## 使い方

1. アップロード領域をクリックするか、BMP ファイルをドラッグ＆ドロップします。
2. ファイルリストを確認します。ファイルを追加したり、不要なファイルを削除したりできます。
3. **PDF に変換**をクリックします。出力は `from_bmps.pdf` としてダウンロードされます。

各 BMP はキャンバスに描画されて PNG として書き出され、その後 pdf-lib を使って PDF に埋め込まれます。ページサイズは元の画像のサイズと一致します。

## オプション

このツールには、追加の品質設定はありません。画像は元の解像度のまま、ロスレスの PNG として PDF に埋め込まれます。

## ユースケース

- BMP で保存されたレガシーなスキャン文書を、アーカイブ用の PDF に変換する
- 古い Windows アプリケーションの BMP スクリーンショットを、共有しやすい文書にする
- 既定で BMP を出力する医療用や産業用のスキャナーの出力を処理する
- 古い画像アーカイブを、より持ち運びやすい形式へ移行する

## ヒント

- BMP ファイルは非圧縮のため、サイズが大きくなりがちです。画像は内部で PNG に再エンコードされるため、できあがる PDF は大幅に小さくなります。
- BMP ファイルと他の画像形式が混在している場合は、[画像からPDF](./image-to-pdf) ツールを使えば、すべてを 1 回のバッチで変換できます。

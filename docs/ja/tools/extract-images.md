# 画像の抽出

1つ以上のPDFファイルから、埋め込まれたすべての画像を取り出します。抽出された画像はプレビューグリッドに表示され、個別にダウンロードすることも、ZIPとしてすべてを一度に取得することもできます。PyMuPDFを搭載しています。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、1つ以上のPDFをアップロードします。必要に応じてファイルを追加したり、個別に削除したりできます。
2. **抽出** をクリックして、処理を開始します。
3. ツールが、アップロードされたすべてのPDFのすべてのページをスキャンし、埋め込まれた画像を見つけて抽出します。
4. 抽出された画像がサムネイル付きのグリッドに表示されます。各画像にはダウンロードボタンがあります。
5. **すべてダウンロード** をクリックして、すべてをZIPアーカイブとして保存します。

## オプション

このツールに設定可能なオプションはありません。埋め込まれたすべての画像は、元の形式（通常はPNG、JPEG、またはPDFに埋め込まれたときに使われた形式）で抽出されます。

## 出力形式

- 画像は、`image_1.png`、`image_2.jpg` のような名前でプレビューグリッドに表示されます。
- **すべてダウンロード** は、すべての画像を含む `extracted-images.zip` を生成します。
- 個々の画像は、グリッドから1つずつダウンロードできます。

## 活用例

- PDFから写真やグラフィックを取り出して、別のプロジェクトで再利用する。
- ECサイトの掲載用に、カタログのPDFから商品画像を抽出する。
- プレゼンテーションで使うために、技術文書から図を取り出す。
- 共有する前に、文書にどの画像が埋め込まれているかを監査する。

## ヒント

- このツールは、PDFに保存されているとおりの画像を抽出します。ページを画像として再描画することはありません。それには、[PDFからPNG](./pdf-to-png) や [PDFからJPG](./pdf-to-jpg) を使ってください。
- ツールが「画像が見つかりません」と報告した場合、PDFが埋め込みのラスター画像ではなくベクターグラフィックを使っているか、ページ全体が1枚の大きな画像になっているスキャン文書である可能性があります。
- バッチ処理は、複数のPDFにまたがって機能します。すべてのファイルのすべての画像が、1つのグリッドと1つのZIPにまとめられます。

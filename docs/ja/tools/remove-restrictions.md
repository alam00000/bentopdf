# 制限の解除

PDFには2種類のパスワードを設定できます。ユーザーパスワード（ファイルを開くために必要）と、所有者パスワード（ファイルに対してできることを制御）です。このツールは、その両方に加えて、印刷、編集、コピー、注釈のロックといった関連するすべての制限を取り除きます。

## 使い方

1. PDFファイルをアップロードします。
2. PDFに所有者パスワードが設定されている場合は、**所有者パスワード**欄に入力します。パスワードがなく利用制限だけがある場合は、空欄のままにします。
3. **制限を解除**をクリックします。
4. 制限のないPDFをダウンロードします。

このツールはQPDFの`--decrypt`フラグと`--remove-restrictions`フラグを使用して、クリーンで制限のないコピーを生成します。

## 削除されるもの

- パスワード保護（ユーザーパスワードと所有者パスワードの両方）
- 印刷の制限
- 編集の制限
- テキストと画像のコピー制限
- 注釈とコメントの制限
- PDFに設定されているその他すべてのセキュリティ制限

## 活用例

- 自分のPDFだが、何年も前に設定したパスワードのロックを解除する
- 正当にアクセスできるドキュメントから、印刷制限を取り除く
- メモを取るために、参考資料でコピーアンドペーストを有効にする
- 制限付きのドキュメントを扱えないアクセシビリティツール向けにPDFを準備する

## ヒント

- 所有者パスワードが設定されている場合は、それを知っている必要があります。このツールはパスワードの解読やブルートフォースは行いません。
- ファイルを暗号化したまま特定の権限だけを変更したい場合は、代わりに権限の変更ツールを使用してください。
- 出力ファイルは暗号化されていません。受け取った人は誰でも自由に開けます。

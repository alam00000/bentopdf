# PDFの圧縮

PDFファイルを壊さずに小さくします。PDFの圧縮は、BentoPDF独自の圧縮エンジンである [Hyper Compress](https://www.bentopdf.com/hyper-compress) を使用しています。画像の再圧縮、フォントのサブセット化と統合、埋め込みサムネイルやアプリケーション固有の非公開データなど不要なデータの削除を行います。PDFの機能は完全に保たれ、テキストは選択でき、リンクやフォームフィールドも動作します。

Hyper CompressはWebAssemblyにコンパイルされてBentoPDFに同梱されているため、追加のセットアップなしで、オフラインやエアギャップ環境でも圧縮できます。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、1つ以上のPDFをアップロードします。
2. **圧縮レベル** を選びます。低、中、高、ロスレスのいずれかです。
3. 必要に応じて **目標ファイルサイズ** を入力するか、**詳細設定** を開いて、**グレースケールに変換** を含むきめ細かな設定をします。
4. **PDFを圧縮** をクリックします。複数のファイルの場合は、1つのZIPとしてダウンロードされます。

## 特殊な文書

- **デジタル署名付きPDF** は、変更すると署名が無効になるため、そのまま返されます。詳細設定で **コンテンツ保護を上書き** をオンにすると、署名が削除されて圧縮されます。見える署名はページに残りますが、ファイルは署名済みではなくなります。
- **PDF/Aファイル** は、圧縮後にPDF/Aのラベルを失います。これは、もはや満たしていない準拠を主張しないようにするためです。代わりにファイルの準拠を保ちたい場合は、詳細設定で **PDF/Aを維持** をオンにします。
- **パスワード保護されたPDF** には、ファイルカードにパスワード欄が表示されます。そこにパスワードを入力すると、Hyper Compressがファイルを自分で開くため、別途ロック解除の手順は不要です。ロックされたファイルが2つ以上ある場合は、同じパスワードを使うすべてのファイルを、共有の1つの欄でロック解除できます。圧縮後のコピーにはパスワードがありません。再度設定するには [PDFの暗号化](./protect-pdf) を使用してください。
- **テキストレイヤーのないスキャン** は、詳細設定の **ページを画像化** を使うと、さらに小さくできます。これは各ページを1枚の最適化された画像に置き換えます。OCR済みのスキャンを含め、選択可能なテキストを持つ文書では、**コンテンツ保護を上書き** がオンでない限りスキップされます。オンにした場合は、テキストのページも画像になるため、テキストは選択できなくなり、リンクも動作しなくなります。

## 圧縮レベル

| レベル       | 画像品質       | 最大解像度 | 最適な用途                        |
| ------------ | -------------- | ---------- | --------------------------------- |
| **低**       | 80             | 200 DPI    | 見た目の品質を保ちたいとき        |
| **中**       | 50             | 150 DPI    | 日常的な文書                      |
| **高**       | 20             | 72 DPI     | メールの添付、Webへのアップロード |
| **ロスレス** | 画像はそのまま | 変更なし   | アーカイブ用のコピー              |

高では、標準の14種類のPDFフォントに加え、安全な場合はArialなどの類似フォントも埋め込みを解除します。

## 目標ファイルサイズ

KBまたはMBでサイズを入力すると、Hyper Compressは、選んだレベルから始めて、そのサイズに収まる最良の画像品質を探します。文書がそこまで小さくならない場合は、作成できる最小のバージョンが出力され、その旨のメッセージが表示されます。[PDFを1MBに圧縮](https://www.bentopdf.com/compress-pdf-to-1mb) のような専用ページは、目標があらかじめ入力された状態で開きます。

## 詳細設定

詳細設定パネルを開くと、Hyper Compressを直接調整できます。圧縮レベルを選ぶと、これらはそのレベルの値にリセットされ、どれかを編集すると、レベルはカスタムに切り替わります。

- **コンテンツ保護を上書き**: デフォルトでは、Hyper Compressは署名付きPDFには手を加えず、テキストのあるページを画像化しません。これをオンにすると、その両方を回避します。レベルを変更してもオンのままです。

- **画像**: 画像品質、最大解像度、強制的な再サンプリング、色の削減、見えない画像領域のクリッピング、代替画像の削除、カラープロファイルの簡素化、JPEG 2000、ロスレスモード
- **フォント**: サブセット化、重複の統合、標準フォントとその類似フォントの埋め込み解除
- **コンテンツ**: 注釈、フォームフィールド、リンクの平坦化
- **クリーンアップ**: サムネイル、アプリケーションデータ、記事スレッド、Webキャプチャ情報、構造ツリー、出力インテントの削除
- **画像化**: 画像のみのスキャンで、ページを画像に置き換える。選択可能なテキストがある文書ではスキップ
- **出力**: PDF/Aを維持、およびBrotli圧縮に対応するPDF 2.0リーダー向けのBrotli圧縮

## 活用例

- 50 MBのレポートを、メールの添付ファイルの上限以下にする
- 目標ファイルサイズを使って、スキャンをポータルの厳しいアップロード上限以下にする
- マーケティング用PDFを最適化して、Webサイトでのダウンロードを速くする
- ストレージコストが問題になる大量の文書セットをアーカイブする
- メッセージアプリでPDFを共有するときのモバイルデータ使用量を減らす

## ヒント

- まずは中から始めましょう。それでも大きすぎる場合は、目標ファイルサイズを設定するか、高に上げてください。
- テキストレイヤーのないスキャンには、詳細設定の「ページを画像化」をオンにします。
- 詳細設定の「グレースケールに変換」は、カラーが多い文書のファイルサイズを減らせます。

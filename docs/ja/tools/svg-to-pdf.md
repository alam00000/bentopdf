# SVGからPDF

Scalable Vector Graphics（SVG）ファイルをPDFに変換します。このツールは各SVGをブラウザの描画エンジンでラスタライズし、その結果を元の解像度で埋め込みます。ベクターのアイコン、図、イラストを持ち運びやすいドキュメントにするのに便利です。

## 対応フォーマット

| フォーマット | 拡張子 |
| :----------- | :----- |
| SVG          | `.svg` |

## 使い方

1. アップロード領域をクリックするか、1つ以上のSVGファイルをドラッグアンドドロップします。
2. ファイル一覧を確認して管理します。
3. **PDF品質**のレベルを選択します。
4. **PDFに変換**をクリックします。結果は`from_svgs.pdf`としてダウンロードされます。

各SVGはテキストとして読み込まれ、本来の幅と高さ（サイズの指定がない場合は800x600がデフォルト）でキャンバスに描画され、PNGとして書き出されます。そのPNGがpdf-libを使ってPDFに埋め込まれます。透明な部分は白い背景で塗りつぶされます。

## オプション

**PDF品質**は、ラスタライズ後の圧縮を制御します。

- **高品質**：元の描画に最も近くなります。
- **中品質**（デフォルト）：バランスが良い設定です。
- **低品質**：ファイルが最小になりますが、細部が失われます。

## 活用例

- 建築やエンジニアリングの図を、SVGから印刷用のPDFに変換する
- アイコンセットを、デザインシステムのリファレンスPDFにまとめる
- データの可視化（D3.jsやチャートライブラリの出力）を、レポートに使えるPDFにする
- SVGベースのインフォグラフィックの印刷用バージョンを作成する

## ヒント

- `width`と`height`属性が明示されていないSVGファイルは、800x600ピクセルで描画されます。最良の結果を得るには、変換する前にSVGのソースでサイズを設定してください。
- 外部フォントの参照やリンクされた画像を含む複雑なSVGは、完全には描画されない場合があります。確実な出力のために、すべてのアセットをSVG内にインライン化してください。
- SVGはラスタライズされるため、PDFにはベクターパスではなくビットマップ画像が含まれます。真のベクターPDF出力には、専用のベクターツールが必要です。

# XPSからPDF

Microsoft XPSおよびOXPS文書を、標準的なPDFファイルに変換します。XPS(XML Paper Specification)はPDFに対抗するMicrosoftの規格でしたが、対応するプラットフォームは減っています。このツールを使えば、そうした文書をふたたび誰でも読めるようにできます。

## 対応フォーマット

| フォーマット | 拡張子  | 備考                               |
| :----------- | :------ | :--------------------------------- |
| XPS          | `.xps`  | Microsoft独自の元のXPS形式         |
| OXPS         | `.oxps` | Open XPS、ECMA-388標準のバリアント |

## 使い方

1. アップロード領域をクリックするか、XPS/OXPSファイルをドラッグ&ドロップします。複数のファイルを一度に選択できます。
2. ファイル一覧を確認します。個別のファイルはゴミ箱アイコンで削除するか、**さらにファイルを追加する**をクリックして文書を追加します。
3. **PDFに変換**をクリックします。PyMuPDFエンジンが、各文書をブラウザ内でローカルに処理します。
4. 1ファイルの場合は、そのままPDFとしてダウンロードされます。複数ファイルの場合は、`xps-converted.zip`という名前のZIPアーカイブにまとめられます。

## オプション

このツールは、追加の設定なしで直接フォーマットを変換します。出力では、XPS元データのページサイズ、ベクターグラフィックス、フォント、画像が維持されます。

## 活用例

- XPS印刷ドライバーが既定だった古いWindowsシステムから受け取ったXPSファイルを開く
- Windows 10/11のOXPS文書を、macOSやLinuxのユーザーと共有できるように変換する
- 古いXPSファイルを、より広く対応された形式で保管する
- XPSベースの政府文書や企業文書を、外部の受取人が利用できるようにする

## ヒント

- `.xps`と`.oxps`の両方の拡張子が自動的に処理されるため、同じバッチに混在させることができます。
- 元のXPSファイルが高解像度の印刷ドライバーで作成されていた場合、生成されるPDFもその品質を維持します。再サンプリングは行われません。

# MOBIからPDF

Amazon KindleのMOBI形式の電子書籍を、PDF文書に変換します。MOBIファイルはKindleの端末やアプリに依存しているため、ほかの環境では読みにくいことがあります。PDFに変換すれば、どんなデバイスでも開いたり印刷したりできる、持ち運びしやすい版が手に入ります。

## 対応フォーマット

| フォーマット | 拡張子  | 備考                               |
| :----------- | :------ | :--------------------------------- |
| MOBI         | `.mobi` | Kindleの電子書籍形式（Mobipocket） |

## 使い方

1. アップロードエリアをクリックするか、1つ以上のMOBIファイルをドラッグ＆ドロップします。
2. ファイル一覧を確認します。不要なファイルはゴミ箱アイコンで削除でき、**ファイルを追加**で電子書籍を追加できます。
3. **PDFに変換**をクリックします。PyMuPDFエンジンがMOBIの構造を解析し、各ページをPDFの内容としてレンダリングします。
4. ファイルが1つの場合はPDFとしてダウンロードされます。複数ファイルを変換した場合は、`mobi-converted.zip`という名前のZIPアーカイブが得られます。

## オプション

追加の設定は不要です。変換では、元のMOBIファイルのテキスト、書式、埋め込み画像が保持されます。

## 活用例

- PDFにしか対応していない、Kindle以外の電子書籍リーダーで、Kindleで購入したコンテンツを読む
- オフラインでの学習や書き込みのために、電子書籍の章を印刷する
- 個人の電子書籍ライブラリを、汎用的な形式でアーカイブする
- Kindleアプリを持っていない相手に、抜粋を共有する

## ヒント

- DRM保護されたMOBIファイルは変換できません。このツールが扱えるのはDRMフリーのMOBIファイルのみです。
- すべてがブラウザー内で処理されるため、画像が多く埋め込まれた大きな電子書籍は、処理に数秒長くかかる場合があります。

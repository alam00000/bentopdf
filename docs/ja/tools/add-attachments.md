# 添付ファイルの追加

1 つまたは複数のファイルを PDF 文書の中に直接埋め込みます。添付ファイルは文書レベル（あらゆる PDF リーダーの添付ファイルパネルに表示されます）で追加することも、特定のページに紐づけることもできます。

## 使い方

1. ファイルを添付したい PDF をアップロードします。
2. 添付ファイルのドロップゾーンで、埋め込みたいファイル（どんな種類でも可）を選択します。
3. 添付レベルを選択します。**文書**（デフォルト）または**ページ**です。
4. ページレベルを選んだ場合は、ページ範囲（例: `1-3` や `5`）を入力します。
5. 処理ボタンをクリックします。ファイルが埋め込まれた PDF がダウンロードされます。

## 機能

- あらゆる種類のファイルを添付可能。画像、スプレッドシート、アーカイブ、実行ファイルなど何でも対応
- 文書レベルまたはページレベルで添付位置を指定
- 1 回の操作で複数のファイルを添付可能
- 選択したすべての添付ファイルのファイル名とサイズを表示
- 出力では元の PDF の内容を保持したまま、埋め込みファイルを追加

## オプション

| オプション       | 説明                                                                   |
| ---------------- | ---------------------------------------------------------------------- |
| **文書レベル**   | PDF 全体にファイルを添付します。添付ファイルパネルからアクセスできます |
| **ページレベル** | ページ範囲の入力で指定した特定のページにファイルを添付します           |

## ユースケース

- PDF レポートにソースデータ（Excel ファイルや CSV）を同梱する
- 写真ポートフォリオ PDF に元の画像ファイルを添付する
- 契約書や提案書に関連書類を埋め込む
- 研修マニュアルの特定のページに補足資料を追加する

## ヒント

- 文書レベルの添付ファイルは、PDF リーダー全般で最も広くサポートされています。ページレベルの添付ファイルは、すべてのビューアで表示されるとは限りません。
- 添付ファイルのサイズに上限はありませんが、非常に大きなファイルを埋め込むと、それに比例して PDF のサイズも大きくなります。

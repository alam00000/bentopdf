# 電子署名

電子署名は、特定の人物が文書に署名したこと、そして署名後に文書が改変されていないことの、暗号による証明です。手書きの署名（単なる画像）とは異なり、電子署名はX.509証明書とPKCS#7標準を使って、検証可能な真正性と完全性を提供します。

BentoPDFは電子署名をすべてブラウザ内で適用します。秘密鍵がお使いのデバイスから出ることはありません。

## 使い方

1. PDFファイルをアップロードします。
2. 証明書ファイル（.pfx、.p12、または.pem）をアップロードします。
3. 証明書のパスワードを入力してロックを解除します。ツールに、証明書のサブジェクト、発行者、有効期間が表示されます。
4. 必要に応じて、署名のメタデータ（理由、場所、連絡先）を設定します。
5. 必要に応じて、位置、サイズ、画像、テキストをカスタマイズできる **可視署名** を有効にします。
6. **PDFに署名** をクリックします。

## 対応する証明書形式

| 形式        | 拡張子     | 説明                                                                                                          |
| ----------- | ---------- | ------------------------------------------------------------------------------------------------------------- |
| **PKCS#12** | .pfx、.p12 | 秘密鍵と証明書チェーンを含む、業界標準のバンドル。最も一般的な形式。                                          |
| **PEM**     | .pem       | テキストベースの形式。証明書と秘密鍵の両方を1つのファイルに含める必要があります。暗号化された秘密鍵にも対応。 |

## 可視署名のオプション

有効にすると、PDFのページに可視の署名ブロックが描画されます。

- **位置**: X/Y座標と、幅/高さ（ポイント単位）
- **ページ**: 最初のページ、最後のページ、すべてのページ、または特定のページ番号
- **画像**: PNG、JPG、WebPの画像をアップロード（手書きの署名、社印など）
- **テキスト**: 色とフォントサイズを設定できるカスタムテキスト。画像もテキストも指定しない場合、ツールは証明書のコモンネームと現在の日付からテキストを自動生成します。

## 署名のメタデータ

- **理由**: 文書に署名した理由（例: 「承認済み」、「確認済み」）
- **場所**: 署名を行った場所（例: 「New York, NY」）
- **連絡先**: 署名者への連絡方法（例: メールアドレス）

## インターネット接続について

署名にはインターネット接続が必要な場合があります。署名ライブラリは、証明書の認証局情報アクセス（AIA）拡張に埋め込まれたURLから、証明書チェーンを取得します。それらのサーバーに到達できない場合、チェーンの検証が必要な証明書では署名に失敗します。

## 活用例

- 契約書、提案書、合意書に、法的拘束力のある電子署名で署名する
- PKIベースの認証が必要なワークフローで、公式文書を認証する
- 規制対応のためにPDFの請求書に署名する（EU諸国の多くが、電子署名付きの電子請求書を求めています）
- 設計図や品質文書に、組織としての承認を加える

## ヒント

- 自己署名証明書はテストには使えますが、Adobe Readerでは警告が表示されます。本番の文書には、信頼できる認証局の証明書を使ってください。
- 可視署名は見た目だけのものです。暗号署名は、可視ブロックを有効にしているかどうかにかかわらず埋め込まれます。
- 署名済みPDFを署名の検証ツールで確認し、署名が損なわれていないことを確かめましょう。

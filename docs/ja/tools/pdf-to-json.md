# PDFからJSON

1つ以上のPDFファイルをJSON形式に変換します。このツールはCPDF (Coherent PDF) を使い、各PDFの内部構造を機械可読なJSON表現にシリアライズします。出力は常にZIPアーカイブとして提供されます。

## 使い方

1. ファイルピッカーで1つ以上のPDFファイルを選択します。
2. **変換**をクリックして処理を開始します。変換はバックグラウンドのWebワーカーで実行されます。
3. 入力したPDFごとに1つのJSONファイルを含むZIPアーカイブがダウンロードされます。

ステータスバーに、変換とZIP作成の各段階の進行状況が表示されます。

## オプション

このツールに設定可能なオプションはありません。各PDFは完全なJSON表現に変換されます。

## 出力形式

- 入力したPDFごとの`filename.json`を含む`pdfs-to-json.zip`ファイル。

JSON出力は、ページツリー、フォント参照、メタデータ、コンテンツストリームなど、PDFの内部オブジェクト構造を表します。

## ユースケース

- デバッグや検証のために、PDFの内部構造を調べる。
- 構造化されたメタデータやページのプロパティをプログラムで抽出する。
- PDFの構造データを独自の処理パイプラインに渡す。
- オブジェクトツリーを分析して、PDF文書のコンプライアンスを監査する。

## ヒント

- このツールが出力するのは生のPDFオブジェクト構造で、抽出したテキストコンテンツではありません。ページのテキストをJSON形式で取得したい場合は、代わりに[AI用のPDFを準備する](./prepare-pdf-for-ai)を使ってください。
- プレーンテキストの抽出には、[PDFからテキスト](./pdf-to-text)のほうが簡単です。
- 構造が複雑な大きなPDFは、非常に大きなJSONファイルになります。

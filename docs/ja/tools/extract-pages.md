# ページの抽出

PDFから複数のページを取り出して、新しいファイルとして保存します。範囲の構文で必要なページを正確に指定すると、ツールがそれらのページだけを含むすっきりしたPDFを作成します。

## 使い方

1. PDFファイルをアップロードします。ツールにファイル名、サイズ、総ページ数が表示されます。
2. 範囲の構文（例: `1-5`、`3, 7, 10-12`）で、抽出したいページを入力します。
3. 必要に応じて、各範囲を別々のPDFとしてZIPアーカイブでダウンロードするよう選択します。
4. 処理ボタンをクリックします。抽出されたページが、新しいPDF（またはZIP）としてダウンロードされます。

## 機能

- 柔軟なページ範囲の構文：個別のページ、範囲、またはカンマ区切りの組み合わせ
- アップロード後に総ページ数を表示し、参照しやすく
- 1つにまとめたPDF、またはZIP内の別々のファイルとして出力するオプション
- 元のページの内容と書式を保持

## 活用例

- 長いレポートから、エグゼクティブサマリー（最初の数ページ）を取り出す
- 教科書のPDFから、1つの章を抽出する
- 書類一式から特定のページを、独立した文書として保存する
- 大きなファイルの選択したページから、サンプル文書を作成する

## ヒント

- ページ番号は1から始まります。最初のページには `0` ではなく `1` を使ってください。
- ページを抽出するのではなく取り除きたい場合は、逆の操作にあたる [ページの削除](./delete-pages) を使ってください。
- サムネイルでページを視覚的に選択したい場合は、[PDFの分割](./split-pdf) をビジュアル選択モードで使ってください。

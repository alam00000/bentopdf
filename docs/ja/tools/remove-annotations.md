# 注釈の削除

コメント、ハイライト、付箋、テキストマークアップ、リンク、スタンプなど、ドキュメントに埋め込まれたすべての注釈オブジェクトを削除して、PDFをきれいにします。ページの本来の内容（テキスト、画像、グラフィック）はそのまま残ります。

## 使い方

1. PDFファイルをアップロードします。
2. ツールがドキュメントのページ数を検出し、ファイル情報を表示します。
3. **注釈を削除**をクリックして処理します。
4. すべての注釈が取り除かれたPDFが自動的にダウンロードされます。

## 機能

- すべての種類の注釈を削除：コメント、ハイライト、下線、取り消し線、付箋、スタンプ、リンク、フォームマークアップ
- ドキュメントのすべてのページが対象
- 注釈以外の内容（テキスト、画像、ベクターグラフィック、フォームフィールド）はすべて保持
- 処理前にページ数とファイルサイズを表示

## 活用例

- 複数のレビュアーがコメントを付けたレビューの後、最終配布の前にドキュメントを整理する
- 共有している学習ガイドから、ハイライトと付箋を削除する
- アーカイブの前に、ドキュメントからリンク注釈を取り除く
- 交渉中に大量の注釈が付いた法的文書の「クリーン」版を用意する
- 印刷に送る前に、原稿からレビュアーのコメントを削除する

## ヒント

- このツールはPDFの構造レベルで注釈を削除するため、結果は選択可能なテキストと元の品質を保ちます。ラスタライズは行われません。
- すべてではなく特定の注釈だけを削除したい場合は、[PDFエディター](./edit-pdf)を使って個々の注釈を選んで削除してください。
- フラット化されたPDF（注釈がページの内容に統合されたもの）の注釈は、もう独立したオブジェクトではないため削除できません。

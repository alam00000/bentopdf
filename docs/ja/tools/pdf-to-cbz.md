# PDFからCBZ

PDFをCBZ (Comic Book ZIP) ファイルに変換します。デジタルコミックやマンガの標準形式です。PDFの各ページはアーカイブ内の画像になります。最大限の互換性のため、メタデータはComicInfo.xml、metadata.opf、ComicBookInfo JSONの3つの形式で生成されます。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、PDFをアップロードします。
2. 画像形式、品質、スケール、任意のメタデータを選びます。
3. **変換**をクリックしてCBZファイルを生成します。
4. `.cbz`ファイルが自動的にダウンロードされます。

## オプション

| オプション         | 値              | デフォルト | 説明                                                                                     |
| ------------------ | --------------- | ---------- | ---------------------------------------------------------------------------------------- |
| 画像形式           | JPEG, PNG, WebP | JPEG       | カラーのコミックにはJPEG、ロスレスの白黒マンガにはPNG、最高の圧縮にはWebP。              |
| 品質               | 50–100%         | 85%        | JPEG/WebPの圧縮を制御します。PNG (常にロスレス) では非表示です。                         |
| スケール           | 1.0x–4.0x       | 2.0x       | スケールを上げると、高解像度の画面向けにより鮮明な画像になります。                       |
| グレースケール     | オン/オフ       | オフ       | ページをグレースケールに変換します。白黒のコンテンツではファイルサイズが小さくなります。 |
| マンガモード       | オン/オフ       | オフ       | メタデータに右から左への読み方向を設定します。                                           |
| メタデータを含める | オン/オフ       | オン       | ComicInfo.xml、metadata.opf、ComicBookInfo JSONを埋め込みます。                          |

## メタデータ項目

メタデータを有効にすると、次の項目を入力できます。

- **タイトル**: PDFのファイル名から自動検出されます。
- **シリーズ**: シリーズ名 (例: 「Naruto」)。
- **番号 (#)**: シリーズ内の号数。
- **巻 (Vol.)**: 巻数。
- **著者**: 作者または制作者の名前。
- **出版社**: 出版会社。
- **タグ / ジャンル**: カンマ区切りのタグ (例: 「Action, Adventure」)。
- **出版年**: 出版された年 (1900〜2100)。
- **評価**: 0から5のコミュニティ評価。

## メタデータの互換性

このツールは、どのリーダーでも見つけられるよう、3つの形式でメタデータを書き込みます。

| 形式               | 場所            | 対応するリーダー                            |
| ------------------ | --------------- | ------------------------------------------- |
| ComicInfo.xml      | ZIP内のファイル | Komga, Kavita, CDisplayEx, Mylar, ComicRack |
| metadata.opf       | ZIP内のファイル | Calibre                                     |
| ComicBookInfo JSON | ZIPのコメント欄 | Calibre (フォールバック)                    |

## 出力形式

- `filename.cbz`: 番号付きのページ画像とメタデータファイルを含むZIPアーカイブ。

ページ画像には、リーダーが正しい順序で表示できるよう、ゼロ埋めした番号 (`01.jpg`、`02.jpg`など) が付けられます。

## ユースケース

- マンガやコミックのPDFを、コミックリーダーで使えるように変換する。
- Komga、Kavita、Calibreでデジタルコミックのライブラリを構築する。
- スキャンしたコミックを、リーダーで読みやすい形式に変換する。
- 読み方向とメタデータを保持した形式でコミックを共有する。

## ヒント

- カラーのコミックには**JPEG**、白黒のマンガには**PNG**を使ってください。PNGは白黒のコンテンツを非常に効率よく圧縮します。
- マンガでは**グレースケール**を有効にすると、ファイルサイズを大幅に減らせます。
- ライブラリ管理ツール (Komga、Calibre) がコレクションを自動的に整理できるよう、**シリーズ**と**番号**を入力してください。
- **WebP**は最高の圧縮率ですが、古いコミックリーダーは対応していない場合があります。

# PDFマルチツール

ページ単位のあらゆるPDF操作をまとめた統合ワークスペースです。1つ以上のPDFをアップロードすると、すべてのページを1つの視覚的なグリッドで扱えます。回転、並べ替え、複製、削除、PDFや画像、空白ページの挿入、ページ番号の振り直し、サイズ変更、結果の分割まで、ツールを離れずに行えます。

## 使い方

1. **ファイルの選択**をクリックするか、アップロード領域にファイルをドラッグします。複数のファイルに対応しており、アップロードした順に結合されます。
2. すべてのページが、サムネイル付きのスクロール可能なグリッドに表示されます。
3. ページをクリックすると選択できます。Shiftキーを押しながらクリックすると範囲を選択でき、Cmd/Ctrlキーを押しながらクリックすると個別のページを選択に追加したり、選択から外したりできます。
4. ページの操作には、オーガナイザーのツールバーを使うか、ページを右クリックします。
5. **PDFをエクスポート**をクリックして最終結果をダウンロードします。

## 機能

- **結合**: 複数のPDFや画像をアップロードすると、自動的に1つの文書にまとまります
- **並べ替え**: ページをドラッグ&ドロップして順序を変更したり、文書全体の順序を逆にしたりできます
- **回転**: 選択したページを90度単位で左または右に回転します
- **複製**: 選択したページをコピーし、そのすぐ後ろに配置します
- **削除**: 選択したページを削除します
- **挿入**: 別のPDFや画像のページ、空白ページ、クリップボードのページを追加したり、2つ目のPDFのページを現在のページと交互に組み合わせたりできます
- **置換**: ページを別のPDFの1ページ目に差し替えます
- **切り取り、コピー、貼り付け**: 文書内でページを移動またはコピーします
- **抽出**: 選択したページをPDFまたは画像としてダウンロードします
- **ページ番号**: ページ範囲に「i, ii, iii」や「A-1, A-2」のようなページラベルを設定します
- **ページサイズ**: ページを標準の用紙サイズまたはカスタムサイズに合わせます
- **分割**: ページ範囲、奇数ページと偶数ページ、1ページずつ、しおり、Nページごと、ファイルサイズで文書を分割します
- **元に戻す / やり直し**: すべてのページ操作を元に戻したり、やり直したりできます
- 破損したPDFは読み込み前に自動修復します

## キーボードショートカット

| 操作                       | ショートカット                |
| -------------------------- | ----------------------------- |
| 右に回転 / 左に回転        | R / Shift+R                   |
| すべて選択                 | Cmd/Ctrl+A                    |
| 切り取り、コピー、貼り付け | Cmd/Ctrl+X, C, V              |
| 複製                       | Cmd/Ctrl+D                    |
| 削除                       | DeleteまたはBackspace         |
| 元に戻す / やり直し        | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| 選択範囲の移動             | 矢印キー、Home、End           |

## ユースケース

- 複数の元PDFのページから独自の文書を作る
- スキャン文書の空白ページを削除し、横向きのスキャンを回転し、セクションを並べ替えて整える
- しおりを使って、大きなPDFを章の区切りで分割する
- 本格的なPDFエディターを使わずに、手早くページ単位で編集する

## ヒント

- 元に戻す/やり直しの履歴は、すべてのページ操作を記録します。作業が誤って失われることはないので、気軽に使ってください。
- **Insert > From File**を使うか、ページのグリッドにPDFや画像をいつでもドロップすると、文書に追加できます。
- 単純な結合や分割には、専用の[PDFの結合](./merge-pdf)または[PDFの分割](./split-pdf)ツールのほうが速い場合があります。マルチツールは、1回のセッションで複数の操作が必要なときに力を発揮します。

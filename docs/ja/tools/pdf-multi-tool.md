# PDFマルチツール

ページ単位のあらゆるPDF操作をまとめた統合ワークスペースです。1つ以上のPDFをアップロードすると、すべてのページを1つの視覚的なグリッドで扱えます。回転、並べ替え、複製、削除、新しいPDFの挿入、空白ページの追加、結果の分割まで、ツールを離れずに行えます。

## 使い方

1. **PDFをアップロード**をクリックするか、アップロード領域にファイルをドラッグします。複数のファイルに対応しています。
2. アップロードしたすべてのファイルのページが、サムネイル付きのスクロール可能なグリッドに表示されます。
3. ツールバーまたはページごとの操作ボタンでページを操作します。
4. 各カードのチェックボックスでページを選択し、一括操作を適用します。
5. はさみアイコンで分割位置を指定すると、出力が複数のファイルに分割されます。
6. **PDFをエクスポート**をクリックして最終結果をダウンロードします。分割マーカーがある場合、出力は複数のPDFを含むZIPになります。

## 機能

- **結合**: 複数のPDFをアップロードすると、自動的に1つのワークスペースにまとまります
- **並べ替え**: ページカードをドラッグ&ドロップして順序を変更します
- **回転**: ページごと、または一括で、90度単位 (左または右) に回転します
- **複製**: ワンクリックで任意のページを複製します
- **削除**: 個別のページ、または選択したページをまとめて削除します
- **PDFの挿入**: 指定したページの後ろに新しいPDFを追加します
- **空白ページの追加**: 末尾に空白のA4ページを追加します
- **分割**: ページの間に分割マーカーを置き、別々のPDFのZIPとしてエクスポートします
- **すべて選択 / 選択解除**: 一括操作のための素早い選択
- **元に戻す / やり直し**: すべての操作に対応した完全な履歴
- **選択したページをダウンロード**: 選択したページだけを独立したPDFとしてエクスポートします
- 破損したPDFは読み込み前に自動修復します

## ユースケース

- 複数の元PDFのページから独自の文書を作る
- スキャン文書の空白ページを削除し、横向きのスキャンを回転し、セクションを並べ替えて整える
- 視覚的な分割マーカーで、大きなPDFを章の区切りで分割する
- 本格的なPDFエディターを使わずに、手早くページ単位で編集する

## ヒント

- 元に戻す/やり直しはすべての操作を記録します。作業が誤って失われることはないので、気軽に使ってください。
- 分割マーカーはページ間の青い破線として表示されます。文書を分けたい位置に視覚的に置いてからエクスポートすると、ZIPが得られます。
- 単純な結合や分割には、専用の[PDFの結合](./merge-pdf)または[PDFの分割](./split-pdf)ツールのほうが速い場合があります。マルチツールは、1回のセッションで複数の操作が必要なときに力を発揮します。

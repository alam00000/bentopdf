# テキストの色の変更

PDF全体のテキストの色を置き換えます。このツールは各ページのテキスト領域を識別して選択した色に変更し、ドキュメントのレイアウトとテキスト以外の内容は保持します。

## 使い方

1. PDFファイルをアップロードします。
2. カラーセレクターで新しいテキストの色を選びます。デフォルトは青（#0000FF）です。
3. **テキストの色を変更**をクリックして処理します。
4. 色が変更されたPDFが自動的にダウンロードされます。進捗インジケーターに、処理中のページが表示されます。

## オプション

- **新しいテキストの色**：ドキュメント内のすべてのテキストの置き換え後の色を選ぶカラーピッカーです。

## 機能

- ドキュメントのすべてのページのテキストの色を変更
- 進捗表示付きのページごとの処理
- 16進数カラーに完全対応したカラーピッカー
- ページのレイアウトとテキスト以外の要素を保持

## 活用例

- 黒いテキストを濃い青に変えて、より柔らかく現代的なドキュメントの印象にする
- ドキュメントを配布する前に、ブランドガイドラインに合わせてテキストの色を変更する
- アクセシビリティ要件への準拠のために、テキストを特定の色にする
- 新しく適用した背景色に対して、テキストが見えるようにする

## ヒント

- このツールは品質を保つためにページを2倍のスケールで描画し、PDFを再構築します。出力は画像ベースになるため、テキストは選択も検索もできなくなります。
- 選択可能なテキストを保ちたいドキュメントでは、代わりに[PDFエディター](./edit-pdf)でPDFを直接編集することを検討してください。
- 各ページが個別に描画されるため、処理時間はページ数に応じて長くなります。

# スキャナー効果

きれいなデジタルPDFを、フラットベッドスキャナーから出てきたかのような見た目に変換します。ノイズ、わずかな回転、ぼかし、明るさの変化、任意の黄ばみを設定して適用し、物理的なスキャンの不完全さを再現します。

## 使い方

1. PDFファイルをアップロードします。
2. 1ページ目のライブプレビューと設定パネルが並んだエディターが開きます。
3. スライダーとトグルを使って、スキャン効果のパラメーターを調整します。
4. 設定を変更するたびに、プレビューがリアルタイムで更新されます。
5. **適用**をクリックして、すべてのページを処理し、結果をダウンロードします。

## オプション

- **カラースペース（グレースケールのトグル）**：出力をグレースケールに変換し、昔ながらの白黒スキャンの見た目にします。
- **枠線**：ページの端に目立たない暗い枠線を追加し、スキャナーの縁のアーティファクトを再現します。
- **回転**：わずかな回転（-5度から+5度）を適用し、紙のずれた給紙を再現します。
- **回転のばらつき**：回転角度にランダムなばらつきを加え、ページごとに少しずつ違う傾きにします。
- **明るさ**：全体の明るさを上げ下げします。
- **コントラスト**：コントラストを調整し、トナー品質の違いを再現します。
- **ぼかし**：ガウスぼかしを適用し、低品質のスキャンのようにテキストの縁をやわらげます。
- **ノイズ**：ランダムなピクセルノイズを加え、スキャナーセンサーの粒状感を再現します。値が高いほど粒子が粗くなります。
- **黄ばみ**：温かみのある黄色の色合いを加え、古い紙や再生紙を再現します。
- **解像度**：出力のDPIを設定します。値が低いほど、ピクセルが粗いスキャンらしい見た目になります。
- **リセット**：すべての設定をデフォルトに戻します。

## 機能

- 各パラメーターを調整するたびに更新されるリアルタイムプレビュー
- リアルな変化を出すための、ページごとのランダムな回転のばらつき
- 独立して調整できる10個のパラメーター
- 本物らしい白黒スキャンの出力に対応するグレースケールモード
- 低DPIのFAX品質から高DPIのアーカイブ品質まで対応する解像度の調整

## 活用例

- デジタルで作成したドキュメントを、スキャンして印刷したもののように見せる
- 歴史的な文書の再現のために、物理的な文書の経年劣化をシミュレートする
- 劣化したスキャン品質に対して、OCRソフトウェアをテストする
- 既存のスキャンされたアーカイブの見た目に合ったドキュメントを作成する

## ヒント

- 控えめな値から始めてください。ノイズレベル10から20、0.5度のわずかな回転、最小限のぼかしでも、十分にスキャンらしい見た目になります。
- グレースケールモードとわずかな黄ばみを組み合わせると、「コピーのコピー」のような効果になります。
- 低めの解像度設定（100から150 DPI）にすると、最もリアルなFAX機の見た目になります。

# PDFの回転

PDFのページを時計回りまたは反時計回りに90度回転します。すべてのページのサムネイルプレビューが表示され、個別に回転することも、ドキュメント全体を一括で回転することもできます。

## 使い方

1. PDFファイルをアップロードします。すべてのページのサムネイルがグリッドに表示されます。
2. 各ページのサムネイルの下にある左/右の回転ボタンで、そのページを回転します。
3. 上部の一括回転コントロールで、すべてのページを一度に回転します。
4. サムネイルのプレビューがリアルタイムで更新され、回転の状態が表示されます。
5. 処理ボタンをクリックして、回転したPDFを保存します。

## 機能

- 90度単位のページごとの回転（左または右）
- すべてのページを同時に回転する一括回転
- アニメーション付きの回転トランジションを備えた、リアルタイムのサムネイルプレビュー
- 大きなドキュメントでも滑らかに動作する、サムネイルの遅延読み込み
- 元のページ内容と品質を保持

## 活用例

- 横向きや上下逆さまにスキャンされたページを修正する
- 横向きのページを縦向きに回転する（またはその逆）
- 一部のページが誤った角度でスキャンされた、向きが混在するドキュメントを修正する
- 特定の表示の向きに合わせてドキュメントを準備する

## ヒント

- 回転は累積されます。時計回りのボタンを2回クリックすると、180度回転します。
- 90度以外の回転（例：わずかに傾いたスキャンを直す45度）には、代わりに[任意の角度で回転](./rotate-custom)を使用してください。
- 一括回転コントロールは、選択したページだけでなくすべてのページに作用します。このツールには選択機能がありません。選択が必要な場合は、[PDFマルチツール](./pdf-multi-tool)を使用してください。

# FB2からPDF

FictionBook 2（FB2）ファイルをPDFドキュメントに変換します。FB2はXMLベースの電子書籍フォーマットで、ロシアや東欧で広く使われています。一部のプラットフォームでは対応していますが、ほとんどの環境ではほぼ知られていません。PDFに変換すれば、どこでも本を読めるようになります。

## 対応フォーマット

| フォーマット  | 拡張子 | 備考                    |
| :------------ | :----- | :---------------------- |
| FictionBook 2 | `.fb2` | XMLベースの電子書籍形式 |

## 使い方

1. アップロードエリアをクリックするか、FB2ファイルをドラッグ＆ドロップします。複数ファイルの一括選択も可能です。
2. ファイル一覧を確認します。ゴミ箱アイコンで個別に削除でき、**ファイルを追加**でさらに追加できます。
3. **PDFに変換**をクリックします。PyMuPDFエンジンがFB2のXML構造を解析し、ページ分割されたPDFとして出力します。
4. ファイルが1つの場合はPDFが直接ダウンロードされます。複数の場合は`fb2-converted.zip`にまとめられます。

## オプション

設定は不要です。コンバーターがFB2のXML構造を自動で処理し、章の区切り、書式、埋め込み画像を保持します。

## 活用例

- PDFにしか対応していない端末やアプリでFB2の電子書籍を読む
- FB2形式で配布されているロシア語文学を印刷する
- FB2ライブラリを、どこでも使える形式でアーカイブする
- FictionBookに対応していないリーダーを使っている相手に本を共有する

## ヒント

- FB2ファイルはプレーンなXMLなので、サイズが小さく、ブラウザー上でも素早く変換できます。
- FB2ファイルが`.fb2.zip`として圧縮されている場合は、先に展開してからアップロードしてください。

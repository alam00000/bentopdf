# PDFからZIP

複数のPDFファイルを1つのZIPアーカイブにまとめます。シンプルなパッケージツールで、PDF自体の変換、圧縮、変更は行いません。

## 使い方

1. ドロップゾーンを使って、複数のPDFファイルをアップロードします。
2. ファイルの一覧を確認します。含めたくないものは削除します。
3. 処理ボタンをクリックします。
4. アップロードしたすべてのPDFを含むZIPアーカイブがすぐにダウンロードされます。

## 機能

- 任意の数のPDFファイルに対応
- アーカイブ作成前にファイルごとに削除可能
- ZIP内で元のファイル名を保持
- PDFの内容は変更せず、ファイルはそのままパッケージ化
- アップロードした各PDFのファイル名とサイズを表示

## ユースケース

- メールに添付するため、請求書や領収書をまとめる
- 引き継ぎのために、プロジェクトの成果物 (複数のPDFレポート) をまとめる
- フォームやテンプレートのコレクションを、1回でダウンロードできるようにする
- 一連の文書を1つの圧縮ファイルに保管する

## ヒント

- ZIPファイルには元のPDFのファイル名が使われます。同じ名前のファイルがある場合は、競合を避けるためアップロード前に名前を変更してください。
- このツールはPDF自体を圧縮しません。ファイルサイズを減らしたい場合は、先にPDFの圧縮を通してから、このツールでまとめてください。

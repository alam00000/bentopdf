# 背景色

PDF の既存の内容の背後に、単色の背景色を設定します。このツールは各ページに色付きの長方形を作成し、その上に元の内容を重ねるため、テキスト、画像、グラフィックは新しい背景の上でもすべてはっきり見えます。

## 使い方

1. PDF ファイルをアップロードします。
2. カラーセレクターで背景色を選びます。デフォルトは明るい黄色（#FFFFCC）です。
3. **背景色を変更**をクリックして処理します。
4. 更新された PDF が自動的にダウンロードされます。

## オプション

- **背景色** -- 好きな単色を選べる標準のカラーピッカーです。デフォルトは明るい黄色です。

## 機能

- すべてのページに均一な背景色を適用
- 元の内容（テキスト、画像、ベクターグラフィック）を色付きレイヤーの上にすべて保持
- 元のページサイズを維持
- ページ数に関係なく利用可能

## ユースケース

- 明るいクリーム色やアイボリーの背景を付けて、文書に紙のような柔らかい印象を与える
- カテゴリーごとに異なる背景色を適用して、文書セットを色分けする
- 同じ文書を、読者に応じて見た目の異なるバージョンにする
- 文書を画面に映すときに、明るい背景の色味を加えて読みやすくする

## ヒント

- 明るく落ち着いた色が最適です。テキストがすでに明るい色でない限り、非常に暗い背景ではテキストが読みにくくなることがあります。
- 背景色とテキストの色の両方を変えたい場合は、先に背景色を適用してから、その結果に対して [テキストの色の変更](./text-color) を使用してください。
- このツールは PDF の構造レベルで動作し（ラスタライズではありません）、出力でもテキストを選択、検索できます。

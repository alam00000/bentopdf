# PowerPointからPDF

プレゼンテーションファイルをPDFに変換します。各スライドが出力ドキュメントの1ページになり、テキスト、画像、図形、トランジションがブラウザ上のLibreOfficeエンジンで描画されます。新しい形式と古い形式のPowerPoint、さらにOpenDocument Presentation形式に対応しています。

## 対応フォーマット

| フォーマット              | 拡張子  |
| :------------------------ | :------ |
| PowerPoint（新形式）      | `.pptx` |
| PowerPoint（旧形式）      | `.ppt`  |
| OpenDocument Presentation | `.odp`  |

## 使い方

1. アップロード領域をクリックするか、プレゼンテーションファイルをドラッグアンドドロップします。
2. ファイル一覧を確認します。必要に応じてファイルを追加または削除します。
3. **PDFに変換**をクリックします。LibreOfficeエンジンは初回使用時に読み込まれ、その後各ファイルが変換されます。
4. ファイルが1つの場合はPDFとして直接ダウンロードされます。複数の場合は`powerpoint-converted.zip`にまとめられます。

## オプション

このツールに追加の設定はありません。スライドは元のサイズで描画されます。

## 出力

| 入力数        | 出力                                                                        |
| :------------ | :-------------------------------------------------------------------------- |
| 1ファイル     | PDFを1つダウンロード（元のファイル名に`.pdf`拡張子）                        |
| 2ファイル以上 | ZIPアーカイブ（`powerpoint-converted.zip`）に、ファイルごとに1つのPDFを格納 |

## 活用例

- PowerPointを持っていない相手に共有する前に、プレゼンテーションをPDFに変換する
- 会議やワークショップ向けに、スライドの印刷用配布資料を作成する
- どの端末でも同じように表示される形式でプレゼンテーションを保管する
- LibreOffice ImpressのODPプレゼンテーションをまとめてPDFに変換する
- メールに添付するために、ピッチデッキのPDF版を作成する

## ヒント

- スライドのアニメーションやトランジションはPDFには反映されません。各スライドは静止したページとして取り込まれます。
- 埋め込まれた動画は出力に表示されません。必要に応じて、スクリーンショットやプレースホルダー画像に置き換えてください。
- スピーカーノートは、デフォルトのPDF出力には含まれません。ノートが必要な場合は、先にPowerPoint標準の「ノートの印刷」ビューから書き出すことを検討してください。
- LibreOfficeエンジンは初回の読み込み後にキャッシュされるため、同じセッションで2つ目のプレゼンテーションを変換するときははるかに高速です。

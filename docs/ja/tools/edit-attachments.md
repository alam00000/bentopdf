# 添付ファイルの編集

PDF内のファイル添付を調べて管理します。このツールは、埋め込まれたすべてのファイルを、名前と添付レベルとともに一覧表示し、個々の添付ファイルを削除対象にするか、すべてをまとめて取り除くことができます。

## 使い方

1. PDFファイルをアップロードします。
2. ツールが自動的に添付ファイルをスキャンし、一覧に表示します。
3. 各添付ファイルには、ファイル名と、文書レベルかページレベルの添付かが表示されます。
4. 添付ファイルの横にあるゴミ箱アイコンをクリックすると、削除対象になります（もう一度クリックすると解除されます）。
5. **すべての添付ファイルを削除** ボタンですべてを一度に選択するか、**すべて選択解除** で選択を解除します。
6. 処理ボタンをクリックして、選択した添付ファイルを取り除いた新しいPDFを保存します。

## 機能

- 文書レベルとページレベルのすべての添付ファイルを一覧表示
- 個別または一括での添付ファイルの削除
- 確定する前に、選択のオンとオフを切り替え可能
- 削除対象の項目に、取り消し線と不透明度の変化を視覚的に表示
- 選択した添付ファイルを取り除いた、変更後のPDFをダウンロード

## 活用例

- 再配布の前に、文書に埋め込まれた古い、または誤ったファイルを削除する
- 共有の前に、PDFから機密性の高い添付ファイル（財務データ、個人情報）を取り除く
- 不要になった大きな埋め込みファイルを削除して、PDFのファイルサイズを減らす
- 埋め込まれたコンテンツを監査し、アーカイブの前に文書を整理する

## ヒント

- 削除対象の添付ファイルは、取り消し線付きで表示されます。気が変わった場合は、処理の前に元に戻せます。
- 添付ファイルが見つからない場合、ツールは「添付ファイルが見つかりません」というメッセージを表示します。そのPDFには埋め込みファイルが含まれていないということです。

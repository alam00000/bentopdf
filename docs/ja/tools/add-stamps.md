# スタンプの追加

スタンプ用アノテーションツールバーを備えた埋め込みビューアを使って、PDF のページに画像スタンプを配置します。スタンプには自分の名前を含めて帰属を示せるため、承認ワークフロー、レビュー作業、文書への押印に便利です。

## 使い方

1. **スタンプのユーザー名**欄に名前を入力します。この名前は、作成するスタンプに表示されます。
2. PDF ファイルをクリックするか、ドロップゾーンにドラッグしてアップロードします。
3. 文書がビューアに読み込まれた状態で、スタンプエディタが開きます。
4. ツールバーの画像スタンプツールを使って、任意のページにスタンプを選択して配置します。
5. 必要に応じて、スタンプの位置とサイズを調整します。
6. **スタンプ済み PDF を保存**をクリックして、結果をダウンロードします。

## 機能

- スタンプ専用のアノテーションツールバーを備えた統合 PDF ビューア
- 作成したスタンプにユーザー名を表示
- 任意のページに画像スタンプを配置可能
- ドラッグ＆ドロップによる位置調整とサイズ変更
- ページの縦横比に応じたビューアの自動サイズ調整
- ファイル名とサイズ情報の表示

## ユースケース

- レビューワークフローで、文書に「承認済み」や「確認済み」の画像スタンプを追加する
- 公式文書に会社の社印や公証人の印影画像を配置する
- 確認者の名前入りの「受領」スタンプをページに押す
- 検査報告書に品質管理スタンプを追加する

## ヒント

- PDF をアップロードする前に、スタンプのユーザー名を設定してください。ユーザー名はスタンプのメタデータに埋め込まれます。
- ビューアの高さは、PDF の最初のページの縦横比に合わせて調整され、見やすい表示になります。
- 画像スタンプではなく、テキストベースの透かしを入れたい場合は、[透かしの追加](./add-watermark) ツールを使用してください。

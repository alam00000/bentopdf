# JPGからPDF

JPG画像をきれいなPDFにします。ファイルを1つだけ、または複数のJPGをまとめてアップロードでき、各画像が出力文書のフルサイズの1ページになります。

## 対応フォーマット

| フォーマット | 拡張子          |
| :----------- | :-------------- |
| JPEG         | `.jpg`, `.jpeg` |
| JPEG 2000    | `.jp2`, `.jpx`  |

## 使い方

1. アップロードエリアをクリックするか、JPGファイルをドラッグ＆ドロップします。複数選択に対応しています。
2. アップロードしたファイルを確認します。ゴミ箱アイコンで個別に削除でき、**ファイルを追加**で一覧に追加できます。
3. **PDFの品質**を選びます。
4. **PDFに変換**をクリックします。ツールは品質設定に応じて画像を圧縮し、PyMuPDFエンジンで変換して、`from_jpgs.pdf`をダウンロードします。

## オプション

**PDFの品質**は、PDFに埋め込む前に各画像へ適用する圧縮を調整します。

- **高品質**: 細部を最大限に保ちます。写真や印刷向けです。
- **中品質**（初期値）: 鮮明さとファイルサイズのバランスが良い設定です。
- **低品質**: 強力に圧縮して、出力を最小にします。

## 活用例

- JPGで保存したスキャン文書を、提出用の1つのPDFにまとめる
- 顧客向けに、商品写真をカタログとしてまとめる
- 医療や衛星のJPEG 2000画像を、持ち運びしやすいPDFにする
- カメラから書き出した写真で、印刷用のフォトアルバムを作る

## ヒント

- 標準のJPEGだけでなく、JPEG 2000ファイル（`.jp2`、`.jpx`）にも完全に対応しています。医療画像や地理空間データに便利です。
- スマートフォンのカメラで撮ったJPGなら、中品質にすると、画面上では違いが見えないまま、高品質よりファイルが40〜60%小さくなることが多いです。

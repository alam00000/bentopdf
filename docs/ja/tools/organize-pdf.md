# 複製と整理

視覚的なドラッグ&ドロップ操作で、PDFのページを並べ替え、複製、削除します。各ページはサムネイルとして表示され、移動、複製、削除をしてから新しいファイルとして保存できます。

## 使い方

1. PDFファイルを1つアップロードします。
2. すべてのページを示すサムネイルグリッドが表示されます。
3. サムネイルをドラッグしてページを並べ替えます。緑の複製ボタンでページを複製し、赤の削除ボタンでページを削除します。
4. または、テキストフィールドにカスタムページ順 (例: `3, 1, 2, 4`) を入力して**適用**をクリックすると、すべてのページを一度に並べ替えられます。
5. 処理ボタンをクリックして、整理したPDFを作成しダウンロードします。

## 機能

- アニメーション付きのドラッグ&ドロップによるページの並べ替え
- ページごとの複製ボタンと削除ボタン
- 正確な並べ替えのためのカスタムページ順入力
- 変更のたびに自動更新されるページ番号ラベル
- 最後に残った1ページは削除できません

## ユースケース

- レポートの中で位置がずれたページを正しい位置に移動する
- フォームのページを複製し、1つのファイルに複数の空白コピーを作る
- 文書を配布する前に、下書きやプレースホルダーのページを削除する
- 印刷準備のためにページ順を逆にしたり入れ替えたりする
- 別々のファイルを再結合せずに、独自のページ順序を作る

## ヒント

- カスタムページ順のフィールドには、元のページ番号をカンマ区切りで入力します。すべてのページをちょうど1回ずつ含める必要があり、抜けや重複は使えません。
- ページを複製すると、2つのコピーは同じ元のページインデックスを参照します。どちらのコピーも独立して並べ替えられます。
- 複数ファイルにまたがる一括操作やより高度なワークフローには、代わりに[PDFマルチツール](./pdf-multi-tool)をご検討ください。

# 空白ページの削除

PDFをスキャンして、空白またはほぼ空白のページを自動的に削除します。このツールは各ページを描画してピクセルの内容を分析し、空白かどうかを判定した上で、処理の前にどのページを削除するか確認できます。

## 使い方

1. PDFファイルをアップロードします。
2. **感度**スライダーを調整して、「空白」の判定の厳しさを決めます。
3. **空白ページを検出**をクリックして、ドキュメントをスキャンします。
4. 検出された空白ページのサムネイルが表示されるので、確認します。
5. 選択を確定して、空白ページを削除したPDFをダウンロードします。

## オプション

- **感度**：0%から100%までのスライダー（デフォルトは80%）。値が高いほど厳しくなり、完全にまたはほぼ白いページだけを対象にします。値が低いほど寛容になり、1つの点やかすかな透かしのような、わずかな内容を含むページも検出します。

## 機能

- ページごとのピクセルレベル分析で空白の内容を検出
- 検出を細かく調整できる感度スライダー
- 検出された空白ページを目視で確認できるページサムネイルのプレビュー
- 空白でないページはそのまま保持
- どんなサイズやページ数のドキュメントにも対応
- スキャン中の進捗表示

## 活用例

- 片面の原稿をスキャンしたときに取り込まれた、空の裏面を取り除く
- 一括スキャンした文書の束から、区切りのページを削除する
- 文書管理システムが挿入した空白ページを取り除く
- ワープロから書き出したPDFに含まれることがある、末尾の空白ページを取り除く
- 不要な空ページを削除して、ファイルサイズを小さくする

## ヒント

- まずデフォルトの感度80%で試し、そこから調整してください。空白に見えるページを見逃す場合は感度を下げ、残したい薄い内容のページが検出される場合は感度を上げます。
- このツールは内容を分析するために各ページを描画するため、処理時間はページ数に比例します。非常に大きなドキュメントでは、少し待つことになります。
- 削除を確定する前に、サムネイルのプレビューで検出された空白ページを確認してください。かすかなヘッダー、フッター、透かしのあるページは、感度の設定によっては検出されることがあります。

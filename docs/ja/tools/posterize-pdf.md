# PDFのポスタライズ

PDFの各ページを、小さなサブページのグリッドに分割します。1ページを複数枚の用紙に印刷し、それらをつなぎ合わせて大きなポスターやバナーを作るためのツールです。

## 使い方

1. PDFファイルをアップロードします。
2. **行**と**列**の数を設定してグリッドを決めます（例：2行 x 2列なら各ページが4つのサブページに分割されます）。
3. 必要に応じて、ポスタライズするページ範囲を指定します。
4. プレビューキャンバスには現在のページにグリッドが重ねて表示されるため、切り取り位置を確認できます。
5. ページを切り替えて、他のページのオーバーレイも確認します。
6. 処理ボタンをクリックします。グリッドの各セルが、出力PDFの1ページになります。

## 機能

- 行数と列数を自由に設定でき、柔軟なグリッドサイズに対応
- ページが分割される位置を正確に示すグリッドオーバーレイ付きのライブプレビュー
- 特定のページだけをポスタライズするページ範囲フィルター
- プレビューでのページ単位の移動
- ページのスナップショットをキャッシュし、プレビューの移動を高速化
- 赤い破線のグリッド線で切り取りの境界を明確に表示

## オプション

| オプション     | 説明                                         |
| -------------- | -------------------------------------------- |
| **行**         | 横方向の分割数（デフォルト：1）              |
| **列**         | 縦方向の分割数（デフォルト：1）              |
| **ページ範囲** | ポスタライズするページ（空欄の場合はすべて） |

## 活用例

- ポスターサイズのPDFを標準のA4またはレターサイズの用紙に印刷し、壁の上で組み立てる
- 1ページのPDFデザインから大きなバナーを作る
- 大きすぎる技術図面を印刷可能なタイルに分割する
- 大判プリンターがなくても大判印刷を行う

## ヒント

- 2x2のグリッドは1ページを4ページに、3x3のグリッドは1ページを9ページにします。組み立てた後の大きさに合わせてグリッドを計画してください。
- プレビューのオーバーレイで、重要な内容が切り取り線にかからないか確認できます。必要に応じて行や列を調整してください。
- 逆の操作（複数のページを1枚にまとめる）には、[N-Up PDF](./n-up-pdf)を使用します。

# PDFからテキスト

PDFファイルからすべてのテキストコンテンツを抽出し、プレーンな`.txt`ファイルとして保存します。一括処理に対応しており、複数のPDFをアップロードすると、1回の操作でそれぞれのテキストを抽出できます。PyMuPDFを使用しています。

## 使い方

1. ドロップゾーンをクリックするか、ファイルをドラッグして、1つ以上のPDFをアップロードします。ファイルリストは、追加ボタンとクリアボタンで管理できます。
2. **抽出**をクリックして処理を開始します。
3. 1つのファイルは`filename.txt`としてダウンロードされます。複数のファイルは`pdf-to-text.zip`アーカイブになります。

## オプション

このツールに設定可能なオプションはありません。すべてのページのテキストコンテンツが、読み順に抽出されます。

## 出力形式

- **単一ファイル**: `filename.txt`
- **複数ファイル**: 入力したPDFごとに1つの`.txt`を含む`pdf-to-text.zip`。

## ユースケース

- 全文検索のインデックス作成のために、PDFレポートから本文を抽出する。
- PDFの電子書籍や記事を、電子ペーパー端末で読めるプレーンテキストに変換する。
- キーワード分析のために、契約書や法的文書からテキストを取り出す。
- データ処理スクリプト用に、PDFから書式を取り除いてきれいなテキストにする。
- 自然言語処理のために、PDFアーカイブからテキストコーパスを準備する。

## ヒント

- スキャンされたPDF (画像のみ) は、抽出できるテキストレイヤーがないため、空のテキストファイルになります。スキャンした文書は、先にOCRにかけてください。
- 出力は、PyMuPDFが解釈した読み順を保持します。一般的には左から右、上から下の順です。複数段組みのレイアウトでは、テキストが入り混じることがあります。
- 見出しや書式を含む構造化された出力には、[PDFからマークダウン](./pdf-to-markdown)をお試しください。AI向けの構造化JSONには、[AI用のPDFを準備する](./prepare-pdf-for-ai)を使ってください。

# 透かしの追加

ビジュアルエディタを使って、PDF のページにテキストまたは画像の透かしを追加します。プレビュー上で透かしを直接ドラッグして位置を決め、角のハンドルでサイズを変更し、不透明度、回転、フォント、色を設定できます。ページごとに透かしの位置を変えることも、すべてのページに同じ透かしを一括で適用することもできます。

## 使い方

1. PDF ファイルをアップロードします。
2. 最初のページのライブプレビューと、ドラッグ可能な透かしのオーバーレイが表示されたエディタが開きます。
3. 切り替えボタンで、**テキスト**または**画像**の透かしモードを選びます。
4. サイドバーのパネルで透かしの設定を行います。
5. プレビュー上で透かしをドラッグして、好みの位置に正確に配置します。サイズを変えるには、角のハンドルを使います。
6. ページを移動してページごとの透かしを設定するか、**すべてのページに適用**をオンのままにします。
7. **透かしを追加**をクリックして、処理とダウンロードを行います。

## オプション

**テキスト透かしの設定:**

- **テキスト** -- 透かしの文字列です（例: "CONFIDENTIAL"、"DRAFT"）。
- **フォントサイズ** -- 10 ～ 200 ポイントです。デフォルトは 72 です。
- **色** -- カラーピッカーで好きな色を選べます。
- **不透明度** -- 完全な透明から完全な不透明まで、透明度を調整できます。
- **回転** -- 透かしの文字を -180 度から 180 度の範囲で回転できます。

**画像透かしの設定:**

- **画像のアップロード** -- 透かしとして使う PNG、JPG などの画像ファイルをアップロードします。
- **不透明度** -- 画像の透明度を調整します。
- **スケール** -- 画像透かしのサイズを変更します。

**レイアウトの設定:**

- **単一** -- 1 ページに透かしを 1 つ配置します。ドラッグするか、位置のプリセットで位置を決めます。
- **タイル** -- 回転角度に沿った斜めのグリッド状に、ページ全体へ透かしを繰り返し配置します。これにより、透かしが文書の端から端までを覆います。
- **水平方向の間隔** -- 文字方向に沿ったタイル間の間隔です。透かしの幅に対する割合（パーセント）で指定します（タイルモードのみ）。
- **垂直方向の間隔** -- タイルの行間の間隔です。透かしの高さに対する割合（パーセント）で指定します（タイルモードのみ）。

**一般設定:**

- **すべてのページに適用** -- オンにすると、すべてのページに同じ透かしが適用されます。オフにすると、ページごとに個別の透かしを設定できます。
- **ページ範囲** -- 透かしを入れるページを指定します（例: "1-3, 5, 7-9" や "all"）。

## 機能

- ライブ PDF プレビュー上での、ビジュアルなドラッグ＆ドロップによる位置決め
- 角のハンドルでサイズ変更できる透かし
- テキストと画像の透かしモード
- 間隔を調整できる、単一配置またはページ全体のタイル（繰り返し）レイアウト
- ページごと、または全体への透かしの適用
- プレビューでのページ単位の移動
- 不透明度と回転のコントロール
- ページ範囲によるフィルタリング

## ユースケース

- レビュー用に回覧する前に、下書き文書へ "DRAFT" の透かしを入れる
- 機密性の高い財務レポートに "CONFIDENTIAL" の透かしを追加する
- 会社のロゴ画像の透かしで文書にブランドを付ける
- 見込み客と共有する製品ドキュメントに "SAMPLE" と押印する
- 配布する PDF 資料に著作権表示を追加する

## ヒント

- ページを斜めに横切る透かしにするには、回転を約 45 度に設定し、フォントサイズを大きくします。
- タイルモードにすると、トリミングしても透かしが何十個も残るため、文書の再利用がはるかに難しくなります。タイルにする場合は、下の文字が読めるように不透明度を下げてください。
- 背景が透明な画像透かし（PNG 形式）は、文書の内容とより自然になじみます。
- ページごとに異なる透かしテキストが必要な場合は、「すべてのページに適用」をオフにして、ページごとに移動しながら設定してください。

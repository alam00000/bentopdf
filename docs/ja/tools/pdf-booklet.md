# PDFブックレット

PDFのページをブックレットの面付け順に並べ替えます。両面印刷して半分に折ると、ページが正しい読み順になります。中綴じの冊子やジンで使われるレイアウトです。

## 使い方

1. PDFファイルをアップロードします。
2. ブックレットの設定を行います。出力ページサイズと向きを選びます。
3. **プレビューを生成**をクリックして、各シートでのページの配置を確認します。
4. プレビューを確認します。各用紙の表面と裏面に割り当てられたページが表示されます。
5. **ダウンロード**をクリックして、面付け済みのブックレットPDFを保存します。

## 機能

- 中綴じ製本のための自動ページ並べ替え
- 出力ページサイズの設定
- ダウンロード前にブックレットのレイアウトを視覚的にプレビュー
- ページ数が奇数の場合は必要に応じて空白ページを挿入
- 元のページをブックレットの用紙サイズに合わせて拡大縮小

## ユースケース

- 通常のPDFから印刷できるブックレットやジンを作る
- 社内印刷用にカンファレンスのプログラムやイベントガイドを準備する
- 二つ折りのグリーティングカードや小さなカタログを作る
- 手製本用の小冊子や詩集を作る

## ヒント

- きれいなブックレットにするには、元のPDFのページ数が4の倍数であることが理想です。そうでない場合は、最後の用紙を埋めるため空白ページが自動的に追加されます。
- 出力は、プリンターの「短辺とじ」で両面印刷し、すべての用紙を重ねて折り、背をホチキスで留めてください。
- ブックレット順にせず、単に複数のページを1枚の用紙に並べたい場合は、代わりに[N-Up PDF](./n-up-pdf)を使ってください。

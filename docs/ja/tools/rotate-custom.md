# 任意の角度で回転

PDFのページを、90度単位に限らず任意の角度で回転します。各ページに個別の角度入力欄があり、一括コントロールを使って、すべてのページに同じ角度を一度に適用することもできます。

## 使い方

1. PDFファイルをアップロードします。すべてのページのサムネイルが描画されます。
2. 各ページには、現在の回転角度を示す数値入力欄があります。
3. 特定のページを回転するには、任意の角度（正または負）を入力します。90度単位ですばやく調整するには、ページごとの左/右ボタンを使用します。
4. 上部の**一括角度**入力欄で、すべてのページに共通の回転を設定します。
5. 処理ボタンをクリックして、回転したPDFを生成します。

## 機能

- ページごとの自由な角度入力（任意の整数値）
- すべてのページに同じ回転を設定する一括角度コントロール
- サムネイルでの回転のリアルタイムプレビュー
- 90度単位のページごとのクイック回転ボタン
- 大きなドキュメントでも快適に動作する、サムネイルの遅延読み込み

## 活用例

- 数度だけ傾いたスキャンを補正する
- 標準的でない向きの要件に合わせてページを回転する
- 内容が混在するドキュメントの個々のページに、正確な回転を適用する
- 最初に一括回転した後で、ページの角度を微調整する

## ヒント

- 正の値は時計回り、負の値は反時計回りに回転します。
- 一括角度欄を適用すると、ページごとの角度がすべて上書きされます。個別の調整が必要な場合は、一括操作の後で行ってください。
- 90/180/270度の標準的な回転をより簡単な画面で行うには、[PDFの回転](./rotate-pdf)を使用してください。

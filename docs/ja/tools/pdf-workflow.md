# PDFワークフロービルダー

ワークフロービルダーを使うと、複数のPDF操作を1つの自動化パイプラインにつなげられます。ツールを1つずつ実行する代わりに、入力、処理、出力のノードを視覚的なグラフとしてつなぎ、ワンクリックですべてを実行します。ファイルがブラウザの外に出ることはありません。

## 使い方

画面は3つのパネルに分かれています。左の**ノードツールボックス**、中央の**キャンバス**、ノードを選択すると右に表示される**設定パネル**です。

1. **ノードを追加**するには、左のサイドバーでクリックするか、キャンバスに直接ドラッグします。ツールボックス上部の検索バーで名前による絞り込みができます。
2. **ノードを接続**するには、出力ソケット (ノードの下側) から別のノードの入力ソケット (上側) へドラッグします。接続は上から下へ流れます。
3. **設定する**には、ノードをクリックして右側の設定パネルを開きます。ノードの種類ごとに独自のオプション (ページ範囲、品質スライダー、パスワードなど) があります。
4. **ワークフローを実行**するには、ツールバーの**実行**ボタンをクリックします。エンジンはノードをトポロジカル順に実行し、1つずつ処理します。下部のステータスバーで進行状況を確認できます。
5. **結果をダウンロード**するには、最後のダウンロードノードが最終的なPDF (複数ファイルが生成された場合はZIP) を保存します。

## ノードのカテゴリ

ノードは6つのカテゴリに整理されており、キャンバス上で色分けされています。

- **入力** (青): PDF入力、画像入力、Word/Excel/PowerPointからPDF、およびパイプラインにファイルを渡す15種類以上のその他の形式コンバーター。
- **編集と注釈** (インディゴ): トリミング、グレースケール、色の反転、透かし、ページ番号、ヘッダーとフッター、スキャナー効果、色の調整、背景色、空白ページの削除、注釈の削除。
- **整理と管理** (紫): 結合、分割、ページの抽出、回転、ページの削除、反転、空白ページの追加、ページの分割、N-Up、ページサイズの固定、単一ページに結合、ブックレット、ポスター化、メタデータの編集、目次、OCR。
- **最適化と修復** (琥珀): 圧縮、ラスタライズ、リニアライズ、傾き補正、PDFからPDF/A、フォントのアウトライン化、修復。
- **PDFの保護** (ローズ): 暗号化、復号、サニタイズ、平坦化、電子署名、墨消し。
- **出力** (ティール): ダウンロード (単一のPDFかZIPかを自動判別)、PDFから画像、PDFからテキスト、PDFからDOCX、PDFからXLSX、PDFからCSV、PDFからSVG、PDFからMarkdown、画像の抽出。

## ワークフローの保存と読み込み

ツールバーには4つの保存オプションがあります。

- **保存**: 現在のワークフローを、名前付きテンプレートとしてブラウザのローカルストレージに保存します。複数のテンプレートを保存できます。
- **読み込み**: 保存済みのテンプレートをすべて一覧表示するモーダルを開きます。読み込みをクリックして復元するか、不要になったテンプレートを削除できます。
- **エクスポート**: ワークフローを`.json`ファイルとしてダウンロードし、共有やバックアップに使えます。
- **インポート**: ディスクから`.json`のワークフローファイルを読み込み、すべてのノード、位置、接続を復元します。

テンプレートはローカルストレージにセッションをまたいで保持されます。エクスポートしたJSONファイルは、ブラウザやマシンの間で持ち運べます。

## 実行モデル

エンジンは接続から依存関係グラフを作成し、ノードをトポロジカル順に実行します。いずれかのノードが失敗すると実行は停止し、失敗したノードが赤く表示されます。次のルールに注意してください。

- すべてのワークフローには、少なくとも1つの**入力**ノードと1つの**出力**ノードが必要です。
- エンジンは循環依存を検出し、エラーを出して実行をブロックします。
- **暗号化**ノードは、出力ノードの直前の最後の処理ステップにする必要があります。それより前に置くと、下流のノードは暗号化されたデータを扱えないため、検証の警告が出ます。
- パスワード保護されたPDFは、実行中にパスワードの入力を求められます。
- 複数のPDF入力に対応しています。結合ノードでまとめることも、一括処理ノードで各PDFを個別に処理することもできます。

## ソケットの種類

接続には型付きのソケットが使われ、無効な配線を防ぎます。

- **PDF** (インディゴ): 1つのPDF文書。
- **MultiPDF** (琥珀): まとめられた複数のPDF文書。
- **画像** (緑): 画像のBlob。

## オプション

各ノードには、右側の設定パネルから行える独自の設定があります。よくあるパターンは次のとおりです。

- 分割、ページの抽出、ページの削除ノードの**ページ範囲**
- 画像変換の出力ノードの**品質スライダー**
- 暗号化と復号ノードの**パスワード欄**
- 透かし、ヘッダーとフッター、メタデータの編集の**テキスト入力**
- 回転ノードの**回転角度**
- 圧縮ノードの**圧縮レベル**
- OCRノードの**OCR言語の選択**

## ユースケース

- **請求書処理パイプライン**: PDF入力 -> OCR -> 表の抽出 -> CSVとしてダウンロード。
- **レポートの標準化**: WordからPDF -> ページサイズの固定 -> ページ番号の追加 -> 透かし -> 圧縮 -> ダウンロード。
- **保管の準備**: PDF入力 -> 修復 -> 平坦化 -> サニタイズ -> PDFからPDF/A -> ダウンロード。
- **画像の一括抽出**: PDF入力 (複数ファイル) -> 画像の抽出 -> ZIPをダウンロード。
- **印刷用ブックレット**: PDF入力 -> ブックレット -> トリミング -> 圧縮 -> ダウンロード。
- **安全な配布**: PDF入力 -> 墨消し -> 注釈の削除 -> 暗号化 -> ダウンロード。

## ヒント

- **Delete**または**Backspace**を使うと、選択したノードをキャンバスから削除できます。
- ノードのステータスバーにある**X**ボタンをクリックすると、そのノードを直接削除できます。
- 何もない場所をクリックしてドラッグすると、キャンバスを移動できます。移動中はカーソルがつかむアイコンに変わります。
- モバイルでは、ツールバーの<strong>+</strong>ボタンでノードツールボックスを切り替えます。
- ワークフローが複数の出力ファイルを生成する場合、ダウンロードノードが自動的にZIPにまとめます。
- まずはシンプルに、2ノードのパイプラインを作ってテストしてから、複雑にしていきましょう。

# PDFフォーム入力機能

フォームフィールドのあるPDFを開き、埋め込みビューアーで直接入力できます。標準のAcroFormフィールドと、従来のXFA（XML Forms Architecture）フォームの両方に対応しています。入力が終わったら、ワンクリックで記入済みのPDFをダウンロードできます。

## 使い方

1. フォームフィールドを含むPDFをアップロードします。
2. 文書が統合PDFビューアーで開き、フォームフィールドがインタラクティブな入力欄として表示されます。
3. テキストフィールド、チェックボックス、ドロップダウン、ラジオボタンをクリックして入力します。
4. **保存してダウンロード**をクリックすると、記入済みのPDFが取得できます。

## 機能

- フォームフィールドを操作できる、PDF.jsの埋め込みビューアー
- 標準のAcroFormフィールド（テキスト入力、チェックボックス、ドロップダウン、ラジオボタン）に対応
- 従来のXMLベースのフォーム向けにXFAフォームに対応
- ページ寸法に合わせたビューアーサイズの自動調整
- ファイル名とサイズの表示

## オプション

追加の設定項目はありません。フォームをアップロードして入力し、ダウンロードするだけです。

## 活用例

- 税務書類、保険の申込書、役所の書類に記入する
- PDFの添付ファイルで届いた求人応募フォームに記入する
- 取引先登録フォームやサプライヤー向けアンケートに記入する
- チェックボックスのフィールドでコンプライアンスのチェックリストを承認する
- 診察前に問診票に記入する

## ヒント

- XFAフォームは従来の形式で、一部のPDFビューアーでしか対応していません。XFAのPDFをChromeやほとんどのツールで開いて空白ページが表示される場合、それらのビューアーがXFAに対応していないためです。BentoPDFのフォーム入力機能とFirefoxはXFAを正しく処理できます。
- 既存のフォームフィールドがないPDFは、まず[PDFフォームの作成](./form-creator)ツールでフィールドを追加してから、ここで入力してください。
- ビューアーはPDFのページ寸法に合わせて自動でサイズが調整されます。

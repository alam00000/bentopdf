# フォントをアウトライン化

フォントをアウトライン化すると、すべての文字がフォントのグリフからベクターパスに変換されます。PDFはインストール済みのフォントに依存しなくなり、あらゆるデバイス、OS、プリンターで同じように表示されます。これは印刷前工程（プリプレス）の標準的な手順です。

## 使い方

1. 1つ以上のPDFファイルをアップロードします。
2. **アウトラインに変換**をクリックします。
3. Ghostscriptがすべてのテキストをベクターパスに変換します。
4. 結果をダウンロードします。複数ファイルの場合はZIPアーカイブになります。

設定項目はありません。このツールはGhostscript（WebAssembly）を使い、すべてのフォント参照を1回のパスでアウトライン化したパスに変換します。

## 変わること

- 文字がベクター曲線（ベジェパス）になる
- フォントの埋め込みが不要になり、PDFはグリフレベルで自己完結する
- ベクターパスは通常フォント参照より大きいため、ファイルサイズが増える場合がある
- 見た目は完全に保たれる

## 失われるもの

- テキストの選択とコピー＆ペースト
- テキスト検索（Ctrl+Fが使えなくなる）
- テキスト内容の編集
- スクリーンリーダーによるアクセシビリティ

## 活用例

- アウトライン化したフォントを要求する印刷所にPDFを送る
- カスタムフォントやライセンスフォントを使った文書を、そのフォントを持たない相手と共有する
- 他のシステムでフォントが置き換わって見た目が変わるのを防ぐ
- ベクター入力が必要なレーザー彫刻やCNCカットの工程用にPDFを準備する
- ロゴを多く含むPDFをすべてのプラットフォームで正しく表示させる

## ヒント

- 元のPDFは必ず保管してください。アウトライン化は元に戻せず、パスを編集可能なテキストに戻すことはできません。
- テキストを検索可能なままにしたい場合は、代わりに「PDFの画像化」ツールを使い、その後にOCRを行うことを検討してください。
- アウトライン化したPDFは大きくなりがちです。ファイルサイズが気になる場合は、後から「PDFの圧縮」を実行してください。

# PDFからPDF/A

PDF/Aは、デジタルデータの長期保存のために設計された、PDFのISO標準サブセットです。このツールは、ブラウザ内で直接動作するGhostscriptを使い、標準のPDFをPDF/A準拠の文書に変換します。

## 使い方

1. 1つ以上のPDFファイルをアップロードします。
2. ドロップダウンから**PDF/Aバージョン**を選びます。
3. 通常の変換に失敗する複雑なファイルでは、必要に応じて**事前に平坦化**を有効にします。
4. **PDF/Aに変換**をクリックします。複数のファイルはZIPアーカイブになります。

## PDF/Aのバージョン

| バージョン   | 制限                                       | 適した用途                         |
| ------------ | ------------------------------------------ | ---------------------------------- |
| **PDF/A-1b** | 最も厳格。透明効果とレイヤーは使用不可。   | 古い保管システムとの最大限の互換性 |
| **PDF/A-2b** | 透明効果とJPEG2000を許可。                 | 汎用的な保管 (推奨)                |
| **PDF/A-3b** | あらゆる形式の埋め込み添付ファイルを許可。 | 元のデータファイルを含む文書の保管 |

デフォルトではPDF/A-2bが選択されており、ほとんどの保管ニーズに対応できます。

## 事前平坦化オプション

PDFによっては、特殊なフォントエンコーディング、複雑な透明効果の重なり、壊れた内部構造など、PDF/Aへのきれいな変換を妨げる機能が含まれていることがあります。**事前に平坦化**を有効にすると、変換前にPDFを300 DPIでラスタライズします。これにより準拠が保証されますが、テキストは選択できなくなります。標準の変換でエラーが出る場合のフォールバックとして使ってください。

事前平坦化にはPyMuPDF WASMエンジンが必要です。

## ユースケース

- 政府や法的な保管要件を満たす (多くの法域で、裁判所への提出書類にPDF/Aが義務付けられています)
- 機関リポジトリやデジタルライブラリに文書を提出する
- 元のソフトウェアが10年後には存在しないかもしれない業務記録を保存する
- XML添付ファイル付きのPDF/A-3bを必要とする電子請求書の規格向けに請求書を準備する

## ヒント

- まず事前平坦化なしで変換を試してください。エラーが出た場合にのみ有効にします。
- PDF/Aはすべてのフォントを埋め込むため、出力ファイルは元のファイルより大きくなることがよくあります。
- ワークフローで厳密な準拠が必要な場合は、専用のPDF/A検証ツールで出力を検証してください。

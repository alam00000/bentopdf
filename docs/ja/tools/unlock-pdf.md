# PDFのロック解除

暗号化されたPDFのパスワードがわかっている場合、このツールで暗号化を完全に解除し、パスワードなしで誰でも開けるコピーを作成できます。複数のPDFが同じパスワードを共有している場合は、一括で復号化できます。

## 使い方

1. 暗号化されたPDFファイルを1つまたは複数アップロードします。
2. ファイルの保護に使用した**パスワード**を入力します。
3. **PDFの復号化**をクリックします。
4. 1ファイルの場合はそのままダウンロードされます。複数ファイルの場合は、ロック解除済みのPDFをすべて含むZIPアーカイブが作成されます。

## 機能

- 単一ファイルの復号化と一括復号化
- ユーザーパスワードと所有者パスワードの両方に対応
- 制限が一切残らない、完全に暗号化されていない出力
- パスワードの誤りや破損ファイルを明確に報告
- 一括モードではファイルごとの成功/失敗を追跡

## 制限の解除との違い

**PDFの復号化**はパスワードが必要で、すべての暗号化を解除します。**制限を解除**は使用制限(印刷、コピー、編集)を対象とし、所有者パスワードのみが設定されている場合はパスワードが不要なことがあります。パスワードなしではPDFをまったく開けない場合は、Decryptを使用してください。

## 活用例

- 以前に暗号化したPDFで、パスワードが不要になったものを恒久的にロック解除する
- 保管済みの文書をまとめて暗号化解除し、長期的にアクセスしやすくする
- 暗号化ファイルに対応していない文書管理システム向けに、パスワード保護されたPDFを準備する
- 他の文書と結合する前にPDFのロックを解除する(多くの結合ツールは暗号化された入力を処理できません)

## ヒント

- パスワード欄はアップロードしたすべてのファイルに適用されます。PDFごとにパスワードが異なる場合は、別々のバッチで処理してください。
- 「パスワードが正しくありません」エラーが出る場合は、末尾の空白やCaps Lockを確認してください。
- 復号化後の出力にはセキュリティがまったくありません。新しいパスワードを設定したい場合は、PDFの暗号化で再び暗号化してください。

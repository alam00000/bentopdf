# Inverter ordem das páginas

Inverta a ordem das páginas de um PDF para que a última página se torne a primeira, a penúltima se torne a segunda, e assim por diante. Suporta o processamento em lote de vários arquivos de uma vez.

## Como funciona

1. Envie um ou mais arquivos PDF.
2. Clique no botão de processar.
3. Cada arquivo é invertido de forma independente. Se você enviou vários arquivos, a saída é um arquivo ZIP com todos os PDFs invertidos.
4. Um único arquivo é baixado diretamente como PDF invertido.

## Recursos

- Processamento em lote: inverta vários PDFs em uma única operação
- Saída de um único arquivo para um PDF, saída em ZIP para vários
- Botões de remoção por arquivo antes de processar
- Preserva todo o conteúdo e a formatação das páginas

## Casos de uso

- Corrigir um documento que foi digitalizado em ordem inversa
- Preparar um PDF de apresentação para ser lido de trás para frente
- Inverter a ordem das páginas em fluxos de impressão específicos que alimentam as páginas ao contrário
- Corrigir um documento cujas páginas foram montadas ao contrário por engano

## Dicas

- Cada arquivo de um lote é invertido de forma independente: os arquivos em si não são reordenados entre si.
- Para uma reordenação de páginas mais detalhada (não apenas uma inversão completa), use [Duplicar e Organizar](./organize-pdf).

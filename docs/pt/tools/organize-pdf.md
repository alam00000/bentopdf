# Duplicar e Organizar

Reorganize, duplique e remova páginas de um PDF usando uma interface visual de arrastar e soltar. Cada página aparece como uma miniatura que você pode mover, clonar ou excluir antes de salvar o resultado como um novo arquivo.

## Como Funciona

1. Envie um único arquivo PDF.
2. A ferramenta renderiza uma grade de miniaturas com todas as páginas.
3. Arraste as miniaturas para reordenar as páginas, clique no botão verde de duplicar para clonar uma página ou no botão vermelho de excluir para removê-la.
4. Se preferir, digite uma ordem de páginas personalizada no campo de texto (ex.: `3, 1, 2, 4`) e clique em **Aplicar** para reorganizar todas as páginas de uma vez.
5. Clique no botão de processar para gerar e baixar o PDF reorganizado.

## Recursos

- Reordenação de páginas por arrastar e soltar com transições animadas
- Botões de duplicar e excluir em cada página
- Campo de ordem de páginas personalizada para reorganização precisa
- Números de página que se atualizam automaticamente a cada alteração
- Impede a exclusão da última página restante

## Casos de Uso

- Mover uma página fora do lugar para a posição correta em um relatório
- Duplicar a página de um formulário para ter várias cópias em branco em um só arquivo
- Remover páginas de rascunho ou de preenchimento antes de distribuir um documento
- Inverter ou embaralhar a ordem das páginas para preparar a impressão
- Montar uma sequência de páginas personalizada sem precisar mesclar arquivos separados novamente

## Dicas

- O campo de ordem personalizada espera os números das páginas originais separados por vírgula. Ele deve incluir cada página exatamente uma vez, sem omissões nem duplicatas.
- Depois de duplicar uma página, as duas cópias referenciam o mesmo índice de página original. Reordenar qualquer uma das cópias funciona de forma independente.
- Para operações em lote com vários arquivos ou fluxos mais avançados, considere usar a [Multiferramenta PDF](./pdf-multi-tool).

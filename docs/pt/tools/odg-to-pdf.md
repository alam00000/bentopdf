# ODG para PDF

Converta arquivos OpenDocument Graphics em PDF. O ODG é o formato nativo do LibreOffice Draw e é usado para diagramas, fluxogramas e ilustrações vetoriais. Converter para PDF facilita compartilhar, imprimir e incorporar esses desenhos em outros documentos.

## Formatos suportados

| Formato               | Extensão | Observações                                    |
| :-------------------- | :------- | :--------------------------------------------- |
| OpenDocument Graphics | `.odg`   | Arquivos do LibreOffice Draw / OpenOffice Draw |

## Como funciona

1. Clique na área de upload ou arraste e solte seus arquivos ODG. Vários arquivos podem ser adicionados de uma vez.
2. Revise a lista de arquivos. Remova itens individuais com o ícone da lixeira ou clique em **Adicionar mais arquivos** para incluir mais desenhos.
3. Clique em **Converter para PDF**. Um mecanismo baseado no LibreOffice é carregado no navegador e converte cada arquivo ODG, preservando gráficos vetoriais, formas e texto.
4. Um único arquivo é baixado diretamente como PDF. Vários arquivos geram um arquivo ZIP chamado `odg-to-pdf.zip`.

## Opções

Nenhuma configuração adicional é necessária. A conversão preserva as dimensões originais da página, formas, conectores e caixas de texto do ODG de origem.

## Casos de uso

- Compartilhar diagramas do LibreOffice Draw com clientes que não têm o LibreOffice instalado
- Imprimir fluxogramas e diagramas de rede criados no Draw
- Incluir ilustrações ODG em um relatório ou apresentação como PDFs incorporados
- Arquivar desenhos técnicos em um formato que continuará legível por décadas

## Dicas

- Os elementos vetoriais continuam vetoriais no PDF, então o resultado escala sem perda para qualquer tamanho de impressão.
- O mecanismo do LibreOffice leva um momento para inicializar no primeiro uso. As conversões seguintes na mesma sessão são mais rápidas.

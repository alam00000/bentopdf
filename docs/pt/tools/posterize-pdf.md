# Posterizar PDF

Divida cada página de um PDF em uma grade de subpáginas menores. Esta é a ferramenta para imprimir uma única página em várias folhas de papel, que você depois junta para formar um pôster ou banner grande.

## Como funciona

1. Envie um arquivo PDF.
2. Defina o número de **linhas** e **colunas** da grade (por exemplo, 2 linhas x 2 colunas divide cada página em 4 subpáginas).
3. Opcionalmente, informe um intervalo de páginas para limitar quais páginas serão posterizadas.
4. A tela de pré-visualização mostra uma grade sobre a página atual para você visualizar os cortes.
5. Navegue entre as páginas para conferir a grade em páginas diferentes.
6. Clique no botão de processar. Cada célula da grade vira uma página própria no PDF de saída.

## Recursos

- Número de linhas e colunas configurável para grades flexíveis
- Pré-visualização ao vivo com a grade mostrando exatamente onde as páginas serão divididas
- Filtro de intervalo de páginas para posterizar apenas páginas específicas
- Navegação página a página na pré-visualização
- Capturas de página em cache para navegação rápida na pré-visualização
- Linhas tracejadas vermelhas marcam claramente os limites de corte

## Opções

| Opção                    | Descrição                                           |
| ------------------------ | --------------------------------------------------- |
| **Linhas**               | Número de divisões horizontais (padrão: 1)          |
| **Colunas**              | Número de divisões verticais (padrão: 1)            |
| **Intervalo de páginas** | Quais páginas posterizar (vazio = todas as páginas) |

## Casos de uso

- Imprimir um PDF do tamanho de um pôster em folhas A4 ou Carta comuns para montar na parede
- Criar banners grandes a partir de um design de uma única página
- Dividir desenhos técnicos grandes em blocos imprimíveis
- Fazer impressões em grande formato sem acesso a uma impressora de grande formato

## Dicas

- Uma grade 2x2 transforma uma página em 4 páginas. Uma grade 3x3 transforma uma página em 9. Planeje a grade conforme o tamanho final que você quer na montagem.
- A grade na pré-visualização ajuda a verificar se conteúdo importante não cai em uma linha de corte. Ajuste linhas/colunas se necessário.
- Para a operação inversa (colocar várias páginas em uma folha), use [PDF N-Up](./n-up-pdf).

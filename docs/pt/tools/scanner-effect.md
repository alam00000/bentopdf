# Efeito scanner

Transforme um PDF digital limpo em algo que parece ter saído de um scanner de mesa. A ferramenta aplica ruído configurável, leve rotação, desfoque, variações de brilho e amarelamento opcional para simular as imperfeições de uma digitalização física.

## Como funciona

1. Envie seu arquivo PDF.
2. O editor abre com uma pré-visualização ao vivo da primeira página ao lado de um painel de configurações.
3. Ajuste os parâmetros do efeito de digitalização com os controles deslizantes e as chaves.
4. A pré-visualização é atualizada em tempo real conforme você altera as configurações.
5. Clique em **Aplicar** para processar todas as páginas e baixar o resultado.

## Opções

- **Espaço de cor (chave de tons de cinza)**: converta a saída para tons de cinza para o visual clássico de digitalização em preto e branco.
- **Borda**: adicione uma borda escura sutil nas bordas da página para imitar os artefatos de borda do scanner.
- **Rotação**: aplique uma leve rotação (-5 a +5 graus) para simular a alimentação desalinhada do papel.
- **Variação da rotação**: adicione variação aleatória ao ângulo de rotação para que cada página se incline de forma um pouco diferente.
- **Brilho**: aumente ou diminua o brilho geral.
- **Contraste**: ajuste o contraste para simular variações na qualidade do toner.
- **Desfoque**: aplique desfoque gaussiano para suavizar as bordas do texto como em uma digitalização de baixa qualidade.
- **Ruído**: adicione ruído aleatório de pixels para simular o granulado do sensor do scanner. Valores mais altos produzem resultados mais granulados.
- **Amarelado**: adicione um tom amarelo quente para simular papel envelhecido ou reciclado.
- **Resolução**: defina o DPI de saída. Valores mais baixos criam uma aparência mais pixelada, típica de digitalização.
- **Redefinir**: restaure todas as configurações para os valores padrão.

## Recursos

- Pré-visualização em tempo real que é atualizada conforme você ajusta cada parâmetro
- Variação aleatória de rotação por página para uma variação realista
- Dez parâmetros ajustáveis de forma independente
- Modo tons de cinza para uma saída autêntica de digitalização em preto e branco
- Controle de resolução, da qualidade de fax de baixo DPI à qualidade de arquivo de alto DPI

## Casos de uso

- Fazer documentos criados digitalmente parecerem ter sido impressos e digitalizados
- Simular o envelhecimento de documentos físicos para recriação de documentos históricos
- Testar softwares de OCR contra digitalizações de qualidade degradada
- Produzir documentos que combinem com o estilo visual de arquivos digitalizados existentes

## Dicas

- Comece com valores sutis. Um nível de ruído de 10-20, uma leve rotação de 0,5 grau e desfoque mínimo já produzem uma aparência convincente de digitalização.
- Combine o modo tons de cinza com um leve amarelamento para um efeito de "fotocópia de uma fotocópia".
- Resoluções mais baixas (100-150 DPI) criam a aparência mais realista de máquina de fax.

# Mesclar PDF

Combine vários arquivos PDF em um único documento. Você pode mesclar arquivos inteiros em uma ordem específica ou alternar para o Modo Página para ter controle detalhado sobre cada página de todos os PDFs enviados.

## Como funciona

1. Envie dois ou mais arquivos PDF clicando na área de soltar ou arrastando-os para ela.
2. Escolha entre **Modo Arquivo** e **Modo Página** usando o seletor no topo.
3. No Modo Arquivo, arraste os arquivos para reordená-los e, se quiser, especifique intervalos de páginas (por exemplo, `1-3, 5`) para cada um. Deixe o intervalo em branco para incluir todas as páginas.
4. No Modo Página, arraste e solte miniaturas de páginas individuais para montar a sequência exata de páginas.
5. Clique em **Mesclar PDFs** para combinar tudo em um único arquivo. O PDF mesclado é baixado automaticamente.

## Recursos

- Dois modos de mesclagem: Modo Arquivo para combinar arquivos inteiros rapidamente, Modo Página para controle página a página
- Reordenação por arrastar e soltar nos dois modos, com animações suaves
- A sintaxe de intervalo de páginas (por exemplo, `1-3, 5, 8-10`) permite escolher páginas sem mudar para o Modo Página
- Miniaturas de páginas carregadas sob demanda mantêm a interface responsiva mesmo com documentos grandes
- Sem limite de número de arquivos ou de total de páginas
- Preserva a qualidade original do PDF, sem recodificação

## Opções

| Opção                | Descrição                                                                                                      |
| -------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Modo Arquivo**     | Mescle arquivos inteiros em uma ordem personalizada, com filtros opcionais de intervalo de páginas por arquivo |
| **Modo Página**      | Grade visual de todas as páginas de todos os arquivos: arraste as miniaturas para montar a sequência exata     |
| **Campo de páginas** | Campo de texto por arquivo que aceita intervalos como `1-3, 5` para incluir apenas páginas específicas         |

## Casos de uso

- Combinar PDFs de capítulos separados em um único livro ou relatório
- Mesclar uma carta de apresentação e um currículo em um único documento de candidatura
- Reunir páginas específicas de vários documentos de origem em um arquivo consolidado
- Montar recibos ou faturas digitalizados em um único PDF de arquivo
- Criar um material de apoio de apresentação com slides de vários conjuntos

## Dicas

- Use o Modo Página quando precisar intercalar páginas de arquivos diferentes em vez de anexar um arquivo após o outro.
- Você pode adicionar mais arquivos após o envio inicial com o botão **Adicionar mais arquivos**, sem perder a organização atual.
- Os intervalos de páginas começam em 1, então `1` se refere à primeira página daquele arquivo.

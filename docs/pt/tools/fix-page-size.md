# Ajustar tamanho da página

PDFs montados a partir de várias fontes costumam acabar com tamanhos de página diferentes: alguns em Carta, outros em A4, outros completamente fora do padrão. Esta ferramenta força todas as páginas a um único tamanho de destino, redimensionando o conteúdo para caber ou preencher conforme necessário.

## Como funciona

1. Envie um arquivo PDF.
2. Selecione um **Tamanho da Página de Destino** na lista (A4, Carta, Ofício, A3, A5, Tabloide ou Personalizado).
3. Escolha uma **Orientação**: Automática mantém a orientação original de cada página, ou você pode forçar Retrato ou Paisagem.
4. Escolha um modo de **Escala do Conteúdo**: Ajustar (preserva todo o conteúdo, pode adicionar margens) ou Preencher (preenche a página, pode cortar as bordas).
5. Opcionalmente, defina uma **Cor de Fundo** para as margens adicionadas.
6. Clique em **Ajustar Tamanho da Página**.

## Opções

- **Tamanhos padrão**: A4, Carta, Ofício, A3, A5, Tabloide
- **Dimensões personalizadas**: Informe largura e altura em polegadas ou milímetros
- **Orientação**: Automática, Retrato, Paisagem
- **Modo de escala**: Ajustar ou Preencher (Cortar)
- **Cor de fundo**: Qualquer cor para o preenchimento das margens

## Casos de uso

- Normalizar um PDF mesclado em que as páginas vieram de scanners diferentes
- Converter um documento Carta dos EUA para A4 para distribuição internacional
- Preparar PDFs prontos para impressão que exigem um tamanho de corte consistente
- Corrigir páginas ligeiramente fora do padrão (por exemplo, 8,49 x 11,02 polegadas em vez de 8,5 x 11)

## Dicas

- Use o modo Ajustar para garantir que nenhum conteúdo seja perdido. O modo Preencher fica mais limpo, mas pode cortar as bordas.
- Verifique o resultado com a ferramenta Dimensões da Página para confirmar que todas as páginas correspondem ao tamanho de destino.
- Branco é a cor de fundo padrão; troque para uma cor escura se o seu documento tiver margens escuras.

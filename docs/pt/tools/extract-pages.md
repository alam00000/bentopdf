# Extrair páginas

Retire um conjunto de páginas de um PDF e salve-as como um novo arquivo. Indique exatamente quais páginas você quer usando a sintaxe de intervalos, e a ferramenta cria um PDF limpo contendo apenas essas páginas.

## Como funciona

1. Envie um arquivo PDF. A ferramenta exibe o nome do arquivo, o tamanho e o total de páginas.
2. Digite as páginas que deseja extrair usando a sintaxe de intervalos (por exemplo, `1-5`, `3, 7, 10-12`).
3. Se quiser, escolha baixar cada intervalo como um PDF separado em um arquivo ZIP.
4. Clique no botão de processar. As páginas extraídas são baixadas como um novo PDF (ou ZIP).

## Recursos

- Sintaxe flexível de intervalos de páginas: páginas individuais, intervalos ou combinações separadas por vírgula
- Exibe o total de páginas após o upload para facilitar a consulta
- Opção de gerar um único PDF combinado ou arquivos separados em um ZIP
- Preserva o conteúdo e a formatação originais das páginas

## Casos de uso

- Retirar o resumo executivo (as primeiras páginas) de um relatório extenso
- Extrair um único capítulo de um PDF de livro didático
- Salvar páginas específicas de um pacote de formulários como documentos independentes
- Criar um documento de amostra a partir de páginas selecionadas de um arquivo maior

## Dicas

- Os números de página começam em 1. Use `1` para a primeira página, não `0`.
- Para remover páginas em vez de extraí-las, use [Excluir Páginas](./delete-pages), que é a operação inversa.
- Se você precisa de seleção visual de páginas com miniaturas, use [Dividir PDF](./split-pdf) no modo de Seleção visual.

# PDFs para ZIP

Reúna vários arquivos PDF em um único arquivo ZIP. É uma ferramenta de empacotamento simples: não há conversão, compressão nem modificação dos próprios PDFs.

## Como Funciona

1. Envie vários arquivos PDF usando a área de soltar.
2. Revise a lista de arquivos. Remova os que você não quer incluir.
3. Clique no botão de processar.
4. Um arquivo ZIP com todos os PDFs enviados é baixado imediatamente.

## Recursos

- Aceita qualquer quantidade de arquivos PDF
- Remoção individual de arquivos antes de criar o arquivo ZIP
- Preserva os nomes originais dos arquivos dentro do ZIP
- Nenhuma modificação no conteúdo dos PDFs: os arquivos são empacotados como estão
- Exibe o nome e o tamanho de cada PDF enviado

## Casos de Uso

- Reunir um conjunto de faturas ou recibos para anexar a um e-mail
- Empacotar entregas de um projeto (vários relatórios em PDF) para a passagem de bastão
- Criar um único download para uma coleção de formulários ou modelos
- Arquivar um lote de documentos em um único arquivo compactado

## Dicas

- O arquivo ZIP usa os nomes originais dos PDFs. Se houver arquivos com o mesmo nome, renomeie-os antes de enviar para evitar conflitos.
- Esta ferramenta não comprime os próprios PDFs. Para reduzir o tamanho dos arquivos, passe-os primeiro por Comprimir PDF e depois empacote com esta ferramenta.

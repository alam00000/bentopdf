# PUB para PDF

Converta arquivos do Microsoft Publisher em PDF. O Publisher é uma ferramenta de editoração eletrônica incluída em algumas edições do Microsoft Office, mas a maioria das pessoas não o tem instalado. Esta ferramenta permite que qualquer pessoa converta arquivos PUB em PDF direto no navegador, sem nenhum software da Microsoft.

## Formatos suportados

| Formato             | Extensão | Observações                         |
| :------------------ | :------- | :---------------------------------- |
| Microsoft Publisher | `.pub`   | Documentos de editoração eletrônica |

## Como funciona

1. Clique na área de envio ou arraste e solte seus arquivos PUB. Vários arquivos podem ser enviados de uma vez.
2. Revise a lista de arquivos. Remova arquivos indesejados com o ícone de lixeira ou clique em **Adicionar mais arquivos** para incluir outros.
3. Clique em **Converter para PDF**. Um mecanismo baseado em LibreOffice é carregado no navegador e converte cada arquivo PUB, preservando layout, imagens e caixas de texto.
4. Um arquivo é baixado diretamente como PDF. Vários arquivos são entregues em um arquivo ZIP chamado `pub-to-pdf.zip`.

## Opções

Nenhuma configuração adicional é necessária. O conversor cuida do mecanismo de layout do PUB automaticamente.

## Casos de uso

- Abrir um folheto ou boletim em PUB de um cliente sem comprar o Microsoft Publisher
- Converter boletins de igrejas, programas de eventos ou jornais escolares criados no Publisher
- Arquivar materiais de marketing do Publisher em um formato acessível a todos
- Imprimir arquivos PUB em um sistema que não tem o Publisher instalado

## Dicas

- Layouts complexos do Publisher, com caixas de texto sobrepostas e posicionamento preciso, podem se deslocar um pouco durante a conversão. Revise a saída se o posicionamento exato for crítico.
- O mecanismo LibreOffice é inicializado uma vez por sessão. A primeira conversão demora mais; as seguintes são mais rápidas.
- Para uma conversão mais fiel de arquivos do Publisher, garanta que as fontes personalizadas usadas no original sejam fontes padrão do sistema.

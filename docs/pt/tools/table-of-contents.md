# Sumário

Esta ferramenta lê os favoritos (estrutura de tópicos) do seu PDF e gera uma página de sumário formatada que é inserida no início do documento. Se o seu PDF já tem favoritos, mas não tem uma página de sumário visível, esta ferramenta cria uma automaticamente.

## Como funciona

1. Envie um PDF que contenha favoritos.
2. Personalize o título do sumário, o tamanho da fonte e a família da fonte.
3. Opcionalmente, marque **Adicionar favorito para a página do sumário** para incluir o próprio sumário na árvore de favoritos.
4. Clique em **Gerar Sumário** para processar o arquivo.
5. O PDF atualizado é baixado automaticamente, com a página do sumário inserida no início.

## Opções

- **Título do sumário**: o título exibido no topo da página gerada. O padrão é "Sumário".
- **Tamanho da fonte**: escolha de 10pt a 72pt. O padrão é 12pt.
- **Família da fonte**: escolha entre as variantes Times Roman, Helvetica ou Courier (regular, negrito, itálico, negrito itálico). O padrão é Helvetica.
- **Adicionar favorito para a página do sumário**: quando marcada, uma entrada de favorito para a própria página do sumário é adicionada à árvore de tópicos do PDF.

## Recursos

- Lê toda a hierarquia de favoritos do PDF
- Gera uma página de sumário bem formatada, com referências de números de página
- Suporta níveis aninhados de favoritos com recuo
- Escolha entre 12 fontes PDF integradas
- Favorito opcional que aponta para a própria página do sumário

## Casos de uso

- Adicionar um sumário imprimível a e-books ou relatórios que só têm favoritos digitais
- Criar um sumário para um documento mesclado depois de combinar vários PDFs
- Gerar uma página de referência para manuais técnicos longos
- Preparar documentos para impressão em que se espera um sumário visível

## Dicas

- Se o seu PDF não tem favoritos, use primeiro a ferramenta [Editar Favoritos](./bookmark) para criá-los e depois volte aqui para gerar o sumário.
- Para documentos grandes, um tamanho de fonte maior, como 14pt ou 16pt, melhora a legibilidade.

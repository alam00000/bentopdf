# Alterar cor do texto

Substitua a cor do texto em todo o seu PDF. A ferramenta identifica as regiões de texto em cada página e as recolore com a cor escolhida, preservando o layout do documento e o conteúdo que não é texto.

## Como funciona

1. Envie seu arquivo PDF.
2. Escolha uma nova cor de texto no seletor de cores. O padrão é azul (#0000FF).
3. Clique em **Alterar Cor do Texto** para processar.
4. O PDF recolorido é baixado automaticamente. Um indicador de progresso mostra qual página está sendo processada.

## Opções

- **Nova cor do texto**: um seletor de cores para escolher a cor de substituição de todo o texto do documento.

## Recursos

- Recolore o texto de todas as páginas do documento
- Processamento página a página com indicação de progresso
- Seletor de cores com suporte completo a cores hexadecimais
- Preserva o layout da página e os elementos que não são texto

## Casos de uso

- Mudar texto preto para azul-escuro, para uma aparência de documento mais suave e moderna
- Recolorir o texto para seguir as diretrizes da marca antes de distribuir documentos
- Converter o texto para uma cor específica para atender à conformidade de acessibilidade
- Tornar o texto visível sobre uma cor de fundo recém-aplicada

## Dicas

- Esta ferramenta renderiza as páginas em escala 2x para manter a qualidade e depois reconstrói o PDF. A saída é baseada em imagem, então o texto não poderá mais ser selecionado nem pesquisado.
- Para documentos em que você precisa manter o texto selecionável, considere editar o PDF diretamente com o [Editor de PDF](./edit-pdf).
- O tempo de processamento aumenta com o número de páginas, pois cada página é renderizada individualmente.

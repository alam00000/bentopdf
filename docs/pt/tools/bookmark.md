# Editar marcadores

O editor de favoritos oferece controle total sobre os favoritos de navegação do PDF (também chamados de estrutura de tópicos). Você pode adicionar novos favoritos, editar os existentes, reorganizar a hierarquia e importar ou exportar os dados em formatos CSV e JSON.

## Como funciona

1. Envie seu PDF clicando ou arrastando um arquivo para a área de soltar.
2. Se quiser, marque **Extrair favoritos existentes automaticamente** para carregar a árvore de favoritos atual do documento.
3. O editor abre em visualização dividida: visualizador de PDF à esquerda e painel de favoritos à direita.
4. Digite o título de um favorito e clique em **Adicionar à página** para criar um novo favorito apontando para a página atual.
5. Use os botões da barra de ferramentas para reorganizar, estilizar ou excluir favoritos.
6. Clique em **Salvar PDF com favoritos** para baixar o arquivo atualizado.

## Recursos

- Visualizador de PDF com navegação de páginas, controles de zoom e campo para ir a uma página
- Adicione favoritos a qualquer página com um único clique
- Clique diretamente no PDF para definir um destino preciso do favorito (modo de seleção)
- Hierarquia de favoritos aninhados com reordenação por arrastar e soltar
- Operações em lote: selecione vários favoritos para alterar a cor, o estilo ou excluir de uma vez
- Busca de favoritos para encontrar rapidamente itens em árvores grandes
- Suporte a desfazer e refazer para todas as alterações
- Importe favoritos de arquivos CSV (título, página, nível) ou JSON
- Exporte favoritos para CSV ou JSON para edição externa
- Estilo dos favoritos: cor (vermelho, azul, verde, amarelo, roxo) e estilo da fonte (negrito, itálico, negrito itálico)
- Navegação rápida: percorra as páginas com as teclas Page Up/Page Down

## Opções

- **Extrair favoritos existentes automaticamente**: quando marcada, a ferramenta lê e exibe os favoritos atuais do PDF ao carregar.
- **Modo em lote**: ative para selecionar vários favoritos e aplicar alterações de cor, estilo ou exclusão em massa.
- **Expandir/Recolher tudo**: mostre ou oculte rapidamente os favoritos filhos.

## Casos de uso

- Adicionar um sumário a um livro didático ou manual que não tem favoritos
- Reestruturar os favoritos de um documento digitalizado após o processamento de OCR
- Exportar favoritos para CSV, editá-los em uma planilha e importá-los novamente
- Limpar favoritos gerados automaticamente que têm referências de página incorretas
- Adicionar favoritos coloridos para marcar seções importantes em uma petição jurídica

## Dicas

- Use a importação de CSV para criar favoritos em massa. O formato é simples: `title,page,level`, em que o nível 1 é o nível superior.
- O modo de seleção permite clicar em um ponto exato da página do PDF para definir o destino do favorito, o que é mais preciso do que apenas indicar o número da página.
- Exporte seus favoritos antes de fazer grandes alterações para ter um backup.

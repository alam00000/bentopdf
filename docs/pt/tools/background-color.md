# Cor de fundo

Defina uma cor de fundo sólida atrás de todo o conteúdo existente do seu PDF. A ferramenta cria um retângulo colorido em cada página e coloca o conteúdo original por cima, de modo que texto, imagens e gráficos continuam totalmente visíveis sobre o novo fundo.

## Como Funciona

1. Envie seu arquivo PDF.
2. Escolha uma cor de fundo no seletor de cores. O padrão é um amarelo claro (#FFFFCC).
3. Clique em **Alterar Cor de Fundo** para processar.
4. O PDF atualizado é baixado automaticamente.

## Opções

- **Cor de Fundo**: um seletor de cores padrão para escolher qualquer cor sólida. O padrão é amarelo claro.

## Recursos

- Aplica uma cor de fundo uniforme a todas as páginas
- Preserva todo o conteúdo original (texto, imagens, gráficos vetoriais) por cima da camada colorida
- Mantém as dimensões originais das páginas
- Funciona com documentos de qualquer número de páginas

## Casos de Uso

- Adicionar um fundo creme ou marfim claro para dar aos documentos uma aparência mais suave, parecida com papel
- Codificar conjuntos de documentos por cor, aplicando fundos diferentes a categorias diferentes
- Criar versões visualmente distintas do mesmo documento para públicos diferentes
- Adicionar uma leve tonalidade de fundo para melhorar a legibilidade ao projetar documentos na tela

## Dicas

- Cores claras e suaves funcionam melhor. Um fundo muito escuro pode dificultar a leitura do texto, a menos que o texto já seja claro.
- Se quiser mudar tanto a cor de fundo quanto a do texto, aplique primeiro a cor de fundo e depois use [Alterar cor do texto](./text-color) no resultado.
- Esta ferramenta trabalha no nível estrutural do PDF (sem rasterização), então o texto continua selecionável e pesquisável na saída.

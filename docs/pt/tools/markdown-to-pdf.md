# Markdown para PDF

Um editor Markdown completo com prévia ao vivo e exportação para PDF com um clique. Escreva do zero, envie um arquivo `.md` existente ou cole o conteúdo da área de transferência. O editor renderiza seu Markdown em tempo real e exporta um PDF estilizado usando o mecanismo de impressão nativo do navegador.

## Formatos suportados

| Entrada        | Descrição                |
| :------------- | :----------------------- |
| Arquivos `.md` | Envie pelo botão Enviar  |
| Entrada direta | Digite ou cole no editor |

## Como funciona

1. Abra a ferramenta Markdown para PDF. O editor carrega com visualização dividida: o código Markdown à esquerda e a prévia renderizada à direita.
2. Escreva seu Markdown, cole-o ou clique em **Enviar** para carregar um arquivo `.md`.
3. Alterne entre os temas claro e escuro usando o controle deslizante de tema na barra de ferramentas.
4. Clique em **Exportar PDF** (ou pressione `Ctrl/Cmd + S`) para gerar um PDF pela caixa de diálogo de impressão do navegador.

## Recursos

O editor suporta um amplo conjunto de recursos de Markdown além do básico:

- **Markdown padrão**: títulos, negrito, itálico, links, imagens, listas, citações, linhas horizontais
- **Blocos de código** com destaque de sintaxe para mais de 15 linguagens (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash e mais)
- **Diagramas Mermaid**: fluxogramas, diagramas de sequência, diagramas ER e outros tipos de gráficos Mermaid são renderizados diretamente na prévia
- **Tabelas** com a sintaxe padrão de tabelas do Markdown
- **Listas de tarefas** com caixas de seleção
- **Notas de rodapé**, **subscrito**, **sobrescrito**
- **Listas de definição**, **abreviações**
- Suporte a **emoji** (`:smile:` é renderizado como o emoji)
- **Destaques** (`==marked text==`) e **inserções** (`++inserted text++`)
- **URLs com link automático**: URLs simples são convertidas em links clicáveis
- Geração de **sumário**
- **Links de âncora** nos títulos

## Casos de uso

- Escrever documentação de projeto e exportar um PDF bem acabado para as partes interessadas
- Criar relatórios técnicos com exemplos de código e diagramas de arquitetura em Mermaid
- Converter um README do GitHub em PDF para uso offline ou impressão
- Redigir uma proposta ou especificação com listas de tarefas e tabelas
- Gerar um material de apoio estilizado a partir de anotações de aula escritas em Markdown

## Dicas

- A saída em PDF usa a função de imprimir como PDF do navegador. No Chrome, você pode personalizar margens e escala na caixa de diálogo de impressão antes de salvar.
- Os diagramas Mermaid são renderizados na prévia, mas podem levar um instante para inicializar no primeiro uso.
- Use `Ctrl/Cmd + S` como atalho de teclado para exportar sem precisar procurar o botão.

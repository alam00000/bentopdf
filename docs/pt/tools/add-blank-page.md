# Adicionar página em branco

Insira páginas vazias em um PDF na posição que você especificar. Você controla onde as páginas em branco entram e quantas adicionar.

## Como Funciona

1. Envie um arquivo PDF. A ferramenta exibe o número de páginas.
2. Informe a **posição** onde as páginas em branco devem ser inseridas. Use `0` para inserir no início, ou o total de páginas para adicionar ao final.
3. Informe o **número** de páginas em branco a adicionar (o padrão é 1).
4. Clique no botão de processar. O PDF modificado é baixado com as páginas em branco inseridas.

## Recursos

- Insira em qualquer posição: início, meio ou fim do documento
- Adicione várias páginas em branco em uma só operação
- A dica de posição é atualizada dinamicamente conforme o número de páginas do PDF enviado
- Páginas em branco no tamanho A4 padrão

## Casos de Uso

- Adicionar uma página em branco separadora entre as seções de um documento compilado
- Inserir páginas em branco para alinhar a impressão frente e verso
- Deixar espaço para anotações manuscritas em um guia de estudo impresso
- Completar um documento para atingir um número mínimo de páginas

## Dicas

- A posição `0` insere antes da primeira página. A posição igual ao total de páginas adiciona depois da última página.
- Se você precisa inserir conteúdo (não apenas páginas em branco) em uma posição específica, use a [Multiferramenta PDF](./pdf-multi-tool) para inserir outro PDF após uma determinada página.

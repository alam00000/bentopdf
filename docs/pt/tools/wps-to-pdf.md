# WPS para PDF

Converta arquivos do processador de texto Microsoft Works em PDF. O Microsoft Works vinha instalado em PCs domésticos no fim dos anos 1990 e nos anos 2000, e muitos arquivos WPS ainda estão em discos rígidos antigos e arquivos de e-mail. Esta ferramenta os abre no navegador e gera PDFs limpos.

## Formatos suportados

| Formato         | Extensão | Observações                                         |
| :-------------- | :------- | :-------------------------------------------------- |
| Microsoft Works | `.wps`   | Arquivos do processador de texto do Microsoft Works |

## Como funciona

1. Clique na área de upload ou arraste e solte seus arquivos WPS. Vários arquivos são aceitos.
2. Revise a lista de arquivos. Use o ícone de lixeira para remover arquivos individuais ou clique em **Adicionar Mais Arquivos** para ampliar o lote.
3. Clique em **Converter para PDF**. Um mecanismo baseado em LibreOffice é carregado no navegador e converte cada documento WPS em PDF.
4. Um arquivo é baixado diretamente como PDF. Vários arquivos são reunidos em um arquivo ZIP chamado `wps-to-pdf.zip`.

## Opções

Nenhuma configuração adicional é necessária. O conversor trata o texto, a formatação básica e as imagens incorporadas do arquivo WPS.

## Casos de uso

- Recuperar documentos antigos da escola ou do trabalho salvos no formato Microsoft Works
- Abrir anexos WPS de e-mail quando você não tem o Microsoft Works instalado
- Converter um acervo de arquivos WPS para migrar para um sistema de documentos moderno
- Imprimir documentos legados que os processadores de texto atuais não conseguem abrir

## Dicas

- Não confunda os arquivos `.wps` do Microsoft Works com os arquivos do WPS Office. Esta ferramenta é específica para o formato mais antigo do Microsoft Works.
- O mecanismo LibreOffice leva um momento para carregar no primeiro uso. Depois de carregado, as conversões seguintes na mesma sessão são mais rápidas.

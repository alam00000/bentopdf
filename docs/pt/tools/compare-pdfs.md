# Comparar PDFs

Envie dois PDFs e veja exatamente o que mudou entre eles. A ferramenta emparelha as páginas de forma inteligente, detecta diferenças em texto, imagens, anotações, cabeçalhos e formatação, e as apresenta em uma visualização lado a lado ou em sobreposição.

## Como funciona

1. Envie dois arquivos PDF: o original (à esquerda) e a versão revisada (à direita).
2. A ferramenta emparelha as páginas dos dois documentos usando assinaturas de conteúdo.
3. Selecione um modo de visualização: **Lado a lado** ou **Sobreposição**.
4. Navegue entre os pares de páginas com os controles de paginação.
5. As diferenças são destacadas e categorizadas. Use o painel de filtros para focar em tipos específicos de alteração.
6. Se quiser, exporte a comparação como um relatório em PDF.

## Recursos

- Emparelhamento automático de páginas com base na similaridade de conteúdo
- Visualizações de comparação lado a lado e em sobreposição
- Categorização das alterações: texto, imagem, cabeçalho/rodapé, anotação, formatação, plano de fundo
- Filtros por categoria para mostrar ou ocultar tipos específicos de alteração
- Busca de alterações de texto com filtro por consulta
- Suporte a OCR para comparar documentos digitalizados
- Controles de zoom para inspeção detalhada
- Rolagem sincronizada entre os painéis no modo lado a lado
- Exportação dos resultados da comparação como PDF

## Opções

| Opção                     | Descrição                                                                                                       |
| ------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Modo de visualização**  | Lado a lado ou Sobreposição                                                                                     |
| **OCR**                   | Ativa/desativa o OCR para comparar documentos digitalizados                                                     |
| **Idioma do OCR**         | Idioma para a extração de texto por OCR                                                                         |
| **Filtros de categoria**  | Alterna a visibilidade das alterações de texto, imagem, cabeçalho/rodapé, anotação, formatação e plano de fundo |
| **Escopo das alterações** | No modo de sobreposição, alterna entre todas as alterações ou somente o conteúdo                                |
| **Zoom**                  | Ajusta o nível de ampliação para inspeção detalhada                                                             |

## Casos de uso

- Revisar versões de um contrato para encontrar exatamente o que mudou entre elas
- Comparar protótipos de design para verificar se as exportações em PDF correspondem ao esperado
- Auditar alterações em documentos de setores regulados, em que toda edição precisa ser rastreada
- Verificar se um processo de conversão de PDF preservou o conteúdo original com precisão
- Conferir documentos traduzidos com o original para detectar mudanças de layout

## Dicas

- A sobreposição empilha os dois documentos um sobre o outro, tornando imediatamente visíveis as diferenças espaciais (elementos deslocados, imagens redimensionadas).
- Ative o OCR ao comparar documentos digitalizados que não têm camada de texto. O mecanismo de comparação extrairá o texto das imagens das páginas.
- Use os filtros de categoria para focar no que importa. Por exemplo, oculte as alterações de formatação quando só se importar com as diferenças no conteúdo do texto.

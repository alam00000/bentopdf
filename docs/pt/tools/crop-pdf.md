# Cortar PDF

Apare as margens das páginas do PDF com uma interface visual de corte. Desenhe um retângulo de corte diretamente em cada página, visualize o resultado e aplique o corte. Você pode definir regiões de corte diferentes para páginas diferentes ou aplicar o mesmo corte ao documento inteiro.

## Como funciona

1. Envie seu arquivo PDF.
2. O editor de corte abre, mostrando a primeira página com uma sobreposição de corte arrastável.
3. Ajuste o retângulo de corte arrastando suas bordas ou cantos.
4. Use os botões de navegação de páginas para passar entre as páginas e definir a região de corte de cada uma.
5. Clique em **Cortar** para aplicar o corte e baixar o resultado.

## Recursos

- Editor de corte visual baseado em Cropper.js, com alças para ajuste preciso
- Navegação página a página para definir regiões de corte individuais
- Guarda as configurações de corte por página, para que você defina cortes diferentes em páginas diferentes
- Pré-visualização ao vivo da área de corte selecionada
- Compatível com PDFs de qualquer tamanho de página ou orientação

## Casos de uso

- Remover margens largas de documentos digitalizados para focar na área de conteúdo
- Aparar marcas de corte ou de registro de impressora em PDFs de pré-impressão
- Cortar slides de aula para remover a área de notas do apresentador
- Remover cabeçalhos ou rodapés de todas as páginas antes de compartilhar um trecho de documento
- Redimensionar páginas para caber em uma tela ou layout de impressão específico

## Dicas

- A sobreposição de corte pode ser redimensionada e reposicionada livremente. Arraste os cantos para redimensionar proporcionalmente ou as bordas para ajustar um só eixo.
- Para documentos em que todas as páginas precisam do mesmo corte, defina-o na primeira página: a ferramenta lembra a região de corte conforme você navega pelas páginas.
- Se você precisa padronizar os tamanhos das páginas em vez de cortar visualmente, a ferramenta Ajustar Tamanho da Página pode ser mais adequada.

# Editar metadados

Edite os metadados incorporados em um arquivo PDF. A ferramenta preenche um formulário com os metadados existentes do documento, permite modificar qualquer campo e salva as alterações em um novo PDF.

## Como funciona

1. Envie um arquivo PDF. A ferramenta lê os metadados atuais e preenche o formulário.
2. Edite qualquer um dos campos padrão: Título, Autor, Assunto, Palavras-chave, Criador, Produtor.
3. Ajuste a Data de criação e a Data de modificação usando os seletores de data e hora.
4. Adicione campos de metadados personalizados clicando no botão de adicionar e informando um par chave-valor.
5. Clique no botão de processar para salvar o PDF modificado.

## Recursos

- Preenche todos os metadados existentes do PDF enviado
- Campos padrão: Título, Autor, Assunto, Palavras-chave, Criador, Produtor
- Seletores de data e hora para Data de criação e Data de modificação
- Campos personalizados de chave-valor para propriedades arbitrárias
- Salva as alterações diretamente no dicionário de informações do documento PDF

## Campos editáveis

| Campo                     | Descrição                                               |
| ------------------------- | ------------------------------------------------------- |
| **Título**                | O título do documento exibido nos leitores de PDF       |
| **Autor**                 | A pessoa ou organização que criou o documento           |
| **Assunto**               | Uma breve descrição do tema do documento                |
| **Palavras-chave**        | Termos separados por vírgula para busca e categorização |
| **Criador**               | O aplicativo que criou o conteúdo originalmente         |
| **Produtor**              | O aplicativo que gerou o PDF                            |
| **Data de criação**       | Quando o documento foi criado originalmente             |
| **Data de modificação**   | Quando o documento foi modificado pela última vez       |
| **Campos personalizados** | Quaisquer pares chave-valor adicionais que você definir |

## Casos de uso

- Definir um título e um autor adequados antes de publicar um documento
- Adicionar palavras-chave para melhorar a capacidade de busca em sistemas de gestão de documentos
- Atualizar a data de modificação para refletir a revisão atual
- Adicionar campos de metadados personalizados, como Departamento, ID do projeto ou Classificação
- Limpar metadados deixados pelo software de criação original

## Dicas

- Os campos personalizados são gravados diretamente no dicionário de informações do PDF. Alguns leitores de PDF podem não exibir campos personalizados, mas eles são preservados no arquivo.
- Deixe um campo em branco para apagá-lo dos metadados. O botão de processar salva o que estiver no formulário.
- Para ver os metadados sem editar, use [Ver Metadados](./view-metadata). Para remover todos os metadados, use Remover Metadados.

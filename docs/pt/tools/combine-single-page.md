# Combinar em página única

Junte todas as páginas de um PDF em uma única página longa. As páginas são unidas na vertical (como um rolo) ou na horizontal (lado a lado), gerando uma página contínua na saída.

## Como funciona

1. Envie um arquivo PDF.
2. Escolha a direção do layout: **Vertical** (páginas empilhadas de cima para baixo) ou **Horizontal** (páginas lado a lado).
3. Defina o espaçamento entre as páginas em pontos.
4. Escolha uma cor de fundo para os espaços entre as páginas.
5. Se quiser, ative os separadores (linhas finas entre as páginas) e configure a espessura e a cor.
6. Clique no botão de processar. A saída é um PDF de uma única página.

## Recursos

- União de páginas na vertical ou na horizontal
- Espaçamento configurável entre as páginas
- Seletor de cor de fundo para as áreas de espaço
- Linhas separadoras opcionais com espessura e cor ajustáveis
- Renderiza cada página original em resolução total no canvas combinado

## Opções

| Opção                       | Descrição                                        |
| --------------------------- | ------------------------------------------------ |
| **Orientação**              | Vertical (empilhado) ou Horizontal (lado a lado) |
| **Espaçamento das páginas** | Espaço entre as páginas em pontos                |
| **Cor de fundo**            | Cor da área entre as páginas                     |
| **Adicionar separador**     | Ativa linhas finas entre as páginas              |
| **Espessura do separador**  | Espessura da linha em pontos                     |
| **Cor do separador**        | Cor das linhas separadoras                       |

## Casos de uso

- Criar uma única imagem longa a partir de um wireframe ou protótipo de design com várias páginas
- Gerar uma visualização contínua e rolável de um documento para incorporar na web
- Unir um quadrinho ou storyboard de várias páginas em uma única tira
- Produzir uma visão panorâmica de páginas sequenciais para revisão

## Dicas

- A orientação vertical funciona melhor para documentos com páginas em retrato. A horizontal é melhor para conteúdo em paisagem.
- Documentos grandes com muitas páginas geram uma saída muito alta ou muito larga. Alguns visualizadores de PDF podem ter dificuldade com páginas únicas extremamente grandes.
- Adicionar separadores com uma cor contrastante facilita ver onde termina uma página original e começa a próxima.

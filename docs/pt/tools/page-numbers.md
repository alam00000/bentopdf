# Números de página

Adicione números de página visíveis a todas as páginas do seu PDF. Você escolhe a posição, o formato, o tamanho da fonte e a cor, e a ferramenta cuida do resto.

## Como Funciona

1. Envie seu arquivo PDF.
2. Configure os ajustes de numeração no painel de opções que aparece.
3. Clique em **Adicionar Números de Página** para processar.
4. O PDF numerado é baixado automaticamente.

## Opções

- **Posição**: escolha onde os números de página aparecem: Inferior Centro, Inferior Esquerda, Inferior Direita, Superior Centro, Superior Esquerda ou Superior Direita.
- **Formato**: selecione entre numeração simples (1, 2, 3...) ou o formato "página X de Y" (1 / 5, 2 / 5...).
- **Tamanho da Fonte**: defina o tamanho do texto do número de página. O padrão é 12.
- **Cor**: escolha qualquer cor para o texto do número de página usando o seletor de cores.

## Recursos

- Seis opções de posição, cobrindo todos os cantos e o centro
- Dois formatos de numeração: sequencial simples ou "página X de Y"
- Tamanho de fonte personalizável de 6 a 72 pontos
- Seletor de cores completo para o texto
- Tratamento automático de margens que mantém os números em áreas seguras, independentemente do tamanho da página

## Casos de Uso

- Preparar para impressão documentos que precisam de referências de página visíveis
- Adicionar números de página a um PDF mesclado a partir de vários arquivos de origem
- Numerar materiais de apresentação antes de distribuí-los
- Adicionar numeração sequencial a documentos jurídicos ou contratos

## Dicas

- O formato "página X de Y" é útil em documentos nos quais os leitores precisam saber a extensão total, como propostas ou relatórios.
- Se você precisar de estilos de numeração diferentes para seções diferentes (como algarismos romanos para a parte inicial), use a ferramenta [Adicionar rótulos de página](./add-page-labels).

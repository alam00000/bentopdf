# Inverter cores

Troque cada cor do seu PDF pela sua inversa. Fundos brancos ficam pretos, texto preto fica branco e todas as outras cores passam para seus valores complementares. É a forma mais rápida de criar uma versão "modo escuro" de qualquer PDF.

## Como funciona

1. Envie seu arquivo PDF.
2. Clique em **Inverter Cores** para processar.
3. O PDF invertido é baixado automaticamente.

Não há configurações adicionais. A ferramenta renderiza cada página como imagem, inverte as cores de todos os pixels e remonta o resultado em um novo PDF.

## Recursos

- Inversão de cores com um clique em todas as páginas
- Processa todas as páginas do documento
- Mantém as dimensões e o layout originais da página
- Funciona com qualquer PDF, independentemente do tipo de conteúdo (texto, imagens, misto)

## Casos de uso

- Criar versões em modo escuro de livros didáticos ou manuais para leitura confortável à noite
- Preparar versões de alto contraste de documentos para fins de acessibilidade
- Inverter documentos digitalizados que foram capturados com exposição incorreta
- Gerar versões em negativo de PDFs com muitas imagens para análise visual

## Dicas

- Como a ferramenta rasteriza as páginas para aplicar o efeito, o resultado é baseado em imagem. O texto deixa de ser selecionável e pesquisável. Se você precisa de texto pesquisável após a inversão, passe o resultado por uma ferramenta de OCR.
- Para ajustes de cor mais detalhados (brilho, contraste, saturação), use a ferramenta [Ajustar Cores](./adjust-colors).
- PDFs grandes com muitas páginas podem levar mais tempo, pois cada página é renderizada e invertida individualmente.

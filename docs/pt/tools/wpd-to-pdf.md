# WPD para PDF

Converta documentos do Corel WordPerfect em arquivos PDF. O WPD já foi o formato de processamento de texto dominante em escritórios de advocacia e órgãos públicos. Se você tem arquivos antigos do WordPerfect que os programas modernos se recusam a abrir, esta ferramenta os traz de volta à vida como PDFs padrão.

## Formatos suportados

| Formato     | Extensão | Observações                                |
| :---------- | :------- | :----------------------------------------- |
| WordPerfect | `.wpd`   | Todas as principais versões do WordPerfect |

## Como funciona

1. Clique na área de upload ou arraste e solte seus arquivos WPD. Vários arquivos podem ser selecionados de uma vez.
2. Revise a lista de arquivos. Remova arquivos indesejados com o ícone de lixeira ou use **Adicionar Mais Arquivos** para incluir mais documentos.
3. Clique em **Converter para PDF**. A ferramenta carrega no navegador um mecanismo de conversão baseado em LibreOffice, que analisa o formato WPD e gera o PDF.
4. Um único arquivo é baixado diretamente como PDF. Conversões em lote geram um arquivo ZIP chamado `wpd-to-pdf.zip`.

## Opções

Nenhuma configuração é necessária. O mecanismo LibreOffice cuida automaticamente da formatação, das fontes e do layout do WPD.

## Casos de uso

- Abrir documentos jurídicos de décadas atrás escritos em WordPerfect
- Converter registros governamentais arquivados de WPD para um formato moderno
- Migrar uma biblioteca de documentos WordPerfect legados para PDF para armazenamento de longo prazo
- Compartilhar arquivos WPD com destinatários que não têm o Corel WordPerfect instalado

## Dicas

- O mecanismo LibreOffice é carregado no primeiro uso, o que leva um momento. As conversões seguintes na mesma sessão são mais rápidas.
- Macros complexas do WPD e reveal codes não são preservados, mas o layout visual, o conteúdo do texto e a formatação básica são mantidos no PDF.

# Adicionar anexos

Incorpore um ou mais arquivos diretamente dentro de um documento PDF. Os anexos podem ser adicionados no nível do documento (visíveis no painel de anexos de qualquer leitor de PDF) ou vinculados a páginas específicas.

## Como Funciona

1. Envie o PDF ao qual você quer anexar arquivos.
2. Use a área de soltar anexos para selecionar os arquivos que deseja incorporar (qualquer tipo de arquivo).
3. Escolha o nível do anexo: **Documento** (padrão) ou **Página**.
4. Se escolher o nível de Página, informe um intervalo de páginas (por exemplo, `1-3` ou `5`).
5. Clique no botão de processar. O PDF modificado é baixado com seus arquivos incorporados.

## Recursos

- Anexe qualquer tipo de arquivo: imagens, planilhas, arquivos compactados, executáveis, o que for
- Anexos no nível do documento ou da página
- Vários arquivos podem ser anexados em uma única operação
- Exibe os nomes e tamanhos de todos os anexos selecionados
- A saída preserva o conteúdo original do PDF com os arquivos incorporados adicionados

## Opções

| Opção                  | Descrição                                                                      |
| ---------------------- | ------------------------------------------------------------------------------ |
| **Nível do documento** | Anexa os arquivos ao PDF como um todo, acessíveis pelo painel de anexos        |
| **Nível da página**    | Anexa os arquivos a páginas específicas, definidas por um intervalo de páginas |

## Casos de Uso

- Reunir dados de origem (arquivos Excel, CSVs) com um relatório em PDF
- Anexar os arquivos de imagem originais a um PDF de portfólio fotográfico
- Incorporar documentos de apoio em um contrato ou proposta
- Adicionar materiais complementares a páginas específicas de um manual de treinamento

## Dicas

- Os anexos no nível do documento são os mais amplamente compatíveis entre leitores de PDF. Os anexos no nível da página podem não ser visíveis em todos os visualizadores.
- Não há limite de tamanho para os anexos, mas arquivos incorporados muito grandes aumentam o tamanho do PDF proporcionalmente.

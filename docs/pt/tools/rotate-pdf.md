# Girar PDF

Gire as páginas de um PDF em 90 graus no sentido horário ou anti-horário. A ferramenta mostra miniaturas de todas as páginas, permitindo girá-las individualmente ou aplicar uma rotação em massa a todo o documento.

## Como funciona

1. Envie um arquivo PDF. As miniaturas de todas as páginas são renderizadas em uma grade.
2. Use os botões de rotação esquerda/direita abaixo da miniatura de cada página para girar aquela página específica.
3. Use os controles de rotação em massa no topo para girar todas as páginas de uma vez.
4. A pré-visualização das miniaturas é atualizada em tempo real para mostrar a rotação.
5. Clique no botão de processar para salvar o PDF girado.

## Recursos

- Rotação por página em incrementos de 90 graus (esquerda ou direita)
- Rotação em massa de todas as páginas simultaneamente
- Pré-visualização das miniaturas em tempo real com transições de rotação animadas
- Miniaturas carregadas sob demanda para um desempenho fluido em documentos grandes
- Preserva o conteúdo e a qualidade originais das páginas

## Casos de uso

- Corrigir páginas digitalizadas de lado ou de cabeça para baixo
- Girar páginas em paisagem para retrato (ou vice-versa)
- Corrigir um documento de orientação mista em que algumas páginas foram digitalizadas no ângulo errado
- Preparar um documento para uma orientação de exibição específica

## Dicas

- As rotações são cumulativas. Clicar duas vezes no botão horário aplica uma rotação de 180 graus.
- Para rotações que não sejam de 90 graus (por exemplo, 45 graus para corrigir uma digitalização levemente inclinada), use [Rotacionar em Graus Customizáveis](./rotate-custom).
- Os controles de rotação em massa afetam todas as páginas, não apenas as selecionadas. Não há mecanismo de seleção nesta ferramenta; para isso, use a [Multiferramenta PDF](./pdf-multi-tool).

# Girar em graus personalizados

Rotacione páginas de PDF em qualquer ângulo, não apenas em múltiplos de 90 graus. Cada página tem seu próprio campo de ângulo, e você pode aplicar um único ângulo a todas as páginas de uma vez com o controle em lote.

## Como funciona

1. Envie um arquivo PDF. As miniaturas são renderizadas para cada página.
2. Cada página tem um campo numérico que mostra seu ângulo de rotação atual.
3. Digite qualquer valor em graus (positivo ou negativo) para rotacionar uma página específica, ou use os botões esquerda/direita de cada página para ajustes rápidos de 90 graus.
4. Use o campo de **ângulo em lote** no topo para definir uma rotação uniforme para todas as páginas.
5. Clique no botão de processar para gerar o PDF rotacionado.

## Recursos

- Entrada livre de graus por página (qualquer valor inteiro)
- Controle de ângulo em lote para definir a mesma rotação em todas as páginas
- Pré-visualização da rotação em tempo real nas miniaturas
- Botões de rotação rápida por página em incrementos de 90 graus
- Miniaturas carregadas sob demanda para desempenho em documentos grandes

## Casos de uso

- Corrigir digitalizações levemente inclinadas em alguns graus
- Rotacionar páginas para atender a um requisito de orientação fora do padrão
- Aplicar rotações precisas a páginas individuais em um documento de conteúdo misto
- Ajustar os ângulos das páginas após uma rotação em massa inicial

## Dicas

- Valores positivos rotacionam no sentido horário, valores negativos rotacionam no sentido anti-horário.
- O campo de ângulo em lote sobrescreve todos os ângulos por página quando aplicado. Faça os ajustes individuais depois da operação em lote, se necessário.
- Para rotações padrão de 90/180/270 graus com uma interface mais simples, use [Girar PDF](./rotate-pdf).

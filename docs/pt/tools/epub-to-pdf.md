# EPUB para PDF

Converta ebooks EPUB em arquivos PDF sem sair do navegador. O EPUB é o padrão aberto para livros digitais, mas às vezes você precisa de um PDF de layout fixo para imprimir, anotar ou compartilhar com pessoas que não têm um leitor de ebooks.

## Formatos compatíveis

| Formato | Extensão | Observações              |
| :------ | :------- | :----------------------- |
| EPUB    | `.epub`  | Arquivos EPUB 2 e EPUB 3 |

## Como funciona

1. Clique na área de upload ou arraste e solte seus arquivos EPUB. A seleção múltipla é compatível.
2. Revise os arquivos enviados. Remova entradas indesejadas com o ícone de lixeira ou clique em **Adicionar mais arquivos** para ampliar o lote.
3. Clique em **Converter para PDF**. O mecanismo PyMuPDF renderiza o conteúdo do EPUB (texto, imagens e formatação) em uma saída PDF paginada.
4. Um único EPUB é baixado diretamente como PDF. Vários arquivos são empacotados em um arquivo ZIP chamado `epub-converted.zip`.

## Opções

A conversão roda com padrões sensatos e sem configuração obrigatória. O texto é reorganizado nas dimensões de página padrão, e as fontes e imagens incorporadas são levadas para o PDF.

## Casos de uso

- Imprimir um ebook sem DRM para ler longe das telas
- Enviar um manuscrito em EPUB como PDF de layout fixo para revisão
- Arquivar livros digitais em um formato que todo sistema operacional abre nativamente
- Compartilhar um capítulo com um colega que não tem um leitor de EPUB
- Converter documentação técnica distribuída em EPUB em PDFs que podem ser anotados

## Dicas

- Recursos do EPUB 3, como áudio e vídeo incorporados, não são levados para o PDF, mas todo o texto, imagens e tabelas são convertidos sem problemas.
- Para obter os melhores resultados com EPUBs muito estilizados, confira as primeiras páginas da saída para confirmar a fidelidade do layout.

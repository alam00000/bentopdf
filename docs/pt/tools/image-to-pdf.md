# Imagens para PDF

O conversor universal de imagem para PDF. Envie imagens em praticamente qualquer formato e combine-as em um único documento PDF. Cada imagem ocupa sua própria página, com o tamanho das dimensões originais.

## Formatos suportados

| Formato         | Extensões                              |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

Este é o suporte a formatos mais amplo entre todos os conversores de imagem do BentoPDF. Se você precisa de apenas um formato específico, use uma das ferramentas dedicadas.

## Como funciona

1. Clique na área de upload ou arraste e solte seus arquivos de imagem. Você pode selecionar vários arquivos de uma vez.
2. Revise a lista de arquivos. Remova os indesejados com o ícone da lixeira ou clique em **Adicionar mais arquivos** para incluir outras imagens.
3. Escolha um nível de **Qualidade do PDF** na lista.
4. Clique em **Converter para PDF**. A ferramenta processa as imagens com o mecanismo PyMuPDF e baixa o resultado como `images_to_pdf.pdf`.

## Opções

A **Qualidade do PDF** controla a compressão aplicada às imagens ao incorporá-las no PDF:

- **Alta qualidade**: compressão mínima, arquivo maior. Ideal para impressão ou arquivamento.
- **Qualidade média** (padrão): compressão equilibrada. Boa para a maioria dos casos.
- **Baixa qualidade**: compressão agressiva, menor tamanho de arquivo. Adequada para e-mail ou compartilhamento rápido.

Arquivos HEIC e WebP são convertidos automaticamente em PNG antes de serem incorporados. Isso acontece de forma transparente e não exige nenhuma etapa extra.

## Casos de uso

- Combinar recibos ou documentos digitalizados com a câmera do celular em um único PDF
- Criar um portfólio de fotos ou um lookbook a partir de imagens em formatos mistos
- Converter fotos do iPhone (HEIC) em um PDF compartilhável sem instalar software de desktop
- Reunir mockups de design a partir de exportações PSD e capturas de tela em uma entrega para o cliente
- Arquivar uma pasta de formatos de imagem antigos (PNM, JXR, JP2) como um único PDF

## Dicas

- A ordem das imagens no PDF segue a ordem em que aparecem na lista de arquivos. Envie-as na sequência desejada.
- Para o menor tamanho de arquivo possível, escolha Baixa qualidade. A diferença visual costuma ser insignificante em digitalizações com muito texto.
- Se você tem apenas um formato de imagem, os conversores dedicados (JPG para PDF, PNG para PDF etc.) oferecem o mesmo resultado com uma interface mais simples.

# Ajustar cores

Um kit completo de correção de cor para PDFs. Ajuste oito parâmetros independentes (brilho, contraste, saturação, deslocamento de matiz, temperatura, tonalidade, gama e sépia) com uma visualização ao vivo que é atualizada conforme você move cada controle deslizante.

## Como Funciona

1. Envie seu arquivo PDF.
2. O editor abre mostrando uma visualização da primeira página e um painel de configurações de cor.
3. Mova os controles deslizantes para ajustar cada parâmetro de cor. A visualização é atualizada em tempo real.
4. Clique em **Redefinir** para restaurar todos os controles às posições padrão.
5. Clique em **Aplicar** para processar todas as páginas e baixar o PDF ajustado.

## Opções

- **Brilho**: clareia ou escurece a página inteira (-100 a +100).
- **Contraste**: aumenta ou diminui a diferença entre áreas claras e escuras (-100 a +100).
- **Saturação**: aumenta ou reduz a intensidade das cores (-100 a +100). Definir como -100 gera um resultado em tons de cinza.
- **Deslocamento de Matiz**: gira a roda de cores para deslocar todas as cores uniformemente.
- **Temperatura**: desloca as cores para mais quentes (amarelo/laranja) ou mais frias (azul).
- **Tonalidade**: adiciona uma dominante verde ou magenta.
- **Gama**: ajusta o brilho dos meios-tons usando uma curva de gama. Valores abaixo de 1,0 escurecem os meios-tons; valores acima de 1,0 os clareiam.
- **Sépia**: aplica um efeito clássico de tom sépia. Valores mais altos produzem uma tonalidade marrom mais forte.

## Recursos

- Oito parâmetros de cor ajustáveis de forma independente
- Visualização ao vivo que responde imediatamente às mudanças nos controles
- Botão de redefinição para voltar rapidamente aos padrões
- Processa todas as páginas do documento
- Funciona com qualquer conteúdo de PDF (texto, imagens, gráficos)

## Casos de Uso

- Clarear uma digitalização escura ou corrigir páginas superexpostas
- Dessaturar um documento colorido para reduzir o uso de tinta antes de imprimir
- Aplicar um tom sépia para criar um visual antigo em certificados ou premiações
- Corrigir a temperatura de cor de fotos incorporadas em um PDF
- Aumentar o contraste de documentos digitalizados desbotados ou de baixa qualidade

## Dicas

- Para uma conversão rápida em tons de cinza, arraste o controle de saturação até -100.
- O controle de gama é especialmente útil para melhorar a legibilidade de documentos digitalizados em que os meios-tons estão escuros ou claros demais.
- Como as outras ferramentas de efeito de imagem, esta rasteriza cada página. A saída será baseada em imagem, então o texto não poderá ser selecionado.

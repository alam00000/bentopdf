# Multiferramenta PDF

Um espaço de trabalho unificado para todas as operações de PDF em nível de página. Envie um ou mais PDFs e trabalhe com todas as páginas em uma única grade visual. Gire, reordene, duplique e exclua páginas, insira PDFs, imagens e páginas em branco, renumere, redimensione e divida o resultado, tudo sem sair da ferramenta.

## Como Funciona

1. Clique em **Selecionar Arquivos** ou arraste arquivos para a área de envio. Vários arquivos são suportados e eles são mesclados na ordem de envio.
2. Todas as páginas aparecem em uma grade rolável com miniaturas.
3. Clique em uma página para selecioná-la. Use Shift+clique para selecionar um intervalo e Cmd/Ctrl+clique para adicionar ou remover páginas individuais da seleção.
4. Use a barra de ferramentas do organizador ou clique com o botão direito em uma página para ver as ações de página.
5. Clique em **Exportar PDF** para baixar o resultado final.

## Recursos

- **Mesclar**: envie vários PDFs e imagens e eles são combinados automaticamente em um único documento
- **Reordenar**: arraste e solte páginas para reorganizar a sequência ou inverta a ordem do documento inteiro
- **Girar**: gire as páginas selecionadas para a esquerda ou para a direita em incrementos de 90 graus
- **Duplicar**: copie as páginas selecionadas e coloque as cópias logo depois delas
- **Excluir**: remova as páginas selecionadas
- **Inserir**: adicione páginas de outro PDF ou imagem, uma página em branco ou páginas da área de transferência, ou intercale as páginas de um segundo PDF com as atuais
- **Substituir**: troque uma página pela primeira página de outro PDF
- **Recortar, copiar e colar**: mova ou copie páginas dentro do documento
- **Extrair**: baixe as páginas selecionadas como PDF ou como imagens
- **Números de Página**: defina rótulos de página como i, ii, iii ou A-1, A-2 para um intervalo de páginas
- **Tamanho da Página**: ajuste as páginas a um tamanho de papel padrão ou a um tamanho personalizado
- **Dividir**: divida o documento por intervalos de páginas, páginas ímpares e pares, cada página, marcadores, a cada N páginas ou tamanho de arquivo
- **Desfazer / Refazer**: toda operação de página pode ser desfeita e refeita
- Repara automaticamente PDFs corrompidos antes de carregá-los

## Atalhos de Teclado

| Ação                            | Atalho                        |
| ------------------------------- | ----------------------------- |
| Girar para a direita / esquerda | R / Shift+R                   |
| Selecionar tudo                 | Cmd/Ctrl+A                    |
| Recortar, copiar, colar         | Cmd/Ctrl+X, C, V              |
| Duplicar                        | Cmd/Ctrl+D                    |
| Excluir                         | Delete ou Backspace           |
| Desfazer / Refazer              | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| Mover a seleção                 | Teclas de seta, Home, End     |

## Casos de Uso

- Montar um documento personalizado com páginas de vários PDFs de origem
- Limpar um documento digitalizado excluindo páginas em branco, girando digitalizações de lado e reordenando seções
- Dividir um PDF grande nos limites dos capítulos usando os marcadores do próprio arquivo
- Fazer edições rápidas em nível de página sem precisar de um editor de PDF completo

## Dicas

- O histórico de desfazer/refazer registra cada operação de página. Use-o à vontade, pois você não consegue destruir seu trabalho por acidente.
- Use **Insert > From File** ou solte mais PDFs ou imagens na grade de páginas a qualquer momento para adicioná-los ao documento.
- Para tarefas simples de mesclar ou dividir, as ferramentas dedicadas [Mesclar PDF](./merge-pdf) ou [Dividir PDF](./split-pdf) podem ser mais rápidas. A Multiferramenta brilha quando você precisa de várias operações em uma só sessão.

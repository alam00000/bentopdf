# Multiferramenta PDF

Um espaço de trabalho unificado para todas as operações de PDF em nível de página. Envie um ou mais PDFs e trabalhe com todas as páginas em uma única grade visual. Gire, reordene, duplique, exclua, insira novos PDFs, adicione páginas em branco e divida o resultado, tudo sem sair da ferramenta.

## Como Funciona

1. Clique em **Enviar PDFs** ou arraste arquivos para a área de envio. Vários arquivos são suportados.
2. Todas as páginas de cada arquivo enviado aparecem em uma grade rolável com miniaturas.
3. Use a barra de ferramentas ou os botões de ação de cada página para manipular as páginas.
4. Selecione páginas usando a caixa de seleção de cada cartão e depois aplique operações em lote.
5. Marque pontos de divisão com o ícone de tesoura para dividir a saída em arquivos separados.
6. Clique em **Exportar PDF** para baixar o resultado final. Se houver marcadores de divisão, a saída é um ZIP com vários PDFs.

## Recursos

- **Mesclar**: envie vários PDFs e eles são combinados em um único espaço de trabalho automaticamente
- **Reordenar**: arraste e solte os cartões de página para reorganizar a sequência
- **Girar**: rotação por página ou em lote, em incrementos de 90 graus (para a esquerda ou para a direita)
- **Duplicar**: clone qualquer página com um clique
- **Excluir**: remova páginas individuais ou exclua em lote as selecionadas
- **Inserir PDF**: adicione um novo PDF após qualquer página específica
- **Adicionar Página em Branco**: acrescente uma página A4 em branco no final
- **Dividir**: coloque marcadores de divisão entre as páginas e depois exporte como um ZIP de PDFs separados
- **Selecionar Tudo / Desmarcar Tudo**: seleção rápida para operações em lote
- **Desfazer / Refazer**: histórico completo de desfazer/refazer para cada operação
- **Baixar selecionadas**: exporte apenas as páginas selecionadas como um PDF independente
- Repara automaticamente PDFs corrompidos antes de carregá-los

## Casos de Uso

- Montar um documento personalizado com páginas de vários PDFs de origem
- Limpar um documento digitalizado excluindo páginas em branco, girando digitalizações de lado e reordenando seções
- Dividir um PDF grande nos limites dos capítulos usando marcadores de divisão visuais
- Fazer edições rápidas em nível de página sem precisar de um editor de PDF completo

## Dicas

- O sistema de desfazer/refazer registra cada operação. Use-o à vontade, pois você não consegue destruir seu trabalho por acidente.
- Os marcadores de divisão aparecem como linhas azuis tracejadas entre as páginas. Posicione-os visualmente onde quer dividir o documento e depois exporte para obter um ZIP.
- Para tarefas simples de mesclar ou dividir, as ferramentas dedicadas [Mesclar PDF](./merge-pdf) ou [Dividir PDF](./split-pdf) podem ser mais rápidas. A Multiferramenta brilha quando você precisa de várias operações em uma só sessão.

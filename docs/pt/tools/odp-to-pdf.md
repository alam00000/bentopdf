# ODP para PDF

Converta arquivos OpenDocument Presentation em PDF. O ODP é o formato nativo do LibreOffice Impress e uma exportação padrão do Google Slides. Transformar apresentações em PDFs permite que qualquer pessoa as veja sem software de apresentação, e os slides são impressos de forma limpa.

## Formatos suportados

| Formato                   | Extensão | Observações                                       |
| :------------------------ | :------- | :------------------------------------------------ |
| OpenDocument Presentation | `.odp`   | LibreOffice Impress / exportação do Google Slides |

## Como funciona

1. Clique na área de upload ou arraste e solte seus arquivos ODP. Você pode selecionar várias apresentações de uma vez.
2. Revise a lista de arquivos. Remova itens com o ícone da lixeira ou use **Adicionar mais arquivos** para incluir outras apresentações.
3. Clique em **Converter para PDF**. O mecanismo baseado no LibreOffice processa cada apresentação e produz um PDF em que cada slide vira uma página.
4. Um único arquivo é baixado como PDF. Vários arquivos são entregues em um arquivo ZIP chamado `odp-to-pdf.zip`.

## Opções

Sem configurações. Cada slide é renderizado em suas dimensões originais, preservando texto, imagens, formas e planos de fundo dos slides.

## Casos de uso

- Distribuir uma apresentação ao público como PDF de apoio
- Compartilhar exportações do Google Slides com pessoas que preferem PDF a ODP
- Arquivar palestras e aulas em um formato somente leitura
- Imprimir apresentações para workshops presenciais

## Dicas

- Transições e animações de slides são recursos apenas visuais que não passam para o PDF, mas todo o conteúdo estático é renderizado corretamente.
- As notas do apresentador não são incluídas no PDF. Se você precisa das notas, exporte-as separadamente pelo seu software de apresentação.
- Como as outras ferramentas baseadas no LibreOffice, o mecanismo é carregado no primeiro uso e fica em cache durante a sessão.

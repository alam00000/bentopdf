# Editar anexos

Inspecione e gerencie os arquivos anexados dentro de um PDF. A ferramenta lista cada arquivo incorporado com seu nome e nível de anexo, e permite marcar anexos individuais para remoção ou removê-los todos de uma vez.

## Como funciona

1. Envie um arquivo PDF.
2. A ferramenta procura os anexos automaticamente e os exibe em uma lista.
3. Cada anexo mostra o nome do arquivo e se é um anexo de nível de documento ou de nível de página.
4. Clique no ícone de lixeira ao lado de um anexo para marcá-lo para remoção (clique novamente para desmarcar).
5. Use o botão **Remover todos os anexos** para selecionar tudo de uma vez ou **Desmarcar tudo** para limpar suas seleções.
6. Clique no botão de processar para salvar um novo PDF sem os anexos selecionados.

## Recursos

- Lista todos os anexos de nível de documento e de nível de página
- Remoção de anexos individual ou em massa
- Alterne a seleção antes de confirmar as alterações
- Texto riscado e opacidade reduzida nos itens marcados para remoção
- Baixa o PDF modificado sem os anexos selecionados

## Casos de uso

- Remover arquivos desatualizados ou incorretos incorporados em um documento antes de redistribuí-lo
- Retirar anexos sensíveis (dados financeiros, informações pessoais) de um PDF antes de compartilhá-lo
- Reduzir o tamanho do PDF removendo arquivos incorporados grandes que não são mais necessários
- Auditar o conteúdo incorporado e limpar um documento antes de arquivá-lo

## Dicas

- Os anexos marcados para remoção aparecem riscados. Você pode desfazer a marcação antes de processar, se mudar de ideia.
- Se nenhum anexo for encontrado, a ferramenta exibe a mensagem "Nenhum anexo encontrado", ou seja, o PDF simplesmente não contém arquivos incorporados.

# Excluir páginas

Remova páginas indesejadas de um documento PDF. Indique as páginas a excluir digitando números de página ou intervalos, ou clique diretamente nas miniaturas para marcá-las para remoção.

## Como funciona

1. Envie um arquivo PDF. A ferramenta renderiza miniaturas de todas as páginas.
2. Digite as páginas a excluir no campo de texto usando a sintaxe de intervalos (por exemplo, `2, 5-8`) ou clique nas miniaturas para alternar a seleção.
3. As páginas marcadas ficam destacadas para você confirmar a seleção.
4. Clique no botão de processar. Um novo PDF é criado sem as páginas selecionadas.

## Recursos

- Seleção de páginas por texto com sintaxe de intervalos (`2, 5-8, 12`)
- Grade visual de miniaturas para excluir com um clique
- Destaque em tempo real das páginas marcadas para exclusão
- Validação da entrada em relação ao número real de páginas
- Mantém todas as páginas não excluídas na ordem original

## Casos de uso

- Remover páginas em branco ou de preenchimento de um documento digitalizado
- Retirar capas ou apêndices antes de compartilhar um documento
- Limpar páginas de rascunho deixadas por engano em um PDF final
- Remover páginas com informações sensíveis antes da distribuição

## Dicas

- Excluir páginas não afeta o conteúdo nem a formatação das páginas restantes. A saída é uma cópia fiel do original sem as páginas removidas.
- Se você quer manter apenas páginas específicas em vez de remover algumas, [Extrair Páginas](./extract-pages) é a melhor opção.
- A visualização de miniaturas carrega sob demanda, então documentos grandes continuam responsivos.

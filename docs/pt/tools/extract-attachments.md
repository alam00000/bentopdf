# Extrair anexos

Retire todos os anexos incorporados de um ou mais arquivos PDF. Todos os arquivos extraídos são reunidos em um único arquivo ZIP para download.

## Como funciona

1. Envie um ou mais arquivos PDF que contenham anexos incorporados.
2. Clique em **Extrair Anexos**.
3. A ferramenta procura anexos de nível de documento e de nível de página em cada PDF.
4. Todos os arquivos encontrados são empacotados em um arquivo ZIP e baixados automaticamente.
5. Uma mensagem de status confirma quantos anexos foram encontrados e o tamanho total.

## Recursos

- Extração em lote de vários PDFs de uma só vez
- Extrai anexos de nível de documento e de nível de página
- Gera um único arquivo ZIP contendo todos os arquivos extraídos
- Exibe a contagem total de anexos e o tamanho combinado dos arquivos
- Mensagens de status claras se nenhum anexo for encontrado

## Casos de uso

- Recuperar arquivos de dados incorporados em um PDF de relatório
- Retirar recursos de imagem de um portfólio ou de um documento de especificação
- Extrair materiais complementares de PDFs de treinamento ou de conformidade
- Auditar quais arquivos estão incorporados em um lote de PDFs

## Dicas

- Se a ferramenta informar que não há anexos, o PDF pode conter imagens incorporadas ou dados de formulário, que não são anexos de arquivo. Use [Extrair Imagens](./extract-images) para imagens incorporadas.
- Ao processar vários PDFs, todos os anexos de todos os arquivos vão para um único ZIP. Os nomes dos arquivos são preservados como nas incorporações originais.

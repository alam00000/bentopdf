# Criar formulário PDF

Projete formulários PDF preenchíveis profissionais do zero ou adicionando campos a um PDF existente. O editor visual permite arrastar e soltar elementos de formulário (campos de texto, caixas de seleção, listas suspensas, botões de opção, campos de assinatura e mais) diretamente nas prévias das páginas. Configure as propriedades dos campos, defina regras de visibilidade condicional e exporte um formulário PDF totalmente interativo.

## Como funciona

1. Envie um PDF existente **ou** clique em **Criar PDF em Branco** para começar do zero.
2. Se estiver criando um PDF em branco, selecione um tamanho de página (Carta, A4, A5, Ofício, Tabloide, A3 ou dimensões personalizadas).
3. O editor de formulários abre com uma barra de ferramentas de tipos de campo e uma área de prévia da página.
4. Selecione um tipo de campo na barra de ferramentas e clique na página para posicioná-lo.
5. Arraste os campos para reposicioná-los. Use as alças de redimensionamento para ajustar as dimensões.
6. Clique em um campo para abrir o painel de propriedades, onde você pode definir o nome do campo, valor padrão, tamanho da fonte, alinhamento e mais.
7. Navegue entre as páginas usando os controles de página.
8. Clique em **Salvar** para baixar o PDF preenchível finalizado.

## Recursos

- Posicionamento de campos por arrastar e soltar, com alças visuais para redimensionar
- Tipos de campo: entrada de texto, texto de várias linhas, caixa de seleção, lista suspensa, botão de opção, assinatura, data, número e código de barras
- Painel de propriedades para configurar o nome, rótulo, valor padrão, tamanho da fonte, cor, alinhamento e validação de cada campo
- Ações de campo e regras de visibilidade condicional (mostrar/ocultar campos com base nos valores de outros campos)
- Navegação de páginas para formulários de várias páginas
- Extração de campos existentes: detecta e importa automaticamente os campos de formulário de PDFs enviados
- Suporte a PDFs enviados e a páginas em branco como tela do formulário
- Vários tamanhos de página predefinidos, além de dimensões personalizadas
- Geração de códigos de barras com bwip-js
- Gerenciamento de grupos de botões de opção

## Opções

**Tamanhos de página predefinidos (para PDFs em branco):**

- Carta (8,5" x 11")
- A4 (210mm x 297mm)
- A5 (148mm x 210mm)
- Ofício (8,5" x 14")
- Tabloide (11" x 17")
- A3 (297mm x 420mm)
- Personalizado (informe largura e altura)

**Propriedades do campo (variam conforme o tipo de campo):**

- Nome, rótulo e texto de espaço reservado
- Valor padrão
- Família, tamanho e cor da fonte
- Alinhamento do texto (esquerda, centro, direita)
- Alternância de campo obrigatório
- Alternância de somente leitura
- Comprimento máximo para campos de texto
- Lista de opções para listas suspensas e botões de opção
- Ações de visibilidade condicional

## Casos de uso

- Criar formulários de integração de funcionários com campos de texto para dados pessoais e caixas de seleção para ciência das políticas
- Criar questionários de admissão de clientes com listas suspensas para escolha de serviço
- Projetar formulários de pedido com campos calculados e identificadores em código de barras
- Criar checklists de inspeção com botões de opção para avaliações de aprovado/reprovado
- Criar formulários de pesquisa com perguntas de acompanhamento condicionais que aparecem conforme as respostas

## Dicas

- Se você enviar um PDF existente, a ferramenta tentará extrair os campos de formulário já presentes, permitindo editá-los ou adicionar novos.
- Use o recurso de grupo de botões de opção para criar seleções mutuamente exclusivas. Campos do mesmo grupo compartilham um nome de grupo.
- Teste seu formulário baixando-o e abrindo-o no [Preenchedor de Formulários](./form-filler) para verificar o comportamento dos campos.

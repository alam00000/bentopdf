# 메타데이터 보기

PDF 파일에 숨겨진 속성을 살펴보세요. 이 도구는 문서 정보(제목, 작성자, 날짜), XMP 메타데이터, 페이지 크기 및 기타 구조 데이터를 읽기 쉬운 형태로 보여 줍니다.

## 작동 방식

1. PDF 파일을 업로드합니다.
2. 도구가 즉시 파일을 분석해 사용 가능한 모든 메타데이터를 구분된 섹션으로 표시합니다.
3. 문서 정보 사전, XMP 메타데이터 트리, 구조 속성을 검토합니다.
4. 별도의 처리 단계는 없습니다. 파일이 로드되자마자 메타데이터가 표시됩니다.

## 기능

- 표준 문서 정보 필드 표시: 제목, 작성자, 주제, 키워드, 작성 프로그램, 생성 프로그램
- 생성 및 수정 날짜를 사람이 읽기 쉬운 형식으로 표시
- 중첩된 네임스페이스를 포함한 전체 XMP 메타데이터 트리를 분석하고 렌더링
- PDF 날짜 형식(`D:20240101120000Z`)을 읽기 쉬운 날짜로 변환
- 쉽게 탐색할 수 있도록 접을 수 있는 섹션으로 구성

## 메타데이터 섹션

| 섹션               | 내용                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------- |
| **문서 정보**      | 제목, 작성자, 주제, 키워드, 작성 프로그램, 생성 프로그램, 생성 날짜, 수정 날짜           |
| **XMP 메타데이터** | Dublin Core, XAP, PDF 및 사용자 지정 네임스페이스를 포함한 전체 XML 기반 메타데이터 트리 |
| **문서 속성**      | 페이지 수, PDF 버전, 파일 크기, 암호화 상태                                              |

## 사용 사례

- PDF의 작성자와 마지막 수정 시점 확인
- 문서를 게시하기 전에 메타데이터가 올바르게 설정되었는지 확인
- 어떤 개인 정보가 포함되어 있는지 확인해 PDF의 개인정보 보호 감사
- 생성 프로그램 필드를 통해 PDF를 만들거나 수정한 소프트웨어 조사
- 디지털 자산 관리 규정 준수를 위한 XMP 메타데이터 검토

## 팁

- `D:`로 시작하는 PDF 날짜 문자열은 자동으로 현지 시간대 형식으로 변환됩니다.
- 메타데이터 필드가 비어 있다면 PDF 작성자가 설정하지 않은 것뿐입니다. 모든 PDF에 풍부한 메타데이터가 있는 것은 아닙니다.
- 확인한 메타데이터를 수정하려면 [메타데이터 편집](./edit-metadata)을 사용하세요. 모두 제거하려면 메타데이터 제거를 사용하세요.

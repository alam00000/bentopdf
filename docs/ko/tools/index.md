# 도구 안내

BentoPDF는 PDF 작업을 위한 **130개 이상의 도구**를 제공합니다. 모든 도구는 전적으로 브라우저에서 실행되므로 파일이 기기 밖으로 나가지 않습니다.

---

## 편집 및 주석

다양한 편집 도구로 PDF 문서를 수정하고, 표시하고, 보강하세요.

<div class="tool-grid">

- [**PDF 편집기**](./edit-pdf): 주석, 하이라이트, 교정(가리기), 댓글, 도형/이미지 추가, 검색, PDF 보기.
- [**북마크 편집**](./bookmark): PDF 북마크를 추가, 편집, 가져오기, 삭제, 추출합니다.
- [**목차 생성**](./table-of-contents): PDF 북마크로 목차 페이지를 생성합니다.
- [**페이지 번호**](./page-numbers): 문서에 페이지 번호를 삽입합니다.
- [**페이지 레이블 추가**](./add-page-labels): 로마 숫자, 접두사, 사용자 지정 시작 번호로 PDF 페이지 레이블을 적용합니다.
- [**베이츠 번호 매기기**](./bates-numbering): 하나 이상의 PDF 파일에 연속된 베이츠 번호를 추가합니다.
- [**워터마크 추가**](./add-watermark): PDF 페이지 위에 텍스트나 이미지를 찍습니다.
- [**머리글 및 바닥글**](./header-footer): 페이지 위쪽과 아래쪽에 텍스트를 추가합니다.
- [**색상 반전**](./invert-colors): PDF의 다크 모드 버전을 만듭니다.
- [**스캔 효과**](./scanner-effect): PDF를 스캔한 문서처럼 보이게 합니다.
- [**색상 조정**](./adjust-colors): 밝기, 대비, 채도 등을 세밀하게 조정합니다.
- [**배경색 변경**](./background-color): PDF의 배경색을 바꿉니다.
- [**텍스트 색상 변경**](./text-color): PDF 텍스트의 색상을 바꿉니다.
- [**PDF 서명**](./sign-pdf): 서명을 그리거나, 입력하거나, 업로드합니다.
- [**도장 추가**](./add-stamps): 주석 도구 모음으로 PDF에 이미지 도장을 추가합니다.
- [**주석 제거**](./remove-annotations): 댓글, 하이라이트, 링크를 제거합니다.
- [**PDF 자르기**](./crop-pdf): PDF 모든 페이지의 여백을 다듬습니다.
- [**PDF 양식 작성**](./form-filler): 브라우저에서 바로 양식을 작성합니다. XFA 양식도 지원합니다.
- [**PDF 양식 만들기**](./form-creator): 드래그 앤 드롭 텍스트 필드로 작성 가능한 PDF 양식을 만듭니다.
- [**빈 페이지 제거**](./remove-blank-pages): 빈 페이지를 자동으로 감지해 삭제합니다.

</div>

## PDF에서 변환

<div class="tool-grid">

- [**PDF를 JPG로**](./pdf-to-jpg): PDF의 각 페이지를 JPG 이미지로 변환합니다.
- [**PDF를 PNG로**](./pdf-to-png): PDF의 각 페이지를 PNG 이미지로 변환합니다.
- [**PDF를 WebP로**](./pdf-to-webp): PDF의 각 페이지를 WebP 이미지로 변환합니다.
- [**PDF를 BMP로**](./pdf-to-bmp): PDF의 각 페이지를 BMP 이미지로 변환합니다.
- [**PDF를 TIFF로**](./pdf-to-tiff): PDF의 각 페이지를 TIFF 이미지로 변환합니다.
- [**PDF를 CBZ로**](./pdf-to-cbz): 만화 리더와 Calibre용으로 PDF를 CBZ(만화책 아카이브)로 변환합니다.
- [**PDF를 SVG로**](./pdf-to-svg): PDF의 각 페이지를 확장 가능한 벡터 그래픽으로 변환합니다.
- [**PDF를 CSV로**](./pdf-to-csv): PDF에서 표를 추출해 CSV 형식으로 변환합니다.
- [**PDF를 Excel로**](./pdf-to-excel): PDF에서 표를 추출해 Excel(XLSX)로 변환합니다.
- [**PDF 흑백 변환**](./pdf-to-greyscale): 모든 색상을 흑백으로 변환합니다.
- [**PDF를 JSON으로**](./pdf-to-json): PDF 파일을 JSON 형식으로 변환합니다.
- [**PDF를 Word로**](./pdf-to-word): PDF 파일을 편집 가능한 Word 문서로 변환합니다.
- [**이미지 추출**](./extract-images): PDF 파일에 포함된 모든 이미지를 추출합니다.
- [**PDF를 Markdown으로**](./pdf-to-markdown): PDF 텍스트와 표를 Markdown 형식으로 변환합니다.
- [**AI용 PDF 준비**](./prepare-pdf-for-ai): RAG/LLM 파이프라인용으로 PDF 내용을 LlamaIndex JSON으로 추출합니다.
- [**PDF를 텍스트로**](./pdf-to-text): PDF 파일에서 텍스트를 추출해 일반 텍스트로 저장합니다.
- [**PDF 표 추출**](./extract-tables): PDF의 표를 CSV, JSON, Markdown으로 추출합니다.

- [**페이지 분할**](./divide-pages): 페이지를 가로 또는 세로로 나눕니다.

- [**페이지 삭제**](./delete-pages): 문서에서 특정 페이지를 제거합니다.
- [**빈 페이지 추가**](./add-blank-page): PDF의 원하는 위치에 빈 페이지를 삽입합니다.
- [**페이지 역순 정렬**](./reverse-pages): 문서의 모든 페이지 순서를 뒤집습니다.
- [**PDF 회전**](./rotate-pdf): 페이지를 90도 단위로 돌립니다.
- [**사용자 지정 각도 회전**](./rotate-custom): 원하는 각도로 페이지를 회전합니다.
- [**N-Up PDF**](./n-up-pdf): 여러 페이지를 한 장에 배치합니다.
- [**PDF 소책자**](./pdf-booklet): 양면 소책자 인쇄에 맞게 페이지를 재배열합니다.
- [**한 페이지로 합치기**](./combine-single-page): 모든 페이지를 이어진 하나의 스크롤로 연결합니다.
- [**메타데이터 보기**](./view-metadata): PDF의 숨겨진 속성을 확인합니다.

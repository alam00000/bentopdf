# WPD를 PDF로

Corel WordPerfect 문서를 PDF 파일로 변환합니다. WPD는 한때 법률 사무소와 정부 기관에서 지배적인 워드 프로세서 형식이었습니다. 최신 소프트웨어가 열어 주지 않는 오래된 WordPerfect 파일이 있다면, 이 도구로 표준 PDF로 되살릴 수 있습니다.

## 지원 형식

| 형식        | 확장자 | 참고                       |
| :---------- | :----- | :------------------------- |
| WordPerfect | `.wpd` | 모든 주요 WordPerfect 버전 |

## 작동 방식

1. 업로드 영역을 클릭하거나 WPD 파일을 끌어다 놓습니다. 여러 파일을 한 번에 선택할 수 있습니다.
2. 파일 목록을 확인합니다. 휴지통 아이콘으로 원하지 않는 파일을 제거하거나, **파일 더 추가**로 문서를 더 추가합니다.
3. **PDF로 변환**을 클릭합니다. 도구가 브라우저에 LibreOffice 기반 변환 엔진을 로드해 WPD 형식을 분석하고 PDF로 출력합니다.
4. 파일이 하나면 PDF로 바로 다운로드됩니다. 일괄 변환은 `wpd-to-pdf.zip`이라는 ZIP 압축 파일로 만들어집니다.

## 옵션

별도의 설정은 필요하지 않습니다. LibreOffice 엔진이 WPD의 서식, 글꼴, 레이아웃을 자동으로 처리합니다.

## 사용 사례

- 수십 년 전 WordPerfect로 작성한 법률 문서 열기
- 보관된 정부 제출 서류를 WPD에서 최신 형식으로 변환
- 장기 보관을 위해 레거시 WordPerfect 문서 라이브러리를 PDF로 이전
- Corel WordPerfect가 설치되지 않은 수신자와 WPD 파일 공유

## 팁

- LibreOffice 엔진은 처음 사용할 때 로드되므로 잠시 걸립니다. 같은 세션의 이후 변환은 더 빠릅니다.
- 복잡한 WPD 매크로와 코드 표시는 유지되지 않지만, 시각적 레이아웃, 텍스트 내용, 기본 서식은 PDF로 그대로 옮겨집니다.

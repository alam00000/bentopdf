# 복제 및 정리

시각적인 드래그 앤 드롭 인터페이스로 PDF의 페이지를 재배열, 복제, 제거합니다. 각 페이지가 미리보기로 표시되며, 새 파일로 저장하기 전에 이동, 복제, 삭제할 수 있습니다.

## 사용 방법

1. PDF 파일 하나를 업로드합니다.
2. 도구가 모든 페이지의 미리보기 그리드를 렌더링합니다.
3. 미리보기를 끌어 순서를 바꾸고, 초록색 복제 버튼으로 페이지를 복제하고, 빨간색 삭제 버튼으로 페이지를 제거합니다.
4. 또는 텍스트 필드에 사용자 지정 페이지 순서(예: `3, 1, 2, 4`)를 입력하고 **적용**을 클릭하면 모든 페이지가 한 번에 재배열됩니다.
5. 처리 버튼을 클릭해 재구성된 PDF를 만들고 다운로드합니다.

## 기능

- 애니메이션 전환이 있는 드래그 앤 드롭 페이지 재정렬
- 페이지별 복제 및 삭제 버튼
- 정밀한 재배열을 위한 사용자 지정 페이지 순서 입력
- 변경할 때마다 자동으로 갱신되는 페이지 번호 레이블
- 마지막 남은 페이지 삭제 방지

## 활용 사례

- 보고서에서 잘못 놓인 페이지를 올바른 위치로 옮기기
- 양식 페이지를 복제해 한 파일에 빈 사본 여러 개 만들기
- 문서를 배포하기 전에 초안이나 임시 페이지 제거하기
- 인쇄 준비를 위해 페이지 순서 뒤집기 또는 섞기
- 별도 파일을 다시 병합하지 않고 사용자 지정 페이지 순서 만들기

## 팁

- 사용자 지정 페이지 순서 필드에는 쉼표로 구분한 원래 페이지 번호를 입력해야 합니다. 모든 페이지가 정확히 한 번씩 포함되어야 하며, 누락이나 중복은 허용되지 않습니다.
- 페이지를 복제하면 두 사본이 같은 원본 페이지 인덱스를 참조합니다. 어느 사본이든 순서 변경은 독립적으로 작동합니다.
- 여러 파일에 걸친 대량 작업이나 더 고급 워크플로우에는 [PDF 멀티 도구](./pdf-multi-tool)를 사용해 보세요.

# 배경색 변경

PDF의 기존 내용 뒤에 단색 배경을 설정합니다. 각 페이지에 색 사각형을 만들고 원본 내용을 그 위에 겹치므로, 텍스트, 이미지, 그래픽이 새 배경 위에서도 완전히 보입니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 색상 선택기로 배경색을 고릅니다. 기본값은 연한 노랑(#FFFFCC)입니다.
3. **배경색 변경**을 클릭하여 처리합니다.
4. 업데이트된 PDF가 자동으로 다운로드됩니다.

## 옵션

- **배경색** -- 원하는 단색을 고르는 표준 색상 선택기입니다. 기본값은 연한 노랑입니다.

## 기능

- 모든 페이지에 균일한 배경색 적용
- 색 레이어 위에 모든 원본 내용(텍스트, 이미지, 벡터 그래픽) 유지
- 원본 페이지 크기 유지
- 페이지 수에 상관없이 사용 가능

## 활용 사례

- 연한 크림색이나 아이보리 배경으로 문서에 종이 같은 부드러운 느낌 부여
- 분류별로 다른 배경색을 적용해 문서 세트를 색으로 구분
- 대상 독자별로 시각적으로 구분되는 같은 문서의 버전 만들기
- 화면에 문서를 띄울 때 가독성을 높이기 위해 연한 배경 색조 추가

## 팁

- 연하고 차분한 색이 가장 잘 어울립니다. 텍스트가 이미 밝은 색이 아니라면 매우 어두운 배경은 글자를 읽기 어렵게 만들 수 있습니다.
- 배경과 텍스트 색을 모두 바꾸려면 먼저 배경색을 적용한 뒤 결과물에 [텍스트 색상 변경](./text-color)을 사용하세요.
- 이 도구는 래스터화가 아닌 PDF 구조 수준에서 작동하므로 출력에서도 텍스트를 선택하고 검색할 수 있습니다.

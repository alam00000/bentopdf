# PDF OCG 레이어

PDF 안의 선택적 콘텐츠 그룹(OCG), 흔히 "레이어"라고 부르는 항목을 관리합니다. 레이어 표시 여부를 전환하고, 새 레이어(중첩된 하위 레이어 포함)를 추가하고, 레이어를 삭제한 뒤 수정된 PDF를 저장할 수 있습니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 처리 버튼을 클릭해 PyMuPDF 엔진으로 문서를 불러옵니다.
3. 도구가 기존 레이어를 표시 상태, 잠금 상태, 중첩 계층과 함께 보여줍니다.
4. 체크박스를 전환해 레이어를 표시하거나 숨깁니다. 잠긴 레이어는 전환할 수 없습니다.
5. 이름을 입력하고 추가 버튼을 클릭해 새 최상위 레이어를 추가하거나, 기존 상위 레이어 아래에 하위 레이어를 추가합니다.
6. 더 이상 필요 없는 레이어를 삭제합니다.
7. **저장**을 클릭해 레이어 변경 사항이 적용된 PDF를 다운로드합니다.

## 기능

- 중첩된 레이어를 올바른 들여쓰기로 계층 구조 표시
- 레이어 표시 켜기/끄기 전환
- 실수로 변경하는 것을 막아주는 잠금 레이어 표시
- 사용자 지정 이름으로 최상위 또는 하위 레이어 추가
- 개별 레이어 삭제
- 모든 변경 사항을 새 PDF 파일로 저장

## 활용 사례

- 건축 또는 엔지니어링 도면에서 마크업 레이어 표시 전환하기
- 여러 레이어로 된 디자인 문서에 새 주석 레이어 추가하기
- 템플릿을 배포하기 전에 더 이상 쓰지 않는 레이어 제거하기
- 외부에서 받은 복잡한 PDF에 어떤 레이어가 있는지 확인하기

## 팁

- PDF에 레이어가 없으면 도구가 빈 상태와 함께 레이어 추가 안내를 표시합니다. 모든 PDF가 OCG 레이어를 사용하는 것은 아니며, CAD 내보내기와 디자인 파일에서 가장 흔합니다.
- 하위 레이어는 상위 레이어 아래에 들여쓰기되어 표시됩니다. 레이어는 원하는 깊이까지 중첩할 수 있습니다.
- 잠긴 레이어는 잠금 아이콘과 함께 표시되며 체크박스가 비활성화됩니다. 이 잠금은 PDF 작성자가 설정한 것입니다.

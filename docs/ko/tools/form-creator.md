# PDF 양식 만들기

처음부터 전문적인 작성 가능 PDF 양식을 설계하거나 기존 PDF에 필드를 추가하세요. 시각적 편집기에서 텍스트 필드, 체크박스, 드롭다운, 라디오 버튼, 서명 필드 등 양식 요소를 페이지 미리보기 위로 바로 끌어다 놓을 수 있습니다. 필드 속성을 설정하고 조건부 표시 규칙을 만든 뒤, 완전한 대화형 PDF 양식으로 내보내세요.

## 사용 방법

1. 기존 PDF를 업로드하거나 **빈 PDF 만들기**를 클릭해 처음부터 시작하세요.
2. 빈 PDF를 만드는 경우 페이지 크기를 선택하세요(Letter, A4, A5, Legal, Tabloid, A3 또는 사용자 지정 크기).
3. 필드 유형 도구 모음과 페이지 미리보기 영역이 있는 양식 편집기가 열립니다.
4. 도구 모음에서 필드 유형을 선택한 다음 페이지를 클릭해 배치하세요.
5. 필드를 끌어 위치를 옮기고 크기 조절 핸들로 크기를 조정하세요.
6. 필드를 클릭하면 속성 패널이 열려 필드 이름, 기본값, 글꼴 크기, 정렬 등을 설정할 수 있습니다.
7. 페이지 컨트롤로 페이지 사이를 이동하세요.
8. **저장**을 클릭해 완성된 작성 가능 PDF를 다운로드하세요.

## 기능

- 크기 조절 핸들이 있는 드래그 앤 드롭 필드 배치
- 필드 유형: 텍스트 입력, 여러 줄 텍스트, 체크박스, 드롭다운, 라디오 버튼, 서명, 날짜, 숫자, 바코드
- 각 필드의 이름, 레이블, 기본값, 글꼴 크기, 색상, 정렬, 유효성 검사를 설정하는 속성 패널
- 필드 동작과 조건부 표시 규칙(다른 필드 값에 따라 필드 표시/숨김)
- 여러 페이지 양식을 위한 페이지 탐색
- 기존 필드 추출: 업로드한 PDF의 양식 필드를 자동으로 감지해 가져옴
- 업로드한 PDF와 빈 페이지 모두 양식 캔버스로 사용 가능
- 여러 페이지 크기 프리셋과 사용자 지정 크기
- bwip-js 기반 바코드 생성
- 라디오 버튼 그룹 관리

## 옵션

**페이지 크기 프리셋(빈 PDF용):**

- Letter (8.5" x 11")
- A4 (210mm x 297mm)
- A5 (148mm x 210mm)
- Legal (8.5" x 14")
- Tabloid (11" x 17")
- A3 (297mm x 420mm)
- 사용자 지정(너비와 높이 지정)

**필드 속성(필드 유형에 따라 다름):**

- 이름, 레이블, 자리 표시자 텍스트
- 기본값
- 글꼴, 크기, 색상
- 텍스트 정렬(왼쪽, 가운데, 오른쪽)
- 필수 필드 전환
- 읽기 전용 전환
- 텍스트 필드 최대 길이
- 드롭다운과 라디오 버튼의 옵션 목록
- 조건부 표시 동작

## 활용 사례

- 개인 정보용 텍스트 필드와 정책 동의용 체크박스가 있는 신규 직원 온보딩 양식 만들기
- 서비스 선택용 드롭다운이 있는 고객 접수 설문지 만들기
- 계산 필드와 바코드 식별자가 있는 주문서 설계하기
- 합격/불합격 평가용 라디오 버튼이 있는 점검 체크리스트 만들기
- 응답에 따라 후속 질문이 나타나는 조건부 설문 양식 만들기

## 팁

- 기존 PDF를 업로드하면 이미 있는 양식 필드를 추출하려고 시도하므로 해당 필드를 편집하거나 추가할 수 있습니다.
- 라디오 버튼 그룹 기능으로 상호 배타적인 선택지를 만드세요. 같은 라디오 그룹의 필드는 그룹 이름을 공유합니다.
- 양식을 다운로드하여 [PDF 양식 작성](./form-filler)에서 열어 필드가 올바르게 동작하는지 테스트하세요.

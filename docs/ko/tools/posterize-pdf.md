# PDF 포스터화

PDF의 각 페이지를 격자 형태의 작은 하위 페이지로 나눕니다. 한 페이지를 여러 장의 용지에 나누어 인쇄한 뒤 이어 붙여 대형 포스터나 현수막을 만들 때 사용하는 도구입니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. **행**과 **열** 수를 설정하여 격자를 정합니다(예: 2행 x 2열이면 각 페이지가 4개의 하위 페이지로 나뉩니다).
3. 필요하면 페이지 범위를 지정하여 포스터화할 페이지를 제한합니다.
4. 미리보기 캔버스에 현재 페이지 위로 격자 오버레이가 표시되어 자르는 위치를 확인할 수 있습니다.
5. 페이지를 넘기며 다른 페이지의 오버레이도 확인합니다.
6. 처리 버튼을 클릭합니다. 격자의 각 칸이 출력 PDF의 개별 페이지가 됩니다.

## 기능

- 행과 열 수를 자유롭게 설정하여 다양한 격자 크기 지원
- 페이지가 나뉘는 위치를 정확히 보여주는 격자 오버레이 실시간 미리보기
- 특정 페이지만 포스터화하는 페이지 범위 필터
- 미리보기에서 페이지별 탐색
- 빠른 미리보기 탐색을 위한 페이지 스냅샷 캐시
- 빨간 점선 격자선으로 자르는 경계를 명확하게 표시

## 옵션

| 옵션            | 설명                                      |
| --------------- | ----------------------------------------- |
| **행**          | 가로 분할 수 (기본값: 1)                  |
| **열**          | 세로 분할 수 (기본값: 1)                  |
| **페이지 범위** | 포스터화할 페이지 (비워 두면 모든 페이지) |

## 활용 사례

- 포스터 크기의 PDF를 일반 A4 또는 Letter 용지에 나누어 인쇄하여 벽에 붙이기
- 한 페이지짜리 PDF 디자인으로 대형 현수막 만들기
- 큰 기술 도면을 인쇄 가능한 조각으로 나누기
- 대형 프린터 없이 대형 인쇄물 만들기

## 팁

- 2x2 격자는 한 페이지를 4페이지로, 3x3 격자는 9페이지로 만듭니다. 최종적으로 이어 붙인 결과물의 크기에 맞춰 격자를 계획하세요.
- 미리보기 오버레이로 중요한 내용이 자르는 선에 걸치지 않는지 확인할 수 있습니다. 필요하면 행/열을 조정하세요.
- 반대 작업(여러 페이지를 한 장에 맞추기)에는 [N-Up PDF](./n-up-pdf)를 사용하세요.

# 북마크 편집

북마크 편집기를 사용하면 PDF 탐색 북마크(개요라고도 합니다)를 완전히 제어할 수 있습니다. 새 북마크를 추가하고, 기존 북마크를 편집하고, 계층 구조를 재구성하고, 북마크 데이터를 CSV 및 JSON 형식으로 가져오거나 내보낼 수 있습니다.

## 사용 방법

1. 클릭하거나 파일을 드롭 영역으로 끌어다 놓아 PDF를 업로드합니다.
2. 필요하면 **기존 북마크 자동 추출**을 선택하여 문서의 현재 북마크 트리를 불러옵니다.
3. 편집기가 분할 보기로 열립니다. 왼쪽에는 PDF 뷰어, 오른쪽에는 북마크 패널이 표시됩니다.
4. 북마크 제목을 입력하고 **페이지에 추가**를 클릭하면 현재 페이지를 가리키는 새 북마크가 만들어집니다.
5. 도구 모음 버튼으로 북마크를 재정렬하거나, 스타일을 지정하거나, 삭제합니다.
6. **북마크 포함하여 PDF 저장**을 클릭하여 업데이트된 파일을 다운로드합니다.

## 기능

- 페이지 이동, 확대/축소 컨트롤, 페이지 이동 입력란이 있는 시각적 PDF 뷰어
- 한 번의 클릭으로 모든 페이지에 북마크 추가
- PDF를 직접 클릭하여 정확한 북마크 위치 지정(지정 모드)
- 드래그 앤 드롭으로 순서를 바꿀 수 있는 중첩 북마크 계층 구조
- 일괄 작업: 여러 북마크를 선택하여 색상, 스타일 변경 또는 삭제를 한 번에 처리
- 큰 트리에서 항목을 빠르게 찾는 북마크 검색
- 모든 변경 사항에 대한 실행 취소 및 다시 실행 지원
- CSV(제목, 페이지, 수준) 또는 JSON 파일에서 북마크 가져오기
- 외부 편집을 위해 북마크를 CSV 또는 JSON으로 내보내기
- 북마크 스타일: 색상(빨강, 파랑, 초록, 노랑, 보라)과 글꼴 스타일(굵게, 기울임, 굵은 기울임)
- 빠른 탐색: 페이지 위/아래 키로 페이지 스크롤

## 옵션

- **기존 북마크 자동 추출**: 선택하면 로드할 때 PDF의 현재 북마크를 읽어 표시합니다.
- **일괄 모드**: 여러 북마크를 선택하여 색상, 스타일 또는 삭제 작업을 한꺼번에 적용합니다.
- **모두 펼치기/접기**: 중첩된 하위 북마크를 빠르게 표시하거나 숨깁니다.

## 사용 사례

- 북마크가 없는 교재나 매뉴얼에 목차 추가
- OCR 처리 후 스캔 문서의 북마크 구조 재정비
- 북마크를 CSV로 내보내 스프레드시트에서 편집한 뒤 다시 가져오기
- 페이지 참조가 잘못된 자동 생성 북마크 정리
- 법률 준비서면의 중요한 섹션을 표시하기 위해 색상 북마크 추가

## 팁

- 대량으로 북마크를 만들 때는 CSV 가져오기를 사용하세요. 형식은 간단합니다. `title,page,level`이며 level 1이 최상위입니다.
- 지정 모드에서는 PDF 페이지의 정확한 위치를 클릭하여 북마크 대상을 지정할 수 있어, 페이지 번호만 지정하는 것보다 정밀합니다.
- 큰 변경을 하기 전에 북마크를 내보내 백업해 두세요.

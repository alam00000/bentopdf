# XML을 PDF로

XML 데이터 파일을 읽기 쉬운 구조화된 PDF 문서로 변환합니다. 원시 XML은 강력하지만 사람이 읽기에는 어렵습니다. 이 도구는 XML 트리를 분석해 반복되는 데이터 구조를 찾아내고, 가로 방향 A4 PDF에 서식이 있는 표와 섹션으로 렌더링합니다.

## 지원 형식

| 형식 | 확장자 | 참고                        |
| :--- | :----- | :-------------------------- |
| XML  | `.xml` | 올바른 형식의 모든 XML 문서 |

## 작동 방식

1. 업로드 영역을 클릭하거나 XML 파일을 끌어다 놓습니다. 여러 파일을 한 번에 처리할 수 있습니다.
2. 파일 목록을 확인합니다. 휴지통 아이콘으로 원하지 않는 파일을 제거하거나, **파일 더 추가**를 클릭해 더 포함합니다.
3. **PDF로 변환**을 클릭합니다. 도구가 브라우저 내장 DOMParser로 XML 구조를 분석하고, 데이터 계층을 파악한 뒤, jsPDF와 자동 표 서식을 사용해 PDF로 렌더링합니다.
4. 파일이 하나면 PDF로 다운로드됩니다. 여러 변환 결과는 `xml-to-pdf.zip`으로 묶입니다.

## 옵션

수동 설정은 필요하지 않습니다. 변환기가 XML 구조를 자동으로 감지해 적절한 표 레이아웃을 선택합니다. 넓은 데이터 세트를 담기 위해 결과물은 가로 방향 A4를 사용합니다.

## 사용 사례

- 데이터베이스나 API에서 내보낸 XML 데이터를 인쇄 가능한 보고서로 변환
- XML 구성 파일에서 읽기 쉬운 요약 만들기
- XML 기반 청구서나 거래 로그를 기록 보관용 PDF로 변환
- XML 사이트맵이나 RSS 피드를 문서 형태로 읽기 쉽게 만들기

## 팁

- XML은 올바른 형식이어야 합니다. 파서가 구문 오류를 발견하면 문제 위치를 알려 주는 오류 메시지와 함께 변환이 실패합니다.
- 깊게 중첩된 XML 구조는 표로 평면화됩니다. 최상의 결과를 위해 데이터에는 일관된 하위 요소를 가진 반복 형제 요소가 있어야 합니다.
- 변환 중에는 읽기, 분석, 구조 파악, 렌더링의 각 단계를 보여 주는 진행 상황이 표시됩니다.

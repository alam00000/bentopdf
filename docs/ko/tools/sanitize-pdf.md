# PDF 정리

PDF에는 화면에 보이는 것보다 훨씬 많은 정보가 들어 있을 수 있습니다. 숨겨진 메타데이터, 삽입된 JavaScript, 파일 첨부, 양식 데이터, 레이어 정보는 민감한 데이터를 유출하거나 보안 위험이 될 수 있습니다. 정리 기능은 이 모든 것을 제거하여 공개적으로 공유해도 안전한 깨끗한 문서를 만들어 줍니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 체크리스트에서 제거할 요소를 선택합니다.
3. **PDF 정리**를 클릭합니다.
4. 정리된 파일을 다운로드합니다.

## 정리 옵션

모든 옵션은 기본적으로 활성화되어 있습니다. 유지하려는 항목은 선택을 해제하세요.

| 옵션                 | 제거되는 항목                                          |
| -------------------- | ------------------------------------------------------ |
| **양식 평탄화**      | 상호작용 양식 필드를 정적 내용으로 변환                |
| **메타데이터 제거**  | 작성자, 제목, 생성일, 소프트웨어 정보, XMP 데이터 제거 |
| **주석 제거**        | 댓글, 강조 표시, 스티커 메모, 마크업 삭제              |
| **JavaScript 제거**  | 열 때 실행될 수 있는 삽입된 스크립트 제거              |
| **첨부 파일 제거**   | PDF에 삽입된 파일 첨부 제거                            |
| **레이어(OCG) 제거** | 선택적 콘텐츠 그룹을 하나의 레이어로 평탄화            |
| **링크 제거**        | 하이퍼링크와 URL 참조 제거                             |
| **구조 트리 제거**   | 접근성 태그에 사용되는 문서 구조 제거                  |
| **MarkInfo 제거**    | 표시된 콘텐츠 정보 제거                                |
| **글꼴 제거**        | 삽입된 글꼴 데이터 제거 (주의해서 사용)                |

## 활용 사례

- 내부 메타데이터(작성자 이름, 소프트웨어 버전, 편집 이력)를 제거하여 PDF를 공개 배포용으로 준비
- 신뢰할 수 없는 출처에서 받은 PDF를 열기 전에 JavaScript 제거
- 삽입된 댓글이나 양식 필드 이름을 보면 안 되는 고객에게 보내기 전에 PDF 정리
- 최종본을 공유하기 전에 건축 도면의 숨겨진 레이어 제거
- 개인정보 보호 규정의 데이터 최소화 요구사항 준수

## 팁

- PDF가 제대로 렌더링될 것이 확실하지 않다면 "글꼴 제거"는 선택하지 마세요. 글꼴을 제거하면 일부 뷰어에서 텍스트가 보이지 않을 수 있습니다.
- 메타데이터만 제거하면 된다면 전용 메타데이터 제거 도구가 더 빠르고 목적에 맞습니다.
- 정리는 되돌릴 수 없습니다. 원본 파일을 보관하세요.

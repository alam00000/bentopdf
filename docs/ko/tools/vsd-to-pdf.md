# VSD를 PDF로

Visio를 설치하지 않고 Microsoft Visio 다이어그램을 PDF로 변환합니다. VSD와 VSDX 파일에는 대부분의 사람이 열 수 없는 순서도, 조직도, 네트워크 다이어그램, 평면도가 들어 있습니다. 이 도구는 이를 어떤 기기에서나 볼 수 있는 깔끔한 PDF로 렌더링합니다.

## 지원 형식

| 형식           | 확장자  | 참고                                        |
| :------------- | :------ | :------------------------------------------ |
| Visio 바이너리 | `.vsd`  | 레거시 Visio 형식 (Visio 2003 및 이전 버전) |
| Visio XML      | `.vsdx` | 최신 Visio 형식 (Visio 2013 이상)           |

## 작동 방식

1. 업로드 영역을 클릭하거나 VSD 또는 VSDX 파일을 끌어다 놓습니다. 두 형식을 한 번에 섞어서 올릴 수 있습니다.
2. 파일 목록을 확인합니다. 휴지통 아이콘으로 원하지 않는 항목을 제거하거나, **파일 더 추가**로 다이어그램을 더 추가합니다.
3. **PDF로 변환**을 클릭합니다. LibreOffice 기반 엔진이 브라우저에 로드되어 각 다이어그램을 도형, 연결선, 레이블, 페이지 레이아웃을 유지한 채 PDF로 렌더링합니다.
4. 다이어그램이 하나면 PDF로 바로 다운로드됩니다. 여러 파일이면 `vsd-to-pdf.zip`이라는 ZIP 압축 파일이 만들어집니다.

## 옵션

별도의 설정은 필요하지 않습니다. 변환기는 Visio 문서의 원래 페이지 크기와 방향을 따릅니다.

## 사용 사례

- Visio 라이선스가 없을 때 동료가 보낸 Visio 다이어그램 검토
- 프로젝트 문서에 네트워크 또는 아키텍처 다이어그램을 PDF로 포함
- 회의 자료용으로 조직도나 프로세스 흐름도 인쇄
- 이전 Visio 버전의 레거시 VSD 파일을 장기 보존 가능한 형식으로 보관

## 팁

- 여러 페이지로 된 Visio 문서는 여러 페이지의 PDF가 되며, 각 Visio 페이지가 PDF 페이지에 대응됩니다.
- VSDX 파일(최신 XML 기반 형식)은 일반적으로 이전 VSD 바이너리 파일보다 충실도가 높게 변환됩니다.
- LibreOffice 엔진은 세션당 한 번 로드됩니다. 첫 변환에는 잠시 기다려야 하지만 이후 파일은 더 빠르게 처리됩니다.

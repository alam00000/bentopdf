# TIFF를 PDF로

다중 페이지 TIFF를 포함한 TIFF 파일을 PDF로 변환합니다. TIFF 파일의 각 페이지(또는 "IFD")가 출력 PDF의 개별 페이지가 됩니다. 다중 페이지 TIFF로 흔히 저장되는 스캔 문서, 팩스, 의료 영상에 특히 유용합니다.

## 지원 형식

| 형식 | 확장자          |
| :--- | :-------------- |
| TIFF | `.tiff`, `.tif` |

## 사용 방법

1. 업로드 영역을 클릭하거나 TIFF 파일을 끌어다 놓습니다.
2. 파일 목록을 확인하고 필요에 따라 관리합니다.
3. **PDF로 변환**을 클릭합니다. 결과는 `from_tiff.pdf`로 다운로드됩니다.

이 도구는 JavaScript TIFF 디코더로 각 TIFF 파일을 디코딩하여 모든 페이지의 원시 RGBA 픽셀 데이터를 추출합니다. 각 페이지는 캔버스에 렌더링되어 PNG로 내보내진 뒤 PDF에 삽입됩니다. 페이지 크기는 원본 TIFF 페이지와 같습니다.

## 옵션

이 도구는 추가 품질 설정을 제공하지 않습니다. 이미지는 원래 해상도로 삽입됩니다.

## 활용 사례

- 다중 페이지 팩스 문서(TIFF-F)를 더 휴대하기 좋은 PDF 형식으로 변환
- TIFF로 저장된 스캔 문서 보관 자료를 검색 가능한 PDF로 변환(이후 OCR 도구와 함께 사용)
- TIFF를 사용하는 의료 영상 파일(병리 슬라이드, 방사선 내보내기) 처리
- GIS 또는 위성 영상 TIFF 파일을 공유 가능한 문서로 변환

## 팁

- 다중 페이지 TIFF를 완전히 지원합니다. 10페이지 TIFF는 10페이지 PDF가 됩니다. TIFF를 먼저 분할할 필요가 없습니다.
- 매우 큰 TIFF 파일(수백 메가바이트)은 전체 파일을 브라우저 메모리에서 디코딩해야 하므로 처리 시간이 더 걸릴 수 있습니다.
- 결과 PDF에 OCR이 필요하면 변환 후 [OCR PDF](./ocr-pdf) 도구로 처리하세요.

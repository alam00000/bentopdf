# PDF 표 추출

PDF의 모든 표를 감지하여 CSV, JSON, Markdown 중 원하는 형식으로 내보낼 수 있게 해 줍니다. 각 표는 페이지와 위치 메타데이터와 함께 개별적으로 추출됩니다. PyMuPDF의 표 감지 엔진으로 구동됩니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 업로드합니다.
2. 원하는 **내보내기 형식**을 선택합니다. CSV, JSON 또는 Markdown.
3. **추출**을 클릭하여 처리를 시작합니다.
4. 표가 하나면 파일 하나로 다운로드됩니다. 표가 여러 개이면 표당 파일 하나를 담은 ZIP 아카이브가 만들어집니다.

## 옵션

- **내보내기 형식**: 다음 중에서 선택합니다.
  - **CSV**: 쉼표, 따옴표 또는 줄바꿈이 포함된 필드를 올바르게 따옴표 처리한 쉼표로 구분된 값. 스프레드시트와 데이터베이스에 적합합니다.
  - **JSON**: 배열의 배열 구조이며 2칸 들여쓰기로 보기 좋게 출력됩니다. 프로그램에서 사용하기에 적합합니다.
  - **Markdown**: PyMuPDF가 렌더링하는 파이프 구분 표 형식. 문서와 README 파일에 적합합니다.

## 출력 형식

- **표 하나**: `filename_table.csv` (또는 `.json` / `.md`)
- **표 여러 개**: `table_1_page3.csv`, `table_2_page5.csv` 같은 이름의 파일을 담은 `filename_tables.zip`

## 사용 사례

- 문서 전체의 데이터를 가져오지 않고 긴 PDF 보고서에서 특정 표만 추출
- GitHub 이슈, 위키 또는 문서에 바로 붙여 넣을 수 있도록 Markdown 형식으로 표 가져오기
- API 연동이나 스크립트를 위해 PDF 표에서 구조화된 JSON 데이터 가져오기
- 두 버전을 모두 CSV로 내보내 diff하여 서로 다른 PDF 버전의 표 비교

## 팁

- 이 도구는 표 단위로 제어할 수 있습니다. 모든 표를 하나의 CSV에 담기만 하면 된다면 [PDF를 CSV로](./pdf-to-csv)를 사용하세요. 전체 Excel 통합 문서가 필요하면 [PDF를 Excel로](./pdf-to-excel)를 사용하세요.
- 여러 페이지에 걸친 표는 페이지별로 별개의 표로 감지될 수 있습니다. 직접 이어 붙여야 할 수 있습니다.
- 표가 감지되지 않으면 PDF가 스캔 이미지일 수 있습니다. 먼저 OCR을 실행하여 텍스트 레이어를 추가하세요.

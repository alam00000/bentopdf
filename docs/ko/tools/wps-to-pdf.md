# WPS를 PDF로

Microsoft Works 워드 프로세서 파일을 PDF로 변환합니다. Microsoft Works는 1990년대 후반부터 2000년대까지 가정용 PC에 기본 포함되었고, 지금도 오래된 하드 드라이브와 이메일 보관함에 많은 WPS 파일이 남아 있습니다. 이 도구는 브라우저에서 이를 열어 깔끔한 PDF로 만들어 줍니다.

## 지원 형식

| 형식            | 확장자 | 참고                                 |
| :-------------- | :----- | :----------------------------------- |
| Microsoft Works | `.wps` | Microsoft Works의 워드 프로세서 파일 |

## 작동 방식

1. 업로드 영역을 클릭하거나 WPS 파일을 끌어다 놓습니다. 여러 파일을 받을 수 있습니다.
2. 파일 목록을 확인합니다. 휴지통 아이콘으로 개별 파일을 제거하거나, **파일 더 추가**를 클릭해 묶음을 늘립니다.
3. **PDF로 변환**을 클릭합니다. LibreOffice 기반 엔진이 브라우저에 로드되어 각 WPS 문서를 PDF로 변환합니다.
4. 파일이 하나면 PDF로 바로 다운로드됩니다. 여러 파일은 `wps-to-pdf.zip`이라는 ZIP 압축 파일로 묶입니다.

## 옵션

추가 설정은 필요하지 않습니다. 변환기는 WPS 파일의 텍스트, 기본 서식, 삽입된 이미지를 처리합니다.

## 사용 사례

- Microsoft Works 형식으로 저장된 옛 학교 또는 업무 문서 복구
- Microsoft Works가 설치되지 않은 상태에서 WPS 이메일 첨부 파일 열기
- 최신 문서 시스템으로 이전하기 위해 WPS 파일 보관본 변환
- 현재의 워드 프로세서가 열지 못하는 레거시 문서 인쇄

## 팁

- Microsoft Works의 `.wps` 파일과 WPS Office 파일을 혼동하지 마세요. 이 도구는 오래된 Microsoft Works 형식 전용입니다.
- LibreOffice 엔진은 처음 사용할 때 로드되는 데 잠시 걸립니다. 로드된 후에는 같은 세션의 추가 변환이 더 빠르게 실행됩니다.

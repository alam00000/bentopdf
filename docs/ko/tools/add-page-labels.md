# 페이지 레이블 추가

페이지 레이블은 PDF 뷰어에 표시되는 페이지 번호(페이지에 인쇄된 번호가 아니라 도구 모음에 표시되는 번호)를 제어합니다. 이 도구로 페이지 범위마다 다른 레이블 방식을 지정할 수 있습니다 -- 앞부분에는 로마 숫자, 본문에는 십진수, 부록에는 문자 등입니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 옵션 패널이 나타나며 기본으로 레이블 규칙이 하나 있습니다.
3. 각 규칙에 페이지 범위, 스타일, 선택 사항인 접두사, 시작 값을 설정합니다.
4. **규칙 추가**를 클릭하여 다른 구간에 쓸 규칙을 더 만듭니다.
5. **페이지 레이블 추가**를 클릭하여 모든 규칙을 적용하고 결과를 다운로드합니다.

## 옵션

각 레이블 규칙에는 다음 설정이 있습니다.

- **페이지 범위** -- 규칙을 적용할 페이지입니다. 비워 두면 모든 페이지에 적용됩니다. `1-4`, `7`, `odd`, `1-9,30-40` 같은 범위를 지원합니다.
- **레이블 스타일** -- 아라비아 숫자, 소문자 로마 숫자(i, ii, iii), 대문자 로마 숫자(I, II, III), 소문자 알파벳(a, b, c), 대문자 알파벳(A, B, C), 레이블 없음(접두사만) 중에서 선택합니다.
- **레이블 접두사** -- 각 레이블 앞에 붙는 선택적 텍스트입니다. 예를 들어 "A-"를 입력하면 A-1, A-2, A-3 같은 레이블이 만들어집니다.
- **시작 값** -- 번호를 매기기 시작할 숫자입니다. 기본값은 1입니다. 0부터 시작하려면 0으로 설정합니다.
- **떨어진 범위에서 번호 이어가기** -- 규칙이 연속되지 않은 페이지(`1-9,30-40` 또는 `odd` 등)를 대상으로 하며 번호를 순서대로 이어가고 싶을 때 켭니다.
- **기존 페이지 레이블 제거** -- 기본으로 선택되어 있습니다. 새 규칙을 적용하기 전에 이전 레이블을 모두 지웁니다.

## 기능

- 복잡한 번호 체계를 위한 문서당 다중 레이블 규칙
- 모든 표준 번호 체계를 포괄하는 여섯 가지 레이블 스타일
- 섹션별 레이블을 위한 사용자 지정 접두사 지원
- 떨어진 범위에서 이어지는 번호 매기기 지원
- 기존 레이블 유지 또는 제거 옵션

## 활용 사례

- 책의 머리말에는 로마 숫자(i, ii, iii), 본문에는 십진수 레이블 설정
- 부록 페이지에 "A-1", "A-2", "B-1", "B-2" 같은 문자 접두사 레이블 지정
- 실제 페이지 번호가 PDF 페이지 순서와 맞지 않는 스캔 문서의 페이지 레이블 수정
- 기술 문서에 0부터 시작하는 번호 매기기 적용

## 팁

- 페이지 레이블은 PDF 뷰어가 탐색 도구 모음에 표시하는 메타데이터입니다. 실제 페이지에는 인쇄되지 않습니다. 눈에 보이는 번호가 필요하면 [페이지 번호](./page-numbers)를 사용하세요.
- 이 도구를 사용하려면 WASM 설정에서 CoherentPDF(CPDF)를 구성해야 합니다. 설정되어 있지 않으면 구성하라는 안내가 표시됩니다.

# PDF 병합

여러 PDF 파일을 하나의 문서로 합칩니다. 전체 파일을 원하는 순서로 병합하거나, 페이지 모드로 전환해 업로드한 모든 PDF의 개별 페이지를 세밀하게 제어할 수 있습니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 PDF 파일 두 개 이상을 끌어다 놓아 업로드하세요.
2. 상단의 토글로 **파일 모드**와 **페이지 모드** 중 하나를 선택하세요.
3. 파일 모드에서는 파일을 끌어 순서를 바꾸고, 필요하면 파일별로 페이지 범위(예: `1-3, 5`)를 지정하세요. 범위를 비워 두면 모든 페이지가 포함됩니다.
4. 페이지 모드에서는 개별 페이지 썸네일을 끌어다 놓아 원하는 페이지 순서를 구성하세요.
5. **PDF 병합**을 클릭하면 모든 내용이 하나의 파일로 합쳐지고, 병합된 PDF가 자동으로 다운로드됩니다.

## 기능

- 두 가지 병합 모드: 전체 파일을 빠르게 합치는 파일 모드, 페이지 단위로 제어하는 페이지 모드
- 두 모드 모두 부드러운 애니메이션과 함께 드래그 앤 드롭으로 순서 변경
- 페이지 범위 문법(예: `1-3, 5, 8-10`)으로 페이지 모드로 전환하지 않고도 원하는 페이지만 선택
- 지연 로딩되는 페이지 썸네일로 큰 문서에서도 UI가 원활하게 동작
- 파일 수나 전체 페이지 수에 제한 없음
- 재인코딩 없이 원본 PDF 품질 유지

## 옵션

| 옵션            | 설명                                                                                 |
| --------------- | ------------------------------------------------------------------------------------ |
| **파일 모드**   | 전체 파일을 원하는 순서로 병합하며, 파일별 페이지 범위 필터를 선택적으로 사용        |
| **페이지 모드** | 모든 파일의 모든 페이지를 보여주는 시각적 그리드로, 썸네일을 끌어 원하는 순서를 구성 |
| **페이지 입력** | `1-3, 5` 같은 범위를 받아 특정 페이지만 포함하는 파일별 텍스트 필드                  |

## 활용 사례

- 장별로 나뉜 PDF를 책이나 보고서 하나로 합치기
- 자기소개서와 이력서를 지원서 문서 하나로 병합하기
- 여러 원본 문서에서 특정 페이지만 뽑아 하나의 파일로 통합하기
- 스캔한 영수증이나 청구서를 보관용 PDF 하나로 모으기
- 여러 슬라이드 덱의 슬라이드로 발표 유인물 만들기

## 팁

- 파일을 차례로 이어 붙이는 대신 서로 다른 파일의 페이지를 교차로 배치해야 한다면 페이지 모드를 사용하세요.
- **파일 더 추가** 버튼으로 처음 업로드한 후에도 현재 배치를 잃지 않고 파일을 더 추가할 수 있습니다.
- 페이지 범위는 1부터 시작하므로 `1`은 해당 파일의 첫 페이지를 뜻합니다.

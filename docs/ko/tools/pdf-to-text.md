# PDF를 텍스트로

PDF 파일의 모든 텍스트 콘텐츠를 추출해 일반 `.txt` 파일로 저장합니다. 일괄 처리를 지원하므로 PDF 여러 개를 업로드하면 한 번에 각각의 텍스트가 추출됩니다. PyMuPDF를 기반으로 합니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 하나 이상 업로드합니다. 더 추가 및 지우기 버튼으로 파일 목록을 관리하세요.
2. **추출**을 클릭해 처리를 시작합니다.
3. 파일 하나는 `filename.txt`로 다운로드됩니다. 여러 파일은 `pdf-to-text.zip` 압축 파일이 만들어집니다.

## 옵션

이 도구에는 설정 가능한 옵션이 없습니다. 모든 페이지의 텍스트 콘텐츠가 읽기 순서대로 추출됩니다.

## 출력 형식

- **파일 하나**: `filename.txt`
- **파일 여러 개**: 입력한 PDF마다 `.txt` 하나가 담긴 `pdf-to-text.zip`

## 활용 사례

- 전체 텍스트 검색 색인용으로 PDF 보고서의 본문 추출하기
- 전자잉크 기기에서 읽을 수 있도록 PDF 전자책이나 기사를 일반 텍스트로 변환하기
- 키워드 분석을 위해 계약서나 법률 문서에서 텍스트 가져오기
- 데이터 처리 스크립트용으로 PDF의 서식을 제거해 깨끗한 텍스트 얻기
- PDF 보관소에서 자연어 처리용 텍스트 말뭉치 준비하기

## 팁

- 스캔한 PDF(이미지만 있는 경우)는 추출할 텍스트 레이어가 없으므로 빈 텍스트 파일이 만들어집니다. 스캔 문서는 먼저 OCR을 거치세요.
- 출력은 PyMuPDF가 해석한 읽기 순서를 유지하며, 일반적으로 왼쪽에서 오른쪽, 위에서 아래로 따릅니다. 다단 레이아웃은 텍스트가 뒤섞일 수 있습니다.
- 제목과 서식이 있는 구조화된 출력은 [PDF를 Markdown으로](./pdf-to-markdown)를 사용해 보세요. AI에 바로 쓸 수 있는 구조화된 JSON은 [AI용 PDF 준비](./prepare-pdf-for-ai)를 사용하세요.

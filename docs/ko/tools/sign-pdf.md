# PDF 서명

모든 PDF 문서에 서명을 추가합니다. 이 도구는 서명 도구가 내장된 PDF 뷰어를 포함하고 있어 서명을 손으로 그리거나, 서명 글꼴로 이름을 입력하거나, 서명 이미지를 업로드할 수 있습니다. 어느 페이지에든 서명을 배치하고 크기를 조절한 뒤 서명된 문서를 저장합니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 문서가 주석 도구가 있는 통합 PDF 뷰어에서 열립니다.
3. 뷰어의 서명 도구로 그리기, 입력, 이미지 업로드 중 하나로 서명을 만듭니다.
4. 서명을 놓을 페이지 위치를 클릭하고 크기와 위치를 조절합니다.
5. 필요하면 **PDF 평탄화**를 선택하여 서명을 문서에 영구적으로 삽입합니다.
6. **저장 및 서명된 PDF 다운로드**를 클릭하여 서명된 파일을 받습니다.

## 옵션

- **PDF 평탄화**: 선택하면 서명이 페이지 내용에 영구적으로 삽입됩니다. 다른 사람이 서명을 이동하거나 삭제할 수 없습니다. 선택하지 않으면 서명은 호환되는 뷰어에서 편집할 수 있는 주석으로 남습니다.

## 기능

- 세 가지 서명 생성 방법: 손으로 그리기, 텍스트 입력, 이미지 업로드
- 정확한 배치를 위한 통합 PDF 뷰어
- 어느 페이지에서든 서명을 드래그하여 배치하고 크기 조절
- 서명을 영구적으로 삽입하는 선택적 평탄화
- 한 문서에 여러 서명 지원

## 활용 사례

- 계약서, 합의서, 승인 양식에 서명하여 회신
- 세금 문서, 보험 청구서, 정부 양식에 서명 추가
- 여러 페이지로 된 합의서의 개별 페이지에 이니셜 넣기
- PDF 첨부 파일로 도착한 NDA나 인사 문서에 서명

## 팁

- 서명된 PDF를 받는 사람이 서명을 제거하거나 위치를 바꾸면 안 되는 경우 평탄화를 켜세요.
- 인증서 기반 검증이 가능한 법적 효력이 있는 디지털 서명이 필요하면 BentoPDF의 별도 디지털 서명 도구를 사용할 수 있습니다.
- 배경이 투명한 PNG 서명 이미지를 업로드하면 가장 깔끔한 결과를 얻을 수 있습니다.

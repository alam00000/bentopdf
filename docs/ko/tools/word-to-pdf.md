# Word를 PDF로

Microsoft Word 문서와 호환 형식을 PDF로 변환합니다. 이 도구는 브라우저 기반 LibreOffice 엔진을 사용해 DOC, DOCX, ODT, RTF 파일을 처리하며, 서식, 표, 이미지, 머리글, 바닥글, 스타일을 결과물에 그대로 유지합니다.

## 지원 형식

| 형식                | 확장자  |
| :------------------ | :------ |
| Word (최신)         | `.docx` |
| Word (레거시)       | `.doc`  |
| OpenDocument 텍스트 | `.odt`  |
| 서식 있는 텍스트    | `.rtf`  |

## 작동 방식

1. 업로드 영역을 클릭하거나 Word 문서를 끌어다 놓습니다. 여러 파일을 한 번에 선택할 수 있습니다.
2. 파일 목록을 확인하고 관리합니다.
3. **PDF로 변환**을 클릭합니다. LibreOffice 엔진은 처음 사용할 때 로드되며(진행 표시기에 초기화 상태가 나타남), 이후 각 파일이 변환됩니다.
4. 파일이 하나면 PDF로 바로 다운로드됩니다. 여러 파일은 `word-converted.zip`으로 묶입니다.

## 옵션

이 도구에는 추가 설정이 없습니다. LibreOffice 엔진이 기본 PDF 내보내기 프로필로 결과물을 만듭니다.

## 출력

| 입력 개수     | 출력                                                        |
| :------------ | :---------------------------------------------------------- |
| 파일 1개      | PDF 한 개 다운로드 (원래 파일명에 `.pdf` 확장자)            |
| 파일 2개 이상 | ZIP 압축 파일(`word-converted.zip`), 파일마다 PDF 하나 포함 |

## 사용 사례

- 입사 지원서를 제출하기 전에 이력서나 자기소개서를 DOCX에서 PDF로 변환
- 고객에게 전달할 계약서나 제안서 묶음을 PDF로 일괄 변환
- 장기 보관을 위해 레거시 `.doc` 파일을 최신 PDF로 변환
- Google Docs에서 DOCX로 내보낸 공동 작업 문서를 PDF로 변환
- 자동 문서 생성에 쓰는 Word 템플릿에서 인쇄용 PDF 생성

## 팁

- LibreOffice 엔진은 세션당 한 번 다운로드되어 캐시됩니다. 첫 변환에는 로딩에 몇 초가 걸리지만 이후 변환은 훨씬 빠릅니다.
- 복잡한 서식(매크로, ActiveX 컨트롤, 고급 SmartArt)은 완벽하게 변환되지 않을 수 있습니다. 텍스트, 표, 이미지, 머리글, 각주 같은 표준 문서 요소는 안정적으로 변환됩니다.
- 이 도구는 ODT와 RTF도 받으므로 모든 워드 프로세서 형식을 위한 통합 변환기로 사용할 수 있습니다.

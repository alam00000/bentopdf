# Excel을 PDF로

스프레드시트 파일을 PDF로 변환합니다. 이 도구는 최신 Excel 파일, 구형 XLS 형식, OpenDocument 스프레드시트, 심지어 CSV까지 처리하며, 모두 셀 서식, 수식(계산된 값으로), 차트, 여러 시트 레이아웃을 유지하는 브라우저 기반 LibreOffice 엔진으로 렌더링됩니다.

## 지원 형식

| 형식                      | 확장자  |
| :------------------------ | :------ |
| Excel (최신)              | `.xlsx` |
| Excel (구형)              | `.xls`  |
| OpenDocument 스프레드시트 | `.ods`  |
| CSV                       | `.csv`  |

## 사용 방법

1. 업로드 영역을 클릭하거나 스프레드시트 파일을 끌어다 놓습니다.
2. 파일 목록을 확인합니다. 파일을 더 추가하거나 필요 없는 파일을 제거합니다.
3. **PDF로 변환**을 클릭합니다. LibreOffice 엔진이 처음 사용할 때 초기화된 후 각 파일을 처리합니다.
4. 파일이 하나면 PDF로 바로 다운로드됩니다. 여러 파일이면 `excel-converted.zip`으로 제공됩니다.

## 옵션

이 도구에는 추가 설정이 없습니다. LibreOffice 엔진이 스프레드시트에 내장된 설정을 기준으로 페이지 레이아웃, 배율, 인쇄 영역을 결정합니다.

## 출력

| 입력 수       | 출력                                                        |
| :------------ | :---------------------------------------------------------- |
| 파일 1개      | PDF 한 개 다운로드 (원래 파일 이름에 `.pdf` 확장자)         |
| 파일 2개 이상 | 파일당 PDF 하나를 담은 ZIP 아카이브 (`excel-converted.zip`) |

## 사용 사례

- 배포를 위해 재무 보고서나 예산을 Excel에서 PDF로 변환
- 재고나 제품 카탈로그 스프레드시트로 인쇄용 PDF 만들기
- Excel이 설치되지 않은 이해관계자와 데이터 분석 결과 공유
- 분기 보고서를 편집할 수 없는 형식으로 보관
- LibreOffice Calc의 ODS 파일을 PDF로 변환

## 팁

- 스프레드시트에 포함된 차트는 PDF에 렌더링됩니다. 변환하기 전에 원본 파일에서 올바르게 보이는지 확인하세요.
- 스프레드시트에 시트가 여러 개이면 모든 시트가 PDF 출력에 포함됩니다.
- 서식이 없는 단순한 CSV 데이터는 [CSV를 PDF로](./csv-to-pdf) 도구가 더 가벼운 변환을 제공합니다. 서식, 차트, 여러 시트를 유지해야 할 때는 Excel을 PDF로를 사용하세요.

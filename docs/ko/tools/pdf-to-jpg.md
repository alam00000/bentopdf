# PDF를 JPG로

PDF의 각 페이지를 JPG 이미지로 변환합니다. 한 페이지 문서는 독립된 `.jpg` 파일로 다운로드됩니다. 여러 페이지 PDF는 페이지당 JPG 하나가 담긴 ZIP 압축 파일이 만들어집니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 업로드합니다. 도구에 파일 이름, 파일 크기, 페이지 수가 표시됩니다.
2. **품질** 슬라이더로 JPG 압축을 조절합니다.
3. **변환**을 클릭해 처리를 시작합니다.
4. 결과가 자동으로 다운로드됩니다. 한 페이지 PDF는 JPG 하나, 여러 페이지 문서는 ZIP 파일입니다.

## 옵션

- **품질**: 0%에서 100%까지의 슬라이더(기본값 90%). 값이 높을수록 이미지가 선명하고 파일이 커집니다. 값이 낮을수록 더 강하게 압축됩니다.

페이지는 내부적으로 2배 배율로 렌더링되므로 출력 해상도는 PDF 페이지 크기의 두 배입니다. 표준 Letter 크기 페이지는 약 1,224 x 1,584 픽셀 이미지가 됩니다.

## 출력 형식

- **한 페이지**: `filename.jpg`
- **여러 페이지**: `page_1.jpg`, `page_2.jpg` 등이 담긴 `filename_jpgs.zip`

## 활용 사례

- 문서 관리 시스템용 미리보기 썸네일 생성하기
- PDF를 지원하지 않는 채팅이나 이메일로 보고서의 한 페이지 공유하기
- PDF 다이어그램이나 일러스트에서 이미지 자산 만들기
- 스캔한 문서를 개별 이미지로 보관하기

## 팁

- 무손실 출력이 필요하면 [PDF를 PNG로](./pdf-to-png)를 대신 사용하세요.
- 품질 80-90% 설정이 파일 크기와 시각적 충실도 사이의 좋은 균형입니다.
- 페이지마다 특정 형식이 필요하면 PDF를 이미지로 내보내는 출력 노드가 있는 [PDF 워크플로우 빌더](./pdf-workflow)를 고려해 보세요.

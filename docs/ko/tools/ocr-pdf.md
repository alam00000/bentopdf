# OCR PDF

스캔한 문서를 검색하고 복사할 수 있는 PDF로 바꾸세요. 이 도구는 Tesseract OCR로 이미지 속 텍스트를 인식하고 원본 페이지 위에 보이지 않는 텍스트 레이어를 덧씌웁니다. 시각적 모습은 그대로 유지하면서 내용을 완전히 검색할 수 있게 됩니다.

## 사용 방법

1. 스캔한 PDF 또는 이미지 기반 PDF 파일을 업로드하세요.
2. 검색 가능한 언어 목록에서 문서에 포함된 언어를 하나 이상 선택하세요.
3. 필요하면 고급 설정(해상도, 이진화, 화이트리스트)을 조정하세요.
4. **OCR 시작**을 클릭하고 실시간 진행률 표시줄로 진행 상황을 확인하세요.
5. 완료되면 추출된 텍스트를 확인한 뒤 검색 가능한 PDF 또는 일반 `.txt` 파일을 다운로드하세요.

## 기능

- 검색 가능한 언어 선택기를 갖춘 다국어 OCR
- 보이지 않는 텍스트 레이어로 원본 문서의 모습 유지
- 처리 중 실시간 진행률 표시줄과 로그 출력
- 검색 가능한 PDF 또는 일반 텍스트 파일로 결과 다운로드
- 추출된 텍스트를 클립보드로 바로 복사
- 속도와 정확도의 균형을 맞추는 세 가지 해상도 단계

## 옵션

| 설정                         | 값                                                                   | 기본값    | 용도                                                                 |
| ---------------------------- | -------------------------------------------------------------------- | --------- | -------------------------------------------------------------------- |
| **해상도**                   | 표준(192 DPI), 높음(288 DPI), 최고(384 DPI)                          | 높음      | 해상도가 높을수록 작은 글자의 정확도가 향상되지만 시간이 더 걸립니다 |
| **이미지 이진화**            | 켜기 / 끄기                                                          | 끄기      | 흑백으로 변환하여 깨끗한 스캔본의 대비를 높입니다                    |
| **문자 화이트리스트 프리셋** | 없음, 영숫자, 숫자 + 통화, 문자만, 숫자만, 청구서, 양식, 사용자 지정 | 없음      | 인식할 문자를 제한하여 특정 문서 유형의 정확도를 높입니다            |
| **문자 화이트리스트**        | 자유 텍스트                                                          | 비어 있음 | 프리셋이 사용자 지정일 때 직접 입력하는 문자 집합                    |

## 활용 사례

- 스캔한 계약서와 청구서를 Ctrl+F로 검색할 수 있게 만들기
- 사진으로 찍은 문서나 오래된 종이 기록에서 텍스트 추출하기
- 청구서 프리셋으로 영수증을 처리하여 금액과 날짜를 정확하게 인식하기
- 규정 준수를 위해 이미지만 있는 스캔본으로 접근 가능한 PDF 만들기
- 스캔한 책이나 매뉴얼에서 텍스트 콘텐츠를 일괄 추출하기

## 팁

- 문서에 여러 언어가 섞여 있다면(예: 영어 제목과 일본어 본문) 언어를 여러 개 선택하세요.
- 글자가 흐리거나 대비가 낮은 문서에는 이진화 옵션을 사용하세요. 인식 정확도가 크게 향상될 수 있습니다.
- 청구서와 양식 화이트리스트 프리셋은 관련 없는 문자 모양을 무시하여 구조화된 문서의 오인식을 크게 줄여줍니다.

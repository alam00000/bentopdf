# PDF 멀티 도구

모든 페이지 단위 PDF 작업을 위한 통합 작업 공간입니다. PDF를 하나 이상 업로드하면 모든 페이지를 하나의 시각적 그리드에서 다룰 수 있습니다. 회전, 재정렬, 복제, 삭제, PDF와 이미지, 빈 페이지 삽입, 페이지 번호 다시 매기기, 크기 조정, 결과 분할까지 도구를 벗어나지 않고 모두 처리합니다.

## 사용 방법

1. **파일 선택**을 클릭하거나 업로드 영역에 파일을 끌어다 놓습니다. 여러 파일을 지원하며, 업로드한 순서대로 병합됩니다.
2. 모든 페이지가 미리보기와 함께 스크롤 가능한 그리드에 표시됩니다.
3. 페이지를 클릭하면 선택됩니다. Shift 키를 누른 채 클릭하면 범위를 선택하고, Cmd/Ctrl 키를 누른 채 클릭하면 개별 페이지를 선택에 추가하거나 선택에서 뺍니다.
4. 오거나이저 도구 모음을 사용하거나 페이지를 마우스 오른쪽 버튼으로 클릭해 페이지 작업을 실행합니다.
5. **PDF 내보내기**를 클릭해 최종 결과를 다운로드합니다.

## 기능

- **병합**: 여러 PDF와 이미지를 업로드하면 하나의 문서로 자동 결합됩니다
- **재정렬**: 페이지를 끌어다 놓아 순서를 바꾸거나 문서 전체의 순서를 뒤집습니다
- **회전**: 선택한 페이지를 90도 단위로 왼쪽 또는 오른쪽으로 회전합니다
- **복제**: 선택한 페이지를 복사해 바로 뒤에 배치합니다
- **삭제**: 선택한 페이지를 제거합니다
- **삽입**: 다른 PDF나 이미지의 페이지, 빈 페이지, 클립보드의 페이지를 추가하거나, 두 번째 PDF의 페이지를 현재 페이지와 번갈아 끼워 넣습니다
- **교체**: 페이지를 다른 PDF의 첫 페이지로 바꿉니다
- **잘라내기, 복사, 붙여넣기**: 문서 안에서 페이지를 이동하거나 복사합니다
- **추출**: 선택한 페이지를 PDF 또는 이미지로 다운로드합니다
- **페이지 번호**: 페이지 범위에 i, ii, iii 또는 A-1, A-2 같은 페이지 레이블을 지정합니다
- **페이지 크기**: 페이지를 표준 용지 크기나 사용자 지정 크기에 맞춥니다
- **분할**: 페이지 범위, 홀수 및 짝수 페이지, 한 페이지씩, 북마크, N페이지마다, 파일 크기 기준으로 문서를 나눕니다
- **실행 취소 / 다시 실행**: 모든 페이지 작업을 실행 취소하고 다시 실행할 수 있습니다
- 불러오기 전에 손상된 PDF를 자동 복구

## 키보드 단축키

| 작업                     | 단축키                        |
| ------------------------ | ----------------------------- |
| 오른쪽 / 왼쪽으로 회전   | R / Shift+R                   |
| 모두 선택                | Cmd/Ctrl+A                    |
| 잘라내기, 복사, 붙여넣기 | Cmd/Ctrl+X, C, V              |
| 복제                     | Cmd/Ctrl+D                    |
| 삭제                     | Delete 또는 Backspace         |
| 실행 취소 / 다시 실행    | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| 선택 영역 이동           | 화살표 키, Home, End          |

## 활용 사례

- 여러 원본 PDF의 페이지로 사용자 지정 문서 만들기
- 빈 페이지 삭제, 옆으로 누운 스캔 회전, 섹션 재정렬로 스캔 문서 정리하기
- 북마크를 이용해 큰 PDF를 챕터 경계에서 분할하기
- 전체 PDF 편집기 없이 빠르게 페이지 단위 편집하기

## 팁

- 실행 취소/다시 실행 기록은 모든 페이지 작업을 추적합니다. 마음껏 사용하세요. 작업 내용을 실수로 잃을 일은 없습니다.
- **Insert > From File**을 사용하거나 언제든지 페이지 그리드에 PDF나 이미지를 더 끌어다 놓으면 문서에 추가됩니다.
- 단순한 병합이나 분할 작업에는 전용 [PDF 병합](./merge-pdf) 또는 [PDF 분할](./split-pdf) 도구가 더 빠를 수 있습니다. 멀티 도구는 한 세션에서 여러 작업이 필요할 때 빛을 발합니다.

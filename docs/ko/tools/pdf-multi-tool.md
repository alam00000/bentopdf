# PDF 멀티 도구

모든 페이지 단위 PDF 작업을 위한 통합 작업 공간입니다. PDF를 하나 이상 업로드하면 모든 페이지를 하나의 시각적 그리드에서 다룰 수 있습니다. 회전, 재정렬, 복제, 삭제, 새 PDF 삽입, 빈 페이지 추가, 결과 분할까지 도구를 벗어나지 않고 모두 처리합니다.

## 사용 방법

1. **PDF 업로드**를 클릭하거나 업로드 영역에 파일을 끌어다 놓습니다. 여러 파일을 지원합니다.
2. 업로드한 모든 파일의 페이지가 미리보기와 함께 스크롤 가능한 그리드에 표시됩니다.
3. 도구 모음이나 페이지별 작업 버튼으로 페이지를 조작합니다.
4. 각 카드의 체크박스로 페이지를 선택한 뒤 일괄 작업을 적용합니다.
5. 가위 아이콘으로 분할 지점을 표시해 출력을 여러 파일로 나눕니다.
6. **PDF 내보내기**를 클릭해 최종 결과를 다운로드합니다. 분할 표시가 있으면 출력은 여러 PDF가 담긴 ZIP입니다.

## 기능

- **병합**: 여러 PDF를 업로드하면 하나의 작업 공간으로 자동 결합됩니다
- **재정렬**: 페이지 카드를 끌어다 놓아 순서를 바꿉니다
- **회전**: 페이지별 또는 일괄로 90도 단위(왼쪽 또는 오른쪽) 회전
- **복제**: 클릭 한 번으로 페이지 복제
- **삭제**: 개별 페이지를 제거하거나 선택한 페이지를 일괄 삭제
- **PDF 삽입**: 원하는 페이지 뒤에 새 PDF 추가
- **빈 페이지 추가**: 끝에 빈 A4 페이지 추가
- **분할**: 페이지 사이에 분할 표시를 놓은 뒤 별도 PDF가 담긴 ZIP으로 내보내기
- **모두 선택 / 모두 선택 해제**: 일괄 작업을 위한 빠른 선택
- **실행 취소 / 다시 실행**: 모든 작업에 대한 전체 실행 취소/다시 실행 기록
- **선택 항목 다운로드**: 선택한 페이지만 독립된 PDF로 내보내기
- 불러오기 전에 손상된 PDF를 자동 복구

## 활용 사례

- 여러 원본 PDF의 페이지로 사용자 지정 문서 만들기
- 빈 페이지 삭제, 옆으로 누운 스캔 회전, 섹션 재정렬로 스캔 문서 정리하기
- 시각적 분할 표시로 큰 PDF를 챕터 경계에서 분할하기
- 전체 PDF 편집기 없이 빠르게 페이지 단위 편집하기

## 팁

- 실행 취소/다시 실행 시스템은 모든 작업을 추적합니다. 마음껏 사용하세요. 작업 내용을 실수로 잃을 일은 없습니다.
- 분할 표시는 페이지 사이에 파란색 점선으로 나타납니다. 문서를 나누고 싶은 위치에 시각적으로 놓은 뒤 내보내면 ZIP을 받을 수 있습니다.
- 단순한 병합이나 분할 작업에는 전용 [PDF 병합](./merge-pdf) 또는 [PDF 분할](./split-pdf) 도구가 더 빠를 수 있습니다. 멀티 도구는 한 세션에서 여러 작업이 필요할 때 빛을 발합니다.

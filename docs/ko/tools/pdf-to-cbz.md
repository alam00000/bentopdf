# PDF를 CBZ로

PDF를 디지털 만화와 망가의 표준 형식인 CBZ(Comic Book ZIP) 파일로 변환합니다. PDF의 각 페이지가 아카이브 안의 이미지가 됩니다. 최대한의 호환성을 위해 ComicInfo.xml, metadata.opf, ComicBookInfo JSON 세 가지 형식으로 메타데이터를 생성합니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 업로드합니다.
2. 이미지 형식, 품질, 배율, 선택적 메타데이터를 지정합니다.
3. **변환**을 클릭해 CBZ 파일을 생성합니다.
4. `.cbz` 파일이 자동으로 다운로드됩니다.

## 옵션

| 옵션            | 값              | 기본값 | 설명                                                                  |
| --------------- | --------------- | ------ | --------------------------------------------------------------------- |
| 이미지 형식     | JPEG, PNG, WebP | JPEG   | 컬러 만화는 JPEG, 무손실 흑백 망가는 PNG, 최고 압축률은 WebP입니다.   |
| 품질            | 50–100%         | 85%    | JPEG/WebP 압축을 조절합니다. PNG는 항상 무손실이므로 숨겨집니다.      |
| 배율            | 1.0x–4.0x       | 2.0x   | 배율이 높을수록 고해상도 화면에 맞는 더 선명한 이미지가 만들어집니다. |
| 흑백            | 켜짐/꺼짐       | 꺼짐   | 페이지를 흑백으로 변환합니다. 흑백 콘텐츠의 파일 크기를 줄여줍니다.   |
| 망가 모드       | 켜짐/꺼짐       | 꺼짐   | 메타데이터에 오른쪽에서 왼쪽으로 읽는 방향을 설정합니다.              |
| 메타데이터 포함 | 켜짐/꺼짐       | 켜짐   | ComicInfo.xml, metadata.opf, ComicBookInfo JSON을 포함합니다.         |

## 메타데이터 필드

메타데이터를 켜면 다음 항목을 입력할 수 있습니다.

- **제목**: PDF 파일 이름에서 자동으로 감지됩니다.
- **시리즈**: 시리즈 이름(예: "Naruto").
- **번호(#)**: 시리즈 내 권호 번호.
- **권(Vol.)**: 권 번호.
- **작가**: 작가 또는 제작자 이름.
- **출판사**: 출판사 이름.
- **태그 / 장르**: 쉼표로 구분한 태그(예: "Action, Adventure").
- **출판 연도**: 출판 연도(1900–2100).
- **평점**: 0부터 5까지의 커뮤니티 평점.

## 메타데이터 호환성

모든 리더가 메타데이터를 찾을 수 있도록 세 가지 형식으로 기록합니다.

| 형식               | 위치          | 지원 프로그램                               |
| ------------------ | ------------- | ------------------------------------------- |
| ComicInfo.xml      | ZIP 내부 파일 | Komga, Kavita, CDisplayEx, Mylar, ComicRack |
| metadata.opf       | ZIP 내부 파일 | Calibre                                     |
| ComicBookInfo JSON | ZIP 주석 필드 | Calibre (대체)                              |

## 출력 형식

- `filename.cbz`: 번호가 매겨진 페이지 이미지와 메타데이터 파일이 담긴 ZIP 압축 파일입니다.

페이지 이미지는 0으로 채운 번호(`01.jpg`, `02.jpg` 등)로 이름이 지정되어 리더가 올바른 순서로 표시합니다.

## 활용 사례

- 망가나 만화 PDF를 만화책 리더에서 쓸 수 있게 변환하기
- Komga, Kavita, Calibre에서 디지털 만화 라이브러리 만들기
- 스캔한 만화책을 리더에 맞는 형식으로 변환하기
- 읽기 방향과 메타데이터를 유지하는 형식으로 만화 공유하기

## 팁

- 컬러 만화에는 **JPEG**, 흑백 망가에는 **PNG**를 사용하세요. PNG는 흑백 콘텐츠를 매우 효율적으로 압축합니다.
- 망가에는 **흑백**을 켜면 파일 크기가 크게 줄어듭니다.
- 라이브러리 관리자(Komga, Calibre)가 컬렉션을 자동으로 정리할 수 있도록 **시리즈**와 **번호** 필드를 입력하세요.
- **WebP**는 압축률이 가장 좋지만 오래된 만화 리더는 지원하지 않을 수 있습니다.

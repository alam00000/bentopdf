# 머리글 및 바닥글

PDF 페이지의 여섯 위치(머리글 왼쪽, 가운데, 오른쪽, 바닥글 왼쪽, 가운데, 오른쪽)에 텍스트를 추가하세요. 페이지 번호와 전체 페이지 수를 나타내는 동적 변수를 지원하므로 "10페이지 중 3페이지"처럼 페이지마다 자동으로 바뀌는 템플릿을 만들 수 있습니다.

## 사용 방법

1. PDF 파일을 업로드하세요.
2. 서식 컨트롤과 여섯 개의 텍스트 입력란이 있는 옵션 패널이 나타납니다.
3. 원하는 머리글/바닥글 위치에 텍스트를 입력하세요.
4. 동적 페이지 번호에는 `{page}`와 `{total}` 자리 표시자를 사용하세요.
5. 글꼴 크기와 글꼴 색상을 조정하고, 필요하면 특정 페이지 범위로 제한하세요.
6. **머리글 및 바닥글 추가**를 클릭해 처리하고 다운로드하세요.

## 옵션

- **페이지 범위**: 머리글과 바닥글을 넣을 페이지를 제한할 수 있습니다. 비워 두면 모든 페이지에 적용됩니다. 형식: "1-3, 5"(쉼표로 구분한 범위).
- **글꼴 크기**: 6~24포인트. 기본값은 10입니다.
- **글꼴 색상**: 색상 선택기로 원하는 색을 고르세요.
- **머리글 왼쪽 / 가운데 / 오른쪽**: 각 페이지 상단의 텍스트 필드.
- **바닥글 왼쪽 / 가운데 / 오른쪽**: 각 페이지 하단의 텍스트 필드.

## 기능

- 페이지당 독립적인 여섯 개의 텍스트 위치
- 현재 페이지 번호를 넣는 동적 `{page}` 변수
- 전체 페이지 수를 넣는 동적 `{total}` 변수
- 특정 페이지를 대상으로 하는 페이지 범위 필터링
- 글꼴 크기와 색상 사용자 지정
- 깔끔하고 전문적인 결과를 위한 Helvetica 글꼴

## 활용 사례

- 보고서 바닥글 가운데에 "{total}페이지 중 {page}페이지" 추가하기
- 머리글 왼쪽에 회사 이름, 머리글 오른쪽에 문서 날짜 넣기
- 법률 문서 바닥글에 기밀 유지 고지 추가하기
- 특정 페이지 범위에 문서 개정 번호 찍기

## 팁

- `{page}`와 `{total}`을 한 필드에 함께 써서 "{total}페이지 중 {page}페이지"나 "{page}/{total}" 같은 형식을 만들 수 있습니다.
- 필요한 위치만 채우고 나머지는 비워 두어도 됩니다. 빈 필드는 건너뜁니다.
- 이미지나 로고가 들어가는 복잡한 머리글이 필요하면 페이지 상단에 배치한 [워터마크 추가](./add-watermark) 도구를 고려하세요.

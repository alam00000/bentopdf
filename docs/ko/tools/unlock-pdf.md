# PDF 잠금 해제

암호화된 PDF의 비밀번호를 알고 있다면, 이 도구로 암호화를 완전히 제거해 누구나 비밀번호 없이 열 수 있는 잠금 해제 사본을 만들 수 있습니다. 여러 PDF가 같은 비밀번호를 사용하는 경우 일괄 복호화도 지원합니다.

## 작동 방식

1. 암호화된 PDF 파일을 하나 이상 업로드합니다.
2. 파일 보호에 사용된 **비밀번호**를 입력합니다.
3. **PDF 복호화**를 클릭합니다.
4. 파일이 하나면 바로 다운로드됩니다. 여러 파일이면 잠금이 해제된 모든 PDF가 담긴 ZIP 압축 파일이 만들어집니다.

## 기능

- 단일 파일 및 일괄 복호화
- 사용자 비밀번호와 소유자 비밀번호 모두 처리
- 남아 있는 제한 없이 완전히 암호화되지 않은 결과물 생성
- 잘못된 비밀번호나 손상된 파일에 대한 명확한 오류 보고
- 일괄 모드에서 파일별 성공/실패 추적

## 제한 해제와의 차이

**PDF 복호화**는 비밀번호가 필요하며 모든 암호화를 제거합니다. **제한 해제**는 사용 제한(인쇄, 복사, 편집)을 대상으로 하며, 소유자 비밀번호만 설정된 경우에는 비밀번호가 필요하지 않을 수 있습니다. 비밀번호 없이는 PDF가 아예 열리지 않을 때 복호화를 사용하세요.

## 사용 사례

- 이전에 직접 암호화했지만 더 이상 비밀번호가 필요 없는 PDF의 잠금을 영구적으로 해제
- 보관 중인 문서를 장기적으로 쉽게 열람할 수 있도록 일괄 암호화 해제
- 암호화된 파일을 지원하지 않는 문서 관리 시스템에 사용할 비밀번호 보호 PDF 준비
- 다른 문서와 병합하기 전에 PDF 잠금 해제 (많은 병합 도구가 암호화된 입력을 처리하지 못합니다)

## 팁

- 비밀번호 입력란은 업로드한 모든 파일에 적용됩니다. PDF마다 비밀번호가 다르면 별도의 묶음으로 처리하세요.
- "잘못된 비밀번호" 오류가 나면 끝에 공백이 있거나 Caps Lock이 켜져 있지 않은지 확인하세요.
- 복호화 후의 결과물에는 보안이 전혀 없습니다. 새 비밀번호를 적용하려면 PDF 암호화로 다시 암호화하세요.

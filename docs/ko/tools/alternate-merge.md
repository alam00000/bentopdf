# 페이지 교차 병합

여러 PDF 파일의 페이지를 문서 간에 번갈아 가며 끼워 넣습니다. 일반 병합은 파일을 단순히 이어 붙이지만, 파일 A의 1페이지, 파일 B의 1페이지, 파일 A의 2페이지 순으로 배치해야 할 때 사용하는 도구입니다.

## 사용 방법

1. 드롭 영역을 사용해 PDF 파일을 두 개 이상 업로드합니다.
2. 도구에 각 파일의 페이지 수와 파일 크기가 표시됩니다.
3. 손잡이를 끌어 교차 순서에서 어느 파일의 페이지가 먼저 오는지 바꿉니다.
4. **페이지 섞기**를 클릭하여 교차 출력을 만듭니다.
5. 결과가 `alternated-mixed.pdf`로 다운로드됩니다.

## 기능

- 개수에 상관없이(최소 두 개) 여러 PDF의 페이지를 교차 배치
- 끌어서 놓기로 파일 순서를 바꿔 교차 우선순위 조절
- 원본 문서의 북마크 유지
- 업로드한 각 파일의 페이지 수와 파일 크기 표시
- 전용 웹 워커로 처리하여 반응성이 좋은 UI

## 활용 사례

- 홀수 페이지와 짝수 페이지를 따로 스캔한 양면 스캔본 재조립
- 문제지와 답안지를 합쳐 각 문제 뒤에 답이 오도록 구성
- 두 언어 문서를 페이지 단위로 병합(예: 한쪽은 영어, 다음 쪽은 번역)
- 단면 스캐너로 스캔한 앞면과 뒷면 교차 배치

## 팁

- 원본 PDF의 페이지 수가 다르면 짧은 문서의 페이지가 먼저 소진되고, 긴 문서의 남은 페이지가 끝에 나옵니다.
- 파일 순서가 중요합니다 -- 목록의 첫 번째 파일이 출력의 첫 페이지를 제공합니다. 필요하면 끌어서 순서를 바꾸세요.

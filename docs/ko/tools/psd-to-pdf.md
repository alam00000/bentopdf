# PSD를 PDF로

Adobe Photoshop PSD 파일을 PDF 문서로 변환합니다. PSD는 Photoshop의 기본 형식이라 보통 값비싼 Adobe 소프트웨어가 있어야 열 수 있습니다. 이 도구는 PSD 파일의 병합된 합성 이미지를 원본 해상도 그대로 PDF 페이지로 렌더링합니다.

## 지원 형식

| 형식            | 확장자 | 참고                        |
| :-------------- | :----- | :-------------------------- |
| Adobe Photoshop | `.psd` | 병합된 합성 이미지를 렌더링 |

## 사용 방법

1. 업로드 영역을 클릭하거나 PSD 파일을 끌어다 놓습니다. 여러 파일을 지원합니다.
2. 파일 목록을 확인합니다. 원하지 않는 파일은 휴지통 아이콘으로 제거하거나 **파일 더 추가**로 더 포함합니다.
3. **PDF로 변환**을 클릭합니다. PyMuPDF 엔진이 PSD 파일을 읽고 합성 이미지를 원본 해상도로 PDF 페이지에 삽입합니다.
4. PSD 하나는 PDF 하나가 됩니다. 여러 PSD 파일을 업로드하면 `psd_to_pdf.pdf`라는 이름의 여러 페이지짜리 PDF 하나로 합쳐지며, 각 PSD가 한 페이지가 됩니다.

## 옵션

설정이 필요 없습니다. 변환기는 PSD 파일의 병합된 이미지 데이터를 사용합니다.

## 활용 사례

- Photoshop을 열지 않고 디자인 미리보기
- Adobe Creative Suite가 없는 고객에게 디자인 시안 전달
- PSD 파일의 고해상도 아트워크 인쇄
- 여러 PSD 디자인 파일로 PDF 포트폴리오 만들기: 각 파일이 하나의 문서 안에서 한 페이지가 됩니다

## 팁

- 변환은 PSD의 합성(병합된) 보기를 렌더링합니다. 개별 레이어, 조정 레이어, 레이어 효과는 PDF에서 별도 요소로 유지되지 않습니다.
- 여러 PSD 파일은 개별 PDF가 아니라 여러 페이지짜리 PDF 하나로 합쳐집니다. 포트폴리오나 룩북을 만들 때 유용합니다.
- 해상도가 매우 높은 PSD 파일(300 DPI 이상의 인쇄용 파일)은 PDF 크기가 커집니다. 이 도구는 전체 해상도를 유지합니다.

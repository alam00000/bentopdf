# EPUB를 PDF로

브라우저를 벗어나지 않고 EPUB 전자책을 PDF 파일로 변환합니다. EPUB는 디지털 도서의 개방형 표준이지만, 인쇄, 주석 작성 또는 전자책 리더가 없는 사람과의 공유를 위해 고정 레이아웃 PDF가 필요할 때가 있습니다.

## 지원 형식

| 형식 | 확장자  | 참고                  |
| :--- | :------ | :-------------------- |
| EPUB | `.epub` | EPUB 2 및 EPUB 3 파일 |

## 사용 방법

1. 업로드 영역을 클릭하거나 EPUB 파일을 끌어다 놓습니다. 여러 파일 선택을 지원합니다.
2. 업로드한 파일을 확인합니다. 필요 없는 항목은 휴지통 아이콘으로 제거하고, 배치를 늘리려면 **파일 더 추가**를 클릭합니다.
3. **PDF로 변환**을 클릭합니다. PyMuPDF 엔진이 EPUB 콘텐츠(텍스트, 이미지, 서식)를 페이지가 나뉜 PDF 출력으로 렌더링합니다.
4. EPUB가 하나면 PDF로 바로 다운로드됩니다. 여러 파일이면 `epub-converted.zip`이라는 ZIP 아카이브로 묶입니다.

## 옵션

변환은 필수 설정 없이 합리적인 기본값으로 실행됩니다. 텍스트는 표준 페이지 크기에 맞게 재배치되며, 포함된 글꼴과 이미지는 PDF로 이어집니다.

## 사용 사례

- 화면을 벗어나 읽기 위해 DRM이 없는 전자책 인쇄
- 검토용으로 EPUB 원고를 고정 레이아웃 PDF로 제출
- 모든 운영 체제에서 기본으로 열 수 있는 형식으로 디지털 도서 보관
- EPUB 리더가 없는 동료와 한 챕터 공유
- EPUB로 배포된 기술 문서를 주석을 달 수 있는 PDF로 변환

## 팁

- 내장 오디오와 비디오 같은 EPUB 3 기능은 PDF로 이어지지 않지만, 모든 텍스트, 이미지, 표는 깔끔하게 변환됩니다.
- 스타일이 많이 적용된 EPUB는 출력의 처음 몇 페이지를 확인하여 레이아웃이 충실한지 점검하세요.

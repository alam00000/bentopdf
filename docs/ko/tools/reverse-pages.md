# 페이지 역순 정렬

PDF의 페이지 순서를 뒤집어 마지막 페이지가 첫 페이지, 끝에서 두 번째 페이지가 두 번째 페이지가 되도록 합니다. 여러 파일을 한 번에 일괄 처리할 수 있습니다.

## 사용 방법

1. PDF 파일을 하나 이상 업로드합니다.
2. 처리 버튼을 클릭합니다.
3. 각 파일은 독립적으로 역순 정렬됩니다. 여러 파일을 업로드했다면 역순으로 정렬된 모든 PDF가 담긴 ZIP 압축 파일이 출력됩니다.
4. 파일이 하나면 역순 정렬된 PDF가 바로 다운로드됩니다.

## 기능

- 일괄 처리: 한 번의 작업으로 여러 PDF 역순 정렬
- PDF 하나는 단일 파일로, 여러 개는 ZIP으로 출력
- 처리 전에 파일별 제거 버튼 제공
- 모든 페이지 내용과 서식 유지

## 활용 사례

- 거꾸로 된 순서로 스캔된 문서 수정
- 뒤에서 앞으로 읽도록 프레젠테이션 PDF 준비
- 페이지를 역순으로 공급하는 특정 인쇄 작업 준비
- 실수로 거꾸로 조립된 문서 바로잡기

## 팁

- 일괄 처리에서 각 파일은 독립적으로 역순 정렬됩니다. 파일끼리의 순서는 바뀌지 않습니다.
- 전체 역순이 아닌 더 세밀한 페이지 순서 변경에는 [복제 및 정리](./organize-pdf)를 사용하세요.

# PDF를 PNG로

PDF의 각 페이지를 PNG 이미지로 변환합니다. PNG는 무손실 압축을 사용하므로 출력이 원본 페이지의 모든 세부 사항을 유지합니다. 한 페이지 PDF는 `.png` 파일로 다운로드되고 여러 페이지 PDF는 ZIP이 만들어집니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 업로드합니다.
2. **배율** 슬라이더로 출력 해상도를 설정합니다.
3. **변환**을 클릭해 처리를 시작합니다.
4. PNG 하나 또는 ZIP 압축 파일이 자동으로 다운로드됩니다.

## 옵션

- **배율**: 1.0x에서 3.0x까지(기본값 2.0x). 2.0x에서는 표준 Letter 크기 페이지가 약 1,224 x 1,584 픽셀로 렌더링됩니다. 배율이 높을수록 이미지가 더 크고 선명해지지만 파일 크기와 처리 시간이 늘어납니다.

## 출력 형식

- **한 페이지**: `filename.png`
- **여러 페이지**: `page_1.png`, `page_2.png` 등이 담긴 `filename_pngs.zip`

## 활용 사례

- 프레젠테이션용으로 PDF 페이지의 고화질 스크린샷 캡처하기
- 선명한 가장자리와 압축 흔적이 없어야 하는 차트나 다이어그램 추출하기
- PDF 목업에서 웹 디자인용 자산 준비하기
- OCR 전처리를 위한 무손실 페이지 이미지 만들기

## 팁

- PNG 파일은 JPG보다 훨씬 큽니다. 완벽한 품질보다 파일 크기가 중요하다면 [PDF를 JPG로](./pdf-to-jpg) 또는 [PDF를 WebP로](./pdf-to-webp)를 사용하세요.
- 배율 1.0x에서는 출력이 PDF의 원래 해상도와 일치합니다. 인쇄 품질로 내보내려면 3.0x로 올리세요.

# PDF 양식 작성

양식 필드가 있는 PDF를 열어 내장 뷰어에서 바로 작성하세요. 표준 AcroForm 필드와 레거시 XFA(XML Forms Architecture) 양식을 모두 지원합니다. 양식 작성을 마치면 클릭 한 번으로 작성된 버전을 다운로드할 수 있습니다.

## 사용 방법

1. 양식 필드가 있는 PDF를 업로드하세요.
2. 문서가 통합 PDF 뷰어에서 열리고 양식 필드가 대화형 입력란으로 표시됩니다.
3. 텍스트 필드, 체크박스, 드롭다운, 라디오 버튼을 클릭해 내용을 입력하세요.
4. **저장 및 작성된 양식 다운로드**를 클릭하면 완성된 PDF를 받을 수 있습니다.

## 기능

- 양식 필드를 완전히 조작할 수 있는 내장 PDF.js 뷰어
- 표준 AcroForm 필드 지원(텍스트 입력, 체크박스, 드롭다운, 라디오 버튼)
- XML 기반 레거시 양식을 위한 XFA 양식 지원
- 페이지 크기에 맞춘 뷰어 자동 크기 조정
- 이름과 크기 정보가 있는 파일 표시

## 옵션

추가 설정 옵션은 없습니다. 양식을 업로드하고 작성한 뒤 다운로드하면 됩니다.

## 활용 사례

- 세금 양식, 보험 신청서, 관공서 서류 작성하기
- PDF 첨부파일로 받은 입사 지원서 작성하기
- 거래처 온보딩 양식이나 공급업체 설문지 작성하기
- 체크박스 필드가 있는 규정 준수 체크리스트 승인하기
- 진료 예약 전 문진표 작성하기

## 팁

- XFA 양식은 일부 PDF 뷰어에서만 지원되는 레거시 형식입니다. XFA PDF를 Chrome이나 대부분의 다른 도구에서 열었을 때 빈 페이지가 보인다면 해당 뷰어가 XFA를 지원하지 않기 때문입니다. BentoPDF의 양식 작성 도구와 Firefox는 XFA를 제대로 처리합니다.
- 양식 필드가 없는 PDF는 먼저 [PDF 양식 만들기](./form-creator) 도구로 필드를 추가한 뒤 여기서 작성하세요.
- 뷰어는 PDF의 페이지 크기에 맞게 자동으로 크기를 조정합니다.

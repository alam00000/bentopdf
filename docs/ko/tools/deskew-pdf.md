# PDF 기울기 보정

스캔한 문서가 완벽하게 반듯한 경우는 드뭅니다. 약간만 기울어도 OCR 정확도가 떨어지고 인쇄물이 어수선해 보입니다. 이 도구는 OpenCV의 이미지 처리 알고리즘으로 각 페이지의 기울기 각도를 감지하고 수평으로 다시 돌려 놓습니다.

## 사용 방법

1. 스캔한 PDF를 하나 이상 업로드합니다.
2. **기울기 임계값**을 설정합니다. 감지된 기울기가 이 값보다 작은 페이지는 그대로 둡니다.
3. <strong>처리 품질(DPI)</strong>을 선택합니다. DPI가 높을수록 감지 정확도가 올라가지만 시간이 더 걸립니다.
4. **PDF 기울기 보정**을 클릭합니다.
5. 처리가 끝나면 결과 패널에 각 페이지의 감지된 각도와 보정 여부가 표시됩니다.

## 옵션

| 설정              | 값                   | 기본값 |
| ----------------- | -------------------- | ------ |
| **기울기 임계값** | 0.1, 0.5, 1.0, 2.0도 | 0.5    |
| **처리 DPI**      | 100, 150, 200, 300   | 150    |

## 기울기 감지 방식

도구는 선택한 DPI로 각 페이지를 이미지로 렌더링한 다음 OpenCV로 콘텐츠의 주된 선 각도를 감지합니다. 감지된 기울기가 임계값을 넘으면 페이지를 반대 각도로 회전시켜 바로잡습니다. 임계값 미만의 페이지는 그대로 통과합니다.

## 사용 사례

- 일괄 스캔한 계약서나 법률 문서 정리
- OCR 처리를 위한 스캔 영수증이나 청구서 준비
- 용지 놓는 위치가 일정하지 않은 평판 스캐너로 스캔한 페이지 바로잡기
- 디지털화한 보관 자료의 시각적 품질 향상

## 팁

- OCR을 위해 픽셀 단위의 정렬이 필요하다면 임계값을 0.1도로 낮추세요.
- 150 DPI는 대부분의 문서에서 빠르고 정확합니다. 아주 작은 텍스트나 세밀한 페이지에는 300 DPI를 사용하세요.
- 기울기 보정은 가로 텍스트 줄이 뚜렷한 문서에서 가장 잘 작동합니다. 대부분 이미지이거나 대각선 디자인 요소가 있는 페이지에서는 어려울 수 있습니다.

# 목차 생성

이 도구는 PDF의 북마크(개요)를 읽어 서식이 적용된 목차 페이지를 만들어 문서 맨 앞에 추가합니다. PDF에 북마크는 있지만 보이는 목차 페이지가 없다면 이 도구가 자동으로 만들어 줍니다.

## 사용 방법

1. 북마크가 있는 PDF를 업로드합니다.
2. 목차 제목, 글꼴 크기, 글꼴 모음을 설정합니다.
3. 필요하면 **목차 페이지용 북마크 추가**를 선택하여 목차 자체를 북마크 트리에 포함합니다.
4. **목차 생성**을 클릭하여 파일을 처리합니다.
5. 목차 페이지가 맨 앞에 삽입된 PDF가 자동으로 다운로드됩니다.

## 옵션

- **목차 제목**: 생성된 페이지 상단에 표시되는 제목입니다. 기본값은 "목차"입니다.
- **글꼴 크기**: 10pt에서 72pt까지 선택합니다. 기본값은 12pt입니다.
- **글꼴 모음**: Times Roman, Helvetica, Courier 변형(보통, 굵게, 기울임, 굵은 기울임) 중에서 선택합니다. 기본값은 Helvetica입니다.
- **목차 페이지용 북마크 추가**: 선택하면 목차 페이지 자체에 대한 북마크 항목이 PDF의 개요 트리에 추가됩니다.

## 기능

- PDF의 전체 북마크 계층 구조 읽기
- 페이지 번호 참조가 있는 깔끔한 서식의 목차 페이지 생성
- 들여쓰기로 중첩된 북마크 수준 지원
- 12가지 내장 PDF 글꼴 중 선택
- 목차 페이지를 가리키는 선택적 북마크

## 활용 사례

- 디지털 북마크만 있는 전자책이나 보고서에 인쇄 가능한 목차 추가
- 여러 PDF를 합친 후 병합된 문서의 목차 만들기
- 긴 기술 매뉴얼의 참조 페이지 생성
- 눈에 보이는 목차가 기대되는 인쇄용 문서 준비

## 팁

- PDF에 북마크가 없다면 먼저 [북마크 편집](./bookmark) 도구로 북마크를 만든 뒤 여기로 돌아와 목차를 생성하세요.
- 큰 문서에서는 14pt나 16pt 같은 더 큰 글꼴 크기가 가독성을 높여 줍니다.

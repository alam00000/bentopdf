# PDF 워크플로우 빌더

워크플로우 빌더를 사용하면 여러 PDF 작업을 하나의 자동화된 파이프라인으로 연결할 수 있습니다. 도구를 하나씩 실행하는 대신 입력, 처리, 출력 노드로 이루어진 시각적 그래프를 구성하고 클릭 한 번으로 모두 실행합니다. 파일은 브라우저 밖으로 나가지 않습니다.

## 사용 방법

인터페이스는 왼쪽의 **노드 도구 상자**, 가운데의 **캔버스**, 노드를 선택하면 오른쪽에 나타나는 **설정 패널**의 세 패널로 나뉩니다.

1. 왼쪽 사이드바에서 노드를 클릭하거나 캔버스로 직접 끌어다 놓아 **노드를 추가**합니다. 도구 상자 상단의 검색창으로 이름을 필터링할 수 있습니다.
2. 출력 소켓(노드 아래쪽)에서 다른 노드의 입력 소켓(위쪽)으로 끌어 **노드를 연결**합니다. 연결은 위에서 아래로 흐릅니다.
3. 노드를 클릭해 오른쪽에 설정 패널을 열어 **설정을 구성**합니다. 노드 유형마다 고유한 옵션(페이지 범위, 품질 슬라이더, 비밀번호 등)이 있습니다.
4. 도구 모음의 **실행** 버튼을 클릭해 **워크플로우를 실행**합니다. 엔진이 노드를 위상 순서로 실행하며 하나씩 순서대로 처리합니다. 하단의 상태 표시줄에서 진행 상황을 확인할 수 있습니다.
5. **결과 다운로드**: 마지막 다운로드 노드가 최종 PDF(여러 파일이 만들어지면 ZIP)를 저장합니다.

## 노드 카테고리

노드는 여섯 개의 카테고리로 구성되며 캔버스에서 각각 색상으로 구분됩니다.

- **입력** (파랑): PDF 입력, 이미지 입력, Word/Excel/PowerPoint를 PDF로, 그리고 파이프라인에 파일을 공급하는 15개 이상의 다른 형식 변환기.
- **편집 및 주석** (남색): 자르기, 흑백, 색상 반전, 워터마크, 페이지 번호, 머리글 및 바닥글, 스캔 효과, 색상 조정, 배경색, 빈 페이지 제거, 주석 제거.
- **정리 및 관리** (보라): 병합, 분할, 페이지 추출, 회전, 페이지 삭제, 역순, 빈 페이지 추가, 페이지 분할, N-Up, 페이지 크기 통일, 한 페이지로 합치기, 소책자, 포스터화, 메타데이터 편집, 목차, OCR.
- **최적화 및 복구** (호박색): 압축, 래스터화, 선형화, 기울기 보정, PDF를 PDF/A로, 폰트 윤곽선 변환, 복구.
- **PDF 보안** (장미색): 암호화, 복호화, 정리, 평탄화, 디지털 서명, 교정(Redact).
- **출력** (청록): 다운로드(단일 PDF와 ZIP을 자동 감지), PDF를 이미지로, PDF를 텍스트로, PDF를 DOCX로, PDF를 XLSX로, PDF를 CSV로, PDF를 SVG로, PDF를 Markdown으로, 이미지 추출.

## 워크플로우 저장 및 불러오기

도구 모음은 네 가지 보존 옵션을 제공합니다.

- **저장**: 현재 워크플로우를 브라우저의 로컬 저장소에 이름이 있는 템플릿으로 저장합니다. 여러 템플릿을 저장할 수 있습니다.
- **불러오기**: 저장된 모든 템플릿이 나열된 모달을 엽니다. 불러오기를 클릭해 복원하거나, 더 이상 필요 없는 템플릿을 삭제합니다.
- **내보내기**: 공유하거나 백업할 수 있도록 워크플로우를 `.json` 파일로 다운로드합니다.
- **가져오기**: 디스크의 `.json` 워크플로우 파일을 불러와 모든 노드, 위치, 연결을 복원합니다.

템플릿은 세션이 바뀌어도 로컬 저장소에 유지됩니다. 내보낸 JSON 파일은 브라우저와 기기 간에 이동할 수 있습니다.

## 실행 모델

엔진은 연결로부터 종속성 그래프를 만들고 노드를 위상 순서로 실행합니다. 노드가 하나라도 실패하면 실행이 중단되고 실패한 노드는 빨간색으로 표시됩니다. 알아둘 규칙은 다음과 같습니다.

- 모든 워크플로우에는 **입력** 노드와 **출력** 노드가 각각 최소 하나 필요합니다.
- 엔진은 순환 종속성을 감지하고 오류와 함께 실행을 차단합니다.
- **암호화** 노드는 출력 노드 직전의 마지막 처리 단계여야 합니다. 더 앞에 배치하면 하위 노드가 암호화된 데이터를 처리할 수 없으므로 검증 경고가 표시됩니다.
- 비밀번호로 보호된 PDF는 실행 중에 비밀번호를 요청합니다.
- 여러 PDF 입력을 지원합니다. 병합 노드로 합치거나, 일괄 처리 노드가 각 PDF를 개별로 처리합니다.

## 소켓 유형

연결은 잘못된 배선을 막기 위해 유형이 있는 소켓을 사용합니다.

- **PDF** (남색): PDF 문서 하나.
- **MultiPDF** (호박색): 함께 묶인 여러 PDF 문서.
- **Image** (초록): 이미지 blob.

## 옵션

모든 노드에는 오른쪽 설정 패널로 접근하는 고유한 설정이 있습니다. 흔한 예는 다음과 같습니다.

- 분할, 페이지 추출, 페이지 삭제 노드의 **페이지 범위**
- 이미지 변환 출력 노드의 **품질 슬라이더**
- 암호화 및 복호화 노드의 **비밀번호 필드**
- 워터마크, 머리글 및 바닥글, 메타데이터 편집의 **텍스트 입력**
- 회전 노드의 **회전 각도**
- 압축 노드의 **압축 수준**
- OCR 노드의 **OCR 언어 선택**

## 활용 사례

- **청구서 처리 파이프라인**: PDF 입력 -> OCR -> 표 추출 -> CSV로 다운로드.
- **보고서 표준화**: Word를 PDF로 -> 페이지 크기 통일 -> 페이지 번호 추가 -> 워터마크 -> 압축 -> 다운로드.
- **보관 준비**: PDF 입력 -> 복구 -> 평탄화 -> 정리 -> PDF를 PDF/A로 -> 다운로드.
- **일괄 이미지 추출**: PDF 입력(여러 파일) -> 이미지 추출 -> ZIP 다운로드.
- **인쇄용 소책자**: PDF 입력 -> 소책자 -> 자르기 -> 압축 -> 다운로드.
- **안전한 배포**: PDF 입력 -> 교정 -> 주석 제거 -> 암호화 -> 다운로드.

## 팁

- 선택한 노드를 캔버스에서 제거하려면 **Delete** 또는 **Backspace**를 사용하세요.
- 노드 상태 표시줄의 **X** 버튼을 클릭하면 바로 삭제할 수 있습니다.
- 빈 공간을 클릭하고 끌어 캔버스를 이동하세요. 이동하는 동안 커서가 손바닥 아이콘으로 바뀝니다.
- 모바일에서는 도구 모음의 **+** 버튼으로 노드 도구 상자를 전환하세요.
- 워크플로우가 여러 출력 파일을 만들면 다운로드 노드가 자동으로 ZIP으로 묶습니다.
- 간단하게 시작하세요. 복잡도를 더하기 전에 노드 두 개짜리 파이프라인을 만들고 테스트해 보세요.

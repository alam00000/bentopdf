# 색상 반전

PDF의 모든 색상을 반대 색으로 뒤집습니다. 흰색 배경은 검은색이 되고, 검은색 텍스트는 흰색이 되며, 나머지 색상은 보색으로 바뀝니다. 어떤 PDF든 "다크 모드" 버전으로 만드는 가장 빠른 방법입니다.

## 사용 방법

1. PDF 파일을 업로드하세요.
2. **색상 반전**을 클릭해 처리하세요.
3. 반전된 PDF가 자동으로 다운로드됩니다.

추가 설정은 없습니다. 이 도구는 각 페이지를 이미지로 렌더링하고 모든 픽셀 색상을 반전한 뒤 결과를 새 PDF로 다시 조립합니다.

## 기능

- 모든 페이지를 한 번에 색상 반전
- 문서의 모든 페이지 처리
- 원래 페이지 크기와 레이아웃 유지
- 텍스트, 이미지, 혼합 등 콘텐츠 유형에 관계없이 모든 PDF에서 작동

## 활용 사례

- 밤에 편하게 읽을 수 있도록 교재나 매뉴얼의 다크 모드 버전 만들기
- 접근성을 위해 고대비 문서 버전 준비하기
- 노출이 잘못 촬영된 스캔 문서 반전하기
- 시각 분석용으로 이미지가 많은 PDF의 네거티브 버전 만들기

## 팁

- 이 도구는 효과를 적용하기 위해 페이지를 래스터화하므로 결과물은 이미지 기반입니다. 텍스트를 더 이상 선택하거나 검색할 수 없습니다. 반전 후에도 검색 가능한 텍스트가 필요하면 결과물을 OCR 도구로 처리하세요.
- 밝기, 대비, 채도 등 더 세밀한 색상 조정이 필요하면 [색상 조정](./adjust-colors) 도구를 사용하세요.
- 페이지가 많은 큰 PDF는 각 페이지를 개별적으로 렌더링하고 반전하므로 처리 시간이 더 걸릴 수 있습니다.

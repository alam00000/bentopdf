# PDF를 ZIP으로

여러 PDF 파일을 하나의 ZIP 압축 파일로 묶습니다. PDF 자체를 변환, 압축, 수정하지 않는 단순한 묶음 도구입니다.

## 사용 방법

1. 드롭 영역으로 PDF 파일을 여러 개 업로드합니다.
2. 파일 목록을 확인합니다. 포함하고 싶지 않은 파일은 제거합니다.
3. 처리 버튼을 클릭합니다.
4. 업로드한 모든 PDF가 담긴 ZIP 압축 파일이 바로 다운로드됩니다.

## 기능

- 개수 제한 없이 PDF 파일 허용
- 압축 파일을 만들기 전에 파일별 제거
- ZIP 안에서 원래 파일 이름 유지
- PDF 내용은 수정하지 않고 파일을 그대로 묶음
- 업로드한 각 PDF의 파일 이름과 크기 표시

## 활용 사례

- 이메일 첨부를 위해 청구서나 영수증 묶음 만들기
- 인수인계를 위해 프로젝트 산출물(PDF 보고서 여러 개) 묶기
- 양식이나 템플릿 모음을 한 번에 내려받을 수 있게 만들기
- 문서 묶음을 하나의 압축 파일로 보관하기

## 팁

- ZIP 파일은 원래 PDF 파일 이름을 사용합니다. 이름이 같은 파일이 있으면 충돌을 피하기 위해 업로드 전에 이름을 바꾸세요.
- 이 도구는 PDF 자체를 압축하지 않습니다. 파일 크기를 줄이려면 먼저 PDF 압축을 거친 뒤 이 도구로 묶으세요.

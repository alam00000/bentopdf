# 빈 페이지 제거

PDF에서 빈 페이지나 거의 빈 페이지를 찾아 자동으로 제거합니다. 각 페이지를 렌더링하여 픽셀 내용을 분석해 빈 페이지인지 판단하고, 처리 전에 제거할 페이지를 확인할 수 있습니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. **민감도** 슬라이더로 "빈 페이지"의 기준을 얼마나 엄격하게 할지 조절합니다.
3. **빈 페이지 감지**를 클릭하여 문서를 스캔합니다.
4. 감지된 빈 페이지의 썸네일이 표시되어 검토할 수 있습니다.
5. 선택을 확인하고 빈 페이지가 제거된 PDF를 다운로드합니다.

## 옵션

- **민감도**: 0%에서 100%까지의 슬라이더(기본값 80%). 값이 높을수록 엄격하여 완전히 또는 거의 흰색인 페이지만 표시합니다. 값이 낮을수록 관대하여 점 하나나 희미한 워터마크처럼 내용이 거의 없는 페이지도 잡아냅니다.

## 기능

- 각 페이지의 픽셀 수준 분석으로 빈 내용 감지
- 감지를 세밀하게 조정하는 민감도 슬라이더
- 수동 확인을 위한 감지된 빈 페이지 썸네일 미리보기
- 빈 페이지가 아닌 모든 페이지를 그대로 유지
- 문서 크기와 페이지 수에 제한 없음
- 스캔 중 진행 상황 표시

## 활용 사례

- 단면 원본의 빈 뒷면까지 스캔된 문서 정리
- 대량 스캔한 문서 묶음에서 구분용 페이지 제거
- 문서 관리 시스템이 삽입한 빈 페이지 제거
- 워드 프로세서에서 내보낸 PDF 끝에 가끔 포함되는 빈 페이지 정리
- 불필요한 빈 페이지를 제거하여 파일 크기 줄이기

## 팁

- 기본 민감도 80%로 시작하여 조절하세요. 빈 페이지처럼 보이는데 도구가 놓치면 민감도를 낮추고, 남기고 싶은 옅은 내용이 있는 페이지가 표시되면 높이세요.
- 내용을 분석하기 위해 각 페이지를 렌더링하므로 처리 시간은 페이지 수에 비례합니다. 매우 큰 문서는 잠시 기다려야 할 수 있습니다.
- 제거를 확인하기 전에 썸네일 미리보기에서 감지된 빈 페이지를 검토하세요. 희미한 머리글, 바닥글, 워터마크가 있는 페이지는 민감도 설정에 따라 표시될 수 있습니다.

# PDF 자르기

시각적인 자르기 인터페이스로 PDF 페이지의 여백을 다듬습니다. 각 페이지에 직접 자르기 사각형을 그리고, 결과를 미리 보고, 자르기를 적용하세요. 페이지마다 다른 자르기 영역을 지정하거나 문서 전체에 같은 자르기를 적용할 수 있습니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 자르기 편집기가 열리고 드래그할 수 있는 자르기 오버레이와 함께 첫 페이지가 표시됩니다.
3. 가장자리나 모서리를 끌어 자르기 사각형을 조정합니다.
4. 페이지 이동 버튼으로 페이지 사이를 이동하며 각 페이지의 자르기 영역을 설정합니다.
5. **자르기**를 클릭하여 자르기를 적용하고 결과를 다운로드합니다.

## 기능

- 정밀 조정용 핸들이 있는 Cropper.js 기반 시각적 자르기 편집기
- 페이지별로 이동하며 개별 자르기 영역 설정
- 페이지마다 자르기 설정을 저장하므로 페이지별로 다른 자르기 지정 가능
- 선택한 자르기 영역의 실시간 미리 보기
- 모든 페이지 크기와 방향의 PDF 지원

## 사용 사례

- 스캔 문서의 넓은 여백을 제거하여 콘텐츠 영역에 집중
- 인쇄 전 PDF에서 프린터 자르기 표시나 등록 표시 제거
- 강의 슬라이드에서 발표자 노트 영역 자르기
- 문서 발췌본을 공유하기 전에 모든 페이지의 머리글이나 바닥글 제거
- 특정 화면이나 인쇄 레이아웃에 맞게 페이지 크기 조정

## 팁

- 자르기 오버레이는 자유롭게 크기를 조정하고 위치를 옮길 수 있습니다. 모서리를 끌면 비율을 유지하며 크기가 바뀌고, 가장자리를 끌면 한 축으로만 조정됩니다.
- 모든 페이지에 같은 자르기가 필요한 문서라면 첫 페이지에서 설정하세요. 페이지를 이동해도 도구가 자르기 영역을 기억합니다.
- 시각적으로 자르는 대신 페이지 크기를 통일하려면 페이지 크기 수정 도구가 더 적합할 수 있습니다.

# 메타데이터 제거

모든 PDF에는 누가 만들었는지, 어떤 소프트웨어를 사용했는지, 마지막으로 언제 수정했는지 등을 알려줄 수 있는 메타데이터가 들어 있습니다. 이 도구는 정보 사전, XMP 메타데이터 스트림, 문서 ID, 애플리케이션 고유 데이터를 모두 제거하여 출처의 흔적이 없는 깨끗한 문서를 만듭니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. **메타데이터 제거**를 클릭합니다.
3. 정리된 파일을 다운로드합니다.

설정할 옵션이 없습니다. 이 도구는 모든 것을 지우도록 철저하게 설계되었습니다.

## 제거되는 항목

- **정보 사전 필드**: 제목, 작성자, 주제, 키워드, 생성 프로그램(Creator), 변환 프로그램(Producer), 생성일, 수정일
- **XMP 메타데이터 스트림**: 문서 카탈로그에 저장된 XML 기반 메타데이터 블록
- **문서 ID**: 시스템 간에 문서를 추적하는 데 사용될 수 있는 PDF 트레일러의 고유 식별자
- **PieceInfo**: Illustrator나 InDesign 같은 프로그램이 추가한 애플리케이션 고유 메타데이터

## 유지되는 항목

- 눈에 보이는 모든 페이지 내용(텍스트, 이미지, 그래픽)
- 양식 필드와 주석
- 북마크와 링크
- 문서 구조 자체

## 활용 사례

- 익명으로 게시하기 전에 문서에서 이름과 소속 제거
- 문서를 준비한 시점이 드러나는 생성 타임스탬프 제거
- 사용 중인 PDF 소프트웨어를 알려주는 Producer 문자열 정리
- 메타데이터 없는 PDF를 요구하는 규제 제출용 문서 준비
- 외부 공유 전에 편집 이력 흔적 제거

## 팁

- 제거하기 전에 메타데이터 보기 도구로 PDF에 어떤 메타데이터가 있는지 먼저 확인하세요.
- 메타데이터와 함께 JavaScript, 주석, 첨부 파일까지 제거해야 한다면 PDF 정리를 사용하여 더 철저히 정리하세요.
- 메타데이터 제거는 되돌릴 수 없습니다. 나중에 그 데이터가 필요할 수 있다면 원본을 보관하세요.

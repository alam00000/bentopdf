# N-Up PDF

여러 페이지를 한 장에 격자 형태로 배치합니다. 한 장에 2, 4, 6, 8, 9 또는 16페이지를 넣어 인쇄 매수를 줄입니다. 이 도구가 배율 조정, 위치 지정, 선택적인 페이지 크기 설정을 처리합니다.

## 사용 방법

1. PDF 파일을 업로드하세요.
2. 한 장에 넣을 페이지 수("N" 값)를 선택하세요: 2, 4, 6, 8, 9 또는 16.
3. 출력 페이지 크기(기본값은 A4)와 방향을 선택하세요.
4. 필요하면 간격, 테두리 색상, 배경색을 설정하세요.
5. 처리 버튼을 클릭하세요. 도구가 각 페이지의 배율을 조정해 새 시트에 타일처럼 배치합니다.

## 기능

- 격자 레이아웃: 2-up, 4-up, 6-up, 8-up, 9-up, 16-up
- 출력 페이지 크기와 방향 설정 가능
- 배치된 페이지 사이의 간격 선택 가능
- 배경색과 테두리 색상 설정
- 맞추어 배율을 조정하면서도 원본 페이지의 가로세로 비율 유지

## 옵션

| 옵션            | 설명                                                       |
| --------------- | ---------------------------------------------------------- |
| **장당 페이지** | 출력 페이지 한 장에 넣을 원본 페이지 수(2, 4, 6, 8, 9, 16) |
| **페이지 크기** | 출력 시트 크기(A4, Letter, Legal 등)                       |
| **방향**        | 출력 시트의 세로 또는 가로 방향                            |
| **간격**        | 배치된 페이지 사이의 간격(포인트 단위)                     |
| **배경색**      | 출력 시트 배경을 채우는 색상                               |
| **테두리 색상** | 배치된 각 페이지를 둘러싸는 테두리의 색상                  |

## 활용 사례

- 용지를 아끼기 위해 한 장에 슬라이드 4개씩 넣어 유인물 인쇄하기
- 한 장에 여러 참고 페이지를 담은 학습 자료 만들기
- 서류 정리를 위한 간결한 문서 보관본 만들기
- 긴 문서의 썸네일 개요 시트 생성하기

## 팁

- 2-up 레이아웃에는 가로 방향이 더 잘 맞는 경우가 많고, 4-up 이상에는 대개 세로 방향이 가장 좋습니다.
- 간격을 늘리면 가독성은 좋아지지만 배치된 각 페이지에 쓸 수 있는 영역이 줄어듭니다.
- 반대 작업(페이지 하나를 여러 장으로 나누기)은 [PDF 포스터화](./posterize-pdf)를 참고하세요.

# 주석 제거

모든 주석을 제거하여 PDF를 깔끔하게 만듭니다. 댓글, 강조 표시, 스티커 메모, 텍스트 마크업, 링크, 도장 등 문서에 삽입된 모든 주석 개체가 대상입니다. 페이지의 기본 내용(텍스트, 이미지, 그래픽)은 그대로 유지됩니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 도구가 문서의 페이지 수를 확인하고 파일 정보를 표시합니다.
3. **주석 제거**를 클릭하여 처리합니다.
4. 모든 주석이 제거된 PDF가 자동으로 다운로드됩니다.

## 기능

- 모든 주석 유형 제거: 댓글, 강조 표시, 밑줄, 취소선, 스티커 메모, 도장, 링크, 양식 마크업
- 문서의 모든 페이지에 적용
- 주석이 아닌 모든 내용(텍스트, 이미지, 벡터 그래픽, 양식 필드) 유지
- 처리 전에 페이지 수와 파일 크기 표시

## 활용 사례

- 여러 검토자가 댓글을 남긴 검토 과정 후 최종 배포 전에 문서 정리
- 공유한 학습 자료에서 강조 표시와 스티커 메모 제거
- 보관 전에 문서에서 링크 주석 제거
- 협상 중 주석이 많이 달린 법률 문서의 "깨끗한" 버전 준비
- 인쇄 전에 원고에서 검토자 댓글 제거

## 팁

- 이 도구는 PDF 구조 수준에서 주석을 제거하므로 결과물은 선택 가능한 텍스트와 원본 품질을 유지합니다. 래스터화는 사용하지 않습니다.
- 모든 주석이 아니라 특정 주석만 제거하려면 [PDF 편집기](./edit-pdf)로 개별 주석을 선택하여 삭제하세요.
- 평탄화된 PDF(주석이 페이지 내용에 병합된 경우)의 주석은 더 이상 별도 개체가 아니므로 제거할 수 없습니다.

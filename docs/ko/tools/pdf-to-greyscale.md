# PDF 흑백 변환

컬러 PDF를 흑백 버전으로 변환합니다. 각 페이지를 렌더링하고 채도를 제거한 뒤 JPEG 이미지로 새 PDF에 다시 삽입합니다. 출력은 원래 페이지 크기를 유지합니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 업로드합니다.
2. **변환**을 클릭해 파일을 처리합니다.
3. 모든 페이지가 흑백으로 변환된 새 `greyscale.pdf`가 다운로드됩니다.

내부적으로 각 페이지를 2배 배율로 렌더링하고, 픽셀 데이터에 흑백 필터를 적용한 뒤, 품질 90%의 JPEG로 다시 인코딩하여 새 PDF 문서에 배치합니다.

## 옵션

이 도구에는 설정 가능한 옵션이 없습니다. 흑백 변환은 표준 휘도 공식을 사용하며 JPEG 품질은 90%로 고정되어 있습니다.

## 출력 형식

- 모든 페이지가 흑백 JPEG 이미지로 들어 있는 `greyscale.pdf` 파일 하나.

## 활용 사례

- 컬러 잉크 비용을 아끼기 위해 흑백 인쇄용 문서 준비하기
- 흑백을 요구하는 법률 또는 정부 제출 요건 충족하기
- 컬러 비중이 큰 PDF의 파일 크기 줄이기(흑백 JPEG 이미지는 컬러보다 작습니다)
- 컬러와 흑백 페이지가 섞인 문서들의 시각적 스타일 통일하기

## 팁

- 각 페이지가 래스터화되어 JPEG로 다시 삽입되므로 출력은 이미지 기반입니다. 원본 PDF의 텍스트는 더 이상 선택하거나 검색할 수 없습니다. 이후 검색 가능한 텍스트가 필요하면 출력을 OCR 도구에 넣어 처리하세요.
- 색상 조정(밝기, 대비, 채도)을 더 세밀하게 제어하려면 색상 조정 도구나 [PDF 워크플로우 빌더](./pdf-workflow)의 흑백 노드를 살펴보세요.

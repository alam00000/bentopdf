# 첨부파일 편집

PDF 안의 파일 첨부를 확인하고 관리합니다. 도구가 포함된 모든 파일을 이름과 첨부 수준과 함께 나열하며, 개별 첨부파일을 제거 대상으로 표시하거나 한꺼번에 모두 제거할 수 있습니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 도구가 자동으로 첨부파일을 검색하여 목록으로 표시합니다.
3. 각 첨부파일에 파일 이름과 문서 수준인지 페이지 수준인지가 표시됩니다.
4. 첨부파일 옆의 휴지통 아이콘을 클릭하면 제거 대상으로 표시됩니다(다시 클릭하면 표시가 해제됩니다).
5. **모든 첨부파일 제거** 버튼으로 전체를 한 번에 선택하거나, **모두 선택 해제**로 선택을 지웁니다.
6. 처리 버튼을 클릭하면 선택한 첨부파일이 제거된 새 PDF가 저장됩니다.

## 기능

- 모든 문서 수준 및 페이지 수준 첨부파일 나열
- 개별 또는 일괄 첨부파일 제거
- 변경을 확정하기 전에 선택을 켜고 끄기
- 제거 대상으로 표시된 항목에 취소선과 투명도 변경 적용
- 선택한 첨부파일이 제거된 수정된 PDF 다운로드

## 사용 사례

- 문서를 재배포하기 전에 오래되었거나 잘못된 포함 파일 제거
- 공유하기 전에 PDF에서 민감한 첨부파일(재무 데이터, 개인 정보) 제거
- 더 이상 필요 없는 큰 포함 파일을 제거하여 PDF 파일 크기 줄이기
- 포함된 콘텐츠를 점검하고 보관하기 전에 문서 정리

## 팁

- 제거 대상으로 표시된 첨부파일은 취소선으로 표시됩니다. 마음이 바뀌면 처리하기 전에 표시를 되돌릴 수 있습니다.
- 첨부파일이 없으면 도구에 "첨부파일을 찾을 수 없습니다"라는 메시지가 표시됩니다. PDF에 포함된 파일이 없다는 뜻입니다.

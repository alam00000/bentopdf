# 텍스트 색상 변경

PDF 전체의 텍스트 색상을 바꿉니다. 이 도구는 각 페이지의 텍스트 영역을 식별하여 선택한 색으로 다시 칠하며, 문서 레이아웃과 텍스트가 아닌 내용은 그대로 유지합니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 색상 선택기로 새 텍스트 색상을 고릅니다. 기본값은 파란색(#0000FF)입니다.
3. **텍스트 색상 변경**을 클릭하여 처리합니다.
4. 색상이 바뀐 PDF가 자동으로 다운로드됩니다. 진행 표시기에 처리 중인 페이지가 표시됩니다.

## 옵션

- **새 텍스트 색상**: 문서의 모든 텍스트를 대체할 색상을 고르는 색상 선택기입니다.

## 기능

- 문서의 모든 페이지에서 텍스트 색상 변경
- 진행 상황을 보여주는 페이지별 처리
- 16진수 색상 코드를 완전히 지원하는 색상 선택기
- 페이지 레이아웃과 텍스트가 아닌 요소 유지

## 활용 사례

- 더 부드럽고 현대적인 문서 느낌을 위해 검은색 텍스트를 진한 파란색으로 변경
- 문서를 배포하기 전에 브랜드 가이드라인에 맞게 텍스트 색상 변경
- 접근성 준수를 위해 텍스트를 특정 색으로 변환
- 새로 적용한 배경색 위에서 텍스트가 잘 보이게 만들기

## 팁

- 이 도구는 품질을 위해 페이지를 2배 배율로 렌더링한 뒤 PDF를 다시 구성합니다. 출력은 이미지 기반이므로 텍스트를 더 이상 선택하거나 검색할 수 없습니다.
- 선택 가능한 텍스트를 유지해야 하는 문서라면 [PDF 편집기](./edit-pdf)로 PDF를 직접 편집하는 것을 고려하세요.
- 각 페이지를 개별적으로 렌더링하므로 페이지 수가 많을수록 처리 시간이 늘어납니다.

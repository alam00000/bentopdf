# PDF 편집기

BentoPDF의 PDF 편집기로 PDF에 주석을 달고, 강조하고, 가리고(교정), 댓글을 남기고, 도형과 이미지를 추가하고, 내용을 검색할 수 있습니다. 서버 업로드 없이 브라우저에서 바로 모든 기능을 갖춘 편집기를 불러옵니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 업로드합니다.
2. 문서가 로드된 상태로 내장 PDF 편집기가 자동으로 열립니다.
3. 도구 모음으로 주석, 강조, 가리기, 텍스트 추가, 도형 그리기, 이미지 삽입을 합니다.
4. **편집된 PDF 다운로드**를 클릭하여 변경 사항을 저장합니다.

## 기능

- 강조, 밑줄, 취소선, 자유 그리기를 포함한 전체 주석 도구 모음
- 텍스트 삽입 및 댓글
- 가리기를 적용하면 표시한 콘텐츠를 영구적으로 제거하는 가리기(교정) 도구. **편집된 PDF 다운로드**를 클릭할 때 적용되지 않은 표시가 있으면 편집기가 먼저 적용할지 묻습니다.
- 사각형, 원, 선, 화살표용 도형 도구
- PDF 페이지에 이미지 삽입
- 문서 전체를 대상으로 한 내장 텍스트 검색
- 탭을 사용한 다중 문서 지원(최대 10개 문서 동시 열기)
- 드래그 앤 드롭 파일 불러오기

## 사용 사례

- 계약서를 검토하며 강조와 댓글로 변경 사항 표시
- 공유하기 전에 주민등록번호나 재무 데이터 같은 기밀 정보 가리기
- 건축 도면이나 엔지니어링 도면에 주석 추가
- 문서 페이지에 회사 로고나 스탬프 삽입
- 긴 법률 문서에서 특정 용어 검색

## 팁

- 여러 PDF를 동시에 열고 편집기 상단의 탭 막대로 전환할 수 있습니다.
- 편집기는 원본 PDF 구조를 유지하므로 글꼴, 레이아웃, 양식 필드가 그대로 보존됩니다.
- 가리기 대상으로 텍스트나 영역을 표시해도 가리기를 적용하기 전에는 아무것도 제거되지 않습니다. 선택한 텍스트를 가리면 파일 속성, 북마크, 댓글, 첨부파일에 있는 해당 텍스트의 사본도 다운로드에서 제거됩니다(파일이 암호화되어 있지 않은 경우).
- 일괄 워터마크나 페이지 번호 작업에는 서식을 더 세밀하게 제어할 수 있는 전용 도구를 사용하세요.

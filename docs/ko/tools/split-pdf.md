# PDF 분할

여섯 가지 분할 모드 중 하나로 PDF를 더 작은 문서로 나눕니다. 간단한 페이지 범위부터 북마크 기반 분할까지, 문서를 나누는 모든 상황을 처리합니다.

## 사용 방법

1. PDF 파일 하나를 업로드합니다.
2. 드롭다운에서 분할 모드를 선택합니다.
3. 모드별 옵션(페이지 범위, 선택 등)을 설정합니다.
4. 처리 버튼을 클릭합니다.
5. 모드와 설정에 따라 결과가 PDF 하나 또는 ZIP 압축 파일로 다운로드됩니다.

## 분할 모드

| 모드            | 설명                                                                                                                                   |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **범위**        | `1-3, 5, 8-10`처럼 페이지 범위를 입력합니다. 범위가 여러 개면 ZIP 안에 각각의 PDF가 만들어지고, 범위가 하나면 PDF 하나가 만들어집니다. |
| **시각적 선택** | 페이지 썸네일을 보면서 클릭하여 원하는 페이지를 선택합니다. 선택한 페이지가 새 PDF로 추출됩니다.                                       |
| **짝수 / 홀수** | 짝수 번호 또는 홀수 번호 페이지만 추출합니다.                                                                                          |
| **모든 페이지** | 모든 페이지를 각각의 PDF 파일로 분할하여 ZIP으로 다운로드합니다.                                                                       |
| **북마크**      | 북마크 경계에서 분할합니다. 북마크 수준을 선택하여 분할 위치를 제어합니다.                                                             |
| **N페이지마다** | N페이지씩(예: 5페이지마다) 묶음으로 분할합니다. 마지막 묶음은 페이지가 더 적을 수 있습니다.                                            |

## 기능

- 거의 모든 사용 사례를 아우르는 여섯 가지 분할 모드
- 지연 로딩 썸네일이 있는 시각적 페이지 선택기
- 수준 필터링이 가능한 북마크 기반 분할
- 범위 및 시각적 모드의 ZIP 출력 옵션
- 혼합 구문(`1-3, 5, 8-10`)의 페이지 범위 처리
- N페이지 분할로 묶음 크기가 고르지 않을 때 경고 표시

## 활용 사례

- 큰 문서에서 특정 장이나 섹션 추출
- 양면 인쇄 작업을 위해 홀수 페이지와 짝수 페이지 분리
- 책 PDF를 북마크 경계에서 장별 파일로 분할
- 계약서에서 서명 페이지 같은 특정 페이지 분리
- 편집된 보고서를 배포용으로 섹션별 파일로 분할

## 팁

- 쉼표로 구분한 여러 페이지 범위(예: `1-5, 10-15, 20-25`)는 범위마다 별도의 PDF를 만들어 ZIP으로 묶습니다.
- 북마크 분할 모드는 PDF에 실제로 북마크가 있어야 합니다. 북마크가 없으면 오류 메시지가 표시됩니다.
- 범위 및 시각적 모드의 "ZIP으로 다운로드" 체크박스를 사용하면 합친 파일 대신 페이지별 개별 PDF를 받을 수 있습니다.

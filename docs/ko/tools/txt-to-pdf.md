# 텍스트를 PDF로

일반 텍스트를 서식이 적용된 PDF로 변환합니다. `.txt` 파일을 업로드하거나 내장 텍스트 편집기에 직접 입력할 수 있습니다. 여러 글꼴, 사용자 지정 텍스트 색상, A0부터 A10까지의 다양한 페이지 크기와 US Letter, Legal, Tabloid를 지원합니다.

## 지원 형식

| 입력             | 확장자                       |
| :--------------- | :--------------------------- |
| 일반 텍스트 파일 | `.txt`                       |
| 직접 텍스트 입력 | 편집기에 입력하거나 붙여넣기 |

## 사용 방법

1. 상단 토글로 입력 모드를 선택합니다: **파일 업로드** 또는 **텍스트 입력**.
2. 업로드하는 경우 `.txt` 파일을 하나 이상 끌어다 놓거나 클릭하여 선택합니다. 입력하는 경우 텍스트 영역에 직접 입력합니다.
3. 서식 옵션(글꼴 모음, 글꼴 크기, 텍스트 색상, 페이지 크기)을 설정합니다.
4. **PDF 만들기**를 클릭합니다. 출력은 `text_to_pdf.pdf`로 다운로드됩니다.

여러 파일을 업로드하면 내용이 사이에 빈 줄을 두고 이어 붙여집니다.

## 옵션

| 옵션            | 값                                                                    | 기본값         |
| :-------------- | :-------------------------------------------------------------------- | :------------- |
| **글꼴 모음**   | Helvetica (산세리프), Tiro (세리프), Courier (고정폭), Times (세리프) | Helvetica      |
| **글꼴 크기**   | 6 - 72 pt                                                             | 12             |
| **텍스트 색상** | 색상 선택기로 선택한 모든 색                                          | 검정 (#000000) |
| **페이지 크기** | ISO A0-A10, B0-B10, C0-C10, US Letter, Legal, Tabloid, Ledger, 11x17  | A4             |

RTL 언어(아랍어, 히브리어, 페르시아어, 우르두어)는 자동으로 감지됩니다. RTL 텍스트가 발견되면 텍스트 방향과 정렬이 그에 맞게 전환됩니다.

## 활용 사례

- 코드 조각이나 로그 파일을 Courier 글꼴의 인쇄 가능한 PDF로 변환
- 즉석에서 입력한 회의 메모로 빠르게 PDF 만들기
- 제출용으로 일반 텍스트 원고를 특정 글꼴과 페이지 크기로 서식 지정
- 오프라인 배포를 위해 README나 변경 로그의 PDF 버전 만들기

## 팁

- 클립보드 내용을 파일로 저장하지 않고 빠르게 변환하려면 **텍스트 입력** 모드를 사용하세요.
- 코드, 로그 또는 열 정렬이 중요한 내용에는 Courier(고정폭)가 가장 좋은 글꼴입니다.
- 페이지 여백은 모든 면에서 72포인트(1인치)로 고정되어 있습니다.

# 스캔 효과

깨끗한 디지털 PDF를 평판 스캐너에서 나온 것처럼 보이게 바꿉니다. 노이즈, 미세한 회전, 흐림, 밝기 변화, 선택적인 누렇게 변색 효과를 조절하여 실제 스캔의 불완전함을 재현합니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 설정 패널과 함께 첫 페이지의 실시간 미리보기가 있는 편집기가 열립니다.
3. 슬라이더와 토글로 스캔 효과 매개변수를 조절합니다.
4. 설정을 바꾸면 미리보기가 실시간으로 업데이트됩니다.
5. **적용**을 클릭하여 모든 페이지를 처리하고 결과를 다운로드합니다.

## 옵션

- **색 공간(흑백 토글)**: 출력을 흑백으로 변환하여 전형적인 흑백 스캔 느낌을 냅니다.
- **테두리**: 스캐너 테두리 흔적을 흉내 내어 페이지 가장자리에 은은한 어두운 테두리를 추가합니다.
- **회전**: 종이가 어긋나게 급지된 것을 흉내 내어 미세한 회전(-5도에서 +5도)을 적용합니다.
- **회전 변동**: 회전 각도에 무작위 변화를 더해 페이지마다 조금씩 다르게 기울어지게 합니다.
- **밝기**: 전체 밝기를 높이거나 낮춥니다.
- **대비**: 토너 품질 차이를 흉내 내어 대비를 조절합니다.
- **흐림**: 저품질 스캔처럼 텍스트 가장자리가 부드러워지도록 가우시안 블러를 적용합니다.
- **노이즈**: 스캐너 센서의 입자감을 흉내 내어 무작위 픽셀 노이즈를 추가합니다. 값이 높을수록 더 거칠어집니다.
- **누런 색조**: 오래되었거나 재활용된 종이를 흉내 내어 따뜻한 노란 색조를 추가합니다.
- **해상도**: 출력 DPI를 설정합니다. 값이 낮을수록 더 픽셀이 보이는 스캔 같은 모습이 됩니다.
- **초기화**: 모든 설정을 기본값으로 되돌립니다.

## 기능

- 각 매개변수를 조정할 때마다 업데이트되는 실시간 미리보기
- 현실감 있는 변화를 위한 페이지별 무작위 회전 변동
- 독립적으로 조절 가능한 10개의 매개변수
- 진짜 같은 흑백 스캔 출력을 위한 흑백 모드
- 저해상도 팩스 품질부터 고해상도 보관 품질까지 해상도 조절

## 활용 사례

- 디지털로 만든 문서를 스캔하여 인쇄한 것처럼 보이게 만들기
- 역사 문서 재현을 위해 실제 문서의 노화 모사
- 품질이 저하된 스캔에 대한 OCR 소프트웨어 테스트
- 기존 스캔 보관 자료와 시각적 스타일이 일치하는 문서 제작

## 팁

- 약한 값으로 시작하세요. 노이즈 10-20, 0.5도의 미세한 회전, 최소한의 흐림만으로도 충분히 그럴듯한 스캔 느낌이 납니다.
- 흑백 모드와 약간의 누런 색조를 함께 쓰면 "복사본의 복사본" 효과가 납니다.
- 낮은 해상도 설정(100-150 DPI)이 가장 현실적인 팩스 느낌을 줍니다.

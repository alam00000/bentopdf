# JPG를 PDF로

JPG 이미지를 깔끔한 PDF로 만드세요. 파일 하나를 올리거나 여러 JPG를 한꺼번에 묶을 수 있으며, 각 이미지는 출력 문서에서 전체 크기 페이지가 됩니다.

## 지원 형식

| 형식      | 확장자          |
| :-------- | :-------------- |
| JPEG      | `.jpg`, `.jpeg` |
| JPEG 2000 | `.jp2`, `.jpx`  |

## 사용 방법

1. 업로드 영역을 클릭하거나 JPG 파일을 끌어다 놓으세요. 여러 파일을 선택할 수 있습니다.
2. 업로드한 파일을 확인하세요. 휴지통 아이콘으로 개별 파일을 제거하거나 **파일 더 추가**를 클릭해 목록에 추가하세요.
3. **PDF 품질** 수준을 선택하세요.
4. **PDF로 변환**을 클릭하세요. 도구가 품질 설정에 따라 이미지를 압축하고 PyMuPDF 엔진으로 변환한 뒤 `from_jpgs.pdf`를 다운로드합니다.

## 옵션

**PDF 품질**은 이미지를 PDF에 삽입하기 전에 적용하는 압축을 조절합니다.

- **고품질**: 최대한의 디테일을 보존합니다. 사진이나 인쇄용에 사용하세요.
- **중간 품질**(기본값): 선명도와 파일 크기 사이의 균형이 좋습니다.
- **저품질**: 가장 작은 결과물을 위한 강한 압축입니다.

## 활용 사례

- JPG로 저장된 스캔 문서를 제출용 PDF 하나로 변환하기
- 고객용 카탈로그로 제품 사진 묶기
- JPEG 2000 의료 또는 위성 이미지를 휴대 가능한 PDF로 만들기
- 카메라에서 내보낸 사진으로 인쇄 가능한 포토 앨범 만들기

## 팁

- 표준 JPEG뿐 아니라 JPEG 2000 파일(`.jp2`, `.jpx`)도 완전히 지원합니다. 의료 영상과 지리 공간 데이터에 유용합니다.
- 휴대폰 카메라로 찍은 JPG라면 중간 품질이 고품질보다 40~60% 작은 파일을 만들면서 화면에서는 눈에 띄는 차이가 없는 경우가 많습니다.

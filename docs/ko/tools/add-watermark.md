# 워터마크 추가

시각적 편집기를 사용해 PDF 페이지에 텍스트 또는 이미지 워터마크를 추가합니다. 미리보기에서 워터마크를 직접 끌어 위치를 정하고, 모서리 핸들로 크기를 조절하며, 불투명도, 회전, 글꼴, 색상을 설정할 수 있습니다. 페이지마다 워터마크 위치를 따로 지정하거나 모든 페이지에 같은 워터마크를 한 번에 적용할 수 있습니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 첫 페이지의 실시간 미리보기와 끌 수 있는 워터마크 오버레이가 있는 편집기가 열립니다.
3. 토글 버튼으로 **텍스트** 또는 **이미지** 워터마크 모드를 선택합니다.
4. 사이드바 패널에서 워터마크 설정을 구성합니다.
5. 미리보기에서 워터마크를 끌어 원하는 위치에 놓습니다. 모서리 핸들로 크기를 조절합니다.
6. 페이지별 워터마크를 설정하려면 페이지를 넘겨 가며 지정하고, 아니면 **모든 페이지에 적용**을 선택한 상태로 둡니다.
7. **워터마크 추가**를 클릭하여 처리하고 다운로드합니다.

## 옵션

**텍스트 워터마크 설정:**

- **텍스트** -- 워터마크 문구입니다(예: "CONFIDENTIAL", "DRAFT").
- **글꼴 크기** -- 10에서 200포인트입니다. 기본값은 72입니다.
- **색상** -- 색상 선택기로 원하는 색을 고릅니다.
- **불투명도** -- 완전 투명에서 완전 불투명까지 투명도를 조절합니다.
- **회전** -- 워터마크 텍스트를 -180도에서 180도까지 회전합니다.

**이미지 워터마크 설정:**

- **이미지 업로드** -- 워터마크로 사용할 PNG, JPG 등의 이미지 파일을 업로드합니다.
- **불투명도** -- 이미지 투명도를 조절합니다.
- **배율** -- 이미지 워터마크의 크기를 조정합니다.

**레이아웃 설정:**

- **단일** -- 페이지당 워터마크 하나를 끌어서 또는 위치 프리셋으로 배치합니다.
- **타일** -- 회전 각도를 따르는 대각선 격자로 페이지 전체에 워터마크를 반복하여 문서를 가장자리까지 덮습니다.
- **가로 간격** -- 텍스트 방향을 따른 타일 사이의 간격으로, 워터마크 너비에 대한 백분율입니다(타일 모드에서만 해당).
- **세로 간격** -- 타일 행 사이의 간격으로, 워터마크 높이에 대한 백분율입니다(타일 모드에서만 해당).

**일반 설정:**

- **모든 페이지에 적용** -- 선택하면 모든 페이지에 같은 워터마크가 적용됩니다. 선택을 해제하면 페이지별로 워터마크를 설정할 수 있습니다.
- **페이지 범위** -- 워터마크를 넣을 페이지를 지정합니다(예: "1-3, 5, 7-9" 또는 "all").

## 기능

- 실시간 PDF 미리보기에서 끌어서 놓는 시각적 위치 지정
- 모서리 핸들로 크기를 조절할 수 있는 워터마크
- 텍스트 및 이미지 워터마크 모드
- 간격을 조절할 수 있는 단일 또는 전체 페이지 타일(반복) 레이아웃
- 페이지별 또는 전체 워터마크 적용
- 미리보기에서 페이지 단위 탐색
- 불투명도 및 회전 조절
- 페이지 범위 필터링

## 활용 사례

- 검토용으로 배포하기 전에 초안 문서에 "DRAFT" 표시
- 민감한 재무 보고서에 "CONFIDENTIAL" 워터마크 추가
- 회사 로고 이미지 워터마크로 문서 브랜딩
- 잠재 고객에게 공유하는 제품 문서에 "SAMPLE" 찍기
- 배포용 PDF 자료에 저작권 고지 추가

## 팁

- 페이지를 대각선으로 가로지르는 워터마크는 회전을 약 45도로 설정하고 글꼴 크기를 키우세요.
- 타일 모드는 하나를 지워도 수십 개가 남기 때문에 잘라내기 후 문서를 재사용하기가 훨씬 어려워집니다. 타일을 쓸 때는 아래 텍스트가 읽히도록 불투명도를 낮추세요.
- 배경이 투명한 이미지 워터마크(PNG 형식)가 문서 내용과 더 자연스럽게 어우러집니다.
- 페이지마다 다른 워터마크 텍스트가 필요하면 "모든 페이지에 적용"을 해제하고 페이지별로 이동하며 설정하세요.

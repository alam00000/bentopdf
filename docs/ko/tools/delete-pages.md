# 페이지 삭제

PDF 문서에서 불필요한 페이지를 제거합니다. 페이지 번호나 범위를 입력하여 삭제할 페이지를 지정하거나, 페이지 썸네일을 직접 클릭하여 제거할 페이지로 표시하세요.

## 사용 방법

1. PDF 파일을 업로드합니다. 도구가 모든 페이지의 썸네일 미리 보기를 렌더링합니다.
2. 텍스트 필드에 범위 구문(예: `2, 5-8`)으로 삭제할 페이지를 입력하거나, 썸네일을 클릭하여 선택을 전환합니다.
3. 표시된 페이지는 시각적으로 강조되어 선택 내용을 확인할 수 있습니다.
4. 처리 버튼을 클릭합니다. 선택한 페이지가 제거된 새 PDF가 만들어집니다.

## 기능

- 범위 구문(`2, 5-8, 12`)을 사용한 텍스트 기반 페이지 선택
- 클릭으로 삭제할 페이지를 선택하는 시각적 썸네일 그리드
- 삭제로 표시된 페이지의 실시간 미리 보기 강조
- 실제 페이지 수에 대한 입력 검증
- 삭제하지 않은 모든 페이지를 원래 순서대로 유지

## 사용 사례

- 스캔 문서에서 빈 페이지나 불필요한 페이지 제거
- 문서를 공유하기 전에 표지나 부록 제거
- 최종 PDF에 실수로 남은 초안 페이지 정리
- 배포 전에 민감한 정보가 있는 페이지 제거

## 팁

- 페이지를 삭제해도 나머지 페이지의 내용이나 서식에는 영향이 없습니다. 출력은 제거된 페이지를 뺀 원본의 충실한 사본입니다.
- 특정 페이지를 제거하는 대신 특정 페이지만 남기려면 [페이지 추출](./extract-pages)이 더 적합합니다.
- 썸네일 보기는 지연 로딩되므로 큰 문서에서도 반응성이 유지됩니다.

# 페이지 크기 정보

PDF의 모든 페이지를 읽어 정확한 크기, 방향, 표준 용지 이름, 가로세로 비율, 면적, 회전을 보고하는 진단 도구입니다. 인쇄 전에 크기가 섞인 페이지를 찾아내거나 받은 PDF의 속성을 문서화할 때 유용합니다.

## 사용 방법

1. PDF 파일을 업로드합니다. 분석이 자동으로 시작되므로 누를 버튼이 없습니다.
2. 요약 패널에 전체 페이지 수, 고유한 페이지 크기 수, 문서에 크기가 섞여 있는지 여부가 표시됩니다.
3. 페이지별 세부 정보가 담긴 전체 결과 표를 살펴봅니다.
4. 표시 단위를 포인트, 인치, 밀리미터, 픽셀 중에서 전환합니다.
5. **CSV로 내보내기**를 클릭해 데이터를 저장합니다.

## 보고 항목

| 열            | 설명                                            |
| ------------- | ----------------------------------------------- |
| 페이지 #      | 순차 페이지 번호                                |
| 크기          | 선택한 단위의 너비 x 높이                       |
| 표준 크기     | 일치하는 이름(A4, Letter 등) 또는 "사용자 지정" |
| 방향          | 세로 또는 가로                                  |
| 가로세로 비율 | 너비 대 높이 비율(소수)                         |
| 면적          | 선택한 단위의 제곱으로 나타낸 페이지 면적       |
| 회전          | 페이지 회전 각도(도)                            |

## 기능

- 표준 용지 크기(A3, A4, A5, Letter, Legal, Tabloid 등) 자동 감지
- 어떤 크기가 몇 페이지에 쓰였는지 보여주는 크기 혼합 문서 경고
- 포인트, 인치, 밀리미터, 픽셀(96 PPI 기준) 간 단위 변환
- 스프레드시트나 문서 관리 시스템에서 쓸 수 있는 CSV 내보내기

## 활용 사례

- 인쇄소에 문서를 제출하기 전에 모든 페이지가 A4인지 확인하기
- 병합한 PDF가 특정 페이지에서 예상치 못한 여백으로 인쇄되는 원인 진단하기
- 대규모 PDF 보관소의 페이지 레이아웃을 메타데이터 기록으로 문서화하기
- 보정이 필요한 회전된 페이지 찾기

## 팁

- 요약에 "크기 혼합"이 표시되면 인쇄 전에 페이지 크기 통일 도구로 크기를 맞추세요.
- 회전 필드는 올바르게 표시되지만 회전 속성이 0이 아닌 페이지를 찾는 데 도움이 되며, 이런 페이지는 일부 워크플로우에서 문제를 일으킬 수 있습니다.

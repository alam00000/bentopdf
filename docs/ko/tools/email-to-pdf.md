# 이메일을 PDF로

저장된 이메일 파일을 깔끔하고 인쇄 가능한 PDF로 변환합니다. 도구가 EML 및 MSG 파일을 구문 분석하여 헤더, 본문 내용, 첨부파일 메타데이터까지 전체 메시지를 추출하고 구조화된 PDF로 렌더링합니다. 법적 증거 개시, 기록 보관, 또는 중요한 이메일을 인쇄할 때 유용합니다.

## 지원 형식

| 형식 | 확장자 | 참고                                                            |
| :--- | :----- | :-------------------------------------------------------------- |
| EML  | `.eml` | 표준 MIME 이메일 형식 (대부분의 이메일 클라이언트에서 내보내기) |
| MSG  | `.msg` | Microsoft Outlook 전용 형식                                     |

## 사용 방법

1. 업로드 영역을 클릭하거나 EML 또는 MSG 파일을 끌어다 놓습니다. 두 형식을 한 번에 섞어서 처리할 수 있습니다.
2. 파일 목록을 확인합니다. 필요 없는 항목은 휴지통 아이콘으로 제거하고, 이메일을 더 추가하려면 **파일 더 추가**를 클릭합니다.
3. 변환 옵션을 설정합니다(아래 참조).
4. **PDF로 변환**을 클릭합니다. 도구가 각 이메일을 구문 분석하고, 콘텐츠를 스타일이 적용된 HTML로 렌더링한 뒤, PyMuPDF 엔진으로 PDF로 변환합니다.
5. 이메일이 하나면 PDF로 바로 다운로드됩니다. 여러 이메일이면 `emails-converted.zip`으로 묶입니다.

## 옵션

| 옵션                       | 기본값 | 설명                                                                              |
| :------------------------- | :----- | :-------------------------------------------------------------------------------- |
| **페이지 크기**            | A4     | A4, Letter, Legal 중에서 선택합니다.                                              |
| **참조 및 숨은 참조 포함** | 켜짐   | 켜면 참조(CC)와 숨은 참조(BCC) 수신자 목록이 PDF의 이메일 헤더 섹션에 표시됩니다. |
| **첨부파일 목록 포함**     | 켜짐   | 켜면 이메일의 첨부파일 목록(파일 이름과 크기)이 PDF에 표시됩니다.                 |

## 사용 사례

- 규정 준수나 감사를 위해 중요한 업무 서신을 PDF로 보관
- 법적 절차나 증거 개시 요청을 위한 이메일 스레드 인쇄
- 이메일로 받은 주문 확인서, 영수증, 계약서의 영구 기록 만들기
- Outlook이 없어도 읽을 수 있는 형식으로 Outlook MSG 파일 백업
- 내보낸 EML 파일로 고객 지원 대화 기록

## 팁

- Thunderbird, Apple Mail 등 대부분의 이메일 클라이언트에서 쓰는 EML과 Outlook MSG 파일을 모두 지원합니다. 이메일 클라이언트에서 이메일을 내보내 도구에 바로 끌어다 놓으세요.
- HTML 형식의 이메일은 PDF에서도 스타일이 유지됩니다. 일반 텍스트 이메일은 깔끔하고 읽기 쉬운 서식으로 렌더링됩니다.
- 첨부파일 목록에는 파일 이름과 크기가 표시되지만 실제 첨부파일이 PDF에 포함되지는 않습니다.

# 이미지 추출

하나 이상의 PDF 파일에 포함된 모든 이미지를 꺼냅니다. 추출된 이미지는 미리 보기 그리드에 표시되며 개별적으로 다운로드하거나 ZIP으로 한꺼번에 받을 수 있습니다. PyMuPDF로 구동됩니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 하나 이상 업로드합니다. 필요에 따라 파일을 더 추가하거나 개별 파일을 제거합니다.
2. **추출**을 클릭하여 처리를 시작합니다.
3. 도구가 업로드한 모든 PDF의 모든 페이지를 검색하여 포함된 이미지를 찾아 추출합니다.
4. 추출된 이미지가 썸네일과 함께 그리드에 표시됩니다. 각 이미지에는 다운로드 버튼이 있습니다.
5. **모두 다운로드**를 클릭하여 전체를 ZIP 아카이브로 저장합니다.

## 옵션

이 도구에는 설정할 수 있는 옵션이 없습니다. 포함된 모든 이미지는 원래 형식(일반적으로 PNG, JPEG 또는 PDF에 이미지를 포함할 때 사용된 형식)으로 추출됩니다.

## 출력 형식

- 이미지는 `image_1.png`, `image_2.jpg` 같은 이름으로 미리 보기 그리드에 표시됩니다.
- **모두 다운로드**는 모든 이미지를 담은 `extracted-images.zip`을 만듭니다.
- 그리드에서 이미지를 하나씩 개별적으로 다운로드할 수 있습니다.

## 사용 사례

- 다른 프로젝트에서 재사용하기 위해 PDF에서 사진이나 그래픽 복구
- 전자상거래 목록을 위해 카탈로그 PDF에서 제품 이미지 추출
- 발표 자료에 쓰기 위해 기술 문서에서 다이어그램 꺼내기
- 문서를 공유하기 전에 어떤 이미지가 포함되어 있는지 점검

## 팁

- 도구는 PDF에 저장된 그대로 이미지를 추출합니다. 페이지를 이미지로 다시 렌더링하지는 않습니다. 그럴 때는 [PDF를 PNG로](./pdf-to-png) 또는 [PDF를 JPG로](./pdf-to-jpg)를 사용하세요.
- 도구가 "이미지를 찾을 수 없습니다"라고 알려 주면, PDF가 포함된 래스터 이미지가 아닌 벡터 그래픽을 사용하거나 페이지 전체가 하나의 큰 이미지인 스캔 문서일 수 있습니다.
- 일괄 처리는 여러 PDF에 걸쳐 작동합니다. 모든 파일의 모든 이미지가 하나의 그리드와 ZIP으로 합쳐집니다.

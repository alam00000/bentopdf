# ODS를 PDF로

OpenDocument Spreadsheet 파일을 PDF로 변환합니다. ODS는 LibreOffice Calc의 기본 형식이며 Google Sheets에서도 흔히 내보내는 형식입니다. 이 도구는 스프레드시트의 데이터, 서식, 차트를 페이지로 나뉜 PDF로 렌더링하여 인쇄하거나 공유할 수 있게 해줍니다.

## 지원 형식

| 형식                     | 확장자 | 비고                                      |
| :----------------------- | :----- | :---------------------------------------- |
| OpenDocument Spreadsheet | `.ods` | LibreOffice Calc / Google Sheets 내보내기 |

## 사용 방법

1. 업로드 영역을 클릭하거나 ODS 파일을 끌어다 놓습니다. 여러 파일을 지원합니다.
2. 파일 목록을 확인합니다. 휴지통 아이콘으로 파일을 제거하거나 **파일 더 추가**를 클릭해 일괄 작업을 확장할 수 있습니다.
3. **PDF로 변환**을 클릭합니다. LibreOffice 기반 엔진이 브라우저에 로드되어 각 스프레드시트를 PDF 페이지로 렌더링합니다.
4. 스프레드시트 하나는 PDF로 다운로드됩니다. 여러 파일은 `ods-to-pdf.zip`으로 묶입니다.

## 옵션

별도 설정은 필요하지 않습니다. 변환기는 스프레드시트의 기존 인쇄 레이아웃, 셀 서식, 열 너비를 PDF 출력에 그대로 적용합니다.

## 활용 사례

- PDF만 받는 상대에게 LibreOffice Calc 예산표나 보고서 공유하기
- ODS로 내려받은 Google Sheets 내보내기 파일 인쇄하기
- 재무 기록을 편집할 수 없는 형식으로 보관하기
- ODS 기반 양식이나 근무 시간표를 고정 레이아웃 문서로 제출하기

## 팁

- 스프레드시트에 시트가 여러 개 있으면 모든 시트가 PDF 출력에 포함됩니다.
- 매우 넓은 스프레드시트는 PDF에서 가로로 여러 페이지에 걸칠 수 있습니다. 레이아웃이 중요하다면 변환 전에 원본 파일의 열 너비를 조정하세요.
- LibreOffice 엔진은 처음 사용할 때 초기화됩니다. 같은 세션에서 이후 변환은 더 빠릅니다.

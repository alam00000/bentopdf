# PDF를 PDF/A로

PDF/A는 장기 디지털 보존을 위해 설계된 ISO 표준 PDF 하위 집합입니다. 이 도구는 브라우저에서 직접 실행되는 Ghostscript로 일반 PDF를 PDF/A 규격 문서로 변환합니다.

## 사용 방법

1. PDF 파일을 하나 이상 업로드합니다.
2. 드롭다운에서 **PDF/A 버전**을 선택합니다.
3. 일반 변환이 실패하는 복잡한 파일이라면 **사전 평탄화**를 선택적으로 켭니다.
4. **PDF/A로 변환**을 클릭합니다. 여러 파일은 ZIP 압축 파일로 만들어집니다.

## PDF/A 버전

| 버전         | 제한 사항                                      | 적합한 용도                            |
| ------------ | ---------------------------------------------- | -------------------------------------- |
| **PDF/A-1b** | 가장 엄격함. 투명도와 레이어를 사용할 수 없음. | 오래된 보관 시스템과의 최대 호환성     |
| **PDF/A-2b** | 투명도와 JPEG2000을 허용.                      | 범용 보관 (권장)                       |
| **PDF/A-3b** | 모든 형식의 첨부 파일 포함을 허용.             | 원본 데이터 파일이 함께 있는 문서 보관 |

PDF/A-2b가 기본으로 선택되어 있으며 대부분의 보관 요구를 충족합니다.

## 사전 평탄화 옵션

일부 PDF에는 특이한 글꼴 인코딩, 복잡한 투명도 스택, 손상된 내부 구조처럼 깔끔한 PDF/A 변환을 방해하는 요소가 있습니다. **사전 평탄화**를 켜면 변환 전에 PDF를 300 DPI로 래스터화하여 규정 준수를 보장하지만, 대신 텍스트를 선택할 수 없게 됩니다. 표준 변환에서 오류가 발생할 때의 대안으로 사용하세요.

사전 평탄화에는 PyMuPDF WASM 엔진이 필요합니다.

## 활용 사례

- 정부 또는 법률 보관 요건 충족하기 (많은 관할권이 법원 제출 문서에 PDF/A를 의무화합니다)
- 기관 저장소나 디지털 도서관에 문서 제출하기
- 10년 뒤에는 원본 소프트웨어가 없을 수 있는 업무 기록 보존하기
- XML 첨부가 있는 PDF/A-3b를 요구하는 전자 청구서 표준에 맞춰 청구서 준비하기

## 팁

- 먼저 사전 평탄화 없이 변환을 시도하세요. 오류가 발생할 때만 켜세요.
- PDF/A는 모든 글꼴을 포함하므로 출력 파일이 원본보다 큰 경우가 많습니다.
- 워크플로우에서 엄격한 준수가 필요하다면 전용 PDF/A 검증기로 출력을 검증하세요.

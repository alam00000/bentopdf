# CSV를 PDF로

CSV 파일을 깔끔하게 서식이 적용된 PDF 문서로 변환합니다. 각 CSV를 구문 분석하여 출력 PDF에 표로 렌더링합니다. 받는 사람이 스프레드시트 소프트웨어 없이도 표 형식의 데이터를 인쇄하거나 공유해야 할 때 유용합니다.

## 지원 형식

| 형식 | 확장자 |
| :--- | :----- |
| CSV  | `.csv` |

## 사용 방법

1. 업로드 영역을 클릭하거나 CSV 파일을 하나 이상 끌어다 놓습니다.
2. 파일 목록을 확인합니다. 파일을 더 추가하거나 필요 없는 파일을 제거합니다.
3. **PDF로 변환**을 클릭합니다. 진행 표시기가 변환 상태를 보여 줍니다.
4. 파일이 하나면 PDF로 바로 다운로드됩니다. 여러 파일이면 `csv-converted.zip`으로 묶입니다.

## 옵션

이 도구에는 추가 설정이 없습니다. CSV는 자동으로 구문 분석되어 표로 서식이 적용됩니다.

## 출력

| 입력 수       | 출력                                                      |
| :------------ | :-------------------------------------------------------- |
| 파일 1개      | PDF 한 개 다운로드 (예: `data.pdf`)                       |
| 파일 2개 이상 | 파일당 PDF 하나를 담은 ZIP 아카이브 (`csv-converted.zip`) |

## 사용 사례

- 내보낸 데이터베이스 보고서를 인쇄 가능한 PDF 표로 변환
- Excel이 없는 사람과 재무 데이터나 재고 목록 공유
- 규정 준수 문서화를 위해 CSV 로그 파일의 PDF 버전 만들기
- CSV로 저장된 주소 목록, 성적표 등 표 형식 데이터 인쇄

## 팁

- 최상의 결과를 위해 CSV가 표준 쉼표 구분자를 사용하는지 확인하세요. 이 도구는 일반적인 CSV 구문 분석 규칙을 따릅니다.
- CSV에 열이 많으면 표가 페이지 너비에 맞게 압축될 수 있습니다. 넓은 데이터 세트는 여러 파일로 나누는 것을 고려하세요.
- Excel 파일(`.xls`, `.xlsx`)은 스프레드시트 서식과 여러 시트를 유지하는 [Excel을 PDF로](./excel-to-pdf) 도구를 사용하세요.

# PowerPoint를 PDF로

프레젠테이션 파일을 PDF로 변환합니다. 각 슬라이드가 출력 문서의 한 페이지가 되며, 텍스트, 이미지, 도형, 전환 효과는 브라우저 기반 LibreOffice 엔진으로 렌더링됩니다. 최신 및 구형 PowerPoint 형식과 OpenDocument Presentation 형식을 모두 지원합니다.

## 지원 형식

| 형식                      | 확장자  |
| :------------------------ | :------ |
| PowerPoint (최신)         | `.pptx` |
| PowerPoint (구형)         | `.ppt`  |
| OpenDocument Presentation | `.odp`  |

## 사용 방법

1. 업로드 영역을 클릭하거나 프레젠테이션 파일을 끌어다 놓습니다.
2. 파일 목록을 확인합니다. 필요에 따라 파일을 추가하거나 제거합니다.
3. **PDF로 변환**을 클릭합니다. 처음 사용할 때 LibreOffice 엔진이 로드된 후 각 파일을 변환합니다.
4. 파일이 하나면 PDF로 바로 다운로드됩니다. 여러 파일은 `powerpoint-converted.zip`으로 묶여 다운로드됩니다.

## 옵션

이 도구에는 추가 설정이 없습니다. 슬라이드는 원래 크기 그대로 렌더링됩니다.

## 출력

| 입력 수       | 출력                                                              |
| :------------ | :---------------------------------------------------------------- |
| 파일 1개      | PDF 한 개 다운로드 (원본 파일명에 `.pdf` 확장자)                  |
| 파일 2개 이상 | 파일당 PDF 하나를 담은 ZIP 압축 파일 (`powerpoint-converted.zip`) |

## 활용 사례

- PowerPoint가 없을 수 있는 대상에게 공유하기 전에 프레젠테이션을 PDF로 변환
- 컨퍼런스나 워크숍용 슬라이드 인쇄 자료 만들기
- 모든 기기에서 동일하게 보이는 형식으로 프레젠테이션 보관
- LibreOffice Impress의 ODP 프레젠테이션을 일괄 PDF로 변환
- 이메일 첨부용 피치 덱 PDF 만들기

## 팁

- 슬라이드 애니메이션과 전환 효과는 PDF에 반영되지 않습니다. 각 슬라이드는 정적인 페이지로 저장됩니다.
- 삽입된 동영상은 출력에 나타나지 않습니다. 필요하면 스크린샷이나 대체 이미지로 바꾸세요.
- 발표자 노트는 기본 PDF 내보내기에 포함되지 않습니다. 노트가 필요하면 먼저 PowerPoint 자체의 "노트 인쇄" 보기에서 내보내는 것을 고려하세요.
- LibreOffice 엔진은 처음 로드한 뒤 캐시되므로 같은 세션에서 두 번째 프레젠테이션을 변환하면 훨씬 빠릅니다.

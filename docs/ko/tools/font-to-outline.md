# 폰트 윤곽선 변환

폰트를 윤곽선으로 변환하면 모든 텍스트 문자가 폰트 기반 글리프에서 벡터 경로로 바뀝니다. PDF가 설치된 폰트에 더 이상 의존하지 않으므로 모든 기기, 운영체제, 프린터에서 똑같이 표시됩니다. 인쇄 전 작업(프리프레스)의 표준 단계입니다.

## 사용 방법

1. PDF 파일을 하나 이상 업로드하세요.
2. **윤곽선으로 변환**을 클릭하세요.
3. Ghostscript가 모든 텍스트를 벡터 경로로 변환합니다.
4. 결과를 다운로드하세요. 여러 파일은 ZIP 아카이브로 제공됩니다.

설정할 항목은 없습니다. 이 도구는 Ghostscript(WebAssembly)를 사용하여 모든 폰트 참조를 한 번에 윤곽선 경로로 변환합니다.

## 변경되는 점

- 텍스트 문자가 벡터 곡선(베지어 경로)이 됩니다
- 폰트를 포함할 필요가 없어집니다. PDF가 글리프 수준에서 독립적으로 완성됩니다
- 벡터 경로가 폰트 참조보다 일반적으로 크기 때문에 파일 크기가 늘어날 수 있습니다
- 겉모습은 그대로 보존됩니다

## 잃게 되는 것

- 텍스트 선택과 복사 및 붙여넣기
- 텍스트 검색(Ctrl+F가 작동하지 않음)
- 텍스트 내용 편집 기능
- 스크린 리더 접근성

## 활용 사례

- 윤곽선 처리된 폰트를 요구하는 인쇄소에 PDF 보내기
- 사용자 지정 폰트나 라이선스 폰트를 쓴 문서를 해당 폰트가 없는 사람과 공유하기
- 다른 시스템에서 폰트가 대체되어 문서 모양이 달라지는 것 방지하기
- 벡터 입력이 필요한 레이저 각인 또는 CNC 절단 작업용 PDF 준비하기
- 로고가 많은 PDF가 모든 플랫폼에서 올바르게 표시되도록 하기

## 팁

- 원본 PDF를 보관하세요. 윤곽선 변환은 되돌릴 수 없으며 경로를 편집 가능한 텍스트로 되돌릴 수 없습니다.
- 텍스트를 계속 검색할 수 있어야 한다면, 대신 PDF 래스터화 도구로 변환한 뒤 OCR을 적용하는 방법을 고려하세요.
- 윤곽선 처리된 PDF는 대체로 용량이 큽니다. 파일 크기가 중요하다면 이후에 PDF 압축을 실행하세요.

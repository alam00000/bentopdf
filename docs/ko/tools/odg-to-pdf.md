# ODG를 PDF로

OpenDocument Graphics 파일을 PDF로 변환합니다. ODG는 LibreOffice Draw의 기본 형식으로 다이어그램, 순서도, 벡터 일러스트에 쓰입니다. PDF로 변환하면 이런 그림을 쉽게 공유하고, 인쇄하고, 다른 문서에 삽입할 수 있습니다.

## 지원 형식

| 형식                  | 확장자 | 참고                                    |
| :-------------------- | :----- | :-------------------------------------- |
| OpenDocument Graphics | `.odg` | LibreOffice Draw / OpenOffice Draw 파일 |

## 사용 방법

1. 업로드 영역을 클릭하거나 ODG 파일을 끌어다 놓으세요. 여러 파일을 한 번에 추가할 수 있습니다.
2. 파일 목록을 확인하세요. 휴지통 아이콘으로 개별 항목을 제거하거나 **파일 더 추가**를 클릭해 그림을 더 추가하세요.
3. **PDF로 변환**을 클릭하세요. LibreOffice 기반 엔진이 브라우저에 로드되어 각 ODG 파일을 변환하며 벡터 그래픽, 도형, 텍스트를 보존합니다.
4. 파일 하나는 PDF로 바로 다운로드됩니다. 여러 파일은 `odg-to-pdf.zip`이라는 ZIP 아카이브로 제공됩니다.

## 옵션

추가 설정은 필요하지 않습니다. 변환은 ODG 원본의 페이지 크기, 도형, 커넥터, 텍스트 상자를 그대로 보존합니다.

## 활용 사례

- LibreOffice가 설치되어 있지 않은 고객과 LibreOffice Draw 다이어그램 공유하기
- Draw에서 만든 순서도와 네트워크 다이어그램 인쇄하기
- ODG 일러스트를 임베디드 PDF로 보고서나 프레젠테이션에 포함하기
- 수십 년간 읽을 수 있는 형식으로 기술 도면 보관하기

## 팁

- 벡터 요소는 PDF 출력에서도 벡터로 유지되므로 어떤 인쇄 크기로도 깔끔하게 확대할 수 있습니다.
- LibreOffice 엔진은 처음 사용할 때 초기화에 잠시 시간이 걸립니다. 같은 세션에서 그다음부터는 변환이 더 빠릅니다.

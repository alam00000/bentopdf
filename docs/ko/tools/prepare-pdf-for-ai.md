# AI용 PDF 준비

PDF 파일에서 내용을 추출하여 대규모 언어 모델(LLM)과 LlamaIndex 같은 AI 프레임워크에서 사용하기 좋은 JSON으로 구조화합니다. 각 페이지의 내용이 추출되어 RAG 파이프라인, 챗봇, 시맨틱 검색 시스템에 바로 쓸 수 있는 구조화된 형식으로 정리됩니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 하나 이상 업로드합니다.
2. **추출**을 클릭하여 처리를 시작합니다.
3. 파일이 하나면 `filename_llm.json`으로 다운로드됩니다. 여러 파일은 `pdf-for-ai.zip` 압축 파일로 생성됩니다.

이 도구는 PyMuPDF의 LlamaIndex 통합 기능을 사용하여 메타데이터가 포함된 페이지 단위 내용을 추출하며, 결과물은 AI 프레임워크에 바로 불러올 수 있습니다.

## 옵션

이 도구에는 설정할 수 있는 옵션이 없습니다. 모든 페이지가 전체 텍스트와 메타데이터와 함께 추출됩니다.

## 출력 형식

- **파일 하나**: `filename_llm.json`
- **여러 파일**: 입력 PDF마다 `_llm.json` 하나씩을 담은 `pdf-for-ai.zip`.

JSON 출력은 페이지별 텍스트 내용과 메타데이터 필드를 가진 LlamaIndex 문서 스키마를 따릅니다.

## 활용 사례

- 검색 증강 생성(RAG) 파이프라인용 PDF 문서 준비
- PDF 아카이브로 AI 챗봇용 검색 가능한 지식 베이스 구축
- PDF 보고서를 LLM 기반 분석 워크플로에 입력
- 시맨틱 검색 및 질의응답 시스템을 위한 연구 논문 전처리
- PDF 문서 모음에서 구조화된 학습 데이터 생성

## 팁

- AI 전용 형식이 필요 없는 일반 텍스트 추출에는 [PDF를 텍스트로](./pdf-to-text)를 사용하세요.
- 제목과 구조를 유지하는 Markdown 출력에는 [PDF를 Markdown으로](./pdf-to-markdown)를 사용하세요.
- 스캔한 PDF는 출력이 비어 있거나 거의 없습니다. 추출 전에 OCR로 텍스트 레이어를 먼저 추가하세요.

# 양면 스캔 정렬

양면 스캔 정렬은 하나의 PDF에 두 개의 페이지 블록이 들어 있는 ADF 스캔 워크플로를 위해 설계되었습니다.

- 모든 앞면이 먼저
- 모든 뒷면이 그다음

수동으로 나누고 다시 조립하는 대신, 이 도구가 두 블록을 자연스러운 읽기 순서(앞면1, 뒷면1, 앞면2, 뒷면2 등)로 교차 배열합니다.

## 사용 방법

1. 양면 스택 스캔으로 만든 PDF 하나를 업로드합니다.
2. 앞면 블록이 끝나는 분할 지점을 설정합니다.
3. 뒷면 블록 처리 방식을 선택합니다.
   - **뒷면 블록 뒤집기** (뒷면을 스캔하기 전에 스택을 뒤집은 경우 일반적)
   - **뒷면 블록 그대로 유지**
4. **PDF 정렬**을 클릭하여 재정렬된 결과를 다운로드합니다.

## 옵션

- **분할 지점 자동 감지(절반)**: 분할 지점을 `ceil(totalPages / 2)`로 설정합니다.
- **홀수 페이지 경고**: 전체 페이지 수가 홀수이면 경고합니다(스캔 불일치인 경우가 많습니다).
- **불균등 블록 확인**: 앞면/뒷면 블록 크기가 다르면 확인을 요청합니다.
- **그룹 내보내기**: 정렬된 출력을 원본 문서의 페이지 수에 따라 별도의 PDF로 나누고 ZIP으로 다운로드합니다.

## 출력 동작

- **기본**: 출력 PDF 하나(입력 PDF 하나에 출력 PDF 하나).
- **그룹 모드**: 문서당 페이지 수 값에 따라 출력을 나눕니다. 여러 덩어리가 만들어지면 하나의 ZIP으로 다운로드되고, 그렇지 않으면 PDF 하나가 다운로드됩니다.

블록 크기가 다르면 짝이 맞는 페이지를 먼저 정렬하고, 짝이 없는 나머지 페이지는 끝에 덧붙입니다.

## 일반적인 사용 사례

- 양면 양식 더미를 두 번에 나누어 스캔한 후 순서 복원
- 모든 앞면을 먼저, 모든 뒷면을 나중에 출력하는 사무용 스캐너의 앞면/뒷면 묶음 재구성
- 문서별 파일로 나누기 전 보관용 스캔 후처리

## 팁

- 대부분의 양면 배치는 전체 페이지 수가 짝수여야 합니다.
- 뒷면이 거꾸로 보이면 **뒷면 블록 뒤집기**와 **뒷면 블록 그대로 유지** 사이를 전환해 보세요.
- 2페이지짜리 원본(앞면+뒷면)에는 문서당 페이지 수를 `2`로 하여 그룹 내보내기를 사용하세요.

# 메타데이터 편집

PDF 파일에 포함된 메타데이터를 편집합니다. 도구가 문서의 기존 메타데이터로 양식을 미리 채우고, 원하는 필드를 수정한 뒤 변경 사항을 새 PDF에 저장합니다.

## 사용 방법

1. PDF 파일을 업로드합니다. 도구가 현재 메타데이터를 읽어 양식에 채웁니다.
2. 표준 필드(제목, 작성자, 주제, 키워드, 작성 프로그램, PDF 생성기)를 편집합니다.
3. 날짜/시간 선택기로 작성일과 수정일을 조정합니다.
4. 추가 버튼을 클릭하고 키-값 쌍을 입력하여 사용자 지정 메타데이터 필드를 추가합니다.
5. 처리 버튼을 클릭하여 수정된 PDF를 저장합니다.

## 기능

- 업로드한 PDF의 기존 메타데이터를 모두 미리 채움
- 표준 필드: 제목, 작성자, 주제, 키워드, 작성 프로그램, PDF 생성기
- 작성일과 수정일용 날짜/시간 선택기
- 임의 속성을 위한 사용자 지정 키-값 메타데이터 필드
- 변경 사항을 PDF의 문서 정보 딕셔너리에 직접 저장

## 편집 가능한 필드

| 필드                 | 설명                                  |
| -------------------- | ------------------------------------- |
| **제목**             | PDF 리더에 표시되는 문서 제목         |
| **작성자**           | 문서를 만든 사람 또는 조직            |
| **주제**             | 문서 주제에 대한 간단한 설명          |
| **키워드**           | 검색과 분류를 위한 쉼표로 구분된 용어 |
| **작성 프로그램**    | 콘텐츠를 처음 만든 애플리케이션       |
| **PDF 생성기**       | PDF를 생성한 애플리케이션             |
| **작성일**           | 문서가 처음 만들어진 시점             |
| **수정일**           | 문서가 마지막으로 수정된 시점         |
| **사용자 지정 필드** | 직접 정의하는 추가 키-값 쌍           |

## 사용 사례

- 문서를 게시하기 전에 적절한 제목과 작성자 설정
- 문서 관리 시스템에서 검색성을 높이기 위해 키워드 추가
- 현재 개정을 반영하도록 수정일 업데이트
- 부서, 프로젝트 ID, 분류 같은 사용자 지정 메타데이터 필드 추가
- 원래 작성 소프트웨어가 남긴 메타데이터 정리

## 팁

- 사용자 지정 필드는 PDF의 정보 딕셔너리에 직접 기록됩니다. 일부 PDF 리더는 사용자 지정 필드를 표시하지 않을 수 있지만 파일에는 보존됩니다.
- 필드를 비워 두면 메타데이터에서 해당 값이 지워집니다. 처리 버튼은 양식에 있는 내용을 그대로 저장합니다.
- 편집 없이 메타데이터를 보려면 [메타데이터 보기](./view-metadata)를 사용하세요. 모든 메타데이터를 완전히 제거하려면 메타데이터 제거를 사용하세요.

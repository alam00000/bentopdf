# PUB를 PDF로

Microsoft Publisher 파일을 PDF로 변환합니다. Publisher는 일부 Microsoft Office 에디션에 포함된 데스크톱 출판 도구이지만 대부분의 사람들은 설치하지 않았습니다. 이 도구로 누구나 Microsoft 소프트웨어 없이 브라우저에서 바로 PUB 파일을 PDF로 변환할 수 있습니다.

## 지원 형식

| 형식                | 확장자 | 참고               |
| :------------------ | :----- | :----------------- |
| Microsoft Publisher | `.pub` | 데스크톱 출판 문서 |

## 사용 방법

1. 업로드 영역을 클릭하거나 PUB 파일을 끌어다 놓습니다. 여러 파일을 한 번에 업로드할 수 있습니다.
2. 파일 목록을 확인합니다. 원하지 않는 파일은 휴지통 아이콘으로 제거하거나 **파일 더 추가**를 클릭해 더 추가합니다.
3. **PDF로 변환**을 클릭합니다. LibreOffice 기반 엔진이 브라우저에 로드되어 레이아웃, 이미지, 텍스트 상자를 유지한 채 각 PUB 파일을 변환합니다.
4. 파일이 하나면 PDF로 바로 다운로드됩니다. 여러 파일은 `pub-to-pdf.zip`이라는 ZIP 압축 파일로 제공됩니다.

## 옵션

추가 설정이 필요 없습니다. 변환기가 PUB 레이아웃 엔진을 자동으로 처리합니다.

## 활용 사례

- Microsoft Publisher를 구매하지 않고 고객이 보낸 PUB 전단지나 소식지 열기
- Publisher로 만든 교회 주보, 행사 프로그램, 학교 소식지 변환
- Publisher의 마케팅 자료를 누구나 열 수 있는 형식으로 보관
- Publisher가 설치되지 않은 시스템에서 PUB 파일 인쇄

## 팁

- 텍스트 상자가 겹쳐 있고 위치가 정밀한 복잡한 Publisher 레이아웃은 변환 중 약간 어긋날 수 있습니다. 정확한 위치가 중요하다면 결과를 확인하세요.
- LibreOffice 엔진은 세션당 한 번 초기화됩니다. 첫 변환은 시간이 더 걸리고 이후는 더 빠릅니다.
- Publisher 파일을 가장 충실하게 변환하려면 원본에 사용된 사용자 지정 글꼴이 표준 시스템 글꼴인지 확인하세요.

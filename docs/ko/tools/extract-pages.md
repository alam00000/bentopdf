# 페이지 추출

PDF에서 여러 페이지를 꺼내 새 파일로 저장합니다. 범위 구문으로 원하는 페이지를 정확히 지정하면 도구가 해당 페이지만 담은 깔끔한 PDF를 만듭니다.

## 사용 방법

1. PDF 파일을 업로드합니다. 도구가 파일 이름, 크기, 전체 페이지 수를 표시합니다.
2. 범위 구문(예: `1-5`, `3, 7, 10-12`)으로 추출할 페이지를 입력합니다.
3. 필요하면 각 범위를 ZIP 아카이브 안의 별도 PDF로 다운로드하도록 선택합니다.
4. 처리 버튼을 클릭합니다. 추출된 페이지가 새 PDF(또는 ZIP)로 다운로드됩니다.

## 기능

- 유연한 페이지 범위 구문: 개별 페이지, 범위, 쉼표로 구분한 조합
- 업로드 후 전체 페이지 수를 표시하여 쉽게 참조
- 하나로 합친 PDF 또는 ZIP 안의 개별 파일로 출력하는 옵션
- 원본 페이지 내용과 서식 유지

## 사용 사례

- 긴 보고서에서 요약(처음 몇 페이지) 꺼내기
- 교재 PDF에서 한 챕터 추출
- 양식 묶음에서 특정 페이지를 독립된 문서로 저장
- 큰 파일에서 선택한 페이지로 샘플 문서 만들기

## 팁

- 페이지 번호는 1부터 시작합니다. 첫 페이지는 `0`이 아니라 `1`을 사용하세요.
- 페이지를 추출하는 대신 제거하려면 반대 작업인 [페이지 삭제](./delete-pages)를 사용하세요.
- 썸네일로 페이지를 시각적으로 선택하려면 [PDF 분할](./split-pdf)의 시각적 선택 모드를 사용하세요.

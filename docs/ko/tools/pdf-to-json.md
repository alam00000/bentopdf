# PDF를 JSON으로

PDF 파일을 하나 이상 JSON 형식으로 변환합니다. 이 도구는 CPDF(Coherent PDF)를 사용해 각 PDF의 내부 구조를 기계가 읽을 수 있는 JSON 표현으로 직렬화합니다. 출력은 항상 ZIP 압축 파일로 제공됩니다.

## 사용 방법

1. 파일 선택기로 PDF 파일을 하나 이상 선택합니다.
2. **변환**을 클릭해 처리를 시작합니다. 변환은 백그라운드 웹 워커에서 실행됩니다.
3. 입력한 PDF마다 JSON 파일 하나가 담긴 ZIP 압축 파일이 다운로드됩니다.

상태 표시줄에 변환과 ZIP 생성 단계의 진행 상황이 표시됩니다.

## 옵션

이 도구에는 설정 가능한 옵션이 없습니다. 각 PDF는 전체 JSON 표현으로 변환됩니다.

## 출력 형식

- 입력한 PDF마다 `filename.json`이 담긴 `pdfs-to-json.zip` 파일.

JSON 출력은 페이지 트리, 글꼴 참조, 메타데이터, 콘텐츠 스트림을 포함한 PDF의 내부 개체 구조를 나타냅니다.

## 활용 사례

- 디버깅이나 검증을 위해 PDF의 내부 구조 살펴보기
- 구조화된 메타데이터와 페이지 속성을 프로그래밍 방식으로 추출하기
- PDF 구조 데이터를 맞춤형 처리 파이프라인에 전달하기
- 개체 트리를 분석해 규정 준수를 위한 PDF 문서 감사하기

## 팁

- 이 도구는 추출된 텍스트 콘텐츠가 아닌 원시 PDF 개체 구조를 출력합니다. 페이지 텍스트를 JSON 형식으로 원한다면 [AI용 PDF 준비](./prepare-pdf-for-ai)를 사용하세요.
- 일반 텍스트 추출에는 [PDF를 텍스트로](./pdf-to-text)가 더 간단합니다.
- 구조가 복잡한 큰 PDF는 매우 큰 JSON 파일을 만듭니다.

# CBZ를 PDF로

만화책 아카이브 파일을 PDF로 변환합니다. CBZ와 CBR은 디지털 만화의 표준 형식으로, 이미지로 채워진 ZIP 또는 RAR 아카이브일 뿐입니다. 이 도구는 각 페이지를 추출하고 읽는 순서를 유지하며, 모든 이미지가 전체 크기 페이지가 되는 깔끔한 PDF를 만듭니다.

## 지원 형식

| 형식 | 확장자 | 참고                                             |
| :--- | :----- | :----------------------------------------------- |
| CBZ  | `.cbz` | ZIP 기반 만화 아카이브 (pdf-lib로 로컬에서 처리) |
| CBR  | `.cbr` | RAR 기반 만화 아카이브 (PyMuPDF 엔진으로 처리)   |

CBZ 변환기는 아카이브 안의 JPEG, PNG, GIF, BMP, WebP, AVIF, TIFF, HEIC, JXL 이미지를 인식합니다. 비표준 형식은 삽입 전에 자동으로 PNG로 변환됩니다.

## 사용 방법

1. 업로드 영역을 클릭하거나 CBZ 또는 CBR 파일을 끌어다 놓습니다. 두 형식을 한 번에 섞어서 처리할 수 있습니다.
2. 나열된 파일을 확인합니다. 필요 없는 파일은 제거하고, 더 추가하려면 **파일 더 추가**를 클릭합니다.
3. **PDF로 변환**을 클릭합니다. CBZ 파일은 아카이브를 풀고, 이미지 파일을 이름의 자연스러운 순서로 정렬하고, 각 이미지의 실제 형식을 감지한 다음 pdf-lib로 PDF에 삽입합니다. CBR 파일은 대신 PyMuPDF 엔진으로 처리됩니다.
4. 파일이 하나면 PDF로 다운로드됩니다. 여러 파일이면 `comic-converted.zip`이라는 ZIP 아카이브가 만들어집니다.

## 옵션

별도의 설정이 필요 없습니다. 각 이미지는 원본 크기에 맞춰 한 페이지가 되므로, 두 페이지에 걸친 펼침면은 넓게, 한 페이지짜리는 좁게 유지됩니다.

## 사용 사례

- PDF는 지원하지만 CBZ/CBR은 지원하지 않는 태블릿이나 휴대폰 앱에서 만화 읽기
- 디지털 만화의 특정 페이지 인쇄
- 만화 컬렉션을 어떤 파일 뷰어로도 열 수 있는 형식으로 보관
- 전용 만화 리더가 없는 사람과 만화 공유

## 팁

- 아카이브 안의 이미지는 자연스러운 순서로 정렬됩니다(`page2.jpg`가 `page10.jpg`보다 먼저 옵니다). 올바른 페이지 순서를 위해 파일 이름에 일관된 번호를 붙이세요.
- 변환기는 파일 확장자가 아니라 바이너리 시그니처로 이미지 형식을 감지합니다. 실수로 `.jpg`라는 이름이 붙은 PNG도 올바르게 삽입됩니다.
- CBZ 파일은 PyMuPDF 엔진을 불러오지 않고 브라우저에서 전부 처리되므로 CBR 파일보다 빠르게 변환됩니다.

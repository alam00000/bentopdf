# PDF 선형화

선형화는 파일 전체를 다운로드하기 전에 첫 페이지를 표시할 수 있도록 PDF를 재구성합니다. Adobe는 이를 "빠른 웹 보기"라고 부릅니다. 웹사이트에 PDF를 올리거나 문서 포털로 제공한다면 선형화로 훨씬 빠르게 열리는 느낌을 줄 수 있습니다.

## 사용 방법

1. PDF 파일을 하나 이상 업로드하세요.
2. **PDF 선형화**를 클릭하세요.
3. 선형화된 모든 파일이 담긴 ZIP 아카이브로 결과를 다운로드하세요.

설정할 항목은 없습니다. 이 도구는 QPDF의 `--linearize` 플래그를 사용하며, 시각적 콘텐츠는 바꾸지 않고 PDF의 내부 구조만 재배열합니다.

## 선형화가 하는 일

- 첫 페이지의 데이터가 파일 맨 앞에 오도록 PDF 객체 순서를 재정렬
- 뷰어가 각 페이지의 위치를 알 수 있도록 선형화 사전과 힌트 테이블 추가
- 바이트 범위 요청 지원: 브라우저가 파일 전체를 받지 않고 첫 페이지만 가져올 수 있음
- 효율적인 임의 접근을 위해 상호 참조 테이블 정리

## 기능

- 한 번의 작업으로 여러 PDF 일괄 처리
- 출력물이 모든 콘텐츠, 폰트, 이미지, 대화형 요소를 보존
- 안정적이고 표준을 준수하는 선형화를 위해 QPDF(WebAssembly) 사용
- 쉬운 다운로드를 위해 결과를 ZIP으로 묶음

## 활용 사례

- 사용자가 즉시 페이지가 표시되길 기대하는 웹사이트에 PDF 보고서 올리기
- 브라우저 내 뷰어가 있는 웹 애플리케이션에 PDF 삽입하기
- 느린 모바일 연결로 접근하는 PDF 카탈로그나 매뉴얼 게시하기
- 바이트 범위 제공을 지원하는 콘텐츠 전송 네트워크(CDN)용 문서 준비하기

## 팁

- 다른 모든 편집이 끝난 뒤에 선형화하세요. 이후 수정(병합, 페이지 추가 등)을 하면 선형화가 깨집니다.
- PDF 압축과 함께 사용하면 가장 작고 가장 빠르게 로드되는 PDF를 만들 수 있습니다.
- 선형화로 파일 크기가 약간 늘어납니다(보통 1% 미만).

# 사용자 지정 각도 회전

90도 단위뿐 아니라 임의의 각도로 PDF 페이지를 회전합니다. 각 페이지마다 각도를 입력할 수 있고, 일괄 제어로 모든 페이지에 같은 각도를 한 번에 적용할 수도 있습니다.

## 사용 방법

1. PDF 파일을 업로드합니다. 모든 페이지의 썸네일이 렌더링됩니다.
2. 각 페이지에는 현재 회전 각도를 보여주는 숫자 입력 필드가 있습니다.
3. 특정 페이지를 회전하려면 원하는 각도 값(양수 또는 음수)을 입력하거나, 페이지별 왼쪽/오른쪽 버튼으로 90도씩 빠르게 조정합니다.
4. 상단의 **일괄 각도** 입력으로 모든 페이지에 동일한 회전을 설정합니다.
5. 처리 버튼을 클릭하여 회전된 PDF를 생성합니다.

## 기능

- 페이지별 자유 각도 입력(임의의 정수 값)
- 모든 페이지에 같은 회전을 설정하는 일괄 각도 제어
- 썸네일에서 회전을 실시간으로 미리보기
- 90도 단위로 빠르게 회전하는 페이지별 버튼
- 큰 문서에서도 성능이 좋은 지연 로딩 썸네일

## 활용 사례

- 몇 도 기울어진 스캔본 바로잡기
- 비표준 방향 요구사항에 맞게 페이지 회전
- 여러 내용이 섞인 문서에서 개별 페이지를 정밀하게 회전
- 처음 일괄 회전한 후 페이지 각도 미세 조정

## 팁

- 양수 값은 시계 방향, 음수 값은 시계 반대 방향으로 회전합니다.
- 일괄 각도 필드를 적용하면 페이지별 각도가 모두 덮어쓰기됩니다. 필요하면 일괄 작업 후에 개별 조정을 하세요.
- 표준 90/180/270도 회전을 더 간단한 인터페이스로 하려면 [PDF 회전](./rotate-pdf)을 사용하세요.

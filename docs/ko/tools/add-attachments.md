# 첨부파일 추가

하나 이상의 파일을 PDF 문서 안에 직접 삽입합니다. 첨부파일은 문서 수준(모든 PDF 리더의 첨부파일 패널에서 확인 가능)으로 추가하거나 특정 페이지에 연결할 수 있습니다.

## 사용 방법

1. 파일을 첨부할 PDF를 업로드합니다.
2. 첨부파일 드롭 영역에서 삽입할 파일(모든 형식)을 선택합니다.
3. 첨부 수준을 선택합니다. **문서**(기본값) 또는 **페이지**입니다.
4. 페이지 수준을 선택한 경우 페이지 범위(예: `1-3` 또는 `5`)를 입력합니다.
5. 처리 버튼을 클릭합니다. 파일이 삽입된 PDF가 다운로드됩니다.

## 기능

- 모든 파일 형식 첨부 가능 -- 이미지, 스프레드시트, 압축 파일, 실행 파일 등 무엇이든 가능
- 문서 수준 또는 페이지 수준으로 첨부 위치 지정
- 한 번에 여러 파일 첨부 가능
- 선택한 모든 첨부파일의 이름과 크기 표시
- 원본 PDF 내용은 그대로 유지하고 삽입된 파일만 추가

## 옵션

| 옵션            | 설명                                                             |
| --------------- | ---------------------------------------------------------------- |
| **문서 수준**   | PDF 전체에 파일을 첨부하며, 첨부파일 패널에서 접근할 수 있습니다 |
| **페이지 수준** | 페이지 범위 입력으로 지정한 특정 페이지에 파일을 첨부합니다      |

## 활용 사례

- PDF 보고서에 원본 데이터(Excel 파일, CSV)를 함께 묶기
- 사진 포트폴리오 PDF에 원본 이미지 파일 첨부
- 계약서나 제안서 안에 증빙 자료 삽입
- 교육 매뉴얼의 특정 페이지에 보충 자료 추가

## 팁

- 문서 수준 첨부파일은 PDF 리더에서 가장 폭넓게 지원됩니다. 페이지 수준 첨부파일은 일부 뷰어에서 보이지 않을 수 있습니다.
- 첨부파일 크기에는 제한이 없지만, 매우 큰 파일을 삽입하면 PDF 크기도 그만큼 커집니다.

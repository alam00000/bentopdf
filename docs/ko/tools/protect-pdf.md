# PDF 보호

PDF를 비밀번호로 잠가 권한이 있는 사람만 열 수 있게 합니다. BentoPDF는 은행과 정부 기관에서 사용하는 것과 같은 표준인 256비트 AES 암호화를 QPDF를 통해 브라우저 안에서 모두 처리합니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. **사용자 비밀번호**를 입력합니다(필수). 파일을 열 때 필요한 비밀번호입니다.
3. 필요하면 **소유자 비밀번호**를 입력합니다. 설정하면 PDF에 인쇄, 편집, 복사, 주석 달기를 막는 사용 제한이 적용됩니다.
4. **PDF 암호화**를 클릭합니다.
5. 암호화된 파일을 다운로드합니다.

## 비밀번호 종류

### 사용자 비밀번호 (필수)

사용자 비밀번호는 받는 사람이 PDF를 열 때 입력하는 비밀번호입니다. 이 비밀번호가 없으면 문서에 전혀 접근할 수 없습니다. 암호화된 모든 PDF에는 반드시 있어야 합니다.

### 소유자 비밀번호 (선택)

소유자 비밀번호는 권한이 있는 사용자가 파일을 연 후 할 수 있는 작업을 제어합니다. 별도의 소유자 비밀번호를 설정하면 BentoPDF가 가장 엄격한 제한 설정을 자동으로 적용합니다.

- 수정 비활성화
- 추출/복사 비활성화
- 인쇄 비활성화
- 주석 비활성화
- 양식 작성 비활성화
- 문서 조립 비활성화

소유자 비밀번호를 비워 두면 PDF는 암호화되어 열 때 사용자 비밀번호가 필요하지만, 일단 열고 나면 사용 제한이 없습니다.

## 암호화 세부 정보

- **알고리즘**: AES-256 (256비트 Advanced Encryption Standard)
- **키 길이**: 256비트
- **표준**: PDF 2.0 암호화 (QPDF 구현)

AES-256은 현재 기술로는 무차별 대입으로 뚫는 것이 계산상 불가능합니다. 암호화된 PDF의 보안은 전적으로 비밀번호의 강도에 달려 있습니다.

## 활용 사례

- 기밀 재무 보고서를 이메일로 보내기 전에 보호
- 상대측 변호인과 공유하는 법률 문서 보안
- 의료 기록이나 개인 식별 정보에 비밀번호 추가
- 유료 콘텐츠(전자책, 보고서)를 접근 제어와 함께 배포
- 저장 데이터 암호화를 요구하는 데이터 보호 정책 준수

## 팁

- 강력하고 고유한 비밀번호를 사용하세요. 대소문자, 숫자, 기호를 섞은 12자 이상의 암호 문구가 이상적입니다.
- 비밀번호는 별도의 경로(전화, 문자 메시지)로 전달하고, PDF를 보내는 이메일에는 절대 함께 적지 마세요.
- 열 때 비밀번호를 요구하지 않고 동작(인쇄 금지, 복사 금지)만 제한하려면 권한 변경 도구를 대신 사용하세요.

# XPS를 PDF로

Microsoft XPS 및 OXPS 문서를 표준 PDF 파일로 변환합니다. XPS(XML Paper Specification)는 PDF에 대한 Microsoft의 대답이었지만, 여러 플랫폼에서 지원이 줄어들었습니다. 이 도구는 그런 문서를 다시 누구나 읽을 수 있게 만들어 줍니다.

## 지원 형식

| 형식 | 확장자  | 참고                         |
| :--- | :------ | :--------------------------- |
| XPS  | `.xps`  | 원래의 Microsoft XPS 형식    |
| OXPS | `.oxps` | Open XPS, ECMA-388 표준 변형 |

## 작동 방식

1. 업로드 영역을 클릭하거나 XPS/OXPS 파일을 끌어다 놓습니다. 여러 파일을 한 번에 선택할 수 있습니다.
2. 파일 목록을 확인합니다. 휴지통 아이콘으로 개별 파일을 제거하거나, **파일 더 추가**를 클릭해 문서를 더 추가합니다.
3. **PDF로 변환**을 클릭합니다. PyMuPDF 엔진이 브라우저에서 각 문서를 로컬로 처리합니다.
4. 파일이 하나면 PDF로 바로 다운로드됩니다. 여러 파일은 `xps-converted.zip`이라는 ZIP 압축 파일로 묶입니다.

## 옵션

이 도구는 추가 설정 없이 형식을 직접 변환합니다. 결과물은 XPS 원본의 페이지 크기, 벡터 그래픽, 글꼴, 이미지를 그대로 유지합니다.

## 사용 사례

- XPS 인쇄 드라이버를 기본으로 쓰던 오래된 Windows 시스템에서 받은 XPS 파일 열기
- macOS나 Linux 사용자와 공유하기 위해 Windows 10/11의 OXPS 문서 변환
- 레거시 XPS 파일을 더 널리 지원되는 형식으로 보관
- XPS 기반 정부 또는 기업 문서를 외부 수신자가 열람할 수 있게 하기

## 팁

- `.xps`와 `.oxps` 확장자 모두 자동으로 처리되므로 같은 묶음에 섞어서 올릴 수 있습니다.
- 원래 XPS 파일이 고해상도 인쇄 드라이버로 만들어졌다면 결과 PDF도 그 품질을 유지합니다. 리샘플링은 일어나지 않습니다.

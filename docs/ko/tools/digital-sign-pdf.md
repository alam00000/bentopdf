# 디지털 서명

디지털 서명은 특정 사람이 문서에 서명했고 그 이후 문서가 변경되지 않았음을 보여 주는 암호학적 증거입니다. 단순한 이미지일 뿐인 그려 넣은 서명과 달리, 디지털 서명은 X.509 인증서와 PKCS#7 표준을 사용하여 검증 가능한 진위성과 무결성을 제공합니다.

BentoPDF는 디지털 서명을 전부 브라우저에서 적용합니다. 개인 키는 기기 밖으로 나가지 않습니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 인증서 파일(.pfx, .p12 또는 .pem)을 업로드합니다.
3. 인증서 비밀번호를 입력하여 잠금을 해제합니다. 도구가 인증서의 주체, 발급자, 유효 기간을 표시합니다.
4. 필요하면 서명 메타데이터(사유, 위치, 연락처)를 설정합니다.
5. 필요하면 위치, 크기, 이미지, 텍스트를 사용자 지정할 수 있는 **보이는 서명**을 켭니다.
6. **PDF 서명**을 클릭합니다.

## 지원하는 인증서 형식

| 형식        | 확장자     | 설명                                                                                                    |
| ----------- | ---------- | ------------------------------------------------------------------------------------------------------- |
| **PKCS#12** | .pfx, .p12 | 개인 키와 인증서 체인을 담은 업계 표준 번들입니다. 가장 일반적인 형식입니다.                            |
| **PEM**     | .pem       | 텍스트 기반 형식입니다. 인증서와 개인 키가 한 파일에 모두 있어야 합니다. 암호화된 개인 키를 지원합니다. |

## 보이는 서명 옵션

켜면 PDF 페이지에 보이는 서명 블록이 렌더링됩니다.

- **위치**: X/Y 좌표와 너비/높이(포인트)
- **페이지**: 첫 페이지, 마지막 페이지, 모든 페이지 또는 특정 페이지 번호
- **이미지**: PNG, JPG 또는 WebP 이미지 업로드(손글씨 서명, 회사 직인 등)
- **텍스트**: 색상과 글꼴 크기를 설정할 수 있는 사용자 지정 텍스트. 이미지나 텍스트를 제공하지 않으면 도구가 인증서의 일반 이름(common name)과 현재 날짜로 텍스트를 자동 생성합니다.

## 서명 메타데이터

- **사유**: 문서에 서명한 이유(예: "승인됨", "검토됨")
- **위치**: 서명이 이루어진 장소(예: "New York, NY")
- **연락처**: 서명자에게 연락하는 방법(예: 이메일 주소)

## 인터넷 연결 참고

서명에는 인터넷 연결이 필요할 수 있습니다. 서명 라이브러리가 인증서의 AIA(Authority Information Access) 확장에 포함된 URL에서 인증서 체인을 가져옵니다. 해당 서버에 접속할 수 없으면 체인 검증이 필요한 인증서의 서명이 실패합니다.

## 사용 사례

- 법적 효력이 있는 디지털 서명으로 계약서, 제안서, 합의서 서명
- PKI 기반 인증이 필요한 워크플로에서 공식 문서 인증
- 규정 준수를 위한 PDF 청구서 서명(많은 EU 국가가 디지털 서명된 전자 청구서를 요구합니다)
- 엔지니어링 도면이나 품질 문서에 조직의 승인 추가

## 팁

- 자체 서명 인증서는 테스트에는 쓸 수 있지만 Adobe Reader에서 경고가 표시됩니다. 실제 운영 문서에는 신뢰할 수 있는 인증 기관의 인증서를 사용하세요.
- 보이는 서명은 순전히 시각적인 것입니다. 보이는 블록을 켜든 켜지 않든 암호화 서명은 포함됩니다.
- 서명 검증 도구로 서명된 PDF를 확인하여 서명이 온전한지 검증하세요.

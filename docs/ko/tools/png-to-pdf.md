# PNG를 PDF로

PNG 이미지를 원본 해상도를 유지한 채 PDF로 변환합니다. 각 PNG는 원본 이미지 크기에 맞춰진 별도의 페이지가 됩니다. 투명도는 자동으로 처리됩니다.

## 지원 형식

| 형식 | 확장자 |
| :--- | :----- |
| PNG  | `.png` |

## 사용 방법

1. 업로드 영역을 클릭하거나 PNG 파일을 끌어다 놓습니다. 여러 개를 한 번에 선택할 수 있습니다.
2. 파일 목록을 관리합니다. 필요 없는 파일은 제거하고 더 추가할 수 있습니다.
3. 드롭다운에서 **PDF 품질** 수준을 선택합니다.
4. **PDF로 변환**을 클릭합니다. 출력은 `from_jpgs.pdf`로 다운로드됩니다.

이 도구는 pdf-lib로 각 이미지를 직접 포함합니다. PNG를 기본 방식으로 포함할 수 없는 경우(예: 특이한 색상 프로필) 캔버스를 통해 JPEG로 다시 렌더링하는 방식으로 대체합니다.

## 옵션

**PDF 품질**은 포함하기 전에 적용되는 압축을 조절합니다.

- **높은 품질**: 최소 압축, 가장 큰 파일 크기.
- **중간 품질** (기본값): 크기와 선명도의 좋은 균형.
- **낮은 품질**: 최대 압축, 가장 작은 출력.

## 활용 사례

- 버그 보고서나 문서화를 위해 스크린샷을 여러 페이지 PDF로 변환하기
- UI 디자인 내보내기 파일을 검토용 단일 파일로 묶기
- 다이어그램 내보내기(draw.io, Excalidraw)를 공유 가능한 PDF로 만들기
- 차트 이미지 모음을 보고서로 구성하기

## 팁

- 투명도가 있는 PNG 파일은 PDF에서 흰색 배경이 적용됩니다. 다른 배경이 필요하면 미리 이미지를 편집하세요.
- 선명한 가장자리와 텍스트가 있는 스크린샷과 다이어그램은 높은 품질을 사용하면 JPEG 압축 흔적을 피할 수 있습니다. 중간 또는 낮은 품질은 내부적으로 JPEG로 변환될 수 있습니다.

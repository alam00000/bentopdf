# PDF를 BMP로

PDF의 각 페이지를 BMP(비트맵) 이미지로 변환합니다. BMP는 비압축 형식이므로 품질 손실 없이 픽셀 단위로 정확한 결과를 얻을 수 있지만 파일 크기가 큽니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 업로드합니다.
2. **변환**을 클릭해 파일을 처리합니다.
3. `.bmp` 파일 하나 또는 ZIP 압축 파일이 자동으로 다운로드됩니다.

## 옵션

이 도구에는 설정 가능한 옵션이 없습니다. 페이지는 고정된 2배 배율로 렌더링되어, PDF 원래 페이지 크기의 약 두 배인 이미지가 만들어집니다.

## 출력 형식

- **한 페이지**: `filename.bmp`
- **여러 페이지**: `page_1.bmp`, `page_2.bmp` 등이 담긴 `filename_bmps.zip`

## 활용 사례

- BMP 입력만 받는 레거시 시스템이나 장비에 PDF 페이지 전달하기
- 특정 인쇄 워크플로우를 위한 비압축 이미지 준비하기
- 원시 픽셀 데이터가 필요한 이미지 처리 도구의 입력으로 비트맵 출력 사용하기

## 팁

- BMP 파일은 압축 없이 원시 픽셀 데이터를 저장하므로 매우 큽니다. 대부분의 용도에서는 [PDF를 PNG로](./pdf-to-png)가 무손실 품질에 훨씬 작은 파일을 제공합니다.
- 대상 시스템이 PNG나 TIFF를 받는다면 디스크 공간을 아끼기 위해 해당 형식을 선택하세요.

# PDF를 WebP로

PDF의 각 페이지를 WebP 이미지로 변환합니다. WebP는 같은 체감 화질에서 보통 JPG보다 파일이 25-35% 작아 웹 용도에 좋은 선택입니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 업로드합니다.
2. **품질** 슬라이더를 조절합니다.
3. **변환**을 클릭해 파일을 처리합니다.
4. `.webp` 파일 하나 또는 ZIP 압축 파일이 자동으로 다운로드됩니다.

## 옵션

- **품질**: 0%에서 100%까지의 슬라이더(기본값 85%). 손실 압축 수준을 조절합니다. 값이 높을수록 더 많은 세부 사항이 유지됩니다.

페이지는 내부적으로 2배 배율로 렌더링되어 PDF 원래 크기의 약 두 배인 이미지가 만들어집니다.

## 출력 형식

- **한 페이지**: `filename.webp`
- **여러 페이지**: `page_1.webp`, `page_2.webp` 등이 담긴 `filename_webps.zip`

## 활용 사례

- 대역폭이 중요한 웹사이트용 페이지 미리보기 준비하기
- 소셜 미디어용으로 전단지나 브로슈어의 가벼운 이미지 버전 만들기
- 여러 페이지 문서를 웹에 최적화된 이미지 세트로 일괄 변환하기

## 팁

- WebP는 모든 최신 브라우저에서 지원됩니다. 레거시 호환이 필요하면 [PDF를 JPG로](./pdf-to-jpg)를 사용하세요.
- 품질 80-85%는 보통 화면에서 원본과 구분되지 않으면서 파일 크기를 작게 유지합니다.

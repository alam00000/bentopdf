# 빈 페이지 추가

지정한 위치에 빈 페이지를 PDF에 삽입합니다. 빈 페이지를 넣을 위치와 개수를 직접 정할 수 있습니다.

## 사용 방법

1. PDF 파일을 업로드합니다. 도구에 페이지 수가 표시됩니다.
2. 빈 페이지를 삽입할 **위치**를 입력합니다. 맨 앞에 삽입하려면 `0`을, 맨 끝에 추가하려면 전체 페이지 수를 입력합니다.
3. 추가할 빈 페이지의 **개수**를 입력합니다(기본값은 1).
4. 처리 버튼을 클릭합니다. 빈 페이지가 삽입된 PDF가 다운로드됩니다.

## 기능

- 문서의 처음, 중간, 끝 등 원하는 위치에 삽입
- 한 번에 여러 개의 빈 페이지 추가
- 업로드한 PDF의 페이지 수에 따라 위치 안내가 동적으로 갱신
- 표준 A4 크기의 빈 페이지

## 활용 사례

- 합쳐진 문서의 섹션 사이에 빈 구분 페이지 추가
- 양면 인쇄 정렬을 위한 빈 페이지 삽입
- 인쇄한 학습 자료에 손글씨 메모 공간 확보
- 최소 페이지 수 요건을 맞추기 위한 페이지 채우기

## 팁

- 위치 `0`은 첫 페이지 앞에 삽입하고, 전체 페이지 수와 같은 위치는 마지막 페이지 뒤에 추가합니다.
- 빈 페이지가 아니라 내용을 특정 위치에 삽입해야 한다면 [PDF 멀티 도구](./pdf-multi-tool)로 지정한 페이지 뒤에 다른 PDF를 삽입하세요.

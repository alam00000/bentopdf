# PDF를 SVG로

PDF의 각 페이지를 SVG(Scalable Vector Graphics) 파일로 변환합니다. 래스터 형식과 달리 SVG는 벡터 경로, 텍스트, 도형을 유지하므로 출력이 어떤 크기로 확대해도 깨지지 않습니다. PyMuPDF를 기반으로 합니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 하나 이상 업로드합니다. 여러 파일을 추가하고 개별적으로 관리할 수 있습니다.
2. **변환**을 클릭해 업로드한 모든 파일을 처리합니다.
3. 파일 하나에 페이지 하나인 변환은 독립된 `.svg`로 다운로드됩니다. 그 외에는 ZIP 압축 파일로 다운로드됩니다.

## 옵션

이 도구에는 설정 가능한 옵션이 없습니다. 각 페이지는 PyMuPDF의 기본 벡터 내보내기로 SVG로 변환됩니다.

## 출력 형식

- **파일 하나, 페이지 하나**: `filename.svg`
- **파일 하나, 페이지 여러 개**: `page_1.svg`, `page_2.svg` 등이 담긴 `filename_svg.zip`
- **파일 여러 개**: 원본 문서 이름별로 정리된 파일이 담긴 `pdf_to_svg.zip`

## 활용 사례

- PDF 보고서의 벡터 다이어그램, 차트, 일러스트를 웹 페이지용으로 추출하기
- Inkscape나 Illustrator 같은 벡터 편집기에서 PDF 페이지 콘텐츠 편집하기
- 반응형 웹 애플리케이션에 확장 가능한 페이지 미리보기 삽입하기
- PDF 브로슈어에서 선명한 가장자리를 유지한 채 로고나 그래픽 추출하기

## 팁

- SVG는 벡터 콘텐츠가 있는 PDF에서 가장 잘 작동합니다. 스캔 문서나 이미지가 많은 PDF는 래스터 데이터가 포함된 큰 SVG 파일을 만듭니다.
- 이미지가 많은 PDF의 래스터 출력에는 [PDF를 PNG로](./pdf-to-png) 또는 [PDF를 JPG로](./pdf-to-jpg)를 대신 사용하세요.
- 이 도구는 일괄 변환을 지원합니다. 여러 PDF를 한 번에 업로드해 한꺼번에 변환하세요.

# 페이지 번호

PDF의 모든 페이지에 보이는 페이지 번호를 추가합니다. 위치, 형식, 글꼴 크기, 색상을 선택하면 나머지는 도구가 처리합니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 나타나는 옵션 패널에서 페이지 번호 설정을 지정합니다.
3. **페이지 번호 추가**를 클릭해 처리합니다.
4. 번호가 매겨진 PDF가 자동으로 다운로드됩니다.

## 옵션

- **위치**: 페이지 번호가 표시될 위치를 선택합니다. 하단 가운데, 하단 왼쪽, 하단 오른쪽, 상단 가운데, 상단 왼쪽, 상단 오른쪽 중에서 고릅니다.
- **형식**: 단순 번호(1, 2, 3...) 또는 "X / Y 페이지" 형식(1 / 5, 2 / 5...) 중에서 선택합니다.
- **글꼴 크기**: 페이지 번호 텍스트의 크기를 설정합니다. 기본값은 12입니다.
- **색상**: 색상 선택기로 페이지 번호 텍스트의 색상을 자유롭게 고릅니다.

## 기능

- 모든 모서리와 가운데 위치를 포함한 여섯 가지 위치 옵션
- 단순 순차 번호 또는 "X / Y 페이지"의 두 가지 번호 형식
- 6~72포인트 범위의 글꼴 크기 설정
- 텍스트 색상을 위한 전체 색상 선택기
- 페이지 크기와 관계없이 번호가 안전 영역 안에 머물도록 여백을 자동 처리

## 활용 사례

- 페이지 참조가 필요한 인쇄용 문서 준비하기
- 여러 원본 파일로 만든 병합 PDF에 페이지 번호 추가하기
- 배포 전에 프레젠테이션 유인물에 번호 매기기
- 법률 문서나 계약서에 순차 번호 추가하기

## 팁

- "X / Y 페이지" 형식은 제안서나 보고서처럼 독자가 전체 분량을 알아야 하는 문서에 유용합니다.
- 앞부분에 로마 숫자를 쓰는 것처럼 섹션마다 다른 번호 스타일이 필요하다면 [페이지 레이블 추가](./add-page-labels) 도구를 사용하세요.

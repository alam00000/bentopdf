# PDF 소책자

PDF 페이지를 소책자 면부착 순서로 재배열합니다. 양면 인쇄 후 반으로 접으면 페이지가 올바른 읽기 순서가 됩니다. 중철 소책자와 진(zine)에 쓰이는 레이아웃입니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 소책자 설정을 지정합니다. 출력 페이지 크기와 방향을 선택합니다.
3. **미리보기 생성**을 클릭해 각 용지에 페이지가 어떻게 배치되는지 확인합니다.
4. 각 실물 용지의 앞면과 뒷면 페이지 배정을 보여주는 미리보기를 검토합니다.
5. **다운로드**를 클릭해 소책자 순서로 재배열된 PDF를 저장합니다.

## 기능

- 중철 제본을 위한 자동 페이지 재정렬
- 출력 페이지 크기 설정 가능
- 다운로드 전에 소책자 레이아웃을 시각적으로 미리보기
- 페이지 수가 홀수이면 필요한 곳에 빈 페이지 삽입
- 원본 페이지를 소책자 용지 크기에 맞게 크기 조정

## 활용 사례

- 일반 PDF로 인쇄 가능한 소책자나 진 만들기
- 사내 인쇄용 학회 프로그램이나 행사 안내서 준비하기
- 접이식 카드나 작은 카탈로그 만들기
- 수제본용 소형 책자나 시집 제작하기

## 팁

- 깔끔한 소책자를 위해 원본 PDF의 페이지 수는 4의 배수가 이상적입니다. 그렇지 않으면 마지막 용지를 채우기 위해 빈 페이지가 자동으로 추가됩니다.
- 프린터의 "짧은 가장자리 넘김" 설정으로 양면 인쇄한 뒤, 모든 용지를 함께 접어 책등에 스테이플러로 고정하세요.
- 소책자 순서 없이 한 용지에 여러 페이지만 배치하려면 [N-Up PDF](./n-up-pdf)를 사용하세요.

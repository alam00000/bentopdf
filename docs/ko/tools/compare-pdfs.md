# PDF 비교

두 개의 PDF를 업로드하면 무엇이 달라졌는지 정확히 확인할 수 있습니다. 이 도구는 페이지를 똑똑하게 짝지어 텍스트, 이미지, 주석, 머리글, 서식의 차이를 감지하고 나란히 보기 또는 오버레이 보기로 표시합니다.

## 사용 방법

1. PDF 파일 두 개를 업로드합니다. 원본(왼쪽)과 수정본(오른쪽)입니다.
2. 도구가 콘텐츠 시그니처를 사용해 문서 간 페이지를 짝짓습니다.
3. 보기 모드를 선택합니다. **나란히 보기** 또는 **오버레이**.
4. 페이지 이동 컨트롤로 페이지 쌍 사이를 이동합니다.
5. 차이점이 강조되고 분류됩니다. 필터 패널로 특정 변경 유형에 집중할 수 있습니다.
6. 필요하면 비교 결과를 PDF 보고서로 내보냅니다.

## 기능

- 콘텐츠 유사도 기반 자동 페이지 짝짓기
- 나란히 보기와 오버레이 비교 보기
- 변경 분류: 텍스트, 이미지, 머리글/바닥글, 주석, 서식, 배경
- 특정 변경 유형을 표시하거나 숨기는 분류별 필터 토글
- 쿼리 필터링을 지원하는 텍스트 변경 검색
- 스캔 문서 비교를 위한 OCR 지원
- 세부 검사를 위한 확대/축소 컨트롤
- 나란히 보기에서 패널 간 동기화 스크롤
- 비교 결과를 PDF로 내보내기

## 옵션

| 옵션          | 설명                                                                  |
| ------------- | --------------------------------------------------------------------- |
| **보기 모드** | 나란히 보기 또는 오버레이                                             |
| **OCR**       | 스캔 문서 비교를 위한 OCR 사용/사용 안 함                             |
| **OCR 언어**  | OCR 텍스트 추출에 사용할 언어                                         |
| **분류 필터** | 텍스트, 이미지, 머리글/바닥글, 주석, 서식, 배경 변경의 표시 여부 전환 |
| **변경 범위** | 오버레이 모드에서 모든 변경 또는 콘텐츠만 필터링                      |
| **확대/축소** | 세부 검사를 위한 배율 조정                                            |

## 사용 사례

- 계약서 개정본을 검토하여 버전 간 정확히 무엇이 바뀌었는지 확인
- 디자인 목업을 비교하여 PDF 내보내기가 기대와 일치하는지 확인
- 모든 수정 사항을 추적해야 하는 규제 산업에서 문서 변경 감사
- PDF 변환 과정이 원본 내용을 정확히 보존했는지 확인
- 번역 문서를 원본과 비교하여 레이아웃 변경 확인

## 팁

- 오버레이 보기는 두 문서를 겹쳐 놓기 때문에 위치가 달라진 요소나 크기가 바뀐 이미지 같은 공간적 차이가 바로 눈에 띕니다.
- 텍스트 레이어가 없는 스캔 문서를 비교할 때는 OCR을 켜세요. 비교 엔진이 페이지 이미지에서 텍스트를 추출합니다.
- 분류 필터를 사용해 중요한 것에 집중하세요. 예를 들어 텍스트 내용의 차이만 필요하다면 서식 변경을 숨기세요.

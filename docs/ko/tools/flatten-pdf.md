# PDF 평탄화

평탄화는 양식 필드, 드롭다운, 체크박스, 주석, 하이라이트, 스티커 메모 같은 대화형 요소를 페이지 콘텐츠에 직접 합칩니다. 겉모습은 그대로지만 더 이상 편집하거나 추출할 수 없습니다. 작성한 양식을 인쇄한 뒤 다시 스캔하는 것과 같지만, 품질은 완벽하게 유지됩니다.

## 사용 방법

1. PDF 파일을 하나 이상 업로드하세요.
2. **PDF 평탄화**를 클릭하세요.
3. 파일 하나는 바로 다운로드되고, 여러 파일은 ZIP 아카이브로 제공됩니다.

이 도구는 pdf-lib로 양식 필드를 평탄화하고(`form.flatten()` 사용), 전용 주석 평탄화기로 주석을 페이지 스트림에 합칩니다. 두 작업은 한 번에 처리됩니다.

## 평탄화되는 항목

- **양식 필드**: 텍스트 입력, 체크박스, 라디오 버튼, 드롭다운, 서명 필드
- **주석**: 댓글, 하이라이트, 취소선, 밑줄, 스티커 메모, 도장, 잉크 주석
- **대화형 요소**: 버튼, 동작 트리거

## 그대로 유지되는 항목

- 텍스트 콘텐츠(선택 및 검색 가능)
- 이미지와 그래픽
- 페이지 레이아웃과 크기
- 북마크와 목차
- 하이퍼링크(주석 기반이 아닌 경우)

## 활용 사례

- 작성을 마친 양식을 잠가 수신자가 제출된 답변을 바꾸지 못하게 하기
- 대화형 요소가 필요 없는 보관용 PDF 준비하기
- 뷰어마다 주석이 다르게 표시되는 문제 해결하기
- 서명된 문서가 서명 후 수정되지 않도록 보장하기
- 양식 필드 정의와 주석 객체를 제거하여 파일 크기 줄이기

## 팁

- 모든 편집이 끝난 뒤에 평탄화하세요. 평탄화를 되돌릴 방법은 없습니다.
- 평탄화와 함께 메타데이터, JavaScript, 첨부파일까지 제거해야 한다면 PDF 정리 도구를 사용하세요. 평탄화도 옵션에 포함되어 있습니다.
- 일부 PDF에서 "양식을 찾을 수 없음"이 표시될 수 있습니다. 문서에 주석만 있고 양식 필드가 없다면 정상입니다.

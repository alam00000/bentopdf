# 색상 조정

PDF를 위한 본격적인 색 보정 도구입니다. 밝기, 대비, 채도, 색조 이동, 색온도, 틴트, 감마, 세피아의 여덟 가지 매개변수를 각각 독립적으로 조정할 수 있으며, 슬라이더를 움직일 때마다 미리보기가 실시간으로 갱신됩니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 첫 페이지 미리보기와 색상 설정 패널이 있는 편집기가 열립니다.
3. 슬라이더를 움직여 각 색상 매개변수를 조정합니다. 미리보기가 실시간으로 갱신됩니다.
4. **초기화**를 클릭하면 모든 슬라이더가 기본 위치로 돌아갑니다.
5. **적용**을 클릭하여 모든 페이지를 처리하고 조정된 PDF를 다운로드합니다.

## 옵션

- **밝기** -- 페이지 전체를 밝게 하거나 어둡게 합니다(-100에서 +100).
- **대비** -- 밝은 영역과 어두운 영역의 차이를 키우거나 줄입니다(-100에서 +100).
- **채도** -- 색의 강도를 높이거나 낮춥니다(-100에서 +100). -100으로 설정하면 회색조 결과가 나옵니다.
- **색조 이동** -- 색상환을 회전하여 모든 색을 일괄적으로 이동합니다.
- **색온도** -- 색을 따뜻하게(노랑/주황) 또는 차갑게(파랑) 이동합니다.
- **틴트** -- 녹색 또는 마젠타 색조를 더합니다.
- **감마** -- 감마 곡선으로 중간 톤의 밝기를 조정합니다. 1.0 미만이면 중간 톤이 어두워지고, 1.0 초과면 밝아집니다.
- **세피아** -- 고전적인 세피아 톤 효과를 적용합니다. 값이 높을수록 갈색이 더 강해집니다.

## 기능

- 독립적으로 조정 가능한 여덟 가지 색상 매개변수
- 슬라이더 변경에 즉시 반응하는 실시간 미리보기
- 기본값으로 빠르게 되돌리는 초기화 버튼
- 문서의 모든 페이지 처리
- 텍스트, 이미지, 그래픽 등 모든 PDF 콘텐츠에 사용 가능

## 활용 사례

- 어두운 스캔본을 밝게 하거나 과다 노출된 페이지 보정
- 인쇄 전에 컬러 문서의 채도를 낮춰 잉크 사용량 절감
- 증명서나 상장에 세피아 톤을 적용해 고풍스러운 느낌 연출
- PDF에 삽입된 사진의 색온도 보정
- 바래거나 품질이 낮은 스캔 문서의 대비 강화

## 팁

- 빠르게 회색조로 변환하려면 채도 슬라이더를 -100까지 끝까지 끌어 내리세요.
- 감마 슬라이더는 중간 톤이 너무 어둡거나 밝은 스캔 문서의 가독성을 개선하는 데 특히 유용합니다.
- 다른 이미지 효과 도구와 마찬가지로 각 페이지를 래스터화합니다. 출력은 이미지 기반이 되므로 텍스트를 선택할 수 없습니다.

# 페이지 크기 통일

여러 출처의 파일을 합친 PDF는 페이지 크기가 제각각인 경우가 많습니다. Letter와 A4가 섞여 있거나 표준에서 완전히 벗어난 크기가 있기도 합니다. 이 도구는 모든 페이지를 하나의 목표 크기로 맞추고, 필요에 따라 콘텐츠를 맞춤 또는 채움 방식으로 조정합니다.

## 사용 방법

1. PDF 파일을 업로드하세요.
2. 드롭다운에서 **목표 페이지 크기**를 선택하세요(A4, Letter, Legal, A3, A5, Tabloid 또는 사용자 지정).
3. **방향**을 선택하세요. 자동은 각 페이지의 원래 방향을 유지하며, 세로 또는 가로로 고정할 수도 있습니다.
4. **콘텐츠 배율** 모드를 고르세요. 맞춤은 모든 콘텐츠를 보존하며 여백이 생길 수 있고, 채움은 페이지를 가득 채우며 가장자리가 잘릴 수 있습니다.
5. 필요하면 추가된 여백에 적용할 **배경색**을 설정하세요.
6. **페이지 크기 통일**을 클릭하세요.

## 옵션

- **표준 크기**: A4, Letter, Legal, A3, A5, Tabloid
- **사용자 지정 크기**: 너비와 높이를 인치 또는 밀리미터로 입력
- **방향**: 자동, 세로, 가로
- **배율 모드**: 맞춤 또는 채움(자르기)
- **배경색**: 여백을 채울 아무 색상

## 활용 사례

- 서로 다른 스캐너에서 가져온 페이지가 섞인 병합 PDF 정리하기
- 미국 Letter 문서를 해외 배포용 A4로 변환하기
- 일정한 재단 크기가 필요한 인쇄용 PDF 준비하기
- 표준에서 약간 벗어난 페이지 바로잡기(예: 8.5 x 11 대신 8.49 x 11.02 인치)

## 팁

- 콘텐츠 손실이 없어야 한다면 맞춤 모드를 사용하세요. 채움 모드는 더 깔끔해 보이지만 가장자리가 잘릴 수 있습니다.
- 페이지 크기 정보 도구로 결과를 확인하여 모든 페이지가 목표 크기와 일치하는지 점검하세요.
- 기본 배경색은 흰색입니다. 문서에 어두운 여백이 있다면 어두운 색으로 바꾸세요.

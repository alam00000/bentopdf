# 페이지 분할

개별 PDF 페이지를 가로 또는 세로로 잘라 반으로 나눕니다. 한 페이지에 별도의 페이지로 분리해야 할 내용이 들어 있을 때 유용합니다. 예를 들어 2단 레이아웃이 넓은 한 페이지로 스캔된 경우입니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 나누기 방향을 선택합니다. **세로**(왼쪽/오른쪽 절반) 또는 **가로**(위/아래 절반).
3. 필요하면 나눌 페이지를 제한하는 페이지 범위를 지정합니다. 비워 두면 모든 페이지를 나눕니다.
4. 처리 버튼을 클릭하여 나눈 PDF를 생성합니다.

## 기능

- 세로 나누기: 각 페이지를 왼쪽과 오른쪽 절반으로 나눔
- 가로 나누기: 각 페이지를 위쪽과 아래쪽 절반으로 나눔
- 특정 페이지만 선택적으로 나누는 페이지 범위 필터
- 대상이 아닌 페이지는 그대로 통과
- 다시 렌더링하지 않고 콘텐츠 품질 유지

## 사용 사례

- 2쪽씩 스캔된 페이지 분리(예: 한 장에 왼쪽과 오른쪽 페이지가 함께 있는 책 스캔)
- 내용이 나란히 있는 가로형 PDF를 개별 세로형 페이지로 나누기
- 긴 인포그래픽이나 포스터를 위쪽과 아래쪽 섹션으로 나누기
- 와이드 포맷 문서를 표준 용지 인쇄용으로 준비

## 팁

- 페이지의 콘텐츠 분포가 고르지 않아도 나누기는 정확히 중간 지점에서 이루어집니다. 비대칭으로 나누려면 [PDF 자르기](./crop-pdf)를 대신 고려하세요.
- 나누기 전이나 후에 페이지를 회전해야 한다면 이 도구를 [PDF 회전](./rotate-pdf)과 함께 사용하세요.

# PDF 압축

PDF 파일을 망가뜨리지 않고 줄입니다. PDF 압축은 BentoPDF의 자체 압축 엔진인 [Hyper Compress](https://www.bentopdf.com/hyper-compress)로 구동됩니다. 이미지를 다시 압축하고, 글꼴을 서브셋으로 만들어 병합하며, 내장 썸네일과 비공개 애플리케이션 데이터 같은 불필요한 용량을 제거합니다. PDF는 완전히 기능을 유지합니다. 텍스트는 계속 선택할 수 있고 링크와 양식 필드도 계속 작동합니다.

Hyper Compress는 WebAssembly로 컴파일되어 BentoPDF에 포함되어 있으므로 별도 설정 없이 오프라인과 외부와 단절된 환경에서도 압축이 작동합니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 하나 이상 업로드합니다.
2. **압축 수준**을 선택합니다. 낮음, 중간, 높음 또는 무손실.
3. 필요하면 **목표 파일 크기**를 입력하거나, **사용자 지정 설정**을 펼쳐 **회색조로 변환**을 포함한 세부 설정을 조정합니다.
4. **PDF 압축**을 클릭합니다. 파일이 여러 개이면 하나의 ZIP으로 다운로드됩니다.

## 특수 문서

- **디지털 서명된 PDF**는 변경하면 서명이 무효가 되므로 그대로 반환됩니다. 사용자 지정 설정에서 **콘텐츠 보호 재정의**를 켜면 서명을 제거하고 압축합니다. 화면에 보이는 서명은 페이지에 남지만 파일은 더 이상 서명된 상태가 아닙니다.
- **PDF/A 파일**은 압축 후 PDF/A 표시를 잃습니다. 더 이상 충족하지 못하는 준수 상태를 파일이 주장하지 않도록 하기 위해서입니다. 대신 파일의 준수 상태를 유지하려면 사용자 지정 설정에서 **PDF/A 유지**를 켜세요.
- **비밀번호로 보호된 PDF**는 파일 카드에 비밀번호 필드가 표시됩니다. 여기에 비밀번호를 입력하면 Hyper Compress가 별도의 잠금 해제 단계 없이 파일을 직접 엽니다. 잠긴 파일이 둘 이상이면 하나의 공유 필드가 같은 비밀번호를 쓰는 모든 파일의 잠금을 해제합니다. 압축된 사본에는 비밀번호가 없으므로, 다시 설정하려면 [PDF 보호](./protect-pdf)를 사용하세요.
- **텍스트 레이어가 없는 스캔본**은 사용자 지정 설정의 **페이지 래스터화**로 더 줄일 수 있습니다. 이 옵션은 각 페이지를 최적화된 이미지 하나로 바꿉니다. OCR 처리된 스캔본을 포함해 선택 가능한 텍스트가 있는 문서에서는 **콘텐츠 보호 재정의**를 켜지 않는 한 건너뜁니다. 켜면 텍스트 페이지도 이미지가 되어 텍스트를 선택할 수 없고 링크도 작동하지 않습니다.

## 압축 수준

| 수준       | 이미지 품질      | 최대 해상도 | 적합한 용도            |
| ---------- | ---------------- | ----------- | ---------------------- |
| **낮음**   | 80               | 200 DPI     | 시각적 품질 보존       |
| **중간**   | 50               | 150 DPI     | 일반 문서              |
| **높음**   | 20               | 72 DPI      | 이메일 첨부, 웹 업로드 |
| **무손실** | 이미지 변경 없음 | 변경 없음   | 보관용 사본            |

높음은 14개의 표준 PDF 글꼴과, 안전한 경우 Arial 같은 유사 글꼴의 내장도 해제합니다.

## 목표 파일 크기

KB 또는 MB 단위로 크기를 입력하면 Hyper Compress가 선택한 수준에서 시작하여 그 크기에 맞는 최선의 이미지 품질을 찾습니다. 문서가 그만큼 작아질 수 없으면 만들 수 있는 가장 작은 버전과 함께 그 사실을 알리는 메시지가 표시됩니다. [PDF를 1MB로 압축](https://www.bentopdf.com/compress-pdf-to-1mb) 같은 전용 페이지는 목표가 이미 입력된 상태로 열립니다.

## 사용자 지정 설정

사용자 지정 설정 패널을 펼쳐 Hyper Compress를 직접 조정합니다. 압축 수준을 선택하면 이 값들이 해당 수준의 값으로 초기화되고, 하나라도 수정하면 수준이 사용자 지정으로 바뀝니다.

- **콘텐츠 보호 재정의**: 기본적으로 Hyper Compress는 서명된 PDF를 건드리지 않고 텍스트가 있는 페이지를 래스터화하지 않습니다. 이 옵션을 켜면 둘 다 우회합니다. 수준을 바꿔도 켜진 상태로 유지됩니다.

- **이미지**: 이미지 품질, 최대 해상도, 강제 리샘플링, 색상 감소, 보이지 않는 이미지 영역 잘라내기, 대체 이미지 제거, 색상 프로필 단순화, JPEG 2000, 무손실 모드
- **글꼴**: 서브셋 생성, 중복 병합, 표준 글꼴과 유사 글꼴의 내장 해제
- **콘텐츠**: 주석, 양식 필드, 링크 평면화
- **정리**: 썸네일, 애플리케이션 데이터, 아티클 스레드, 웹 캡처 정보, 구조 트리, 출력 인텐트 제거
- **래스터화**: 이미지만 있는 스캔본을 위해 페이지를 이미지로 교체. 문서에 선택 가능한 텍스트가 있으면 건너뜀
- **출력**: PDF/A 유지, 지원하는 PDF 2.0 리더를 위한 Brotli 압축

## 사용 사례

- 50MB 보고서를 이메일 첨부 한도 이하로 줄이기
- 목표 파일 크기로 스캔본을 포털의 엄격한 업로드 한도 이하로 맞추기
- 웹사이트 다운로드를 빠르게 하기 위해 마케팅 PDF 최적화
- 저장 비용이 중요한 대규모 문서 세트 보관
- 메신저 앱으로 PDF를 공유할 때 모바일 데이터 사용량 절감

## 팁

- 중간으로 시작하세요. 결과가 여전히 크면 목표 파일 크기를 설정하거나 높음으로 올리세요.
- 텍스트 레이어가 없는 스캔본은 사용자 지정 설정에서 페이지 래스터화를 켜세요.
- 사용자 지정 설정의 회색조로 변환은 색상이 많은 문서의 파일 크기를 줄일 수 있습니다.

# WebP를 PDF로

Google의 WebP 이미지 형식을 PDF로 변환합니다. 웹에서 내려받은 이미지가 WebP 형식이라 인쇄나 공유를 위해 더 널리 쓰이는 형식이 필요할 때 특히 유용합니다.

## 지원 형식

| 형식 | 확장자  |
| :--- | :------ |
| WebP | `.webp` |

## 작동 방식

1. 업로드 영역을 클릭하거나 WebP 파일을 끌어다 놓습니다.
2. 파일 목록을 확인하고 필요 없는 파일을 제거합니다.
3. **PDF 품질** 수준을 선택합니다.
4. **PDF로 변환**을 클릭합니다. 결과물은 `from_webps.pdf`로 다운로드됩니다.

내부적으로 각 WebP 이미지는 브라우저의 canvas API로 디코딩된 다음 pdf-lib를 사용해 PDF에 삽입됩니다. 따라서 WebP 디코딩을 지원하는 모든 브라우저(최신 브라우저는 모두 해당)에서 변환이 작동합니다.

## 옵션

**PDF 품질**은 이미지를 삽입할 때의 압축을 조절합니다.

- **높은 품질**: 가장 많은 디테일을 유지합니다.
- **중간 품질**(기본값): 균형 잡힌 결과물.
- **낮은 품질**: 가장 작은 파일 크기.

## 사용 사례

- 웹에서 내려받아 WebP로 저장된 이미지를 인쇄 가능한 PDF로 변환
- Chrome이나 Edge의 WebP 스크린샷을 문서로 묶기
- 기본값이 WebP인 디자인 도구에서 내보낸 이미지로 PDF 포트폴리오 만들기
- WebP 이미지를 더 널리 읽을 수 있는 형식으로 보관

## 팁

- WebP는 PDF에 삽입되기 전에 내부적으로 PNG로 디코딩되므로, 무손실 WebP 이미지는 높은 품질 설정에서 품질이 유지됩니다.
- WebP와 다른 이미지 형식이 섞여 있다면 대신 [이미지를 PDF로](./image-to-pdf) 도구를 사용하세요. 모든 형식을 한 번에 받습니다.

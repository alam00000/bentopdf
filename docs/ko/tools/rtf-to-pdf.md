# RTF를 PDF로

Rich Text Format 문서를 PDF로 변환합니다. RTF는 거의 모든 워드 프로세서에서 지원하는 크로스 플랫폼 문서 형식입니다. 이 도구는 브라우저 기반 LibreOffice 엔진으로 RTF 파일을 서식 그대로 렌더링하며, 굵게, 기울임, 표, 삽입된 이미지가 모두 PDF에 반영됩니다.

## 지원 형식

| 형식 | 확장자 | MIME 유형                     |
| :--- | :----- | :---------------------------- |
| RTF  | `.rtf` | `text/rtf`, `application/rtf` |

## 사용 방법

1. 업로드 영역을 클릭하거나 RTF 파일을 하나 이상 끌어다 놓습니다.
2. 파일 목록을 확인합니다. 필요에 따라 파일을 추가하거나 제거합니다.
3. **PDF로 변환**을 클릭합니다. 처음 사용할 때 LibreOffice 엔진이 초기화된 후 각 파일을 처리합니다.
4. 파일이 하나면 PDF로 바로 다운로드됩니다. 여러 파일은 `rtf-converted.zip`으로 제공됩니다.

## 옵션

이 도구에는 추가 설정이 없습니다. 변환 시 원본 RTF 서식이 유지됩니다.

## 출력

| 입력 수       | 출력                                                       |
| :------------ | :--------------------------------------------------------- |
| 파일 1개      | PDF 한 개 다운로드 (예: `letter.pdf`)                      |
| 파일 2개 이상 | 파일당 PDF 하나를 담은 ZIP 압축 파일 (`rtf-converted.zip`) |

## 활용 사례

- 오래된 워드 프로세서의 RTF 문서를 최신 PDF로 변환
- RTF 이메일 템플릿을 PDF 미리보기로 변환
- 법률 또는 의료 소프트웨어 시스템에서 나온 RTF 출력 처리
- 문서 관리 시스템의 RTF 파일을 보관용 PDF로 일괄 변환

## 팁

- LibreOffice 엔진은 한 번 로드된 후 캐시됩니다. 세션의 첫 변환은 몇 초 더 걸리고 이후는 더 빠릅니다.
- OLE 개체가 삽입된 RTF 파일은 모든 개체가 완벽하게 렌더링되지 않을 수 있습니다. 일반 텍스트, 이미지, 표준 서식은 안정적으로 변환됩니다.
- RTF 파일을 Microsoft Word로 만들었다면 DOC, DOCX와 함께 RTF도 지원하는 [Word를 PDF로](./word-to-pdf) 도구로 바로 변환할 수도 있습니다.

# PDF를 Word로

PDF 파일을 편집 가능한 Word(`.docx`) 문서로 변환합니다. 이 도구는 PyMuPDF로 문서 내용을 재구성하여 텍스트, 기본 서식, 레이아웃을 유지합니다. 단일 변환과 일괄 변환을 지원합니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 하나 이상 업로드합니다. 목록에서 파일을 더 추가하거나 개별 파일을 제거할 수 있습니다.
2. **변환**을 클릭해 처리를 시작합니다.
3. 파일 하나는 `filename.docx`로 다운로드됩니다. 여러 파일은 `converted-documents.zip`으로 묶입니다.

## 옵션

이 도구에는 설정 가능한 옵션이 없습니다. 각 PDF는 PyMuPDF의 내장 변환 엔진으로 DOCX로 변환됩니다.

## 출력 형식

- **파일 하나**: `filename.docx`
- **파일 여러 개**: 입력한 PDF마다 `.docx` 하나가 담긴 `converted-documents.zip`

## 활용 사례

- 받은 PDF에서 수정이 필요한 텍스트 편집하기
- 보관된 PDF 보고서를 동료가 Microsoft Word나 Google Docs에서 편집할 수 있는 형식으로 변환하기
- PDF 계약서나 제안서의 내용을 수정 표시용으로 Word로 가져오기
- 레거시 PDF 문서를 편집 가능한 형식으로 이전하기

## 팁

- 다단 텍스트, 포함된 양식, 그래픽이 많은 복잡한 레이아웃은 완벽하게 변환되지 않을 수 있습니다. 출력을 검토하고 워드 프로세서에서 서식을 조정하세요.
- 스캔한 PDF(이미지만 있는 경우)는 비어 있거나 내용이 거의 없는 DOCX 파일이 만들어집니다. 먼저 OCR로 텍스트 레이어를 추가하세요.
- 일괄 모드는 폴더 전체의 PDF를 변환할 때 효율적입니다. 한 번에 모두 업로드하세요.

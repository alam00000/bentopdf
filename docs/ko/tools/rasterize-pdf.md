# PDF 래스터화

래스터화는 PDF의 각 페이지를 이미지로 변환한 뒤 그 이미지들을 다시 PDF로 조립합니다. 결과물은 원본과 똑같아 보이지만 선택 가능한 텍스트, 상호작용 요소, 편집 가능한 레이어가 없습니다. 사실상 고품질 복사본입니다.

## 사용 방법

1. PDF 파일을 하나 이상 업로드합니다.
2. 래스터화 출력의 **DPI**(해상도)를 설정합니다.
3. **이미지 형식**을 선택합니다. 무손실 품질은 PNG, 더 작은 파일은 JPEG입니다.
4. 필요하면 **흑백으로 변환**을 선택합니다.
5. **PDF 래스터화**를 클릭합니다. 여러 파일은 ZIP으로 다운로드됩니다.

## 옵션

| 설정            | 값                           | 기본값 |
| --------------- | ---------------------------- | ------ |
| **DPI**         | 72, 150, 200, 300, 600       | 150    |
| **이미지 형식** | PNG (무손실), JPEG (더 작음) | PNG    |
| **흑백**        | 켜기/끄기                    | 끄기   |

## DPI 가이드

- **72**: 화면에서만 볼 때, 가장 작은 파일 크기
- **150**: 일반 용도에 적합한 균형
- **200**: 더 선명한 텍스트, 보통 파일 크기
- **300**: 인쇄 품질 출력
- **600**: 고품질 보관 또는 전문 인쇄

## 활용 사례

- 공유 전에 기밀 문서의 텍스트 추출 방지
- 텍스트를 픽셀로 변환하여 글꼴 의존 문제 해결
- 복잡한 레이어나 투명도 때문에 뷰어마다 다르게 보이는 PDF의 "평면" 버전 만들기
- 이미지 기반 입력만 받는 시스템용 PDF 준비
- PDF를 순수 이미지로 줄여 숨겨진 내용(변경 내역이나 양식 데이터 등) 제거

## 팁

- PNG 150 DPI가 안정적인 기본값입니다. 인쇄용 출력이 필요하거나 세부를 확대해야 할 때만 더 높이세요.
- JPEG는 파일이 눈에 띄게 작아지지만 선명한 텍스트 가장자리에 압축 노이즈가 생깁니다.
- 래스터화는 되돌릴 수 없습니다. 나중에 편집 가능한 텍스트가 필요할 수 있다면 원본 PDF를 보관하세요.

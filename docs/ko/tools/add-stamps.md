# 도장 추가

도장 주석 도구 모음이 있는 내장 뷰어를 사용해 PDF 페이지에 이미지 도장을 찍습니다. 도장에 이름을 넣어 작성자를 표시할 수 있어 승인 절차, 검토 과정, 문서 표시에 유용합니다.

## 사용 방법

1. **도장 사용자 이름** 필드에 이름을 입력합니다. 이 이름이 만든 도장에 표시됩니다.
2. PDF 파일을 클릭하거나 드롭 영역으로 끌어다 놓아 업로드합니다.
3. 문서가 불러와진 뷰어와 함께 도장 편집기가 열립니다.
4. 도구 모음의 이미지 도장 도구로 도장을 선택하여 원하는 페이지에 놓습니다.
5. 필요에 따라 도장의 위치와 크기를 조정합니다.
6. **도장 찍은 PDF 저장**을 클릭하여 결과를 다운로드합니다.

## 기능

- 도장 전용 주석 도구 모음이 있는 통합 PDF 뷰어
- 만든 도장에 사용자 이름 표기
- 모든 페이지에 이미지 도장 배치
- 끌어서 놓기로 위치 지정 및 크기 조절
- 페이지 가로세로 비율에 따른 뷰어 크기 자동 조정
- 이름과 크기 정보가 있는 파일 표시

## 활용 사례

- 검토 과정에서 문서에 "APPROVED" 또는 "REVIEWED" 이미지 도장 찍기
- 공문서에 회사 직인이나 공증 도장 이미지 배치
- 검토자 이름이 포함된 "RECEIVED" 도장으로 페이지 표시
- 검사 보고서에 품질 관리 도장 추가

## 팁

- PDF를 업로드하기 전에 도장 사용자 이름을 설정하세요. 사용자 이름은 도장 메타데이터에 포함됩니다.
- 뷰어는 PDF 첫 페이지의 가로세로 비율에 맞춰 높이를 조정하여 보기 좋게 표시합니다.
- 이미지 도장 대신 텍스트 기반 워터마크가 필요하면 [워터마크 추가](./add-watermark) 도구를 사용하세요.

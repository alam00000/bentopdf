# BMP를 PDF로

Windows 비트맵(BMP) 파일을 PDF로 변환합니다. BMP는 압축되지 않은 이미지 형식으로, 오래된 시스템, 의료 영상, 산업용 스캐너에서 여전히 볼 수 있습니다. 이 도구는 아무것도 설치하지 않고도 이를 PDF로 변환합니다.

## 지원 형식

| 형식 | 확장자 |
| :--- | :----- |
| BMP  | `.bmp` |

## 사용 방법

1. 업로드 영역을 클릭하거나 BMP 파일을 끌어다 놓습니다.
2. 파일 목록을 확인합니다. 파일을 더 추가하거나 불필요한 파일을 제거합니다.
3. **PDF로 변환**을 클릭합니다. 출력은 `from_bmps.pdf`로 다운로드됩니다.

각 BMP는 캔버스에 그려져 PNG로 내보내진 뒤 pdf-lib를 사용해 PDF에 삽입됩니다. 페이지 크기는 원본 이미지 크기와 같습니다.

## 옵션

이 도구는 별도의 품질 설정을 제공하지 않습니다. 이미지는 PDF 안에 원본 해상도의 무손실 PNG로 삽입됩니다.

## 활용 사례

- BMP로 저장된 오래된 스캔 문서를 보관용 PDF로 변환
- 구형 Windows 응용 프로그램의 BMP 스크린샷을 공유 가능한 문서로 변환
- 기본 출력이 BMP인 의료 또는 산업용 스캐너 결과물 처리
- 오래된 이미지 아카이브를 이식성이 더 좋은 형식으로 이전

## 팁

- BMP 파일은 압축되지 않아 용량이 큰 편입니다. 이미지가 내부적으로 PNG로 다시 인코딩되므로 결과 PDF는 훨씬 작아집니다.
- BMP 파일과 다른 이미지 형식이 섞여 있다면 [이미지를 PDF로](./image-to-pdf) 도구로 한 번에 일괄 변환하세요.

# 베이츠 번호 매기기

베이츠 번호 매기기는 PDF의 모든 페이지에 순차적인 식별 번호를 찍는 방식입니다. 법적 절차, 감사, 규정 준수 업무에서 문서에 번호를 붙이는 표준 방법입니다. 이 도구는 여러 파일, 사용자 지정 템플릿을 지원하며 번호가 매겨진 PDF를 개별 파일이나 하나의 ZIP 아카이브로 만듭니다.

## 사용 방법

1. PDF 파일을 하나 이상 업로드합니다. 여러 파일을 한 번에 끌어다 놓을 수 있습니다.
2. 스타일 프리셋을 고르거나 사용자 지정 템플릿을 만듭니다.
3. 위치, 글꼴, 크기, 색상, 시작 번호를 설정합니다.
4. **베이츠 번호 적용**을 클릭하여 처리합니다.
5. 파일이 하나면 바로 다운로드되고, 여러 개면 ZIP 아카이브로 다운로드됩니다.

## 옵션

- **스타일 프리셋** -- 기본 제공 형식 중에서 선택합니다.
  - 증거 + 사건 + Bates + 페이지 (예: "Exhibit 1 Case XYZ 000001 Page 1")
  - 증거 + 사건 + Bates (페이지 번호 없음)
  - 사건 + Bates
  - Bates 번호만 (예: "000001")
  - 사용자 지정 (직접 템플릿 작성)
- **스타일 사용자 지정** -- 자리 표시자 `[BATES]`, `[PAGE]`, `[FILE]`, `[FILENAME]`을 사용하는 템플릿 문자열입니다.
- **베이츠 자릿수** -- 0으로 채운 베이츠 번호의 자릿수(3에서 6)입니다. 사용자 지정 모드에서만 표시됩니다.
- **위치** -- 머리글 또는 바닥글, 그리고 왼쪽, 가운데, 오른쪽입니다.
- **베이츠 시작 번호** -- 첫 번째 베이츠 번호입니다. 기본값은 1입니다. 번호는 파일을 넘어 이어집니다.
- **파일 카운터 시작 번호** -- `[FILE]` 자리 표시자의 시작 번호입니다.
- **글꼴** -- Helvetica, Times New Roman 또는 Courier입니다.
- **글꼴 크기** -- 찍히는 텍스트의 크기입니다.
- **색상** -- 베이츠 번호 텍스트의 색상 선택기입니다.

## 기능

- 업로드한 모든 파일에 베이츠 번호가 어떻게 표시될지 보여 주는 실시간 미리보기
- 문서 간에 번호가 이어지는 다중 파일 지원
- 끌어서 놓기로 파일 순서를 바꿔 번호 순서 제어
- 여섯 가지 위치 옵션(머리글/바닥글, 왼쪽/가운데/오른쪽)
- 페이지 크기에 따라 달라지는 여백을 고려한 적응형 여백 계산
- 여러 파일 일괄 처리 시 ZIP 출력
- 최대한의 유연성을 위한 템플릿 자리 표시자

## 활용 사례

- 소송 증거 개시 문서에 순차적인 증거 번호 찍기
- 수십 개 파일에 걸친 감사 증빙 패키지에 번호 매기기
- 규정 준수 문서에 규제 참조 번호 적용
- 특허 출원 첨부 자료에 사건별 식별자 붙이기

## 팁

- 처리하기 전에 파일 목록에서 파일을 끌어 순서를 바꾸세요. 베이츠 번호 순서는 이 순서를 따릅니다.
- `[FILENAME]` 자리 표시자를 사용하면 원본 파일 이름이 도장에 들어가 페이지를 원본 문서로 추적하는 데 도움이 됩니다.
- 설정을 바꾸면 미리보기 상자가 실시간으로 갱신되므로 처리하기 전에 형식을 확인할 수 있습니다.

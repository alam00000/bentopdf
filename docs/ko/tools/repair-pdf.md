# PDF 복구

PDF가 열리지 않거나 내용이 깨져 보이거나 뷰어에서 오류가 발생할 때, 이 도구가 내부 구조를 다시 구성하려고 시도합니다. QPDF의 복구 엔진을 사용하며, 손상된 상호 참조 테이블, 잘린 스트림, 잘못된 개체 참조 등 다양한 유형의 손상에서 데이터를 복구할 수 있습니다.

## 사용 방법

1. 손상된 PDF 파일을 하나 이상 업로드합니다.
2. **PDF 복구**를 클릭합니다.
3. 파일이 하나면 복구된 파일이 바로 다운로드됩니다. 여러 파일은 ZIP 압축 파일로 생성됩니다.

이 도구는 각 파일을 `--decrypt` 플래그와 함께 QPDF에 통과시켜 PDF 전체 구조를 강제로 읽고 다시 쓰며, 그 과정에서 복구 가능한 문제를 수정합니다.

## 기능

- 한 번의 작업으로 여러 PDF 일괄 복구
- 복구 가능한 파일과 불가능한 파일 자동 감지
- 여러 파일 처리 시 파일별 성공/실패 보고
- 검증된 PDF 변환 라이브러리인 QPDF(WebAssembly) 사용

## 복구할 수 있는 문제

- 손상되었거나 누락된 상호 참조 테이블
- 불완전한 다운로드로 잘린 파일 끝부분
- 잘못된 개체 번호와 스트림 길이
- 버그가 있는 PDF 생성기가 만든 경미한 구조적 불일치
- 실패한 복호화 시도로 생긴 암호화 흔적

## 복구할 수 없는 문제

- 대부분의 내용 데이터가 없는 심하게 잘린 파일
- 알지 못하는 비밀번호로 암호화된 PDF
- 실제로는 PDF가 아닌 파일(잘못된 파일 확장자)
- PDF 내부의 이미지 손상(구조는 수정되지만 픽셀 데이터는 다시 생성되지 않음)

## 활용 사례

- 이메일 다운로드 실패로 손상된 PDF 복구
- 구형이거나 비표준 PDF 생성기가 만든 파일 열기
- 한 뷰어에서는 되지만 다른 뷰어에서는 안 되는 PDF 수정
- 손상된 보관 문서를 장기 보관용으로 준비

## 팁

- 복구에 실패하면 먼저 브라우저에서 파일을 열어 보세요. 브라우저에는 자체 복구 로직이 있어 다시 저장할 수 있을 만큼 내용을 표시할 수도 있습니다.
- 암호화된 PDF의 복구가 실패하면 먼저 PDF 잠금 해제를 한 뒤 복호화된 출력을 복구하세요.

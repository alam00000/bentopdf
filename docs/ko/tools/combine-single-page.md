# 한 페이지로 합치기

PDF의 모든 페이지를 하나의 긴 페이지로 합칩니다. 페이지를 세로(스크롤처럼) 또는 가로(나란히)로 이어 붙여 출력에 연속된 한 페이지를 만듭니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. 배치 방향을 선택합니다. **세로**(페이지를 위에서 아래로 쌓음) 또는 **가로**(페이지를 나란히 배치).
3. 페이지 사이 간격을 포인트 단위로 설정합니다.
4. 페이지 사이 빈 공간의 배경색을 선택합니다.
5. 필요하면 구분선(페이지 사이의 가는 선)을 켜고 두께와 색상을 설정합니다.
6. 처리 버튼을 클릭합니다. 출력은 한 페이지짜리 PDF입니다.

## 기능

- 세로 또는 가로 페이지 이어 붙이기
- 페이지 사이 간격 설정 가능
- 빈 공간용 배경색 선택기
- 두께와 색상을 조절할 수 있는 선택적 구분선
- 원본 페이지를 각각 전체 해상도로 합친 캔버스에 렌더링

## 옵션

| 옵션            | 설명                          |
| --------------- | ----------------------------- |
| **방향**        | 세로(쌓기) 또는 가로(나란히)  |
| **페이지 간격** | 페이지 사이 간격(포인트)      |
| **배경색**      | 페이지 사이 영역의 색상       |
| **구분선 추가** | 페이지 사이 가는 선 켜기/끄기 |
| **구분선 두께** | 선 두께(포인트)               |
| **구분선 색상** | 구분선의 색상                 |

## 사용 사례

- 여러 페이지의 와이어프레임이나 디자인 목업으로 긴 이미지 하나 만들기
- 웹에 삽입할 수 있도록 문서의 연속 스크롤 보기 생성
- 여러 페이지의 만화나 스토리보드를 하나의 띠로 이어 붙이기
- 검토를 위해 연속된 페이지의 파노라마 보기 만들기

## 팁

- 세로 방향은 세로형 페이지 문서에 가장 적합합니다. 가로 방향은 가로형 콘텐츠에 더 적합합니다.
- 페이지가 많은 문서는 매우 길거나 넓은 출력이 만들어집니다. 일부 PDF 뷰어는 아주 큰 단일 페이지를 처리하지 못할 수 있습니다.
- 대비되는 색상의 구분선을 추가하면 원본 페이지가 어디서 끝나고 다음 페이지가 어디서 시작하는지 쉽게 알 수 있습니다.

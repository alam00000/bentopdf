# PDF를 Markdown으로

PDF 파일을 제목, 문단, 목록, 기본 서식을 유지하며 Markdown(`.md`) 형식으로 변환합니다. 포함된 이미지를 추출해 함께 넣을 수도 있습니다. 단일 변환과 일괄 변환을 지원하며 PyMuPDF를 기반으로 합니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 하나 이상 업로드합니다.
2. 필요하면 **이미지 포함**을 켜서 추출한 이미지를 Markdown 출력에 포함합니다.
3. **변환**을 클릭해 처리를 시작합니다.
4. 파일 하나는 `filename.md`로 다운로드됩니다. 여러 파일은 `markdown-files.zip`이 만들어집니다.

## 옵션

- **이미지 포함**: 체크하면 PDF에 포함된 이미지가 추출되어 Markdown 출력에서 참조됩니다. 체크를 해제하면 텍스트 콘텐츠만 변환됩니다.

## 출력 형식

- **파일 하나**: `filename.md`
- **파일 여러 개**: 입력한 PDF마다 `.md` 하나가 담긴 `markdown-files.zip`

## 활용 사례

- PDF 문서를 VitePress, Hugo, Jekyll 같은 정적 사이트 생성기용 Markdown으로 변환하기
- PDF 연구 논문을 Obsidian 같은 노트 앱에서 쓸 수 있는 편집 가능한 Markdown으로 바꾸기
- 레거시 PDF 지식 베이스를 Git 친화적인 텍스트 형식으로 이전하기
- PDF 전자책에서 구조화된 콘텐츠를 추출해 다시 편집하기

## 팁

- 이미지 포함 옵션은 PDF에 콘텐츠에 필수적인 다이어그램이나 그림이 있을 때 유용합니다. 텍스트 위주 문서에서는 출력을 깔끔하게 유지하려면 끄세요.
- 사이드바, 각주, 다단 텍스트가 있는 복잡한 레이아웃은 Markdown이 완벽하지 않을 수 있습니다. 필요에 따라 출력을 검토하고 수정하세요.
- 서식이 전혀 없는 원시 텍스트가 필요하면 [PDF를 텍스트로](./pdf-to-text)를 대신 사용하세요.

# MOBI를 PDF로

Amazon Kindle MOBI 전자책을 PDF 문서로 변환합니다. MOBI 파일은 Kindle 기기와 앱에 묶여 있어 다른 곳에서 읽기 어렵습니다. PDF로 변환하면 어떤 기기에서든 열거나 인쇄할 수 있는 휴대용 버전을 얻게 됩니다.

## 지원 형식

| 형식 | 확장자  | 참고                           |
| :--- | :------ | :----------------------------- |
| MOBI | `.mobi` | Kindle 전자책 형식(Mobipocket) |

## 사용 방법

1. 업로드 영역을 클릭하거나 MOBI 파일을 하나 이상 끌어다 놓으세요.
2. 파일 목록을 확인하세요. 휴지통 아이콘으로 불필요한 파일을 제거하거나 **파일 더 추가**로 전자책을 더 넣을 수 있습니다.
3. **PDF로 변환**을 클릭하세요. PyMuPDF 엔진이 MOBI 구조를 분석하고 각 페이지를 PDF 콘텐츠로 렌더링합니다.
4. 파일 하나는 PDF로 다운로드됩니다. 여러 파일을 변환하면 `mobi-converted.zip`이라는 ZIP 아카이브를 받게 됩니다.

## 옵션

추가 설정은 필요하지 않습니다. 변환은 원본 MOBI 파일의 텍스트 콘텐츠, 서식, 포함된 이미지를 그대로 보존합니다.

## 활용 사례

- PDF만 지원하는 Kindle 외 전자책 리더에서 Kindle에서 구매한 콘텐츠 읽기
- 오프라인 학습이나 주석 작성을 위해 전자책의 일부 장 인쇄하기
- 개인 전자책 라이브러리를 범용 형식으로 보관하기
- Kindle 앱이 없는 사람과 발췌본 공유하기

## 팁

- DRM으로 보호된 MOBI 파일은 변환할 수 없습니다. 이 도구는 DRM이 없는 MOBI 파일에서만 작동합니다.
- 이미지가 많이 포함된 큰 전자책은 모든 작업이 브라우저에서 이루어지므로 처리에 몇 초 더 걸릴 수 있습니다.

# PDF를 CSV로

PDF에서 표를 추출해 CSV 파일로 내보냅니다. PyMuPDF의 표 감지 엔진으로 모든 페이지에서 표 형태의 데이터를 찾고, 발견한 모든 행을 하나의 쉼표로 구분된 출력에 기록합니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 업로드합니다.
2. **변환**을 클릭해 표 추출을 시작합니다.
3. 도구가 각 페이지를 스캔하여 표를 자동으로 식별합니다.
4. 추출한 모든 표 데이터가 담긴 `.csv` 파일이 다운로드됩니다.

서로 다른 페이지의 표는 출력에서 빈 행으로 구분됩니다. 쉼표, 따옴표, 줄바꿈이 포함된 셀은 RFC 4180에 따라 올바르게 이스케이프됩니다.

## 옵션

이 도구에는 설정 가능한 옵션이 없습니다. 문서에서 발견된 모든 표가 추출되어 하나의 CSV로 합쳐집니다.

## 출력 형식

- 감지된 모든 표가 담긴 `filename.csv` 파일 하나.

## 활용 사례

- PDF 은행 명세서나 청구서의 재무 데이터를 스프레드시트로 가져오기
- 공급업체 견적서의 가격표를 추출해 비교하기
- PDF 논문의 표 형태 연구 데이터를 분석 도구에 맞는 형식으로 변환하기
- 레거시 PDF 보고서의 데이터를 데이터베이스로 이전하기

## 팁

- 표를 찾지 못하면 도구가 "표를 찾을 수 없음" 메시지를 표시합니다. 보통 PDF가 표처럼 보이지만 실제 표로 구조화되지 않은 텍스트 레이아웃을 사용한다는 뜻입니다.
- 개별 표를 더 세밀하게 제어하려면 CSV, JSON, Markdown 출력 형식 중에서 고를 수 있는 [PDF 표 추출](./extract-tables)을 사용하세요.
- 표마다 별도 시트가 있는 Excel 형식이 필요하다면 [PDF를 Excel로](./pdf-to-excel)를 사용하세요.

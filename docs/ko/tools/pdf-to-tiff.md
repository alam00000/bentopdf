# PDF를 TIFF로

PDF의 각 페이지를 TIFF 이미지로 변환합니다. TIFF는 인쇄 제작, 팩스 시스템, 문서 보관의 표준 형식입니다. 이 도구는 TIFF 인코딩에 PackBits 압축을 사용하며, 페이지 인코딩에 실패하면 PNG로 대체합니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 업로드합니다.
2. **변환**을 클릭해 파일을 처리합니다.
3. TIFF 파일 하나 또는 ZIP 압축 파일이 자동으로 다운로드됩니다.

## 옵션

이 도구에는 설정 가능한 옵션이 없습니다. 페이지는 고정된 2배 배율로 렌더링됩니다.

## 출력 형식

- **한 페이지**: `filename.tiff`
- **여러 페이지**: `page_1.tiff`, `page_2.tiff` 등이 담긴 `filename_tiffs.zip`

특정 페이지의 TIFF 인코딩이 실패하면(압축 문제 등) 해당 페이지는 대신 `.png` 파일로 저장됩니다. 이 경우 ZIP에는 TIFF와 PNG 파일이 섞여 있습니다.

## 활용 사례

- TIFF 형식을 요구하는 정부 기관이나 법률 시스템에 문서 제출하기
- 디지털 팩스 서비스를 통한 팩스 전송용 페이지 준비하기
- 스캔 문서를 널리 지원되는 무손실 형식으로 보관하기
- 기업 문서 관리 시스템에 페이지 전달하기

## 팁

- TIFF 파일은 큽니다. 웹이나 화면용으로만 무손실 품질이 필요하다면 [PDF를 PNG로](./pdf-to-png)가 더 좋은 선택입니다.
- 일부 페이지가 PNG 대체를 사용했다면 ZIP 내용을 확인하세요. 해당 페이지는 따로 변환하는 것이 좋을 수 있습니다.

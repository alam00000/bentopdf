# ODP를 PDF로

OpenDocument Presentation 파일을 PDF로 변환합니다. ODP는 LibreOffice Impress의 기본 형식이며 Google Slides의 표준 내보내기 형식이기도 합니다. 프레젠테이션을 PDF로 만들면 누구나 프레젠테이션 소프트웨어 없이 볼 수 있고 슬라이드도 깔끔하게 인쇄됩니다.

## 지원 형식

| 형식                      | 확장자 | 참고                                         |
| :------------------------ | :----- | :------------------------------------------- |
| OpenDocument Presentation | `.odp` | LibreOffice Impress / Google Slides 내보내기 |

## 사용 방법

1. 업로드 영역을 클릭하거나 ODP 파일을 끌어다 놓으세요. 여러 프레젠테이션을 한 번에 선택할 수 있습니다.
2. 파일 목록을 확인하세요. 휴지통 아이콘으로 항목을 제거하거나 **파일 더 추가**로 프레젠테이션을 더 넣으세요.
3. **PDF로 변환**을 클릭하세요. LibreOffice 기반 엔진이 각 프레젠테이션을 처리하여 슬라이드마다 한 페이지가 되는 PDF를 만듭니다.
4. 파일 하나는 PDF로 다운로드됩니다. 여러 파일은 `odp-to-pdf.zip`이라는 ZIP 아카이브로 제공됩니다.

## 옵션

설정할 항목은 없습니다. 각 슬라이드는 원래 크기로 렌더링되며 텍스트, 이미지, 도형, 슬라이드 배경이 보존됩니다.

## 활용 사례

- 청중에게 유인물 PDF로 프레젠테이션 배포하기
- ODP보다 PDF를 선호하는 사람들과 Google Slides 내보내기 공유하기
- 학회 발표와 강의를 읽기 전용 형식으로 보관하기
- 대면 워크숍용 슬라이드 덱 인쇄하기

## 팁

- 슬라이드 전환과 애니메이션은 시각 효과 전용 기능이라 PDF로 옮겨지지 않지만 모든 정적 콘텐츠는 올바르게 렌더링됩니다.
- 발표자 노트는 PDF 출력에 포함되지 않습니다. 노트가 필요하면 프레젠테이션 소프트웨어에서 따로 내보내세요.
- 다른 LibreOffice 기반 도구와 마찬가지로 엔진은 처음 사용할 때 로드되며 세션 동안 캐시된 상태로 유지됩니다.

# PDF 회전

PDF의 페이지를 시계 방향 또는 시계 반대 방향으로 90도 회전합니다. 모든 페이지의 썸네일 미리보기가 표시되어 페이지별로 회전하거나 문서 전체에 일괄 회전을 적용할 수 있습니다.

## 사용 방법

1. PDF 파일을 업로드합니다. 모든 페이지의 썸네일이 격자로 렌더링됩니다.
2. 각 페이지 썸네일 아래의 왼쪽/오른쪽 회전 버튼으로 해당 페이지를 회전합니다.
3. 상단의 일괄 회전 제어로 모든 페이지를 한 번에 회전합니다.
4. 썸네일 미리보기가 실시간으로 업데이트되어 회전 결과를 보여줍니다.
5. 처리 버튼을 클릭하여 회전된 PDF를 저장합니다.

## 기능

- 90도 단위의 페이지별 회전(왼쪽 또는 오른쪽)
- 모든 페이지를 동시에 회전하는 일괄 회전
- 회전 전환 애니메이션이 있는 실시간 썸네일 미리보기
- 큰 문서에서도 부드러운 성능을 위한 지연 로딩 썸네일
- 원본 페이지 내용과 품질 유지

## 활용 사례

- 옆으로 누워 있거나 거꾸로 스캔된 페이지 수정
- 가로 페이지를 세로로(또는 그 반대로) 회전
- 일부 페이지가 잘못된 각도로 스캔된 방향이 섞인 문서 바로잡기
- 특정 표시 방향에 맞게 문서 준비

## 팁

- 회전은 누적됩니다. 시계 방향 버튼을 두 번 클릭하면 180도 회전이 적용됩니다.
- 90도 단위가 아닌 회전(예: 약간 기울어진 스캔을 바로잡기 위한 45도)에는 [사용자 지정 각도 회전](./rotate-custom)을 사용하세요.
- 일괄 회전 제어는 선택한 페이지가 아니라 모든 페이지에 적용됩니다. 이 도구에는 선택 기능이 없으며, 선택이 필요하면 [PDF 멀티 도구](./pdf-multi-tool)를 사용하세요.

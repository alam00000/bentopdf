# FB2를 PDF로

FictionBook 2(FB2) 파일을 PDF 문서로 변환합니다. FB2는 러시아와 동유럽에서 널리 쓰이는 XML 기반 전자책 형식입니다. 일부 플랫폼에서는 잘 지원되지만 다른 곳에서는 거의 알려져 있지 않으므로, PDF로 변환하면 어디서나 책을 읽을 수 있습니다.

## 지원 형식

| 형식          | 확장자 | 참고                 |
| :------------ | :----- | :------------------- |
| FictionBook 2 | `.fb2` | XML 기반 전자책 형식 |

## 사용 방법

1. 업로드 영역을 클릭하거나 FB2 파일을 끌어다 놓으세요. 여러 파일을 한꺼번에 선택할 수 있습니다.
2. 파일 목록을 확인하세요. 휴지통 아이콘으로 개별 항목을 제거하거나 **파일 더 추가**로 파일을 더 넣을 수 있습니다.
3. **PDF로 변환**을 클릭하세요. PyMuPDF 엔진이 FB2 XML 구조를 분석하여 페이지가 나뉜 PDF 콘텐츠로 렌더링합니다.
4. 파일 하나는 PDF로 바로 다운로드됩니다. 여러 파일을 변환하면 `fb2-converted.zip`으로 묶여 다운로드됩니다.

## 옵션

별도 설정이 필요하지 않습니다. 변환기가 FB2 XML 구조를 자동으로 처리하며 장 구분, 서식, 포함된 이미지를 그대로 유지합니다.

## 활용 사례

- PDF만 지원하는 기기나 앱에서 FB2 전자책 읽기
- FB2 형식으로 배포된 러시아어 문학 작품 인쇄하기
- FB2 라이브러리를 범용 형식으로 보관하기
- FictionBook을 지원하지 않는 리더를 쓰는 사람에게 책 공유하기

## 팁

- FB2 파일은 일반 XML이라 용량이 작고 브라우저에서도 빠르게 변환됩니다.
- FB2 파일이 `.fb2.zip`으로 압축되어 있다면 먼저 압축을 풀고 업로드하세요.

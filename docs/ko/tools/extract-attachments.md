# 첨부파일 추출

하나 이상의 PDF 파일에서 포함된 모든 첨부파일을 꺼냅니다. 추출된 모든 파일은 다운로드용 하나의 ZIP 아카이브로 묶입니다.

## 사용 방법

1. 첨부파일이 포함된 PDF 파일을 하나 이상 업로드합니다.
2. **첨부파일 추출**을 클릭합니다.
3. 도구가 각 PDF에서 문서 수준 및 페이지 수준 첨부파일을 검색합니다.
4. 찾은 모든 파일이 ZIP 아카이브로 묶여 자동으로 다운로드됩니다.
5. 상태 메시지가 찾은 첨부파일 수와 전체 크기를 알려 줍니다.

## 기능

- 여러 PDF에서 한 번에 일괄 추출
- 문서 수준과 페이지 수준 첨부파일을 모두 추출
- 추출된 모든 파일을 담은 ZIP 파일 하나를 출력
- 전체 첨부파일 수와 합계 파일 크기 표시
- 첨부파일이 없을 때 명확한 상태 메시지 표시

## 사용 사례

- 보고서 PDF에 포함된 데이터 파일 복구
- 포트폴리오나 사양 문서에서 이미지 자산 꺼내기
- 교육이나 규정 준수 PDF에서 보충 자료 추출
- PDF 묶음에 어떤 파일이 포함되어 있는지 점검

## 팁

- 도구가 첨부파일이 없다고 알려 주면, PDF에는 파일 첨부가 아닌 포함된 이미지나 양식 데이터가 들어 있을 수 있습니다. 포함된 이미지는 [이미지 추출](./extract-images)을 사용하세요.
- 여러 PDF를 처리하면 모든 파일의 첨부파일이 하나의 ZIP에 담깁니다. 파일 이름은 원래 포함된 이름이 그대로 유지됩니다.

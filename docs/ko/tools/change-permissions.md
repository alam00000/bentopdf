# 권한 변경

받는 사람이 PDF로 할 수 있는 일을 세밀하게 조정합니다. 파일을 비밀번호로 잠그기만 하는 기본 암호화와 달리, 이 도구는 인쇄, 복사, 편집, 주석, 양식 작성, 문서 조합, 페이지 추출을 선택적으로 허용하거나 거부할 수 있으며, 모두 256비트 AES 암호화로 적용됩니다.

## 사용 방법

1. PDF 파일을 업로드합니다.
2. PDF가 이미 암호화되어 있다면 **현재 비밀번호**를 입력합니다.
3. **새 사용자 비밀번호**(열 때 필요)와 **새 소유자 비밀번호**(권한 제어) 중 하나 또는 둘 다 설정합니다.
4. 체크박스로 개별 권한을 켜거나 끕니다.
5. **권한 변경**을 클릭합니다.
6. 업데이트된 PDF를 다운로드합니다.

새 비밀번호 필드를 둘 다 비워 두면 도구가 PDF를 완전히 복호화하여 모든 암호화와 제한을 제거합니다.

## 권한 제어

| 권한                 | 제어 대상                                        |
| -------------------- | ------------------------------------------------ |
| **인쇄 허용**        | 문서를 인쇄할 수 있는지 여부                     |
| **복사 허용**        | 텍스트와 이미지를 선택하고 복사할 수 있는지 여부 |
| **수정 허용**        | 문서 내용을 편집할 수 있는지 여부                |
| **주석 허용**        | 댓글, 강조 표시, 스탬프를 추가할 수 있는지 여부  |
| **양식 작성 허용**   | 대화형 양식 필드를 작성할 수 있는지 여부         |
| **문서 조합 허용**   | 페이지를 삽입, 삭제, 회전할 수 있는지 여부       |
| **페이지 추출 허용** | 개별 페이지를 추출할 수 있는지 여부              |

모든 권한이 적용되려면 소유자 비밀번호가 필요합니다. 소유자 비밀번호가 없으면 대부분의 PDF 리더가 권한 플래그를 무시합니다.

## PDF의 권한 작동 방식

PDF 권한은 암호화 사양의 일부입니다. 암호화 딕셔너리에 비트 플래그로 저장되며 규격을 준수하는 PDF 리더가 이를 적용합니다. 핵심적인 차이는 다음과 같습니다.

- **사용자 비밀번호**: 파일을 여는 데 필요합니다.
- **소유자 비밀번호**: 권한을 변경하거나 제한을 제거하는 데 필요합니다. 이 비밀번호가 없으면 권한 플래그가 사용자가 수행할 수 있는 작업을 제어합니다.

소유자 비밀번호만 설정하면(사용자 비밀번호 없음) 누구나 파일을 열 수 있지만 허용된 작업으로만 제한됩니다. 둘 다 설정하면 파일을 열 때 비밀번호가 필요하고 인증 후에도 제한이 적용됩니다.

## 사용 사례

- 보기와 인쇄는 가능하지만 편집이나 복사는 할 수 없는 보고서 배포
- 받는 사람이 작성할 수는 있지만 수정할 수는 없는 계약서 템플릿 공유
- 이미지 복사를 비활성화한 PDF 카탈로그 게시
- 구조 변경은 막으면서 검토용 초안에 주석은 허용

## 팁

- 효과를 내려면 항상 소유자 비밀번호를 설정하세요. 소유자 비밀번호가 없는 권한은 강제할 수 없습니다.
- 일부 서드파티 PDF 도구는 권한 플래그를 무시합니다. 더 강력한 보호가 필요하면 PDF를 래스터화하거나 DRM 사용을 고려하세요.
- 이 도구로 오래된 RC4 암호화 PDF를 AES-256으로 업그레이드할 수 있습니다.

# Markdown을 PDF로

실시간 미리보기와 원클릭 PDF 내보내기를 갖춘 다기능 Markdown 편집기입니다. 처음부터 작성하거나 기존 `.md` 파일을 업로드하거나 클립보드의 내용을 붙여넣을 수 있습니다. 편집기는 Markdown을 실시간으로 렌더링하고 브라우저의 내장 인쇄 엔진으로 스타일이 적용된 PDF를 내보냅니다.

## 지원 형식

| 입력       | 설명                         |
| :--------- | :--------------------------- |
| `.md` 파일 | 업로드 버튼으로 업로드       |
| 직접 입력  | 편집기에 입력하거나 붙여넣기 |

## 사용 방법

1. Markdown을 PDF로 도구를 여세요. 편집기가 분할 보기로 열리며 왼쪽에는 Markdown 소스, 오른쪽에는 렌더링된 미리보기가 표시됩니다.
2. Markdown을 작성하거나 붙여넣거나 **업로드**를 클릭해 `.md` 파일을 불러오세요.
3. 도구 모음의 테마 슬라이더로 라이트와 다크 테마를 전환하세요.
4. **PDF 내보내기**를 클릭하거나 `Ctrl/Cmd + S`를 눌러 브라우저의 인쇄 대화상자로 PDF를 생성하세요.

## 기능

편집기는 기본 기능 외에도 폭넓은 Markdown 기능을 지원합니다.

- **표준 Markdown**: 제목, 굵게, 기울임, 링크, 이미지, 목록, 인용문, 가로줄
- 15개 이상의 언어(JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash 등)에 대한 구문 강조가 적용되는 **코드 블록**
- **Mermaid 다이어그램**: 순서도, 시퀀스 다이어그램, ER 다이어그램 등 Mermaid 차트 유형이 미리보기에 바로 렌더링됩니다
- 표준 Markdown 표 문법을 사용하는 **표**
- 체크박스가 있는 **작업 목록**
- **각주**, **아래 첨자**, **위 첨자**
- **정의 목록**, **약어**
- **이모지** 지원(`:smile:`이 이모지로 렌더링됨)
- **하이라이트**(`==marked text==`)와 **삽입**(`++inserted text++`)
- **URL 자동 링크**: 일반 URL이 클릭 가능한 링크로 변환됩니다
- **목차** 생성
- 제목의 **앵커 링크**

## 활용 사례

- 프로젝트 문서를 작성하고 이해관계자용으로 다듬어진 PDF 내보내기
- 코드 샘플과 Mermaid 아키텍처 다이어그램이 있는 기술 보고서 만들기
- GitHub README를 오프라인 사용이나 인쇄용 PDF로 변환하기
- 작업 목록과 표를 사용해 제안서나 명세서 초안 작성하기
- Markdown으로 쓴 강의 노트로 스타일이 적용된 유인물 만들기

## 팁

- PDF 출력은 브라우저의 PDF로 인쇄 기능을 사용합니다. Chrome에서는 저장하기 전에 인쇄 대화상자에서 여백과 배율을 조정할 수 있습니다.
- Mermaid 다이어그램은 미리보기에 렌더링되지만 처음 사용할 때는 초기화에 잠시 시간이 걸릴 수 있습니다.
- 버튼을 누르지 않고 내보내려면 `Ctrl/Cmd + S` 단축키를 사용하세요.

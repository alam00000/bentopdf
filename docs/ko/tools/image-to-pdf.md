# 이미지를 PDF로

범용 이미지 PDF 변환기입니다. 거의 모든 형식의 이미지를 업로드해 하나의 PDF 문서로 합칠 수 있습니다. 각 이미지는 원본 크기에 맞춘 별도 페이지가 됩니다.

## 지원 형식

| 형식            | 확장자                                 |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

BentoPDF의 이미지 변환기 중 가장 폭넓은 형식을 지원합니다. 특정 형식만 필요하다면 해당 전용 도구를 사용하세요.

## 사용 방법

1. 업로드 영역을 클릭하거나 이미지 파일을 끌어다 놓으세요. 여러 파일을 한 번에 선택할 수 있습니다.
2. 파일 목록을 확인하세요. 휴지통 아이콘으로 불필요한 파일을 제거하거나 **파일 더 추가**를 클릭해 이미지를 더 추가할 수 있습니다.
3. 드롭다운에서 **PDF 품질** 수준을 선택하세요.
4. **PDF로 변환**을 클릭하세요. 도구가 PyMuPDF 엔진으로 이미지를 처리하고 결과를 `images_to_pdf.pdf`로 다운로드합니다.

## 옵션

**PDF 품질**은 이미지를 PDF에 삽입할 때 적용하는 압축을 조절합니다.

- **고품질**: 압축을 최소화하며 파일 크기가 커집니다. 인쇄나 보관용에 적합합니다.
- **중간 품질**(기본값): 균형 잡힌 압축입니다. 대부분의 용도에 알맞습니다.
- **저품질**: 강한 압축으로 파일 크기가 가장 작습니다. 이메일이나 빠른 공유에 적합합니다.

HEIC와 WebP 파일은 삽입 전에 자동으로 PNG로 변환됩니다. 이 과정은 투명하게 이루어지며 추가 작업이 필요하지 않습니다.

## 활용 사례

- 휴대폰 카메라로 찍은 스캔 영수증이나 문서를 하나의 PDF로 합치기
- 여러 형식의 이미지로 포토 포트폴리오나 룩북 만들기
- 데스크톱 소프트웨어 설치 없이 iPhone 사진(HEIC)을 공유 가능한 PDF로 변환하기
- PSD 내보내기 파일과 스크린샷으로 클라이언트 전달용 디자인 시안 모음 만들기
- 오래된 이미지 형식(PNM, JXR, JP2) 폴더를 PDF 하나로 보관하기

## 팁

- PDF 속 이미지 순서는 파일 목록의 순서와 같습니다. 원하는 순서대로 업로드하세요.
- 파일 크기를 가장 작게 하려면 저품질을 선택하세요. 텍스트 위주의 스캔본은 시각적 차이가 거의 없는 경우가 많습니다.
- 이미지 형식이 하나뿐이라면 전용 변환기(JPG를 PDF로, PNG를 PDF로 등)가 더 간단한 인터페이스로 같은 결과를 제공합니다.

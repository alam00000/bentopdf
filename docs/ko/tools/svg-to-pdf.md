# SVG를 PDF로

Scalable Vector Graphics(SVG) 파일을 PDF로 변환합니다. 이 도구는 브라우저의 렌더링 엔진으로 각 SVG를 래스터화한 뒤 원래 해상도로 삽입합니다. 벡터 아이콘, 다이어그램, 일러스트를 휴대 가능한 문서로 만들 때 유용합니다.

## 지원 형식

| 형식 | 확장자 |
| :--- | :----- |
| SVG  | `.svg` |

## 사용 방법

1. 업로드 영역을 클릭하거나 SVG 파일을 하나 이상 끌어다 놓습니다.
2. 파일 목록을 확인하고 관리합니다.
3. **PDF 품질** 수준을 선택합니다.
4. **PDF로 변환**을 클릭합니다. 결과는 `from_svgs.pdf`로 다운로드됩니다.

각 SVG는 텍스트로 읽혀 고유한 너비와 높이(크기가 지정되지 않으면 기본 800x600)로 캔버스에 렌더링된 후 PNG로 내보내집니다. 그 PNG가 pdf-lib로 PDF에 삽입됩니다. 투명한 영역은 흰색 배경으로 채워집니다.

## 옵션

**PDF 품질**은 래스터화 후의 압축을 제어합니다.

- **높은 품질**: 원본 렌더링에 가장 가까움
- **중간 품질** (기본값): 좋은 균형
- **낮은 품질**: 가장 작은 파일, 세부 정보 일부 손실

## 활용 사례

- 건축 또는 공학 다이어그램을 SVG에서 인쇄용 PDF로 변환
- 디자인 시스템 참고용으로 아이콘 세트를 PDF로 묶기
- 데이터 시각화(D3.js, 차트 라이브러리 내보내기)를 보고서용 PDF로 변환
- SVG 기반 인포그래픽의 인쇄용 버전 만들기

## 팁

- 명시적인 `width`와 `height` 속성이 없는 SVG 파일은 800x600 픽셀로 렌더링됩니다. 최상의 결과를 위해 변환 전에 SVG 소스에 크기를 지정하세요.
- 외부 글꼴 참조나 링크된 이미지가 있는 복잡한 SVG는 완벽하게 렌더링되지 않을 수 있습니다. 안정적인 출력을 위해 모든 에셋을 SVG 안에 포함하세요.
- SVG가 래스터화되므로 PDF에는 벡터 경로가 아닌 비트맵 이미지가 포함됩니다. 진정한 벡터 PDF 출력에는 전용 벡터 도구가 필요합니다.

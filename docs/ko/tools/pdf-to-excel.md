# PDF를 Excel로

PDF에서 표를 추출해 Excel(`.xlsx`) 스프레드시트로 저장합니다. 감지된 각 표는 표 번호와 원본 페이지가 표시된 별도의 워크시트에 배치됩니다. 표 감지는 PyMuPDF가, Excel 생성은 SheetJS 라이브러리가 담당합니다.

## 사용 방법

1. 드롭 영역을 클릭하거나 파일을 끌어다 놓아 PDF를 업로드합니다.
2. **변환**을 클릭해 표 추출을 시작합니다.
3. 도구가 모든 페이지에서 표를 스캔한 뒤 Excel 통합 문서를 만듭니다.
4. 표당 시트 하나가 있는 `.xlsx` 파일이 다운로드됩니다.

## 옵션

이 도구에는 설정 가능한 옵션이 없습니다. 감지된 모든 표가 자동으로 추출됩니다.

## 출력 형식

- `filename.xlsx` 파일 하나.
- **표 하나**: "Table"이라는 이름의 워크시트 하나.
- **표 여러 개**: "Table 1 (Page 3)", "Table 2 (Page 5)" 등의 이름이 붙은 워크시트. 시트 이름은 Excel 제한인 31자로 잘립니다.

## 활용 사례

- PDF 재무 보고서를 추가 분석을 위한 편집 가능한 스프레드시트로 변환하기
- 공급업체 PDF에서 재고나 주문 표 추출하기
- PDF 양식이나 카탈로그의 구조화된 데이터를 정렬과 필터링을 위해 Excel로 가져오기
- 표 형태의 PDF 데이터를 비전문가 동료도 다룰 수 있는 형식으로 보관하기

## 팁

- 도구가 "표를 찾을 수 없음"이라고 알려준다면 PDF가 구조화된 표가 아닌 자유로운 텍스트 레이아웃을 사용했을 가능성이 높습니다. 대신 [PDF를 텍스트로](./pdf-to-text)로 원본 내용을 가져와 보세요.
- 더 단순한 평면 형식은 [PDF를 CSV로](./pdf-to-csv)를 사용하세요. 여러 형식으로 표별 다운로드가 필요하면 [PDF 표 추출](./extract-tables)을 사용하세요.
- 시트 이름을 보면 각 표가 어느 페이지에서 왔는지 알 수 있습니다.

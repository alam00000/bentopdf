# 复制与组织

通过可视化的拖放界面，对 PDF 的页面进行重新排列、复制和删除。每个页面都以缩略图显示，您可以在保存为新文件之前移动、克隆或删除它们。

## 使用方法

1. 上传单个 PDF 文件。
2. 工具会渲染显示所有页面的缩略图网格。
3. 拖动缩略图以重新排序页面，点击绿色复制按钮克隆页面，或点击红色删除按钮移除页面。
4. 或者，在文本框中输入自定义页面顺序（例如 `3, 1, 2, 4`），然后点击 **应用** 一次性重新排列所有页面。
5. 点击处理按钮，生成并下载重新组织后的 PDF。

## 功能

- 带动画过渡的拖放页面重新排序
- 每个页面都有复制和删除按钮
- 自定义页面顺序输入，实现精确排列
- 页码标签在每次更改后自动更新
- 防止删除最后一个剩余页面

## 使用场景

- 将报告中放错位置的页面移到正确位置
- 复制表单页面，在一个文件中获得多份空白副本
- 在分发文档之前移除草稿页或占位页
- 为打印准备而反转或打乱页面顺序
- 无需重新合并单独的文件，即可构建自定义页面序列

## 小技巧

- 自定义页面顺序字段需要以逗号分隔的原始页码。必须恰好包含每个页面一次，不能遗漏或重复。
- 复制页面后，两个副本引用相同的原始页面索引。对任一副本重新排序都是相互独立的。
- 如需跨多个文件的批量操作或更高级的工作流，请考虑改用 [PDF 多功能工具](./pdf-multi-tool)。

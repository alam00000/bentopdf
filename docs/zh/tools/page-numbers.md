# 页码

为 PDF 的每一页添加可见的页码。您可以选择位置、格式、字号和颜色，其余交给工具处理。

## 使用方法

1. 上传 PDF 文件。
2. 在出现的选项面板中配置页码设置。
3. 点击 **添加页码** 进行处理。
4. 带页码的 PDF 会自动下载。

## 选项

- **位置**：选择页码出现的位置，包括底部居中、底部左侧、底部右侧、顶部居中、顶部左侧或顶部右侧。
- **格式**：可选简单编号（1、2、3...）或“第 X 页，共 Y 页”格式（1 / 5、2 / 5...）。
- **字号**：设置页码文本的大小。默认为 12。
- **颜色**：使用取色器为页码文本选择任意颜色。

## 功能

- 六种位置选项，涵盖所有角落和居中位置
- 两种编号格式：简单顺序编号或“第 X 页，共 Y 页”
- 可自定义字号，范围为 6 到 72 点
- 完整的文本颜色取色器
- 自动处理边距，无论页面大小如何都能让页码保持在安全区域内

## 使用场景

- 为需要可见页面引用的文档准备打印
- 为由多个源文件合并而成的 PDF 添加页码
- 在分发前为演示讲义编号
- 为法律文件或合同添加连续编号

## 小技巧

- “第 X 页，共 Y 页”格式适用于读者需要了解总长度的文档，例如提案或报告。
- 如果不同部分需要不同的编号样式（例如前言部分使用罗马数字），请改用 [添加页面标签](./add-page-labels) 工具。

# 旋转 PDF

将 PDF 中的页面顺时针或逆时针旋转 90 度。该工具会显示每个页面的缩略图预览，让您可以逐页旋转，也可以对整个文档进行批量旋转。

## 工作原理

1. 上传 PDF 文件。每个页面的缩略图会以网格形式渲染。
2. 使用每个页面缩略图下方的左/右旋转按钮旋转该页面。
3. 使用顶部的批量旋转控件一次旋转所有页面。
4. 缩略图预览会实时更新以显示旋转效果。
5. 点击处理按钮保存旋转后的 PDF。

## 功能

- 每页以 90 度为单位旋转（向左或向右）
- 同时对所有页面进行批量旋转
- 实时缩略图预览，带有旋转过渡动画
- 缩略图延迟加载，使大型文档也能流畅运行
- 保留原始页面内容和质量

## 使用场景

- 修复侧向或上下颠倒的扫描页面
- 将横向页面旋转为纵向（或反之）
- 纠正混合方向的文档，其中部分页面以错误的角度扫描
- 为特定的显示方向准备文档

## 提示

- 旋转是累积的。点击两次顺时针按钮会应用 180 度旋转。
- 如需非 90 度的旋转（例如用 45 度修正略微倾斜的扫描件），请改用[按自定义角度旋转](./rotate-custom)。
- 批量旋转控件会影响所有页面，而不仅仅是选定的页面。此工具没有选择机制，如需选择，请使用 [PDF 多功能工具](./pdf-multi-tool)。

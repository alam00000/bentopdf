# RTF 转 PDF

将富文本格式文档转换为 PDF。RTF 是一种跨平台的文档格式，几乎所有文字处理软件都支持。此工具使用浏览器内的 LibreOffice 引擎渲染 RTF 文件并保留其格式，粗体、斜体、表格和嵌入图片都会带到 PDF 中。

## 支持的格式

| 格式 | 扩展名 | MIME 类型                     |
| :--- | :----- | :---------------------------- |
| RTF  | `.rtf` | `text/rtf`, `application/rtf` |

## 工作原理

1. 点击上传区域，或拖放一个或多个 RTF 文件。
2. 查看文件列表。可根据需要添加或移除文件。
3. 点击**转换为 PDF**。LibreOffice 引擎会在首次使用时初始化，然后处理每个文件。
4. 单个文件会直接下载为 PDF。多个文件会以 `rtf-converted.zip` 的形式提供。

## 选项

此工具没有额外设置。转换会保留原始 RTF 格式。

## 输出

| 输入数量 | 输出                                                    |
| :------- | :------------------------------------------------------ |
| 1 个文件 | 下载单个 PDF（例如 `letter.pdf`）                       |
| 2 个以上 | ZIP 压缩包（`rtf-converted.zip`），每个文件对应一个 PDF |

## 使用场景

- 将旧版文字处理软件中的 RTF 文档转换为现代 PDF
- 将 RTF 邮件模板转为 PDF 预览
- 处理法律或医疗软件系统输出的 RTF
- 将文档管理系统中的 RTF 文件批量转换为 PDF 进行归档

## 提示

- LibreOffice 引擎只加载一次并被缓存。会话中的第一次转换会多花几秒，之后会更快。
- 带有嵌入 OLE 对象的 RTF 文件可能无法完美渲染所有对象。纯文本、图片和标准格式可以可靠转换。
- 如果您的 RTF 文件由 Microsoft Word 创建，也可以直接使用 [Word 转 PDF](./word-to-pdf) 工具转换，它除了 DOC 和 DOCX 外也接受 RTF。

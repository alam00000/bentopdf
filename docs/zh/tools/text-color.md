# 更改文本颜色

替换整个 PDF 中文本的颜色。该工具会识别每页上的文本区域，并将其重新着色为您选择的颜色，同时保留文档版面和非文本内容。

## 工作原理

1. 上传您的 PDF 文件。
2. 使用颜色选择器选取新的文本颜色。默认为蓝色（#0000FF）。
3. 点击**更改文本颜色**开始处理。
4. 重新着色后的 PDF 会自动下载。进度指示器会显示正在处理的页面。

## 选项

- **新文本颜色**：颜色选择器，用于选择文档中所有文本的替换颜色。

## 功能

- 对文档中每一页的文本重新着色
- 逐页处理并提供进度反馈
- 颜色选择器完整支持十六进制颜色
- 保留页面版面和非文本元素

## 使用场景

- 将黑色文本改为深蓝色，使文档外观更柔和、更现代
- 在分发文档之前，将文本重新着色以符合品牌规范
- 为满足无障碍合规要求，将文本转换为特定颜色
- 让文本在新应用的背景颜色上清晰可见

## 提示

- 此工具会以 2 倍比例渲染页面以保证质量，然后重建 PDF。输出是基于图像的，因此文本将不再可选择或可搜索。
- 如果文档需要保留可选择的文本，请考虑改用 [PDF 编辑器](./edit-pdf) 直接编辑 PDF。
- 由于每一页都是单独渲染的，处理时间会随页数增加。

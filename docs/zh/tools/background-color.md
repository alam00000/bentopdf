# 背景颜色

在 PDF 所有现有内容后面设置纯色背景。工具会在每页创建一个彩色矩形，并将原始内容叠放在其上，因此文字、图片和图形在新背景上仍然完全可见。

## 工作原理

1. 上传您的 PDF 文件。
2. 使用颜色选择器选取背景颜色。默认为浅黄色 (#FFFFCC)。
3. 点击**更改背景颜色**进行处理。
4. 更新后的 PDF 会自动下载。

## 选项

- **背景颜色**：标准取色器，可选择任意纯色。默认为浅黄色。

## 功能

- 为每一页应用统一的背景颜色
- 将所有原始内容（文字、图片、矢量图形）完整保留在彩色图层之上
- 保持原始页面尺寸
- 适用于任意页数的文档

## 使用场景

- 添加浅奶油色或象牙色背景，使文档呈现更柔和的纸质外观
- 为不同类别应用不同的背景颜色，对文档集进行颜色编码
- 为不同受众创建同一文档的视觉区分版本
- 添加浅色背景色调，提升文档在屏幕上投影时的可读性

## 提示

- 浅色、柔和的颜色效果最佳。除非文字本身是浅色，否则很深的背景会使文字难以阅读。
- 如果想同时更改背景和文字颜色，请先应用背景颜色，然后对结果使用[更改文字颜色](./text-color)。
- 此工具在 PDF 结构层面工作（不进行栅格化），因此输出中的文字仍可选中和搜索。

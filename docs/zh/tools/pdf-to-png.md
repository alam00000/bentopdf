# PDF 转 PNG

将 PDF 的每一页转换为 PNG 图像。PNG 使用无损压缩，因此输出会保留原始页面的每一个细节。单页 PDF 会下载为 `.png` 文件，多页 PDF 会生成 ZIP。

## 使用方法

1. 点击拖放区域或将文件拖到其上以上传 PDF。
2. 设置 **缩放** 滑块以控制输出分辨率。
3. 点击 **转换** 开始处理。
4. 单个 PNG 或 ZIP 压缩包会自动下载。

## 选项

- **缩放**：范围从 1.0x 到 3.0x（默认 2.0x）。在 2.0x 时，标准 Letter 尺寸的页面渲染为约 1,224 x 1,584 像素。更高的缩放值会生成更大、更清晰的图像，但代价是文件大小和处理时间。

## 输出格式

- **单页**：`filename.png`
- **多页**：`filename_pngs.zip`，包含 `page_1.png`、`page_2.png` 等。

## 使用场景

- 为演示文稿捕获 PDF 页面的高保真截图。
- 提取需要清晰边缘且无压缩伪影的图表或示意图。
- 从 PDF 原型图准备网页设计素材。
- 为 OCR 预处理创建无损页面图像。

## 小技巧

- PNG 文件比 JPG 大得多。如果文件大小比完美质量更重要，请使用 [PDF 转 JPG](./pdf-to-jpg) 或 [PDF 转 WebP](./pdf-to-webp)。
- 在 1.0x 缩放时，输出与 PDF 的原生分辨率一致。如需印刷质量的导出，请提高到 3.0x。

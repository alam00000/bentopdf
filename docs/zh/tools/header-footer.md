# 页眉和页脚

在 PDF 页面的六个位置添加文本：页眉左、页眉中、页眉右、页脚左、页脚中和页脚右。该工具支持页码和总页数的动态变量，因此您可以创建类似“第 3 页，共 10 页”的模板，并按页自动更新。

## 使用方法

1. 上传 PDF 文件。
2. 出现选项面板，显示格式控件和六个文本输入框。
3. 在任意页眉或页脚位置输入所需文本。
4. 使用 `{page}` 和 `{total}` 占位符实现动态页码。
5. 调整字体大小、字体颜色，也可以选择限制在特定页面范围内。
6. 点击 **添加页眉和页脚** 进行处理并下载。

## 选项

- **页面范围**：可选，限制哪些页面添加页眉和页脚。留空则应用于所有页面。格式："1-3, 5"（以逗号分隔的范围）。
- **字体大小**：6 到 24 磅之间。默认为 10。
- **字体颜色**：使用颜色选择器选取任意颜色。
- **页眉左 / 中 / 右**：每页顶部的文本字段。
- **页脚左 / 中 / 右**：每页底部的文本字段。

## 功能

- 每页六个独立的文本位置
- 动态 `{page}` 变量，插入当前页码
- 动态 `{total}` 变量，插入总页数
- 页面范围过滤，针对特定页面
- 可自定义字体大小和颜色
- 使用 Helvetica 字体，输出整洁专业

## 使用场景

- 在报告的页脚中间添加“第 {page} 页，共 {total} 页”
- 在页眉左侧放置公司名称，在页眉右侧放置文档日期
- 在法律文件的页脚添加保密声明
- 在特定页面范围上标注文档修订编号

## 小贴士

- 可以在同一个字段中组合 `{page}` 和 `{total}`，例如“第 {page} 页，共 {total} 页”或“{page}/{total}”。
- 大多数字段可以留空，只填写需要的位置。空字段会被直接跳过。
- 对于包含图片或徽标的更复杂页眉，可以考虑使用 [添加水印](./add-watermark) 工具，并将其放置在页面顶部。

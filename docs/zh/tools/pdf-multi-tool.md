# PDF 多功能工具

一个统一的工作区，涵盖所有页面级 PDF 操作。上传一个或多个 PDF，并在单个可视化网格中处理它们的所有页面。无需离开工具，即可旋转、重新排序、复制和删除页面，插入 PDF、图片和空白页，重新编号、调整尺寸并分割结果。

## 使用方法

1. 点击 **选择文件** 或将文件拖到上传区域。支持多个文件，并会按上传顺序合并。
2. 所有页面会以缩略图形式显示在可滚动的网格中。
3. 点击页面即可选中。按住 Shift 点击可选择连续范围，按住 Cmd/Ctrl 点击可添加或取消单个页面。
4. 使用页面管理器的工具栏，或右键点击页面，来执行页面操作。
5. 点击 **导出 PDF** 下载最终结果。

## 功能

- **合并**：上传多个 PDF 和图片，它们会自动合并为一个文档
- **重新排序**：拖放页面以重新排列顺序，或反转整个文档
- **旋转**：将所选页面按 90 度为单位向左或向右旋转
- **复制**：复制所选页面，并将副本放在原页面之后
- **删除**：移除所选页面
- **插入**：添加其他 PDF 或图片中的页面、空白页、剪贴板中的页面，或将第二个 PDF 的页面与当前页面交替排列
- **替换**：用另一个 PDF 的第一页替换某个页面
- **剪切、复制和粘贴**：在文档内移动或复制页面
- **提取**：将所选页面下载为 PDF 或图片
- **页码**：为一段页面设置页面标签，例如 i、ii、iii 或 A-1、A-2
- **页面尺寸**：将页面调整为标准纸张尺寸或自定义尺寸
- **分割**：按页面范围、奇偶页、每一页、书签、每 N 页或文件大小分割文档
- **撤销 / 重做**：每项页面操作都可以撤销和重做
- 加载前自动修复损坏的 PDF

## 键盘快捷键

| 操作             | 快捷键                        |
| ---------------- | ----------------------------- |
| 向右 / 向左旋转  | R / Shift+R                   |
| 全选             | Cmd/Ctrl+A                    |
| 剪切、复制、粘贴 | Cmd/Ctrl+X, C, V              |
| 复制页面         | Cmd/Ctrl+D                    |
| 删除             | Delete 或 Backspace           |
| 撤销 / 重做      | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| 移动选择         | 方向键、Home、End             |

## 使用场景

- 使用多个源 PDF 中的页面构建自定义文档
- 通过删除空白页、旋转横向扫描页和重新排序章节来整理扫描文档
- 利用书签在章节边界处分割大型 PDF
- 无需完整的 PDF 编辑器，即可快速进行页面级编辑

## 小技巧

- 撤销和重做历史会记录每项页面操作。请放心使用，您不会意外毁掉自己的工作。
- 随时可以使用 **Insert > From File**，或将更多 PDF 或图片拖放到页面网格中，将它们添加到文档。
- 对于简单的合并或分割任务，专用的 [合并 PDF](./merge-pdf) 或 [分割 PDF](./split-pdf) 工具可能更快。当您需要在一次会话中完成多项操作时，多功能工具最能发挥优势。

# PDF 多功能工具

一个统一的工作区，涵盖所有页面级 PDF 操作。上传一个或多个 PDF，并在单个可视化网格中处理它们的所有页面。无需离开工具，即可旋转、重新排序、复制、删除、插入新的 PDF、添加空白页并分割结果。

## 使用方法

1. 点击 **上传 PDF** 或将文件拖到上传区域。支持多个文件。
2. 所有上传文件的全部页面会以缩略图形式显示在可滚动的网格中。
3. 使用工具栏或每页的操作按钮来处理页面。
4. 使用每张卡片上的复选框选择页面，然后应用批量操作。
5. 使用剪刀图标标记分割点，将输出划分为多个单独的文件。
6. 点击 **导出 PDF** 下载最终结果。如果存在分割标记，输出将是包含多个 PDF 的 ZIP。

## 功能

- **合并**：上传多个 PDF，它们会自动合并到一个工作区
- **重新排序**：拖放页面卡片以重新排列顺序
- **旋转**：按 90 度增量（向左或向右）对单页或批量旋转
- **复制**：一键克隆任意页面
- **删除**：移除单个页面或批量删除所选页面
- **插入 PDF**：在任意指定页面之后添加新的 PDF
- **添加空白页**：在末尾追加一个空白 A4 页面
- **分割**：在页面之间放置分割标记，然后导出为单独 PDF 的 ZIP
- **全选 / 取消全选**：快速选择以进行批量操作
- **撤销 / 重做**：每项操作都有完整的撤销和重做历史
- **下载所选**：仅将所选页面导出为独立的 PDF
- 加载前自动修复损坏的 PDF

## 使用场景

- 使用多个源 PDF 中的页面构建自定义文档
- 通过删除空白页、旋转横向扫描页和重新排序章节来整理扫描文档
- 使用可视化分割标记，在章节边界处分割大型 PDF
- 无需完整的 PDF 编辑器，即可快速进行页面级编辑

## 小技巧

- 撤销和重做系统会记录每项操作。请放心使用，您不会意外毁掉自己的工作。
- 分割标记显示为页面之间的蓝色虚线。请直观地将其放在您想要划分文档的位置，然后导出以获得 ZIP。
- 对于简单的合并或分割任务，专用的 [合并 PDF](./merge-pdf) 或 [分割 PDF](./split-pdf) 工具可能更快。当您需要在一次会话中完成多项操作时，多功能工具最能发挥优势。

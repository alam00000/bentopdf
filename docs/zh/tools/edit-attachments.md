# 编辑附件

检查并管理 PDF 内部的文件附件。工具会列出每个嵌入文件的名称和附件级别，然后让您将单个附件标记为移除，或一次性清除全部附件。

## 使用方法

1. 上传 PDF 文件。
2. 工具会自动扫描附件并以列表显示。
3. 每个附件都会显示其文件名，以及它是文档级还是页面级附件。
4. 点击附件旁的垃圾桶图标将其标记为移除（再次点击可取消标记）。
5. 使用 **移除所有附件** 按钮一次性全选，或使用 **取消全选** 清除选择。
6. 点击处理按钮，保存已移除所选附件的新 PDF。

## 功能

- 列出所有文档级和页面级附件
- 单个或批量移除附件
- 在提交更改前可开关选择状态
- 标记为移除的项目会显示删除线并降低不透明度
- 下载已清除所选附件的修改后 PDF

## 使用场景

- 在重新分发之前，移除嵌入文档中的过时或错误文件
- 在分享前，从 PDF 中清除敏感附件（财务数据、个人信息）
- 通过移除不再需要的大型嵌入文件来减小 PDF 体积
- 在归档前审查嵌入内容并清理文档

## 小提示

- 标记为移除的附件会以删除线显示。如果您改变主意，可以在处理前将其切换回来。
- 如果没有找到附件，工具会显示明确的“未找到附件”消息，说明该 PDF 不包含嵌入文件。

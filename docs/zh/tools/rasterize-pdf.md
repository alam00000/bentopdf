# 栅格化 PDF

栅格化会将 PDF 的每一页转换为图像，再将这些图像重新组合成 PDF。结果看起来与原件完全相同，但不包含可选择的文本、交互元素和可编辑图层，相当于一份高质量的复印件。

## 工作原理

1. 上传一个或多个 PDF 文件。
2. 设置栅格化输出的 **DPI**（分辨率）。
3. 选择**图像格式**：PNG 为无损质量，JPEG 文件更小。
4. 可选：勾选**转换为灰度**。
5. 点击**栅格化 PDF**。多个文件会以 ZIP 下载。

## 选项

| 设置         | 取值                      | 默认值 |
| ------------ | ------------------------- | ------ |
| **DPI**      | 72、150、200、300、600    | 150    |
| **图像格式** | PNG（无损）、JPEG（更小） | PNG    |
| **灰度**     | 开/关                     | 关     |

## DPI 参考

- **72**：仅用于屏幕查看，文件最小
- **150**：适合一般用途的良好平衡
- **200**：文字更清晰，文件大小适中
- **300**：印刷品质输出
- **600**：高质量归档或专业印刷

## 使用场景

- 在分享前防止机密文档的文本被提取
- 通过将文本转换为像素，消除字体依赖问题
- 为包含复杂图层或透明度、在不同阅读器中渲染不一致的 PDF 创建“扁平”版本
- 为只接受图像输入的系统准备 PDF
- 将 PDF 简化为纯图像，从而剥离隐藏内容（如修订记录或表单数据）

## 提示

- 150 DPI 搭配 PNG 是可靠的默认选择。只有在需要打印输出或放大查看细节时才提高。
- JPEG 生成的文件明显更小，但会在锐利的文字边缘产生压缩伪影。
- 栅格化不可逆，如果以后可能需要可编辑的文本，请保留原始 PDF。

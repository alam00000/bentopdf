# WebP 转 PDF

将 Google 的 WebP 图片格式转换为 PDF。当您从网上下载了 WebP 格式的图片，并需要将其转为更通用的格式用于打印或分享时，这特别有用。

## 支持的格式

| 格式 | 扩展名  |
| :--- | :------ |
| WebP | `.webp` |

## 工作原理

1. 点击上传区域，或拖放您的 WebP 文件。
2. 查看文件列表，移除不需要的文件。
3. 选择 **PDF 质量**级别。
4. 点击**转换为 PDF**。输出文件将以 `from_webps.pdf` 为名下载。

在内部，每张 WebP 图片都会通过浏览器的 canvas API 解码，然后使用 pdf-lib 嵌入 PDF。这意味着转换可在任何支持 WebP 解码的浏览器上运行（所有现代浏览器都支持）。

## 选项

**PDF 质量**控制嵌入图片时的压缩：

- **高质量**：保留最多细节。
- **中等质量**（默认）：均衡的输出。
- **低质量**：文件最小。

## 使用场景

- 将从网上下载并保存为 WebP 的图片转换为可打印的 PDF
- 将 Chrome 或 Edge 中的 WebP 截图整理进文档
- 用默认导出 WebP 的设计工具所导出的图片创建 PDF 作品集
- 将 WebP 图片归档为更通用、更易读取的格式

## 提示

- WebP 在嵌入 PDF 之前会在内部解码为 PNG，因此无损 WebP 图片在高质量设置下可保持其画质。
- 如果您同时有 WebP 和其他图片格式，请改用[图片转 PDF](./image-to-pdf)工具，它可以一次性接受所有格式。

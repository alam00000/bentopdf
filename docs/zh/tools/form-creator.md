# 创建 PDF 表单

从零开始，或在现有 PDF 上添加字段，设计专业的可填写 PDF 表单。可视化编辑器让您将文本字段、复选框、下拉菜单、单选按钮、签名字段等表单元素直接拖放到页面预览上。配置字段属性，设置条件显示规则，并导出完全交互式的 PDF 表单。

## 使用方法

1. 上传现有 PDF，**或** 点击 **创建空白 PDF** 从头开始。
2. 如果创建空白 PDF，请选择页面尺寸（Letter、A4、A5、Legal、Tabloid、A3 或自定义尺寸）。
3. 表单编辑器打开后，会显示字段类型工具栏和页面预览区域。
4. 从工具栏选择字段类型，然后在页面上点击以放置。
5. 拖动字段以调整位置，使用缩放手柄调整大小。
6. 点击字段打开属性面板，可设置字段名称、默认值、字体大小、对齐方式等。
7. 使用页面控件在各页之间切换。
8. 点击 **保存** 下载完成的可填写 PDF。

## 功能

- 拖放放置字段，带有可视化的缩放手柄
- 字段类型：文本输入、多行文本、复选框、下拉菜单、单选按钮、签名、日期、数字和条形码
- 属性面板，用于配置每个字段的名称、标签、默认值、字体大小、颜色、对齐方式和验证
- 字段动作和条件显示规则（根据其他字段的值显示或隐藏字段）
- 多页表单的页面导航
- 现有字段提取：自动检测并导入上传 PDF 中的表单字段
- 支持将上传的 PDF 和空白页面作为表单画布
- 多种页面尺寸预设，以及自定义尺寸
- 由 bwip-js 提供支持的条形码生成
- 单选按钮组管理

## 选项

**页面尺寸预设（适用于空白 PDF）：**

- Letter (8.5" x 11")
- A4 (210mm x 297mm)
- A5 (148mm x 210mm)
- Legal (8.5" x 14")
- Tabloid (11" x 17")
- A3 (297mm x 420mm)
- 自定义（指定宽度和高度）

**字段属性（因字段类型而异）：**

- 名称、标签和占位文本
- 默认值
- 字体、大小和颜色
- 文本对齐（左、中、右）
- 必填字段开关
- 只读开关
- 文本字段的最大长度
- 下拉菜单和单选按钮的选项列表
- 条件显示动作

## 使用场景

- 构建员工入职表单，包含个人信息文本字段和政策确认复选框
- 创建客户登记问卷，使用下拉菜单选择服务
- 设计带有计算字段和条形码标识的订单表
- 构建使用单选按钮进行合格或不合格评级的检查清单
- 创建调查表单，根据回答显示条件式的后续问题

## 小贴士

- 如果您上传了现有 PDF，工具会尝试提取其中已有的表单字段，让您可以编辑或补充它们。
- 使用单选按钮组功能创建互斥选项。同一单选组中的字段共享一个组名。
- 下载表单后在 [PDF 表单填写](./form-filler) 中打开测试，以验证字段行为。

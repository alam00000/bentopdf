# 移除限制

PDF 可以带有两种密码：用户密码（打开文件时需要）和所有者密码（控制您可以对文件执行的操作）。此工具会同时移除这两种密码以及所有相关限制，包括打印、编辑、复制和注释锁定。

## 工作原理

1. 上传 PDF 文件。
2. 如果 PDF 设置了所有者密码，请在**所有者密码**字段中输入。如果 PDF 只有使用限制而没有密码，请留空。
3. 点击**移除限制**。
4. 下载无限制的 PDF。

此工具使用 QPDF 的 `--decrypt` 和 `--remove-restrictions` 参数，生成干净且无限制的副本。

## 会被移除的内容

- 密码保护（用户密码和所有者密码）
- 打印限制
- 编辑限制
- 文本和图像复制限制
- 注释和评论限制
- PDF 中编码的所有其他安全限制

## 使用场景

- 解锁您自己拥有、但多年前设置的密码已记不清的 PDF
- 移除您有合法访问权限的文档的打印限制
- 为便于做笔记，启用参考资料的复制粘贴
- 为无法处理受限文档的无障碍工具准备 PDF

## 提示

- 如果设置了所有者密码，您必须知道该密码。此工具不会破解或暴力枚举密码。
- 如果您需要保持文件加密状态，只修改特定权限，请改用“更改权限”工具。
- 输出文件没有任何加密，收到它的人都可以随意打开。

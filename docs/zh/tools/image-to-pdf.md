# 图片转 PDF

通用的图片转 PDF 转换器。上传几乎任何格式的图片，并将它们合并为一个 PDF 文档。每张图片独占一页，页面大小与原始尺寸一致。

## 支持的格式

| 格式            | 扩展名                                 |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

这是 BentoPDF 所有图片转换器中支持格式最广的一个。如果您只需要某一种特定格式，可以改用对应的专用工具。

## 使用方法

1. 点击上传区域或将图片文件拖放进来。可以一次选择多个文件。
2. 查看文件列表。使用垃圾桶图标移除不需要的文件，或点击 **添加更多文件** 加入更多图片。
3. 从下拉菜单中选择 **PDF 质量** 级别。
4. 点击 **转换为 PDF**。该工具通过 PyMuPDF 引擎处理图片，并将结果下载为 `images_to_pdf.pdf`。

## 选项

**PDF 质量** 控制将图片嵌入 PDF 时应用的图片压缩：

- **高质量**：压缩最少，文件较大。最适合打印或归档。
- **中等质量**（默认）：均衡压缩。适合大多数用途。
- **低质量**：激进压缩，文件最小。适合邮件发送或快速分享。

HEIC 和 WebP 文件在嵌入前会自动转换为 PNG。这一过程是透明的，无需任何额外操作。

## 使用场景

- 将手机相机拍摄的扫描收据或文档合并为一个 PDF
- 用多种格式的图片制作摄影作品集或产品画册
- 无需安装桌面软件，即可将 iPhone 照片 (HEIC) 转换为可分享的 PDF
- 将 PSD 导出文件和截图汇总为交付给客户的设计稿
- 将一个文件夹中的旧版图片格式 (PNM、JXR、JP2) 归档为单个 PDF

## 小贴士

- 图片在 PDF 中的顺序与它们在文件列表中的顺序一致。请按您想要的顺序上传。
- 若要获得尽可能小的文件，请选择低质量。对于以文字为主的扫描件，视觉差异通常可以忽略。
- 如果您只有一种图片格式，专用转换器（JPG 转 PDF、PNG 转 PDF 等）能以更简单的界面得到相同的结果。

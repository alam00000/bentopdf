# OCR PDF

将扫描文档变成可搜索、可复制的 PDF。该工具使用 Tesseract OCR 识别图像中的文字，并在原始页面上叠加一层不可见的文本层，在保留视觉外观的同时，让内容完全可搜索。

## 使用方法

1. 上传扫描版 PDF 或基于图像的 PDF 文件。
2. 从可搜索的语言列表中选择文档中出现的一种或多种语言。
3. 可选：调整高级设置（分辨率、二值化、白名单）。
4. 点击 **开始 OCR**，并通过实时进度条监控进度。
5. 完成后，查看提取的文本，然后下载可搜索的 PDF 或纯文本 `.txt` 文件。

## 功能

- 多语言 OCR，带可搜索的语言选择器
- 不可见的文本层保留原始文档外观
- 处理期间显示实时进度条和日志输出
- 可将结果下载为可搜索的 PDF 或纯文本文件
- 可直接将提取的文本复制到剪贴板
- 三档分辨率，在速度和准确度之间取得平衡

## 选项

| 设置               | 取值                                                          | 默认值 | 用途                                           |
| ------------------ | ------------------------------------------------------------- | ------ | ---------------------------------------------- |
| **分辨率**         | 标准 (192 DPI)、高 (288 DPI)、超高 (384 DPI)                  | 高     | 更高的分辨率可提高小字的准确度，但耗时更长     |
| **二值化图像**     | 开 / 关                                                       | 关     | 通过转换为黑白来增强清晰扫描件的对比度         |
| **字符白名单预设** | 无、字母数字、数字 + 货币、仅字母、仅数字、发票、表单、自定义 | 无     | 限制识别的字符范围，以提高特定类型文档的准确度 |
| **字符白名单**     | 自由文本                                                      | 空     | 当预设设为自定义时，手动指定字符集             |

## 使用场景

- 让扫描的合同和发票可搜索，这样您就可以用 Ctrl+F 查找内容
- 从拍摄的文档或旧纸质记录中提取文本
- 使用发票预设处理收据，准确识别金额和日期
- 为满足合规要求，将仅含图像的扫描件制作为无障碍 PDF
- 批量提取扫描书籍或手册中的文本内容

## 小贴士

- 如果文档包含多种语言的内容（例如英文标题搭配日文正文），请选择多种语言。
- 对于文字褪色或对比度低的文档，请使用二值化选项，它可以显著提高识别准确度。
- 发票和表单白名单预设会忽略不相关的字符形状，从而大幅减少结构化文档上的误识别。

# BMP 转 PDF

将 Windows 位图 (BMP) 文件转换为 PDF。BMP 是一种未压缩的图像格式，至今仍见于旧系统、医学影像和工业扫描仪中。此工具无需安装任何软件即可将它们转换为 PDF。

## 支持的格式

| 格式 | 扩展名 |
| :--- | :----- |
| BMP  | `.bmp` |

## 工作原理

1. 点击上传区域或拖放您的 BMP 文件。
2. 查看文件列表。可以添加更多文件或移除不需要的文件。
3. 点击**转换为 PDF**。输出会以 `from_bmps.pdf` 下载。

每个 BMP 会被绘制到画布上，导出为 PNG，然后使用 pdf-lib 嵌入 PDF。页面尺寸与原始图像尺寸一致。

## 选项

此工具不提供额外的质量设置。图像以原始分辨率作为无损 PNG 嵌入 PDF。

## 使用场景

- 将以 BMP 存储的旧扫描文档转换为存档 PDF
- 将旧版 Windows 应用程序的 BMP 截图转为便于分享的文档
- 处理默认输出 BMP 的医学或工业扫描仪结果
- 将旧的图像档案迁移到更便于移植的格式

## 提示

- BMP 文件未经压缩，因此通常很大。由于图像在内部重新编码为 PNG，生成的 PDF 会小得多。
- 如果您的 BMP 文件与其他图像格式混在一起，请使用[图片转 PDF](./image-to-pdf)工具一次性批量转换。

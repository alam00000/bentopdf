# XML 转 PDF

将 XML 数据文件转换为易读的结构化 PDF 文档。原始 XML 功能强大，但对人类来说很难阅读。此工具会解析 XML 树，识别重复的数据结构，并将其渲染为横向 A4 PDF 中格式化的表格和章节。

## 支持的格式

| 格式 | 扩展名 | 说明                    |
| :--- | :----- | :---------------------- |
| XML  | `.xml` | 任何格式良好的 XML 文档 |

## 工作原理

1. 点击上传区域，或拖放您的 XML 文件。可以在同一批次中处理多个文件。
2. 查看文件列表。使用垃圾桶图标移除不需要的文件，或点击**添加更多文件**加入更多文件。
3. 点击**转换为 PDF**。工具使用浏览器内置的 DOMParser 解析 XML 结构，分析数据层次，并使用 jsPDF 的 auto-table 格式将其渲染为 PDF。
4. 单个文件会下载为 PDF。多个转换结果会打包为 `xml-to-pdf.zip`。

## 选项

无需手动配置。转换器会自动检测 XML 结构并选择合适的表格布局。输出使用横向 A4 方向，以容纳较宽的数据集。

## 使用场景

- 将数据库或 API 导出的 XML 数据转为可打印的报告
- 从 XML 配置文件创建易读的摘要
- 将基于 XML 的发票或交易日志转换为 PDF 以便留存记录
- 让 XML 站点地图或 RSS 订阅源以文档形式易于阅读

## 提示

- XML 必须格式良好。如果解析器遇到语法错误，转换会失败，并给出指明问题的描述性错误信息。
- 嵌套很深的 XML 结构会被展平为表格。为获得最佳效果，数据应包含子元素一致的重复同级元素。
- 转换过程中会显示进度更新，展示每个阶段：读取、解析、分析和渲染。

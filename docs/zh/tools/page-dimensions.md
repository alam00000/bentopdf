# 页面尺寸

一款诊断工具，会读取 PDF 中的每个页面，并报告其精确尺寸、方向、标准尺寸名称、宽高比、面积和旋转角度。适合在打印前发现混合尺寸页面，或记录收到的 PDF 的属性。

## 使用方法

1. 上传 PDF 文件。分析会自动开始，无需点击按钮。
2. 摘要面板会显示总页数、唯一页面尺寸的数量，以及文档是否包含混合尺寸。
3. 浏览包含每页详细信息的完整结果表。
4. 在点、英寸、毫米或像素之间切换显示单位。
5. 点击 **导出为 CSV** 保存数据。

## 报告字段

| 列       | 说明                                  |
| -------- | ------------------------------------- |
| 页码 #   | 连续页码                              |
| 尺寸     | 所选单位下的宽 x 高                   |
| 标准尺寸 | 匹配的名称（A4、Letter 等）或“自定义” |
| 方向     | 纵向或横向                            |
| 宽高比   | 以小数表示的宽高比                    |
| 面积     | 所选单位平方下的页面面积              |
| 旋转     | 页面旋转角度（度）                    |

## 功能

- 自动检测标准纸张尺寸（A3、A4、A5、Letter、Legal、Tabloid 等）
- 混合尺寸文档警告，并详细列出出现了哪些尺寸以及每种尺寸使用的页数
- 在点、英寸、毫米和像素（按 96 PPI）之间转换单位
- 导出 CSV，可用于电子表格或文档系统

## 使用场景

- 在将文档提交给印刷店之前，确认所有页面都是 A4
- 诊断合并后的 PDF 为何在某些页面上打印出意外的页边距
- 为元数据记录整理大型 PDF 档案的页面布局
- 找出需要修正的已旋转页面

## 小技巧

- 如果摘要显示“混合尺寸”，请在打印前使用修复页面尺寸工具进行统一。
- 旋转字段有助于识别显示正常但旋转属性非零的页面，这在某些工作流中可能引发问题。

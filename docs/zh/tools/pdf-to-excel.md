# PDF 转 Excel

从 PDF 中提取表格并保存为 Excel (`.xlsx`) 电子表格。每个检测到的表格都放在单独的工作表中，并标有表格编号和来源页面。表格检测由 PyMuPDF 提供支持，Excel 生成由 SheetJS 库提供支持。

## 使用方法

1. 点击拖放区域或将文件拖到其上以上传 PDF。
2. 点击 **转换** 开始提取表格。
3. 工具会扫描每一页的表格，然后构建 Excel 工作簿。
4. 下载 `.xlsx` 文件，每个表格对应一个工作表。

## 选项

此工具没有可配置的选项。所有检测到的表格都会被自动提取。

## 输出格式

- 一个 `filename.xlsx` 文件。
- **一个表格**：一个名为“Table”的工作表。
- **多个表格**：工作表名称为“Table 1 (Page 3)”、“Table 2 (Page 5)”等。工作表名称会被截断为 31 个字符（Excel 的限制）。

## 使用场景

- 将 PDF 财务报告转换为可编辑的电子表格以便进一步分析。
- 从供应商 PDF 中提取库存或订单表格。
- 将 PDF 表单或目录中的结构化数据导入 Excel 进行排序和筛选。
- 以非技术同事可以处理的格式归档 PDF 中的表格数据。

## 小技巧

- 如果工具报告“未找到表格”，说明 PDF 可能使用自由流动的文本布局，而不是结构化表格。请尝试 [PDF 转文本](./pdf-to-text) 来获取原始内容。
- 如需更简单的扁平格式，请使用 [PDF 转 CSV](./pdf-to-csv)。如需以多种格式按表格下载，请使用 [提取 PDF 表格](./extract-tables)。
- 查看工作表名称，以确定每个表格来自哪一页。

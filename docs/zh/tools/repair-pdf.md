# 修复 PDF

当 PDF 无法打开、显示乱码或在阅读器中触发错误时，此工具会尝试重建其内部结构。它使用 QPDF 的修复引擎，可以从多种类型的损坏中恢复数据，包括损坏的交叉引用表、被截断的数据流、无效的对象引用等。

## 工作原理

1. 上传一个或多个受损的 PDF 文件。
2. 点击**修复 PDF**。
3. 单个修复后的文件会直接下载。多个文件会生成 ZIP 压缩包。

该工具会使用 `--decrypt` 参数让每个文件通过 QPDF，这会强制 QPDF 读取并重写整个 PDF 结构，在此过程中修复可恢复的问题。

## 功能

- 一次操作批量修复多个 PDF
- 自动判断文件是否可恢复
- 处理多个文件时按文件报告成功或失败
- 使用 QPDF（WebAssembly），一个久经考验的 PDF 转换库

## 可以修复的问题

- 损坏或缺失的交叉引用表
- 因下载不完整而被截断的文件结尾
- 无效的对象编号和数据流长度
- 有缺陷的 PDF 生成器造成的轻微结构不一致
- 解密尝试失败留下的加密痕迹

## 无法修复的问题

- 大部分内容数据缺失的严重截断文件
- 使用您不知道的密码加密的 PDF
- 实际上并非 PDF 的文件（扩展名错误）
- PDF 内部的图像损坏（结构会被修复，但不会重新生成像素数据）

## 使用场景

- 从失败的邮件下载中恢复 PDF
- 打开由旧版或非标准 PDF 生成器生成的文件
- 修复在某个阅读器中可用、在另一个阅读器中无法打开的 PDF
- 为长期存储准备受损的归档文档

## 提示

- 如果修复失败，请先尝试在浏览器中打开文件。浏览器有自己的恢复逻辑，可能会渲染出足够的内容以便重新保存。
- 对于修复失败的加密 PDF，请先尝试解密 PDF，再修复解密后的输出。

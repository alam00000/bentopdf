# 添加附件

将一个或多个文件直接嵌入 PDF 文档。附件可以添加到文档级别（在任何 PDF 阅读器的附件面板中可见），也可以绑定到特定页面。

## 工作原理

1. 上传要添加附件的 PDF。
2. 使用附件拖放区选择要嵌入的文件（任意文件类型）。
3. 选择附件级别：**文档**（默认）或**页面**。
4. 如果选择页面级别，请输入页面范围（例如 `1-3` 或 `5`）。
5. 点击处理按钮。嵌入了您的文件的 PDF 会自动下载。

## 功能

- 可附加任意文件类型：图片、电子表格、压缩包、可执行文件等
- 支持文档级或页面级附件位置
- 一次操作可附加多个文件
- 显示所有已选附件的文件名和大小
- 输出保留原始 PDF 内容，并加入嵌入的文件

## 选项

| 选项         | 说明                                       |
| ------------ | ------------------------------------------ |
| **文档级别** | 将文件附加到整个 PDF，可从附件面板访问     |
| **页面级别** | 将文件附加到特定页面，通过页面范围输入指定 |

## 使用场景

- 将源数据（Excel 文件、CSV）与 PDF 报告打包在一起
- 将原始图片文件附加到摄影作品集 PDF
- 在合同或提案中嵌入支持文档
- 为培训手册的特定页面添加补充材料

## 提示

- 文档级附件在各 PDF 阅读器中的支持最广泛。页面级附件可能无法在所有查看器中显示。
- 附件没有文件大小限制，但嵌入非常大的文件会使 PDF 按比例增大。

# 工具参考

BentoPDF 提供 **130 多种工具** 来处理 PDF。所有工具完全在您的浏览器中运行，您的文件永远不会离开您的设备。

---

## 编辑与批注

使用一整套编辑工具修改、标记和增强您的 PDF 文档。

<div class="tool-grid">

- [**PDF 编辑器**](./edit-pdf)：批注、高亮、涂黑、评论、添加形状和图片、搜索和查看 PDF。
- [**编辑书签**](./bookmark)：添加、编辑、导入、删除和提取 PDF 书签。
- [**目录**](./table-of-contents)：根据 PDF 书签生成目录页。
- [**页码**](./page-numbers)：在文档中插入页码。
- [**添加页面标签**](./add-page-labels)：应用带有罗马数字、前缀和自定义起始值的 PDF 页面标签。
- [**Bates 编号**](./bates-numbering)：在一个或多个 PDF 文件中添加连续的 Bates 编号。
- [**添加水印**](./add-watermark)：在 PDF 页面上叠加文字或图片。
- [**页眉和页脚**](./header-footer)：在页面顶部和底部添加文本。
- [**反转颜色**](./invert-colors)：创建 PDF 的深色模式版本。
- [**扫描效果**](./scanner-effect)：让您的 PDF 看起来像扫描文档。
- [**调整颜色**](./adjust-colors)：微调亮度、对比度、饱和度等。
- [**背景颜色**](./background-color)：更改 PDF 的背景颜色。
- [**更改文字颜色**](./text-color)：更改 PDF 中文字的颜色。
- [**签署 PDF**](./sign-pdf)：绘制、输入或上传您的签名。
- [**添加图章**](./add-stamps)：使用批注工具栏为 PDF 添加图片图章。
- [**移除批注**](./remove-annotations)：清除评论、高亮和链接。
- [**裁剪 PDF**](./crop-pdf)：裁掉 PDF 中每一页的边距。
- [**PDF 表单填写**](./form-filler)：直接在浏览器中填写表单。也支持 XFA 表单。
- [**创建 PDF 表单**](./form-creator)：通过拖放文本字段创建可填写的 PDF 表单。
- [**移除空白页**](./remove-blank-pages)：自动检测并删除空白页。

</div>

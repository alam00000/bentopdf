# PDF 转 WebP

将 PDF 的每一页转换为 WebP 图像。在相同的感知质量下，WebP 生成的文件通常比 JPG 小 25-35%，是网页使用的理想选择。

## 使用方法

1. 点击拖放区域或将文件拖到其上以上传 PDF。
2. 调整 **质量** 滑块。
3. 点击 **转换** 处理文件。
4. 单个 `.webp` 文件或 ZIP 压缩包会自动下载。

## 选项

- **质量**：从 0% 到 100% 的滑块（默认 85%）。控制有损压缩级别。数值越高，保留的细节越多。

页面在内部以 2 倍比例渲染，生成的图像尺寸大约是 PDF 原始尺寸的两倍。

## 输出格式

- **单页**：`filename.webp`
- **多页**：`filename_webps.zip`，包含 `page_1.webp`、`page_2.webp` 等。

## 使用场景

- 为带宽有限的网站准备页面预览。
- 为社交媒体生成传单或宣传册的轻量图像版本。
- 将多页文档批量转换为经过网页优化的图像集。

## 小技巧

- 所有现代浏览器都支持 WebP。如需兼容旧版浏览器，请回退使用 [PDF 转 JPG](./pdf-to-jpg)。
- 80-85% 的质量在屏幕上通常与原图难以区分，同时能保持较小的文件大小。

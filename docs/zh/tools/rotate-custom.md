# 按自定义角度旋转

将 PDF 页面旋转任意角度，而不仅限于 90 度的倍数。每个页面都有自己的角度输入，您也可以使用批量控制一次性对所有页面应用同一角度。

## 工作原理

1. 上传 PDF 文件。每个页面都会渲染缩略图。
2. 每个页面都有一个数字输入框，显示其当前旋转角度。
3. 输入任意度数（正数或负数）来旋转特定页面，或使用每页的左/右按钮快速调整 90 度。
4. 使用顶部的**批量角度**输入为所有页面设置统一的旋转角度。
5. 点击处理按钮生成旋转后的 PDF。

## 功能

- 每页可自由输入度数（任意整数）
- 批量角度控制，可为每个页面设置相同的旋转
- 缩略图中实时预览旋转效果
- 每页快速旋转按钮，以 90 度为单位
- 缩略图延迟加载，使大型文档也能流畅运行

## 使用场景

- 将略微倾斜的扫描件校正几度
- 旋转页面以满足非标准的方向要求
- 对混合内容文档中的单个页面应用精确旋转
- 在初次批量旋转之后微调页面角度

## 提示

- 正值为顺时针旋转，负值为逆时针旋转。
- 应用批量角度字段时会覆盖所有页面各自的角度。如有需要，请在批量操作之后再设置单个页面的调整。
- 如需使用更简单的界面进行标准的 90/180/270 度旋转，请使用[旋转 PDF](./rotate-pdf)。

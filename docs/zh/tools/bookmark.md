# 编辑书签

书签编辑器让您完全掌控 PDF 的导航书签（也称为大纲）。您可以添加新书签、编辑现有书签、调整层级结构，并以 CSV 和 JSON 格式导入或导出书签数据。

## 使用方法

1. 点击或将文件拖入上传区域，上传您的 PDF。
2. 可选：勾选 **自动提取现有书签**，载入文档当前的书签树。
3. 编辑器会以分屏视图打开：左侧是 PDF 查看器，右侧是书签面板。
4. 输入书签标题并点击 **添加到页面**，即可创建指向当前页面的新书签。
5. 使用工具栏按钮重新排列、设置样式或删除书签。
6. 点击 **保存带书签的 PDF** 下载更新后的文件。

## 功能

- 可视化 PDF 查看器，支持页面导航、缩放控制和跳转到指定页码
- 一键为任意页面添加书签
- 直接在 PDF 上点击以设置精确的书签目标位置（拾取模式）
- 支持嵌套书签层级，可拖放排序
- 批量操作：选择多个书签，一次性更改颜色、样式或删除
- 书签搜索，可在大型书签树中快速找到条目
- 所有更改均支持撤销和重做
- 从 CSV（标题、页码、层级）或 JSON 文件导入书签
- 将书签导出为 CSV 或 JSON，便于在外部编辑
- 书签样式：颜色（红、蓝、绿、黄、紫）和字体样式（粗体、斜体、粗斜体）
- 快速导航：使用 Page Up/Page Down 键滚动页面

## 选项

- **自动提取现有书签**：勾选后，工具会在加载时读取并显示 PDF 当前的书签。
- **批量模式**：切换后可选择多个书签，并批量应用颜色、样式或删除操作。
- **全部展开/折叠**：快速显示或隐藏嵌套的子书签。

## 使用场景

- 为缺少书签的教材或手册添加目录
- 在 OCR 处理后重新整理扫描文档的书签结构
- 将书签导出为 CSV，在电子表格中编辑后再重新导入
- 清理页码引用错误的自动生成书签
- 在法律文书中添加彩色书签来标记重要章节

## 小提示

- 批量创建书签时请使用 CSV 导入。格式很简单：`title,page,level`，其中 level 1 表示顶层。
- 拾取模式可以让您点击 PDF 页面上的确切位置来设置书签目标，比只指定页码更精确。
- 在进行大幅修改之前先导出书签，作为备份。

# 反转颜色

将 PDF 中的每种颜色翻转为其反色。白色背景变为黑色，黑色文字变为白色，所有其他颜色则转为其互补色。这是为任何 PDF 创建“深色模式”版本的最快方法。

## 使用方法

1. 上传 PDF 文件。
2. 点击 **反转颜色** 开始处理。
3. 反转后的 PDF 会自动下载。

没有其他设置。该工具会将每一页渲染为图像，反转所有像素颜色，并将结果重新组装为新的 PDF。

## 功能

- 一键反转所有页面的颜色
- 处理文档中的每一页
- 保持原有的页面尺寸和布局
- 适用于任何 PDF，无论内容类型（文本、图片或混合）

## 使用场景

- 为教科书或手册创建深色模式版本，方便夜间舒适阅读
- 为无障碍需求准备高对比度版本的文档
- 反转因曝光不当而扫描的文档
- 为以图片为主的 PDF 生成负片版本，用于视觉分析

## 小贴士

- 由于该工具通过栅格化页面来应用效果，输出结果是基于图像的。文本将不再可选择或可搜索。如果您在反转后需要可搜索的文本，请将输出结果交给 OCR 工具处理。
- 如需更精细的颜色调整（亮度、对比度、饱和度），请改用 [调整颜色](./adjust-colors) 工具。
- 页数较多的大型 PDF 可能需要更长的处理时间，因为每一页都要单独渲染和反转。

# Markdown 转 PDF

功能齐全的 Markdown 编辑器，带有实时预览和一键导出 PDF。您可以从零开始编写、上传现有的 `.md` 文件，或从剪贴板粘贴内容。编辑器会实时渲染您的 Markdown，并使用浏览器内置的打印引擎导出带样式的 PDF。

## 支持的格式

| 输入       | 说明                 |
| :--------- | :------------------- |
| `.md` 文件 | 通过上传按钮上传     |
| 直接输入   | 在编辑器中输入或粘贴 |

## 使用方法

1. 打开 Markdown 转 PDF 工具。编辑器以分栏视图加载：左侧是 Markdown 源码，右侧是渲染后的预览。
2. 编写您的 Markdown、粘贴内容，或点击 **上传** 加载 `.md` 文件。
3. 使用工具栏中的主题滑块在浅色和深色主题之间切换。
4. 点击 **导出 PDF**（或按 `Ctrl/Cmd + S`），通过浏览器的打印对话框生成 PDF。

## 功能

除基础语法外，编辑器还支持大量 Markdown 功能：

- **标准 Markdown**：标题、粗体、斜体、链接、图片、列表、引用块、分隔线
- **代码块**，支持 15 种以上语言的语法高亮（JavaScript、TypeScript、Python、Go、Rust、SQL、Java、C#、C++、YAML、Bash 等）
- **Mermaid 图表**：流程图、时序图、ER 图和其他 Mermaid 图表类型可直接在预览中渲染
- **表格**，使用标准 Markdown 表格语法
- **任务列表**，带复选框
- **脚注**、**下标**、**上标**
- **定义列表**、**缩写**
- **表情符号** 支持（`:smile:` 会渲染为表情符号）
- **高亮**（`==marked text==`）和 **插入**（`++inserted text++`）
- **自动链接 URL**：纯 URL 会被转换为可点击的链接
- **目录** 生成
- 标题上的 **锚点链接**

## 使用场景

- 编写项目文档，并为相关方导出精美的 PDF
- 创建包含代码示例和 Mermaid 架构图的技术报告
- 将 GitHub README 转换为 PDF，以便离线使用或打印
- 使用任务列表和表格起草提案或规格说明
- 根据用 Markdown 写成的课堂笔记生成带样式的讲义

## 小贴士

- PDF 输出使用浏览器的打印为 PDF 功能。在 Chrome 中，您可以在保存前于打印对话框中自定义页边距和缩放。
- Mermaid 图表会在预览中渲染，但首次使用时可能需要稍等片刻进行初始化。
- 使用 `Ctrl/Cmd + S` 键盘快捷键即可导出，无需去点按钮。

# 校正 PDF

扫描文档很少是完全端正的。即使轻微的倾斜也会降低 OCR 的准确性，并让打印效果显得草率。此工具使用 OpenCV 的图像处理算法检测每页的倾斜角度，并将其旋转回水平。

## 使用方法

1. 上传一个或多个扫描 PDF。
2. 设置 **倾斜阈值**：检测到的倾斜低于该值的页面不会被改动。
3. 选择 **处理质量 (DPI)**：DPI 越高，检测越准确，但耗时更长。
4. 点击 **校正 PDF**。
5. 处理完成后，结果面板会显示每页检测到的角度以及是否已校正。

## 选项

| 设置         | 取值                  | 默认值 |
| ------------ | --------------------- | ------ |
| **倾斜阈值** | 0.1、0.5、1.0、2.0 度 | 0.5    |
| **处理 DPI** | 100、150、200、300    | 150    |

## 倾斜检测原理

工具会以所选 DPI 将每页渲染为图像，然后使用 OpenCV 检测内容中的主要线条角度。如果检测到的倾斜超过阈值，页面会按相反角度旋转以摆正。低于阈值的页面保持不变。

## 使用场景

- 整理批量扫描的合同或法律文件
- 为 OCR 处理准备扫描的收据或发票
- 校正平板扫描仪上纸张放置不一致的页面
- 提升数字化档案资料的视觉质量

## 小提示

- 如果需要为 OCR 实现像素级对齐，请将阈值降低到 0.1 度。
- 对大多数文档来说，150 DPI 速度快且准确。对于文字非常小或细节丰富的页面，请使用 300 DPI。
- 校正功能最适合带有清晰水平文本行的文档。对于以图片为主或带有斜向设计元素的页面，效果可能不佳。

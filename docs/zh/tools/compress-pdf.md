# 压缩 PDF

在不破坏文件的前提下缩小 PDF。压缩 PDF 由 [Hyper Compress](https://www.bentopdf.com/hyper-compress) 驱动，这是 BentoPDF 自研的压缩引擎。它会重新压缩图片，对字体进行子集化和合并，并清除嵌入缩略图和私有应用数据等冗余内容。PDF 仍然功能完整：文本依然可选，链接和表单字段继续可用。

Hyper Compress 已编译为 WebAssembly 并随 BentoPDF 一同发布，因此压缩可离线运行，在隔离网络的部署中也无需额外设置。

## 使用方法

1. 点击拖放区域或将文件拖入，上传一个或多个 PDF。
2. 选择 **压缩级别**：低、中、高或无损。
3. 可选：输入 **目标文件大小**，或展开 **自定义设置** 进行精细控制，包括 **转换为灰度**。
4. 点击 **压缩 PDF**。处理多个文件时，您会得到一个 ZIP 下载。

## 特殊文档

- **带数字签名的 PDF** 会原样返回，因为任何更改都会使签名失效。在自定义设置中开启 **覆盖内容保护**，即可移除签名并进行压缩；可见的签名仍会留在页面上，但文件不再处于签名状态。
- **PDF/A 文件** 在压缩后会失去 PDF/A 标记，这样文件就不会声称自己符合已不再满足的一致性要求。在自定义设置中开启 **保留 PDF/A**，可让文件保持合规。
- **受密码保护的 PDF** 的文件卡片上会显示密码字段。在此输入密码，Hyper Compress 会自行打开文件，无需单独的解锁步骤。如果有两个或更多锁定的文件，一个共用的字段即可解锁所有使用相同密码的文件。压缩后的副本没有密码；可使用 [加密 PDF](./protect-pdf) 重新添加。
- **没有文本层的扫描件** 可以通过自定义设置中的 **栅格化页面** 进一步缩小，它会将每一页替换为一张优化后的图片。对于任何含有可选文本的文档（包括经过 OCR 的扫描件），此项会被跳过，除非开启了 **覆盖内容保护**。开启后，文本页面也会变成图片，因此文本将无法选择，链接也会失效。

## 压缩级别

| 级别     | 图片质量 | 最大分辨率 | 适用场景           |
| -------- | -------- | ---------- | ------------------ |
| **低**   | 80       | 200 DPI    | 保持视觉质量       |
| **中**   | 50       | 150 DPI    | 日常文档           |
| **高**   | 20       | 72 DPI     | 邮件附件、网页上传 |
| **无损** | 图片不变 | 不变       | 归档副本           |

高级别还会取消嵌入 14 种标准 PDF 字体，以及在安全时取消嵌入 Arial 等相似字体。

## 目标文件大小

以 KB 或 MB 输入大小，Hyper Compress 会从您选择的级别开始，搜索仍能满足该大小的最佳图片质量。如果文档无法缩小到该大小，您会得到它能生成的最小版本，并看到相应提示。诸如 [压缩 PDF 至 1MB](https://www.bentopdf.com/compress-pdf-to-1mb) 之类的专用页面打开时，目标大小已预先填好。

## 自定义设置

展开自定义设置面板，可直接调整 Hyper Compress。选择压缩级别会将这些设置重置为该级别的值，而修改其中任何一项都会将级别切换为自定义。

- **覆盖内容保护**：默认情况下，Hyper Compress 不会改动已签名的 PDF，也不会栅格化含有文本的页面。开启后将绕过这两项限制。更改级别时它会保持开启。

- **图片**：图片质量、最大分辨率、强制重采样、颜色缩减、裁剪不可见的图片区域、移除备用图片、简化颜色配置文件、JPEG 2000 和无损模式
- **字体**：子集化、合并重复字体，以及取消嵌入标准字体及其相似字体
- **内容**：拼合批注、表单字段或链接
- **清理**：移除缩略图、应用数据、文章线程、网页抓取信息、结构树或输出意图
- **栅格化**：将页面替换为图片，适用于纯图像扫描件；文档含有可选文本时会跳过
- **输出**：保留 PDF/A，以及面向支持 Brotli 的 PDF 2.0 阅读器的 Brotli 压缩

## 使用场景

- 将 50 MB 的报告压缩到邮件附件限制以内
- 通过目标文件大小，让扫描件满足门户网站严格的上传限制
- 优化营销 PDF，加快网站下载速度
- 归档大量文档，节省存储成本
- 通过即时通讯应用分享 PDF 时减少移动数据用量

## 小提示

- 先从中级别开始。如果结果仍然太大，可设置目标文件大小或升级到高级别。
- 对于没有文本层的扫描件，请在自定义设置中开启栅格化页面。
- 自定义设置中的转换为灰度，可以显著减小以彩色内容为主的文档体积。

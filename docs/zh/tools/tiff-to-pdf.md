# TIFF 转 PDF

将 TIFF 文件转换为 PDF，包括多页 TIFF。TIFF 文件中的每一页（即“IFD”）都会成为输出 PDF 中的单独一页。这对于通常以多页 TIFF 存储的扫描文档、传真和医学图像尤其有用。

## 支持的格式

| 格式 | 扩展名          |
| :--- | :-------------- |
| TIFF | `.tiff`, `.tif` |

## 工作原理

1. 点击上传区域，或将 TIFF 文件拖放到此处。
2. 查看文件列表，并根据需要进行管理。
3. 点击**转换为 PDF**。结果会以 `from_tiff.pdf` 下载。

该工具使用 JavaScript TIFF 解码器解码每个 TIFF 文件，提取每一页的原始 RGBA 像素数据。每一页会被渲染到画布上，导出为 PNG，并嵌入 PDF。页面尺寸与原始 TIFF 页面一致。

## 选项

此工具不提供额外的质量设置。图像以其原始分辨率嵌入。

## 使用场景

- 将多页传真文档（TIFF-F）转换为更便于携带的 PDF 格式
- 将以 TIFF 存储的扫描文档档案转换为可搜索的 PDF（之后配合 OCR 工具使用）
- 处理使用 TIFF 的医学影像文件（病理切片、放射学导出文件）
- 将 GIS 或卫星影像 TIFF 文件转换为可分享的文档

## 提示

- 完整支持多页 TIFF。10 页的 TIFF 会生成 10 页的 PDF，无需先拆分 TIFF。
- 非常大的 TIFF 文件（数百兆字节）可能需要更长的处理时间，因为整个文件必须在浏览器内存中解码。
- 如果需要对生成的 PDF 进行 OCR，请在转换后使用 [OCR PDF](./ocr-pdf) 工具处理。

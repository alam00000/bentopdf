# 移除元数据

每个 PDF 都带有元数据，可能会泄露创建者、使用的软件、最后修改时间等信息。此工具会将其全部清除，包括信息字典、XMP 元数据流、文档 ID 和应用程序专用数据，留下一份不带任何来源痕迹的干净文档。

## 工作原理

1. 上传 PDF 文件。
2. 点击**移除元数据**。
3. 下载清理后的文件。

无需配置选项。该工具在设计上追求彻底：清除一切。

## 会被移除的内容

- **信息字典字段**：标题、作者、主题、关键词、创建者、生成程序、创建日期、修改日期
- **XMP 元数据流**：存储在文档目录中的基于 XML 的元数据块
- **文档 ID**：PDF 尾部中的唯一标识符，可用于跨系统追踪文档
- **PieceInfo**：由 Illustrator 或 InDesign 等程序添加的应用程序专用元数据

## 会保留的内容

- 所有可见的页面内容（文本、图片、图形）
- 表单字段和注释
- 书签和链接
- 文档结构本身

## 使用场景

- 在匿名发布文档之前移除您的姓名和所属组织
- 清除会暴露文档准备时间的创建时间戳
- 清理标识您 PDF 软件栈的生成程序字符串
- 为要求无元数据 PDF 的监管提交准备文档
- 在对外分享文档之前移除编辑历史痕迹

## 提示

- 在清除之前，请先使用查看元数据工具，确切了解您的 PDF 包含哪些元数据。
- 如果您需要同时移除元数据以及 JavaScript、注释和嵌入文件，请使用清理 PDF 进行更彻底的清理。
- 元数据移除是永久性的。如果以后可能需要这些数据，请保留原始文件。

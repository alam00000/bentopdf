# PUB 转 PDF

将 Microsoft Publisher 文件转换为 PDF。Publisher 是部分 Microsoft Office 版本附带的桌面排版工具，但大多数人并没有安装。使用此工具，任何人都可以直接在浏览器中将 PUB 文件转换为 PDF，无需 Microsoft 软件。

## 支持的格式

| 格式                | 扩展名 | 说明         |
| :------------------ | :----- | :----------- |
| Microsoft Publisher | `.pub` | 桌面排版文档 |

## 工作原理

1. 点击上传区域或将 PUB 文件拖放到此处。可一次上传多个文件。
2. 查看文件列表。使用垃圾桶图标移除不需要的文件，或点击**添加更多文件**加入更多文件。
3. 点击**转换为 PDF**。基于 LibreOffice 的引擎会在浏览器中加载并转换每个 PUB 文件，保留版面、图片和文本框。
4. 单个文件会直接下载为 PDF。多个文件会打包为名为 `pub-to-pdf.zip` 的 ZIP 压缩包。

## 选项

无需额外配置。转换器会自动处理 PUB 排版引擎。

## 使用场景

- 无需购买 Microsoft Publisher，即可打开客户发来的 PUB 传单或简报
- 转换用 Publisher 制作的教会公告、活动节目单或学校通讯
- 将 Publisher 制作的营销材料以通用格式归档
- 在未安装 Publisher 的系统上打印 PUB 文件

## 提示

- 包含多层文本框和精确定位的复杂 Publisher 版面在转换过程中可能会有轻微位移。如果精确位置很重要，请检查输出结果。
- LibreOffice 引擎每个会话只初始化一次。第一次转换耗时较长，之后会更快。
- 为了让 Publisher 文件的转换最为忠实，请确保原文件中使用的自定义字体是标准系统字体。

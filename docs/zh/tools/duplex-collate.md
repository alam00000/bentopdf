# 双面扫描整理

双面扫描整理专为 ADF 扫描流程设计，适用于一个 PDF 包含两个页面区块的情况：

- 先是所有正面
- 然后是所有背面

无需手动拆分再重新组装，此工具会将两个区块交错排列成自然的阅读顺序：正面 1、背面 1、正面 2、背面 2，依此类推。

## 使用方法

1. 上传一个由双面纸堆扫描生成的 PDF。
2. 设置正面区块结束的分割点。
3. 选择背面区块的处理方式：
   - **反转背面区块**（扫描背面前翻转了纸堆时常用）
   - **保持背面区块原样**
4. 点击 **整理 PDF**，下载重新排序后的结果。

## 选项

- **自动检测分割点（一半）**：将分割点设置为 `ceil(totalPages / 2)`。
- **奇数页警告**：总页数为奇数时发出警告（通常意味着扫描不匹配）。
- **区块不均等确认**：正面和背面区块大小不同时，要求确认。
- **分组导出**：根据原始文档页数，将整理后的输出拆分为多个 PDF，并以 ZIP 下载。

## 输出行为

- **默认**：输出一个 PDF（输入单个 PDF，输出单个 PDF）。
- **分组模式**：输出按您设置的每文档页数分块；如果产生多个分块，会作为一个 ZIP 下载，否则下载单个 PDF。

如果区块大小不均等，会先整理成对的页面，剩余未配对的页面则追加在末尾。

## 常见使用场景

- 分两次扫描一堆双面表格后恢复页面顺序。
- 为先输出所有正面再输出所有背面的办公扫描仪重建正反面文档包。
- 在拆分为单个文档文件之前，对归档扫描件进行后期处理。

## 小提示

- 大多数双面批次的总页数应为偶数。
- 如果背面看起来是颠倒的，请在 **反转背面区块** 和 **保持背面区块原样** 之间切换。
- 对于 2 页的原件（正面加背面），请使用分组导出，并将每文档页数设为 `2`。

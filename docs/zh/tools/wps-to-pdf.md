# WPS 转 PDF

将 Microsoft Works 文字处理文件转换为 PDF。Microsoft Works 在 20 世纪 90 年代末至 21 世纪初预装在大量家用电脑上，许多 WPS 文件仍保存在旧硬盘和邮件存档中。此工具可在浏览器中打开它们，并生成简洁的 PDF。

## 支持的格式

| 格式            | 扩展名 | 说明                           |
| :-------------- | :----- | :----------------------------- |
| Microsoft Works | `.wps` | Microsoft Works 的文字处理文件 |

## 工作原理

1. 点击上传区域，或拖放您的 WPS 文件。支持多个文件。
2. 查看文件列表。使用垃圾桶图标移除单个文件，或点击**添加更多文件**扩充批次。
3. 点击**转换为 PDF**。基于 LibreOffice 的引擎会在浏览器中加载，并将每个 WPS 文档转换为 PDF。
4. 单个文件会直接下载为 PDF。多个文件会打包为名为 `wps-to-pdf.zip` 的 ZIP 压缩包。

## 选项

无需额外设置。转换器会处理 WPS 文件中的文本、基本格式和嵌入的图片。

## 使用场景

- 恢复以 Microsoft Works 格式保存的旧学校或工作文档
- 在没有安装 Microsoft Works 时打开 WPS 邮件附件
- 转换一批 WPS 文件，以便迁移到现代文档系统
- 打印当前文字处理软件无法打开的旧文档

## 提示

- 请勿将 Microsoft Works 的 `.wps` 文件与 WPS Office 文件混淆。此工具专用于较旧的 Microsoft Works 格式。
- LibreOffice 引擎在首次使用时需要一点时间加载。加载完成后，同一会话中的后续转换会更快。

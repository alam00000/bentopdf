# 提取页面

从 PDF 中取出一组页面并保存为新文件。使用范围语法准确指定所需页面，工具会创建仅包含这些页面的干净 PDF。

## 使用方法

1. 上传 PDF 文件。工具会显示文件名、大小和总页数。
2. 使用范围语法输入要提取的页面（例如 `1-5`、`3, 7, 10-12`）。
3. 可选：选择将每个范围作为单独的 PDF 放入 ZIP 压缩包下载。
4. 点击处理按钮。提取的页面会下载为新的 PDF（或 ZIP）。

## 功能

- 灵活的页面范围语法：单个页面、范围或以逗号分隔的组合
- 上传后显示总页数，方便参考
- 可选择输出为单个合并 PDF，或 ZIP 中的多个独立文件
- 保留原始页面内容和格式

## 使用场景

- 从冗长的报告中取出执行摘要（前几页）
- 从教科书 PDF 中提取单个章节
- 将表单包中的特定页面保存为独立文档
- 从较大文件的选定页面创建示例文档

## 小提示

- 页码从 1 开始。第一页请使用 `1`，而不是 `0`。
- 如果要移除页面而不是提取页面，请使用 [删除页面](./delete-pages)，它是相反的操作。
- 如果您需要带缩略图的可视化页面选择，请在可视化选择模式下使用 [分割 PDF](./split-pdf)。

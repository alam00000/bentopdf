# 裁剪 PDF

通过可视化裁剪界面修剪 PDF 页面的边距。直接在每个页面上绘制裁剪矩形，预览结果并应用裁剪。您可以为不同页面设置不同的裁剪区域，也可以对整个文档应用相同的裁剪。

## 使用方法

1. 上传您的 PDF 文件。
2. 裁剪编辑器打开，显示第一页和可拖动的裁剪叠加层。
3. 拖动边缘或角点来调整裁剪矩形。
4. 使用页面导航按钮在页面之间切换，并为每页设置裁剪区域。
5. 点击 **裁剪** 应用裁剪并下载结果。

## 功能

- 基于 Cropper.js 的可视化裁剪编辑器，带有用于精确调整的手柄
- 逐页导航，可设置各自的裁剪区域
- 按页面保存裁剪设置，因此可以为不同页面定义不同的裁剪
- 实时预览所选裁剪区域
- 支持任意页面尺寸或方向的 PDF

## 使用场景

- 去除扫描文档的宽边距，聚焦内容区域
- 从印前 PDF 中修剪打印裁切标记或套准标记
- 裁剪讲义幻灯片，去除演讲者备注区域
- 在分享文档节选前，去除每页的页眉或页脚
- 调整页面大小，以适应特定的显示或打印版式

## 小提示

- 裁剪叠加层可以自由调整大小和位置。拖动角点可按比例缩放，拖动边缘可沿单个轴调整。
- 如果每页都需要相同的裁剪，请在第一页上设置，工具会在您切换页面时记住裁剪区域。
- 如果您需要统一页面尺寸而不是可视化裁剪，修正页面尺寸工具可能更合适。

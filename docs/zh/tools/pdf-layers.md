# PDF 图层 (OCG)

管理 PDF 中的可选内容组 (OCG)，通常称为“图层”。您可以切换图层可见性、添加新图层（包括嵌套的子图层）、删除图层，并保存修改后的 PDF。

## 使用方法

1. 上传 PDF 文件。
2. 点击处理按钮，使用 PyMuPDF 引擎加载文档。
3. 工具会显示所有现有图层及其可见状态、锁定状态和嵌套层级。
4. 勾选或取消勾选复选框以显示或隐藏图层。锁定的图层无法切换。
5. 输入名称并点击添加按钮来添加新的顶级图层，或在现有父图层下添加子图层。
6. 删除不再需要的图层。
7. 点击 **保存**，下载应用了图层更改的修改后 PDF。

## 功能

- 以适当的缩进显示图层层级和嵌套图层
- 切换图层可见性的开或关
- 锁定图层标识可防止意外更改
- 使用自定义名称添加顶级或子图层
- 删除单个图层
- 将所有更改保存到新的 PDF 文件中

## 使用场景

- 切换建筑或工程图纸中标注图层的可见性
- 为多图层设计文档添加新的注释图层
- 在分发模板之前移除过时的图层
- 检查从第三方收到的复杂 PDF 中包含哪些图层

## 小技巧

- 如果 PDF 没有图层，工具会显示空状态并提示添加图层。并非所有 PDF 都使用 OCG 图层，它们在 CAD 导出文件和设计文件中最为常见。
- 子图层会在其父图层下缩进显示。您可以嵌套任意深度的图层。
- 锁定的图层会显示锁图标，其复选框被禁用。这些锁定由 PDF 创建者设置。

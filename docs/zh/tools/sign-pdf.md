# 签署 PDF

为任意 PDF 文档添加您的签名。该工具嵌入了完整的 PDF 查看器和内置签名工具，您可以手绘签名、用签名字体键入姓名，或上传签名图片。可在任意页面放置并调整签名大小，然后保存已签署的文档。

## 工作原理

1. 上传您的 PDF 文件。
2. 文档会在带有注释工具的集成 PDF 查看器中打开。
3. 使用查看器的签名工具，通过手绘、键入或上传图片来创建签名。
4. 点击页面上想要放置签名的位置，并调整其大小和位置。
5. 可选：勾选**扁平化 PDF**，将签名永久嵌入文档。
6. 点击**保存并下载已签署的 PDF** 获取已签署的文件。

## 选项

- **扁平化 PDF**：勾选后，签名会被永久嵌入页面内容。这可以防止他人移动或删除签名。未勾选时，签名仍是注释，可在兼容的查看器中编辑。

## 功能

- 三种创建签名的方式：手绘、键入文本或上传图片
- 集成的 PDF 查看器，放置位置准确
- 可在任意页面拖动定位并调整签名大小
- 可选扁平化，永久嵌入签名
- 支持在同一文档中添加多个签名

## 使用场景

- 在寄回合同、协议或审批表之前进行签署
- 在税务文件、保险理赔或政府表格上添加您的签名
- 在多页协议的各页上签署姓名缩写
- 签署以 PDF 附件形式收到的保密协议或人事文件

## 提示

- 如果您要将已签署的 PDF 发送给不应能够移除或重新定位您签名的人，请启用扁平化。
- 如需具有法律约束力、基于证书验证的数字签名，BentoPDF 还提供独立的 PDF 数字签名工具。
- 上传背景透明的 PNG 签名图片可获得最干净的效果。

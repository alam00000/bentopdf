# 解锁 PDF

如果您知道加密 PDF 的密码，此工具可以完全移除加密，生成任何人无需凭据即可打开的解锁副本。当多个 PDF 使用同一密码时，支持批量解密。

## 工作原理

1. 上传一个或多个加密的 PDF 文件。
2. 输入用于保护这些文件的**密码**。
3. 点击**解密 PDF**。
4. 单个文件会直接下载。多个文件会生成包含所有已解锁 PDF 的 ZIP 压缩包。

## 功能特点

- 支持单文件和批量解密
- 同时支持用户密码和所有者密码
- 输出完全未加密，不残留任何限制
- 对密码错误或文件损坏给出清晰的错误提示
- 批量模式下按文件记录成功/失败状态

## 与移除限制的区别

**解密 PDF** 需要密码，并会移除所有加密。**移除限制**针对使用限制（打印、复制、编辑），如果只设置了所有者密码，可能不需要密码。当 PDF 没有密码就完全无法打开时，请使用解密。

## 使用场景

- 当不再需要密码时，永久解锁您之前加密的 PDF
- 移除一批归档文档的加密，方便长期访问
- 为不支持加密文件的文档管理系统准备受密码保护的 PDF
- 在与其他文档合并之前解锁 PDF（许多合并工具无法处理加密的输入）

## 提示

- 密码字段适用于所有上传的文件。如果您的 PDF 密码各不相同，请分批处理。
- 如果出现“密码错误”提示，请检查是否有多余的空格或是否开启了大写锁定。
- 解密后，输出文件没有任何安全保护。如果需要设置新密码，请使用加密 PDF 重新加密。

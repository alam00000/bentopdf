# PDF 工作流构建器

工作流构建器可让您将多个 PDF 操作串联成一个自动化流水线。无需逐个运行工具，您只需连接由输入、处理和输出节点组成的可视化图，然后一键执行所有操作。您的文件始终不会离开浏览器。

## 使用方法

界面分为三个面板：左侧的 **节点工具箱**，中间的 **画布**，以及选中节点时出现在右侧的 **设置面板**。

1. **添加节点**：点击左侧边栏中的节点，或将其直接拖到画布上。使用工具箱顶部的搜索栏按名称筛选。
2. **连接节点**：从一个节点的输出接口（节点底部）拖动到另一个节点的输入接口（节点顶部）。连接自上而下流动。
3. **配置设置**：点击节点以打开右侧的设置面板。每种节点类型都有自己的选项（页面范围、质量滑块、密码等）。
4. **运行工作流**：点击工具栏中的 **运行** 按钮。引擎会按拓扑顺序执行节点，依次处理每个节点。底部的状态栏会跟踪进度。
5. **下载结果**：末端的下载节点会保存最终的 PDF（如果生成多个文件则为 ZIP）。

## 节点类别

节点分为六个类别，在画布上以不同颜色标识：

- **输入**（蓝色）：PDF 输入、图片输入、Word/Excel/PowerPoint 转 PDF，以及其他 15 种以上将文件送入流水线的格式转换器。
- **编辑与注释**（靛蓝色）：裁剪、灰度、反转颜色、水印、页码、页眉和页脚、扫描效果、调整颜色、背景颜色、移除空白页、移除注释。
- **组织与管理**（紫色）：合并、分割、提取页面、旋转、删除页面、反转、添加空白页、分割页面、N-Up、修复页面尺寸、合并为单页、小册子、海报化、编辑元数据、目录、OCR。
- **优化与修复**（琥珀色）：压缩、栅格化、线性化、校正、PDF 转 PDF/A、字体转轮廓、修复。
- **PDF 安全**（玫红色）：加密、解密、清理、扁平化、数字签名、涂黑。
- **输出**（青色）：下载（自动检测单个 PDF 还是 ZIP）、PDF 转图片、PDF 转文本、PDF 转 DOCX、PDF 转 XLSX、PDF 转 CSV、PDF 转 SVG、PDF 转 Markdown、提取图片。

## 保存和加载工作流

工具栏提供四种持久化选项：

- **保存**：将当前工作流作为命名模板存储在浏览器的本地存储中。您可以保存多个模板。
- **加载**：打开一个列出所有已保存模板的弹窗。点击加载以恢复某个模板，或删除不再需要的模板。
- **导出**：将工作流下载为 `.json` 文件，以便分享或备份。
- **导入**：从磁盘加载 `.json` 工作流文件，恢复所有节点、位置和连接。

模板会在本地存储中跨会话保留。导出的 JSON 文件可在不同浏览器和机器之间移植。

## 执行模型

引擎会根据您的连接构建依赖图，并按拓扑顺序执行节点。如果任何节点失败，执行会停止，失败的节点会被标红。需要记住几条规则：

- 每个工作流至少需要一个 **输入** 节点和一个 **输出** 节点。
- 引擎会检测循环依赖，并以错误阻止执行。
- **加密** 节点必须是输出节点之前的最后一个处理步骤。将其放在更前面会触发验证警告，因为下游节点无法处理已加密的数据。
- 受密码保护的 PDF 会在执行期间提示输入密码。
- 支持多 PDF 输入：合并节点可以将它们合并，批处理节点则会逐个处理每个 PDF。

## 接口类型

连接使用带类型的接口，以防止无效连线：

- **PDF**（靛蓝色）：单个 PDF 文档。
- **MultiPDF**（琥珀色）：打包在一起的多个 PDF 文档。
- **Image**（绿色）：图片二进制数据。

## 选项

每个节点都有自己的配置，可通过右侧设置面板访问。常见模式包括：

- 分割、提取页面、删除页面节点上的 **页面范围**
- 图片转换输出节点上的 **质量滑块**
- 加密和解密节点上的 **密码字段**
- 水印、页眉和页脚、编辑元数据的 **文本输入**
- 旋转节点上的 **旋转角度**
- 压缩节点上的 **压缩级别**
- OCR 节点上的 **OCR 语言选择**

## 使用场景

- **发票处理流水线**：PDF 输入 -> OCR -> 提取 PDF 表格 -> 下载为 CSV。
- **报告标准化**：Word 转 PDF -> 修复页面尺寸 -> 添加页码 -> 水印 -> 压缩 -> 下载。
- **归档准备**：PDF 输入 -> 修复 -> 扁平化 -> 清理 -> PDF 转 PDF/A -> 下载。
- **批量图片提取**：PDF 输入（多个文件） -> 提取图片 -> 下载 ZIP。
- **可直接印刷的小册子**：PDF 输入 -> 小册子 -> 裁剪 -> 压缩 -> 下载。
- **安全分发**：PDF 输入 -> 涂黑 -> 移除注释 -> 加密 -> 下载。

## 小技巧

- 使用 **Delete** 或 **Backspace** 从画布上移除选中的节点。
- 点击节点状态栏上的 **X** 按钮可直接将其删除。
- 点击并拖动空白处即可平移画布。平移时光标会变为抓取图标。
- 在移动设备上，使用工具栏中的 **+** 按钮切换节点工具箱。
- 如果您的工作流生成多个输出文件，下载节点会自动将它们打包为 ZIP。
- 从简单开始：在增加复杂度之前，先构建并测试一个包含两个节点的流水线。

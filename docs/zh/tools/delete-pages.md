# 删除页面

从 PDF 文档中移除不需要的页面。您可以输入页码或范围来指定要删除的页面，也可以直接点击页面缩略图将其标记为删除。

## 使用方法

1. 上传 PDF 文件。工具会渲染每一页的缩略图预览。
2. 在文本框中使用范围语法（例如 `2, 5-8`）输入要删除的页面，或点击缩略图进行切换。
3. 被标记的页面会高亮显示，方便您确认选择。
4. 点击处理按钮。系统会创建一个已移除所选页面的新 PDF。

## 功能

- 基于文本的页面选择，支持范围语法（`2, 5-8, 12`）
- 可视化缩略图网格，点击即可选择要删除的页面
- 实时预览高亮显示被标记删除的页面
- 根据实际页数验证输入
- 未删除的页面保持原有顺序

## 使用场景

- 从扫描文档中移除空白页或填充页
- 在分享文档前去除封面页或附录
- 清理不小心留在最终 PDF 中的草稿页
- 在分发前移除含有敏感信息的页面

## 小提示

- 删除页面不会影响其余页面的内容或格式。输出是原始文档去掉被移除页面后的忠实副本。
- 如果您想只保留特定页面，而不是移除特定页面，[提取页面](./extract-pages) 更合适。
- 缩略图视图采用延迟加载，因此大型文档也能保持流畅响应。

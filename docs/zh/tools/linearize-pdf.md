# 线性化 PDF

线性化会重新组织 PDF 的结构，使第一页无需等待整个文件下载完毕即可显示。Adobe 将此称为“快速网页视图”。如果您在网站上托管 PDF，或通过文档门户提供 PDF，线性化会让它们打开起来明显更快。

## 使用方法

1. 上传一个或多个 PDF 文件。
2. 点击 **线性化 PDF**。
3. 下载包含所有线性化文件的 ZIP 压缩包。

无需任何设置。该工具使用 QPDF 的 `--linearize` 标志，在不改变视觉内容的前提下重新排列 PDF 的内部结构。

## 线性化的作用

- 重新排列 PDF 对象，使第一页的数据位于文件开头
- 添加线性化字典和提示表，让查看器知道每一页的位置
- 支持字节范围请求：浏览器只需获取第一页，而无需下载整个文件
- 整理交叉引用表，以便高效地随机访问

## 功能

- 一次操作批量处理多个 PDF
- 输出保留所有内容、字体、图片和交互元素
- 使用 QPDF (WebAssembly) 实现可靠且符合标准的线性化
- 结果打包为 ZIP，便于下载

## 使用场景

- 在网站上托管 PDF 报告，让用户立即看到页面
- 在带有浏览器内查看器的 Web 应用中嵌入 PDF
- 发布在慢速移动网络下访问的 PDF 目录或手册
- 为支持字节范围服务的内容分发网络 (CDN) 准备文档

## 小贴士

- 请在完成所有其他编辑之后再线性化。之后的任何修改（合并、添加页面）都会破坏线性化。
- 与压缩 PDF 结合使用，可得到体积最小、加载最快的 PDF。
- 线性化会让文件体积略有增加（通常不到 1%）。

# 分割 PDF

使用六种拆分模式之一将 PDF 拆分为较小的文档。从简单的页面范围到基于书签的拆分，此工具可应对各种文档分割场景。

## 工作原理

1. 上传单个 PDF 文件。
2. 从下拉菜单中选择拆分模式。
3. 配置该模式的专属选项（页面范围、选择内容等）。
4. 点击处理按钮。
5. 根据模式和设置，结果会以单个 PDF 或 ZIP 压缩包的形式下载。

## 拆分模式

| 模式            | 说明                                                                                         |
| --------------- | -------------------------------------------------------------------------------------------- |
| **范围**        | 输入页面范围，如 `1-3, 5, 8-10`。多个范围会在 ZIP 中生成多个独立 PDF，单个范围生成一个 PDF。 |
| **可视化选择**  | 浏览页面缩略图并点击选择所需页面。所选页面会被提取到新的 PDF 中。                            |
| **偶数 / 奇数** | 仅提取偶数页或奇数页。                                                                       |
| **所有页面**    | 将每一页拆分为独立的 PDF 文件，以 ZIP 下载。                                                 |
| **书签**        | 在书签边界处拆分。可选择书签级别来控制拆分位置。                                             |
| **每 N 页**     | 按每 N 页一组拆分（例如每 5 页）。最后一组的页数可能较少。                                   |

## 功能

- 六种不同的拆分模式，几乎涵盖所有使用场景
- 可视化页面选择器，缩略图延迟加载
- 支持按书签拆分，并可筛选级别
- 范围和可视化模式可选 ZIP 输出
- 支持混合语法的页面范围（`1-3, 5, 8-10`）
- 按 N 页拆分导致分组不均时给出警告

## 使用场景

- 从大型文档中提取特定章节或部分
- 为双面打印流程分离奇数页和偶数页
- 在书签边界处将整本书的 PDF 拆分为单独的章节文件
- 从合同中单独取出特定页面（如签字页）
- 将汇编的报告拆分为按部分划分的文件以便分发

## 提示

- 以逗号分隔的多个页面范围（例如 `1-5, 10-15, 20-25`）会生成多个独立的 PDF（每个范围一个），并打包在 ZIP 中。
- 书签拆分模式要求 PDF 确实包含书签。如果未找到书签，您将看到错误消息。
- 在范围和可视化模式中，“下载为 ZIP”复选框可让您获得每页一个的独立 PDF，而不是合并的文件。

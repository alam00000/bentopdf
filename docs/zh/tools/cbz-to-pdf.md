# CBZ 转 PDF

将漫画压缩包文件转换为 PDF。CBZ 和 CBR 是数字漫画的标准格式，本质上就是装满图片的 ZIP 或 RAR 压缩包。此工具会提取每一页，保留阅读顺序，并生成干净的 PDF，每张图片都会变成一个全尺寸页面。

## 支持的格式

| 格式 | 扩展名 | 说明                                             |
| :--- | :----- | :----------------------------------------------- |
| CBZ  | `.cbz` | 基于 ZIP 的漫画压缩包（使用 pdf-lib 在本地处理） |
| CBR  | `.cbr` | 基于 RAR 的漫画压缩包（通过 PyMuPDF 引擎处理）   |

CBZ 转换器可识别压缩包内的 JPEG、PNG、GIF、BMP、WebP、AVIF、TIFF、HEIC 和 JXL 图片。非标准格式会在嵌入前自动转换为 PNG。

## 使用方法

1. 点击上传区域，或拖放您的 CBZ 或 CBR 文件。可以在同一批次中混用两种格式。
2. 查看文件列表。移除不需要的文件，或点击 **添加更多文件** 继续添加。
3. 点击 **转换为 PDF**。对于 CBZ 文件，工具会解压压缩包，按自然顺序按名称排序图片文件，检测每张图片的实际格式，并使用 pdf-lib 将它们嵌入 PDF。CBR 文件则改由 PyMuPDF 引擎处理。
4. 单个文件会直接下载为 PDF。多个文件会生成名为 `comic-converted.zip` 的 ZIP 压缩包。

## 选项

无需任何配置。每张图片都会成为与其原始尺寸一致的页面，因此跨页大图保持宽幅，单页保持窄幅。

## 使用场景

- 在支持 PDF 但不支持 CBZ/CBR 的平板或手机应用中阅读漫画
- 打印数字漫画中的特定页面
- 将漫画收藏归档为任何文件查看器都能打开的格式
- 与没有专用漫画阅读器的人分享漫画

## 小提示

- 压缩包内的图片按自然顺序排序（因此 `page2.jpg` 会排在 `page10.jpg` 之前）。请使用编号一致的文件名，以确保页面顺序正确。
- 转换器通过二进制签名而不是文件扩展名来检测图片格式。即使 PNG 被误命名为 `.jpg`，也能正确嵌入。
- CBZ 文件完全在浏览器中处理，无需加载 PyMuPDF 引擎，因此转换速度比 CBR 文件更快。

# 查看元数据

查看嵌入在 PDF 文件中的隐藏属性。该工具会以易读的格式显示文档信息（标题、作者、日期）、XMP 元数据、页面尺寸和其他结构数据。

## 工作原理

1. 上传 PDF 文件。
2. 工具会立即解析文件，并分区显示所有可用的元数据。
3. 查看文档信息字典、XMP 元数据树和结构属性。
4. 无需处理步骤：文件加载后即会显示元数据。

## 功能特点

- 显示标准文档信息字段：标题、作者、主题、关键词、创建者、生成器
- 以易读格式显示创建和修改日期
- 解析并呈现包含嵌套命名空间的完整 XMP 元数据树
- 将 PDF 日期格式（`D:20240101120000Z`）转换为易读的日期
- 按可折叠分区组织，便于浏览

## 元数据分区

| 分区           | 内容                                                                 |
| -------------- | -------------------------------------------------------------------- |
| **文档信息**   | 标题、作者、主题、关键词、创建者、生成器、创建日期、修改日期         |
| **XMP 元数据** | 基于 XML 的完整元数据树，包含 Dublin Core、XAP、PDF 和自定义命名空间 |
| **文档属性**   | 页数、PDF 版本、文件大小、加密状态                                   |

## 使用场景

- 查看 PDF 的作者以及最后修改时间
- 在发布文档之前确认元数据已正确设置
- 通过检查嵌入了哪些个人信息来审计 PDF 的隐私
- 通过生成器字段调查创建或修改 PDF 所用的软件
- 查看 XMP 元数据以满足数字资产管理的合规要求

## 提示

- 以 `D:` 开头的 PDF 日期字符串会自动转换为您本地时区的格式。
- 如果元数据字段为空，说明 PDF 的创建者没有设置它们。并非所有 PDF 都包含丰富的元数据。
- 检查之后如需修改元数据，请使用[编辑元数据](./edit-metadata)。如需完全清除，请使用移除元数据。

# 移除空白页

扫描 PDF 中的空白或近乎空白的页面并自动移除。该工具会渲染每一页并分析其像素内容，以判断是否为空白，然后让您在处理前确认要移除哪些页面。

## 工作原理

1. 上传您的 PDF 文件。
2. 调整**灵敏度**滑块，控制“空白”的判定标准有多严格。
3. 点击**检测空白页**扫描文档。
4. 工具会显示检测到的空白页缩略图，供您查看。
5. 确认所选页面，然后下载已移除空白页的清理后 PDF。

## 选项

- **灵敏度**：0% 到 100% 的滑块（默认 80%）。数值越高越严格，只标记完全或近乎全白的页面。数值越低越宽松，会捕获仅含极少内容（如一个点或淡淡的水印）的页面。

## 功能

- 对每一页进行像素级分析以检测空白内容
- 可调节灵敏度滑块，精细调整检测效果
- 检测到的空白页缩略图预览，便于手动核对
- 所有非空白页面完全保持原样
- 可处理任意大小或页数的文档
- 扫描期间显示进度反馈

## 使用场景

- 清理扫描文档中扫描仪捕获到的单面原件空白背面
- 移除批量扫描文档中的分隔页
- 清除文档管理系统插入的空白页
- 清理从文字处理软件导出、有时会带有末尾空白页的 PDF
- 通过移除不必要的空白页来减小文件大小

## 提示

- 从默认的 80% 灵敏度开始，再逐步调整。如果工具漏掉了您认为空白的页面，请降低灵敏度。如果它标记了包含您想保留的少量内容的页面，请提高灵敏度。
- 工具需要渲染每一页来分析其内容，因此处理时间会随页数增加。对于非常大的文档，需要稍等片刻。
- 在确认移除之前，请在缩略图预览中检查检测到的空白页。根据灵敏度设置，带有淡淡页眉、页脚或水印的页面可能会被标记。

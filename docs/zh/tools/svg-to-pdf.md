# SVG 转 PDF

将可缩放矢量图形（SVG）文件转换为 PDF。该工具通过浏览器的渲染引擎对每个 SVG 进行栅格化，然后以其原始分辨率嵌入结果。适用于将矢量图标、图表和插图变成便携文档。

## 支持的格式

| 格式 | 扩展名 |
| :--- | :----- |
| SVG  | `.svg` |

## 工作原理

1. 点击上传区域，或拖放一个或多个 SVG 文件。
2. 查看并管理文件列表。
3. 选择 **PDF 质量**级别。
4. 点击**转换为 PDF**。结果会以 `from_svgs.pdf` 下载。

每个 SVG 会被作为文本读取，按其固有宽度和高度渲染到画布上（未指定尺寸时默认为 800x600），并导出为 PNG。然后使用 pdf-lib 将该 PNG 嵌入 PDF。透明区域会以白色背景填充。

## 选项

**PDF 质量**控制栅格化之后的压缩：

- **高质量**：最接近原始渲染效果。
- **中等质量**（默认）：良好的平衡。
- **低质量**：文件最小，会损失一些细节。

## 使用场景

- 将建筑或工程图表从 SVG 转换为可直接打印的 PDF
- 将图标集打包成设计系统的参考 PDF
- 将数据可视化（D3.js、图表库导出）转换为可用于报告的 PDF
- 创建基于 SVG 的信息图的可打印版本

## 提示

- 没有明确 `width` 和 `height` 属性的 SVG 文件会以 800x600 像素渲染。为获得最佳效果，请在转换前在 SVG 源码中设置尺寸。
- 带有外部字体引用或链接图片的复杂 SVG 可能无法完美渲染。请将所有资源内联到 SVG 中，以获得可靠的输出。
- 由于 SVG 会被栅格化，PDF 将包含位图图像而不是矢量路径。如需真正的矢量 PDF 输出，需要专用的矢量工具。

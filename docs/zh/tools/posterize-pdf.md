# 海报化 PDF

将 PDF 的每一页划分为由较小子页面组成的网格。使用此工具可以把单个页面打印到多张纸上，再将它们拼接起来，制作成大型海报或横幅。

## 工作原理

1. 上传 PDF 文件。
2. 设置**行数**和**列数**来定义网格（例如，2 行 x 2 列会将每页拆分为 4 个子页面）。
3. 可选：指定页面范围，限制要海报化的页面。
4. 预览画布会在当前页面上显示网格叠加层，方便您直观查看切割位置。
5. 在页面之间切换，查看其他页面上的叠加层。
6. 点击处理按钮。每个网格单元都会成为输出 PDF 中的一个独立页面。

## 功能

- 可配置行数和列数，网格尺寸灵活
- 实时预览，网格叠加层精确显示页面的分割位置
- 页面范围筛选，仅对指定页面进行海报化
- 在预览中逐页浏览
- 缓存页面快照，预览切换更快
- 红色虚线网格线清晰标出切割边界

## 选项

| 选项         | 说明                              |
| ------------ | --------------------------------- |
| **行数**     | 水平分割数量（默认：1）           |
| **列数**     | 垂直分割数量（默认：1）           |
| **页面范围** | 要海报化的页面（留空 = 所有页面） |

## 使用场景

- 将海报尺寸的 PDF 打印到多张标准 A4 或 Letter 纸上，拼贴到墙上
- 用单页 PDF 设计制作大型横幅
- 将超大的技术图纸拆分为可打印的分块
- 在没有宽幅打印机的情况下完成大幅面打印

## 提示

- 2x2 网格会将一页变成 4 页，3x3 网格会将一页变成 9 页。请根据最终拼接成品的大小规划网格。
- 预览叠加层可帮助您确认重要内容不会落在切割线上。如有需要，请调整行数和列数。
- 如需相反的操作（将多个页面放到一张纸上），请使用 [N-Up PDF](./n-up-pdf)。

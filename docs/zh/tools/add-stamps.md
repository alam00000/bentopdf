# 添加印章

使用带有印章注释工具栏的内嵌查看器，在 PDF 页面上放置图片印章。印章可以包含您的姓名以便署名，适用于审批流程、审阅流程和文档标记。

## 工作原理

1. 在**印章用户名**字段中输入您的姓名。此名称会显示在您创建的印章上。
2. 点击或将 PDF 文件拖入拖放区进行上传。
3. 印章编辑器打开，文档加载到查看器中。
4. 使用工具栏中的图片印章工具，在任意页面选择并放置印章。
5. 根据需要调整印章的位置和大小。
6. 点击**保存已盖章的 PDF** 下载结果。

## 功能

- 集成的 PDF 查看器，带有印章专用注释工具栏
- 为创建的印章署名用户名
- 可在任意页面放置图片印章
- 拖放定位和调整大小
- 根据页面宽高比自动调整查看器尺寸
- 显示文件名称和大小信息

## 使用场景

- 在审阅流程中为文档添加 "APPROVED" 或 "REVIEWED" 图片印章
- 在正式文件上放置公司公章或公证印章图片
- 为页面添加包含审阅者姓名的 "RECEIVED" 印章
- 为检验报告添加质量控制印章

## 提示

- 请在上传 PDF 之前设置印章用户名。用户名会嵌入印章元数据中。
- 查看器会根据 PDF 第一页的宽高比调整高度，以获得最佳查看效果。
- 如需基于文本的水印而不是图片印章，请使用[添加水印](./add-watermark)工具。

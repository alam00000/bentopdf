# JPG 转 PDF

将 JPG 图片变成整洁的 PDF。可以上传单个文件，也可以批量上传多张 JPG，每张图片都会成为输出文档中的一个整页。

## 支持的格式

| 格式      | 扩展名          |
| :-------- | :-------------- |
| JPEG      | `.jpg`, `.jpeg` |
| JPEG 2000 | `.jp2`, `.jpx`  |

## 使用方法

1. 点击上传区域或将 JPG 文件拖放进来。支持多选。
2. 查看已上传的文件。使用垃圾桶图标移除单个文件，或点击 **添加更多文件** 追加到列表。
3. 选择 **PDF 质量** 级别。
4. 点击 **转换为 PDF**。该工具会按照您的质量设置压缩图片，通过 PyMuPDF 引擎进行转换，并下载 `from_jpgs.pdf`。

## 选项

**PDF 质量** 用于调整图片嵌入 PDF 之前应用的压缩程度：

- **高质量**：保留最多细节。适用于摄影作品或打印。
- **中等质量**（默认）：在清晰度和文件大小之间取得良好平衡。
- **低质量**：激进压缩，输出最小。

## 使用场景

- 将保存为 JPG 的扫描文档转换为一份用于提交的 PDF
- 将产品照片整理成给客户的目录
- 将 JPEG 2000 格式的医学或卫星图像转为便携的 PDF
- 用相机导出的照片创建可打印的相册

## 小贴士

- 完整支持 JPEG 2000 文件（`.jp2`、`.jpx`），而不仅仅是标准 JPEG。这对医学影像和地理空间数据很有用。
- 如果您的 JPG 来自手机相机，中等质量生成的文件通常比高质量小 40-60%，而在屏幕上看不出明显差异。

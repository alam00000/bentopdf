# 交替混合页面

将多个 PDF 文件的页面交错排列，使页面在各文档之间交替出现。标准合并只会把文件首尾相接，而当您需要文件 A 的第 1 页、文件 B 的第 1 页、文件 A 的第 2 页，依此类推时，就该使用此工具。

## 工作原理

1. 使用拖放区上传至少两个 PDF 文件。
2. 工具会显示每个文件的页数和文件大小。
3. 拖动抓取手柄，调整交错顺序中哪个文件的页面排在前面。
4. 点击**混合页面**生成交错后的输出。
5. 结果会以 `alternated-mixed.pdf` 下载。

## 功能

- 可对任意数量的 PDF 交错页面（至少两个）
- 拖放重新排序文件，以控制交错优先级
- 保留源文档中的书签
- 显示每个已上传文件的页数和文件大小
- 通过专用的 Web Worker 处理，界面保持流畅

## 使用场景

- 重新组合奇数页和偶数页分别扫描的双面扫描件
- 将试题与答案合并，使每道题后面紧跟答案
- 逐页合并双语文档（例如一面英文，下一面译文）
- 交错合并单面扫描仪扫出的正面和背面

## 提示

- 如果源 PDF 的页数不同，较短文档的页面会先用完，较长文档剩余的页面会出现在末尾。
- 文件顺序很重要：列表中的第一个文件提供输出的第一页。如有需要，请拖动重新排列。

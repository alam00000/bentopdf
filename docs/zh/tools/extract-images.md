# 提取图片

从一个或多个 PDF 文件中取出所有嵌入的图片。提取的图片会显示在预览网格中，您可以逐个下载，也可以一次性打包为 ZIP 下载。由 PyMuPDF 提供支持。

## 使用方法

1. 点击拖放区域或将文件拖到其上，上传一个或多个 PDF。可根据需要添加更多文件或移除单个文件。
2. 点击 **提取** 开始处理。
3. 工具会扫描每个已上传 PDF 的每一页，查找并提取嵌入的图片。
4. 提取的图片以缩略图形式显示在网格中。每张图片都有下载按钮。
5. 点击 **全部下载**，将所有内容保存为 ZIP 压缩包。

## 选项

此工具没有可配置的选项。所有嵌入的图片都会以其原生格式提取（通常是 PNG、JPEG，或图片嵌入 PDF 时使用的任何格式）。

## 输出格式

- 图片在预览网格中以 `image_1.png`、`image_2.jpg` 等名称显示。
- **全部下载** 会生成包含所有图片的 `extracted-images.zip`。
- 可以从网格中逐个下载单张图片。

## 使用场景

- 从 PDF 中恢复照片或图形，以便在其他项目中重复使用。
- 从产品目录 PDF 中提取产品图片，用于电商商品列表。
- 从技术文档中取出图表，用于演示文稿。
- 在分享文档前，审查其中嵌入了哪些图片。

## 小提示

- 此工具会按图片在 PDF 中的存储方式原样提取。它不会将页面重新渲染为图片。如需那样做，请使用 [PDF 转 PNG](./pdf-to-png) 或 [PDF 转 JPG](./pdf-to-jpg)。
- 如果工具提示“未找到图片”，则 PDF 可能使用的是矢量图形而非嵌入的光栅图片，或者它是整页为一张大图的扫描文档。
- 批量处理可跨多个 PDF 进行。所有文件的全部图片会合并到同一个网格和 ZIP 中。

# 清理 PDF

PDF 所携带的内容远不止屏幕上看到的那些。隐藏的元数据、嵌入的 JavaScript、文件附件、表单数据和图层信息都可能泄露敏感数据或带来安全风险。清理会将这些全部清除，让您得到一份可以安全公开分享的干净文档。

## 工作原理

1. 上传 PDF 文件。
2. 在清单中选择要移除的元素。
3. 点击**清理 PDF**。
4. 下载清理后的文件。

## 清理选项

所有选项默认启用。取消勾选您想保留的选项。

| 选项                | 移除的内容                                    |
| ------------------- | --------------------------------------------- |
| **扁平化表单**      | 将交互式表单字段转换为静态内容                |
| **移除元数据**      | 清除作者、标题、创建日期、软件信息和 XMP 数据 |
| **移除注释**        | 删除评论、高亮、便签和标记                    |
| **移除 JavaScript** | 清除打开时可能执行的嵌入脚本                  |
| **移除嵌入文件**    | 清除 PDF 中嵌入的文件附件                     |
| **移除图层 (OCG)**  | 将可选内容组扁平化为单一图层                  |
| **移除链接**        | 清除超链接和 URL 引用                         |
| **移除结构树**      | 移除用于无障碍标记的文档结构                  |
| **移除 MarkInfo**   | 清除标记内容信息                              |
| **移除字体**        | 移除嵌入的字体数据（请谨慎使用）              |

## 使用场景

- 通过清除内部元数据（作者姓名、软件版本、编辑历史）为公开发布准备 PDF
- 在打开来自不可信来源的 PDF 之前移除其中的 JavaScript
- 在发送给客户之前清理 PDF，避免对方看到嵌入的评论或表单字段名称
- 在分享最终版本之前清除建筑图纸中的隐藏图层
- 满足隐私法规下的数据最小化要求

## 提示

- 除非您确定 PDF 仍能正确渲染，否则请不要勾选“移除字体”。移除字体可能会使文本在某些阅读器中不可见。
- 如果您只需要清除元数据，专用的移除元数据工具更快、更专注。
- 清理是不可逆的。请保留您的原始文件。

# 数字签名

数字签名是加密证明：特定的人签署了文档，且文档自签署以来未被更改。与手绘签名（只是一张图片）不同，数字签名使用 X.509 证书和 PKCS#7 标准，提供可验证的真实性和完整性。

BentoPDF 完全在您的浏览器中应用数字签名。您的私钥不会离开您的设备。

## 使用方法

1. 上传 PDF 文件。
2. 上传您的证书文件（.pfx、.p12 或 .pem）。
3. 输入证书密码以解锁。工具会显示证书主体、颁发者和有效期。
4. 可选：配置签名元数据（原因、地点、联系信息）。
5. 可选：启用 **可见签名**，并自定义位置、大小、图片和文本。
6. 点击 **签署 PDF**。

## 支持的证书格式

| 格式        | 扩展名     | 说明                                                                 |
| ----------- | ---------- | -------------------------------------------------------------------- |
| **PKCS#12** | .pfx, .p12 | 包含私钥和证书链的行业标准捆绑包。最常见的格式。                     |
| **PEM**     | .pem       | 基于文本的格式。必须在同一文件中同时包含证书和私钥。支持加密的私钥。 |

## 可见签名选项

启用后，PDF 页面上会渲染一个可见的签名块：

- **位置**：X/Y 坐标以及宽度/高度，单位为点
- **页面**：第一页、最后一页、所有页面或指定页码
- **图片**：上传 PNG、JPG 或 WebP 图片（您的手写签名、公司印章等）
- **文本**：自定义文本，颜色和字号可配置。如果未提供图片或文本，工具会根据证书的通用名称和当前日期自动生成文本。

## 签名元数据

- **原因**：签署文档的原因（例如“已批准”“已审阅”）
- **地点**：签署发生的地点（例如“New York, NY”）
- **联系信息**：联系签署人的方式（例如电子邮件地址）

## 网络连接说明

签署可能需要网络连接。签名库会从证书的颁发机构信息访问 (AIA) 扩展中嵌入的 URL 获取证书链。如果这些服务器无法访问，需要证书链验证的证书将无法签署。

## 使用场景

- 使用具有法律效力的数字签名签署合同、提案和协议
- 在需要基于 PKI 认证的工作流程中认证官方文件
- 为满足监管要求而签署 PDF 发票（许多欧盟国家要求电子发票带有数字签名）
- 为工程图纸或质量文件添加组织批准

## 小提示

- 自签名证书可用于测试，但在 Adobe Reader 中会显示警告。正式文档请使用受信任证书颁发机构签发的证书。
- 可见签名纯粹是视觉效果。无论是否启用可见签名块，加密签名都会被嵌入。
- 使用验证签名工具检查已签署的 PDF，确认签名完好无损。

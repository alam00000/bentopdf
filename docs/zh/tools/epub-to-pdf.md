# EPUB 转 PDF

无需离开浏览器，即可将 EPUB 电子书转换为 PDF 文件。EPUB 是数字图书的开放标准，但有时您需要固定版式的 PDF，用于打印、批注，或分享给没有电子书阅读器的人。

## 支持的格式

| 格式 | 扩展名  | 说明                  |
| :--- | :------ | :-------------------- |
| EPUB | `.epub` | EPUB 2 和 EPUB 3 文件 |

## 使用方法

1. 点击上传区域，或拖放您的 EPUB 文件。支持多选。
2. 查看已上传的文件。使用垃圾桶图标移除不需要的条目，或点击 **添加更多文件** 扩充批次。
3. 点击 **转换为 PDF**。PyMuPDF 引擎会将 EPUB 内容（文本、图片和格式）渲染为分页的 PDF 输出。
4. 单个 EPUB 会直接下载为 PDF。多个文件会打包成名为 `epub-converted.zip` 的 ZIP 压缩包。

## 选项

转换使用合理的默认值运行，无需任何配置。文本会重排为标准页面尺寸，嵌入的字体和图片会带入 PDF。

## 使用场景

- 打印无 DRM 的电子书，以便离开屏幕阅读
- 将 EPUB 稿件以固定版式 PDF 提交审阅
- 以每个操作系统都能原生打开的格式归档数字图书
- 与没有 EPUB 阅读器的同事分享某一章节
- 将以 EPUB 分发的技术文档转换为可批注的 PDF

## 小提示

- 嵌入的音频和视频等 EPUB 3 功能无法带入 PDF，但所有文本、图片和表格都能干净地转换。
- 对于样式繁多的 EPUB，为获得最佳效果，请检查输出的前几页，确认版式是否还原。

# 保护 PDF

用密码锁定您的 PDF，使只有获得授权的人才能打开。BentoPDF 使用 256 位 AES 加密（银行和政府机构使用的同一标准），并通过 QPDF 完全在您的浏览器中完成。

## 工作原理

1. 上传 PDF 文件。
2. 输入**用户密码**（必填）。这是他人打开文件时需要输入的密码。
3. 可选：输入**所有者密码**。设置后，PDF 将获得使用限制，禁止打印、编辑、复制和批注。
4. 点击**加密 PDF**。
5. 下载加密后的文件。

## 密码类型

### 用户密码（必填）

用户密码是收件人打开 PDF 时需要输入的密码。没有它，文档将完全无法访问。每个加密的 PDF 都必须有用户密码。

### 所有者密码（可选）

所有者密码用于控制获得授权的用户在打开文件后可以执行的操作。当您设置了不同的所有者密码时，BentoPDF 会自动应用最严格的限制集：

- 禁止修改
- 禁止提取/复制
- 禁止打印
- 禁止批注
- 禁止填写表单
- 禁止文档组装

如果您将所有者密码留空，PDF 仍会被加密（打开时仍需要用户密码），但打开后没有任何使用限制。

## 加密详情

- **算法**：AES-256（256 位高级加密标准）
- **密钥长度**：256 位
- **标准**：PDF 2.0 加密（QPDF 实现）

以当前技术，暴力破解 AES-256 在计算上是不可行的。加密 PDF 的安全性完全取决于密码的强度。

## 使用场景

- 在通过邮件发送之前保护机密财务报告
- 保护与对方律师共享的法律文件
- 为医疗记录或个人身份信息添加密码
- 通过访问控制分发付费内容（电子书、报告）
- 遵守要求静态数据加密的数据保护政策

## 提示

- 使用强度高且唯一的密码。包含大小写字母、数字和符号的 12 位以上口令最为理想。
- 通过单独的渠道（电话、短信）分享密码，切勿与 PDF 放在同一封邮件中。
- 如果您只想限制操作（禁止打印、禁止复制），而不需要密码才能打开，请改用“更改权限”工具。

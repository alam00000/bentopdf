# 更改权限

精细控制接收者可以对您的 PDF 执行哪些操作。与仅用密码锁定文件的基本加密不同，此工具允许您有选择地允许或禁止打印、复制、编辑、批注、填写表单、文档组装和页面提取，所有这些都通过 256 位 AES 加密强制执行。

## 使用方法

1. 上传 PDF 文件。
2. 如果 PDF 已加密，请输入 **当前密码**。
3. 设置 **新用户密码**（打开文件所需）和/或 **新所有者密码**（控制权限）。
4. 使用复选框逐项开启或关闭权限。
5. 点击 **更改权限**。
6. 下载更新后的 PDF。

如果两个新密码字段都留空，工具会完全解密 PDF，移除所有加密和限制。

## 权限控制

| 权限             | 控制内容                       |
| ---------------- | ------------------------------ |
| **允许打印**     | 文档是否可以打印               |
| **允许复制**     | 文本和图片是否可以被选择和复制 |
| **允许修改**     | 文档内容是否可以编辑           |
| **允许批注**     | 是否可以添加评论、高亮和印章   |
| **允许填写表单** | 交互式表单字段是否可以填写     |
| **允许文档组装** | 页面是否可以插入、删除或旋转   |
| **允许提取页面** | 单个页面是否可以被提取         |

所有权限都需要设置所有者密码才能生效。没有所有者密码时，大多数 PDF 阅读器会忽略权限标志。

## PDF 中的权限机制

PDF 权限是加密规范的一部分。它们以位标志的形式存储在加密字典中，并由合规的 PDF 阅读器强制执行。关键区别如下：

- **用户密码**：打开文件所必需。
- **所有者密码**：更改权限或移除限制所必需。没有它时，权限标志决定用户可以执行哪些操作。

如果只设置所有者密码（不设置用户密码），任何人都可以打开文件，但只能执行被允许的操作。如果两者都设置，则打开文件需要密码，且验证之后仍受限制。

## 使用场景

- 分发可查看和打印但不能编辑或复制的报告
- 分享接收者可以填写但不能修改的合同模板
- 发布禁止复制图片的 PDF 目录
- 允许在审阅草稿上添加批注，同时防止结构性更改

## 小提示

- 为了确保有效，请始终设置所有者密码。没有所有者密码的权限无法强制执行。
- 某些第三方 PDF 工具会忽略权限标志。如需更强的保护，可以考虑将 PDF 栅格化或使用 DRM。
- 使用此工具可将旧的 RC4 加密 PDF 升级为 AES-256。

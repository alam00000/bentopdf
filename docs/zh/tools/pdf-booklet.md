# PDF 小册子

将 PDF 的页面重新排列为小册子拼版顺序。双面打印并对折后，页面会呈现正确的阅读顺序。这是骑马钉小册子和独立杂志常用的版式。

## 使用方法

1. 上传 PDF 文件。
2. 配置小册子设置：输出页面大小和方向。
3. 点击 **生成预览**，查看页面在每张纸上的排列方式。
4. 查看预览，其中显示每张实体纸张及其正反面的页面分配。
5. 点击 **下载** 保存已拼版的小册子 PDF。

## 功能

- 自动为骑马钉装订重新排列页面
- 可配置输出页面大小
- 下载前可视化预览小册子布局
- 页数为奇数时，会在需要的位置插入空白页
- 缩放源页面以适应小册子纸张大小

## 使用场景

- 将普通 PDF 制作成可打印的小册子或独立杂志
- 准备会议议程或活动指南用于内部打印
- 制作折叠贺卡或小型目录
- 制作用于手工装订的小诗集

## 小技巧

- 源 PDF 的页数最好是 4 的倍数，这样小册子更整齐。如果不是，会自动添加空白页来补满最后一张纸。
- 在打印机上选择“短边翻转”进行双面打印，然后将所有纸张一起对折，并在书脊处装订。
- 如果只是将多个页面放在一张纸上而不需要小册子排序，请改用 [N-Up PDF](./n-up-pdf)。

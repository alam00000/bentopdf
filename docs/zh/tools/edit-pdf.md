# PDF 编辑器

BentoPDF 的 PDF 编辑器让您可以批注、高亮、涂黑、评论、添加形状和图片，并在 PDF 中搜索。它直接在浏览器中加载功能齐全的编辑器，无需上传到服务器。

## 使用方法

1. 点击拖放区域或将文件拖到其上，上传您的 PDF。
2. 内嵌的 PDF 编辑器会自动打开并载入您的文档。
3. 使用工具栏进行批注、高亮、涂黑、添加文本、绘制形状或插入图片。
4. 点击 **下载已编辑的 PDF** 保存您的更改。

## 功能

- 完整的批注工具栏，支持高亮、下划线、删除线和手绘
- 文本插入和评论
- 涂黑工具，在应用涂黑后会永久移除被标记的内容。如果点击 **下载已编辑的 PDF** 时仍有标记尚未应用，编辑器会提示先应用它们。
- 矩形、圆形、直线和箭头等形状工具
- 在 PDF 页面上插入图片
- 内置的全文档文本搜索
- 支持多文档标签页（最多同时打开 10 个文档）
- 支持拖放加载文件

## 使用场景

- 审阅合同，并用高亮和评论标记修改
- 在分享前涂黑社会安全号码或财务数据等机密信息
- 为建筑平面图或工程图纸添加批注
- 在文档页面上插入公司标志或印章
- 在冗长的法律文件中搜索特定术语

## 小提示

- 您可以同时打开多个 PDF，并使用编辑器顶部的标签栏在它们之间切换。
- 编辑器会保留原始 PDF 的结构，因此字体、版面和表单字段保持完好。
- 标记文本或区域用于涂黑，在应用涂黑之前不会移除任何内容。涂黑所选文本时，文件属性、书签、评论和附件中的副本也会从下载文件中一并移除，除非文件已加密。
- 对于批量水印或页码，请改用专用工具，以便更好地控制格式。

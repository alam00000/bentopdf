# 目录

此工具会读取 PDF 中的书签（大纲），并生成一页格式化的目录，将其添加到文档开头。如果您的 PDF 已有书签但缺少可见的目录页，此工具会自动为您创建一个。

## 工作原理

1. 上传包含书签的 PDF。
2. 自定义目录标题、字号和字体。
3. 可选：勾选**为目录页添加书签**，将目录本身加入书签树。
4. 点击**生成目录**处理文件。
5. 更新后的 PDF 会自动下载，目录页已插入到开头。

## 选项

- **目录标题**：显示在生成页面顶部的标题。默认为“目录”。
- **字号**：可选 10pt 到 72pt。默认为 12pt。
- **字体**：可选 Times Roman、Helvetica 或 Courier 的变体（常规、粗体、斜体、粗斜体）。默认为 Helvetica。
- **为目录页添加书签**：勾选后，会在 PDF 的大纲树中为目录页本身添加一个书签条目。

## 功能

- 读取 PDF 中完整的书签层级
- 生成格式清晰、带有页码引用的目录页
- 支持带缩进的嵌套书签级别
- 可选 12 种内置 PDF 字体
- 可选为目录页添加指向自身的书签

## 使用场景

- 为只有数字书签的电子书或报告添加可打印的目录
- 合并多个 PDF 后，为合并文档创建目录
- 为篇幅较长的技术手册生成参考页
- 为需要可见目录的印刷准备文档

## 提示

- 如果您的 PDF 没有书签，请先使用[编辑书签](./bookmark)工具创建，然后再回到这里生成目录。
- 对于大型文档，使用 14pt 或 16pt 等较大的字号可提高可读性。

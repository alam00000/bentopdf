# 提取附件

从一个或多个 PDF 文件中取出所有嵌入的附件。所有提取的文件会打包成单个 ZIP 压缩包供下载。

## 使用方法

1. 上传一个或多个包含嵌入附件的 PDF 文件。
2. 点击 **提取附件**。
3. 工具会扫描每个 PDF 中的文档级和页面级附件。
4. 找到的所有文件会被打包成 ZIP 压缩包并自动下载。
5. 状态消息会确认找到了多少个附件及其总大小。

## 功能

- 一次性从多个 PDF 批量提取
- 同时提取文档级和页面级附件
- 输出包含所有提取文件的单个 ZIP 文件
- 显示附件总数和合计文件大小
- 未找到附件时给出明确的状态消息

## 使用场景

- 恢复嵌入在报告 PDF 中的数据文件
- 从作品集或规格文档中取出图片素材
- 从培训或合规 PDF 中提取补充材料
- 审查一批 PDF 中嵌入了哪些文件

## 小提示

- 如果工具提示没有附件，PDF 中可能包含的是嵌入图片或表单数据，它们不属于文件附件。嵌入的图片请使用 [提取图片](./extract-images)。
- 处理多个 PDF 时，所有文件的附件都会汇集到一个 ZIP 中。文件名会保留原始嵌入时的名称。

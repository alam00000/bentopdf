# 比较 PDF

上传两个 PDF，准确查看它们之间发生了哪些变化。工具会智能配对页面，检测文本、图片、批注、页眉和格式的差异，并以并排或叠加视图呈现。

## 使用方法

1. 上传两个 PDF 文件：原始版本（左）和修订版本（右）。
2. 工具使用内容签名在两个文档之间配对页面。
3. 选择视图模式：**并排** 或 **叠加**。
4. 使用分页控件在页面对之间切换。
5. 差异会被高亮并分类。使用筛选面板专注于特定的变更类型。
6. 可选：将比较结果导出为 PDF 报告。

## 功能

- 基于内容相似度自动配对页面
- 并排和叠加两种比较视图
- 变更分类：文本、图片、页眉/页脚、批注、格式、背景
- 按类别切换筛选，显示或隐藏特定类型的变更
- 支持带查询过滤的文本变更搜索
- 支持 OCR，可比较扫描文档
- 缩放控制，便于详细检查
- 并排模式下两个面板同步滚动
- 将比较结果导出为 PDF

## 选项

| 选项         | 说明                                                    |
| ------------ | ------------------------------------------------------- |
| **视图模式** | 并排或叠加                                              |
| **OCR**      | 启用/禁用 OCR 以比较扫描文档                            |
| **OCR 语言** | OCR 文本提取所用的语言                                  |
| **类别筛选** | 切换文本、图片、页眉/页脚、批注、格式和背景变更的可见性 |
| **变更范围** | 在叠加模式下，在全部变更或仅内容变更之间筛选            |
| **缩放**     | 调整放大级别以便详细检查                                |

## 使用场景

- 审阅合同修订，准确找出不同版本之间的变化
- 比较设计稿，验证 PDF 导出结果是否符合预期
- 在受监管行业中审计文档变更，确保每次编辑都可追溯
- 验证 PDF 转换流程是否准确保留了原始内容
- 对照原文检查翻译文档的版面变化

## 小提示

- 叠加视图会将两个文档相互重叠，使空间上的差异（元素位移、图片尺寸变化）一目了然。
- 比较没有文本层的扫描文档时请启用 OCR。比较引擎会从页面图像中提取文本。
- 使用类别筛选专注于重要内容。例如，只关心文本内容差异时，可以隐藏格式变更。

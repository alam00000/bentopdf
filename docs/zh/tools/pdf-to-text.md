# PDF 转文本

从 PDF 文件中提取所有文本内容，并保存为纯 `.txt` 文件。支持批量处理：上传多个 PDF，一次操作即可提取每个文件的文本。由 PyMuPDF 提供支持。

## 使用方法

1. 点击拖放区域或将文件拖到其上以上传一个或多个 PDF。使用“添加更多”和“清除”按钮管理文件列表。
2. 点击 **提取** 开始处理。
3. 单个文件会下载为 `filename.txt`。多个文件会生成 `pdf-to-text.zip` 压缩包。

## 选项

此工具没有可配置的选项。会按阅读顺序提取每一页的所有文本内容。

## 输出格式

- **单个文件**：`filename.txt`
- **多个文件**：`pdf-to-text.zip`，每个输入 PDF 对应一个 `.txt`。

## 使用场景

- 从 PDF 报告中提取正文，用于全文搜索索引。
- 将 PDF 电子书或文章转换为纯文本，以便在电子墨水设备上阅读。
- 从合同或法律文件中提取文本，用于关键词分析。
- 去除 PDF 的格式，获得干净的文本，供数据处理脚本使用。
- 从 PDF 档案中准备用于自然语言处理的文本语料库。

## 小技巧

- 扫描的 PDF（仅有图像）会生成空的文本文件，因为没有可提取的文本层。请先对扫描文档进行 OCR。
- 输出保留 PyMuPDF 所解读的阅读顺序，通常是从左到右、从上到下。多栏布局可能会生成交错的文本。
- 如需带有标题和格式的结构化输出，请尝试 [PDF 转 Markdown](./pdf-to-markdown)。如需适用于 AI 的结构化 JSON，请使用 [为 AI 准备 PDF](./prepare-pdf-for-ai)。

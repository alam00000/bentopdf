# ODP 转 PDF

将 OpenDocument Presentation 文件转换为 PDF。ODP 是 LibreOffice Impress 的原生格式，也是 Google Slides 的标准导出格式。将演示文稿转为 PDF 后，任何人都无需演示软件即可查看，幻灯片也能整洁地打印。

## 支持的格式

| 格式                      | 扩展名 | 备注                                     |
| :------------------------ | :----- | :--------------------------------------- |
| OpenDocument Presentation | `.odp` | LibreOffice Impress / Google Slides 导出 |

## 使用方法

1. 点击上传区域或将 ODP 文件拖放进来。可以一次选择多个演示文稿。
2. 查看文件列表。使用垃圾桶图标移除条目，或使用 **添加更多文件** 加入更多演示文稿。
3. 点击 **转换为 PDF**。基于 LibreOffice 的引擎会处理每个演示文稿，并生成每张幻灯片对应一页的 PDF。
4. 单个文件会下载为 PDF。多个文件会打包在名为 `odp-to-pdf.zip` 的 ZIP 压缩包中。

## 选项

无需配置。每张幻灯片都按原始尺寸渲染，并保留文字、图片、形状和幻灯片背景。

## 使用场景

- 将演示文稿作为讲义 PDF 分发给听众
- 与更喜欢 PDF 而非 ODP 的人分享 Google Slides 导出文件
- 将会议演讲和讲座以只读格式归档
- 为线下工作坊打印幻灯片

## 小贴士

- 幻灯片切换和动画属于仅限视觉的功能，不会带入 PDF，但所有静态内容都能正确渲染。
- 演讲者备注不会包含在 PDF 输出中。如果您需要备注，请从演示软件中单独导出。
- 与其他基于 LibreOffice 的工具一样，引擎在首次使用时加载，并在会话期间保持缓存。

# PDF 表单填写器

打开带有表单字段的 PDF，并在内嵌查看器中直接填写。该工具同时支持标准 AcroForm 字段和旧版 XFA (XML Forms Architecture) 表单。填写完成后，一键下载已填写的版本。

## 使用方法

1. 上传包含表单字段的 PDF。
2. 文档会在集成的 PDF 查看器中打开，表单字段呈现为可交互的输入控件。
3. 点击文本字段、复选框、下拉菜单和单选按钮进行填写。
4. 点击 **保存并下载已填写表单** 获取完成的 PDF。

## 功能

- 内嵌 PDF.js 查看器，支持完整的表单字段交互
- 支持标准 AcroForm 字段（文本输入、复选框、下拉菜单、单选按钮）
- 支持基于 XML 的旧版 XFA 表单
- 根据页面尺寸自动调整查看器大小
- 显示文件名称和大小信息

## 选项

没有其他配置选项。上传表单，填写，然后下载即可。

## 使用场景

- 填写税务表格、保险申请表或政府文书
- 填写以 PDF 附件形式收到的求职申请表
- 填写供应商入驻表单或供应商问卷
- 通过复选框字段签署合规检查清单
- 就诊前填写医疗登记表

## 小贴士

- XFA 表单是仅被部分 PDF 查看器支持的旧版格式。如果您在 Chrome 或大多数其他工具中打开 XFA PDF 后看到空白页，说明这些查看器不支持 XFA。BentoPDF 的表单填写工具和 Firefox 都能正确处理 XFA。
- 对于没有现成表单字段的 PDF，请先使用 [创建 PDF 表单](./form-creator) 工具添加字段，再在此处填写。
- 查看器会自动调整大小以匹配 PDF 的页面尺寸。

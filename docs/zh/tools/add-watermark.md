# 添加水印

使用可视化编辑器为 PDF 页面添加文字或图片水印。您可以直接在预览中拖动水印来定位，使用角点手柄调整大小，并配置不透明度、旋转、字体和颜色。每个页面可以有各自的水印位置，也可以一次性对所有页面应用相同的水印。

## 工作原理

1. 上传您的 PDF 文件。
2. 编辑器打开，显示第一页的实时预览和可拖动的水印叠层。
3. 使用切换按钮在**文字**或**图片**水印模式之间选择。
4. 在侧边栏面板中配置水印设置。
5. 在预览中拖动水印到您想要的位置。使用角点手柄调整大小。
6. 在页面之间切换以设置每页的水印，或保持勾选**应用到所有页面**。
7. 点击**添加水印**进行处理并下载。

## 选项

**文字水印设置：**

- **文字**：水印文字（例如“机密”、“草稿”）。
- **字号**：10 到 200 点。默认为 72。
- **颜色**：通过取色器选择任意颜色。
- **不透明度**：控制透明度，从完全透明到完全不透明。
- **旋转**：将水印文字旋转 -180 到 180 度。

**图片水印设置：**

- **图片上传**：上传 PNG、JPG 或其他图片文件用作水印。
- **不透明度**：控制图片透明度。
- **缩放**：调整图片水印的大小。

**布局设置：**

- **单个**：每页一个水印，通过拖动或位置预设来定位。
- **平铺**：沿着旋转角度以对角网格在整页重复水印，使水印从边缘到边缘覆盖整个文档。
- **水平间距**：沿文字方向的平铺间距，以水印宽度的百分比表示（仅平铺模式）。
- **垂直间距**：平铺行之间的间距，以水印高度的百分比表示（仅平铺模式）。

**通用设置：**

- **应用到所有页面**：勾选后，同一水印应用于每一页。取消勾选可为每页单独设置水印。
- **页面范围**：指定哪些页面添加水印（例如 "1-3, 5, 7-9" 或 "all"）。

## 功能

- 在实时 PDF 预览上进行可视化拖放定位
- 水印可通过角点手柄调整大小
- 文字和图片水印模式
- 单个或整页平铺（重复）布局，间距可调
- 按页或全局应用水印
- 在预览中逐页浏览
- 不透明度和旋转控制
- 页面范围筛选

## 使用场景

- 在分发审阅前为草稿文档标记“草稿”
- 为敏感财务报告添加“机密”水印
- 使用公司标志图片水印为文档添加品牌标识
- 在向潜在客户分享的产品文档上加盖 "SAMPLE"
- 为分发的 PDF 资料添加版权声明

## 提示

- 若要在页面上添加对角水印，请将旋转设为约 45 度并增大字号。
- 平铺模式让文档裁剪后更难被重复使用，因为去掉一个水印仍会留下几十个。平铺时请降低不透明度，以保持底层文字清晰可读。
- 带透明背景的图片水印（PNG 格式）与文档内容的融合更自然。
- 如果需要在不同页面使用不同的水印文字，请取消勾选"应用到所有页面"，然后逐页操作。

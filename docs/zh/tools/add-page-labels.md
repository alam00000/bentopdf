# 添加页面标签

页面标签控制页码在 PDF 查看器中的显示方式（显示在工具栏中的数字，而不是印在页面上的数字）。此工具可以为不同的页面范围分配不同的标签方案：前言使用罗马数字，正文使用十进制数字，附录使用字母等。

## 工作原理

1. 上传您的 PDF 文件。
2. 出现选项面板，默认带有一条标签规则。
3. 为每条规则配置页面范围、样式、可选前缀和起始值。
4. 点击**添加规则**为不同部分创建更多规则。
5. 点击**添加页面标签**应用所有规则并下载结果。

## 选项

每条标签规则有以下设置：

- **页面范围**：规则适用的页面。留空表示所有页面。支持 `1-4`、`7`、`odd` 或 `1-9,30-40` 等范围。
- **标签样式**：十进制阿拉伯数字、小写罗马数字（i, ii, iii）、大写罗马数字（I, II, III）、小写字母（a, b, c）、大写字母（A, B, C），或无标签（仅前缀）。
- **标签前缀**：添加在每个标签前的可选文本，例如 "A-" 可生成 A-1、A-2、A-3 这样的标签。
- **起始值**：开始计数的数字。默认为 1。设为 0 可使用从零开始的编号。
- **跨不连续范围继续编号**：当规则针对不连续的页面（如 `1-9,30-40` 或 `odd`）并且希望编号顺序延续时启用。
- **移除现有页面标签**：默认勾选。在应用新规则之前清除之前的所有标签。

## 功能

- 每个文档可设置多条标签规则，适应复杂的编号方案
- 六种标签样式，涵盖所有标准编号系统
- 支持自定义前缀，用于按章节标注
- 支持不连续范围并可连续编号
- 可选择保留或移除现有标签

## 使用场景

- 为书籍的前言设置罗马数字标签（i, ii, iii），正文使用十进制标签
- 使用 "A-1"、"A-2"、"B-1"、"B-2" 等字母前缀标注附录页
- 修正扫描文档中实体页码与 PDF 页面顺序不一致的页面标签
- 为技术文档添加从零开始的编号

## 提示

- 页面标签是元数据，PDF 查看器会在导航工具栏中显示，它们不会打印在实际页面上。如需可见的页码，请使用[页码](./page-numbers)。
- 此工具需要在 WASM 设置中配置 CoherentPDF (CPDF)。如果尚未设置，系统会提示您进行配置。

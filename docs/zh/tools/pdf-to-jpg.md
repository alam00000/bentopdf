# PDF 转 JPG

将 PDF 的每一页转换为 JPG 图像。单页文档会下载为独立的 `.jpg` 文件。多页 PDF 会生成一个 ZIP 压缩包，其中每页对应一个 JPG。

## 使用方法

1. 点击拖放区域或将文件拖到其上以上传 PDF。工具会显示文件名、文件大小和页数。
2. 调整 **质量** 滑块以控制 JPG 压缩。
3. 点击 **转换** 开始处理。
4. 结果会自动下载：单页 PDF 为单个 JPG，多页文档为 ZIP 文件。

## 选项

- **质量**：从 0% 到 100% 的滑块（默认 90%）。数值越高，图像越清晰，文件也越大。数值越低，压缩越激进。

页面在内部以 2 倍比例渲染，因此输出分辨率是 PDF 页面尺寸的两倍。标准 Letter 尺寸的页面会生成约 1,224 x 1,584 像素的图像。

## 输出格式

- **单页**：`filename.jpg`
- **多页**：`filename_jpgs.zip`，包含 `page_1.jpg`、`page_2.jpg` 等。

## 使用场景

- 为文档管理系统生成预览缩略图。
- 在不支持 PDF 的聊天或电子邮件中分享报告的某一页。
- 从 PDF 图表或插图创建图像素材。
- 将扫描文档作为单独的图像归档。

## 小技巧

- 如需无损输出，请改用 [PDF 转 PNG](./pdf-to-png)。
- 80-90% 的质量设置能在文件大小和视觉保真度之间取得良好平衡。
- 如果您需要为每页指定格式，可以考虑 [PDF 工作流构建器](./pdf-workflow)，它提供 PDF 转图片输出节点。

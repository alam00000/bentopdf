# PDF 转 PDF/A

PDF/A 是 PDF 的 ISO 标准化子集，专为长期数字保存而设计。此工具使用直接在浏览器中运行的 Ghostscript，将您的标准 PDF 转换为符合 PDF/A 的文档。

## 使用方法

1. 上传一个或多个 PDF 文件。
2. 从下拉菜单中选择 **PDF/A 版本**。
3. 对于正常转换失败的复杂文件，可选择启用 **预先扁平化 PDF**。
4. 点击 **转换为 PDF/A**。多个文件会生成 ZIP 压缩包。

## PDF/A 版本

| 版本         | 限制                       | 最适合                     |
| ------------ | -------------------------- | -------------------------- |
| **PDF/A-1b** | 最严格。无透明度，无图层。 | 与较旧归档系统的最大兼容性 |
| **PDF/A-2b** | 允许透明度和 JPEG2000。    | 通用归档（推荐）           |
| **PDF/A-3b** | 允许嵌入任何格式的附件。   | 归档带有源数据文件的文档   |

默认选择 PDF/A-2b，可满足绝大多数归档需求。

## 预先扁平化选项

某些 PDF 包含会妨碍干净地转换为 PDF/A 的特性，例如不常见的字体编码、复杂的透明度堆叠或损坏的内部结构。启用 **预先扁平化** 会在转换前以 300 DPI 栅格化 PDF，这能保证合规，但代价是文本将无法选择。当标准转换出错时，请将其用作备用方案。

预先扁平化需要 PyMuPDF WASM 引擎。

## 使用场景

- 满足政府或法律的归档要求（许多司法管辖区要求法院文件使用 PDF/A）
- 向机构存储库或数字图书馆提交文档
- 保存十年后原始软件可能已不存在的业务记录
- 为要求带有 XML 附件的 PDF/A-3b 的电子发票标准准备发票

## 小技巧

- 请先尝试不使用预先扁平化进行转换。仅在出现错误时才启用它。
- PDF/A 会嵌入所有字体，因此输出文件通常比原始文件更大。
- 如果您的工作流需要严格合规，请在专门的 PDF/A 验证器中验证输出。

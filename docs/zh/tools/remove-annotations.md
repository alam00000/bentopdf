# 移除注释

通过移除所有注释来清理您的 PDF，包括评论、高亮、便签、文本标记、链接、印章以及文档中嵌入的任何其他注释对象。页面的底层内容（文本、图片、图形）保持不变。

## 工作原理

1. 上传您的 PDF 文件。
2. 工具会检测文档的页数并显示文件信息。
3. 点击**移除注释**开始处理。
4. 清理后的 PDF 会自动下载，所有注释均已清除。

## 功能

- 移除所有注释类型：评论、高亮、下划线、删除线、便签、印章、链接和表单标记
- 处理文档中的每一页
- 保留所有非注释内容（文本、图片、矢量图形、表单字段）
- 处理前显示页数和文件大小

## 使用场景

- 在多位审阅者添加评论的审阅周期结束后，于最终分发前清理文档
- 移除共享学习指南中的高亮标记和便签
- 在归档前清除文档中的链接注释
- 为谈判期间被大量批注的法律文件准备“干净”版本
- 在送印前移除稿件中的审阅者评论

## 提示

- 此工具在 PDF 结构层面移除注释，因此结果保留可选择的文本和原始质量，不涉及栅格化。
- 如果只想移除特定注释而不是全部，请使用 [PDF 编辑器](./edit-pdf) 选择性地删除单个注释。
- 已扁平化的 PDF（注释已合并到页面内容中）中的注释无法移除，因为它们不再是独立对象。

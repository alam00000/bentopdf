# 反转页面

反转 PDF 的页面顺序，使最后一页变为第一页，倒数第二页变为第二页，依此类推。支持一次批量处理多个文件。

## 工作原理

1. 上传一个或多个 PDF 文件。
2. 点击处理按钮。
3. 每个文件会被独立反转。如果上传了多个文件，输出为包含所有反转后 PDF 的 ZIP 压缩包。
4. 单个文件会直接下载为反转后的 PDF。

## 功能

- 批量处理：一次操作反转多个 PDF
- 单个 PDF 输出单个文件，多个 PDF 输出 ZIP
- 处理前可通过每个文件的移除按钮移除文件
- 保留所有页面内容和格式

## 使用场景

- 修复以相反顺序扫描的文档
- 准备需要从后往前阅读的演示文稿 PDF
- 为需要倒序送纸的特定打印流程反转页面顺序
- 纠正页面被意外反向装订的文档

## 提示

- 批量中的每个文件都是独立反转的，文件彼此之间的顺序不会改变。
- 如需更精细的页面重新排序（而不仅仅是完全反转），请使用[复制与组织](./organize-pdf)。

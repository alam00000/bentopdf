# PDF 转 ZIP

将多个 PDF 文件打成单个 ZIP 压缩包。这是一个简单的打包工具，不会对 PDF 本身进行转换、压缩或修改。

## 使用方法

1. 使用拖放区域上传多个 PDF 文件。
2. 查看文件列表。移除您不想包含的文件。
3. 点击处理按钮。
4. 包含所有已上传 PDF 的 ZIP 压缩包会立即下载。

## 功能

- 接受任意数量的 PDF 文件
- 创建压缩包前可逐个移除文件
- 在 ZIP 内保留原始文件名
- 不修改 PDF 内容，文件按原样打包
- 显示每个已上传 PDF 的文件名和大小

## 使用场景

- 将一组发票或收据打包，作为电子邮件附件
- 打包项目交付物（多个 PDF 报告）以便交接
- 为一组表单或模板创建单个下载文件
- 将一批文档归档为一个压缩文件

## 小技巧

- ZIP 文件使用原始的 PDF 文件名。如果有同名文件，请在上传前重命名以避免冲突。
- 此工具不会压缩 PDF 本身。如需减小文件大小，请先使用压缩 PDF 处理，然后再用此工具打包。

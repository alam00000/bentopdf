# ODG 转 PDF

将 OpenDocument Graphics 文件转换为 PDF。ODG 是 LibreOffice Draw 的原生格式，用于图表、流程图和矢量插图。转换为 PDF 后，这些绘图更便于分享、打印和嵌入其他文档。

## 支持的格式

| 格式                  | 扩展名 | 备注                                    |
| :-------------------- | :----- | :-------------------------------------- |
| OpenDocument Graphics | `.odg` | LibreOffice Draw / OpenOffice Draw 文件 |

## 使用方法

1. 点击上传区域或将 ODG 文件拖放进来。可以一次添加多个文件。
2. 查看文件列表。使用垃圾桶图标移除单个条目，或点击 **添加更多文件** 添加更多绘图。
3. 点击 **转换为 PDF**。基于 LibreOffice 的引擎会在浏览器中加载并转换每个 ODG 文件，同时保留矢量图形、形状和文字。
4. 单个文件会直接下载为 PDF。多个文件会生成名为 `odg-to-pdf.zip` 的 ZIP 压缩包。

## 选项

无需额外设置。转换会保留 ODG 源文件中原有的页面尺寸、形状、连接线和文本框。

## 使用场景

- 与没有安装 LibreOffice 的客户分享 LibreOffice Draw 图表
- 打印在 Draw 中创建的流程图和网络图
- 将 ODG 插图作为嵌入的 PDF 加入报告或演示文稿
- 将技术图纸归档为数十年后仍可读取的格式

## 小贴士

- 矢量元素在 PDF 输出中仍保持矢量，因此结果可以清晰地缩放到任何打印尺寸。
- LibreOffice 引擎在首次使用时需要一点时间初始化。在同一会话中，之后的转换会更快。

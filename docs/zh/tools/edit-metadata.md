# 编辑元数据

编辑嵌入在 PDF 文件中的元数据。工具会用文档现有的元数据预先填充表单，让您修改任何字段，并将更改保存到新的 PDF 中。

## 使用方法

1. 上传 PDF 文件。工具会读取其当前元数据并填充表单。
2. 编辑任意标准字段：标题、作者、主题、关键词、创建者、生成器。
3. 使用日期时间选择器调整创建日期和修改日期。
4. 点击添加按钮并输入键值对，即可添加自定义元数据字段。
5. 点击处理按钮保存修改后的 PDF。

## 功能

- 预先填入上传 PDF 的所有现有元数据
- 标准字段：标题、作者、主题、关键词、创建者、生成器
- 创建日期和修改日期的日期时间选择器
- 自定义键值元数据字段，可用于任意属性
- 将更改直接保存到 PDF 的文档信息字典中

## 可编辑字段

| 字段           | 说明                             |
| -------------- | -------------------------------- |
| **标题**       | PDF 阅读器中显示的文档标题       |
| **作者**       | 创建文档的个人或组织             |
| **主题**       | 对文档主题的简要描述             |
| **关键词**     | 以逗号分隔的词语，用于搜索和分类 |
| **创建者**     | 最初创建内容的应用程序           |
| **生成器**     | 生成该 PDF 的应用程序            |
| **创建日期**   | 文档最初创建的时间               |
| **修改日期**   | 文档最后修改的时间               |
| **自定义字段** | 您定义的任何其他键值对           |

## 使用场景

- 在发布文档前设置恰当的标题和作者
- 添加关键词，以提高文档管理系统中的可搜索性
- 更新修改日期以反映当前修订版本
- 添加部门、项目 ID 或密级等自定义元数据字段
- 清理原始创作软件留下的元数据

## 小提示

- 自定义字段会直接写入 PDF 的信息字典。某些 PDF 阅读器可能不会显示自定义字段，但它们会保留在文件中。
- 将字段留空即可从元数据中清除它。处理按钮会保存表单中的所有内容。
- 如果只想查看元数据而不编辑，请使用 [查看元数据](./view-metadata)。如需完全移除所有元数据，请使用移除元数据。

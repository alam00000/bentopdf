# 分割页面

通过水平或垂直分割，将单个 PDF 页面切成两半。当一个页面包含应分开成独立页面的内容时，这会很有用，例如被扫描成一张宽页的双栏版式。

## 使用方法

1. 上传 PDF 文件。
2. 选择分割方向：**垂直**（左/右两半）或 **水平**（上/下两半）。
3. 可选：指定页面范围，限定要分割的页面。留空则分割所有页面。
4. 点击处理按钮，生成分割后的 PDF。

## 功能

- 垂直分割：将每页分成左右两半
- 水平分割：将每页分成上下两半
- 页面范围过滤，可有选择地分割特定页面
- 未选中的页面保持不变
- 无需重新渲染，保持内容质量

## 使用场景

- 分开双页扫描件（例如一张纸上同时包含左右两页的书籍扫描）
- 将带有并排内容的横向 PDF 拆分为单独的纵向页面
- 将较高的信息图或海报分成上下两个独立部分
- 为标准纸张打印准备宽幅文档

## 小提示

- 如果页面内容分布不均，分割仍会在精确的中点进行。如需非对称分割，可考虑改用 [裁剪 PDF](./crop-pdf)。
- 如果页面在分割前或分割后需要旋转，可将此工具与 [旋转 PDF](./rotate-pdf) 结合使用。

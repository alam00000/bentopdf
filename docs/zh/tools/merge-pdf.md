# 合并 PDF

将多个 PDF 文件合并为一个文档。您可以按指定顺序合并整个文件，也可以切换到页面模式，对每个上传 PDF 中的单个页面进行精细控制。

## 使用方法

1. 点击拖放区域或将文件拖入，上传两个或更多 PDF 文件。
2. 使用顶部的切换开关在 **文件模式** 和 **页面模式** 之间选择。
3. 在文件模式下，拖动文件重新排序，并可为每个文件指定页面范围（例如 `1-3, 5`）。范围留空则包含所有页面。
4. 在页面模式下，拖放单个页面缩略图来构建您想要的页面顺序。
5. 点击 **合并 PDF**，将所有内容合并为一个文件。合并后的 PDF 会自动下载。

## 功能

- 两种合并模式：文件模式用于快速合并整个文件，页面模式用于逐页控制
- 两种模式都支持拖放排序，动画流畅
- 页面范围语法（例如 `1-3, 5, 8-10`）让您无需切换到页面模式即可挑选页面
- 页面缩略图懒加载，即使处理大型文档，界面也保持响应
- 文件数量和总页数均无限制
- 保留原始 PDF 质量，不会重新编码

## 选项

| 选项           | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| **文件模式**   | 按自定义顺序合并整个文件，可为每个文件设置页面范围过滤       |
| **页面模式**   | 以网格形式显示所有文件的所有页面，拖动缩略图构建您想要的顺序 |
| **页面输入框** | 每个文件的文本字段，接受类似 `1-3, 5` 的范围，只包含特定页面 |

## 使用场景

- 将各章节的 PDF 合并为一本书或一份报告
- 将求职信和简历合并为一份申请文档
- 从多个源文档中提取特定页面，汇总为一个文件
- 将扫描的收据或发票整理为一个归档 PDF
- 用多份幻灯片中的页面制作演示文稿讲义

## 小贴士

- 当您需要将不同文件的页面交错排列，而不是一个文件接着一个文件追加时，请使用页面模式。
- 初次上传后，您可以使用 **添加更多文件** 按钮继续添加文件，而不会丢失当前的排列。
- 页码从 1 开始，因此 `1` 指该文件的第一页。

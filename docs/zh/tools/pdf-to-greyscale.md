# PDF 转灰度

将彩色 PDF 转换为灰度版本。每个页面都会被渲染、去饱和，并作为 JPEG 图像重新嵌入到新的 PDF 中。输出保留原始页面尺寸。

## 使用方法

1. 点击拖放区域或将文件拖到其上以上传 PDF。
2. 点击 **转换** 处理文件。
3. 新的 `greyscale.pdf` 会下载，所有页面都已转换为黑白。

在底层，每个页面以 2 倍比例渲染，像素数据经过灰度滤镜处理，然后以 90% 质量重新编码为 JPEG，并放入全新的 PDF 文档中。

## 选项

此工具没有可配置的选项。灰度转换使用标准亮度公式，JPEG 质量固定为 90%。

## 输出格式

- 一个 `greyscale.pdf` 文件，其中所有页面均为灰度 JPEG 图像。

## 使用场景

- 准备黑白打印的文档，以节省彩色墨水成本。
- 满足要求使用灰度的法律或政府文件的提交要求。
- 减小色彩丰富的 PDF 的文件大小（JPEG 灰度图像比彩色图像更小）。
- 为混合了彩色和黑白页面的文档创建一致的视觉风格。

## 小技巧

- 由于每个页面都被栅格化并重新嵌入为 JPEG，输出是基于图像的。原始 PDF 中的文本将不再可选择或可搜索。如果之后需要可搜索的文本，请将输出通过 OCR 工具处理。
- 如需对颜色调整（亮度、对比度、饱和度）进行更多控制，请查看调整颜色工具，或 [PDF 工作流构建器](./pdf-workflow) 中的灰度节点。

# 扫描效果

将干净的数字 PDF 变成看起来像是从平板扫描仪中出来的文档。该工具会应用可配置的噪点、轻微旋转、模糊、亮度偏移以及可选的泛黄效果，模拟实体扫描的瑕疵。

## 工作原理

1. 上传您的 PDF 文件。
2. 编辑器打开后，会在设置面板旁显示第一页的实时预览。
3. 使用滑块和开关调整扫描效果参数。
4. 更改设置时，预览会实时更新。
5. 点击**应用**处理所有页面并下载结果。

## 选项

- **色彩空间（灰度开关）**：将输出转换为灰度，呈现经典的黑白扫描效果。
- **边框**：在页面边缘添加一圈淡淡的深色边框，模拟扫描仪的边框伪影。
- **旋转**：应用轻微旋转（-5 到 +5 度），模拟纸张送入时没有对齐。
- **旋转变化**：为旋转角度添加随机变化，使每页的倾斜略有不同。
- **亮度**：整体调高或调低亮度。
- **对比度**：调整对比度，模拟碳粉质量的差异。
- **模糊**：应用高斯模糊，使文字边缘变得柔和，如同低质量的扫描。
- **噪点**：添加随机像素噪点，模拟扫描仪传感器的颗粒感。数值越高，颗粒感越强。
- **泛黄**：添加暖黄色调，模拟老化或再生纸张。
- **分辨率**：设置输出 DPI。数值越低，画面越像素化，越像扫描件。
- **重置**：将所有设置恢复为默认值。

## 功能

- 实时预览，随每个参数的调整而更新
- 每页随机旋转变化，效果更逼真
- 十个可独立调节的参数
- 灰度模式，呈现真实的黑白扫描输出
- 分辨率可控，从低 DPI 的传真质量到高 DPI 的归档质量

## 使用场景

- 让数字创建的文档看起来像是经过扫描和打印的
- 模拟实体文档的老化，用于历史文档的复原
- 针对劣化的扫描质量测试 OCR 软件
- 制作与现有扫描档案视觉风格一致的文档

## 提示

- 从细微的数值开始。10-20 的噪点级别、0.5 度的轻微旋转和极少的模糊，就已能产生逼真的扫描效果。
- 将灰度模式与轻微泛黄结合，可获得“复印件的复印件”效果。
- 较低的分辨率设置（100-150 DPI）最能呈现真实的传真机效果。

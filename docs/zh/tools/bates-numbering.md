# Bates 编号

Bates 编号会在 PDF 的每一页上加盖顺序标识符。它是法律程序、审计和合规工作流中标注文档的标准方法。此工具支持多个文件和自定义模板，可输出分别编号的 PDF 或单个 ZIP 压缩包。

## 工作原理

1. 上传一个或多个 PDF 文件。可以一次拖入多个文件。
2. 选择样式预设或创建自定义模板。
3. 配置位置、字体、大小、颜色和起始编号。
4. 点击**应用 Bates 编号**进行处理。
5. 单个文件直接下载。多个文件会作为 ZIP 压缩包下载。

## 选项

- **样式预设**：从内置格式中选择：
  - 证据 + 案件 + Bates + 页码（例如“Exhibit 1 Case XYZ 000001 Page 1”）
  - 证据 + 案件 + Bates（无页码）
  - 案件 + Bates
  - 仅 Bates 编号（例如 "000001"）
  - 自定义（编写您自己的模板）
- **自定义样式**：使用占位符的模板字符串：`[BATES]`、`[PAGE]`、`[FILE]`、`[FILENAME]`。
- **Bates 补零位数**：补零的 Bates 编号的位数（3 到 6）。仅在自定义模式下可见。
- **位置**：页眉或页脚，左、中或右。
- **Bates 起始编号**：第一个 Bates 编号。默认为 1。编号会在各文件之间延续。
- **文件计数器起始值**：`[FILE]` 占位符的起始数字。
- **字体**：Helvetica、Times New Roman 或 Courier。
- **字号**：加盖文字的大小。
- **颜色**：Bates 编号文字的取色器。

## 功能

- 实时预览，显示 Bates 编号在所有已上传文件中的显示效果
- 支持多个文件，编号在各文档之间连续
- 拖放重新排序文件，以控制编号顺序
- 六种位置选项（页眉/页脚，左/中/右）
- 自适应页边距计算，适应不同的页面尺寸
- 多文件批量处理时输出 ZIP
- 模板占位符提供最大灵活性

## 使用场景

- 为诉讼的证据开示文档加盖顺序证据编号
- 为跨越数十个文件的审计证据包编号
- 为合规文档应用监管参考编号
- 使用案件专属标识符标注专利申请的附件

## 提示

- 处理前，在文件列表中拖动文件可重新排序。Bates 编号顺序遵循此排列。
- 使用 `[FILENAME]` 占位符可在印章中包含原始文件名，有助于将页面追溯到源文档。
- 更改设置时，预览框会实时更新，因此您可以在处理前核对格式。

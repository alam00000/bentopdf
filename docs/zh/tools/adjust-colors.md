# 调整颜色

面向 PDF 的完整调色工具集。可调整八个独立参数：亮度、对比度、饱和度、色相偏移、色温、色调、伽马和棕褐色，拖动每个滑块时实时预览都会更新。

## 工作原理

1. 上传您的 PDF 文件。
2. 编辑器打开，显示第一页的预览和颜色设置面板。
3. 移动滑块调整各项颜色参数。预览会实时更新。
4. 点击**重置**将所有滑块恢复到默认位置。
5. 点击**应用**处理所有页面并下载调整后的 PDF。

## 选项

- **亮度**：使整个页面变亮或变暗（-100 到 +100）。
- **对比度**：增大或减小明暗区域之间的差异（-100 到 +100）。
- **饱和度**：增强或降低颜色强度（-100 到 +100）。设为 -100 会得到灰度效果。
- **色相偏移**：旋转色轮，统一改变所有颜色。
- **色温**：使颜色偏暖（黄/橙）或偏冷（蓝）。
- **色调**：添加绿色或洋红色偏色。
- **伽马**：使用伽马曲线调整中间调亮度。小于 1.0 的值会使中间调变暗，大于 1.0 的值会使其变亮。
- **棕褐色**：应用经典的棕褐色调效果。数值越高，棕色色调越强。

## 功能

- 八个可独立调整的颜色参数
- 实时预览，对滑块变化立即响应
- 重置按钮可快速恢复默认值
- 处理文档中的所有页面
- 适用于任何 PDF 内容（文字、图片、图形）

## 使用场景

- 提亮较暗的扫描件或校正曝光过度的页面
- 在打印前降低彩色文档的饱和度以节省墨水
- 应用棕褐色调，为证书或奖状营造复古外观
- 校正 PDF 中嵌入照片的色温
- 增强褪色或低质量扫描文档的对比度

## 提示

- 若要快速转换为灰度，请将饱和度滑块一直拖到 -100。
- 对于中间调过暗或过亮的扫描文档，伽马滑块对提升可读性特别有用。
- 与其他图像效果工具一样，此工具会将每一页栅格化。输出将基于图像，因此文字无法选中。

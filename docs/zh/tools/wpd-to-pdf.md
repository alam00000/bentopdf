# WPD 转 PDF

将 Corel WordPerfect 文档转换为 PDF 文件。WPD 曾是律师事务所和政府机构中占主导地位的文字处理格式。如果您有旧的 WordPerfect 文件，而现代软件拒绝打开它们，此工具可以把它们变回标准 PDF。

## 支持的格式

| 格式        | 扩展名 | 说明                        |
| :---------- | :----- | :-------------------------- |
| WordPerfect | `.wpd` | 所有主要的 WordPerfect 版本 |

## 工作原理

1. 点击上传区域，或拖放您的 WPD 文件。可以一次选择多个文件。
2. 查看文件列表。使用垃圾桶图标移除不需要的文件，或使用**添加更多文件**添加更多文档。
3. 点击**转换为 PDF**。工具会在浏览器中加载基于 LibreOffice 的转换引擎，解析 WPD 格式并输出 PDF。
4. 单个文件会直接下载为 PDF。批量转换会生成名为 `wpd-to-pdf.zip` 的 ZIP 压缩包。

## 选项

无需任何配置。LibreOffice 引擎会自动处理 WPD 的格式、字体和布局。

## 使用场景

- 打开几十年前用 WordPerfect 写成的法律文件
- 将归档的政府申报文件从 WPD 转换为现代格式
- 将旧的 WordPerfect 文档库迁移为 PDF 以便长期存储
- 与没有安装 Corel WordPerfect 的收件人分享 WPD 文件

## 提示

- LibreOffice 引擎在首次使用时加载，需要一点时间。同一会话中之后的转换会更快。
- 复杂的 WPD 宏和显示代码不会保留，但视觉布局、文本内容和基本格式会带入 PDF。

# PDF 转 CSV

从 PDF 中提取表格并导出为 CSV 文件。工具使用 PyMuPDF 的表格检测引擎扫描每一页的表格数据，然后将找到的所有行写入单个逗号分隔的输出中。

## 使用方法

1. 点击拖放区域或将文件拖到其上以上传 PDF。
2. 点击 **转换** 开始提取表格。
3. 工具会扫描每一页并自动识别表格。
4. 包含所有提取的表格数据的 `.csv` 文件会下载。

输出中，来自不同页面的表格以空行分隔。包含逗号、引号或换行符的单元格会按照 RFC 4180 正确转义。

## 选项

此工具没有可配置的选项。文档中找到的所有表格都会被提取并合并为单个 CSV。

## 输出格式

- 一个包含所有检测到的表格的 `filename.csv` 文件。

## 使用场景

- 将 PDF 银行对账单或发票中的财务数据导入电子表格。
- 从供应商报价单中提取价格表进行比较。
- 将 PDF 论文中的表格研究数据转换为适合分析工具的格式。
- 将旧版 PDF 报告中的数据迁移到数据库。

## 小技巧

- 如果未找到表格，工具会显示“未找到表格”消息。这通常意味着 PDF 使用的文本布局看起来像表格，但并非真正结构化的表格。
- 如需对单个表格进行更多控制，请使用 [提取 PDF 表格](./extract-tables)，它允许您在 CSV、JSON 和 Markdown 输出格式之间选择。
- 如果您需要 Excel 格式的数据，并让每个表格位于单独的工作表，请使用 [PDF 转 Excel](./pdf-to-excel)。

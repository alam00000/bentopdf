# N-Up PDF

将多个页面按网格排列到同一张纸上。每张纸可容纳 2、4、6、8、9 或 16 页，从而减少打印的页数。该工具会处理缩放、定位和可选的页面尺寸配置。

## 使用方法

1. 上传一个 PDF 文件。
2. 选择每张纸上的页数（即“N”值）：2、4、6、8、9 或 16。
3. 选择输出页面尺寸（默认为 A4）和方向。
4. 可选：配置间距、边框颜色和背景颜色。
5. 点击处理按钮。该工具会缩放每一页，并将它们平铺到新的纸张上。

## 功能

- 网格布局：2 合 1、4 合 1、6 合 1、8 合 1、9 合 1 和 16 合 1
- 可配置的输出页面尺寸和方向
- 平铺页面之间可选的间距
- 背景和边框颜色设置
- 缩放以适应时保持原始页面的宽高比

## 选项

| 选项         | 说明                                              |
| ------------ | ------------------------------------------------- |
| **每张页数** | 每个输出页面上容纳的原始页数（2、4、6、8、9、16） |
| **页面尺寸** | 输出纸张的尺寸（A4、Letter、Legal 等）            |
| **方向**     | 输出纸张为纵向或横向                              |
| **间距**     | 平铺页面之间的间隙，单位为磅                      |
| **背景颜色** | 输出纸张背景的填充颜色                            |
| **边框颜色** | 每个平铺页面周围边框的颜色                        |

## 使用场景

- 打印每页 4 张幻灯片的讲义以节省纸张
- 创建在一张纸上放置多页参考资料的学习资料
- 制作紧凑的文档归档以便存档
- 为长文档生成缩略图概览页

## 小贴士

- 对于 2 合 1 布局，横向通常效果更好，而 4 合 1 及以上的布局通常最适合纵向。
- 增加间距有助于提高可读性，但会减少每个平铺页面的可用区域。
- 若要执行相反的操作（将一页拆分为多页），请参阅 [海报化 PDF](./posterize-pdf)。

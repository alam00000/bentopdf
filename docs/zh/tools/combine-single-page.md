# 合并为单页

将 PDF 的每一页合并成一个长页面。页面会垂直拼接（像卷轴一样）或水平拼接（并排放置），输出为一个连续的单页。

## 使用方法

1. 上传 PDF 文件。
2. 选择排列方向：**垂直**（页面从上到下堆叠）或 **水平**（页面并排放置）。
3. 以点为单位设置页面之间的间距。
4. 为页面之间的间隙选择背景颜色。
5. 可选：启用分隔线（页面之间的细线），并配置其粗细和颜色。
6. 点击处理按钮。输出为单页 PDF。

## 功能

- 垂直或水平拼接页面
- 可配置页面间距
- 为间隙区域提供背景颜色选择器
- 可选分隔线，粗细和颜色可调
- 将每个原始页面以完整分辨率渲染到合并后的画布上

## 选项

| 选项           | 说明                       |
| -------------- | -------------------------- |
| **方向**       | 垂直（堆叠）或水平（并排） |
| **页面间距**   | 页面之间的间隙，单位为点   |
| **背景颜色**   | 页面之间区域的颜色         |
| **添加分隔线** | 切换页面之间的细线         |
| **分隔线粗细** | 线条粗细，单位为点         |
| **分隔线颜色** | 分隔线的颜色               |

## 使用场景

- 将多页线框图或设计稿制作成一张长图
- 生成可连续滚动的文档视图，用于网页嵌入
- 将多页漫画或分镜拼接成一条长带
- 生成连续页面的全景视图，便于审阅

## 小提示

- 垂直方向最适合纵向页面的文档。横向内容则更适合水平方向。
- 页数很多的大型文档会生成非常高或非常宽的输出。某些 PDF 查看器可能无法处理特别大的单页。
- 使用对比色的分隔线，可以轻松看出一个原始页面在哪里结束、下一页从哪里开始。

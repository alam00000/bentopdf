# MOBI 转 PDF

将亚马逊 Kindle 的 MOBI 电子书转换为 PDF 文档。MOBI 文件与 Kindle 设备和应用绑定，难以在其他地方阅读。转换为 PDF 后，您就得到一个可在任何设备上打开或打印的便携版本。

## 支持的格式

| 格式 | 扩展名  | 备注                           |
| :--- | :------ | :----------------------------- |
| MOBI | `.mobi` | Kindle 电子书格式 (Mobipocket) |

## 使用方法

1. 点击上传区域或拖放一个或多个 MOBI 文件。
2. 查看文件列表。使用垃圾桶图标移除不需要的文件，或使用 **添加更多文件** 加入更多电子书。
3. 点击 **转换为 PDF**。PyMuPDF 引擎会解析 MOBI 结构，并将每一页渲染为 PDF 内容。
4. 单个文件会下载为 PDF。转换多个文件时，您会得到名为 `mobi-converted.zip` 的 ZIP 压缩包。

## 选项

无需额外设置。转换会保留原始 MOBI 文件中的文本内容、格式和嵌入的图片。

## 使用场景

- 在只支持 PDF 的非 Kindle 电子阅读器上阅读在 Kindle 购买的内容
- 打印电子书中的章节，用于离线学习或批注
- 将个人电子书库归档为通用格式
- 与没有安装 Kindle 应用的人分享摘录

## 小贴士

- 受 DRM 保护的 MOBI 文件无法转换。该工具只适用于无 DRM 的 MOBI 文件。
- 带有大量嵌入图片的大型电子书可能需要多花几秒钟，因为所有处理都在浏览器中进行。

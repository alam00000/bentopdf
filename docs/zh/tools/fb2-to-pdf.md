# FB2 转 PDF

将 FictionBook 2 (FB2) 文件转换为 PDF 文档。FB2 是一种基于 XML 的电子书格式，在俄罗斯和东欧很流行。它在某些平台上支持良好，在其他平台上却几乎无人知晓，转换为 PDF 后，您的书籍就可以在任何地方阅读。

## 支持的格式

| 格式          | 扩展名 | 备注                  |
| :------------ | :----- | :-------------------- |
| FictionBook 2 | `.fb2` | 基于 XML 的电子书格式 |

## 使用方法

1. 点击上传区域或将 FB2 文件拖放进来。支持批量选择多个文件。
2. 查看文件列表。使用垃圾桶图标移除单个文件，或点击 **添加更多文件** 加入更多文件。
3. 点击 **转换为 PDF**。PyMuPDF 引擎会解析 FB2 的 XML 结构，并将其渲染为分页的 PDF 内容。
4. 单个文件会直接下载为 PDF。转换多个文件时，会打包为 `fb2-converted.zip`。

## 选项

无需任何配置。转换器会自动处理 FB2 的 XML 结构，并保留章节分隔、格式和所有嵌入的图片。

## 使用场景

- 在只支持 PDF 的设备或应用上阅读 FB2 电子书
- 打印以 FB2 格式发布的俄语文学作品
- 将 FB2 藏书归档为通用支持的格式
- 与阅读器不支持 FictionBook 的人分享一本书

## 小贴士

- FB2 文件是纯 XML，因此通常体积很小，即使在浏览器中也能快速转换。
- 如果您的 FB2 文件被压缩为 `.fb2.zip`，请先解压再上传。

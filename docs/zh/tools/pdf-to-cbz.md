# PDF 转 CBZ

将 PDF 转换为 CBZ（Comic Book ZIP）文件，这是数字漫画和日本漫画的标准格式。每个 PDF 页面都会成为压缩包内的一张图片。工具会生成三种格式的元数据以获得最佳兼容性：ComicInfo.xml、metadata.opf 和 ComicBookInfo JSON。

## 使用方法

1. 点击拖放区域或将文件拖到其上以上传 PDF。
2. 选择图片格式、质量、缩放比例和可选的元数据。
3. 点击 **转换** 生成 CBZ 文件。
4. `.cbz` 文件会自动下载。

## 选项

| 选项       | 值              | 默认值 | 说明                                                                 |
| ---------- | --------------- | ------ | -------------------------------------------------------------------- |
| 图片格式   | JPEG, PNG, WebP | JPEG   | JPEG 适用于彩色漫画，PNG 适用于无损黑白日本漫画，WebP 压缩效果最佳。 |
| 质量       | 50–100%         | 85%    | 控制 JPEG/WebP 压缩。PNG 不显示此项（始终无损）。                    |
| 缩放       | 1.0x–4.0x       | 2.0x   | 缩放比例越高，图像在高分辨率屏幕上越清晰。                           |
| 灰度       | 开/关           | 关     | 将页面转换为灰度。可减小黑白内容的文件大小。                         |
| 日漫模式   | 开/关           | 关     | 在元数据中设置从右到左的阅读方向。                                   |
| 包含元数据 | 开/关           | 开     | 嵌入 ComicInfo.xml、metadata.opf 和 ComicBookInfo JSON。             |

## 元数据字段

启用元数据后，您可以填写：

- **标题**：从 PDF 文件名自动检测。
- **系列**：系列名称（例如“Naruto”）。
- **编号 (#)**：系列中的期号。
- **卷 (Vol.)**：卷号。
- **作者**：作者或创作者姓名。
- **出版商**：出版公司。
- **标签 / 类型**：以逗号分隔的标签（例如“Action, Adventure”）。
- **出版年份**：出版年份（1900–2100）。
- **评分**：社区评分，范围 0 到 5。

## 元数据兼容性

工具会以三种格式写入元数据，以便每个阅读器都能找到它：

| 格式               | 位置         | 支持的软件                                  |
| ------------------ | ------------ | ------------------------------------------- |
| ComicInfo.xml      | ZIP 内的文件 | Komga, Kavita, CDisplayEx, Mylar, ComicRack |
| metadata.opf       | ZIP 内的文件 | Calibre                                     |
| ComicBookInfo JSON | ZIP 注释字段 | Calibre（备用）                             |

## 输出格式

- `filename.cbz`：包含编号页面图片和元数据文件的 ZIP 压缩包。

页面图片以补零的编号命名（`01.jpg`、`02.jpg` 等），以便阅读器按正确顺序显示。

## 使用场景

- 转换日本漫画或漫画 PDF，以便在漫画阅读器中使用。
- 在 Komga、Kavita 或 Calibre 中建立数字漫画库。
- 将扫描的漫画书转换为便于阅读器使用的格式。
- 以保留阅读方向和元数据的格式分享漫画。

## 小技巧

- 彩色漫画使用 **JPEG**，黑白日本漫画使用 **PNG**，PNG 能非常高效地压缩黑白内容。
- 对日本漫画启用 **灰度** 可显著减小文件大小。
- 填写 **系列** 和 **编号** 字段，以便库管理器（Komga、Calibre）自动整理您的收藏。
- **WebP** 压缩效果最佳，但较旧的漫画阅读器可能不支持。

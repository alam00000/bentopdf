# 添加空白页

在您指定的位置向 PDF 插入空白页。您可以控制空白页的插入位置和数量。

## 工作原理

1. 上传 PDF 文件。工具会显示页数。
2. 输入要插入空白页的**位置**。使用 `0` 在最开头插入，或使用总页数在末尾追加。
3. 输入要添加的空白页**数量**（默认为 1）。
4. 点击处理按钮。插入了空白页的 PDF 会自动下载。

## 功能

- 可在任意位置插入：文档开头、中间或末尾
- 一次操作添加多个空白页
- 位置提示会根据上传 PDF 的页数动态更新
- 标准 A4 尺寸的空白页

## 使用场景

- 在合编文档的各部分之间添加空白分隔页
- 插入空白页以对齐双面打印
- 为打印的学习指南添加手写笔记空间
- 补页以满足最低页数要求

## 提示

- 位置 `0` 表示插入到第一页之前。位置等于总页数表示追加到最后一页之后。
- 如果需要在特定位置插入内容（而不只是空白页），请使用 [PDF 多功能工具](./pdf-multi-tool)在指定页后插入另一个 PDF。

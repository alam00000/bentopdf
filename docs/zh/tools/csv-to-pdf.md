# CSV 转 PDF

将 CSV 文件转换为整洁、格式化的 PDF 文档。每个 CSV 都会被解析并在输出的 PDF 中渲染为表格。当您需要打印或分享表格数据，而接收者没有电子表格软件时，这会很有用。

## 支持的格式

| 格式 | 扩展名 |
| :--- | :----- |
| CSV  | `.csv` |

## 使用方法

1. 点击上传区域，或拖放一个或多个 CSV 文件。
2. 查看文件列表。可添加更多文件或移除不需要的文件。
3. 点击 **转换为 PDF**。进度指示器会显示转换状态。
4. 单个文件会直接下载为 PDF。多个文件会打包成 `csv-converted.zip`。

## 选项

此工具没有额外配置。CSV 会被自动解析并格式化为表格。

## 输出

| 输入数量 | 输出                                                    |
| :------- | :------------------------------------------------------ |
| 1 个文件 | 下载单个 PDF（例如 `data.pdf`）                         |
| 2 个以上 | ZIP 压缩包（`csv-converted.zip`），每个文件对应一个 PDF |

## 使用场景

- 将导出的数据库报表转换为可打印的 PDF 表格
- 与没有 Excel 的人分享财务数据或库存清单
- 为合规文档创建 CSV 日志文件的 PDF 版本
- 打印地址列表、成绩单，或任何以 CSV 存储的表格数据

## 小提示

- 为获得最佳效果，请确保您的 CSV 使用标准的逗号分隔符。工具遵循常见的 CSV 解析约定。
- 如果 CSV 列数很多，表格可能会被压缩以适应页面宽度。可考虑将过宽的数据集拆分为多个文件。
- 对于 Excel 文件（`.xls`、`.xlsx`），请使用 [Excel 转 PDF](./excel-to-pdf) 工具，它会保留电子表格格式和多个工作表。

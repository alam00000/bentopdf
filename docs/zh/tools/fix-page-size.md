# 修复页面尺寸

由多个来源拼合而成的 PDF，页面尺寸往往不一致：有的是 Letter，有的是 A4，有的完全是非标准尺寸。此工具会将每一页统一为同一个目标尺寸，并按需缩放内容以适应或填满页面。

## 使用方法

1. 上传一个 PDF 文件。
2. 从下拉菜单中选择 **目标页面尺寸**（A4、Letter、Legal、A3、A5、Tabloid 或自定义）。
3. 选择 **方向**：自动会保留每页原有的方向，也可以强制设为纵向或横向。
4. 选择 **内容缩放** 模式：适应（保留全部内容，可能添加边距）或填充（铺满页面，可能裁掉边缘）。
5. 可选：为新增的边距设置 **背景颜色**。
6. 点击 **修正页面尺寸**。

## 选项

- **标准尺寸**：A4、Letter、Legal、A3、A5、Tabloid
- **自定义尺寸**：以英寸或毫米输入宽度和高度
- **方向**：自动、纵向、横向
- **缩放模式**：适应或填充（裁剪）
- **背景颜色**：用于填充边距的任意颜色

## 使用场景

- 统一来自不同扫描仪的页面合并而成的 PDF
- 将美国 Letter 文档转换为 A4，便于国际分发
- 准备要求裁切尺寸一致的可印刷 PDF
- 修正略微偏离标准的页面（例如 8.49 x 11.02 英寸而不是 8.5 x 11）

## 小贴士

- 使用适应模式可确保不丢失任何内容。填充模式看起来更整洁，但可能裁掉边缘。
- 使用页面尺寸工具检查输出结果，确认每一页都与目标尺寸一致。
- 默认背景色为白色；如果文档带有深色边距，请改用深色。

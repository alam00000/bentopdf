# 扁平化 PDF

展平会将交互元素（表单字段、下拉菜单、复选框、注释、高亮、便签）直接合并到页面内容中。外观保持不变，但内容不再可编辑或可提取。这相当于把填好的表单打印出来再扫描回去，只不过质量依然完美。

## 使用方法

1. 上传一个或多个 PDF 文件。
2. 点击 **展平 PDF**。
3. 单个文件会直接下载，多个文件会生成 ZIP 压缩包。

该工具使用 pdf-lib 展平表单字段（通过 `form.flatten()`），并使用专用的注释展平器将注释烧录到页面流中。两项操作在一次处理中完成。

## 会被展平的内容

- **表单字段**：文本输入框、复选框、单选按钮、下拉菜单、签名字段
- **注释**：批注、高亮、删除线、下划线、便签、图章、墨迹注释
- **交互元素**：按钮、动作触发器

## 保持不变的内容

- 文本内容（仍可选择和搜索）
- 图片和图形
- 页面布局和尺寸
- 书签和目录
- 超链接（基于注释的除外）

## 使用场景

- 锁定已填写的表单，使收件人无法更改已提交的答案
- 为归档准备 PDF，此时不需要交互元素
- 修复因注释在不同查看器中渲染不一致而导致的显示问题
- 确保已签名的文档在签名后无法被修改
- 通过去除表单字段定义和注释对象来减小文件体积

## 小贴士

- 请在所有编辑完成后再展平。PDF 无法取消展平。
- 如果您需要在展平的同时清除元数据、JavaScript 和附件，请改用清理 PDF 工具，它的选项中包含展平。
- 有些 PDF 会提示“未找到表单”，如果文档只有注释而没有表单字段，这是正常现象。

# 邮件转 PDF

将保存的邮件文件转换为整洁、可打印的 PDF。工具会解析 EML 和 MSG 文件，提取完整的邮件内容（邮件头、正文和附件元数据），并将所有内容渲染成结构化的 PDF。适用于法律取证、记录保存，或只是打印一封重要邮件。

## 支持的格式

| 格式 | 扩展名 | 说明                                           |
| :--- | :----- | :--------------------------------------------- |
| EML  | `.eml` | 标准 MIME 邮件格式（大多数邮件客户端均可导出） |
| MSG  | `.msg` | Microsoft Outlook 专有格式                     |

## 使用方法

1. 点击上传区域，或拖放您的 EML 或 MSG 文件。可以在同一批次中混用两种格式。
2. 查看文件列表。使用垃圾桶图标移除不需要的条目，或点击 **添加更多文件** 加入更多邮件。
3. 配置转换选项（见下文）。
4. 点击 **转换为 PDF**。工具会解析每封邮件，将内容渲染为带样式的 HTML，并通过 PyMuPDF 引擎转换为 PDF。
5. 单封邮件会直接下载为 PDF。多封邮件会打包成 `emails-converted.zip`。

## 选项

| 选项               | 默认值 | 说明                                                          |
| :----------------- | :----- | :------------------------------------------------------------ |
| **页面大小**       | A4     | 在 A4、Letter 或 Legal 页面尺寸之间选择。                     |
| **包含抄送和密送** | 开启   | 启用后，抄送和密送收件人列表会显示在 PDF 的邮件头部分。       |
| **包含附件列表**   | 开启   | 启用后，邮件的文件附件列表（含文件名和大小）会显示在 PDF 中。 |

## 使用场景

- 将重要的商务往来邮件归档为 PDF，用于合规或审计
- 为法律程序或取证请求打印邮件往来
- 为通过邮件收到的订单确认、收据或合同创建永久记录
- 以无需 Outlook 即可阅读的格式备份 Outlook MSG 文件
- 根据导出的 EML 文件记录客户支持沟通

## 小提示

- 同时支持 EML（Thunderbird、Apple Mail 和大多数邮件客户端使用）和 Outlook MSG 文件。从邮件客户端导出邮件，然后直接拖入工具即可。
- HTML 格式的邮件会在 PDF 中保留其样式。纯文本邮件则以整洁易读的格式渲染。
- 附件列表会显示文件名和大小，但不会将实际的附件文件嵌入 PDF。

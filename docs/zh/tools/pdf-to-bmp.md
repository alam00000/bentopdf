# PDF 转 BMP

将 PDF 的每一页转换为 BMP（位图）图像。BMP 是未压缩格式，因此输出逐像素精确且无质量损失，但文件很大。

## 使用方法

1. 点击拖放区域或将文件拖到其上以上传 PDF。
2. 点击 **转换** 处理文件。
3. 单个 `.bmp` 文件或 ZIP 压缩包会自动下载。

## 选项

此工具没有可配置的选项。页面以固定的 2 倍比例渲染，生成的图像尺寸约为 PDF 原始页面尺寸的两倍。

## 输出格式

- **单页**：`filename.bmp`
- **多页**：`filename_bmps.zip`，包含 `page_1.bmp`、`page_2.bmp` 等。

## 使用场景

- 将 PDF 页面输入只接受 BMP 的旧系统或硬件。
- 为特定打印工作流准备未压缩图像。
- 将位图输出用作需要原始像素数据的图像处理工具的输入。

## 小技巧

- BMP 文件非常大，因为它们存储未经压缩的原始像素数据。在大多数情况下，[PDF 转 PNG](./pdf-to-png) 能以小得多的文件提供无损质量。
- 如果目标系统接受 PNG 或 TIFF，请优先使用这些格式以节省磁盘空间。

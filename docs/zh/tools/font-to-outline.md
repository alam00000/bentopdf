# 字体转轮廓

将字体转换为轮廓，会把每个文字字符从基于字体的字形变为矢量路径。PDF 不再依赖任何已安装的字体，在每台设备、每种操作系统和每台打印机上的呈现都完全相同。这是印前工作流程中的标准步骤。

## 使用方法

1. 上传一个或多个 PDF 文件。
2. 点击 **转换为轮廓**。
3. Ghostscript 会将所有文字转换为矢量路径。
4. 下载结果。多个文件会生成 ZIP 压缩包。

无需任何设置。该工具使用 Ghostscript (WebAssembly)，在一次处理中将所有字体引用转换为轮廓路径。

## 会发生的变化

- 文字字符变为矢量曲线（贝塞尔路径）
- 不再需要嵌入字体，PDF 在字形层面是自包含的
- 文件体积可能增大，因为矢量路径通常比字体引用更大
- 视觉外观完全保持不变

## 会失去的功能

- 文本选择和复制粘贴
- 文本可搜索性（Ctrl+F 将失效）
- 编辑文本内容的能力
- 屏幕阅读器的无障碍访问

## 使用场景

- 将 PDF 发送给要求字体转曲的印刷厂
- 与没有相应字体的人分享使用自定义或授权字体的文档
- 防止字体替换导致文档在其他系统上外观改变
- 为需要矢量输入的激光雕刻或 CNC 切割流程准备 PDF
- 确保含有大量徽标的 PDF 在所有平台上正确显示

## 小贴士

- 请保留原始 PDF。转轮廓不可逆，无法将路径转换回可编辑的文本。
- 如果您需要文本仍可搜索，可以考虑改用栅格化 PDF 工具，之后再进行 OCR。
- 转轮廓后的 PDF 往往更大。如果文件体积很重要，请随后运行压缩 PDF。

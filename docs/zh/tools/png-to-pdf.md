# PNG 转 PDF

将 PNG 图片转换为 PDF，并保留其完整分辨率。每张 PNG 都会成为单独的一页，页面大小与原始图片尺寸一致。透明度会被自动处理。

## 支持的格式

| 格式 | 扩展名 |
| :--- | :----- |
| PNG  | `.png` |

## 使用方法

1. 点击上传区域或拖放 PNG 文件。您可以一次选择多个文件。
2. 管理文件列表：移除不需要的文件或添加更多文件。
3. 从下拉菜单中选择 **PDF 质量** 级别。
4. 点击 **转换为 PDF**。输出会下载为 `from_jpgs.pdf`。

工具使用 pdf-lib 直接嵌入每张图片。如果某张 PNG 无法原生嵌入（例如由于不常见的颜色配置文件），则会回退为通过画布重新渲染为 JPEG。

## 选项

**PDF 质量** 控制嵌入之前应用的压缩：

- **高质量**：压缩最少，文件最大。
- **中等质量**（默认）：在大小和清晰度之间取得良好平衡。
- **低质量**：压缩最强，输出最小。

## 使用场景

- 将截图转换为多页 PDF，用于错误报告或文档
- 将 UI 设计导出文件打包为单个文件以供审阅
- 将图表导出文件（draw.io、Excalidraw）转换为可分享的 PDF
- 将一组图表图片汇编为报告

## 小技巧

- 带透明度的 PNG 文件在 PDF 中会获得白色背景。如果您需要不同的背景，请事先编辑图片。
- 对于带有锐利边缘和文字的截图和图表，高质量可避免 JPEG 压缩伪影。中等或低质量可能会在内部转换为 JPEG。

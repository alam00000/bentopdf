# 文本转 PDF

将纯文本转换为格式化的 PDF。您可以上传 `.txt` 文件，也可以直接在内置文本编辑器中输入。该工具支持多种字体、自定义文本颜色和各种页面尺寸，从 A0 到 A10，以及 US Letter、Legal 和 Tabloid。

## 支持的格式

| 输入         | 扩展名               |
| :----------- | :------------------- |
| 纯文本文件   | `.txt`               |
| 直接输入文本 | 在编辑器中键入或粘贴 |

## 工作原理

1. 使用顶部的开关选择输入模式：**上传文件**或**键入文本**。
2. 如果选择上传，请拖放或点击选择一个或多个 `.txt` 文件。如果选择键入，请直接在文本框中输入文本。
3. 配置格式选项：字体、字号、文本颜色和页面尺寸。
4. 点击**创建 PDF**。输出会以 `text_to_pdf.pdf` 下载。

上传多个文件时，它们的内容会被拼接在一起，中间以空行分隔。

## 选项

| 选项         | 取值                                                                          | 默认值          |
| :----------- | :---------------------------------------------------------------------------- | :-------------- |
| **字体**     | Helvetica（无衬线）、Tiro（衬线）、Courier（等宽）、Times（衬线）             | Helvetica       |
| **字号**     | 6 至 72 pt                                                                    | 12              |
| **文本颜色** | 通过颜色选择器选择任意颜色                                                    | 黑色（#000000） |
| **页面尺寸** | ISO A0 至 A10、B0 至 B10、C0 至 C10、US Letter、Legal、Tabloid、Ledger、11x17 | A4              |

系统会自动检测从右到左（RTL）的语言（阿拉伯语、希伯来语、波斯语、乌尔都语）。发现 RTL 文本时，文本方向和对齐方式会相应切换。

## 使用场景

- 使用 Courier 字体将代码片段或日志文件转换为可打印的 PDF
- 用当场键入的会议记录快速创建 PDF
- 以特定的字体和页面尺寸排版纯文本稿件以供提交
- 制作 README 或更新日志的 PDF 版本，用于离线分发

## 提示

- 想快速转换剪贴板内容而不先将其保存为文件时，请使用**键入文本**模式。
- Courier（等宽）是代码、日志或任何需要列对齐的内容的最佳字体选择。
- 页边距固定为四周各 72 点（1 英寸）。

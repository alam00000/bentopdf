# PDF 转 TIFF

将 PDF 的每一页转换为 TIFF 图像。TIFF 是印刷制作、传真系统和文档归档的标准格式。工具使用 PackBits 压缩进行 TIFF 编码，如果某个页面编码失败，则回退为 PNG。

## 使用方法

1. 点击拖放区域或将文件拖到其上以上传 PDF。
2. 点击 **转换** 处理文件。
3. 单个 TIFF 文件或 ZIP 压缩包会自动下载。

## 选项

此工具没有可配置的选项。页面以固定的 2 倍比例渲染。

## 输出格式

- **单页**：`filename.tiff`
- **多页**：`filename_tiffs.zip`，包含 `page_1.tiff`、`page_2.tiff` 等。

如果某个特定页面的 TIFF 编码失败（由于压缩问题），该页面会改为保存为 `.png` 文件。在这种情况下，ZIP 中会混合包含 TIFF 和 PNG 文件。

## 使用场景

- 向要求 TIFF 格式的政府机构或法律系统提交文档。
- 准备页面，通过数字传真服务进行传真传输。
- 以广泛支持的无损格式归档扫描文档。
- 将页面输入企业文档管理系统。

## 小技巧

- TIFF 文件很大。如果您只需要用于网页或屏幕的无损质量，[PDF 转 PNG](./pdf-to-png) 是更好的选择。
- 如果某些页面需要使用 PNG 回退，请检查 ZIP 内容，您可能需要单独转换这些页面。

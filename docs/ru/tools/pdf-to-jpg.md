# PDF в JPG

Преобразует каждую страницу PDF в изображение JPG. Одностраничные документы скачиваются как отдельный файл `.jpg`. Многостраничные PDF дают ZIP-архив с одним JPG на страницу.

## Как это работает

1. Загрузите PDF, нажав на область загрузки или перетащив файл. Инструмент покажет имя файла, размер и число страниц.
2. Ползунком **Качество изображения** настройте степень сжатия JPG.
3. Нажмите **Конвертировать**, чтобы начать обработку.
4. Результат скачается автоматически: один JPG для одностраничного PDF или ZIP-файл для многостраничного.

## Параметры

- **Качество изображения**: ползунок от 0% до 100% (по умолчанию 90%). Большие значения дают более чёткие изображения и большие файлы. Меньшие значения сжимают сильнее.

Внутри страницы рендерятся в масштабе 2x, поэтому разрешение результата вдвое больше размеров страницы PDF. Стандартная страница формата Letter даёт изображение примерно 1 224 x 1 584 пикселей.

## Формат результата

- **Одна страница**: `filename.jpg`
- **Несколько страниц**: `filename_jpgs.zip` с файлами `page_1.jpg`, `page_2.jpg` и так далее.

## Сценарии использования

- Создание миниатюр для системы управления документами.
- Отправка страницы отчёта в чат или письмо, где PDF не поддерживается.
- Получение изображений из PDF-схем и иллюстраций.
- Архивирование отсканированных документов в виде отдельных изображений.

## Советы

- Для вывода без потерь используйте [PDF в PNG](./pdf-to-png).
- Качество 80-90% даёт хороший баланс между размером файла и качеством изображения.
- Если для каждой страницы нужен определённый формат, посмотрите [Конструктор PDF-процессов](./pdf-workflow) с узлом вывода «PDF в изображения».

# Email в PDF

Превращайте сохраненные файлы электронной почты в аккуратные PDF для печати. Инструмент разбирает файлы EML и MSG, извлекает все письмо (заголовки, текст и сведения о вложениях) и отображает все это в структурированном PDF. Подходит для юридического раскрытия документов, ведения записей или просто печати важного письма.

## Поддерживаемые форматы

| Формат | Расширение | Примечания                                                                      |
| :----- | :--------- | :------------------------------------------------------------------------------ |
| EML    | `.eml`     | Стандартный формат писем MIME (экспортируется из большинства почтовых клиентов) |
| MSG    | `.msg`     | Проприетарный формат Microsoft Outlook                                          |

## Как это работает

1. Щелкните по области загрузки или перетащите в нее файлы EML или MSG. В одной партии можно смешивать оба формата.
2. Проверьте список файлов. Удаляйте ненужные записи значком корзины или нажмите **Добавить еще файлы**, чтобы добавить еще письма.
3. Настройте параметры преобразования (см. ниже).
4. Нажмите **Преобразовать в PDF**. Инструмент разбирает каждое письмо, отображает содержимое как стилизованный HTML и преобразует его в PDF через движок PyMuPDF.
5. Одно письмо скачивается сразу как PDF. Несколько писем упаковываются в `emails-converted.zip`.

## Параметры

| Параметр                                                    | По умолчанию | Описание                                                                                  |
| :---------------------------------------------------------- | :----------- | :---------------------------------------------------------------------------------------- |
| **Размер страницы**                                         | A4           | Выберите размер страницы: A4, Letter или Legal.                                           |
| **Указывать получателей копии и скрытой копии в заголовке** | Вкл.         | Если включено, списки получателей CC и BCC отображаются в разделе заголовка письма в PDF. |
| **Добавить список вложений письма**                         | Вкл.         | Если включено, в PDF появляется список вложенных файлов письма (с именами и размерами).   |

## Сценарии использования

- Архивирование важной деловой переписки в PDF для соблюдения требований или аудита
- Печать цепочек писем для судебных разбирательств или запросов на раскрытие документов
- Создание постоянной записи подтверждений заказов, чеков и договоров, полученных по электронной почте
- Резервное копирование файлов Outlook MSG в формате, для чтения которого не нужен Outlook
- Документирование обращений в службу поддержки по экспортированным файлам EML

## Советы

- Поддерживаются и EML (используется в Thunderbird, Apple Mail и большинстве почтовых клиентов), и файлы Outlook MSG. Экспортируйте письма из почтового клиента и перетащите их прямо в инструмент.
- Письма в формате HTML сохраняют оформление в PDF. Письма в виде обычного текста отображаются с аккуратным читаемым форматированием.
- Список вложений показывает имена файлов и размеры, но не встраивает сами вложенные файлы в PDF.

# Добавить метки страниц

Метки страниц определяют, как номера страниц отображаются в программах для чтения PDF (номер в панели инструментов, а не напечатанный на странице). Этот инструмент позволяет назначать разные схемы нумерации разным диапазонам страниц: римские цифры для вводной части, обычные числа для основного текста, буквенные приложения и другое.

## Как это работает

1. Загрузите PDF-файл.
2. Появится панель параметров с одним правилом меток по умолчанию.
3. Для каждого правила задайте диапазон страниц, стиль, необязательный префикс и начальное значение.
4. Нажмите **Добавить правило**, чтобы создать дополнительные правила для других разделов.
5. Нажмите **Добавить метки страниц**, чтобы применить все правила и скачать результат.

## Параметры

У каждого правила меток есть следующие настройки:

- **Диапазон страниц**: страницы, к которым применяется правило. Оставьте пустым для всех страниц. Поддерживаются записи вида `1-4`, `7`, `odd` или `1-9,30-40`.
- **Стиль метки**: десятичные арабские цифры, строчные римские (i, ii, iii), прописные римские (I, II, III), строчные буквы (a, b, c), прописные буквы (A, B, C) или без метки (только префикс).
- **Префикс метки**: необязательный текст перед каждой меткой, например «A-», чтобы получились метки A-1, A-2, A-3.
- **Начальное значение**: число, с которого начинается счет. По умолчанию 1. Укажите 0 для нумерации с нуля.
- **Продолжать нумерацию в несмежных диапазонах**: включите, если правило охватывает несмежные страницы (например, `1-9,30-40` или `odd`) и нумерация должна идти подряд.
- **Удалить существующие метки страниц**: включено по умолчанию. Очищает все прежние метки перед применением новых правил.

## Возможности

- Несколько правил меток на документ для сложных схем нумерации
- Шесть стилей меток, покрывающих все стандартные системы нумерации
- Произвольные префиксы для нумерации по разделам
- Поддержка несмежных диапазонов со сквозной нумерацией
- Возможность сохранить или удалить существующие метки

## Сценарии использования

- Римские цифры (i, ii, iii) для предисловия книги и обычные числа для основного текста
- Нумерация страниц приложений с буквенными префиксами, например «A-1», «A-2», «B-1», «B-2»
- Исправление меток страниц в отсканированном документе, где номера на бумаге не совпадают с порядком страниц в PDF
- Нумерация с нуля для технических документов

## Советы

- Метки страниц являются метаданными, которые программы для чтения PDF показывают в панели навигации. На самой странице они не печатаются. Для видимых номеров используйте [Номера страниц](./page-numbers).
- Для этого инструмента нужно настроить CoherentPDF (CPDF) в настройках WASM. Если он не настроен, вам предложат это сделать.

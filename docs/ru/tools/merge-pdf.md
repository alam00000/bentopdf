# Объединение PDF

Объединяйте несколько файлов PDF в один документ. Можно объединять файлы целиком в нужном порядке или переключиться в режим страниц для точного управления отдельными страницами из каждого загруженного PDF.

## Как это работает

1. Загрузите два или более файла PDF: нажмите на область загрузки или перетащите их.
2. Выберите **Режим файлов** или **Режим страниц** переключателем вверху.
3. В режиме файлов перетаскивайте файлы, чтобы изменить порядок, и при желании укажите для каждого файла диапазоны страниц (например, `1-3, 5`). Оставьте диапазон пустым, чтобы включить все страницы.
4. В режиме страниц перетаскивайте миниатюры отдельных страниц, чтобы составить точную последовательность.
5. Нажмите **Объединить PDF**, чтобы собрать всё в один файл. Объединённый PDF скачивается автоматически.

## Возможности

- Два режима объединения: режим файлов для быстрого объединения целых файлов и режим страниц для управления каждой страницей
- Изменение порядка перетаскиванием в обоих режимах с плавной анимацией
- Синтаксис диапазонов страниц (например, `1-3, 5, 8-10`) позволяет выбирать страницы без перехода в режим страниц
- Миниатюры страниц загружаются по мере необходимости, поэтому интерфейс остаётся отзывчивым даже с большими документами
- Нет ограничений на число файлов и общее количество страниц
- Сохраняет исходное качество PDF без повторного кодирования

## Параметры

| Параметр          | Описание                                                                                                          |
| ----------------- | ----------------------------------------------------------------------------------------------------------------- |
| **Режим файлов**  | Объединение файлов целиком в произвольном порядке с необязательными фильтрами диапазонов страниц                  |
| **Режим страниц** | Визуальная сетка всех страниц из всех файлов: перетаскивайте миниатюры, чтобы составить точную последовательность |
| **Поле страниц**  | Текстовое поле для каждого файла, принимающее диапазоны вроде `1-3, 5`, чтобы включить только нужные страницы     |

## Сценарии использования

- Объединение отдельных PDF с главами в одну книгу или отчёт
- Объединение сопроводительного письма и резюме в один документ для заявки
- Сбор нужных страниц из нескольких исходных документов в один файл
- Сборка отсканированных чеков или счетов в один архивный PDF
- Создание раздаточного материала для презентации из слайдов нескольких наборов

## Советы

- Используйте режим страниц, когда нужно чередовать страницы из разных файлов, а не добавлять один файл после другого.
- После первоначальной загрузки можно добавить ещё файлы кнопкой **Добавить ещё файлы**, не теряя текущего порядка.
- Нумерация страниц в диапазонах начинается с 1, поэтому `1` означает первую страницу файла.

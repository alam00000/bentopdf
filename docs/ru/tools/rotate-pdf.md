# Поворот PDF

Поворачивайте страницы PDF на 90 градусов по часовой стрелке или против неё. Инструмент показывает миниатюры всех страниц, позволяя поворачивать их по отдельности или сразу весь документ.

## Как это работает

1. Загрузите PDF-файл. Миниатюры всех страниц отображаются сеткой.
2. Кнопками поворота влево и вправо под миниатюрой повернёте именно эту страницу.
3. Элементами пакетного поворота вверху поверните все страницы сразу.
4. Предпросмотр миниатюр обновляется в реальном времени и показывает поворот.
5. Нажмите кнопку обработки, чтобы сохранить повёрнутый PDF.

## Возможности

- Поворот отдельных страниц с шагом 90 градусов (влево или вправо)
- Пакетный поворот всех страниц одновременно
- Предпросмотр миниатюр в реальном времени с анимацией поворота
- Отложенная загрузка миниатюр для плавной работы с большими документами
- Исходное содержимое и качество страниц сохраняются

## Сценарии использования

- Исправление отсканированных страниц, лежащих боком или вверх ногами
- Поворот альбомных страниц в книжную ориентацию (или наоборот)
- Исправление документа со смешанной ориентацией, где часть страниц отсканирована под неверным углом
- Подготовка документа к определённой ориентации отображения

## Советы

- Повороты накапливаются. Двойной щелчок по кнопке по часовой стрелке даёт поворот на 180 градусов.
- Для поворотов не на 90 градусов (например, на 45 градусов, чтобы выровнять слегка наклонённый скан) используйте [Поворот на заданное количество градусов](./rotate-custom).
- Элементы пакетного поворота действуют на все страницы, а не только на выбранные. Выбора страниц в этом инструменте нет: для этого используйте [PDF мультиинструмент](./pdf-multi-tool).

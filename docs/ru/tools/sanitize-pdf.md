# Санирование документа

PDF может содержать гораздо больше, чем видно на экране. Скрытые метаданные, встроенный JavaScript, вложенные файлы, данные форм и сведения о слоях могут раскрыть конфиденциальную информацию или создать угрозу безопасности. Санирование убирает всё это и оставляет чистый документ, безопасный для публикации.

## Как это работает

1. Загрузите PDF-файл.
2. Отметьте в списке, какие элементы удалить.
3. Нажмите **Санирование документа**.
4. Скачайте очищенный файл.

## Параметры санирования

Все параметры включены по умолчанию. Снимите отметку с тех, что нужно сохранить.

| Параметр                      | Что удаляется                                                       |
| ----------------------------- | ------------------------------------------------------------------- |
| **Свести формы**              | Превращает интерактивные поля форм в статичное содержимое           |
| **Удалить метаданные**        | Удаляет автора, название, дату создания, сведения о ПО и данные XMP |
| **Удалить аннотации**         | Удаляет комментарии, выделения, стикеры и разметку                  |
| **Удалить JavaScript**        | Убирает встроенные скрипты, которые могут выполниться при открытии  |
| **Удалить встроенные файлы**  | Удаляет файлы, вложенные в PDF                                      |
| **Удалить слои (OCG)**        | Сводит группы необязательного содержимого в один слой               |
| **Удалить ссылки**            | Удаляет гиперссылки и ссылки на URL                                 |
| **Удалить дерево структуры**  | Удаляет структуру документа, используемую для тегов доступности     |
| **Удалить MarkInfo**          | Удаляет сведения о размеченном содержимом                           |
| **Удалить встроенные шрифты** | Удаляет данные встроенных шрифтов (использовать с осторожностью)    |

## Сценарии использования

- Подготовка PDF к публикации с удалением внутренних метаданных (имена авторов, версии ПО, история правок)
- Удаление JavaScript из PDF, полученного из ненадёжного источника, перед открытием
- Очистка PDF перед отправкой клиенту, который не должен видеть встроенные комментарии и имена полей форм
- Удаление скрытых слоёв из архитектурного чертежа перед отправкой окончательной версии
- Соблюдение требований минимизации данных по нормам о конфиденциальности

## Советы

- Не отмечайте «Удалить встроенные шрифты», если не уверены, что PDF по-прежнему будет отображаться правильно. Удаление шрифтов может сделать текст невидимым в некоторых программах просмотра.
- Если нужно удалить только метаданные, быстрее и целенаправленнее воспользоваться отдельным инструментом «Удаление метаданных».
- Санирование необратимо. Сохраните исходный файл.

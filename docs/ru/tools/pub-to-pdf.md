# PUB в PDF

Преобразуйте файлы Microsoft Publisher в PDF. Publisher это программа для настольной вёрстки, входящая в некоторые версии Microsoft Office, но у большинства людей она не установлена. Этот инструмент позволяет любому преобразовать PUB в PDF прямо в браузере, без программ Microsoft.

## Поддерживаемые форматы

| Формат              | Расширение | Примечания                   |
| :------------------ | :--------- | :--------------------------- |
| Microsoft Publisher | `.pub`     | Документы настольной вёрстки |

## Как это работает

1. Нажмите на область загрузки или перетащите в неё PUB-файлы. Можно загрузить сразу несколько файлов.
2. Просмотрите список файлов. Удалите лишние значком корзины или нажмите **Добавить еще файлы**, чтобы добавить новые.
3. Нажмите **Преобразовать в PDF**. В браузере загружается движок на основе LibreOffice и преобразует каждый PUB-файл, сохраняя макет, изображения и текстовые блоки.
4. Один файл скачивается сразу как PDF. Несколько файлов доставляются в ZIP-архиве `pub-to-pdf.zip`.

## Параметры

Дополнительная настройка не нужна. Конвертер сам обрабатывает макет PUB.

## Сценарии использования

- Открытие PUB-флаеров и бюллетеней от клиента без покупки Microsoft Publisher
- Преобразование церковных бюллетеней, программ мероприятий и школьных газет, созданных в Publisher
- Архивирование маркетинговых материалов из Publisher в универсально доступном формате
- Печать PUB-файлов на системе, где Publisher не установлен

## Советы

- Сложные макеты Publisher с наложенными текстовыми блоками и точным позиционированием при преобразовании могут слегка сместиться. Если точность важна, проверьте результат.
- Движок LibreOffice инициализируется один раз за сессию. Первое преобразование занимает больше времени, последующие быстрее.
- Для наиболее точного преобразования убедитесь, что пользовательские шрифты из оригинала являются стандартными системными шрифтами.

# Поворот на заданное количество градусов

Поворачивайте страницы PDF на произвольный угол, а не только кратный 90 градусам. У каждой страницы своё поле ввода угла, а с помощью пакетного элемента управления можно применить один угол сразу ко всем страницам.

## Как это работает

1. Загрузите PDF-файл. Для каждой страницы отображаются миниатюры.
2. У каждой страницы есть числовое поле с текущим углом поворота.
3. Введите любое значение в градусах (положительное или отрицательное), чтобы повернуть конкретную страницу, или используйте кнопки влево и вправо у каждой страницы для быстрых поворотов на 90 градусов.
4. С помощью поля **пакетного угла** вверху задайте одинаковый поворот для всех страниц.
5. Нажмите кнопку обработки, чтобы создать повёрнутый PDF.

## Возможности

- Свободный ввод градусов для каждой страницы (любое целое число)
- Пакетное управление углом для одинакового поворота всех страниц
- Предпросмотр поворота в миниатюрах в реальном времени
- Кнопки быстрого поворота страницы с шагом 90 градусов
- Отложенная загрузка миниатюр для быстрой работы с большими документами

## Сценарии использования

- Исправление слегка наклонённых сканов на несколько градусов
- Поворот страниц под нестандартные требования к ориентации
- Точные повороты отдельных страниц в документе со смешанным содержимым
- Тонкая подстройка углов страниц после первоначального массового поворота

## Советы

- Положительные значения поворачивают по часовой стрелке, отрицательные против часовой.
- Поле пакетного угла при применении перезаписывает углы всех страниц. При необходимости задавайте индивидуальные поправки после пакетной операции.
- Для стандартных поворотов на 90, 180 и 270 градусов с более простым интерфейсом используйте [Поворот PDF](./rotate-pdf).

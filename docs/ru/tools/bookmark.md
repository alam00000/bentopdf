# Редактирование закладок

Редактор закладок дает полный контроль над навигационными закладками PDF (их также называют структурой документа). Вы можете добавлять новые закладки, редактировать существующие, менять иерархию, а также импортировать и экспортировать данные закладок в форматах CSV и JSON.

## Как это работает

1. Загрузите PDF, щелкнув по области загрузки или перетащив в нее файл.
2. При желании отметьте **Автоматически извлекать существующие закладки**, чтобы загрузить текущее дерево закладок документа.
3. Редактор откроется в режиме разделенного экрана: слева просмотр PDF, справа панель закладок.
4. Введите название закладки и нажмите **Добавить на страницу**, чтобы создать закладку на текущую страницу.
5. Кнопками на панели инструментов можно переставлять, оформлять или удалять закладки.
6. Нажмите **Сохранить PDF с закладками**, чтобы скачать обновленный файл.

## Возможности

- Визуальный просмотр PDF с навигацией по страницам, масштабированием и переходом к нужной странице
- Добавление закладки на любую страницу одним щелчком
- Щелчок прямо по PDF для точного задания места назначения закладки (режим выбора)
- Вложенная иерархия закладок с изменением порядка перетаскиванием
- Пакетные операции: выберите несколько закладок, чтобы сразу изменить цвет, стиль или удалить их
- Поиск по закладкам для быстрого нахождения записей в больших деревьях
- Отмена и повтор всех изменений
- Импорт закладок из CSV (название, страница, уровень) или JSON
- Экспорт закладок в CSV или JSON для внешнего редактирования
- Оформление закладок: цвет (красный, синий, зеленый, желтый, фиолетовый) и начертание (полужирный, курсив, полужирный курсив)
- Быстрая навигация: прокручивайте страницы клавишами Page Up и Page Down

## Параметры

- **Автоматически извлекать существующие закладки**: если отмечено, инструмент при загрузке считывает и показывает текущие закладки PDF.
- **Пакетный режим**: включите, чтобы выбирать несколько закладок и применять к ним массовое изменение цвета, стиля или удаление.
- **Развернуть всё / Свернуть всё**: быстро показывает или скрывает вложенные закладки.

## Сценарии использования

- Добавление оглавления в учебник или руководство, где нет закладок
- Перестройка закладок в отсканированном документе после распознавания текста
- Экспорт закладок в CSV, правка в электронной таблице и повторный импорт
- Очистка автоматически созданных закладок с неверными ссылками на страницы
- Цветные закладки для выделения важных разделов в юридическом документе

## Советы

- Для массового создания закладок используйте импорт CSV. Формат простой: `title,page,level`, где уровень 1 означает верхний уровень.
- Режим выбора позволяет щелкнуть по точному месту на странице PDF и задать место назначения закладки, что точнее, чем указание только номера страницы.
- Экспортируйте закладки перед крупными изменениями, чтобы иметь резервную копию.

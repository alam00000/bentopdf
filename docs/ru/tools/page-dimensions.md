# Размеры страниц

Диагностический инструмент, который читает каждую страницу PDF и показывает её точные размеры, ориентацию, название стандартного формата, пропорции, площадь и поворот. Полезен, чтобы найти страницы разного размера перед печатью или чтобы описать свойства полученного PDF.

## Как это работает

1. Загрузите PDF-файл. Анализ запускается автоматически, нажимать кнопку не нужно.
2. В сводной панели показаны общее число страниц, число уникальных размеров и наличие страниц разного размера.
3. Просмотрите полную таблицу с данными по каждой странице.
4. Переключайте единицы измерения: пункты, дюймы, миллиметры или пиксели.
5. Нажмите **Экспорт в CSV**, чтобы сохранить данные.

## Поля отчёта

| Столбец            | Описание                                            |
| ------------------ | --------------------------------------------------- |
| Страница №         | Порядковый номер страницы                           |
| Размеры            | Ширина x высота в выбранных единицах                |
| Стандартный формат | Подходящее название (A4, Letter и т. д.) или "Свой" |
| Ориентация         | Книжная или альбомная                               |
| Соотношение сторон | Отношение ширины к высоте в десятичном виде         |
| Площадь            | Площадь страницы в квадратных выбранных единицах    |
| Rotation           | Поворот страницы в градусах                         |

## Возможности

- Автоматическое определение стандартных форматов бумаги (A3, A4, A5, Letter, Legal, Tabloid и других)
- Предупреждение о страницах разного размера с разбивкой по размерам и числу страниц каждого размера
- Перевод между пунктами, дюймами, миллиметрами и пикселями (при 96 PPI)
- Экспорт в CSV для электронных таблиц и систем документации

## Сценарии использования

- Убедиться, что все страницы имеют формат A4, перед отправкой документа в типографию
- Выяснить, почему объединённый PDF печатается с неожиданными полями на некоторых страницах
- Описать структуру страниц большого PDF-архива для записей метаданных
- Найти повёрнутые страницы, которые нужно исправить

## Советы

- Если в сводке указано "Разные размеры", перед печатью приведите страницы к единому размеру с помощью инструмента "Редактор размера страниц".
- Поле поворота помогает найти страницы, которые отображаются правильно, но имеют ненулевой атрибут поворота. В некоторых процессах это вызывает проблемы.

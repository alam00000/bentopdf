# Удаление метаданных

Каждый PDF содержит метаданные, которые могут раскрыть, кто его создал, какая программа использовалась, когда он последний раз изменялся и многое другое. Этот инструмент удаляет всё: словарь информации, потоки метаданных XMP, идентификаторы документа и данные конкретных приложений, оставляя чистый документ без следов происхождения.

## Как это работает

1. Загрузите PDF-файл.
2. Нажмите **Удаление метаданных**.
3. Скачайте очищенный файл.

Настраивать ничего не нужно. Инструмент сделан тщательным намеренно: он очищает всё.

## Что удаляется

- **Поля словаря информации**: название, автор, тема, ключевые слова, создатель, производитель, дата создания, дата изменения
- **Поток метаданных XMP**: блок метаданных на основе XML, хранящийся в каталоге документа
- **Идентификаторы документа**: уникальные идентификаторы в трейлере PDF, по которым документ можно отслеживать между системами
- **PieceInfo**: метаданные конкретных приложений, добавляемые такими программами, как Illustrator или InDesign

## Что остаётся

- Всё видимое содержимое страниц (текст, изображения, графика)
- Поля форм и аннотации
- Закладки и ссылки
- Сама структура документа

## Сценарии использования

- Удаление вашего имени и организации из документа перед анонимной публикацией
- Удаление меток времени создания, которые показывают, когда документ готовился
- Очистка строк производителя, по которым определяется ваш набор PDF-программ
- Подготовка документов для регуляторных подач, требующих PDF без метаданных
- Удаление следов истории правок перед отправкой документа вовне

## Советы

- Сначала воспользуйтесь инструментом «Просмотр метаданных», чтобы увидеть, какие именно метаданные содержит ваш PDF.
- Если нужно удалить метаданные _и_ JavaScript, аннотации и встроенные файлы, используйте «Санирование документа» для более тщательной очистки.
- Удаление метаданных необратимо. Сохраните оригинал, если эти данные могут понадобиться позже.

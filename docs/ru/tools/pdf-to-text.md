# PDF в текст

Извлекает весь текст из PDF-файлов и сохраняет его в обычные файлы `.txt`. Поддерживает пакетную обработку: загрузите несколько PDF и получите текст каждого за одну операцию. Работает на PyMuPDF.

## Как это работает

1. Загрузите один или несколько PDF, нажав на область загрузки или перетащив файлы. Управляйте списком кнопками «Добавить еще файлы» и «Очистить файлы».
2. Нажмите **Извлечь текст**, чтобы начать обработку.
3. Один файл скачивается как `filename.txt`. Несколько файлов дают архив `pdf-to-text.zip`.

## Параметры

Настраиваемых параметров нет. Весь текст извлекается со всех страниц в порядке чтения.

## Формат результата

- **Один файл**: `filename.txt`
- **Несколько файлов**: `pdf-to-text.zip` с одним `.txt` на каждый исходный PDF.

## Сценарии использования

- Извлечение основного текста из PDF-отчётов для индексации полнотекстового поиска.
- Преобразование PDF-книг и статей в простой текст для чтения на устройствах с электронными чернилами.
- Получение текста из договоров и юридических документов для анализа по ключевым словам.
- Удаление форматирования из PDF, чтобы получить чистый текст для скриптов обработки данных.
- Подготовка текстового корпуса из PDF-архивов для обработки естественного языка.

## Советы

- Отсканированные PDF (только изображения) дадут пустые текстовые файлы, потому что текстового слоя для извлечения нет. Сначала пропустите отсканированные документы через OCR.
- Результат сохраняет порядок чтения, определённый PyMuPDF: как правило, слева направо и сверху вниз. При многоколоночной вёрстке строки могут перемешиваться.
- Для структурированного результата с заголовками и форматированием попробуйте [PDF в Markdown](./pdf-to-markdown). Для структурированного JSON, готового для ИИ, используйте [Подготовка PDF для ИИ](./prepare-pdf-for-ai).

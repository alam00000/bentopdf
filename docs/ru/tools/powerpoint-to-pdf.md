# PowerPoint в PDF

Преобразуйте файлы презентаций в PDF. Каждый слайд становится страницей итогового документа, а текст, изображения и фигуры отображаются через LibreOffice, работающий прямо в браузере. Поддерживаются современный и устаревший форматы PowerPoint, а также формат OpenDocument Presentation.

## Поддерживаемые форматы

| Формат                    | Расширения |
| :------------------------ | :--------- |
| PowerPoint (современный)  | `.pptx`    |
| PowerPoint (устаревший)   | `.ppt`     |
| OpenDocument Presentation | `.odp`     |

## Как это работает

1. Нажмите на область загрузки или перетащите в неё файлы презентаций.
2. Просмотрите список файлов. Добавьте ещё или удалите лишние.
3. Нажмите **Преобразовать в PDF**. При первом использовании загружается движок LibreOffice, затем каждый файл преобразуется.
4. Один файл скачивается сразу как PDF. Несколько файлов упаковываются в `powerpoint-converted.zip`.

## Параметры

У этого инструмента нет дополнительных настроек. Слайды отображаются в исходных размерах.

## Результат

| Количество файлов | Результат                                                                |
| :---------------- | :----------------------------------------------------------------------- |
| 1 файл            | Один PDF (исходное имя файла с расширением `.pdf`)                       |
| 2 и более         | ZIP-архив (`powerpoint-converted.zip`) с отдельным PDF для каждого файла |

## Сценарии использования

- Преобразование презентации в PDF перед отправкой аудитории, у которой может не быть PowerPoint
- Создание печатной версии слайдов для конференции или семинара
- Архивирование презентаций в формате, который одинаково выглядит на любом устройстве
- Пакетное преобразование коллекции презентаций ODP из LibreOffice Impress в PDF
- Подготовка PDF-версии презентации для отправки по электронной почте

## Советы

- Анимация и переходы между слайдами в PDF не сохраняются. Каждый слайд фиксируется как статичная страница.
- Встроенные видео в результате не отображаются. При необходимости замените их снимком экрана или изображением-заглушкой.
- Заметки докладчика не попадают в PDF при экспорте по умолчанию. Если они нужны, сначала экспортируйте их из режима печати заметок в PowerPoint.
- Движок LibreOffice кэшируется после первой загрузки, поэтому вторая презентация в той же сессии преобразуется намного быстрее.

# Дублирование и организация

Переставляйте, дублируйте и удаляйте страницы PDF в наглядном интерфейсе с перетаскиванием. Каждая страница отображается миниатюрой, которую можно переместить, клонировать или удалить перед сохранением результата в новый файл.

## Как это работает

1. Загрузите один PDF-файл.
2. Инструмент отобразит сетку миниатюр всех страниц.
3. Перетаскивайте миниатюры, чтобы изменить порядок, нажимайте зелёную кнопку дублирования, чтобы клонировать страницу, или красную кнопку удаления, чтобы убрать её.
4. Либо введите свой порядок страниц в текстовое поле (например, `3, 1, 2, 4`) и нажмите **Применить порядок**, чтобы переставить все страницы сразу.
5. Нажмите кнопку обработки, чтобы собрать и скачать PDF с новым порядком.

## Возможности

- Перестановка страниц перетаскиванием с плавной анимацией
- Кнопки дублирования и удаления для каждой страницы
- Ввод порядка страниц для точной перестановки
- Номера страниц автоматически обновляются после каждого изменения
- Защита от удаления последней оставшейся страницы

## Сценарии использования

- Перенести неправильно поставленную страницу отчёта на нужное место
- Продублировать страницу формы, чтобы в одном файле было несколько пустых копий
- Убрать черновые и служебные страницы перед рассылкой документа
- Развернуть или перемешать порядок страниц при подготовке к печати
- Собрать свою последовательность страниц без повторного объединения файлов

## Советы

- В поле порядка страниц указываются исходные номера страниц через запятую. Каждая страница должна встретиться ровно один раз, без пропусков и повторов.
- После дублирования страницы обе копии ссылаются на один и тот же исходный индекс страницы. Перемещать каждую копию можно независимо.
- Для массовых операций с несколькими файлами или более сложных сценариев воспользуйтесь инструментом [PDF мультиинструмент](./pdf-multi-tool).

# PDF в ZIP

Соберите несколько PDF-файлов в один ZIP-архив. Это простой инструмент для упаковки: сами PDF не конвертируются, не сжимаются и не изменяются.

## Как это работает

1. Загрузите несколько PDF-файлов в область загрузки.
2. Проверьте список файлов. Удалите те, которые не нужны.
3. Нажмите кнопку обработки.
4. Сразу скачается ZIP-архив со всеми загруженными PDF.

## Возможности

- Принимает любое количество PDF-файлов
- Удаление отдельных файлов до создания архива
- Сохраняет исходные имена файлов внутри ZIP
- Содержимое PDF не изменяется: файлы упаковываются как есть
- Показывает имя и размер каждого загруженного PDF

## Сценарии использования

- Упаковка набора счетов или чеков для отправки по почте
- Упаковка результатов проекта (нескольких PDF-отчётов) для передачи
- Создание одной ссылки для скачивания набора форм или шаблонов
- Архивирование пакета документов в один сжатый файл

## Советы

- В ZIP используются исходные имена PDF-файлов. Если у файлов одинаковые имена, переименуйте их перед загрузкой, чтобы избежать конфликтов.
- Инструмент не сжимает сами PDF. Чтобы уменьшить размер, сначала пропустите их через "Сжатие PDF", затем упакуйте этим инструментом.

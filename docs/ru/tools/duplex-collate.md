# Сортировка двустороннего сканирования

Этот инструмент предназначен для сценариев сканирования через автоподатчик (ADF), когда один PDF содержит два блока страниц:

- сначала все лицевые стороны
- затем все оборотные стороны

Вместо ручного разделения и пересборки инструмент чередует два блока в естественном порядке чтения: лицевая 1, оборотная 1, лицевая 2, оборотная 2 и так далее.

## Как это работает

1. Загрузите один PDF, созданный сканированием стопки с двух сторон.
2. Укажите точку разделения, где заканчивается блок лицевых сторон.
3. Выберите обработку блока оборотных сторон:
   - **Обратить блок оборотов** (обычно нужно, когда стопку переворачивают перед сканированием оборотов)
   - **Оставить блок оборотов без изменений**
4. Нажмите **Собрать PDF**, чтобы скачать результат с измененным порядком.

## Параметры

- **Определить разделение автоматически (половина)**: устанавливает точку разделения на `ceil(totalPages / 2)`.
- **Предупреждение о нечетном числе страниц**: предупреждает, если общее число страниц нечетное (часто это признак несоответствия при сканировании).
- **Подтверждение неравных блоков**: запрашивает подтверждение, если размеры блоков лицевых и оборотных сторон различаются.
- **Экспорт группами**: делит результат на отдельные PDF по числу страниц исходного документа и скачивает их в виде ZIP.

## Поведение результата

- **По умолчанию**: один выходной PDF (один входной PDF дает один выходной PDF).
- **Групповой режим**: результат делится на части по заданному числу страниц на документ; если получилось несколько частей, они скачиваются одним ZIP, иначе скачивается один PDF.

Если размеры блоков различаются, сначала сопоставляются парные страницы, а оставшиеся непарные страницы добавляются в конец.

## Типичные сценарии использования

- Восстановление порядка после сканирования стопки двусторонних форм за два прохода.
- Пересборка комплектов лицевых и оборотных страниц с офисных сканеров, которые выдают сначала все лицевые, затем все оборотные стороны.
- Постобработка архивных сканов перед разделением на файлы по документам.

## Советы

- В большинстве двусторонних пакетов общее число страниц должно быть четным.
- Если оборотные стороны оказались перевернутыми, переключитесь между **Обратить блок оборотов** и **Оставить блок оборотов без изменений**.
- Для оригиналов из 2 страниц (лицевая и оборотная) используйте групповой экспорт с `2` страницами на документ.

# Редактирование метаданных

Редактируйте метаданные, встроенные в PDF-файл. Инструмент заполняет форму существующими метаданными документа, позволяет изменить любое поле и сохраняет изменения в новый PDF.

## Как это работает

1. Загрузите PDF-файл. Инструмент считает текущие метаданные и заполнит ими форму.
2. Измените любое из стандартных полей: Название, Автор, Тема, Ключевые слова, Создатель, Производитель.
3. Настройте поля «Дата создания» и «Дата изменения» с помощью выбора даты и времени.
4. Добавьте пользовательские поля метаданных, нажав кнопку добавления и введя пару «ключ-значение».
5. Нажмите кнопку обработки, чтобы сохранить измененный PDF.

## Возможности

- Автоматическое заполнение всех существующих метаданных из загруженного PDF
- Стандартные поля: Название, Автор, Тема, Ключевые слова, Создатель, Производитель
- Выбор даты и времени для полей «Дата создания» и «Дата изменения»
- Пользовательские поля «ключ-значение» для произвольных свойств
- Изменения сохраняются прямо в словарь информации о документе PDF

## Редактируемые поля

| Поле                      | Описание                                                      |
| ------------------------- | ------------------------------------------------------------- |
| **Название**              | Заголовок документа, который показывают программы для PDF     |
| **Автор**                 | Человек или организация, создавшие документ                   |
| **Тема**                  | Краткое описание темы документа                               |
| **Ключевые слова**        | Термины через запятую для поиска и классификации              |
| **Создатель**             | Приложение, в котором было создано исходное содержимое        |
| **Производитель**         | Приложение, создавшее PDF                                     |
| **Дата создания**         | Когда документ был создан изначально                          |
| **Дата изменения**        | Когда документ последний раз изменялся                        |
| **Пользовательские поля** | Любые дополнительные пары «ключ-значение», которые вы задаете |

## Сценарии использования

- Задание правильного заголовка и автора перед публикацией документа
- Добавление ключевых слов для лучшего поиска в системах управления документами
- Обновление даты изменения под текущую редакцию
- Добавление пользовательских полей метаданных, например Department, Project ID или Classification
- Очистка метаданных, оставленных исходной программой

## Советы

- Пользовательские поля записываются прямо в словарь информации PDF. Некоторые программы для PDF могут не показывать пользовательские поля, но в файле они сохраняются.
- Оставьте поле пустым, чтобы убрать его из метаданных. Кнопка обработки сохраняет все, что находится в форме.
- Чтобы просмотреть метаданные без редактирования, используйте [Просмотр метаданных](./view-metadata). Чтобы полностью удалить все метаданные, используйте «Удаление метаданных».

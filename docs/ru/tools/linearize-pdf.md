# Линеаризация документа

Линеаризация перестраивает PDF так, чтобы первую страницу можно было показать до полной загрузки файла. В Adobe это называется «Быстрый просмотр в Интернете». Если вы размещаете PDF на сайте или отдаёте их через портал документов, линеаризация заметно ускоряет их открытие.

## Как это работает

1. Загрузите один или несколько файлов PDF.
2. Нажмите **Линеаризовать PDF**.
3. Скачайте результат в виде ZIP-архива со всеми линеаризованными файлами.

Настраивать ничего не нужно. Инструмент использует флаг `--linearize` из QPDF, который перестраивает внутреннюю структуру PDF, не меняя его внешний вид.

## Что делает линеаризация

- Переупорядочивает объекты PDF так, чтобы данные первой страницы находились в начале файла
- Добавляет словарь линеаризации и таблицы подсказок, чтобы программы просмотра знали, где найти каждую страницу
- Включает запросы по диапазонам байтов: браузер может загрузить только первую страницу, не скачивая весь файл
- Приводит в порядок таблицу перекрёстных ссылок для эффективного произвольного доступа

## Возможности

- Пакетная обработка нескольких PDF за одну операцию
- Результат сохраняет все содержимое, шрифты, изображения и интерактивные элементы
- Использует QPDF (WebAssembly) для надёжной линеаризации по стандартам
- Результаты упаковываются в ZIP для удобной загрузки

## Сценарии использования

- Размещение отчётов в PDF на сайте, где пользователи ожидают мгновенного отображения страницы
- Встраивание PDF в веб-приложения со встроенными просмотрщиками
- Публикация каталогов и руководств в PDF, которые открывают при медленном мобильном соединении
- Подготовка документов для сетей доставки контента (CDN), поддерживающих выдачу по диапазонам байтов

## Советы

- Линеаризуйте документ после завершения всех остальных правок. Любое последующее изменение (объединение, добавление страниц) нарушит линеаризацию.
- Сочетайте с инструментом «Сжатие PDF», чтобы получить самые компактные и быстро загружаемые PDF.
- Линеаризация немного увеличивает размер файла (обычно менее чем на 1%).

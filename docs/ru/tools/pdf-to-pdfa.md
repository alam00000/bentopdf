# PDF в PDF/A

PDF/A - стандартизированное ISO подмножество PDF, созданное для долговременного хранения цифровых документов. Инструмент преобразует обычные PDF в документы, соответствующие PDF/A, с помощью Ghostscript, который работает прямо в вашем браузере.

## Как это работает

1. Загрузите один или несколько PDF-файлов.
2. Выберите **Версия PDF/A** в выпадающем списке.
3. При необходимости включите **Предварительно свести PDF** для сложных файлов, которые не конвертируются обычным способом.
4. Нажмите **Конвертировать в PDF/A**. Несколько файлов дают ZIP-архив.

## Версии PDF/A

| Версия       | Ограничения                                   | Лучше всего подходит для                                  |
| ------------ | --------------------------------------------- | --------------------------------------------------------- |
| **PDF/A-1b** | Самая строгая. Без прозрачности и слоёв.      | Максимальная совместимость со старыми архивными системами |
| **PDF/A-2b** | Допускает прозрачность и JPEG2000.            | Универсальное архивирование (рекомендуется)               |
| **PDF/A-3b** | Допускает встроенные вложения любого формата. | Архивирование документов с исходными файлами данных       |

PDF/A-2b выбран по умолчанию и подходит для подавляющего большинства задач архивирования.

## Параметр Pre-flatten

Некоторые PDF содержат особенности, мешающие корректному преобразованию в PDF/A: необычные кодировки шрифтов, сложные стеки прозрачности или повреждённую внутреннюю структуру. Параметр **Предварительно свести PDF** растеризует PDF с разрешением 300 DPI перед конвертацией. Это гарантирует соответствие стандарту, но делает текст невыделяемым. Используйте его как запасной вариант, если обычная конвертация завершается ошибками.

Для Pre-flatten нужен движок PyMuPDF WASM.

## Сценарии использования

- Выполнение требований государственных и юридических архивов (во многих юрисдикциях PDF/A обязателен для судебных документов)
- Подача документов в институциональные репозитории и электронные библиотеки
- Сохранение деловых документов, когда исходной программы через десять лет может не существовать
- Подготовка счетов для стандартов электронного инвойсинга, требующих PDF/A-3b с XML-вложениями

## Советы

- Сначала попробуйте конвертацию без Pre-flatten. Включайте его, только если получили ошибку.
- PDF/A встраивает все шрифты, поэтому итоговые файлы часто больше исходных.
- Если в вашем процессе нужно строгое соответствие, проверьте результат в специальном валидаторе PDF/A.

# Изображения в PDF

Универсальный конвертер изображений в PDF. Загружайте изображения практически в любом формате и объединяйте их в один документ PDF. Каждое изображение получает отдельную страницу, размер которой соответствует оригиналу.

## Поддерживаемые форматы

| Формат          | Расширения                             |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

Это самая широкая поддержка форматов среди всех конвертеров изображений BentoPDF. Если вам нужен только один формат, используйте соответствующий специализированный инструмент.

## Как это работает

1. Нажмите на область загрузки или перетащите в неё файлы изображений. Можно выбрать сразу несколько файлов.
2. Просмотрите список файлов. Удалите ненужные значком корзины или нажмите **Добавить ещё файлы**, чтобы добавить другие изображения.
3. Выберите уровень **Качества PDF** в выпадающем списке.
4. Нажмите **Преобразовать в PDF**. Инструмент обрабатывает изображения движком PyMuPDF и скачивает результат как `images_to_pdf.pdf`.

## Параметры

**Качество PDF** определяет сжатие, применяемое к изображениям при встраивании в PDF:

- **Высокое качество**: минимальное сжатие, больший размер файла. Лучше всего для печати и архивирования.
- **Среднее качество** (по умолчанию): сбалансированное сжатие. Подходит для большинства задач.
- **Низкое качество**: сильное сжатие, наименьший размер файла. Подходит для отправки по почте и быстрого обмена.

Файлы HEIC и WebP автоматически преобразуются в PNG перед встраиванием. Это происходит незаметно и не требует дополнительных действий.

## Сценарии использования

- Объединение отсканированных чеков или документов, снятых на камеру телефона, в один PDF
- Создание портфолио или лукбука из изображений в разных форматах
- Преобразование фотографий с iPhone (HEIC) в PDF, которым удобно делиться, без установки программ на компьютер
- Сборка макетов из экспорта PSD и снимков экрана в один документ для клиента
- Архивирование папки с устаревшими форматами изображений (PNM, JXR, JP2) в один PDF

## Советы

- Порядок изображений в PDF совпадает с их порядком в списке файлов. Загружайте их в нужной последовательности.
- Для минимального размера файла выберите низкое качество. Для сканов с большим количеством текста разница на глаз часто незаметна.
- Если у вас только один формат изображений, специализированные конвертеры (JPG в PDF, PNG в PDF и другие) дают тот же результат с более простым интерфейсом.

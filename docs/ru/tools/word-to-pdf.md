# Word в PDF

Конвертируйте документы Microsoft Word и совместимые форматы в PDF. Инструмент использует движок LibreOffice, работающий в браузере, который обрабатывает файлы DOC, DOCX, ODT и RTF и сохраняет в результате форматирование, таблицы, изображения, колонтитулы и стили.

## Поддерживаемые форматы

| Формат             | Расширения |
| :----------------- | :--------- |
| Word (современный) | `.docx`    |
| Word (устаревший)  | `.doc`     |
| OpenDocument Text  | `.odt`     |
| Rich Text Format   | `.rtf`     |

## Как это работает

1. Нажмите на область загрузки или перетащите документы Word. Можно выбрать сразу несколько файлов.
2. Проверьте список файлов и при необходимости измените его.
3. Нажмите **Преобразовать в PDF**. При первом использовании загружается движок LibreOffice (индикатор прогресса показывает состояние инициализации), после чего каждый файл конвертируется.
4. Один файл скачивается сразу как PDF. Несколько файлов упаковываются в `word-converted.zip`.

## Параметры

Дополнительных настроек у этого инструмента нет. Движок LibreOffice создаёт результат с профилем экспорта в PDF по умолчанию.

## Результат

| Количество файлов | Результат                                                       |
| :---------------- | :-------------------------------------------------------------- |
| 1 файл            | Скачивание одного PDF (исходное имя файла с расширением `.pdf`) |
| 2 и больше        | ZIP-архив (`word-converted.zip`) с одним PDF на каждый файл     |

## Сценарии использования

- Конвертировать резюме или сопроводительное письмо из DOCX в PDF перед отправкой отклика на вакансию
- Пакетно конвертировать набор договоров или предложений в PDF для передачи клиенту
- Превратить старые файлы `.doc` в современные PDF для долгосрочного архива
- Конвертировать документы совместной работы из Google Docs (экспортированные как DOCX) в PDF
- Получать PDF, готовые к печати, из шаблонов Word, которые используются при автоматической генерации документов

## Советы

- Движок LibreOffice загружается один раз за сеанс и кэшируется. При первой конвертации придётся подождать несколько секунд, последующие выполняются намного быстрее.
- Сложное форматирование (макросы, элементы ActiveX, продвинутые SmartArt) может конвертироваться неидеально. Стандартные элементы документа (текст, таблицы, изображения, колонтитулы, сноски) конвертируются надёжно.
- Поскольку инструмент принимает также ODT и RTF, его можно использовать как универсальный конвертер для всех текстовых форматов.

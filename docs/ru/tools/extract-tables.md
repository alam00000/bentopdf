# Извлечение таблиц из PDF

Находит все таблицы в PDF и позволяет экспортировать их в выбранном формате: CSV, JSON или Markdown. Каждая таблица извлекается отдельно с метаданными о странице и положении. Работает на движке обнаружения таблиц PyMuPDF.

## Как это работает

1. Загрузите PDF, щелкнув по области загрузки или перетащив на нее файл.
2. Выберите нужный **формат экспорта**: CSV, JSON или Markdown.
3. Нажмите **Извлечь таблицы**, чтобы начать обработку.
4. Если найдена одна таблица, она скачивается одним файлом. Если таблиц несколько, создается ZIP-архив с отдельным файлом для каждой таблицы.

## Параметры

- **Формат экспорта**: выберите один из вариантов:
  - **CSV**: значения через запятую с корректным заключением в кавычки полей, содержащих запятые, кавычки или переводы строк. Подходит для электронных таблиц и баз данных.
  - **JSON**: структура «массив массивов» с форматированием и отступом в 2 пробела. Подходит для программной обработки.
  - **Markdown**: формат таблицы с разделителями-вертикальными чертами, создаваемый PyMuPDF. Подходит для документации и файлов README.

## Формат результата

- **Одна таблица**: `filename_table.csv` (или `.json` / `.md`)
- **Несколько таблиц**: `filename_tables.zip` с файлами `table_1_page3.csv`, `table_2_page5.csv` и так далее.

## Сценарии использования

- Извлечение отдельных таблиц из объемных PDF-отчетов без выгрузки данных всего документа.
- Получение таблиц в формате Markdown для вставки прямо в задачи GitHub, вики и документацию.
- Получение структурированных данных JSON из таблиц PDF для интеграций с API и скриптов.
- Сравнение таблиц из разных версий PDF: экспортируйте обе версии в CSV и сравните их.

## Советы

- Этот инструмент дает контроль над каждой таблицей. Если нужно выгрузить все таблицы в один CSV, используйте [PDF в CSV](./pdf-to-csv). Для полной книги Excel используйте [PDF в Excel](./pdf-to-excel).
- Таблицы, занимающие несколько страниц, могут быть определены как отдельные таблицы на каждой странице. Возможно, их придется объединить вручную.
- Если таблицы не обнаружены, возможно, PDF является отсканированным изображением. Сначала выполните распознавание текста, чтобы добавить текстовый слой.

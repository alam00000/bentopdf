# Markdown в PDF

Полнофункциональный редактор Markdown с живым предпросмотром и экспортом в PDF одним нажатием. Пишите с нуля, загрузите готовый файл `.md` или вставьте содержимое из буфера обмена. Редактор отображает Markdown в реальном времени и экспортирует оформленный PDF с помощью встроенного механизма печати браузера.

## Поддерживаемые форматы

| Вход        | Описание                        |
| :---------- | :------------------------------ |
| Файлы `.md` | Загрузка кнопкой «Загрузить»    |
| Прямой ввод | Введите или вставьте в редактор |

## Как это работает

1. Откройте инструмент Markdown в PDF. Редактор загрузится в режиме разделённого экрана: исходный Markdown слева, готовый предпросмотр справа.
2. Напишите Markdown, вставьте его или нажмите **Загрузить**, чтобы открыть файл `.md`.
3. Переключайтесь между светлой и тёмной темой ползунком темы на панели инструментов.
4. Нажмите **Экспорт в PDF** (или `Ctrl/Cmd + S`), чтобы создать PDF через диалог печати браузера.

## Возможности

Редактор поддерживает широкий набор возможностей Markdown помимо базовых:

- **Стандартный Markdown**: заголовки, полужирный, курсив, ссылки, изображения, списки, цитаты, горизонтальные линии
- **Блоки кода** с подсветкой синтаксиса для более чем 15 языков (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash и другие)
- **Диаграммы Mermaid**: блок-схемы, диаграммы последовательности, ER-диаграммы и другие типы диаграмм Mermaid отображаются прямо в предпросмотре
- **Таблицы** со стандартным синтаксисом таблиц Markdown
- **Списки задач** с флажками
- **Сноски**, **подстрочные** и **надстрочные** символы
- **Списки определений**, **аббревиатуры**
- Поддержка **эмодзи** (`:smile:` отображается как эмодзи)
- **Выделение** (`==marked text==`) и **вставки** (`++inserted text++`)
- **Автоматические ссылки**: обычные URL превращаются в кликабельные ссылки
- Создание **оглавления**
- **Якорные ссылки** в заголовках

## Сценарии использования

- Написание документации проекта и экспорт аккуратного PDF для заинтересованных сторон
- Создание технических отчётов с примерами кода и архитектурными диаграммами Mermaid
- Преобразование README с GitHub в PDF для автономного чтения или печати
- Подготовка предложения или спецификации со списками задач и таблицами
- Создание оформленного раздаточного материала из конспектов лекций, написанных в Markdown

## Советы

- Для создания PDF используется функция печати в PDF в браузере. В Chrome перед сохранением можно настроить поля и масштаб в диалоге печати.
- Диаграммы Mermaid отображаются в предпросмотре, но при первом использовании им может потребоваться немного времени на инициализацию.
- Используйте сочетание `Ctrl/Cmd + S`, чтобы экспортировать, не тянясь к кнопке.

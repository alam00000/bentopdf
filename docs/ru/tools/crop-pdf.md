# Обрезка PDF

Обрезайте поля страниц PDF в визуальном интерфейсе. Нарисуйте прямоугольник обрезки прямо на странице, посмотрите результат и примените обрезку. Для разных страниц можно задать разные области обрезки или применить одну и ту же обрезку ко всему документу.

## Как это работает

1. Загрузите PDF-файл.
2. Откроется редактор обрезки с первой страницей и перетаскиваемой областью обрезки.
3. Меняйте прямоугольник обрезки, перетаскивая его края или углы.
4. Кнопками навигации переходите между страницами и задавайте область обрезки для каждой из них.
5. Нажмите **Обрезать и скачать**, чтобы применить обрезку и скачать результат.

## Возможности

- Визуальный редактор обрезки на базе Cropper.js с маркерами для точной настройки
- Постраничная навигация для задания отдельных областей обрезки
- Настройки обрезки хранятся для каждой страницы, поэтому для разных страниц можно задать разную обрезку
- Предпросмотр выбранной области обрезки в реальном времени
- Поддержка PDF с любым размером и ориентацией страниц

## Сценарии использования

- Удаление широких полей из отсканированных документов, чтобы сосредоточиться на содержимом
- Удаление печатных меток обреза и приводочных меток из PDF для допечатной подготовки
- Обрезка слайдов лекций, чтобы убрать область заметок докладчика
- Удаление верхних и нижних колонтитулов со всех страниц перед отправкой отрывка документа
- Изменение размера страниц под конкретный экран или макет печати

## Советы

- Область обрезки можно свободно менять по размеру и перемещать. Тяните за углы для пропорционального изменения или за края для изменения по одной оси.
- Если для всех страниц нужна одинаковая обрезка, задайте ее на первой странице: инструмент запоминает область обрезки при переходе между страницами.
- Если нужно привести страницы к единому размеру, а не обрезать визуально, лучше подойдет инструмент «Редактор размера страниц».

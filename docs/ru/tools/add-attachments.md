# Добавление вложений

Встраивайте один или несколько файлов прямо в PDF-документ. Вложения можно добавить на уровне документа (они видны в панели вложений любой программы для чтения PDF) или привязать к определенным страницам.

## Как это работает

1. Загрузите PDF, к которому нужно прикрепить файлы.
2. В зоне для вложений выберите файлы, которые хотите встроить (любого типа).
3. Выберите уровень вложения: **Документ** (по умолчанию) или **Страница**.
4. Если выбран уровень страницы, укажите диапазон страниц (например, `1-3` или `5`).
5. Нажмите кнопку обработки. Измененный PDF скачается со встроенными файлами.

## Возможности

- Вложения любых типов: изображения, таблицы, архивы, исполняемые файлы, что угодно
- Размещение вложений на уровне документа или страницы
- Несколько файлов можно прикрепить за одну операцию
- Отображаются имена и размеры всех выбранных вложений
- В результате сохраняется исходное содержимое PDF, к которому добавлены встроенные файлы

## Параметры

| Параметр              | Описание                                                        |
| --------------------- | --------------------------------------------------------------- |
| **Уровень документа** | Прикрепляет файлы к PDF целиком, они доступны в панели вложений |
| **Уровень страницы**  | Прикрепляет файлы к определенным страницам, заданным диапазоном |

## Сценарии использования

- Добавление исходных данных (файлов Excel, CSV) к PDF-отчету
- Прикрепление исходных изображений к PDF-портфолио фотографа
- Встраивание подтверждающих документов в договор или коммерческое предложение
- Добавление дополнительных материалов к отдельным страницам учебного пособия

## Советы

- Вложения на уровне документа поддерживаются в программах для чтения PDF лучше всего. Вложения на уровне страницы могут быть видны не во всех программах.
- Ограничения на размер вложений нет, но очень большие встроенные файлы пропорционально увеличат размер PDF.

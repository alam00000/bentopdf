# Извлечение страниц

Извлеките набор страниц из PDF и сохраните их как новый файл. Укажите нужные страницы с помощью синтаксиса диапазонов, и инструмент создаст чистый PDF, содержащий только эти страницы.

## Как это работает

1. Загрузите PDF-файл. Инструмент покажет имя файла, размер и общее число страниц.
2. Введите страницы для извлечения с помощью синтаксиса диапазонов (например, `1-5`, `3, 7, 10-12`).
3. При желании выберите скачивание каждого диапазона как отдельного PDF в ZIP-архиве.
4. Нажмите кнопку обработки. Извлеченные страницы скачиваются как новый PDF (или ZIP).

## Возможности

- Гибкий синтаксис диапазонов: отдельные страницы, диапазоны или комбинации через запятую
- После загрузки показывается общее число страниц для удобства
- Результат можно получить одним объединенным PDF или отдельными файлами в ZIP
- Содержимое и форматирование исходных страниц сохраняются

## Сценарии использования

- Извлечение краткого резюме (первых нескольких страниц) из объемного отчета
- Извлечение одной главы из PDF-учебника
- Сохранение отдельных страниц из пакета форм как самостоятельных документов
- Создание образца документа из выбранных страниц большого файла

## Советы

- Нумерация страниц начинается с 1. Для первой страницы используйте `1`, а не `0`.
- Чтобы удалить страницы, а не извлечь их, используйте [Удаление страниц](./delete-pages): это обратная операция.
- Если нужен визуальный выбор страниц по миниатюрам, используйте [Разделение PDF](./split-pdf) в режиме «Выбрать страницы визуально».

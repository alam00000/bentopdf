# HEIC в PDF

Преобразуйте изображения HEIC/HEIF в PDF. HEIC - формат фотографий по умолчанию на iPhone и iPad начиная с iOS 11. Этот инструмент превращает такие фотографии в PDF без установки программ на компьютер и без загрузки файлов на сервер.

## Поддерживаемые форматы

| Формат | Расширения |
| :----- | :--------- |
| HEIC   | `.heic`    |
| HEIF   | `.heif`    |

## Как это работает

1. Нажмите на область загрузки или перетащите в неё файлы HEIC/HEIF.
2. Просмотрите список файлов и удалите ненужные.
3. Нажмите **Преобразовать в PDF**. Результат скачивается как `from_heic.pdf`.

Каждый файл HEIC декодируется библиотекой heic2any и преобразуется в PNG с качеством 92%. Затем PNG встраивается в PDF с помощью pdf-lib, и каждое изображение занимает отдельную страницу в полном разрешении.

## Параметры

У этого инструмента нет дополнительных настроек. Изображения HEIC перед встраиванием преобразуются в PNG с высоким качеством (0,92).

## Сценарии использования

- Создание PDF из фотографий с iPhone для страховой заявки или отчёта
- Преобразование фотографий HEIC для объявления о недвижимости в один документ для печати
- Превращение снимков экрана iPad (формат HEIF) в PDF, которым удобно делиться
- Пакетное преобразование фотографий из отпуска для дневника путешествий

## Советы

- Декодирование HEIC целиком выполняется в браузере с помощью WebAssembly. Первое преобразование может занять некоторое время, пока загружается декодер.
- Если нужно объединить HEIC с другими форматами изображений (JPG, PNG и др.), используйте инструмент [Изображения в PDF](./image-to-pdf), который работает с HEIC наравне со всеми остальными форматами.
- Файлы HEIC с iPhone часто содержат данные EXIF, включая координаты GPS. В итоговый PDF эти метаданные не переносятся.

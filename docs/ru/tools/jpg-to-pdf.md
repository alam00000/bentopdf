# JPG в PDF

Превратите изображения JPG в аккуратный PDF. Загрузите один файл или сразу несколько JPG: каждое изображение станет полноразмерной страницей итогового документа.

## Поддерживаемые форматы

| Формат    | Расширения      |
| :-------- | :-------------- |
| JPEG      | `.jpg`, `.jpeg` |
| JPEG 2000 | `.jp2`, `.jpx`  |

## Как это работает

1. Нажмите на область загрузки или перетащите в неё файлы JPG. Можно выбрать несколько файлов.
2. Просмотрите загруженные файлы. Значок корзины удаляет отдельные файлы, а **Добавить ещё файлы** дополняет список.
3. Выберите уровень **Качества PDF**.
4. Нажмите **Преобразовать в PDF**. Инструмент сжимает изображения согласно выбранному качеству, преобразует их движком PyMuPDF и скачивает `from_jpgs.pdf`.

## Параметры

**Качество PDF** определяет сжатие, применяемое к каждому изображению перед встраиванием в PDF:

- **Высокое качество**: сохраняет максимум деталей. Подходит для фотографий и печати.
- **Среднее качество** (по умолчанию): хороший баланс между чёткостью и размером файла.
- **Низкое качество**: сильное сжатие для наименьшего размера результата.

## Сценарии использования

- Преобразование отсканированных документов, сохранённых как JPG, в один PDF для отправки
- Упаковка фотографий товаров в каталог для клиентов
- Превращение медицинских или спутниковых изображений JPEG 2000 в переносимый PDF
- Создание фотоальбома для печати из файлов с камеры

## Советы

- Файлы JPEG 2000 (`.jp2`, `.jpx`) поддерживаются полностью, а не только обычный JPEG. Это удобно для медицинских изображений и геоданных.
- Если ваши JPG сняты на камеру телефона, среднее качество обычно даёт файл на 40-60% меньше, чем высокое, без заметной на экране разницы.

# Постеризация документа

Разделите каждую страницу PDF на сетку из более мелких страниц. Этот инструмент нужен, чтобы напечатать одну страницу на нескольких листах бумаги, а затем склеить их в большой плакат или баннер.

## Как это работает

1. Загрузите PDF-файл.
2. Задайте количество **строк** и **столбцов**, определяющих сетку (например, 2 строки x 2 столбца делят каждую страницу на 4 части).
3. При желании укажите диапазон страниц, чтобы постеризировать только их.
4. На холсте предпросмотра поверх текущей страницы показана сетка, так что линии разреза видны заранее.
5. Переключайтесь между страницами, чтобы проверить сетку на разных страницах.
6. Нажмите кнопку обработки. Каждая ячейка сетки станет отдельной страницей итогового PDF.

## Возможности

- Настраиваемое число строк и столбцов для сетки любого размера
- Живой предпросмотр с сеткой, показывающей, где именно страницы будут разделены
- Фильтр по диапазону страниц, чтобы постеризировать только нужные
- Постраничная навигация в предпросмотре
- Кэширование снимков страниц для быстрой навигации
- Красные пунктирные линии сетки отчётливо обозначают границы разреза

## Параметры

| Параметр             | Описание                                              |
| -------------------- | ----------------------------------------------------- |
| **Строки**           | Число горизонтальных делений (по умолчанию: 1)        |
| **Столбцы**          | Число вертикальных делений (по умолчанию: 1)          |
| **Диапазон страниц** | Какие страницы постеризировать (пусто = все страницы) |

## Сценарии использования

- Печать PDF размером с плакат на стандартных листах A4 или Letter для сборки на стене
- Создание больших баннеров из одностраничного PDF-макета
- Разделение крупных технических чертежей на печатаемые фрагменты
- Печать в большом формате без доступа к широкоформатному принтеру

## Советы

- Сетка 2x2 превращает одну страницу в 4, а сетка 3x3 в 9. Выбирайте сетку исходя из того, насколько большим должен получиться собранный результат.
- Предпросмотр помогает убедиться, что важное содержимое не попадает на линию разреза. При необходимости измените число строк и столбцов.
- Для обратной операции (размещение нескольких страниц на одном листе) используйте [N-Up PDF](./n-up-pdf).

# Цвет фона

Задайте сплошной цвет фона за всем существующим содержимым PDF. Инструмент создает цветной прямоугольник на каждой странице и накладывает поверх него исходное содержимое, поэтому текст, изображения и графика остаются полностью видимыми на новом фоне.

## Как это работает

1. Загрузите PDF-файл.
2. Выберите цвет фона с помощью палитры. По умолчанию это светло-желтый (#FFFFCC).
3. Нажмите **Изменить цвет фона**, чтобы начать обработку.
4. Обновленный PDF скачается автоматически.

## Параметры

- **Цвет фона**: стандартная палитра для выбора любого сплошного цвета. По умолчанию светло-желтый.

## Возможности

- Единый цвет фона на каждой странице
- Все исходное содержимое (текст, изображения, векторная графика) сохраняется поверх цветного слоя
- Исходные размеры страниц сохраняются
- Работает с документами с любым числом страниц

## Сценарии использования

- Светлый кремовый или цвета слоновой кости фон, чтобы документ выглядел мягче, как бумага
- Цветовая маркировка наборов документов с разными фонами для разных категорий
- Создание визуально различимых версий одного документа для разных аудиторий
- Легкий оттенок фона для лучшей читаемости при показе документов на экране

## Советы

- Лучше всего подходят светлые приглушенные цвета. Очень темный фон затрудняет чтение текста, если только сам текст уже не светлый.
- Если нужно изменить и фон, и цвет текста, сначала примените цвет фона, а затем используйте [Изменение цвета текста](./text-color) для результата.
- Инструмент работает на структурном уровне PDF (без растрирования), поэтому текст в результате остается выделяемым и доступным для поиска.

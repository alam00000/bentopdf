# Изменение цвета текста

Замените цвет текста во всём PDF. Инструмент находит текстовые области на каждой странице и перекрашивает их в выбранный цвет, сохраняя макет документа и нетекстовое содержимое.

## Как это работает

1. Загрузите PDF-файл.
2. Выберите новый цвет текста в селекторе цвета. По умолчанию синий (#0000FF).
3. Нажмите **Изменение цвета текста** для обработки.
4. Перекрашенный PDF скачивается автоматически. Индикатор хода показывает, какая страница обрабатывается.

## Параметры

- **Новый цвет текста**: палитра для выбора цвета, которым будет заменён весь текст документа.

## Возможности

- Перекрашивает текст на каждой странице документа
- Постраничная обработка с индикацией хода
- Палитра с полной поддержкой шестнадцатеричных цветов
- Сохраняет макет страницы и нетекстовые элементы

## Сценарии использования

- Замена чёрного текста на тёмно-синий для более мягкого и современного вида документа
- Перекраска текста под фирменный стиль перед рассылкой документов
- Преобразование текста в определённый цвет для соответствия требованиям доступности
- Обеспечение видимости текста на вновь применённом цвете фона

## Советы

- Инструмент отрисовывает страницы в масштабе 2x для качества, а затем пересобирает PDF. Результат состоит из изображений, поэтому текст больше нельзя будет выделять и искать.
- Если нужно сохранить выделяемый текст, лучше отредактируйте PDF напрямую в [Редактор PDF](./edit-pdf).
- Время обработки растёт с числом страниц, так как каждая страница отрисовывается отдельно.

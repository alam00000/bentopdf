# Удаление аннотаций

Очистите PDF, удалив все аннотации: комментарии, выделения, стикеры, разметку текста, ссылки, штампы и любые другие объекты аннотаций в документе. Основное содержимое страниц (текст, изображения, графика) остаётся нетронутым.

## Как это работает

1. Загрузите PDF-файл.
2. Инструмент определяет число страниц документа и показывает сведения о файле.
3. Нажмите **Удаление аннотаций** для обработки.
4. Очищенный PDF скачивается автоматически, все аннотации удалены.

## Возможности

- Удаляет аннотации всех типов: комментарии, выделения, подчёркивания, зачёркивания, стикеры, штампы, ссылки и разметку форм
- Обрабатывает каждую страницу документа
- Сохраняет всё содержимое, не являющееся аннотациями (текст, изображения, векторную графику, поля форм)
- Показывает число страниц и размер файла перед обработкой

## Сценарии использования

- Очистка документа перед окончательной рассылкой после рецензирования, в котором несколько рецензентов оставили комментарии
- Удаление выделений и стикеров из общего учебного пособия
- Удаление ссылок из документа перед архивированием
- Подготовка «чистой» версии юридического документа, который активно размечали при согласовании
- Удаление комментариев рецензентов из рукописи перед отправкой в печать

## Советы

- Инструмент удаляет аннотации на уровне структуры PDF, поэтому текст остаётся выделяемым, а качество исходным, без растеризации.
- Если нужно удалить только отдельные аннотации, а не все, используйте [Редактор PDF](./edit-pdf) для выборочного удаления.
- Аннотации в сведённых PDF (где они объединены с содержимым страницы) удалить нельзя, так как они уже не являются отдельными объектами.

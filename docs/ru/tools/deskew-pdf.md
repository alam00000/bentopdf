# Выпрямление PDF

Отсканированные документы редко бывают идеально ровными. Даже небольшой наклон снижает точность OCR и портит вид печати. Этот инструмент использует алгоритмы обработки изображений OpenCV, чтобы определить угол перекоса каждой страницы и повернуть ее обратно в горизонтальное положение.

## Как это работает

1. Загрузите один или несколько отсканированных PDF.
2. Задайте **Порог наклона**: страницы, у которых обнаруженный перекос меньше этого значения, остаются без изменений.
3. Выберите **Качество обработки (DPI)**: более высокий DPI повышает точность определения, но занимает больше времени.
4. Нажмите **Выпрямление PDF**.
5. После обработки панель результатов покажет обнаруженный угол каждой страницы и то, была ли она исправлена.

## Параметры

| Параметр                     | Значения                   | По умолчанию |
| ---------------------------- | -------------------------- | ------------ |
| **Порог наклона**            | 0.1, 0.5, 1.0, 2.0 градуса | 0.5          |
| **Качество обработки (DPI)** | 100, 150, 200, 300         | 150          |

## Как работает определение перекоса

Инструмент отображает каждую страницу в изображение с выбранным DPI, затем с помощью OpenCV находит преобладающие углы линий в содержимом. Если обнаруженный перекос превышает порог, страница поворачивается на обратный угол. Страницы ниже порога передаются без изменений.

## Сценарии использования

- Очистка пакетно отсканированных договоров и юридических документов
- Подготовка отсканированных чеков и счетов к распознаванию текста
- Выпрямление страниц с планшетного сканера при неровной укладке бумаги
- Улучшение внешнего вида оцифрованных архивных материалов

## Советы

- Уменьшите порог до 0.1 градуса, если для OCR нужно попиксельное выравнивание.
- 150 DPI быстро и точно подходит для большинства документов. Используйте 300 DPI для очень мелкого текста или страниц с тонкими деталями.
- Выпрямление лучше всего работает с документами, где есть четкие горизонтальные строки текста. Страницы, состоящие в основном из изображений или диагональных элементов оформления, могут вызывать трудности.

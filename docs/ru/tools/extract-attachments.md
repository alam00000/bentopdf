# Извлечение вложений

Извлеките все встроенные вложения из одного или нескольких PDF-файлов. Все извлеченные файлы собираются в один ZIP-архив для скачивания.

## Как это работает

1. Загрузите один или несколько PDF-файлов со встроенными вложениями.
2. Нажмите **Извлечение вложений**.
3. Инструмент просматривает каждый PDF в поисках вложений уровня документа и уровня страницы.
4. Все найденные файлы упаковываются в ZIP-архив, который скачивается автоматически.
5. Сообщение о статусе подтверждает, сколько вложений найдено и каков их общий размер.

## Возможности

- Пакетное извлечение из нескольких PDF одновременно
- Извлекаются вложения как уровня документа, так и уровня страницы
- Результат: один ZIP-файл со всеми извлеченными файлами
- Показывает общее число вложений и суммарный размер файлов
- Понятные сообщения о статусе, если вложения не найдены

## Сценарии использования

- Восстановление файлов данных, встроенных в PDF-отчет
- Извлечение графических материалов из портфолио или технической спецификации
- Извлечение дополнительных материалов из обучающих PDF и документов по соответствию требованиям
- Аудит файлов, встроенных в набор PDF

## Советы

- Если инструмент сообщает об отсутствии вложений, в PDF могут быть встроенные изображения или данные форм, а они не являются вложенными файлами. Для встроенных изображений используйте [Извлечение изображений](./extract-images).
- При обработке нескольких PDF все вложения из всех файлов попадают в один ZIP. Имена файлов сохраняются такими, какими они были при встраивании.

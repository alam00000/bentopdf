# PDF в PNG

Преобразует каждую страницу PDF в изображение PNG. PNG использует сжатие без потерь, поэтому результат сохраняет все детали исходной страницы. Одностраничные PDF скачиваются как файл `.png`, многостраничные дают ZIP.

## Как это работает

1. Загрузите PDF, нажав на область загрузки или перетащив файл.
2. Ползунком **Масштаб изображения** задайте разрешение результата.
3. Нажмите **Конвертировать**, чтобы начать обработку.
4. Автоматически скачается один PNG или ZIP-архив.

## Параметры

- **Масштаб изображения**: от 1.0x до 3.0x (по умолчанию 2.0x). При 2.0x стандартная страница формата Letter рендерится примерно в 1 224 x 1 584 пикселей. Большие значения дают более крупные и чёткие изображения ценой размера файла и времени обработки.

## Формат результата

- **Одна страница**: `filename.png`
- **Несколько страниц**: `filename_pngs.zip` с файлами `page_1.png`, `page_2.png` и так далее.

## Сценарии использования

- Получение точных скриншотов страниц PDF для презентаций.
- Извлечение графиков и схем, которым нужны чёткие края без артефактов сжатия.
- Подготовка ресурсов для веб-дизайна из PDF-макетов.
- Создание изображений страниц без потерь для предварительной обработки перед OCR.

## Советы

- Файлы PNG заметно больше JPG. Если размер важнее идеального качества, используйте [PDF в JPG](./pdf-to-jpg) или [PDF в WebP](./pdf-to-webp).
- При масштабе 1.0x результат соответствует исходному разрешению PDF. Для экспорта в качестве, пригодном для печати, поставьте 3.0x.

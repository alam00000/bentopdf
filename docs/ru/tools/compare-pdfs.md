# Сравнение документов

Загрузите два PDF и узнайте, что именно изменилось. Инструмент интеллектуально сопоставляет страницы, находит различия в тексте, изображениях, аннотациях, колонтитулах и оформлении и показывает их рядом или в режиме наложения.

## Как это работает

1. Загрузите два PDF-файла: оригинал (слева) и исправленную версию (справа).
2. Инструмент сопоставляет страницы документов по сигнатурам содержимого.
3. Выберите режим просмотра: **Рядом** или **Наложение**.
4. Переключайтесь между парами страниц с помощью элементов постраничной навигации.
5. Различия выделяются и классифицируются. Панель фильтров помогает сосредоточиться на нужных типах изменений.
6. При желании экспортируйте сравнение в виде PDF-отчета.

## Возможности

- Автоматическое сопоставление страниц по схожести содержимого
- Режимы сравнения рядом и с наложением
- Классификация изменений: текст, изображение, колонтитулы, аннотации, оформление, фон
- Переключатели фильтров по категориям для показа или скрытия отдельных типов изменений
- Поиск по изменениям текста с фильтрацией по запросу
- Поддержка OCR для сравнения отсканированных документов
- Масштабирование для детального просмотра
- Синхронная прокрутка панелей в режиме рядом
- Экспорт результатов сравнения в PDF

## Параметры

| Параметр              | Описание                                                                                        |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| **Режим просмотра**   | Рядом или наложение                                                                             |
| **OCR**               | Включает и отключает OCR для сравнения отсканированных документов                               |
| **Язык OCR**          | Язык для извлечения текста методом OCR                                                          |
| **Фильтры категорий** | Переключает видимость изменений текста, изображений, колонтитулов, аннотаций, оформления и фона |
| **Область изменений** | В режиме наложения: все изменения или только изменения содержимого                              |
| **Масштаб**           | Настройка масштаба для детального просмотра                                                     |

## Сценарии использования

- Проверка правок договора, чтобы увидеть, что именно изменилось между версиями
- Сравнение макетов, чтобы убедиться, что экспорт в PDF соответствует ожиданиям
- Аудит изменений документов в регулируемых отраслях, где нужно отслеживать каждую правку
- Проверка того, что преобразование в PDF точно сохранило исходное содержимое
- Сверка переводов документов с оригиналом на предмет изменений верстки

## Советы

- Режим наложения помещает оба документа друг на друга, поэтому пространственные различия (сдвинутые элементы, измененные размеры изображений) сразу заметны.
- Включайте OCR при сравнении отсканированных документов без текстового слоя. Движок сравнения извлечет текст из изображений страниц.
- Используйте фильтры категорий, чтобы сосредоточиться на важном. Например, скройте изменения оформления, если вас интересуют только различия в тексте.

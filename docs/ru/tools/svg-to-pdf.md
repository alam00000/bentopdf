# SVG в PDF

Преобразуйте файлы Scalable Vector Graphics (SVG) в PDF. Инструмент растеризует каждый SVG средствами отрисовки браузера, а затем встраивает результат в исходном разрешении. Удобно для превращения векторных значков, диаграмм и иллюстраций в переносимые документы.

## Поддерживаемые форматы

| Формат | Расширения |
| :----- | :--------- |
| SVG    | `.svg`     |

## Как это работает

1. Нажмите на область загрузки или перетащите в неё один или несколько SVG-файлов.
2. Просмотрите список файлов и при необходимости измените его.
3. Выберите уровень **Качество PDF**.
4. Нажмите **Конвертировать в PDF**. Результат скачивается как `from_svgs.pdf`.

Каждый SVG читается как текст, отрисовывается на холсте в собственных ширине и высоте (по умолчанию 800x600, если размеры не указаны) и экспортируется в PNG. Затем этот PNG встраивается в PDF с помощью pdf-lib. Прозрачные области заливаются белым фоном.

## Параметры

**Качество PDF** управляет сжатием после растеризации:

- **Высокое качество**: ближе всего к исходной отрисовке.
- **Среднее качество** (по умолчанию): хороший баланс.
- **Низкое качество**: наименьший файл, часть деталей теряется.

## Сценарии использования

- Преобразование архитектурных и инженерных схем из SVG в PDF, готовый к печати
- Упаковка наборов значков в справочный PDF для дизайн-системы
- Превращение визуализаций данных (D3.js, экспорт из библиотек диаграмм) в PDF для отчётов
- Создание печатных версий инфографики на основе SVG

## Советы

- SVG-файлы без явных атрибутов `width` и `height` отрисовываются в размере 800x600 пикселей. Для лучшего результата задайте размеры в исходнике SVG перед преобразованием.
- Сложные SVG с внешними ссылками на шрифты или связанными изображениями могут отображаться неидеально. Встройте все ресурсы в SVG для надёжного результата.
- Поскольку SVG растеризуется, в PDF будет растровое изображение, а не векторные контуры. Для настоящего векторного PDF нужен специальный векторный инструмент.

# PDF-буклет

Переставьте страницы PDF в порядке буклетной импозиции. При двусторонней печати и сложении пополам страницы окажутся в правильной последовательности. Такая раскладка используется для брошюр на скрепке и зинов.

## Как это работает

1. Загрузите PDF-файл.
2. Задайте параметры буклета: размер страницы результата и ориентацию.
3. Нажмите **Создать предпросмотр**, чтобы увидеть, как страницы расположатся на каждом листе.
4. Просмотрите превью: для каждого физического листа показано, какие страницы окажутся на лицевой и оборотной стороне.
5. Нажмите **Скачать**, чтобы сохранить PDF с буклетной импозицией.

## Возможности

- Автоматическая перестановка страниц для сшивания скрепкой по сгибу
- Настраиваемый размер страницы результата
- Наглядное превью раскладки буклета перед скачиванием
- При нечётном числе страниц автоматически добавляются пустые
- Исходные страницы масштабируются под размер листа буклета

## Сценарии использования

- Создание печатных буклетов и зинов из обычного PDF
- Подготовка программ конференций и путеводителей мероприятий к печати своими силами
- Изготовление сложенных открыток и небольших каталогов
- Выпуск небольших сборников стихов и прозы для ручной брошюровки

## Советы

- Для аккуратного буклета число страниц исходного PDF желательно кратно 4. Если это не так, недостающие пустые страницы добавятся автоматически, чтобы заполнить последний лист.
- Печатайте двусторонне с настройкой принтера "переворот по короткому краю", затем сложите все листы вместе и скрепите по сгибу.
- Если нужно просто разместить несколько страниц на одном листе без буклетного порядка, используйте [N-Up PDF](./n-up-pdf).

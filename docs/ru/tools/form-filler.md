# Заполнение PDF-форм

Откройте PDF с полями формы и заполните его прямо во встроенном просмотрщике. Инструмент поддерживает как обычные поля AcroForm, так и устаревшие формы XFA (XML Forms Architecture). Когда форма заполнена, скачайте готовую версию одним нажатием.

## Как это работает

1. Загрузите PDF с полями формы.
2. Документ откроется во встроенном просмотрщике PDF, где поля формы отображаются как интерактивные элементы ввода.
3. Щёлкайте текстовые поля, флажки, выпадающие списки и переключатели, чтобы заполнить их.
4. Нажмите **Сохранить и скачать заполненную форму**, чтобы получить готовый PDF.

## Возможности

- Встроенный просмотрщик PDF.js с полной поддержкой работы с полями формы
- Поддержка стандартных полей AcroForm (текстовые поля, флажки, выпадающие списки, переключатели)
- Поддержка форм XFA, устаревших форм на основе XML
- Автоматический подбор размера просмотрщика по размерам страницы
- Отображение имени и размера файла

## Параметры

Дополнительных параметров нет. Загрузите форму, заполните её и скачайте.

## Сценарии использования

- Заполнение налоговых деклараций, страховых заявлений или государственных бумаг
- Заполнение анкет для приёма на работу, полученных в виде вложений PDF
- Заполнение форм регистрации поставщиков и анкет для поставщиков
- Подтверждение контрольных списков соответствия с помощью флажков
- Заполнение медицинских анкет перед приёмом

## Советы

- XFA - устаревший формат, который поддерживают только некоторые программы просмотра PDF. Если вы открываете PDF с XFA в Chrome или в большинстве других программ и видите пустые страницы, значит, в них нет поддержки XFA. Заполнение PDF-форм в BentoPDF и Firefox корректно работают с XFA.
- Если в PDF нет полей формы, сначала добавьте их инструментом [Создание PDF-форм](./form-creator), а затем заполните форму здесь.
- Просмотрщик автоматически подстраивает свой размер под размеры страницы PDF.

# PDF в Excel

Извлекает таблицы из PDF и сохраняет их в электронную таблицу Excel (`.xlsx`). Каждая найденная таблица размещается на отдельном листе с номером таблицы и исходной страницей в названии. Для поиска таблиц используется PyMuPDF, для создания файла Excel библиотека SheetJS.

## Как это работает

1. Загрузите PDF, нажав на область загрузки или перетащив файл.
2. Нажмите **Конвертировать в Excel**, чтобы начать извлечение таблиц.
3. Инструмент просматривает каждую страницу в поисках таблиц и собирает книгу Excel.
4. Скачивается файл `.xlsx`, где каждой таблице соответствует свой лист.

## Параметры

Настраиваемых параметров нет. Все найденные таблицы извлекаются автоматически.

## Формат результата

- Один файл `filename.xlsx`.
- **Одна таблица**: один лист с названием "Table".
- **Несколько таблиц**: листы с названиями "Table 1 (Page 3)", "Table 2 (Page 5)" и так далее. Названия листов обрезаются до 31 символа (ограничение Excel).

## Сценарии использования

- Преобразование финансовых отчётов из PDF в редактируемые таблицы для дальнейшего анализа.
- Извлечение таблиц складских остатков и заказов из PDF поставщиков.
- Перенос структурированных данных из PDF-форм и каталогов в Excel для сортировки и фильтрации.
- Архивирование табличных данных из PDF в формате, с которым могут работать коллеги без технической подготовки.

## Советы

- Если инструмент сообщает "Таблицы не найдены", скорее всего, в PDF свободная вёрстка текста, а не структурированные таблицы. Попробуйте [PDF в текст](./pdf-to-text), чтобы получить исходное содержимое.
- Для более простого плоского формата используйте [PDF в CSV](./pdf-to-csv). Для скачивания отдельных таблиц в разных форматах используйте [Извлечение таблиц из PDF](./extract-tables).
- По названиям листов можно понять, с какой страницы взята каждая таблица.

# XML в PDF

Конвертируйте файлы данных XML в читаемые структурированные PDF-документы. Исходный XML удобен для машин, но людям его читать трудно. Этот инструмент разбирает дерево XML, находит повторяющиеся структуры данных и отображает их как оформленные таблицы и разделы в PDF формата A4 с альбомной ориентацией.

## Поддерживаемые форматы

| Формат | Расширение | Примечания                      |
| :----- | :--------- | :------------------------------ |
| XML    | `.xml`     | Любой корректно оформленный XML |

## Как это работает

1. Нажмите на область загрузки или перетащите файлы XML. В одном пакете можно обработать несколько файлов.
2. Проверьте список файлов. Удалите ненужные значком корзины или нажмите **Добавить еще файлы**, чтобы добавить ещё.
3. Нажмите **Преобразовать в PDF**. Инструмент разбирает структуру XML встроенным в браузер DOMParser, анализирует иерархию данных и отрисовывает её в PDF с помощью jsPDF с форматированием auto-table.
4. Один файл скачивается как PDF. Несколько результатов упаковываются в `xml-to-pdf.zip`.

## Параметры

Ручная настройка не требуется. Конвертер сам определяет структуру XML и выбирает подходящую раскладку таблиц. Результат выводится в альбомной ориентации A4, чтобы поместились широкие наборы данных.

## Сценарии использования

- Превратить выгрузки данных XML из баз данных или API в отчёты для печати
- Получить читаемые сводки из файлов конфигурации XML
- Конвертировать счета или журналы транзакций в формате XML в PDF для хранения
- Сделать карты сайта XML или ленты RSS читаемыми в виде документа

## Советы

- XML должен быть корректно оформлен. Если парсер встретит синтаксические ошибки, конвертация завершится сообщением об ошибке с указанием на проблему.
- Глубоко вложенные структуры XML разворачиваются в таблицы. Лучший результат получается, если у данных есть повторяющиеся соседние элементы с одинаковым набором дочерних.
- Во время конвертации отображаются обновления прогресса по каждому этапу: чтение, разбор, анализ и отрисовка.

# WebP в PDF

Конвертируйте изображения в формате Google WebP в PDF. Это особенно удобно, если вы скачали из интернета картинки в WebP и вам нужен более универсальный формат для печати или отправки.

## Поддерживаемые форматы

| Формат | Расширения |
| :----- | :--------- |
| WebP   | `.webp`    |

## Как это работает

1. Нажмите на область загрузки или перетащите файлы WebP.
2. Проверьте список файлов и удалите лишние.
3. Выберите уровень **Качество PDF**.
4. Нажмите **Конвертировать в PDF**. Результат скачивается как `from_webps.pdf`.

Внутри каждое изображение WebP декодируется через canvas API браузера, а затем встраивается в PDF с помощью pdf-lib. Поэтому конвертация работает в любом браузере с поддержкой декодирования WebP (это все современные браузеры).

## Параметры

**Качество PDF** задаёт степень сжатия при встраивании изображений:

- **Высокое качество**: сохраняет максимум деталей.
- **Среднее качество** (по умолчанию): сбалансированный результат.
- **Низкое качество**: минимальный размер файла.

## Сценарии использования

- Превратить скачанные из интернета картинки WebP в PDF для печати
- Собрать скриншоты WebP из Chrome или Edge в документацию
- Создать PDF-портфолио из изображений, которые дизайнерские инструменты по умолчанию экспортируют в WebP
- Архивировать изображения WebP в более универсально читаемом формате

## Советы

- Перед встраиванием в PDF WebP внутри декодируется в PNG, поэтому изображения WebP без потерь сохраняют качество при настройке High.
- Если у вас смесь WebP и других форматов изображений, используйте инструмент [Изображения в PDF](./image-to-pdf): он принимает всё сразу.

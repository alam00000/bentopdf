# RTF в PDF

Преобразуйте документы Rich Text Format в PDF. RTF это кроссплатформенный формат документов, который поддерживает практически любой текстовый редактор. Инструмент использует LibreOffice, работающий в браузере, и отображает RTF-файлы с сохранением форматирования: полужирный и курсивный шрифт, таблицы и встроенные изображения переносятся в PDF.

## Поддерживаемые форматы

| Формат | Расширения | Типы MIME                     |
| :----- | :--------- | :---------------------------- |
| RTF    | `.rtf`     | `text/rtf`, `application/rtf` |

## Как это работает

1. Нажмите на область загрузки или перетащите в неё один или несколько RTF-файлов.
2. Просмотрите список файлов. Добавьте ещё или удалите лишние.
3. Нажмите **Конвертировать в PDF**. При первом использовании инициализируется движок LibreOffice, затем обрабатывается каждый файл.
4. Один файл скачивается сразу как PDF. Несколько файлов доставляются как `rtf-converted.zip`.

## Параметры

У этого инструмента нет дополнительных настроек. Преобразование сохраняет исходное форматирование RTF.

## Результат

| Количество файлов | Результат                                                         |
| :---------------- | :---------------------------------------------------------------- |
| 1 файл            | Один PDF (например, `letter.pdf`)                                 |
| 2 и более         | ZIP-архив (`rtf-converted.zip`) с отдельным PDF для каждого файла |

## Сценарии использования

- Преобразование устаревших RTF-документов из старых текстовых редакторов в современные PDF
- Превращение RTF-шаблонов писем в PDF-превью
- Обработка RTF-вывода из юридических и медицинских программ
- Пакетное преобразование RTF-файлов из системы управления документами в PDF для архива

## Советы

- Движок LibreOffice загружается один раз и кэшируется. Первое преобразование за сессию занимает на несколько секунд больше, последующие быстрее.
- RTF-файлы со встроенными OLE-объектами могут отображаться не идеально. Простой текст, изображения и стандартное форматирование преобразуются надёжно.
- Если ваши RTF-файлы созданы в Microsoft Word, их можно также преобразовать напрямую инструментом [Word в PDF](./word-to-pdf), который принимает RTF наряду с DOC и DOCX.

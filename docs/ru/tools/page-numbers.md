# Нумерация страниц

Добавьте видимые номера на каждую страницу PDF. Вы выбираете положение, формат, размер шрифта и цвет, остальное инструмент сделает сам.

## Как это работает

1. Загрузите PDF-файл.
2. Настройте параметры нумерации в появившейся панели.
3. Нажмите **Добавить номера страниц**, чтобы начать обработку.
4. PDF с номерами скачается автоматически.

## Параметры

- **Положение**: где будут номера страниц. Внизу по центру, внизу слева, внизу справа, вверху по центру, вверху слева или вверху справа.
- **Формат**: простая нумерация (1, 2, 3...) или формат "страница X из Y" (1 / 5, 2 / 5...).
- **Размер шрифта**: размер текста номера. По умолчанию 12.
- **Цвет**: любой цвет текста номера, выбирается в палитре.

## Возможности

- Шесть вариантов положения: все углы и центр сверху и снизу
- Два формата нумерации: простая последовательная или "страница X из Y"
- Размер шрифта от 6 до 72 пунктов
- Полноценная палитра для цвета текста
- Автоматический подбор полей, чтобы номера оставались в безопасной зоне при любом размере страницы

## Сценарии использования

- Подготовка документов к печати, где нужны видимые номера страниц
- Нумерация объединённого PDF, собранного из нескольких файлов
- Нумерация раздаточных материалов к презентациям перед рассылкой
- Последовательная нумерация юридических документов и договоров

## Советы

- Формат "страница X из Y" удобен для документов, где читателю важно знать общий объём, например для коммерческих предложений и отчётов.
- Если для разных разделов нужны разные стили нумерации (например, римские цифры для вводной части), воспользуйтесь инструментом [Добавить метки страниц](./add-page-labels).

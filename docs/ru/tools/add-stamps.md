# Добавление штампов

Размещайте штампы-изображения на страницах PDF во встроенном просмотрщике с панелью аннотаций для штампов. Штампы могут содержать ваше имя, что удобно для процессов согласования, проверки и маркировки документов.

## Как это работает

1. Введите свое имя в поле **Имя автора штампа**. Это имя будет указано на создаваемых штампах.
2. Загрузите PDF-файл, нажав на зону загрузки или перетащив файл в нее.
3. Откроется редактор штампов с загруженным документом в просмотрщике.
4. С помощью инструмента штампа-изображения на панели выберите и разместите штампы на любой странице.
5. При необходимости измените положение и размер штампов.
6. Нажмите **Сохранить PDF со штампами**, чтобы скачать результат.

## Возможности

- Встроенный просмотрщик PDF с панелью аннотаций для штампов
- Указание имени автора на созданных штампах
- Размещение штампов-изображений на любой странице
- Перетаскивание и изменение размера штампов
- Автоматический подбор размера просмотрщика по пропорциям страницы
- Отображение имени и размера файла

## Сценарии использования

- Добавление штампов «УТВЕРЖДЕНО» или «ПРОВЕРЕНО» в документы в процессе согласования
- Размещение изображений печати компании или нотариуса на официальных документах
- Отметка страниц штампами «ПОЛУЧЕНО» с именем проверяющего
- Добавление штампов контроля качества в акты проверок

## Советы

- Задайте имя автора штампа до загрузки PDF. Имя встраивается в метаданные штампа.
- Высота просмотрщика подстраивается под пропорции первой страницы PDF для удобного просмотра.
- Для текстовых водяных знаков вместо штампов-изображений используйте инструмент [Добавление водяных знаков](./add-watermark).

# Объединение в одну страницу

Объедините все страницы PDF в одну длинную страницу. Страницы склеиваются по вертикали (как свиток) или по горизонтали (рядом друг с другом), и на выходе получается одна непрерывная страница.

## Как это работает

1. Загрузите PDF-файл.
2. Выберите направление: **Вертикально** (страницы друг под другом) или **Горизонтально** (страницы рядом).
3. Задайте расстояние между страницами в пунктах.
4. Выберите цвет фона для промежутков между страницами.
5. При желании включите разделители (тонкие линии между страницами) и настройте их толщину и цвет.
6. Нажмите кнопку обработки. На выходе будет одностраничный PDF.

## Возможности

- Вертикальная или горизонтальная склейка страниц
- Настраиваемое расстояние между страницами
- Выбор цвета фона для промежутков
- Необязательные линии-разделители с настраиваемой толщиной и цветом
- Каждая исходная страница отображается в полном разрешении на общем холсте

## Параметры

| Параметр                       | Описание                                        |
| ------------------------------ | ----------------------------------------------- |
| **Направление раскладки**      | Вертикально (стопкой) или горизонтально (рядом) |
| **Интервал**                   | Расстояние между страницами в пунктах           |
| **Цвет фона**                  | Цвет области между страницами                   |
| **Добавить линии-разделители** | Включает тонкие линии между страницами          |
| **Толщина разделителя**        | Толщина линии в пунктах                         |
| **Цвет разделителя**           | Цвет линий-разделителей                         |

## Сценарии использования

- Создание одного длинного изображения из многостраничного макета или прототипа
- Непрерывный прокручиваемый вид документа для встраивания на веб-страницу
- Склейка многостраничного комикса или раскадровки в одну ленту
- Панорамный вид последовательных страниц для рецензирования

## Советы

- Вертикальная ориентация лучше подходит для документов с книжными страницами. Горизонтальная лучше для альбомного содержимого.
- Большие документы с множеством страниц дадут очень высокий или очень широкий результат. Некоторые программы просмотра PDF могут плохо справляться со слишком большими одиночными страницами.
- Разделители контрастного цвета помогают легко увидеть, где заканчивается одна исходная страница и начинается следующая.

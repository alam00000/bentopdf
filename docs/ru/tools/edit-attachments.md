# Редактирование вложений

Просматривайте вложенные файлы PDF и управляйте ими. Инструмент перечисляет каждый встроенный файл с его именем и уровнем вложения, а затем позволяет отметить отдельные вложения для удаления или удалить их все сразу.

## Как это работает

1. Загрузите PDF-файл.
2. Инструмент автоматически ищет вложения и показывает их в списке.
3. Для каждого вложения показаны имя файла и уровень: документа или страницы.
4. Щелкните значок корзины рядом с вложением, чтобы отметить его для удаления (повторный щелчок снимает отметку).
5. Кнопка **Удалить все вложения** выбирает все сразу, а **Снять выделение** снимает выбор.
6. Нажмите кнопку обработки, чтобы сохранить новый PDF без выбранных вложений.

## Возможности

- Список всех вложений уровня документа и уровня страницы
- Удаление отдельных вложений или всех сразу
- Выбор можно включать и отключать до применения изменений
- Отмеченные для удаления элементы зачеркиваются и становятся полупрозрачными
- Скачивание измененного PDF без выбранных вложений

## Сценарии использования

- Удаление устаревших или неверных файлов, встроенных в документ, перед повторным распространением
- Удаление конфиденциальных вложений (финансовые данные, личная информация) из PDF перед отправкой
- Уменьшение размера PDF за счет удаления больших встроенных файлов, которые больше не нужны
- Аудит встроенного содержимого и очистка документа перед архивацией

## Советы

- Вложения, отмеченные для удаления, показываются зачеркнутыми. Если вы передумали, можно снять отметку до обработки.
- Если вложения не найдены, инструмент показывает сообщение «В этом PDF вложений не найдено»: в PDF просто нет встроенных файлов.

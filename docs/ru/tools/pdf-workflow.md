# Конструктор PDF-процессов

Конструктор процессов позволяет объединить несколько операций с PDF в один автоматизированный конвейер. Вместо запуска инструментов по одному вы собираете визуальный граф из узлов (ввод, обработка, вывод) и выполняете всё одним нажатием. Ваши файлы не покидают браузер.

## Как это работает

Интерфейс состоит из трёх панелей: **набор узлов** слева, **холст** в центре и **панель настроек** справа, которая появляется при выборе узла.

1. **Добавляйте узлы**, нажимая на них в левой боковой панели или перетаскивая прямо на холст. Для фильтрации по названию используйте строку поиска вверху набора узлов.
2. **Соединяйте узлы**, перетаскивая от выходного разъёма (внизу узла) к входному разъёму (вверху другого узла). Соединения идут сверху вниз.
3. **Настраивайте параметры**: нажмите на узел, чтобы открыть его панель настроек справа. У каждого типа узла свои параметры (диапазоны страниц, ползунки качества, пароли и так далее).
4. **Запустите процесс** кнопкой **Запустить** на панели инструментов. Движок выполняет узлы в топологическом порядке, обрабатывая каждый по очереди. Строка состояния внизу показывает ход выполнения.
5. **Скачайте результат**: конечный узел Скачать сохраняет итоговый PDF (или ZIP, если создано несколько файлов).

## Категории узлов

Узлы разделены на шесть категорий, каждая обозначена своим цветом на холсте:

- **Ввод** (синий): PDF-вход, Ввод изображений, Word/Excel/PowerPoint в PDF и более 15 других конвертеров форматов, которые подают файлы в конвейер.
- **Редактирование и добавление примечаний** (индиго): Обрезка PDF, PDF в оттенки серого, Инверсия цвета, Добавление водяных знаков, Нумерация страниц, Колонтитулы, Эффект сканера, Настройка цвета, Цвет фона, Удаление пустых страниц, Удаление аннотаций.
- **Организация и управление** (фиолетовый): Объединение PDF, Разделение PDF, Извлечение страниц, Поворот PDF, Удаление страниц, Обращение порядка страниц, Добавление пустой страницы, Разделение страниц, N-Up PDF, Редактор размера страниц, Объединить на одну страницу, PDF-буклет, Постеризация документа, Редактирование метаданных, Оглавление, Распознавание текста в PDF.
- **Оптимизация и восстановление** (янтарный): Сжатие PDF, Растеризация документа, Линеаризация документа, Выпрямление PDF, PDF в PDF/A, Шрифты в кривые, Восстановление документа.
- **Защита PDF** (розовый): Зашифровать, Расшифровать, Санирование документа, Сведение документа, Цифровая подпись, Вымарать.
- **Вывод** (бирюзовый): Скачать (автоматически определяет один PDF или ZIP), PDF в изображения, PDF в текст, PDF в DOCX, PDF в XLSX, PDF в CSV, PDF в SVG, PDF в Markdown, Извлечение изображений.

## Сохранение и загрузка процессов

На панели инструментов доступны четыре варианта сохранения:

- **Сохранить**: сохраняет текущий процесс как именованный шаблон в локальном хранилище браузера. Можно сохранить несколько шаблонов.
- **Загрузить**: открывает окно со списком всех сохранённых шаблонов. Нажмите «Загрузить», чтобы восстановить шаблон, или удалите ненужные.
- **Экспорт**: скачивает процесс в виде файла `.json`, которым можно поделиться или сохранить резервную копию.
- **Импорт**: загружает файл процесса `.json` с диска, восстанавливая все узлы, их положение и соединения.

Шаблоны сохраняются между сеансами в локальном хранилище. Экспортированные файлы JSON переносимы между браузерами и компьютерами.

## Модель выполнения

Движок строит граф зависимостей по вашим соединениям и выполняет узлы в топологическом порядке. Если какой-либо узел завершается ошибкой, выполнение останавливается, а узел с ошибкой отмечается красным. Несколько правил, которые нужно учитывать:

- В каждом процессе должен быть минимум один узел **Ввод** и один узел **Вывод**.
- Движок обнаруживает циклические зависимости и блокирует выполнение с ошибкой.
- Узел **Зашифровать** должен быть последним шагом обработки перед узлом вывода. Если поставить его раньше, появится предупреждение при проверке, потому что следующие узлы не могут работать с зашифрованными данными.
- Для PDF, защищённых паролем, во время выполнения запрашивается пароль.
- Поддерживаются входы с несколькими PDF: узел Объединение PDF может их объединить, а узлы пакетной обработки обработают каждый PDF отдельно.

## Типы разъёмов

Соединения используют типизированные разъёмы, чтобы не допустить неверных связей:

- **PDF** (индиго): один PDF-документ.
- **MultiPDF** (янтарный): несколько PDF-документов, собранных вместе.
- **Image** (зелёный): изображение (blob).

## Параметры

У каждого узла есть собственная конфигурация, доступная через правую панель настроек. Типичные примеры:

- **Диапазоны страниц** в узлах Разделение PDF, Извлечение страниц, Удаление страниц
- **Ползунки качества** в узлах вывода с преобразованием в изображения
- **Поля пароля** в узлах Зашифровать и Расшифровать
- **Текстовые поля** в узлах Добавление водяных знаков, Колонтитулы, Редактирование метаданных
- **Углы поворота** в узле Поворот PDF
- **Уровень сжатия** в узле Сжатие PDF
- **Выбор языка OCR** в узле Распознавание текста в PDF

## Сценарии использования

- **Конвейер обработки счетов**: PDF-вход -> Распознавание текста в PDF -> Извлечение таблиц из PDF -> Скачать в формате CSV.
- **Стандартизация отчётов**: Word в PDF -> Редактор размера страниц -> Нумерация страниц -> Добавление водяных знаков -> Сжатие PDF -> Скачать.
- **Подготовка к архивированию**: PDF-вход -> Восстановление документа -> Сведение документа -> Санирование документа -> PDF в PDF/A -> Скачать.
- **Пакетное извлечение изображений**: PDF-вход (несколько файлов) -> Извлечение изображений -> Скачать ZIP.
- **Буклеты, готовые к печати**: PDF-вход -> PDF-буклет -> Обрезка PDF -> Сжатие PDF -> Скачать.
- **Защищённая рассылка**: PDF-вход -> Вымарать -> Удаление аннотаций -> Зашифровать -> Скачать.

## Советы

- Клавиши **Delete** или **Backspace** удаляют выбранный узел с холста.
- Нажмите кнопку **X** в строке состояния узла, чтобы удалить его напрямую.
- Перемещайте холст, нажимая и перетаскивая пустое место. Во время перемещения курсор меняется на значок руки.
- На мобильных устройствах кнопкой **+** на панели инструментов можно показать или скрыть набор узлов.
- Если процесс создаёт несколько выходных файлов, узел Скачать автоматически упаковывает их в ZIP.
- Начните с простого: соберите и проверьте конвейер из двух узлов, прежде чем усложнять.

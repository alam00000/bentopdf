# Оглавление

Инструмент читает закладки (структуру) вашего PDF и создаёт страницу с оформленным оглавлением, которая добавляется в начало документа. Если в PDF уже есть закладки, но нет видимой страницы оглавления, инструмент создаст её автоматически.

## Как это работает

1. Загрузите PDF, содержащий закладки.
2. Настройте заголовок оглавления, размер шрифта и семейство шрифтов.
3. При желании отметьте **Добавить закладку для страницы оглавления**, чтобы включить само оглавление в дерево закладок.
4. Нажмите **Создать оглавление**, чтобы обработать файл.
5. Обновлённый PDF скачивается автоматически, страница оглавления вставлена в начало.

## Параметры

- **Заголовок оглавления**: заголовок вверху созданной страницы. По умолчанию «Оглавление».
- **Размер шрифта**: от 10 pt до 72 pt. По умолчанию 12 pt.
- **Семейство шрифтов**: Times Roman, Helvetica или Courier (обычный, полужирный, курсив, полужирный курсив). По умолчанию Helvetica.
- **Добавить закладку для страницы оглавления**: если отмечено, в дерево структуры PDF добавляется закладка на саму страницу оглавления.

## Возможности

- Считывает всю иерархию закладок из PDF
- Создаёт аккуратно оформленную страницу оглавления с номерами страниц
- Поддерживает вложенные уровни закладок с отступами
- Выбор из 12 встроенных шрифтов PDF
- Необязательная закладка на саму страницу оглавления

## Сценарии использования

- Добавление печатного оглавления в электронные книги и отчёты, где есть только цифровые закладки
- Создание оглавления для сводного документа после объединения нескольких PDF
- Создание справочной страницы для длинных технических руководств
- Подготовка документов к печати, где ожидается видимое оглавление

## Советы

- Если в PDF нет закладок, сначала создайте их инструментом [Редактирование закладок](./bookmark), а затем вернитесь сюда, чтобы создать оглавление.
- Для больших документов больший размер шрифта, например 14 pt или 16 pt, улучшает читаемость.

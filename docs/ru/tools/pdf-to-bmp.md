# PDF в BMP

Преобразует каждую страницу PDF в изображение BMP (Bitmap). BMP - несжатый формат, поэтому результат точен до пикселя и без потери качества, но файлы получаются большими.

## Как это работает

1. Загрузите PDF, нажав на область загрузки или перетащив файл.
2. Нажмите **Конвертировать**, чтобы обработать файл.
3. Автоматически скачается один файл `.bmp` или ZIP-архив.

## Параметры

Настраиваемых параметров нет. Страницы рендерятся в фиксированном масштабе 2x, поэтому размер изображений примерно вдвое больше исходных размеров страницы PDF.

## Формат результата

- **Одна страница**: `filename.bmp`
- **Несколько страниц**: `filename_bmps.zip` с файлами `page_1.bmp`, `page_2.bmp` и так далее.

## Сценарии использования

- Передача страниц PDF в устаревшие системы и оборудование, принимающее только BMP.
- Подготовка несжатых изображений для определённых печатных процессов.
- Использование растрового результата как входных данных для программ обработки изображений, которым нужны необработанные пиксели.

## Советы

- Файлы BMP очень большие, потому что хранят необработанные пиксели без сжатия. В большинстве случаев [PDF в PNG](./pdf-to-png) даёт то же качество без потерь при гораздо меньшем размере.
- Если ваша система принимает PNG или TIFF, выбирайте эти форматы, чтобы экономить место на диске.

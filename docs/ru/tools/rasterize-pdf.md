# Растеризация документа

Растеризация превращает каждую страницу PDF в изображение и собирает эти изображения обратно в PDF. Результат выглядит так же, как оригинал, но в нём нет выделяемого текста, интерактивных элементов и редактируемых слоёв. По сути, это качественная фотокопия.

## Как это работает

1. Загрузите один или несколько PDF-файлов.
2. Задайте **DPI** (разрешение) растеризованного результата.
3. Выберите **Формат изображения**: PNG для качества без потерь или JPEG для файлов меньшего размера.
4. При желании включите **Преобразовать в оттенки серого**.
5. Нажмите **Растеризация документа**. Несколько файлов скачиваются в ZIP.

## Параметры

| Настройка              | Значения                               | По умолчанию |
| ---------------------- | -------------------------------------- | ------------ |
| **DPI**                | 72, 150, 200, 300, 600                 | 150          |
| **Формат изображения** | PNG (без потерь), JPEG (меньше размер) | PNG          |
| **Градации серого**    | Вкл/Выкл                               | Выкл         |

## Рекомендации по DPI

- **72**: только просмотр на экране, наименьший размер файла
- **150**: хороший баланс для общего использования
- **200**: более чёткий текст, умеренный размер файла
- **300**: качество для печати
- **600**: высокое качество для архива или профессиональной печати

## Сценарии использования

- Защита конфиденциальных документов от извлечения текста перед отправкой
- Устранение проблем с зависимостью от шрифтов путём превращения текста в пиксели
- Создание «плоской» версии PDF со сложными слоями или прозрачностью, которая по-разному отображается в разных программах просмотра
- Подготовка PDF для системы, принимающей только изображения
- Удаление скрытого содержимого (например, исправлений или данных форм) путём сведения PDF к чистым изображениям

## Советы

- 150 DPI и PNG это надёжный вариант по умолчанию. Повышайте разрешение, только если нужна печать или вам нужно приближать мелкие детали.
- JPEG даёт заметно меньшие файлы, но добавляет артефакты сжатия на резких краях текста.
- Растеризация необратима: сохраните исходный PDF, если позже понадобится редактируемый текст.

# PDF в CSV

Извлекает таблицы из PDF и экспортирует их в файл CSV. Инструмент просматривает каждую страницу с помощью механизма поиска таблиц PyMuPDF и записывает все найденные строки в один файл с разделителями-запятыми.

## Как это работает

1. Загрузите PDF, нажав на область загрузки или перетащив файл.
2. Нажмите **Конвертировать в CSV**, чтобы начать извлечение таблиц.
3. Инструмент просматривает каждую страницу и автоматически находит таблицы.
4. Скачивается файл `.csv` со всеми извлечёнными данными таблиц.

Таблицы с разных страниц разделяются в результате пустыми строками. Ячейки с запятыми, кавычками или переводами строк корректно экранируются по RFC 4180.

## Параметры

Настраиваемых параметров нет. Все найденные в документе таблицы извлекаются и объединяются в один CSV.

## Формат результата

- Один файл `filename.csv` со всеми найденными таблицами.

## Сценарии использования

- Перенос финансовых данных из банковских выписок и счетов в PDF в электронную таблицу.
- Извлечение таблиц цен из предложений поставщиков для сравнения.
- Преобразование табличных данных исследований из PDF в формат, удобный для анализа.
- Перенос данных из старых PDF-отчётов в базы данных.

## Советы

- Если таблицы не найдены, инструмент покажет сообщение "Таблицы не найдены". Обычно это значит, что в PDF текст выглядит как таблица, но не является настоящей таблицей.
- Для более тонкого контроля над отдельными таблицами используйте [Извлечение таблиц из PDF](./extract-tables), где можно выбрать формат CSV, JSON или Markdown.
- Если данные нужны в Excel с отдельным листом для каждой таблицы, используйте [PDF в Excel](./pdf-to-excel).

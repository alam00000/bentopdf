# Эффект сканера

Превратите чистый цифровой PDF в документ, выглядящий так, будто он вышел из планшетного сканера. Инструмент применяет настраиваемый шум, лёгкий поворот, размытие, сдвиги яркости и необязательное пожелтение, имитируя несовершенства физического скана.

## Как это работает

1. Загрузите PDF-файл.
2. Откроется редактор с живым предпросмотром первой страницы и панелью настроек.
3. Настройте параметры эффекта сканирования ползунками и переключателями.
4. Предпросмотр обновляется в реальном времени при изменении настроек.
5. Нажмите **Применить эффект сканера**, чтобы обработать все страницы и скачать результат.

## Параметры

- **Цветовое пространство (переключатель градаций серого)**: преобразует результат в градации серого для классического чёрно-белого скана.
- **Граница**: добавляет едва заметную тёмную рамку по краям страницы, имитируя артефакты границ сканера.
- **Поворот**: применяет лёгкий поворот (от -5 до +5 градусов), имитируя неровную подачу бумаги.
- **Разброс поворота**: добавляет случайное отклонение угла, чтобы каждая страница наклонялась немного по-разному.
- **Яркость**: сдвигает общую яркость вверх или вниз.
- **Контраст**: регулирует контраст, имитируя различия в качестве тонера.
- **Размытие**: применяет размытие по Гауссу, смягчая края текста, как у скана низкого качества.
- **Шум**: добавляет случайный пиксельный шум, имитируя зернистость датчика сканера. Чем выше значение, тем зернистее результат.
- **Желтоватость**: добавляет тёплый жёлтый оттенок, имитируя старую или переработанную бумагу.
- **Разрешение**: задаёт DPI результата. Чем ниже значение, тем более пикселизированным и «сканированным» выглядит документ.
- **Сброс**: возвращает все настройки к значениям по умолчанию.

## Возможности

- Предпросмотр в реальном времени, обновляющийся при изменении каждого параметра
- Случайный разброс поворота для каждой страницы для реалистичного вида
- Десять независимо настраиваемых параметров
- Режим градаций серого для достоверного чёрно-белого скана
- Управление разрешением от качества факса с низким DPI до архивного качества с высоким DPI

## Сценарии использования

- Придание цифровым документам вида отсканированных и напечатанных
- Имитация старения физического документа для воссоздания исторических документов
- Проверка программ распознавания текста на сканах ухудшенного качества
- Создание документов, соответствующих визуальному стилю существующих архивов сканов

## Советы

- Начните с мягких значений. Уровня шума 10-20, лёгкого поворота в 0,5 градуса и минимального размытия уже достаточно для убедительного вида скана.
- Сочетайте режим градаций серого с лёгким пожелтением для эффекта «ксерокопии с ксерокопии».
- Низкие значения разрешения (100-150 DPI) дают наиболее реалистичный вид факса.

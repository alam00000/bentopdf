# BMP в PDF

Конвертируйте файлы Windows Bitmap (BMP) в PDF. BMP, несжатый формат изображений, до сих пор встречается в устаревших системах, медицинской визуализации и промышленных сканерах. Этот инструмент превращает их в PDF без установки чего-либо.

## Поддерживаемые форматы

| Формат | Расширения |
| :----- | :--------- |
| BMP    | `.bmp`     |

## Как это работает

1. Нажмите на зону загрузки или перетащите в нее файлы BMP.
2. Просмотрите список файлов. Добавьте еще файлы или удалите ненужные.
3. Нажмите **Конвертировать в PDF**. Результат скачается как `from_bmps.pdf`.

Каждое BMP рисуется на canvas, экспортируется в PNG и затем встраивается в PDF с помощью pdf-lib. Размер страницы совпадает с размерами исходного изображения.

## Параметры

У этого инструмента нет дополнительных настроек качества. Изображения встраиваются в исходном разрешении как PNG без потерь внутри PDF.

## Сценарии использования

- Конвертация старых отсканированных документов в формате BMP в архивные PDF
- Превращение снимков экрана в BMP из старых приложений Windows в документы, которыми удобно делиться
- Обработка результатов медицинских или промышленных сканеров, которые по умолчанию сохраняют BMP
- Перенос старых архивов изображений в более переносимый формат

## Советы

- Файлы BMP не сжаты, поэтому обычно велики. Итоговый PDF будет заметно меньше, так как внутри изображения перекодируются в PNG.
- Если у вас есть файлы BMP вместе с другими форматами изображений, используйте инструмент [Изображения в PDF](./image-to-pdf), чтобы конвертировать все за один раз.

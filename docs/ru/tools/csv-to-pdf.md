# CSV в PDF

Превращайте файлы CSV в аккуратные отформатированные PDF-документы. Каждый CSV разбирается и отображается в выходном PDF в виде таблицы. Это удобно, когда нужно распечатать или передать табличные данные, не требуя от получателя программы для работы с электронными таблицами.

## Поддерживаемые форматы

| Формат | Расширения |
| :----- | :--------- |
| CSV    | `.csv`     |

## Как это работает

1. Щелкните по области загрузки или перетащите в нее один или несколько файлов CSV.
2. Проверьте список файлов. Добавьте еще файлы или удалите ненужные.
3. Нажмите **Конвертировать в PDF**. Индикатор выполнения показывает состояние преобразования.
4. Один файл скачивается сразу как PDF. Несколько файлов упаковываются в `csv-converted.zip`.

## Параметры

У этого инструмента нет дополнительных настроек. CSV автоматически разбирается и форматируется как таблица.

## Результат

| Количество файлов | Результат                                                         |
| :---------------- | :---------------------------------------------------------------- |
| 1 файл            | Скачивание одного PDF (например, `data.pdf`)                      |
| 2 и более файлов  | ZIP-архив (`csv-converted.zip`) с отдельным PDF для каждого файла |

## Сценарии использования

- Преобразование экспортированных отчетов из баз данных в печатные PDF-таблицы
- Передача финансовых данных или списков инвентаризации тем, у кого нет Excel
- Создание PDF-версий лог-файлов CSV для документации по соответствию требованиям
- Печать списков адресов, ведомостей оценок и любых других табличных данных в формате CSV

## Советы

- Для лучшего результата используйте в CSV стандартный разделитель-запятую. Инструмент следует общепринятым правилам разбора CSV.
- Если в CSV много столбцов, таблица может быть сжата по ширине страницы. Подумайте о разделении широких наборов данных на несколько файлов.
- Для файлов Excel (`.xls`, `.xlsx`) используйте инструмент [Excel в PDF](./excel-to-pdf), который сохраняет форматирование таблиц и несколько листов.

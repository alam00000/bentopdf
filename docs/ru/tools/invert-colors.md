# Инверсия цвета

Замените каждый цвет в PDF на противоположный. Белый фон становится чёрным, чёрный текст белым, а все остальные цвета переходят в дополнительные. Это самый быстрый способ получить «тёмную тему» для любого PDF.

## Как это работает

1. Загрузите файл PDF.
2. Нажмите **Инвертировать цвета** для обработки.
3. Инвертированный PDF скачивается автоматически.

Дополнительных настроек нет. Инструмент отображает каждую страницу как изображение, инвертирует цвета всех пикселей и собирает результат в новый PDF.

## Возможности

- Инверсия цвета всех страниц в одно нажатие
- Обработка каждой страницы документа
- Сохранение исходных размеров и макета страниц
- Работает с любым PDF независимо от содержимого (текст, изображения, смешанное содержимое)

## Сценарии использования

- Создание тёмных версий учебников и руководств для комфортного чтения ночью
- Подготовка высококонтрастных версий документов для доступности
- Инверсия отсканированных документов, снятых с неправильной экспозицией
- Создание негативов PDF с большим количеством изображений для визуального анализа

## Советы

- Чтобы применить эффект, инструмент растеризует страницы, поэтому результат состоит из изображений. Текст больше нельзя выделять и искать. Если после инверсии нужен текст с возможностью поиска, пропустите результат через инструмент распознавания текста.
- Для более точной настройки цвета (яркость, контраст, насыщенность) используйте инструмент [Настройка цвета](./adjust-colors).
- Большие PDF с множеством страниц могут обрабатываться дольше, так как каждая страница отображается и инвертируется отдельно.

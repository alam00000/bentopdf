# Excel в PDF

Преобразуйте файлы электронных таблиц в PDF. Инструмент работает с современными файлами Excel, устаревшим форматом XLS, таблицами OpenDocument и даже CSV. Все они обрабатываются браузерным движком LibreOffice, который сохраняет форматирование ячеек, формулы (как вычисленные значения), диаграммы и макеты с несколькими листами.

## Поддерживаемые форматы

| Формат               | Расширения |
| :------------------- | :--------- |
| Excel (современный)  | `.xlsx`    |
| Excel (устаревший)   | `.xls`     |
| Таблица OpenDocument | `.ods`     |
| CSV                  | `.csv`     |

## Как это работает

1. Щелкните по области загрузки или перетащите в нее файлы электронных таблиц.
2. Проверьте список файлов. Добавьте еще файлы или удалите ненужные.
3. Нажмите **Преобразовать в PDF**. Движок LibreOffice инициализируется при первом использовании, затем обрабатывает каждый файл.
4. Один файл скачивается сразу как PDF. Несколько файлов передаются в виде `excel-converted.zip`.

## Параметры

У этого инструмента нет дополнительных настроек. Движок LibreOffice определяет макет страницы, масштаб и область печати по встроенным настройкам таблицы.

## Результат

| Количество файлов | Результат                                                           |
| :---------------- | :------------------------------------------------------------------ |
| 1 файл            | Скачивание одного PDF (исходное имя файла с расширением `.pdf`)     |
| 2 и более файлов  | ZIP-архив (`excel-converted.zip`) с отдельным PDF для каждого файла |

## Сценарии использования

- Преобразование финансовых отчетов и бюджетов из Excel в PDF для рассылки
- Создание готовых к печати PDF из таблиц складских остатков и каталогов товаров
- Передача результатов анализа данных заинтересованным лицам, у которых не установлен Excel
- Архивирование квартальных отчетов в формате, не допускающем редактирования
- Преобразование файлов ODS из LibreOffice Calc в PDF

## Советы

- Диаграммы, встроенные в таблицу, отображаются в PDF. Перед преобразованием убедитесь, что в исходном файле они выглядят правильно.
- Если в таблице несколько листов, в итоговый PDF попадают все листы.
- Для простых данных CSV без форматирования инструмент [CSV в PDF](./csv-to-pdf) выполняет более легкое преобразование. Используйте Excel в PDF, когда нужно сохранить форматирование, диаграммы или несколько листов.

# Разделение страниц

Разрезайте отдельные страницы PDF пополам по горизонтали или по вертикали. Это полезно, когда на одной странице находится содержимое, которое нужно разнести на отдельные страницы, например двухколоночная верстка, отсканированная как одна широкая страница.

## Как это работает

1. Загрузите PDF-файл.
2. Выберите направление разделения: **По вертикали** (левая и правая половины) или **По горизонтали** (верхняя и нижняя половины).
3. При желании укажите диапазон страниц, чтобы разделить только их. Оставьте поле пустым, чтобы разделить все страницы.
4. Нажмите кнопку обработки, чтобы создать разделенный PDF.

## Возможности

- Вертикальное разделение: каждая страница делится на левую и правую половины
- Горизонтальное разделение: каждая страница делится на верхнюю и нижнюю половины
- Фильтр по диапазону страниц для выборочного разделения
- Страницы вне диапазона остаются без изменений
- Качество содержимого сохраняется без повторной отрисовки

## Сценарии использования

- Разделение отсканированных разворотов (например, скан книги, где на одном листе левая и правая страницы)
- Разделение альбомного PDF с содержимым рядом на отдельные книжные страницы
- Разделение высоких инфографик и плакатов на верхнюю и нижнюю части
- Подготовка широкоформатных документов к печати на стандартной бумаге

## Советы

- Если содержимое на страницах распределено неравномерно, разделение все равно происходит ровно посередине. Для несимметричного разделения лучше использовать [Обрезка PDF](./crop-pdf).
- Если страницы нужно повернуть до или после разделения, сочетайте этот инструмент с [Поворот PDF](./rotate-pdf).

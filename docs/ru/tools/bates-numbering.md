# Bates-нумерация

Bates-нумерация проставляет последовательные идентификаторы на каждой странице ваших PDF. Это стандартный способ маркировки документов в судебных разбирательствах, аудитах и процессах комплаенса. Инструмент поддерживает несколько файлов и настраиваемые шаблоны, а результат выдает в виде отдельных пронумерованных PDF или одного ZIP-архива.

## Как это работает

1. Загрузите один или несколько PDF-файлов. Можно перетащить сразу несколько.
2. Выберите готовый стиль или создайте собственный шаблон.
3. Настройте положение, шрифт, размер, цвет и начальные номера.
4. Нажмите **Применить Bates-номера**, чтобы начать обработку.
5. Один файл скачивается напрямую. Несколько файлов скачиваются как ZIP-архив.

## Параметры

- **Готовый стиль**: выберите один из встроенных форматов:
  - Exhibit + Case + Bates + Page (например, «Exhibit 1 Case XYZ 000001 Page 1»)
  - Exhibit + Case + Bates (без номера страницы)
  - Case + Bates
  - Только Bates-номер (например, «000001»)
  - Пользовательский (напишите свой шаблон)
- **Настроить стиль**: строка шаблона с плейсхолдерами: `[BATES]`, `[PAGE]`, `[FILE]`, `[FILENAME]`.
- **Дополнение Bates-номера**: количество цифр (от 3 до 6) для Bates-номеров с ведущими нулями. Видно только в пользовательском режиме.
- **Положение**: верхний или нижний колонтитул, слева, по центру или справа.
- **Bates-нумерация начинается с**: первый Bates-номер. По умолчанию 1. Нумерация продолжается между файлами.
- **Счетчик файлов начинается с**: начальное число для плейсхолдера `[FILE]`.
- **Шрифт**: Helvetica, Times New Roman или Courier.
- **Размер шрифта**: размер наносимого текста.
- **Цвет**: палитра для цвета текста Bates-номера.

## Возможности

- Предпросмотр в реальном времени показывает, как Bates-номера будут выглядеть во всех загруженных файлах
- Поддержка нескольких файлов со сквозной нумерацией между документами
- Изменение порядка файлов перетаскиванием для управления последовательностью нумерации
- Шесть вариантов положения (верх или низ, слева, по центру, справа)
- Адаптивный расчет полей с учетом разных размеров страниц
- Результат в ZIP для пакетной обработки нескольких файлов
- Плейсхолдеры в шаблонах для максимальной гибкости

## Сценарии использования

- Нумерация документов раскрытия в судебном процессе последовательными номерами доказательств
- Нумерация пакетов аудиторских доказательств, состоящих из десятков файлов
- Нанесение регуляторных справочных номеров на документацию по комплаенсу
- Маркировка приложений к патентной заявке идентификаторами конкретного дела

## Советы

- Перетащите файлы в списке, чтобы изменить их порядок перед обработкой. Последовательность Bates-номеров следует этому порядку.
- Используйте плейсхолдер `[FILENAME]`, чтобы включить в штамп исходное имя файла: так проще отследить страницы до исходных документов.
- Окно предпросмотра обновляется в реальном времени при изменении настроек, поэтому формат можно проверить до обработки.

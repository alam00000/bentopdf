# Редактор PDF

Редактор PDF в BentoPDF позволяет аннотировать, выделять, закрашивать конфиденциальные данные, комментировать, добавлять фигуры и изображения и искать по PDF. Полнофункциональный редактор загружается прямо в браузере, без отправки файлов на сервер.

## Как это работает

1. Загрузите PDF, щелкнув по области загрузки или перетащив файл на нее.
2. Встроенный редактор PDF автоматически откроется с вашим документом.
3. С помощью панели инструментов аннотируйте, выделяйте, закрашивайте, добавляйте текст, рисуйте фигуры или вставляйте изображения.
4. Нажмите **Скачать изменённый PDF**, чтобы сохранить изменения.

## Возможности

- Полная панель аннотаций: выделение, подчеркивание, зачеркивание и рисование от руки
- Вставка текста и комментирование
- Инструменты редактирования (redaction), которые безвозвратно удаляют отмеченное содержимое после применения. Если при нажатии **Скачать изменённый PDF** остались непримененные отметки, редактор предложит сначала применить их.
- Фигуры: прямоугольники, окружности, линии и стрелки
- Вставка изображений на страницы PDF
- Встроенный текстовый поиск по документу
- Поддержка нескольких документов во вкладках (до 10 документов одновременно)
- Загрузка файлов перетаскиванием

## Сценарии использования

- Проверка договоров и пометка изменений выделениями и комментариями
- Закрашивание конфиденциальной информации, например номеров социального страхования или финансовых данных, перед отправкой
- Добавление аннотаций на архитектурные планы и инженерные чертежи
- Вставка логотипов компании или штампов на страницы документа
- Поиск определенных терминов в объемных юридических документах

## Советы

- Можно открыть несколько PDF одновременно и переключаться между ними с помощью панели вкладок вверху редактора.
- Редактор сохраняет исходную структуру PDF, поэтому шрифты, макеты и поля форм остаются нетронутыми.
- Пометка текста или области для закрашивания ничего не удаляет, пока закрашивание не применено. Когда вы закрашиваете выделенный текст, его копии в свойствах файла, закладках, комментариях и вложениях также удаляются из скачиваемого файла, если файл не зашифрован.
- Для массового нанесения водяных знаков или нумерации страниц используйте специальные инструменты: у них больше возможностей форматирования.

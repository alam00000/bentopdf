# Редактор размера страниц

PDF, собранные из нескольких источников, часто содержат страницы разных размеров: одни Letter, другие A4, а третьи совсем нестандартные. Этот инструмент приводит каждую страницу к одному целевому размеру, масштабируя содержимое по размеру или с заполнением.

## Как это работает

1. Загрузите файл PDF.
2. Выберите **Целевой размер страницы** в выпадающем списке (A4, Letter, Legal, A3, A5, Tabloid или Свой).
3. Выберите **Ориентацию**: «Авто» сохраняет исходную ориентацию каждой страницы, а также можно принудительно задать книжную или альбомную.
4. Выберите режим **Масштабирования содержимого**: «Вписать» (сохраняет всё содержимое, могут появиться поля) или «Заполнить» (заполняет страницу, края могут быть обрезаны).
5. При желании задайте **Цвет фона** для добавленных полей.
6. Нажмите **Исправить размер страниц**.

## Параметры

- **Стандартные размеры**: A4, Letter, Legal, A3, A5, Tabloid
- **Свои размеры**: введите ширину и высоту в дюймах или миллиметрах
- **Ориентация**: авто, книжная, альбомная
- **Режим масштабирования**: вписать или заполнить (с обрезкой)
- **Цвет фона**: любой цвет для заполнения полей

## Сценарии использования

- Выравнивание объединённого PDF, страницы которого получены с разных сканеров
- Преобразование документа US Letter в A4 для международной рассылки
- Подготовка PDF к печати, где нужен единый размер обреза
- Исправление страниц, которые слегка отличаются от стандарта (например, 8,49 x 11,02 дюйма вместо 8,5 x 11)

## Советы

- Режим «Вписать» гарантирует, что содержимое не потеряется. Режим «Заполнить» выглядит аккуратнее, но может обрезать края.
- Проверьте результат инструментом «Размеры страниц», чтобы убедиться, что все страницы соответствуют целевому размеру.
- По умолчанию фон белый. Если у документа тёмные поля, выберите тёмный цвет.

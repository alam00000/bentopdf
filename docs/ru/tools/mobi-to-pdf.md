# MOBI в PDF

Преобразуйте электронные книги Amazon Kindle в формате MOBI в документы PDF. Файлы MOBI привязаны к устройствам и приложениям Kindle, поэтому их сложно читать в других местах. PDF даёт переносимую версию, которую можно открыть на любом устройстве или распечатать.

## Поддерживаемые форматы

| Формат | Расширение | Примечания                      |
| :----- | :--------- | :------------------------------ |
| MOBI   | `.mobi`    | Формат книг Kindle (Mobipocket) |

## Как это работает

1. Нажмите на область загрузки или перетащите в неё один или несколько файлов MOBI.
2. Просмотрите список файлов. Удалите ненужные значком корзины или нажмите **Добавить ещё файлы**, чтобы добавить другие книги.
3. Нажмите **Преобразовать в PDF**. Движок PyMuPDF разбирает структуру MOBI и отображает каждую страницу как содержимое PDF.
4. Один файл скачивается как PDF. При конвертации нескольких файлов вы получите ZIP-архив `mobi-converted.zip`.

## Параметры

Дополнительные настройки не нужны. При преобразовании сохраняются текст, форматирование и встроенные изображения исходного файла MOBI.

## Сценарии использования

- Чтение содержимого, купленного в Kindle, на устройстве для чтения без Kindle, которое поддерживает только PDF
- Печать глав книги для автономного изучения или заметок
- Архивирование личной библиотеки книг в универсальном формате
- Отправка фрагментов тому, у кого не установлено приложение Kindle

## Советы

- Файлы MOBI с защитой DRM преобразовать нельзя. Инструмент работает только с файлами MOBI без DRM.
- Большие книги с множеством встроенных изображений могут обрабатываться на несколько секунд дольше, так как всё выполняется в браузере.

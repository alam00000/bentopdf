# Разделение PDF

Разбейте PDF на небольшие документы одним из шести режимов разделения. От простых диапазонов страниц до разделения по закладкам: инструмент подходит для любого сценария деления документа.

## Как это работает

1. Загрузите один PDF-файл.
2. Выберите режим разделения в выпадающем списке.
3. Настройте параметры выбранного режима (диапазоны страниц, выбор и т. д.).
4. Нажмите кнопку обработки.
5. Результат скачивается как один PDF или ZIP-архив в зависимости от режима и настроек.

## Режимы разделения

| Режим                 | Описание                                                                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **Диапазон**          | Введите диапазоны страниц, например `1-3, 5, 8-10`. Несколько диапазонов дают отдельные PDF в ZIP. Один диапазон даёт один PDF. |
| **Визуальный выбор**  | Просматривайте миниатюры страниц и щёлкайте по нужным. Выбранные страницы извлекаются в новый PDF.                              |
| **Чётные / нечётные** | Извлекаются только чётные или только нечётные страницы.                                                                         |
| **Все страницы**      | Каждая страница сохраняется как отдельный PDF-файл, всё скачивается в ZIP.                                                      |
| **Закладки**          | Разделение по границам закладок. Выберите уровень закладок, чтобы определить, где проходят разрезы.                             |
| **Каждые N страниц**  | Разделение на части по N страниц (например, каждые 5 страниц). В последней части может быть меньше страниц.                     |

## Возможности

- Шесть различных режимов разделения, охватывающих практически любой сценарий
- Визуальный выбор страниц с отложенной загрузкой миниатюр
- Разделение по закладкам с фильтрацией по уровню
- Вывод в ZIP для режимов диапазона и визуального выбора
- Поддержка диапазонов страниц со смешанным синтаксисом (`1-3, 5, 8-10`)
- Предупреждение, если разделение по N страниц даёт части неравного размера

## Сценарии использования

- Извлечение определённой главы или раздела из большого документа
- Разделение нечётных и чётных страниц для двусторонней печати
- Разбиение PDF книги на файлы отдельных глав по границам закладок
- Выделение отдельных страниц (например, страницы с подписями) из договора
- Разделение сводного отчёта на файлы по разделам для рассылки

## Советы

- Несколько диапазонов страниц через запятую (например, `1-5, 10-15, 20-25`) дают отдельные PDF, по одному на диапазон, упакованные в ZIP.
- Для режима закладок в PDF должны быть закладки. Если их нет, вы получите сообщение об ошибке.
- Флажок «Скачать как ZIP» в режимах диапазона и визуального выбора позволяет получить отдельные PDF для каждой страницы вместо одного общего файла.

# Сжатие PDF

Уменьшайте PDF-файлы, не разрушая их. Сжатие PDF работает на [Hyper Compress](https://www.bentopdf.com/hyper-compress), собственном движке сжатия BentoPDF. Он пережимает изображения, создает подмножества шрифтов и объединяет их, а также удаляет лишний вес: встроенные миниатюры и приватные данные приложений. PDF остается полностью рабочим: текст можно выделять, ссылки и поля форм продолжают работать.

Hyper Compress скомпилирован в WebAssembly и поставляется вместе с BentoPDF, поэтому сжатие работает офлайн и в изолированных развертываниях без дополнительной настройки.

## Как это работает

1. Загрузите один или несколько PDF, щелкнув по области загрузки или перетащив файлы.
2. Выберите **Уровень сжатия**: Низкий, Средний, Высокий или Без потерь.
3. При желании введите **Целевой размер файла** или раскройте **Пользовательские настройки** для тонкой настройки, включая **Конвертировать в оттенки серого**.
4. Нажмите **Сжатие PDF**. Для нескольких файлов вы получите один ZIP-архив.

## Особые документы

- **PDF с цифровой подписью** возвращаются без изменений, так как любое изменение сделает подпись недействительной. Включите **Игнорировать защиту содержимого** в разделе «Пользовательские настройки», чтобы удалить подписи и сжать файл: видимая подпись останется на странице, но файл больше не будет подписан.
- **Файлы PDF/A** после сжатия теряют метку PDF/A, чтобы файл не заявлял соответствие, которому он больше не отвечает. Включите **Сохранить PDF/A** в разделе «Пользовательские настройки», чтобы сохранить соответствие.
- **PDF, защищенные паролем**, получают поле пароля на карточке файла. Введите пароль там, и Hyper Compress откроет файл сам, без отдельного шага расшифровки. Если заблокированных файлов два и больше, одно общее поле открывает все файлы с одинаковым паролем. У сжатой копии пароля нет; чтобы снова добавить его, используйте [Защита PDF](./protect-pdf).
- **Сканы без текстового слоя** можно сжать сильнее с помощью **Растеризовать страницы в изображения** в разделе «Пользовательские настройки», который заменяет каждую страницу одним оптимизированным изображением. Это пропускается для любого документа с выделяемым текстом, включая сканы с распознанным текстом, если не включено **Игнорировать защиту содержимого**. Тогда текстовые страницы тоже становятся изображениями, текст перестает выделяться, а ссылки перестают работать.

## Уровни сжатия

| Уровень        | Качество изображений   | Макс. разрешение | Лучше всего подходит для             |
| -------------- | ---------------------- | ---------------- | ------------------------------------ |
| **Низкий**     | 80                     | 200 DPI          | Сохранения визуального качества      |
| **Средний**    | 50                     | 150 DPI          | Повседневных документов              |
| **Высокий**    | 20                     | 72 DPI           | Вложений в письма, загрузки на сайты |
| **Без потерь** | Изображения не тронуты | Без изменений    | Архивных копий                       |

Уровень «Высокий» также убирает встраивание 14 стандартных шрифтов PDF и похожих на них, например Arial, если это безопасно.

## Целевой размер файла

Введите размер в КБ или МБ, и Hyper Compress подберет наилучшее качество изображений, при котором файл все еще укладывается в этот размер, начиная с выбранного уровня. Если документ невозможно сжать до такого размера, вы получите самую маленькую версию, которую удалось создать, и сообщение об этом. Специальные страницы, например [Сжать PDF до 1MB](https://www.bentopdf.com/compress-pdf-to-1mb), открываются с уже заполненным целевым размером.

## Пользовательские настройки

Раскройте панель «Пользовательские настройки», чтобы напрямую настроить Hyper Compress. Выбор уровня сжатия сбрасывает эти параметры к значениям этого уровня, а изменение любого из них переключает уровень на «Пользовательский».

- **Игнорировать защиту содержимого**: по умолчанию Hyper Compress не трогает подписанные PDF и не растеризует страницы с текстом. Включение отменяет оба ограничения. Параметр остается включенным при смене уровня.

- **Изображения**: качество изображений, максимальное разрешение, принудительная передискретизация, сокращение цветов, обрезка невидимых областей изображений, удаление альтернативных изображений, упрощение цветовых профилей, JPEG 2000 и режим без потерь
- **Шрифты**: создание подмножеств, объединение дубликатов и отмена встраивания стандартных шрифтов и похожих на них
- **Содержимое**: сведение аннотаций, полей форм или ссылок
- **Очистка**: удаление миниатюр, данных приложений, цепочек статей, информации о веб-захвате, дерева структуры или выходных намерений
- **Растеризовать**: замена страниц изображениями для сканов, состоящих только из изображений; пропускается, если в документе есть выделяемый текст
- **Вывод**: «Сохранить PDF/A» и сжатие Brotli для программ чтения PDF 2.0, которые его поддерживают

## Сценарии использования

- Уменьшение отчета в 50 МБ до лимита вложений электронной почты
- Уменьшение скана до строгого лимита загрузки на портале с помощью целевого размера файла
- Оптимизация маркетинговых PDF для более быстрой загрузки с сайта
- Архивирование больших наборов документов, когда важна стоимость хранения
- Снижение расхода мобильного трафика при отправке PDF через мессенджеры

## Советы

- Начните с уровня «Средний». Если результат все еще слишком большой, задайте целевой размер файла или перейдите на «Высокий».
- Для скана без текстового слоя включите «Растеризовать страницы в изображения» в разделе «Пользовательские настройки».
- Параметр «Конвертировать в оттенки серого» в разделе «Пользовательские настройки» может уменьшить размер документов с большим количеством цветных элементов.

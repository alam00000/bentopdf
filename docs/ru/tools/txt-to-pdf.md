# Текст в PDF

Преобразуйте обычный текст в оформленный PDF. Можно загрузить файлы `.txt` или набрать текст прямо во встроенном редакторе. Поддерживаются несколько шрифтов, произвольные цвета текста и широкий набор размеров страниц: от A0 до A10, а также US Letter, Legal и Tabloid.

## Поддерживаемые форматы

| Ввод                    | Расширения                       |
| :---------------------- | :------------------------------- |
| Обычные текстовые файлы | `.txt`                           |
| Прямой ввод текста      | Наберите или вставьте в редактор |

## Как это работает

1. Выберите режим ввода переключателем вверху: **Загрузить файлы** или **Ввести текст**.
2. При загрузке перетащите или выберите один или несколько файлов `.txt`. При наборе введите текст прямо в текстовое поле.
3. Настройте параметры форматирования: семейство шрифтов, размер шрифта, цвет текста и размер страницы.
4. Нажмите **Создать PDF**. Результат скачивается как `text_to_pdf.pdf`.

При загрузке нескольких файлов их содержимое объединяется, между ними вставляются пустые строки.

## Параметры

| Параметр              | Значения                                                                                 | По умолчанию     |
| :-------------------- | :--------------------------------------------------------------------------------------- | :--------------- |
| **Семейство шрифтов** | Helvetica (без засечек), Tiro (с засечками), Courier (моноширинный), Times (с засечками) | Helvetica        |
| **Размер шрифта**     | 6 -- 72 pt                                                                               | 12               |
| **Цвет текста**       | Любой цвет через палитру                                                                 | Чёрный (#000000) |
| **Размер страницы**   | ISO A0--A10, B0--B10, C0--C10, US Letter, Legal, Tabloid, Ledger, 11x17                  | A4               |

Языки с письмом справа налево (арабский, иврит, персидский, урду) определяются автоматически. Когда найден RTL-текст, направление текста и выравнивание переключаются соответственно.

## Сценарии использования

- Преобразование фрагментов кода и файлов журналов в печатный PDF шрифтом Courier
- Быстрое создание PDF из заметок встречи, набранных на месте
- Оформление текстовой рукописи определённым шрифтом и размером страницы для подачи
- Создание PDF-версии README или журнала изменений для распространения офлайн

## Советы

- Используйте режим **Ввести текст**, когда нужно быстро преобразовать содержимое буфера обмена, не сохраняя его сначала в файл.
- Courier (моноширинный) лучший выбор для кода, журналов и любого содержимого, где важно выравнивание по столбцам.
- Поля страницы фиксированы: 72 пункта (1 дюйм) со всех сторон.

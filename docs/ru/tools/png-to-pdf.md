# PNG в PDF

Преобразуйте изображения PNG в PDF с сохранением полного разрешения. Каждый PNG становится отдельной страницей, размер которой совпадает с размером исходного изображения. Прозрачность обрабатывается автоматически.

## Поддерживаемые форматы

| Формат | Расширения |
| :----- | :--------- |
| PNG    | `.png`     |

## Как это работает

1. Нажмите на область загрузки или перетащите файлы PNG. Можно выбрать сразу несколько.
2. Управляйте списком файлов: удаляйте лишние или добавляйте новые.
3. Выберите уровень **Качество PDF** в выпадающем списке.
4. Нажмите **Конвертировать в PDF**. Результат скачается как `from_jpgs.pdf`.

Инструмент использует pdf-lib, чтобы встроить каждое изображение напрямую. Если PNG нельзя встроить как есть (например, из-за необычного цветового профиля), он перерисовывается через canvas и сохраняется как JPEG.

## Параметры

**Качество PDF** определяет сжатие, применяемое перед встраиванием:

- **Высокое качество**: минимальное сжатие, самый большой размер файла.
- **Среднее качество** (по умолчанию): хороший баланс размера и чёткости.
- **Низкое качество**: максимальное сжатие, самый маленький результат.

## Сценарии использования

- Преобразование скриншотов в многостраничный PDF для отчётов об ошибках и документации
- Упаковка экспортированных макетов интерфейса в один файл для согласования
- Превращение экспорта диаграмм (draw.io, Excalidraw) в PDF, которым удобно делиться
- Сборка набора изображений графиков в отчёт

## Советы

- У PNG с прозрачностью в PDF будет белый фон. Если нужен другой фон, отредактируйте изображения заранее.
- Для скриншотов и схем с чёткими краями и текстом вариант «Высокое качество» позволяет избежать артефактов сжатия JPEG. При среднем или низком качестве изображение может внутри преобразоваться в JPEG.

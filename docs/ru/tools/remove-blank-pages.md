# Удаление пустых страниц

Просканируйте PDF на пустые и почти пустые страницы и удалите их автоматически. Инструмент отрисовывает каждую страницу и анализирует её пиксели, чтобы определить, пуста ли она, а затем позволяет подтвердить, какие страницы удалить.

## Как это работает

1. Загрузите PDF-файл.
2. Настройте ползунок **Чувствительность**, определяющий, насколько строго понимается «пустая» страница.
3. Нажмите **Найти пустые страницы**, чтобы просканировать документ.
4. Инструмент покажет миниатюры найденных пустых страниц для проверки.
5. Подтвердите выбор и скачайте очищенный PDF без пустых страниц.

## Параметры

- **Чувствительность**: ползунок от 0% до 100% (по умолчанию 80%). Высокие значения строже и отмечают только полностью или почти белые страницы. Низкие значения мягче и находят страницы с минимальным содержимым, например с одной точкой или бледным водяным знаком.

## Возможности

- Попиксельный анализ каждой страницы для выявления пустого содержимого
- Настраиваемый ползунок чувствительности для тонкой подстройки
- Миниатюры найденных пустых страниц для ручной проверки
- Все непустые страницы сохраняются без изменений
- Работает с документами любого размера и числа страниц
- Индикатор хода сканирования

## Сценарии использования

- Очистка отсканированных документов, в которых сканер захватил пустые оборотные стороны односторонних оригиналов
- Удаление разделительных страниц из пакетов сканирования
- Удаление пустых страниц, добавленных системами управления документами
- Очистка PDF, экспортированных из текстовых редакторов, которые иногда добавляют пустые страницы в конце
- Уменьшение размера файла за счёт удаления ненужных пустых страниц

## Советы

- Начните с чувствительности по умолчанию 80% и корректируйте от неё. Если инструмент пропускает страницы, которые вам кажутся пустыми, снизьте чувствительность. Если он отмечает страницы с лёгким содержимым, которое нужно сохранить, повысьте её.
- Инструмент отрисовывает каждую страницу для анализа, поэтому время обработки растёт с числом страниц. Для очень больших документов придётся немного подождать.
- Проверьте найденные пустые страницы в миниатюрах перед подтверждением удаления. Страницы с бледными колонтитулами или водяными знаками могут быть отмечены в зависимости от чувствительности.

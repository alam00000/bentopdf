# PDF в WebP

Преобразует каждую страницу PDF в изображение WebP. WebP обычно даёт файлы на 25-35% меньше, чем JPG, при том же воспринимаемом качестве, что делает его хорошим выбором для веба.

## Как это работает

1. Загрузите PDF, нажав на область загрузки или перетащив файл.
2. Настройте ползунок **Качество изображения**.
3. Нажмите **Конвертировать**, чтобы обработать файл.
4. Автоматически скачается один файл `.webp` или ZIP-архив.

## Параметры

- **Качество изображения**: ползунок от 0% до 100% (по умолчанию 85%). Управляет уровнем сжатия с потерями. Большие значения сохраняют больше деталей.

Внутри страницы рендерятся в масштабе 2x, поэтому размер изображений примерно вдвое больше исходных размеров PDF.

## Формат результата

- **Одна страница**: `filename.webp`
- **Несколько страниц**: `filename_webps.zip` с файлами `page_1.webp`, `page_2.webp` и так далее.

## Сценарии использования

- Подготовка превью страниц для сайтов, где важен трафик.
- Создание лёгких изображений листовок и брошюр для соцсетей.
- Пакетная конвертация многостраничных документов в набор изображений, оптимизированных для веба.

## Советы

- WebP поддерживается во всех современных браузерах. Для совместимости со старыми используйте [PDF в JPG](./pdf-to-jpg).
- Качество 80-85% обычно неотличимо от оригинала на экране, а размер файлов остаётся небольшим.

# PDF в CBZ

Преобразует PDF в файл CBZ (Comic Book ZIP), стандартный формат цифровых комиксов и манги. Каждая страница PDF становится изображением внутри архива. Для максимальной совместимости инструмент создаёт метаданные в трёх форматах: ComicInfo.xml, metadata.opf и ComicBookInfo JSON.

## Как это работает

1. Загрузите PDF, нажав на область загрузки или перетащив файл.
2. Выберите формат изображений, качество, масштаб и при желании метаданные.
3. Нажмите **Конвертировать**, чтобы создать файл CBZ.
4. Файл `.cbz` скачается автоматически.

## Параметры

| Параметр             | Значения        | По умолчанию | Описание                                                                                    |
| -------------------- | --------------- | ------------ | ------------------------------------------------------------------------------------------- |
| Формат изображения   | JPEG, PNG, WebP | JPEG         | JPEG для цветных комиксов, PNG для чёрно-белой манги без потерь, WebP для лучшего сжатия.   |
| Качество изображения | 50–100%         | 85%          | Степень сжатия JPEG/WebP. Для PNG скрыт (всегда без потерь).                                |
| Масштаб              | 1.0x–4.0x       | 2.0x         | Больший масштаб даёт более чёткие изображения для экранов с высоким разрешением.            |
| Оттенки серого       | Вкл/Выкл        | Выкл         | Преобразует страницы в оттенки серого. Уменьшает размер файла для чёрно-белого содержимого. |
| Режим манги          | Вкл/Выкл        | Выкл         | Задаёт в метаданных направление чтения справа налево.                                       |
| Включить метаданные  | Вкл/Выкл        | Вкл          | Встраивает ComicInfo.xml, metadata.opf и ComicBookInfo JSON.                                |

## Поля метаданных

Когда метаданные включены, можно заполнить:

- **Название**: определяется автоматически по имени PDF-файла.
- **Серия**: название серии (например, "Naruto").
- **Номер (#)**: номер выпуска в серии.
- **Том**: номер тома.
- **Автор(ы)**: имя автора или создателя.
- **Издатель**: издательство.
- **Теги / Жанр**: теги через запятую (например, "Action, Adventure").
- **Год издания**: год публикации (1900–2100).
- **Рейтинг**: оценка сообщества от 0 до 5.

## Совместимость метаданных

Инструмент записывает метаданные в трёх форматах, чтобы любая программа чтения могла их найти:

| Формат             | Расположение         | Поддерживается в                            |
| ------------------ | -------------------- | ------------------------------------------- |
| ComicInfo.xml      | Файл внутри ZIP      | Komga, Kavita, CDisplayEx, Mylar, ComicRack |
| metadata.opf       | Файл внутри ZIP      | Calibre                                     |
| ComicBookInfo JSON | Поле комментария ZIP | Calibre (запасной вариант)                  |

## Формат результата

- `filename.cbz`: ZIP-архив с пронумерованными изображениями страниц и файлами метаданных.

Изображения страниц называются с числами с ведущими нулями (`01.jpg`, `02.jpg` и так далее), чтобы программы чтения показывали их в правильном порядке.

## Сценарии использования

- Конвертация PDF с мангой и комиксами для программ чтения комиксов.
- Создание цифровой библиотеки комиксов в Komga, Kavita или Calibre.
- Преобразование отсканированных комиксов в удобный для чтения формат.
- Обмен комиксами в формате, который сохраняет направление чтения и метаданные.

## Советы

- Используйте **JPEG** для цветных комиксов и **PNG** для чёрно-белой манги: PNG очень эффективно сжимает чёрно-белое содержимое.
- Включите **Конвертировать в оттенки серого** для манги, чтобы заметно уменьшить размер файла.
- Заполните поля **Серия** и **Номер (#)**, чтобы менеджеры библиотек (Komga, Calibre) могли автоматически упорядочить вашу коллекцию.
- **WebP** даёт лучшее сжатие, но старые программы чтения комиксов могут его не поддерживать.

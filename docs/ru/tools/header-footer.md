# Колонтитулы

Добавляйте текст в шесть позиций на страницах PDF: верхний левый, верхний по центру, верхний правый, нижний левый, нижний по центру и нижний правый. Инструмент поддерживает динамические переменные номера страницы и общего числа страниц, поэтому можно создавать шаблоны вроде «Страница 3 из 10», которые автоматически обновляются на каждой странице.

## Как это работает

1. Загрузите файл PDF.
2. Появится панель параметров с элементами форматирования и шестью полями ввода текста.
3. Введите нужный текст в любую из позиций колонтитулов.
4. Используйте заполнители `{page}` и `{total}` для динамической нумерации страниц.
5. Настройте размер и цвет шрифта и при желании ограничьте диапазон страниц.
6. Нажмите **Добавить колонтитулы**, чтобы обработать файл и скачать результат.

## Параметры

- **Диапазон страниц**: при желании ограничьте, на каких страницах будут колонтитулы. Оставьте поле пустым, чтобы применить ко всем страницам. Формат: «1-3, 5» (диапазоны через запятую).
- **Размер шрифта**: от 6 до 24 пунктов. По умолчанию 10.
- **Цвет шрифта**: выберите любой цвет с помощью палитры.
- **Верхний левый / по центру / правый**: текстовые поля для верхней части каждой страницы.
- **Нижний левый / по центру / правый**: текстовые поля для нижней части каждой страницы.

## Возможности

- Шесть независимых позиций текста на странице
- Динамическая переменная `{page}`, которая вставляет номер текущей страницы
- Динамическая переменная `{total}`, которая вставляет общее число страниц
- Фильтрация по диапазону страниц для выбора нужных страниц
- Настраиваемые размер и цвет шрифта
- Шрифт Helvetica для аккуратного, профессионального результата

## Сценарии использования

- Добавление «Страница {page} из {total}» в нижний колонтитул по центру отчёта
- Размещение названия компании в верхнем левом колонтитуле и даты документа в верхнем правом
- Добавление уведомлений о конфиденциальности в нижний колонтитул юридических документов
- Проставление номеров редакций документа на определённых диапазонах страниц

## Советы

- Объединяйте `{page}` и `{total}` в одном поле для форматов вроде «Страница {page} из {total}» или «{page}/{total}».
- Большинство полей можно оставить пустыми и заполнить только нужные позиции. Пустые поля просто пропускаются.
- Для более сложных колонтитулов с изображениями или логотипами попробуйте инструмент [Добавление водяных знаков](./add-watermark), разместив знак в верхней части страницы.

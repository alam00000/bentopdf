# N-Up PDF

Размещайте несколько страниц на одном листе в виде сетки. Это сокращает число печатаемых листов: на каждый лист помещается 2, 4, 6, 8, 9 или 16 страниц. Инструмент сам масштабирует и размещает страницы, а размер страницы можно настроить.

## Как это работает

1. Загрузите файл PDF.
2. Выберите число страниц на листе (значение «N»): 2, 4, 6, 8, 9 или 16.
3. Выберите размер страницы результата (по умолчанию A4) и ориентацию.
4. При желании настройте интервал, цвет границ и цвет фона.
5. Нажмите кнопку обработки. Инструмент масштабирует каждую страницу и размещает их плиткой на новых листах.

## Возможности

- Макеты сетки: 2, 4, 6, 8, 9 и 16 страниц на листе
- Настраиваемые размер и ориентация страницы результата
- Необязательный интервал между страницами
- Настройки цвета фона и границ
- Сохраняет пропорции исходных страниц при масштабировании

## Параметры

| Параметр             | Описание                                                                 |
| -------------------- | ------------------------------------------------------------------------ |
| **Страниц на листе** | Число исходных страниц на каждой странице результата (2, 4, 6, 8, 9, 16) |
| **Размер страницы**  | Размер выходного листа (A4, Letter, Legal и другие)                      |
| **Ориентация**       | Книжная или альбомная для выходного листа                                |
| **Интервал**         | Промежуток между страницами в пунктах                                    |
| **Цвет фона**        | Цвет заливки фона выходного листа                                        |
| **Цвет границы**     | Цвет границ вокруг каждой страницы                                       |

## Сценарии использования

- Печать раздаточных материалов по 4 слайда на странице для экономии бумаги
- Создание шпаргалок с несколькими справочными страницами на одном листе
- Подготовка компактных архивов документов для подшивки
- Создание листов-обзоров с миниатюрами длинного документа

## Советы

- Альбомная ориентация часто лучше подходит для макета по 2 страницы, а книжная обычно лучше для 4 и более.
- Увеличение интервала улучшает читаемость, но уменьшает область для каждой страницы.
- Для обратной операции (разделения одной страницы на несколько) см. [Постеризация документа](./posterize-pdf).

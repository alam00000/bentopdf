# CBZ в PDF

Превращайте архивы комиксов в PDF. CBZ и CBR являются стандартными форматами цифровых комиксов: это обычные архивы ZIP или RAR с изображениями. Инструмент извлекает каждую страницу, сохраняет порядок чтения и создает аккуратный PDF, где каждое изображение становится страницей полного размера.

## Поддерживаемые форматы

| Формат | Расширение | Примечания                                                          |
| :----- | :--------- | :------------------------------------------------------------------ |
| CBZ    | `.cbz`     | Архив комикса на основе ZIP (обрабатывается локально через pdf-lib) |
| CBR    | `.cbr`     | Архив комикса на основе RAR (обрабатывается движком PyMuPDF)        |

Конвертер CBZ распознает изображения JPEG, PNG, GIF, BMP, WebP, AVIF, TIFF, HEIC и JXL внутри архива. Нестандартные форматы перед встраиванием автоматически преобразуются в PNG.

## Как это работает

1. Щелкните по области загрузки или перетащите в нее файлы CBZ или CBR. В одной партии можно смешивать оба формата.
2. Проверьте список файлов. Удалите ненужные или нажмите **Добавить еще файлы**, чтобы добавить еще.
3. Нажмите **Преобразовать в PDF**. Для файлов CBZ инструмент распаковывает архив, сортирует изображения по имени в естественном порядке, определяет реальный формат каждого изображения и встраивает их в PDF с помощью pdf-lib. Файлы CBR обрабатываются движком PyMuPDF.
4. Один файл скачивается как PDF. Несколько файлов дают ZIP-архив с именем `comic-converted.zip`.

## Параметры

Настройка не требуется. Каждое изображение становится страницей того же размера, что и оригинал, поэтому развороты остаются широкими, а одиночные страницы узкими.

## Сценарии использования

- Чтение комиксов на планшете или в приложении для телефона, которое поддерживает PDF, но не CBZ/CBR
- Печать отдельных страниц цифрового комикса
- Архивирование коллекции комиксов в формат, который откроет любой просмотрщик
- Передача комикса тому, у кого нет специальной программы для чтения комиксов

## Советы

- Изображения внутри архива сортируются в естественном порядке (так что `page2.jpg` идет раньше `page10.jpg`). Нумеруйте файлы единообразно, чтобы страницы шли в правильной последовательности.
- Конвертер определяет формат изображений по двоичным сигнатурам, а не по расширениям. PNG, случайно названный `.jpg`, все равно будет встроен правильно.
- Файлы CBZ обрабатываются полностью в браузере без загрузки движка PyMuPDF, поэтому конвертируются быстрее, чем CBR.

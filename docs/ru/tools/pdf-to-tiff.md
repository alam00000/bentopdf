# PDF в TIFF

Преобразует каждую страницу PDF в изображение TIFF. TIFF - стандартный формат для полиграфии, факсимильных систем и архивного хранения документов. Для кодирования TIFF инструмент использует сжатие PackBits, а при ошибке кодирования страницы сохраняет её как PNG.

## Как это работает

1. Загрузите PDF, нажав на область загрузки или перетащив файл.
2. Нажмите **Конвертировать**, чтобы обработать файл.
3. Автоматически скачается один файл TIFF или ZIP-архив.

## Параметры

Настраиваемых параметров нет. Страницы рендерятся в фиксированном масштабе 2x.

## Формат результата

- **Одна страница**: `filename.tiff`
- **Несколько страниц**: `filename_tiffs.zip` с файлами `page_1.tiff`, `page_2.tiff` и так далее.

Если кодирование TIFF для конкретной страницы не удалось (из-за проблем со сжатием), эта страница сохраняется как файл `.png`. В таком случае в ZIP будет смесь файлов TIFF и PNG.

## Сценарии использования

- Подача документов в государственные органы и юридические системы, требующие формат TIFF.
- Подготовка страниц для отправки по факсу через цифровые факс-сервисы.
- Архивирование отсканированных документов в широко поддерживаемом формате без потерь.
- Передача страниц в корпоративные системы управления документами.

## Советы

- Файлы TIFF большие. Если качество без потерь нужно только для веба или экрана, лучше подойдёт [PDF в PNG](./pdf-to-png).
- Проверьте содержимое ZIP, если для некоторых страниц понадобился запасной PNG: возможно, их стоит сконвертировать отдельно.

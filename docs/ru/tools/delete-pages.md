# Удаление страниц

Удаляйте ненужные страницы из PDF-документа. Укажите страницы для удаления, введя номера или диапазоны, или щелкайте по миниатюрам страниц, чтобы отметить их.

## Как это работает

1. Загрузите PDF-файл. Инструмент отобразит миниатюры всех страниц.
2. Введите страницы для удаления в текстовое поле с синтаксисом диапазонов (например, `2, 5-8`) или щелкайте по миниатюрам, чтобы переключать выбор.
3. Отмеченные страницы выделяются, чтобы вы могли проверить выбор.
4. Нажмите кнопку обработки. Будет создан новый PDF без выбранных страниц.

## Возможности

- Выбор страниц текстом с синтаксисом диапазонов (`2, 5-8, 12`)
- Визуальная сетка миниатюр для удаления щелчком
- Подсветка страниц, отмеченных для удаления, в реальном времени
- Проверка ввода по фактическому числу страниц
- Все оставшиеся страницы сохраняют исходный порядок

## Сценарии использования

- Удаление пустых или заполняющих страниц из отсканированного документа
- Удаление титульных страниц или приложений перед передачей документа
- Очистка черновых страниц, случайно оставшихся в итоговом PDF
- Удаление страниц с конфиденциальной информацией перед распространением

## Советы

- Удаление страниц не влияет на содержимое и оформление остальных страниц. Результат является точной копией оригинала без удаленных страниц.
- Если вам нужно оставить только определенные страницы, а не удалить определенные, лучше подойдет [Извлечение страниц](./extract-pages).
- Миниатюры загружаются лениво, поэтому с большими документами интерфейс остается отзывчивым.

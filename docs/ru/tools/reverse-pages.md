# Обращение порядка страниц

Переверните порядок страниц PDF: последняя страница станет первой, предпоследняя второй и так далее. Поддерживается пакетная обработка нескольких файлов сразу.

## Как это работает

1. Загрузите один или несколько PDF-файлов.
2. Нажмите кнопку обработки.
3. Каждый файл обращается независимо. Если вы загрузили несколько файлов, результатом будет ZIP-архив со всеми обращёнными PDF.
4. Один файл скачивается сразу как PDF с обращённым порядком страниц.

## Возможности

- Пакетная обработка: обращение нескольких PDF за одну операцию
- Один PDF на выходе для одного файла, ZIP для нескольких
- Кнопки удаления отдельных файлов перед обработкой
- Всё содержимое страниц и форматирование сохраняются

## Сценарии использования

- Исправление документа, отсканированного в обратном порядке
- Подготовка PDF-презентации для чтения с конца к началу
- Обращение порядка страниц для печати, при которой страницы подаются в обратном порядке
- Исправление документа, страницы которого случайно собрали задом наперёд

## Советы

- Каждый файл в пакете обращается независимо: сами файлы относительно друг друга не переставляются.
- Для более гибкой перестановки страниц (не только полного обращения) используйте [Дублирование и организация](./organize-pdf).

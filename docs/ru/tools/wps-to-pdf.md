# WPS в PDF

Конвертируйте файлы текстового редактора Microsoft Works в PDF. Microsoft Works шёл в комплекте с домашними компьютерами в конце 1990-х и 2000-х, и множество файлов WPS до сих пор лежит на старых жёстких дисках и в архивах почты. Этот инструмент открывает их в браузере и создаёт аккуратные PDF.

## Поддерживаемые форматы

| Формат          | Расширение | Примечания                                    |
| :-------------- | :--------- | :-------------------------------------------- |
| Microsoft Works | `.wps`     | Файлы текстового редактора из Microsoft Works |

## Как это работает

1. Нажмите на область загрузки или перетащите файлы WPS. Можно загружать несколько файлов.
2. Проверьте список файлов. Значком корзины удаляйте отдельные файлы или нажмите **Добавить еще файлы**, чтобы расширить пакет.
3. Нажмите **Преобразовать в PDF**. В браузере загружается движок на основе LibreOffice и конвертирует каждый документ WPS в PDF.
4. Один файл скачивается сразу как PDF. Несколько файлов упаковываются в ZIP-архив `wps-to-pdf.zip`.

## Параметры

Дополнительные настройки не нужны. Конвертер обрабатывает текст, базовое форматирование и встроенные изображения из файла WPS.

## Сценарии использования

- Восстановить старые учебные или рабочие документы, сохранённые в формате Microsoft Works
- Открыть вложения WPS из почты, если Microsoft Works не установлен
- Конвертировать архив файлов WPS для переноса в современную систему документооборота
- Распечатать старые документы, которые современные текстовые редакторы не открывают

## Советы

- Не путайте файлы Microsoft Works `.wps` с файлами WPS Office. Этот инструмент предназначен именно для старого формата Microsoft Works.
- Движок LibreOffice загружается при первом использовании не мгновенно. После загрузки последующие конвертации в том же сеансе выполняются быстрее.

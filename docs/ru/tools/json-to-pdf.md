# JSON в PDF

Восстанавливайте документы PDF из файлов JSON, ранее созданных инструментом **PDF в JSON** от BentoPDF. Это инструмент обратного преобразования: он берёт структурированное JSON-представление PDF и собирает исходный документ заново.

::: warning
Этот инструмент принимает только файлы JSON, созданные конвертером PDF в JSON от BentoPDF. Обычные файлы JSON из API, баз данных и других инструментов не поддерживаются.
:::

## Поддерживаемые форматы

| Вход    | Описание                                                         |
| :------ | :--------------------------------------------------------------- |
| `.json` | Файлы JSON, экспортированные инструментом PDF в JSON от BentoPDF |

## Как это работает

1. Нажмите на область загрузки или перетащите в неё один или несколько файлов JSON.
2. В списке файлов показан каждый выбранный файл с его размером.
3. Нажмите **Преобразовать в PDF**. Инструмент обрабатывает все файлы с помощью Web Worker и движка CPDF.
4. Результат скачивается как `jsons-to-pdf.zip` и содержит по одному PDF на каждый входной файл JSON.

Преобразование выполняется в фоновом Web Worker, поэтому интерфейс остаётся отзывчивым даже с большими файлами.

## Параметры

У этого инструмента нет настраиваемых параметров. Итоговый PDF полностью определяется структурой JSON.

## Результат

При преобразовании нескольких файлов JSON результаты поставляются в ZIP-архиве. Каждый PDF называется по исходному файлу JSON (например, `report.json` превращается в `report.pdf`).

## Сценарии использования

- Восстановление PDF из резервной копии или архивного конвейера на основе JSON
- Прогон PDF через JSON для проверки и обратно в PDF
- Пересборка документов после программных изменений структуры JSON
- Проверка того, что экспорт PDF в JSON сохранил всё содержимое документа, путём обратного преобразования

## Советы

- Если нужно преобразовать произвольные данные JSON (например, ответы API или файлы конфигурации) в отформатированный PDF, лучше подходит инструмент [Текст в PDF](./txt-to-pdf). Вставьте JSON как текст, и он будет отображён с правильным форматированием.
- Для работы этого инструмента должен быть доступен движок CPDF WebAssembly. На самостоятельно размещённых экземплярах нужно настроить файлы CPDF WASM.

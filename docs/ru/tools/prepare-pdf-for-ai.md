# Подготовка PDF для ИИ

Извлекает содержимое PDF-файлов и структурирует его в JSON, оптимизированный для загрузки в большие языковые модели (LLM) и ИИ-фреймворки вроде LlamaIndex. Содержимое каждой страницы извлекается и организуется в структурированный формат, готовый для RAG-конвейеров, чат-ботов и систем семантического поиска.

## Как это работает

1. Загрузите один или несколько PDF, нажав на область загрузки или перетащив файлы.
2. Нажмите **Извлечь для ИИ**, чтобы начать обработку.
3. Один файл скачивается как `filename_llm.json`. Несколько файлов дают архив `pdf-for-ai.zip`.

Инструмент использует интеграцию PyMuPDF с LlamaIndex, чтобы извлекать содержимое постранично вместе с метаданными. Результат можно напрямую загружать в ИИ-фреймворки.

## Параметры

У этого инструмента нет настраиваемых параметров. Все страницы извлекаются с полным текстом и метаданными.

## Формат результата

- **Один файл**: `filename_llm.json`
- **Несколько файлов**: `pdf-for-ai.zip` с одним `_llm.json` на каждый исходный PDF.

JSON соответствует схеме документов LlamaIndex: текст каждой страницы и поля метаданных.

## Сценарии использования

- Подготовка PDF-документов для конвейеров RAG (генерация с дополнением выборкой).
- Создание базы знаний с поиском по архивам PDF для ИИ-чат-бота.
- Передача PDF-отчётов в процессы анализа на основе LLM.
- Предварительная обработка научных статей для семантического поиска и систем вопросов и ответов.
- Создание структурированных обучающих данных из коллекций PDF-документов.

## Советы

- Для извлечения простого текста без ИИ-форматирования используйте [PDF в текст](./pdf-to-text).
- Для вывода в Markdown с сохранением заголовков и структуры используйте [PDF в Markdown](./pdf-to-markdown).
- Для отсканированных PDF результат будет пустым или минимальным. Сначала пропустите их через распознавание текста, чтобы добавить текстовый слой.

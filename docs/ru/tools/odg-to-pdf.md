# ODG в PDF

Преобразуйте файлы OpenDocument Graphics в PDF. ODG - родной формат LibreOffice Draw, который используется для диаграмм, блок-схем и векторных иллюстраций. PDF упрощает обмен такими рисунками, их печать и встраивание в другие документы.

## Поддерживаемые форматы

| Формат                | Расширение | Примечания                               |
| :-------------------- | :--------- | :--------------------------------------- |
| OpenDocument Graphics | `.odg`     | Файлы LibreOffice Draw / OpenOffice Draw |

## Как это работает

1. Нажмите на область загрузки или перетащите в неё файлы ODG. Можно добавить сразу несколько файлов.
2. Просмотрите список файлов. Значок корзины удаляет отдельные записи, а **Добавить ещё файлы** добавляет другие рисунки.
3. Нажмите **Преобразовать в PDF**. В браузере загружается движок на основе LibreOffice и преобразует каждый файл ODG, сохраняя векторную графику, фигуры и текст.
4. Один файл скачивается сразу как PDF. Несколько файлов создают ZIP-архив `odg-to-pdf.zip`.

## Параметры

Дополнительные настройки не нужны. При преобразовании сохраняются исходные размеры страницы, фигуры, соединители и текстовые блоки из файла ODG.

## Сценарии использования

- Передача диаграмм LibreOffice Draw клиентам, у которых не установлен LibreOffice
- Печать блок-схем и сетевых диаграмм, созданных в Draw
- Включение иллюстраций ODG в отчёт или презентацию в виде встроенных PDF
- Архивирование технических чертежей в формате, который останется читаемым десятилетиями

## Советы

- Векторные элементы остаются векторными в итоговом PDF, поэтому результат чётко масштабируется для печати любого размера.
- При первом использовании движку LibreOffice нужно время на запуск. Последующие преобразования в том же сеансе выполняются быстрее.

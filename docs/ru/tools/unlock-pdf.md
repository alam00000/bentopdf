# Разблокировка PDF

Если у вас есть пароль к зашифрованному PDF, этот инструмент полностью снимает шифрование и создаёт разблокированную копию, которую можно открыть без пароля. Если у нескольких PDF один и тот же пароль, их можно расшифровать пакетом.

## Как это работает

1. Загрузите один или несколько зашифрованных PDF-файлов.
2. Введите **пароль**, которым защищены файлы.
3. Нажмите **Расшифровка документа**.
4. Один файл скачивается сразу. Если файлов несколько, вы получите ZIP-архив со всеми разблокированными PDF.

## Возможности

- Расшифровка одного файла и пакетная расшифровка
- Работает как с паролями пользователя, так и с паролями владельца
- Результат полностью не зашифрован и не содержит остаточных ограничений
- Понятные сообщения об ошибках при неверном пароле или повреждённых файлах
- Учёт успеха и ошибок по каждому файлу в пакетном режиме

## Чем это отличается от снятия ограничений

**Разблокировка PDF** требует пароль и снимает всё шифрование. **Снятие ограничений** убирает ограничения на использование (печать, копирование, редактирование) и может не требовать пароля, если задан только пароль владельца. Используйте расшифровку, когда PDF вообще не открывается без пароля.

## Сценарии использования

- Окончательно разблокировать PDF, которые вы зашифровали раньше, если пароль больше не нужен
- Снять шифрование с пакета архивных документов для удобного долгосрочного доступа
- Подготовить защищённые паролем PDF для системы документооборота, которая не поддерживает зашифрованные файлы
- Разблокировать PDF перед объединением с другими документами (многие инструменты объединения не работают с зашифрованными файлами)

## Советы

- Поле пароля применяется ко всем загруженным файлам. Если у ваших PDF разные пароли, обрабатывайте их отдельными пакетами.
- Если появляется ошибка «Неверный пароль», проверьте, нет ли лишних пробелов в конце и не включён ли Caps Lock.
- После расшифровки файл остаётся без защиты. Если нужен новый пароль, зашифруйте файл снова через «Защита PDF».

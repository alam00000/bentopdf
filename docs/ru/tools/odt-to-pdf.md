# ODT в PDF

Преобразуйте файлы OpenDocument Text в PDF. ODT - родной формат LibreOffice Writer, Apache OpenOffice и других открытых текстовых редакторов. Инструмент использует браузерный движок LibreOffice и точно сохраняет форматирование, таблицы, изображения и стили.

## Поддерживаемые форматы

| Формат            | Расширения |
| :---------------- | :--------- |
| OpenDocument Text | `.odt`     |

## Как это работает

1. Нажмите на область загрузки или перетащите один или несколько ODT-файлов.
2. Проверьте список файлов. Добавьте ещё или удалите лишние.
3. Нажмите **Конвертировать в PDF**. Движок LibreOffice инициализируется (индикатор показывает ход загрузки), затем конвертируется каждый файл.
4. Один файл скачивается сразу как PDF. Несколько файлов упаковываются в `odt-converted.zip`.

## Параметры

Дополнительных настроек нет. При конвертации форматирование исходного документа сохраняется максимально близко к оригиналу.

## Результат

| Количество файлов | Результат                                                  |
| :---------------- | :--------------------------------------------------------- |
| 1 файл            | Скачивается один PDF (например, `document.pdf`)            |
| 2 и более         | ZIP-архив (`odt-converted.zip`) с одним PDF на каждый файл |

## Сценарии использования

- Конвертация документов LibreOffice Writer в PDF для пользователей Microsoft Office
- Подготовка PDF для печати из научных работ в формате OpenDocument
- Пакетная конвертация папки шаблонов ODT в PDF для рассылки
- Получение PDF из ODT-файлов, созданных системами автоматической генерации документов

## Советы

- Движок LibreOffice загружается при первом использовании и кэшируется для следующих конвертаций. Первая загрузка занимает несколько секунд, потом конвертация проходит быстро.
- Сложные документы со встроенными OLE-объектами или необычными шрифтами могут выглядеть немного иначе, чем в настольном LibreOffice. Перед пакетной конвертацией проверьте на образце.
- Для документов Word (`.doc`, `.docx`) используйте инструмент [Word в PDF](./word-to-pdf): он тоже работает на движке LibreOffice, но напрямую принимает форматы Microsoft.

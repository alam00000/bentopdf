# Изменение разрешений

Гибко настройте, что получатели могут делать с вашим PDF. В отличие от обычного шифрования, которое просто закрывает файл паролем, этот инструмент позволяет выборочно разрешать или запрещать печать, копирование, редактирование, аннотирование, заполнение форм, сборку документа и извлечение страниц. Все ограничения обеспечиваются 256-битным шифрованием AES.

## Как это работает

1. Загрузите PDF-файл.
2. Если PDF уже зашифрован, введите **Текущий пароль**.
3. Задайте **Новый пароль пользователя** (нужен для открытия) и/или **Новый пароль владельца** (управляет разрешениями).
4. Включайте и отключайте отдельные разрешения с помощью флажков.
5. Нажмите **Изменение разрешений**.
6. Скачайте обновленный PDF.

Если оставить оба поля нового пароля пустыми, инструмент полностью расшифрует PDF, сняв все шифрование и ограничения.

## Управление разрешениями

| Разрешение                       | Что оно контролирует                                |
| -------------------------------- | --------------------------------------------------- |
| **Разрешить печать**             | Можно ли печатать документ                          |
| **Разрешить копирование текста** | Можно ли выделять и копировать текст и изображения  |
| **Разрешить изменение**          | Можно ли редактировать содержимое документа         |
| **Разрешить аннотирование**      | Можно ли добавлять комментарии, выделения и штампы  |
| **Разрешить заполнение форм**    | Можно ли заполнять интерактивные поля форм          |
| **Разрешить сборку документа**   | Можно ли вставлять, удалять и поворачивать страницы |
| **Разрешить извлечение страниц** | Можно ли извлекать отдельные страницы               |

Для работы любых разрешений необходим пароль владельца. Без пароля владельца флаги разрешений игнорируются большинством программ для чтения PDF.

## Как работают разрешения в PDF

Разрешения PDF входят в спецификацию шифрования. Они хранятся как битовые флаги в словаре шифрования, и их соблюдают совместимые программы для чтения PDF. Главное различие:

- **Пароль пользователя**: нужен, чтобы вообще открыть файл.
- **Пароль владельца**: нужен, чтобы изменить разрешения или снять ограничения. Без него флаги разрешений определяют, какие операции доступны пользователю.

Если задать только пароль владельца (без пароля пользователя), файл сможет открыть любой, но ему будут доступны только разрешенные операции. Если задать оба пароля, для открытия файла потребуется пароль, а после аутентификации действуют ограничения.

## Сценарии использования

- Рассылка отчета, который можно смотреть и печатать, но нельзя редактировать и копировать
- Передача шаблона договора, который получатели могут заполнить, но не изменить
- Публикация PDF-каталога с отключенным копированием изображений
- Разрешение аннотировать черновик для рецензирования при запрете структурных изменений

## Советы

- Чтобы защита работала, всегда задавайте пароль владельца. Разрешения без пароля владельца невозможно обеспечить.
- Некоторые сторонние PDF-инструменты игнорируют флаги разрешений. Для более надежной защиты рассмотрите растеризацию PDF или DRM.
- Используйте этот инструмент, чтобы обновить старые PDF с шифрованием RC4 до AES-256.

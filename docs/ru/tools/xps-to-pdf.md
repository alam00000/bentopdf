# XPS в PDF

Конвертируйте документы Microsoft XPS и OXPS в обычные PDF-файлы. XPS (XML Paper Specification) был ответом Microsoft на PDF, но поддержка этого формата на разных платформах сошла на нет. Этот инструмент снова делает такие документы доступными для всех.

## Поддерживаемые форматы

| Формат | Расширение | Примечания                           |
| :----- | :--------- | :----------------------------------- |
| XPS    | `.xps`     | Исходный формат Microsoft XPS        |
| OXPS   | `.oxps`    | Open XPS, вариант стандарта ECMA-388 |

## Как это работает

1. Нажмите на область загрузки или перетащите файлы XPS/OXPS. Можно выбрать сразу несколько файлов.
2. Проверьте список файлов. Удаляйте отдельные файлы значком корзины или нажмите **Добавить еще файлы**, чтобы добавить документы.
3. Нажмите **Преобразовать в PDF**. Движок PyMuPDF обрабатывает каждый документ локально в вашем браузере.
4. Один файл скачивается сразу как PDF. Несколько файлов упаковываются в ZIP-архив `xps-converted.zip`.

## Параметры

Этот инструмент выполняет прямую конвертацию формата без дополнительных настроек. Результат сохраняет исходные размеры страниц, векторную графику, шрифты и изображения из файла XPS.

## Сценарии использования

- Открыть файлы XPS, полученные из старых систем Windows, где драйвер печати XPS был выбран по умолчанию
- Конвертировать документы OXPS из Windows 10/11 для отправки пользователям macOS или Linux
- Архивировать старые файлы XPS в более широко поддерживаемом формате
- Сделать документы государственных организаций и компаний в формате XPS доступными для внешних получателей

## Советы

- Расширения `.xps` и `.oxps` обрабатываются автоматически, поэтому их можно смешивать в одном пакете.
- Если исходный файл XPS был создан драйвером печати с высоким разрешением, итоговый PDF сохраняет это качество. Передискретизации не происходит.

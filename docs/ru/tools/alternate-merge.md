# Объединение документов с чередованием страниц

Чередуйте страницы нескольких PDF-файлов так, чтобы они шли по очереди из разных документов. Этот инструмент нужен, когда обычное объединение просто склеивает файлы один за другим, а вам требуется страница 1 файла A, затем страница 1 файла B, затем страница 2 файла A и так далее.

## Как это работает

1. Загрузите не менее двух PDF-файлов через зону загрузки.
2. Инструмент покажет каждый файл с числом страниц и размером.
3. Перетаскивайте маркеры, чтобы изменить, страницы какого файла идут первыми в последовательности чередования.
4. Нажмите **Смешать страницы**, чтобы получить результат с чередованием.
5. Результат скачается как `alternated-mixed.pdf`.

## Возможности

- Чередование страниц любого числа PDF (минимум два)
- Изменение порядка файлов перетаскиванием для управления приоритетом чередования
- Сохранение закладок исходных документов
- Отображение числа страниц и размера каждого загруженного файла
- Обработка в отдельном веб-воркере, чтобы интерфейс оставался отзывчивым

## Сценарии использования

- Сборка двусторонних сканов, когда нечетные и четные страницы сканировались отдельно
- Объединение листов с вопросами и ответами, чтобы после каждого вопроса шел ответ
- Постраничное объединение документов на двух языках (например, английский на одной странице, перевод на следующей)
- Чередование лицевых и оборотных сканов, полученных на одностороннем сканере

## Советы

- Если в исходных PDF разное число страниц, страницы более короткого документа закончатся первыми, а оставшиеся страницы более длинного окажутся в конце.
- Порядок файлов важен: первый файл в списке дает первую страницу результата. При необходимости перетащите файлы, чтобы изменить порядок.

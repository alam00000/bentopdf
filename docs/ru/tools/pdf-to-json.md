# PDF в JSON

Преобразует один или несколько PDF-файлов в формат JSON. Инструмент использует CPDF (Coherent PDF), чтобы сериализовать внутреннюю структуру каждого PDF в машиночитаемое представление JSON. Результат всегда выдаётся в виде ZIP-архива.

## Как это работает

1. Выберите один или несколько PDF-файлов через окно выбора файлов.
2. Нажмите **Конвертировать в JSON**, чтобы начать обработку. Конвертация выполняется в фоновом веб-воркере.
3. Скачивается ZIP-архив с одним файлом JSON на каждый исходный PDF.

Строка состояния показывает ход конвертации и создания ZIP.

## Параметры

Настраиваемых параметров нет. Каждый PDF преобразуется в полное представление JSON.

## Формат результата

- Файл `pdfs-to-json.zip` с файлом `filename.json` для каждого исходного PDF.

JSON отражает внутреннюю структуру объектов PDF, включая деревья страниц, ссылки на шрифты, метаданные и потоки содержимого.

## Сценарии использования

- Изучение внутренней структуры PDF для отладки или проверки.
- Программное извлечение структурированных метаданных и свойств страниц.
- Передача данных о структуре PDF в собственные конвейеры обработки.
- Аудит PDF-документов на соответствие требованиям через анализ деревьев объектов.

## Советы

- Инструмент выводит необработанную структуру объектов PDF, а не извлечённый текст. Если нужен текст страниц в JSON, используйте [Подготовка PDF для ИИ](./prepare-pdf-for-ai).
- Для простого извлечения текста удобнее [PDF в текст](./pdf-to-text).
- Большие PDF со сложной структурой дают очень большие файлы JSON.

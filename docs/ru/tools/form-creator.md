# Создание PDF-форм

Создавайте профессиональные заполняемые PDF-формы с нуля или добавляйте поля в существующий PDF. Визуальный редактор позволяет перетаскивать элементы формы (текстовые поля, флажки, выпадающие списки, переключатели, поля подписи и другие) прямо на предварительный просмотр страницы. Настраивайте свойства полей, задавайте правила условной видимости и экспортируйте полностью интерактивную PDF-форму.

## Как это работает

1. Загрузите существующий PDF **или** нажмите **Создать пустой PDF**, чтобы начать с нуля.
2. При создании пустого PDF выберите размер страницы (Letter, A4, A5, Legal, Tabloid, A3 или свои размеры).
3. Откроется редактор форм с панелью типов полей и областью предварительного просмотра страницы.
4. Выберите тип поля на панели, затем щёлкните на странице, чтобы разместить его.
5. Перетаскивайте поля, чтобы изменить их положение. Маркеры изменения размера помогут подогнать размеры.
6. Щёлкните поле, чтобы открыть панель свойств, где можно задать имя поля, значение по умолчанию, размер шрифта, выравнивание и многое другое.
7. Переключайтесь между страницами с помощью элементов управления страницами.
8. Нажмите **Сохранить**, чтобы скачать готовый заполняемый PDF.

## Возможности

- Размещение полей перетаскиванием с визуальными маркерами изменения размера
- Типы полей: текстовое поле, многострочный текст, флажок, выпадающий список, переключатель, подпись, дата, число и штрихкод
- Панель свойств для настройки имени, подписи, значения по умолчанию, размера шрифта, цвета, выравнивания и проверки каждого поля
- Действия полей и правила условной видимости (показ и скрытие полей в зависимости от значений других полей)
- Навигация по страницам для многостраничных форм
- Извлечение существующих полей: поля формы из загруженных PDF определяются и импортируются автоматически
- Поддержка как загруженных PDF, так и пустых страниц в качестве основы формы
- Несколько готовых размеров страниц и возможность задать свои
- Генерация штрихкодов на основе bwip-js
- Управление группами переключателей

## Параметры

**Готовые размеры страниц (для пустых PDF):**

- Letter (8,5" x 11")
- A4 (210 мм x 297 мм)
- A5 (148 мм x 210 мм)
- Legal (8,5" x 14")
- Tabloid (11" x 17")
- A3 (297 мм x 420 мм)
- Свой (укажите ширину и высоту)

**Свойства полей (зависят от типа поля):**

- Имя, подпись и текст подсказки
- Значение по умолчанию
- Шрифт, размер и цвет
- Выравнивание текста (по левому краю, по центру, по правому краю)
- Переключатель обязательного поля
- Переключатель «только чтение»
- Максимальная длина текстовых полей
- Список вариантов для выпадающих списков и переключателей
- Действия условной видимости

## Сценарии использования

- Создание форм для приёма сотрудников с текстовыми полями для личных данных и флажками для подтверждения ознакомления с политикой
- Создание анкет для клиентов с выпадающими списками для выбора услуги
- Разработка бланков заказов с вычисляемыми полями и штрихкодами-идентификаторами
- Создание контрольных листов для осмотра с переключателями для оценки «пройдено/не пройдено»
- Создание опросов с условными уточняющими вопросами, которые появляются в зависимости от ответов

## Советы

- Если вы загрузите существующий PDF, инструмент попытается извлечь уже имеющиеся поля формы, и вы сможете их редактировать или дополнять.
- Используйте группы переключателей, чтобы создавать взаимоисключающие варианты. Поля в одной группе переключателей имеют общее имя группы.
- Проверьте форму: скачайте её и откройте в инструменте [Заполнение PDF-форм](./form-filler), чтобы убедиться, что поля работают правильно.

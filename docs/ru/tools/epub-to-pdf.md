# EPUB в PDF

Преобразуйте электронные книги EPUB в PDF-файлы, не выходя из браузера. EPUB является открытым стандартом цифровых книг, но иногда нужен PDF с фиксированной версткой: для печати, аннотирования или передачи тем, у кого нет программы для чтения электронных книг.

## Поддерживаемые форматы

| Формат | Расширение | Примечания            |
| :----- | :--------- | :-------------------- |
| EPUB   | `.epub`    | Файлы EPUB 2 и EPUB 3 |

## Как это работает

1. Щелкните по области загрузки или перетащите в нее файлы EPUB. Можно выбрать сразу несколько файлов.
2. Проверьте загруженные файлы. Удаляйте ненужные записи значком корзины или нажмите **Добавить еще файлы**, чтобы расширить партию.
3. Нажмите **Преобразовать в PDF**. Движок PyMuPDF преобразует содержимое EPUB (текст, изображения и форматирование) в постраничный PDF.
4. Один EPUB скачивается сразу как PDF. Несколько файлов упаковываются в ZIP-архив `epub-converted.zip`.

## Параметры

Преобразование выполняется с разумными настройками по умолчанию, дополнительная конфигурация не нужна. Текст перетекает в страницы стандартного размера, а встроенные шрифты и изображения переносятся в PDF.

## Сценарии использования

- Печать электронной книги без DRM для чтения вдали от экранов
- Отправка рукописи в формате EPUB на рецензию в виде PDF с фиксированной версткой
- Архивирование цифровых книг в формате, который нативно открывает любая операционная система
- Передача главы коллеге, у которого нет программы для чтения EPUB
- Преобразование технической документации в формате EPUB в PDF с возможностью аннотирования

## Советы

- Возможности EPUB 3, такие как встроенное аудио и видео, в PDF не переносятся, но весь текст, изображения и таблицы преобразуются корректно.
- Для сильно стилизованных EPUB проверьте первые страницы результата, чтобы убедиться в точности верстки.

# ODP в PDF

Преобразуйте файлы OpenDocument Presentation в PDF. ODP - родной формат LibreOffice Impress и стандартный вариант экспорта из Google Slides. Если превратить презентации в PDF, их сможет открыть любой человек без программ для презентаций, а слайды аккуратно печатаются.

## Поддерживаемые форматы

| Формат                    | Расширение | Примечания                                     |
| :------------------------ | :--------- | :--------------------------------------------- |
| OpenDocument Presentation | `.odp`     | LibreOffice Impress / экспорт из Google Slides |

## Как это работает

1. Нажмите на область загрузки или перетащите в неё файлы ODP. Можно выбрать сразу несколько презентаций.
2. Просмотрите список файлов. Значок корзины удаляет записи, а **Добавить ещё файлы** добавляет другие презентации.
3. Нажмите **Преобразовать в PDF**. Движок на основе LibreOffice обрабатывает каждую презентацию и создаёт PDF, где каждый слайд становится страницей.
4. Один файл скачивается как PDF. Несколько файлов поставляются в ZIP-архиве `odp-to-pdf.zip`.

## Параметры

Настраивать ничего не нужно. Каждый слайд отображается в исходных размерах, а текст, изображения, фигуры и фоны слайдов сохраняются.

## Сценарии использования

- Рассылка презентации аудитории в виде раздаточного PDF
- Передача экспорта из Google Slides тем, кто предпочитает PDF вместо ODP
- Архивирование докладов и лекций на конференциях в формате только для чтения
- Печать наборов слайдов для очных семинаров

## Советы

- Переходы и анимация слайдов относятся только к визуальным эффектам и в PDF не переносятся, но всё статичное содержимое отображается правильно.
- Заметки докладчика в итоговый PDF не включаются. Если они нужны, экспортируйте их отдельно из программы для презентаций.
- Как и другие инструменты на основе LibreOffice, движок загружается при первом использовании и остаётся в кэше на время сеанса.

# Извлечение изображений

Извлекает все встроенные изображения из одного или нескольких PDF-файлов. Извлеченные изображения показываются в сетке предпросмотра, где их можно скачать по одному или сразу все ZIP-архивом. Работает на PyMuPDF.

## Как это работает

1. Загрузите один или несколько PDF, щелкнув по области загрузки или перетащив на нее файлы. Добавляйте файлы или удаляйте отдельные при необходимости.
2. Нажмите **Извлечение изображений**, чтобы начать обработку.
3. Инструмент просматривает каждую страницу каждого загруженного PDF, находя и извлекая встроенные изображения.
4. Извлеченные изображения появляются в сетке с миниатюрами. У каждого изображения есть кнопка скачивания.
5. Нажмите **Скачать всё**, чтобы сохранить все в виде ZIP-архива.

## Параметры

У этого инструмента нет настраиваемых параметров. Все встроенные изображения извлекаются в исходном формате (обычно PNG, JPEG или тот формат, в котором изображение было встроено в PDF).

## Формат результата

- В сетке предпросмотра изображения называются `image_1.png`, `image_2.jpg` и так далее.
- **Скачать всё** создает `extracted-images.zip` со всеми изображениями.
- Отдельные изображения можно скачивать по одному из сетки.

## Сценарии использования

- Восстановление фотографий и графики из PDF для повторного использования в другом проекте.
- Извлечение изображений товаров из PDF-каталога для карточки в интернет-магазине.
- Извлечение схем из технической документации для презентаций.
- Аудит изображений, встроенных в документ, перед его отправкой.

## Советы

- Инструмент извлекает изображения ровно в том виде, в котором они хранятся в PDF. Он не преобразует страницы в изображения: для этого используйте [PDF в PNG](./pdf-to-png) или [PDF в JPG](./pdf-to-jpg).
- Если инструмент сообщает «Изображения не найдены», в PDF может быть векторная графика вместо встроенных растровых изображений, либо это отсканированный документ, где вся страница является одним большим изображением.
- Пакетная обработка работает с несколькими PDF. Все изображения из всех файлов объединяются в одну сетку и один ZIP.

# PDF в SVG

Преобразует каждую страницу PDF в файл SVG (Scalable Vector Graphics). В отличие от растровых форматов, SVG сохраняет векторные контуры, текст и фигуры, поэтому результат масштабируется до любого размера без пикселизации. Работает на PyMuPDF.

## Как это работает

1. Загрузите один или несколько PDF, нажав на область загрузки или перетащив файлы. Можно добавить несколько файлов и управлять ими по отдельности.
2. Нажмите **Конвертировать в SVG**, чтобы обработать все загруженные файлы.
3. Конвертация одного файла с одной страницей скачивается как отдельный `.svg`. Во всех остальных случаях скачивается ZIP-архив.

## Параметры

Настраиваемых параметров нет. Каждая страница преобразуется в SVG встроенным векторным экспортом PyMuPDF.

## Формат результата

- **Один файл, одна страница**: `filename.svg`
- **Один файл, несколько страниц**: `filename_svg.zip` с файлами `page_1.svg`, `page_2.svg` и так далее.
- **Несколько файлов**: `pdf_to_svg.zip` с файлами, разложенными по именам исходных документов.

## Сценарии использования

- Извлечение векторных схем, графиков и иллюстраций из PDF-отчётов для веб-страниц.
- Редактирование содержимого страниц PDF в векторном редакторе, таком как Inkscape или Illustrator.
- Встраивание масштабируемых превью страниц в адаптивные веб-приложения.
- Извлечение логотипов и графики из PDF-брошюр с сохранением чётких краёв.

## Советы

- SVG лучше всего работает с PDF, содержащими векторное содержимое. Отсканированные документы и PDF с множеством изображений дают крупные файлы SVG со встроенными растровыми данными.
- Для растрового результата из PDF с большим количеством изображений используйте [PDF в PNG](./pdf-to-png) или [PDF в JPG](./pdf-to-jpg).
- Инструмент поддерживает пакетную конвертацию: загрузите несколько PDF сразу, чтобы преобразовать их за один запуск.

# Распознавание текста в PDF

Превращайте отсканированные документы в PDF с поиском и копированием текста. Инструмент использует Tesseract OCR, чтобы распознавать текст на изображениях, и накладывает поверх исходных страниц невидимый текстовый слой. Внешний вид страниц сохраняется, а содержимое становится полностью доступным для поиска.

## Как это работает

1. Загрузите отсканированный PDF или PDF на основе изображений.
2. Выберите один или несколько языков документа в списке языков с поиском.
3. При желании настройте расширенные параметры (разрешение, бинаризация, белый список).
4. Нажмите **Начать распознавание** и следите за ходом выполнения на индикаторе прогресса.
5. По завершении просмотрите извлечённый текст, затем скачайте PDF с поиском или обычный файл `.txt`.

## Возможности

- Распознавание на нескольких языках с выбором языка через поиск
- Невидимый текстовый слой сохраняет исходный вид документа
- Индикатор прогресса и журнал в реальном времени во время обработки
- Скачивание результата как PDF с поиском или обычного текстового файла
- Копирование извлечённого текста в буфер обмена
- Три уровня разрешения для баланса между скоростью и точностью

## Параметры

| Настройка                        | Значения                                                                          | По умолчанию | Назначение                                                                                     |
| -------------------------------- | --------------------------------------------------------------------------------- | ------------ | ---------------------------------------------------------------------------------------------- |
| **Разрешение**                   | Стандартное (192 DPI), Высокое (288 DPI), Максимальное (384 DPI)                  | Высокое      | Более высокое разрешение повышает точность для мелкого текста, но работает дольше              |
| **Бинаризация изображения**      | Вкл. / Выкл.                                                                      | Выкл.        | Повышает контраст чистых сканов, преобразуя их в чёрно-белые                                   |
| **Набор символов белого списка** | Нет, Буквы и цифры, Числа и валюта, Только буквы, Только цифры, Счёт, Формы, Свой | Нет          | Ограничивает распознаваемые символы, чтобы повысить точность для определённых типов документов |
| **Белый список символов**        | Произвольный текст                                                                | Пусто        | Ручной набор символов, если выбран набор «Свой»                                                |

## Сценарии использования

- Превращение отсканированных договоров и счетов в документы с поиском, чтобы искать по ним через Ctrl+F
- Извлечение текста из сфотографированных документов или старых бумажных записей
- Обработка чеков с набором «Счёт» для точного распознавания сумм и дат
- Создание доступных PDF из сканов, состоящих только из изображений, для соответствия требованиям
- Пакетное извлечение текста из отсканированных книг или руководств

## Советы

- Выбирайте несколько языков, если документ содержит текст на разных языках (например, английские заголовки и основной текст на японском).
- Используйте бинаризацию для документов с выцветшим или малоконтрастным текстом: она может заметно повысить точность распознавания.
- Наборы белого списка «Счёт» и «Формы» значительно снижают число ложных срабатываний в структурированных документах, игнорируя лишние формы символов.

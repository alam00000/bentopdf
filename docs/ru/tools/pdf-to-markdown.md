# PDF в Markdown

Преобразует PDF-файлы в формат Markdown (`.md`), сохраняя заголовки, абзацы, списки и базовое форматирование. При желании извлекает и включает встроенные изображения. Поддерживает одиночную и пакетную конвертацию. Работает на PyMuPDF.

## Как это работает

1. Загрузите один или несколько PDF, нажав на область загрузки или перетащив файлы.
2. При желании включите **Включить изображения как base64**, чтобы встроить извлечённые изображения в Markdown.
3. Нажмите **Конвертировать в Markdown**, чтобы начать обработку.
4. Один файл скачивается как `filename.md`. Несколько файлов дают `markdown-files.zip`.

## Параметры

- **Включить изображения как base64**: если включено, встроенные изображения из PDF извлекаются и подключаются в Markdown. Если выключено, конвертируется только текст.

## Формат результата

- **Один файл**: `filename.md`
- **Несколько файлов**: `markdown-files.zip` с одним `.md` на каждый исходный PDF.

## Сценарии использования

- Преобразование PDF-документации в Markdown для генераторов статических сайтов, таких как VitePress, Hugo или Jekyll.
- Превращение научных статей из PDF в редактируемый Markdown для приложений заметок вроде Obsidian.
- Перенос старых баз знаний из PDF в текстовый формат, удобный для Git.
- Извлечение структурированного содержимого из PDF-книг для переверстки.

## Советы

- Параметр «Включить изображения как base64» полезен, когда в PDF есть схемы и рисунки, важные для содержания. Для текстовых документов отключите его, чтобы результат оставался чистым.
- Сложная вёрстка с боковыми колонками, сносками или многоколоночным текстом может дать неидеальный Markdown. Проверьте и поправьте результат при необходимости.
- Для чистого текста без форматирования используйте [PDF в текст](./pdf-to-text).

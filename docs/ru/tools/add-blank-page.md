# Добавление пустой страницы

Вставляйте пустые страницы в PDF в указанное место. Вы сами выбираете, куда поместить пустые страницы и сколько их добавить.

## Как это работает

1. Загрузите PDF-файл. Инструмент покажет количество страниц.
2. Введите **позицию**, в которую нужно вставить пустые страницы. Укажите `0`, чтобы вставить в самое начало, или общее число страниц, чтобы добавить в конец.
3. Введите **количество** добавляемых пустых страниц (по умолчанию 1).
4. Нажмите кнопку обработки. Измененный PDF скачается со вставленными пустыми страницами.

## Возможности

- Вставка в любое место: в начало, середину или конец документа
- Добавление нескольких пустых страниц за одну операцию
- Подсказка по позиции динамически обновляется в зависимости от числа страниц загруженного PDF
- Пустые страницы стандартного размера A4

## Сценарии использования

- Добавление пустой страницы-разделителя между разделами сводного документа
- Вставка пустых страниц для правильной двусторонней печати
- Добавление места для рукописных заметок в распечатанном учебном пособии
- Дополнение документа до минимально необходимого числа страниц

## Советы

- Позиция `0` вставляет страницы перед первой. Позиция, равная общему числу страниц, добавляет их после последней.
- Если нужно вставить в определенное место не просто пустые страницы, а содержимое, используйте [Мультиинструмент PDF](./pdf-multi-tool), чтобы вставить другой PDF после заданной страницы.

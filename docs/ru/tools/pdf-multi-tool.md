# PDF мультиинструмент

Единое рабочее пространство для всех операций со страницами PDF. Загрузите один или несколько PDF и работайте со всеми страницами в одной визуальной сетке. Поворачивайте, переставляйте, дублируйте и удаляйте страницы, вставляйте PDF, изображения и пустые страницы, меняйте нумерацию и размер страниц и разделяйте результат, не выходя из инструмента.

## Как это работает

1. Нажмите **Выбрать файлы** или перетащите файлы в область загрузки. Можно выбрать несколько файлов, они объединяются в порядке загрузки.
2. Все страницы появятся в прокручиваемой сетке с миниатюрами.
3. Щёлкните страницу, чтобы выделить её. Щелчок с Shift выделяет диапазон, а щелчок с Cmd/Ctrl добавляет отдельные страницы к выделению или убирает их.
4. Для действий со страницами используйте панель инструментов или щёлкните страницу правой кнопкой мыши.
5. Нажмите **Экспортировать PDF**, чтобы скачать итог.

## Возможности

- **Объединить**: несколько загруженных PDF и изображений автоматически объединяются в один документ
- **Изменить порядок**: перетаскивание страниц для изменения последовательности или обратный порядок для всего документа
- **Повернуть**: поворот выбранных страниц влево или вправо с шагом 90 градусов
- **Дублировать**: копирование выбранных страниц с размещением копий сразу после них
- **Удалить**: удаление выбранных страниц
- **Вставить**: добавление страниц из другого PDF или изображения, пустой страницы или страниц из буфера обмена, а также чередование страниц второго PDF с текущими
- **Заменить**: замена страницы первой страницей другого PDF
- **Вырезать, копировать и вставить**: перемещение или копирование страниц внутри документа
- **Извлечь**: скачивание выбранных страниц в виде PDF или изображений
- **Номера страниц**: метки страниц вида i, ii, iii или A-1, A-2 для диапазона страниц
- **Размер страницы**: подгонка страниц под стандартный формат бумаги или произвольный размер
- **Разделить**: разделение документа по диапазонам страниц, на нечётные и чётные страницы, постранично, по закладкам, каждые N страниц или по размеру файла
- **Отменить / Вернуть**: любую операцию со страницами можно отменить и вернуть
- Автоматическое восстановление повреждённых PDF перед загрузкой

## Сочетания клавиш

| Действие                       | Сочетание клавиш                |
| ------------------------------ | ------------------------------- |
| Повернуть вправо / влево       | R / Shift+R                     |
| Выбрать все                    | Cmd/Ctrl+A                      |
| Вырезать, копировать, вставить | Cmd/Ctrl+X, C, V                |
| Дублировать                    | Cmd/Ctrl+D                      |
| Удалить                        | Delete или Backspace            |
| Отменить / Вернуть             | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z   |
| Переместить выделение          | Клавиши со стрелками, Home, End |

## Сценарии использования

- Сборка своего документа из страниц нескольких исходных PDF
- Очистка отсканированного документа: удаление пустых страниц, поворот боковых сканов, перестановка разделов
- Разделение большого PDF по границам глав с помощью его закладок
- Быстрое редактирование страниц без полноценного PDF-редактора

## Советы

- История отмены и повтора учитывает каждую операцию со страницами. Пользуйтесь ей свободно: случайно потерять работу нельзя.
- Чтобы добавить файлы в документ, используйте **Insert > From File** или в любой момент перетащите дополнительные PDF или изображения на сетку страниц.
- Для простого объединения или разделения быстрее могут оказаться отдельные инструменты [Объединение PDF](./merge-pdf) и [Разделение PDF](./split-pdf). Мультиинструмент выручает, когда за один сеанс нужно несколько операций.

# PDF мультиинструмент

Единое рабочее пространство для всех операций со страницами PDF. Загрузите один или несколько PDF и работайте со всеми страницами в одной визуальной сетке. Поворачивайте, переставляйте, дублируйте, удаляйте, вставляйте другие PDF, добавляйте пустые страницы и разделяйте результат, не выходя из инструмента.

## Как это работает

1. Нажмите **Загрузить PDF** или перетащите файлы в область загрузки. Можно выбрать несколько файлов.
2. Все страницы всех загруженных файлов появятся в прокручиваемой сетке с миниатюрами.
3. Для работы со страницами используйте панель инструментов или кнопки на каждой странице.
4. Отмечайте страницы флажком на карточке, затем применяйте массовые операции.
5. Отмечайте точки разделения значком ножниц, чтобы разбить результат на отдельные файлы.
6. Нажмите **Экспортировать PDF**, чтобы скачать итог. Если есть метки разделения, результатом будет ZIP с несколькими PDF.

## Возможности

- **Объединить**: загруженные PDF автоматически объединяются в одном рабочем пространстве
- **Изменить порядок**: перетаскивайте карточки страниц, чтобы изменить порядок
- **Повернуть**: поворот отдельных страниц или группы с шагом 90 градусов (влево или вправо)
- **Дублировать**: клонирование любой страницы одним щелчком
- **Удалить**: удаление отдельных страниц или выбранной группы
- **Вставить PDF**: вставка нового PDF после любой страницы
- **Добавить пустую страницу**: добавление пустой страницы A4 в конец
- **Разделить**: расставьте метки разделения между страницами, затем экспортируйте ZIP с отдельными PDF
- **Выбрать все / Снять выбор**: быстрое выделение для массовых операций
- **Отменить / Вернуть**: полная история отмены и повтора для каждой операции
- **Скачать выбранное**: экспорт только выбранных страниц в отдельный PDF
- Автоматическое восстановление повреждённых PDF перед загрузкой

## Сценарии использования

- Сборка своего документа из страниц нескольких исходных PDF
- Очистка отсканированного документа: удаление пустых страниц, поворот боковых сканов, перестановка разделов
- Разделение большого PDF по границам глав с помощью визуальных меток
- Быстрое редактирование страниц без полноценного PDF-редактора

## Советы

- Система отмены и повтора учитывает каждую операцию. Пользуйтесь ей свободно: случайно потерять работу нельзя.
- Метки разделения отображаются пунктирными синими линиями между страницами. Поставьте их там, где нужно разделить документ, затем экспортируйте ZIP.
- Для простого объединения или разделения быстрее могут оказаться отдельные инструменты [Объединение PDF](./merge-pdf) и [Разделение PDF](./split-pdf). Мультиинструмент выручает, когда за один сеанс нужно несколько операций.

# Просмотр метаданных

Изучите скрытые свойства, встроенные в PDF-файл. Инструмент показывает сведения о документе (название, автор, даты), метаданные XMP, размеры страниц и другие структурные данные в удобном виде.

## Как это работает

1. Загрузите PDF-файл.
2. Инструмент сразу разбирает файл и показывает все доступные метаданные по разделам.
3. Просмотрите словарь сведений о документе, дерево метаданных XMP и структурные свойства.
4. Отдельный шаг обработки не нужен: метаданные отображаются сразу после загрузки файла.

## Возможности

- Показывает стандартные поля сведений о документе: название, автор, тема, ключевые слова, создатель, производитель
- Показывает даты создания и изменения в читаемом формате
- Разбирает и отображает полное дерево метаданных XMP с вложенными пространствами имён
- Преобразует формат даты PDF (`D:20240101120000Z`) в читаемые даты
- Разделы сворачиваются для удобной навигации

## Разделы метаданных

| Раздел                   | Содержимое                                                                                             |
| ------------------------ | ------------------------------------------------------------------------------------------------------ |
| **Сведения о документе** | Название, автор, тема, ключевые слова, создатель, производитель, дата создания, дата изменения         |
| **Метаданные XMP**       | Полное дерево метаданных на основе XML с пространствами имён Dublin Core, XAP, PDF и пользовательскими |
| **Свойства документа**   | Число страниц, версия PDF, размер файла, статус шифрования                                             |

## Сценарии использования

- Узнать, кто автор PDF и когда он был изменён в последний раз
- Убедиться, что метаданные заданы правильно, перед публикацией документа
- Проверить PDF на приватность: какие личные данные в них встроены
- Выяснить, какая программа создала или изменила PDF (по полю Producer)
- Проверить метаданные XMP на соответствие требованиям управления цифровыми активами

## Советы

- Строки дат PDF, начинающиеся с `D:`, автоматически преобразуются в формат вашего часового пояса.
- Если поля метаданных пустые, значит, создатель PDF просто не задал их. Не во всех PDF есть подробные метаданные.
- Чтобы изменить метаданные после просмотра, используйте [Редактирование метаданных](./edit-metadata). Чтобы удалить их полностью, используйте «Удаление метаданных».

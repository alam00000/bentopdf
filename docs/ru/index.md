## OCR офлайн

Если вы размещаете BentoPDF у себя в изолированной или офлайн-среде, для OCR нужны не только воркер Tesseract и файлы traineddata. Чтобы получать PDF с возможностью поиска, шрифты текстового слоя OCR тоже должны раздаваться изнутри.
Полную настройку, включая `VITE_OCR_FONT_BASE_URL`, поставляемый каталог `ocr-fonts/` и обновлённый процесс для изолированных сред, смотрите в разделе [Самостоятельный хостинг](/ru/self-hosting/).

# PUB ke PDF

Konversi file Microsoft Publisher menjadi PDF. Publisher adalah alat desktop publishing yang disertakan dalam beberapa edisi Microsoft Office, tetapi kebanyakan orang tidak menginstalnya. Alat ini memungkinkan siapa pun mengonversi file PUB ke PDF langsung di browser, tanpa perangkat lunak Microsoft.

## Format yang Didukung

| Format              | Ekstensi | Catatan                    |
| :------------------ | :------- | :------------------------- |
| Microsoft Publisher | `.pub`   | Dokumen desktop publishing |

## Cara Kerja

1. Klik area unggah atau seret dan lepas file PUB Anda. Beberapa file dapat diunggah sekaligus.
2. Periksa daftar file. Hapus file yang tidak diinginkan dengan ikon tempat sampah, atau klik **Tambah File Lainnya** untuk menambah file.
3. Klik **Konversi ke PDF**. Mesin berbasis LibreOffice dimuat di browser dan mengonversi setiap file PUB, dengan mempertahankan tata letak, gambar, dan kotak teks.
4. Satu file diunduh langsung sebagai PDF. Beberapa file dikirim dalam arsip ZIP bernama `pub-to-pdf.zip`.

## Opsi

Tidak diperlukan konfigurasi tambahan. Konverter menangani mesin tata letak PUB secara otomatis.

## Kasus Penggunaan

- Membuka flyer atau buletin PUB dari klien tanpa membeli Microsoft Publisher
- Mengonversi buletin gereja, program acara, atau buletin sekolah yang dibuat di Publisher
- Mengarsipkan materi pemasaran dari Publisher dalam format yang dapat diakses secara universal
- Mencetak file PUB di sistem yang tidak memiliki Publisher

## Tips

- Tata letak Publisher yang kompleks dengan kotak teks berlapis dan penempatan presisi dapat bergeser sedikit selama konversi. Periksa hasilnya jika posisi yang tepat sangat penting.
- Mesin LibreOffice diinisialisasi sekali per sesi. Konversi pertama memakan waktu lebih lama, konversi berikutnya lebih cepat.
- Untuk konversi file Publisher yang paling akurat, pastikan font khusus yang digunakan di file asli adalah font sistem standar.

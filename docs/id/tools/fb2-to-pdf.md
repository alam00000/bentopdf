# FB2 ke PDF

Konversi file FictionBook 2 (FB2) menjadi dokumen PDF. FB2 adalah format ebook berbasis XML yang populer di Rusia dan Eropa Timur. Meski didukung dengan baik di beberapa platform, format ini hampir tidak dikenal di platform lain. Dengan mengonversinya ke PDF, buku Anda bisa dibaca di mana saja.

## Format yang Didukung

| Format        | Ekstensi | Catatan                   |
| :------------ | :------- | :------------------------ |
| FictionBook 2 | `.fb2`   | Format ebook berbasis XML |

## Cara Kerja

1. Klik area unggah atau seret dan lepas file FB2 Anda. Pemilihan banyak file sekaligus didukung.
2. Periksa daftar file. Gunakan ikon tempat sampah untuk menghapus entri tertentu, atau **Tambah File Lagi** untuk menyertakan lebih banyak file.
3. Klik **Konversi ke PDF**. Mesin PyMuPDF mengurai struktur XML FB2 dan merendernya sebagai konten PDF berhalaman.
4. Satu file langsung diunduh sebagai PDF. Beberapa hasil konversi dikemas dalam `fb2-converted.zip`.

## Opsi

Tidak diperlukan konfigurasi. Konverter menangani struktur XML FB2 secara otomatis, dengan mempertahankan pemisah bab, pemformatan, dan gambar yang tertanam.

## Kasus Penggunaan

- Membaca ebook FB2 di perangkat atau aplikasi yang hanya mendukung PDF
- Mencetak literatur berbahasa Rusia yang didistribusikan dalam format FB2
- Mengarsipkan pustaka FB2 ke format yang didukung secara universal
- Membagikan buku kepada orang yang pembacanya tidak mendukung FictionBook

## Tips

- File FB2 adalah XML biasa, sehingga ukurannya cenderung kecil dan cepat dikonversi bahkan di browser.
- Jika file FB2 Anda dikompresi sebagai `.fb2.zip`, ekstrak terlebih dahulu sebelum mengunggah.

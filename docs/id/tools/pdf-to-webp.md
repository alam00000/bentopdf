# PDF ke WebP

Mengonversi setiap halaman PDF menjadi gambar WebP. WebP biasanya menghasilkan file 25-35% lebih kecil daripada JPG pada kualitas yang tampak sama, sehingga menjadi pilihan kuat untuk penggunaan web.

## Cara Kerja

1. Unggah PDF dengan mengklik zona lepas atau menyeret file ke dalamnya.
2. Atur penggeser **Kualitas**.
3. Klik **Konversi** untuk memproses file.
4. Satu file `.webp` atau arsip ZIP diunduh secara otomatis.

## Opsi

- **Kualitas**: penggeser dari 0% hingga 100% (default 85%). Mengontrol tingkat kompresi lossy. Nilai lebih tinggi mempertahankan lebih banyak detail.

Halaman dirender pada skala 2x secara internal, menghasilkan gambar dengan dimensi sekitar dua kali dimensi asli PDF.

## Format Hasil

- **Satu halaman**: `filename.webp`
- **Beberapa halaman**: `filename_webps.zip` berisi `page_1.webp`, `page_2.webp`, dan seterusnya.

## Kasus Penggunaan

- Menyiapkan pratinjau halaman untuk situs web yang mementingkan bandwidth.
- Membuat versi gambar ringan dari flyer atau brosur untuk media sosial.
- Mengonversi massal dokumen multi-halaman menjadi kumpulan gambar yang dioptimalkan untuk web.

## Tips

- WebP didukung di semua browser modern. Untuk kompatibilitas lama, gunakan [PDF ke JPG](./pdf-to-jpg).
- Kualitas 80-85% biasanya tidak dapat dibedakan dari aslinya di layar sambil menjaga ukuran file tetap kecil.

# Gambar ke PDF

Konverter gambar ke PDF universal. Unggah gambar dalam hampir semua format dan gabungkan menjadi satu dokumen PDF. Setiap gambar mendapat halamannya sendiri, dengan ukuran yang sesuai dimensi aslinya.

## Format yang Didukung

| Format          | Ekstensi                               |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

Ini adalah dukungan format terluas di antara semua konverter gambar BentoPDF. Jika Anda hanya membutuhkan satu format tertentu, gunakan alat khusus sebagai gantinya.

## Cara Kerja

1. Klik area unggah atau seret dan lepas file gambar Anda. Anda dapat memilih banyak file sekaligus.
2. Periksa daftar file. Hapus file yang tidak diinginkan dengan ikon tempat sampah, atau klik **Tambah File Lagi** untuk menyertakan gambar tambahan.
3. Pilih tingkat **Kualitas PDF** dari menu tarik-turun.
4. Klik **Konversi ke PDF**. Alat ini memproses gambar melalui mesin PyMuPDF dan mengunduh hasilnya sebagai `images_to_pdf.pdf`.

## Opsi

**Kualitas PDF** mengatur kompresi gambar yang diterapkan saat menyematkan gambar ke PDF:

- **Kualitas Tinggi**: kompresi minimal, ukuran file lebih besar. Terbaik untuk cetak atau arsip.
- **Kualitas Sedang** (default): kompresi seimbang. Cocok untuk sebagian besar keperluan.
- **Kualitas Rendah**: kompresi agresif, ukuran file terkecil. Cocok untuk email atau berbagi cepat.

File HEIC dan WebP otomatis dikonversi ke PNG sebelum disematkan. Ini terjadi secara transparan dan tidak memerlukan langkah tambahan.

## Kasus Penggunaan

- Menggabungkan struk atau dokumen hasil pindai dari kamera ponsel menjadi satu PDF
- Membuat portofolio foto atau lookbook dari gambar berbagai format
- Mengonversi foto iPhone (HEIC) menjadi PDF yang mudah dibagikan tanpa memasang perangkat lunak desktop
- Menyusun mockup desain dari ekspor PSD dan tangkapan layar menjadi hasil kerja untuk klien
- Mengarsipkan folder berisi format gambar lawas (PNM, JXR, JP2) sebagai satu PDF

## Tips

- Urutan gambar dalam PDF sesuai dengan urutannya di daftar file. Unggah sesuai urutan yang Anda inginkan.
- Untuk ukuran file sekecil mungkin, pilih Kualitas Rendah. Perbedaan visualnya sering kali dapat diabaikan untuk hasil pindai yang dominan teks.
- Jika Anda hanya memiliki satu format gambar, konverter khusus (JPG ke PDF, PNG ke PDF, dll.) memberikan hasil yang sama dengan antarmuka yang lebih sederhana.

# MOBI ke PDF

Konversi ebook Amazon Kindle MOBI menjadi dokumen PDF. File MOBI terikat pada perangkat dan aplikasi Kindle sehingga sulit dibaca di tempat lain. Mengonversinya ke PDF memberi Anda versi portabel yang dapat dibuka di perangkat apa pun atau dicetak.

## Format yang Didukung

| Format | Ekstensi | Catatan                          |
| :----- | :------- | :------------------------------- |
| MOBI   | `.mobi`  | Format ebook Kindle (Mobipocket) |

## Cara Kerja

1. Klik area unggah atau seret dan lepas satu atau beberapa file MOBI.
2. Periksa daftar file. Hapus file yang tidak diinginkan dengan ikon tempat sampah, atau gunakan **Tambah File Lagi** untuk menyertakan ebook tambahan.
3. Klik **Konversi ke PDF**. Mesin PyMuPDF mengurai struktur MOBI dan merender setiap halaman sebagai konten PDF.
4. Satu file diunduh sebagai PDF. Saat mengonversi beberapa file, Anda mendapatkan arsip ZIP bernama `mobi-converted.zip`.

## Opsi

Tidak diperlukan pengaturan tambahan. Konversi mempertahankan isi teks, pemformatan, dan gambar tertanam dari file MOBI asli.

## Kasus Penggunaan

- Membaca konten yang dibeli di Kindle pada e-reader non-Kindle yang hanya mendukung PDF
- Mencetak bab dari ebook untuk belajar atau memberi anotasi secara offline
- Mengarsipkan pustaka ebook pribadi Anda dalam format universal
- Membagikan kutipan kepada orang yang tidak memasang aplikasi Kindle

## Tips

- File MOBI yang dilindungi DRM tidak dapat dikonversi. Alat ini hanya bekerja dengan file MOBI bebas DRM.
- Ebook besar dengan banyak gambar tertanam mungkin membutuhkan beberapa detik lebih lama karena semuanya diproses di browser.

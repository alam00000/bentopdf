# Referensi Alat

BentoPDF menawarkan **130+ alat** untuk bekerja dengan PDF. Semua alat berjalan sepenuhnya di browser Anda: file Anda tidak pernah meninggalkan perangkat Anda.

---

## Edit & Anotasi

Ubah, tandai, dan tingkatkan dokumen PDF Anda dengan rangkaian alat pengeditan yang lengkap.

<div class="tool-grid">

- [**Editor PDF**](./edit-pdf): Beri anotasi, sorot, redaksi, komentar, tambahkan bentuk/gambar, cari, dan lihat PDF.
- [**Edit Bookmark**](./bookmark): Tambah, edit, impor, hapus, dan ekstrak bookmark PDF.
- [**Daftar Isi**](./table-of-contents): Buat halaman daftar isi dari bookmark PDF.
- [**Nomor Halaman**](./page-numbers): Sisipkan nomor halaman ke dokumen Anda.
- [**Tambahkan label halaman**](./add-page-labels): Terapkan label halaman PDF dengan angka Romawi, awalan, dan awal kustom.
- [**Penomoran Bates**](./bates-numbering): Tambahkan nomor Bates berurutan di satu atau beberapa file PDF.
- [**Tambah Watermark**](./add-watermark): Bubuhkan teks atau gambar di atas halaman PDF Anda.
- [**Kepala & Kaki Halaman**](./header-footer): Tambahkan teks di bagian atas dan bawah halaman.
- [**Balik Warna**](./invert-colors): Buat versi mode gelap dari PDF Anda.
- [**Efek Pemindai**](./scanner-effect): Buat PDF Anda tampak seperti dokumen hasil pindai.
- [**Sesuaikan Warna**](./adjust-colors): Atur kecerahan, kontras, saturasi, dan lainnya.
- [**Warna Latar Belakang**](./background-color): Ubah warna latar belakang PDF Anda.
- [**Ubah Warna Teks**](./text-color): Ubah warna teks dalam PDF Anda.
- [**Tanda Tangan PDF**](./sign-pdf): Gambar, ketik, atau unggah tanda tangan Anda.
- [**Tambah Stempel**](./add-stamps): Tambahkan stempel gambar ke PDF Anda menggunakan toolbar anotasi.
- [**Hapus Anotasi**](./remove-annotations): Hapus komentar, sorotan, dan tautan.
- [**Potong PDF**](./crop-pdf): Pangkas margin setiap halaman dalam PDF Anda.
- [**Pengisi Formulir PDF**](./form-filler): Isi formulir langsung di browser. Juga mendukung formulir XFA.
- [**Buat Formulir PDF**](./form-creator): Buat formulir PDF yang dapat diisi dengan kolom teks seret dan lepas.
- [**Hapus Halaman Kosong**](./remove-blank-pages): Deteksi dan hapus halaman kosong secara otomatis.

</div>

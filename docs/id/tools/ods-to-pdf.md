# ODS ke PDF

Konversi file OpenDocument Spreadsheet menjadi PDF. ODS adalah format asli LibreOffice Calc dan format ekspor umum dari Google Sheets. Alat ini merender data, format, dan grafik spreadsheet Anda menjadi PDF berhalaman yang bisa dicetak atau dibagikan.

## Format yang Didukung

| Format                   | Ekstensi | Catatan                                 |
| :----------------------- | :------- | :-------------------------------------- |
| OpenDocument Spreadsheet | `.ods`   | Ekspor LibreOffice Calc / Google Sheets |

## Cara Kerja

1. Klik area unggah atau seret dan lepas file ODS Anda. Beberapa file sekaligus didukung.
2. Periksa daftar file. Gunakan ikon tempat sampah untuk menghapus file, atau klik **Tambah File Lagi** untuk memperbesar batch.
3. Klik **Konversi ke PDF**. Engine berbasis LibreOffice dimuat di browser dan merender setiap spreadsheet menjadi halaman PDF.
4. Satu spreadsheet diunduh sebagai PDF. Beberapa file dikemas menjadi `ods-to-pdf.zip`.

## Opsi

Tidak diperlukan konfigurasi. Konverter menerapkan tata letak cetak, format sel, dan lebar kolom yang sudah ada pada spreadsheet ke hasil PDF.

## Kasus Penggunaan

- Membagikan anggaran atau laporan LibreOffice Calc kepada orang yang hanya menerima PDF
- Mencetak ekspor Google Sheets yang diunduh sebagai ODS
- Mengarsipkan catatan keuangan dalam format yang tidak dapat diedit
- Mengirim formulir atau lembar waktu berbasis ODS sebagai dokumen dengan tata letak tetap

## Tips

- Jika spreadsheet Anda memiliki beberapa lembar, semua lembar disertakan dalam hasil PDF.
- Spreadsheet yang sangat lebar dapat terbagi ke beberapa halaman PDF secara horizontal. Pertimbangkan menyesuaikan lebar kolom di file sumber sebelum konversi jika tata letak penting.
- Engine LibreOffice diinisialisasi saat pertama digunakan. Konversi berikutnya dalam sesi yang sama lebih cepat.

# PSD ke PDF

Konversi file Adobe Photoshop PSD menjadi dokumen PDF. PSD adalah format asli Photoshop, dan membukanya biasanya memerlukan perangkat lunak Adobe yang mahal. Alat ini merender komposit gabungan (flattened) dari file PSD Anda sebagai halaman PDF beresolusi penuh.

## Format yang Didukung

| Format          | Ekstensi | Catatan                                      |
| :-------------- | :------- | :------------------------------------------- |
| Adobe Photoshop | `.psd`   | Merender gambar komposit yang sudah digabung |

## Cara Kerja

1. Klik area unggah atau seret dan lepas file PSD Anda. Beberapa file didukung.
2. Periksa daftar file. Hapus file yang tidak diinginkan dengan ikon tempat sampah, atau gunakan **Tambah File Lainnya** untuk menambah file.
3. Klik **Konversi ke PDF**. Mesin PyMuPDF membaca file PSD dan menyematkan gambar komposit ke halaman PDF pada resolusi aslinya.
4. Satu PSD menghasilkan satu PDF. Saat Anda mengunggah beberapa file PSD, semuanya digabung menjadi satu PDF multi-halaman bernama `psd_to_pdf.pdf`, dengan setiap PSD menjadi satu halaman.

## Opsi

Tidak diperlukan pengaturan. Konverter menggunakan data gambar gabungan dari file PSD.

## Kasus Penggunaan

- Melihat pratinjau desain Photoshop tanpa membuka Photoshop
- Mengirim bukti desain kepada klien yang tidak memiliki Adobe Creative Suite
- Mencetak karya seni beresolusi tinggi dari file PSD
- Membuat portofolio PDF dari beberapa file desain PSD, masing-masing menjadi satu halaman dalam satu dokumen

## Tips

- Konversi merender tampilan komposit (gabungan) dari PSD. Layer individual, layer penyesuaian, dan efek layer tidak dipertahankan sebagai elemen terpisah di PDF.
- Beberapa file PSD digabung menjadi satu PDF multi-halaman, bukan PDF individual. Ini berguna untuk membuat portofolio atau lookbook.
- File PSD beresolusi sangat tinggi (file cetak 300+ DPI) akan menghasilkan PDF besar. Alat ini mempertahankan resolusi penuh.

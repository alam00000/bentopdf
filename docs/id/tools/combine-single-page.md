# Gabung ke Halaman Tunggal

Gabungkan setiap halaman PDF menjadi satu halaman panjang. Halaman dirangkai secara vertikal (seperti gulungan) atau horizontal (berdampingan), menghasilkan satu halaman kontinu pada output.

## Cara Kerja

1. Unggah file PDF.
2. Pilih arah tata letak: **Vertikal** (halaman ditumpuk dari atas ke bawah) atau **Horizontal** (halaman diletakkan berdampingan).
3. Atur jarak antar halaman dalam satuan point.
4. Pilih warna latar untuk celah di antara halaman.
5. Secara opsional, aktifkan pemisah (garis tipis di antara halaman) dan atur ketebalan serta warnanya.
6. Klik tombol proses. Hasilnya adalah PDF satu halaman.

## Fitur

- Perangkaian halaman vertikal atau horizontal
- Jarak antar halaman yang dapat diatur
- Pemilih warna latar untuk area celah
- Garis pemisah opsional dengan ketebalan dan warna yang dapat disesuaikan
- Merender setiap halaman asli dengan resolusi penuh ke kanvas gabungan

## Opsi

| Opsi                        | Deskripsi                                           |
| --------------------------- | --------------------------------------------------- |
| **Arah Tata Letak**         | Vertical (bertumpuk) atau Horizontal (berdampingan) |
| **Jarak**                   | Celah antar halaman dalam point                     |
| **Warna Latar Belakang**    | Warna area di antara halaman                        |
| **Tambahkan Garis Pemisah** | Aktifkan garis tipis di antara halaman              |
| **Ketebalan Pemisah**       | Ketebalan garis dalam point                         |
| **Warna Pemisah**           | Warna garis pemisah                                 |

## Kasus Penggunaan

- Membuat satu gambar panjang dari wireframe atau mockup desain multi-halaman
- Menghasilkan tampilan dokumen yang dapat digulir terus-menerus untuk disematkan di web
- Merangkai komik atau storyboard multi-halaman menjadi satu strip
- Membuat tampilan panorama halaman berurutan untuk ditinjau

## Tips

- Orientasi vertikal paling cocok untuk dokumen dengan halaman potret. Horizontal lebih baik untuk konten berorientasi lanskap.
- Dokumen besar dengan banyak halaman akan menghasilkan output yang sangat tinggi atau lebar. Beberapa penampil PDF mungkin kesulitan dengan halaman tunggal yang sangat besar.
- Menambahkan pemisah dengan warna kontras memudahkan Anda melihat di mana satu halaman asli berakhir dan halaman berikutnya dimulai.

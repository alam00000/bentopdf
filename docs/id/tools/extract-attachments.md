# Ekstrak Lampiran

Keluarkan setiap lampiran tertanam dari satu atau beberapa file PDF. Semua file yang diekstrak dibundel dalam satu arsip ZIP untuk diunduh.

## Cara Kerja

1. Unggah satu atau beberapa file PDF yang berisi lampiran tertanam.
2. Klik **Ekstrak Lampiran**.
3. Alat memindai setiap PDF untuk lampiran tingkat dokumen dan tingkat halaman.
4. Semua file yang ditemukan dikemas ke arsip ZIP dan diunduh otomatis.
5. Pesan status mengonfirmasi berapa banyak lampiran yang ditemukan dan ukuran totalnya.

## Fitur

- Ekstraksi batch dari beberapa PDF sekaligus
- Mengekstrak lampiran tingkat dokumen maupun tingkat halaman
- Menghasilkan satu file ZIP berisi semua file yang diekstrak
- Menampilkan jumlah total lampiran dan gabungan ukuran file
- Pesan status yang jelas jika tidak ada lampiran ditemukan

## Kasus Penggunaan

- Memulihkan file data yang tertanam di PDF laporan
- Mengambil aset gambar dari portofolio atau dokumen spesifikasi
- Mengekstrak materi tambahan dari PDF pelatihan atau kepatuhan
- Mengaudit file apa saja yang tertanam di dalam sekumpulan PDF

## Tips

- Jika alat melaporkan tidak ada lampiran, PDF mungkin berisi gambar tertanam atau data formulir, yang bukan lampiran file. Gunakan [Ekstrak Gambar](./extract-images) untuk gambar tertanam.
- Saat memproses beberapa PDF, semua lampiran dari setiap file berakhir dalam satu ZIP. Nama file dipertahankan dari penyematan aslinya.

# Nomor Halaman

Tambahkan nomor halaman yang terlihat pada setiap halaman PDF Anda. Anda memilih posisi, format, ukuran font, dan warna, sisanya ditangani alat ini.

## Cara Kerja

1. Unggah file PDF Anda.
2. Atur pengaturan nomor halaman di panel opsi yang muncul.
3. Klik **Tambah Nomor Halaman** untuk memproses.
4. PDF bernomor diunduh secara otomatis.

## Opsi

- **Posisi**: Pilih tempat nomor halaman muncul: Bawah Tengah, Bawah Kiri, Bawah Kanan, Atas Tengah, Atas Kiri, atau Atas Kanan.
- **Format**: Pilih antara penomoran sederhana (1, 2, 3...) atau format "halaman X dari Y" (1 / 5, 2 / 5...).
- **Ukuran Font**: Atur ukuran teks nomor halaman. Default 12.
- **Warna**: Pilih warna apa pun untuk teks nomor halaman menggunakan pemilih warna.

## Fitur

- Enam pilihan posisi yang mencakup semua sudut dan posisi tengah
- Dua format penomoran: berurutan sederhana atau "halaman X dari Y"
- Ukuran font dapat diatur dari 6 hingga 72 poin
- Pemilih warna penuh untuk warna teks
- Penanganan margin otomatis yang menjaga nomor tetap di area aman pada ukuran halaman apa pun

## Kasus Penggunaan

- Menyiapkan dokumen cetak yang memerlukan rujukan halaman yang terlihat
- Menambahkan nomor halaman pada PDF gabungan dari beberapa file sumber
- Menomori handout presentasi sebelum dibagikan
- Menambahkan penomoran berurutan pada dokumen hukum atau kontrak

## Tips

- Format "halaman X dari Y" berguna untuk dokumen yang pembacanya perlu tahu total panjangnya, seperti proposal atau laporan.
- Jika Anda memerlukan gaya penomoran berbeda untuk bagian berbeda (seperti angka Romawi untuk bagian awal), gunakan alat [Tambahkan label halaman](./add-page-labels).

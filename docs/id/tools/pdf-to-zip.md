# PDF ke ZIP

Gabungkan beberapa file PDF ke dalam satu arsip ZIP. Ini adalah alat pengemasan sederhana, tanpa konversi, kompresi, atau perubahan pada PDF itu sendiri.

## Cara Kerja

1. Unggah beberapa file PDF menggunakan zona lepas.
2. Periksa daftar file. Hapus yang tidak ingin disertakan.
3. Klik tombol proses.
4. Arsip ZIP berisi semua PDF yang diunggah langsung diunduh.

## Fitur

- Menerima file PDF dalam jumlah berapa pun
- Penghapusan per file sebelum membuat arsip
- Mempertahankan nama file asli di dalam ZIP
- Tidak mengubah konten PDF, file dikemas apa adanya
- Menampilkan nama dan ukuran file untuk setiap PDF yang diunggah

## Kasus Penggunaan

- Menggabungkan sekumpulan faktur atau tanda terima sebagai lampiran email
- Mengemas hasil proyek (beberapa laporan PDF) untuk serah terima
- Membuat satu unduhan untuk kumpulan formulir atau templat
- Mengarsipkan sekumpulan dokumen ke dalam satu file terkompresi

## Tips

- File ZIP memakai nama file PDF asli. Jika Anda memiliki file dengan nama yang sama, ubah namanya sebelum mengunggah untuk menghindari konflik.
- Alat ini tidak mengompres PDF itu sendiri. Untuk mengurangi ukuran file, jalankan melalui Kompres PDF terlebih dahulu, lalu kemas dengan alat ini.

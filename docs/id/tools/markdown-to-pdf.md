# Markdown ke PDF

Editor Markdown lengkap dengan pratinjau langsung dan ekspor PDF satu klik. Tulis dari awal, unggah file `.md` yang ada, atau tempel konten dari clipboard. Editor merender Markdown Anda secara real time dan mengekspor PDF bergaya menggunakan mesin cetak bawaan browser.

## Format yang Didukung

| Input          | Deskripsi                    |
| :------------- | :--------------------------- |
| File `.md`     | Unggah melalui tombol Unggah |
| Input langsung | Ketik atau tempel ke editor  |

## Cara Kerja

1. Buka alat Markdown ke PDF. Editor dimuat dengan tampilan terbagi: sumber Markdown di kiri, pratinjau hasil render di kanan.
2. Tulis Markdown Anda, tempel, atau klik **Unggah** untuk memuat file `.md`.
3. Beralih antara tema terang dan gelap menggunakan penggeser tema di toolbar.
4. Klik **Ekspor PDF** (atau tekan `Ctrl/Cmd + S`) untuk membuat PDF melalui dialog cetak browser.

## Fitur

Editor mendukung serangkaian fitur Markdown yang luas di luar dasar-dasarnya:

- **Markdown standar**: judul, tebal, miring, tautan, gambar, daftar, kutipan blok, garis horizontal
- **Blok kode** dengan penyorotan sintaks untuk 15+ bahasa (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash, dan lainnya)
- **Diagram Mermaid**: flowchart, diagram urutan, diagram ER, dan jenis bagan Mermaid lainnya dirender langsung di pratinjau
- **Tabel** dengan sintaks tabel Markdown standar
- **Daftar tugas** dengan kotak centang
- **Catatan kaki**, **subskrip**, **superskrip**
- **Daftar definisi**, **singkatan**
- Dukungan **Emoji** (`:smile:` dirender sebagai emoji)
- **Sorotan** (`==marked text==`) dan **sisipan** (`++inserted text++`)
- **URL tertaut otomatis**: URL biasa diubah menjadi tautan yang dapat diklik
- Pembuatan **daftar isi**
- **Tautan anchor** pada judul

## Kasus Penggunaan

- Menulis dokumentasi proyek dan mengekspor PDF yang rapi untuk pemangku kepentingan
- Membuat laporan teknis dengan contoh kode dan diagram arsitektur Mermaid
- Mengonversi README GitHub menjadi PDF untuk penggunaan offline atau pencetakan
- Menyusun proposal atau spesifikasi dengan daftar tugas dan tabel
- Membuat handout bergaya dari catatan kuliah yang ditulis dalam Markdown

## Tips

- Output PDF menggunakan fungsi cetak-ke-PDF browser. Di Chrome, Anda dapat menyesuaikan margin dan skala di dialog cetak sebelum menyimpan.
- Diagram Mermaid dirender di pratinjau tetapi mungkin memerlukan waktu sebentar untuk diinisialisasi pada penggunaan pertama.
- Gunakan `Ctrl/Cmd + S` sebagai pintasan keyboard untuk mengekspor tanpa perlu menekan tombol.

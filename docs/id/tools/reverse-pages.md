# Balik Halaman

Balik urutan halaman PDF sehingga halaman terakhir menjadi yang pertama, halaman kedua dari belakang menjadi yang kedua, dan seterusnya. Mendukung pemrosesan batch beberapa file sekaligus.

## Cara Kerja

1. Unggah satu atau beberapa file PDF.
2. Klik tombol proses.
3. Setiap file dibalik secara independen. Jika Anda mengunggah beberapa file, hasilnya berupa arsip ZIP berisi semua PDF yang sudah dibalik.
4. Satu file diunduh langsung sebagai PDF yang sudah dibalik.

## Fitur

- Pemrosesan batch: balik beberapa PDF dalam satu operasi
- Keluaran satu file untuk satu PDF, keluaran ZIP untuk beberapa
- Tombol hapus per file sebelum diproses
- Mempertahankan semua konten dan format halaman

## Kasus Penggunaan

- Memperbaiki dokumen yang dipindai dengan urutan terbalik
- Menyiapkan PDF presentasi untuk dibaca dari belakang ke depan
- Membalik urutan halaman untuk alur kerja pencetakan tertentu yang memasukkan halaman secara terbalik
- Memperbaiki dokumen yang halamannya tidak sengaja tersusun terbalik

## Tips

- Setiap file dalam batch dibalik secara independen, urutan file satu sama lain tidak berubah.
- Untuk pengurutan ulang halaman yang lebih terperinci (bukan hanya pembalikan penuh), gunakan [Duplikat & Atur](./organize-pdf).

# VSD ke PDF

Konversi diagram Microsoft Visio menjadi PDF tanpa menginstal Visio. File VSD dan VSDX berisi diagram alur, bagan organisasi, diagram jaringan, dan denah yang tidak bisa dibuka kebanyakan orang. Alat ini merendernya menjadi PDF bersih yang bisa dilihat di perangkat apa pun.

## Format yang Didukung

| Format       | Ekstensi | Catatan                                       |
| :----------- | :------- | :-------------------------------------------- |
| Visio Binary | `.vsd`   | Format Visio lama (Visio 2003 dan sebelumnya) |
| Visio XML    | `.vsdx`  | Format Visio modern (Visio 2013+)             |

## Cara Kerja

1. Klik area unggah atau seret dan lepas file VSD atau VSDX Anda. Kedua format bisa dicampur dalam satu batch.
2. Tinjau daftar file. Hapus entri yang tidak diinginkan dengan ikon tempat sampah, atau gunakan **Tambah Lebih Banyak File** untuk menambah diagram.
3. Klik **Konversi ke PDF**. Mesin berbasis LibreOffice dimuat di browser dan merender setiap diagram menjadi PDF, dengan mempertahankan bentuk, konektor, label, dan tata letak halaman.
4. Satu diagram langsung diunduh sebagai PDF. Beberapa file menghasilkan arsip ZIP bernama `vsd-to-pdf.zip`.

## Opsi

Tidak diperlukan konfigurasi. Konverter mengikuti ukuran dan orientasi halaman asli dari dokumen Visio.

## Kasus Penggunaan

- Meninjau diagram Visio dari rekan kerja saat Anda tidak punya lisensi Visio
- Menyertakan diagram jaringan atau arsitektur dalam dokumentasi proyek sebagai PDF
- Mencetak bagan organisasi atau alur proses sebagai handout rapat
- Mengarsipkan file VSD lama dari Visio versi lama dalam format yang tahan masa depan

## Tips

- Dokumen Visio multi-halaman menghasilkan PDF multi-halaman, dengan setiap halaman Visio menjadi satu halaman PDF.
- File VSDX (format modern berbasis XML) umumnya dikonversi dengan fidelitas lebih tinggi daripada file biner VSD yang lebih lama.
- Mesin LibreOffice dimuat sekali per sesi. Harap tunggu sebentar pada konversi pertama, dan file berikutnya akan lebih cepat.

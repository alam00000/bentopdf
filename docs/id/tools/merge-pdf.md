# Gabung PDF

Gabungkan beberapa file PDF menjadi satu dokumen. Anda dapat menggabungkan seluruh file dalam urutan tertentu, atau beralih ke Mode Halaman untuk kontrol terperinci atas setiap halaman dari semua PDF yang diunggah.

## Cara Kerja

1. Unggah dua atau lebih file PDF dengan mengklik area lepas atau menyeretnya ke dalamnya.
2. Pilih antara **Mode File** dan **Mode Halaman** menggunakan sakelar di bagian atas.
3. Di Mode File, seret file untuk mengubah urutan dan secara opsional tentukan rentang halaman (misalnya `1-3, 5`) untuk setiap file. Biarkan rentang kosong untuk menyertakan semua halaman.
4. Di Mode Halaman, seret dan lepas thumbnail halaman satu per satu untuk menyusun urutan halaman yang Anda inginkan.
5. Klik **Gabung PDF** untuk menggabungkan semuanya menjadi satu file. PDF hasil gabungan diunduh secara otomatis.

## Fitur

- Dua mode penggabungan: Mode File untuk menggabungkan seluruh file dengan cepat, Mode Halaman untuk kontrol per halaman
- Pengurutan seret dan lepas di kedua mode dengan animasi yang mulus
- Sintaks rentang halaman (misalnya `1-3, 5, 8-10`) memungkinkan Anda memilih halaman tanpa beralih ke Mode Halaman
- Thumbnail halaman yang dimuat bertahap menjaga antarmuka tetap responsif bahkan dengan dokumen besar
- Tidak ada batas jumlah file atau total halaman
- Mempertahankan kualitas PDF asli tanpa pengodean ulang

## Opsi

| Opsi              | Deskripsi                                                                                          |
| ----------------- | -------------------------------------------------------------------------------------------------- |
| **Mode File**     | Gabungkan seluruh file dalam urutan kustom, dengan filter rentang halaman opsional per file        |
| **Mode Halaman**  | Kisi visual semua halaman dari semua file: seret thumbnail untuk menyusun urutan Anda              |
| **Input halaman** | Kolom teks per file yang menerima rentang seperti `1-3, 5` untuk menyertakan halaman tertentu saja |

## Kasus Penggunaan

- Menggabungkan PDF bab terpisah menjadi satu buku atau laporan
- Menggabungkan surat lamaran dan resume menjadi satu dokumen lamaran
- Mengambil halaman tertentu dari beberapa dokumen sumber ke dalam satu file gabungan
- Menyusun struk atau faktur hasil pindai menjadi satu PDF arsip
- Membuat handout presentasi dari slide di beberapa deck

## Tips

- Gunakan Mode Halaman saat Anda perlu menyisipkan halaman dari file berbeda secara selang-seling, bukan menambahkan satu file setelah file lainnya.
- Anda dapat menambahkan file setelah unggahan awal menggunakan tombol **Tambah File Lagi** tanpa kehilangan susunan saat ini.
- Rentang halaman dimulai dari 1, jadi `1` merujuk ke halaman pertama file tersebut.

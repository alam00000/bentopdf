# Posterisasi PDF

Bagi setiap halaman PDF menjadi kisi sub-halaman yang lebih kecil. Alat ini cocok untuk mencetak satu halaman di beberapa lembar kertas, yang kemudian disusun bersama menjadi poster atau spanduk besar.

## Cara Kerja

1. Unggah file PDF.
2. Atur jumlah **baris** dan **kolom** untuk menentukan kisi (misalnya, 2 baris x 2 kolom membagi setiap halaman menjadi 4 sub-halaman).
3. Secara opsional, tentukan rentang halaman untuk membatasi halaman yang diposterisasi.
4. Kanvas pratinjau menampilkan lapisan kisi pada halaman saat ini sehingga Anda dapat melihat garis potongnya.
5. Berpindah antarhalaman untuk memeriksa lapisan kisi di halaman lain.
6. Klik tombol proses. Setiap sel kisi menjadi halaman tersendiri di PDF hasil.

## Fitur

- Jumlah baris dan kolom yang dapat diatur untuk ukuran kisi yang fleksibel
- Pratinjau langsung dengan lapisan kisi yang menunjukkan persis di mana halaman akan dibagi
- Filter rentang halaman untuk memposterisasi halaman tertentu saja
- Navigasi halaman demi halaman di pratinjau
- Cuplikan halaman yang di-cache untuk navigasi pratinjau yang cepat
- Garis kisi merah putus-putus menandai batas potongan dengan jelas

## Opsi

| Opsi                | Deskripsi                                           |
| ------------------- | --------------------------------------------------- |
| **Baris**           | Jumlah pembagian horizontal (default: 1)            |
| **Kolom**           | Jumlah pembagian vertikal (default: 1)              |
| **Rentang halaman** | Halaman yang diposterisasi (kosong = semua halaman) |

## Kasus Penggunaan

- Mencetak PDF berukuran poster di lembar A4 atau Letter standar untuk dirangkai di dinding
- Membuat spanduk besar dari desain PDF satu halaman
- Membagi gambar teknis berukuran besar menjadi potongan yang dapat dicetak
- Membuat cetakan format besar tanpa printer format lebar

## Tips

- Kisi 2x2 mengubah satu halaman menjadi 4 halaman. Kisi 3x3 mengubah satu halaman menjadi 9. Rencanakan kisi Anda berdasarkan seberapa besar hasil akhir yang diinginkan.
- Lapisan pratinjau membantu Anda memastikan konten penting tidak jatuh pada garis potong. Ubah baris/kolom jika perlu.
- Untuk operasi sebaliknya (memuat beberapa halaman dalam satu lembar), gunakan [N-Up PDF](./n-up-pdf).

# ODG ke PDF

Konversi file OpenDocument Graphics menjadi PDF. ODG adalah format asli LibreOffice Draw dan digunakan untuk diagram, flowchart, dan ilustrasi vektor. Mengonversinya ke PDF membuat gambar-gambar ini mudah dibagikan, dicetak, dan disematkan di dokumen lain.

## Format yang Didukung

| Format                | Ekstensi | Catatan                                 |
| :-------------------- | :------- | :-------------------------------------- |
| OpenDocument Graphics | `.odg`   | File LibreOffice Draw / OpenOffice Draw |

## Cara Kerja

1. Klik area unggah atau seret dan lepas file ODG Anda. Beberapa file dapat ditambahkan sekaligus.
2. Periksa daftar file. Hapus entri tertentu dengan ikon tempat sampah, atau klik **Tambah File Lagi** untuk menambah gambar.
3. Klik **Konversi ke PDF**. Mesin berbasis LibreOffice dimuat di browser dan mengonversi setiap file ODG, dengan mempertahankan grafik vektor, bentuk, dan teks.
4. Satu file langsung diunduh sebagai PDF. Beberapa file menghasilkan arsip ZIP bernama `odg-to-pdf.zip`.

## Opsi

Tidak diperlukan pengaturan tambahan. Konversi mempertahankan dimensi halaman, bentuk, konektor, dan kotak teks asli dari sumber ODG.

## Kasus Penggunaan

- Membagikan diagram LibreOffice Draw kepada klien yang tidak memasang LibreOffice
- Mencetak flowchart dan diagram jaringan yang dibuat di Draw
- Menyertakan ilustrasi ODG dalam laporan atau presentasi sebagai PDF tersemat
- Mengarsipkan gambar teknis dalam format yang tetap terbaca selama puluhan tahun

## Tips

- Elemen vektor tetap berupa vektor di output PDF, sehingga hasilnya dapat diskalakan dengan bersih ke ukuran cetak apa pun.
- Mesin LibreOffice membutuhkan waktu sebentar untuk diinisialisasi pada penggunaan pertama. Konversi berikutnya dalam sesi yang sama lebih cepat.

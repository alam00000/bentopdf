# Tambah Stempel

Tempatkan stempel gambar pada halaman PDF Anda menggunakan penampil tertanam dengan toolbar anotasi stempel. Stempel dapat menyertakan nama Anda sebagai atribusi, sehingga berguna untuk alur persetujuan, proses peninjauan, dan penandaan dokumen.

## Cara Kerja

1. Masukkan nama Anda di kolom **Nama Pengguna Stempel**. Nama ini akan muncul pada stempel yang Anda buat.
2. Unggah file PDF Anda dengan mengklik atau menyeretnya ke area unggah.
3. Editor stempel terbuka dengan dokumen Anda dimuat di penampil.
4. Gunakan alat stempel gambar di toolbar untuk memilih dan menempatkan stempel di halaman mana pun.
5. Atur posisi dan ubah ukuran stempel sesuai kebutuhan.
6. Klik **Simpan PDF Berstempel** untuk mengunduh hasilnya.

## Fitur

- Penampil PDF terpadu dengan toolbar anotasi khusus stempel
- Atribusi nama pengguna pada stempel yang dibuat
- Penempatan stempel gambar di halaman mana pun
- Pengaturan posisi dan ukuran dengan seret dan lepas
- Ukuran penampil otomatis berdasarkan rasio aspek halaman
- Tampilan file dengan informasi nama dan ukuran

## Kasus Penggunaan

- Menambahkan stempel gambar "APPROVED" atau "REVIEWED" pada dokumen dalam alur peninjauan
- Menempatkan gambar stempel perusahaan atau notaris pada dokumen resmi
- Menandai halaman dengan stempel "RECEIVED" yang menyertakan nama peninjau
- Menambahkan stempel kendali mutu pada laporan inspeksi

## Tips

- Atur nama pengguna stempel sebelum mengunggah PDF. Nama pengguna disematkan dalam metadata stempel.
- Penampil menyesuaikan tingginya berdasarkan rasio aspek halaman pertama PDF agar tampilan optimal.
- Untuk watermark berbasis teks alih-alih stempel gambar, gunakan alat [Tambah Watermark](./add-watermark).

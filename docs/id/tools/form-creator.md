# Buat Formulir PDF

Rancang formulir PDF profesional yang dapat diisi dari awal atau dengan menambahkan kolom ke PDF yang sudah ada. Editor visual memungkinkan Anda menyeret dan melepas elemen formulir (kolom teks, kotak centang, menu tarik-turun, tombol radio, kolom tanda tangan, dan lainnya) langsung ke pratinjau halaman. Atur properti kolom, siapkan aturan visibilitas bersyarat, dan ekspor formulir PDF yang sepenuhnya interaktif.

## Cara Kerja

1. Unggah PDF yang sudah ada **atau** klik **Buat PDF Kosong** untuk memulai dari awal.
2. Jika membuat PDF kosong, pilih ukuran halaman (Letter, A4, A5, Legal, Tabloid, A3, atau dimensi kustom).
3. Editor formulir terbuka dengan toolbar jenis kolom dan area pratinjau halaman.
4. Pilih jenis kolom dari toolbar, lalu klik pada halaman untuk menempatkannya.
5. Seret kolom untuk memindahkannya. Gunakan gagang ubah ukuran untuk menyesuaikan dimensi.
6. Klik kolom untuk membuka panel properti tempat Anda dapat mengatur nama kolom, nilai default, ukuran font, perataan, dan lainnya.
7. Berpindah antarhalaman menggunakan kontrol halaman.
8. Klik **Simpan** untuk mengunduh PDF yang dapat diisi.

## Fitur

- Penempatan kolom dengan seret dan lepas serta gagang visual untuk mengubah ukuran
- Jenis kolom: input teks, teks multibaris, kotak centang, menu tarik-turun, tombol radio, tanda tangan, tanggal, angka, dan barcode
- Panel properti untuk mengatur nama, label, nilai default, ukuran font, warna, perataan, dan validasi setiap kolom
- Aksi kolom dan aturan visibilitas bersyarat (tampilkan/sembunyikan kolom berdasarkan nilai kolom lain)
- Navigasi halaman untuk formulir multihalaman
- Ekstraksi kolom yang ada: secara otomatis mendeteksi dan mengimpor kolom formulir dari PDF yang diunggah
- Dukungan untuk PDF yang diunggah maupun halaman kosong sebagai kanvas formulir
- Beberapa preset ukuran halaman plus dimensi kustom
- Pembuatan barcode didukung oleh bwip-js
- Pengelolaan grup tombol radio

## Opsi

**Preset ukuran halaman (untuk PDF kosong):**

- Letter (8.5" x 11")
- A4 (210mm x 297mm)
- A5 (148mm x 210mm)
- Legal (8.5" x 14")
- Tabloid (11" x 17")
- A3 (297mm x 420mm)
- Kustom (tentukan lebar dan tinggi)

**Properti kolom (bervariasi menurut jenis kolom):**

- Nama, label, dan teks placeholder
- Nilai default
- Jenis font, ukuran, dan warna
- Perataan teks (kiri, tengah, kanan)
- Sakelar kolom wajib diisi
- Sakelar hanya-baca
- Panjang maksimum untuk kolom teks
- Daftar opsi untuk menu tarik-turun dan tombol radio
- Aksi visibilitas bersyarat

## Kasus Penggunaan

- Membuat formulir onboarding karyawan dengan kolom teks untuk informasi pribadi dan kotak centang untuk persetujuan kebijakan
- Membuat kuesioner penerimaan klien dengan menu tarik-turun untuk memilih layanan
- Merancang formulir pemesanan dengan kolom terhitung dan pengenal barcode
- Membuat daftar periksa inspeksi dengan tombol radio untuk penilaian lulus/gagal
- Membuat formulir survei dengan pertanyaan lanjutan bersyarat yang muncul berdasarkan jawaban

## Tips

- Jika Anda mengunggah PDF yang sudah ada, alat ini akan mencoba mengekstrak kolom formulir yang sudah ada sehingga Anda dapat mengedit atau menambahkannya.
- Gunakan fitur grup tombol radio untuk membuat pilihan yang saling eksklusif. Kolom dalam grup radio yang sama berbagi nama grup.
- Uji formulir Anda dengan mengunduhnya dan membukanya di [Pengisi Formulir PDF](./form-filler) untuk memverifikasi perilaku kolom.

# Editor PDF

Editor PDF BentoPDF memungkinkan Anda memberi anotasi, menyorot, meredaksi, berkomentar, menambah bentuk dan gambar, serta mencari di dalam PDF Anda. Editor lengkap dimuat langsung di browser Anda tanpa unggahan ke server.

## Cara Kerja

1. Unggah PDF Anda dengan mengklik area unggah atau menyeret file ke dalamnya.
2. Editor PDF tertanam terbuka otomatis dengan dokumen Anda sudah dimuat.
3. Gunakan toolbar untuk memberi anotasi, menyorot, meredaksi, menambah teks, menggambar bentuk, atau menyisipkan gambar.
4. Klik **Unduh PDF yang Diedit** untuk menyimpan perubahan Anda.

## Fitur

- Toolbar anotasi lengkap dengan sorotan, garis bawah, coretan, dan gambar bebas
- Penyisipan teks dan komentar
- Alat redaksi yang menghapus konten bertanda secara permanen setelah Anda menerapkan redaksi. Jika ada tanda yang belum diterapkan saat Anda mengklik **Unduh PDF yang Diedit**, editor menawarkan untuk menerapkannya terlebih dahulu.
- Alat bentuk untuk persegi panjang, lingkaran, garis, dan panah
- Penyisipan gambar ke halaman PDF
- Pencarian teks bawaan di seluruh dokumen
- Dukungan multi-dokumen dengan tab (hingga 10 dokumen terbuka bersamaan)
- Pemuatan file dengan seret dan lepas

## Kasus Penggunaan

- Meninjau kontrak dan menandai perubahan dengan sorotan dan komentar
- Meredaksi informasi rahasia seperti nomor identitas atau data keuangan sebelum dibagikan
- Menambahkan anotasi pada denah arsitektur atau gambar teknik
- Menyisipkan logo atau stempel perusahaan ke halaman dokumen
- Mencari istilah tertentu di dokumen hukum yang panjang

## Tips

- Anda dapat membuka beberapa PDF sekaligus dan berpindah di antaranya menggunakan bilah tab di bagian atas editor.
- Editor mempertahankan struktur PDF asli, sehingga font, tata letak, dan kolom formulir tetap utuh.
- Menandai teks atau area untuk redaksi tidak menghapus apa pun sampai redaksi diterapkan. Saat Anda meredaksi teks terpilih, salinannya di properti file, bookmark, komentar, dan lampiran juga dihapus dari hasil unduhan, kecuali file terenkripsi.
- Untuk watermark massal atau penomoran halaman, gunakan alat khusus agar kontrol format lebih baik.

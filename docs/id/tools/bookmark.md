# Edit Bookmark

Editor bookmark memberi Anda kendali penuh atas bookmark navigasi PDF (disebut juga outline). Anda dapat menambah bookmark baru, mengedit yang sudah ada, menata ulang hierarki, serta mengimpor atau mengekspor data bookmark dalam format CSV dan JSON.

## Cara Kerja

1. Unggah PDF Anda dengan mengklik atau menyeret file ke area unggah.
2. Secara opsional, centang **Ekstrak otomatis bookmark yang ada** untuk memuat struktur bookmark yang sudah ada di dokumen.
3. Editor terbuka dengan tampilan terbagi: penampil PDF di kiri, panel bookmark di kanan.
4. Ketik judul bookmark lalu klik **Tambahkan ke Halaman** untuk membuat bookmark yang mengarah ke halaman saat ini.
5. Gunakan tombol di toolbar untuk menata ulang, memberi gaya, atau menghapus bookmark.
6. Klik **Simpan PDF dengan Bookmark** untuk mengunduh file yang sudah diperbarui.

## Fitur

- Penampil PDF visual dengan navigasi halaman, kontrol zoom, dan input pindah ke halaman
- Tambah bookmark ke halaman mana pun dengan satu klik
- Klik langsung pada PDF untuk menentukan tujuan bookmark secara presisi (mode pemilihan)
- Hierarki bookmark bertingkat dengan penataan ulang melalui seret dan lepas
- Operasi massal: pilih beberapa bookmark untuk mengubah warna, gaya, atau menghapusnya sekaligus
- Pencarian bookmark untuk menemukan entri dengan cepat di struktur yang besar
- Dukungan undo dan redo untuk semua perubahan
- Impor bookmark dari file CSV (judul, halaman, level) atau JSON
- Ekspor bookmark ke CSV atau JSON untuk diedit di luar
- Gaya bookmark: warna (merah, biru, hijau, kuning, ungu) dan gaya font (tebal, miring, tebal miring)
- Navigasi cepat: telusuri halaman dengan tombol page up/down

## Opsi

- **Ekstrak otomatis bookmark yang ada**: Jika dicentang, alat membaca dan menampilkan bookmark PDF yang ada saat dimuat.
- **Mode Massal**: Aktifkan untuk memilih beberapa bookmark dan menerapkan perubahan warna, gaya, atau penghapusan secara massal.
- **Luaskan Semua / Ciutkan Semua**: Tampilkan atau sembunyikan anak bookmark bertingkat dengan cepat.

## Kasus Penggunaan

- Menambahkan daftar isi ke buku teks atau manual yang belum memiliki bookmark
- Menyusun ulang bookmark pada dokumen hasil pindai setelah proses OCR
- Mengekspor bookmark ke CSV, mengeditnya di spreadsheet, lalu mengimpornya kembali
- Merapikan bookmark buatan otomatis yang memiliki referensi halaman keliru
- Menambahkan bookmark berwarna untuk menandai bagian penting dalam berkas hukum

## Tips

- Gunakan impor CSV untuk membuat banyak bookmark sekaligus. Formatnya sederhana: `title,page,level` dengan level 1 sebagai tingkat teratas.
- Mode pemilihan memungkinkan Anda mengklik titik tertentu di halaman PDF untuk menentukan tujuan bookmark, yang lebih presisi daripada hanya menargetkan nomor halaman.
- Ekspor bookmark Anda sebelum melakukan perubahan besar agar Anda memiliki cadangan.

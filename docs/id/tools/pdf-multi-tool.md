# Alat Multi PDF

Ruang kerja terpadu untuk setiap operasi tingkat halaman PDF. Unggah satu atau beberapa PDF dan kerjakan semua halamannya dalam satu kisi visual. Putar, atur ulang, duplikat, hapus, sisipkan PDF, gambar, dan halaman kosong, beri nomor ulang, ubah ukuran, dan pisahkan hasilnya, semuanya tanpa meninggalkan alat ini.

## Cara Kerja

1. Klik **Pilih File** atau seret file ke area unggah. Beberapa file didukung dan digabung sesuai urutan unggah.
2. Semua halaman tampil dalam kisi yang bisa digulir dengan thumbnail.
3. Klik halaman untuk memilihnya. Gunakan Shift+klik untuk memilih rentang dan Cmd/Ctrl+klik untuk menambah atau mengurangi halaman satu per satu.
4. Gunakan toolbar pengatur halaman atau klik kanan halaman untuk aksi halaman.
5. Klik **Ekspor PDF** untuk mengunduh hasil akhir.

## Fitur

- **Gabung**: Unggah beberapa PDF dan gambar, semuanya otomatis digabung menjadi satu dokumen
- **Atur ulang**: Seret dan lepas halaman untuk menyusun ulang urutan, atau balik urutan seluruh dokumen
- **Putar**: Putar halaman terpilih ke kiri atau kanan dalam kelipatan 90 derajat
- **Duplikat**: Salin halaman terpilih dan letakkan salinannya tepat setelahnya
- **Hapus**: Hapus halaman yang dipilih
- **Sisipkan**: Tambahkan halaman dari PDF atau gambar lain, halaman kosong, halaman dari clipboard, atau selang-selingkan halaman PDF kedua dengan halaman saat ini
- **Ganti**: Tukar halaman dengan halaman pertama dari PDF lain
- **Potong, salin, dan tempel**: Pindahkan atau salin halaman di dalam dokumen
- **Ekstrak**: Unduh halaman terpilih sebagai PDF atau gambar
- **Nomor Halaman**: Atur label halaman seperti i, ii, iii atau A-1, A-2 untuk rentang halaman tertentu
- **Ukuran Halaman**: Sesuaikan halaman dengan ukuran kertas standar atau ukuran kustom
- **Pisah**: Bagi dokumen berdasarkan rentang halaman, halaman ganjil dan genap, setiap halaman, bookmark, setiap N halaman, atau ukuran file
- **Urungkan / Ulangi**: Setiap operasi halaman bisa diurungkan dan diulangi
- Memperbaiki PDF yang rusak secara otomatis sebelum dimuat

## Pintasan Keyboard

| Aksi                  | Pintasan                      |
| --------------------- | ----------------------------- |
| Putar ke kanan / kiri | R / Shift+R                   |
| Pilih semua           | Cmd/Ctrl+A                    |
| Potong, salin, tempel | Cmd/Ctrl+X, C, V              |
| Duplikat              | Cmd/Ctrl+D                    |
| Hapus                 | Delete atau Backspace         |
| Urungkan / Ulangi     | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| Pindahkan pilihan     | Tombol panah, Home, End       |

## Kasus Penggunaan

- Membuat dokumen kustom dari halaman-halaman beberapa PDF sumber
- Merapikan dokumen pindaian dengan menghapus halaman kosong, memutar pindaian yang miring, dan mengatur ulang bagian
- Memisah PDF besar pada batas bab menggunakan bookmark-nya
- Penyuntingan tingkat halaman yang cepat tanpa memerlukan editor PDF lengkap

## Tips

- Riwayat urungkan/ulangi melacak setiap operasi halaman. Gunakan dengan bebas, Anda tidak bisa merusak pekerjaan Anda secara tidak sengaja.
- Gunakan **Insert > From File** atau letakkan PDF atau gambar lain ke kisi halaman kapan saja untuk menambahkannya ke dokumen.
- Untuk tugas gabung atau pisah sederhana, alat khusus [Gabung PDF](./merge-pdf) atau [Pisah PDF](./split-pdf) mungkin lebih cepat. Alat Multi unggul saat Anda memerlukan banyak operasi dalam satu sesi.

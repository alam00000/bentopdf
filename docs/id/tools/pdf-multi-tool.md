# Alat Multi PDF

Ruang kerja terpadu untuk setiap operasi tingkat halaman PDF. Unggah satu atau beberapa PDF dan kerjakan semua halamannya dalam satu kisi visual. Putar, atur ulang, duplikat, hapus, sisipkan PDF baru, tambah halaman kosong, dan pisahkan hasilnya, semuanya tanpa meninggalkan alat ini.

## Cara Kerja

1. Klik **Unggah PDF** atau seret file ke area unggah. Beberapa file didukung.
2. Semua halaman dari setiap file yang diunggah tampil dalam kisi yang bisa digulir dengan thumbnail.
3. Gunakan toolbar atau tombol aksi per halaman untuk memanipulasi halaman.
4. Pilih halaman dengan kotak centang pada setiap kartu, lalu terapkan operasi massal.
5. Tandai titik pisah dengan ikon gunting untuk membagi hasil menjadi file terpisah.
6. Klik **Ekspor PDF** untuk mengunduh hasil akhir. Jika ada penanda pisah, hasilnya berupa ZIP berisi beberapa PDF.

## Fitur

- **Gabung**: Unggah beberapa PDF dan semuanya otomatis digabung dalam satu ruang kerja
- **Atur ulang**: Seret dan lepas kartu halaman untuk menyusun ulang urutan
- **Putar**: Rotasi per halaman atau massal dalam kelipatan 90 derajat (kiri atau kanan)
- **Duplikat**: Gandakan halaman apa pun dengan satu klik
- **Hapus**: Hapus halaman satu per satu atau hapus massal halaman yang dipilih
- **Sisipkan PDF**: Tambahkan PDF baru setelah halaman tertentu
- **Tambah Halaman Kosong**: Tambahkan halaman A4 kosong di akhir
- **Pisah**: Letakkan penanda pisah di antara halaman, lalu ekspor sebagai ZIP berisi PDF terpisah
- **Pilih Semua / Batalkan Semua**: Pemilihan cepat untuk operasi massal
- **Urungkan / Ulangi**: Riwayat urungkan/ulangi penuh untuk setiap operasi
- **Unduh yang dipilih**: Ekspor hanya halaman terpilih sebagai PDF mandiri
- Memperbaiki PDF yang rusak secara otomatis sebelum dimuat

## Kasus Penggunaan

- Membuat dokumen kustom dari halaman-halaman beberapa PDF sumber
- Merapikan dokumen pindaian dengan menghapus halaman kosong, memutar pindaian yang miring, dan mengatur ulang bagian
- Memisah PDF besar pada batas bab menggunakan penanda pisah visual
- Penyuntingan tingkat halaman yang cepat tanpa memerlukan editor PDF lengkap

## Tips

- Sistem urungkan/ulangi melacak setiap operasi. Gunakan dengan bebas, Anda tidak bisa merusak pekerjaan Anda secara tidak sengaja.
- Penanda pisah tampil sebagai garis putus-putus biru di antara halaman. Letakkan secara visual di tempat dokumen ingin dibagi, lalu ekspor untuk mendapatkan ZIP.
- Untuk tugas gabung atau pisah sederhana, alat khusus [Gabung PDF](./merge-pdf) atau [Pisah PDF](./split-pdf) mungkin lebih cepat. Alat Multi unggul saat Anda memerlukan banyak operasi dalam satu sesi.

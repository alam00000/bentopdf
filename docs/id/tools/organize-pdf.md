# Atur & Duplikat

Susun ulang, duplikat, dan hapus halaman dari PDF menggunakan antarmuka visual seret dan lepas. Setiap halaman tampil sebagai thumbnail yang bisa dipindahkan, digandakan, atau dihapus sebelum hasilnya disimpan sebagai file baru.

## Cara Kerja

1. Unggah satu file PDF.
2. Alat ini merender kisi thumbnail yang menampilkan setiap halaman.
3. Seret thumbnail untuk mengatur ulang halaman, klik tombol duplikat hijau untuk menggandakan halaman, atau klik tombol hapus merah untuk menghapusnya.
4. Sebagai alternatif, masukkan urutan halaman kustom di kolom teks (mis., `3, 1, 2, 4`) lalu klik **Terapkan** untuk menyusun ulang semua halaman sekaligus.
5. Klik tombol proses untuk membuat dan mengunduh PDF yang sudah diatur ulang.

## Fitur

- Pengaturan ulang halaman dengan seret dan lepas disertai transisi animasi
- Tombol duplikat dan hapus per halaman
- Input urutan halaman kustom untuk penyusunan yang presisi
- Label nomor halaman yang diperbarui otomatis setelah setiap perubahan
- Mencegah penghapusan halaman terakhir yang tersisa

## Kasus Penggunaan

- Memindahkan halaman yang salah tempat ke posisi yang benar dalam laporan
- Menduplikat halaman formulir agar Anda memiliki beberapa salinan kosong dalam satu file
- Menghapus halaman draf atau placeholder sebelum dokumen dibagikan
- Membalik atau mengacak urutan halaman untuk persiapan cetak
- Membuat urutan halaman kustom tanpa menggabungkan ulang file terpisah

## Tips

- Kolom urutan halaman kustom menerima nomor halaman asli yang dipisahkan koma. Setiap halaman harus disertakan tepat satu kali, tanpa ada yang terlewat atau duplikat.
- Setelah menduplikat halaman, kedua salinan merujuk ke indeks halaman asli yang sama. Mengatur ulang salah satu salinan bekerja secara independen.
- Untuk operasi massal pada beberapa file atau alur kerja yang lebih lanjut, pertimbangkan [Alat Multi PDF](./pdf-multi-tool).

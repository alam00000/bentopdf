# Hapus Anotasi

Bersihkan PDF Anda dengan menghapus semua anotasi: komentar, sorotan, catatan tempel, markup teks, tautan, stempel, dan objek anotasi lain yang tertanam di dokumen. Konten halaman di bawahnya (teks, gambar, grafik) tidak tersentuh.

## Cara Kerja

1. Unggah file PDF Anda.
2. Alat mendeteksi jumlah halaman dokumen dan menampilkan informasi file.
3. Klik **Hapus Anotasi** untuk memproses.
4. PDF yang sudah bersih diunduh otomatis tanpa anotasi apa pun.

## Fitur

- Menghapus semua jenis anotasi: komentar, sorotan, garis bawah, coretan, catatan tempel, stempel, tautan, dan markup formulir
- Bekerja pada setiap halaman di dokumen
- Mempertahankan semua konten non-anotasi (teks, gambar, grafik vektor, bidang formulir)
- Menampilkan jumlah halaman dan ukuran file sebelum diproses

## Kasus Penggunaan

- Membersihkan dokumen sebelum distribusi akhir setelah siklus peninjauan di mana beberapa peninjau menambahkan komentar
- Menghapus markup sorotan dan catatan tempel dari panduan belajar yang dibagikan
- Menghapus anotasi tautan dari dokumen sebelum diarsipkan
- Menyiapkan versi "bersih" dari dokumen hukum yang banyak dianotasi selama negosiasi
- Menghapus komentar peninjau dari naskah sebelum dikirim ke percetakan

## Tips

- Alat ini menghapus anotasi pada tingkat struktur PDF, sehingga hasilnya tetap memiliki teks yang dapat dipilih dan kualitas asli, tanpa rasterisasi.
- Jika Anda hanya ingin menghapus anotasi tertentu, bukan semuanya, gunakan [Editor PDF](./edit-pdf) untuk menghapus anotasi satu per satu.
- Anotasi di PDF yang sudah diratakan (di mana anotasi telah digabung ke konten halaman) tidak dapat dihapus karena sudah bukan objek terpisah.

# Bandingkan PDF

Unggah dua PDF dan lihat dengan tepat apa yang berubah di antara keduanya. Alat ini memasangkan halaman secara cerdas, mendeteksi perbedaan pada teks, gambar, anotasi, header, dan format, lalu menampilkannya dalam tampilan berdampingan atau overlay.

## Cara Kerja

1. Unggah dua file PDF: versi asli (kiri) dan versi revisi (kanan).
2. Alat memasangkan halaman antar dokumen menggunakan signature konten.
3. Pilih mode tampilan: **Berdampingan** atau **Tumpang Tindih**.
4. Berpindah antar pasangan halaman menggunakan kontrol paginasi.
5. Perbedaan disorot dan dikelompokkan. Gunakan panel filter untuk berfokus pada jenis perubahan tertentu.
6. Secara opsional, ekspor hasil perbandingan sebagai laporan PDF.

## Fitur

- Pemasangan halaman otomatis berdasarkan kemiripan konten
- Tampilan perbandingan berdampingan dan overlay
- Pengelompokan perubahan: teks, gambar, header/footer, anotasi, format, latar belakang
- Tombol filter per kategori untuk menampilkan atau menyembunyikan jenis perubahan tertentu
- Pencarian perubahan teks dengan filter kueri
- Dukungan OCR untuk membandingkan dokumen hasil pindai
- Kontrol zoom untuk pemeriksaan terperinci
- Pengguliran tersinkron antar panel pada mode berdampingan
- Ekspor hasil perbandingan sebagai PDF

## Opsi

| Opsi                  | Deskripsi                                                                                   |
| --------------------- | ------------------------------------------------------------------------------------------- |
| **Mode Tampilan**     | Berdampingan atau Tumpang Tindih                                                            |
| **OCR**               | Aktifkan/nonaktifkan OCR untuk perbandingan dokumen hasil pindai                            |
| **Bahasa OCR**        | Bahasa untuk ekstraksi teks OCR                                                             |
| **Filter Kategori**   | Atur visibilitas perubahan teks, gambar, header/footer, anotasi, format, dan latar belakang |
| **Cakupan Perubahan** | Pada mode tumpang tindih, filter antara semua perubahan atau hanya konten                   |
| **Zoom**              | Atur tingkat pembesaran untuk pemeriksaan terperinci                                        |

## Kasus Penggunaan

- Meninjau revisi kontrak untuk menemukan dengan tepat apa yang berubah antar versi
- Membandingkan mockup desain untuk memastikan ekspor PDF sesuai harapan
- Mengaudit perubahan dokumen di industri teregulasi yang mewajibkan setiap suntingan dicatat
- Memverifikasi bahwa proses konversi PDF mempertahankan konten asli dengan akurat
- Memeriksa dokumen terjemahan terhadap sumbernya untuk perubahan tata letak

## Tips

- Tampilan overlay menumpuk kedua dokumen sehingga perbedaan spasial (elemen bergeser, gambar berubah ukuran) langsung terlihat.
- Aktifkan OCR saat membandingkan dokumen hasil pindai yang tidak memiliki lapisan teks. Mesin perbandingan akan mengekstrak teks dari gambar halaman.
- Gunakan filter kategori untuk berfokus pada yang penting. Misalnya, sembunyikan perubahan format jika Anda hanya peduli pada perbedaan isi teks.

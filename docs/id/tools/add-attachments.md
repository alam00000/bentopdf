# Tambah Lampiran

Sematkan satu atau beberapa file langsung ke dalam dokumen PDF. Lampiran dapat ditambahkan pada tingkat dokumen (terlihat di panel lampiran pembaca PDF mana pun) atau diikat ke halaman tertentu.

## Cara Kerja

1. Unggah PDF yang ingin Anda beri lampiran.
2. Gunakan area penyimpanan lampiran untuk memilih file yang ingin disematkan (format apa pun).
3. Pilih tingkat lampiran: **Dokumen** (default) atau **Halaman**.
4. Jika memilih tingkat Halaman, masukkan rentang halaman (misalnya `1-3` atau `5`).
5. Klik tombol proses. PDF yang telah diubah akan diunduh beserta file yang tersemat.

## Fitur

- Lampirkan file dalam format apa pun: gambar, spreadsheet, arsip, file eksekusi, apa saja
- Penempatan lampiran pada tingkat dokumen atau tingkat halaman
- Beberapa file dapat dilampirkan dalam satu operasi
- Menampilkan nama dan ukuran semua lampiran yang dipilih
- Hasil tetap mempertahankan isi PDF asli dengan file tersemat ditambahkan

## Opsi

| Opsi                | Deskripsi                                                                      |
| ------------------- | ------------------------------------------------------------------------------ |
| **Tingkat dokumen** | Melampirkan file ke PDF secara keseluruhan, dapat diakses dari panel lampiran  |
| **Tingkat halaman** | Melampirkan file ke halaman tertentu, ditentukan melalui input rentang halaman |

## Kasus Penggunaan

- Menggabungkan data sumber (file Excel, CSV) dengan laporan PDF
- Melampirkan file gambar asli ke PDF portofolio fotografi
- Menyematkan dokumen pendukung di dalam kontrak atau proposal
- Menambahkan materi tambahan ke halaman tertentu pada buku panduan pelatihan

## Tips

- Lampiran tingkat dokumen paling didukung di berbagai pembaca PDF. Lampiran tingkat halaman mungkin tidak terlihat di semua penampil.
- Tidak ada batas ukuran file untuk lampiran, tetapi file tersemat yang sangat besar akan menambah ukuran PDF secara proporsional.

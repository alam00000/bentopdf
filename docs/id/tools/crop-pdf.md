# Potong PDF

Pangkas margin halaman PDF Anda dengan antarmuka pemotongan visual. Gambar persegi pemotongan langsung pada setiap halaman, pratinjau hasilnya, lalu terapkan. Anda dapat menetapkan area pemotongan berbeda untuk halaman berbeda atau menerapkan pemotongan yang sama ke seluruh dokumen.

## Cara Kerja

1. Unggah file PDF Anda.
2. Editor pemotong terbuka, menampilkan halaman pertama dengan overlay pemotongan yang dapat diseret.
3. Sesuaikan persegi pemotongan dengan menyeret tepi atau sudutnya.
4. Gunakan tombol navigasi halaman untuk berpindah antar halaman dan menetapkan area pemotongan untuk masing-masing.
5. Klik **Potong & Unduh** untuk menerapkan pemotongan dan mengunduh hasilnya.

## Fitur

- Editor pemotongan visual berbasis Cropper.js dengan handle untuk penyesuaian presisi
- Navigasi halaman demi halaman untuk menetapkan area pemotongan individual
- Menyimpan pengaturan pemotongan per halaman sehingga Anda dapat menentukan pemotongan berbeda untuk halaman berbeda
- Pratinjau langsung area pemotongan yang dipilih
- Mendukung PDF dengan ukuran atau orientasi halaman apa pun

## Kasus Penggunaan

- Menghapus margin lebar dari dokumen hasil pindai agar fokus pada area konten
- Memangkas tanda potong atau tanda registrasi printer dari PDF prepress
- Memotong slide kuliah untuk menghapus area catatan presenter
- Menghapus header atau footer dari setiap halaman sebelum membagikan kutipan dokumen
- Mengubah ukuran halaman agar sesuai dengan tampilan atau tata letak cetak tertentu

## Tips

- Overlay pemotongan dapat diubah ukuran dan dipindahkan secara bebas. Seret sudut untuk mengubah ukuran secara proporsional atau tepi untuk penyesuaian satu sumbu.
- Untuk dokumen yang setiap halamannya memerlukan pemotongan yang sama, atur di halaman pertama. Alat mengingat area pemotongan Anda saat Anda berpindah halaman.
- Jika Anda perlu menyeragamkan ukuran halaman alih-alih memotong secara visual, alat Perbaiki Ukuran Halaman mungkin lebih cocok.

# EPUB ke PDF

Konversi ebook EPUB menjadi file PDF tanpa meninggalkan browser Anda. EPUB adalah standar terbuka untuk buku digital, tetapi terkadang Anda membutuhkan PDF dengan tata letak tetap untuk dicetak, diberi anotasi, atau dibagikan kepada orang yang tidak memiliki pembaca ebook.

## Format yang Didukung

| Format | Ekstensi | Catatan                |
| :----- | :------- | :--------------------- |
| EPUB   | `.epub`  | File EPUB 2 dan EPUB 3 |

## Cara Kerja

1. Klik area unggah atau seret dan lepas file EPUB Anda. Pemilihan banyak file didukung.
2. Tinjau file yang diunggah. Hapus entri yang tidak diinginkan dengan ikon tempat sampah, atau klik **Tambah Lebih Banyak File** untuk memperluas batch.
3. Klik **Konversi ke PDF**. Mesin PyMuPDF merender konten EPUB (teks, gambar, dan format) menjadi output PDF berhalaman.
4. Satu EPUB diunduh langsung sebagai PDF. Beberapa file dikemas menjadi arsip ZIP bernama `epub-converted.zip`.

## Opsi

Konversi berjalan dengan default yang masuk akal tanpa konfigurasi wajib. Teks mengalir ke dimensi halaman standar, dan font serta gambar tertanam dibawa ke PDF.

## Kasus Penggunaan

- Mencetak ebook bebas DRM untuk dibaca jauh dari layar
- Mengirim naskah EPUB sebagai PDF dengan tata letak tetap untuk ditinjau
- Mengarsipkan buku digital dalam format yang dapat dibuka secara native oleh setiap sistem operasi
- Membagikan satu bab kepada rekan yang tidak memiliki pembaca EPUB
- Mengonversi dokumentasi teknis yang didistribusikan sebagai EPUB menjadi PDF yang dapat diberi anotasi

## Tips

- Fitur EPUB 3 seperti audio dan video tertanam tidak akan terbawa ke PDF, tetapi semua teks, gambar, dan tabel terkonversi dengan baik.
- Untuk hasil terbaik pada EPUB dengan gaya yang rumit, periksa beberapa halaman pertama output untuk memastikan kesetiaan tata letak.

# Ekstrak Halaman

Keluarkan sekumpulan halaman dari PDF dan simpan sebagai file baru. Tentukan dengan tepat halaman yang Anda inginkan menggunakan sintaks rentang, dan alat membuat PDF bersih yang hanya berisi halaman tersebut.

## Cara Kerja

1. Unggah file PDF. Alat menampilkan nama file, ukuran, dan jumlah total halaman.
2. Masukkan halaman yang ingin diekstrak dengan sintaks rentang (mis., `1-5`, `3, 7, 10-12`).
3. Secara opsional, pilih untuk mengunduh setiap rentang sebagai PDF terpisah dalam arsip ZIP.
4. Klik tombol proses. Halaman yang diekstrak diunduh sebagai PDF baru (atau ZIP).

## Fitur

- Sintaks rentang halaman yang fleksibel: halaman individual, rentang, atau kombinasi dipisah koma
- Menampilkan jumlah total halaman setelah unggah sebagai acuan mudah
- Opsi output sebagai satu PDF gabungan atau file terpisah dalam ZIP
- Mempertahankan konten dan format halaman asli

## Kasus Penggunaan

- Mengambil ringkasan eksekutif (beberapa halaman pertama) dari laporan yang panjang
- Mengekstrak satu bab dari PDF buku teks
- Menyimpan halaman tertentu dari paket formulir sebagai dokumen mandiri
- Membuat dokumen contoh dari halaman terpilih pada file yang lebih besar

## Tips

- Nomor halaman dimulai dari 1. Gunakan `1` untuk halaman pertama, bukan `0`.
- Untuk menghapus halaman alih-alih mengekstraknya, gunakan [Hapus Halaman](./delete-pages), yang merupakan operasi kebalikannya.
- Jika Anda memerlukan pemilihan halaman visual dengan thumbnail, gunakan [Pisah PDF](./split-pdf) dalam mode Visual Select.

# Putar PDF

Putar halaman PDF 90 derajat searah atau berlawanan arah jarum jam. Alat ini menampilkan pratinjau thumbnail setiap halaman, sehingga Anda dapat memutarnya satu per satu atau menerapkan rotasi massal ke seluruh dokumen.

## Cara Kerja

1. Unggah file PDF. Thumbnail setiap halaman dirender dalam kisi.
2. Gunakan tombol rotasi kiri/kanan di bawah thumbnail setiap halaman untuk memutar halaman tersebut.
3. Gunakan kontrol rotasi massal di bagian atas untuk memutar semua halaman sekaligus.
4. Pratinjau thumbnail diperbarui secara real-time untuk menunjukkan rotasi.
5. Klik tombol proses untuk menyimpan PDF yang sudah diputar.

## Fitur

- Rotasi per halaman dengan kelipatan 90 derajat (kiri atau kanan)
- Rotasi massal untuk semua halaman sekaligus
- Pratinjau thumbnail real-time dengan transisi rotasi beranimasi
- Thumbnail dimuat secara lazy untuk performa mulus pada dokumen besar
- Mempertahankan konten dan kualitas halaman asli

## Kasus Penggunaan

- Memperbaiki halaman hasil pindai yang miring ke samping atau terbalik
- Memutar halaman lanskap ke orientasi potret (atau sebaliknya)
- Memperbaiki dokumen berorientasi campuran di mana beberapa halaman dipindai dengan sudut yang salah
- Menyiapkan dokumen untuk orientasi tampilan tertentu

## Tips

- Rotasi bersifat kumulatif. Mengklik tombol searah jarum jam dua kali menerapkan rotasi 180 derajat.
- Untuk rotasi non-90 derajat (misalnya, 45 derajat untuk memperbaiki pindaian yang sedikit miring), gunakan [Putar dengan Derajat Kustom](./rotate-custom).
- Kontrol rotasi massal memengaruhi semua halaman, bukan hanya yang dipilih. Alat ini tidak memiliki mekanisme pemilihan. Untuk itu, gunakan [Alat Multi PDF](./pdf-multi-tool).

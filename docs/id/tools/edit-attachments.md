# Edit Lampiran

Periksa dan kelola lampiran file di dalam PDF. Alat ini mendaftar setiap file tertanam beserta nama dan tingkat lampirannya, lalu memungkinkan Anda menandai lampiran tertentu untuk dihapus atau menghapus semuanya sekaligus.

## Cara Kerja

1. Unggah file PDF.
2. Alat otomatis memindai lampiran dan menampilkannya dalam daftar.
3. Setiap lampiran menampilkan nama file dan apakah itu lampiran tingkat dokumen atau tingkat halaman.
4. Klik ikon tempat sampah di samping lampiran untuk menandainya untuk dihapus (klik lagi untuk membatalkan tanda).
5. Gunakan tombol **Hapus Semua Lampiran** untuk memilih semuanya sekaligus, atau **Batalkan Pilih Semua** untuk menghapus semua pilihan.
6. Klik tombol proses untuk menyimpan PDF baru dengan lampiran terpilih dihapus.

## Fitur

- Mendaftar semua lampiran tingkat dokumen dan tingkat halaman
- Penghapusan lampiran satu per satu atau massal
- Aktifkan dan nonaktifkan pilihan sebelum menerapkan perubahan
- Coretan visual dan perubahan opasitas pada item yang ditandai untuk dihapus
- Mengunduh PDF yang sudah dimodifikasi dengan lampiran terpilih dihapus

## Kasus Penggunaan

- Menghapus file usang atau salah yang tertanam di dokumen sebelum disebarkan ulang
- Membuang lampiran sensitif (data keuangan, info pribadi) dari PDF sebelum dibagikan
- Memperkecil ukuran file PDF dengan menghapus file tertanam besar yang tidak lagi diperlukan
- Mengaudit konten tertanam dan membersihkan dokumen sebelum diarsipkan

## Tips

- Lampiran yang ditandai untuk dihapus ditampilkan dengan coretan visual. Anda dapat membatalkan tanda sebelum memproses jika berubah pikiran.
- Jika tidak ada lampiran ditemukan, alat menampilkan pesan "Tidak ada lampiran di PDF ini" yang jelas. Artinya PDF memang tidak berisi file tertanam.

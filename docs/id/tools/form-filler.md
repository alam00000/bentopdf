# Pengisi Formulir PDF

Buka PDF yang memiliki kolom formulir dan isi langsung di penampil tertanam. Alat ini mendukung kolom AcroForm standar maupun formulir XFA (XML Forms Architecture) lama. Setelah formulir selesai diisi, unduh versi yang sudah terisi dengan satu klik.

## Cara Kerja

1. Unggah PDF yang berisi kolom formulir.
2. Dokumen terbuka di penampil PDF terintegrasi yang merender kolom formulir sebagai input interaktif.
3. Klik kolom teks, kotak centang, menu tarik-turun, dan tombol radio untuk mengisinya.
4. Klik **Simpan & Unduh Formulir yang Terisi** untuk mendapatkan PDF yang sudah lengkap.

## Fitur

- Penampil PDF.js tertanam dengan interaksi penuh pada kolom formulir
- Dukungan untuk kolom AcroForm standar (input teks, kotak centang, menu tarik-turun, tombol radio)
- Dukungan formulir XFA untuk formulir lama berbasis XML
- Ukuran penampil otomatis menyesuaikan dimensi halaman
- Tampilan file dengan informasi nama dan ukuran

## Opsi

Tidak ada opsi konfigurasi tambahan. Unggah formulir, isi, lalu unduh.

## Kasus Penggunaan

- Mengisi formulir pajak, aplikasi asuransi, atau berkas pemerintahan
- Mengisi formulir lamaran kerja yang diterima sebagai lampiran PDF
- Mengisi formulir onboarding vendor atau kuesioner pemasok
- Menyetujui daftar periksa kepatuhan dengan kolom kotak centang
- Mengisi formulir penerimaan pasien sebelum janji temu

## Tips

- Formulir XFA adalah format lama yang hanya didukung oleh beberapa penampil PDF. Jika Anda membuka PDF XFA di Chrome atau sebagian besar alat lain dan melihat halaman kosong, artinya penampil tersebut tidak mendukung XFA. Pengisi Formulir BentoPDF dan Firefox sama-sama menangani XFA dengan baik.
- Untuk PDF tanpa kolom formulir, gunakan alat [Buat Formulir PDF](./form-creator) untuk menambahkan kolom terlebih dahulu, lalu isi di sini.
- Penampil secara otomatis menyesuaikan ukurannya dengan dimensi halaman PDF.

# N-Up PDF

Tempatkan beberapa halaman dalam satu lembar dengan susunan kisi. Ini mengurangi jumlah halaman yang dicetak dengan memuat 2, 4, 6, 8, 9, atau 16 halaman per lembar. Alat ini menangani penskalaan, penempatan, dan konfigurasi ukuran halaman opsional.

## Cara Kerja

1. Unggah file PDF.
2. Pilih jumlah halaman per lembar (nilai "N"): 2, 4, 6, 8, 9, atau 16.
3. Pilih ukuran halaman output (default A4) dan orientasi.
4. Secara opsional atur jarak, warna garis tepi, dan warna latar belakang.
5. Klik tombol proses. Alat ini menskalakan setiap halaman dan menyusunnya pada lembar baru.

## Fitur

- Tata letak kisi: 2-up, 4-up, 6-up, 8-up, 9-up, dan 16-up
- Ukuran halaman dan orientasi output yang dapat dikonfigurasi
- Jarak opsional antarhalaman yang disusun
- Pengaturan warna latar belakang dan garis tepi
- Mempertahankan rasio aspek halaman asli saat menskalakan agar pas

## Opsi

| Opsi                     | Deskripsi                                                                      |
| ------------------------ | ------------------------------------------------------------------------------ |
| **Halaman per lembar**   | Jumlah halaman asli yang dimuat pada setiap halaman output (2, 4, 6, 8, 9, 16) |
| **Ukuran halaman**       | Ukuran lembar output (A4, Letter, Legal, dll.)                                 |
| **Orientasi**            | Potret atau Lanskap untuk lembar output                                        |
| **Jarak**                | Celah dalam poin antarhalaman yang disusun                                     |
| **Warna latar belakang** | Warna isian untuk latar belakang lembar output                                 |
| **Warna garis tepi**     | Warna untuk garis tepi di sekeliling setiap halaman yang disusun               |

## Kasus Penggunaan

- Mencetak handout dengan 4 slide per halaman untuk menghemat kertas
- Membuat lembar belajar dengan beberapa halaman referensi dalam satu lembar
- Menghasilkan arsip dokumen yang ringkas untuk penyimpanan berkas
- Membuat lembar ikhtisar thumbnail dari dokumen yang panjang

## Tips

- Orientasi lanskap sering bekerja lebih baik untuk tata letak 2-up, sedangkan potret biasanya terbaik untuk 4-up ke atas.
- Menambah jarak membantu keterbacaan tetapi mengurangi area yang tersedia untuk setiap halaman yang disusun.
- Untuk operasi sebaliknya (memecah satu halaman menjadi beberapa), lihat [Posterisasi PDF](./posterize-pdf).

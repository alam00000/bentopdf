# ODP ke PDF

Konversi file OpenDocument Presentation menjadi PDF. ODP adalah format asli LibreOffice Impress dan ekspor standar dari Google Slides. Mengubah presentasi menjadi PDF berarti siapa pun dapat melihatnya tanpa perangkat lunak presentasi, dan slide tercetak dengan rapi.

## Format yang Didukung

| Format                    | Ekstensi | Catatan                                    |
| :------------------------ | :------- | :----------------------------------------- |
| OpenDocument Presentation | `.odp`   | LibreOffice Impress / ekspor Google Slides |

## Cara Kerja

1. Klik area unggah atau seret dan lepas file ODP Anda. Anda dapat memilih beberapa presentasi sekaligus.
2. Periksa daftar file. Hapus entri dengan ikon tempat sampah, atau gunakan **Tambah File Lagi** untuk menyertakan presentasi tambahan.
3. Klik **Konversi ke PDF**. Mesin berbasis LibreOffice memproses setiap presentasi dan menghasilkan PDF di mana setiap slide menjadi satu halaman.
4. Satu file diunduh sebagai PDF. Beberapa file dikirim dalam arsip ZIP bernama `odp-to-pdf.zip`.

## Opsi

Tidak ada pengaturan yang perlu dikonfigurasi. Setiap slide dirender pada dimensi aslinya, dengan mempertahankan teks, gambar, bentuk, dan latar belakang slide.

## Kasus Penggunaan

- Membagikan presentasi kepada audiens sebagai PDF handout
- Membagikan ekspor Google Slides kepada orang yang lebih suka PDF daripada ODP
- Mengarsipkan presentasi konferensi dan kuliah dalam format hanya-baca
- Mencetak slide deck untuk lokakarya tatap muka

## Tips

- Transisi dan animasi slide adalah fitur visual yang tidak terbawa ke PDF, tetapi semua konten statis dirender dengan benar.
- Catatan pembicara tidak disertakan dalam output PDF. Jika Anda memerlukan catatan, ekspor secara terpisah dari perangkat lunak presentasi Anda.
- Seperti alat berbasis LibreOffice lainnya, mesin dimuat pada penggunaan pertama dan tetap tersimpan di cache selama sesi.

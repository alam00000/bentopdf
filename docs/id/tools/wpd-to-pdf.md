# WPD ke PDF

Konversi dokumen Corel WordPerfect menjadi file PDF. WPD dulu adalah format pengolah kata dominan di kantor hukum dan instansi pemerintah. Jika Anda punya file WordPerfect lama yang tidak mau dibuka perangkat lunak modern, alat ini menghidupkannya kembali sebagai PDF standar.

## Format yang Didukung

| Format      | Ekstensi | Catatan                       |
| :---------- | :------- | :---------------------------- |
| WordPerfect | `.wpd`   | Semua versi WordPerfect utama |

## Cara Kerja

1. Klik area unggah atau seret dan lepas file WPD Anda. Beberapa file bisa dipilih sekaligus.
2. Tinjau daftar file. Hapus file yang tidak diinginkan dengan ikon tempat sampah, atau gunakan **Tambah Lebih Banyak File** untuk menambah dokumen.
3. Klik **Konversi ke PDF**. Alat memuat mesin konversi berbasis LibreOffice di browser Anda, yang mengurai format WPD dan menghasilkan PDF.
4. Satu file langsung diunduh sebagai PDF. Konversi massal menghasilkan arsip ZIP bernama `wpd-to-pdf.zip`.

## Opsi

Tidak diperlukan konfigurasi. Mesin LibreOffice menangani format, font, dan tata letak WPD secara otomatis.

## Kasus Penggunaan

- Membuka dokumen hukum berusia puluhan tahun yang ditulis di WordPerfect
- Mengonversi arsip berkas pemerintah dari WPD ke format modern
- Memigrasikan pustaka dokumen WordPerfect lama ke PDF untuk penyimpanan jangka panjang
- Membagikan file WPD kepada penerima yang tidak memasang Corel WordPerfect

## Tips

- Mesin LibreOffice dimuat saat pertama digunakan, yang membutuhkan waktu sebentar. Konversi berikutnya dalam sesi yang sama lebih cepat.
- Makro WPD yang kompleks dan reveal codes tidak dipertahankan, tetapi tata letak visual, isi teks, dan format dasar terbawa ke PDF.

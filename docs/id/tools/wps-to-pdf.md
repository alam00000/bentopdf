# WPS ke PDF

Konversi file pengolah kata Microsoft Works menjadi PDF. Microsoft Works dulu disertakan pada PC konsumen sepanjang akhir 1990-an dan 2000-an, dan banyak file WPS masih tersimpan di hard drive dan arsip email lama. Alat ini membukanya di browser dan menghasilkan PDF yang bersih.

## Format yang Didukung

| Format          | Ekstensi | Catatan                                 |
| :-------------- | :------- | :-------------------------------------- |
| Microsoft Works | `.wps`   | File pengolah kata dari Microsoft Works |

## Cara Kerja

1. Klik area unggah atau seret dan lepas file WPS Anda. Beberapa file diterima.
2. Tinjau daftar file. Gunakan ikon tempat sampah untuk menghapus file tertentu, atau klik **Tambah Lebih Banyak File** untuk memperbesar batch.
3. Klik **Konversi ke PDF**. Mesin berbasis LibreOffice dimuat di browser dan mengonversi setiap dokumen WPS ke PDF.
4. Satu file langsung diunduh sebagai PDF. Beberapa file dikemas dalam arsip ZIP bernama `wps-to-pdf.zip`.

## Opsi

Tidak ada pengaturan tambahan. Konverter menangani teks, format dasar, dan gambar tertanam dari file WPS.

## Kasus Penggunaan

- Memulihkan dokumen sekolah atau kerja lama yang tersimpan dalam format Microsoft Works
- Membuka lampiran email WPS ketika Microsoft Works tidak terpasang
- Mengonversi arsip file WPS untuk migrasi ke sistem dokumen modern
- Mencetak dokumen lama yang tidak bisa dibuka pengolah kata saat ini

## Tips

- Jangan campuradukkan file `.wps` Microsoft Works dengan file WPS Office. Alat ini khusus untuk format Microsoft Works yang lebih lama.
- Mesin LibreOffice membutuhkan waktu sebentar untuk dimuat saat pertama digunakan. Setelah dimuat, konversi berikutnya dalam sesi yang sama berjalan lebih cepat.

# PDF opschonen

PDF's kunnen veel meer bevatten dan je op het scherm ziet. Verborgen metadata, ingesloten JavaScript, bestandsbijlagen, formuliergegevens en laaginformatie kunnen gevoelige gegevens lekken of beveiligingsrisico's vormen. Opschonen verwijdert dit alles en laat een schoon document over dat veilig openbaar gedeeld kan worden.

## Hoe het werkt

1. Upload een PDF-bestand.
2. Selecteer in de checklist welke elementen moeten worden verwijderd.
3. Klik op **PDF opschonen**.
4. Download het opgeschoonde bestand.

## Opschoonopties

Alle opties staan standaard aan. Haal het vinkje weg bij opties die je wilt behouden.

| Optie                                | Wat het verwijdert                                                               |
| ------------------------------------ | -------------------------------------------------------------------------------- |
| **Formulieren platmaken**            | Zet interactieve formuliervelden om in statische inhoud                          |
| **Metadata verwijderen**             | Verwijdert auteur, titel, aanmaakdatum, software-info en XMP-gegevens            |
| **Annotaties verwijderen**           | Verwijdert opmerkingen, markeringen, plaknotities en opmaak                      |
| **JavaScript verwijderen**           | Verwijdert ingesloten scripts die bij het openen kunnen worden uitgevoerd        |
| **Ingesloten bestanden verwijderen** | Verwijdert bestandsbijlagen die in de PDF zijn ingesloten                        |
| **Lagen verwijderen (OCG)**          | Voegt optionele inhoudsgroepen samen tot één laag                                |
| **Links verwijderen**                | Verwijdert hyperlinks en URL-verwijzingen                                        |
| **Structuurboom verwijderen**        | Verwijdert de documentstructuur die voor toegankelijkheidstagging wordt gebruikt |
| **MarkInfo verwijderen**             | Verwijdert informatie over gemarkeerde inhoud                                    |
| **Lettertypen verwijderen**          | Verwijdert ingesloten lettertypegegevens (met voorzichtigheid gebruiken)         |

## Toepassingen

- Een PDF voorbereiden voor openbare publicatie door interne metadata (auteursnamen, softwareversies, bewerkingsgeschiedenis) te verwijderen
- JavaScript verwijderen uit een PDF van een onvertrouwde bron voordat je die opent
- Een PDF opschonen voordat je die naar een klant stuurt die geen ingesloten opmerkingen of namen van formuliervelden hoeft te zien
- Verborgen lagen verwijderen uit een architectuurtekening voordat je de definitieve versie deelt
- Voldoen aan eisen voor gegevensminimalisatie volgens privacywetgeving

## Tips

- Laat "Lettertypen verwijderen" uitgevinkt, tenzij je zeker weet dat de PDF daarna nog correct wordt weergegeven. Het verwijderen van lettertypen kan tekst in sommige viewers onzichtbaar maken.
- Als je alleen metadata wilt verwijderen, is de speciale tool Metadata Verwijderen sneller en gerichter.
- Opschonen is onomkeerbaar. Bewaar je originele bestand.

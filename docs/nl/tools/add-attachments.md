# Bijlagen toevoegen

Sluit een of meer bestanden rechtstreeks in een PDF-document in. Bijlagen kunnen op documentniveau worden toegevoegd (zichtbaar in het bijlagenpaneel van elke PDF-lezer) of aan specifieke pagina's worden gekoppeld.

## Hoe het werkt

1. Upload de PDF waaraan je bestanden wilt toevoegen.
2. Selecteer via de uploadzone de bestanden die je wilt insluiten (elk bestandstype).
3. Kies het bijlageniveau: **Document** (standaard) of **Pagina**.
4. Kies je Pagina-niveau, voer dan een paginabereik in (bijv. `1-3` of `5`).
5. Klik op de verwerkknop. De aangepaste PDF wordt gedownload met je bestanden ingesloten.

## Functies

- Voeg elk bestandstype toe: afbeeldingen, spreadsheets, archieven, uitvoerbare bestanden, alles
- Bijlagen op documentniveau of paginaniveau
- Meerdere bestanden in één bewerking toevoegen
- Toont bestandsnamen en groottes van alle geselecteerde bijlagen
- De uitvoer behoudt de originele PDF-inhoud met de ingesloten bestanden erbij

## Opties

| Optie              | Beschrijving                                                                   |
| ------------------ | ------------------------------------------------------------------------------ |
| **Documentniveau** | Voegt bestanden toe aan de PDF als geheel, toegankelijk via het bijlagenpaneel |
| **Paginaniveau**   | Voegt bestanden toe aan specifieke pagina's, opgegeven via een paginabereik    |

## Toepassingen

- Brondata (Excel-bestanden, CSV's) bundelen met een PDF-rapport
- Originele afbeeldingsbestanden toevoegen aan een PDF met een fotografieportfolio
- Ondersteunende documenten insluiten in een contract of voorstel
- Aanvullend materiaal toevoegen aan specifieke pagina's van een trainingshandleiding

## Tips

- Bijlagen op documentniveau worden door de meeste PDF-lezers ondersteund. Bijlagen op paginaniveau zijn mogelijk niet in alle viewers zichtbaar.
- Er is geen limiet voor de bestandsgrootte van bijlagen, maar zeer grote ingesloten bestanden vergroten de PDF evenredig.

# Afbeelding naar PDF

De universele converter van afbeeldingen naar PDF. Upload afbeeldingen in vrijwel elk formaat en combineer ze tot één PDF-document. Elke afbeelding krijgt een eigen pagina, met het formaat van het origineel.

## Ondersteunde formaten

| Formaat         | Extensies                              |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

Dit is de breedste formaatondersteuning van alle afbeeldingsconverters in BentoPDF. Heb je maar één specifiek formaat nodig, gebruik dan liever de bijbehorende aparte tool.

## Zo werkt het

1. Klik op het uploadgebied of sleep je afbeeldingsbestanden erheen. Je kunt meerdere bestanden tegelijk selecteren.
2. Bekijk de bestandslijst. Verwijder ongewenste bestanden met het prullenbakpictogram, of klik op **Meer bestanden toevoegen** om extra afbeeldingen toe te voegen.
3. Kies een **PDF-kwaliteit** in de keuzelijst.
4. Klik op **Converteren naar PDF**. De tool verwerkt de afbeeldingen met de PyMuPDF-engine en downloadt het resultaat als `images_to_pdf.pdf`.

## Opties

**PDF-kwaliteit** bepaalt de beeldcompressie bij het insluiten van afbeeldingen in de PDF:

- **Hoge kwaliteit**: minimale compressie, groter bestand. Het beste voor drukwerk of archivering.
- **Gemiddelde kwaliteit** (standaard): gebalanceerde compressie. Geschikt voor de meeste doeleinden.
- **Lage kwaliteit**: sterke compressie, kleinste bestand. Geschikt voor e-mail of snel delen.

HEIC- en WebP-bestanden worden automatisch omgezet naar PNG voordat ze worden ingesloten. Dit gebeurt vanzelf en vergt geen extra stappen.

## Toepassingen

- Gescande bonnetjes of documenten van een telefooncamera combineren tot één PDF
- Een fotoportfolio of lookbook maken van afbeeldingen in verschillende formaten
- iPhone-foto's (HEIC) omzetten naar een deelbare PDF zonder desktopsoftware te installeren
- Ontwerpmockups uit PSD-exports en schermafbeeldingen samenstellen tot een oplevering voor een klant
- Een map met oudere afbeeldingsformaten (PNM, JXR, JP2) archiveren als één PDF

## Tips

- De volgorde van de afbeeldingen in de PDF komt overeen met de volgorde in de bestandslijst. Upload ze dus in de gewenste volgorde.
- Kies Lage kwaliteit voor het kleinst mogelijke bestand. Het zichtbare verschil is bij scans met veel tekst vaak verwaarloosbaar.
- Heb je maar één afbeeldingsformaat, dan geven de aparte converters (JPG naar PDF, PNG naar PDF, enz.) hetzelfde resultaat met een eenvoudigere interface.

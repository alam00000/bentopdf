# Metadata bewerken

Bewerk de metadata die in een PDF-bestand is ingesloten. De tool vult een formulier vooraf met de bestaande metadata van het document, laat je elk veld wijzigen en slaat de wijzigingen op in een nieuwe PDF.

## Zo werkt het

1. Upload een PDF-bestand. De tool leest de huidige metadata en vult het formulier.
2. Bewerk een van de standaardvelden: Titel, Auteur, Onderwerp, Trefwoorden, Maker, Producent.
3. Pas de aanmaakdatum en de wijzigingsdatum aan met de datum-tijdkiezers.
4. Voeg aangepaste metadatavelden toe door op de toevoegknop te klikken en een sleutel-waardepaar in te voeren.
5. Klik op de verwerkingsknop om de gewijzigde PDF op te slaan.

## Functies

- Vult alle bestaande metadata van de geüploade PDF vooraf in
- Standaardvelden: Titel, Auteur, Onderwerp, Trefwoorden, Maker, Producent
- Datum-tijdkiezers voor de aanmaakdatum en de wijzigingsdatum
- Aangepaste sleutel-waardevelden voor willekeurige eigenschappen
- Slaat wijzigingen direct op in het documentinformatiewoordenboek van de PDF

## Bewerkbare velden

| Veld                  | Beschrijving                                              |
| --------------------- | --------------------------------------------------------- |
| **Titel**             | De documenttitel die in PDF-lezers wordt getoond          |
| **Auteur**            | De persoon of organisatie die het document heeft gemaakt  |
| **Onderwerp**         | Een korte beschrijving van het onderwerp van het document |
| **Trefwoorden**       | Door komma's gescheiden termen voor zoeken en indelen     |
| **Maker**             | De toepassing waarmee de inhoud oorspronkelijk is gemaakt |
| **Producent**         | De toepassing die de PDF heeft gegenereerd                |
| **Aanmaakdatum**      | Wanneer het document oorspronkelijk is gemaakt            |
| **Wijzigingsdatum**   | Wanneer het document voor het laatst is gewijzigd         |
| **Aangepaste velden** | Alle extra sleutel-waardeparen die je zelf definieert     |

## Toepassingen

- Een juiste titel en auteur instellen voordat je een document publiceert
- Trefwoorden toevoegen om de vindbaarheid in documentbeheersystemen te verbeteren
- De wijzigingsdatum bijwerken zodat die de huidige revisie weergeeft
- Aangepaste metadatavelden toevoegen, zoals Afdeling, Project-ID of Classificatie
- Metadata opschonen die door de oorspronkelijke authoringsoftware is achtergelaten

## Tips

- Aangepaste velden worden rechtstreeks in het informatiewoordenboek van de PDF geschreven. Sommige PDF-lezers tonen aangepaste velden mogelijk niet, maar ze blijven in het bestand bewaard.
- Laat een veld leeg om het uit de metadata te wissen. De verwerkingsknop slaat op wat er in het formulier staat.
- Gebruik [Metadata weergeven](./view-metadata) om metadata te bekijken zonder te bewerken. Gebruik Metadata verwijderen om alle metadata volledig te verwijderen.

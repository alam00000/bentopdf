# Imatges a PDF

El convertidor universal d'imatges a PDF. Puja imatges en pràcticament qualsevol format i combina-les en un únic document PDF. Cada imatge té la seva pròpia pàgina, amb la mida de l'original.

## Formats compatibles

| Format          | Extensions                             |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

Aquesta és la compatibilitat de formats més àmplia de tots els convertidors d'imatges de BentoPDF. Si només necessites un format concret, fes servir una de les eines dedicades.

## Com funciona

1. Fes clic a l'àrea de càrrega o arrossega-hi els fitxers d'imatge. Pots seleccionar-ne diversos alhora.
2. Revisa la llista de fitxers. Elimina els que no vulguis amb la icona de la paperera, o fes clic a **Afegeix més fitxers** per incloure més imatges.
3. Tria un nivell de **Qualitat del PDF** al desplegable.
4. Fes clic a **Converteix a PDF**. L'eina processa les imatges amb el motor PyMuPDF i baixa el resultat com a `images_to_pdf.pdf`.

## Opcions

**Qualitat del PDF** controla la compressió que s'aplica a les imatges en incrustar-les al PDF:

- **Alta qualitat**: compressió mínima, mida de fitxer més gran. Ideal per a impressió o arxiu.
- **Qualitat mitjana** (per defecte): compressió equilibrada. Bona per a la majoria d'usos.
- **Baixa qualitat**: compressió agressiva, la mida de fitxer més petita. Adequada per al correu electrònic o per compartir ràpidament.

Els fitxers HEIC i WebP es converteixen automàticament a PNG abans d'incrustar-los. Es fa de manera transparent i no requereix cap pas addicional.

## Casos d'ús

- Combinar en un sol PDF tiquets o documents escanejats amb la càmera del mòbil
- Crear un portafoli de fotos o un catàleg a partir d'imatges de formats diversos
- Convertir fotos d'iPhone (HEIC) en un PDF que es pugui compartir sense instal·lar cap programa d'escriptori
- Muntar maquetes de disseny a partir d'exportacions PSD i captures de pantalla com a lliurable per a un client
- Arxivar una carpeta de formats d'imatge antics (PNM, JXR, JP2) com un únic PDF

## Consells

- L'ordre de les imatges al PDF coincideix amb l'ordre de la llista de fitxers. Puja-les en la seqüència que vulguis.
- Per obtenir la mida de fitxer més petita possible, tria Baixa qualitat. La diferència visual sol ser insignificant en escanejos amb molt de text.
- Si només tens un format d'imatge, els convertidors dedicats (JPG a PDF, PNG a PDF, etc.) donen el mateix resultat amb una interfície més senzilla.

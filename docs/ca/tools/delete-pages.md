# Suprimeix pàgines

Elimina les pàgines no desitjades d'un document PDF. Indica les pàgines que vols suprimir escrivint-ne els números o intervals, o fes clic directament a les miniatures de les pàgines per marcar-les perquè s'eliminin.

## Com funciona

1. Puja un fitxer PDF. L'eina mostra previsualitzacions en miniatura de totes les pàgines.
2. Introdueix les pàgines que vols suprimir al camp de text amb la sintaxi d'intervals (p. ex., `2, 5-8`), o fes clic a les miniatures per activar-les o desactivar-les.
3. Les pàgines marcades es ressalten visualment perquè puguis confirmar la selecció.
4. Fes clic al botó de processar. Es crea un PDF nou sense les pàgines seleccionades.

## Funcions

- Selecció de pàgines per text amb sintaxi d'intervals (`2, 5-8, 12`)
- Quadrícula visual de miniatures per suprimir amb un clic
- Ressaltat en temps real de les pàgines marcades per suprimir
- Validació de l'entrada segons el nombre real de pàgines
- Conserva totes les pàgines no suprimides en l'ordre original

## Casos d'ús

- Eliminar pàgines en blanc o de farciment d'un document escanejat
- Treure les portades o els apèndixs abans de compartir un document
- Netejar les pàgines d'esborrany que s'han deixat per error en un PDF final
- Eliminar les pàgines amb informació sensible abans de distribuir-lo

## Consells

- Suprimir pàgines no afecta el contingut ni el format de les pàgines restants. El resultat és una còpia fidel de l'original sense les pàgines eliminades.
- Si vols conservar només pàgines concretes en lloc d'eliminar-ne, [Extreu pàgines](./extract-pages) és l'opció més adequada.
- La vista de miniatures es carrega de manera progressiva, de manera que els documents grans continuen responent bé.

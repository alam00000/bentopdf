# ODG a PDF

Converteix fitxers OpenDocument Graphics en PDF. ODG és el format natiu de LibreOffice Draw i s'utilitza per a diagrames, diagrames de flux i il·lustracions vectorials. Convertir-los a PDF facilita compartir aquests dibuixos, imprimir-los i incrustar-los en altres documents.

## Formats compatibles

| Format                | Extensió | Notes                                         |
| :-------------------- | :------- | :-------------------------------------------- |
| OpenDocument Graphics | `.odg`   | Fitxers de LibreOffice Draw / OpenOffice Draw |

## Com funciona

1. Fes clic a l'àrea de càrrega o arrossega-hi els fitxers ODG. Pots afegir-ne diversos alhora.
2. Revisa la llista de fitxers. Elimina entrades concretes amb la icona de la paperera, o fes clic a **Afegeix més fitxers** per afegir més dibuixos.
3. Fes clic a **Converteix a PDF**. Un motor basat en LibreOffice es carrega al navegador i converteix cada fitxer ODG, conservant els gràfics vectorials, les formes i el text.
4. Si és un sol fitxer, es baixa directament com a PDF. Si són diversos, es genera un arxiu ZIP anomenat `odg-to-pdf.zip`.

## Opcions

No calen paràmetres addicionals. La conversió conserva les dimensions de pàgina, les formes, els connectors i els quadres de text originals de l'ODG.

## Casos d'ús

- Compartir diagrames de LibreOffice Draw amb clients que no tenen LibreOffice instal·lat
- Imprimir diagrames de flux i diagrames de xarxa creats amb Draw
- Incloure il·lustracions ODG en un informe o una presentació com a PDF incrustats
- Arxivar dibuixos tècnics en un format que continuarà sent llegible durant dècades

## Consells

- Els elements vectorials es conserven com a vectors al PDF resultant, de manera que escalen netament a qualsevol mida d'impressió.
- El motor de LibreOffice triga una mica a inicialitzar-se el primer cop. Les conversions posteriors dins de la mateixa sessió són més ràpides.

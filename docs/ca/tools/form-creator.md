# Crea un formulari PDF

Dissenya formularis PDF emplenables professionals des de zero o afegint camps a un PDF existent. L'editor visual et permet arrossegar i deixar anar elements de formulari (camps de text, caselles de selecció, desplegables, botons d'opció, camps de signatura i més) directament sobre les vistes prèvies de les pàgines. Configura les propietats dels camps, defineix regles de visibilitat condicional i exporta un formulari PDF totalment interactiu.

## Com funciona

1. Puja un PDF existent **o** fes clic a **Crea un PDF en blanc** per començar de zero.
2. Si crees un PDF en blanc, selecciona una mida de pàgina (Letter, A4, A5, Legal, Tabloid, A3 o dimensions personalitzades).
3. S'obre l'editor de formularis amb una barra d'eines amb els tipus de camp i una àrea de vista prèvia de la pàgina.
4. Selecciona un tipus de camp a la barra d'eines i fes clic a la pàgina per col·locar-lo.
5. Arrossega els camps per canviar-ne la posició. Fes servir els tiradors per ajustar-ne les dimensions.
6. Fes clic en un camp per obrir el tauler de propietats, on pots definir el nom del camp, el valor per defecte, la mida de la lletra, l'alineació i més.
7. Navega entre pàgines amb els controls de pàgina.
8. Fes clic a **Desa** per baixar el PDF emplenable acabat.

## Funcionalitats

- Col·locació de camps arrossegant i deixant anar, amb tiradors visuals per redimensionar
- Tipus de camp: entrada de text, text multilínia, casella de selecció, desplegable, botó d'opció, signatura, data, número i codi de barres
- Tauler de propietats per configurar el nom, l'etiqueta, el valor per defecte, la mida de la lletra, el color, l'alineació i la validació de cada camp
- Accions de camp i regles de visibilitat condicional (mostrar o amagar camps segons els valors d'altres camps)
- Navegació per pàgines per a formularis de diverses pàgines
- Extracció de camps existents: detecta i importa automàticament els camps de formulari dels PDF pujats
- Compatibilitat amb PDF pujats i pàgines en blanc com a llenç del formulari
- Diverses mides de pàgina predefinides, a més de dimensions personalitzades
- Generació de codis de barres amb bwip-js
- Gestió de grups de botons d'opció

## Opcions

**Mides de pàgina predefinides (per a PDF en blanc):**

- Letter (8,5" x 11")
- A4 (210 mm x 297 mm)
- A5 (148 mm x 210 mm)
- Legal (8,5" x 14")
- Tabloid (11" x 17")
- A3 (297 mm x 420 mm)
- Personalitzada (indica l'amplada i l'alçada)

**Propietats dels camps (varien segons el tipus de camp):**

- Nom, etiqueta i text de subtítol
- Valor per defecte
- Família, mida i color de la lletra
- Alineació del text (esquerra, centre, dreta)
- Interruptor de camp obligatori
- Interruptor de només lectura
- Longitud màxima dels camps de text
- Llista d'opcions per a desplegables i botons d'opció
- Accions de visibilitat condicional

## Casos d'ús

- Crear formularis d'acollida d'empleats amb camps de text per a les dades personals i caselles de selecció per acceptar polítiques
- Crear qüestionaris d'entrada de clients amb desplegables per triar el servei
- Dissenyar formularis de comanda amb camps calculats i identificadors de codi de barres
- Crear llistes de control d'inspecció amb botons d'opció per a valoracions d'apte o no apte
- Crear formularis d'enquesta amb preguntes de seguiment condicionals que apareixen segons les respostes

## Consells

- Si puges un PDF existent, l'eina intentarà extreure'n els camps de formulari que ja hi hagi, perquè els puguis editar o ampliar.
- Fes servir la funció de grup de botons d'opció per crear seleccions mútuament excloents. Els camps del mateix grup comparteixen un nom de grup.
- Prova el formulari baixant-lo i obrint-lo a l'[Emplena formularis PDF](./form-filler) per comprovar el comportament dels camps.

# Elimina les anotacions

Neteja el PDF eliminant-ne totes les anotacions: comentaris, ressaltats, notes adhesives, marcatge de text, enllaços, segells i qualsevol altre objecte d'anotació incrustat al document. El contingut de fons de les pàgines (text, imatges, gràfics) queda intacte.

## Com funciona

1. Puja el fitxer PDF.
2. L'eina detecta el nombre de pàgines del document i mostra la informació del fitxer.
3. Fes clic a **Elimina les anotacions** per processar-lo.
4. El PDF net es descarrega automàticament sense cap anotació.

## Funcions

- Elimina tots els tipus d'anotació: comentaris, ressaltats, subratllats, tacats, notes adhesives, segells, enllaços i marcatge de formularis
- Actua sobre totes les pàgines del document
- Conserva tot el contingut que no és anotació (text, imatges, gràfics vectorials, camps de formulari)
- Mostra el nombre de pàgines i la mida del fitxer abans de processar

## Casos d'ús

- Netejar un document abans de la distribució final després d'un cicle de revisió en què diversos revisors han afegit comentaris
- Eliminar el marcatge de ressaltats i les notes adhesives d'una guia d'estudi compartida
- Eliminar les anotacions d'enllaç d'un document abans d'arxivar-lo
- Preparar una versió «neta» d'un document legal que s'ha anotat intensament durant una negociació
- Eliminar els comentaris dels revisors d'un manuscrit abans d'enviar-lo a impremta

## Consells

- Aquesta eina elimina les anotacions a nivell d'estructura del PDF, de manera que el resultat manté el text seleccionable i la qualitat original, sense cap rasterització.
- Si només vols eliminar anotacions concretes i no totes, utilitza l'[Editor de PDF](./edit-pdf) per suprimir-ne de manera selectiva.
- Les anotacions dels PDF aplanats (on les anotacions s'han fusionat amb el contingut de la pàgina) no es poden eliminar perquè ja no són objectes separats.

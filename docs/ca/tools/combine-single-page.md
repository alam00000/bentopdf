# Combina en una única pàgina

Fusiona totes les pàgines d'un PDF en una sola pàgina llarga. Les pàgines s'uneixen en vertical (com un rotllo) o en horitzontal (una al costat de l'altra) i el resultat és una única pàgina contínua.

## Com funciona

1. Puja un fitxer PDF.
2. Selecciona la direcció del disseny: **Vertical** (pàgines apilades de dalt a baix) o **Horitzontal** (pàgines col·locades una al costat de l'altra).
3. Defineix l'espai entre pàgines en punts.
4. Tria un color de fons per als espais entre pàgines.
5. Si vols, activa els separadors (línies fines entre pàgines) i configura'n el gruix i el color.
6. Fes clic al botó de processar. El resultat és un PDF d'una sola pàgina.

## Funcions

- Unió de pàgines en vertical o en horitzontal
- Espai entre pàgines configurable
- Selector de color de fons per a les àrees d'espai
- Línies separadores opcionals amb gruix i color ajustables
- Renderitza cada pàgina original a resolució completa sobre el llenç combinat

## Opcions

| Opció                          | Descripció                                                  |
| ------------------------------ | ----------------------------------------------------------- |
| **Direcció de la disposició**  | Vertical (apilades) o Horizontal (una al costat de l'altra) |
| **Espaiat**                    | Espai entre pàgines en punts                                |
| **Color de fons**              | Color de l'àrea entre pàgines                               |
| **Afegeix línies separadores** | Activa les línies fines entre pàgines                       |
| **Gruix del separador**        | Gruix de la línia en punts                                  |
| **Color del separador**        | Color de les línies separadores                             |

## Casos d'ús

- Crear una única imatge llarga a partir d'un wireframe o una maqueta de disseny de diverses pàgines
- Generar una vista contínua i desplaçable d'un document per incrustar-la al web
- Unir un còmic o un guió gràfic de diverses pàgines en una sola tira
- Obtenir una vista panoràmica de pàgines consecutives per revisar-les

## Consells

- L'orientació vertical funciona millor amb documents de pàgines verticals. L'horitzontal és més adequada per a contingut apaïsat.
- Els documents grans amb moltes pàgines generaran un resultat molt alt o molt ample. Alguns visors de PDF poden tenir problemes amb pàgines úniques extremadament grans.
- Afegir separadors d'un color que contrasti permet veure fàcilment on acaba una pàgina original i on comença la següent.

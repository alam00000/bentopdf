# PDF a WebP

Converteix cada pàgina d'un PDF en una imatge WebP. WebP sol produir fitxers entre un 25 % i un 35 % més petits que JPG amb la mateixa qualitat percebuda, cosa que el converteix en una bona opció per a l'ús web.

## Com funciona

1. Carrega un PDF fent clic a la zona de càrrega o arrossegant-hi un fitxer.
2. Ajusta el control lliscant de **Qualitat**.
3. Fes clic a **Converteix** per processar el fitxer.
4. Un sol fitxer `.webp` o un arxiu ZIP es baixa automàticament.

## Opcions

- **Qualitat**: un control lliscant del 0 % al 100 % (per defecte 85 %). Controla el nivell de compressió amb pèrdua. Els valors més alts conserven més detall.

Les pàgines es renderitzen internament a escala 2x, de manera que s'obtenen imatges d'aproximadament el doble de les dimensions natives del PDF.

## Format de sortida

- **Una pàgina**: `filename.webp`
- **Diverses pàgines**: `filename_webps.zip` amb `page_1.webp`, `page_2.webp`, etc.

## Casos d'ús

- Preparar previsualitzacions de pàgines per a llocs web on l'ample de banda és important.
- Generar versions d'imatge lleugeres de flyers o fullets per a les xarxes socials.
- Convertir en lot documents de diverses pàgines en un conjunt d'imatges optimitzat per a la web.

## Consells

- WebP és compatible amb tots els navegadors moderns. Per a la compatibilitat amb sistemes antics, recorre a [PDF a JPG](./pdf-to-jpg).
- Una qualitat del 80-85 % acostuma a ser indistingible de l'original en pantalla i manté els fitxers petits.

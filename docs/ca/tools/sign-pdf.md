# Signa PDF

Afegeix la teva signatura a qualsevol document PDF. L'eina incorpora un visor PDF complet amb eines de signatura on pots dibuixar una signatura a mà alçada, escriure el teu nom amb una font de signatura o pujar una imatge de signatura. Col·loca i redimensiona les signatures a qualsevol pàgina i després desa el document signat.

## Com funciona

1. Puja el fitxer PDF.
2. El document s'obre en un visor PDF integrat amb eines d'anotació.
3. Utilitza l'eina de signatura del visor per crear la signatura dibuixant, escrivint o pujant una imatge.
4. Fes clic a la pàgina on vulguis col·locar la signatura i ajusta'n la mida i la posició.
5. Opcionalment, marca **Aplana el PDF** per incrustar la signatura de manera permanent al document.
6. Fes clic a **Desa i baixa el PDF signat** per obtenir el fitxer signat.

## Opcions

- **Aplana el PDF**: si està marcat, la signatura s'incrusta de manera permanent al contingut de la pàgina. Això impedeix que altres persones la moguin o l'eliminin. Si no està marcat, la signatura continua sent una anotació que es pot editar en visors compatibles.

## Funcions

- Tres maneres de crear signatures: dibuix a mà alçada, text escrit o imatge pujada
- Visor PDF integrat per a una col·locació precisa
- Arrossega per posicionar i redimensionar signatures a qualsevol pàgina
- Aplanament opcional per incrustar les signatures de manera permanent
- Compatibilitat amb diverses signatures al mateix document

## Casos d'ús

- Signar contractes, acords o formularis d'aprovació abans de retornar-los
- Afegir la teva signatura a documents fiscals, reclamacions d'assegurances o formularis oficials
- Posar inicials a pàgines individuals d'un acord de diverses pàgines
- Signar acords de confidencialitat o documents de RH que arriben com a fitxers PDF adjunts

## Consells

- Activa l'aplanament si envies el PDF signat a algú que no hauria de poder eliminar ni moure la teva signatura.
- Per a signatures digitals legalment vinculants amb verificació basada en certificats, BentoPDF també ofereix una eina independent de signatura digital.
- Puja una imatge de signatura PNG amb fons transparent per obtenir el resultat més net.

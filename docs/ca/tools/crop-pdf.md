# Retalla PDF

Retalla els marges de les pàgines del teu PDF amb una interfície de retall visual. Dibuixa un rectangle de retall directament sobre cada pàgina, previsualitza el resultat i aplica el retall. Pots definir regions de retall diferents per a pàgines diferents o aplicar el mateix retall a tot el document.

## Com funciona

1. Puja el teu fitxer PDF.
2. S'obre l'editor de retall, que mostra la primera pàgina amb una superposició de retall que es pot arrossegar.
3. Ajusta el rectangle de retall arrossegant-ne les vores o els cantons.
4. Fes servir els botons de navegació de pàgines per moure't entre pàgines i definir la regió de retall de cadascuna.
5. Fes clic a **Retalla i descarrega** per aplicar el retall i baixar el resultat.

## Funcions

- Editor de retall visual amb Cropper.js i nanses per a un ajust precís
- Navegació pàgina a pàgina per definir regions de retall individuals
- Desa la configuració del retall per pàgina, de manera que pots definir retalls diferents per a pàgines diferents
- Previsualització en directe de l'àrea de retall seleccionada
- Admet PDF de qualsevol mida o orientació de pàgina

## Casos d'ús

- Eliminar els marges amples dels documents escanejats per centrar-se en l'àrea de contingut
- Treure les marques de tall o de registre de la impressora dels PDF de preimpressió
- Retallar diapositives de classe per eliminar l'àrea de notes del presentador
- Eliminar les capçaleres o els peus de pàgina de totes les pàgines abans de compartir un fragment d'un document
- Canviar la mida de les pàgines perquè s'ajustin a una pantalla o a un disseny d'impressió concrets

## Consells

- La superposició de retall es pot redimensionar i reposicionar lliurement. Arrossega els cantons per redimensionar-la proporcionalment o les vores per ajustar-la en un sol eix.
- En documents on totes les pàgines necessiten el mateix retall, defineix-lo a la primera pàgina: l'eina recorda la regió de retall mentre navegues per les pàgines.
- Si necessites normalitzar la mida de les pàgines en lloc de retallar visualment, l'eina Uniformitza la mida de pàgina pot ser més adequada.

# Inverteix l'ordre de les pàgines

Inverteix l'ordre de les pàgines d'un PDF perquè l'última passi a ser la primera, la penúltima la segona, i així successivament. Admet el processament per lots de diversos fitxers alhora.

## Com funciona

1. Puja un o més fitxers PDF.
2. Fes clic al botó de processament.
3. Cada fitxer s'inverteix de manera independent. Si has pujat diversos fitxers, el resultat és un arxiu ZIP amb tots els PDF invertits.
4. Un sol fitxer es baixa directament com a PDF invertit.

## Funcions

- Processament per lots: inverteix diversos PDF en una sola operació
- Sortida en un sol fitxer per a un PDF, sortida ZIP per a diversos
- Botons per eliminar cada fitxer abans del processament
- Conserva tot el contingut i el format de les pàgines

## Casos d'ús

- Corregir un document que es va escanejar en ordre invers
- Preparar un PDF de presentació per llegir-lo del final al principi
- Invertir l'ordre de les pàgines per a fluxos d'impressió que alimenten les pàgines a la inversa
- Corregir un document on les pàgines es van muntar al revés per error

## Consells

- Cada fitxer d'un lot s'inverteix de manera independent: els fitxers no es reordenen entre ells.
- Per reordenar les pàgines amb més detall (no només una inversió completa), utilitza [Duplica i organitza](./organize-pdf).

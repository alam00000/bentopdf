# Fusiona PDF

Combina diversos fitxers PDF en un únic document. Pots fusionar fitxers sencers en un ordre concret o canviar al mode Pàgina per tenir un control detallat de cada pàgina de tots els PDF pujats.

## Com funciona

1. Puja dos o més fitxers PDF fent clic a la zona de càrrega o arrossegant-hi els fitxers.
2. Tria entre el **Mode Fitxer** i el **Mode Pàgina** amb l'interruptor de la part superior.
3. Al Mode Fitxer, arrossega els fitxers per reordenar-los i, si vols, indica intervals de pàgines (p. ex., `1-3, 5`) per a cadascun. Deixa l'interval en blanc per incloure-hi totes les pàgines.
4. Al Mode Pàgina, arrossega i deixa anar les miniatures de cada pàgina per construir la seqüència exacta.
5. Fes clic a **Fusiona PDF** per combinar-ho tot en un sol fitxer. El PDF fusionat es baixa automàticament.

## Funcionalitats

- Dos modes de fusió: el Mode Fitxer per combinar fitxers sencers ràpidament i el Mode Pàgina per controlar cada pàgina
- Reordenació arrossegant i deixant anar en tots dos modes, amb animacions fluides
- La sintaxi d'intervals de pàgines (p. ex., `1-3, 5, 8-10`) permet triar pàgines concretes sense canviar al Mode Pàgina
- Les miniatures de pàgina es carreguen a mesura que cal, de manera que la interfície continua responent bé amb documents grans
- Sense límit de nombre de fitxers ni de pàgines totals
- Conserva la qualitat original del PDF, sense tornar a codificar res

## Opcions

| Opció               | Descripció                                                                                                              |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Mode Fitxer**     | Fusiona fitxers sencers en un ordre personalitzat, amb filtres opcionals d'interval de pàgines per fitxer               |
| **Mode Pàgina**     | Quadrícula visual amb totes les pàgines de tots els fitxers: arrossega les miniatures per construir la seqüència exacta |
| **Camp de pàgines** | Camp de text per fitxer que accepta intervals com `1-3, 5` per incloure només pàgines concretes                         |

## Casos d'ús

- Combinar PDF de capítols independents en un sol llibre o informe
- Fusionar una carta de presentació i un currículum en un únic document de candidatura
- Reunir pàgines concretes de diversos documents d'origen en un fitxer consolidat
- Muntar tiquets o factures escanejats en un únic PDF d'arxiu
- Crear un full de resum d'una presentació a partir de diapositives de diverses presentacions

## Consells

- Fes servir el Mode Pàgina quan necessitis intercalar pàgines de fitxers diferents en lloc d'afegir un fitxer darrere de l'altre.
- Pots afegir més fitxers després de la càrrega inicial amb el botó **Afegeix més fitxers** sense perdre l'ordenació actual.
- Els intervals de pàgines comencen a 1, de manera que `1` fa referència a la primera pàgina d'aquell fitxer.

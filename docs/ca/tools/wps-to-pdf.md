# WPS a PDF

Converteix fitxers de processador de textos de Microsoft Works a PDF. Microsoft Works s'incloïa als ordinadors domèstics a finals dels anys 90 i durant els 2000, i encara hi ha molts fitxers WPS en discs durs antics i arxius de correu. Aquesta eina els obre al navegador i genera PDF nets.

## Formats admesos

| Format          | Extensió | Notes                                               |
| :-------------- | :------- | :-------------------------------------------------- |
| Microsoft Works | `.wps`   | Fitxers de processador de textos de Microsoft Works |

## Com funciona

1. Fes clic a l'àrea de càrrega o arrossega i deixa anar els fitxers WPS. S'accepten diversos fitxers.
2. Revisa la llista de fitxers. Utilitza la icona de la paperera per eliminar fitxers individuals, o fes clic a **Afegeix més fitxers** per ampliar el lot.
3. Fes clic a **Converteix a PDF**. Un motor basat en LibreOffice es carrega al navegador i converteix cada document WPS a PDF.
4. Un fitxer es descarrega directament com a PDF. Diversos fitxers s'agrupen en un arxiu ZIP anomenat `wps-to-pdf.zip`.

## Opcions

No calen paràmetres addicionals. El convertidor gestiona el text, el format bàsic i les imatges incrustades del fitxer WPS.

## Casos d'ús

- Recuperar documents antics d'escola o de feina desats en format Microsoft Works
- Obrir fitxers WPS adjunts al correu quan no tens Microsoft Works instal·lat
- Convertir un arxiu de fitxers WPS per migrar-lo a un sistema de documents modern
- Imprimir documents antics que els processadors de textos actuals no poden obrir

## Consells

- No confonguis els fitxers `.wps` de Microsoft Works amb els fitxers de WPS Office. Aquesta eina és específicament per al format antic de Microsoft Works.
- El motor LibreOffice triga una estona a carregar-se en el primer ús. Un cop carregat, les conversions següents de la mateixa sessió són més ràpides.

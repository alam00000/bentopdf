# Emplena formularis PDF

Obre un PDF amb camps de formulari i emplena'l directament en un visor integrat. L'eina admet tant els camps AcroForm estàndard com els formularis XFA (XML Forms Architecture) heretats. Quan hagis acabat el formulari, baixa la versió emplenada amb un sol clic.

## Com funciona

1. Puja un PDF que contingui camps de formulari.
2. El document s'obre en un visor de PDF integrat que mostra els camps de formulari com a entrades interactives.
3. Fes clic als camps de text, les caselles de selecció, els desplegables i els botons d'opció per emplenar-los.
4. Fes clic a **Desa i baixa el formulari emplenat** per obtenir el PDF completat.

## Funcionalitats

- Visor PDF.js integrat amb interacció completa amb els camps de formulari
- Compatibilitat amb els camps AcroForm estàndard (entrades de text, caselles de selecció, desplegables, botons d'opció)
- Compatibilitat amb formularis XFA per a formularis heretats basats en XML
- Mida del visor ajustada automàticament segons les dimensions de la pàgina
- Visualització del fitxer amb el nom i la mida

## Opcions

No hi ha opcions de configuració addicionals. Puja el formulari, emplena'l i baixa'l.

## Casos d'ús

- Completar formularis d'impostos, sol·licituds d'assegurança o tràmits administratius
- Emplenar formularis de sol·licitud de feina rebuts com a fitxers PDF adjunts
- Completar formularis d'alta de proveïdors o qüestionaris per a proveïdors
- Aprovar llistes de control de compliment amb camps de casella de selecció
- Emplenar formularis mèdics d'ingrés abans d'una cita

## Consells

- Els formularis XFA són un format heretat que només admeten alguns visors de PDF. Si obres un PDF XFA a Chrome o a la majoria d'altres eines i veus pàgines en blanc, vol dir que aquests visors no admeten XFA. L'emplenador de formularis de BentoPDF i Firefox gestionen correctament l'XFA.
- Per als PDF sense camps de formulari, fes servir l'eina [Crea un formulari PDF](./form-creator) per afegir-hi camps primer i després emplena'ls aquí.
- El visor ajusta automàticament la mida perquè coincideixi amb les dimensions de la pàgina del PDF.

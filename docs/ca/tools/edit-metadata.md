# Edita les metadades

Edita les metadades incrustades en un fitxer PDF. L'eina emplena prèviament un formulari amb les metadades existents del document, et deixa modificar qualsevol camp i desa els canvis en un PDF nou.

## Com funciona

1. Puja un fitxer PDF. L'eina en llegeix les metadades actuals i emplena el formulari.
2. Edita qualsevol dels camps estàndard: Títol, Autor, Assumpte, Paraules clau, Creador, Productor.
3. Ajusta la Data de creació i la Data de modificació amb els selectors de data i hora.
4. Afegeix camps de metadades personalitzats fent clic al botó d'afegir i introduint un parell clau-valor.
5. Fes clic al botó de processar per desar el PDF modificat.

## Funcions

- Emplena prèviament totes les metadades existents del PDF pujat
- Camps estàndard: Títol, Autor, Assumpte, Paraules clau, Creador, Productor
- Selectors de data i hora per a la Data de creació i la Data de modificació
- Camps de metadades personalitzats de tipus clau-valor per a propietats arbitràries
- Desa els canvis directament al diccionari d'informació del document del PDF

## Camps editables

| Camp                     | Descripció                                                   |
| ------------------------ | ------------------------------------------------------------ |
| **Títol**                | El títol del document que mostren els lectors de PDF         |
| **Autor**                | La persona o organització que ha creat el document           |
| **Assumpte**             | Una breu descripció del tema del document                    |
| **Paraules clau**        | Termes separats per comes per a la cerca i la categorització |
| **Creador**              | L'aplicació que va crear originalment el contingut           |
| **Productor**            | L'aplicació que ha generat el PDF                            |
| **Data de creació**      | Quan es va crear originalment el document                    |
| **Data de modificació**  | Quan es va modificar per darrera vegada el document          |
| **Camps personalitzats** | Qualsevol parell clau-valor addicional que defineixis        |

## Casos d'ús

- Definir un títol i un autor adequats abans de publicar un document
- Afegir paraules clau per millorar la cerca als sistemes de gestió documental
- Actualitzar la data de modificació perquè reflecteixi la revisió actual
- Afegir camps de metadades personalitzats com Departament, ID de projecte o Classificació
- Netejar les metadades que ha deixat el programari d'autoria original

## Consells

- Els camps personalitzats s'escriuen directament al diccionari d'informació del PDF. Pot ser que alguns lectors de PDF no mostrin els camps personalitzats, però es conserven al fitxer.
- Deixa un camp en blanc per esborrar-lo de les metadades. El botó de processar desa el que hi hagi al formulari.
- Per veure les metadades sense editar-les, fes servir [Visualitza les metadades](./view-metadata). Per eliminar-les totes completament, fes servir Elimina les metadades.

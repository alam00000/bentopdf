# PDF a ZIP

Agrupa diversos fitxers PDF en un únic arxiu ZIP. És una eina d'empaquetament senzilla: no es converteix, comprimeix ni modifica els PDF.

## Com funciona

1. Carrega diversos fitxers PDF amb la zona de càrrega.
2. Revisa la llista de fitxers. Elimina els que no vulguis incloure.
3. Fes clic al botó de processar.
4. Un arxiu ZIP amb tots els PDF carregats es baixa immediatament.

## Característiques

- Accepta qualsevol nombre de fitxers PDF
- Eliminació de fitxers individuals abans de crear l'arxiu
- Conserva els noms de fitxer originals dins del ZIP
- No modifica el contingut dels PDF: els fitxers s'empaqueten tal com són
- Mostra el nom i la mida de cada PDF carregat

## Casos d'ús

- Agrupar un conjunt de factures o rebuts per adjuntar-los en un correu
- Empaquetar lliurables d'un projecte (diversos informes en PDF) per al traspàs
- Crear una única baixada per a una col·lecció de formularis o plantilles
- Arxivar un lot de documents en un sol fitxer comprimit

## Consells

- El fitxer ZIP utilitza els noms de fitxer originals dels PDF. Si tens fitxers amb el mateix nom, canvia'ls abans de carregar-los per evitar conflictes.
- Aquesta eina no comprimeix els PDF en si. Per reduir-ne la mida, passa'ls primer per Comprimeix PDF i després empaqueta'ls amb aquesta eina.

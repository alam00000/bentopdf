# Gira amb un angle personalitzat

Gira les pàgines d'un PDF en qualsevol angle arbitrari, no només en increments de 90 graus. Cada pàgina té el seu propi camp d'angle, i pots aplicar un mateix angle a totes les pàgines alhora amb el control per lots.

## Com funciona

1. Puja un fitxer PDF. Es mostren miniatures de totes les pàgines.
2. Cada pàgina té un camp numèric que mostra el seu angle de rotació actual.
3. Escriu qualsevol valor en graus (positiu o negatiu) per girar una pàgina concreta, o utilitza els botons esquerra/dreta de cada pàgina per fer ajustos ràpids de 90 graus.
4. Utilitza el camp **angle per lots** de la part superior per aplicar una rotació uniforme a totes les pàgines.
5. Fes clic al botó de processament per generar el PDF girat.

## Funcions

- Camp de graus lliure per pàgina (qualsevol valor enter)
- Control d'angle per lots per aplicar la mateixa rotació a cada pàgina
- Previsualització de la rotació en temps real a les miniatures
- Botons de gir ràpid per pàgina en increments de 90 graus
- Miniatures amb càrrega diferida per a un bon rendiment en documents grans

## Casos d'ús

- Corregir escanejats lleugerament inclinats uns quants graus
- Girar pàgines per complir un requisit d'orientació no estàndard
- Aplicar rotacions precises a pàgines individuals d'un document amb contingut mixt
- Ajustar amb precisió els angles de les pàgines després d'una rotació massiva inicial

## Consells

- Els valors positius giren en sentit horari i els negatius en sentit antihorari.
- El camp d'angle per lots sobreescriu tots els angles de cada pàgina quan s'aplica. Si cal, fes els ajustos individuals després de l'operació per lots.
- Per a rotacions estàndard de 90/180/270 graus amb una interfície més senzilla, utilitza [Gira PDF](./rotate-pdf).

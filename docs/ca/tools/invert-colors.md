# Inverteix els colors

Canvia cada color del PDF pel seu invers. Els fons blancs passen a ser negres, el text negre passa a ser blanc i la resta de colors es converteixen en els seus complementaris. És la manera més ràpida de crear una versió en «mode fosc» de qualsevol PDF.

## Com funciona

1. Puja el fitxer PDF.
2. Fes clic a **Inverteix els colors** per processar-lo.
3. El PDF invertit es baixa automàticament.

No hi ha cap paràmetre addicional. L'eina renderitza cada pàgina com a imatge, inverteix el color de tots els píxels i torna a muntar el resultat en un PDF nou.

## Funcionalitats

- Inversió de colors amb un sol clic per a totes les pàgines
- Processa totes les pàgines del document
- Manté les dimensions i el disseny originals de la pàgina
- Funciona amb qualsevol PDF, sigui quin sigui el tipus de contingut (text, imatges o mixt)

## Casos d'ús

- Crear versions en mode fosc de llibres de text o manuals per llegir còmodament de nit
- Preparar versions d'alt contrast dels documents per a l'accessibilitat
- Invertir documents escanejats que es van capturar amb una exposició incorrecta
- Generar versions en negatiu de PDF plens d'imatges per a l'anàlisi visual

## Consells

- Com que l'eina rasteritza les pàgines per aplicar l'efecte, el resultat és basat en imatges. El text ja no es podrà seleccionar ni cercar. Si necessites text cercable després de la inversió, passa el resultat per una eina d'OCR.
- Per a ajustos de color més detallats (brillantor, contrast, saturació), fes servir l'eina [Ajusta els colors](./adjust-colors).
- Els PDF grans amb moltes pàgines poden trigar més a processar-se, ja que cada pàgina es renderitza i s'inverteix per separat.

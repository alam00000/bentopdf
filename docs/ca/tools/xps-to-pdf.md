# XPS a PDF

Converteix documents Microsoft XPS i OXPS en fitxers PDF estàndard. XPS (XML Paper Specification) va ser la resposta de Microsoft al PDF, però el seu suport ha anat minvant a totes les plataformes. Aquesta eina fa que aquests documents tornin a ser llegibles per a tothom.

## Formats admesos

| Format | Extensió | Notes                                        |
| :----- | :------- | :------------------------------------------- |
| XPS    | `.xps`   | Format XPS original de Microsoft             |
| OXPS   | `.oxps`  | Open XPS, la variant de l'estàndard ECMA-388 |

## Com funciona

1. Fes clic a l'àrea de càrrega o arrossega i deixa anar els fitxers XPS/OXPS. Pots seleccionar diversos fitxers alhora.
2. Revisa la llista de fitxers. Elimina fitxers individuals amb la icona de la paperera, o fes clic a **Afegeix més fitxers** per afegir-hi més documents.
3. Fes clic a **Converteix a PDF**. El motor PyMuPDF processa cada document localment al navegador.
4. Un sol fitxer es descarrega directament com a PDF. Diversos fitxers s'agrupen en un arxiu ZIP anomenat `xps-converted.zip`.

## Opcions

Aquesta eina fa una conversió de format directa, sense cap configuració addicional. La sortida conserva les dimensions de pàgina, els gràfics vectorials, les tipografies i les imatges originals de l'XPS.

## Casos d'ús

- Obrir fitxers XPS rebuts de sistemes Windows antics que feien servir per defecte el controlador d'impressió XPS
- Convertir documents OXPS de Windows 10/11 per compartir-los amb usuaris de macOS o Linux
- Arxivar fitxers XPS antics en un format més àmpliament compatible
- Fer accessibles a destinataris externs documents governamentals o corporatius basats en XPS

## Consells

- Les extensions `.xps` i `.oxps` es gestionen automàticament: les pots barrejar en un mateix lot.
- Si el fitxer XPS original es va crear amb un controlador d'impressió d'alta resolució, el PDF resultant conserva aquesta qualitat. No es fa cap remostreig.

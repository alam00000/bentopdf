# Eina PDF multifunció

Un espai de treball unificat per a totes les operacions de PDF a nivell de pàgina. Carrega un o més PDF i treballa amb totes les pàgines en una sola quadrícula visual. Gira, reordena, duplica, suprimeix, insereix PDF, imatges i pàgines en blanc, renumera, redimensiona i divideix el resultat, sense sortir de l'eina.

## Com funciona

1. Fes clic a **Selecciona fitxers** o arrossega fitxers a la zona de càrrega. Admet diversos fitxers, que es combinen en l'ordre en què es carreguen.
2. Totes les pàgines apareixen en una quadrícula desplaçable amb miniatures.
3. Fes clic a una pàgina per seleccionar-la. Fes Shift-clic per seleccionar un interval i Cmd/Ctrl-clic per afegir o treure pàgines individuals de la selecció.
4. Utilitza la barra d'eines de l'organitzador o fes clic amb el botó dret a una pàgina per accedir a les accions de pàgina.
5. Fes clic a **Exporta el PDF** per baixar el resultat final.

## Característiques

- **Fusiona**: carrega diversos PDF i imatges i es combinen automàticament en un sol document
- **Reordena**: arrossega i deixa anar les pàgines per canviar la seqüència, o inverteix l'ordre de tot el document
- **Gira**: gira les pàgines seleccionades a l'esquerra o a la dreta en increments de 90 graus
- **Duplica**: copia les pàgines seleccionades i col·loca les còpies just després
- **Suprimeix**: elimina les pàgines seleccionades
- **Insereix**: afegeix pàgines d'un altre PDF o d'una imatge, una pàgina en blanc, pàgines del porta-retalls, o intercala les pàgines d'un segon PDF amb les actuals
- **Substitueix**: canvia una pàgina per la primera pàgina d'un altre PDF
- **Retalla, copia i enganxa**: mou o copia pàgines dins del document
- **Extreu**: baixa les pàgines seleccionades com a PDF o com a imatges
- **Números de pàgina**: defineix etiquetes de pàgina com i, ii, iii o A-1, A-2 per a un interval de pàgines
- **Mida de pàgina**: ajusta les pàgines a una mida de paper estàndard o a una mida personalitzada
- **Divideix**: divideix el document per intervals de pàgines, pàgines senars i parells, cada pàgina, marcadors, cada N pàgines o mida del fitxer
- **Desfés / Refés**: totes les operacions de pàgina es poden desfer i refer
- Repara automàticament els PDF malmesos abans de carregar-los

## Dreceres de teclat

| Acció                          | Drecera                       |
| ------------------------------ | ----------------------------- |
| Gira a la dreta / a l'esquerra | R / Shift+R                   |
| Selecciona-ho tot              | Cmd/Ctrl+A                    |
| Retalla, copia, enganxa        | Cmd/Ctrl+X, C, V              |
| Duplica                        | Cmd/Ctrl+D                    |
| Suprimeix                      | Supr o Retrocés               |
| Desfés / Refés                 | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| Mou la selecció                | Tecles de fletxa, Home, End   |

## Casos d'ús

- Crear un document personalitzat amb pàgines de diversos PDF d'origen
- Netejar un document escanejat suprimint pàgines en blanc, girant els escanejos de costat i reordenant seccions
- Dividir un PDF gran pels capítols fent servir els seus marcadors
- Edició ràpida a nivell de pàgina sense necessitat d'un editor de PDF complet

## Consells

- L'historial de desfer i refer registra cada operació de pàgina. Utilitza'l amb llibertat: no pots destruir el teu treball per accident.
- Utilitza **Insert > From File** o deixa anar més PDF o imatges a la quadrícula de pàgines en qualsevol moment per afegir-los al document.
- Per a tasques senzilles de fusió o divisió, les eines dedicades [Fusiona PDF](./merge-pdf) o [Divideix PDF](./split-pdf) poden ser més ràpides. L'eina multifunció destaca quan necessites fer diverses operacions en una sola sessió.

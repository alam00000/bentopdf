# Eina PDF multifunció

Un espai de treball unificat per a totes les operacions de PDF a nivell de pàgina. Carrega un o més PDF i treballa amb totes les pàgines en una sola quadrícula visual. Gira, reordena, duplica, suprimeix, insereix PDF nous, afegeix pàgines en blanc i divideix el resultat, sense sortir de l'eina.

## Com funciona

1. Fes clic a **Carrega PDF** o arrossega fitxers a la zona de càrrega. Admet diversos fitxers.
2. Totes les pàgines de tots els fitxers carregats apareixen en una quadrícula desplaçable amb miniatures.
3. Utilitza la barra d'eines o els botons d'acció de cada pàgina per manipular les pàgines.
4. Selecciona pàgines amb la casella de cada targeta i aplica-hi operacions en bloc.
5. Marca punts de divisió amb la icona de les tisores per dividir la sortida en fitxers separats.
6. Fes clic a **Exporta PDF** per baixar el resultat final. Si hi ha marques de divisió, la sortida és un ZIP amb diversos PDF.

## Característiques

- **Fusiona**: carrega diversos PDF i es combinen automàticament en un sol espai de treball
- **Reordena**: arrossega i deixa anar les targetes de pàgina per canviar la seqüència
- **Gira**: rotació per pàgina o en bloc en increments de 90 graus (a l'esquerra o a la dreta)
- **Duplica**: clona qualsevol pàgina amb un clic
- **Suprimeix**: elimina pàgines individuals o suprimeix en bloc les seleccionades
- **Insereix PDF**: afegeix un PDF nou després de qualsevol pàgina concreta
- **Afegeix una pàgina en blanc**: afegeix una pàgina A4 en blanc al final
- **Divideix**: col·loca marques de divisió entre pàgines i exporta com a ZIP de PDF separats
- **Selecciona-ho tot / Desselecciona-ho tot**: selecció ràpida per a operacions en bloc
- **Desfés / Refés**: historial complet de desfer i refer per a cada operació
- **Baixa la selecció**: exporta només les pàgines seleccionades com a PDF independent
- Repara automàticament els PDF malmesos abans de carregar-los

## Casos d'ús

- Crear un document personalitzat amb pàgines de diversos PDF d'origen
- Netejar un document escanejat suprimint pàgines en blanc, girant els escanejos de costat i reordenant seccions
- Dividir un PDF gran pels límits dels capítols amb marques de divisió visuals
- Edició ràpida a nivell de pàgina sense necessitat d'un editor de PDF complet

## Consells

- El sistema de desfer i refer registra cada operació. Utilitza'l amb llibertat: no pots destruir el teu treball per accident.
- Les marques de divisió apareixen com a línies blaves discontínues entre pàgines. Col·loca-les visualment on vulguis dividir el document i exporta per obtenir un ZIP.
- Per a tasques senzilles de fusió o divisió, les eines dedicades [Fusiona PDF](./merge-pdf) o [Divideix PDF](./split-pdf) poden ser més ràpides. L'eina multifunció destaca quan necessites fer diverses operacions en una sola sessió.

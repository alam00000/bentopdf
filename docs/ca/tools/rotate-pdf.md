# Gira PDF

Gira les pàgines d'un PDF 90 graus en sentit horari o antihorari. L'eina mostra miniatures de cada pàgina i et permet girar-les individualment o aplicar una rotació massiva a tot el document.

## Com funciona

1. Puja un fitxer PDF. Les miniatures de totes les pàgines es mostren en una quadrícula.
2. Utilitza els botons de rotació esquerra/dreta sota cada miniatura per girar aquella pàgina concreta.
3. Utilitza els controls de rotació massiva de la part superior per girar totes les pàgines alhora.
4. La previsualització de les miniatures s'actualitza en temps real per mostrar la rotació.
5. Fes clic al botó de processament per desar el PDF girat.

## Funcions

- Rotació per pàgina en increments de 90 graus (esquerra o dreta)
- Rotació massiva de totes les pàgines alhora
- Previsualització de miniatures en temps real amb transicions de rotació animades
- Miniatures amb càrrega diferida per a un rendiment fluid en documents grans
- Conserva el contingut i la qualitat originals de les pàgines

## Casos d'ús

- Corregir pàgines escanejades de costat o cap per avall
- Girar pàgines horitzontals a orientació vertical (o a l'inrevés)
- Corregir un document amb orientació mixta on algunes pàgines es van escanejar amb un angle incorrecte
- Preparar un document per a una orientació de visualització concreta

## Consells

- Les rotacions són acumulatives. Si fas clic dues vegades al botó horari, s'aplica una rotació de 180 graus.
- Per a rotacions que no siguin de 90 graus (p. ex., 45 graus per corregir un escanejat lleugerament inclinat), utilitza [Gira amb un angle personalitzat](./rotate-custom).
- Els controls de rotació massiva afecten totes les pàgines, no només les seleccionades. Aquesta eina no té cap mecanisme de selecció: per a això, utilitza [Eina PDF multifunció](./pdf-multi-tool).

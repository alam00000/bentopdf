# Afegeix fitxers adjunts

Incrusta un o més fitxers directament dins d'un document PDF. Els adjunts es poden afegir a nivell de document (visibles al tauler d'adjunts de qualsevol lector de PDF) o vincular a pàgines concretes.

## Com funciona

1. Puja el PDF al qual vols adjuntar fitxers.
2. Fes servir la zona de càrrega d'adjunts per seleccionar els fitxers que vols incrustar (de qualsevol tipus).
3. Tria el nivell de l'adjunt: **Document** (per defecte) o **Pàgina**.
4. Si tries el nivell de pàgina, introdueix un interval de pàgines (per exemple, `1-3` o `5`).
5. Fes clic al botó de processar. El PDF modificat es baixa amb els fitxers incrustats.

## Característiques

- Adjunta qualsevol tipus de fitxer: imatges, fulls de càlcul, arxius comprimits, executables, el que sigui
- Adjunts a nivell de document o de pàgina
- Es poden adjuntar diversos fitxers en una sola operació
- Mostra els noms i les mides de tots els adjunts seleccionats
- El resultat conserva el contingut original del PDF amb els fitxers incrustats afegits

## Opcions

| Opció                  | Descripció                                                                    |
| ---------------------- | ----------------------------------------------------------------------------- |
| **Nivell de document** | Adjunta els fitxers al PDF en conjunt, accessibles des del tauler d'adjunts   |
| **Nivell de pàgina**   | Adjunta els fitxers a pàgines concretes, indicades amb un interval de pàgines |

## Casos d'ús

- Incloure dades d'origen (fitxers Excel, CSV) amb un informe en PDF
- Adjuntar les imatges originals a un PDF de portfoli fotogràfic
- Incrustar documents justificatius dins d'un contracte o una proposta
- Afegir material complementari a pàgines concretes d'un manual de formació

## Consells

- Els adjunts a nivell de document són els més compatibles amb els lectors de PDF. És possible que els adjunts a nivell de pàgina no es vegin en tots els visualitzadors.
- No hi ha cap límit de mida per als adjunts, però els fitxers incrustats molt grans fan créixer el PDF en la mateixa proporció.

# Duplica i organitza

Reorganitza, duplica i elimina pàgines d'un PDF amb una interfície visual d'arrossegar i deixar anar. Cada pàgina apareix com a miniatura que pots moure, clonar o suprimir abans de desar el resultat com a fitxer nou.

## Com funciona

1. Carrega un únic fitxer PDF.
2. L'eina renderitza una quadrícula de miniatures amb totes les pàgines.
3. Arrossega les miniatures per reordenar les pàgines, fes clic al botó verd de duplicar per clonar una pàgina o al botó vermell de suprimir per eliminar-la.
4. També pots introduir un ordre de pàgines personalitzat al camp de text (p. ex., `3, 1, 2, 4`) i fer clic a **Aplica** per reorganitzar totes les pàgines alhora.
5. Fes clic al botó de processar per crear i baixar el PDF reorganitzat.

## Característiques

- Reordenació de pàgines arrossegant i deixant anar amb transicions animades
- Botons de duplicar i suprimir per a cada pàgina
- Camp d'ordre de pàgines personalitzat per a una reorganització precisa
- Els números de pàgina s'actualitzen automàticament després de cada canvi
- Impedeix suprimir l'última pàgina que queda

## Casos d'ús

- Moure una pàgina mal col·locada a la posició correcta d'un informe
- Duplicar la pàgina d'un formulari per tenir diverses còpies en blanc en un sol fitxer
- Eliminar pàgines d'esborrany o de reserva abans de distribuir un document
- Invertir o barrejar l'ordre de les pàgines per preparar la impressió
- Crear una seqüència de pàgines personalitzada sense tornar a fusionar fitxers separats

## Consells

- El camp d'ordre de pàgines personalitzat espera els números de pàgina originals separats per comes. Ha d'incloure cada pàgina exactament una vegada, sense ometre'n ni repetir-ne cap.
- Després de duplicar una pàgina, les dues còpies fan referència al mateix índex de pàgina original. Reordenar qualsevol de les dues funciona de manera independent.
- Per a operacions en bloc amb diversos fitxers o fluxos més avançats, considera l'[Eina PDF multifunció](./pdf-multi-tool).

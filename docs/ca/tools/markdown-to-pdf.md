# Markdown a PDF

Un editor de Markdown complet amb vista prèvia en directe i exportació a PDF amb un sol clic. Escriu des de zero, puja un fitxer `.md` existent o enganxa contingut del porta-retalls. L'editor renderitza el Markdown en temps real i exporta un PDF amb estil mitjançant el motor d'impressió integrat al navegador.

## Formats compatibles

| Entrada         | Descripció                           |
| :-------------- | :----------------------------------- |
| Fitxers `.md`   | Puja'ls amb el botó Puja             |
| Entrada directa | Escriu o enganxa al camp de l'editor |

## Com funciona

1. Obre l'eina Markdown a PDF. L'editor es carrega amb una vista dividida: el codi Markdown a l'esquerra i la vista prèvia renderitzada a la dreta.
2. Escriu el Markdown, enganxa'l o fes clic a **Puja** per carregar un fitxer `.md`.
3. Canvia entre el tema clar i el fosc amb el control lliscant de tema de la barra d'eines.
4. Fes clic a **Exporta PDF** (o prem `Ctrl/Cmd + S`) per generar un PDF mitjançant el diàleg d'impressió del navegador.

## Funcionalitats

L'editor admet un conjunt ampli de funcionalitats de Markdown més enllà de les bàsiques:

- **Markdown estàndard**: encapçalaments, negreta, cursiva, enllaços, imatges, llistes, cites, línies horitzontals
- **Blocs de codi** amb ressaltat de sintaxi per a més de 15 llenguatges (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash i més)
- **Diagrames Mermaid**: els diagrames de flux, de seqüència, ER i altres tipus de gràfics Mermaid es renderitzen directament a la vista prèvia
- **Taules** amb la sintaxi estàndard de taules de Markdown
- **Llistes de tasques** amb caselles de selecció
- **Notes a peu de pàgina**, **subíndexs**, **superíndexs**
- **Llistes de definicions**, **abreviatures**
- Compatibilitat amb **emojis** (`:smile:` es renderitza com a emoji)
- **Ressaltats** (`==marked text==`) i **insercions** (`++inserted text++`)
- **URL enllaçades automàticament**: les URL soltes es converteixen en enllaços clicables
- Generació de **taula de continguts**
- **Enllaços d'àncora** als encapçalaments

## Casos d'ús

- Escriure documentació de projectes i exportar un PDF acurat per als interessats
- Crear informes tècnics amb exemples de codi i diagrames d'arquitectura Mermaid
- Convertir un README de GitHub en un PDF per utilitzar-lo sense connexió o imprimir-lo
- Redactar una proposta o una especificació amb llistes de tasques i taules
- Generar un full de resum amb estil a partir d'apunts de classe escrits en Markdown

## Consells

- El PDF resultant es genera amb la funció d'imprimir a PDF del navegador. A Chrome, pots personalitzar els marges i l'escala al diàleg d'impressió abans de desar.
- Els diagrames Mermaid es renderitzen a la vista prèvia, però poden necessitar un moment per inicialitzar-se el primer cop.
- Fes servir `Ctrl/Cmd + S` com a drecera de teclat per exportar sense haver d'anar al botó.

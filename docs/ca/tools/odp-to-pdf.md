# ODP a PDF

Converteix fitxers OpenDocument Presentation en PDF. ODP és el format natiu de LibreOffice Impress i una exportació estàndard de Google Slides. Convertir les presentacions a PDF permet que qualsevol persona les pugui veure sense programari de presentacions, i les diapositives s'imprimeixen netament.

## Formats compatibles

| Format                    | Extensió | Notes                                             |
| :------------------------ | :------- | :------------------------------------------------ |
| OpenDocument Presentation | `.odp`   | LibreOffice Impress / exportació de Google Slides |

## Com funciona

1. Fes clic a l'àrea de càrrega o arrossega-hi els fitxers ODP. Pots seleccionar diverses presentacions alhora.
2. Revisa la llista de fitxers. Elimina entrades amb la icona de la paperera, o fes servir **Afegeix més fitxers** per incloure més presentacions.
3. Fes clic a **Converteix a PDF**. El motor basat en LibreOffice processa cada presentació i genera un PDF on cada diapositiva és una pàgina.
4. Si és un sol fitxer, es baixa com a PDF. Si són diversos, es lliuren en un arxiu ZIP anomenat `odp-to-pdf.zip`.

## Opcions

No hi ha res per configurar. Cada diapositiva es renderitza a les seves dimensions originals, conservant el text, les imatges, les formes i els fons de les diapositives.

## Casos d'ús

- Distribuir una presentació al públic com a PDF de resum
- Compartir exportacions de Google Slides amb persones que prefereixen el PDF a l'ODP
- Arxivar xerrades de congressos i classes en un format de només lectura
- Imprimir presentacions per a tallers presencials

## Consells

- Les transicions i les animacions de les diapositives són funcions purament visuals que no passen al PDF, però tot el contingut estàtic es renderitza correctament.
- Les notes de l'orador no s'inclouen al PDF resultant. Si en necessites, exporta-les per separat des del teu programari de presentacions.
- Com les altres eines basades en LibreOffice, el motor es carrega el primer cop que s'usa i es conserva a la memòria cau durant la sessió.

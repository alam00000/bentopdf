# Uniformitza la mida de pàgina

Els PDF muntats a partir de diverses fonts solen tenir pàgines de mides diferents: unes en Letter, unes altres en A4 i d'altres amb mides gens estàndard. Aquesta eina força totes les pàgines a una única mida de destinació i escala el contingut perquè hi càpiga o l'ompli, segons el cas.

## Com funciona

1. Puja un fitxer PDF.
2. Selecciona una **Mida de pàgina de destinació** al desplegable (A4, Letter, Legal, A3, A5, Tabloid o Personalitzada).
3. Tria una **Orientació**: Automàtica conserva l'orientació original de cada pàgina, o bé pots forçar Vertical o Horitzontal.
4. Escull un mode d'**Escalat del contingut**: Ajusta (conserva tot el contingut i pot afegir marges) o Omple (omple la pàgina i pot retallar les vores).
5. Si vols, defineix un **Color de fons** per als marges afegits.
6. Fes clic a **Uniformitza la mida de pàgina**.

## Opcions

- **Mides estàndard**: A4, Letter, Legal, A3, A5, Tabloid
- **Dimensions personalitzades**: introdueix l'amplada i l'alçada en polzades o mil·límetres
- **Orientació**: Automàtica, Vertical, Horitzontal
- **Mode d'escalat**: Ajusta o Omple (retalla)
- **Color de fons**: qualsevol color per als marges

## Casos d'ús

- Normalitzar un PDF fusionat amb pàgines que provenen d'escàners diferents
- Convertir un document en US Letter a A4 per distribuir-lo internacionalment
- Preparar PDF llestos per imprimir que requereixen una mida de tall uniforme
- Corregir pàgines que no s'ajusten gaire a l'estàndard (p. ex., 8,49 x 11,02 polzades en lloc de 8,5 x 11)

## Consells

- Fes servir el mode Ajusta per garantir que no es perdi cap contingut. El mode Omple té un aspecte més net, però pot tallar les vores.
- Comprova el resultat amb l'eina Dimensions de pàgina per confirmar que totes les pàgines coincideixen amb la mida de destinació.
- El blanc és el color de fons per defecte; canvia'l a un color fosc si el teu document té marges foscos.

- [Retalla PDF](./crop-pdf): retalla les pàgines manualment en lloc d'escalar-les automàticament

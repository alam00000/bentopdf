# Números de pàgina

Afegeix números de pàgina visibles a totes les pàgines del PDF. Tu tries la posició, el format, la mida del text i el color, i l'eina fa la resta.

## Com funciona

1. Carrega el fitxer PDF.
2. Configura els paràmetres dels números de pàgina al quadre d'opcions que apareix.
3. Fes clic a **Afegeix números de pàgina** per processar.
4. El PDF numerat es baixa automàticament.

## Opcions

- **Posició**: tria on apareixen els números de pàgina: a baix al centre, a baix a l'esquerra, a baix a la dreta, a dalt al centre, a dalt a l'esquerra o a dalt a la dreta.
- **Format**: selecciona entre la numeració simple (1, 2, 3...) o el format "pàgina X de Y" (1 / 5, 2 / 5...).
- **Mida del text**: defineix la mida del text del número de pàgina. Per defecte, 12.
- **Color**: tria qualsevol color per al text del número de pàgina amb el selector de color.

## Característiques

- Sis opcions de posició que cobreixen totes les cantonades i les posicions centrals
- Dos formats de numeració: correlatiu simple o "pàgina X de Y"
- Mida del text personalitzable de 6 a 72 punts
- Selector de color complet per al color del text
- Gestió automàtica dels marges que manté els números dins de les àrees segures, sigui quina sigui la mida de la pàgina

## Casos d'ús

- Preparar documents per imprimir que necessiten referències de pàgina visibles
- Afegir números de pàgina a un PDF fusionat creat a partir de diversos fitxers d'origen
- Numerar el material de les presentacions abans de distribuir-lo
- Afegir numeració correlativa a documents legals o contractes

## Consells

- El format "pàgina X de Y" és útil per als documents en què els lectors necessiten saber la longitud total, com ara propostes o informes.
- Si necessites estils de numeració diferents per a seccions diferents (com xifres romanes per a les pàgines preliminars), utilitza l'eina [Afegeix etiquetes de pàgina](./add-page-labels).

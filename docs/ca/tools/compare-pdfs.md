# Compara PDF

Puja dos PDF i comprova exactament què ha canviat entre ells. L'eina aparella les pàgines de manera intel·ligent, detecta diferències en el text, les imatges, les anotacions, les capçaleres i el format, i les presenta en una vista de costat a costat o de superposició.

## Com funciona

1. Puja dos fitxers PDF: l'original (a l'esquerra) i la versió revisada (a la dreta).
2. L'eina aparella les pàgines dels dos documents mitjançant signatures de contingut.
3. Selecciona un mode de vista: **Un al costat de l'altre** o **Superposició**.
4. Navega entre els parells de pàgines amb els controls de paginació.
5. Les diferències es ressalten i es classifiquen. Fes servir el tauler de filtres per centrar-te en tipus de canvi concrets.
6. Si vols, exporta la comparació com a informe en PDF.

## Funcions

- Aparellament automàtic de pàgines segons la semblança del contingut
- Vistes de comparació de costat a costat i de superposició
- Classificació dels canvis: text, imatge, capçalera/peu de pàgina, anotació, format, fons
- Filtres per categoria per mostrar o amagar tipus de canvi concrets
- Cerca de canvis de text amb filtratge per consulta
- Compatibilitat amb OCR per comparar documents escanejats
- Controls de zoom per a una inspecció detallada
- Desplaçament sincronitzat entre tauler i tauler en el mode de costat a costat
- Exporta els resultats de la comparació com a PDF

## Opcions

| Opció                     | Descripció                                                                                            |
| ------------------------- | ----------------------------------------------------------------------------------------------------- |
| **Mode de visualització** | Un al costat de l'altre o Superposició                                                                |
| **OCR**                   | Activa o desactiva l'OCR per comparar documents escanejats                                            |
| **Idioma de l'OCR**       | Idioma per a l'extracció de text amb OCR                                                              |
| **Filtres de categoria**  | Activa o desactiva la visibilitat dels canvis de text, imatge, capçalera/peu, anotació, format i fons |
| **Abast dels canvis**     | En mode de superposició, filtra entre tots els canvis o només el contingut                            |
| **Zoom**                  | Ajusta el nivell d'ampliació per a una inspecció detallada                                            |

## Casos d'ús

- Revisar les modificacions d'un contracte per trobar exactament què ha canviat entre versions
- Comparar maquetes de disseny per verificar que les exportacions a PDF coincideixen amb el que s'espera
- Auditar els canvis en documents de sectors regulats on cal registrar cada edició
- Verificar que un procés de conversió de PDF ha conservat amb precisió el contingut original
- Comprovar si hi ha canvis de disseny en documents traduïts respecte a l'original

## Consells

- La vista de superposició apila els dos documents l'un sobre l'altre, de manera que les diferències espacials (elements desplaçats, imatges redimensionades) es veuen a l'instant.
- Activa l'OCR quan comparis documents escanejats que no tenen capa de text. El motor de comparació extreurà el text de les imatges de les pàgines.
- Fes servir els filtres per categoria per centrar-te en el que importa. Per exemple, amaga els canvis de format quan només t'interessin les diferències en el text.

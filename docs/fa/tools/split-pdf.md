# تقسیم PDF

یک PDF را با یکی از شش حالت تقسیم به اسناد کوچک‌تر بشکنید. از بازه‌های سادهٔ صفحات تا تقسیم بر اساس نشانک‌ها، این ابزار همهٔ سناریوهای تقسیم سند را پوشش می‌دهد.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید.
2. یک حالت تقسیم از فهرست کشویی انتخاب کنید.
3. گزینه‌های ویژهٔ آن حالت را تنظیم کنید (بازه‌های صفحات، انتخاب‌ها و غیره).
4. روی دکمهٔ پردازش کلیک کنید.
5. نتیجه بسته به حالت و تنظیمات به‌صورت یک PDF یا یک بایگانی ZIP دانلود می‌شود.

## حالت‌های تقسیم

| حالت              | توضیح                                                                                                                   |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **بازه**          | بازه‌هایی مانند `1-3, 5, 8-10` وارد کنید. چند بازه PDFهای جداگانه در یک ZIP تولید می‌کنند. یک بازه یک PDF تولید می‌کند. |
| **انتخاب تصویری** | تصاویر کوچک صفحات را مرور کنید و صفحات دلخواه را با کلیک انتخاب کنید. صفحات انتخاب‌شده در یک PDF جدید استخراج می‌شوند.  |
| **زوج / فرد**     | فقط صفحات زوج یا فرد را استخراج کنید.                                                                                   |
| **همهٔ صفحات**    | هر صفحه را به یک فایل PDF جداگانه تقسیم کنید که به‌صورت ZIP دانلود می‌شود.                                              |
| **نشانک‌ها**      | در مرز نشانک‌ها تقسیم کنید. سطح نشانک را انتخاب کنید تا محل تقسیم‌ها مشخص شود.                                          |
| **هر N صفحه**     | به بخش‌های N صفحه‌ای تقسیم کنید (مثلاً هر ۵ صفحه). بخش آخر ممکن است صفحات کمتری داشته باشد.                             |

## ویژگی‌ها

- شش حالت تقسیم متمایز که تقریباً همهٔ موارد استفاده را پوشش می‌دهند
- انتخابگر تصویری صفحات با بارگذاری تنبل تصاویر کوچک
- تقسیم مبتنی بر نشانک با فیلتر سطح
- گزینهٔ خروجی ZIP برای حالت‌های بازه و تصویری
- پشتیبانی از بازه‌های صفحات با نحو ترکیبی (`1-3, 5, 8-10`)
- هشدار وقتی تقسیم N صفحه‌ای بخش‌های نابرابر ایجاد می‌کند

## موارد استفاده

- استخراج یک فصل یا بخش خاص از یک سند بزرگ
- جدا کردن صفحات فرد و زوج برای فرایندهای چاپ دورو
- شکستن PDF یک کتاب به فایل‌های جداگانهٔ فصل‌ها در مرز نشانک‌ها
- جدا کردن صفحات خاص (مانند صفحهٔ امضا) از یک قرارداد
- تقسیم یک گزارش گردآوری‌شده به فایل‌های جداگانهٔ هر بخش برای توزیع

## نکته‌ها

- چند بازهٔ صفحات که با کاما جدا شده‌اند (مثلاً `1-5, 10-15, 20-25`) PDFهای جداگانه تولید می‌کنند، یکی برای هر بازه، که در یک ZIP بسته‌بندی می‌شوند.
- حالت تقسیم با نشانک نیاز دارد PDF واقعاً نشانک داشته باشد. اگر هیچ نشانکی یافت نشود، پیام خطا دریافت می‌کنید.
- کادر «دانلود به‌صورت ZIP» در حالت‌های بازه و تصویری به شما امکان می‌دهد به‌جای یک فایل ترکیبی، برای هر صفحه یک PDF جداگانه بگیرید.

# وارونه‌سازی ترتیب صفحات

ترتیب صفحات PDF را برعکس کنید تا صفحهٔ آخر اول شود، صفحهٔ یکی مانده به آخر دوم شود و به همین ترتیب. از پردازش دسته‌ای چند فایل به‌طور هم‌زمان پشتیبانی می‌کند.

## نحوهٔ کار

1. یک یا چند فایل PDF بارگذاری کنید.
2. روی دکمهٔ پردازش کلیک کنید.
3. هر فایل به‌طور مستقل وارونه می‌شود. اگر چند فایل بارگذاری کرده باشید، خروجی یک بایگانی ZIP شامل همهٔ PDFهای وارونه است.
4. یک فایل مستقیماً به‌صورت PDF وارونه دانلود می‌شود.

## ویژگی‌ها

- پردازش دسته‌ای: وارونه‌سازی چند PDF در یک عملیات
- خروجی تک‌فایل برای یک PDF و خروجی ZIP برای چند فایل
- دکمهٔ حذف برای هر فایل پیش از پردازش
- حفظ همهٔ محتوا و قالب‌بندی صفحات

## موارد استفاده

- اصلاح سندی که به ترتیب معکوس اسکن شده است
- آماده‌سازی PDF ارائه برای خواندن از آخر به اول
- وارونه کردن ترتیب صفحات برای فرایندهای چاپی خاص که صفحات را به ترتیب معکوس تغذیه می‌کنند
- اصلاح سندی که صفحاتش به اشتباه برعکس کنار هم گذاشته شده‌اند

## نکته‌ها

- هر فایل در یک دسته به‌طور مستقل وارونه می‌شود و ترتیب خود فایل‌ها نسبت به هم تغییر نمی‌کند.
- برای جابه‌جایی دقیق‌تر صفحات (نه فقط وارونه‌سازی کامل)، از [تکثیر و سازماندهی](./organize-pdf) استفاده کنید.

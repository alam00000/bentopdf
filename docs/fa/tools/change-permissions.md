# تغییر مجوزها

آنچه گیرندگان می‌توانند با PDF شما انجام دهند را دقیق تنظیم کنید. برخلاف رمزگذاری ساده که فقط فایل را پشت گذرواژه قفل می‌کند، این ابزار به شما اجازه می‌دهد چاپ، کپی، ویرایش، حاشیه‌نویسی، پر کردن فرم، سرهم‌بندی سند و استخراج صفحه را به‌صورت انتخابی مجاز یا ممنوع کنید؛ همه با رمزگذاری AES ۲۵۶ بیتی اعمال می‌شوند.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید.
2. اگر PDF از قبل رمزگذاری شده است، **گذرواژهٔ فعلی** را وارد کنید.
3. یک **گذرواژهٔ کاربر جدید** (برای باز کردن لازم است) و/یا **گذرواژهٔ مالک جدید** (کنترل مجوزها) تعیین کنید.
4. هر مجوز را با کادرهای علامت روشن یا خاموش کنید.
5. روی **تغییر مجوزها** کلیک کنید.
6. PDF به‌روزشده را دانلود کنید.

اگر هر دو فیلد گذرواژهٔ جدید را خالی بگذارید، ابزار PDF را به‌طور کامل رمزگشایی می‌کند و همهٔ رمزگذاری‌ها و محدودیت‌ها را برمی‌دارد.

## کنترل‌های مجوز

| مجوز                      | آنچه کنترل می‌کند                              |
| ------------------------- | ---------------------------------------------- |
| **اجازهٔ چاپ**            | اینکه آیا سند قابل چاپ است                     |
| **اجازهٔ کپی**            | اینکه آیا متن و تصاویر قابل انتخاب و کپی هستند |
| **اجازهٔ تغییر**          | اینکه آیا محتوای سند قابل ویرایش است           |
| **اجازهٔ حاشیه‌نویسی**    | اینکه آیا می‌توان نظر، برجسته‌سازی و مهر افزود |
| **اجازهٔ پر کردن فرم‌ها** | اینکه آیا فیلدهای فرم تعاملی قابل تکمیل هستند  |
| **اجازهٔ سرهم‌بندی سند**  | اینکه آیا صفحات قابل درج، حذف یا چرخش هستند    |
| **اجازهٔ استخراج صفحه**   | اینکه آیا صفحات جداگانه قابل استخراج هستند     |

همهٔ مجوزها برای اعمال شدن به گذرواژهٔ مالک نیاز دارند. بدون گذرواژهٔ مالک، بیشتر نمایشگرهای PDF پرچم‌های مجوز را نادیده می‌گیرند.

## مجوزها در PDF چگونه کار می‌کنند

مجوزهای PDF بخشی از مشخصات رمزگذاری هستند. آن‌ها به‌صورت پرچم‌های بیتی در دیکشنری رمزگذاری ذخیره می‌شوند و نمایشگرهای PDF سازگار آن‌ها را اعمال می‌کنند. تفاوت اصلی:

- **گذرواژهٔ کاربر**: برای باز کردن فایل لازم است.
- **گذرواژهٔ مالک**: برای تغییر مجوزها یا برداشتن محدودیت‌ها لازم است. بدون آن، پرچم‌های مجوز تعیین می‌کنند کاربر چه عملیاتی می‌تواند انجام دهد.

اگر فقط گذرواژهٔ مالک تعیین کنید (بدون گذرواژهٔ کاربر)، هر کسی می‌تواند فایل را باز کند اما به عملیات مجاز محدود است. اگر هر دو را تعیین کنید، فایل برای باز شدن گذرواژه می‌خواهد و پس از احراز هویت نیز محدود است.

## کاربردها

- توزیع گزارشی که قابل مشاهده و چاپ است اما قابل ویرایش یا کپی نیست
- اشتراک‌گذاری الگوی قراردادی که گیرندگان می‌توانند پر کنند اما نمی‌توانند تغییر دهند
- انتشار کاتالوگ PDF که کپی تصاویر در آن غیرفعال است
- اجازهٔ حاشیه‌نویسی روی پیش‌نویس بازبینی در عین جلوگیری از تغییرات ساختاری

## نکته‌ها

- برای اثربخشی، همیشه گذرواژهٔ مالک تعیین کنید. مجوزها بدون گذرواژهٔ مالک قابل اعمال نیستند.
- برخی ابزارهای PDF شخص ثالث پرچم‌های مجوز را نادیده می‌گیرند. برای محافظت قوی‌تر، رستر کردن PDF یا استفاده از DRM را در نظر بگیرید.
- از این ابزار برای ارتقای PDFهای قدیمی رمزگذاری‌شده با RC4 به AES-256 استفاده کنید.

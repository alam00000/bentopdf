# PDF به PNG

هر صفحهٔ PDF را به یک تصویر PNG تبدیل می‌کند. PNG از فشرده‌سازی بدون افت استفاده می‌کند، بنابراین خروجی همهٔ جزئیات صفحهٔ اصلی را حفظ می‌کند. PDFهای تک‌صفحه‌ای به‌صورت فایل `.png` دانلود می‌شوند؛ PDFهای چندصفحه‌ای یک ZIP تولید می‌کنند.

## نحوهٔ کار

1. با کلیک روی ناحیهٔ رها کردن یا کشیدن فایل روی آن، یک PDF بارگذاری کنید.
2. لغزندهٔ **مقیاس تصویر** را برای کنترل وضوح خروجی تنظیم کنید.
3. برای شروع پردازش روی **تبدیل** کلیک کنید.
4. یک PNG یا یک بایگانی ZIP خودکار دانلود می‌شود.

## گزینه‌ها

- **مقیاس**: از 1.0x تا 3.0x (پیش‌فرض 2.0x). در 2.0x، یک صفحهٔ استاندارد letter تقریباً با 1,224 x 1,584 پیکسل رندر می‌شود. مقیاس‌های بالاتر تصاویر بزرگ‌تر و واضح‌تری تولید می‌کنند، به بهای حجم فایل و زمان پردازش بیشتر.

## قالب خروجی

- **تک‌صفحه**: `filename.png`
- **چندصفحه**: `filename_pngs.zip` شامل `page_1.png`، `page_2.png` و غیره.

## موارد استفاده

- گرفتن اسکرین‌شات‌های باکیفیت از صفحات PDF برای ارائه‌ها.
- استخراج نمودارها یا دیاگرام‌هایی که به لبه‌های تیز و بدون اثرات فشرده‌سازی نیاز دارند.
- آماده‌سازی داراییها برای طراحی وب از ماکت‌های PDF.
- ساخت تصاویر بدون افت صفحات برای پیش‌پردازش OCR.

## نکته‌ها

- فایل‌های PNG به‌طور چشمگیری از JPG بزرگ‌ترند. اگر حجم فایل از کیفیت کامل مهم‌تر است، از [PDF به JPG](./pdf-to-jpg) یا [PDF به WebP](./pdf-to-webp) استفاده کنید.
- در مقیاس 1.0x، خروجی با وضوح اصلی PDF برابر است. برای خروجی با کیفیت چاپ آن را تا 3.0x افزایش دهید.

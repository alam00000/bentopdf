# XML به PDF

فایل‌های دادهٔ XML را به اسناد PDF خوانا و ساختاریافته تبدیل کنید. XML خام قدرتمند است اما خواندن آن برای انسان دشوار است. این ابزار درخت XML را تجزیه می‌کند، ساختارهای دادهٔ تکرارشونده را شناسایی می‌کند و آن‌ها را به‌صورت جدول‌ها و بخش‌های قالب‌بندی‌شده در یک PDF افقی A4 نمایش می‌دهد.

## قالب‌های پشتیبانی‌شده

| قالب | پسوند  | توضیحات             |
| :--- | :----- | :------------------ |
| XML  | `.xml` | هر سند XML خوش‌ساخت |

## نحوهٔ کار

1. روی ناحیهٔ بارگذاری کلیک کنید یا فایل‌های XML خود را بکشید و رها کنید. چند فایل را می‌توان در یک دسته پردازش کرد.
2. فهرست فایل‌ها را بررسی کنید. فایل‌های ناخواسته را با نماد سطل زباله حذف کنید یا روی **افزودن فایل‌های بیشتر** کلیک کنید.
3. روی **تبدیل به PDF** کلیک کنید. ابزار ساختار XML را با DOMParser داخلی مرورگر تجزیه می‌کند، سلسله‌مراتب داده را تحلیل می‌کند و آن را با jsPDF و قالب‌بندی auto-table به PDF تبدیل می‌کند.
4. یک فایل تکی به‌صورت PDF دانلود می‌شود. چند تبدیل در `xml-to-pdf.zip` بسته‌بندی می‌شوند.

## گزینه‌ها

به پیکربندی دستی نیازی نیست. مبدل ساختار XML را به‌طور خودکار تشخیص می‌دهد و چیدمان‌های جدول مناسب را انتخاب می‌کند. خروجی از جهت افقی A4 استفاده می‌کند تا مجموعه‌داده‌های عریض جا شوند.

## موارد استفاده

- تبدیل خروجی‌های دادهٔ XML از پایگاه‌داده‌ها یا APIها به گزارش‌های قابل چاپ
- ساخت خلاصه‌های خوانا از فایل‌های پیکربندی XML
- تبدیل فاکتورها یا لاگ‌های تراکنش مبتنی بر XML به PDF برای نگهداری سوابق
- خوانا کردن نقشه‌های سایت XML یا خوراک‌های RSS در قالب سند

## نکته‌ها

- XML باید خوش‌ساخت باشد. اگر تجزیه‌گر با خطای نحوی روبه‌رو شود، تبدیل با یک پیام خطای توصیفی که به مشکل اشاره می‌کند ناموفق می‌شود.
- ساختارهای XML با تودرتویی عمیق به جدول‌ها تخت می‌شوند. برای بهترین نتیجه، داده باید عناصر هم‌سطح تکرارشونده با عناصر فرزند یکسان داشته باشد.
- در طول تبدیل، به‌روزرسانی‌های پیشرفت نمایش داده می‌شوند و هر مرحله را نشان می‌دهند: خواندن، تجزیه، تحلیل و رندر.

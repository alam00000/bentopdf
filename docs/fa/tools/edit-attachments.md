# ویرایش پیوست‌ها

پیوست‌های فایل داخل یک PDF را بررسی و مدیریت کنید. ابزار همهٔ فایل‌های جاسازی‌شده را با نام و سطح پیوستشان فهرست می‌کند و سپس به شما اجازه می‌دهد پیوست‌های جداگانه را برای حذف علامت بزنید یا همه را یکجا حذف کنید.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید.
2. ابزار به‌طور خودکار پیوست‌ها را جستجو و در یک فهرست نمایش می‌دهد.
3. هر پیوست نام فایل و اینکه پیوست سطح سند است یا سطح صفحه را نشان می‌دهد.
4. روی نماد سطل زباله کنار هر پیوست کلیک کنید تا برای حذف علامت بخورد (برای لغو، دوباره کلیک کنید).
5. از دکمهٔ **حذف همهٔ پیوست‌ها** برای انتخاب همه یکجا، یا **لغو انتخاب همه** برای پاک کردن انتخاب‌ها استفاده کنید.
6. روی دکمهٔ پردازش کلیک کنید تا PDF جدیدی بدون پیوست‌های انتخاب‌شده ذخیره شود.

## ویژگی‌ها

- فهرست همهٔ پیوست‌های سطح سند و سطح صفحه
- حذف تکی یا گروهی پیوست‌ها
- روشن و خاموش کردن انتخاب پیش از اعمال تغییرات
- خط‌خوردگی و تغییر شفافیت بصری روی موارد علامت‌خورده برای حذف
- دانلود PDF تغییریافته بدون پیوست‌های انتخاب‌شده

## کاربردها

- حذف فایل‌های قدیمی یا نادرست جاسازی‌شده در سند پیش از توزیع دوباره
- حذف پیوست‌های حساس (داده‌های مالی، اطلاعات شخصی) از PDF پیش از اشتراک‌گذاری
- کاهش حجم PDF با حذف فایل‌های جاسازی‌شدهٔ بزرگی که دیگر لازم نیستند
- ممیزی محتوای جاسازی‌شده و پاک‌سازی سند پیش از بایگانی

## نکته‌ها

- پیوست‌های علامت‌خورده برای حذف با خط‌خوردگی بصری نمایش داده می‌شوند. اگر نظرتان عوض شد، می‌توانید پیش از پردازش آن‌ها را برگردانید.
- اگر پیوستی یافت نشود، ابزار پیام واضح «پیوستی یافت نشد» را نمایش می‌دهد؛ یعنی PDF هیچ فایل جاسازی‌شده‌ای ندارد.

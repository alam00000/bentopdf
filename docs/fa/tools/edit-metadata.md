# ویرایش فراداده

فرادادهٔ جاسازی‌شده در یک فایل PDF را ویرایش کنید. ابزار فرمی را با فرادادهٔ موجود سند از پیش پر می‌کند، به شما اجازه می‌دهد هر فیلدی را تغییر دهید و تغییرات را در یک PDF جدید ذخیره می‌کند.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید. ابزار فرادادهٔ فعلی آن را می‌خواند و فرم را پر می‌کند.
2. هر یک از فیلدهای استاندارد را ویرایش کنید: عنوان، نویسنده، موضوع، کلیدواژه‌ها، سازنده، تولیدکننده.
3. تاریخ ایجاد و تاریخ تغییر را با انتخابگرهای تاریخ و زمان تنظیم کنید.
4. با کلیک روی دکمهٔ افزودن و وارد کردن یک جفت کلید و مقدار، فیلدهای فرادادهٔ سفارشی اضافه کنید.
5. روی دکمهٔ پردازش کلیک کنید تا PDF تغییریافته ذخیره شود.

## ویژگی‌ها

- پیش‌پر کردن همهٔ فرادادهٔ موجود از PDF بارگذاری‌شده
- فیلدهای استاندارد: عنوان، نویسنده، موضوع، کلیدواژه‌ها، سازنده، تولیدکننده
- انتخابگرهای تاریخ و زمان برای تاریخ ایجاد و تاریخ تغییر
- فیلدهای فرادادهٔ سفارشی کلید و مقدار برای ویژگی‌های دلخواه
- ذخیرهٔ مستقیم تغییرات در دیکشنری اطلاعات سند PDF

## فیلدهای قابل ویرایش

| فیلد               | توضیحات                                         |
| ------------------ | ----------------------------------------------- |
| **عنوان**          | عنوان سند که در نمایشگرهای PDF نشان داده می‌شود |
| **نویسنده**        | شخص یا سازمانی که سند را ساخته است              |
| **موضوع**          | توضیح کوتاهی از موضوع سند                       |
| **کلیدواژه‌ها**    | عبارت‌های جداشده با کاما برای جستجو و دسته‌بندی |
| **سازنده**         | برنامه‌ای که محتوا را در اصل ساخته است          |
| **تولیدکننده**     | برنامه‌ای که PDF را تولید کرده است              |
| **تاریخ ایجاد**    | زمانی که سند در اصل ساخته شده است               |
| **تاریخ تغییر**    | آخرین زمانی که سند تغییر کرده است               |
| **فیلدهای سفارشی** | هر جفت کلید و مقدار اضافه‌ای که تعریف می‌کنید   |

## کاربردها

- تعیین عنوان و نویسندهٔ مناسب پیش از انتشار سند
- افزودن کلیدواژه برای بهبود قابلیت جستجو در سامانه‌های مدیریت اسناد
- به‌روزرسانی تاریخ تغییر برای بازتاب نسخهٔ فعلی
- افزودن فیلدهای فرادادهٔ سفارشی مانند دپارتمان، شناسهٔ پروژه یا طبقه‌بندی
- پاک‌سازی فرادادهٔ به‌جامانده از نرم‌افزار تولید اصلی

## نکته‌ها

- فیلدهای سفارشی مستقیماً در دیکشنری اطلاعات PDF نوشته می‌شوند. برخی نمایشگرهای PDF ممکن است فیلدهای سفارشی را نمایش ندهند، اما در فایل حفظ می‌شوند.
- برای پاک کردن یک فیلد از فراداده، آن را خالی بگذارید. دکمهٔ پردازش هر آنچه در فرم است را ذخیره می‌کند.
- برای مشاهدهٔ فراداده بدون ویرایش، از [مشاهدهٔ فراداده](./view-metadata) استفاده کنید. برای حذف کامل همهٔ فراداده، از حذف فراداده استفاده کنید.

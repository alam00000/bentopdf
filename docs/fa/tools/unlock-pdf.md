# باز کردن قفل PDF

اگر رمز عبور یک PDF رمزگذاری‌شده را دارید، این ابزار رمزگذاری را به‌طور کامل حذف می‌کند و نسخه‌ای باز تولید می‌کند که هر کسی بدون اعتبارنامه می‌تواند آن را باز کند. وقتی چند PDF رمز عبور یکسانی دارند، رمزگشایی دسته‌ای پشتیبانی می‌شود.

## نحوهٔ کار

1. یک یا چند فایل PDF رمزگذاری‌شده بارگذاری کنید.
2. **رمز عبوری** را که برای محافظت از فایل‌ها استفاده شده وارد کنید.
3. روی **رمزگشایی PDF** کلیک کنید.
4. یک فایل تکی مستقیماً دانلود می‌شود. چند فایل یک بایگانی ZIP شامل همهٔ PDFهای باز‌شده تولید می‌کنند.

## ویژگی‌ها

- رمزگشایی تک‌فایلی و دسته‌ای
- پشتیبانی از رمز عبور کاربر و رمز عبور مالک
- تولید خروجی کاملاً رمزگذاری‌نشده بدون هیچ محدودیت باقی‌مانده
- گزارش خطای واضح برای رمز عبور نادرست یا فایل‌های خراب
- پیگیری موفقیت یا شکست هر فایل در حالت دسته‌ای

## تفاوت با حذف محدودیت‌ها

**رمزگشایی PDF** به رمز عبور نیاز دارد و همهٔ رمزگذاری را حذف می‌کند. **حذف محدودیت‌ها** محدودیت‌های استفاده (چاپ، کپی، ویرایش) را هدف می‌گیرد و اگر فقط رمز عبور مالک تنظیم شده باشد ممکن است به رمز عبور نیازی نداشته باشد. وقتی PDF بدون رمز عبور اصلاً باز نمی‌شود، از رمزگشایی استفاده کنید.

## موارد استفاده

- باز کردن دائمی PDFهایی که قبلاً رمزگذاری کرده‌اید، وقتی دیگر به رمز عبور نیازی نیست
- حذف رمزگذاری از دسته‌ای از اسناد بایگانی‌شده برای دسترسی آسان‌تر در بلندمدت
- آماده‌سازی PDFهای محافظت‌شده برای سیستم مدیریت اسنادی که از فایل‌های رمزگذاری‌شده پشتیبانی نمی‌کند
- باز کردن PDFها پیش از ادغام با اسناد دیگر (بسیاری از ابزارهای ادغام نمی‌توانند ورودی رمزگذاری‌شده را پردازش کنند)

## نکته‌ها

- فیلد رمز عبور برای همهٔ فایل‌های بارگذاری‌شده اعمال می‌شود. اگر PDFهای شما رمزهای متفاوتی دارند، آن‌ها را در دسته‌های جداگانه پردازش کنید.
- اگر خطای «رمز عبور نادرست» دریافت کردید، فاصله‌های انتهایی یا روشن بودن Caps Lock را بررسی کنید.
- پس از رمزگشایی، خروجی هیچ امنیتی ندارد. اگر به رمز عبور جدید نیاز دارید، با رمزگذاری PDF دوباره آن را رمزگذاری کنید.

# XPS به PDF

اسناد Microsoft XPS و OXPS را به فایل‌های PDF استاندارد تبدیل کنید. XPS (XML Paper Specification) پاسخ Microsoft به PDF بود، اما پشتیبانی از آن در پلتفرم‌های مختلف کاهش یافته است. این ابزار این اسناد را دوباره برای همه خوانا می‌کند.

## قالب‌های پشتیبانی‌شده

| قالب | پسوند   | توضیحات                            |
| :--- | :------ | :--------------------------------- |
| XPS  | `.xps`  | قالب اصلی Microsoft XPS            |
| OXPS | `.oxps` | Open XPS، نسخهٔ استاندارد ECMA-388 |

## نحوهٔ کار

1. روی ناحیهٔ بارگذاری کلیک کنید یا فایل‌های XPS/OXPS خود را بکشید و رها کنید. می‌توانید چند فایل را هم‌زمان انتخاب کنید.
2. فهرست فایل‌ها را بررسی کنید. فایل‌ها را جداگانه با نماد سطل زباله حذف کنید یا روی **افزودن فایل‌های بیشتر** کلیک کنید تا اسناد دیگری اضافه کنید.
3. روی **تبدیل به PDF** کلیک کنید. موتور PyMuPDF هر سند را به‌صورت محلی در مرورگر شما پردازش می‌کند.
4. یک فایل تکی مستقیماً به‌صورت PDF دانلود می‌شود. چند فایل در یک بایگانی ZIP با نام `xps-converted.zip` بسته‌بندی می‌شوند.

## گزینه‌ها

این ابزار یک تبدیل مستقیم قالب را بدون پیکربندی اضافی انجام می‌دهد. خروجی ابعاد صفحه، گرافیک‌های برداری، فونت‌ها و تصاویر منبع XPS را حفظ می‌کند.

## موارد استفاده

- باز کردن فایل‌های XPS دریافتی از سیستم‌های قدیمی Windows که به‌طور پیش‌فرض از درایور چاپ XPS استفاده می‌کردند
- تبدیل اسناد OXPS از Windows 10/11 برای اشتراک‌گذاری با کاربران macOS یا Linux
- بایگانی فایل‌های قدیمی XPS در قالبی با پشتیبانی گسترده‌تر
- دسترس‌پذیر کردن اسناد دولتی یا سازمانی مبتنی بر XPS برای گیرندگان خارجی

## نکته‌ها

- هر دو پسوند `.xps` و `.oxps` به‌طور خودکار پردازش می‌شوند، بنابراین می‌توانید آن‌ها را در یک دسته ترکیب کنید.
- اگر فایل XPS اصلی با یک درایور چاپ با وضوح بالا ایجاد شده باشد، PDF حاصل همان کیفیت را حفظ می‌کند. هیچ نمونه‌برداری مجددی انجام نمی‌شود.

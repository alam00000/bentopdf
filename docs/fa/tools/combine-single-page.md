# ترکیب در یک صفحه

همهٔ صفحات یک PDF را در یک صفحهٔ بلند ادغام کنید. صفحات به‌صورت عمودی (مانند طومار) یا افقی (کنار هم) به هم دوخته می‌شوند و خروجی یک صفحهٔ پیوسته است.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید.
2. جهت چیدمان را انتخاب کنید: **عمودی** (صفحات از بالا به پایین روی هم) یا **افقی** (صفحات کنار هم).
3. فاصلهٔ بین صفحات را بر حسب پوینت تعیین کنید.
4. یک رنگ پس‌زمینه برای فاصله‌های بین صفحات انتخاب کنید.
5. در صورت تمایل جداکننده‌ها (خطوط نازک بین صفحات) را فعال کنید و ضخامت و رنگ آن‌ها را تنظیم کنید.
6. روی دکمهٔ پردازش کلیک کنید. خروجی یک PDF تک‌صفحه‌ای است.

## ویژگی‌ها

- دوختن صفحات به‌صورت عمودی یا افقی
- فاصلهٔ قابل تنظیم بین صفحات
- انتخابگر رنگ پس‌زمینه برای نواحی فاصله
- خطوط جداکنندهٔ اختیاری با ضخامت و رنگ قابل تنظیم
- رندر هر صفحهٔ اصلی با وضوح کامل روی بوم ترکیبی

## گزینه‌ها

| گزینه               | توضیحات                             |
| ------------------- | ----------------------------------- |
| **جهت**             | عمودی (روی هم) یا افقی (کنار هم)    |
| **فاصلهٔ صفحات**    | فاصلهٔ بین صفحات بر حسب پوینت       |
| **رنگ پس‌زمینه**    | رنگ ناحیهٔ بین صفحات                |
| **افزودن جداکننده** | روشن/خاموش کردن خطوط نازک بین صفحات |
| **ضخامت جداکننده**  | ضخامت خط بر حسب پوینت               |
| **رنگ جداکننده**    | رنگ خطوط جداکننده                   |

## کاربردها

- ساخت یک تصویر بلند از وایرفریم یا ماکت طراحی چندصفحه‌ای
- تولید نمای پیوستهٔ قابل پیمایش از یک سند برای جاسازی در وب
- به هم دوختن یک کمیک یا استوری‌بورد چندصفحه‌ای در یک نوار
- تولید نمای پانوراما از صفحات متوالی برای بازبینی

## نکته‌ها

- جهت عمودی برای اسناد با صفحات عمودی بهترین است. جهت افقی برای محتوای افقی مناسب‌تر است.
- اسناد بزرگ با صفحات زیاد خروجی بسیار بلند یا عریضی تولید می‌کنند. برخی نمایشگرهای PDF ممکن است با صفحات تکی بسیار بزرگ مشکل داشته باشند.
- افزودن جداکننده با رنگ متضاد، دیدن محل پایان یک صفحهٔ اصلی و آغاز صفحهٔ بعدی را آسان می‌کند.

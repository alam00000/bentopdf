# Word به PDF

اسناد Microsoft Word و قالب‌های سازگار را به PDF تبدیل کنید. این ابزار از موتور LibreOffice مبتنی بر مرورگر استفاده می‌کند که فایل‌های DOC، DOCX، ODT و RTF را پردازش می‌کند و قالب‌بندی، جدول‌ها، تصاویر، سرصفحه‌ها، پاصفحه‌ها و سبک‌ها را در خروجی حفظ می‌کند.

## قالب‌های پشتیبانی‌شده

| قالب              | پسوندها |
| :---------------- | :------ |
| Word (مدرن)       | `.docx` |
| Word (قدیمی)      | `.doc`  |
| OpenDocument Text | `.odt`  |
| Rich Text Format  | `.rtf`  |

## نحوهٔ کار

1. روی ناحیهٔ بارگذاری کلیک کنید یا اسناد Word خود را بکشید و رها کنید. می‌توانید چند فایل را هم‌زمان انتخاب کنید.
2. فهرست فایل‌ها را بررسی و مدیریت کنید.
3. روی **تبدیل به PDF** کلیک کنید. موتور LibreOffice در اولین استفاده بارگذاری می‌شود (یک نشانگر پیشرفت وضعیت راه‌اندازی را نشان می‌دهد) و سپس هر فایل تبدیل می‌شود.
4. یک فایل تکی مستقیماً به‌صورت PDF دانلود می‌شود. چند فایل در `word-converted.zip` بسته‌بندی می‌شوند.

## گزینه‌ها

این ابزار تنظیمات اضافی ندارد. موتور LibreOffice خروجی را با نمایهٔ پیش‌فرض صدور PDF خود تولید می‌کند.

## خروجی

| تعداد ورودی     | خروجی                                                       |
| :-------------- | :---------------------------------------------------------- |
| ۱ فایل          | دانلود یک PDF (نام فایل اصلی با پسوند `.pdf`)               |
| ۲ فایل یا بیشتر | بایگانی ZIP (`word-converted.zip`) شامل یک PDF برای هر فایل |

## موارد استفاده

- تبدیل رزومه یا نامهٔ همراه از DOCX به PDF پیش از ارسال درخواست شغلی
- تبدیل دسته‌ای مجموعه‌ای از قراردادها یا پیشنهادها به PDF برای تحویل به مشتری
- تبدیل فایل‌های قدیمی `.doc` به PDFهای مدرن برای بایگانی بلندمدت
- تبدیل اسناد مشارکتی Google Docs (صادرشده به‌صورت DOCX) به PDF
- تولید PDFهای آمادهٔ چاپ از قالب‌های Word که در تولید خودکار اسناد استفاده می‌شوند

## نکته‌ها

- موتور LibreOffice در هر نشست یک بار دانلود و در حافظهٔ پنهان ذخیره می‌شود. در اولین تبدیل چند ثانیه زمان بارگذاری لازم است و تبدیل‌های بعدی بسیار سریع‌ترند.
- قالب‌بندی‌های پیچیده (ماکروها، کنترل‌های ActiveX، SmartArt پیشرفته) ممکن است کاملاً درست تبدیل نشوند. عناصر استاندارد سند (متن، جدول‌ها، تصاویر، سرصفحه‌ها، پانویس‌ها) به‌طور قابل اعتمادی تبدیل می‌شوند.
- چون این ابزار ODT و RTF را هم می‌پذیرد، می‌توانید از آن به‌عنوان مبدل یکپارچه برای همهٔ قالب‌های واژه‌پرداز استفاده کنید.

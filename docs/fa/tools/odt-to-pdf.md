# ODT به PDF

فایل‌های متنی OpenDocument را به PDF تبدیل کنید. ODT قالب اصلی LibreOffice Writer، Apache OpenOffice و دیگر واژه‌پردازهای متن‌باز است. این ابزار از یک موتور LibreOffice در مرورگر استفاده می‌کند تا تبدیل‌هایی دقیق با حفظ قالب‌بندی، جدول‌ها، تصاویر و سبک‌ها تولید کند.

## قالب‌های پشتیبانی‌شده

| قالب             | پسوندها |
| :--------------- | :------ |
| متن OpenDocument | `.odt`  |

## نحوهٔ کار

1. روی ناحیهٔ بارگذاری کلیک کنید یا یک یا چند فایل ODT را بکشید و رها کنید.
2. فهرست فایل‌ها را بررسی کنید. فایل‌های بیشتری اضافه کنید یا فایل‌های ناخواسته را حذف کنید.
3. روی **تبدیل به PDF** کلیک کنید. موتور LibreOffice راه‌اندازی می‌شود (یک نشانگر پیشرفت وضعیت بارگذاری را نشان می‌دهد) و سپس هر فایل تبدیل می‌شود.
4. یک فایل تکی مستقیماً به‌صورت PDF دانلود می‌شود. چند فایل در `odt-converted.zip` بسته‌بندی می‌شوند.

## گزینه‌ها

این ابزار پیکربندی اضافه‌ای ندارد. تبدیل، قالب‌بندی سند اصلی را تا حد امکان حفظ می‌کند.

## خروجی

| تعداد ورودی     | خروجی                                                      |
| :-------------- | :--------------------------------------------------------- |
| ۱ فایل          | دانلود یک PDF (مثلاً `document.pdf`)                       |
| ۲ فایل یا بیشتر | بایگانی ZIP (`odt-converted.zip`) شامل یک PDF برای هر فایل |

## موارد استفاده

- تبدیل اسناد LibreOffice Writer به PDF برای اشتراک با کاربران Microsoft Office
- تولید PDFهای آمادهٔ چاپ از مقالات دانشگاهی نوشته‌شده در قالب OpenDocument
- تبدیل دسته‌ای پوشه‌ای از قالب‌های ODT به PDF برای توزیع
- تولید PDF از فایل‌های ODT ساخته‌شده توسط سامانه‌های خودکار تولید سند

## نکته‌ها

- موتور LibreOffice در اولین استفاده بارگذاری و برای تبدیل‌های بعدی ذخیره می‌شود. بارگذاری اولیه چند ثانیه طول می‌کشد؛ پس از آن تبدیل‌ها سریع هستند.
- اسناد پیچیده با اشیای OLE جاسازی‌شده یا فونت‌های غیرمعمول ممکن است کمی متفاوت از LibreOffice رومیزی نمایش داده شوند. پیش از تبدیل دسته‌ای با یک نمونه آزمایش کنید.
- برای اسناد Word (`.doc`، `.docx`) به‌جای آن از ابزار [Word به PDF](./word-to-pdf) استفاده کنید که آن هم از موتور LibreOffice استفاده می‌کند اما قالب‌های Microsoft را مستقیماً می‌پذیرد.

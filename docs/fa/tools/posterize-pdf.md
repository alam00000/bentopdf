# پوستری‌کردن PDF

هر صفحهٔ PDF را به شبکه‌ای از زیرصفحه‌های کوچک‌تر تقسیم کنید. این ابزار برای چاپ یک صفحه روی چند برگه کاغذ است که سپس آن‌ها را کنار هم می‌چینید تا یک پوستر یا بنر بزرگ بسازید.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید.
2. تعداد **ردیف‌ها** و **ستون‌ها** را برای تعریف شبکه تنظیم کنید (مثلاً ۲ ردیف در ۲ ستون هر صفحه را به ۴ زیرصفحه تقسیم می‌کند).
3. در صورت تمایل یک بازهٔ صفحات مشخص کنید تا فقط صفحات خاصی پوستری شوند.
4. بوم پیش‌نمایش یک شبکهٔ روی صفحهٔ فعلی نشان می‌دهد تا محل برش‌ها را ببینید.
5. بین صفحات جابه‌جا شوید تا شبکه را روی صفحات مختلف بررسی کنید.
6. روی دکمهٔ پردازش کلیک کنید. هر خانهٔ شبکه به یک صفحهٔ جداگانه در PDF خروجی تبدیل می‌شود.

## ویژگی‌ها

- تعداد ردیف و ستون قابل تنظیم برای اندازه‌های متنوع شبکه
- پیش‌نمایش زنده با شبکه‌ای که دقیقاً محل تقسیم صفحات را نشان می‌دهد
- فیلتر بازهٔ صفحات برای پوستری‌کردن فقط صفحات خاص
- پیمایش صفحه به صفحه در پیش‌نمایش
- ذخیرهٔ موقت تصویر صفحات برای پیمایش سریع پیش‌نمایش
- خطوط قرمز خط‌چین مرز برش‌ها را به‌وضوح مشخص می‌کنند

## گزینه‌ها

| گزینه           | توضیح                                        |
| --------------- | -------------------------------------------- |
| **ردیف‌ها**     | تعداد تقسیم‌های افقی (پیش‌فرض: ۱)            |
| **ستون‌ها**     | تعداد تقسیم‌های عمودی (پیش‌فرض: ۱)           |
| **بازهٔ صفحات** | صفحاتی که پوستری می‌شوند (خالی = همهٔ صفحات) |

## موارد استفاده

- چاپ یک PDF در اندازهٔ پوستر روی برگه‌های استاندارد A4 یا Letter برای چیدن روی دیوار
- ساخت بنرهای بزرگ از طرح PDF تک‌صفحه‌ای
- تقسیم نقشه‌های فنی بزرگ به قطعات قابل چاپ
- چاپ در قطع بزرگ بدون دسترسی به چاپگر عریض

## نکته‌ها

- شبکهٔ 2x2 یک صفحه را به ۴ صفحه و شبکهٔ 3x3 یک صفحه را به ۹ صفحه تبدیل می‌کند. شبکه را بر اساس اندازهٔ نهایی مورد نظر برنامه‌ریزی کنید.
- شبکهٔ پیش‌نمایش کمک می‌کند مطمئن شوید محتوای مهم روی خط برش قرار نمی‌گیرد. در صورت نیاز ردیف‌ها یا ستون‌ها را تغییر دهید.
- برای عملیات معکوس (قرار دادن چند صفحه روی یک برگه)، از [N-Up کردن PDF](./n-up-pdf) استفاده کنید.

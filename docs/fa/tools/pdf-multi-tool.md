# ابزار چندکارهٔ PDF

فضای کاری یکپارچه برای همهٔ عملیات سطح صفحه در PDF. یک یا چند PDF بارگذاری کنید و با همهٔ صفحات آن‌ها در یک شبکهٔ بصری کار کنید. صفحات را بچرخانید، جابه‌جا، تکثیر و حذف کنید، PDF، تصویر و صفحهٔ خالی درج کنید، شماره‌گذاری صفحات را تغییر دهید، اندازهٔ آن‌ها را عوض کنید و نتیجه را تقسیم کنید، همه بدون خروج از ابزار.

## نحوهٔ کار

1. روی **انتخاب فایل‌ها** کلیک کنید یا فایل‌ها را روی ناحیهٔ بارگذاری بکشید. چند فایل پشتیبانی می‌شود و فایل‌ها به ترتیب بارگذاری ادغام می‌شوند.
2. همهٔ صفحات در یک شبکهٔ پیمایش‌پذیر با تصاویر بندانگشتی نمایش داده می‌شوند.
3. برای انتخاب یک صفحه روی آن کلیک کنید. برای انتخاب یک بازه از Shift+کلیک و برای افزودن یا برداشتن تک‌صفحه‌ها از انتخاب از Cmd/Ctrl+کلیک استفاده کنید.
4. برای عملیات صفحه از نوار ابزار سازمان‌دهنده استفاده کنید یا روی صفحه راست‌کلیک کنید.
5. برای دانلود نتیجهٔ نهایی روی **برون‌ریزی PDF** کلیک کنید.

## ویژگی‌ها

- **ادغام**: چند PDF و تصویر بارگذاری کنید تا خودکار در یک سند ترکیب شوند
- **تغییر ترتیب**: صفحات را بکشید و رها کنید تا ترتیب تغییر کند، یا ترتیب کل سند را وارونه کنید
- **چرخش**: صفحات انتخاب‌شده را با گام‌های 90 درجه به چپ یا راست بچرخانید
- **تکثیر**: صفحات انتخاب‌شده را کپی کنید و نسخه‌ها را درست بعد از آن‌ها قرار دهید
- **حذف**: صفحات انتخاب‌شده را حذف کنید
- **درج**: صفحاتی از یک PDF یا تصویر دیگر، یک صفحهٔ خالی یا صفحاتی از کلیپ‌بورد اضافه کنید، یا صفحات یک PDF دوم را یک‌درمیان با صفحات فعلی بچینید
- **جایگزینی**: یک صفحه را با صفحهٔ اول یک PDF دیگر عوض کنید
- **برش، کپی و چسباندن**: صفحات را درون سند جابه‌جا یا کپی کنید
- **استخراج**: صفحات انتخاب‌شده را به‌صورت PDF یا تصویر دانلود کنید
- **شمارهٔ صفحات**: برای یک بازه از صفحات برچسب‌هایی مانند i, ii, iii یا A-1, A-2 تعیین کنید
- **اندازهٔ صفحه**: صفحات را با یک اندازهٔ کاغذ استاندارد یا اندازهٔ دلخواه منطبق کنید
- **تقسیم**: سند را بر اساس بازه‌های صفحات، صفحات فرد و زوج، تک‌تک صفحه‌ها، نشانک‌ها، هر N صفحه یا اندازهٔ فایل تقسیم کنید
- **واگرد / ازنو**: هر عملیات صفحه را می‌توان واگرد و ازنو کرد
- تعمیر خودکار PDFهای آسیب‌دیده پیش از بارگذاری

## میان‌برهای صفحه‌کلید

| عملیات            | میان‌بر                       |
| ----------------- | ----------------------------- |
| چرخش به راست / چپ | R / Shift+R                   |
| انتخاب همه        | Cmd/Ctrl+A                    |
| برش، کپی، چسباندن | Cmd/Ctrl+X, C, V              |
| تکثیر             | Cmd/Ctrl+D                    |
| حذف               | Delete یا Backspace           |
| واگرد / ازنو      | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| جابه‌جایی انتخاب  | کلیدهای جهت‌نما، Home، End    |

## موارد استفاده

- ساخت یک سند دلخواه از صفحات چند PDF مبدأ
- مرتب‌سازی یک سند اسکن‌شده با حذف صفحات خالی، چرخاندن اسکن‌های کج و تغییر ترتیب بخش‌ها
- تقسیم یک PDF بزرگ در مرز فصل‌ها با استفاده از نشانک‌های آن
- ویرایش سریع در سطح صفحه بدون نیاز به ویرایشگر کامل PDF

## نکته‌ها

- تاریخچهٔ واگرد و ازنو همهٔ عملیات صفحه را ثبت می‌کند. آزادانه از آن استفاده کنید؛ کارتان به‌اشتباه از بین نمی‌رود.
- هر زمان خواستید از **Insert > From File** استفاده کنید یا PDFها یا تصاویر بیشتری را روی شبکهٔ صفحات رها کنید تا به سند اضافه شوند.
- برای کارهای سادهٔ ادغام یا تقسیم، ابزارهای اختصاصی [ادغام PDF](./merge-pdf) یا [تقسیم PDF](./split-pdf) ممکن است سریع‌تر باشند. ابزار چندکاره زمانی می‌درخشد که در یک نشست به چند عملیات نیاز دارید.

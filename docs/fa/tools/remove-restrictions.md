# حذف محدودیت‌ها

PDFها می‌توانند دو نوع رمز عبور داشته باشند: رمز کاربر (برای باز کردن فایل لازم است) و رمز مالک (تعیین می‌کند با فایل چه کاری می‌توانید انجام دهید). این ابزار هر دو را به‌همراه همهٔ محدودیت‌های مرتبط (قفل‌های چاپ، ویرایش، کپی و حاشیه‌نویسی) حذف می‌کند.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید.
2. اگر PDF رمز مالک دارد، آن را در فیلد **رمز مالک** وارد کنید. اگر PDF فقط محدودیت استفاده بدون رمز عبور دارد، آن را خالی بگذارید.
3. روی **حذف محدودیت‌ها** کلیک کنید.
4. PDF بدون محدودیت را دانلود کنید.

این ابزار از گزینه‌های `--decrypt` و `--remove-restrictions` در QPDF برای تولید نسخه‌ای تمیز و بدون محدودیت استفاده می‌کند.

## چه چیزهایی حذف می‌شوند

- محافظت با رمز عبور (هم رمز کاربر و هم رمز مالک)
- محدودیت‌های چاپ
- محدودیت‌های ویرایش
- محدودیت‌های کپی متن و تصویر
- محدودیت‌های حاشیه‌نویسی و نظر دادن
- همهٔ محدودیت‌های امنیتی دیگر که در PDF رمزگذاری شده‌اند

## موارد استفاده

- باز کردن قفل PDFی که مال شماست اما رمزش را سال‌ها پیش تعیین کرده‌اید
- حذف محدودیت چاپ از سندی که دسترسی مشروع به آن دارید
- فعال کردن کپی و چسباندن در منابع مرجع برای یادداشت‌برداری
- آماده‌سازی PDFها برای ابزارهای دسترس‌پذیری که نمی‌توانند با اسناد محدودشده کار کنند

## نکته‌ها

- اگر رمز مالک تعیین شده باشد، باید آن را بدانید. این ابزار رمزها را نمی‌شکند و حدس نمی‌زند.
- اگر می‌خواهید فایل رمزگذاری‌شده بماند اما مجوزهای خاصی تغییر کنند، به‌جای آن از ابزار تغییر مجوزها استفاده کنید.
- فایل خروجی هیچ رمزگذاری‌ای ندارد و هر کسی که آن را دریافت کند می‌تواند آزادانه بازش کند.

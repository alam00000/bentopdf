# رنگ پس‌زمینه

یک رنگ پس‌زمینهٔ یکدست پشت همهٔ محتوای موجود PDF قرار دهید. ابزار روی هر صفحه یک مستطیل رنگی می‌سازد و محتوای اصلی را روی آن قرار می‌دهد، بنابراین متن، تصاویر و گرافیک‌ها روی پس‌زمینهٔ جدید کاملاً قابل مشاهده می‌مانند.

## نحوهٔ کار

1. فایل PDF خود را بارگذاری کنید.
2. با انتخابگر رنگ یک رنگ پس‌زمینه انتخاب کنید. پیش‌فرض زرد روشن (#FFFFCC) است.
3. روی **تغییر رنگ پس‌زمینه** کلیک کنید تا پردازش شود.
4. PDF به‌روزشده به‌طور خودکار دانلود می‌شود.

## گزینه‌ها

- **رنگ پس‌زمینه**: یک انتخابگر رنگ استاندارد برای انتخاب هر رنگ یکدست. پیش‌فرض زرد روشن است.

## ویژگی‌ها

- اعمال رنگ پس‌زمینهٔ یکسان روی همهٔ صفحات
- حفظ همهٔ محتوای اصلی (متن، تصاویر، گرافیک برداری) روی لایهٔ رنگی
- حفظ ابعاد اصلی صفحه
- کار با اسنادی با هر تعداد صفحه

## موارد استفاده

- افزودن پس‌زمینهٔ کرم یا عاجی روشن برای ظاهری نرم‌تر و کاغذمانند
- رنگ‌بندی مجموعه اسناد با اعمال رنگ‌های پس‌زمینهٔ متفاوت برای دسته‌های مختلف
- ساخت نسخه‌های متمایز بصری از یک سند برای مخاطبان مختلف
- افزودن ته‌رنگ روشن به پس‌زمینه برای خوانایی بهتر هنگام نمایش اسناد روی پرده

## نکته‌ها

- رنگ‌های روشن و ملایم بهترین نتیجه را دارند. پس‌زمینهٔ خیلی تیره می‌تواند خواندن متن را دشوار کند، مگر اینکه متن از قبل روشن باشد.
- اگر می‌خواهید هم پس‌زمینه و هم رنگ متن را تغییر دهید، ابتدا رنگ پس‌زمینه را اعمال کنید، سپس روی نتیجه از [تغییر رنگ متن](./text-color) استفاده کنید.
- این ابزار در سطح ساختار PDF کار می‌کند (نه تبدیل به تصویر)، بنابراین متن در خروجی قابل انتخاب و جستجو باقی می‌ماند.

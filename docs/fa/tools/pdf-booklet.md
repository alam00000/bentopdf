# دفترچهٔ PDF

صفحات یک PDF را به ترتیب صفحه‌آرایی دفترچه‌ای بچینید. وقتی دورو چاپ و از وسط تا شود، صفحات به ترتیب درست خواندن قرار می‌گیرند. این همان چیدمانی است که برای دفترچه‌ها و زین‌های منگنه‌شده از وسط استفاده می‌شود.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید.
2. تنظیمات دفترچه را پیکربندی کنید: اندازه و جهت صفحهٔ خروجی.
3. روی **ایجاد پیش‌نمایش** کلیک کنید تا ببینید صفحات روی هر برگه چگونه چیده می‌شوند.
4. پیش‌نمایش را بررسی کنید؛ هر برگهٔ فیزیکی را با صفحات روی و پشت آن نشان می‌دهد.
5. برای ذخیرهٔ PDF دفترچه‌ای روی **دانلود** کلیک کنید.

## ویژگی‌ها

- ترتیب‌دهی خودکار صفحات برای صحافی منگنه‌ای از وسط
- اندازهٔ صفحهٔ خروجی قابل‌تنظیم
- پیش‌نمایش بصری چیدمان دفترچه پیش از دانلود
- مدیریت تعداد صفحات فرد با درج صفحات خالی در صورت نیاز
- مقیاس‌دهی صفحات مبدأ برای جا شدن در اندازهٔ برگهٔ دفترچه

## موارد استفاده

- ساخت دفترچه‌ها یا زین‌های قابل‌چاپ از یک PDF معمولی
- آماده‌سازی برنامه‌های همایش یا راهنماهای رویداد برای چاپ داخلی
- ساخت کارت‌تبریک‌های تاشو یا کاتالوگ‌های کوچک
- تولید جزوه‌ها یا مجموعه‌های شعر برای صحافی دستی

## نکته‌ها

- برای یک دفترچهٔ تمیز، بهتر است تعداد صفحات PDF مبدأ مضربی از 4 باشد. در غیر این صورت، صفحات خالی خودکار برای پر کردن آخرین برگه اضافه می‌شوند.
- خروجی را با تنظیم "برگرداندن از لبهٔ کوتاه" چاپگر خود دورو چاپ کنید، سپس همهٔ برگه‌ها را با هم تا کنید و از عطف منگنه کنید.
- برای قرار دادن ساده‌ی چند صفحه روی یک برگه بدون ترتیب دفترچه‌ای، به‌جای آن از [N-Up کردن PDF](./n-up-pdf) استفاده کنید.

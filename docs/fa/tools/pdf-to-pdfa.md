# PDF به PDF/A

PDF/A زیرمجموعه‌ای از PDF با استاندارد ISO است که برای نگهداری دیجیتال بلندمدت طراحی شده است. این ابزار با Ghostscript که مستقیماً در مرورگر شما اجرا می‌شود، PDFهای استاندارد را به اسناد منطبق با PDF/A تبدیل می‌کند.

## نحوهٔ کار

1. یک یا چند فایل PDF بارگذاری کنید.
2. از فهرست کشویی یک **نسخهٔ PDF/A** انتخاب کنید.
3. در صورت تمایل، برای فایل‌های پیچیده‌ای که تبدیل عادی‌شان ناموفق است، **مسطح‌سازی پیشین PDF** را فعال کنید.
4. روی **تبدیل به PDF/A** کلیک کنید. چند فایل یک بایگانی ZIP تولید می‌کنند.

## نسخه‌های PDF/A

| نسخه         | محدودیت‌ها                                        | مناسب برای                                    |
| ------------ | ------------------------------------------------- | --------------------------------------------- |
| **PDF/A-1b** | سخت‌گیرانه‌ترین. بدون شفافیت، بدون لایه.          | حداکثر سازگاری با سامانه‌های بایگانی قدیمی‌تر |
| **PDF/A-2b** | شفافیت و JPEG2000 را مجاز می‌داند.                | بایگانی عمومی (توصیه‌شده)                     |
| **PDF/A-3b** | پیوست‌های جاسازی‌شده با هر قالبی را مجاز می‌داند. | بایگانی اسناد همراه با فایل‌های دادهٔ مبدأ    |

PDF/A-2b به‌طور پیش‌فرض انتخاب شده است و برای اکثر نیازهای بایگانی کافی است.

## گزینهٔ Pre-flatten

برخی PDFها ویژگی‌هایی دارند که مانع تبدیل تمیز به PDF/A می‌شوند: کدگذاری‌های غیرمعمول فونت، پشته‌های پیچیدهٔ شفافیت یا ساختارهای داخلی معیوب. فعال کردن **مسطح‌سازی پیشین PDF** پیش از تبدیل، PDF را با 300 DPI شطرنجی می‌کند که انطباق را تضمین می‌کند، به بهای غیرقابل‌انتخاب شدن متن. از آن به‌عنوان راه جایگزین زمانی استفاده کنید که تبدیل استاندارد خطا می‌دهد.

Pre-flatten به موتور PyMuPDF WASM نیاز دارد.

## موارد استفاده

- رعایت الزامات بایگانی دولتی یا حقوقی (بسیاری از حوزه‌های قضایی PDF/A را برای پرونده‌های دادگاه الزامی می‌کنند)
- ارسال اسناد به مخازن سازمانی یا کتابخانه‌های دیجیتال
- نگهداری سوابق تجاری در شرایطی که نرم‌افزار اصلی ممکن است ده سال بعد وجود نداشته باشد
- آماده‌سازی فاکتورها برای استانداردهای فاکتور الکترونیکی که PDF/A-3b با پیوست XML می‌خواهند

## نکته‌ها

- ابتدا تبدیل را بدون Pre-flatten امتحان کنید. فقط در صورت خطا آن را فعال کنید.
- PDF/A همهٔ فونت‌ها را جاسازی می‌کند، بنابراین فایل‌های خروجی اغلب از نسخهٔ اصلی بزرگ‌ترند.
- اگر گردش کار شما انطباق سخت‌گیرانه می‌خواهد، خروجی را در یک اعتبارسنج اختصاصی PDF/A بررسی کنید.

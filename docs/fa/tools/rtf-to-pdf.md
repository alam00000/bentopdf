# RTF به PDF

اسناد Rich Text Format را به PDF تبدیل کنید. RTF یک قالب سند چندسکویی است که تقریباً همهٔ واژه‌پردازها از آن پشتیبانی می‌کنند. این ابزار از موتور LibreOffice در مرورگر برای رندر فایل‌های RTF با حفظ قالب‌بندی استفاده می‌کند: متن پررنگ، کج، جدول‌ها و تصاویر جاسازی‌شده همه به PDF منتقل می‌شوند.

## قالب‌های پشتیبانی‌شده

| قالب | پسوندها | انواع MIME                    |
| :--- | :------ | :---------------------------- |
| RTF  | `.rtf`  | `text/rtf`, `application/rtf` |

## نحوهٔ کار

1. روی ناحیهٔ بارگذاری کلیک کنید یا یک یا چند فایل RTF را بکشید و رها کنید.
2. فهرست فایل‌ها را بررسی کنید. در صورت نیاز فایل اضافه یا حذف کنید.
3. روی **تبدیل به PDF** کلیک کنید. موتور LibreOffice در اولین استفاده راه‌اندازی می‌شود و سپس هر فایل را پردازش می‌کند.
4. یک فایل مستقیماً به‌صورت PDF دانلود می‌شود. چند فایل به‌صورت `rtf-converted.zip` تحویل داده می‌شوند.

## گزینه‌ها

این ابزار تنظیمات اضافی ندارد. تبدیل، قالب‌بندی اصلی RTF را حفظ می‌کند.

## خروجی

| تعداد ورودی     | خروجی                                                      |
| :-------------- | :--------------------------------------------------------- |
| ۱ فایل          | دانلود یک PDF (مثلاً `letter.pdf`)                         |
| ۲ فایل یا بیشتر | بایگانی ZIP (`rtf-converted.zip`) شامل یک PDF برای هر فایل |

## موارد استفاده

- تبدیل اسناد RTF قدیمی از واژه‌پردازهای قدیمی به PDFهای امروزی
- تبدیل قالب‌های ایمیل RTF به پیش‌نمایش PDF
- پردازش خروجی RTF از نرم‌افزارهای حقوقی یا پزشکی
- تبدیل دسته‌ای فایل‌های RTF از سامانهٔ مدیریت اسناد به PDF برای بایگانی

## نکته‌ها

- موتور LibreOffice یک بار بارگذاری و ذخیره می‌شود. اولین تبدیل در هر نشست چند ثانیه بیشتر طول می‌کشد و تبدیل‌های بعدی سریع‌ترند.
- فایل‌های RTF با اشیای OLE جاسازی‌شده ممکن است همهٔ اشیا را کاملاً درست نمایش ندهند. متن ساده، تصاویر و قالب‌بندی استاندارد به‌طور قابل اعتمادی تبدیل می‌شوند.
- اگر فایل‌های RTF شما با Microsoft Word ساخته شده‌اند، می‌توانید آن‌ها را مستقیماً با ابزار [Word به PDF](./word-to-pdf) هم تبدیل کنید که RTF را در کنار DOC و DOCX می‌پذیرد.

# PDF به Markdown

فایل‌های PDF را با حفظ سرفصل‌ها، پاراگراف‌ها، فهرست‌ها و قالب‌بندی پایه به قالب Markdown (`.md`) تبدیل می‌کند. به‌صورت اختیاری تصاویر جاسازی‌شده را استخراج و اضافه می‌کند. از تبدیل تکی و دسته‌ای پشتیبانی می‌کند. با قدرت PyMuPDF.

## نحوهٔ کار

1. با کلیک روی ناحیهٔ رها کردن یا کشیدن فایل‌ها روی آن، یک یا چند PDF بارگذاری کنید.
2. در صورت تمایل **شامل کردن تصاویر به‌صورت base64** را فعال کنید تا تصاویر استخراج‌شده در خروجی Markdown جاسازی شوند.
3. برای شروع پردازش روی **تبدیل به Markdown** کلیک کنید.
4. یک فایل تکی به‌صورت `filename.md` دانلود می‌شود. چند فایل یک `markdown-files.zip` تولید می‌کنند.

## گزینه‌ها

- **افزودن تصاویر**: وقتی فعال باشد، تصاویر جاسازی‌شدهٔ PDF استخراج و در خروجی Markdown ارجاع داده می‌شوند. وقتی غیرفعال باشد، فقط محتوای متنی تبدیل می‌شود.

## قالب خروجی

- **تک‌فایل**: `filename.md`
- **چند فایل**: `markdown-files.zip` شامل یک `.md` برای هر PDF ورودی.

## موارد استفاده

- تبدیل مستندات PDF به Markdown برای مولدهای سایت ایستا مانند VitePress، Hugo یا Jekyll.
- تبدیل مقالات پژوهشی PDF به Markdown قابل‌ویرایش برای برنامه‌های یادداشت‌برداری مانند Obsidian.
- انتقال پایگاه‌های دانش قدیمی PDF به قالب متنی سازگار با Git.
- استخراج محتوای ساختاریافته از کتاب‌های الکترونیکی PDF برای قالب‌بندی دوباره.

## نکته‌ها

- گزینهٔ «شامل کردن تصاویر به‌صورت base64» زمانی مفید است که PDF نمودارها یا شکل‌هایی ضروری برای محتوا دارد. برای اسناد پرمتن آن را غیرفعال کنید تا خروجی تمیز بماند.
- چیدمان‌های پیچیده با نوار کناری، پانویس یا متن چندستونی ممکن است Markdown ناقصی تولید کنند. در صورت نیاز خروجی را بررسی و اصلاح کنید.
- برای متن خام بدون قالب‌بندی، به‌جای آن از [PDF به متن](./pdf-to-text) استفاده کنید.

# ابعاد صفحه

ابزاری تشخیصی که همهٔ صفحات PDF شما را می‌خواند و ابعاد دقیق، جهت، نام اندازهٔ استاندارد، نسبت ابعاد، مساحت و چرخش هر صفحه را گزارش می‌دهد. برای یافتن صفحات با اندازه‌های مختلط پیش از چاپ یا مستندسازی ویژگی‌های PDF دریافتی مفید است.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید. تحلیل خودکار آغاز می‌شود و نیازی به فشردن دکمه نیست.
2. یک پنل خلاصه، تعداد کل صفحات، تعداد اندازه‌های منحصربه‌فرد و مختلط بودن یا نبودن اندازه‌ها را نشان می‌دهد.
3. جدول کامل نتایج را با جزئیات هر صفحه مرور کنید.
4. واحد نمایش را بین Points، Inches، Millimeters یا Pixels تغییر دهید.
5. برای ذخیرهٔ داده‌ها روی **خروجی CSV** کلیک کنید.

## فیلدهای گزارش‌شده

| ستون              | توضیحات                                   |
| ----------------- | ----------------------------------------- |
| شمارهٔ صفحه       | شمارهٔ ترتیبی صفحه                        |
| ابعاد             | عرض x ارتفاع در واحد انتخاب‌شده           |
| اندازهٔ استاندارد | نام منطبق (A4، Letter و غیره) یا "سفارشی" |
| جهت               | عمودی یا افقی                             |
| نسبت ابعاد        | نسبت عرض به ارتفاع به‌صورت عدد اعشاری     |
| مساحت             | مساحت صفحه در مربع واحد انتخاب‌شده        |
| چرخش              | چرخش صفحه بر حسب درجه                     |

## ویژگی‌ها

- تشخیص خودکار اندازه‌های استاندارد کاغذ (A3، A4، A5، Letter، Legal، Tabloid و موارد دیگر)
- هشدار سند با اندازه‌های مختلط همراه با تفکیک اندازه‌های موجود و تعداد صفحات هر کدام
- تبدیل واحد بین پوینت، اینچ، میلی‌متر و پیکسل (با ۹۶ PPI)
- صدور به CSV برای استفاده در صفحه‌گسترده‌ها یا سامانه‌های مستندسازی

## موارد استفاده

- اطمینان از A4 بودن همهٔ صفحات پیش از ارسال سند به چاپخانه
- یافتن علت چاپ یک PDF ادغام‌شده با حاشیه‌های غیرمنتظره در برخی صفحات
- مستندسازی چیدمان صفحات یک بایگانی بزرگ PDF برای سوابق فراداده
- شناسایی صفحات چرخیده‌ای که نیاز به اصلاح دارند

## نکته‌ها

- اگر خلاصه "اندازه‌های ناهمسان" را نشان داد، پیش از چاپ با ابزار اصلاح اندازهٔ صفحه اندازه‌ها را یکسان کنید.
- فیلد چرخش به شناسایی صفحاتی کمک می‌کند که درست نمایش داده می‌شوند اما ویژگی چرخش غیرصفر دارند و ممکن است در برخی گردش‌کارها مشکل ایجاد کنند.

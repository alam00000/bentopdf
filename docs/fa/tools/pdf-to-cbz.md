# PDF به CBZ

یک PDF را به فایل CBZ (Comic Book ZIP) تبدیل می‌کند؛ قالب استاندارد کمیک‌ها و مانگاهای دیجیتال. هر صفحهٔ PDF به یک تصویر درون بایگانی تبدیل می‌شود. ابزار برای حداکثر سازگاری، فراداده را در سه قالب تولید می‌کند: ComicInfo.xml، metadata.opf و ComicBookInfo JSON.

## نحوهٔ کار

1. با کلیک روی ناحیهٔ رها کردن یا کشیدن فایل روی آن، یک PDF بارگذاری کنید.
2. قالب تصویر، کیفیت، مقیاس و فرادادهٔ اختیاری را انتخاب کنید.
3. برای ساخت فایل CBZ روی **تبدیل** کلیک کنید.
4. فایل `.cbz` خودکار دانلود می‌شود.

## گزینه‌ها

| گزینه          | مقادیر          | پیش‌فرض | توضیحات                                                                                    |
| -------------- | --------------- | ------- | ------------------------------------------------------------------------------------------ |
| قالب تصویر     | JPEG، PNG، WebP | JPEG    | JPEG برای کمیک‌های رنگی، PNG برای مانگای سیاه‌وسفید بدون افت، WebP برای بهترین فشرده‌سازی. |
| کیفیت          | 50–100%         | 85%     | فشرده‌سازی JPEG/WebP را کنترل می‌کند. برای PNG پنهان است (همیشه بدون افت).                 |
| مقیاس          | 1.0x–4.0x       | 2.0x    | مقیاس بالاتر تصاویر واضح‌تری برای نمایشگرهای پرتفکیک تولید می‌کند.                         |
| خاکستری        | روشن/خاموش      | خاموش   | صفحات را خاکستری می‌کند. حجم فایل را برای محتوای سیاه‌وسفید کاهش می‌دهد.                   |
| حالت مانگا     | روشن/خاموش      | خاموش   | جهت خواندن راست‌به‌چپ را در فراداده تنظیم می‌کند.                                          |
| افزودن فراداده | روشن/خاموش      | روشن    | ComicInfo.xml، metadata.opf و ComicBookInfo JSON را جاسازی می‌کند.                         |

## فیلدهای فراداده

وقتی فراداده فعال است، می‌توانید این موارد را پر کنید:

- **عنوان**: خودکار از نام فایل PDF تشخیص داده می‌شود.
- **مجموعه**: نام مجموعه (مثلاً "Naruto").
- **شماره (#)**: شمارهٔ قسمت در مجموعه.
- **جلد (Vol.)**: شمارهٔ جلد.
- **نویسنده(ها)**: نام نویسنده یا خالق.
- **ناشر**: شرکت انتشاراتی.
- **برچسب‌ها / ژانر**: برچسب‌های جداشده با ویرگول (مثلاً "Action, Adventure").
- **سال انتشار**: سال انتشار (1900–2100).
- **امتیاز**: امتیاز جامعه از 0 تا 5.

## سازگاری فراداده

ابزار فراداده را در سه قالب می‌نویسد تا هر کمیک‌خوانی بتواند آن را پیدا کند:

| قالب               | محل            | پشتیبانی‌شده در                             |
| ------------------ | -------------- | ------------------------------------------- |
| ComicInfo.xml      | فایلی درون ZIP | Komga، Kavita، CDisplayEx، Mylar، ComicRack |
| metadata.opf       | فایلی درون ZIP | Calibre                                     |
| ComicBookInfo JSON | فیلد توضیح ZIP | Calibre (جایگزین)                           |

## قالب خروجی

- `filename.cbz`: یک بایگانی ZIP شامل تصاویر شماره‌دار صفحات و فایل‌های فراداده.

نام تصاویر صفحات با اعداد دارای صفر پیشرو است (`01.jpg`، `02.jpg` و غیره) تا کمیک‌خوان‌ها آن‌ها را به ترتیب درست نمایش دهند.

## موارد استفاده

- تبدیل PDFهای مانگا یا کمیک برای استفاده در کمیک‌خوان‌ها.
- ساخت کتابخانهٔ کمیک دیجیتال در Komga، Kavita یا Calibre.
- تبدیل کمیک‌های اسکن‌شده به قالبی مناسب کمیک‌خوان‌ها.
- اشتراک‌گذاری کمیک‌ها در قالبی که جهت خواندن و فراداده را حفظ می‌کند.

## نکته‌ها

- برای کمیک‌های رنگی از **JPEG** و برای مانگای سیاه‌وسفید از **PNG** استفاده کنید؛ PNG محتوای سیاه‌وسفید را بسیار کارآمد فشرده می‌کند.
- برای مانگا **تبدیل به خاکستری** را فعال کنید تا حجم فایل به‌طور چشمگیری کاهش یابد.
- فیلدهای **مجموعه** و **شماره (#)** را پر کنید تا مدیران کتابخانه (Komga، Calibre) مجموعهٔ شما را خودکار سازماندهی کنند.
- **WebP** بهترین فشرده‌سازی را ارائه می‌دهد، اما ممکن است کمیک‌خوان‌های قدیمی‌تر از آن پشتیبانی نکنند.

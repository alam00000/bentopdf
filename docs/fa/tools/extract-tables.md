# استخراج جدول‌ها

همهٔ جدول‌های یک PDF را تشخیص می‌دهد و به شما امکان می‌دهد آن‌ها را در قالب دلخواه خود صادر کنید: CSV، JSON یا Markdown. هر جدول به‌طور جداگانه همراه با فرادادهٔ صفحه و موقعیت استخراج می‌شود. با قدرت موتور تشخیص جدول PyMuPDF.

## نحوهٔ کار

1. یک PDF را با کلیک روی ناحیهٔ رها کردن یا کشیدن فایل روی آن بارگذاری کنید.
2. **قالب خروجی** دلخواه خود را انتخاب کنید: CSV، JSON یا Markdown.
3. برای شروع پردازش روی **استخراج** کلیک کنید.
4. اگر یک جدول یافت شود، به‌صورت یک فایل دانلود می‌شود. چند جدول یک آرشیو ZIP با یک فایل برای هر جدول تولید می‌کنند.

## گزینه‌ها

- **قالب خروجی**: یکی را انتخاب کنید:
  - **CSV**: مقادیر جداشده با کاما با نقل‌قول‌گذاری درست برای فیلدهای شامل کاما، نقل‌قول یا خط جدید. مناسب صفحه‌گسترده‌ها و پایگاه‌های داده.
  - **JSON**: ساختار آرایه‌ای از آرایه‌ها، با تورفتگی ۲ فاصله‌ای و قالب‌بندی خوانا. مناسب استفادهٔ برنامه‌نویسی.
  - **Markdown**: قالب جدول جداشده با خط عمودی که PyMuPDF رندر می‌کند. مناسب مستندات و فایل‌های README.

## قالب خروجی

- **یک جدول**: `filename_table.csv` (یا `.json` / `.md`)
- **چند جدول**: `filename_tables.zip` شامل فایل‌هایی با نام‌های `table_1_page3.csv`، `table_2_page5.csv` و غیره

## کاربردها

- استخراج جدول‌های خاص از گزارش‌های طولانی PDF بدون بیرون کشیدن دادهٔ کل سند.
- دریافت جدول‌ها در قالب Markdown برای چسباندن مستقیم در issueهای GitHub، ویکی‌ها یا مستندات.
- بیرون کشیدن دادهٔ ساختاریافتهٔ JSON از جدول‌های PDF برای یکپارچه‌سازی API یا اسکریپت‌ها.
- مقایسهٔ جدول‌ها در نسخه‌های مختلف PDF با صادر کردن هر دو به CSV و مقایسهٔ تفاوت‌ها.

## نکته‌ها

- این ابزار کنترل جداگانه بر هر جدول به شما می‌دهد. اگر فقط می‌خواهید همهٔ جدول‌ها در یک CSV ریخته شوند، از [PDF به CSV](./pdf-to-csv) استفاده کنید. برای یک کتاب کار کامل Excel، از [PDF به Excel](./pdf-to-excel) استفاده کنید.
- جدول‌هایی که در چند صفحه گسترده‌اند ممکن است به‌صورت جدول‌های جداگانه در هر صفحه تشخیص داده شوند. ممکن است لازم باشد آن‌ها را دستی به هم بچسبانید.
- اگر جدولی تشخیص داده نشود، ممکن است PDF یک تصویر اسکن‌شده باشد. ابتدا آن را از OCR عبور دهید تا لایهٔ متنی اضافه شود.

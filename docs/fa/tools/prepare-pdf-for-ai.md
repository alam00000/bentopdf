# آماده‌سازی PDF برای هوش مصنوعی

محتوای فایل‌های PDF را استخراج کرده و به‌صورت JSON بهینه برای ورود به مدل‌های زبانی بزرگ (LLM) و چارچوب‌های هوش مصنوعی مانند LlamaIndex ساختاردهی می‌کند. محتوای هر صفحه استخراج شده و در قالبی ساختاریافته، آماده برای خطوط RAG، چت‌بات‌ها یا سامانه‌های جست‌وجوی معنایی، سازماندهی می‌شود.

## نحوهٔ کار

1. یک یا چند PDF را با کلیک روی ناحیهٔ رها کردن یا کشیدن فایل‌ها روی آن بارگذاری کنید.
2. برای شروع پردازش روی **استخراج** کلیک کنید.
3. یک فایل به‌صورت `filename_llm.json` دانلود می‌شود. چند فایل یک بایگانی `pdf-for-ai.zip` تولید می‌کنند.

این ابزار از یکپارچگی PyMuPDF با LlamaIndex برای استخراج محتوای سطح صفحه همراه با فراداده استفاده می‌کند و خروجی‌ای تولید می‌کند که مستقیماً در چارچوب‌های هوش مصنوعی قابل بارگذاری است.

## گزینه‌ها

این ابزار گزینهٔ قابل تنظیمی ندارد. همهٔ صفحات با متن کامل و فراداده استخراج می‌شوند.

## قالب خروجی

- **یک فایل**: `filename_llm.json`
- **چند فایل**: `pdf-for-ai.zip` شامل یک `_llm.json` برای هر PDF ورودی.

خروجی JSON از طرح‌وارهٔ سند LlamaIndex با محتوای متنی و فیلدهای فرادادهٔ هر صفحه پیروی می‌کند.

## موارد استفاده

- آماده‌سازی اسناد PDF برای خطوط تولید تقویت‌شده با بازیابی (RAG).
- ساخت پایگاه دانش قابل جست‌وجو از بایگانی‌های PDF برای یک چت‌بات هوش مصنوعی.
- ارسال گزارش‌های PDF به جریان‌های تحلیل مبتنی بر LLM.
- پیش‌پردازش مقالات پژوهشی برای سامانه‌های جست‌وجوی معنایی و پرسش و پاسخ.
- ساخت داده‌های آموزشی ساختاریافته از مجموعه‌های اسناد PDF.

## نکته‌ها

- برای استخراج متن ساده بدون قالب‌بندی ویژهٔ هوش مصنوعی، از [PDF به متن](./pdf-to-text) استفاده کنید.
- برای خروجی Markdown که سرفصل‌ها و ساختار را حفظ می‌کند، از [PDF به Markdown](./pdf-to-markdown) استفاده کنید.
- PDFهای اسکن‌شده خروجی خالی یا ناچیزی تولید می‌کنند. ابتدا آن‌ها را با OCR پردازش کنید تا پیش از استخراج یک لایهٔ متنی اضافه شود.

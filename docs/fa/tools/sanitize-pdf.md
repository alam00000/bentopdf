# پاک‌سازی PDF

PDFها می‌توانند بسیار بیشتر از آنچه روی صفحه می‌بینید در خود داشته باشند. فرادادهٔ پنهان، JavaScript جاسازی‌شده، فایل‌های پیوست، دادهٔ فرم و اطلاعات لایه‌ها می‌توانند داده‌های حساس را فاش کنند یا خطر امنیتی ایجاد کنند. پاک‌سازی همهٔ آن‌ها را حذف می‌کند و سندی تمیز و امن برای اشتراک عمومی باقی می‌گذارد.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید.
2. عناصری را که باید حذف شوند از فهرست انتخاب کنید.
3. روی **پاک‌سازی PDF** کلیک کنید.
4. فایل پاک‌شده را دانلود کنید.

## گزینه‌های پاک‌سازی

همهٔ گزینه‌ها به‌طور پیش‌فرض فعال‌اند. هر کدام را که می‌خواهید حفظ شود از حالت انتخاب خارج کنید.

| گزینه                       | چه چیزی را حذف می‌کند                                                       |
| --------------------------- | --------------------------------------------------------------------------- |
| **یکپارچه‌سازی فرم‌ها**     | فیلدهای فرم تعاملی را به محتوای ثابت تبدیل می‌کند                           |
| **حذف فراداده**             | نویسنده، عنوان، تاریخ ایجاد، اطلاعات نرم‌افزار و دادهٔ XMP را حذف می‌کند    |
| **حذف حاشیه‌نویسی‌ها**      | نظرها، هایلایت‌ها، یادداشت‌های چسبان و نشانه‌گذاری‌ها را پاک می‌کند         |
| **حذف JavaScript**          | اسکریپت‌های جاسازی‌شده‌ای را که ممکن است هنگام باز شدن اجرا شوند حذف می‌کند |
| **حذف فایل‌های جاسازی‌شده** | پیوست‌های جاسازی‌شده در PDF را حذف می‌کند                                   |
| **حذف لایه‌ها (OCG)**       | گروه‌های محتوای اختیاری را در یک لایه یکپارچه می‌کند                        |
| **حذف پیوندها**             | ابرپیوندها و ارجاع‌های URL را حذف می‌کند                                    |
| **حذف درخت ساختار**         | ساختار سند مورد استفاده برای برچسب‌گذاری دسترس‌پذیری را حذف می‌کند          |
| **حذف MarkInfo**            | اطلاعات محتوای نشانه‌گذاری‌شده را حذف می‌کند                                |
| **حذف قلم‌ها**              | دادهٔ قلم‌های جاسازی‌شده را حذف می‌کند (با احتیاط استفاده کنید)             |

## موارد استفاده

- آماده‌سازی PDF برای انتشار عمومی با حذف فرادادهٔ داخلی (نام نویسندگان، نسخهٔ نرم‌افزار، تاریخچهٔ ویرایش)
- حذف JavaScript از PDF دریافتی از منبع نامطمئن پیش از باز کردن آن
- پاک‌سازی PDF پیش از ارسال برای مشتری‌ای که نباید نظرهای جاسازی‌شده یا نام فیلدهای فرم را ببیند
- حذف لایه‌های پنهان از نقشهٔ معماری پیش از اشتراک نسخهٔ نهایی
- رعایت الزامات کمینه‌سازی داده طبق مقررات حریم خصوصی

## نکته‌ها

- «حذف قلم‌ها» را علامت نزنید مگر اینکه مطمئن باشید PDF همچنان درست نمایش داده می‌شود. حذف قلم‌ها ممکن است متن را در برخی نمایشگرها نامرئی کند.
- اگر فقط لازم است فراداده را حذف کنید، ابزار اختصاصی حذف فراداده سریع‌تر و متمرکزتر است.
- پاک‌سازی برگشت‌ناپذیر است. فایل اصلی خود را نگه دارید.

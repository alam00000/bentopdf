# افزودن مهر

با استفاده از یک نمایشگر تعبیه‌شده همراه با نوار ابزار حاشیه‌نویسی مهر، مهرهای تصویری را روی صفحات PDF قرار دهید. مهرها می‌توانند نام شما را برای انتساب داشته باشند، که این ابزار را برای گردش‌های کاری تأیید، فرایندهای بازبینی و علامت‌گذاری اسناد مفید می‌کند.

## نحوهٔ کار

1. نام خود را در فیلد **نام کاربری مهر** وارد کنید. این نام روی مهرهایی که می‌سازید نمایش داده می‌شود.
2. فایل PDF خود را با کلیک یا کشیدن به ناحیهٔ رها کردن بارگذاری کنید.
3. ویرایشگر مهر با سند بارگذاری‌شده در یک نمایشگر باز می‌شود.
4. از ابزار مهر تصویری در نوار ابزار برای انتخاب و قرار دادن مهر روی هر صفحه استفاده کنید.
5. در صورت نیاز موقعیت و اندازهٔ مهرها را تنظیم کنید.
6. روی **ذخیرهٔ PDF مهرشده** کلیک کنید تا نتیجه دانلود شود.

## ویژگی‌ها

- نمایشگر PDF یکپارچه با نوار ابزار حاشیه‌نویسی ویژهٔ مهر
- انتساب نام کاربری روی مهرهای ساخته‌شده
- قرار دادن مهر تصویری روی هر صفحه
- جابه‌جایی و تغییر اندازه با کشیدن و رها کردن
- تنظیم خودکار اندازهٔ نمایشگر بر اساس نسبت ابعاد صفحه
- نمایش فایل با نام و اندازهٔ آن

## موارد استفاده

- افزودن مهرهای تصویری «APPROVED» یا «REVIEWED» به اسناد در گردش کار بازبینی
- قرار دادن تصویر مهر شرکت یا مهر دفتر اسناد رسمی روی اسناد رسمی
- علامت‌گذاری صفحات با مهر «RECEIVED» همراه با نام بازبین
- افزودن مهرهای کنترل کیفیت به گزارش‌های بازرسی

## نکته‌ها

- پیش از بارگذاری PDF، نام کاربری مهر را تنظیم کنید. نام کاربری در فرادادهٔ مهر جاسازی می‌شود.
- نمایشگر ارتفاع خود را بر اساس نسبت ابعاد صفحهٔ اول PDF برای بهترین نمایش تنظیم می‌کند.
- برای واترمارک‌های متنی به‌جای مهرهای تصویری، از ابزار [افزودن واترمارک](./add-watermark) استفاده کنید.

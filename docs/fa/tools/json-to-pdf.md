# JSON به PDF

اسناد PDF را از فایل‌های JSON که پیش‌تر با ابزار **PDF به JSON** در BentoPDF ساخته شده‌اند بازسازی کنید. این یک ابزار تبدیل رفت‌وبرگشتی است: نمایش ساختاریافتهٔ JSON یک PDF را می‌گیرد و سند اصلی را دوباره می‌سازد.

::: warning
این ابزار فقط فایل‌های JSON تولیدشده با مبدل PDF به JSON در BentoPDF را می‌پذیرد. فایل‌های JSON معمولی از APIها، پایگاه‌های داده یا ابزارهای دیگر پشتیبانی نمی‌شوند.
:::

## قالب‌های پشتیبانی‌شده

| ورودی   | توضیحات                                                        |
| :------ | :------------------------------------------------------------- |
| `.json` | فایل‌های JSON خروجی‌گرفته‌شده با ابزار PDF به JSON در BentoPDF |

## نحوهٔ کار

1. روی ناحیهٔ بارگذاری کلیک کنید یا یک یا چند فایل JSON را بکشید و رها کنید.
2. فهرست فایل‌ها هر فایل انتخاب‌شده را با حجمش نشان می‌دهد.
3. روی **تبدیل به PDF** کلیک کنید. ابزار همهٔ فایل‌ها را با یک Web Worker و موتور CPDF پردازش می‌کند.
4. خروجی با نام `jsons-to-pdf.zip` دانلود می‌شود که به‌ازای هر فایل JSON ورودی یک PDF دارد.

تبدیل در یک Web Worker پس‌زمینه اجرا می‌شود، بنابراین رابط کاربری حتی با فایل‌های بزرگ هم پاسخگو می‌ماند.

## گزینه‌ها

این ابزار گزینهٔ قابل تنظیمی ندارد. ساختار JSON به‌طور کامل PDF خروجی را تعیین می‌کند.

## خروجی

هنگام تبدیل چند فایل JSON، نتایج به‌صورت بایگانی ZIP ارائه می‌شوند. نام هر PDF از فایل JSON منبعش گرفته می‌شود (مثلاً `report.json` به `report.pdf` تبدیل می‌شود).

## موارد استفاده

- بازیابی PDFها از یک پشتیبان یا فرایند بایگانی مبتنی بر JSON
- عبور رفت‌وبرگشتی یک PDF از JSON برای بررسی و سپس بازگرداندن به PDF
- بازسازی اسناد پس از تغییرات برنامه‌نویسی‌شده در ساختار JSON
- اطمینان از اینکه خروجی PDF به JSON همهٔ محتوای سند را ثبت کرده است، با تبدیل دوبارهٔ آن

## نکات

- اگر لازم است دادهٔ JSON دلخواه (مانند پاسخ‌های API یا فایل‌های پیکربندی) را به یک PDF قالب‌بندی‌شده تبدیل کنید، ابزار [متن به PDF](./txt-to-pdf) مناسب‌تر است. JSON را به‌صورت متن جای‌گذاری کنید تا با قالب‌بندی مناسب رندر شود.
- برای کار این ابزار، موتور CPDF WebAssembly باید در دسترس باشد. نمونه‌های خودمیزبان باید فایل‌های CPDF WASM را پیکربندی کنند.

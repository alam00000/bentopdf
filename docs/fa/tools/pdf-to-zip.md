# PDFها به ZIP

چند فایل PDF را در یک بایگانی ZIP جمع کنید. این یک ابزار سادهٔ بسته‌بندی است، بدون تبدیل، فشرده‌سازی یا تغییر خود PDFها.

## نحوهٔ کار

1. با ناحیهٔ رها کردن چند فایل PDF بارگذاری کنید.
2. فهرست فایل‌ها را بررسی کنید. هر فایلی را که نمی‌خواهید حذف کنید.
3. روی دکمهٔ پردازش کلیک کنید.
4. یک بایگانی ZIP شامل همهٔ PDFهای بارگذاری‌شده بی‌درنگ دانلود می‌شود.

## ویژگی‌ها

- پذیرش هر تعداد فایل PDF
- حذف تک‌تک فایل‌ها پیش از ساخت بایگانی
- حفظ نام اصلی فایل‌ها درون ZIP
- بدون تغییر محتوای PDF؛ فایل‌ها همان‌طور که هستند بسته‌بندی می‌شوند
- نمایش نام و حجم هر PDF بارگذاری‌شده

## موارد استفاده

- جمع کردن مجموعه‌ای از فاکتورها یا رسیدها برای پیوست ایمیل
- بسته‌بندی تحویلی‌های پروژه (چند گزارش PDF) برای تحویل
- ساخت یک دانلود واحد برای مجموعه‌ای از فرم‌ها یا الگوها
- بایگانی دسته‌ای از اسناد در یک فایل فشرده

## نکته‌ها

- فایل ZIP از نام‌های اصلی فایل‌های PDF استفاده می‌کند. اگر فایل‌های هم‌نام دارید، برای جلوگیری از تداخل پیش از بارگذاری نامشان را تغییر دهید.
- این ابزار خود PDFها را فشرده نمی‌کند. برای کاهش حجم، ابتدا آن‌ها را از فشرده‌سازی PDF عبور دهید و سپس با این ابزار بسته‌بندی کنید.

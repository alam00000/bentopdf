# PDF به متن

همهٔ محتوای متنی فایل‌های PDF را استخراج و به‌صورت فایل‌های ساده `.txt` ذخیره می‌کند. از پردازش دسته‌ای پشتیبانی می‌کند؛ چند PDF بارگذاری کنید و متن همه را در یک عملیات دریافت کنید. با قدرت PyMuPDF.

## نحوهٔ کار

1. با کلیک روی ناحیهٔ رها کردن یا کشیدن فایل‌ها روی آن، یک یا چند PDF بارگذاری کنید. فهرست فایل‌ها را با دکمه‌های «افزودن فایل بیشتر» و «پاک کردن فایل‌ها» مدیریت کنید.
2. برای شروع پردازش روی **استخراج متن** کلیک کنید.
3. یک فایل تکی به‌صورت `filename.txt` دانلود می‌شود. چند فایل یک بایگانی `pdf-to-text.zip` تولید می‌کنند.

## گزینه‌ها

این ابزار گزینهٔ قابل‌تنظیمی ندارد. همهٔ محتوای متنی همهٔ صفحات به ترتیب خواندن استخراج می‌شود.

## قالب خروجی

- **تک‌فایل**: `filename.txt`
- **چند فایل**: `pdf-to-text.zip` شامل یک `.txt` برای هر PDF ورودی.

## موارد استفاده

- استخراج متن اصلی گزارش‌های PDF برای نمایه‌سازی جستجوی تمام‌متن.
- تبدیل کتاب‌ها یا مقالات الکترونیکی PDF به متن ساده برای خواندن در دستگاه‌های جوهر الکترونیکی.
- بیرون کشیدن متن از قراردادها یا اسناد حقوقی برای تحلیل کلیدواژه.
- حذف قالب‌بندی PDFها برای دریافت متن تمیز برای اسکریپت‌های پردازش داده.
- آماده‌سازی پیکرهٔ متنی از بایگانی‌های PDF برای پردازش زبان طبیعی.

## نکته‌ها

- PDFهای اسکن‌شده (فقط تصویر) فایل‌های متنی خالی تولید می‌کنند، چون لایهٔ متنی برای استخراج ندارند. ابتدا اسناد اسکن‌شده را از OCR عبور دهید.
- خروجی ترتیب خواندن را همان‌طور که PyMuPDF تفسیر می‌کند حفظ می‌کند که معمولاً چپ‌به‌راست و بالا به پایین است. چیدمان‌های چندستونی ممکن است متن درهم‌آمیخته تولید کنند.
- برای خروجی ساختاریافته با سرفصل‌ها و قالب‌بندی، [PDF به Markdown](./pdf-to-markdown) را امتحان کنید. برای JSON ساختاریافتهٔ آماده برای هوش مصنوعی، از [آماده‌سازی PDF برای هوش مصنوعی](./prepare-pdf-for-ai) استفاده کنید.

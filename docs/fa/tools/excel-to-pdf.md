# Excel به PDF

فایل‌های صفحه‌گسترده را به PDF تبدیل کنید. این ابزار فایل‌های Excel جدید، قالب قدیمی XLS، صفحه‌گسترده‌های OpenDocument و حتی CSV را پشتیبانی می‌کند؛ همه از طریق موتور LibreOffice مبتنی بر مرورگر رندر می‌شوند که قالب‌بندی سلول‌ها، فرمول‌ها (به‌صورت مقادیر محاسبه‌شده)، نمودارها و چیدمان‌های چندبرگه‌ای را حفظ می‌کند.

## قالب‌های پشتیبانی‌شده

| قالب                      | پسوندها |
| :------------------------ | :------ |
| Excel (جدید)              | `.xlsx` |
| Excel (قدیمی)             | `.xls`  |
| صفحه‌گستردهٔ OpenDocument | `.ods`  |
| CSV                       | `.csv`  |

## نحوهٔ کار

1. روی ناحیهٔ بارگذاری کلیک کنید یا فایل‌های صفحه‌گستردهٔ خود را بکشید و رها کنید.
2. فهرست فایل‌ها را بررسی کنید. فایل‌های بیشتری اضافه کنید یا موارد ناخواسته را حذف کنید.
3. روی **تبدیل به PDF** کلیک کنید. موتور LibreOffice در اولین استفاده راه‌اندازی می‌شود و سپس هر فایل را پردازش می‌کند.
4. یک فایل مستقیماً به‌صورت PDF دانلود می‌شود. چند فایل به‌صورت `excel-converted.zip` تحویل داده می‌شوند.

## گزینه‌ها

این ابزار پیکربندی اضافه‌ای ندارد. موتور LibreOffice چیدمان صفحه، مقیاس و ناحیهٔ چاپ را بر اساس تنظیمات داخلی صفحه‌گسترده تعیین می‌کند.

## خروجی

| تعداد ورودی | خروجی                                                      |
| :---------- | :--------------------------------------------------------- |
| 1 فایل      | دانلود یک PDF (نام فایل اصلی با پسوند `.pdf`)              |
| 2+ فایل     | آرشیو ZIP (`excel-converted.zip`) شامل یک PDF برای هر فایل |

## کاربردها

- تبدیل گزارش‌های مالی یا بودجه از Excel به PDF برای توزیع
- ساخت PDFهای آمادهٔ چاپ از صفحه‌گسترده‌های موجودی یا کاتالوگ محصول
- اشتراک‌گذاری نتایج تحلیل داده با ذی‌نفعانی که Excel نصب ندارند
- بایگانی گزارش‌های فصلی در قالبی غیرقابل ویرایش
- تبدیل فایل‌های ODS از LibreOffice Calc به PDF

## نکته‌ها

- نمودارهای جاسازی‌شده در صفحه‌گسترده در PDF رندر می‌شوند. پیش از تبدیل مطمئن شوید در فایل منبع درست به نظر می‌رسند.
- اگر صفحه‌گستردهٔ شما چند برگه دارد، همهٔ برگه‌ها در خروجی PDF گنجانده می‌شوند.
- برای داده‌های ساده CSV بدون قالب‌بندی، ابزار [CSV به PDF](./csv-to-pdf) تبدیلی سبک‌تر ارائه می‌دهد. وقتی به حفظ قالب‌بندی، نمودارها یا چند برگه نیاز دارید از Excel به PDF استفاده کنید.

# تصاویر به PDF

مبدل همه‌کارهٔ تصویر به PDF. تصاویر را تقریباً در هر قالبی بارگذاری کنید و آن‌ها را در یک سند PDF ترکیب کنید. هر تصویر صفحهٔ خودش را می‌گیرد که اندازه‌اش با ابعاد اصلی تصویر مطابقت دارد.

## قالب‌های پشتیبانی‌شده

| قالب            | پسوندها                                |
| :-------------- | :------------------------------------- |
| JPEG            | `.jpg`, `.jpeg`                        |
| JPEG 2000       | `.jp2`, `.jpx`                         |
| PNG             | `.png`                                 |
| BMP             | `.bmp`                                 |
| GIF             | `.gif`                                 |
| TIFF            | `.tiff`, `.tif`                        |
| SVG             | `.svg`                                 |
| HEIC/HEIF       | `.heic`, `.heif`                       |
| WebP            | `.webp`                                |
| PSD             | `.psd`                                 |
| Portable Anymap | `.pnm`, `.pgm`, `.pbm`, `.ppm`, `.pam` |
| JPEG XR         | `.jxr`                                 |

این گسترده‌ترین پشتیبانی از قالب‌ها در میان مبدل‌های تصویر BentoPDF است. اگر فقط به یک قالب خاص نیاز دارید، از یکی از ابزارهای اختصاصی استفاده کنید.

## نحوهٔ کار

1. روی ناحیهٔ بارگذاری کلیک کنید یا فایل‌های تصویری خود را بکشید و رها کنید. می‌توانید چند فایل را همزمان انتخاب کنید.
2. فهرست فایل‌ها را بررسی کنید. فایل‌های ناخواسته را با نماد سطل زباله حذف کنید یا برای افزودن تصاویر بیشتر روی **افزودن فایل‌های بیشتر** کلیک کنید.
3. از منوی کشویی یک سطح **کیفیت PDF** انتخاب کنید.
4. روی **تبدیل به PDF** کلیک کنید. ابزار تصاویر را با موتور PyMuPDF پردازش می‌کند و نتیجه را با نام `images_to_pdf.pdf` دانلود می‌کند.

## گزینه‌ها

**کیفیت PDF** فشرده‌سازی اعمال‌شده هنگام جاسازی تصاویر در PDF را کنترل می‌کند:

- **کیفیت بالا**: فشرده‌سازی حداقلی، حجم بیشتر. بهترین گزینه برای چاپ یا بایگانی.
- **کیفیت متوسط** (پیش‌فرض): فشرده‌سازی متعادل. مناسب برای بیشتر کاربردها.
- **کیفیت پایین**: فشرده‌سازی شدید، کمترین حجم. مناسب برای ایمیل یا اشتراک سریع.

فایل‌های HEIC و WebP پیش از جاسازی به‌طور خودکار به PNG تبدیل می‌شوند. این کار بی‌صدا انجام می‌شود و به هیچ مرحلهٔ اضافه‌ای نیاز ندارد.

## موارد استفاده

- ترکیب رسیدها یا اسناد اسکن‌شده با دوربین گوشی در یک PDF
- ساخت نمونه‌کار عکس یا کاتالوگ از تصاویری با قالب‌های مختلف
- تبدیل عکس‌های آیفون (HEIC) به یک PDF قابل اشتراک بدون نصب نرم‌افزار دسکتاپ
- گردآوری ماکاپ‌های طراحی از خروجی‌های PSD و اسکرین‌شات‌ها در یک تحویلی برای مشتری
- بایگانی پوشه‌ای از قالب‌های تصویری قدیمی (PNM، JXR، JP2) در یک PDF واحد

## نکات

- ترتیب تصاویر در PDF با ترتیب آن‌ها در فهرست فایل‌ها یکسان است. آن‌ها را به ترتیبی که می‌خواهید بارگذاری کنید.
- برای کمترین حجم ممکن، کیفیت پایین را انتخاب کنید. تفاوت بصری برای اسکن‌های پرمتن اغلب ناچیز است.
- اگر فقط یک قالب تصویری دارید، مبدل‌های اختصاصی (JPG به PDF، PNG به PDF و غیره) همان نتیجه را با رابطی ساده‌تر ارائه می‌دهند.

# CSV به PDF

فایل‌های CSV را به اسناد PDF تمیز و قالب‌بندی‌شده تبدیل کنید. هر CSV تجزیه و به‌صورت جدول در PDF خروجی رندر می‌شود. این کار زمانی مفید است که بخواهید داده‌های جدولی را چاپ یا به اشتراک بگذارید بدون اینکه گیرنده به نرم‌افزار صفحه‌گسترده نیاز داشته باشد.

## قالب‌های پشتیبانی‌شده

| قالب | پسوندها |
| :--- | :------ |
| CSV  | `.csv`  |

## نحوهٔ کار

1. روی ناحیهٔ بارگذاری کلیک کنید یا یک یا چند فایل CSV را بکشید و رها کنید.
2. فهرست فایل‌ها را بررسی کنید. فایل‌های بیشتری اضافه کنید یا موارد ناخواسته را حذف کنید.
3. روی **تبدیل به PDF** کلیک کنید. یک نشانگر پیشرفت وضعیت تبدیل را نشان می‌دهد.
4. یک فایل مستقیماً به‌صورت PDF دانلود می‌شود. چند فایل در `csv-converted.zip` بسته‌بندی می‌شوند.

## گزینه‌ها

این ابزار پیکربندی اضافه‌ای ندارد. CSV به‌طور خودکار تجزیه و به‌صورت جدول قالب‌بندی می‌شود.

## خروجی

| تعداد ورودی | خروجی                                                    |
| :---------- | :------------------------------------------------------- |
| 1 فایل      | دانلود یک PDF (مثلاً `data.pdf`)                         |
| 2+ فایل     | آرشیو ZIP (`csv-converted.zip`) شامل یک PDF برای هر فایل |

## کاربردها

- تبدیل گزارش‌های صادرشده از پایگاه داده به جدول‌های PDF قابل چاپ
- اشتراک‌گذاری داده‌های مالی یا فهرست موجودی با افرادی که Excel ندارند
- ساخت نسخهٔ PDF از فایل‌های گزارش CSV برای مستندات انطباق
- چاپ فهرست نشانی‌ها، کارنامه‌ها یا هر دادهٔ جدولی ذخیره‌شده به‌صورت CSV

## نکته‌ها

- برای بهترین نتیجه، مطمئن شوید CSV شما از جداکنندهٔ استاندارد کاما استفاده می‌کند. ابزار از قواعد رایج تجزیهٔ CSV پیروی می‌کند.
- اگر CSV شما ستون‌های زیادی دارد، ممکن است جدول برای جا شدن در عرض صفحه فشرده شود. تقسیم مجموعه‌داده‌های عریض به چند فایل را در نظر بگیرید.
- برای فایل‌های Excel (`.xls`، `.xlsx`) از ابزار [Excel به PDF](./excel-to-pdf) استفاده کنید که قالب‌بندی صفحه‌گسترده و چند برگه را حفظ می‌کند.

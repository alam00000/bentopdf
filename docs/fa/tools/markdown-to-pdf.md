# Markdown به PDF

یک ویرایشگر کامل Markdown با پیش‌نمایش زنده و خروجی PDF با یک کلیک. از ابتدا بنویسید، یک فایل `.md` موجود بارگذاری کنید یا محتوا را از کلیپ‌بورد جای‌گذاری کنید. ویرایشگر Markdown شما را به‌صورت بلادرنگ رندر می‌کند و با موتور چاپ داخلی مرورگر یک PDF سبک‌دار خروجی می‌دهد.

## قالب‌های پشتیبانی‌شده

| ورودی          | توضیحات                       |
| :------------- | :---------------------------- |
| فایل‌های `.md` | بارگذاری با دکمهٔ Upload      |
| ورودی مستقیم   | تایپ یا جای‌گذاری در ویرایشگر |

## نحوهٔ کار

1. ابزار Markdown به PDF را باز کنید. ویرایشگر با نمای دوقسمتی بارگیری می‌شود: منبع Markdown در سمت چپ و پیش‌نمایش رندرشده در سمت راست.
2. Markdown خود را بنویسید، جای‌گذاری کنید یا برای بارگیری یک فایل `.md` روی **بارگذاری** کلیک کنید.
3. با لغزندهٔ پوسته در نوار ابزار بین پوسته‌های روشن و تیره جابه‌جا شوید.
4. برای تولید PDF از طریق پنجرهٔ چاپ مرورگر روی **برون‌ریزی PDF** کلیک کنید (یا `Ctrl/Cmd + S` را بزنید).

## ویژگی‌ها

ویرایشگر مجموعهٔ گسترده‌ای از قابلیت‌های Markdown فراتر از موارد پایه را پشتیبانی می‌کند:

- **Markdown استاندارد**: عنوان‌ها، پررنگ، کج، پیوندها، تصاویر، فهرست‌ها، نقل‌قول‌ها، خطوط افقی
- **بلوک‌های کد** با برجسته‌سازی نحو برای بیش از 15 زبان (JavaScript، TypeScript، Python، Go، Rust، SQL، Java، C#، C++، YAML، Bash و غیره)
- **نمودارهای Mermaid**: فلوچارت‌ها، نمودارهای توالی، نمودارهای ER و دیگر انواع نمودار Mermaid مستقیماً در پیش‌نمایش رندر می‌شوند
- **جدول‌ها** با نحو استاندارد جدول Markdown
- **فهرست کارها** با کادرهای انتخاب
- **پانویس‌ها**، **زیرنویس**، **بالانویس**
- **فهرست‌های تعریف**، **اختصارها**
- پشتیبانی از **ایموجی** (`:smile:` به‌صورت ایموجی رندر می‌شود)
- **هایلایت‌ها** (`==marked text==`) و **درج‌ها** (`++inserted text++`)
- **پیوند خودکار URLها**: URLهای ساده به پیوندهای قابل کلیک تبدیل می‌شوند
- تولید **فهرست مطالب**
- **پیوندهای لنگر** روی عنوان‌ها

## موارد استفاده

- نوشتن مستندات پروژه و خروجی گرفتن یک PDF شسته‌رفته برای ذی‌نفعان
- ساخت گزارش‌های فنی با نمونه کد و نمودارهای معماری Mermaid
- تبدیل README یک مخزن GitHub به PDF برای استفادهٔ آفلاین یا چاپ
- پیش‌نویس یک پیشنهاد یا مشخصات فنی با فهرست کارها و جدول‌ها
- تولید جزوه‌ای سبک‌دار از یادداشت‌های درسی نوشته‌شده با Markdown

## نکات

- خروجی PDF از قابلیت چاپ به PDF مرورگر استفاده می‌کند. در Chrome می‌توانید پیش از ذخیره، حاشیه‌ها و مقیاس را در پنجرهٔ چاپ تنظیم کنید.
- نمودارهای Mermaid در پیش‌نمایش رندر می‌شوند اما ممکن است در نخستین استفاده کمی زمان برای راه‌اندازی لازم داشته باشند.
- از `Ctrl/Cmd + S` به‌عنوان میان‌بر صفحه‌کلید برای خروجی گرفتن بدون رفتن سراغ دکمه استفاده کنید.

# مشاهدهٔ فراداده

ویژگی‌های پنهان جاسازی‌شده در یک فایل PDF را بررسی کنید. این ابزار اطلاعات سند (عنوان، نویسنده، تاریخ‌ها)، فرادادهٔ XMP، ابعاد صفحه و سایر داده‌های ساختاری را در قالبی خوانا نمایش می‌دهد.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید.
2. ابزار بلافاصله فایل را تجزیه می‌کند و همهٔ فرادادهٔ موجود را در بخش‌های منظم نمایش می‌دهد.
3. دیکشنری اطلاعات سند، درخت فرادادهٔ XMP و ویژگی‌های ساختاری را مرور کنید.
4. به هیچ مرحلهٔ پردازشی نیاز نیست: فراداده به‌محض بارگذاری فایل نمایش داده می‌شود.

## ویژگی‌ها

- نمایش فیلدهای استاندارد اطلاعات سند: عنوان، نویسنده، موضوع، کلیدواژه‌ها، سازنده، تولیدکننده
- نمایش تاریخ‌های ایجاد و تغییر در قالبی خوانا برای انسان
- تجزیه و نمایش کامل درخت فرادادهٔ XMP با فضاهای نام تودرتو
- تبدیل قالب تاریخ PDF (`D:20240101120000Z`) به تاریخ‌های خوانا
- سازمان‌دهی در بخش‌های تاشو برای پیمایش آسان

## بخش‌های فراداده

| بخش               | محتوا                                                                            |
| ----------------- | -------------------------------------------------------------------------------- |
| **اطلاعات سند**   | عنوان، نویسنده، موضوع، کلیدواژه‌ها، سازنده، تولیدکننده، تاریخ ایجاد، تاریخ تغییر |
| **فرادادهٔ XMP**  | درخت کامل فرادادهٔ مبتنی بر XML با فضاهای نام Dublin Core، XAP، PDF و سفارشی     |
| **ویژگی‌های سند** | تعداد صفحات، نسخهٔ PDF، اندازهٔ فایل، وضعیت رمزگذاری                             |

## موارد استفاده

- بررسی اینکه چه کسی PDF را نوشته و آخرین بار کی تغییر کرده است
- اطمینان از تنظیم درست فراداده پیش از انتشار سند
- ممیزی PDFها از نظر حریم خصوصی با بررسی اطلاعات شخصی جاسازی‌شده
- بررسی نرم‌افزاری که برای ایجاد یا تغییر PDF استفاده شده (از طریق فیلد Producer)
- مرور فرادادهٔ XMP برای انطباق با مدیریت دارایی‌های دیجیتال

## نکته‌ها

- رشته‌های تاریخ PDF که با `D:` شروع می‌شوند به‌طور خودکار به قالب منطقهٔ زمانی محلی شما تبدیل می‌شوند.
- اگر فیلدهای فراداده خالی به نظر می‌رسند، سازندهٔ PDF آن‌ها را تنظیم نکرده است. همهٔ PDFها فرادادهٔ غنی ندارند.
- برای تغییر فراداده پس از بررسی، از [ویرایش فراداده](./edit-metadata) استفاده کنید. برای حذف کامل آن، از حذف فراداده استفاده کنید.

# حذف صفحات

صفحات ناخواسته را از یک سند PDF حذف کنید. صفحات مورد نظر برای حذف را با تایپ شمارهٔ صفحه یا بازه مشخص کنید، یا مستقیماً روی تصاویر بندانگشتی صفحات کلیک کنید تا برای حذف علامت بخورند.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید. ابزار پیش‌نمایش بندانگشتی همهٔ صفحات را رندر می‌کند.
2. صفحات مورد نظر برای حذف را با نحو بازه در فیلد متنی وارد کنید (مثلاً `2, 5-8`)، یا روی تصاویر بندانگشتی کلیک کنید تا انتخاب یا لغو انتخاب شوند.
3. صفحات علامت‌خورده به‌صورت بصری برجسته می‌شوند تا بتوانید انتخاب خود را تأیید کنید.
4. روی دکمهٔ پردازش کلیک کنید. یک PDF جدید بدون صفحات انتخاب‌شده ساخته می‌شود.

## ویژگی‌ها

- انتخاب متنی صفحات با نحو بازه (`2, 5-8, 12`)
- شبکهٔ بصری تصاویر بندانگشتی برای انتخاب با کلیک
- برجسته‌سازی هم‌زمان صفحات علامت‌خورده برای حذف
- اعتبارسنجی ورودی در برابر تعداد واقعی صفحات
- حفظ همهٔ صفحات حذف‌نشده به ترتیب اصلی

## کاربردها

- حذف صفحات خالی یا اضافی از یک سند اسکن‌شده
- حذف صفحات جلد یا پیوست‌ها پیش از اشتراک‌گذاری سند
- پاک‌سازی صفحات پیش‌نویسی که اشتباهاً در PDF نهایی مانده‌اند
- حذف صفحات حاوی اطلاعات حساس پیش از توزیع

## نکته‌ها

- حذف صفحات روی محتوا یا قالب‌بندی صفحات باقی‌مانده اثری ندارد. خروجی نسخه‌ای دقیق از سند اصلی منهای صفحات حذف‌شده است.
- اگر می‌خواهید به‌جای حذف صفحاتی خاص، فقط صفحاتی خاص را نگه دارید، [استخراج صفحات](./extract-pages) مناسب‌تر است.
- نمای بندانگشتی به‌صورت تدریجی بارگیری می‌شود، بنابراین اسناد بزرگ نیز روان می‌مانند.

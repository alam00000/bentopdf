# PDF به JSON

یک یا چند فایل PDF را به قالب JSON تبدیل می‌کند. ابزار از CPDF (Coherent PDF) برای سریال‌سازی ساختار داخلی هر PDF به یک نمایش JSON ماشین‌خوان استفاده می‌کند. خروجی همیشه به‌صورت بایگانی ZIP ارائه می‌شود.

## نحوهٔ کار

1. با انتخابگر فایل یک یا چند فایل PDF انتخاب کنید.
2. برای شروع پردازش روی **تبدیل به JSON** کلیک کنید. تبدیل در یک web worker پس‌زمینه اجرا می‌شود.
3. یک بایگانی ZIP شامل یک فایل JSON برای هر PDF ورودی دانلود می‌شود.

نوار وضعیت پیشرفت مراحل تبدیل و ساخت ZIP را نشان می‌دهد.

## گزینه‌ها

این ابزار گزینهٔ قابل‌تنظیمی ندارد. هر PDF به نمایش کامل JSON خود تبدیل می‌شود.

## قالب خروجی

- یک فایل `pdfs-to-json.zip` شامل `filename.json` برای هر PDF ورودی.

خروجی JSON ساختار اشیای داخلی PDF را نشان می‌دهد، از جمله درخت صفحات، ارجاع‌های فونت، فراداده و جریان‌های محتوا.

## موارد استفاده

- بررسی ساختار داخلی یک PDF برای اشکال‌زدایی یا اعتبارسنجی.
- استخراج برنامه‌نویسی‌شدهٔ فرادادهٔ ساختاریافته و ویژگی‌های صفحات.
- ارسال دادهٔ ساختار PDF به خطوط پردازش سفارشی.
- ممیزی اسناد PDF برای انطباق با تحلیل درخت اشیای آن‌ها.

## نکته‌ها

- این ابزار ساختار خام اشیای PDF را خروجی می‌دهد، نه محتوای متنی استخراج‌شده. اگر متن صفحات را در قالب JSON می‌خواهید، به‌جای آن از [آماده‌سازی PDF برای هوش مصنوعی](./prepare-pdf-for-ai) استفاده کنید.
- برای استخراج متن ساده، [PDF به متن](./pdf-to-text) سرراست‌تر است.
- PDFهای بزرگ با ساختارهای پیچیده فایل‌های JSON بسیار حجیمی تولید می‌کنند.

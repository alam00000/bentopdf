# PDF به Word

فایل‌های PDF را به اسناد قابل‌ویرایش Word (`.docx`) تبدیل می‌کند. ابزار از PyMuPDF برای بازسازی محتوای سند استفاده می‌کند و متن، قالب‌بندی پایه و چیدمان را حفظ می‌کند. از تبدیل تکی و دسته‌ای پشتیبانی می‌کند.

## نحوهٔ کار

1. با کلیک روی ناحیهٔ رها کردن یا کشیدن فایل‌ها روی آن، یک یا چند PDF بارگذاری کنید. می‌توانید فایل‌های بیشتری اضافه یا تک‌تک فایل‌ها را از فهرست حذف کنید.
2. برای شروع پردازش روی **تبدیل به DOCX** کلیک کنید.
3. یک فایل تکی به‌صورت `filename.docx` دانلود می‌شود. چند فایل در `converted-documents.zip` بسته‌بندی می‌شوند.

## گزینه‌ها

این ابزار گزینهٔ قابل‌تنظیمی ندارد. هر PDF با موتور تبدیل داخلی PyMuPDF به DOCX تبدیل می‌شود.

## قالب خروجی

- **تک‌فایل**: `filename.docx`
- **چند فایل**: `converted-documents.zip` شامل یک `.docx` برای هر PDF ورودی.

## موارد استفاده

- ویرایش متن PDF دریافتی که باید تغییرش دهید.
- تبدیل گزارش‌های PDF بایگانی‌شده به قالبی که همکاران بتوانند در Microsoft Word یا Google Docs ویرایش کنند.
- انتقال محتوای قراردادها یا پیشنهادهای PDF به Word برای بازبینی و علامت‌گذاری تغییرات.
- انتقال مستندات قدیمی PDF به قالبی قابل‌ویرایش.

## نکته‌ها

- چیدمان‌های پیچیده با متن چندستونی، فرم‌های جاسازی‌شده یا گرافیک سنگین ممکن است کاملاً درست تبدیل نشوند. خروجی را بررسی و قالب‌بندی را در واژه‌پرداز خود اصلاح کنید.
- PDFهای اسکن‌شده (فقط تصویر) فایل‌های DOCX خالی یا بسیار کم‌محتوا تولید می‌کنند. ابتدا آن‌ها را از OCR عبور دهید تا لایهٔ متنی اضافه شود.
- حالت دسته‌ای برای تبدیل کل پوشه‌های PDF کارآمد است؛ همه را یک‌جا بارگذاری کنید.

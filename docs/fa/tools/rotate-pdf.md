# چرخاندن PDF

صفحات PDF را ۹۰ درجه در جهت یا خلاف جهت عقربه‌های ساعت بچرخانید. ابزار پیش‌نمایش کوچک همهٔ صفحات را نشان می‌دهد و می‌توانید آن‌ها را جداگانه بچرخانید یا یک چرخش دسته‌ای روی کل سند اعمال کنید.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید. تصاویر کوچک همهٔ صفحات در یک شبکه نمایش داده می‌شوند.
2. از دکمه‌های چرخش چپ/راست زیر تصویر کوچک هر صفحه برای چرخاندن همان صفحه استفاده کنید.
3. از کنترل‌های چرخش دسته‌ای در بالا برای چرخاندن همهٔ صفحات به‌طور یک‌جا استفاده کنید.
4. پیش‌نمایش تصاویر کوچک به‌صورت هم‌زمان چرخش را نشان می‌دهد.
5. روی دکمهٔ پردازش کلیک کنید تا PDF چرخانده‌شده ذخیره شود.

## ویژگی‌ها

- چرخش هر صفحه با گام‌های ۹۰ درجه‌ای (چپ یا راست)
- چرخش دسته‌ای همهٔ صفحات به‌طور هم‌زمان
- پیش‌نمایش هم‌زمان تصاویر کوچک با انیمیشن چرخش
- بارگذاری تنبل تصاویر کوچک برای عملکرد روان در اسناد بزرگ
- حفظ محتوا و کیفیت اصلی صفحات

## موارد استفاده

- اصلاح صفحات اسکن‌شدهٔ کج یا وارونه
- چرخاندن صفحات افقی به عمودی (یا برعکس)
- اصلاح سندی با جهت‌های مختلط که برخی صفحاتش با زاویهٔ اشتباه اسکن شده‌اند
- آماده‌سازی سند برای جهت نمایش خاص

## نکته‌ها

- چرخش‌ها تجمعی‌اند. دو بار کلیک روی دکمهٔ چرخش ساعت‌گرد، چرخش ۱۸۰ درجه اعمال می‌کند.
- برای چرخش‌های غیر ۹۰ درجه‌ای (مثلاً ۴۵ درجه برای اصلاح اسکن کمی کج)، به‌جای آن از [چرخاندن با زاویهٔ دلخواه](./rotate-custom) استفاده کنید.
- کنترل‌های چرخش دسته‌ای روی همهٔ صفحات اثر می‌گذارند، نه فقط صفحات انتخاب‌شده. این ابزار سازوکار انتخاب ندارد؛ برای آن از [ابزار چندکارهٔ PDF](./pdf-multi-tool) استفاده کنید.

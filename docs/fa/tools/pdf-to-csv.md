# PDF به CSV

جدول‌ها را از یک PDF استخراج و به‌صورت فایل CSV صادر می‌کند. ابزار با موتور تشخیص جدول PyMuPDF همهٔ صفحات را برای دادهٔ جدولی بررسی می‌کند و سپس همهٔ ردیف‌های یافت‌شده را در یک خروجی جداشده با ویرگول می‌نویسد.

## نحوهٔ کار

1. با کلیک روی ناحیهٔ رها کردن یا کشیدن فایل روی آن، یک PDF بارگذاری کنید.
2. برای شروع استخراج جدول روی **تبدیل به CSV** کلیک کنید.
3. ابزار هر صفحه را بررسی و جدول‌ها را خودکار شناسایی می‌کند.
4. یک فایل `.csv` با همهٔ داده‌های جدولی استخراج‌شده دانلود می‌شود.

جدول‌های صفحات مختلف در خروجی با ردیف‌های خالی از هم جدا می‌شوند. سلول‌هایی که ویرگول، نقل‌قول یا خط جدید دارند، طبق RFC 4180 به‌درستی escape می‌شوند.

## گزینه‌ها

این ابزار گزینهٔ قابل‌تنظیمی ندارد. همهٔ جدول‌های یافت‌شده در سند استخراج و در یک CSV ترکیب می‌شوند.

## قالب خروجی

- یک فایل `filename.csv` شامل همهٔ جدول‌های شناسایی‌شده.

## موارد استفاده

- انتقال داده‌های مالی از صورت‌حساب‌های بانکی یا فاکتورهای PDF به صفحه‌گسترده.
- استخراج جدول‌های قیمت از پیش‌فاکتورهای فروشندگان برای مقایسه.
- تبدیل داده‌های پژوهشی جدولی مقالات PDF به قالبی مناسب ابزارهای تحلیل.
- انتقال داده از گزارش‌های قدیمی PDF به پایگاه‌های داده.

## نکته‌ها

- اگر جدولی یافت نشود، ابزار پیام "جدولی پیدا نشد" را نشان می‌دهد. معمولاً یعنی PDF از چیدمان متنی استفاده می‌کند که جدولی به نظر می‌رسد اما ساختار جدول واقعی ندارد.
- برای کنترل بیشتر روی تک‌تک جدول‌ها از [استخراج جدول‌ها](./extract-tables) استفاده کنید که امکان انتخاب بین قالب‌های خروجی CSV، JSON و Markdown را می‌دهد.
- اگر داده را در قالب Excel با برگه‌های جداگانه برای هر جدول می‌خواهید، از [PDF به Excel](./pdf-to-excel) استفاده کنید.

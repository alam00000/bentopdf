# مقایسهٔ PDFها

دو PDF بارگذاری کنید و دقیقاً ببینید چه چیزی بین آن‌ها تغییر کرده است. ابزار صفحات را هوشمندانه جفت می‌کند، تفاوت‌ها در متن، تصاویر، حاشیه‌نویسی‌ها، سرصفحه‌ها و قالب‌بندی را تشخیص می‌دهد و آن‌ها را در نمای کنار هم یا روی‌هم نمایش می‌دهد.

## نحوهٔ کار

1. دو فایل PDF بارگذاری کنید: نسخهٔ اصلی (چپ) و نسخهٔ بازبینی‌شده (راست).
2. ابزار با استفاده از امضاهای محتوایی، صفحات دو سند را جفت می‌کند.
3. حالت نمایش را انتخاب کنید: **کنار هم** یا **روی‌هم**.
4. با کنترل‌های صفحه‌بندی بین جفت‌صفحه‌ها جابه‌جا شوید.
5. تفاوت‌ها برجسته و دسته‌بندی می‌شوند. از پنل فیلتر برای تمرکز روی انواع خاص تغییر استفاده کنید.
6. در صورت تمایل، مقایسه را به‌صورت گزارش PDF صادر کنید.

## ویژگی‌ها

- جفت کردن خودکار صفحات بر اساس شباهت محتوا
- نمای مقایسهٔ کنار هم و روی‌هم
- دسته‌بندی تغییرات: متن، تصویر، سرصفحه/پاصفحه، حاشیه‌نویسی، قالب‌بندی، پس‌زمینه
- فیلترهای جداگانه برای هر دسته جهت نمایش یا پنهان کردن انواع خاص تغییر
- جستجوی تغییرات متنی با فیلتر پرس‌وجو
- پشتیبانی از OCR برای مقایسهٔ اسناد اسکن‌شده
- کنترل‌های بزرگ‌نمایی برای بررسی دقیق
- پیمایش هماهنگ بین پنل‌ها در حالت کنار هم
- صادر کردن نتایج مقایسه به‌صورت PDF

## گزینه‌ها

| گزینه             | توضیحات                                                                                  |
| ----------------- | ---------------------------------------------------------------------------------------- |
| **حالت نمایش**    | کنار هم یا روی‌هم                                                                        |
| **OCR**           | فعال/غیرفعال کردن OCR برای مقایسهٔ اسناد اسکن‌شده                                        |
| **زبان OCR**      | زبان استخراج متن با OCR                                                                  |
| **فیلترهای دسته** | نمایش یا پنهان کردن تغییرات متن، تصویر، سرصفحه/پاصفحه، حاشیه‌نویسی، قالب‌بندی و پس‌زمینه |
| **دامنهٔ تغییر**  | در حالت روی‌هم، فیلتر بین همهٔ تغییرات یا فقط محتوا                                      |
| **بزرگ‌نمایی**    | تنظیم میزان بزرگ‌نمایی برای بررسی دقیق                                                   |

## کاربردها

- بازبینی نسخه‌های قرارداد برای یافتن دقیق تغییرات بین نسخه‌ها
- مقایسهٔ ماکت‌های طراحی برای اطمینان از مطابقت خروجی‌های PDF با انتظارات
- ممیزی تغییرات اسناد در صنایع تحت نظارت که هر ویرایش باید ردیابی شود
- اطمینان از اینکه فرایند تبدیل PDF محتوای اصلی را دقیق حفظ کرده است
- بررسی اسناد ترجمه در برابر منبع از نظر تغییرات چیدمان

## نکته‌ها

- نمای روی‌هم هر دو سند را روی یکدیگر قرار می‌دهد و تفاوت‌های مکانی (عناصر جابه‌جاشده، تصاویر تغییراندازه‌یافته) را بلافاصله نمایان می‌کند.
- هنگام مقایسهٔ اسناد اسکن‌شده‌ای که لایهٔ متنی ندارند، OCR را فعال کنید. موتور مقایسه متن را از تصاویر صفحه استخراج می‌کند.
- از فیلترهای دسته برای تمرکز روی موارد مهم استفاده کنید. برای مثال، وقتی فقط تفاوت‌های محتوای متنی برایتان مهم است، تغییرات قالب‌بندی را پنهان کنید.

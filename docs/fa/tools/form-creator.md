# ساخت فرم PDF

فرم‌های PDF حرفه‌ای قابل پر کردن را از ابتدا یا با افزودن فیلد به یک PDF موجود طراحی کنید. ویرایشگر بصری به شما امکان می‌دهد عناصر فرم (فیلدهای متنی، کادرهای انتخاب، منوهای کشویی، دکمه‌های رادیویی، فیلدهای امضا و موارد دیگر) را مستقیماً روی پیش‌نمایش صفحات بکشید و رها کنید. ویژگی‌های فیلدها را پیکربندی کنید، قواعد نمایش شرطی تعیین کنید و یک فرم PDF کاملاً تعاملی خروجی بگیرید.

## نحوهٔ کار

1. یک PDF موجود بارگذاری کنید **یا** برای شروع از ابتدا روی **ساخت PDF خالی** کلیک کنید.
2. اگر PDF خالی می‌سازید، اندازهٔ صفحه را انتخاب کنید (Letter، A4، A5، Legal، Tabloid، A3 یا ابعاد سفارشی).
3. ویرایشگر فرم با نوار ابزاری از انواع فیلد و یک ناحیهٔ پیش‌نمایش صفحه باز می‌شود.
4. یک نوع فیلد از نوار ابزار انتخاب کنید، سپس برای قرار دادن آن روی صفحه کلیک کنید.
5. فیلدها را برای جابه‌جایی بکشید. برای تنظیم ابعاد از دستگیره‌های تغییر اندازه استفاده کنید.
6. روی یک فیلد کلیک کنید تا پنل ویژگی‌ها باز شود؛ در آنجا می‌توانید نام فیلد، مقدار پیش‌فرض، اندازهٔ قلم، تراز و موارد دیگر را تنظیم کنید.
7. با کنترل‌های صفحه بین صفحات جابه‌جا شوید.
8. برای دانلود PDF قابل پر کردن نهایی روی **ذخیره** کلیک کنید.

## ویژگی‌ها

- قرار دادن فیلد با کشیدن و رها کردن و دستگیره‌های بصری برای تغییر اندازه
- انواع فیلد: ورودی متن، متن چندخطی، کادر انتخاب، منوی کشویی، دکمهٔ رادیویی، امضا، تاریخ، عدد و بارکد
- پنل ویژگی‌ها برای پیکربندی نام، برچسب، مقدار پیش‌فرض، اندازهٔ قلم، رنگ، تراز و اعتبارسنجی هر فیلد
- عملیات فیلد و قواعد نمایش شرطی (نمایش یا پنهان کردن فیلدها بر اساس مقادیر فیلدهای دیگر)
- پیمایش صفحات برای فرم‌های چندصفحه‌ای
- استخراج فیلدهای موجود: فیلدهای فرم را از PDFهای بارگذاری‌شده به‌طور خودکار شناسایی و وارد می‌کند
- پشتیبانی از PDFهای بارگذاری‌شده و صفحات خالی به‌عنوان بوم فرم
- چند پیش‌تنظیم اندازهٔ صفحه به‌علاوهٔ ابعاد سفارشی
- تولید بارکد با bwip-js
- مدیریت گروه دکمه‌های رادیویی

## گزینه‌ها

**پیش‌تنظیم‌های اندازهٔ صفحه (برای PDFهای خالی):**

- Letter (8.5" x 11")
- A4 (210mm x 297mm)
- A5 (148mm x 210mm)
- Legal (8.5" x 14")
- Tabloid (11" x 17")
- A3 (297mm x 420mm)
- سفارشی (تعیین عرض و ارتفاع)

**ویژگی‌های فیلد (بسته به نوع فیلد):**

- نام، برچسب و متن جایگزین
- مقدار پیش‌فرض
- خانوادهٔ قلم، اندازه و رنگ
- تراز متن (چپ، وسط، راست)
- گزینهٔ فیلد الزامی
- گزینهٔ فقط‌خواندنی
- حداکثر طول برای فیلدهای متنی
- فهرست گزینه‌ها برای منوهای کشویی و دکمه‌های رادیویی
- عملیات نمایش شرطی

## موارد استفاده

- ساخت فرم‌های ورود کارکنان با فیلدهای متنی برای اطلاعات شخصی و کادرهای انتخاب برای تأیید خط‌مشی‌ها
- ایجاد پرسشنامه‌های پذیرش مشتری با منوهای کشویی برای انتخاب خدمات
- طراحی فرم‌های سفارش با فیلدهای محاسبه‌شده و شناسه‌های بارکد
- ساخت چک‌لیست‌های بازرسی با دکمه‌های رادیویی برای ارزیابی قبول یا رد
- ایجاد فرم‌های نظرسنجی با پرسش‌های پیگیری شرطی که بر اساس پاسخ‌ها ظاهر می‌شوند

## نکات

- اگر یک PDF موجود بارگذاری کنید، ابزار تلاش می‌کند فیلدهای فرم موجود را استخراج کند تا بتوانید آن‌ها را ویرایش یا تکمیل کنید.
- برای ایجاد انتخاب‌های انحصاری از قابلیت گروه دکمه‌های رادیویی استفاده کنید. فیلدهای یک گروه رادیویی نام گروه مشترکی دارند.
- فرم خود را با دانلود و باز کردن آن در [پرکنندهٔ فرم PDF](./form-filler) آزمایش کنید تا رفتار فیلدها را بررسی کنید.

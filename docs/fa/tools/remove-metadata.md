# حذف فراداده

هر PDF فراداده‌ای دارد که می‌تواند نشان دهد چه کسی آن را ساخته، از چه نرم‌افزاری استفاده شده، آخرین بار کی تغییر کرده و موارد دیگر. این ابزار همهٔ آن را حذف می‌کند (دیکشنری اطلاعات، جریان‌های فرادادهٔ XMP، شناسه‌های سند و داده‌های ویژهٔ برنامه‌ها) و سندی تمیز بدون هیچ ردی از منشأ آن باقی می‌گذارد.

## نحوهٔ کار

1. یک فایل PDF بارگذاری کنید.
2. روی **حذف فراداده** کلیک کنید.
3. فایل پاک‌شده را دانلود کنید.

گزینه‌ای برای تنظیم وجود ندارد. ابزار عمداً جامع طراحی شده است: همه چیز را پاک می‌کند.

## چه چیزهایی حذف می‌شوند

- **فیلدهای دیکشنری اطلاعات**: عنوان، نویسنده، موضوع، کلیدواژه‌ها، سازنده، تولیدکننده، تاریخ ایجاد، تاریخ تغییر
- **جریان فرادادهٔ XMP**: بلوک فرادادهٔ مبتنی بر XML که در کاتالوگ سند ذخیره شده است
- **شناسه‌های سند**: شناسه‌های یکتا در بخش پایانی PDF که می‌توانند برای ردیابی سند در سامانه‌های مختلف استفاده شوند
- **PieceInfo**: فرادادهٔ ویژهٔ برنامه که برنامه‌هایی مانند Illustrator یا InDesign اضافه می‌کنند

## چه چیزهایی باقی می‌مانند

- همهٔ محتوای قابل مشاهدهٔ صفحه (متن، تصاویر، گرافیک)
- فیلدهای فرم و حاشیه‌نویسی‌ها
- نشانک‌ها و پیوندها
- خود ساختار سند

## موارد استفاده

- حذف نام خود و سازمانتان از سند پیش از انتشار ناشناس
- حذف زمان‌های ایجاد که نشان می‌دهند سند کی تهیه شده است
- پاک کردن رشته‌های تولیدکننده که نرم‌افزارهای PDF شما را مشخص می‌کنند
- آماده‌سازی اسناد برای ارسال‌های نظارتی که PDF بدون فراداده می‌خواهند
- حذف ردپای تاریخچهٔ ویرایش پیش از اشتراک سند با بیرون

## نکته‌ها

- ابتدا از ابزار مشاهدهٔ فراداده استفاده کنید تا دقیقاً ببینید PDF شما پیش از حذف چه فراداده‌ای دارد.
- اگر لازم است فراداده _و_ JavaScript، حاشیه‌نویسی‌ها و فایل‌های جاسازی‌شده را حذف کنید، برای پاک‌سازی کامل‌تر از پاک‌سازی PDF استفاده کنید.
- حذف فراداده دائمی است. اگر ممکن است بعداً به آن داده‌ها نیاز داشته باشید، فایل اصلی را نگه دارید.

## ابزارهای مرتبط

- [پاک‌سازی PDF](./sanitize-pdf): حذف فراداده به‌همراه اسکریپت‌ها، پیوست‌ها و موارد دیگر
- [رمزگذاری PDF](./protect-pdf): محافظت از PDF پاک‌شده با رمز عبور
- [فشرده‌سازی PDF](./compress-pdf): حذف فراداده حجم فایل را کمی کاهش می‌دهد؛ برای صرفه‌جویی بیشتر فشرده کنید

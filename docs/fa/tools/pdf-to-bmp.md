# PDF به BMP

هر صفحهٔ PDF را به یک تصویر BMP (Bitmap) تبدیل می‌کند. BMP قالبی بدون فشرده‌سازی است، بنابراین خروجی بدون هیچ افت کیفیتی دقیق تا سطح پیکسل است، اما فایل‌ها حجیم هستند.

## نحوهٔ کار

1. با کلیک روی ناحیهٔ رها کردن یا کشیدن فایل روی آن، یک PDF بارگذاری کنید.
2. برای پردازش فایل روی **تبدیل** کلیک کنید.
3. یک فایل `.bmp` یا یک بایگانی ZIP خودکار دانلود می‌شود.

## گزینه‌ها

این ابزار گزینهٔ قابل‌تنظیمی ندارد. صفحات با مقیاس ثابت 2x رندر می‌شوند و تصاویری تقریباً دو برابر ابعاد اصلی صفحهٔ PDF تولید می‌کنند.

## قالب خروجی

- **تک‌صفحه**: `filename.bmp`
- **چندصفحه**: `filename_bmps.zip` شامل `page_1.bmp`، `page_2.bmp` و غیره.

## موارد استفاده

- ارسال صفحات PDF به سامانه‌ها یا سخت‌افزارهای قدیمی که فقط ورودی BMP می‌پذیرند.
- آماده‌سازی تصاویر بدون فشرده‌سازی برای گردش‌کارهای چاپی خاص.
- استفاده از خروجی بیت‌مپ به‌عنوان ورودی ابزارهای پردازش تصویر که دادهٔ خام پیکسل می‌خواهند.

## نکته‌ها

- فایل‌های BMP بسیار حجیم‌اند، چون دادهٔ خام پیکسل را بدون فشرده‌سازی ذخیره می‌کنند. برای بیشتر کاربردها، [PDF به PNG](./pdf-to-png) کیفیت بدون افت را با فایل‌های بسیار کوچک‌تر ارائه می‌دهد.
- اگر سامانهٔ مقصد شما PNG یا TIFF می‌پذیرد، برای صرفه‌جویی در فضای دیسک آن قالب‌ها را ترجیح دهید.

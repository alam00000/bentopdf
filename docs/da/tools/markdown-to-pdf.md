# Markdown til PDF

En fuldt udstyret Markdown-editor med live forhåndsvisning og PDF-eksport med ét klik. Skriv fra bunden, upload en eksisterende `.md`-fil, eller indsæt indhold fra udklipsholderen. Editoren gengiver din Markdown i realtid og eksporterer en formateret PDF med browserens indbyggede udskriftsmotor.

## Understøttede formater

| Input         | Beskrivelse                   |
| :------------ | :---------------------------- |
| `.md`-filer   | Upload med knappen Upload     |
| Direkte input | Skriv eller indsæt i editoren |

## Sådan fungerer det

1. Åbn værktøjet Markdown til PDF. Editoren indlæses med delt visning: Markdown-kilde til venstre og gengivet forhåndsvisning til højre.
2. Skriv din Markdown, indsæt den, eller klik på **Upload** for at indlæse en `.md`-fil.
3. Skift mellem lyst og mørkt tema med temaskyderen på værktøjslinjen.
4. Klik på **Eksportér PDF** (eller tryk på `Ctrl/Cmd + S`) for at generere en PDF via browserens udskriftsdialog.

## Funktioner

Editoren understøtter et omfattende sæt Markdown-funktioner ud over det grundlæggende:

- **Standard-Markdown**: overskrifter, fed, kursiv, links, billeder, lister, blokcitater, vandrette streger
- **Kodeblokke** med syntaksfremhævning for 15+ sprog (JavaScript, TypeScript, Python, Go, Rust, SQL, Java, C#, C++, YAML, Bash og flere)
- **Mermaid-diagrammer**: rutediagrammer, sekvensdiagrammer, ER-diagrammer og andre Mermaid-diagramtyper gengives direkte i forhåndsvisningen
- **Tabeller** med standard Markdown-tabelsyntaks
- **Opgavelister** med afkrydsningsfelter
- **Fodnoter**, **sænket skrift**, **hævet skrift**
- **Definitionslister**, **forkortelser**
- Understøttelse af **emoji** (`:smile:` gengives som emojien)
- **Fremhævninger** (`==marked text==`) og **indsættelser** (`++inserted text++`)
- **Automatiske links**: almindelige URL'er konverteres til klikbare links
- Generering af **indholdsfortegnelse**
- **Ankerlinks** på overskrifter

## Anvendelsesområder

- Skrivning af projektdokumentation og eksport af en poleret PDF til interessenter
- Oprettelse af tekniske rapporter med kodeeksempler og Mermaid-arkitekturdiagrammer
- Konvertering af en GitHub README til en PDF til offlinebrug eller udskrivning
- Udarbejdelse af et forslag eller en specifikation med opgavelister og tabeller
- Generering af et formateret handout fra forelæsningsnotater skrevet i Markdown

## Tips

- PDF-outputtet bruger browserens funktion til at udskrive til PDF. I Chrome kan du tilpasse margener og skalering i udskriftsdialogen, før du gemmer.
- Mermaid-diagrammer gengives i forhåndsvisningen, men kan have brug for et øjeblik til at initialisere ved første brug.
- Brug `Ctrl/Cmd + S` som tastaturgenvej til at eksportere uden at række ud efter knappen.

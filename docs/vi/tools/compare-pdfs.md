# So sánh PDF

Tải lên hai PDF và xem chính xác điều gì đã thay đổi giữa chúng. Công cụ ghép cặp các trang một cách thông minh, phát hiện khác biệt về văn bản, hình ảnh, chú thích, đầu trang và định dạng, rồi hiển thị chúng ở dạng cạnh nhau hoặc chồng lớp.

## Cách hoạt động

1. Tải lên hai tệp PDF: bản gốc (bên trái) và bản đã sửa (bên phải).
2. Công cụ ghép cặp các trang giữa hai tài liệu dựa trên chữ ký nội dung.
3. Chọn chế độ xem: **Cạnh nhau** hoặc **Chồng lớp**.
4. Chuyển giữa các cặp trang bằng điều khiển phân trang.
5. Các khác biệt được đánh dấu và phân loại. Dùng bảng bộ lọc để tập trung vào các loại thay đổi cụ thể.
6. Có thể xuất kết quả so sánh thành báo cáo PDF.

## Tính năng

- Tự động ghép cặp trang dựa trên độ tương đồng nội dung
- Chế độ xem so sánh cạnh nhau và chồng lớp
- Phân loại thay đổi: văn bản, hình ảnh, đầu trang/chân trang, chú thích, định dạng, nền
- Công tắc bộ lọc theo từng loại để hiện hoặc ẩn các loại thay đổi cụ thể
- Tìm kiếm thay đổi văn bản với bộ lọc truy vấn
- Hỗ trợ OCR để so sánh tài liệu quét
- Điều khiển thu phóng để kiểm tra chi tiết
- Cuộn đồng bộ giữa các bảng ở chế độ cạnh nhau
- Xuất kết quả so sánh thành PDF

## Tùy chọn

| Tùy chọn             | Mô tả                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| **Chế độ xem**       | Cạnh nhau hoặc Chồng lớp                                                                          |
| **OCR**              | Bật/tắt OCR để so sánh tài liệu quét                                                              |
| **Ngôn ngữ OCR**     | Ngôn ngữ để trích xuất văn bản bằng OCR                                                           |
| **Bộ lọc loại**      | Bật/tắt hiển thị thay đổi về văn bản, hình ảnh, đầu trang/chân trang, chú thích, định dạng và nền |
| **Phạm vi thay đổi** | Ở chế độ chồng lớp, lọc giữa tất cả thay đổi hoặc chỉ nội dung                                    |
| **Thu phóng**        | Điều chỉnh mức phóng đại để kiểm tra chi tiết                                                     |

## Trường hợp sử dụng

- Xem lại các bản sửa hợp đồng để tìm chính xác điều gì đã thay đổi giữa các phiên bản
- So sánh bản mockup thiết kế để xác nhận PDF xuất ra đúng như mong đợi
- Kiểm toán thay đổi tài liệu trong các ngành được quản lý, nơi mọi chỉnh sửa đều phải được theo dõi
- Xác minh quá trình chuyển đổi PDF giữ nguyên nội dung gốc một cách chính xác
- Đối chiếu tài liệu dịch với bản gốc để tìm thay đổi về bố cục

## Mẹo

- Chế độ chồng lớp xếp hai tài liệu lên nhau, giúp các khác biệt về không gian (phần tử bị dịch chuyển, hình ảnh bị đổi kích thước) hiện ra ngay lập tức.
- Bật OCR khi so sánh tài liệu quét không có lớp văn bản. Engine so sánh sẽ trích xuất văn bản từ ảnh trang.
- Dùng bộ lọc loại để tập trung vào điều quan trọng. Ví dụ, ẩn thay đổi định dạng khi bạn chỉ quan tâm đến khác biệt về nội dung văn bản.

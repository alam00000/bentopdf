Frequently Asked Questions

Can I change the existing text in a PDF?

Edit PDF Text lets you click any paragraph and rewrite it in place, with the surrounding text reflowing as you type and controls for fonts and styling. For adding new text boxes, comments, highlights, shapes, or images on top of the page, use the general Edit PDF tool instead.

What can I do in the Edit PDF tool?

The Edit PDF toolbar covers highlighting, underlining, strikethrough, freehand drawing, text and comments, shapes and images, permanent redaction, and full-text search. It keeps the original PDF structure, so fonts, layouts, and form fields stay intact, and you can keep up to 10 documents open in tabs and switch between them.

How do I make a PDF smaller?

Compress PDF strips unused structure, downsamples images, and subsets fonts while keeping text selectable and links working. Start with the Medium level, or enter a target file size, and only step up to High if the file is still too large.

Which editing tools keep my text selectable?

Page-level tools such as Rotate, Organize, Delete Pages, Background Color, and Remove Annotations work on the PDF structure and leave text searchable. Invert Colors, Change Text Color, and PDF to Greyscale re-render every page as an image, so text in their output can no longer be selected or searched. If you need searchable text after one of those, run the result through OCR PDF.

Can I add page numbers or a header and footer?

Page Numbers puts a number in any of six positions on every page, in plain or "page X of Y" style, with your choice of font size and color. Header and Footer adds text to six slots per page (left, center, and right at top and bottom), understands {page} and {total} placeholders so a footer like "Page {page} of {total}" fills in correctly on each page, and can be limited to a page range.

Can I put a watermark on every page?

Add Watermark stamps text or an image onto your pages, and you position it by dragging on a live preview, then set opacity, rotation, and size. A tiled mode repeats the mark across the whole page so it's much harder to crop out, and you can apply one watermark to all pages, restrict it to a page range, or set a different watermark on each page.

Can I rotate a single page, or fix a slightly tilted scan?

Rotate PDF shows a thumbnail of every page with its own left and right buttons for 90-degree turns, plus a bulk control for the whole document. For a scan that's off by a few degrees, Rotate by Custom Degrees accepts any angle, per page or for all pages at once.

Does editing a PDF here upload it anywhere?

No. The editor and every other tool on this page run as WebAssembly inside your browser, so the file is opened, changed, and saved on your own device without a server in between. Nothing is stored, so there's no copy to delete when you're done.

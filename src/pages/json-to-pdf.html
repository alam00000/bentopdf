الأسئلة الشائعة

هل يمكنني تحويل أي ملف JSON إلى PDF بهذه الأداة؟

لا. تعيد الأداة إنشاء PDF فقط من ملفات JSON الصادرة عن أداة بيكسل PDF PDF إلى JSON ، التي تحفظ البنية الداخلية الكاملة للمستند. سيفشل استيراد JSON من واجهة برمجية أو قاعدة بيانات أو ملف إعدادات برسالة خطأ.

كيف أحوّل بيانات API أو ملف إعدادات إلى ملف PDF مقروء بدلًا من ذلك؟

الصق JSON أو ارفعه كنص عادي في نص إلى PDF، الذي ينسّقه كنص منسّق على الصفحات. أما JSON إلى PDF فهو فقط للتحويل ذهابًا وإيابًا للمستندات التي بدأت كملفات PDF.

هل سيطابق ملف PDF المعاد بناؤه الأصل؟

يلتقط JSON الناتج عن PDF إلى JSON كائنات المستند، لذا يعيد تحويله مرة أخرى إنتاج صفحات المصدر ونصوصه وصوره. والتحويل ثم المقارنة وسيلة سريعة أيضًا للتأكد من أن التصدير التقط كل شيء.

ما الناتج عند تحويل عدة ملفات JSON؟

يُنزَّل كل تحويل باسم jsons-to-pdf.zip، حتى للملف الواحد. وبداخله يحمل كل ملف PDF اسم ملف JSON المصدر، فيصبح report.json هو report.pdf.

هل يمكنني تعديل JSON قبل تحويله مرة أخرى؟

نعم، ما دامت البنية تبقى صالحة لمحرك CPDF. التغييرات البرمجية على JSON، مثل البيانات الوصفية أو كائنات النص المعدّلة، تُعاد بناؤها في PDF؛ أما التعديل المشوّه فيسبب خطأ في التحويل.

لماذا تقول الأداة إن محرك CPDF غير متاح؟

يعتمد التحويل على نسخة CPDF الخاصة بـ WebAssembly. وهي مضمّنة على pixelpdf.com، لكن النسخ المستضافة ذاتيًا تحتاج إلى إعداد ملفات CPDF WASM في إعدادات WASM قبل تشغيل هذه الأداة.

هل يُرفع ملف JSON إلى خادم؟

لا. تُقرأ الملفات في متصفحك وتُعاد بناؤها كملفات PDF بواسطة Web Worker يشغّل محرك CPDF محليًا، فلا يُرسل شيء وتبقى الصفحة مستجيبة أثناء التحويلات الكبيرة.

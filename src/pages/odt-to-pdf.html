Frequently Asked Questions

How do I convert an ODT file to PDF without LibreOffice installed?

Drop the .odt file on the page and click Convert to PDF. A build of LibreOffice compiled to WebAssembly loads inside your browser and does the conversion, so you don't need LibreOffice, OpenOffice, or Word on the computer.

Why is converting the first ODT file slower?

The LibreOffice engine is roughly 75 MB compressed and has to be downloaded and started the first time you convert in a session; a progress indicator shows the percentage. Once it's loaded, further conversions in the same session start right away.

Will my formatting, tables, and images be preserved?

The conversion uses LibreOffice's own PDF export, so styles, tables, images, and page layout come through the way Writer would print them. Documents with embedded OLE objects or fonts that aren't available may render slightly differently, so check one sample before converting a large batch.

Can I convert multiple ODT files at once?

Add as many .odt files as you like, remove any you don't want from the list, and convert them in one go. A single file downloads as a PDF named after the original; two or more arrive in odt-converted.zip with one PDF per file.

What about .docx, .doc, or .ott files?

This page accepts only .odt. Word documents go through Word to PDF, which uses the same engine, and an .ott template should be opened and saved as .odt before converting.

Will the PDF text be selectable and searchable?

The PDF is exported from the document's actual text rather than a picture of the page, so the text can be selected, copied, and searched in any viewer.

Does it work with ODT files from OpenOffice or other programs?

Any standard OpenDocument Text file is accepted regardless of which program saved it, including LibreOffice Writer, Apache OpenOffice, and other word processors that write .odt.

Is my ODT document uploaded to convert it?

No. The LibreOffice engine runs entirely inside your browser, so the .odt file is read and the PDF is written on your own device. That makes it usable for confidential contracts, theses, and anything else you'd rather not put on a conversion server.

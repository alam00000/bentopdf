Frequently Asked Questions

Does each WebP image become its own page?

Yes. Every image is placed on a separate page sized to the image itself, in the order the files appear in the list, and the whole set downloads as one file named from_webps.pdf.

What page size will my WebP images get in the PDF?

The page matches the image's pixel dimensions at one point per pixel, so a 1600 x 1200 image produces a 1600 x 1200 point page, roughly 22 x 17 inches. To get standard A4 or Letter pages, run the result through Fix Page Size.

What do the quality settings change for WebP images?

High keeps the full pixel dimensions with the lightest compression. Medium, the default, re-encodes as JPEG at about 75 percent and scales images down so the longest side is at most 2500 pixels; Low uses about 50 percent and a 1500 pixel cap, which gives the smallest files.

Will transparent areas stay transparent?

No. Images are re-encoded through the browser's canvas as JPEG when they're embedded, and JPEG has no alpha channel, so see-through regions come out as a solid background. Flatten the image onto a white background in an image editor first if that matters.

Can I convert an animated WebP?

Only the first frame is used, since the browser decodes the file as a still image before it's placed on the page. Each animation becomes a single static page.

Can I mix WebP with JPG or PNG files in the same PDF?

Not on this page; the file picker accepts .webp only. Use Images to PDF, which takes WebP, JPG, PNG, and other formats together in a single conversion.

Are my images uploaded to make the PDF?

No. Each WebP is decoded by your browser's own image engine and written into the PDF locally, so the pictures never leave your device.

Can I reorder or remove images before converting?

You can remove any file from the list with its delete icon, but there's no drag reordering on this page, so pages follow the order in which you selected the files. Pick them in the order you want them to appear.

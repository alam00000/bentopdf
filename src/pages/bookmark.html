    Frequently Asked Questions

    How do I add bookmarks to a PDF that doesn't have any?

    Upload the PDF, go to a page, type a title, and click Add to Page; drag entries to nest or reorder them. Click Save PDF with Bookmarks to download the result. For a printed contents page inside the document rather than sidebar navigation, use Table of Contents instead.

    Will my existing bookmarks be kept?

    Only if you check Auto-extract existing bookmarks before uploading, or use the extract button afterward, so they load into the panel. When you save, the panel's contents replace the PDF's bookmark tree entirely, so anything not loaded into the editor is dropped.

    What is the CSV format for importing bookmarks?

    A header row followed by one line per bookmark with three columns: title,page,level. Titles containing commas go in double quotes, page is the 1-based page number, and level controls nesting, with the lowest number for top-level entries and each deeper child adding one.

    Can a bookmark jump to a specific spot on a page instead of the top?

    Open the bookmark's edit dialog, turn on Set custom destination, and either type X and Y coordinates plus a zoom percentage or click the pick button and then click the exact spot on the page preview. The bookmark is saved as an XYZ destination, which most readers honor.

    Can I color or bold bookmarks?

    Each bookmark can be red, blue, green, yellow, purple, or a custom hex color, and styled bold, italic, or bold italic. Turn on Batch Mode to select several bookmarks and apply a color or style to all of them at once.

    How do I get bookmarks out of a PDF for editing in a spreadsheet?

    Load them with Auto-extract, then use Export to CSV or Export to JSON; the file is named after your PDF with a -bookmarks suffix. The CSV opens in Excel or Google Sheets, and once you've edited it you can import it back and save a new PDF.

    Does the editor work on password-protected PDFs?

    You'll be asked for the password when you upload the file, and the editor opens once it's entered. The saved PDF is written without the password, so protect it again afterward if you need to.

    Is my PDF uploaded while I edit bookmarks?

    No. The page preview, the bookmark tree, and the final save are all handled in your browser with PDF.js and pdf-lib, so the file never leaves your computer.

Frequently Asked Questions

How do I add Page X of Y to every page?

Type Page {page} of {total} in any of the six fields, usually Footer Center. {page} is replaced with that page's number and {total} with the page count, so a 12-page file gets Page 1 of 12 through Page 12 of 12.

Can I put different text on the left, center, and right?

Yes. There are six independent fields: header left, center, and right, plus footer left, center, and right. Fill only the ones you need, for example a company name at header left, the date at header right, and a confidentiality notice at footer center; empty fields are skipped.

Can I apply the header only to certain pages?

Yes. Enter a range like 1-3, 5 in the Page Range field and only those pages get the text; leave it empty to cover every page. The {page} value still reflects the real page number, so page 5 reads 5 even when pages 1 through 4 were skipped.

What font and size does it use?

Helvetica, at any size from 6 to 24 points (10 by default), in the color you pick. Because it uses the built-in PDF Helvetica, the text is limited to Latin characters; accented letters work, but scripts such as Cyrillic, Arabic, or Chinese don't.

Will it replace the header my document already has?

No. The text is drawn on top of the existing page content about 40 points (a bit over half an inch) from the edge, so if a page already has a running header in that spot the two will overlap. Check the result and pick a different position if they collide.

Is the header text selectable and searchable afterward?

Yes. It's added as real text rather than an image, so it can be selected, searched, and copied, and it stays sharp when printed at any size.

Is my document uploaded to add a header and footer?

No. The text is written into the PDF by your browser and the finished file is saved under its original name; the document never leaves your device.

Can I add page numbers without any other text?

Yes, put {page} alone in a field. Page Numbers does the same job with a dedicated layout and font sizes up to 72 points, and Add Page Labels handles Roman numerals in the viewer's page display.
